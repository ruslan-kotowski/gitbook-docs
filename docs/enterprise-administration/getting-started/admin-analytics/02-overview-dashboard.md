The Overview dashboard provides insights that enable you to track adoption and understand your organization's activity through the following metrics:

- **Boards:** View board totals, see how many boards are active in terms of usage, and follow historical trends.
- **Users:** Track how many users are actively engaging with Miro over time. You can also track based on a specific user role, such as members, company admins, guests, or team guests.
- **Teams:** Monitor team counts and check activity levels.
- **Licenses:** Track different types of allocated licenses and see how this changes over time.
- **Templates:** Discover which templates are being used most across your organization.

## Working with the Overview dashboard

Keep the following considerations in mind when working with metrics in the Overview dashboard:

- **Time range selector:** Use the selector at the top right of the Analytics page to adjust the time range displayed in the Overview dashboard (daily, weekly, monthly, or quarterly).
- **Analytics view settings:** Click the **gear icon** next to the time range selector to open the settings. Under **User privacy**, choose whether to show or hide user names in analytics dashboards that include user-level activity, such as top AI users. **User names are shown by default.** Click **Save** to apply your changes.
- **Last updated:** Metrics are refreshed daily. A Last updated timestamp is shown in each dashboard.
- **Partial data:** If a feature was disabled for part of a selected period, you may see partial data in the metrics history (for example, if a feature was enabled mid-month).
- **No data:** If no activity was recorded in a given period (day, week, or month), the chart will show no data for that timeframe.
- **Historical data display:**

  - In all widgets that show historical data, values represent data as of the last day of each period. For example, if the selected period type is monthly, the Boards chart shows the count of boards at the end of each month.
  - The current ongoing period is not displayed in historical charts. For example, if the selected period type is monthly and the current month is September, the chart will show data only up to August (the last completed period).
  - Historical data is available for up to one year or as far back as the data exists. If older data appears missing, contact Miro Support to request backfill verification.

## Boards analytics

The Boards chart displays the total number of boards, number of boards active in terms of usage, and allows you to view and analyze historical trends. The following table lists the information available in the Boards chart.

| Metric name | Description |
| --- | --- |
| (1) Total | Total number of boards. This excludes boards that are in Trash. |
| (2) Active this &lt;time range selected&gt; (either quarter/month/week/yesterday) | Total number of unique boards that have been opened since the start of the selected period. This includes boards that may have been moved to Trash. |
| (3) Total boards plotted in the chart | Total number of boards at the end of the plotted date or month. This excludes boards that were in Trash. |
| (4) Active boards plotted in the chart | Total number of unique boards that were opened since the start of the plotted date or month. This includes boards that may have been moved to Trash. |

*Note: These metrics are updated at least once every 24 hours. The Last Updated information at the top left of the Analytics page indicates when the most recent metric update was done.*

## Users analytics

The Users chart displays how many users are actively engaging with Miro over time. You can also track user analytics based on a specific user role, such as members, company admins, guests, or team guests. The following table lists the information available in the Users chart.

| Metric name | Description |
| --- | --- |
| (1) Total | Total number of users, including members, company admins, guests, and team guests. The total number changes based on the user type you select in the list. |
| (2) Active this &lt;time range selected&gt; (either quarter/month/week/yesterday) | Total number of unique users who opened a board at least once since the start of the selected period. This includes users who are now deactivated.  The total number changes based on the user type you select in the list. |
| (3) Total users plotted in the chart | Total number of users, including members, company admins, guests, and team guests, at the end of each plotted period.  The total number changes based on the user type you select in the list. |
| (4) Active users plotted in the chart | Total number of unique users who opened a board at least once since the start of each plotted period.  This includes users who are now deactivated. The total number changes based on the user type you select in the list. |

*Note: These metrics are updated at least once every 24 hours. The Last Updated information at the top left of the Analytics page indicates when the most recent metric update was done.*

## Teams analytics

The Teams chart displays team counts and activity levels. The following table lists the information available in the Teams chart.

| Metric name | Description |
| --- | --- |
| (1) Total | Total number of teams.  This excludes teams that are in Trash. |
| (2) Active this &lt;time range selected&gt; (either quarter/month/week/yesterday) | Total number of unique teams whose members opened a board at least once since the start of the selected period.  This includes teams that may have been moved to Trash. |
| (3) Total teams plotted in the chart | Total number of teams at the end of the plotted date or month. This excludes teams that were in Trash. |
| (4) Active teams plotted in the chart | Total number of teams whose members opened a board at least once since the start of the plotted date or month.  This includes teams that may have been moved to Trash. |

*Note: These metrics are updated at least once every 24 hours. The Last Updated information at the top left of the Analytics page indicates when the most recent metric update was done.*

## Licenses analytics

The Licenses chart displays different types of allocated licenses and allows you to track license allocation changes over time. The following table lists the information available in the Licenses chart.

| Metric name | Description |
| --- | --- |
| Allocated | Total number of allocated licenses, including Advanced, Standard, Full (legacy), Free, Free Restricted licenses. This indicates the number of licenses currently used in your organization.  The total number changes based on the license type you select in the list. |
| Allocation history plotted in the chart | Total count of allocated licenses at the end of each plotted period.  The total number changes based on the license type you select in the list. |

*Note: These metrics are updated at least once every 24 hours. The Last Updated information at the top left of the Analytics page indicates when the most recent metric update was done.*

## Templates analytics

The Most popular templates section shows the templates used most frequently across your organization. Currently, this data includes only templates added directly from a board, not from other sources such as miro.com/templates. Support for additional sources will be added in future releases.

*Note: These metrics are updated at least once every 24 hours. The Last Updated information at the top left of the Analytics page indicates when the most recent metric update was done.*
