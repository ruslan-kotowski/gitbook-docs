Gain detailed insights into how Miro AI is used across your company. The Miro AI dashboard shows the number of teams and users that are adopting AI features, and provides a historical view of AI usage by category. The AI dashboard also shows what your organization creates with AI and which AI-powered actions are used most. This helps you understand usage patterns, support champions, and guide responsible rollout of AI.

The Miro AI dashboard shows data to track adoption and understand how Miro AI is used across your organization through the following metrics:

- **Created with AI:** See what your organization created with AI (for example, diagrams, documents, images, tables, and sticky notes) and review usage history over time.
- **AI-powered actions:** See how often people used AI-powered actions (for example, editing text, removing an image background, or adding captions to an image) and review usage history over time.
- **Teams using AI:** See the number of teams that are actively using AI features, along with the total number of active teams using vs. not using AI.

  Filter by **All use cases**, **Created with AI**, or **AI-powered actions**. Review usage history to compare adoption trends across teams over time.
- **People using AI:** Track adoption, including totals of people using vs. not using AI.
  Filter by **All use cases**, **Created with AI**, or **AI-powered actions**. Review usage history to see how usage grows or declines among users over time.
- **Top AI users:** List of the top 10 users by Miro AI usage during the selected period (Quarterly, Monthly, Weekly, Daily).
- **Sidekick collaborations:** Understand how frequently teams engage with Miro Sidekicks through conversations and interactions. This includes prompts, follow-up questions, and responses within the Sidekick chat. The analytics data displays the number of sessions that were started.
- **Executed AI flows:** View the total number of times users have run a Miro AI flow that includes at least two consecutive steps or nodes. Each flow consists of multiple steps and may run over a period of time. The execution is counted at the timestamp of the first event associated with the flow.

## Working with the Miro AI dashboard

Keep the following considerations in mind when working with metrics in the Miro AI dashboard:

- **Time range selector:** Use the selector at the top right of the Miro AI dashboard to adjust the time range displayed (daily, weekly, monthly, or quarterly).
- **Analytics view settings:** Click the **gear icon** next to the time range selector to open the settings. Under **User privacy**, choose whether to show or hide user names in analytics dashboards that include user-level activity, such as top AI users. **User names are shown by default.** Click **Save** to apply your changes.
- **Last updated:** Metrics are refreshed daily. A **Last updated** timestamp appears in the dashboard to indicate the most recent data update.
- **Partial data:** If Miro AI features were disabled for part of a selected period, you may see partial data in the metrics history (for example, if Miro AI was enabled mid-month).
- **No data:** If no AI activity was recorded during a given period (day, week, or month), the chart will show no data for that timeframe.
- **Historical data display:**

  - In widgets that show historical data, values represent data as of the last day of each period. For example, if the selected period type is monthly, the Executed AI flows chart shows the count of flows at the end of each month.
  - The current ongoing period is not displayed in historical charts. For example, if the selected period type is monthly and the current month is September, the chart will show data only up to August (the last completed period).
  - Historical data is available for up to one year or as far back as Miro AI data exists.
- **AI use cases:** For widgets that include a use case filter (for example, Teams using AI and People using AI), use cases are defined as follows:
  - **Created with AI:** AI-generated content that creates board items (for example, diagrams, documents, images, tables, and sticky notes).
  - **AI-powered actions:** AI features that modify or transform existing content (for example, editing or translating text, removing an image background, or adding captions to an image).

## Miro AI metrics

The following table lists the information available in the Miro AI charts:

| Metric name | Description |
| --- | --- |
| Created with AI (total) | Total number of items created with AI since the start of the selected period, broken down by content type (for example, diagrams, documents, images, tables, and sticky notes). |
| Created with AI over time | Historical view of items created with AI over time, based on the selected period. |
| AI-powered actions (total) | Total number of AI-powered actions used since the start of the selected period, broken down by action type (for example, edit/refine/translate text, remove image background, add captions to image). |
| AI-powered actions over time | Historical view of AI-powered actions over time, based on the selected period. |
| Total teams using AI | Total number of unique teams whose members used Miro AI at least once since the start of the selected period. Usage can be filtered by use case (All use cases, Created with AI, or AI-powered actions). |
| Total teams using AI over time | Historical view of AI usage by teams over time based on the selected period and use case filter. |
| Total teams not using AI | Total number of unique active teams whose members have not used Miro AI at least once since the start of the selected period. Usage can be filtered by use case (All use cases, Created with AI, or AI-powered actions). |
| Total teams not using AI over time | Historical view of unique active teams whose members have not used Miro AI over time, based on the selected period and use case filter. |
| Total users using AI | Total number of unique users who used Miro AI at least once since the start of the selected period. Usage can be filtered by use case (All use cases, Created with AI, or AI-powered actions). |
| Total users using AI over time | Historical view of AI usage by users over time based on the selected period and use case filter. |
| Total users not using AI | Total number of unique active users who have not used Miro AI at least once since the start of the selected period. Usage can be filtered by use case (All use cases, Created with AI, or AI-powered actions). |
| Total users not using AI over time | Historical view of unique active users who have not used Miro AI over time, based on the selected period and use case filter. |
| Top AI users | List of the top 10 users by Miro AI usage during the selected period (Quarterly, Monthly, Weekly, Daily). |
| Sidekick collaborations | Total number of Sidekick collaborations that took place in the selected period (day, week, month, or quarter). Each collaboration starts when a user triggers a Sidekick action, including prompts, follow-up questions, and responses within the Sidekick chat. A chat is counted once, at the moment the first message is sent by the user. Although a chat can continue for an indefinite period, it is recorded as a single collaboration. |
| Historical Sidekick collaborations | Historical view of Sidekick collaborations that took place over time in each selected period (day, week, month, or quarter). Each collaboration starts when a user triggers a Sidekick action. |
| Executed AI flows | Total number of multi-step AI flow executions that took place in the selected period (day, week, month, or quarter). Each execution is unique and includes AI actions across all flow steps. |
| Historical executed AI flows | Historical view of multi-step AI flow executions over time in each selected period (day, week, month, or quarter). Each execution is unique and includes AI actions across all flow steps. |

:::note
These metrics are updated at least once every 24 hours. The **Last updated** information at the top left of the Analytics page indicates when the most recent metric update was done.
:::
