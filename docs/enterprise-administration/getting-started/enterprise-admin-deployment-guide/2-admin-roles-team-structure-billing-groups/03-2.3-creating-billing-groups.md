To easily track license usage and renewals for users in your Miro Enterprise subscription, you can optionally create and assign users to a billing group.

For example, create a billing group for each department or cost center, like Design, Marketing, and Product. Then you can appropriately assign users to each group. With users mapped to their respective billing group, you simplify your process for managing licenses, tracking expenses, renewals, true-ups, and ensure effective allocation of resources and budget.

**More information:** See [Billing groups](../../../enterprise-subscription-management/enterprise-billing/01-billing-groups.md).

## How to create a billing group

The following procedure explains how to create a billing group. Repeat the procedure for as many billing groups as you need.

#### Prerequisites

During the create procedure, you can optionally upload a CSV file that includes the email address for each user you want to add to the billing group.

If you choose this method, have your CSV file ready. To learn more, see [How to bulk-add users to a billing group with a CSV file](#how-to-bulk-add-users-to-a-billing-group-with-a-csv-file).

:::note
You can complete the following procedure without adding users to the billing group. If you want to add users later, this article includes separate instructions for user assignment, and options for bulk assignment.
:::

#### Procedure

Follow these steps:

1. Go to **Admin console**.
2. Under **Account**, select **Subscription**.
3. Select **Billing groups**.
4. Select **Create billing group**.
5. Enter a name for your billing group.
6. (Optional) Enter a description for the group.
7. (Optional) To limit the number of licenses available to a billing group, set a soft quota:
   1. Enable **Add quota for full licenses**.
   2. Input a number for the license limit.
8. (Optional) To bulk-add users to the billing group, upload your CSV file.
9. (Optional) To assign a contact for notification about license usage, enter a user email address.
10. Select **Create billing group**.

    You have successfully created a billing group.

:::tip
To edit a billing group, go to **Admin Console** > **Subscription** > **Billing groups**, and select the three dots (**...**) for the billing group you want to edit.
:::

## How to add a user to a billing group

This following procedure explains how to add a user to a billing group.

Follow these steps:

1. Go to **Admin console**.
2. Under **User management**, select **Active users**.
3. Select the three dots (**...**) for the user you want to add.
   A drop-down menu opens.
4. Select **Change billing group**.
5. Select a billing group.
6. Select **Assign user**.

   You have successfully added a user to a billing group.

## How to bulk-add users to a billing group

The following procedure explains how to bulk-add users to a billing group.

Follow these steps:

1. Go to **Admin console**.
2. Under **User management**, select **Active users**.
3. Select or filter the users you want to add to a billing group.
4. Select **Bulk actions**.
5. Select **Assign billing group**.
6. Select a billing group.
7. Select **Assign users**.

   You have successfully bulk-added users to a billing group manually.

## How to bulk-add users to a billing group with a CSV file

The following procedure explains how to use a CSV file to bulk-add users to a billing group.

Follow these steps:

1. Go to the **Admin console**.
2. Under **Account**, select **Subscription**.
3. Select **Billing groups**.
4. Select the three dots (**...**) for the billing group you want to edit.
5. Select **Edit**.
   The **Edit billing group** view opens.
6. Select **Upload CSV file** (see [prerequisites](#prerequisites)).
7. Choose the CSV file that you want to upload then select **Open**.
8. Select **Save**.

   You have successfully bulk-added users to a billing group with a CSV file.
