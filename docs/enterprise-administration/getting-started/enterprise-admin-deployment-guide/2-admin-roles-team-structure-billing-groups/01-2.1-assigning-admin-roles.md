Decide which users in your organization have an admin role. A role in Miro defines access permissions to content for a given user.

Miro Enterprise includes admin roles, and non-admin, collaboration only roles. For example, most users will have a non-admin role—like Member or Guest; while some users will manage privileges for their teams as Team Admins.

Your Miro Enterprise plan includes the following admin roles:

- **Company Admin**
  Specifies the default permissions, security, sharing, and provisioning for all users. The Company Admin has the highest permissions set, and can view and manage all teams.
- **Content Admin**
  Can modify access to any Space, board, and template, including sharing settings. The Content Admin also manages board deletion, and trash restoration and retention. For Spaces and sections, the Content Admin can change metadata, move and delete boards inside a Space or section, and move boards to another Space or section. The same privileges apply to private boards, Spaces, and sections.
- **Security Admin**
  Can modify settings for authentication, collaboration, and domains. The Security Admin can also configure and export audit logs.
- **Team Admin**
  Can manage access rights and other team properties as a member in a given team.
- **User Admin**
  Can manage roles, permissions, and license requests for users. A user admin can also add or remove a user.

Your plan also includes the following non-admin roles:

- **Member**
  Can access and provisionally create and edit any board shared within their team.
- **Guest**
  Can view any board by [invitation only](../../../../using-miro/sharing-boards/07-collaboration-with-guests.md).
- **Visitor**
  Can view any public board by invitation only.

## How to assign admin roles in Miro

Follow these steps:

1. Go to **Admin console**.
2. Under **User management**, select **Admin roles**.
3. For any admin role, select the three dots (**...**).
   A drop-down menu opens.
4. In the drop-down menu, select **Assign role**.
5. Select up to 50 users for the admin role.
6. Select **Apply**.
7. (Optional) Repeat steps 1-6 for each admin role you want to assign.

   You have successfully assigned the admin role(s) for your organization.

:::tip
Ensure that you assign at least one Content Admin.
:::

:::tip
Assign the Company Admin role to strategic members of your organization. For example, your Systems Administrator for technical assistance, and a head of Product Design.
:::
