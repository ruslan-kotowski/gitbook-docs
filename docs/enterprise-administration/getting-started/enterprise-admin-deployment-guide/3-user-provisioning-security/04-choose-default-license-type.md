As Company Admin, you can choose the Flexible Licensing Program (FLP), or non-flexible licensing. The FLP model ensures that your licenses scale with usage.

You can provide a default license—**Free** or **Free restricted**—that is automatically upgraded for users who need a Full license.

You must specify which default license type to provide each user.
