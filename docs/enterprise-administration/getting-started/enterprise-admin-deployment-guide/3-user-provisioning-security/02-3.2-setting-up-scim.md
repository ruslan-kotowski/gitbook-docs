To automate how you manage and provision rights for users inside your Enterprise subscription, set up SCIM (System for Cross-domain Identity Management).

SCIM synchronizes Miro with your identity provider (IdP), and provides you with centralized access control.

You can auto-assign new users in your IdP to a Miro team, billing group, and grant them the default Enterprise license.

## How to set up SCIM

The following procedure explains how to set up SCIM for your Enterprise subscription.

#### Prerequisites

Ensure that you have enabled Single sign-on (SSO).

#### Procedure

The following procedure explains how to set up SCIM for your Enterprise subscription.

Follow these steps:

1. Enable SCIM in Miro.
   1. Go to **Admin console**.
   2. Select **Enterprise integrations**.
   3. Toggle **SCIM provisioning** to the on position.
2. Generate a SCIM token.
   1. Select **Generate new token**.
      The **Generate new SCIM token** dialog opens.
   2. Select **Generate**.
      > ✏️ You need the SCIM token to configure your IdP.
3. Configure your IdP for SCIM.
   You can configure any IdP that supports SCIM. The Miro Help Center provides instructions for the following identity providers:
   - [Okta](../../../security-integrations/system-for-cross-domain-identity-management-scim/05-setting-up-automated-provisioning-with-okta.md)
   - [Entra ID](../../../security-integrations/system-for-cross-domain-identity-management-scim/03-setting-up-automated-provisioning-with-entra-id.md)
   - [Google](../../../security-integrations/system-for-cross-domain-identity-management-scim/04-setting-up-automated-provisioning-with-google.md)
   - [OneLogin](../../../security-integrations/system-for-cross-domain-identity-management-scim/06-setting-up-automated-provisioning-with-onelogin.md)

     You have successfully set up SCIM for Miro.

**More information:** See [SCIM](../../../security-integrations/system-for-cross-domain-identity-management-scim/02-scim.md).
