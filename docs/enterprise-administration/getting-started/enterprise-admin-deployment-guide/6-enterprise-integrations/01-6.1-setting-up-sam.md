Software Asset Management (SAM) helps you to optimize your Miro Enterprise subscription by enabling you to effectively control spend, limit redundancy, and manage inactive users.

Currently supports ServiceNow, Productiv, and Zylo.

## How to set up SAM

The following procedures explain how to set up SAM with Productiv, ServiceNow, or Zylo.

#### Prerequisites

Ensure that you complete the following prerequisites:

- Enable SAM, and generate and copy a Miro SAM access token.

  Follow these steps:
  1. Go to **Admin console**.
  2. Select **Enterprise integrations**.
  3. Under **Single sign-on**, toggle **SAM** to the on position.
  4. For **Access Token** on the right, select **Generate new token**.
     An access token is generated.

     You have successfully enabled SAM, and generated and copied a Miro SAM access token.
- (ServiceNow) Ensure that you have the [SaaS License module installed](https://docs.servicenow.com/bundle/quebec-it-asset-management/page/product/software-asset-management2/task/request-saas-license-management.html) (external).

### ServiceNow

To configure ServiceNow, follow the [Integrating with Miro Enterprise](https://docs.servicenow.com/bundle/xanadu-it-asset-management/page/product/software-asset-management2/concept/integrate-with-miro-enterprise.html) (external) steps in the ServiceNow documentation.

### Zylo

Configure Zylo to monitor activity and support business decisions, like reducing unused applications and inactive users, in your Miro Enterprise subscription.

Follow these steps:

1. In Zylo, access **Integrations**.
2. Under **Categories**, select **Utilization**.
3. For Miro, select **Connect**.
4. Follow the on-screen instructions to complete the integration.

   You have successfully integrated Zylo with Miro Enterprise.
