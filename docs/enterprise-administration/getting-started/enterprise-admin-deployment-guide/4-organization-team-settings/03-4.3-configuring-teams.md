As Company Admin, you can specify collaboration, sharing, and visibility parameters for each team. For example, you can specify who can create new content in a team.

## How to specify Teams settings

The following procedures explain how to specify team settings.

#### Prerequisites

For each of the following procedures, go to **Admin console** and select **Teams**. All procedures in this section occur in the **Teams** settings view.

:::note
Each procedure in this section applies to a given team that you select. Specifications do not apply to the entire organization or team structure.
:::

:::tip
In Admin Console, the team icon shows which team settings a Team admin can change. As Company admin, go to **Admin Console** > **Teams** > **\{team name\}** > **Settings** tab.

Team icon: ![](images/26671854987538_image.png)
:::

### Configure team discovery

Specifies team visibility, and who can join a given team with or without approval.

#### Procedure

Follow these steps:

1. Select a team.
   The view changes.
2. Select **Permissions**.
3. For **Team discovery settings**, select one of the following options:
   - **Hidden**
     No one can find the team unless invited.
   - **Members can join after approval**
     Enterprise members can find and request to join the team.
   - **Open to members**
     Enterprise members can find the team, and join without approval.

     You have successfully configured team discovery.

### Specify which roles can create assets in a team

Specifies whether all users or admins only can create boards, Spaces, and templates for their team(s).

#### Procedure

Follow these steps:

1. Select a team.
   The view changes.
2. Select **Permissions**.
3. Under **Sharing settings**, for **Who can create assets in this team?** specify which groups of admins, or all users, can create assets.

   You have successfully specified who can create assets in a team.

### Set defaults for sharing boards

Specifies parameters for sharing content internally, and publicly.

#### Procedure

Follow these steps:

1. Select a team.
   The view changes.
2. Select **Permissions**.
3. Under **Sharing Settings**, for **Board sharing** do the following:
   1. For With a team, specify whether or not users can share boards with an entire team.
   2. For **With entire company**, specify the following parameters:
      - **Anyone can view and comment**
        Users can share boards with the entire company, and anyone in the company can view and comment on the shared boards.
      - **Anyone can view, comment, and edit**
        Users can share boards with the entire company, and anyone in the company can view, comment, and edit shared boards.
      - **Not allowed**
        Users cannot share boards with the entire company.
   3. For **By public link**, specify whether users can share boards publicly.

      You have successfully set default parameters for sharing boards and Spaces.

### Specify whether board owners can move boards between teams

Specifies whether a board owner can move their board to another team.

#### Procedure

Follow these steps:

1. Select a team.
   The view changes.
2. Select **Permissions**.
3. Under **Permissions**, for **Moving boards to other teams**, specify **Allowed** or **Not allowed**.

:::note
The destination team must also allow **Moving boards to other teams**.
:::

You have successfully specified whether board owners can move their boards to other teams.

### Specify permissions for copying boards and board content

Specifies whether team members only can copy board content, and the default board permissions for copying.

#### Procedure

Follow these steps:

1. Under **Permissions**, do the following:
   1. For **Copying board content**, specify whether team members only, or anyone in the organization, can copy board content.
   2. For **Default board copyin**g, specify the default for who can copy a board.
      > ✏️ The default applies for every newly created board. The board owner can change this setting for their own board.

      You have successfully specified permissions for copying boards and board content.
