Domain control enables you to verify your company domain(s), and ensures that you can actively maintain security compliance. For example, you can detect users not associated with any domain that you manage.

## How to set up domain control

The following procedure explains how to set up domain control.

#### Prerequisites

Ensure that you complete the following prerequisites:

- Get admin access to your domain provider, like Amazon, Cloudflare, or GoDaddy.
- For TXT-record specifications, which you need to verify your domain, see [TXT record for Domain Control](../../../enterprise-guard/appendix/02-txt-record-for-domain-control.md).

#### Procedure

Follow these steps:

1. Go to **Admin console**.
2. Select **Managed domains**.
3. Select **Add a domain**.
4. Enter your full domain name.
   *For example:*

   ```
   yourcompany.com
   ```
5. Select **Save**.
6. To verify your domain, follow the on-screen instructions.
   > ✏️ Verification can take up to 72 hours. You will receive an email when verification is complete. Miro checks for the verification code automatically every two hours for 30 days.
7. (Optional) To check the status of your domain verification, in **Managed domains** select **Check verification**.

   You have successfully set up domain control. For a verified domain in **Managed domains**, you can now select the three dots (**...**) to access **Edit domain settings**.

**More information:** See [Domain Control](../../../canvas-25-admin-features/domain-control/01-domain-control.md).
