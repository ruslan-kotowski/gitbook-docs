Now that you have completed the *Enterprise admin deployment guide*, you are ready to onboard and enable your users to innovate collaboratively.

To continuously support your role as admin, you can access the following resources anytime:

- [**Miro Academy**](https://academy.miro.com/)
  Provides Miro courses for all skill levels.
  > 💡 For a course that covers the core skills in Miro, see [*Getting Started with Miro*](https://academy.miro.com/getting-started-with-miro).
- [**Learning Center**](https://miro.com/app/dashboard/#/lc/getting-started/)
  Provides dashboard access to learning resources in Miro.
- [**Miro Community**](https://community.miro.com/)
  Enables you to ask questions and help others in the Miro community.
- [**Help Center**](https://help.miro.com/hc/en-us)Provides Miro product documentation.

For technical reference and support, visit any of the following resources:

- [**Miro Developer Platform**](https://developers.miro.com/)
  Provides the tools, APIs, libraries and documentation to create Miro apps.
- [**Miroverse**](https://miro.com/miroverse/)
  Enables you to explore and use templates created by the Miro community.
- [**Marketplace**](https://miro.com/marketplace/)
  Enables you to extend Miro with over 150 apps and integrations.
- **Your account team**
  Ensures that you have dedicated support for any questions about your Miro Enterprise subscription.
- [**Miro Support**](../../../../using-miro/tools/troubleshooting/06-contacting-miro-support.md)
  Provides technical assistance for product-related issues.

Congratulations. You have successfully configured Miro Enterprise for your organization.
