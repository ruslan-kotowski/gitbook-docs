Company Admins can manage admin announcements and delegate these capabilities using custom admin roles.

## Default permissions

Company Admins can create, edit, publish, duplicate, cancel, and delete announcements.

## Configure permissions in custom roles

In the custom roles configuration, announcement permissions are grouped under **Announcements**.

For more information about creating and managing custom roles, see [Custom admin roles](https://help.miro.com/hc/en-us/articles/22182074695698).

| Permission | Description |
| --- | --- |
| **View announcements** | Allows users to view announcements. |
| **Manage announcements** | Allows users to create, edit, publish, duplicate, cancel, and delete announcements. |

## Delegate announcement management using custom roles

You can assign the **Manage announcements** permission to specific users or roles to allow them to manage announcements without granting full Company Admin access.

## Example use cases for delegated access

- **Miro Admins**
  Share product updates, team updates, and promote new Miro features.
- **HR teams**
  Manage internal communications and policy updates.
- **IT teams**
  Share system updates, maintenance notifications, security updates, or new Miro feature availability.
- **Enablement teams**
  Promote training sessions and onboarding programs.
