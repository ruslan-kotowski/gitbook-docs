Use the Announcements page to view, track, and manage announcements across their lifecycle.

## View and understand announcements

Go to **Admin Console > Organization > Announcements**. The announcements table provides an overview of all announcements, including their name, status, dates, audience, and creator.

## Announcement statuses

| Status | Description |
| --- | --- |
| **Draft** | Saved but not yet published. |
| **Scheduled** | Published and set to appear at a future date. |
| **Live** | Currently visible to users. |
| **Ended** | No longer active after the end date. |
| **Canceled** | Stopped and no longer shown to users. |

## Update announcements

### Edit an announcement

1. Go to **Announcements**.
2. Select an announcement.
3. Click **Edit**.
4. Update the announcement details.
   You can update the message, link text, link URL, audience, schedule, or priority.
5. Click **Publish**.
   Changes are applied immediately, including for live announcements.

### Publish an announcement

1. Open the announcement.
2. Review the details.
3. Click **Publish**.
   The announcement becomes **Scheduled** if the start date is in the future, or **Live** if the start date is today.

## Reuse announcements

### Duplicate an announcement

1. In the announcements list, open the **Actions** menu.
2. Click **Duplicate**.
3. Update the announcement details.
   Change the name, dates, audience, or other fields as needed.
4. Click **Save draft** or **Publish**.
   **Save draft** stores the announcement without publishing.
   **Publish** makes the announcement live or schedules it based on the selected dates.

## Control the announcement lifecycle

### Cancel an announcement

1. In the announcements list, open the **Actions** menu.
2. Click **Cancel**.

You can cancel an announcement in any state. The announcement is no longer shown to users.

### Delete an announcement

1. In the announcements list, open the **Actions** menu.
2. Click **Delete**.

The announcement is permanently removed and cannot be recovered.

## Track changes

Each announcement includes a history section that shows lifecycle and update events.

History includes actions such as:

- Created
- Published or went live
- Edited
- Canceled

These actions are also recorded in audit logs.
