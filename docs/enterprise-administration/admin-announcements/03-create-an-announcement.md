Create announcements to communicate updates, events, or important information to your organization or a specific team.

## Before you begin

- Prepare your announcement message.
- Prepare link text and a link URL, for example, a signup form or help article.
- If targeting a specific team, know which team to target.

## Create an announcement

1. Go to **Admin Console**.
2. Select **Organization > Announcements**.
3. Click **Create announcement**.
4. Enter the announcement details:
   Provide the following details when creating an announcement:

   | Field | Description |
   | --- | --- |
   | **Name (internal)** | Internal name used to identify the announcement in the list. This is not visible to end users. |
   | **Text** | The text displayed in the announcement banner (maximum 150 characters). |
   | **Link text** | The button label users click to take action (maximum 50 characters). |
   | **Link URL** | The link opened when users click the button (maximum 2000 characters). |
   | **Audience** | Select *Everyone in the organization* or a specific team. The editor shows the estimated audience size. See step 6. |
   | **Dates** | Set the start and end dates for when the announcement is visible. The start date cannot be in the past. The end date is required, and the maximum duration of an announcement is 90 days. |
   | **Priority announcement** | Marks the announcement as high priority so it appears first for the selected audience. If multiple announcements are marked as priority, they are shown in order of creation. |
5. Review the preview.
   Use the preview panel to see how the announcement will appear to users before publishing.
6. Select the audience and review the estimated audience size before publishing.
   Choose who will see the announcement:
   - **Everyone in the organization** – shows the announcement to all users.
   - **Specific team** – shows the announcement only to members of the selected team.
     For more details, see [Target announcements and manage audience](https://help.miro.com/hc/en-us/articles/34094240021906).
7. Set the schedule.
   Select start and end dates to define when the announcement appears.
8. Click **Save draft** or **Publish**.
   **Save draft** stores the announcement without publishing.
   **Publish** makes the announcement live or schedules it based on the selected dates.
   **Cancel** closes the editor without saving changes.
