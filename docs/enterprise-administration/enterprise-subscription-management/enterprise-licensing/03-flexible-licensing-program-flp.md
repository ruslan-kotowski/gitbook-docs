The Flexible Licensing Program (FLP) is our most common licensing model. With FLP your licenses scale as your usage grows. Estimate your organization’s needs and add or remove licenses without any upfront fees, retroactive costs or contract changes.

Learn more about our [Enterprise licensing](02-enterprise-licensing.md).

## How the Flexible Licensing Program (FLP) works

A review of your FLP subscription happens based on your defined true-up frequency. Approaching your true-up period, customers will have a data-driven discussion with their Miro account team to decide how many of their new users need a Standard or Full (legacy) license going forward. The contract will be amended with additional licenses and zero retroactive fees.

## FLP license upgrades

Users can have a Standard, Full (legacy), Free, or Free Restricted license. Certain actions trigger a license upgrade on FLP subscriptions.

Learn more about [managing licenses on FLP](05-license-management-on-the-flexible-licensing-program-flp.md).

|  |  |  |  |
| --- | --- | --- | --- |
|  | **Standard/** **Full (legacy)** | **Free** | **Free Restricted** |
| **Upgrade options** | Already upgraded to the highest license type | **Auto-upgrades** to a Standard or Full (legacy) license when:   - creating a board - editing a shared board - invited to edit a board - granted board co-ownership - added to a [space](../../../using-miro/spaces/01-spaces.md) as Editor | **License upgrade request** sent to the Admin when a user:   - tries to create a board or space - requests edit access - is invited to edit a board - is assigned board ownership |

:::warning
Guests are never automatically upgraded.
:::

## FLP user access

Each user can have different Miro roles (Member, Guest, or Visitor) in multiple Miro [teams](../../../getting-started/start-here/miro-dashboard/04-profile-and-teams.md) within one Enterprise Plan.

Learn more about Miro roles and license types in [User access levels on Enterprise Plan](../../user-management/11-user-access-levels-on-enterprise-plan.md).

|  |  |  |  |
| --- | --- | --- | --- |
|  | **Standard/** **Full (legacy)** | **Free** | **Free Restricted** |
| **Member** | **Members on a Standard or Full (legacy) license can:**   - Create boards, Spaces, and templates - Edit shared boards - See boards shared with the team | **Members on a Free license can:**   - be added to Spaces and boards - see boards shared with a team (and view and comment on team-shared boards) - auto-convert to Standard or Full (legacy) members | **Members on a Free Restricted license can:**   - be added to Spaces and boards - see boards shared with a team (and view and comment on team-shared boards) |
| **Guest** | Not available | **Guests on a Free license can:**   - view and comment on shared boards     **Guests on a Free license cannot:**   - create or see boards shared with a team - see or join Spaces shared with a team | **Guests on a Free Restricted license can:**   - view and comment |
| **Visitor** | **Visitors** don't need to register for Miro or have a license.   - Visitors can view, comment on, and edit boards (with some[limitations](../../../using-miro/sharing-boards/08-collaboration-with-visitors.md)) - Visitors cannot view Spaces, boards or templates shared within a team - Visitors cannot see the list of teams, team members or Team and Company Admins | | |
