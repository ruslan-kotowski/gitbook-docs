To enable prompt blocking for your organization:

1. In Miro, go to **Settings** → **Enterprise Guard** → **Data discovery** → **Configuration**.
2. In **Prompt blocking**, click **Activate**.
3. In the side panel, keep **Select all** enabled or choose specific label categories to block.
4. (Optional) Turn on **Code scanning** to block prompts that include source code (minimum 5 lines). For more information, see [Code scanning](06-prompt-blocking-overview.md#code-scanning).
5. Click **Activate**.

Prompt blocking is on for your organization. All selected categories are enforced immediately.
