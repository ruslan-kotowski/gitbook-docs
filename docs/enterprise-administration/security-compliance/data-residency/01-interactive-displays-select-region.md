Teams on an Enterprise plan with data residency outside the European Union (EU), can select the appropriate region on interactive displays.

This article explains how to connect an interactive display browser to the appropriate data residency region, and how to start using the Miro app on a Windows and Android display in the appropriate region.

For information about interactive displays, see [Interactive Displays.](../../../getting-started/apps-for-devices/07-interactive-displays.md)

To learn more about data residency, see [Data residency at Miro](../../canvas-25-admin-features/data-residency/02-data-residency-at-miro.md).

## Connect interactive display browser to region

1. Open the display browser.
2. Go to the following URL for your region:
   - (Default) **European Union**
     `https://miro.com/displays/?useAsAppDefaultOrigin`
   - **Australia**
     `https://au.miro.com/displays/?useAsAppDefaultOrigin`
   - **United States**
     `https://us.miro.com/displays/?useAsAppDefaultOrigin`
3. Follow the on-screen instructions.

## Change Miro app region on Windows interactive display

1. On your Windows interactive display, open the Miro app.
2. On your keyboard, press the **ALT** key.
   A context menu opens.
3. Select **Help** > **Public device** > **Public**.
   Miro changes to the interactive display experience.
4. Select **Help** > **Public device** > **Default region**.
5. Select one of the following:
   - (Default) **Global**
     Connects to the European Union region
   - **Australia**
     Connects to the Australia region
   - **United States**
     Connects to the United States region

## Change Miro app region on Android interactive display

1. On your Android interactive display, open the Miro app.
2. On the launch screen, in the upper-right tap the gear icon.
3. Tap **Select region**.
   The **Select a different region** modal opens.
4. Select one of the following:
   - (Default) **Global**
     Connects to the European Union region
   - **Australia**
     Connects to the Australia region
   - **United States**
     Connects to the United States region
