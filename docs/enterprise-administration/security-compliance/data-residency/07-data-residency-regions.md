Miro provides data residency in Australia, the European Union (EU), and the United States (US).

## Where are the Miro data residency data centers?

Miro provides data residency in the following regions:

- (Default) **European Union**
  Miro uses two data centers in the European Union (EU). The primary data center is located in Ireland, and the backup data center in Frankfurt.
- **United States**
  Miro uses two data centers in the United States (US). The primary data center is located in Ohio, and the backup data center in Virginia.
- **Australia**
  Miro uses two data centers in Australia. The primary data center is located in Sydney, and the backup data center in Melbourne.

:::note
If you do not initiate a move between regions, then Miro uses the EU as your data residency. For more information, see [Moving data between regions](../../canvas-25-admin-features/data-residency/03-move-data-between-regions.md).
:::

| Interactive displays | Fully supported | Currently unsupported | Currently unsupported |

| Miroverse | Fully supported | Template support only | Template support only |
| Mobile app | Fully supported | Fully supported | Fully supported |
| Formats | Fully supported | Fully supported | Fully supported |

| SAML-based SSO | Business and Enterprise | Enterprise only | Enterprise only |
