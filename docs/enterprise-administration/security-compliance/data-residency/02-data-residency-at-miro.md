> **EU Data Residency:** Available for all plans
>
> **US and AU Data Residency:** Available only for Enterprise Plan

Data residency enables customers to control where their content is hosted and stored, to help meet their data-management and privacy obligations.

## Understand data residency at Miro

Data residency is essential for customers in industries where data protection is critical or regulated, like banking and financial services, healthcare, and government.

Miro's data residency program is designed with two functional pillars:

- **In-region storage**
  Miro stores in-scope production data, backup data, and metadata in local data centers, which helps customers meet their requirements for data compliance.
- **In-region compute infrastructure**
  Miro uses in-region compute infrastructure, which removes the need for off-region data transfers between in-scope IT elements, and helps optimize product performance.

## Data residency regions

Miro provides data residency in the following regions:

- (Default) **European Union**
  Miro uses two data centers in the European Union (EU). The primary data center is located in Ireland, and the backup data center in Germany.
- **United States**
  Miro uses two data centers in the United States (US). The primary data center is located in Ohio, and the backup data center in Virginia.
- **Australia**
  Miro uses two data centers in Australia. The primary data center is located in Sydney, and the backup data center in Melbourne.

:::note
Miro may add or update locations for backup data centers in a given region. Backup data centers will always be located in the same region as their respective primary centers. For example, a backup data center added for Australia would be located in Australia.
:::

## Miro data governance

The following table shows which generally available (GA) Miro features are, and which are not, subject to data residency in-region storage.

| Data | Governed | Not governed |
| --- | --- | --- |
| **Boards and board content** | - [Miro AI](#miro-ai-and-data-residency) - Comments with mentions - Comments without mentions - Data tables - Docs - Embedded files - First-party Miro integrations - Frames - Layers - Metadata like board name and thumbnail - Shapes - Stickers - Sticky notes - Talktracks - Text boxes - Timelines - Widgets | - Notifications - Third-party integration data, e.g. a Google sheet embedded on a Miro board, or notification about changes on a board sent to Slack |
| **Organization details and settings** | - Access requests - App tokens and first-party Miro app data - Logs, including audit, content, and AI interaction logs - Board classification levels - Brand center - Company profile - eDiscovery - Feature activation - Analytics - Roles - Sharing settings | - Claimed domains - Domain control policies - Organization domain - Organization ID - Organization logo - Organization name - SCIM integration - SSO integration - Third-party Miro app data |
| **Teams** | - Team apps and integrations - Team permissions - Team profile - Team users | - n/a |
| **Users** | - n/a | - Avatar - Early access setting - Email - Name - Notification preferences - Organization membership - Personal apps - Personal integrations |

:::note
Miro AI data is stored in-region in accordance with data residency commitments. Processing may occur outside the selected region. Data residency applies only to generally available (GA) features and excludes beta or preview features.
:::

:::note
Third-party apps and integrations may store and process information outside Miro data residency.
:::

### Miro AI and data residency

"Miro AI" refers to product capabilities that use machine learning or generative AI models to analyze, transform, or generate content based on customer data in Miro.

For data residency, data used or generated by Miro AI is stored in-region in accordance with residency commitments. Processing may occur outside the selected region, as some AI models are not yet available in-region.

## Choose your data residency region

Customers can discuss data residency with their dedicated Miro contact.

## Data residency additional cost

For default data residency in the EU, there is no additional cost.

Data residency in regions outside the EU is available only to Enterprise customers.
