The public beta program gives users early access to Miro features before they are generally available. As Company admin, you can enable and disable the public beta program for all users in your Miro Enterprise subscription.

Your users can experience the latest Miro features and give feedback during development, ensuring the best final product for all Miro users.

## Key features

With the public beta program enabled, Enterprise users get the following key features:

- **Self-serve enablement**
  Company admins can enable or disable public beta features for their entire organization.
- **Automated rollout**
  Beta features are automatically rolled out to users with no additional overhead.
- **Feedback collection**
  Users give feedback on Miro features before they are generally available.

## How to enable or disable the public beta program

To enable or disable the public beta program for your organization, follow these steps:

1. In admin settings, click Organization, and then click **Feature activation**.
2. Under **Public beta program**, select one of the following:
   - **No one can use**
     You have successfully disabled the public beta program for your organization.
   - **Everyone can use**
     You have successfully enabled the public beta program for your organization.
