Miro now supports integration with on-premise Jira instances using a customizable OAuth 2.0-based authentication flow. This allows organizations to use a third-party authorization server instead of Jira's default authorization process, providing a scalable solution for diverse customer authentication setups. Note that this feature is available at the organization level, and only one authorization server can be added per organization.
