Slide Format is a new feature in Miro that allows users to create, organize, and customize content directly on the Canvas or in Focus Mode. Users can import existing slide decks (PDF only), reorder and edit slides, and add new slides from templates or from scratch. Additionally, users can present slides live to engage participants in interactive workshops. Slide Format provides the flexibility to present a specific set of slides rather than displaying all slides on the Canvas. This feature includes the ability to create, reorder, and present slides within a slide container, access Slides focus mode for editing and creating presenter notes, and quickly apply a style for the entire slide deck with brand colors. Users can also import and export PDF decks and share links to the Slide deck and Slide focus mode. Note that mobile support is partial, allowing users to view slides in the correct order but not enter focus mode or reorder slides.
