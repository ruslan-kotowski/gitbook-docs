After gathering initial insights from the rollout of the new Spaces interface, we've made three small updates:

1. The template carousel will be moved to the top, with the "Create" button positioned just below it.
2. Miroverse will return to the carousel.
3. The user avatar will be relocated from the bottom left to the top right.

These changes are aimed at enhancing your experience with Spaces.
