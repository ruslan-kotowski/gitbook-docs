For all widgets with a font context menu, Miro users can no longer select the Arial, Times New Roman, and Georgia fonts. For existing content where the removed fonts had been applied, the following transition will take place: Arial > Roboto; Times New Roman > PT Serif; Georgia > PT Serif.
