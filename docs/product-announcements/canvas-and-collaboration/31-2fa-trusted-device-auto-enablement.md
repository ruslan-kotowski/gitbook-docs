The two-factor authentication (2FA) Trusted Device feature is now auto-enabled by default for all organizations with 2FA enabled. Previously, this feature had to be manually switched on by admins. For more details, see the updated [2FA admin guide](../../enterprise-administration/security-integrations/two-factor-authentication-2fa/01-enterprise-two-factor-authentication-2fa-–-admin-guide.md).
