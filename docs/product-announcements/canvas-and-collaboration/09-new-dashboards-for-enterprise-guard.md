Introducing five new dashboards for Enterprise Guard customers, providing a comprehensive view of key metrics. These include dashboards for Data Discovery, Data Classification, Content Lifecycle, and eDiscovery, along with an overview dashboard that consolidates metrics from all domains. The current metrics will serve as an entry point into the Content Explorer, which will no longer be a separate menu item.
