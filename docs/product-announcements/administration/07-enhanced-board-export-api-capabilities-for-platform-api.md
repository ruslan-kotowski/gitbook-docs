We’re introducing additional Board Export API endpoints to help you manage board exports more efficiently. You’ll be able to list export jobs across your organization, view tasks for a specific export job, retrieve download links for export tasks, and cancel export jobs that are no longer needed. These updates will make it easier to monitor, control, and automate your export workflows programmatically.
