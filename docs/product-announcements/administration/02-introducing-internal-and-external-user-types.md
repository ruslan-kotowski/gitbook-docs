Admins can identify user type as internal for users whose email is verified, and external for users whose email is not. The visual differentiation between internal and external user types will lead to functional enhancements to how admins can manage users in the future. To learn more, see [Domain Control](../../enterprise-administration/canvas-25-admin-features/domain-control/01-domain-control.md#internal-and-external-users).
