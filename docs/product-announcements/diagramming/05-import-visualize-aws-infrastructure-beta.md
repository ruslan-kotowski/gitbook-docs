The **AWS Data Import** app allows you to generate a diagram of your AWS cloud infrastructure in Miro. The app guides you through the process with a script in your AWS environment that downloads a JSON file that contains data about your cloud resources. Once the JSON file is uploaded into Miro, a diagram of your cloud infrastructure is generated.
