Custom labels in **Data Discovery** now support **Prototype screens** as a widget type condition. Admins can configure labels to automatically apply when Prototype screens are detected on a board, extending data discovery coverage to prototype content alongside other supported widget types such as Jira cards, Azure cards, and code blocks.

With this update, admins can:

- Include Prototype screens when defining conditions for custom labels.
- Automatically identify boards containing prototype-related content.
- Improve coverage of sensitive or business-critical information across more board elements.

For more information, see our documentation on [Custom labels](../../enterprise-administration/canvas-25-admin-features/data-discovery/08-custom-business-sensitive-data-discovery-overview.md).
