Filter audit logs by standard criteria such as actors and event types for quicker access to relevant information.

Easily download audit logs data in CSV with a higher limit of events per export, and faster and more convenient access to export file.

Events older that 90 days will no longer be available for preview in the UI or via API. However, this data will still be accessible via [CSV export](../../enterprise-administration/security-integrations/security-management/01-audit-logs.md).

We will start rolling out these updates on August 5, 2024, and will make them available to all enterprise customers within the subsequent weeks.
