Miro admins on the Business and Consultant Plans can now view and verify domains in one ‘Managed domains’ section that includes all domains that have been verified by the more secure DNS record method. Admins can then select authentication methods and domain control policies for each domain as needed. This allows for smoother configuration of Miro and less duplicative effort between two verification methods.
