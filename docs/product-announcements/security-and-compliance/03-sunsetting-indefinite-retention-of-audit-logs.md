On December 17, 2024, Miro is updating the Audit Log retention policy from "indefinite" to 180 days. Data older than 180 days will be permanently deleted. If you need a different retention period, please go to the "Settings" tab under "Audit Logs" in the Miro Admin Console to set your policy. Historical data can be exported via CSV in advance if needed. More information can be found in the [Help Center](../../enterprise-administration/security-integrations/security-management/01-audit-logs.md).
