Centralize all your work and tools by adding third-party links to Spaces. Teams can seamlessly access and interact with external resources, like Microsoft Word, directly from Miro, making collaboration and decision-making more seamless and efficient.

**Supported third-party embeds:**

- Box
- Figma
- Google Doc
- Google Slides
- Google Sheets
- Looker
- Microsoft Word Docs
- Microsoft PowerPoint Presentations
- Microsoft Excel Sheets
- Power BI
