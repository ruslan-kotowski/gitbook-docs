The Glean x Miro integration is an exciting new feature that enhances the productivity and efficiency of collaborative sessions by leveraging Glean's Work AI platform within the Miro environment. Here are the key highlights of this integration:

- **Seamless Integration**: Users can easily access Glean's functionalities within Miro by clicking the plus icon and searching for "Glean". This integration allows users to gather insights from various sources such as Miro boards, documents, and Slack discussions directly into their Miro workspace.
- **Enhanced Productivity**: The integration helps in summarizing information, generating insights, and creating action items, thereby streamlining the innovation process. Users can run pre-programmed prompts and import summaries from Glean directly into Miro, making it easier to start sessions with all relevant information at hand.
- **Customizable Workflows**: Organizations can fully leverage Glean's search and AI functionalities within Miro, allowing users to search, retrieve, and curate insights within the canvas with full control of the use cases and workflows. This includes the ability to create content such as documents, sticky notes, and diagrams based on organizational knowledge.
- **Security and Compliance**: The integration conserves Glean access rights in Miro, ensuring that only authorized users can access specific insights. Admins can configure authentication (SSO, OAuth) and manage security, privacy, and compliance for the integration.
- **Availability and Rollout**: The Glean integration is currently available in a Private Beta for Enterprise plans, with a gradual rollout planned. Initially, it will be available on the Desktop app and browser only, with support for additional languages like German and Japanese by the General Availability (GA) phase.
- **User-Friendly Features**: Users can review and edit summaries in Miro docs, navigate to original source data, and use tailored outputs based on system access rights. This integration also supports over 100 data sources, providing comprehensive insights for various use cases.

This integration represents a significant step forward in enhancing the collaborative capabilities of Miro by incorporating Glean's powerful AI and search functionalities, ultimately helping teams innovate faster and more effectively.
