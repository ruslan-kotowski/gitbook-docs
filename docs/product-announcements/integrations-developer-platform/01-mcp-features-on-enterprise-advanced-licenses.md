Enterprise licensing offers [Standard and Advanced licenses](https://help.miro.com/hc/articles/33311996124306) for teams in your organization. To use Miro's [Model Context Protocol](https://help.miro.com/hc/articles/31624028247058) (MCP) server, only the Advanced license provides MCP enhancements, like generating architecture diagrams or tables from code, or vice versa, in minutes.

A Standard license provides basic MCP functionality, like code explanation and Docs creation.

For more information about what MCP functionality is available with an Enterprise Standard versus Advanced license, see [Understanding Enterprise licenses](https://help.miro.com/hc/articles/33311996124306).
