To print your Miro board:

1. Access the export options by clicking the **three dots** (**...**) icon in the top-left toolbar > **Board** > **Export**.
2. Export the board as an image or a PDF.
3. Open and print the exported file.

> **⚠️** Exporting high-resolution PDFs requires a paid plan. Free plan customers can only export low-resolution, watermarked PDFs. To learn more about board export options, visit [this page](03-how-to-export-your-board.md).

![export-entry-point.png](images/21537453537298_export-entry-point.png)
*Board export options*

If you choose to save the board as PDF, each [frame](../../essential-tools/07-frames.md) on the board will be created as a separate page of the PDF document. If you want an entire chart, diagram, or image to be printed on a single page, you can use an A4 or letter-size frame as it automatically matches the standard paper size.

For the best experience, create frames and work on the board at 100% zoom level.

If the text or objects on the printed document are too small, you can select the objects and increase their size on the board, then re-export and print.

If you experience issues exporting your board, please check our [troubleshooting guide](../../tools/troubleshooting/03-board-export-issues.md).
