Invite people on public boards in Miro and enable the option to specify their real names - the quickest and easiest way to identify and collaborate with non-registered visitors.

Learn [how to invite visitors](08-collaboration-with-visitors.md).

### How to enable visitor names

> **Set up by**: [board owners](01-board-access-rights.md)

> **✏️**This feature is not available for [embedded Miro boards](../import-and-export/export/02-embed-a-miro-board.md), including boards embedded in supported apps and via embed code (iFrame).

Open a board's **Share** dialog and switch to **Sharing settings**. In the drop-down under **Adding visitor names if the board is public**, select **Visitors can add their names**.

![visitor_names.gif](images/21017348753298_visitor%20names.gif)
*Enabling the option to add visitor names*

### How visitors can add their names

If the option to add names is enabled for a public board shared for public editing, unregistered visitors who open it will be able to introduce themselves before entering the board. If they leave the field blank, they will be anonymous users on the board and will get randomly generated names (e.g.: *Visiting Inventor*).

![Screenshot_background_template__5__1_.jpg](images/21017348750226_Screenshot%20background%20template%20%205%20(1).jpg)
*Unregistered users can type in their names before entering a public board if the option is enabled in the board settings*

The name of the collaborator will be shown next to their cursor and on the communication toolbar in the top-right corner of the board.

![Screenshot_background_template__5__2_.jpg](images/21017318918930_Screenshot%20background%20template%20%205%20(2).jpg)
*Visitor name on the board*

If the option to add visitor names is disabled, all unregistered users will get generated names on the board. Those users who **sign in** will appear on the board with their real names.
