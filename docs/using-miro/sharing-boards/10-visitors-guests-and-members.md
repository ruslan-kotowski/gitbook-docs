In Miro there are several ways you can share your content. The first step is to decide how frequently and to what extent you wish to collaborate, so you can invite users with the right role type.

## Differences between roles

**Visitors** are one-time Miro users who are not part of a team or organization. [Visitors](08-collaboration-with-visitors.md) are perfect for quick sharing, instant collaboration or a one-off brainstorm session. Visitors can only access public boards shared with them via a link. Visitors don't have to be registered with Miro and can access public boards without a Miro account. Any plan can invite visitors.

**Guests** are occasional Miro users but are also not part of a team or organization. [Guests](07-collaboration-with-guests.md) are perfect for infrequent collaboration on a private board(s). You can give access to a registered user and revoke their access at any moment. This option is only available on paid plans.

**Members** are full team participants for ongoing collaboration. Members can access all boards shared with them in a team. They have full access to the plan features and can create their own boards and content.

## Best practices for sharing boards

Each user type offers different levels of collaboration. When sharing your boards, a good start is to consider how frequently you work with someone.

**For one-time collaboration**, invite visitors by sending them a public link. Visitors can only access public boards shared with them via a link. [Visitors](08-collaboration-with-visitors.md) are perfect for quick sharing, instant collaboration or a one-off brainstorm session.

**For external and occasional collaboration**, invite guests via email. Guests can only access boards shared with them via email. [Guests](07-collaboration-with-guests.md) are perfect for occasional collaboration on a private board(s). You can give access to a registered user and revoke their access at any moment.

**For frequent and ongoing collaboration**, invite members via email. Members can access all boards shared with them in a team. They have full access to the plan features and can create their own boards and content.

## What features are available for visitors, guests and members

|  |  |  |  |
| --- | --- | --- | --- |
|  | **Visitor** | **Guest** | **Member** |
| Access shared boards | ✔ | ✔ | ✔ |
| Create and own boards, Spaces, templates | ✘ | ✘ | ✔ |
| Participate in Spaces | ✘ | ✘ | ✔ |
| See team-shared boards | ✘ | **✘** | ✔ |
| Share boards* | ✘ | ✘ | ✔ |
| Use team or company-shared templates | ✘ | ✘ | ✔ |
| Install applications* | ✘ | ✘ | ✔ |
| Mention other users in comments  (commenters, editors) | ✘ | ✔ | ✔ |
| Set up timer* (editors) | ✘ | ✘ | ✔ |
| Set up and join video chat, screen sharing, and voting sessions | ✔ | ✔ | ✔ |
| Lock and unlock content (editors) | ✘ | ✔ | ✔ |
| See board history and restore content (editors) | ✘ | ✔ | ✔ |
| Upload files | ✘ | ✔ | ✔ |
| Registered user | ✘ | ✔ | ✔ |
| Cost | Free | Free | [Paid seat (license)](https://miro.com/pricing/) |

* [Board sharing](02-who-can-share-a-miro-board.md), [apps](../../integrations-apps/integrations-basics/04-how-to-install-apps.md), and [video chat, timer and screen sharing](../facilitation-tools/06-collaboration-tools.md) are all features that are configurable by Team Admins and/or Board owners.
