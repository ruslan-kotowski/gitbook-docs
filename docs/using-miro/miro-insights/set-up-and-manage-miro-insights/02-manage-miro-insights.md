This guide covers ongoing administrative tasks for Miro Insights, including general settings, team management, notifications, and API access. This is for Company Admins who need to manage Miro Insights after the initial setup is complete.

If you haven't set up Miro Insights yet, start with the [Set up Miro Insights (admin)](01-set-up-miro-insights.md) guide first.

## Prerequisites

To manage Miro Insights administration you need:

- **Company Admin** role in Miro.
- **Miro Insights must already be set up** for your organization.

## Company profile

In this section, you can update your company information that appears in Miro Insights.

- **Name**: Your organization's name.
- **Allowed Email Domains**: Email domains that can access Miro Insights.
- **Company Logo**: Upload or change your company logo.

## Team

This section covers settings related to your Miro Insights team. As an admin, you can invite, add or remove users, and manage their roles.

## Notifications

In this section, you can configure how and when you or your team members receive notifications about new feedback, AI suggestions, and other important events.

You can set notification methods, such as Slack. You can configure notification types by category: feature or feedback.

## Integrations & automations

This section allows you to manage all connected integrations and automations. You can view the status of each integration, reconnect if needed, and adjust import settings.

For detailed setup instructions, see the [Set up Miro Insights (admin)](01-set-up-miro-insights.md) guide.

## API keys

Here you can generate and manage API keys for programmatic access to Miro Insights data. You can create new keys and revoke old or compromised keys.

:::warning
When creating an API key, make sure to give it a descriptive name and copy it to a safe place. You won't be able to see it again after you leave the page.
:::

## What's next?

Once you've configured these administrative settings, your Miro Insights instance should be running smoothly for your team. For ongoing usage guidance, see the [Using Miro Insights](../use-miro-insights) guide.
