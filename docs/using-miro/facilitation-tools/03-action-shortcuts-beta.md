Action shortcuts enable you to add custom features and AI shortcuts to your boards and templates with a single button. Action shortcuts make it easier to streamline repetitive tasks and functions on your boards.

## Key features

Action shortcuts include the following key features:

- **Feature shortcuts**
  Provide quick access on the board to more than 40 features normally hidden within menus.
- **Create with Miro AI**
  Add buttons that create Stickies, Documents, Images, or Diagrams, optionally using board content as input.

## How to add Action shortcuts to your board

The following procedure explains how to add Action shortcuts to your board.

**Procedure**

Follow these steps:

1. Click the **Tools, Media and Integrations** (![icon-tools.svg](images/25581014501266_icon-tools.svg)) icon on the creation toolbar.
2. Search for and click on Action shortcuts.
   Your cursor will change to the Action shortcuts icon.
3. Click on the board where you'd like to place your Action shortcut.
   A dialog will open.

   You have successfully added an Action button. Next you'll learn how to configure the Action button.

## How to configure Action shortcuts to trigger features

The following procedure explains how to configure Action shortcuts to trigger a feature on your board.

**Procedure**

Follow these steps:

1. In the configuration dialog, enter a **Button label**.
2. Under the **Action** dropdown, select **Create shortcut**.
   A new Miro feature field will appear.
3. Select the **Miro feature** you'd like to add to your Action shortcut. You can search or scroll through the list using your arrow keys.
4. Click **Save**.

   You have successfully added an Action button to your board.

## How to configure Action shortcuts for Create with Miro AI

The following procedure explains how to configure Action shortcuts for Create with Miro AI features on your board.

**Procedure**

Follow these steps:

1. In the configuration dialog, enter a **Button label**.
2. Under the **Action** dropdown, select **Create with Miro AI**.
   A new **What do you want to create?** field will appear.
3. Select the type of output you'd like to create with your Action shortcut. You can choose from Docs, Sticky notes, Images, or Diagrams.
4. Select an optional Source and/or Destination for your Action shortcut, if needed.
   1. You can select a Frame for the Source or Destination.
   2. If no Frame is selected for the Source, content from the entire board will be used.
   3. If no Frame is selected for the Destination, the output will be placed on the board near the Action button.
5. Enter the prompt the Miro AI will use to create the output.
6. Click **Save**.

   You have successfully added an Action button for Create with Miro AI to your board.
