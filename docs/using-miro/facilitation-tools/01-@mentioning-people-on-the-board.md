When you work on a board, you may need to quickly notify someone about the changes you’re making. You can do this by @mentioning them in a comment or a text object.

![A team being mentioned in a comment on a Miro board.](images/21017429401362_Screenshot%20background%20template%20%204%20(1).jpg)*The team mentioned in a comment*

## Understand mentions

You can use mentions to draw attention, request feedback, or assign tasks. Mentions work in different parts of Miro, primarily in comments and text objects, each serving slightly different notification purposes.

## Use @mentions to notify collaborators

This section explains how to effectively use @mentions to communicate with your collaborators on a Miro board.

### Ensure users can be mentioned by sharing the board

You can mention somebody on a board if the board is [shared](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) with them. The board can be:

- [Explicitly shared](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md#how-to-invite-to-a-board) with the user who needs to be mentioned.
- [Shared with the project](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md#moving-boards-to-a-space).
- [Shared with the whole team](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md).

### Add a mention in a text object

:::note
Text object mentions are not currently available on the mobile app.
:::

You can reference other users and user groups on the board in text-based objects like [Sticky Notes](../essential-tools/14-sticky-notes.md), [Shapes](../essential-tools/11-shapes.md), and [Text](../essential-tools/16-text.md). To do this, simply type @ followed by the user's name within the text object. Users will not receive feed notifications for text object mentions. Use text object mentions when you want to:

- Specify who is being referred to.
- Clarify involvement in a task or conversation.
- Make a note without needing immediate input or attention from the mentioned user.

### Add a mention in a comment

You can mention yourself, other users, or entire groups like the board, team, or project in [comments](asynchronous-tools/01-comments.md). To do this, open a comment, type @ followed by the user or group name. Comment mentions are ideal for daily communication and when you want users to receive notifications. Use comment mentions to:

- Start a conversation or ask for feedback.
- Assign tasks to people.
- Address comments to specific people.

### Execute specific mention commands

:::tip
When you search for user names, type four or more characters for better results.
:::

**Mention yourself**

To mention yourself, type @ followed by **your name**. This is useful to:

- Assign yourself tasks.
- Highlight your involvement in a task or conversation.
- Set yourself reminders in notifications (this works for comments only).

**Mention a specific user**

To notify a specific person, type @ followed by the **user's name**. For example, you can use this to:

- Ask an editor to provide more details.
- Pass your work for review to a team member once you are done.
- Reach an expert from your team in a field you are currently working on.

:::note
If a user's name is not listed when you try to mention them in a comment, you should invite them to the board via email, or to the team (if the board is [team shared](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)), or to the project (if the board belongs to a [project](../sharing-boards/16-projects.md)).
:::

**Mention everyone on the board**

To notify everyone who has access to the current board, type **@board**. Consider using this to:

- Ask for input from all participants on the board.
- Request feedback after a meeting conducted on the board.
- Communicate significant updates relevant to everyone on the board.

An **@board** mention does not include your project members or team members if the board is not shared with them directly or through the project/team sharing that gives them access to this specific board.

**Mention project members**

To notify all members of a specific [**project**](../sharing-boards/16-projects.md), type **@project** (if the board is part of a project). This can help you to:

- Ask for project status updates from project members.
- Update a project team about a change in deadlines.
- Introduce a new project team member working on a specific part of the project.

:::tip
You can combine **@project** and direct mentions to get insights from a cross-functional team.
:::

**Mention team members**

To notify all your team members, type **@team**. Use this to:

- Invite everyone in the team to comment on a general strategy.
- Collect feedback on an organizational structure or process blueprint.
- Ask everyone for input during team-wide ideation sessions.

### Follow comment threads for updates

To stay updated on replies to a comment, you can follow its thread. You can do this by following these steps:

1. Locate the comment you want to follow.
2. Click the **Follow thread** icon in the top-right of the comment.

![The 'Follow thread' icon on a comment in Miro.](images/21017416358290_start%20following%20a%20thread.jpg)*Following a thread*

:::tip
Hover over a user's name in a mention or comment to see their user profile card.
:::

## Additional information about mentions

This section provides more details on specific mention functionalities and restrictions.

### Mention capabilities and restrictions

:::warning
For security reasons, [Guests](../sharing-boards/07-collaboration-with-guests.md) can find and @mention only users who are directly invited to the board. [Visitors](../sharing-boards/08-collaboration-with-visitors.md) cannot mention other users.
:::

### Suggested mentions feature

> **Plans:** Business, Enterprise, Education

When you type **@** in the comment bar, Miro may show you a list of suggested mentions. This list includes users you have mentioned before and who currently have access to the board.

If [team privacy](../../enterprise-administration/managing-enterprise-teams-and-content/11-manage-team-privacy-and-discovery-on-enterprise-plan.md#team-privacy) is enabled on an Enterprise plan, only users within the same team will be suggested.
