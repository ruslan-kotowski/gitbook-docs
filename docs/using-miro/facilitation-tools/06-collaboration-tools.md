Board owners and co-owners can control the usage of board collaboration tools by setting who can start [timer](16-timer.md), [voting](19-voting.md), [video chat](18-video-chat.md), and use [attention management](04-attention-management.md) on a board. This allows you to define the group of users that should have access to the meeting facilitator’s kit. Though only selected users can start these collaboration tools, other board participants can use them. For example, a board owner can start voting to allow everyone on the meeting to vote.

Open a board **Share** menu and go to **Sharing settings**, switch to **Permissions** and select an option in the drop-down menu under **Who can start collaboration tools**. You can allow this to all editors (except [visitors by link](../sharing-boards/08-collaboration-with-visitors.md)) or to board owners and co-owners only.
