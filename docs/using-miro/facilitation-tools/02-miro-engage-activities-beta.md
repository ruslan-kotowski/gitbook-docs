Activities is the core feature of Miro Engage, a meetings and workshops engagement tool built to boost audience engagement and capture participant insights at scale. Activities let facilitators run interactive exercises (like multiple choice or open-ended questions) from their Miro boards.

Users can participate directly on the board or join via mobile by scanning a QR code or entering a code (no account or app download needed).

Responses are visualized in real-time, making your workshops and presentations more inclusive and dynamic.

Activities work best when using Miro Slides, or can be placed anywhere on your board. They can also be used with AI Flows and Sidekicks.

:::note
Activities are free while in beta.
:::

## Add Activities to the canvas

Activities can be added directly to the canvas. To add them:

1. Click the **Tools, Media and Integrations** icon or the **Frames** icon in the Create toolbar.
2. Search for and select **Activities** or, if accessing via the Frames menu, select **Activities**.
3. Slides will be added to the canvas with a Join instructions slide and a second slide where you can choose which Activity to add.
4. Select which Activity you'd like to add on the second slide.
5. To add additional Activity slides within the frame, click on the **Add template** icon next to an existing slide and then select the **Activities** tab.
6. On the **Activities** tab, select the Activity you'd like to add.

## Add Activities to Slides

1. Create a new Miro Slides deck on your board or open an existing board with the slides you'll use. **More information:** [Miro Slides](../formats/13-miro-slides.md).
2. Click the **Add template** icon next to an existing slide to open a modal to add new slides.
3. Switch to the **Activities** tab in the modal.
4. Select one of the options:
   1. **Join instructions slide:** Displays QR and session codes for participants to join.
   2. **Multiple choice poll:** Create voting questions with multiple answer options.
   3. **Open ended questions:** Collect written responses from your audience.
   4. **Word cloud:** Visualize the most frequent answers collected.
5. Add the applicable content to your new Activities slide.

## Add individual Activities to the canvas

Activities also work on the canvas. To add them:

1. Click the **Tools, Media and Integrations** icon.
2. Search for and select either **Multiple choice**, **Open-ended**, or **Word cloud**. You can also search for Activities to see the available options.
3. Click on the board where you want to place your activity.
4. Add the applicable content to your new activity.

## Available Activities

### **Join instructions**

The Join instructions activity is available when adding a new slide. It includes a QR code and link with code that allows users on a mobile device to join Activities while you present.

### **Multiple choice**

The multiple choice activity lets you run a poll to gather opinions and reach consensus on a topic.

After adding a Multiple choice activity:

1. Enter the poll question or topic in the applicable field.
2. Enter your options in the **Options** fields. Add more options with the **Add option** button at the bottom of the list.
3. Click **Finish editing** to finalize the slide.

**Settings**

- Show results as %: Displays the proportion of the vote, instead of the number of votes.
- Anonymous votes: Hides the name and avatar on placed votes for anonymous inputs.
- Allow multiple votes: Lets you set the votes per person for selecting multiple options. Maximum value of 20.

When users vote on mobile devices, they can check and uncheck boxes prior to clicking **Submit**. On canvas, participants can vote (or change their vote) until the Activity is stopped.

### **Open-ended**

The open-ended activity lets you collect free text responses to share thoughts on a topic.

After adding an Open-ended activity:

1. Enter text in the **Enter poll question** field.
2. Click **Finish editing** to add the Open-ended slide to the canvas.

**Settings**

- Anonymous answers: Hides the name and avatar on submitted answers for anonymous inputs.
- Limit answers per person: Lets you set the number of answers per person. By default, there is no limit.

When the Activity is started, users can add their answers from a device or on the canvas. Submitted answers cannot be changed.

### **Word cloud**

The word cloud activity lets you visualize the most popular thoughts on a topic. More frequently used words will appear larger within the word cloud.

After adding a word cloud activity:

1. Enter text in the **Enter your question** field.
2. Click **Finish editing** to add the Word cloud slide to the canvas.

**Settings**

- Anonymous answers: Hides the name and avatar on submitted answers for anonymous inputs.
- Limit answers per person: Lets you set the number of answers per person. By default, there is no limit.

## Present with Activities

Click **Start Presentation** in the context menu of the Miro Slides deck.

When you reach the **Join instructions** slide, participants can join from any device (phone, laptop, tablet) by:

1. Scan the QR code with their phone camera.
2. Visit miro.com/join and enter the session code. For security reasons, the 6-digit join code changes every 10 minutes.

Navigate through slides like a normal presentation. Participants will see and interact with activities as you progress.

:::note
When a slide is presented without an activity, participants see a **Waiting for activity** screen.
:::

## Participate in Activities

### From a mobile device

You can join Activities by either scanning the **QR code** shared by the facilitator or by entering the 6 digit code at [miro.com/join](http://miro.com/join). You do not need a Miro account to participate.

When you join, you will be prompted to enter your name.

When the facilitator is not presenting an Activity, you will see a **Waiting for the next activity** page.

When the facilitator starts an Activity, the page will be updated so you can participate.

You can change your name and locale on connected devices (via [miro.com/join](http://miro.com/join)) by clicking on the avatar in the top right and adjusting the profile settings.

### On the board

Collaborators can participate in Activities directly on the board. Presenters should make sure participants have been invited to the board prior to starting any Activities.

## Using Activities

When presenting, participants can join Activities by using the join link and code visible in the top bar on the Activities slide. The QR code can also be shown to allow mobile users to join more easily by clicking the QR code icon.

![activities.png](images/31128769665682_activities.png)

*Join Activities through the toolbar at the top of a slide*

Activities can be closed by clicking the **Stop Activity** icon in the context menu. They can be started again by clicking the **Start Activity** icon.

Activities can be reset once they have responses by stopping the activity from the context toolbar and then clicking the **Reset** icon. This will remove all responses but keep the activity configuration (like title and options) and settings.

Once stopped, Activities can be edited by clicking the **Edit** icon in the context toolbar. If the activity contains responses, the activity needs to be reset to make any changes.

### **Export activity response****s**

Choose the slides you’d like to gather participant input from, then click the **Export** icon from the context menu. Answers can be exported to Sticky notes or to a Table.
