Set the status for your Formats, including Diagrams, Prototypes, Docs, and Slides, so that team members instantly know the current stage of your work. The status will be shown in the Context menu above your Format, as well as when in Focus mode.

When the Format is set as the default view for your Board, the Board status and Format status will be synced.

There are five statuses available:

- Draft
- In review
- Approved
- Done
- Outdated

## Set or change a status

1. Click on the **vertical three dots** (![icon-main.svg](images/33291722969234_icon-main.svg)) icon in the **Context** menu toolbar.
2. Select **Assign status**.
3. The default status will appear as **Draft**.
4. Click on the status in the **Context** menu toolbar to change it.

## Remove a status

1. Click on the **vertical three dots** (![icon-main.svg](images/33291722969234_icon-main.svg)) icon in the **Context** menu toolbar.
2. Select **Remove status**.
