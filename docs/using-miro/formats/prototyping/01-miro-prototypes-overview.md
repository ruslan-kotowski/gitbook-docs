Prototyping in Miro helps teams explore ideas visually and build early versions of digital experiences. Miro provides core tools for manual screen creation, and an optional add-on with **Miro Prototypes** that expands these capabilities with AI-powered creation and interactive behaviors.

You can use both approaches together throughout your workflow.

## **Recommended tools for prototyping**

Miro’s prototyping workflow is built on four types of tools:

- **Components** — UI elements, devices, icons, and advanced components.
- **Creation methods** — manual screen creation or AI-powered generation.
- **Interaction** — static layouts or interactive click-through previews.
- **Format** — Container for your prototypes with quick access to focus mode and previews.

Your access depends on your plan and add-on availability.

## **How the tools work together**

Miro’s prototyping tools are designed to be used together, not as separate paths. Most teams blend manual creation with AI-powered creation throughout their workflow.

You might:

- Generate an initial set of screens with AI.
- Rearrange or adjust screens manually.
- Add components by hand.
- Use AI again to restyle or extend the prototype.
- Add interactive navigation for feedback sessions.
- Continue refining manually as the idea develops.

This hybrid approach gives you **speed, flexibility, and control**.
