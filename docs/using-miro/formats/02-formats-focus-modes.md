Formats and Focus modes let your team seamlessly switch between free-form brainstorming and structured Docs, Tables, Timelines, Diagrams and Slides. Start with a blank canvas or a structured Format, and use Focus mode to minimize distractions and stay in the flow. Set a Format as the default view to make sure everyone opening the board lands where you want them to.

You can find more information on each of the formats here:

- [Docs in Miro](12-docs-in-miro.md)

## **Accessing formats**

To add a new format to the canvas:

1. Click the **Tools, Media and Integrations** (![icon-tools.svg](images/26711123751570_icon-tools.svg))iconin the toolbar.
2. Select the format you need: **Doc**, **Table**, **Timeline**, **Diagram**, **Prototype**,or **Slides**.
3. Click anywhere on the canvas to add the selected format.

## **Focus mode**

All formats can be opened in **focus mode** (full screen) when you want to focus solely on the format you're working on and not other content on the board. To access focus mode:

1. Click anywhere on the format you want to enter focus mode with.
2. Click on the **Focus mode** icon in the context menu.
3. To exit focus mode, click on the **Go to canvas** button at the top of the screen.

## **Set a format as default view**

Any of the formats can be set as default view for the board – meaning everyone opening the board will see the Doc, Table, Timeline, Diagram or Slides first.

To set the format as the default view:

1. Click anywhere on the format you want to enter focus mode with.
2. Click the **vertical three dots** (![icon-main.svg](images/30626371160338_icon-main.svg)) icon.
3. Select **Set as default view**.
4. In the modal, click **Set default**.

### Lock the default view

Board owners can lock the default view so that viewers can't access the rest of the board. To do so:

1. Click anywhere on the format you want to enter focus mode with.
2. Click the **vertical three dots** (![icon-main.svg](images/30626371160338_icon-main.svg)) icon.
3. Select **Set as default view**.
4. In the modal that opens, click the toggle to **Lock default view**.
5. Click **Set default**.

## **Share a link to focus mode**

If you'd like to keep the focus on the canvas, you can always share just a link to the focus mode of your format:

1. Click anywhere on the format you want to enter focus mode with.
2. Click the **vertical three dots** (![icon-main.svg](images/30626371160338_icon-main.svg)) icon.
3. Select **Copy focus mode link**.

## **Create formats from Dashboard or Space**

You can also create any format directly from your Dashboard, your Space overview, or the Spaces sidebar. This will automatically create the format as the default view—everyone joining you on the board will land in the focus mode of your format.

1. Open your **Dashboard** or your **Space** overview.
2. Click on the **Create new** menu.
3. Select the format you want to create: **Doc**, **Diagram**, **Prototype**, **Timeline**, **Table**, or **Slides**.

## **Create formats from Spaces sidebar**

When you are working on a board you can create new formats from the **Spaces sidebar**. The new format will be created in the same Space.

1. In the [Board bar](../working-on-the-board/02-miro's-new-simplified-user-interface.md), select the **Open sidebar** hamburger menu.The **Spaces sidebar** will open.
2. Click on the **Create new** icon.
3. Select the format you want to create: **Doc**, **Diagram**, **Prototype,** **Timeline**, **Table**, or **Slides**.

:::tip
You can pin a Format to your Space. The pinned Format appears in the Spaces sidebar.
:::
