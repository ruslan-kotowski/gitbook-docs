To avoid interruption of notifications from Miro, ensure that the following mailers are allowed:

| Mail Server | Marketo | Braze (Marketing) | Braze (Notifications) |
| --- | --- | --- | --- |
| Mailed By | m.miro.com | mail.miro.com, insights.miro.com | notification.miro.com, product.miro.com, updates.miro.com |
| IPs | 130.248.172.35 | 137.22.241.8, 137.22.240.64 | 137.22.241.90, 137.22.241.129, 137.22.240.227, 137.22.240.244 |
| Communication Type | Enterprise communication, Events, Marketing emails | Onboarding emails, Miroverse, Surveys, Other marketing emails | System notifications, Verification codes, Invites, Join requests, Mention notifications |
| Domains | m.miro.com | mail.miro.com, insights.miro.com | notification.miro.com, product.miro.com, updates.miro.com |

:::note
If you need to manage/stop notifications from Miro, check out [this guide](../../managing-your-profile/02-miro-notifications.md).
:::
