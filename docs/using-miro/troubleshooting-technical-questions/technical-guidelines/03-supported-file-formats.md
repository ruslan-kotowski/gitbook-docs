You can upload content to Miro in the following file formats:

| File type | File formats |
| --- | --- |
| Images | **bmp**, **gif**, **svg**(as a solid image), **jpeg**, **jpg**, **png**, **psd**, **heic, heif**, **pdf** |
| Tables and spreadsheets | **xls, xlsx, csv**, **ods** |
| Text documents | **doc**, **docx**, **odt, rtf** |
| Presentations | **ppt, pptx, odp** |
| Video | **MP4, MOV, WebM** |

The maximum file size you can upload from any source is 30 MB. The maximum image resolution from any source is 32 MP. The restriction for image dimensions is 8192x4096 pixels.

Learn how you can upload files to your board: [Uploading files to boards](../../import-and-export/import/05-uploading-files-to-boards.md), [Ways to add content](../../working-on-the-board/07-ways-to-add-content.md).

If you are having issues with uploading PDF files, take a look at [this troubleshooting guide](../../import-and-export/import/05-uploading-files-to-boards.md#possible-issues-with-uploading-pdf-files). In case you experience issues with uploading other types of files, check out [these troubleshooting steps](../../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md).

:::tip
You can add **PDF files** with the option to [turn pages over or page by page](../../working-on-the-board/21-work-smarter-not-harder.md#split-multipage-docs).
:::

:::tip
Import **Google Documents** (spreadsheets, documents, and slides) via [Google Drive integration](../../../integrations-apps/google/05-google-drive.md) with the option to edit them right on the board.
:::

:::tip
There are several ways to import a **spreadsheet**: via [Upload menu](../../import-and-export/import/05-uploading-files-to-boards.md), [as sticky notes](../../essential-tools/14-sticky-notes.md#pasting-from-a-spreadsheet-google-sheets-excel-etc), or [into Miro tables](../../advanced-tools/05-grid.md).
:::

:::tip
If you work with **SVG** images that contain text be sure to have the text converted to lines so the visual of your file does not depend on the fonts installed on the device of your collaborators.
:::

## Video upload per plan

Support for [video upload](../../essential-tools/01-video-upload-and-playback-beta.md) is currently a beta feature available on Business and Education plans, and Enterprise subscriptions that have beta features activated.

Members on a Free plan can upload video during the beta. When the beta ends, Free members can continue to watch videos uploaded during the beta, but cannot upload new videos unless they upgrade.

**More information:** See [Video upload and playback (BETA)](../../essential-tools/01-video-upload-and-playback-beta.md).

## Frequently asked questions

Does Miro support uploading transparent PNG images?

Yes, you can import transparent images to your boards.

Are animated gifs rendered on Miro boards?

Yes, learn more about [GIFs](../../working-on-the-board/21-work-smarter-not-harder.md#adding-gifs).

Can the ZIP format be uploaded to Miro?

No, please extract files before uploading them to Miro. See the list of supported file formats at the top of the page.

If I embed a PDF on a Miro board and then change the source PDF, will the embedded version automatically update?

No. The connection between a desktop or cloud-based PDF file that was uploaded and Miro is one-way only. You'll have to re-embed the PDF if any changes are made.

Is it possible to import Keynote, Pages, Numbers formats from Mac to a Miro board?

The list of supported files does not include the formats, but as a workaround, you may just export your file in Powerpoint/Word/Excel format by clicking on *File* > *Export to* > *Powerpoint...* After this, drag the exported file into Miro.
