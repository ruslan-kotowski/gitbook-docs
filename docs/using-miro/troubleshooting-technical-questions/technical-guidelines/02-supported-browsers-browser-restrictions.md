This article provides information about which desktop and mobile browsers Miro supports.

:::note
Miro supports all versions of major browsers for at least 12 months, including active, long-term support releases. Earlier browser versions may be out of developer support, which may impact your Miro experience. To ensure that you have the optimal Miro experience, update your browser(s) at least once a year.
:::

Miro officially supports the following browsers:

- **Desktop**
  - Chrome
  - MS Edge
  - Firefox
  - Opera
  - Yandex Browser
- **Mobile**
  - Chrome
  - Safari
  - Samsung Internet

:::note
Boards accessed on mobile browsers are view-only. To ensure access with your assigned privileges, download the [Miro mobile app](../../../getting-started/apps-for-devices/08-mobile-app.md).
:::

:::warning
Internet Explorer is not supported.
:::

## Board loading issue in Safari

Please try to follow the steps below if you experience the board freezing/loading issue in Safari v. 15.2, OS Monterey (you may also get the error message "*This web page was reloaded because a problem occurred*" or "*This web page and one other page are not responding*"):

1. Go to Safari > Preferences > **Develop** > **Experimental Features.**
2. Turn **off** the **GPU Process: Canvas Rendering** feature.

   ![](/attachments/token/45hImX8u1weQZnUaPOXtAT971/?name=inline1581405683.png)

   > ✏️ ​If you don’t see the **Develop** menu in the [menu bar](https://support.apple.com/en-gb/guide/safari/aside/glos33eb8abd/15.1/mac/12.0), open Safari > Preferences, click **Advanced**, then select **Show Develop menu in menu bar**.
