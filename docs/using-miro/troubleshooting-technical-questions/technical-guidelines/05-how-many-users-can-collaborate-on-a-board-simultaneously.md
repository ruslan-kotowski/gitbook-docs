Miro is built for teamwork and enables many users to work together effectively on a single board. This section outlines what you can expect when collaborating with a large number of participants.

Miro is meant for collaboration and supports a stable work of multiple users on the same board.

Two of our frequent use cases — PI plannings and Workshops — may involve a few hundred participants, so we constantly optimize performance for scaled-up collaboration.

The largest session we hosted so far had 377 users. Although this case is a bit extreme, the board remained operational and collaboration was successful. A more common scenario that we see almost every week is **around 200 users (Editors/Commenters)** working simultaneously on the same board.

We test our app regularly with a higher number of users, but it is too early for us to say that everyone’s experience will be seamless if you go over 300 collaborators.

Consider that the board is likely to slow down gradually with the number of users or lag to some extent during intensive user activity. Participants with older and less powerful devices will experience a slow-down earlier.
