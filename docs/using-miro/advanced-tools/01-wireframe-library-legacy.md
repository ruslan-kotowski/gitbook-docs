:::note
The Wireframe Library is being upgraded to the new Prototyping Library. Right now, Wireframe library only visible to Enterprise plans not in the Miro Prototyping Beta.

**More information:** See [Prototyping library](../miroverse/prototyping/02-prototyping-library.md), [Prototyping overview](../miroverse/prototyping/01-miro-prototypes-overview.md), and [Miro Prototyping (BETA)](../miroverse/prototyping/03-miro-prototypes.md).
:::

The **Wireframe Library** is being upgraded to a new **Prototyping Library**, which brings a more powerful and flexible set of tools for creating interactive screens.

Anything you’ve already created with the Wireframe Library will still work on your boards. But some older components and device frames will no longer be available in the toolbar and won’t receive future updates.

![legacy-wireframe-library.png](images/28175966882194_legacy-wireframe-library.png)

*The legacy Wireframe library*

### What’s changing

- The **Wireframe Library** has been merged with the **Prototyping Library**.
- All **components** of the Wireframe Library now live under the **Wireframes** tab in the **Prototyping Library**.
- **Icons** are available in the **Icons** tab in the **Prototyping Library**.
- **Mobile**, **Tablet**, and **Browser device frames** have been refreshed and replaced with **Mobile**, **Tablet**, and **Desktop Screens**.
- The **Prototyping Library** screens and components now support new features like:
  - Click-through preview mode.
  - AI-powered screen generation.
  - Editable mockups from screenshots.

:::note
*If you're on an **Enterprise plan and not yet enrolled in the Miro Prototyping Beta**, you might still see the legacy library for now.*
:::

### What this means for your work

- Your existing wireframes are safe and will continue to work.
- Any updates to your wireframes will need to use the new **Prototyping Library**.

## FAQ

**Is the Wireframe library still available?**

No. It’s been replaced by the Prototyping Library, which includes most of the same components and more. If you're on an Enterprise plan and not yet enrolled in the Miro Prototyping Beta, you might still see the legacy library for now.

**What happened to UI elements like buttons and inputs?**

They’re now in the **Wireframes tab** of the Prototyping Library.

**Will my previous wireframes still work?**

Yes. Anything already on your board will remain as-is. But you’ll need to use the Prototyping Library to ensure you can continue add or edit going forward.

**What’s different in the new library?**

The new Prototyping Library supports AI generation, click-through previews, editable mockups from screenshots, and updated visuals — all designed to help teams go from idea to prototype faster.

**Will the Prototyping Library continue to be available on the Free plan like the Wireframe Library is?**

Yes. Basic wireframing tools — including the UI components from the Prototyping Library (formerly the Wireframe Library) — will continue to be available on all plans. Advanced features like interactive preview mode and AI-powered capabilities (e.g., generate from prompt, screenshot to prototype, AI theming) may require a Prototyping Add-on after the free beta ends.
