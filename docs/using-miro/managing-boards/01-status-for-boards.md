Set the status for your boards so that team members instantly know the current stage of your work. The status will be shown on the Board menu toolbar and in the Spaces overview sidebar.

There are five statuses available:

- Draft
- In review
- Approved
- Done
- Outdated

## Set or change a status

1. Click on the **vertical three dots** (![icon-main.svg](images/30051085774994_icon-main.svg)) icon in the Board menu toolbar.
2. Select **Assign status**.
3. The default status will appear as **Draft**.
4. Click on the status in the Board menu toolbar to change it.

## Remove a status

1. Click on the **vertical three dots** (![icon-main.svg](images/30051085774994_icon-main.svg)) icon in the Board menu toolbar.
2. Select **Remove status**.
