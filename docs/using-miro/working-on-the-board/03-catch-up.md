Catch up gives users an AI-powered, streamlined overview of changes that have occurred on the board since their last viewing.

## Key features

Catch up includes the following key features:

- **See visual highlights**
  Key updates are highlighted on the board.
- **Quick summary of changes**
  Immediately see what has changed and what requires action.
- **Step-by-step walkthrough**
  Get a step-by-step walkthrough of the edits and changes, organized by sections on the board.

## How to use Catch up

Follow these steps to access and use Catch up.

1. Click on the **Activity** (![icon-activity.svg](images/24093924443794_icon-activity.svg)) icon in the upper right toolbar.
   The Activity menu opens.
2. Click on the **Catch up** button.
   The Catch up dialog opens on the board.

   ![catch-up-new.png](images/27120802154642_catch-up-new.png)*The Catch up dialog on the board*
3. **Recent changes** will be shown along with the overview.
4. Click on a recent change to go directly to that panel.
5. Click **Show details** to start reviewing the changes.
6. Use the forward and back **arrow** buttons in the dialog to navigate through Catch up.
7. Click on the numerical links for a change to view the relevant section on the board.
8. Use the drop down menu to select a different time period to view: Last week, Last two weeks, or Last month.

### Alternative procedure for accessing Catch up

Follow these steps for an additional way to access Catch up.

1. Click on the board **Main menu** (![icon-main.svg](images/24005170925074_icon-main.svg)) icon.
   The Main menu opens.
2. Hover over the **Board** button.
   The Board submenu opens.
3. Click on the **Catch up** button.
   The Catch up dialog opens.

## FAQ

**Why can't I access Catch up?**

Catch up is only available to users with Miro AI enabled. If your admin hasn't enabled Miro AI, they'll need to do so in order for you to access Catch up. Instructions to do so can be found here: [Feature activation](../../enterprise-administration/managing-enterprise-teams-and-content/06-feature-activation.md).
