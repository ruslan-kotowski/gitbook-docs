Sync and visualize content across boards, keeping it seamlessly connected and up-to-date.

## Key features

- **Seamlessly connected -** Embed live widgets like frames, documents, or diagrams directly into multiple boards and documents. Keep everything consistent with real-time updates.
- **Enhanced efficiency -** Save time by reusing content across platforms, so you can focus on collaboration and creativity without the hassle of repeating tasks.

## How to create a synced copy

### Copy / paste between boards

To sync content across boards, copy one Widget from one board, paste in another, then confirm **Replace with synced copy**.

![](images/24294836401810_002.gif)

*Copying and pasting between boards*

### Via the widget context menu

To create a synced copy:

1. Select a single widget.
2. Open the three dots (**...**) menu and select **Copy and Sync**.
3. Navigate to the destination board and paste (**cmd/ctrl + V**).

This option also allows you to create synced copies of the same board.

![](images/24294836401938_003.jpg)

## Editing Synced Widgets

:::warning
Synced copies are view-only for everyone. To change the copy content, users have to modify the original content.
:::

The synced copy is a standalone board widget.

Users with editing access can change its position, scale, add to Frames or Docs, and group with other widgets.

Comments made on a synced copy are only visible on that specific copy and do not appear on the original widget or any other synced copies.

## Navigation and copies management

Both the original widget and its synced copies have a list of copies in the context menu. It helps with navigation between copies and with opening the original widget to edit the content.

To navigate to the copy/original widget:

1. Click on a synced widget to select it.
2. In the contextual menu, click on the **arrow icon** to open the list.
3. Click on any item to open a board in a separate tab or move to the widget on the same board.

## Permissions

The creation of Synced copies is available for users with a Miro profile and visitors with editing access. If you only have viewing or commenting access, you’ll need to sign up for a Miro account and gain editing permissions to create synced copies.

:::warning
If a user doesn't have access to the board containing the original Widget, they won't be able to see the Synced Widget anywhere else.
:::

Make sure to give the right users permission to see the original content.

## Frequently asked questions

**I added a synced Widget to another page, but no one else can see it.**

Whoever you share the board with needs to have access to the original widget to see any synced copies.

**How can I understand if its synced copy or hard copy?**

Synced Widget are indicated by a purple selection border. Editing the original widget will change other instances within 10sec interval.

**Can I provide access to the synced content with no original board access grants?**

Currently, the original board permissions are used to check the user can see the synced content.

**What if I delete the original content?**

All the synced copies stay, however, users will see the message “The original content was deleted”.

**How can I make sure that the synced content is up-to-date?**

By default, changes in original content are translated to copies within 10 sec with no extra actions from the user. Otherwise, user sees the error message instead of outdated content.
