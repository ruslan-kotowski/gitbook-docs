## Select several objects

Make sure you've activated the  [select tool](21-work-smarter-not-harder.md#switching-between-selectpan-modes)  (or press **V** to activate it) and drag the selection field across the needed objects. This will select every object touched by selection (excluding [USM](../advanced-tools/07-user-story-mapping.md), [Kanban](../advanced-tools/02-columns-formerly-kanban.md), [mind map](../advanced-tools/03-mind-map.md), and [tables](../advanced-tools/05-grid.md) - to select these objects, cover at least 90% by the selection field). If you work in the  [Mobile](../../getting-started/apps-for-devices/08-mobile-app.md)  or  [Tablet app](../../getting-started/apps-for-devices/11-tablet-app.md)  or use touchscreen, make a **long tap**  and drag.

You can also use the object filter feature to select specific types of objects to move. Click and drag to select all objects, then click **Filter** in the context menu, and select an object type. The selection field will adjust, and you will be able to move only the objects you have filtered.

![object-select.png](images/25827368311698_object-select.png)
*Filter by object type*

To start a  *precise*  selection that only includes an object if it covers 90%+ of its surface, long click/press and drag. This is helpful if you need to select objects on top of another background shape.

If you work with a keyboard, you can also select particular objects by clicking them one by one while holding down **Shift**  or  **Ctrl**  *(for Windows)/* **Command** *(for Mac).*

### Precise selection

Precise selection enables you to select objects only when you cover more than 90% of their surface.

To use precise selection, ensure you are using the select tool. Then long-click or long-press your mouse button. You can now drag the select tool using precise selection.

## Using the lasso tool to select multiple objects

Another way to select objects is to use the Lasso tool. To include an object within the selection, you need to include at least 90% of it in the selection area.

:::tip
Select all elements on the board using **Ctrl+A** / **Cmd+A**  [shortcut](06-shortcuts-and-hotkeys.md)  .
:::

## Modifying the selected objects

The selected objects can be moved and resized together. You can [align](08-structuring-board-content.md#aligning), [group](08-structuring-board-content.md#grouping), [lock](17-locking-content-on-the-board.md), and filter the objects (see below), or use other options on the menu.

:::note
Make sure none of the objects you want to select is [locked](17-locking-content-on-the-board.md). Otherwise, you'll need to unlock them first by clicking the object and choosing **Unlock**.
:::

:::warning
You cannot group objects within [tables](../advanced-tools/05-grid.md) or objects located on different [frames.](../essential-tools/07-frames.md)
:::

:::warning
[Visitors](../sharing-boards/08-collaboration-with-visitors.md) cannot lock/unlock objects on the board. If [protected lock](17-locking-content-on-the-board.md#use-protected-lock) is enabled on an object, only the board owner/[co-owner](../sharing-boards/06-co-owners-of-boards-and-spaces.md) can unlock it.
:::

:::tip
Another way to move objects together is to place them on a single frame and move the frame. [Learn more](../essential-tools/07-frames.md) about frames in Miro.
:::

Smart duplicating

Speed up your work by using **Ctrl + D** shortcut to quickly and easily duplicate objects on the board.

:::note
You can also use **Alt + arrows** to duplicate an object vertically or horizontally.
:::

## Lock an object

Prevent objects from being accidentally moved, edited, or deleted by locking them. Use protected lock to prevent other users from changing your content. Learn more in the article: [Locking content on the board](17-locking-content-on-the-board.md).

## Align objects

Turning on this option will create alignment guides for any objects you move, helping to ensure a clean, well-balanced look to your board objects.

You can enable/disable the feature in the Main menu. Click the **three dots**(**...**) > **Preferences** > **Align objects.**

## Arranging objects

Arrange objects on your board. This feature helps you style boards and diagrams precisely, especially with a large amount of overlapping content.

1. Select the object.
2. From the context menu, click the three dots (**...**) to open the **more** menu.
3. Choose one of the following options:

- **Bring to front:** Move an object to the front of all objects.
- **Send to back:** Move an object to the back of all objects.
- **Bring forward:** Move an object in front of the object directly in front of it.
- **Send backward:** Move an object behind the object directly behind it.

:::note
This feature is not available for frames. Frames are always placed behind board objects.
:::

## Rotate objects

Easily rotate objects on the board to adjust your content. Find the rotate icon in the lower-left corner of the object, click and drag it to change the position.

## Clearing Content

You can clear the content of multiple widgets (such as sticky notes, shapes, and cards) simultaneously. This feature allows you to remove all text, tags, emojis, authors, assignees, and due dates from the selected widgets, reverting them to their original state while retaining their styling (colors, sizes, etc.).

To clear content:

1. Select the widgets you want to clear.
2. Right-click to open the context menu.
3. Choose "Clear content" from the menu.
4. Alternatively, use the shortcut Cmd + Backspace (Mac) or Ctrl + Backspace (Windows).

Clear content does not work on other widgets (e.g., text, table widgets) and does not work on Jira or Azure cards. If a user selects multiple sticky notes, shapes, and cards, the content will be deleted on all widgets except for the Jira/Azure cards.

## Frequently asked questions

1. *I cannot drag the selection field. What do I do?*  - Please make sure to switch to the  [select tool](21-work-smarter-not-harder.md#switching-between-selectpan-modes)  .
2. *I cannot group selected objects. Why?*  - Please note that is not possible to group objects within  [tables](../advanced-tools/05-grid.md)  and objects located on different  [frames.](../essential-tools/07-frames.md)
3. *Can I select and move individual objects inside a group?*  - Yes, double-click an object and drag it. Look how you do this  [on this page](08-structuring-board-content.md)  .
