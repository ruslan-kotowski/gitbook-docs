Miro gives you almost infinite possibilities of working with objects on a board, so here are some tips on how to achieve your goals easier and faster.

## Board navigation

### Use minimap

Make use of a minimap, which can be found in the bottom right corner of the board by clicking on the percentage icon and then **Show minimap** (or just press the **M** [hotkey](06-shortcuts-and-hotkeys.md) to open/close it).

![navigation-toolbar-minimap.png](https://help.miro.com/hc/article_attachments/21999229413138)

*Showing the  minimap*

### Switching between select/pan modes

Try using [hotkeys](06-shortcuts-and-hotkeys.md) to select a certain object or pan across the board. Use **V** and **H** hotkeys to switch between the **select/edit** mode (cursor tool) and the **hand**/**pan** mode. You can also activate the select mode on the toolbar.

:::tip
Learn more about navigating the board in [this article](05-using-miro-with-a-mouse-trackpad-or-touchscreen.md).
:::

![work_smarter_select_tool.png](images/21016720033170_work_smarter_select_tool.png)*The select tool on the toolbar*

## Working with objects

### Smart duplicating

Speed up your work by using **Ctrl + D** shortcut to quickly and easily duplicate objects on the board.

![smart_duplicating.gif](images/21016688231442_smart%20duplicating.gif)*Smart duplicating*

:::note
You can also use **Alt + arrows** to duplicate an object vertically or horizontally.
:::

### Object dimensions for precise diagramming

Deliver professional diagrams faster and easier. Use [Object dimensions](../formats/diagramming/01-miro-for-mapping-diagramming.md) to create the same size objects across your board with precision.

![Using_dimensions_in_Miro.gif](images/21016720042386_Using%20dimensions%20in%20Miro.gif)

### Lock an object

Prevent objects from being accidentally moved, edited, or deleted by locking them. Use protected lock to prevent other users from changing your content. Learn more in the article: [Locking content on the board](17-locking-content-on-the-board.md).

![lock_content.jpg](images/21016720044050_lock%20content.jpg)*Lock option*

### Align objects

Turning on this option will create alignment guides for any objects you move, helping to ensure a clean, well-balanced look to your board objects.

![main_menu_work_smarter_align_objects.gif](images/21016720045458_main_menu_work_smarter_align_objects.gif)*Aligning objects on the board*

You can enable/disable the feature in the Main menu. Click the **three dots**(**...**) > **Preferences** > **Align objects.**

![align-objects.png](https://help.miro.com/hc/article_attachments/21537451531794)
*The option to enable Align objects in board settings*

### Arranging objects

Arrange objects on your board. This feature helps you style boards and diagrams precisely, especially with a large amount of overlapping content.

1. Select the object.
2. From the context menu, click the three dots (**...**) to open the **more** menu.
3. Choose one of the following options:

- **Bring to front:** Move an object to the front of all objects.
- **Send to back:** Move an object to the back of all objects.
- **Bring forward:** Move an object in front of the object directly in front of it.
- **Send backward:** Move an object behind the object directly behind it.

:::note
This feature is not available for frames. Frames are always placed behind board objects.
:::

Select and filter objects

Filters are extremely helpful if you need to bulk change a particular type of object in a group: select several items, click **Filter** on the context menu, and choose an object type. Learn more about object selection in [this article](10-working-with-objects.md).

![Miro_filters.gif](images/21016688243346_Miro%20filters.gif)*Selecting, filtering, and modifying multiple objects*

Rotate objects

Easily rotate objects on the board to adjust your content. Find the icon in the lower-left corner of the object, click and drag it to change the position as shown below.

![rotate_an_object.gif](images/21016688245394_rotate%20an%20object.gif)*Rotating an object*

### Clearing Content

You can clear the content of multiple widgets (such as sticky notes, shapes, and cards) simultaneously. This feature allows you to remove all text, tags, emojis, authors, assignees, and due dates from the selected widgets, reverting them to their original state while retaining their styling (colors, sizes, etc.).

To clear content:

1. Select the widgets you want to clear.
2. Right-click to open the context menu.
3. Choose "Clear content" from the menu.
4. Alternatively, use the shortcut Cmd + Backspace (Mac) or Ctrl + Backspace (Windows).

Clear content does not work on other widgets (e.g., text, table widgets) and does not work on Jira or Azure cards. If a user selects multiple sticky notes, shapes, and cards, the content will be deleted on all widgets except for the Jira/Azure cards.

## Working with documents

### Split multipage docs

> **Available on:** browser version, [Desktop App](../../getting-started/apps-for-devices/05-desktop-app.md)

A way for your team to collaborate on documents or PDF or Powerpoint files — expand any pages, lay them out on the board, and leave comments directly on pages.

To divide a PDF or a Powerpoint file into a certain number of pages:

1. Upload the file to the board.
2. Click on the file, in the context menu choose ****Extract pages.****
   > ✏️ The option is available in the [cursor (select) mode](#mini) only. If the option doesn't appear on the menu, press **V** or select the cursor on the toolbar and click the object again.

   ![extract_pages.jpg](images/21016688251154_extract%20pages.jpg)*The option to extract pages on the PDF context menu*
3. Choose how you want to split the file - all or just specific pages and click **Extract.**
   ![extract_pages.gif](images/21016720055698_extract%20pages.gif)*Extracting pages*

Expanded pages will appear right under the original file. If there is no need in the original file you can delete it - all extracted pages will stay on the board.

Pin pages

To pin a particular page of a document on a board, switch to this page on the document's context menu, select **Pin,** and choose **Set current as start**. Every time you open the board, this page will be set as the first one.

> **✏️** The option **Set current as start** is available in the [cursor (select) mode](#pan) only. If the option is greyed out, press **V** or select the cursor on the toolbar and click the object again.

![pin_pages.jpg](images/21016688258706_pin%20pages.jpg)*Pinning a page*

## Working with images

### Replace images

Any image on the board can be replaced without affecting other objects on the canvas.

1. Click on the image to open the context menu.
2. Click the **Replace image** icon, and select one of the following options:

- **Replace from library:** The [Images and Icons app](../essential-tools/08-images-and-icons.md) will open, and you can select a new image.
- **Replace from board:** You will be prompted to select another image already present on the board.
- **Upload from device:** Upload and replace the image with one from your device.
- **Upload via URL:** Replace the image with one hosted online by entering the image's URL into the dialog box.

![Replace-images.png](images/21016720062098_Replace-images.png)

### Crop images

There is no need to use third-party software to crop images, as Miro has a tool for it. Select an image or choose **Crop** on the context menu. This enables the crop mode, which allows editing of the **rectangular** selection. Crop boundaries snap to surrounding board content to ensure the layout of images is visually crisp. You can update the position and scale of the images you are cropping without losing alignment with other content on the board. When it is done, just click anywhere on the board.

![crop_image.gif](images/21016688266130_blobid1.gif)*Cropping an image*

You can **crop images in various shapes** (e.g. a circle, square, etc.). Select the image, click the **Crop** icon in the context menu, and select a shape from the dropdown.

![cropping_in_shapes.gif](images/21016688267794_blobid2.gif)*Cropping an image into a circle*

You can also **bulk-crop images in various shapes**. Click and drag to select the images, click the **Crop** icon in the context menu, and choose a shape from the dropdown.

![](images/21016688269202_blobid3.gif)*Bulk-cropping images into a circle*

:::tip
You can always revert your cropped image to its original, just double click and expand the crop selection to its original size.
:::

### Image borders

Add borders on images and screenshots you upload or paste to your board to help them stand out.

1. Click on the image
2. In the context menu, click the border icon
3. Select the color and adjust the thickness of you border

![Image_borders.gif](images/21016688270610_Image%20borders.gif)
*Adding an image border to a screenshot*

### Bulk resize images

Resize multiple images on your board at once by height or width. Then use [Auto layout](08-structuring-board-content.md#auto-layout) to instantly align them.

**How to bulk resize images**

1. Drag the cursor to select all the images you want to resize
2. Click the resize icon in the context menu. You need to select multiple images before the resize option appears
3. Select **Match height** or **Match width**
4. Click on the gray **Auto layout** icon in the upper right corner

*![Bulk_resizing_images.gif](images/21016688272530_Bulk%20resizing%20images.gif)**Bulk resizing images by height or width*

### Adding GIFs

Add GIFs to your Miro boards to bring ideas to life with fun animated content. GIFs play for individual users for 8 seconds or one loop when added to the board, and when users hover over them. GIFs only play for each user interacting with the board, not for everyone in real-time.

Turn on [Reduce motion](../../getting-started/accessibility-in-miro/06-reduce-motion.md) to disable GIF autoplay.

:::tip
GIFs in presentations and [Miro Talktracks](../facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md) play automatically and loop endlessly while they're visible on the screen.
:::
