Command palette allows you to quickly search for an launch Miro tools and apps. Command palette also allows you to search for recent boards.

Command palette is only available to users with [edit access](../sharing-boards/01-board-access-rights.md#board-access-rights) and while in standard board mode. You won’t be able to launch Command palette while in presentation mode.

## How to use Command palette

1. Select the **vertical three dots** (![icon-main.svg](images/25950509512594_icon-main.svg)) icon in the Board toolbar.
   The Main menu opens.
2. Select **Edit** > **Commands**. Alternatively, use the **Cmd** + **K** keyboard shortcut.
   The Command palette opens.
3. In the search field start typing an app or tool name, or scroll through the list.
4. Click to launch the app or tool.
