There are 23 default colors in the palette. You can apply them to any [drawing](../essential-tools/10-pen.md), [shapes](../essential-tools/11-shapes.md), [connection lines](../essential-tools/05-connection-lines.md), [frames](../essential-tools/07-frames.md), [tables](../advanced-tools/05-grid.md), [cards](../essential-tools/02-cards.md), or [text](../essential-tools/16-text.md). The palette is the same across these tools and makes it much easier to create great-looking content.

:::warning
[Sticky notes](../essential-tools/14-sticky-notes.md) color palette is separate and limited to 16 colors.
:::

### Adding new colors

:::tip
Simplify team content creation by uploading colors to your [Brand center](../../administration/get-started-as-a-miro-admin/04-brand-center.md#how-to-upload-your-brand-colors), and apply your own [Brand style](../../administration/get-started-as-a-miro-admin/04-brand-center.md#how-to-apply-your-brand-style-to-frames) to boards.
:::

To add a new color:

1. Select your object.
2. Open the color palette.
3. Click on the **+** icon.
   You will see the color spectrum open.
4. Select the color you'd like to add. There are three methods to do so, outlined below.

![custom-color-picker-new.png](images/25493668317586_custom-color-picker-new.png)

*The color spectrum tool for adding new colors*

When you add a new color, it is added to the color palette of all tools and the change is applied to your profile.

Note that the color palette of [sticky notes](../essential-tools/14-sticky-notes.md) is not customizable.

There are three ways to add a new color to your palette.

From the color spectrum:

1. Move the slider or click on the place on the spectrum.
2. Then click on the canvas to save the color.

By entering the Hex code:

1. Type in the hex color code in the field at the bottom of the color spectrum.
2. Press **Enter**.

By using the color picker:

1. Click the dropper icon.
2. Click or drag anywhere on your board to pick up the color.

The customized palette applies to every board in your profile.

If you change the color of a [shape](../essential-tools/11-shapes.md)/[sticky note](../essential-tools/14-sticky-notes.md)/[card](../essential-tools/02-cards.md) and add a new shape/sticky note/card to the board, the color of the added objects will be the same as the previously used color until you reload the board.

### Removing colors

If you want to clear the palette of unused colors, just click-and-drag them outside the palette. Please note that the default colors cannot be removed.
