Add code blocks to your boards for collaborative programming, debugging and problem solving. Our code block widget has the most popular coding languages and is customizable.

Combine code blocks with our [mapping and diagramming](../formats/diagramming/01-miro-for-mapping-diagramming.md) features to review architecture and flows. And use diagram connectors to highlight relationships between pieces of source code.

**Use code blocks for:**

- Agile ceremonies
- Collaborative development and debugging sessions
- Remote coding interviews

## How to add a code block

1. Go to the creation toolbar on the left side of the board
2. Click the **More apps** icon
3. Search **Code block** or scroll down until you see Code block
4. Click the Code block app icon
5. Click anywhere on the board to add a Code block

## How to customize a code block

Within the code block context menu you can toggle lines on and off, adjust the font size and switch programming languages.

1. Click the code block.
2. Within the context menu choose a programming language from the dropdown, increase or decrease the font size, and click the line numbers icon to toggle lines on and off.

## Frequently asked questions

What programming languages are currently available in code blocks?

JavaScript, TypeScript, Python, C++, Java, Go, Rust, PlainText, Swift, Ruby, SQL, HTML, CSS, JSON, GraphQL, Kotlin, YAML, and Mermaid.
We add languages based on customer requests regularly; reach out to your Miro customer success manager if you have suggestions.
