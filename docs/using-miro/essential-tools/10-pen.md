With the pen tool, you can add freehand drawings to the board and remove them if need be. The tool works well with mouse, trackpad, and touchscreen and can become an irreplaceable part of your tablet workflow.

## How to use pen

:::note
You can use any type of pen tools - Apple Pencil, Surface Pen, Samsung S Pen, etc. -  on any type of [device that is compatible with Miro](../../getting-started/apps-for-devices). Watch [the video](10-pen.md) about enhanced stylus support on touch devices in Miro.
:::

Click the **Pen** toolor [press P on the keyboard](../working-on-the-board/06-shortcuts-and-hotkeys.md) to start using the tool. Use presets to easily switch from one color and thickness to another.

![using_pen.gif](images/21017348235538_using%20pen.gif)
*Using the pen*

Use **Highlighter** to annotate mockups and make meetings more engaging.

![highlighter.gif](images/21017348236946_highlighter.gif)
*Using highlighter*

Take advantage of [smart drawing](12-smart-drawing.md) and easily create [shapes](11-shapes.md), [sticky notes](14-sticky-notes.md), and [connection lines](05-connection-lines.md).

:::tip
More shapes can be created with the [shape tool](11-shapes.md).
:::

![smart_drawing_in_Miro.gif](images/21017318363666_smart%20drawing%20in%20Miro.gif)
*Miro smart drawing*

You can create up to three presets for pen, highlighter, and smart drawing (three different presets per tool). Double click a preset to edit it by changing the color and thickness.

![presets.jpg](images/21017318365330_presets.jpg)
*Pen presets*

To delete a drawing, choose **Eraser** under the smart drawing icon and swipe across the drawings while holding down the mouse button. Note that the eraser removes pen drawings only. You can also select drawings with the **Select** tool and erase them using the **Delete**key on your keyboard.

![eraser.gif](images/21017318366354_eraser.gif)
*Erasing pen drawings in Miro*

If you need to erase part of a drawing, you can use the **Precision eraser** tool. Just select the tool, then click and hold while going over the part of the drawing you want to erase.

![precision-eraser.png](images/31320402236690_precision-eraser.png)

*Precision eraser tool*

Lasso tool is super helpful for selecting and moving hand-drawn or any other objects on the board.

![lasso_tool.gif](images/21017318367506_lasso%20tool.gif)
*Selecting objects with the Lasso tool*

To stop using the pen, eraser, or lasso tool, simply switch to any other tool or to the select tool on the toolbar.

![select_tool.jpg](images/21017318368786_select%20tool.jpg)
*The select tool on the toolbar*

### Frequently asked questions

1. *Does Miro support converting handwriting to text?*
   - No, this is not yet available. However, as you can see in the video above, the option to convert handwriting to [text](16-text.md) is supported on certain iPad models with Apple Pencil and Scribble.
2. *Can I adjust the transparency of the highlighter?*
   - This is not currently possible.
3. *How do I draw a straight line?*
   - You can use a [connection line](05-connection-lines.md) or create a straight line in the [smart drawing mode](12-smart-drawing.md).
4. *Can I delete a pen preset?*
   - No, but you can easily change the color and thickness of it.
