Resize widgets using numeric dimensions for pixel-perfect sizing in Formats.

:::note
Precise resizing is available in select Formats, including Diagramming, Miro Prototypes, and Miro Slides.
:::

## Precise resizing

1. Enter Focus mode by clicking the **Focus mode** icon on your Format's context menu.
2. Click on the widget you'd like to resize. Supported widgets include text, images, stickies, stencils, and prototyping shapes.
3. In the context menu for the widget, click the **Resize** icon.
   A dimensions dialog will open below the menu.
4. Enter the pixel dimensions for **width** and **height**.
5. Press **enter** to commit the changes.

:::note
In text boxes, only the width can be specified. Height will adjust automatically based on the contents of the text box.
:::
