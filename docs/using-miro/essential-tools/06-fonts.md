Check out the robust Miro font collection, enriched with 20+ best-selling fonts to make your content more visually attractive and efficient. Add greater interest to your text by highlighting its key points.

## Change the font

:::tip
Simplify team content creation by uploading fonts to your [Brand center](../../administration/get-started-as-a-miro-admin/04-brand-center.md#how-to-upload-your-brand-fonts).
:::

To change the font of your text in Miro, highlight the text or a shape and choose the font from the drop-down menu:

![Miro_fonts.gif](images/21017592644754_Miro%20fonts.gif)
*Changing text font*

Please note that the font cannot be chosen for a particular word or phrase in a text box; it is applied to the entire text of an object. You can change text fonts of Docs, Slides, [shapes](11-shapes.md), and [text boxes](16-text.md). [Sticky notes](14-sticky-notes.md) support two font styles. [Cards](02-cards.md), [connection lines](05-connection-lines.md#adding-text-labels), and [mind map nodes](../advanced-tools/03-mind-map.md) don't support multiple fonts.

## FAQ

Can I add other fonts to Miro?

Yes, you can upload your brand fonts via the [Brand center](../../administration/get-started-as-a-miro-admin/04-brand-center.md).

Can I change the font color?

You can change the font color of [text boxes](16-text.md), [shapes](11-shapes.md), [mind map nodes](../advanced-tools/03-mind-map.md), and [connection lines](05-connection-lines.md#adding-text-labels). The text color cannot be changed on [sticky notes](14-sticky-notes.md) and [cards](02-cards.md).

Can I set the default font for my board?

The font that you are using when creating a text box or a shape will be the same for a new text box or shape that you will create on the board in the current working session (until the board is reloaded). If you'd like to change the font for all existing text boxes or shapes on the board, select all objects on the board (you can use **Ctrl + A** *for Windows* or **Cmd + A** *for Mac*), [filter text/shapes](../working-on-the-board/21-work-smarter-not-harder.md), and change the formatting.
