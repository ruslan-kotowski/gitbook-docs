New to Miro AI? Start with ready-made prompts for content generation and ideation. Each use case explains what it’s for and includes copy-ready Miro AI prompts.

## **Idea generation and expansion**

Boost idea flow and get to first drafts faster with ready-made prompts for Miro AI.

### Generate product feature ideas

**What it’s for:** Rapid feature lists grounded in user needs.

**Miro AI prompt:**

Copy

```
Generate 10 innovative product feature ideas based on the user persona selected on the Miro board that would solve their main pain points. Focus on features that are both valuable and technically feasible. Format as Miro Sticky notes.
```

### Create workshop follow-up questions

**What it’s for:** Sharper facilitation and deeper exploration after a session.

**Miro AI prompt:**

Copy

```
Generate 5 thoughtful follow-up questions based on the topic or decision from our workshop selected on the Miro board. Help us dive deeper into this topic and uncover potential issues or opportunities that might have been missed. Format as Miro Sticky notes.
```

### Create additional concepts or variations

**What it’s for:** Turn quick notes into richer idea clusters.

**Miro AI prompt:**

Copy

```
Generate 3–5 related concepts or variations of the idea from our brainstorming selected on the Miro board that we should explore further. Format as Miro Sticky notes.
```

### Generate alternative solutions

**What it’s for:** Explore multiple paths before converging.

**Miro AI prompt:**

Copy

```
Generate 4 alternative approaches to solve the problem selected on the Miro board, with the context of our current solution and problem statement. For each alternative, note one key tradeoff compared to our current plan. Format as Miro Sticky notes.
```

## **Meeting preparation**

Plan, facilitate, and follow up effectively.

### Create meeting agenda

**What it’s for:** Consistent, time-boxed agendas with clear outcomes.

**Miro AI prompt:**

Copy

```
Create a detailed agenda template for the meeting type and main objective selected on the Miro board. Include time allocations, key discussion points, and space for action items. Format as a Miro Doc.
```

### Create retrospective discussion questions

**What it’s for:** Balanced reflection and forward-looking action.

**Miro AI prompt:**

Copy

```
Create 8–10 engaging discussion questions/ideas based on the area we want to focus on for our team retrospective selected on the Miro board. Include both reflection and forward-looking questions. Format as Miro Sticky notes.
```

### Create icebreaker questions

**What it’s for:** Quick, contextual warm-ups for any group.

**Miro AI prompt:**

Copy

```
Generate 6 creative icebreaker questions based on our team context selected on the Miro board that are professional, fun, or thought-provoking as needed. Format as Miro Sticky notes.
```

### Create pre-meeting surveys questions

**What it’s for:** Understand perspectives before the meeting.

**Miro AI prompt:**

Copy

```
Create a 5-question pre-meeting survey based on the meeting type and topic selected on the Miro board. Questions should help us understand current perspectives and prepare more targeted discussions. Format as a Miro Doc.
```
