Use Miro AI with a variety of board objects including [sticky notes](../essential-tools/14-sticky-notes.md), images, diagrams, and [mind maps](../advanced-tools/03-mind-map.md).

:::warning
Miro AI is continually evolving. Miro AI may produce incorrect information, biased information, or may not know about recent events from the previous 6-12 months, resulting in inaccurate or outdated information. Always verify your results when using Miro AI.
:::

:::note
Miro AI is only available for Members. Guests and visitors cannot use Miro AI.
:::

## Using Miro AI with sticky notes

Miro AI enables you to following:

- Generate sticky notes
- Cluster sticky notes by keyword, author, tag, color, or sentiment
- Generate a document based on sticky notes
- Summarize a group of sticky notes

### How to use Miro AI to generate sticky notes

Follow these steps:

1. Above the creation toolbar, select **Create with AI**.
2. Select the **Sticky notes** button.
3. (Optional) Select a type.
4. Do one of the following to prompt Miro AI:
   - Enter a description
   - Select objects on the board
5. Select **Generate sticky notes**.
   Your sticky notes are added to the Miro board.

   You have successfully used Miro AI to generate sticky notes.

### How to use Miro AI to cluster sticky notes

Follow these steps:

1. Use the **Select** tool to select a group of sticky notes.
   The context menu displays above your selection.
2. From the context menu, select the **Cluster objects** button.
3. Do one of the following:
   - Select a cluster option.
     Your sticky notes are clustered based on your selection.
   - Select **Create a cluster**.
     Your sticky notes are clustered. To give context, you can optionally rename your cluster.

     You have successfully used Miro AI to cluster sticky notes.

### How to use Miro AI to generate a document based on sticky notes

Follow these steps:

1. Use the **Select** tool to select a group of sticky notes.
   The context menu displays above your selection.
2. From the context menu, select **Miro AI**.
3. Hover over **Document**.
   A drop-down menu opens.
4. Select a document type.
   Miro AI generates your document.

   You have successfully used Miro AI to generate a document based on a selection of sticky notes.

### How to use Miro AI to summarize a group of sticky notes

Follow these steps:

1. Use the **Select** tool to select a group of sticky notes.
   The context menu displays above your selection.
2. From the context menu, select **Miro AI**.
3. Hover over **Document**.
   A drop-down menu opens.
4. Select **Summary**.
   Miro AI generates your summary.

   You have successfully used Miro AI to generate a summary based on a selection of sticky notes.

## Using Miro AI to remove image backgrounds

Use Miro AI to remove the background from an image.

Follow these steps:

1. Select an image on your board.
   The context menu displays.
2. From the context menu, select **Miro AI**.
   A drop-down menu opens.
3. Select **Remove background**.

   You have successfully used Miro AI to remove the background from an image.

## Using Miro AI to generate a diagram

Use Miro AI to generate a diagram.

Follow these steps:

1. Above the Creation toolbar, select **Create with AI**.
2. Select the **Diagram** button.
3. (Optional) Select the diagram type.
4. Enter a description to prompt Miro AI.
5. Select **Generate Diagram**.

   You have successfully used Miro AI to generate a digram.

## Using Miro AI to transform a hand-drawn sketch to a diagram

Miro AI includes Digitize Diagram (BETA), a feature that converts your hand-drawn diagram sketches into fully editable diagrams in Miro.

Follow these steps:

1. Upload an image of your hand-drawn diagram to a Miro board.
2. Select the image.
   The context menu displays.
3. From the context menu, select **Miro AI**.
4. Select **Digitize Diagram**.
   Miro AI generates a fully editable version of your diagram. Ensure that you inspect the result and make any necessary adjustment or re-alignment.

   You have successfully transformed a hand-drawn diagram to a fully editable digram in Miro.

## Using Miro AI with mind maps

Use Miro AI to generate a **Mind map** based on a root node.

Follow these steps:

1. Add a **Mind map** to your board.
2. Add text to the root node.
3. Select the root node.
   The context menu displays.
4. From the context menu, select **Miro AI**.
   A drop-down menu opens.
5. From the drop-down menu, select **Generate mind map**.
   A **Mind map** appears based on your root node.
6. Select whether you want to **Keep**, **Try again**, or **Discard** the generated **Mind map**.

   You have successfully used Miro AI to generate a **Mind map**.

**More information:** See [Mind map](../advanced-tools/03-mind-map.md).

## Using Miro AI to edit text

Use Miro AI to make the following edits to text on your board:

- Fix grammar and spelling
- Shorten text
- Rewrite for clarity
- Adjust tone to friendly, professional, business, or fun
- Translate to English and 17 other supported languages, including French, German, Japanese, Italian, and Turkish. To see all languages that Miro AI translates, see [AI powered text editing](18-miro-ai-reference.md#ai-powered-text-editing).

**More information:** See [Overview of Create and Edit with AI](03-create-with-ai.md).

## Using Miro AI to suggest alt text for images

Miro AI can generate alt text for your images.

Follow these steps:

1. Select an image on your board.
   The context menu displays.
2. From the context menu, select **ALT**.
   The **Image description** dialog opens. **Miro AI** automatically generates a suggestion.
3. Select **Insert**.
   The generated suggestion is automatically saved.
4. (Optional) Edit the inserted suggestion. Changes are automatically saved.
5. Close the **Image description** dialog.

   You have successfully used Miro AI to suggest alt text for an image.

:::note
Generating alt text with Miro AI does not consume AI credits.
:::
