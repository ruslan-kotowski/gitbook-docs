The Asana integration in Miro significantly enhances collaborative workflows by enabling seamless two-way synchronization between Miro boards and Asana tasks. This capability allows you to import, view, and edit Asana tasks directly within the Miro environment, thereby eliminating the need to frequently switch between applications. The primary objective of this integration is to streamline task management, ensuring that project workflows remain continuously updated and that your teams maintain alignment and productivity.

## Key features

The Miro + Asana integration offers a robust set of features designed to enhance data consistency and collaborative task management:

- **Import Asana tasks:** You can import specific Asana tasks onto Miro boards, facilitating visual organization and management of team progress. The integrated "Ticket picker" functionality allows you to filter tasks by assignee, project, or status for efficient discovery and selection.
- **Create new tasks:** You can create new tasks in Asana directly from a Miro board, streamlining the task initiation process.
- **Edit Asana tasks in Miro:** The integration enables direct editing of Asana task details, including title, type, status, assignee, due date, project, tags, and description, all from within the Miro board interface.
- **Two-way sync:** Changes made to tasks in either Miro or Asana are automatically synchronized between both platforms, ensuring that information remains current and accurate across both tools.
- **Action shortcuts:** Customizable action shortcuts can be created to quickly open the task picker or initiate the creation of new tasks, enhancing workflow efficiency.
- **Organize tasks in frameworks:** Imported Asana tasks can be visually organized within Miro's flexible frameworks, such as Table, Timeline, Columns (previously Kanban), and User Story Mapping layouts. This allows for intuitive drag-and-drop rearrangement to reflect evolving workflows or task statuses.
- **Open original Asana task:** A dedicated "Source" icon allows you to quickly navigate from an Asana card on a Miro board directly to the full task details within the Asana application.
- **Switch detail views:** You can toggle between a side panel detail view and a modal window for displaying task information, offering flexibility in how you interact with task details.
- **Change card color:** Asana cards on the Miro board can be color-coded, providing a visual mechanism to distinguish task priority or status.
- **Secure access:** The integration mandates that every user authenticate with their third-party Asana account, with access granted strictly according to their existing permissions in Asana.
- **Admin controls:** Administrators possess the capability to manage access permissions for the integration across their Miro team or organization.

## Limitations

You should be aware of the following limitations inherent to the current state of the Miro + Asana integration:

- **Custom fields:** The integration does not support the viewing, editing, or creation of custom fields within Asana tasks, even if these fields are supported and utilized within the Asana system itself. This represents a notable functional limitation for teams whose workflows are heavily reliant on custom fields in Asana.
- **Columns (previously Kanban)**: Moving the Asana card widget in the Columns widget doesn't update the status of the Asana card.
- **Initial synchronization delay:** Following the initial connection of an Asana account, the synchronization process can take a considerable amount of time, ranging from several minutes to several hours, particularly for large Asana accounts. You will receive an email notification once the synchronization is complete.
- **Administrative prerequisite:** In many cases, Asana is pre-installed at the organization level. If not, users or admins need to install the app themselves from the marketplace. Once installed at the team or organization level, individual team members can start using the integration.

  If the organization restricts app installations, approval from an administrator is required before the app can be used.
