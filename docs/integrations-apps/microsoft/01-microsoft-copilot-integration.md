As Company admin, you can enable and approve the Microsoft Copilot integration for teams in your Miro organization.

The Microsoft Copilot integration enables you to connect Copilot as a [Knowledge](../../using-miro/miro-ai/09-knowledge.md) resource in Miro. For example, connect Microsoft Copilot to provide company information to Sidekicks or Flows.

You can also connect Copilot to the standalone chat in Miro.

:::note
For information about using a Miro agent with Copilot in Microsoft Teams, see [Miro agent for Copilot](microsoft-teams/03-miro-agent-for-copilot.md).
:::

Each team member must have a Copilot license to use the integration.

To enable the Microsoft Copilot integration, follow these steps:

1. As Company admin, go to **Admin Console**.
2. Go to **Apps & integrations** > **Apps** > **Add apps**.
3. Search and find **Microsoft Copilot**.
   If you cannot find the app by name, then search by the following client ID: `5531308904693541040`.
4. In the app profile, select whether to add the app for **All teams**, or select **Specific teams**.
5. (Optional) Review permissions page. The Microsoft Copilot app for Miro is developed and maintained by Miro, and does not require special permissions.
6. Click **Add**.

:::note
When a team member connects Microsoft Copilot as a Knowledge resource for the first time, the member is asked to authenticate. The team member must have a Copilot license.
:::
