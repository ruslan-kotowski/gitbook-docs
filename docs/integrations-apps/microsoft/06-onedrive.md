OneDrive integration allows you to enrich your boards with Microsoft Office & Office 365 documents (Docs, Excels, PDFs, images, presentations, etc.).

### Installing the plugin

Install the plugin on the team level and connect your OneDrive account to Miro to start using the integration.

You can install the plugin from [Miro Markeplace](../integrations-basics/04-how-to-install-apps.md): find OneDrive and click **Get app.** Then select a team in which you'd like to install the plugin and click **Install & authorize**.

:::warning
Non-admin users can't install the app if it's not allowed in the **Apps & Integrations** settings.
:::

![install_OneDrive.jpg](images/21017348436242_install%20OneDrive.jpg)
*Choosing a team when installing the OneDrive plugin*

You can also install the app from a board. Follow these steps:

1. In the Creation bar, select **Tools, Media and Integrations** (**+**).The **Tools, Media and Integrations** panel opens.
2. In the **Tools** tab, search and select Uploads.
   The **Uploads** menu opens.

![uploads-entry-point.png](images/21537454978706_uploads-entry-point.png)
*The OneDrive icon from the Creation toolbar*

To connect your OneDrive to Miro, choose OneDrive in the **Upload** menu. You'll be redirected to the Microsoft login page to authorize with your login and password.

You can also do that in your [Profile Integrations](https://miro.com/app/account/profile/integrations/): find **OneDrive** and click **Connect**.

![connect_OneDrive.jpg](images/21017348437010_connect%20OneDrive.jpg)
*Connecting OneDrive with Miro*

### Adding files

Click the **Upload** button on the Creation toolbar, choose **OneDrive**. Select the files you'd like to add, and click **Open**.

If you use **OneDrive for Business**, you can look through the document on the board – just make a double-click on the document. The document opens in a pop-up window on the board and you can look through it as if on your OneDrive.

You can edit your documents by going to your OneDrive right from the Miro board.

![file_source_.jpg](images/21017348438546_file%20source%20.jpg)
*Source button to open the file in OneDrive*

### Updating files

In order to update a file on a Miro board, please click the respective button on the context menu.

![update_OneDrive_file.jpg](images/21017318584978_update%20OneDrive%20file.jpg)
*Updating OneDrive document on Miro board*

Please note that there may be a delay in displaying the new data.

### Disabling the plugin

If you'd like to uninstall the plugin for a team, open Team settings, find One Drive in the **Apps & Integrations** section, and click **Unistall for team**.

![uninstall_OneDrive.jpg](images/21017348440978_uninstall%20OneDrive.jpg)
*Uninstalling OneDrive in Team settings*

To disconnect OneDrive from Miro, open your [Profile Integrations](https://miro.com/app/account/profile/integrations/), find **OneDrive** and click **Log out**:

![log_out_from_OneDrive.jpg](images/21017348442002_log%20out%20from%20OneDrive.jpg)
*Disconnecting OneDrive from Miro*

### Frequently asked questions

1. *Does Miro allow to upload Shared files?*
   - No, that's not possible. A Shared folder is not supported by the MS One Drive file picker that we use.
2. *I get the error message "Please authorize your OneDrive account". How can I fix it?*
   - Please [uninstall the plugin](#disabling-the-plugin) and disconnect your OneDrive account in [Profile settings](https://miro.com/app/account/profile/integrations/). Then install and connect the integration again.
