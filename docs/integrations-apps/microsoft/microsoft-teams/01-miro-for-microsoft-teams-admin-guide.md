Enable the Miro integration for Microsoft Teams to accelerate collaboration within your organization. Miro for Microsoft Teams offers a number of experiences which allow users to receive real time notifications as well as collaborate on embedded Miro boards in Teams meetings, channels, chats, and calendar invites.

Miro also supports adaptive cards through link unfurling and search message extensions, giving users more context on shared boards and allows quick board access management - all without leaving their Microsoft Teams space.

## App management

:::warning
Microsoft Admins will need to enable the Miro integration for Microsoft Teams from the Microsoft app management catalog. Miro Enterprise Admins will also need to enable the integration from the Miro app management panel.
:::

### App management in Microsoft Teams

Settings can vary per account. Learn more on [how to manage apps in Microsoft Teams](https://learn.microsoft.com/microsoftteams/manage-apps).

To ensure that your organization gets the most out of the integration, bulk install and pin the Miro app by using [Microsoft’s app setup policy](https://learn.microsoft.com/microsoftteams/teams-app-setup-policies).

### App management in Miro

In your Miro Company settings > **Apps**, you'll see two Microsoft Teams apps:

- Miro for Microsoft Teams (tab integration) - embed Miro into Calendar, Teams meetings, channels and chats
- Microsoft Teams (bot integration) - user notifications

If you turn off Microsoft Teams (bot integration), users will no longer receive Miro notifications within Microsoft Teams.

## Understanding board sharing access settings

When adding a board as a tab in meetings, calendar invites, chats, and channels, users can define the sharing appropriate permissions. To add a board as a tab within Microsoft Teams, visit Adding Miro as a tab in Microsoft Teams. Learn more about [access settings for an embedded board](../../integrate-miro-with-other-apps/01-user-permissions-for-boards-embedded-in-third-party-apps.md).

### Configuring access settings for your board

The access setting options will follow organization-wide access controls. If you have restricted sharing for board embeds on Enterprise Plan, that option will not be available to users. Learn more in [Managing Enterprise sharing policy for embed integrations.](../../../enterprise-administration/managing-apps-on-enterprise-plan/05-how-to-allow-or-restrict-embedding-miro-boards-in-supported-apps.md)
