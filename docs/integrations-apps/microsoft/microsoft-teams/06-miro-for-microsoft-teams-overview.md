Integrate Miro with Microsoft Teams (MS Teams) seamlessly to enable teams to brainstorm, plan, and co-create with Miro directly in the MS Teams environment. The Miro intelligent canvas simplifies project management without switching apps.

## Key features

The Miro for Microsoft Teams integration provides the following key features:

- **Miro Copilot plugin for MS Teams search**
  Search Miro content with Copilot and instantly preview a reference board with metadata.
- **Notifications bot**
  Get instant updates from Miro in the MS Teams chat, like new comments or a reply on your board, and access requests which you can approve directly in the chat.
- **MS Teams Meetings**
  Open or create a Miro board and start interacting on the canvas anytime during a call.
- **MS Teams Calendar**
  Embed a Miro board into a MS Teams calendar invite, set permissions, and give access to collaborators before the meeting.
- **MS Teams tabs**
  Embed a Miro board as a tab in MS Teams.
- **MS Teams chat**
  Add a Miro board as an adaptive card in MS Teams chat.

## How to set up Miro for Microsoft Teams

As a Microsoft Teams admin, you can enable the Miro integration for MS Teams.

Follow these steps:

1. In MS Teams, select **Apps** (**+**).
   The **Apps** panel opens.
2. Search for Miro.
3. In the search results, for Miro select **Add**.
   The Miro app modal opens.
4. Select **Add**.
   You are redirected to the Miro app view.
5. From the Miro app view, log in to your Miro account.
   Your Miro account connects to MS teams.

   You have successfully added the Miro app to MS Teams, and connected your account.

To use a specific Miro integration for Microsoft Teams, see the article for the respective integration.
