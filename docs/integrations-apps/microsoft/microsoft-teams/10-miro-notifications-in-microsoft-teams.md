Get Miro notifications as chat messages inside Microsoft Teams (MS Teams). Stay informed, share boards, and manage work quickly without switching apps.

![](images/22451245005458_mceclip0.png)
*Miro notifications in Microsoft Teams chat*

Miro notifications enables you to track the following events directly in MS Teams chat:

- A board is shared with you
- A comment is posted on a board
- You are mentioned in a comment
- You receive a request for board access, which you can approve or reject immediately
- An invitee signs up

### How to set up Miro notifications in Microsoft Teams

#### Prerequisites

Ensure that you have Miro for Microsoft Teams enabled. To learn how, see [Miro for Microsoft Teams overview](06-miro-for-microsoft-teams-overview.md).

#### Procedure

To add Miro notifications to Microsoft Teams, follow these steps:

1. In Microsoft Teams, open a chat with Miro.
2. In the message bar, type "Connect".![](images/22452689633554_mceclip1.png)
   **Connecting Miro to MS Teams**
3. Select **Connect your Miro Account**.
   The **Install & authorize "Microsoft Teams"** modal opens in a separate tab.
4. Select the team that you want to track.
   ![](images/22454855305362_mceclip2.png)
   **Selecting a Miro team to track in Microsoft Teams**
5. Select **Install & authorize**.
   In you MS Teams chat with Miro, a greeting message from Miro notifications indicates that setup is complete.

   You have successfully set up Miro notifications in MS Teams.
   > ✏️ Notifications are only for the Miro team you select. To track multiple teams, you can repeat the setup instructions for each team that you want to track.

### FAQ

**Why did I stop receiving notifications for my team?**

If you had previously set up Miro notifications in MS Teams, and stopped recieving notifications, repeat the setup instructions. If you continue to experience an issue, contact Miro Support.

**Can I get a summary of changes to a Miro board?**

A changes summary is currently unavailable in Miro notifications in MS Teams. However, this feature is now in our backlog.
