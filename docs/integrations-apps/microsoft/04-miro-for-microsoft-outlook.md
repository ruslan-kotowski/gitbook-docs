Bring context into Outlook emails with expanded Miro links. With this integration, users can get more information about each Miro link sent via Outlook email.

:::note
Users must enable the Miro integration for Microsoft Teams before they can use the Outlook experience. Refer to the documentation for [Microsoft Teams](microsoft-teams/01-miro-for-microsoft-teams-admin-guide.md) for more information.
:::

## How Miro for Microsoft Outlook works

Miro for Microsoft Outlook includes two important features that improve the user experience: link unfurling and search message extensions.

When users add a Miro link in an email, the link unfurls into an adaptive card, where users can get more information about the board, such as the title, board owner, and time last updated.

![](images/20647652622098_9d5d21ee-76f3-4e99-9740-6095aa310079.png)

*Miro links automatically turn into adaptive cards*

From the email compose surface, users can access the Miro integration through the app menu to search for a Miro board, which can then be added into the email as an adaptive card.

![](images/20647667523090_5d17d2ad-8790-47d0-9b5c-7025ecde97d5.png)

*Boards can be searched for and inserted into emails from within Outlook*
