This article provides information about the warning message that may appear when you use the Miro BoardsPicker with a third-party integration that has not yet been reviewed by Miro. It also covers potential risks, how to manage access, and the review process for developers.

## BoardsPicker warning message for unreviewed integrations

You may encounter a warning message when selecting a board to embed using the BoardsPicker. This message appears if the integration you are attempting to use was built by a third-party developer and has not yet been formally reviewed by Miro.

## Potential risks of using unreviewed integrations

When you embed a Miro board using a third-party integration, you provide a link that grants access to your board. If this integration has not been reviewed and approved by Miro, there is a potential risk that the third-party application could use this link to access your board content.

Depending on the level of access you grant when embedding the board, the third-party app might be able to view your board content or even edit the board. It is important to be aware of these potential risks when using unreviewed integrations.

## Revoking access for embedded boards

You have control over the access granted through links generated by these integrations. If you need to revoke access to a board that you have embedded via a third-party integration, you can do so through the board's sharing settings.

To learn the specific steps, please see our guide on how to [manage access to embedded boards](01-user-permissions-for-boards-embedded-in-third-party-apps.md).

## Integration review process for developers

If you are the developer of a third-party integration that uses the BoardsPicker and you wish to have it reviewed and approved by Miro, please refer to our official documentation.

Detailed information on this process can be found in our developer guide: [Live Embed with BoardsPicker for registered users](https://developers.miro.com/docs/miro-live-embed-with-boardspicker-registered).
