:::note
Miro Web Clipper will no longer be available for install nor maintained as of February 1, 2026. For users who have previously installed it, it remains functional "as-is".

You can add screenshots to Miro with image upload, pasting from clipboard, or by dragging them into the canvas.
:::

Capture web pages while in Chrome and save them into your Miro library while putting in as little effort as possible!

### Using the extension

1. Whenever you want to save a screenshot of a website straight to your library in Miro, click the **Web Clipper icon** in your Chrome to open the extension and choose a **team** where the screenshot will be stored and the area you want to save: **Visible area**, **Selected area**, or **Entire page**.

![Web_clipper_menu.jpg](images/21016020037138_Web%20clipper%20menu.jpg)
*Miro Web Clipper menu*

2. When you're ready to add the saved web pages to a Miro board, open the board. Note that the board should belong to the team that you selected when taking the screenshot.

3. In the Creation bar, select **Tools, Media and Integrations** (**+**)**.**A panel opens. In the **Tools** tab, search for Web Clipper. Select **Upload**, then select **Web Clipper**.
A gallery of saved screenshots opens. You can click or drag the ones you need and drop them on your board.

![Miro_web_clipper.gif](images/21016020034962_Miro%20web%20clipper.gif)
*Web Clipper on the toolbar*

Please note that you can leverage the Miro Web Clipper to its full potential if:

- You're logged into your Miro profile (you can always tell you're signed in if the extension icon is active)
- After installing the extension, you refresh the board web pages if they're open (only needed once)

:::warning
Web Clipper doesn't work for pages that require authorization.
:::

### Frequently asked questions

1. *I saved a screenshot but it does not show up in the Web Clipper library. Why?*
   - Please make sure to choose the correct team when saving the screenshot. The screenshot will belong to the Web Clipper library on boards located in this team.
   Also, please keep in mind that the extension does not work on pages that require authorization.
   If the extension does not work on any page, please try to **remove it and install** it again.
