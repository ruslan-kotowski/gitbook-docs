Connecting Google Workspace™ and Miro enhances your visual collaboration from any location, providing powerful, user-friendly tools that boost engagement and creativity in meetings. With this integration, you can connect Miro to Google Drive, Docs, Meet, and Calendar.

## Key features

Once the Miro add-on is installed, you can leverage several key features to streamline your workflows:

- Add a Miro board to a [Google Calendar](08-miro-for-google-calendar.md) invite.
- View and collaborate on boards directly within [Google Meet](09-miro-for-google-meet.md).
- Embed a Miro smart chip with a board preview into a [Google Doc](10-smart-chips-smart-screenshots-for-google.md).
- Save your Miro boards to [Google Drive](05-google-drive.md).
- Receive notifications, unfurl Miro board links, or create a Miro board via [Google Chat](01-miro-for-google-chat.md).

:::note
Your Google Workspace administrator may need to install the Miro add-on for your Google Workspace organization or team. Check with your administrator if it is not available.
:::

## Install the Miro add-on

To connect the Miro add-on to your Google Workspace products, you first need to install it. You can verify if the add-on is already installed by checking the sidebar in Google Docs or Calendar for the Miro 'M' logo.

To install the add-on:

1. Go to [Google Workspace Marketplace](https://workspace.google.com/marketplace/app/miro/1062019541050).
2. Click **Install**.
3. Select the Google account you want to connect to the add-on.

When the add-on is installed, you'll see the Miro icon on your sidebar, confirming the successful installation.

## Google API Services User Data Policy

Miro for Google Workspace's use of information received from Google APIs will adhere to [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. Google Workspace APIs are not used to develop, improve, or train generalized/non-personalized AI and/or ML models.

## Frequently asked questions

Here are answers to common questions about installing the Miro add-on for Google Workspace.

I'm a Miro Admin. How can I install the Miro add-on for my organization?

Google Workspace Admins can install and manage the add-on on behalf of users in their organization. For details, refer to [Google Workspace Marketplace](https://support.google.com/a/topic/1056395?hl=en&ref_topic=27380).

Why can't I install the Miro add-on?

Your administrator may have disabled the add-on, or you may need to ask your administrator to install it for you.
