## How to embed third-party content in Miro

The following procedure explains how to embed content from a third-party integration.

**Prerequisites**

- Ensure that your Company or Content Admin, or Team admin, has allowed the third-party integration(s) you want to use.
- Ensure that you have access to the third-party content you want to embed.

To learn how admins can enable integrations for users in their organization, see [App management](../../enterprise-administration/managing-apps-on-enterprise-plan/02-app-management.md).

**Procedure**

Do one of the following:

- Copy and paste a URL from [a third-party integration](02-miro-apps-and-integrations-overview.md) on the Miro canvas.
- In the Creation bar, select **Tools**. Search and select the supported third-party tool you want to embed. A modal opens where you can input a third-party URL.
- In the Creation bar, select **Tools**. Search and select **Upload**, and then **Upload via url**.
- On the dashboard, select **+ Create new**, and then **Embed**.
- On the boardin the **Spaces** sidebar, select **+,** and then **Embed**.

  If Miro is connecting for the first time, follow the on-screen instructions. You may have to sign in to your third-party tool, or request access to the content you want to embed.

  You have successfully embedded third-party content to your Miro board.

## iFrame context menu for integrations

The iFrame context menu appears above the embed widget.

![figma.png](images/26673893830418_figma.png)

*The iFrame context menu.*

The iFrame context menu includes the following options:

- **Focus mode**
  Focus your attention with the iFrame in fullscreen. To enter focus mode, select the expand button. In Focus mode, to exit select **Go to canvas**.
- **Bookmark view**
  Collapse the iFrame into a bookmark that you can expand later. To access bookmark view, select the vertical dots button, and then select **Switch to bookmark view** under the actions menu.
- **Asset picker**
  Choose another asset or all assets to embed, like a Figma frame or Power BI chart. To open the asset picker, select the vertical dots button and then select **Extract assets from source** under the actions menu. The asset picker supports the following integrations:
  - Figma frames and sections
  - Google Slides
  - Looker charts
  - MS Excel tabs
  - MS Powerpoint slides
  - MS Word pages
  - Power BI charts

The iFrame settings menu also includes a vertical dots button that opens additional options.

## Action shortcuts for integrations on Intelligent Templates

Action Shortcuts are buttons you create to trigger events on your board. You can set an Action Shortcut that immediately launches an integration.
