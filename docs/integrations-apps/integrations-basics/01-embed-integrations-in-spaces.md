You can embed content from a third-party (3P) tool directly into the Spaces sidebar. The content opens on a canvas in immersive mode.

## How to embed integrations in Spaces

To embed 3P into the [Spaces sidebar](../../using-miro/spaces/01-spaces.md), do one of the following:

**From dashboard**

Follow these steps:

1. In the sidebar, for the Space where you want to embed 3P content, select the plus button (**+**).
   The **Create new** menu opens.
2. Select **Embed**.
   The **Add Embed** modal opens.
3. Input the third-party URL.
4. Select **Add**.

**From Spaces stage**

Follow these steps:

1. In the top-left, select **+ Create new**.
2. Select **Embed**.
   The **Add Embed** modal opens.
3. Input the third-party URL.
4. Select **Add**.

**From Spaces sidebar**

Follow these steps:

1. In the [Spaces sidebar](../../using-miro/spaces/01-spaces.md), select the plus button (**+**).
   The **Create new** menu opens.
2. Select **Embed**.
   The **Add Embed** modal opens.
3. Input the third-party URL.
4. Select **Add.**

Your 3P link is added to the Spaces sidebar. Select the link to see your embedded content in immersive mode.

:::tip
To close immersive mode, select **Ideate on canvas**. You can interact with your embedded content as an object on the board.
:::

You have successfully embedded content from a 3P tool into the Spaces sidebar.

**More information:** See [Embed integrations on a Miro board](03-embed-integrations-on-a-miro-board.md).
