The Linear integration in Miro enhances collaborative workflows by enabling seamless two-way synchronization between Miro boards and Linear issues. This integration allows you to import, view, and edit Linear issues directly within Miro, eliminating the need to switch between applications. The primary objective is to streamline issue management, ensuring that project workflows remain up-to-date and teams stay aligned and productive.

## Key features

The Linear integration offers the following features:

- **Import Linear issues:** Import issues onto your Miro board and filter them by assignee, project, or status using the issue picker.
- **Create new issues:** Create Linear issues directly from your Miro board.
- **Edit issues in Miro:** Edit issue details including title, type, status, assignee, due date, project, tags, and description.
- **Two-way sync:** Changes made to issues in either Miro or Linear are automatically synchronized.
- **Organize issues visually:** Arrange issues in Table, Timeline, Columns, and User Story Mapping layouts.
- **Quick access:** Open the original Linear issue with one click using the source icon.
- **Flexible views:** Switch between side panel and modal window views for issue details.
- **Visual organization:** Color-code issues to distinguish priority or status.
- **Secure access:** Authenticate with your Linear account with permissions matching your Linear access.
- **Admin controls:** Manage integration access permissions across your Miro team or organization.

## Limitations

The Linear integration has the following limitations:

- **Custom fields:** The integration doesn't support viewing, editing, or creating custom fields within Linear issues.
- **Columns widget:** Moving issues in the Columns widget doesn't update the Linear issue status.
- **Initial sync:** The first synchronization can take several minutes to hours for large Linear accounts.
- **Installation requirements:**
  - Linear may need to be installed from the marketplace if not pre-installed.
  - Administrator approval is required if the organization restricts app installations.
