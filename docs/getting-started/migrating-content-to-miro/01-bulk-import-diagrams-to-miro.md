You can bulk import your diagrams from source applications as PDF or VSDX.

:::note
For some source applications, only one filetype is supported. To verify, see [Import filetype support](#import-filetype-support).
:::

## How to bulk import diagrams to Miro

To import your diagrams to Miro, ensure you have exported the file(s) from your source application as PDF or VSDX. Then complete the following procedure.

1. On your Miro dashboard, for the Space where you want to import diagrams, click **Create new** (**+**).
   ![](images/32654520716690_image.png)
2. Click **Import** > **Import from \{source\}**. For example, **Import from Mural**.
   The **Import from \{source\}** modal opens.
3. Follow the on-screen instructions.
4. (Optional) Change the target Space for import. Or click the plus (**+**) button to create a new target Space.
5. Click **Import** ***x*** **files**.

## Import filetype support

| Source | Filetype |
| --- | --- |
| Conceptboard | PDF, VSDX |
| Lucidchart | PDF, VSDX |
| Lucidspark | PDF, VSDX |
| Mural | PDF |
| Visio | VSDX |
