You can easily transfer your diagrams from Draw.io into Miro to collaborate in one unified tool. Imported diagrams are fully functional, allowing you to edit, color, move, and redesign them as needed within Miro.

:::note
Currently, Miro supports importing diagrams only from Lucidchart, MS Visio, and Draw.io. Note that you can only import a diagram to a new Miro board, not an existing one.
:::

:::warning
Editing of imported diagrams is one-way only. Changes made in Miro will not be reflected in the original Draw.io diagram. To create new and editable Draw.io diagrams directly in Miro, use the [draw.io diagrams app](../../using-miro/formats/diagramming/03-draw.io-diagrams-by-miro.md).
:::

## Import a Draw.io diagram to a new board

Follow these steps to import a single Draw.io diagram into a new Miro board:

1. In Draw.io, export the diagram as a `.vsdx` file.
2. Navigate to the Miro board where you want to import the diagram.
3. On the Creation toolbar on the left, click **Shapes and lines**, choose **More shapes**, and click the **Import diagram** icon at the top right of the **Diagramming** panel.
4. In the **Import diagram as a new board** dialog box, either drag and drop the `.vsdx` file or click the **Choose file** button and navigate to the `.vsdx` file.
5. Once the file is selected, click **Import**.
6. When the import process completes, click **Go to board** to open the new board with your diagram.

## Bulk import Draw.io diagrams from your dashboard

You can also import multiple Draw.io diagrams at once from your Miro dashboard. Each imported diagram will create a new Miro board named after the original file. Note that you can only import multiple diagrams from the dashboard:

1. Go to your Miro dashboard at `https://miro.com/app/dashboard/`.
2. In the top-right corner, select **+ Create new**.
3. Select **Import**, then select **Import diagram**.
   The **Import diagrams** modal will open.
4. Drag your `.vsdx` files into the modal or use the **Choose files** link.
5. When the import finishes, you can click **Done** to return to your dashboard, or click **Open all boards** to launch the boards your diagrams were imported into. Each board will open in its own tab in your browser.
