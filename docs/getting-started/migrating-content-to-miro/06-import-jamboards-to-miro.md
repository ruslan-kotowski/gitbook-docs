Transfer your ideas and projects from Jamboard to Miro effortlessly. Take advantage of Miro's robust set of features that complement your workflow.

:::warning
Editing imported content is one-way. Changes made in Miro will not sync back to Jamboard.
:::

:::note
Only Miro users with a Full license can migrate content from Jamboard to Miro. Miro users with a [Free Restricted](../../enterprise-administration/enterprise-subscription-management/enterprise-licensing/04-free-restricted-license.md) license and [Guest](../../using-miro/sharing-boards/07-collaboration-with-guests.md) users cannot migrate Jamboards into Miro.
:::

## Import from Jamboard to Miro

This section guides you through the steps to import your Jamboard files into Miro, creating a new Miro board for each imported Jamboard:

1. From the Miro **Home** dashboard, select **+ Create new**.
   > 💡 You can also access the **Create new** (**+**) menu from the sidebar when you have a Miro board open.
2. Select or hover over **Import** in the menu.
3. Select **Import from Jamboard**. A modal window will open with details about the import process.
4. Click **Import Jamboards** to continue.
5. You will be prompted to sign into your Google account and authorize the Jamboard migration access to your Google Drive.
6. Once Google authorization is complete, you will be connected to your Google Drive with access to all your Jamboards. Choose up to 10 Jamboards you wish to import at one time, and click **Select**.
7. All content from the selected Jamboards is now imported into Miro in an editable format. A new Miro board is automatically created for each Jamboard you import.
8. Review the imported content on your new Miro board(s) and make any necessary adjustments. While Miro offers extensive functionalities, there may be slight differences in styling and formatting options compared to Jamboard. Refer to the [Understand Jamboard object mapping in Miro](#understand-jamboard-object-mapping-in-miro) section for guidance on potential variations.

## Understand Jamboard object mapping in Miro

This table provides a comprehensive comparison of how objects from Jamboard are typically imported and represented in Miro:

|  |  |
| --- | --- |
| **Jamboard** | **Miro** |
| Brush, Highlighter, Marker | Shapes or Stencils |
| Connectors | Connectors |
| Emojis | Images |
| Frames | Frames |
| Images | Images |
| Page | Images |
| Shapes | Shapes or Stencils |
| Sticky notes | Sticky notes |
| Text | Text |

## Import limitations

When importing from Jamboard, it's important to be aware of some functional differences and limitations:

- Miro Text boxes can accommodate up to 6,000 characters, including spaces. Any additional text from a Jamboard text object will be cropped.
- Miro Sticky notes do not support rotation, color palette adjustments, or text bulleting in the same way Jamboard might; some visual differences may occur.

## Prepare for Jamboard device transition

As Google is discontinuing Jamboard devices, here's important information regarding this transition and supported hardware options for continued collaboration using Miro:

Starting December 2024, Google will discontinue support for Jamboard 55 devices. For continued collaboration, consider transitioning to Google Meet Series One Board 65 and Desk 27 devices, which support Miro as of 2024.
