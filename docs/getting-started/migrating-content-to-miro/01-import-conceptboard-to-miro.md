Migrate your Conceptboard content seamlessly into Miro for a more robust collaboration experience. This allows you to consolidate your work and leverage Miro's extensive features.

:::warning
Editing imported content is one-way. Changes made in Miro will not sync back to Conceptboard.
:::

:::note
Conceptboard boards under Free or Restricted licenses can be migrated.
:::

## Import your Conceptboard boards

Before you begin importing your Conceptboard boards into Miro, ensure you have exported them from Conceptboard as PDF files. To do this in Conceptboard, access the boards you wish to export, then click **Board** > **Export**, and select **Export board as PDF**.

Once you have your PDF files, follow these steps to import them into Miro:

1. From the Miro **Home** dashboard, select **+ Create new**.
   > 💡 You can also access the **Create new** (**+**) menu from the sidebar when you open a board.
2. Select or hover over **Import**.
3. Select **Import from Conceptboard**. A modal will open with details about the import process.
4. Select **Browse** to open the file picker and select your PDF files, or drag and drop your PDFs into the modal.
5. (Optional) For **Add your boards to a space**, select a space from the dropdown menu.
6. Select **Import boards**. A modal will appear to inform you that the boards are being imported. You will receive an email notification once the import is complete and your new Miro boards are ready.

## How Conceptboard objects appear in Miro

While Conceptboard and Miro have similar functionalities, there may be differences in styling and formatting options after import. This table provides a comparison of how common Conceptboard objects are translated into Miro objects:

| **Conceptboard** | **Miro** |
| --- | --- |
| Collaborators and sharing | 🟠 Can be recreated manually |
| Comments | 🟠 Can be recreated manually |
| Connectors | Connectors |
| Documents | 🟠 Can be recreated manually |
| Draw | Lines |
| Images | Images |
| Mindmap | Shapes and Connectors |
| Sections | Frames and Shapes |
| Shapes | Shapes and images |
| Sticky Notes | Sticky Notes |
| Tables | Tables/Shapes and Connectors |
| Text | Text |
| Videos and other URLs | 🟠 Can be recreated manually |

## Limitations

While the import process aims to be as seamless as possible, be aware of the following limitations when importing from Conceptboard:

- Miro Text boxes can accommodate up to 6,000 characters, including spaces. Any additional text will be cropped.
- Colors and opacity levels are mapped to their nearest matches in Miro.
- Miro sticky notes do not support rotation or color palette adjustments that may have been present in Conceptboard.
