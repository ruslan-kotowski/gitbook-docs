Easily transfer your diagrams from MS Visio into Miro and start collaborating in one unified tool.

Imported diagrams are fully functional so you can edit, color, move and redesign as you need.

:::warning
Editing of imported diagrams is one-way only. Changes made in Miro will not be reflected in Visio.
:::

## Import a single Visio diagram to a new Miro board

Follow these steps to import an individual Visio diagram. The imported diagram will create a new Miro board:

1. In Visio, open the diagram you wish to export.
2. Select the **File** menu, and choose **Save As**. Select a location and save your file in `.vsdx` format.
3. Navigate to the Miro board from which you want to initiate the import. This can be any board, as the import will create a new one.
4. On the Creation toolbar at left, select **Shapes** > **More shapes**, and then select the **Import diagram** icon located at the top right of the diagramming shape library panel.
5. In the dialog box that appears, either drag and drop the `.vsdx` Visio file, or click the **Choose file** button and navigate to select the file from your system.
6. Select **Import**.
   When the import process finishes, you'll see a **File imported** dialog.
7. Click **Go to board** to open the new Miro board containing your imported diagram.

## Bulk import multiple Visio diagrams

You can also import multiple Visio diagrams into Miro simultaneously from your dashboard. Each diagram will be imported into its own new Miro board, named after the original filename:

1. Go to your [Miro dashboard](https://miro.com/app/dashboard/).
2. Select **+ Create new** > **Import** > **Import diagram**.
3. Drag your `.vsdx` files into the designated area, or use the **choose files** link to select multiple Visio diagrams. Note that you can still remove files before importing.
4. Select **Import files**.
   When the import process finishes, you'll see a **Files imported** dialog.
5. Select **Done**.

This creates a new board for each diagram, named after the original filename.
