Kombiniere die kollaborative Stärke von Miro mit der analytischen Kraft von Power BI. Wenn Power BI Reports und Dashboards direkt in Miro-Boards eingebettet sind, kann dein Team die Entscheidungsfindung optimieren, datengesteuerte Strategien visualisieren und den Projektfortschritt klar und präzise vorantreiben.

- Nutze eingebettete Power BI Daten für Echtzeit-Einblicke und eine fundierte Entscheidungsfindung.
- Arbeite effektiv mit Teammitgliedern zusammen, indem du Diagramme mit Power BI Daten aktualisierst und zu Miro-Boards hinzufügst.

## Microsoft Power BI Reports in Miro einbetten

:::tip
Lass dir von deinem Unternehmens-Admin bestätigen, dass die Power BI Integration für dein Unternehmen eingerichtet wurde.
:::

1. Gehe zu Microsoft Power BI und kopiere den Link des Reports oder Dashboards aus der Browser-Adressleiste (nicht aus dem Freigabemenü, da dies derzeit nicht unterstützt wird).
2. Füge den kopierten Link in ein beliebiges Miro-Board ein.
3. Klicke auf **Verbinden**, um die Miro-App in Microsoft Power BI zu autorisieren.
4. Danach öffnet sich ein Dialogfenster, in dem du auswählen kannst, welche Diagramme du einbetten möchtest. Vergewissere dich, dass die Liste mit dem Original-Report übereinstimmt.
5. Klicke auf **Alle Diagramme hinzufügen**, um sie in das Board einzubetten.
6. Die Diagramme werden als Bilder zu deinem Miro-Board hinzugefügt.

## Voraussetzungen zum Einbetten von Power BI Daten in Miro

Um einen Power BI Report oder ein Dashboard in ein Miro-Board einzubetten, musst du:

- Teil eines Miro-Teams oder -Kontos sein, in dem die Power BI Integration aktiviert ist.
- Zugriff auf den jeweiligen Power BI Report oder das Dashboard haben, das du einbetten möchtest.
- sicherstellen, dass das Miro-Board, in das du die Power BI Daten einbetten möchtest, nicht über einen öffentlichen Link geteilt wurde.
- einen unterstützten Power BI Cloud-Service haben (Power BI Premium per Capacity SKU oder Fabric Capacity Reservation SKU). On-Premise-Service wird nicht unterstützt.

## Eingebettete Power BI Daten ansehen und bearbeiten

Nutzer, die Zugriff auf das Miro-Board mit den eingebetteten Power BI Daten haben, können die Daten unabhängig von ihrer Power BI Autorisierung oder ihrem Lizenzstatus ansehen. Dazu gehören Nutzer mit Ansichts-, Kommentar- oder Bearbeitungsberechtigungen für das Board.

Wenn du Bearbeitungsberechtigungen für ein Miro-Board mit eingebetteten Power BI Daten hast, kannst du es über die **Update**-Funktion aktualisieren oder Diagramme über die Funktion **Diagramme hinzufügen** hinzufügen, auch wenn du keinen Zugriff auf den ursprünglichen Power BI Inhalt hast. Es ist jedoch nicht möglich, die Daten des Original-Diagramms über die Integration anzusehen, darauf zuzugreifen oder Filter zu ändern.

## Datenaufbewahrung

Die eingebetteten Power BI Daten unterliegen der Standard-Datenaufbewahrungsrichtlinie von Miro, die für alle Kundendaten gilt. Hier findest du unseren [Zusatz zur Datenverarbeitung bei Miro](https://miro.com/legal/documents/Miro-Data-Processing-Addendum.pdf).

## Fehlerbehebung

Die folgenden Schritte können häufige Probleme bei der Nutzung der Power BI Integration in Miro beheben.

Probleme bei der Autorisierung und der Admin-Genehmigung

Wenn du die App nicht autorisieren kannst oder zur Admin-Genehmigung aufgefordert wirst, ohne dass eine Option zur Anfrage verfügbar ist, wende dich an deinen Unternehmens-Admin, um sicherzustellen, dass Genehmigungsanfragen aktiviert sind. Wenn du das Fenster **Need admin approval** (Admin-Genehmigung erforderlich) siehst, fordere die Genehmigung über dieses Fenster an.

Einbettungsprobleme

Wenn Diagramme nicht wie erwartet angezeigt werden, wende dich an deinen Unternehmens-Admin, um sicherzustellen, dass du das richtige Microsoft Power BI Abo hast.

Verifizierung des Links

Bei fehlenden Elementen überprüfe den verwendeten Link und stelle sicher, dass er direkt aus der Adressleiste des Browsers kopiert wurde.
