Verwende Miro mit deinem Microsoft Surface Hub-Gerät für die Remote-, persönliche und hybride Zusammenarbeit mit deinem Team. Im Folgenden erfährst du mehr über die Verwendung von Miro auf Surface Hubs.

Miro ist mit den Geräten Microsoft Surface Hub 84" und 55" und Microsoft Surface Hub 2S 50" und 85" kompatibel.

:::note
Stelle sicher, dass du die neueste Version von Microsoft Edge verwendest.
:::

## Möglichkeiten zur Verwendung von Miro mit Microsoft Surface Hub

Es gibt zwei Möglichkeiten, Miro mit einem Surface Hub zu verwenden:

1. In einem Microsoft Edge-Browser
2. Installation von Windows 10/11 auf einem Surface Hub und Installation der Miro Windows-App

### Microsoft Edge verwenden

1. Vergewissere dich, dass dein Surface Hub-Gerät auf der neuesten **Windows-Version** läuft ([Update Windows 10 Team 2022](https://learn.microsoft.com/surface-hub/surface-hub-2022-update)).
2. Starte den neuesten **Microsoft Edge-Browser**. Erfahre, wie du diesen Browser auf Surface Hub-Displays installierst
   > ✏️ Zur Aktualisierung von Windows oder Microsoft Edge auf die neuesten Versionen ist möglicherweise eine Administratorberechtigung erforderlich
3. Nun kannst du dich bei Miro über miro.com/login anmelden. Du kannst auch unsere [Funktion zur Schnellanmeldung](../../getting-started/apps-for-devices/10-send-to-display.md) nutzen, um Miro-Boards noch schneller von deinem persönlichen Gerät aus auf deinem Surface Hub zu starten.

### Surface Hub mit der Miro Windows-App verwenden

1. Installiere [Windows 10/11 auf dem Surface Hub](https://learn.microsoft.com/surface-hub/surface-hub-2s-migrate-os) (anstelle von Windows 10 Team)
2. Installiere die [Miro Windows-App](../../getting-started/apps-for-devices/05-desktop-app.md)

:::warning
Derzeit ist keine Miro Surface Hub-App für die Version „Windows 10 Team“ verfügbar.
:::
