Teams mit einem Enterprise-Preisplan und Ort der Datenspeicherung außerhalb der Europäischen Union (EU) können die passende Region auf interaktiven Displays auswählen.

Dieser Artikel erklärt, wie der Browser eines interaktiven Displays mit der entsprechenden Region der Datenspeicherung verbunden wird und wie du die Miro App auf einem Windows- und Android-Display in der entsprechenden Region verwenden kannst.

Für Informationen über interaktive Displays siehe [Interaktive Displays.](../../../getting-started/apps-for-devices/07-interactive-displays.md)

Um mehr über den Ort der Datenspeicherung zu erfahren, siehe [Ort der Datenspeicherung bei Miro](../../canvas-25-admin-features/data-residency/02-data-residency-at-miro.md).

## Browser des interaktiven Displays mit Region verbinden

1. Öffne den Display-Browser.
2. Gehe zu der folgenden URL für deine Region:
   - (Standard) **Europäische Union**
     `https://miro.com/displays/?useAsAppDefaultOrigin`
   - **Australien**
     `https://au.miro.com/displays/?useAsAppDefaultOrigin`
   - **Vereinigte Staaten**
     `https://us.miro.com/displays/?useAsAppDefaultOrigin`
3. Befolge die Anweisungen auf dem Bildschirm.

## Miro App-Region auf Windows-Display ändern

1. Öffne auf deinem Windows interaktiven Display die Miro App.
2. Drücke die **ALT**-Taste auf deiner Tastatur.
   Es öffnet sich ein Kontextmenü.
3. Wähle **Hilfe** > **Öffentliches Gerät** > **Öffentlich**.
   Miro wechselt zum interaktiven Display-Erlebnis.
4. Wähle **Hilfe** > **Öffentliches Gerät** > **Standardregion**.
5. Wähle eine der folgenden Optionen:
   - (Standard) **Global**
     Verbindet mit der Region Europäische Union
   - **Australien**
     Verbindet mit der Region Australien
   - **Vereinigte Staaten**
     Verbindet mit der Region Vereinigte Staaten

## Miro App-Region auf Android interaktivem Display ändern

1. Öffne auf deinem Android interaktiven Display die Miro App.
2. Tippe auf dem Startbildschirm oben rechts auf das Zahnrad-Symbol.
3. Tippe auf **Region wählen**.
   Das Dialogfeld **Andere Region wählen** öffnet sich.
4. Wähle eine der folgenden Optionen:
   - (Standard) **Global**
     Verbindet mit der Region Europäische Union
   - **Australien**
     Verbindet mit der Region Australien
   - **Vereinigte Staaten**
     Verbindet mit der Region Vereinigte Staaten
