Das flexible Lizenzmodell (FLP) ist unser gängigstes Lizenzmodell. Mit FLP skalierst du deine Lizenzen mit zunehmender Nutzung. Schätze die Bedürfnisse deiner Organisation ein und füge Lizenzen hinzu oder entferne sie ohne Vorabgebühren, rückwirkende Kosten oder Vertragsänderungen.

Erfahre mehr über unsere [Enterprise-Lizenzierung](02-enterprise-licensing.md).

## So funktioniert das flexible Lizenzmodell (FLP)

Eine Überprüfung deines FLP-Abos erfolgt basierend auf deiner festgelegten Wahrungsfrequenz. Nähert sich deine Wahrungszeit, wirst du ein datengesteuertes Gespräch mit deinem Miro-Kontoteam führen, um zu entscheiden, wie viele deiner neuen Nutzer zukünftig eine Standard- oder Volllizenz benötigen. Der Vertrag wird um die zusätzlichen Lizenzen ergänzt, wobei keine rückwirkenden Gebühren anfallen.

## FLP-Lizenz-Upgrades

Nutzer können eine Standard-, Volllizenz (legacy), kostenfreie oder kostenlose eingeschränkte Lizenz haben. Bestimmte Aktionen lösen ein Lizenz-Upgrade bei FLP-Abos aus.

Mehr dazu findest du unter [Lizenzverwaltung bei FLP](05-license-management-on-the-flexible-licensing-program-flp.md).

|  |  |  |  |
| --- | --- | --- | --- |
|  | **Standard/** **Voll (Legacy)** | **Kostenlos** | **Kostenlos Eingeschränkt** |
| **Upgrade-Optionen** | Bereits auf den höchsten Lizenztyp upgegradet | **Automatische Upgrades** auf eine Standard- oder Full (legacy) Lizenz wenn:   - ein Board erstellt wird - ein freigegebenes Board bearbeitet wird - zur Bearbeitung eines Boards eingeladen wird - Miteigentümerschaft des Boards gewährt wird - zu einem [Bereich](../../../using-miro/spaces/01-spaces.md) als Bearbeiter hinzugefügt wird | **Eine Anfrage zum Upgrade einer Lizenz** wird an die Admins gesendet, wenn ein Nutzer:   - versucht, ein Board oder einen Bereich zu erstellen - Bearbeitungszugriff anfordert - eingeladen wird, ein Board zu bearbeiten - eine Board-Eigentümerschaft zugewiesen bekommt |

:::warning
Gäste erhalten nie automatisch ein Upgrade.
:::

## FLP-Nutzerzugriff

Jeder Nutzer kann innerhalb eines Enterprise-Plans in mehreren Miro-[Teams](../../../getting-started/start-here/miro-dashboard/04-profile-and-teams.md) unterschiedliche Miro-Rollen (Mitglied, Gast oder Besucher) haben.

Erfahre mehr über Miro-Rollen und Lizenztypen in [Zugriffsebenen auf dem Enterprise-Preisplan](../../user-management/11-user-access-levels-on-enterprise-plan.md).

|  |  |  |  |
| --- | --- | --- | --- |
|  | **Standard/** **Voll (veraltet)** | **Kostenlos** | **Kostenlos Eingeschränkt** |
| **Mitglied** | **Mitglieder mit einer Standard- oder Voll (altes Modell) Lizenz können:**   - Boards, Bereiche und Vorlagen erstellen - Freigegebene Boards bearbeiten - Boards ansehen, die mit dem Team geteilt wurden | **Mitglieder mit einer kostenlosen Lizenz können:**   - zu Bereichen und Boards hinzugefügt werden - Boards ansehen, die für ein Team freigegeben wurden (und die Boards, die für ein Team freigegeben wurden, ansehen und kommentieren) - automatisch zu Standard- oder Vollmitgliedern (legacy) konvertiert werden | **Mitglieder mit einer kostenlosen eingeschränkten Lizenz können:**   - zu Bereichen und Boards hinzugefügt werden - Boards ansehen, die mit einem Team geteilt wurden (und die Boards ansehen und kommentieren, die mit dem Team geteilt wurden) |
| **Gast** | Nicht verfügbar | **Gäste mit einer kostenlosen Lizenz können:**   - freigegebene Boards ansehen und kommentieren     **Gäste mit einer kostenlosen Lizenz können nicht:**   - Boards erstellen oder Boards ansehen, die für ein Team freigegeben wurden - Bereiche ansehen oder Bereiche beitreten, die für ein Team freigegeben wurden | **Gäste mit einer kostenlosen eingeschränkten Lizenz können:**   - ansehen und kommentieren |
| **Besucher** | **Besucher** müssen sich nicht für Miro registrieren oder eine Lizenz haben.   - Besucher können Boards ansehen, kommentieren und bearbeiten (mit einigen [Einschränkungen](../../../using-miro/sharing-boards/08-collaboration-with-visitors.md)) - Besucher können keine Bereiche, Boards oder Vorlagen ansehen, die innerhalb eines Teams freigegeben sind - Besucher können die Liste der Teams, Teammitglieder oder Team- und Unternehmens-Admins nicht einsehen | | |
