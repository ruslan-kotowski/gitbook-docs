## Lizenztypen

Das [Flexible Lizenzmodell (FLP)](../enterprise-subscription-management/enterprise-licensing/03-flexible-licensing-program-flp.md) bietet den zusätzlichen Vorteil einer unbegrenzten Anzahl **kostenloser** Lizenzen sowie die Möglichkeit, Lizenzen jederzeit auf eingeschränkte kostenlose Lizenzen herunterzustufen.

|  |  |  |
| --- | --- | --- |
| **Volllizenz** | **Free (nur FLP)** | **Kostenlose einschränkte Lizenz** |
| Die Person hat [Ansichts-, Kommentar- und Bearbeitungsrechte](../../using-miro/sharing-boards/01-board-access-rights.md) und kann Boards erstellen | Die Nutzer können [ansehen und kommentieren](../../using-miro/sharing-boards/01-board-access-rights.md). Sie erhalten automatisch ein Upgrade auf eine **Volllizenz**, sobald sie [ein Board bearbeiten oder erstellen, zur Bearbeitung eines Boards eingeladen werden, eine Miteigentümerschaft für das Board erhalten oder einem](../../using-miro/sharing-boards/16-projects.md) Projekt als Bearbeiter hinzugefügt werden | Die Nutzenden können nur [ansehen und kommentieren](../../using-miro/sharing-boards/01-board-access-rights.md), sind aber Teil des Teams und können alle freigegebenen Boards ansehen. Sie können ein Lizenz-Upgrade anfordern |

## Miro-Rollen

Die Rollen bei Miro definieren die Zugriffsebene einer Person in deinem Enterprise-Preisplan.

:::note
Unternehmens-Admins und Team-Admins sind immer Mitglieder und haben die gleichen Berechtigungen wie die Mitglieder.
:::

|  |  |  |  |
| --- | --- | --- | --- |
| **Unternehmens-Admin** | **Team-Admins** | **Mitglieder** | **Gäste** |
| **können** alle Teams sehen und Team- und Unternehmenseinstellungen verwalten | **können** die Einstellungen für ein bestimmtes Team einsehen und verwalten | **kann** [Boards ansehen, kommentieren und bearbeiten](../../using-miro/sharing-boards/01-board-access-rights.md)  **kann keine** Team- oder Unternehmenseinstellungen verwalten | **können** freigegebene Boards [ansehen, kommentieren und/oder bearbeiten](../../using-miro/sharing-boards/01-board-access-rights.md) (basierend auf dem [Lizenzmodell](../enterprise-subscription-management/enterprise-licensing/02-enterprise-licensing.md))  **können keine** Boards erstellen oder besitzen, Informationen über andere Teams und Unternehmen sehen, Team- oder Unternehmenseinstellungen verwalten oder eine Lizenz anfordern |

## Häufige Fragen

**Wie kann ich die Lizenz einer Person downgraden?**

Bei FLP-Abos für Unternehmen können Unternehmens-Admins die Lizenz eines Nutzers unter Unternehmenseinstellungen > **Nutzer** > **Alle Nutzer** oder **Teams** auf kostenlose eingeschränkte Lizenz downgraden, das Team auswählen, zu dem der Nutzer gehört, und dann den Nutzer in der Liste suchen.

**Wenn ich Mitglied in zwei Teams sein möchte, benötige ich dann eine Lizenz für jedes Team?**

Wenn die Teams Teil eines Enterprise-Abos sind, benötigst du nur eine Lizenz. Wenn die Teams mit verschiedenen Abonnements verknüpft sind, benötigst du in jedem Team eine Lizenz.

**Welchen Lizenztyp benötigt ein Admin?**

Admins in FLP-Preisplänen brauchen eine Volllizenz, eine kostenlose oder eine eingeschränkte kostenlose Lizenz.  Admins in Nicht-FLP-Preisplänen brauchen eine eingeschränkte kostenlose oder eine Volllizenz.
