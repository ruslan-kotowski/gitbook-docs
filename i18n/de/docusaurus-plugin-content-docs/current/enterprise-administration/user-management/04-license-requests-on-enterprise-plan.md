Verwalte alle Lizenzanfragen von einem einzigen Ort aus. Wenn du Lizenzanfragen direkt in Miro erhältst, kannst du die Lizenznutzung und den Genehmigungsprozess in deinem Unternehmen vereinfachen.

## Einstellungen für Lizenzanfragen

In deinen **Zugriffsanfragen** findest du eine Übersicht über alle aktuellen **Lizenzanfragen**. Diese Lizenzanfragen werden initiiert, wenn ein Nutzer ein Upgrade von einer Free Restricted zu einer Advanced, Standard oder Full (Legacy) Lizenz benötigt.

Die Lizenzanfragen beinhalten folgende Informationen:

- Der Name des Nutzers, für den die Lizenzanfrage gestellt wird
- Name der Abrechnungsgruppe (falls vorhanden), der der Nutzer zugewiesen wird
- Der Name des Anfragenden
- Das Datum der Anfrage

Anfragen können entweder von der Person eingereicht werden, die das Lizenz-Upgrade benötigt, oder im Namen einer anderen Person. Hier findest du Informationen zu den verschiedenen Lizenz-Upgrade-Szenarien für den Enterprise-Preisplan.

:::note
Um Lizenzanfragen direkt in Miro zu erhalten, aktualisiere deine [Anfragenverwaltung](09-request-management-on-enterprise-plan.md)-Einstellungen
:::

## Lizenzanfragen akzeptieren oder ablehnen

:::note
Alle Anfragen verfallen automatisch und werden nach 30 Tagen gelöscht.
:::

1. Gehe zu deinen Miro-Einstellungen.
2. Klicke auf **Unternehmen**.
3. Unter **Benutzer**, klicke auf **Zugriffsanfragen**.
4. Wähle den **Lizenzanfragen** Tab. Hier kannst du alle ausstehenden Lizenzanfragen einsehen.
5. Klicke in der Spalte **Aktionen** auf das Häkchen (**✓**), um die Anfrage zu akzeptieren, oder auf das Kreuz (**x)**, um sie abzulehnen.
6. (Optional:) Um Lizenzanfragen als Massenaktion zu akzeptieren, klicke neben der Spalte **Name** auf das Kästchen, um alle Anfragen auszuwählen, und dann auf **Massengenehmigung**.
7. Wenn du Anfragen akzeptierst oder ablehnst, öffnet sich ein Dialogfeld mit den Details des Anfragenden und der Person, für die die Lizenzanfrage ist.
8. Klicke auf **Genehmigen**, um die Anfrage zu genehmigen, oder auf **Ablehnen**, um die Anfrage abzulehnen. Sobald du eine Anfrage akzeptierst oder ablehnst, wird sie aus der Übersicht deiner Lizenzanfragen entfernt.
9. Sobald die Lizenzanfrage genehmigt wurde, wird der Nutzer von einer eingeschränkten kostenlosen Lizenz auf eine Advanced-, Standard- oder Vollversion (legacy) aufgewertet.

## Lizenz-Upgrade-Szenarien

Es gibt bestimmte Aktionen oder Ereignisse in Miro, für die die Nutzer ein Upgrade ihrer Lizenz anfragen müssen. In den nachfolgenden Szenarien wird beschrieben, wann diese Anfragen für Nutzer des Enterprise-Preisplans initiiert werden. Nach der Genehmigung wird die Lizenz des Nutzers von Free Restricted auf eine Advanced-, Standard- oder Volllizenz (legacy) hochgestuft. Nutzer bleiben in denselben Teams, in denen sie zuvor waren.

:::note
Um deine aktuelle Lizenznutzung anzusehen, gehe zu **Nutzerverwaltung** > **Aktive Nutzer**.
:::

|  |  |  |
| --- | --- | --- |
| **Nutzertyp** | **Aktion** | **Szenario** |
| **Bestehende Mitglieder (kostenlose eingeschränkte Lizenz)** | Ein Board oder Projekt erstellen | Ein Nutzer mit kostenloser eingeschränkter Lizenz versucht, ein neues Board oder Projekt in einem Team zu erstellen. |
| Bearbeitungszugriff | Ein Nutzer mit kostenloser eingeschränkter Lizenz möchte ein Board bearbeiten. |
| Einladung zur Bearbeitung | Ein bestehendes Mitglied beantragt Bearbeitungszugriff für den Nutzer mit der Free Restricted Lizenz |
| Board-Eigentümer | Ein Nutzer mit Free Restricted Lizenz bekommt die [Rolle des Board-Eigentümers](../../getting-started/start-here/05-roles-in-miro.md) von einem Team-Admin zugewiesen |
