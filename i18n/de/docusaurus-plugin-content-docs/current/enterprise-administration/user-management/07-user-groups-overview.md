User Groups vereinfachen das Nutzermanagement für Unternehmens-Admins, indem sie es ermöglichen, Inhalte an alle Mitglieder einer Gruppe anstatt an jeden Nutzer einzeln freizugeben.

Zum Beispiel, wenn Sie ein Projektboard mit allen Designern in Ihrer Organisation teilen möchten. Sie können alle Designer zu einer User Group hinzufügen und mit der Gruppe teilen. Alle Mitglieder der Gruppe haben dann die von Ihnen festgelegten Zugriffsrechte: Bearbeiten, Kommentieren oder Ansehen.

Wie Sie User Groups erstellen, erfahren Sie unter [User Groups](08-user-groups.md).

![](../../../../../../docs/enterprise-administration/user-management/images/23921780232082_image.png)

*Unternehmens-Admins können Benutzergruppen in der Admin-Konsole erstellen.*

Benutzergruppen stellen sicher, dass alle Nutzer in einer Gruppe auf denselben Inhalt zugreifen können, ohne die Boards manuell mit jedem Nutzer zu teilen. Du kannst eine Benutzergruppe auch zu einem Team hinzufügen.

:::note
Um mehr darüber zu erfahren, wie Benutzergruppen über SCIM verwaltet werden, kontaktiere deinen Miro Customer Success Manager oder Support.
:::

## Schlüsselfunktionen

- **Erstellen und verwalten von Nutzergruppen**
  In der Admin-Konsole können Unternehmens-Admins Nutzergruppen erstellen, überprüfen, bearbeiten, Mitglieder hinzufügen und löschen. Weitere Informationen finden Sie unter [User Groups](08-user-groups.md).
- **Boards und Bereiche mit Nutzergruppen teilen**
  Teammitglieder können [jedes Board oder jeden Bereich mit einer Nutzergruppe teilen](08-user-groups.md) und Berechtigungen festlegen.
- **Verwalten von Nutzergruppen über API**
  Mit den Nutzergruppen-APIs können Admins Nutzergruppen programmatisch erstellen, bearbeiten und entfernen.
- **User-Gruppen in Kommentaren erwähnen**
  Erwähne eine User-Gruppe auf einem Board. Alle Nutzer in der Gruppe erhalten eine Benachrichtigung.
- **Mitglieder von User-Gruppen auf Boards sehen**
  Sieh und überprüfe alle Mitglieder einer User-Gruppe, wenn du eine Gruppe auf einem Board erwähnst.
