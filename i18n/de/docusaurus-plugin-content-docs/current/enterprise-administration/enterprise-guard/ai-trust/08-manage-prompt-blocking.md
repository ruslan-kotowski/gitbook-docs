Um anzupassen, welche Labels blockiert sind oder um das Scannen von Code zu aktivieren/deaktivieren:

1. Gehe zu **Einstellungen** → **Enterprise Guard** → **Data Discovery** → **Konfiguration**.
2. Wähle unter **Prompt blocking** die Option **Verwalten**.
3. Im seitlichen Feld, führe eine der folgenden Aktionen aus:
   - Schalte **Alles auswählen** ein oder aus.
   - Markiere oder demarkiere spezifische Labelkategorien, die du blockieren möchtest.
   - Schalte **Code-Scanning** ein oder aus.
4. Wähle **Änderungen übernehmen**.

Änderungen treten sofort für alle Nutzer in Kraft. Prompts mit neu entsperrten Elementen werden fortgesetzt. Prompts mit weiterhin gesperrten Elementen werden weiterhin gestoppt.
