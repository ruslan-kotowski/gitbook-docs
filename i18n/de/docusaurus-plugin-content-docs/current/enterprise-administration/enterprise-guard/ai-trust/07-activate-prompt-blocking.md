So aktivieren Sie Prompt Blocking für Ihre Organisation:

1. Gehe in Miro zu **Einstellungen** → **Enterprise Guard** → **Data Discovery** → **Konfiguration**.
2. Klicke bei **Prompt Blocking** auf **Aktivieren**.
3. Im seitlichen Feld aktiviere entweder **Alle auswählen** oder wähle bestimmte Label-Kategorien zum Blockieren aus.
4. (Optional) Aktiviere **Scannen von Code**, um Prompts zu blockieren, die Quellcode enthalten (mindestens 5 Zeilen). Weitere Informationen findest du unter [Code-Scanning](../../enterprise-guard/ai-trust/06-prompt-blocking-overview.md).
5. Klicke auf **Aktivieren**.

Prompt-Blocking ist für eure Organisation aktiviert. Alle ausgewählten Kategorien werden sofort durchgesetzt.
