Für Organisationen, die Microsoft Entra ID (ehemals Azure AD) als ihren Identitätsanbieter nutzen, leitet Enterprise Guard die AI-Prompts und -Antworten sicher an Microsoft Purview Data Security Posture Management (DSPM) weiter. Security- und Compliance-Teams können dann die Nutzung generativer AI von einer einzigen vertrauenswürdigen Plattform aus überwachen, auditieren und kontrollieren, wodurch der Betriebsaufwand reduziert, Risiken wie Datenlecks und Missbrauch gemindert und Miros AI-Governance auf Unternehmensebene gestärkt werden.

:::note
Die Beta-Version unterstützt Miro AI-Formate, einschließlich Diagramme, Mindmaps, Dokumente, Prototypen, Notizen und Tabellen, jedoch keine Bilder. Wir arbeiten daran, die Unterstützung für Bilder und weitere AI-Features in kommenden Versionen hinzuzufügen.
:::

## **Für wen ist das?**

Diese Funktion ist in der Beta-Version für Enterprise Guard-Kunden verfügbar, die Miro und Microsoft Entra ID (ehemals Azure AD)/Microsoft Purview verwalten.

## **Was Sie erhalten**

- **Zentralisierte Sichtbarkeit:** Sehen Sie sich die Nutzung von Miro AI im AI-Hub von Microsoft Purview an.
- **Revisionsfähigkeit:** Prompts (Benutzereingaben) und Antworten (AI-Ausgaben) werden zur Überprüfung protokolliert.
- **Governance-Ausrichtung:** Nutzen Sie Ihre bestehenden Purview-Workflows für Überwachung, Benachrichtigung und Aufbewahrung.

Weitere Informationen finden Sie in [der ausführlichen Dokumentation hier](../../enterprise-subscription-management/integrations/02-enterprise-guard-and-microsoft-purview-dspm-for-ai-integration-overview.md).
