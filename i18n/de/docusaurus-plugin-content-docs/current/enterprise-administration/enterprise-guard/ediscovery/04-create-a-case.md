Die Erstellung einer Untersuchung für eine Aufbewahrungsfrist ist der erste kritische Schritt im eDiscovery-Prozess, wenn ein Rechtsstreit oder eine Untersuchung erwartet wird. Eine Untersuchung dient als organisatorische Grundlage zur Verwaltung der Aufbewahrungsfrist. Sie ermöglicht eine klare Identifizierung, Dokumentation und Überwachung aller Aktivitäten im Zusammenhang mit der Datenaufbewahrung. Ohne eine ordnungsgemäße Erstellung einer Untersuchung fehlt dem Prozess eine Struktur, was zum versehentlichen Verlust oder zur Löschung kritischer Informationen führen kann und potenzielle rechtliche Risiken und Strafen nach sich zieht.

Als [eDiscovery-Admin](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md) spielst du eine Schlüsselrolle bei der Initiierung und Verwaltung von Aufbewahrungsfristen. Durch das Erstellen einer Untersuchung legst du die formale Struktur fest, die erforderlich ist, um sicherzustellen, dass alle relevanten Miro-Boards für die Dauer des Rechtsstreits ordnungsgemäß aufbewahrt werden. Ein Zweck der Erstellung einer Untersuchung besteht darin, dass sie als Container fungiert, der es Admins ermöglicht, mehrere Aufbewahrungsfristen unter einer Untersuchung zusammenzufassen. Dies kann besonders nützlich sein, wenn verschiedene Aufbewahrungsfristen Teil derselben Untersuchung sind, wie z. B. in einem Gerichtsverfahren.

In vielen Fällen müssen mehrere Nutzer in die Aufbewahrungsfrist aufgenommen werden. Im Zuge der Ermittlung oder des Rechtsfalls musst du möglicherweise zusätzliche Aufbewahrungsfristen erstellen und diese unter einer Untersuchung zusammenfassen. Die Zusammenfassung aller damit verbundenen Aufbewahrungsfristen in einer einzigen Untersuchung ermöglicht eine bessere Verwaltung und Aufsicht, da alle mit einer bestimmten Ermittlung verbundenen Aufbewahrungsfristen in einer zentralen Struktur abgelegt sind.

Durch die effektive Erstellung und Verwaltung einer Untersuchung für eine Aufbewahrungsfrist stellst du sicher, dass alle relevanten Daten gespeichert werden, und du optimierst den Prozess der Verwaltung komplexer Untersuchungen, um rechtliche Risiken für dein Unternehmen zu reduzieren.

Um eine Untersuchung zu erstellen, führe bitte diese Schritte aus:

:::note
Du musst die [eDiscovery-Admin-Rolle](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md) haben, um diese Aufgabe auszuführen. Um die eDiscovery-Admin-Rolle anzufordern, wende dich bitte an deinen Unternehmens-Admin.
:::

1. Gehe zu deinen Miro-Einstellungen.
2. Klicke im linken Bereich unter **Enterprise Guard** auf **eDiscovery**.
3. Klicke auf der **eDiscovery**-Seite auf den **Tab "Untersuchungen"**.
4. Klicke auf der Seite **Untersuchungen** auf **Untersuchung erstellen**.
5. Gib auf der Seite **Untersuchung erstellen** die entsprechenden Informationen in jedes Feld ein. Die einzelnen Felder und ihre Beschreibungen findest du in der nachstehenden Tabelle.

   |  |  |
   | --- | --- |
   | **Feld** | **Beschreibung** |
   | Name der Untersuchung  **(erforderlich)** | Bezeichnung der Untersuchung.  Maximale Länge: 60 Zeichen. |
   | Beschreibung  **(optional)** | Beschreibung für den Fall.  Maximale Länge: 300 Zeichen. |
6. Klicke auf **Untersuchung erstellen**. Die Untersuchung wird erstellt und in der Liste der Untersuchungen auf der eDiscovery-Seite angezeigt. Du kannst jetzt eine Aufbewahrungsfrist zu der Untersuchung hinzufügen.
