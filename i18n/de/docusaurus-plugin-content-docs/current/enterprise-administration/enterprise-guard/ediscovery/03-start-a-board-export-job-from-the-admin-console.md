1. Klicke auf dein Profilbild und dann auf **Admin-Konsole**.
2. Klicke in der linken Seitenleiste auf Enterprise Guard und dann auf **eDiscovery**.
3. Klicke auf den **Tab** "Untersuchungen".
   Die Liste der Untersuchungen erscheint.
4. Klicke auf die Untersuchung, die eine oder mehrere Aufbewahrungsfristen enthält, die du exportieren möchtest.
   Die Liste der Aufbewahrungsfristen, die zur Untersuchung gehören, erscheint.
5. Du kannst einen Board-Export auf eine der folgenden Arten starten:
   - Aus der Aufbewahrungsfrist-Listenansicht: Klicke auf der Aufbewahrungsfrist-Listen-Seite oben auf die Schaltfläche **Inhalt exportieren** und dann auf die spezifische Aufbewahrungsfrist, um alle zugehörigen Boards zu exportieren.
     Ein Dialogfeld wird angezeigt. Weiter zu Schritt 6.
   - Von der Aufbewahrungsfrist-Detailseite: Klicke auf der Aufbewahrungsfrist-Listen-Seite auf den Aufbewahrungsfristnamen, um ihn zu öffnen, und dann oben auf der Seite auf die Schaltfläche Exportieren.
     Ein Dialogfeld wird angezeigt. Weiter zu Schritt 6.
6. Gib im Feld **Exportname** einen Exportnamen für diesen Board-Exportauftrag ein.
7. Wähle in der Liste **Format** das Dateiformat aus, in das du die Boards exportieren möchtest. Du kannst in eine SVG-, PDF- oder HTML-Datei exportieren. Standardmäßig ist das Format auf SVG gesetzt.
8. (Optional) Um für jedes Board im Exportauftrag ein [Inhaltsprotokoll](06-content-logs-overview.md) einzuschließen, aktiviere **Inhaltsprotokolle einschließen**.
9. Klicke auf **Export**.
   Der Exportauftrag erscheint im **Exports** Tab der Untersuchung. Weitere Informationen zum Überwachen von Exportaufträgen und zum Anzeigen des Exportstatus findest du in diesem [Artikel](07-monitor-board-export-jobs-and-view-status-from-the-admin-console.md).
