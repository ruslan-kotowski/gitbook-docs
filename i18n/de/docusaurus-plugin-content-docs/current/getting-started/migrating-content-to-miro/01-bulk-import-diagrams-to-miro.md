Du kannst deine Diagramme als PDF oder VSDX aus Quellanwendungen massenhaft importieren.

:::note
Bei einigen Quellanwendungen wird nur ein Dateityp unterstützt. Um dies zu bestätigen, sieh unter Unterstützte Dateitypen nach.
:::

## So importierst du Diagramme in Miro massenhaft

Um deine Diagramme in Miro zu importieren, stelle sicher, dass du die Datei(en) aus deiner Quellanwendung als PDF oder VSDX exportiert hast. Führe dann das folgende Verfahren durch.

1. Auf deinem Miro-Dashboard, im Bereich, in den du Diagramme importieren möchtest, klicke auf **Neu erstellen** (**+**).
   ![](../../../../../../docs/getting-started/migrating-content-to-miro/images/32654520716690_image.png)
2. Klicke auf **Importieren** > **Importieren von \{source\}**. Zum Beispiel **Importieren von Mural**.
   Das Dialogfeld **Importieren von \{source\}** öffnet sich.
3. Befolge die Anweisungen auf dem Bildschirm.
4. (Optional) Ändere den Zielbereich für den Import. Oder klicke auf die Plus-Schaltfläche (**+**), um einen neuen Zielbereich zu erstellen.
5. Klicke auf **Dateien importieren** ***x*****.**

## Importdateiunterstützung

| Quelle | Dateityp |
| --- | --- |
| Conceptboard | PDF, VSDX |
| Lucidchart | PDF, VSDX |
| Lucidspark | PDF, VSDX |
| Mural | PDF |
| Visio | VSDX |
