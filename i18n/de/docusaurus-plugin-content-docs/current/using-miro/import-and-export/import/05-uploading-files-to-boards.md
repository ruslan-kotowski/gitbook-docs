Am einfachsten kannst du deinen Boards Dateien hinzuzufügen, indem du sie von deinem Desktop auf das Board ziehst. Du kannst Bilder, PDF-Dateien, Google Drive-Dokumente und MS Office-Dateien hinzufügen. Die vollständige Liste der unterstützten Dateiformate findest du in [diesem Artikel](../../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md). Neue Dateien können von deinem Computer oder aus dem Internet hinzugefügt werden (die maximale Dateigröße beträgt 30 MB, die maximale Bildauflösung 32 MP, die maximalen Dimensionen sind 8192 x 4096 Pixel).

> **Einrichtung durch:** [Board-Bearbeiter](../../sharing-boards/01-board-access-rights.md)
> **Erhältlich für:**Alle Miro-Preispläne (Free-Preisplan kann eingebettete Videos nicht abspielen)

### Dateien von deinem Gerät hinzufügen

Um Dateien auf deinem Gerät hochzuladen, wählst du **Hochladen** auf der Erstellungssymbolleiste. Wenn die Option für dich ausgeblendet ist, klicke auf die Pfeile für **weitere Tools** (>>) und füge die Schaltfläche der Symbolleiste hinzu. Klicke auf **Mein Gerät**.

![upload_on_the_toolbar_greybg.gif](https://help.miro.com/hc/article_attachments/23898977458834)
*Schaltfläche „Hochladen“ in der Symbolleiste*

Dadurch öffnet sich ein Dialogfeld, in dem du die Dateien auswählen kannst, die du auf dein Board hochladen möchtest. Wenn du die Dateien ausgewählt und auf **Öffnen** geklickt hast, werden sie hochgeladen und erscheinen auf dem Board.

Oder du ziehst die Dateien ganz einfach von deinem Desktop auf das Board, um sie hochzuladen.

:::note
Überprüfen Sie die Liste der unterstützten Dateiformate [hier](../../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md).
:::

Du kannst mit hochgeladenen Dateien interagieren: die Größe ändern, sie drehen, Seiten umblättern und Seiten extrahieren.

![change_an_uploaded_object_greybg.gif](https://help.miro.com/hc/article_attachments/23898977462162)
*Interaktion mit einer hochgeladenen PDF-Datei*

Wenn du die [mobile App](../../../getting-started/apps-for-devices/08-mobile-app.md) verwendest, drücke das Plus-Symbol in der unteren rechten Ecke des Boards und wähle **Hochladen**. Du kannst eine Datei aus der Zwischenablage einfügen, ein Foto machen oder ein Bild aus der mobilen Bibliothek auswählen. Das Hochladen von PDF-Dateien auf Mobilgeräten wird derzeit nicht unterstützt.

![upload on mobile.png](https://help.miro.com/hc/article_attachments/23898977466642)
*Eine Datei von einem mobilen Gerät hochladen*

### Dateien über URL-Links hinzufügen

Zum Hochladen von Dateien aus dem Internet über einen direkten Link zur Quelle wähle **Hochladen via** **URL.**

*![Upload via URL.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005103890_Upload%20via%20URL.png)**Hochladen über URL auf der Symbolleiste*

Füge dann einen direkten URL-Link in eine Datei aus dem Internet ein, wie zum Beispiel ein YouTube- oder Vimeo-Video.

![upload via URL modal.png](https://help.miro.com/hc/article_attachments/23898956218002)
*Hochladen über einen URL-Link*

:::note
Eingebettete Videowiedergabe ist in Free-Preisplänen und für Nutzer mit einer Basislizenz nicht verfügbar.
:::

Um ein Video anzuschauen, doppelklicke auf das **Play**-Symbol (die hinzugefügte Datei wird nicht automatisch abgespielt). Du kannst auch auf die **Quellseite** gehen und andere Funktionen im Kontextmenü nutzen.

Du kannst ein Video, das Miro hinzugefügt wurde, vorspulen, Untertitel hinzufügen und die Videoqualität ändern – verwalte die hochgeladenen Videos direkt auf deinen Boards.

![video embed.png](https://help.miro.com/hc/article_attachments/23898956225810)
*Die Option, zur Videoquelle zu gehen*

Mit den folgenden Tastenkürzeln kannst du direkt am Board einen Link zur Datei posten: **Strg+C**/**Strg+V** (*für Windows*) oder **Cmd+C/Cmd+V** (*für Mac*).

Um einen URL-Link auf einem Board ohne Vorschau einzufügen, benutze das [Text-Tool](../../essential-tools/16-text.md) und füge den Link in das Textfeld ein.

### Dateien von anderen Diensten hochladen

Du kannst auch Dateien von [Google Drive](../../../integrations-apps/google/05-google-drive.md), [Dropbox](../../../integrations-apps/more-integrations/06-dropbox.md), [Box](../../../integrations-apps/more-integrations/05-box-legacy.md), [OneDrive](../../../integrations-apps/microsoft/06-onedrive.md), [Adobe CC](../../../integrations-apps/adobe/02-adobe-creative-cloud.md) hochladen. Alle diese Optionen sind im Menü **Hochladen** verfügbar. Weitere Informationen findest du in den entsprechenden Artikeln.

Beachte, dass [Besucher](../../sharing-boards/08-collaboration-with-visitors.md) diese Option nicht nutzen können.

### Speichern von hochgeladenen Dateien in der Bibliothek

Du kannst die hochgeladenen Dateien in deiner Miro-Bibliothek für die zukünftige Nutzung in diesem Team speichern. Dazu wählst du die Datei aus, klickst auf die drei Punkte im Kontextmenü und wählst **Hinzufügen zu gespeicherten Dateien**. Das funktioniert für PDFs, Bilder, Präsentationen, Google Dokumente und andere Dateien.

![add to saved files.png](https://help.miro.com/hc/article_attachments/23898956234130)
*Die Option, eine Datei zu gespeicherten Dateien hinzuzufügen*

Gespeicherte Dateien sind im Ordner **Gespeicherte Dateien** im Menü **Hochladen** auf der Symbolleiste verfügbar. Um eine Datei aus der Bibliothek hinzuzufügen, klicke darauf oder ziehe sie auf das Board. Hinweis: Die gespeicherten Dateien sind nur in Boards von dem Team zugänglich, dem das Board, von dem aus sie gespeichert wurden, gehört.

![saved files.png](https://help.miro.com/hc/article_attachments/23898977487378)
*Gespeicherte Dateien auf der Symbolleiste*

Um eine Datei aus der Bibliothek zu löschen, fahre mit dem Mauszeiger darüber und klicke auf das **Papierkorb**symbol.

![delete a saved file.png](https://help.miro.com/hc/article_attachments/23898956241554)
*Lösche eine Datei aus den gespeicherten Dateien, indem du auf das Papierkorb-Symbol klickst*

Wenn die Option **Zu gespeicherten Dateien hinzufügen** inaktiv ist (grau) und die Fehlermeldung **Dieses Tool ist auf diesem Board nicht verfügbar** angezeigt wird, bedeutet das, dass du nicht über die erforderlichen Rechte verfügst, um diese Aktion auszuführen, da du kein Mitglied des Teams bist, in dem das Board gespeichert ist.

### Mehrseitige Dokumente aufteilen

> **Verfügbar mit:** Browser-Version, [Desktop-App](../../../getting-started/apps-for-devices/05-desktop-app.md)

Lass dein Team gemeinsam an Dokumenten, PDF- oder Powerpoint-Dateien arbeiten – du kannst beliebige Seiten erweitern, sie auf dem Board auslegen und Kommentare direkt auf den Seiten hinterlassen.

Um eine PDF- oder Powerpoint-Datei in eine bestimmte Anzahl von Seiten zu unterteilen:

1. Lade die Datei auf das Board hoch.
2. Klicke auf die Datei und wähle im Kontextmenü das **Symbol Seiten extrahieren**.

   > ✏️ Die Option ist nur im [Modus „Auswahl (Cursor)“](#mini) verfügbar. Wenn die Option im Menü nicht erscheint, drücke **V** oder wähle das Symbol für den Cursor in der Symbolleiste und klicke das Objekt erneut an.
3. Im Dialogfeld wähle aus, wie du die Datei aufteilen möchtest – alle oder nur bestimmte Seiten – und klicke auf **Extrahieren.**

Die erweiterten Seiten werden direkt unter der Originaldatei angezeigt. Falls du die Originaldatei nicht mehr brauchst, kannst du sie löschen – alle extrahierten Seiten bleiben auf dem Board.

### Mögliche Probleme beim Hochladen von PDF-Dateien

Manche PDF-Dateien können auf einem Miro-Board nicht hochgeladen werden. Sie bleiben stecken, wobei das Laderad dauerhaft angezeigt wird, oder sie werden zu grauen Bildern mit einem Fehlerzeichen. Wenn du mit diesem Problem konfrontiert bist, überprüfe bitte Folgendes:

- Deine PDF-Datei darf nicht größer als 30 MB sein
- Deine Internetverbindung muss stabil sein
- Dein Gerät erfüllt die minimalen [Systemanforderungen](../../troubleshooting-technical-questions/technical-guidelines/01-system-requirements.md)

Wenn du immer noch Probleme hast, eine Datei auf dein Board hochzuladen, kann es sein, dass die Datei selbst das Problem verursacht. Einige komplexe PDF-Dateien können aufgrund unserer technischen Einschränkungen nicht auf Boards wiedergegeben werden. Das passiert normalerweise bei PDFs, die viele Elemente oder kleine Details enthalten. Wir arbeiten an der Verbesserung unseres Rendering-Tools, aber bis dahin gibt es diesen Workaround:

- Speichere die Datei im PNG- oder JPEG-Format in der Software, in der du sie erstellt hast.
- Oder wandle eine PDF-Datei in eine PNG- oder JPEG-Datei mit einem Online-Tool um. Du kannst jedes beliebige Tool verwenden, z. B. `https://www.freepdfconvert.com/pdf-to-png` oder `https://cloudconvert.com/`)

:::note
Sollten beim Hochladen von Dateien auf Miro-Boards weitere Probleme auftreten, versuchen Sie bitte die Schritte zur Fehlerbehebung aus [diesem Artikel](../../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md).
:::

## Häufig gestellte Fragen

**Kann ich Videodateien von meinem Gerät auf Miro-Boards hochladen?**

Nein, aber du kannst Videos ganz einfach einbetten. Bitte sieh dir dazu diesen Leitfaden an: [Medien auf Boards einbetten](../../../integrations-apps/integrations-basics/03-embed-integrations-on-a-miro-board.md).

**Kann ich bearbeitbare Daten aus einer Excel- oder CSV-Datei importieren?**

Tabellenkalkulationen, einschließlich .xslx- und CSV-Dateien, können als Ansichtsdateien importiert werden oder zur Erstellung einer Tabelle oder eines Rasters verwendet werden. Für weitere Informationen: [Tabellen](../../formats/14-tables.md) oder [Raster](../../advanced-tools/05-grid.md).

**Kann ich Dateien von einem Board herunterladen?**

Ja, falls dies in den [Board-Inhaltseinstellungen](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) erlaubt ist. Um eine Datei herunterzuladen, wähle sie aus und klicke im Kontextmenü auf **Herunterladen**.

**Kann ich auf Links in hochgeladenen PDF-Dateien klicken?**

Nein, das wird derzeit nicht unterstützt.
