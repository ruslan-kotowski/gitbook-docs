Du kannst deine Diagramme aus den Quellanwendungen als PDF oder VSDX importieren.

:::note
Für einige Quellanwendungen wird nur ein Dateityp unterstützt. Um dies zu überprüfen, siehe Unterstützung von Dateitypen bei Importen.
:::

## Wie man Diagramme in Miro importiert

Um deine Diagramme in Miro zu importieren, stelle sicher, dass du die Datei(en) aus deiner Quellanwendung als PDF oder VSDX exportiert hast. Führe dann das folgende Verfahren durch.

1. Klicke auf deinem Miro-Dashboard im Bereich, in dem du Diagramme importieren möchtest, auf **Neu erstellen** (**+**).
   ![](../../../../../../../docs/using-miro/import-and-export/import/images/32657459157138_image.png)
2. Klicke auf **Importieren** > **Importieren von \{source\}**. Zum Beispiel **Importieren von Mural**.
   Das Dialogfeld **Importieren von \{source\}** öffnet sich.
3. Befolge die Anweisungen auf dem Bildschirm.
4. (Optional) Ändere den Zielbereich für den Import. Oder klicke die Plus-Schaltfläche (**+**), um einen neuen Zielbereich zu erstellen.
5. Klicke auf **Importiere** ***x*** **Dateien**.

## Unterstützte Dateitypen für den Import

| Quelle | Dateityp |
| --- | --- |
| Conceptboard | PDF, VSDX |
| Lucidchart | PDF, VSDX |
| Lucidspark | PDF, VSDX |
| Mural | PDF |
| Visio | VSDX |
