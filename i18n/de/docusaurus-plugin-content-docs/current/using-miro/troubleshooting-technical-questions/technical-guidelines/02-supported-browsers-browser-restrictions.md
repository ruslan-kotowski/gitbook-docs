Dieser Artikel bietet Informationen darüber, welche Desktop- und Mobile-Browser von Miro unterstützt werden.

:::note
Miro unterstützt alle Versionen der wichtigsten Browser für mindestens 12 Monate, einschließlich aktiver Langzeit-Support-Versionen. Frühere Browserversionen könnten keinen Entwickler-Support mehr haben, was sich auf Ihre Miro-Erfahrung auswirken kann. Um die optimale Miro-Erfahrung zu gewährleisten, aktualisieren Sie Ihre Browser mindestens einmal im Jahr.
:::

Miro unterstützt offiziell die folgenden Browser:

- **Desktop**
  - Chrome
  - MS Edge
  - Firefox
  - Opera
  - Yandex Browser
- **Mobile**
  - Chrome
  - Safari
  - Samsung Internet

:::note
Boards, auf die über mobile Browser zugegriffen wird, befinden sich im Ansichtsmodus. Um mit deinen zugewiesenen Berechtigungen darauf zugreifen zu können, lade die [mobile Miro-App](../../../getting-started/apps-for-devices/08-mobile-app.md) herunter.
:::

:::warning
Internet Explorer wird nicht unterstützt.
:::

## Problem beim Laden des Boards in Safari

Falls du das Problem hast, dass das Board in Safari v. 15.2, OS Monterey, einfriert bzw. nicht mehr lädt, versuche bitte, die folgenden Schritte auszuführen (möglicherweise erhältst du auch die Fehlermeldungen „*This web page was reloaded because a problem occurred*“ oder „*This web page and one other page are not responding*“):

1. Gehe zu Safari > Einstellungen > **Entwickler** > **Experimentelle Features.**
2. Schalte die **GPU-Prozesse: Canvas Rendering** Funktion **aus** .

   ![](/attachments/token/45hImX8u1weQZnUaPOXtAT971/?name=inline1581405683.png)

   > ✏️ Wenn du das **Entwickler** Menü in der [Menüleiste](https://support.apple.com/en-gb/guide/safari/aside/glos33eb8abd/15.1/mac/12.0) nicht siehst, öffne Safari > Einstellungen, klicke auf **Erweitert**, und wähle dann **Entwickler-Menü in der Menüleiste anzeigen** aus.
