Falls du Probleme bei der Nutzung von Miro auf einem Hybridgerät mit Touchscreen oder mit einem digitalen Stift hast, solltest du deine Browsereinstellungen überprüfen. Beachte, dass die hier vorgeschlagenen Anweisungen nur für einen Browser nützlich sind.

## Google Chrome

1. Öffne eine neue Seite in Google Chrome.
2. Gib **chrome://flags** in der Adressleiste von Chrome ein und gib **t****ouch** in die Suchzeile ein.
3. Stelle sicher, dass **Touch UI Layout**auf **Enabled** gesetzt ist.
4. Stelle sicher, dass **Touch initiated drag and drop** auf **Enabled** gesetzt ist.
5. Verwende den Touchscreen/digitalen Stift erneut, um zu sehen, ob sich etwas geändert hat.

## Edge

1. Öffne eine neue Seite in Edge.
2. Gib **about:flags** in der Adressleiste von Edge ein.
3. Drücke Strg + F, um nach **t****ouch events** zu suchen
4. Stelle sicher, dass **Touch events** auf **Always on** gesetzt ist.
5. Verwende den Touchscreen/digitalen Stift erneut, um zu sehen, ob sich etwas geändert hat.
