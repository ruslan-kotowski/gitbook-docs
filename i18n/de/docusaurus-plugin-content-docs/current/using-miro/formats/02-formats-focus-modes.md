Formate und Fokusmodi ermöglichen deinem Team, nahtlos zwischen freiem Brainstorming und strukturierten Dokumenten, Tabellen, Zeitachsen, Diagrammen und Präsentationen zu wechseln. Beginne mit einem leeren Canvas oder einem strukturierten Format und nutze den Fokusmodus, um Ablenkungen zu minimieren und im Fluss zu bleiben. Setze ein Format als Standardansicht fest, damit jeder, der das Board öffnet, dort landet, wo du es möchtest.

Weitere Informationen zu jedem der Formate findest du hier:

## **Auf Formate zugreifen**

Um ein neues Format auf der Canvas hinzuzufügen:

1. Klicke auf das **Symbol Tools, Media and Integrations** (![icon-tools.svg](../../../../../../docs/using-miro/formats/images/29210901366418_icon-tools.svg))in der Symbolleiste.
2. Wähle das benötigte Format aus: **Dokument**, **Tabelle**, **Zeitleiste**, **Diagramm**, **Prototyp**oder **Präsentationen**.
3. Klicke irgendwo auf die Canvas, um das ausgewählte Format hinzuzufügen.

## **Fokusmodus**

Alle Formate können im **Fokusmodus** (Vollbild) geöffnet werden, wenn du dich ausschließlich auf das Format konzentrieren möchtest, an dem du gerade arbeitest, und nicht auf andere Inhalte auf dem Board. Um den Fokusmodus zu verwenden:

1. Klicke irgendwo auf das Format, das du im Fokusmodus verwenden möchtest.
2. Klicke im Kontextmenü auf das **Fokusmodus**-Symbol.
3. Um den Fokusmodus zu verlassen, klicke oben auf dem Bildschirm auf die **Zurück zur Canvas**-Schaltfläche.

## **Ein Format als Standardansicht festlegen**

Jedes der Formate kann als Standardansicht für das Board festgelegt werden, sodass jeder, der das Board öffnet, zuerst das Dokument, die Tabelle, die Zeitachse, das Diagramm oder die Präsentationen sieht.

Um das Format als Standardansicht festzulegen:

1. Klicke irgendwo auf das Format, mit dem du in den Fokusmodus wechseln möchtest.
2. Klicke auf das Symbol der **vertikalen drei Punkte** (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg)).
3. Wähle **als Standardansicht festlegen**.
4. Klicke im Dialogfeld auf **Standard festlegen**.

### Standardansicht sperren

Board-Eigentümer können die Standardansicht sperren, damit Betrachter keinen Zugriff auf den Rest des Boards haben. Gehe so vor:

1. Klicke irgendwo auf das Format, mit dem du in den Fokusmodus wechseln möchtest.
2. Klicke auf das **vertikale Drei-Punkte-Symbol** (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg)).
3. Wähle **Als Standardansicht festlegen**.
4. Klicke im geöffneten Dialogfeld auf den Umschalter, um die **Standardansicht zu sperren**.
5. Klicke auf **Standard festlegen**.

## **Link zum Fokusmodus teilen**

Wenn du den Fokus auf dem Canvas behalten möchtest, kannst du jederzeit nur einen Link zum Fokusmodus deines Formats teilen:

1. Klicke irgendwo auf das Format, mit dem du den Fokusmodus betreten möchtest.
2. Klicke auf das **Symbol mit den vertikalen drei Punkten** (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg)).
3. Wähle **Fokusmodus-Link kopieren** aus.

## **Formate vom Dashboard oder Bereich erstellen**

Du kannst jedes Format direkt von deinem Dashboard, deiner Bereichsübersicht oder der Bereiche-Seitenleiste erstellen. Dies wird das Format automatisch als Standardansicht einstellen – alle, die mit dir das Board betreten, landen im Fokusmodus deines Formats.

1. Öffne dein **Dashboard** oder deine **Bereichsübersicht**.
2. Klicke auf das Menü **Neu erstellen**.
3. Wähle das Format aus, das du erstellen möchtest: **Dokument**, **Diagramm**, **Prototyp**, **Zeitleiste**, **Tabelle** oder **Präsentation**.

## **Formate aus der Bereiche-Seitenleiste erstellen**

Wenn du an einem Board arbeitest, kannst du neue Formate aus der **Bereiche-Seitenleiste** erstellen. Das neue Format wird im selben Bereich erstellt.

1. Wähle in der [Board-Leiste](../working-on-the-board/02-miro's-new-simplified-user-interface.md) das Hamburger-Menü **Seitenleiste öffnen** aus. Die **Seitenleiste für Bereiche** wird geöffnet.
2. Klicke auf das Symbol **Neu erstellen**.
3. Wähle das gewünschte Format aus: **Dokument**, **Diagramm**, **Prototyp**, **Zeitleiste**, **Tabelle** oder **Präsentation**.

:::tip
Du kannst ein Format an deinen Bereich anheften. Das angeheftete Format wird in der Seitenleiste für Bereiche angezeigt.
:::
