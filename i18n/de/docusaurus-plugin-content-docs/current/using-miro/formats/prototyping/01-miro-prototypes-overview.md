Prototyping in Miro hilft Teams, Ideen visuell zu erkunden und frühe Versionen von digitalen Erlebnissen zu entwickeln. Miro bietet Kernwerkzeuge für die manuelle Erstellung von Bildschirmen und ein optionales Add-on mit **Miro Prototypes**, das diese Funktionen mit KI-gesteuerter Erstellung und interaktiven Verhalten erweitert.

Du kannst beide Ansätze im gesamten Workflow verwenden.

## **Empfohlene Tools zur Prototypenerstellung**

Miros Workflow zur Prototypenerstellung basiert auf vier Arten von Tools:

- **Komponenten** — UI-Elemente, Geräte, Symbole und erweiterte Komponenten.
- **Erstellungsmethoden** — manuelle Bildschirmgestaltung oder KI-gestützte Generierung.
- **Interaktion** — statische Layouts oder interaktive Klick-Demonstrationen.
- **Format** — Container für deine Prototypen mit schnellem Zugriff auf den Fokusmodus und Vorschauen.

Dein Zugriff hängt von deinem Preisplan und der Add-on-Verfügbarkeit ab.

## **Freie vs. Add-on-Prototyping-Funktionen**

|  |  |  |
| --- | --- | --- |
| **Funktion** | **Alle Nutzer** | **Miro Prototypes** **Add-on** |
| Prototypen-Bildschirme (Mobil, Desktop, Tablet) | ✓ | ✓ |
| Prototypen-Bibliothek grundlegende UI-Komponenten und Symbole | ✓ | ✓ |
| Prototypen-Bibliothek für fortgeschrittene Komponenten | – | ✓ |
| KI: Erstellen von Bildschirmen aus Text oder Canvas-Inhalten | – | ✓ |
| KI: Screenshots in bearbeitbare Mock-ups umwandeln | – | ✓ |
| KI: Bildschirme mit einem Prompt verfeinern oder erweitern | – | ✓ |
| KI: Visuelle Gestaltung mit einem Bild | – | ✓ |
| Interaktive Navigation hinzufügen | – | ✓ |
| Vorschau-Modus (interaktive Prototyp-Ansicht) | – | ✓ |
| Format-Container und Fokusmodus | – | ✓ |

## **Wie die Werkzeuge zusammenarbeiten**

Miro's Prototyping-Tools sind dafür ausgelegt, gemeinsam genutzt zu werden, nicht als getrennte Wege. Die meisten Teams verbinden manuelle Erstellung mit KI-gestützter Erstellung innerhalb ihres Workflows.

Du könntest:

- einen Satz von Bildschirmen mit KI erstellen.
- Bildschirme manuell neu anordnen oder anpassen.
- Komponenten von Hand hinzufügen.
- die KI erneut verwenden, um den Prototyp zu restylen oder zu erweitern.
- interaktive Navigation für Feedback-Sitzungen hinzufügen.
- weiterhin manuell verfeinern, während sich die Idee entwickelt.

Dieser hybride Ansatz bietet dir **Geschwindigkeit, Flexibilität und Kontrolle**.
