Wandle Widgets mithilfe von numerischen Dimensionen für pixelgenaue Größenanpassung in Formaten um.

:::note
Präzises Größenskalieren ist in ausgewählten Formaten verfügbar, darunter Diagramme, Miro Prototypes und Miro-Präsentationen.
:::

## Präzises Größenanpassen

1. Wechsle in den **Fokusmodus**, indem du auf das **Fokusmodus**-Symbol im Kontextmenü deines Formats klickst.
2. Klicke auf das Widget, das du skalieren möchtest. Unterstützte Widgets sind unter anderem Text, Bilder, Notizen, Schablonen und Prototypformen.
3. Klicke im Kontextmenü des Widgets auf das **Skalierung**-Symbol.
   Ein Dialogfeld für die Abmessungen wird unter dem Menü geöffnet.
4. Gib die Pixelabmessungen für **Breite** und **Höhe** ein.
5. Drücke **Enter**, um die Änderungen zu übernehmen.

:::note
In Textfeldern kann nur die Breite angegeben werden. Die Höhe passt sich automatisch dem Inhalt des Textfelds an.
:::
