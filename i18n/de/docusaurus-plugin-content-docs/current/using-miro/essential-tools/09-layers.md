Mithilfe von Ebenen kannst du separate Abschnitte der Inhalte auf dem Board besser organisieren. Dies ist vor allem für die Verwaltung von komplexen Diagrammen sehr hilfreich und gibt dir die Möglichkeit, präziser und strukturierter zu arbeiten.

## Zugriff auf Ebenen

Um auf das **Ebenen-Feld** zuzugreifen:

1. Klicke in der Erstellungssymbolleiste auf das Symbol **Medien, Tools und Integrationen** (![icon-tools.svg](../../../../../../docs/using-miro/essential-tools/images/23227364594834_icon-tools.svg)).
2. Suche nach **Ebenen** und klicke dann auf das Ebenen-Tool.
3. Du kannst das Ebenen-Tool in der Erstellungssymbolleiste behalten, indem du mit der rechten Maustaste auf das Symbol **Ebenen** klickst und dann **An die Symbolleiste anheften** auswählst.

![layers-new-entry-point.png](../../../../../../docs/using-miro/essential-tools/images/22431635505426_layers-new-entry-point.png)

*Das Menü „Ebenen“ wird angezeigt, wenn du auf das Symbol für Rahmen und Ebenen klickst*

Wenn du auf das **Ebenensymbol** klickst, öffnet sich ein Feld auf der rechten Seite des Canvas. Hier kannst du eine Ebene aktivieren, deinen bestehenden Ebenen Namen geben oder neue Ebenen erstellen.

![layers-panel.png](../../../../../../docs/using-miro/essential-tools/images/21594007565842_layers-panel.png)

*Das Menü „Ebenen“ wird auf der rechten Seite des Canvas angezeigt*

### Wer kann Ebenen verwenden

Die Funktionalität innerhalb der Ebenen basiert auf der Nutzerrolle.

- Betrachter und Kommentatoren (einschließlich Gäste mit diesen Berechtigungen) können nicht auf Ebenen zugreifen.
- Bearbeitende (einschließlich Gäste mit Bearbeitungsberechtigungen) können Ebenen erstellen, bearbeiten, ausblenden und einblenden.
  - Bearbeitende, die per E-Mail eingeladen wurden, können auch Ebenen sperren und entsperren.
- Board-Eigentümer und -Miteigentümer haben alle Berechtigungen, die Bearbeitende haben, und können Ebenen sperren sowie entsperren und die geschützte Sperre verwenden.

## Ebenen verwenden

Du kannst deine Inhalte auswählen und zu einer neuen oder bereits vorhandenen Ebene hinzufügen, um die zugehörigen Inhalte zu organisieren.

1. Wähle die Inhalte aus, die du einer neuen oder bereits vorhandenen Ebene hinzufügen möchtest.
2. Klicke auf das Menü **Ebenen**.
3. Um den Inhalt zu einer neuen Ebene hinzuzufügen: Klicke auf **+ In eine neue Ebene verschieben**. Du kannst die neue Ebene dann umbenennen.
4. Um den Inhalt in eine bereits vorhandene Ebene zu verschieben: Klicke auf die **drei Punkte** (**...**) neben dem Ebenennamen und wähle **Auswahl in Ebene verschieben** aus.

![layers-move-to.gif](../../../../../../docs/using-miro/essential-tools/images/21594007570962_layers-move-to.gif)

*Inhalte zu einer bereits vorhandenen Ebene hinzufügen*

Wenn du Inhalte hinzufügst, die du in eine bestimmte Ebene aufnehmen möchtest, wähle zuerst die Ebene aus. Neue Inhalte werden dieser Ebene dann automatisch hinzugefügt.

Du kannst auch Inhalte zu einer neuen oder bereits vorhandenen Ebene hinzufügen, indem du:

1. Wähle die Inhalte aus, die du hinzufügen möchtest.
2. Klicke auf das **Drei-Punkte-Menü** (**...**) im Kontextmenü.
3. Wähle die Option **In Ebene verschieben** aus.

![](../../../../../../docs/using-miro/essential-tools/images/21593982256018_803bbedc-722c-45ef-afb8-e9c46ba8a857.png)

*Die Option **In Ebene verschieben** findest du unter den drei Punkten (**...**) im Kontextmenü*

Ebenen können ausgeblendet, gesperrt, umbenannt oder dupliziert werden, je nachdem, was du gerade brauchst.

1. Klicke im Ebenenmenü auf den Namen der Ebene oder fahre mit der Maus über den Namen.
2. Um eine Ebene **auszublenden**: Klicke auf das **Augensymbol**, um die Ebene auszublenden. Das Symbol ändert sich von einem offenen Auge zu einem geschlossenen Auge. Alle Inhalte in der ausgewählten Ebene werden vom Canvas verschwinden. (Beachte, dass die ausgeblendeten Inhalte für alle Nutzer vom Canvas verschwinden und beim Neuladen der Seite ausgeblendet bleiben.)
3. Um die Ebene einzublenden, klicke auf das **Symbol mit dem geschlossenen Auge**. Die ausgeblendeten Inhalte werden auf dem Canvas wieder angezeigt.![layers-eye.png](../../../../../../docs/using-miro/essential-tools/images/21593982258450_layers-eye.png)
   *Das Ausblenden einer Ebene erfolgt über das Augensymbol*
4. Um eine Ebene zu **sperren**: Klicke auf das **Schlosssymbol**, um die Ebene zu sperren. Das Symbol ändert sich von einem offenen Schloss zu einem geschlossenen Schloss. Wenn eine Ebene gesperrt ist, können keine Änderungen an den Inhalten innerhalb dieser Ebene vorgenommen werden (einschließlich des Verschiebens oder Löschens von Inhalten).
5. Klicke erneut auf das **geschlossene** **Schlosssymbol**, um die Inhalte wieder freizugeben.![layers-lock.png](../../../../../../docs/using-miro/essential-tools/images/21594007576466_layers-lock.png)
   *Das Schlosssymbol wird verwendet, um eine Ebene zu sperren oder zu entsperren*
6. Um eine Ebene zu **duplizieren**: Klicke auf die drei Punkte (**...**) auf der rechten Seite der Ebene.
7. Klicke auf **Ebene duplizieren**.
8. Dadurch wird auf dem Board eine identische Version deiner Ebene direkt über der ursprünglichen Ebene angezeigt.
9. Um die duplizierte Ebene zu verschieben, stelle sicher, dass die Ebene im Ebenenmenü ausgewählt ist, klicke dann auf den Inhalt der Ebene auf dem Canvas und ziehe ihn an die gewünschte Position.
   ![layers-three-dots.png](../../../../../../docs/using-miro/essential-tools/images/21593982264594_layers-three-dots.png)
   *Das Duplizieren einer Ebene erfolgt über das Menü mit den drei Punkten (...)*

Um eine Ebene zu benennen:

1. Doppelklicke im Ebenenmenü auf den Namen der Ebene.
2. Bearbeite den Namen der Ebene.
3. Drücke die Eingabetaste.

## Ebenen im Diagrammformat

Ebenen im Diagrammformat funktionieren unabhängig von Canvas-Ebenen. Diese Trennung soll den Diagrammprozess optimieren und Verwechslungen zwischen allgemeinen Board-Inhalten und spezifischen Diagrammkomponenten verhindern. Um mehr über die Besonderheiten zu erfahren, wie Ebenen in Diagrammen funktionieren, lies bitte unseren detaillierten Artikel über das [Diagrammformat](../formats/diagramming/02-miro-diagrams.md).

- **Canvas vs. Diagrammebenen**: Während Canvas-Ebenen für allgemeine Zwecke wie Präsentationen verwendet werden, werden Ebenen innerhalb eines Diagramms separat verwaltet, um die eigenen Elemente des Diagramms zu organisieren.
- **Übergeordnete Elemente**: Sobald ein Element Teil eines Diagramms ist, kann es nicht mehr zu einer Canvas-Ebene hinzugefügt werden, da es vom Diagrammformat selbst als übergeordnetes Element geführt wird.

## Ebenen neu anordnen

Du kannst Ebenen im Feld neu anordnen, was beeinflusst, welche Inhalte einer Ebene oben angezeigt werden. Um die Ebenen neu anzuordnen, ziehe sie einfach im Ebenen-Feld in die gewünschte Reihenfolge.

Dies ist ein leistungsstarkes Tool zum Erstellen von Diagrammen, in denen du möglicherweise zwei Versionen desselben Teils eines Diagramms mit leicht unterschiedlichem Inhalt benötigst. Wenn du die Ebenen direkt übereinander platzierst, kannst du entscheiden, welche angezeigt werden soll, indem du die Ebenen neu anordnest.

## Die Standardebene

Die Standardebene ist immer sichtbar und neue Widgets werden zur Standardebene hinzugefügt, wenn keine andere Ebene aktiv ist. Wenn du in keiner bestimmten Ebene arbeitest, arbeitest du in der Standardebene.

Die Standardebene unterscheidet sich von anderen Ebenen, da sie nicht ausgeblendet oder gesperrt werden kann.
