Verwende Miro AI, um Bilder zu bearbeiten, die du zu Miro hochlädst.

## Bildhintergründe entfernen

1. Wähle ein hochgeladenes oder eingefügtes Bild auf deinem Board aus.
   Das Kontextmenü wird angezeigt.
2. Wähle im Kontextmenü **Miro AI**.
   Es öffnet sich ein Dropdown-Menü.
3. Wähle **Hintergrund entfernen**.

## Vorschläge für Alternativtext erhalten

1. Wähle ein hochgeladenes oder eingefügtes Bild auf deinem Board aus.
   Das Kontextmenü wird angezeigt.
2. Wähle im Kontextmenü **ALT**.
   Der **Bildbeschreibung**-Dialog wird geöffnet. **Miro AI** generiert automatisch einen Vorschlag.
3. Klicke **Einfügen**.
   Der generierte Vorschlag wird automatisch gespeichert.
4. (Optional) Bearbeite den eingefügten Vorschlag. Die Änderungen werden automatisch gespeichert.
5. Schließe den **Bildbeschreibung**-Dialog.

:::note
Das Generieren von Alt-Text mit Miro AI verbraucht keine KI-Credits.
:::

## Bilder in Diagramme oder Miro Prototypes umwandeln (begrenzte Verfügbarkeit)

Miro AI ermöglicht es dir, Bilder von Diagrammen oder Miro Prototypes in vollständig bearbeitbare Versionen auf deinem Miro Board zu konvertieren. Deine Diagrammbilder können sogar handgezeichnete Skizzen sein.
