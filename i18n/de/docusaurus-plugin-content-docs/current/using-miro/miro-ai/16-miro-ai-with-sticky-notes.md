Verwende Miro AI mit Notizen, um basierend auf deiner Auswahl auf dem Board zu generieren, zu gruppieren, zusammenzufassen oder Dokumente zu erstellen. Du kannst auch die Notizerfassung verwenden, mit der du ein Bild von Notizen mit Inhalten hochladen kannst, um vollständig bearbeitbare Notizen auf deinem Board zu erstellen.

## Notizen generieren und Notizerfassung

Du kannst Miro AI auffordern, Notizen zu generieren. Du kannst auch ein Bild von Notizen hochladen, um sie als bearbeitbare Versionen auf deinem Miro-Board oder zur Notizerfassung zu erstellen.

Gehe wie folgt vor:

1. Über der Erstellungsleiste, klicke auf **KI nutzen**.
   Das **Feld „KI nutzen“** öffnet sich**.**
2. Klicken Sie auf **Formate** > **Notizen**.
   Das Eingabefeld öffnet sich.
3. Unter **Wo möchtest du anfangen?**,wähle eine der folgenden Optionen aus:
   - **Ein Text-Prompt**
     Befolge die Anweisungen auf dem Bildschirm, um deinen Prompt zu erstellen.
   - (Sticky Capture) **Ein Bild von Notizen**
     1. Klicken Sie auf **Datei auswählen**.
     2. Wähle eine PNG- oder JPG-Datei von Notizen auf deinem Computer aus.
4. Im Eingabefeld klicke auf den Pfeil oder drücke **ENTER** auf deiner Tastatur.
   Deine Notizen werden dem Miro-Board hinzugefügt.

## Notizen gruppieren

1. Wähle auf deinem Miro-Board eine Gruppe von Notizen aus.
   Das Kontextmenü wird über deiner Auswahl angezeigt.
2. Klicken Sie auf **Miro AI** > **Gruppieren.**
3. Wähle eine der folgenden Optionen:
   - **Nach Stichworten**
     Miro AI gruppiert deine Notizen nach Stichworten.
   - **Nach Meinung**
     Miro AI gruppiert deine Notizen nach Meinung.

:::tip
Du kannst optional jeden Cluster umbenennen.
:::

## Eine Gruppe von Notizen zusammenfassen

1. Wähle auf deinem Miro-Board eine Gruppe von Notizen aus.
   Ein Kontextmenü wird über deiner Auswahl angezeigt.
2. Klicke auf **Miro AI** > **Dokument** > **Zusammenfassung**.
   Miro AI erstellt eine Zusammenfassung basierend auf deinen ausgewählten Notizen.

## Ein Dokument basierend auf Notizen generieren

1. Wähle eine Gruppe von Notizen aus.
   Das Kontextmenü wird über deiner Auswahl angezeigt.
2. Klicke auf **Miro AI** > **Dokument**.
3. Wähle die Art des Dokuments aus, das du erstellen möchtest.
   Miro AI generiert dein Dokument.
