Erstelle im Handumdrehen eine User-Story-Map mit unserem schnellen, flexiblen Framework!  **User-Story-Mapping** ist eine interaktive Vorlage, die mithilfe der von Jeff Patton erfundenen Methode erstellt wurde. Dieses Tool erleichtert die Arbeit mit User-Storys in einem Umfeld agiler Entwicklung erheblich. Es ist eine bessere Version des Backlogs, die dir dabei hilft, dein Produkt zu erklären, Prioritäten zu setzen und Releases zu planen.

> **Verfügbar für:** Browser-Version, [Desktop-App](../../getting-started/apps-for-devices/05-desktop-app.md), [Tablet-App](../../getting-started/apps-for-devices/11-tablet-app.md), [mobile App](../../getting-started/apps-for-devices/08-mobile-app.md) (begrenzte Funktionalität)

### User-Story-Map hinzufügen

Um das Tool User-Story-Mapping in die Symbolleiste einzufügen, öffne die App, indem du auf die Pfeile klickst, und installiere **User-Story-Map**.

Screenshot_background_template__7__2_.jpg
Die App User-Story-Mapp hinzufügen

Ein neues Symbol erscheint bei deinen Apps. Ziehe es in die Symbolleiste, um schnell darauf zuzugreifen.

adding_USM_to_toolbar.gif
Das Symbol User-Story-Mapping in der Symbolleiste

Es gibt zwei einfache Möglichkeiten, um User-Story-Map zum Board hinzuzufügen:

- Ziehe das Symbol **User-Story-Mapping** aus der Symbolleiste und platziere es auf dem Board
- Wähle das Symbol **User-Story-Mapping** aus und klicke auf das Board

USM.jpg
User-Story-Mapping

Für das beste Erlebnis kannst du den Zoom im Board auf **100 %** einstellen, um eine User-Story-Map zu erstellen.

Verwende die folgenden [Abkürzungen](../working-on-the-board/06-shortcuts-and-hotkeys.md), um den Erstellungsprozess zu beschleunigen:

- **Return-Taste**, um eine ausgewählte Karte zu bearbeiten und neue zu erstellen
- **Tab-Taste**, um eine neue Aktivität, Aufgabe oder Story zu erstellen
- **Pfeiltasten**, um zwischen den Elementen der User-Story-Map zu wechseln
- **Escape-Taste**, um den Bearbeitungsmodus der Karte zu verlassen
- **Strg** + **← →↑↓** (*für Windows*)/**Cmd** +**← →↑↓** (*für Mac*), um Karten hinzuzufügen
- **Strg**+**C** und **Strg**+V (**für Windows**)*/Cmd* **+ C** und **Cmd+V** (*für Mac*), um eine Karte zu duplizieren
- **Entf-Taste**, um eine Karte zu löschen

### Karten bearbeiten

Wenn eine [Karte](../essential-tools/02-cards.md) aufgerollt ist, kannst du nur ihre Überschrift bearbeiten. Alle anderen Einstellungen sind im Kontextmenü verfügbar: die Farbe der Karte ändern, Tags hinzufügen, den Teammitgliedern Aufgaben zuweisen, Links und Daten hinzufügen. Klicke auf das Symbol **Erweitern**, um die Beschreibung der Karte hinzuzufügen oder anzuzeigen.

Weitere Informationen zur Bearbeitung von Karten findest du [in diesem nützlichen Artikel](../essential-tools/02-cards.md).

:::warning
Karten innerhalb der USM können weder [gesperrt](../working-on-the-board/17-locking-content-on-the-board.md)noch [gruppiert](../working-on-the-board/08-structuring-board-content.md#grouping) werden.
:::

### Version

Die Möglichkeit, Versionen hinzuzufügen, hilft dabei, die Iterationen der Produktentwicklung zu trennen. Es gibt zwei Möglichkeiten, um eine Version hinzuzufügen:

- In der Pop-up-Steuerung. Klicke auf „**+**“, um eine neue Version hinzuzufügen
- Füge eine Version oben oder unten über das Kontextmenü hinzu. Es kann auch nach unten verschoben, umbenannt oder gelöscht werden.

### Jira-Karten in der USM

Du kannst deine [Jira-Karten](../../integrations-apps/atlassian/03-jira-cards.md) ganz in das User-Story-Mapping-Framework einfügen, indem du sie per Drag-and-drop in die jeweiligen Versionen ziehst.

Außerdem kannst du [Karten in Jira-Karten umwandeln](../../integrations-apps/atlassian/03-jira-cards.md). Hinweis: Es ist nicht möglich, Karten in den USM-**Aufgaben** in Jira-Karten umzuwandeln.
