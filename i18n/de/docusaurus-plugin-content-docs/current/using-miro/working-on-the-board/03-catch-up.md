Die Funktion „Auf einen Blick“ gibt Nutzern einen KI-gestützten, effektiven Überblick über die Änderungen, die seit dem letzten Ansehen des Boards erfolgt sind.

> ***Verfügbar mit:** Allen Preisplänen*
> ***Erhältlich für:** Desktop-App, Desktop-Browser*
> ***Verfügbar für:** Alle Nutzer*

## Wichtige Funktionen

„Auf einen Blick“ umfasst die folgenden wichtigen Funktionen:

- **Visuelle Highlights**
  Wichtige Aktualisierungen sind auf dem Board hervorgehoben.
- **Schnelle Übersicht über Änderungen**
  So siehst du sofort, was sich geändert hat und wo du tätig werden musst.
- **Schritt-für-Schritt-Anleitung**
  Du siehst hier Schritt für Schritte alle Bearbeitungen und Änderungen, organisiert nach Abschnitten auf dem Board.

## So verwendest du „Auf einen Blick“

Gehe wie folgt vor, um „Auf einen Blick“ zu finden und zu nutzen.

1. Klicke auf das **Aktivität**-![icon-activity.svg](../../../../../../docs/using-miro/working-on-the-board/images/24093924443794_icon-activity.svg)-Symbol in der oberen rechten Symbolleiste.
   Das Aktivitätsmenü wird geöffnet.
2. Klicke auf die **„Auf einen Blick“**-Schaltfläche.
   Das Dialogfeld „Auf einen Blick“ öffnet sich auf dem Board.

   ![catch-up-new.png](../../../../../../docs/using-miro/working-on-the-board/images/27120802154642_catch-up-new.png)*Das Dialogfeld „Auf einen Blick“ auf dem Board*
3. **Letzte Änderungen** werden zusammen mit der Übersicht angezeigt.
4. Klicke auf eine der letzten Änderungen, um direkt zu diesem Feld zu gelangen.
5. Klicke **Details anzeigen**, um mit der Überprüfung der Änderungen zu beginnen.
6. Verwende die Schaltflächen **Pfeil** Weiter und Zurück im Dialogfeld, um durch „Auf einen Blick“ zu navigieren.
7. Klicke auf die numerischen Links, um zum entsprechenden Abschnitt auf dem Board zu gelangen.
8. Verwende das Dropdown-Menü, um einen anderen Zeitraum zum Ansehen auszuwählen: „Letzte Woche“, „Letzte zwei Wochen“ oder „Letzter Monat“.

### Alternative Vorgehensweise für den Zugriff auf „Auf einen Blick“

Gehe wie folgt vor, um auf eine andere Weise auf „Auf einen Blick“ zuzugreifen.

1. Klicke auf das **Hauptmenü** (![icon-main.svg](../../../../../../docs/using-miro/working-on-the-board/images/24005170925074_icon-main.svg)) Symbol.
   Das Hauptmenü wird geöffnet.
2. Fahre mit der Maus über die **Board**-Schaltfläche.
   Das Board-Untermenü öffnet sich.
3. Klicke auf die **Auf einen Blick**-Schaltfläche.
   Das Dialogfeld „Auf einen Blick“ wird geöffnet.

## Häufig gestellte Fragen (FAQ)

**Warum kann ich nicht auf „Auf einen Blick“ zugreifen?**

„Auf einen Blick“ ist nur für Nutzer mit aktivierter Miro AI verfügbar. Dein Admin muss Miro AI aktiviert haben, damit du Zugriff auf „Auf einen Blick“ hast. Anleitungen dazu findest du hier: [Feature activation](../../enterprise-administration/managing-enterprise-teams-and-content/06-feature-activation.md).
