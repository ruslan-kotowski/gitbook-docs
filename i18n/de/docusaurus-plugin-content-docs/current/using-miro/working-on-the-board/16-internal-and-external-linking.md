Erweitere deine Board-Inhalte, indem du ein beliebiges Objekt mit einer externen Website oder einem anderen Objekt auf dem Board verknüpfst.

Mitder Option **Verlinken mit** kannst du:

- Interaktive Prototypen erstellen
- Die Navigation auf dem Board vereinfachen
- Links zu Referenzen und nützliche Quellen hinzufügen
- Verlinke [Notizen](../essential-tools/14-sticky-notes.md) oder [Karten](../essential-tools/02-cards.md) mit Aufgabenverfolgungslinks.

## Objekte verknüpfen

1. Wähle das Objekt aus, zu dem du verlinken möchtest, und klicke dann im Kontextmenü auf das Symbol mit den **drei Punkten** (**...**)
2. Wähle im Kontextmenü **Link kopieren**
3. Wähle ein Objekt aus, das du verlinken möchtest **von**, und klicke im Kontextmenü auf das **Symbol mit den drei Punkten** (**...**)
4. Wähle **Link zu** oder verwende **Option +** **Cmd + K** (*für Mac*) oder **Alt +** **Cmd + K** (*für Windows*)
5. Füge die URL ein oder klicke auf ein anderes Objekt auf dem Board, das du verlinken möchtest

:::tip
Verknüpfe Objekte schnell mit der Befehlspalette. Klicke auf das Objekt, tippe **Befehlstaste + K** und **der Link zum Objekt** wird als erster Punkt im Menü angezeigt. Füge einfach deinen Link in das Textfeld ein und tippe auf **Enter**.
:::

Bitte beachte, dass ein Objekt auf dem Board mit nur *einer* Website oder einem Miro-Objekt verlinkt werden kann. Du kannst Links zu externen Websites, anderen Miro-Boards oder bestimmten Objekten auf Boards erstellen.
Klicke einfach auf das Link-Symbol, um zur verlinkten URL zu gelangen.

1. Klicke auf die drei Punkte im Kontextmenü.
2. Wähle **Link bearbeiten**.![edit_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057155218_edit%20link.jpg)*Die Option zum Bearbeiten eines Links*
3. Ändere den Link oder klicke auf **Link löschen** im Pop-up.![change_or_delete_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057156242_change%20or%20delete%20link.jpg)*Die Option zum Löschen eines Links*

## Links zu Objekten auf dem Board

Du kannst einen direkten Link zu jedem Objekt auf dem Board erhalten ([Rahmen](../essential-tools/07-frames.md), Bilder, [Formen](../essential-tools/11-shapes.md), usw.). Teile diesen Link mit deinen Mitwirkenden, um ihre Aufmerksamkeit auf den genauen Bereich auf dem Board zu lenken.

1. Klicke auf das Objekt, das du verlinken möchtest, um das Kontextmenü anzuzeigen.
2. Klicke auf das Symbol **mit den drei Punkten** (**...**).
3. Wähle **Link kopieren**.![copy_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057158162_copy%20link.jpg)*Den Link zu einem Rahmen kopieren*

Wenn das verknüpfte Objekt gelöscht wird, sehen Nutzer, die dem Link folgen, die Nachricht „*Leider wurde das verknüpfte Element von diesem Board gelöscht*“. Es ist möglich, [gelöschte Inhalte wiederherzustellen](18-restoring-board-content.md) über die Aktivitätenliste.

## Links auf dem Board einfügen

Mit diesen Tastenkombinationen kannst du einen Link in dein Board einfügen: **Strg + V** (*für Windows*) oder **Cmd + V** (*für Mac*). Der Link zeigt eine Vorschau.

*![link_to_help_center.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057159186_link%20to%20help%20center.jpg)
Der Link zum Miro-Hilfecenter auf einem Board*

Um einen Link ohne Vorschau auf dem Board einzufügen, verwende das [Text-Tool](../essential-tools/16-text.md) und füge den Link in das Textfeld ein.

## Text verlinken

Wenn du mit Objekten arbeitest, die Text enthalten, klicke auf das **Link-Symbol** im Kontextmenü, um einen Link in den Text einzufügen.

![insert_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016043786642_insert%20link.jpg)
 *Die Option zum Einfügen eines Links*

Du kannst auch den Text auswählen und **Strg + V** (*für Windows*)/**Cmd + V** (*für Mac*) verwenden, um einen Link einzufügen.

![insert_link.gif](../../../../../../docs/using-miro/working-on-the-board/images/21016057161490_insert%20link.gif)
*Einen Link in eine Textzeile einfügen*

:::note
Wenn du zwei Objekte auf einem Board über die Option **Link einfügen** verknüpfstund dann das Board duplizierst, führt der Link auf der Board-Kopie zum Original-Board.</span> Wenn du jedoch zwei Objekte auf dem Board über die Option "Verlinken mit" verknüpfst und dann das Board duplizierst, bleibt der Link auf dem kopierten Board intern (er führt zum Objekt auf demselben Board).
:::

## Häufig gestellte Fragen

Kann ich mein Board mit einem anderen Miro-Board verlinken?

Ja, kopiere den Link zum Board (oder zu einem bestimmten Objekt auf dem Board) und füge den Link auf dem Original-Board ein (oder füge den Link zu einem Objekt hinzu oder zu den [Notizen](../essential-tools/17-visual-notes.md)). Du kannst auch [Miro-Boards einbetten](../import-and-export/export/02-embed-a-miro-board.md).

Wie kann ich einen Link in mein Board kopieren?

Öffne den [Freigabedialog](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) des Boards und klicke auf **Board-Link kopieren**. Du kannst den Link auch einfach aus der Adressleiste des Browsers kopieren. Wenn du ein Board in der [Desktop-App](../../getting-started/apps-for-devices/05-desktop-app.md) geöffnet hast, klicke auf **Datei > Board-Link kopieren**.

Wie erstelle ich einen Link zu einem bestimmten Bereich auf meinem Board?

Du kannst einen [Rahmen](../essential-tools/07-frames.md) erstellen, der den Bereich abdeckt, und einen Link zum Rahmen kopieren. Beachte, dass die [Nutzer, die Zugriff auf dein Board haben](../sharing-boards/05-who-has-access-to-my-board.md), auch in anderen Bereichen des Boards navigieren und diese sehen können.

Kann ich alle Links auf meinem Board auf einmal entfernen?

Du kannst alle Links, die auf dem Canvas eingefügt wurden, mit mehreren Klicks entfernen. [Wähle alle Objekte aus](10-working-with-objects.md), wähle **Filter** im Kontextmenü, wähle **Vorschau** aus und lösche die ausgewählten Verknüpfungsobjekte.
![filter_perviews.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057163410_filter%20perviews.jpg)
*Vorschau in ausgewählten Objekten filtern*

Kann ich auf lokale Dateien auf meinem Computer verlinken?

Nein. Aus Sicherheitsgründen solltest du deine Dateien in einen cloudbasierten Dienst hochladen und sie von dort aus verlinken.

Erkennt Miro Hyperlinks von E-Mail-Adressen als „mailto:“-Links?

Derzeit wird dies nicht unterstützt.
