Importiere Dateien, Medien, Symbole und stelle alle visuellen Informationen auf einem Board dar!

### Was kann dem Board hinzugefügt werden?

- Dokumente
- Tabellenkalkulationen
- Bilder
- Präsentationen
- Webseiten und Links mit Vorschaufunktion
- [Symbole](../essential-tools/08-images-and-icons.md)
- Du kannst auch [Videos und andere Mediendateien einbetten](../../integrations-apps/integrations-basics/03-embed-integrations-on-a-miro-board.md)

### Wie kann man Inhalte schnell hinzufügen?

- Einfach Dateien von deinem Desktop auf ein Board per Drag & Drop ziehen. Sieh dir die [Liste der unterstützten Dateiformate](../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md) an.
- Füge Texte und Bilder aus der Zwischenablage hinzu (verwende **Strg + C** und **Strg + V** *für Windows*, **Cmd + C** und **Cmd + V** *für Mac*)
- [Hochladen von deinem Gerät](../import-and-export/import/05-uploading-files-to-boards.md) (Du kannst xls, doc, ppt, svg, jpg und andere Formate hochladen, siehe die vollständige Liste [in diesem Artikel](../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md))
- Hochladen über URL
- Lade Dokumente, Tabellenkalkulationen oder Bilder aus [Google Drive](../../integrations-apps/google/05-google-drive.md), [Dropbox](../../integrations-apps/more-integrations/06-dropbox.md), [Box](../../integrations-apps/more-integrations/05-box-legacy.md), [Adobe XD](https://help.miro.com/hc/articles/360016621780) oder [OneDrive](../../integrations-apps/microsoft/06-onedrive.md) hoch

  > ✏️ Um auf die oben aufgeführten Optionen zuzugreifen, klicke auf die **Hochladen**-Schaltfläche auf der Symbolleiste für die Zusammenarbeit
- Verwende Symbole und Bilder von [Fontawesome](../essential-tools/08-images-and-icons.md), [Unsplash](../essential-tools/08-images-and-icons.md) und [Google Image](../../integrations-apps/google/06-google-images.md)
- Du kannst Videos, Audio und andere Medien mithilfe von iFrame-Code einbetten. [Mehr erfahren](../../integrations-apps/integrations-basics/03-embed-integrations-on-a-miro-board.md)
  ![embed_iframe_in_Miro.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21020253797266_embed%20iframe%20in%20Miro.jpg)
  *Verwende iFrame-Codes zum Einbetten von Medien in Miro-Boards*
- Füge Inhalte aus Tabellen ein (verwende **Strg+C** und **Strg+V** *für Windows*, **Cmd+C** und **Cmd+V** *für Mac*) als Miro [Tabellen](../advanced-tools/05-grid.md) oder [Notizen](../essential-tools/14-sticky-notes.md)
  ![cells_as_sticky_notes_in_Miro.gif](../../../../../../docs/using-miro/working-on-the-board/images/21020264789266_cells%20as%20sticky%20notes%20in%20Miro.gif)
  *Einfügen von Notizen aus einer Tabelle*

## FAQ

**Wie kann ich ein Bild in mein Board importieren?**

Du kannst es über das [**Hochladen**](../import-and-export/import/05-uploading-files-to-boards.md) von deinem Gerät hochladen, es aus der Zwischenablage einfügen (verwende **Strg + C** und **Strg + V** *für Windows*, **Cmd + C** und **Cmd + V** *für Mac*) oder es einfach von deinem Gerät auf das Board ziehen.

**Wie kann ich meine Inhalte auf dem Board am besten organisieren?**

In diesem Artikel findest du weitere Informationen: [Strukturierung von Board-Inhalten](08-structuring-board-content.md).

**Kann ich von meinem Gerät aus ein Video auf mein Board hochladen?**

Nein, aber du kannst [das Video einbetten](../../integrations-apps/integrations-basics/03-embed-integrations-on-a-miro-board.md): Lade das Video auf eine Videoplattform (*YouTube*, *Vimeo* usw.) hoch und füge den Videolink einfach mit den Tastenkombinationen **Strg + C** und **Strg + V** *für Windows*, **Cmd + C** und **Cmd + V** *für Mac* in ein Board ein.

**Wie kann ich Bilder auf meinem Board ändern?**

Du kannst hochgeladene Bilder verschieben, [ersetzen](21-work-smarter-not-harder.md), die Größe ändern, [zuschneiden](21-work-smarter-not-harder.md) und [drehen](21-work-smarter-not-harder.md).

**Kann ich Wireframes und Formen zu meinem Board hinzufügen?**

Ja, hier erfährst du mehr: [Prototypen Bibliothek](../miroverse/prototyping/02-prototyping-library.md), [Formen](../essential-tools/11-shapes.md). Die Liste weiterer Miro-Werkzeuge findest du auf [dieser Seite](../tools).

**Kann ich Daten aus einer Tabellenkalkulation in ein Miro-Board importieren?**

Ja, Tabellenkalkulationen können im Ansichtsmodus importiert werden oder zur Erstellung einer Tabelle oder einem Raster. Weitere Informationen: [Tabellen](../formats/14-tables.md) oder [Raster](../advanced-tools/05-grid.md).

**Ich kann keine Inhalte auf mein Board hochladen. Was kann ich tun?**

Bitte stelle sicher, dass die Dateigröße und das Format unterstützt werden – siehe [diesen Leitfaden](../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md).
