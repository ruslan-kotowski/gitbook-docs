Aktivitäten sind das Herzstück von Miro Engage, einem Tool für Meetings und Workshops, mit dem du die Teilnehmenden aktiv einbindest und ihre Insights im großen Umfang festhältst. Aktivitäten ermöglichen es Moderatoren, interaktive Übungen (wie Multiple-Choice oder offene Fragen) direkt von ihren Miro-Boards aus durchzuführen.

Nutzer können direkt auf dem Board teilnehmen oder per Mobilgerät beitreten, indem sie einen QR-Code scannen oder einen Code eingeben (kein Konto oder App-Download erforderlich).

Antworten werden in Echtzeit visualisiert, wodurch deine Workshops und Präsentationen inklusiver und dynamischer werden.

Aktivitäten funktionieren am besten mit Miro-Präsentationen oder können überall auf deinem Board platziert werden. Sie können auch mit KI-Flows und KI-Kollege verwendet werden.

:::note
Aktivitäten sind während der Betaversion kostenlos.
:::

## Aktivitäten auf den Canvas setzen

Aktivitäten können direkt auf den Canvas hinzugefügt werden. So fügst du sie hinzu:

1. Klicke auf das Symbol **Tools, Medien und Integrationen** oder das Symbol **Rahmen** in der Symbolleiste Erstellen.
2. Suche nach **Aktivitäten** und wähle diese aus oder, wenn du über das Menü Rahmen zugreifst, wähle **Aktivitäten** aus.
3. Präsentationen werden dem Canvas mit einer Folie „Join Instructions“ und einer zweiten Folie hinzugefügt, auf der du auswählen kannst, welche Aktivität du hinzufügen möchtest.
4. Wähle auf der zweiten Folie die Aktivität aus, die du hinzufügen möchtest.
5. Um weitere Aktivitätsfolien innerhalb des Rahmens hinzuzufügen, klicke auf das Symbol **Vorlage hinzufügen** neben einer vorhandenen Folie und wähle dann den Tab **Aktivitäten** aus.
6. Wähle im **Aktivitäten**-Tab die Aktivität aus, die du hinzufügen möchtest.

## Aktivitäten zu Folien hinzufügens

1. Erstelle eine neue Miro-Präsentation auf deinem Board oder öffne ein bestehendes Board mit den Folien, die du verwenden möchtest. **Mehr Informationen:** [Miro-Präsentationen](../formats/13-miro-slides.md).
2. Klicke auf das **Vorlage hinzufügen**-Symbol neben einer bestehenden Folie, um ein Dialogfeld zu öffnen, in dem du neue Folien hinzufügen kannst.
3. Wechsle im Dialogfeld zum **Aktivitäten**-Tab.
4. Wähle eine der Optionen aus:
   1. **Beitrittsanleitung-Folie:** Zeigt QR- und Sitzungs-Codes an, damit Teilnehmer beitreten können.
   2. **Multiple-Choice-Umfrage:** Erstelle Abstimmungsfragen mit mehreren Antwortmöglichkeiten.
   3. **Offene Fragen:** Sammle schriftliche Antworten von deinem Publikum.
   4. **Wortwolke:** Visualisiere die am häufigsten gesammelten Antworten.
5. Füge den passenden Inhalt zu deiner neuen Aktivitäten-Folie hinzu.

## Einzelne Aktivitäten auf den Canvas setzen

Aktivitäten funktionieren auch auf dem Canvas. So fügst du sie hinzu:

1. Klicke auf das **Symbol für Tools, Medien und Integrationen**.
2. Suche und wähle entweder **Mehrfachauswahl**, **Offene Fragen** oder **Wordcloud**. Du kannst auch nach Aktivitäten suchen, um die verfügbaren Optionen zu sehen.
3. Klicke auf das Board, wo du deine Aktivität platzieren möchtest.
4. Trage die gewünschten Inhalte in die neue Aktivität ein.

## Verfügbare Aktivitäten

### **Anleitung zum Beitreten**

Die Anleitung zum Beitreten ist verfügbar, wenn du eine neue Folie hinzufügst. Sie enthält einen QR-Code und einen Link mit einem Code, der es Nutzern auf mobilen Geräten ermöglicht, den Aktivitäten beizutreten, während du präsentierst.

### **Multiple-Choice**

Die Aktivität „Multiple-Choice“ ermöglicht es dir, eine Umfrage durchzuführen, um Meinungen einzuholen und zu einem Konsens über ein Thema zu gelangen.

Nachdem du eine Multiple-Choice-Aktivität hinzugefügt hast:

1. Gib die Umfragefrage oder das Thema in das entsprechende Feld ein.
2. Gib deine Optionen in die **Optionen**-Felder ein. Füge mit der **Option hinzufügen**-Schaltfläche am Ende der Liste weitere Optionen hinzu.
3. Klicke auf **Bearbeitung beenden**, um die Folie abzuschließen.

**Einstellungen**

- Ergebnisse als % anzeigen: Zeigt den Anteil der Stimmen, anstatt der Anzahl der Stimmen.
- Anonyme Stimmen: Verbirgt den Namen und Avatar bei abgegebenen Stimmen für anonyme Eingaben.
- Mehrfachstimmen zulassen: Ermöglicht es dir, die Anzahl der Stimmen pro Person für die Auswahl mehrerer Optionen festzulegen. Der Maximalwert ist 20.

Wenn Nutzer auf mobilen Geräten abstimmen, können sie vor dem Klick auf **Absenden** Kästchen an- und abwählen. Auf dem Canvas können Teilnehmer abstimmen (oder ihre Stimme ändern), bis die Aktivität beendet wird.

### **Offene Frage**

Diese Aktivität ermöglicht es dir, freie Textantworten zu sammeln, um Gedanken zu einem Thema mitzuteilen.

Nach dem Hinzufügen einer offenen Frage:

1. Gib den Text in das Feld **Frage eingeben** ein.
2. Klicke auf **Bearbeitung beenden**, um die Folie mit der offenen Frage zum Canvas hinzuzufügen.

**Einstellungen**

- Anonyme Antworten: Verbirgt den Namen und Avatar bei abgegebenen Antworten für anonyme Eingaben.
- Antworten pro Person begrenzen: Ermöglicht dir, die Anzahl der Antworten pro Person festzulegen. Standardmäßig gibt es keine Begrenzung.

Wenn die Aktivität gestartet wird, können Nutzer ihre Antworten von einem Gerät oder auf dem Canvas hinzufügen. Übermittelte Antworten können nicht geändert werden.

### **Wortwolke**

Die Wortwolken-Aktivität ermöglicht es dir, die beliebtesten Gedanken zu einem Thema zu visualisieren. Häufig verwendete Wörter erscheinen innerhalb der Wortwolke größer.

Nach dem Hinzufügen einer Wortwolken-Aktivität:

1. Trage den Text im Feld **Gib deine Frage ein** ein.
2. Klicke auf **Bearbeitung beenden**, um die Wortwolken-Folie zum Canvas hinzuzufügen.

**Einstellungen**

- Anonyme Antworten: Verbirgt den Namen und Avatar bei abgegebenen Antworten für anonyme Eingaben.
- Antworten pro Person begrenzen: Ermöglicht dir, die Anzahl der Antworten pro Person festzulegen. Standardmäßig gibt es keine Begrenzung.

## Präsentieren mit Aktivitäten

Klicke auf **Präsentation starten** im Kontextmenü der Miro-Präsentation.

Wenn du die Folie mit der **Anleitung zum Beitreten** erreichst, können Teilnehmer von jedem Gerät (Handy, Laptop, Tablet) aus beitreten, indem sie:

1. den QR-Code mit ihrer Handykamera scannen.
2. miro.com/join besuchen und den Sitzungs-Code eingeben. Aus Sicherheitsgründen ändert sich der 6-stellige Beitrittscode alle 10 Minuten.

Du navigierst durch die Folien wie bei einer normalen Präsentation. Die Teilnehmer sehen und interagieren mit den Aktivitäten, während du fortschreitest.

:::note
Wenn eine Folie ohne Aktivität präsentiert wird, sehen die Teilnehmer einen Bildschirm mit der Aufschrift **Warten auf Aktivität**.
:::

## An Aktivitäten teilnehmen

### Von einem mobilen Gerät aus

Du kannst an Aktivitäten teilnehmen, indem du entweder den vom Moderator freigegebenen **QR-Code** scannst oder den 6-stelligen Code auf [miro.com/join](http://miro.com/join) eingibst. Du benötigst kein Miro-Konto, um teilzunehmen.

Beim Beitritt wirst du aufgefordert, deinen Namen einzugeben.

Wenn der Moderator keine Aktivität präsentiert, siehst du eine Seite mit der Aufschrift **Warten auf die nächste Aktivität**.

Wenn der Moderator eine Aktivität startet, wird die Seite aktualisiert, sodass du teilnehmen kannst.

Du kannst deinen Namen und deine Spracheinstellungen auf verbundenen Geräten (via [miro.com/join](http://miro.com/join)) ändern, indem du auf das Avatar-Symbol oben rechts klickst und die Profileinstellungen anpasst.

### Auf dem Board

Teilnehmer können direkt auf dem Board an Aktivitäten teilnehmen. Präsentatoren sollten sicherstellen, dass die Teilnehmer vor dem Start von Aktivitäten zum Board eingeladen wurden.

## Aktivitäten nutzen

Während der Präsentation können Teilnehmer Aktivitäten beitreten, indem sie den Beitrittslink und den Code verwenden, die in der oberen Leiste auf der Aktivitätenfolie sichtbar sind. Der QR-Code kann ebenfalls angezeigt werden, um es mobilen Nutzern zu erleichtern, beizutreten, indem sie einfach auf das QR-Code-Symbol klicken.

![activities.png](../../../../../../docs/using-miro/facilitation-tools/images/31128769665682_activities.png)

*Du kannst Aktivitäten über die Symbolleiste oben auf einer Folie beitreten*

Aktivitäten können durch Klicken auf das **Aktivität beenden**-Symbol im Kontextmenü geschlossen werden. Sie können erneut gestartet werden, indem auf das **Aktivität starten**-Symbol geklickt wird.

Aktivitäten können zurückgesetzt werden, nachdem sie Antworten erhalten haben, indem man die Aktivität über die Kontext-Symbolleiste stoppt und dann auf das **Zurücksetzen**-Symbol klickt. Dadurch werden alle Antworten entfernt, aber die Konfiguration der Aktivität (wie Titel und Optionen) sowie die Einstellungen werden beibehalten.

Sobald gestoppt, können Aktivitäten bearbeitet werden, indem man auf das **Bearbeiten**-Symbol in der Kontext-Symbolleiste klickt. Wenn die Aktivität Antworten enthält, muss sie zurückgesetzt werden, um Änderungen vorzunehmen.

### **Aktivitätsantworten exportieren****en**

Wähle die Präsentationen aus, von denen du Teilnehmerbeiträge sammeln möchtest, und klicke dann auf das **Exportieren**-Symbol im Kontextmenü. Antworten können in Notizen oder in eine Tabelle exportiert werden.
