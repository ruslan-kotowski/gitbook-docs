Board-Eigentümer und Miteigentümer können die Nutzung von Zusammenarbeitstools im Board kontrollieren, indem sie festlegen, wer innerhalb [eine](16-timer.md)s [Boards Timer](19-voting.md), Abs[timmungen](18-video-chat.md) und Videochats star[ten sowie die Aufmerksam](04-attention-management.md)keitssteuerung verwenden darf. So kannst du festlegen, welche Personengruppe auf die Moderationstools für Meetings zugreifen kann. Obwohl nur ausgewählte Personen die Zusammenarbeitstools starten können, können auch andere Board-Teilnehmende diese verwenden. Board-Eigentümer können z. B. eine Abstimmung beginnen, damit alle Personen im Meeting ihre Meinung abgeben können.

Öffne ein Board-**Freigabe**menü, gehe zu den **Freigabeeinstellungen**, wechsle zu **Berechtigungen** und wähle eine Option im Dropdown-Menü unter **Wer kann Tools für die Zusammenarbeit starten**.  Du kannst dies allen Bearbeitern (außer Personen, die das Board über einen Link besuchen) oder nur Board-Eigentümer und Miteigentümer gestatten.
