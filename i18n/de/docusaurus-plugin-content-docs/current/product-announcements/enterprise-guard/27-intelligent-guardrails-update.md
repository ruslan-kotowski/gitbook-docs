Admins haben jetzt zwei Möglichkeiten, um intelligente Vorgaben in ihrer Organisation einzuführen:

- Standardmodus: Die Vorgaben beeinflussen keine aktiven Optionen zur Board-Freigabe und wirken sich daher nur minimal auf die laufende Zusammenarbeit aus.
- Strikter Modus: Wenn „Vorgaben im strikten Modus anwenden“ aktiviert ist, setzen die Vorgaben alle bestehenden Freigabeoptionen außer Kraft. Dies kann dazu führen, dass einige Nutzer den Zugriff auf das Board sofort verlieren.
