Für Organisationen, die Microsoft Entra ID (ehemals Azure AD) als ihren Identitätsanbieter nutzen, leitet Enterprise Guard sicher KI-Prompts und -Antworten an Microsoft Purview Data Security Posture Management (DSPM) für KI weiter. Sicherheits- und Compliance-Teams können dann die Nutzung von generativer KI von einer einzigen vertrauenswürdigen Plattform aus überwachen, prüfen und steuern, was den betrieblichen Aufwand reduziert, Risiken wie Datenlecks und Missbrauch mindert und die KI-Governance auf Unternehmensniveau von Miro stärkt.
