Custom Labels in der **Datenerkennung** unterstützen jetzt **Prototyp-Bildschirme** als Bedingungstyp. Admins können Labels so konfigurieren, dass sie automatisch angewendet werden, wenn auf einem Board Prototyp-Bildschirme erkannt werden, wodurch die Datenerkennung auch auf Prototyp-Inhalte ausgeweitet wird, neben anderen unterstützten Bedingungstypen wie Jira-Karten, Azure-Karten und Codeblocks.

Mit diesem Update können Admins:

- Prototyp-Bildschirme einschließen, wenn sie Bedingungen für Custom Labels definieren.
- Automatisch Boards identifizieren, die Prototyp-Inhalte enthalten.
- Die Abdeckung sensibler oder geschäftskritischer Informationen über mehr Board-Elemente verbessern.

Weitere Informationen findest du in unserer Dokumentation zu [Custom labels](../../enterprise-administration/canvas-25-admin-features/data-discovery/08-custom-business-sensitive-data-discovery-overview.md).
