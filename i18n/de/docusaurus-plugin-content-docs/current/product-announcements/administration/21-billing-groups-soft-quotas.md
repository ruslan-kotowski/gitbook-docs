Admins können jetzt optional eine weiche Kontingentgrenze für die Anzahl der Lizenzen festlegen, die einer Abrechnungsgruppe zugewiesen werden. Mit weichen Kontingentgrenzen lassen sich die Lizenzzuweisungen innerhalb von Abrechnungsgruppen flexibel und informiert verwalten. Admins erhalten dadurch die Daten, die sie brauchen, um fundierte Entscheidungen zu treffen.
