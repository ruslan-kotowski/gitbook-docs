Wir führen zusätzliche Endpunkte für die Board Export API ein, um den Export von Boards effizienter zu verwalten. Du kannst Exportaufträge in deiner Organisation auflisten, Aufgaben für einen bestimmten Exportauftrag ansehen, Download-Links für Exportaufgaben abrufen und Exportaufträge, die nicht mehr benötigt werden, stornieren. Diese Updates erleichtern es, deine Export-Workflows programmgesteuert zu überwachen, zu steuern und zu automatisieren.
