Mit Benutzergruppen können Admins Gruppen von Nutzern erstellen, die mit ihrem Identitätsanbieter (IDP) synchronisiert werden können. Admins können Gruppen Teams zuweisen und ihnen Zugriff auf bestimmte Inhalte gewähren.

Teammitglieder können Benutzergruppen nutzen, um Boards mit anderen Gruppen zu teilen, damit nur eine bestimmte Gruppe von Nutzern Zugriff auf Inhalte erhalten kann. Anstatt Boards mit neuen Nutzern erneut freizugeben, können Nutzer der entsprechenden Benutzergruppe hinzugefügt werden.

## Wichtige Funktionen

- **User Groups erstellen und verwalten**
  In der Admin-Konsole können Unternehmens-Admins User Groups erstellen, überprüfen, bearbeiten, Mitglieder hinzufügen und löschen. Weitere Informationen findest du in [User Groups](../../enterprise-administration/user-management/08-user-groups.md).
- **Boards und Bereiche mit User Groups teilen**
  Teammitglieder können [jedes Board oder jeden Bereich mit einer User Group teilen](../../enterprise-administration/user-management/08-user-groups.md) und Berechtigungen festlegen.
- **User Groups per API verwalten**
  User Groups APIs ermöglichen es Admins, User Groups programmatisch zu erstellen, zu bearbeiten und zu entfernen.
- **User-Gruppen in Kommentaren erwähnen**
  Erwähne eine User-Gruppe auf einem Board. Alle Nutzer in der Gruppe erhalten eine Benachrichtigung.
- **Mitglieder von User-Gruppen auf Boards einsehen**
  Sieh und überprüfe alle Mitglieder einer User-Gruppe, wenn du eine Gruppe auf einem Board erwähnst.
