La Calculadora de Costos de AWS proporciona una forma sencilla de estimar los costos de los servicios de AWS directamente en tus tableros de Miro. Es especialmente útil para gestores de proyectos y profesionales informáticos, ya que agiliza las estimaciones de costos para planificar con eficacia.

:::note
(Enterprise) La Calculadora de Costos de AWS está disponible solo con licencias Avanzadas. Para más información, consulta [Entender las licencias Enterprise](../../plans-billing/miro-plans/05-understanding-enterprise-licenses.md).
:::

## Cómo configurar y utilizar la Calculadora de Costos de AWS

1. Instala la [AWS Cost Calculator](https://miro.com/marketplace/aws-cost-calculator/) desde el Marketplace de Miro.
2. Abre el tablero de Miro en el que quieras calcular tus costos de AWS.
3. Haz clic en **Herramientas, Medios e Integraciones** (**+**) en la barra de herramientas de [creación](../../getting-started/start-here/your-first-board/05-toolbars.md) y busca ‘AWS Cost Calculator’.
4. Selecciona **AWS Cost Calculator**. Se abrirá el panel Calculadora de costos de AWS en la parte izquierda del tablero.
5. Haz clic y arrastra para seleccionar todos los iconos AWS de tu diagrama. La calculadora de costos rellenará automáticamente todos los iconos AWS de tu diagrama.
6. Para cada icono AWS, haz clic en **Editar** para especificar detalles como Región y Tipo de almacenamiento, y luego haz clic en **Guardar selección de servicio**.
7. Después de editar todos los iconos, haz clic en **Calcular** para ver tus costos totales de AWS.
8. Para comprender mejor tus costos, utiliza las pestañas superiores y el menú desplegable para filtrar los costos por intervalos de tiempo (**Hora**, **Mes**, **Año**) y **Región**.

## Consejos para calcular con precisión

- **Sé específico**: cuantos más detalles proporciones, más precisa será tu estimación de costos.
- **Revisa regularmente**: los precios de AWS pueden cambiar. Verifica y actualiza regularmente tus estimaciones, y confirma siempre los costos reales directamente con AWS.

## Aporta tu opinión sobre la Calculadora de Costos de AWS

Tus comentarios son cruciales para que podamos mejorar la Calculadora de costos de AWS y hacerla más útil para tus necesidades.

1. Abre el panel **AWS Cost Calculator** en tu tablero de Miro.
2. Haz clic en el icono de comentarios situado en la parte inferior derecha del panel para valorar tu experiencia.
3. En el campo de texto abierto, añade cualquier comentario adicional, incluyendo qué iconos de AWS te gustaría ver en futuras actualizaciones.
