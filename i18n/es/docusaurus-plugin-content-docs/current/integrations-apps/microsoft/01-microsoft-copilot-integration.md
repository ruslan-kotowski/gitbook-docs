Como admin de empresa, puedes habilitar y aprobar la integración de Microsoft Copilot para los equipos en tu organización en Miro.

La integración de Microsoft Copilot te permite conectar Copilot como un recurso de [Conocimiento](../../using-miro/miro-ai/09-knowledge.md) en Miro. Por ejemplo, conecta Microsoft Copilot para proporcionar información de la empresa a compañeros de IA o flujos.

También puedes conectar Copilot al chat independiente en Miro.

:::note
Para obtener información sobre el uso de un agente de Miro con Copilot en Microsoft Teams, consulta [agente de Miro para Copilot](microsoft-teams/03-miro-agent-for-copilot.md).
:::

Cada miembro del equipo debe tener una licencia de Copilot para usar la integración.

Para habilitar la integración de Microsoft Copilot, sigue estos pasos:

1. Como admin de empresa, ve a **Consola de administración**.
2. Ve a **Aplicaciones & integraciones** > **Aplicaciones** > **Agregar aplicaciones**.
3. Busca y encuentra **Microsoft Copilot**.
   Si no puedes encontrar la aplicación por nombre, entonces busca por el siguiente ID de cliente: `5531308904693541040`.
4. En el perfil de la aplicación, selecciona si deseas agregar la aplicación para **todos los equipos** o seleccionar **equipos específicos**.
5. (Opcional) Revisa la página de permisos. La aplicación Microsoft Copilot para Miro es desarrollada y mantenida por Miro, y no requiere permisos especiales.
6. Haz clic en **Añadir**.

:::note
Cuando un miembro del equipo conecta Microsoft Copilot como un recurso de conocimiento por primera vez, se le pide autenticarse. El miembro del equipo debe contar con una licencia de Copilot.
:::
