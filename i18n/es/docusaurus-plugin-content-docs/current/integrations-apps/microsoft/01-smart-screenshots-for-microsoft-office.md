Las capturas inteligentes te permiten pegar tableros y widgets de Miro directamente como imágenes en Microsoft Word, PowerPoint y Excel, con funcionalidad mejorada para mantener el contenido sincronizado.

## Capturas inteligentes de Miro

:::note
Es posible que el administrador de Microsoft deba instalar el [complemento de Miro para Microsoft Office](https://miro.com/marketplace/microsoft-office/) para tu organización o equipo. Si no está disponible, consúltalo con tu administrador.
:::

La integración del panel lateral de Miro te permite insertar contenido de los tableros de Miro directamente en archivos de Microsoft Word, PowerPoint y Excel sin salir de tu documento. Esta función proporciona acceso sin interrupciones a tus tableros de Miro y te permite insertar contenido visual con funcionalidad mejorada.

## Panel lateral de Miro

El panel lateral de Miro en Microsoft Word, PowerPoint y Excel incluye las siguientes capacidades:

- **Acceso directo al tablero:** Accede a tus tableros de Miro directamente desde Microsoft Word, PowerPoint y Excel, sin cambiar de aplicación.
- **Selección de tableros:** Elige entre los tableros de Miro disponibles usando el botón "Seleccionar tablero de Miro para insertar".
- **Vista previa interactiva:** Ve y selecciona contenido específico de tu tablero de Miro antes de insertarlo.
- **Colocación precisa:** Inserta contenido exactamente donde está posicionado tu cursor en el documento.
- **Funcionalidad inteligente:** El contenido insertado mantiene la conexión con el tablero original de Miro.

## Cómo usar el panel lateral de Miro

1. En tu archivo de Microsoft Word, PowerPoint y Excel, coloca el cursor en el documento donde quieras insertar el contenido de Miro.
2. Abre el panel lateral derecho haciendo clic en el **icono de integración de Miro**.
3. Haz clic en **Seleccionar tablero de Miro para insertar** para elegir entre tus tableros de Miro disponibles.
4. Navega y selecciona el área, marco o contenido específico que deseas insertar desde la vista previa del tablero.
5. Usa cualquier opción del menú desplegable disponible para elegir diferentes configuraciones de vista o selecciones.
6. Haz clic en **Confirmar** para insertar el contenido en la posición de tu cursor.

El contenido insertado aparecerá como una captura de pantalla en tu documento con una conexión de chip inteligente al tablero original de Miro.

:::note
El panel lateral de Miro requiere que el [complemento de Miro Microsoft Office](https://miro.com/marketplace/microsoft-office/) esté instalado. La función funciona con Microsoft Word, PowerPoint y Excel.
:::

## Gestionar el complemento como administrador

Revisa estos puntos si eres un administrador de Microsoft que gestiona el complemento de Miro:

- El complemento de Microsoft Office se puede instalar o eliminar solo desde Microsoft.
- Si deseas restringir el acceso a las capturas inteligentes de Microsoft Office, esto debe hacerse desde Microsoft; Miro no tiene control sobre qué usuarios instalan y usan las capturas inteligentes.

## Preguntas frecuentes

**¿Qué aplicaciones de Microsoft Office admiten la integración con Miro?**

El panel lateral de Miro funciona con Microsoft Word, PowerPoint y Excel.

**¿Cómo se actualizan los elementos del tablero de Miro insertados?**

El contenido insertado a través del panel lateral de Miro mantiene una conexión con el tablero original de Miro. Aunque no sincroniza automáticamente, puedes actualizar el contenido insertado para asegurar que refleja la versión más reciente de tu tablero de Miro.

**¿Cómo funciona el panel lateral de Miro?**

El panel lateral de Miro proporciona acceso directo a tus tableros de Miro sin salir de tu documento. Haz clic en el ícono de integración de Miro para abrir el panel lateral derecho, luego usa "Seleccionar tablero de Miro para insertar" para elegir entre tus tableros disponibles. El panel te permite previsualizar y seleccionar áreas específicas o marcos antes de insertarlos en tu documento en la posición de tu cursor.
