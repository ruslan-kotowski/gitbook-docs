Inserta un tablero de Miro nuevo o existente en una reunión de Microsoft Teams (MS Teams). Empieza a colaborar al instante sin abandonar la llamada.

## Cómo añadir un tablero de Miro a una reunión de Microsoft Teams

#### Requisitos previos

Asegúrate de que cumples los siguientes requisitos previos:

- Tienes habilitado Miro para Microsoft Teams. Para saber cómo, consulta la [descripción general de Miro para Microsoft Teams](06-miro-for-microsoft-teams-overview.md).
- Eres miembro del equipo de Miro al que pertenece el tablero que quieres insertar.
- Eres el propietario del tablero o el editor del tablero que quieres insertar.

#### Procedimiento

Sigue estos pasos:

1. En Microsoft Teams, selecciona un equipo.
2. Selecciona el icono más**(+**)
   Se abre el modal **Añadir una pestaña**.
3. Selecciona **Miro**.
4. Selecciona **Empezar**.
   Se te instruirá para que inicies sesión en Miro si aún no lo has hecho.
5. Selecciona un tablero de Miro o crea uno nuevo para insertarlo.
   > ✏️ Debes tener el rol de propietario del tablero o editor del tablero, y ser miembro del equipo de Miro propietario del tablero que quieres insertar.
6. Selecciona los permisos para cualquier persona en la inserción.
   ![Seleccionar permisos para insertar Miro en Microsoft Teams](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22476127831698_image.png)
7. Selecciona **Guardar**.
   El tablero se inserta en una pestaña de MS Teams.

   Has añadido correctamente un tablero de Miro a una reunión de Microsoft Teams.
