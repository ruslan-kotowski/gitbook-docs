Recibe notificaciones de Miro como mensajes de chat dentro de Microsoft Teams (MS Teams). Mantente informado, comparte tableros y gestiona el trabajo rápidamente sin cambiar de app.

![](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22451245005458_mceclip0.png)
*Notificaciones de Miro en el chat de Microsoft Teams*

Las notificaciones de Miro te habilitan para hacer un seguimiento de los siguientes eventos directamente en el chat de MS Teams:

- se compartió un tablero contigo;
- Se publica un comentario en un tablero
- Se te menciona en un comentario
- Recibes una solicitud de acceso al tablero, que puedes aprobar o rechazar inmediatamente
- Un invitado se inscribe

### Cómo configurar las notificaciones de Miro en Microsoft Teams

#### Requisitos previos

Asegúrate de que tienes habilitado Miro para Microsoft Teams. Para saber cómo, consulta la [descripción general de Miro para Microsoft Teams](06-miro-for-microsoft-teams-overview.md).

#### Procedimiento

Para añadir notificaciones de Miro a Microsoft Teams, sigue estos pasos:

1. En Microsoft Teams, abre un chat con Miro.
2. En la barra de mensajes, escribe "Conectar".![](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22452689633554_mceclip1.png)
   **Conectar Miro a MS Teams**
3. Selecciona **Conectar tu cuenta Miro**.
   El modal **Instalar y autorizar "Microsoft Teams"** se abre en una pestaña aparte.
4. Selecciona el equipo que quieres seguir.
   ![](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22454855305362_mceclip2.png)
   **Seleccionar un equipo Miro para realizar un seguimiento en Microsoft Teams**
5. Selecciona **Instalar y autorizar**.
   En tu chat de MS Teams con Miro, un mensaje de bienvenida de las notificaciones de Miro indica que la configuración se ha completado.

   Has configurado correctamente las notificaciones de Miro en MS Teams.
   > ✏️ Las notificaciones son sólo para el equipo Miro que selecciones. Para seguir a varios equipos, puedes repetir las instrucciones de configuración para cada equipo que quieras seguir.

### Preguntas frecuentes

**¿Por qué he dejado de recibir notificaciones de mi equipo?**

Si ya habías configurado las notificaciones de Miro en MS Teams y dejaste de recibirlas, repite las instrucciones de configuración. Si sigues teniendo problemas, ponte en contacto con el Soporte de Miro.

**¿Puedo obtener un resumen de los cambios en un tablero de Miro?**

Actualmente no hay disponible un resumen de cambios en las notificaciones de Miro en MS Teams. Sin embargo, esta función está ahora en nuestro backlog.
