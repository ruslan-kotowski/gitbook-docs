Inserta un tablero de Miro en una invitación del calendario de MS Teams, establece permisos y da acceso a los colaboradores antes de la reunión.

## Cómo añadir un tablero de Miro a un evento del calendario de Microsoft Teams

#### Requisitos previos

- Crea y guarda un evento del calendario.
- Asegúrate de que tienes habilitado Miro para Microsoft Teams. Para saber cómo, consulta la [descripción general de Miro para Microsoft Teams](06-miro-for-microsoft-teams-overview.md).

#### Procedimiento

Sigue estos pasos:

1. En Microsoft Teams, abre el evento del calendario y selecciona **Editar**.
2. Selecciona el icono más**(+**).
   Se abre el modal **Añadir una pestaña**.
3. Selecciona **Miro**.
4. Selecciona **Empezar**.
   Se te instruirá para que inicies sesión en Miro si aún no lo has hecho.
5. Selecciona un tablero de Miro o crea uno nuevo para insertarlo.
   > ✏️ Debes tener el rol de propietario del tablero o editor del tablero, y ser miembro del equipo de Miro propietario del tablero que quieres insertar.
6. Selecciona los permisos de usuario para el tablero insertado.
   ![imagen.png](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22476127831698_image.png)
7. Selecciona **Guardar**.

   Has añadido correctamente un tablero de Miro a un evento del calendario de MS Teams.
