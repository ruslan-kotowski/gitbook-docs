Combina la fuerza colaborativa de Miro con la potencia de análisis de Power BI. Al insertar informes y paneles de Power BI directamente en los tableros de Miro, tu equipo podrá agilizar los procesos de toma de decisiones, visualizar estrategias basadas en datos e impulsar el progreso de proyectos con claridad y precisión.

- Utiliza datos insertados de Power BI para obtener estadísticas en tiempo real y tomar decisiones informadas.
- Actualiza y agrega gráficos a tableros de Miro que incluyan datos de Power BI para colaborar de manera eficaz con los miembros de tu equipo.

## Cómo insertar informes de Microsoft Power BI en Miro

:::tip
Confirma con tu admin de empresa que la integración de Power BI se haya configurado para tu organización.
:::

1. Navega a Microsoft Power BI y copia el enlace del informe o panel desde la barra de direcciones del navegador (no desde el menú Compartir, ya que por el momento no es compatible).
2. Pega el enlace copiado en cualquier tablero de Miro.
3. Haz clic en **Conectar** para autorizar la aplicación de Miro en Microsoft Power BI.
4. Después de conectarte, se abrirá un diálogo que te indicará que selecciones los gráficos que quieras insertar. Asegúrate de que la lista coincida con el informe original.
5. Haz clic en **Agregar todos los gráficos** para insertarlos en el tablero.
6. Los gráficos se agregarán como imágenes a tu tablero de Miro.

## Requisitos para insertar datos de Power BI en Miro

A continuación, se indican los requisitos para insertar un informe o panel de Power BI en un tablero de Miro:

- Debes formar parte de una cuenta o un equipo de Miro que tenga habilitada la integración de Power BI.
- Debes tener acceso al informe o panel específico de Power BI que quieras insertar.
- Asegúrate de que el tablero de Miro en el que quieres insertar los datos de Power BI no se comparta a través de un enlace público.
- Debes tener un servicio de Power BI en la nube compatible (SKU de Power BI Premium por capacidad o SKU de reserva de capacidad de Fabric). No se admiten servicios locales.

## Ver y editar datos insertados de Power BI

Los usuarios que tengan acceso al tablero de Miro con datos insertados de Power BI podrán verlos, independientemente del estado de su licencia o autorización de Power BI. Esto abarca a los usuarios que tengan permisos para ver, comentar o editar en el tablero.

Si tienes permisos de edición en un tablero de Miro con datos insertados de Power BI, puedes actualizarlo mediante la función **Actualizar** o agregar gráficos mediante la función **Agregar gráficos**, incluso si no tienes acceso al contenido original de Power BI. Sin embargo, no podrás explorar ni acceder a los datos del gráfico original ni cambiar filtros a través de la integración.

## Retención de datos

Los datos insertados de Power BI cumplen con la política de retención de datos estándar de Miro que se aplica a todos los datos de los clientes. Lee nuestro [Apéndice de procesamiento de datos de Miro](https://miro.com/legal/documents/Miro-Data-Processing-Addendum.pdf).

## Resolución de problemas

Sigue estos pasos de resolución de problemas para solucionar problemas comunes que encuentres al usar la integración de Power BI en Miro.

Problemas de autorización y aprobación de admin

Si no puedes autorizar la aplicación o se requiere la aprobación de un admin sin una opción para solicitarla, comunícate con tu admin de empresa para que compruebe que las solicitudes de aprobación estén habilitadas. Si aparece la ventana **Se requiere la aprobación del admin**, solicita la aprobación allí.

Problemas de inserción

Si los gráficos no aparecen de la forma prevista, comunícate con tu admin de empresa para asegurarte de tener la suscripción de Microsoft Power BI correcta.

Verificación de enlace

Si faltan elementos, comprueba el enlace que utilizaste y asegúrate de haberlo copiado directamente desde la barra de direcciones del navegador.
