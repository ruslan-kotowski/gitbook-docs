Usa Miro en el dispositivo de Surface Hub de Microsoft para colaborar de forma remota, en persona e híbrida con tu equipo. Obtén más información a continuación sobre cómo usar Miro en Surface Hubs.

Miro es compatible con los dispositivos Surface Hub de Microsoft de 84" y 55" y con los Surface Hub 2S de Microsoft de 50" y 85".

:::note
Asegúrate de estar usando la versión más reciente de Microsoft Edge.
:::

## Formas de usar Miro con Surface Hub de Microsoft

Hay dos maneras de usar Miro con un Surface Hub:

1. En navegadores Microsoft Edge
2. Instalar Windows 10/11 en el Surface Hub e instalar la aplicación de Miro para Windows

### Usar Microsoft Edge

1. Asegúrate de que el dispositivo Surface Hub se esté ejecutando con la **versión de Windows** más reciente ([actualización de Windows 10 Team 2022](https://learn.microsoft.com/surface-hub/surface-hub-2022-update))
2. Inicia el **navegador Microsoft Edge** más reciente. Aprende cómo instalar este navegador en pantallas Surface Hub
   > ✏️ Es posible que se requiera permiso de administrador para actualizar Windows o Microsoft Edge a las versiones más recientes.
3. Ahora, podrás iniciar sesión en Miro desde miro.com/login. También puedes usar nuestra [experiencia de inicio de sesión rápido](../../getting-started/apps-for-devices/10-send-to-display.md) para iniciar los tableros de Miro desde tu dispositivo personal y en Surface Hub aún más rápido.

### Usar Surface Hub con la aplicación de Miro para Windows

1. Instalar [Windows 10/11 en el Surface Hub](https://learn.microsoft.com/surface-hub/surface-hub-2s-migrate-os) (en lugar de Windows 10 Team)
2. Instalar la [aplicación de Miro para Windows](../../getting-started/apps-for-devices/05-desktop-app.md)

:::warning
Actualmente, no hay una versión disponible de la aplicación de Miro para Surface Hub en "Windows 10 Team".
:::
