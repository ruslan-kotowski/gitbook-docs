Conectar Google Workspace™ y Miro mejora tu colaboración visual desde cualquier lugar, proporcionándote herramientas potentes y fáciles de usar que aumentan el compromiso y la creatividad en las reuniones. Con esta integración, puedes conectar Miro a Google Drive, documentos, Meet y Calendar.

## Características principales

Una vez que se instala el complemento de Miro, puedes aprovechar varias funciones clave para optimizar tus flujos de trabajo:

- Añadir un tablero de Miro a una invitación de [Google Calendar](08-miro-for-google-calendar.md).
- Ver y colaborar en tableros directamente dentro de [Google Meet](09-miro-for-google-meet.md).
- Insertar un chip inteligente de Miro con una vista previa del tablero en un [documento de Google](10-smart-chips-smart-screenshots-for-google.md).
- Guardar tus tableros de Miro en [Google Drive](05-google-drive.md).
- Recibe notificaciones, despliega enlaces de tableros de Miro o crea un tablero de Miro a través de [Google Chat](01-miro-for-google-chat.md).

:::note
Es posible que el administrador de tu Google Workspace deba instalar el complemento de Miro para tu organización o equipo. Si no está disponible, consúltalo con tu administrador.
:::

## Instalar el complemento de Miro

Para conectar el complemento de Miro a tus productos de Google Workspace, primero necesitas instalarlo. Puedes verificar si el complemento ya está instalado revisando la barra lateral en Google Docs o Calendar en busca del logotipo 'M' de Miro.

Para instalar el complemento:

1. Ve al [Google Workspace Marketplace](https://workspace.google.com/marketplace/app/miro/1062019541050).
2. Haz clic en **Instalar**.
3. Selecciona la cuenta de Google que deseas conectar al complemento.

Cuando se instale el complemento, verás el ícono de Miro en tu barra lateral, confirmando la instalación exitosa.

## Política de Uso de Datos de Usuario de los Servicios de API de Google

El uso de la información recibida de las APIs de Google por parte de Miro para Google Workspace se ajustará a la [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), incluidos los requisitos de Uso Limitado. Las APIs de Google Workspace no se utilizan para desarrollar, mejorar o entrenar modelos de IA y/o ML generalizados/no personalizados.

## Preguntas frecuentes

Aquí tienes respuestas a preguntas comunes sobre la instalación del complemento de Miro para Google Workspace.

Soy admin de Miro. ¿Cómo puedo instalar el complemento de Miro para mi organización?

Los admins de Google Workspace pueden instalar y administrar el complemento en nombre de los usuarios de su organización. Para más detalles, consulta el [Marketplace de Google Workspace](https://support.google.com/a/topic/1056395?hl=en&ref_topic=27380).

¿Por qué no puedo instalar el complemento de Miro?

Es posible que tu administrador haya deshabilitado el complemento o que debas pedirle a tu administrador que lo instale por ti.
