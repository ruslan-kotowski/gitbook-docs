:::note
Miro Web Clipper ya no estará disponible para instalación ni se mantendrá a partir del 1 de febrero de 2026. Para los usuarios que lo hayan instalado previamente, seguirá funcionando "tal cual".

Puedes agregar capturas de pantalla a Miro cargando imágenes, pegándolas desde el portapapeles o arrastrándolas al lienzo.
:::

¡Captura páginas web mientras usas Chrome y guárdalas en tu biblioteca de Miro con el menor esfuerzo posible!

### Cómo usar la extensión

1. Siempre que quieras guardar una captura de pantalla de un sitio web directamente en tu biblioteca de Miro, haz clic en el **icono de Web Clipper** en Chrome para abrir la extensión y elige un **equipo** donde se almacenará la captura de pantalla y el área que deseas guardar: **área visible**, **área seleccionada**, o **página entera**.

![Web_clipper_menu.jpg](../../../../../../docs/integrations-apps/google/images/21016020037138_Web%20clipper%20menu.jpg)
*Menú del Web Clipper de Miro*

2. Cuando estés listo para agregar las páginas web guardadas a un tablero de Miro, abre el tablero. Ten presente que el tablero debe pertenecer al equipo que seleccionaste al tomar la captura de pantalla.

3. En la barra de creación, selecciona **Herramientas, Medios e Integraciones** (**+**).Se abrirá un panel. En la pestaña de **Herramientas**, busca Web Clipper. Selecciona **Subir**, luego selecciona **Web Clipper**.
Se abrirá una galería de capturas de pantalla guardadas. Puedes hacer clic o arrastrar las que necesites y soltarlas en el tablero.

![Miro_web_clipper.gif](../../../../../../docs/integrations-apps/google/images/21016020034962_Miro%20web%20clipper.gif)
*Web Clipper en la barra de herramientas*

Ten presente que puedes aprovechar todo el potencial de Miro Web Clipper si:

- Iniciaste sesión en tu perfil de Miro (siempre puedes saber si has iniciado sesión si el icono de la extensión está activo)
- Después de instalar la extensión, actualizas las páginas web del tablero si están abiertas (solo se necesita una vez)

:::warning
Web Clipper no funciona para páginas que requieren autorización.
:::

### Preguntas frecuentes

1. *Guardé una captura de pantalla pero no aparece en la biblioteca de Web Clipper. ¿Por qué?*
   - Asegúrate de elegir el equipo correcto cuando guardes la captura de pantalla. La captura de pantalla pertenecerá a la biblioteca de Web Clipper en los tableros ubicados en este equipo.
   También ten en cuenta que la extensión no funciona en páginas que requieren autorización.
   Si la extensión no funciona en ninguna página, prueba a **quitarla e instalarla** de nuevo.
