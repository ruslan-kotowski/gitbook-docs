### ¿Por qué veo un mensaje de advertencia en el Selector de tableros?

Si ves el mensaje de error a continuación cuando seleccionas un tablero para insertar, la integración que has abierto fue creada por un desarrollador externo y aún no ha sido revisada por Miro.

Mensaje_de_advertencia_selector_de_tableros.jpg
/em>*Mensaje de advertencia del Selector de Tableros*/span>

### ¿Qué riesgos existen si uso esta integración?

Cuando insertes tu tablero, proporcionas un enlace para acceder a tu tablero. Cuando no hemos revisado ni aprobado la integración, hay posibilidades de que la aplicación de terceros use este enlace para acceder a tu tablero.

Según el nivel de acceso que proporciones cuando insertas el tablero, la aplicación de terceros puede tener acceso para ver el contenido del tablero y editarlo.

### ¿Puedo rechazar este acceso?

Puedes revocar el acceso a los enlaces generados mediante esta integración en la configuración de uso compartido de tableros. Aprende cómo [administrar el acceso a tableros insertados](01-user-permissions-for-boards-embedded-in-third-party-apps.md).

### ¿Cómo obtengo una integración revisada por Miro?

Si eres el desarrollador de esta integración y la necesitas revisada y aprobada por Miro, consulta nuestra guía del desarrollador I[nsertar en vivo con Selector de tableros para usuarios registrados.](https://developers.miro.com/docs/miro-live-embed-with-boardspicker-registered)
