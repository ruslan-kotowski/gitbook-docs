Miro soporta el control por teclado, lectores de pantalla y software de reconocimiento de voz. Este artículo explica cómo usar Miro con tecnologías de accesibilidad.

> **💡** Visita el [Centro de Accesibilidad de Miro](https://miro.com/accessibility-statement/) para obtener más información y mantenerte al tanto de nuestros últimos desarrollos.

:::tip
Estamos dedicados a mejorar continuamente la experiencia de accesibilidad de nuestros usuarios. Por favor, comparte tus comentarios en [accessibility@miro.com](mailto:accessibility@miro.com).
:::

## Navegadores y lectores de pantalla recomendados

:::note
El equipo de accesibilidad de Miro sigue trabajando para mejorar la compatibilidad con las tecnologías de accesibilidad y actualizará esta lista a medida que sea más compatible con otros navegadores, lectores de pantalla y dispositivos.
:::

Recomendamos usar los siguientes navegadores y lectores de pantalla en el escritorio para disfrutar de la mejor experiencia posible:

### Navegadores

- Chrome
- Firefox
- Safari

### Lectores de pantalla

- NVDA para Microsoft Windows
- JAWS para Microsoft Windows
- VoiceOver integrado en macOS

### Reconocimiento de voz

- Control por voz para macOS
- Acceso por voz para Microsoft Windows

:::note
Actualmente proporcionamos un soporte limitado para tecnologías de accesibilidad en dispositivos móviles y tabletas.
:::

## Voz a texto

### Control por voz para macOS

Cuando habilitas el Control por voz en macOS, aparece el botón **Explorar contenido del tablero** en tu tablero de Miro.

:::note
Para aprender cómo habilitar el control por voz en MacOS, consulta el [soporte de Apple](https://support.apple.com/en-gb/102225).
:::

:::tip
En tu Mac, cuando habilites **Control por Voz** en **Configuración**, asegúrate de establecer también **Superposición** como **Nombres de Elementos**.
:::

Para comenzar a dar comandos, di *Presiona Explorar contenido del tablero*. Miro muestra los nombres de los elementos para cada herramienta y objeto en el tablero.

Por ejemplo, di *Presiona Explorar contenido del tablero*, luego da los siguientes comandos para agregar una Nota adhesiva con texto:

1. *Toca **Nota adhesiva***
2. *Toca **Colocar nota adhesiva amarillo claro***
3. *Toca la tecla **Enter***
4. *“¡Hola, Mundo!”*
5. *Toca la tecla **Escape***

### Acceso por voz para Microsoft Windows

Cuando habilites el Acceso por voz en Windows, di *Mostrar números.* Di *Haz clic* y el número que aparece en el centro de tu pantalla. Por ejemplo, di *Haz clic en 44*. Miro se activa para el Acceso por voz.

:::note
Para saber cómo habilitar el acceso por voz en MS Windows, consulta [Asistencia de Microsoft](https://support.microsoft.com/en-gb/windows/use-voice-recognition-in-windows-83ff75bd-63eb-0b6c-18d4-6fae94050571).
:::

Para comenzar a dar comandos, di *Mostrar números*. Luego di *Hacer clic* y el número de la herramienta u objeto que deseas usar.

## Lectores de pantalla

Un tablero de Miro tiene la siguiente estructura:

- Barras de herramientas
- Botón Ir al primer objeto del tablero
- Resumen de contenido del tablero/tabla de contenidos
- Contenido del tablero

## Barras de herramientas

Hay cinco barras de herramientas en un tablero de Miro:

- Menú del tablero y configuración
- Barra de herramientas de colaboración
- Barra de herramientas de creación
- Descripción general del tablero
- Controles de zoom y barra de navegación

> **💡** Consulta nuestro [artículo sobre las barras de herramientas](../start-here/your-first-board/05-toolbars.md) para una visión general completa.

### Cómo utilizar las barras de herramientas

- Para navegar por las barras de herramientas, pulsa **Tab**.
- Para navegar dentro de una barra de herramientas, utiliza las **teclas de flecha**.
- Para activar un elemento, pulsa **Intro**.

## Ir al primer objeto del tablero

Si activas el botón **Ir al primer objeto del tablero**, el foco se desplazará al primer objeto del tablero.

### Cómo utilizar Ir al primer objeto del tablero

- Para mover el foco al primer objeto del tablero de Miro, pulsa **Intro**.
- Pulsa la tecla **Escape** para volver a las barras de herramientas.

## Explorar el contenido del tablero

**Explorar el contenido del tablero** proporciona una visión general de la estructura del tablero, como un Índice, por el cual se puede navegar y utilizar para moverse directamente a los objetos del tablero.

### Cómo usar 'Explorar el contenido del tablero'

- Para activar la vista general del tablero, presiona la tecla **Intro** en el botón **Explorar el contenido del tablero**.
- Utiliza la navegación de tu lector de pantalla para desplazarte por la vista general, por ejemplo:
  - JAWS:
    - Utiliza **las teclas de flecha** para moverte por todos los objetos.
    - Pulsa **H** para navegar por todos los objetos contenedores, como los marcos.
    - Pulsa **F** para navegar por todos los objetos editables del tablero, como las notas adhesivas.
- Para mover el foco a un objeto del tablero, pulsa **Intro**. Esto moverá el foco al objeto del tablero de Miro.
- Vuelve a pulsar **Intro** para editar el objeto.
- Pulsa **Escape** para volver a la vista general del tablero.
