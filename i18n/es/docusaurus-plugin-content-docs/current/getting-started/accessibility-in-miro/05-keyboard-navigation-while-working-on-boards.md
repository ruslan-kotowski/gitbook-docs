Navega por tus tableros de Miro usando comandos de teclado y logra una experiencia perfecta.

## Barras de herramientas y paneles

- Presiona **Tab** para navegar entre las [barras de herramientas](../start-here/your-first-board/05-toolbars.md) y los paneles.
- Usa las teclas de flechas para navegar por los elementos y menús de la barra de herramientas.
- Usa las flechas hacia arriba y abajo para navegar por la [barra de herramientas de creación](../start-here/your-first-board/05-toolbars.md).

## Navegación con el teclado

### Activar/desactivar atajos de una sola tecla

Por defecto, los atajos de una sola letra están activados. Para desactivarlos (por ejemplo, para evitar interferencias con tecnologías de accesibilidad como lectores de pantalla):

1. Haz clic en el icono del **Menú principal** (![icon-main.svg](../../../../../../docs/getting-started/accessibility-in-miro/images/31688274627218_icon-main.svg)) en la barra de herramientas del tablero.
2. Selecciona la opción de menú **Accesibilidad** para abrir el submenú.
3. En el submenú, activa o desactiva los **Atajos de una sola letra**.

### Acceder al tablero

- Pulsa **Tab** hasta que llegues al botón "Saltar al primer objeto del tablero" y pulsa **Enter**, o
- Presiona **B** mientras seleccionas una barra de herramientas o un panel para mover la selección al tablero. Cuando tengas el tablero seleccionado, podrás:
  - Acercarte y alejarte con **Ctrl+/Cmd+** y **Ctrl-/Cmd-**.
  - Desplazarte por el tablero con las flechas de navegación.
  - En macOS, presiona **Cmd + Shift + flecha hacia abajo** para seleccionar el primer objeto en el tablero.
  - En Windows, presiona **Ctrl + Shift + flecha hacia abajo** para seleccionar el primer objeto en el tablero.

### Volver a las barras de herramientas

- Pulsa **Escape**.

### Navegar linealmente por el tablero

- Usa **Tab** para moverte por los objetos del tablero en orden de lectura, desde arriba a la izquierda hasta abajo a la derecha.
- Usa **Shift + Tab** para moverte en sentido inverso.

### Navegar espacialmente por el tablero

macOS

**Cmd + teclas de flecha** para moverte por los objetos del tablero en orden espacial:

- **Cmd + derecha** para mover al elemento a la derecha del objeto actual.
- **Cmd + arriba** para mover al elemento encima del objeto actual.
- **Cmd + abajo** para mover al elemento debajo del objeto actual.
- **Cmd + izquierda** para mover al elemento a la izquierda del objeto actual.

Windows

**Ctrl + flechas de navegación** para moverte por los elementos del tablero en orden espacial:

- **Ctrl + derecha** para mover al elemento a la derecha del objeto actual.
- **Ctrl + arriba** para mover al elemento encima del objeto actual.
- **Ctrl + abajo** para mover al elemento debajo del objeto actual.
- **Ctrl + izquierda** para mover al elemento a la izquierda del objeto actual.

### Saltar al primer o al último objeto

macOS

- **Opción + Shift + flecha izquierda**, u **Opción + Inicio,** para saltar al primer objeto en el contenedor actual.
- **Opción + Shift + flecha derecha**, u **Opción + Fin**, para saltar al último objeto en el contenedor actual.

Windows

- **Alt + Shift + flecha izquierda**, o **Alt + Inicio**, para saltar al primer objeto en el contenedor actual.
- **Alt + Shift + flecha derecha**, o **Alt + Fin**, para saltar al último objeto en el contenedor actual.

### Entrar o salir de un objeto contenedor

Los objetos contenedores incluyen marcos y objetos agrupados. Mientras estás dentro de un objeto contenedor, toda la navegación queda restringida a ese contenedor.

macOS

- **Cmd + Shift + abajo** para entrar a un objeto contenedor.
- **Cmd + Shift + arriba** para salir de un objeto contenedor.

Windows

- **Ctrl + Shift + abajo** para entrar a un objeto contenedor.
- **Ctrl + Shift + arriba** para salir de un objeto contenedor.

### Editar texto del objeto

- Presiona **Enter** en un objeto para comenzar a editar (por ejemplo, una nota adhesiva).
- Presiona **Escape** en un objeto para dejar de editar (por ejemplo, una nota adhesiva).

:::note
La navegación por el teclado solo funciona cuando se seleccionan objetos, no mientras se editan.
:::

### Mover objetos

- Usa **las teclas de flecha** para mover un objeto.
- Usa **Shift + tecla de flecha** para mover un objeto más lejos.

### Seleccionar múltiples objetos del tablero

macOS

- Selecciona el primer objeto.
- Presiona **Cmd** + **Option** + **Shift** + **Flecha** para elegir cada objeto adicional.

Windows

- Selecciona el primer objeto.
- Presiona **Ctrl** + **Alt** + **Shift** + **Flecha** para elegir cada objeto adicional.

### Cambiar el tamaño de objetos del tablero

macOS

- Selecciona el objeto del tablero que deseas redimensionar.
- Presiona **Cmd** + **Opción** + **Shift** + **Más/Menos**.

Windows

- Selecciona el objeto del tablero que deseas redimensionar.
- Presiona **Ctrl** + **Alt** + **Shift** + **Más/Menos**.

### Entrar y navegar por el menú contextual de un objeto

El menú contextual de un objeto incluye funciones adicionales que te permiten personalizarlo, como cambiar su color, tipo o estilo de texto. Tras seleccionar un objeto, su menú contextual aparecerá horizontalmente encima del objeto, proporcionando acceso a estas opciones.

macOS

- Pulsa **Cmd + Intro** para mover el foco al menú contextual de un objeto.
- Utiliza **las teclas de flecha izquierda/derecha** para navegar por el menú contextual de un objeto e **Intro/Espacio** para seleccionar un elemento.

Windows

- Presiona **Ctrl + Intro** para mover el foco al menú contextual de un objeto.
- Usa las **teclas de flecha izquierda/derecha** para navegar por el menú contextual de un objeto y **Intro/espacio** para seleccionar un elemento.

### Crear un objeto nuevo

La manera más fácil de agregar un objeto nuevo es usar la paleta de comandos:

macOS

- Presiona **Cmd+K** para abrir la paleta de comandos.
- Empieza a escribir el nombre del objeto, por ejemplo, nota adhesiva.
- Usa las **teclas de flecha** para seleccionar el objeto.
- Presiona la **tecla Enter** y el objeto se agregará al centro del tablero.

Windows

- Presiona **Ctrl+K** para abrir la paleta de comandos.
- Comienza a escribir el nombre del objeto, por ejemplo, nota adhesiva.
- Usa las **flechas de dirección** para seleccionar el objeto.
- Presiona la **tecla Enter** y el objeto se añadirá en el centro del tablero.

Otras formas de crear un objeto utilizando el teclado incluyen:

- Navega con la tecla **Tab** hasta la [barra de herramientas de creación](../start-here/your-first-board/05-toolbars.md), luego presiona las **flechas hacia arriba o abajo** hasta llegar al tipo de objeto deseado (forma, nota adhesiva, etc.) y presiona **Enter**, después **Tab** para seleccionar el objeto, y presiona **Enter** nuevamente para crear el objeto. El objeto se colocará en el tablero.
- Presiona el atajo de teclado asociado con el objeto (por ejemplo, **N** para notas adhesivas), luego presiona **Tab** para seleccionar el objeto, y presiona **Enter**. El objeto se colocará en el tablero.
- Copia y pega un elemento existente con **Ctrl**/**Cmd+C** y luego **Ctrl/Cmd+V**.
- Duplica un objeto existente con **Ctrl/Cmd+D**.
- Para editar una nota adhesiva presiona **Enter**, luego presiona **Tab** y se creará un objeto nuevo contiguo al objeto seleccionado.

### Crear conexiones de diagramas

Puedes crear líneas de conexión entre objetos en el tablero.

- Navegar con Tab hasta el primer objeto que deseas conectar.
- Presiona Cmd+K (Mac) o Ctrl+K (Windows) para abrir la paleta de comandos.
- Escribe y selecciona **Crear conexión con**.
- Navegar con Tab hasta el segundo objeto.
- Presiona Cmd+K (Mac) o Ctrl+K (Windows) para abrir la paleta de comandos.
- Escribe y selecciona **Conectar a este objeto**.

### Comentarios

macOS

- **Opción + Tab** para navegar hacia adelante a través de los comentarios.
- **Opción + Shift + Tab** para navegar hacia adelante a través de los comentarios.
- **Opción +**C para agregar un comentario al objeto actual.

Windows

- **Alt + C** para agregar un comentario al objeto actual.

## Comandos de tecnologías de accesibilidad

Los siguientes comandos de teclado solo están disponibles cuando se usan tecnologías de accesibilidad como los lectores de pantalla.

### Resumen del tablero

El resumen del tablero proporciona a los usuarios de lectores de pantalla una breve descripción general de los objetos en el tablero.

macOS

- **Opción + S** para recibir información sobre la cantidad y los tipos de objetos en el tablero.

Windows

- **Alt + S** para recibir información sobre la cantidad y los tipos de objetos en el tablero.

### Información adicional de objetos

Esta acción proporciona a los usuarios de lectores de pantalla información adicional sobre el objeto seleccionado en ese momento.

macOS

- **Opción + I** para recibir información adicional de objetos.

Windows

- **Alt + I** para recibir información adicional de objetos.

### Notas de selección de objetos

Es posible repetir la información proporcionada al seleccionar el objeto del tablero.

macOS

- **Opción + R** para repetir la nota mostrada al seleccionar.

Windows

- **Alt + R** para repetir la nota mostrada al seleccionar.
