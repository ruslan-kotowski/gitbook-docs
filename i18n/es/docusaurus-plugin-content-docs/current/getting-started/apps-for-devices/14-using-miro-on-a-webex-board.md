Mejora la actividad de tu pizarra usando Miro en un tablero Webex. Configura la aplicación de Miro y comienza a colaborar fácilmente, presentando tus ideas ¡y creando grandes cosas nuevas!

Hay dos formas de agregar la aplicación de Miro a un tablero Webex: directamente desde el nodo de control o desde dentro del editor de extensiones de UI.

### Añadir la aplicación desde el nodo de control

Para añadir la aplicación desde el nodo de control, ve a **Devices** (dispositivos) y abre el dispositivo (que debe estar registrado desde antes en el nodo de control; consulta [este artículo en el Centro de ayuda de Webex](https://help.webex.com/n3hi0z8/Activate-a-Cisco-Webex-Room-or-Desk-Device-or-Webex-Board) para aprender cómo activar un tablero Webex o un dispositivo de escritorio).

dispositivos_en_Webex.jpg
Abrir el dispositivo en el nodo de control de Webex

Desplaza hacia abajo y haz clic en **Web apps (aplicaciones web)**.

aplicaciones_web.jpg
Acceder a las aplicaciones web en el nodo de control Webex

Elige añadir una nueva app web. Introduce el nombre de la app que aparecerá bajo el icono de la app web en la pantalla de inicio del tablero Webex. Escribe la URL (por ejemplo, miro.com/displays para tener una pantalla de inicio y una experiencia optimizada para pantallas interactivas). Añade un icono personalizado ingresando este enlace en el campo de URL del icono(opcional). Haz clic en Añadir y guarda los resultados.

añadir_aplicación_web_de_miro_desde_nodo_de_control_webex.gif
*/span>Añadir la aplicación web de Miro desde el nodo de control de Webex*

El dispositivo se sincronizará automáticamente y verás el icono de Miro en la pantalla de inicio de tu tablero Webex.

### Añadir la aplicación dentro del editor de extensiones de UI

Abre el portal web de tu dispositivo y ve al editor de extensiones de **UI**.

editor_de_extensiones.jpg
Abrir el editor de extensiones de UI

Luego, elige **Nuevo** en el panel de extensiones y haz clic en **Añadir** aplicación web.

añadir_una_nueva_aplicación_web_desde_el_editor_de_extensiones_UI.gif
*Añadir una nueva aplicación web dentro del* editor de extensiones de UI

Introduce el ID, el nombre y la URL en la barra lateral izquierda. Inserta [este enlace](https://miro.com/static/images/awwapp-miro/miro_logo_rounded.png) en el campo **de la URL del icono de la aplicación web** para añadir un icono personalizado (opcional). Elige **Always** (siempre) para tener la aplicación de Miro disponible mientras estás en una llamada. Haz clic en el botón de flecha en la barra superior para finalizar.

Añadir la aplicación de Miro con el editor de extensiones de UI en un tablero Webex

:::note
Obtén más información sobre cómo añadir aplicaciones web en tableros Webex en el [Centro de ayuda de Webex](https://help.webex.com/h47w6/Add-Web-Apps-on-Webex-Boards-and-Desk-Pros).
:::

### Trabajar en Miro con un tablero Webex

Cuando el icono de Miro aparezca en la pantalla de inicio de tu tablero Webex, presiónalo e inicia sesión en tu perfil de Miro. Ahora puedes utilizar Miro con toda la funcionalidad de la app. Aprende más sobre cómo trabajar en los tableros de Miro consultando estas secciones del Centro de Ayuda: [Cómo empezar](..), [Cómo utilizar Miro](../../using-miro).

- Para disfrutar la mejor experiencia, recomendamos usar un cable de ethernet en lugar de Wi-Fi
- Verifica tu [modo de navegación](../../using-miro/working-on-the-board/05-using-miro-with-a-mouse-trackpad-or-touchscreen.md) y cámbialo a trackpad o mouse si es necesario
- Usa el minimapa en la esquina inferior derecha del tablero para navegar fácilmente por el tablero

barra_navegación.gif
Minimapa de un tablero de Miro

Cuando hayas terminado la sesión y limpiado la pizarra, tu sesión de Miro se cerrará automáticamente.

### Preguntas frecuentes

1. *¿Puedo utilizar Miro* *en mi Webex Desk Pro?*
   - Sí, Miro puede utilizarse en un Desk Pro a través de un navegador.
