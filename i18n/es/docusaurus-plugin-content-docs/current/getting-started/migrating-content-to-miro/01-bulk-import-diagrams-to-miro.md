Puedes importar masivamente tus diagramas desde aplicaciones de origen como PDF o VSDX.

:::note
Para algunas aplicaciones de origen, solo se admite un tipo de archivo. Para verificarlo, consulta Soporte de tipos de archivo de importación.
:::

## Cómo importar masivamente diagramas a Miro

Para importar tus diagramas a Miro, asegúrate de haber exportado el/los archivo(s) desde tu aplicación de origen como PDF o VSDX. Luego completa el siguiente procedimiento.

1. En tu panel de Miro, para el Espacio donde deseas importar diagramas, haz clic en **Crear nuevo** (**+**).
   ![](../../../../../../docs/getting-started/migrating-content-to-miro/images/32654520716690_image.png)
2. Haz clic en **Importar** > **Importar desde \{source\}**. Por ejemplo, **Importar desde Mural**.
   Se abre el modal **Importar desde \{source\}**.
3. Sigue las instrucciones en pantalla.
4. (Opcional) Cambia el Espacio de destino para la importación. O haz clic en el botón más (**+**) para crear un nuevo Espacio de destino.
5. Haz clic en **Importar** ***x*** **archivos**.

## Soporte de tipos de archivo para importación

| Fuente | Tipo de archivo |
| --- | --- |
| Conceptboard | PDF, VSDX |
| Lucidchart | PDF, VSDX |
| Lucidspark | PDF, VSDX |
| Mural | PDF |
| Visio | VSDX |
