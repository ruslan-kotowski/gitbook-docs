Los propietarios y los copropietarios de tableros pueden controlar el uso de las herramientas de colaboración de tableros si establecen quién puede iniciar el [temporizador](16-timer.md), la [votación](19-voting.md), el [videochat](18-video-chat.md) y usar el [manejo de atención](04-attention-management.md) en un tablero.  Esto te permite definir el grupo de usuarios que debería tener acceso al kit de facilitadores de reuniones. Aunque solo determinados usuarios pueden iniciar estas herramientas de colaboración, otros participantes del tablero pueden usarlas. Por ejemplo, un propietario de tablero puede empezar a votar para permitir que todos en la reunión voten.

Abre un tablero, ve al menú **Share (compartir)** y a **Sharing settings (ajustes para compartir)**, cambia a **Permissions (permisos)** y selecciona una opción en el menú desplegable en **Who can start collaboration tools (¿quién puede iniciar herramientas de colaboración?)**.  Puedes autorizar a todos los editores (excepto visitantes mediante enlace) o los propietarios y los copropietarios de tableros solamente.
