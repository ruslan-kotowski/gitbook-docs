Miro Insights está disponible directamente en tus tableros de Miro como un panel lateral conveniente, permitiéndote acceder a los datos de tus productos y agregar elementos a tu lienzo sin salir de tu espacio de trabajo.

## Accediendo a Insights desde el lienzo

1. Abre cualquier tablero de Miro donde desees trabajar con los datos de tu producto.
2. Selecciona **Herramientas, Medios & Integraciones** desde la barra lateral izquierda.
3. Busca **Insights** en la barra de herramientas del tablero.
4. Selecciona **Insights** para abrir el panel lateral.

El panel se abre con pestañas para Preguntar a la IA, Backlog, Opiniones y Empresas.

Esta integración en el lienzo ofrece una forma simplificada de incorporar tus datos de gestión de productos directamente en sesiones colaborativas, reuniones de planificación y talleres de diseño.

## Pestaña Preguntar a la IA

Haz preguntas sobre tu backlog y opiniones de clientes y obtén perspectivas impulsadas por IA sin cambiar el contexto. Esto es perfecto para el análisis en tiempo real durante las reuniones. Los resultados pueden discutirse y capturarse directamente en el tablero.

## Pestaña Backlog

La pestaña Backlog te permite navegar y gestionar tus funciones e incidencias. Puedes filtrar y buscar fácilmente entre los ítems del backlog, luego seleccionar los específicos para agregar a tu lienzo. Esta pestaña es particularmente útil para la planificación de roadmap y sesiones de priorización.

## Pestaña Opiniones

En la pestaña de Comentarios, puedes acceder y revisar comentarios, ideas, patrones y tendencias de los clientes. Puedes agregar elementos de comentarios relevantes para apoyar tus discusiones, conectando efectivamente la voz del cliente con tu proceso de planificación visual.

## Pestaña de Compañías

La pestaña de Compañías proporciona visibilidad sobre la información y requerimientos de las compañías. Puedes ver qué clientes están impulsando funciones específicas y agregar contexto de la compañía a tus discusiones de roadmap. Esta información ayuda a respaldar decisiones de planificación basadas en cuentas.

## Añadir elementos a tu tablero

Puedes agregar elementos desde las pestañas de Backlog, Comentarios y Compañías directamente a tu tablero de Miro como tarjetas:

1. Ve a la pestaña correspondiente (Ask AI, Backlog, Feedback o Companies).
2. Navega o busca los elementos que deseas agregar.
3. Selecciona uno o varios elementos de la lista.
4. Selecciona **Agregar elemento al tablero** para añadir como tarjeta(s).

Las tarjetas aparecen en tu lienzo con la información relevante. Luego puedes posicionar, conectar y organizar las tarjetas según sea necesario.

### Información de la tarjeta

Las tarjetas creadas a partir de Insights incluyen:

- **Títulos de los elementos** y/o descripción.
- **Metadatos clave** como prioridad, estado o nombres de compañías.
- **Indicadores visuales** que muestran el tipo de elemento (función, incidencia, comentarios).
- **Enlaces de regreso** a los datos completos de Insights.

## Panel lateral de Miro Insights vs aplicación web completa

La integración en el lienzo proporciona acceso rápido a las funciones clave de Insights directamente dentro de tus tableros de Miro. Sin embargo, no incluye el rango completo de características disponibles en la aplicación dedicada de Miro Insights. Para tareas más complejas, análisis profundos y gestión integral, aún puede ser necesario usar la aplicación completa de Insights.

### Cuándo usar el panel lateral en el lienzo

- **Colaboración en tiempo real**: Durante sesiones en vivo con múltiples participantes
- **Planificación visual**: Cuando las relaciones espaciales son importantes para la comprensión
- **Conservación del contexto**: Cuando necesitas datos de Insights junto con otros trabajos visuales
- **Acceso rápido**: Para referencias breves o extracciones de datos simples

### Cuándo usar la aplicación web completa

- **Análisis profundo**: Para una exploración y filtrado de datos exhaustivos
- **Tareas administrativas**: Gestión de operaciones masivas, importaciones o configuraciones
- **Informes detallados**: Creación de informes completos o exportaciones
- **Flujos de trabajo complejos**: Procesos de varios pasos que requieren funcionalidad completa

La integración del lienzo complementa y no reemplaza la aplicación completa de Insights, dándote flexibilidad en cómo accedes y utilizas tus datos del producto.
