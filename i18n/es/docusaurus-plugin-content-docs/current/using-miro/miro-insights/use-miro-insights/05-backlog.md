El backlog es tu principal espacio de trabajo en Miro Insights donde gestionas todas tus funciones e incidencias. Este centro central ofrece herramientas completas para organizar, priorizar y seguir tu trabajo de desarrollo de producto.

Tu backlog contiene dos tipos principales de ítems:

- **Funciones**: Nuevas capacidades o mejoras que estás planeando construir.
- **Incidencias**: Errores, problemas o deudas técnicas que necesitan ser abordadas.

Cada ítem incluye detalles como nivel de prioridad, empresas asociadas, cantidad de comentarios, impacto en el valor en dólares y estado actual.

## Organizando tu backlog

Puedes personalizar cómo ves y gestionas tu backlog utilizando campos, agrupaciones, filtros y vistas.

### Agregar campos personalizados

Personaliza tu backlog para que coincida con tu flujo de trabajo añadiendo campos que sean importantes para tu equipo. Esto te ayuda a capturar la información específica que necesitas para la toma de decisiones.

### Agrupar elementos

Organiza tu backlog agrupando elementos según diferentes criterios:

- **Iniciativa**: Agrupar por área de producto o objetivo estratégico.
- **Prioridad**: Organizar por niveles de urgencia o importancia.
- **Estado**: Agrupar por etapa de desarrollo (idea, investigación, en progreso, enviado).
- **Compañías**: Ver qué funciones son solicitadas por clientes específicos.

### Filtrar y buscar

Restringe tu vista para enfocarte en lo que importa:

- Utiliza el **filtro** para mostrar subconjuntos específicos de tu backlog.
- **Busca dentro de las vistas** para encontrar rápidamente elementos específicos.
- Combina múltiples filtros para tener un control preciso sobre lo que ves.

## Trabajar con vistas

Las vistas guardan tus combinaciones preferidas de configuraciones de agrupamiento y filtrado.

### Administrar vistas

- **Vista predeterminada**: Tu perspectiva estándar del backlog que ven los demás.
- **Crear nuevas vistas**: Guarda combinaciones personalizadas de agrupamiento y filtrado con un nombre descriptivo.
- **Reordenar vistas**: Arrastra las vistas para cambiar su orden en la interfaz.
- **Visibilidad compartida**: Los cambios en la vista afectan lo que ven todos los miembros del equipo.

### Estrategias efectivas para vistas

Para aprovechar al máximo las vistas, considera estas estrategias:

- Crea vistas para diferentes enfoques del equipo (backlog de ingeniería, solicitudes de clientes, elementos de alta prioridad).
- Usa nombres descriptivos que expliquen el propósito de la vista.
- Revisa y actualiza regularmente las vistas a medida que cambian tus necesidades.

## Operaciones en masa

Para gestionar eficientemente tus tareas pendientes, puedes realizar acciones en múltiples elementos a la vez.

### Acciones de selección múltiple

Selecciona varios elementos para realizar operaciones por lotes:

- **Fusionar elementos**: Combina funciones/incidencias duplicadas o relacionadas.
- **Eliminar elementos**: Elimina entradas obsoletas o inválidas.
- **Actualizaciones masivas de estado**: Cambia el estado de varios elementos simultáneamente.

:::tip
Para asegurar la precisión y evitar errores:

- Usa filtros primero para aislar los elementos que deseas modificar.
- Verifica tu selección antes de realizar acciones irreversibles como eliminar.
- Fusiona elementos similares para reducir el desorden y centrar las discusiones.
:::

## Funciones impulsadas por IA

Activa las sugerencias de IA para obtener recomendaciones inteligentes a lo largo de tu backlog:

- **Sugerencias de priorización**: La IA destaca los elementos que podrían necesitar atención según los comentarios de los clientes y el impacto en el negocio.
- **Ayuda de categorización**: Sugerencias automáticas para agrupar y etiquetar elementos.
- **Detección de relaciones**: La IA identifica conexiones entre funciones e incidencias relacionadas.

:::tip
Para aprovechar al máximo las funciones de IA:

- Mantén tus datos actualizados para obtener mejores recomendaciones de IA
- Revisa las sugerencias de IA antes de aceptarlas
- Utiliza las ideas de IA como punto de partida para un análisis más profundo
:::

## Agregar nuevos elementos

1. Haz clic en **Nuevo** para agregar elementos a tus tareas pendientes
2. Elige entre tipos de **Funcionalidad** o **Problema**
3. Completa los detalles esenciales:
   - Título y descripción
   - Nivel de prioridad
   - Empresas o clientes asociados
   - Impacto o esfuerzo estimado

Para asegurar claridad y utilidad:

- Escribe títulos claros y específicos que expliquen el valor o problema.
- Incluye contexto sobre por qué el elemento es importante.
- Vincula comentarios de clientes relacionados cuando estén disponibles.
- Establece niveles de prioridad adecuados según tus criterios.

## Importar y exportar

Puedes integrar trabajo existente de otras herramientas o compartir los datos de tu backlog con las partes interesadas.

### Importación de datos

Integra trabajo existente de otras herramientas:

- **Archivos CSV**: Importa datos estructurados desde hojas de cálculo
- **Integración de JIRA**: Usa consultas JQL o realiza búsquedas para importar tickets existentes
- **Otras integraciones**: Conéctate con tus herramientas de gestión de producto existentes

### Exportación de datos

Comparte información de backlog con las partes interesadas:

- **Exportar como CSV**: Crea hojas de cálculo para análisis o informes
- **Compartir vistas**: Proporciona perspectivas filtradas para diferentes audiencias
- **Generar informes**: Usa los datos exportados para resúmenes ejecutivos o actualizaciones del equipo

## Exactitud de los datos

Para obtener las mejores ideas y sugerencias de IA, asegura que la información de tus tareas pendientes esté actualizada. Las recomendaciones de IA se basan en tus datos actuales, por lo tanto, las actualizaciones regulares mejorarán la calidad de las ideas y sugerencias que recibes.

## Accede desde el lienzo

El backlog también está disponible a través del panel lateral de Insights en tus tableros de Miro. Esto te permite navegar, filtrar y buscar los elementos de tus tareas pendientes, y luego seleccionar elementos específicos para agregarlos directamente a tu lienzo como tarjetas. Perfecto para sesiones de planificación de roadmaps y reuniones de priorización donde quieres visualizar los datos reales de tu producto.
