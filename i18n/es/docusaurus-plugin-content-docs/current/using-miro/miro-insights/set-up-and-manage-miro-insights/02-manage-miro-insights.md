Esta guía cubre tareas administrativas continuas para Miro Insights, incluyendo configuración general, gestión de equipos, notificaciones y acceso a la API. Está destinada a los admins de empresa que necesitan gestionar Miro Insights después de completar la configuración inicial.

Si aún no has configurado Miro Insights, empieza con la [guía de configuración de Miro Insights (admin)](../../miro-insights/set-up-and-manage-miro-insights/01-set-up-miro-insights.md) primero.

## Requisitos previos

Para gestionar la administración de Miro Insights necesitas:

- **Rol de admin de empresa** en Miro.
- **Miro Insights ya debe estar configurado** para tu organización.

## Perfil de la empresa

En esta sección, puedes actualizar la información de tu empresa que aparece en Miro Insights.

- **Nombre**: El nombre de tu organización.
- **Dominios de correo permitidos**: Dominios de correo que pueden acceder a Miro Insights.
- **Logotipo de empresa**: Cargar o cambiar tu logotipo de empresa.

## Equipo

Esta sección abarca las configuraciones relacionadas con tu equipo de Miro Insights. Como admin, puedes invitar, agregar o eliminar usuarios, y gestionar sus roles.

## Notificaciones

En esta sección, puedes configurar cómo y cuándo tú o los miembros de tu equipo reciben notificaciones sobre nuevos comentarios, sugerencias de IA y otros eventos importantes.

Puedes establecer métodos de notificación, como Slack. Puedes configurar los tipos de notificación por categoría: función o comentarios.

## Integraciones y automatizaciones

Esta sección te permite gestionar todas las integraciones y automatizaciones conectadas. Puedes ver el estado de cada integración, reconectarlas si es necesario y ajustar las preferencias de importación.

Para instrucciones detalladas de configuración, consulta la [Guía de configuración de Miro Insights (admin)](../../miro-insights/set-up-and-manage-miro-insights/01-set-up-miro-insights.md).

## Claves de API

Aquí puedes generar y gestionar claves de API para el acceso programático a los datos de Miro Insights. Puedes crear nuevas claves y revocar las antiguas o comprometidas.

:::warning
Al crear una clave de API, asegúrate de darle un nombre descriptivo y cópiala en un lugar seguro. No podrás verlo de nuevo después de salir de esta página.
:::

## ¿Qué sigue?

Una vez que hayas configurado estas preferencias administrativas, tu instancia de Miro Insights debería estar funcionando sin problemas para tu equipo. Para obtener orientación continua sobre el uso, consulta la [guía de uso de Miro Insights](../../miro-insights/use-miro-insights).
