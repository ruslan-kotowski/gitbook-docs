Añade bloques de código a tus tableros para la programación colaborativa, la depuración y la resolución de problemas. Nuestro widget de bloques de código tiene los lenguajes de programación más populares y es personalizable.

Combina bloques de código con nuestras [funciones de creación de mapas y diagramas](../formats/diagramming/01-miro-for-mapping-diagramming.md) para revisar la arquitectura y los flujos. Y usa los conectores de diagramas para resaltar las relaciones entre piezas del código fuente.

**Usa bloques de código para lo siguiente:**

- Ceremonias Agile
- Sesiones de desarrollo y depuración colaborativas
- Entrevistas de codificación remota

## Cómo añadir un bloque de código

1. Ve a la barra de herramientas de creación en el lado izquierdo del tablero
2. Haz clic en el ícono **Más aplicaciones**
3. Busca **Code block** (Bloque de código) o desplázate hacia abajo hasta que veas Code block
4. Haz clic en el icono de la aplicación Code block (Bloque de código)
5. Haz clic en cualquier parte del tablero para añadir un bloque de código

## Cómo personalizar un bloque de código

Dentro del menú contextual del bloque de código puedes activar y desactivar líneas, ajustar el tamaño de la fuente y cambiar los lenguajes de programación.

1. Haz clic en el bloque de código.
2. Dentro del menú contextual, elige un lenguaje de programación del menú desplegable, aumenta o reduce el tamaño de la fuente, y haz clic en el icono de los números de línea para activar o desactivar líneas.
