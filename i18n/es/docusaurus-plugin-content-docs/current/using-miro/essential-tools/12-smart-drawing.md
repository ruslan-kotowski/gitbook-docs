Con el dibujo inteligente, puedes disfrutar de trabajo con una sola herramienta en el tablero con un aspecto estupendo desde el principio. El modo dibujo inteligente convierte tus dibujos en lápiz automáticamente en líneas, notas adhesivas y formas precisas.

> **Disponible en:** navegador, [aplicación de escritorio](../../getting-started/apps-for-devices/05-desktop-app.md), [aplicación para tabletas](../../getting-started/apps-for-devices/11-tablet-app.md), [aplicación móvil](../../getting-started/apps-for-devices/08-mobile-app.md)

smart_drawing_in_Miro.gif
Dibujo inteligente en Miro

Para comenzar/detener el dibujo inteligente, elige la herramienta **bolígrafo**en la barra de herramientas y cambia a **dibujo inteligente**. Comienza a dibujar sin interrumpir la línea, un trazo cuenta como un objeto. Te recomendamos que trabajes con el zoom al 100%.

dibujo_inteligente_en_la_barra_de_herramientas.jpg
Dibujo inteligente en la barra de herramientas

Revisa qué objetos son reconocibles; para ello, haz doble clic en el icono de dibujo inteligente.

dibujo_inteligente.gif
Objetos que el dibujo inteligente puede reconocer

Usa los ajustes preestablecidos para crear objetos de color y grosor diferentes. Puedes crear hasta 3 ajustes preestablecidos y editarlos cada vez que lo necesites. Haz doble clic en un ajuste preestablecido para editarlo.

editar_un_ajuste_preestablecido.gif
Ajustes preestablecidos del dibujo inteligente

Para borrar objetos inteligentes garabatea sobre ellos. Asegúrate de cubrir al menos el 50% del objeto, de lo contrario no se borrará.

:::note
Ten presente que el borrador predeterminado funciona solo con dibujos de bolígrafo estándar, no con objetos inteligentes.
:::

borrar.gif
Borrar objetos inteligentes

Para salir del modo dibujo inteligente y cambiar a dibujo libre, elige [el bolígrafo o el resaltador](10-pen.md).

cambiar_a_bolígrafo.jpg
Cambiar a bolígrafo estándar

También puedes crear [formas](11-shapes.md) y [líneas](05-connection-lines.md) mediante las herramientas correspondientes.
