Para acceder al menú de atajos y teclas de acceso rápido, en la parte inferior derecha de tu tablero de Miro selecciona el signo de interrogación (**?**) en la barra de controles del lienzo. Se abre el menú **Ayuda y recursos**. A continuación, selecciona **Atajos de teclado**.

:::tip
También puedes abrir la lista de atajos pulsando F1
:::

### Atajos y accesos rápidos de Windows y Mac

La siguiente tabla muestra todos los atajos y teclas de acceso rápido para Mac y Windows.

Los atajos de texto funcionan cuando seleccionas o editas texto en el tablero.

Puedes utilizar las teclas numéricas 1-9 para cambiar entre las herramientas de la barra de herramientas, en su orden predeterminado. No puedes reasignar las teclas de acceso rápido numeradas. Por ejemplo, **el 2** siempre abre el modal de plantillas.
