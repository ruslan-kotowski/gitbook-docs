Lleva el contenido de tu tablero al formato más estructurado de un Doc. Usando objetos en el lienzo como tu punto de partida, puedes crear resúmenes, informes de investigación e informes de producto para comenzar a reunir y analizar tus ideas.

> Disponible para: todos los planes Miro
> Disponible en: Escritorio, móvil, pantallas interactivas

## Cómo acceder a los documentos

Para añadir un nuevo Doc, haz clic en el ícono de más, busca Docs y luego haz clic en cualquier lugar del lienzo para añadirlo. También se incluyen documentos en algunas plantillas de tableros.

![](https://help.miro.com/hc/article_attachments/25640658809234)

*Añadir un nuevo documento desde el icono de Documentos*

También puedes añadir un Doc con Miro AI.

![](https://help.miro.com/hc/article_attachments/25640674765714)

*Agregar un documento con Miro AI*

Para añadir un documento desde el menú contextual:

1. Crear un Documento seleccionando múltiples objetos en el tablero (como Notas adhesivas).
2. Selecciona **Documento** desde el icono de **Miro Assist** en el menú contextual para abrir el submenú.
3. Elige una plantilla o usa una **Instrucción personalizada**.
4. El documento se creará y se colocará en el tablero.

![doc-from-stickies.png](https://help.miro.com/hc/article_attachments/25640658813074)

*Agregar un Doc mediante el menú contextual*

Para agregar un Doc con Miro AI:

1. Abre el panel **Crear con IA**.
2. Selecciona el tipo de contenido **Documento**.
3. Usa uno de los mensajes predefinidos o escribe el tuyo propio.
4. Selecciona objetos (como notas adhesivas) en el tablero para agregar contexto, si es necesario.
5. Haz clic en **Generar documento**.
6. Tu documento generado aparecerá en un área en blanco del lienzo.

## Plantillas de Docs de Miro

Actualmente hay cuatro plantillas disponibles cuando comienzas un nuevo Doc: Breve de Producto, Resumen de Retrospectiva, Notas de Reunión y Síntesis de Investigación.

Cuando creas un nuevo documento y seleccionas una plantilla, esta se agrega al documento.

## Trabajando en documentos en modo de pantalla completa

Puedes abrir los Docs en modo de pantalla completa cuando quieras concentrarte únicamente en el Doc en el que estás trabajando y no en otro contenido del tablero. Para acceder a este modo, haz clic en el **icono de pantalla completa** sobre el Doc en el que estás trabajando.

![docs-full-screen-icon.png](https://help.miro.com/hc/article_attachments/25640658815378)

*El icono de pantalla completa de Docs*

El modo de pantalla completa sigue incluyendo los menús contextuales para dar formato al texto. Elimina el fondo del tablero, eliminando posibles distracciones.

Para salir del modo de pantalla completa, haz clic en el botón **Ideate on canvas** en la parte superior de la pantalla.

![docs-focus-mode.png](https://help.miro.com/hc/article_attachments/25640674770066)

### Límite de caracteres

Los Miro Docs pueden contener hasta 80 000 caracteres. Si necesitas más espacio, puedes crear Docs adicionales en el mismo tablero y dividir tu contenido en consecuencia. Esto te ayuda a mantenerte dentro del límite mientras organizas toda tu información en un solo lugar.

## Copiar contenido a Docs

Puedes arrastrar y soltar el siguiente contenido de tu tablero a un Doc:

- Nota adhesiva
- Cuadro de texto
- Imagen
- iFrame
- Vista previa
- Tabla
- Línea de tiempo
- Diagrama

> Docs convierte notas adhesivas y cuadros de texto en una lista con viñetas.

![Arrastra y suelta widgets de datos en un Miro Doc.](https://help.miro.com/hc/article_attachments/25640658818066)

*Arrastra y suelta widgets de datos en un documento*

### Diagramas en Documentos

Cuando arrastras y sueltas un Diagrama en un Documento, Miro crea una [copia sincronizada](../working-on-the-board/11-synced-copies.md). Esto significa que los cambios realizados en el diagrama original en el tablero se reflejarán en la copia dentro del documento, pero no al revés. Para cambiar el contenido copiado, modifica el contenido del Diagrama original.

Esto garantiza que tu documentación se mantenga actualizada con la información visual más reciente.

### Otro comportamiento del contenido en Docs

Para widgets con modo enfoque, como una tabla, aún puedes acceder al modo inmersivo cuando el widget está dentro de un documento. Las dimensiones se ajustan para caber y desplazarse dentro del Doc.

También puedes arrastrar el contenido fuera del documento para colocarlo de nuevo en tu tablero.

## Uso de atajos de teclado en Docs

Se pueden usar atajos del teclado para aplicar tipos de encabezado y lista al texto (estos atajos se pueden ver en el submenú de tipos de párrafo):

Convertir en **Usando cmd + opt + \{número\}**

- 0 -> Párrafo
- 1 -> Título 1
- Título 2
- Título 3
- 4 -> Lista con viñetas
- Lista numerada
- 6 -> Lista de verificación

También puedes usar atajos del teclado para la selección de bloques: presiona Escape una vez para entrar en el modo de selección de bloques, luego:

- **shift + arriba/abajo** -> amplía tu selección
- **cmd + opt + arriba/abajo** -> mueve tu selección hacia arriba y hacia abajo

Aquí hay otras funciones en Docs a las que se puede acceder mediante atajos de teclado:

|  |  |
| --- | --- |
| **⌘** + **intro** | Enfocar menú de selección de texto |
| **⌘** + **Shift** + **X** | Alternar tachado |
| **Cmd** + **Shift** + **U** | Agregar enlace |
| **⌘** + **E** | Alternar código en línea |
| **⌘** + **,** | Marcar/Desmarcar el elemento de la lista de verificación |
| **⌘** + **/** | Abrir menú contextual de bloques |
| **⌘** + **D** | Duplicar bloques seleccionados |
| **⌘** + **I** | Copiar enlace a un bloque |

Puedes acceder a la lista completa de atajos de teclado desde la aplicación de Miro haciendo clic en el ícono de **Ayuda y recursos** en la esquina inferior derecha de la pantalla.

![docs-keyboard-shortcuts.png](https://help.miro.com/hc/article_attachments/25640658823442)

*Atajos de teclado a través del icono de Ayuda y recursos*

## Usar Miro AI en Docs

Usar Miro AI para editar tus documentos es una excelente manera de acelerar el proceso de edición y crear documentos más concisos y fáciles de leer.

Puedes usar Miro AI para modificar el texto resaltado en un documento.

![](https://help.miro.com/hc/article_attachments/25640658824210)

*Pide a Miro AI que modifique el texto resaltado en un Doc de Miro.*

Para usar el texto en línea para solicitar Miro AI, destaca el texto en tu Miro Doc. Desde el menú contextual, en el extremo derecho selecciona **Mejorar con Miro AI**. Desde el menú desplegable, selecciona **Solicitud personalizada** o cualquiera de las solicitudes disponibles.

## Colaboración en Miro Docs

Miro Docs permite la colaboración en tiempo real con otros usuarios. Al igual que con otros contenidos en el lienzo, el seguimiento del cursor está habilitado, lo que te permite ver dónde en el Documento están trabajando otros usuarios.

También es posible hacer comentarios en línea, con la capacidad de mencionar a otros usuarios (lo que los notifica tanto en la aplicación como por correo electrónico). También están habilitados tanto los hilos de comentarios como las reacciones a comentarios.

### Componentes de usuario en Miro Docs

Los chips de usuario te permiten proporcionar detalles sobre los usuarios dentro de un documento. Por ejemplo, agrega chips @usuario para miembros clave del equipo o partes interesadas.

Para añadir un chip de usuario en un Documento de Miro, escribe '@'. Continúa escribiendo el nombre de usuario para filtrar los resultados, o selecciona un usuario del menú desplegable que se abre.

![Agrega chips de usuario en cualquier parte de un documento de Miro.](https://help.miro.com/hc/article_attachments/25640674780434)

*Agrega chips de usuario en cualquier parte de un documento de Miro.*

Pasa el cursor sobre un chip @usuario para ver información sobre el usuario.

![Las fichas de usuario incluyen información sobre el usuario.](https://help.miro.com/hc/article_attachments/25640658826130)

*Las fichas de usuario incluyen información sobre el usuario.*

Las etiquetas de usuario se comportan de manera diferente a las menciones en un comentario, por ejemplo, las etiquetas de usuario no envían notificaciones a un usuario específico.

## Copiar, compartir y exportar documentos

Los documentos se pueden copiar entre tableros, pero no se sincronizan para cambios futuros. En otras palabras, cualquier edición que se realice en el Doc en un tablero no se aplicará en ningún otro tablero al que se haya copiado el Doc.

Los documentos pueden compartirse con otros usuarios mediante un enlace.

Los documentos se pueden exportar al formato PDF desde el **icono Más** (![icon-main.svg](https://help.miro.com/hc/article_attachments/25640658827026)) en el menú contextual.
