¿Nuevo en Miro AI? Comienza con instrucciones listas para el análisis y organización de contenido. Cada caso de uso explica para qué sirve e incluye instrucciones de Miro AI listas para usar. Sustituye los marcadores de posición entre corchetes (por ejemplo, [rol], [artefacto], [tono]) con tu contexto y luego ejecuta la instrucción en Miro AI.

## **Procesamiento de información y resumen**

Convierte las notas sin procesar en resúmenes claros, temas y listas accionables.

### Resumir hilos de discusión

**Para qué sirve:** Resúmenes rápidos y compartibles de tableros extensos o grupos de notas.

**Instrucción de Miro AI:**

Copiar

```
Crea un resumen conciso de 3 párrafos con los puntos clave de la discusión seleccionada en el tablero de Miro. Captura los temas principales, decisiones tomadas y los pasos a seguir. Formatea como documento de Miro.
```

### Identificar y agrupar temas clave

**Para qué sirve:** Agrupación rápida para ver patrones y lo que importa más.

**Instrucción de Miro AI:**

Copiar

```
Analiza las ideas y opiniones seleccionadas en el tablero de Miro. Identifica los 5 temas recurrentes principales y agrupa los elementos relacionados bajo cada tema. Presenta como una lista estructurada. Formato en notas adhesivas de Miro.
```

### Extraer y priorizar elementos de acción

**Para qué sirve:** Extraer tareas, responsables y fechas de notas desordenadas.

**Instrucción de Miro AI:**

Copiar

```
Revisa las notas seleccionadas en el tablero de Miro. Extrae todos los elementos de acción y organízalos con: descripción de la tarea, persona responsable (si se menciona) y fecha límite (si se menciona). Formato como una tabla de Miro.
```

### Categorizar comentarios

**Para qué sirve:** Agrupar la información en categorías claras con prioridades.

**Instrucción de Miro AI:**

Copiar

```
Categoriza los comentarios seleccionados en el tablero de Miro en grupos lógicos y sugiere niveles de prioridad (alto/medio/bajo) para cada categoría según la frecuencia y el impacto. Formato como una tabla de Miro.
```

## **Síntesis de datos**

Combina entradas de distintas fuentes en salidas claras y listas para tomar decisiones.

### Combinar resultados de investigación de usuarios

**Para qué sirve:** Resumir múltiples sesiones en un conjunto claro de ideas.

**Instrucción para Miro AI:**

Copiar

```
Sintetiza los hallazgos clave de múltiples sesiones de investigación de usuario seleccionadas en el tablero de Miro en 5 ideas principales con evidencia de apoyo. Resalta cualquier hallazgo contradictorio que requiera más investigación. Formato como un documento de Miro.
```

### Crear resúmenes ejecutivos

**Para qué sirve:** Informes de una página para líderes y partes interesadas.

**Instrucción de Miro AI:**

Copiar

```
Crear resúmenes ejecutivos Crea un resumen ejecutivo de una página basado en la información detallada del proyecto seleccionada en el tablero de Miro. Incluye: estado del proyecto, logros clave, desafíos actuales y próximos pasos recomendados. Formato como un documento de Miro.
```

### Generar informes de estado

**Para qué sirve:** Actualizaciones semanales con avances, bloqueos y prioridades.

**Instrucción de Miro AI:**

Copiar

```
Genera un informe semanal del estado usando la información de seguimiento del proyecto seleccionada en el tablero de Miro (estado actual, tareas completadas, próximos hitos). Destaca los avances, obstáculos y prioridades para la próxima semana. Formatea como una Tabla de Miro.
```

### Consolidar comentarios de las partes interesadas

**Para qué sirve:** Alinear puntos de vista y evidenciar conflictos + resoluciones.

**Instrucción de Miro AI:**

Copiar

```
Consolidar los comentarios de diferentes partes interesadas seleccionados en el tablero de Miro en un resumen que muestre áreas de acuerdo, puntos de vista conflictivos y resoluciones sugeridas. Formatear como un diagrama de Miro.
```
