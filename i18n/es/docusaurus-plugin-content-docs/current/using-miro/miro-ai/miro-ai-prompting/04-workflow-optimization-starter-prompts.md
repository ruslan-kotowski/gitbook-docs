¿Nuevo en Miro AI? Comienza con instrucciones predefinidas para el análisis y la organización de contenido. Cada caso de uso explica para qué sirve e incluye instrucciones de Miro AI listas para copiar.

## **Mejora de contenido**

Fortalece la claridad, la completitud y los supuestos en tu trabajo.

### Mejora la claridad de las notas adhesivas

**Para qué sirve:** Haz que las notas sean específicas, concisas y orientadas a la acción.

**Instrucción de Miro AI:**

Copiar

```
Recrea las notas adhesivas o el contenido seleccionado en nuestro tablero de Miro para que sean más claros, específicos, y prácticos, manteniendo la intención original. Formatea como notas adhesivas de Miro.
```

### Sugerir consideraciones adicionales del proyecto

**Para qué sirve:** Detectar riesgos, dependencias y puntos ciegos desde el principio.

**Instrucción de Miro AI:**

Copiar

```
Revisar nuestro plan de proyecto actual seleccionado en el tablero de Miro. ¿Qué consideraciones importantes, riesgos o dependencias podríamos estar omitiendo? Sugiere 5–7 elementos adicionales que deberíamos abordar. Formato como documento de Miro.
```

### Recomendar elementos faltantes del flujo

**Para qué sirve:** Llenar los vacíos en pasos, decisiones y ciclos de opiniones.

**Instrucción de Miro AI:**

Copiar

```
Analiza el flujo de proceso actual seleccionado en el tablero de Miro y sugiere cualquier paso, punto de decisión o ciclo de retroalimentación que falte para hacerlo más completo y efectivo. Formatear como un Diagrama de flujo de Miro.
```

### Generar preguntas para validar suposiciones

**Para qué sirve:** Prueba las suposiciones antes de comprometer recursos.

**Instrucción de Miro AI:**

Copiar

```
Genera preguntas o pruebas específicas para validar cada suposición en nuestro plan de proyecto seleccionado en el tablero de Miro antes de avanzar. Formato como notas adhesivas de Miro.
```

## **Guía para la toma de decisiones**

Toma decisiones informadas con estructura, criterios y resultados medibles.

### Crear listas de pros y contras

**Para qué sirve:** Vista equilibrada de los compromisos entre opciones.

**Instrucción de Miro AI:**

Copiar

```
Crea un análisis completo de pros y contras para la decisión u opción seleccionada en el tablero de Miro, incluyendo posibles impactos a corto y largo plazo para cada lado. Formatea como un documento de Miro.
```

### Generar criterios para evaluación de riesgos

**Para qué sirve:** Puntaje de riesgo consistente en propuestas/iniciativas.

**Instrucción de Miro AI:**

Copiar

```
Generar criterios de evaluación de riesgos
Crea un marco de evaluación de riesgos con 5–7 criterios clave basados en el tipo de proyecto o iniciativa seleccionada en el tablero de Miro. Incluye un sistema de puntuación y orientación sobre cómo evaluar cada criterio. Formato como una Tabla de Miro.
```

### Desarrollar marcos de evaluación

**Para qué sirve:** Comparaciones ponderadas y objetivas entre opciones.

**Instrucción de Miro AI:**

Copiar

```
Desarrollar marcos de evaluación Crea un marco de evaluación con criterios ponderados para las múltiples opciones seleccionadas en el tablero de Miro (ideas, soluciones, proveedores, etc.) para ayudarnos a tomar una decisión objetiva y basada en datos. Formato como una Tabla de Miro.
```

### Sugerir métricas de éxito

**Para qué sirve:** Definir indicadores líderes y rezagados desde el principio.

**Instrucción de Miro AI:**

Copiar

```
Sugiere de 5 a 8 indicadores de éxito específicos y medibles para la iniciativa seleccionada en el tablero de Miro. Incluye tanto indicadores líderes (señales tempranas) como indicadores rezagados (resultados finales). Formato como una tabla de Miro.
```

## **Documentación de procesos**

Convierte talleres y flujos en guías prácticas y listas de verificación.

### Convertir lluvias de ideas en planes estructurados

**Para qué sirve:** Pasar de las ideas a un plan de acción con prioridades.

**Instrucción de Miro AI:**

Copiar

```
Convierte los resultados de la lluvia de ideas seleccionada en nuestro tablero de Miro en un plan de acción estructurado con pasos priorizados, fecha de inicio con la fecha de hoy, fecha de finalización dentro de 2 semanas, requisitos de recursos y cualquier otra cosa que pueda ser útil. Formato como una Tabla de Miro.
```

### Crear guías paso a paso

**Para qué sirve:** Instrucciones claras que cualquiera en el equipo puede seguir.

**Instrucción de Miro AI:**

Copiar

```
Crea una guía detallada paso a paso basada en el diagrama de flujo de trabajo seleccionado en nuestro tablero de Miro que cualquiera en el equipo puede seguir. Incluye puntos de decisión, herramientas necesarias y resultados esperados para cada paso. Formato como documento de Miro.
```

### Generar listas de verificación a partir de mapas de procesos

**Para qué sirve:** Asegurar que no se omita nada durante la ejecución.

**Instrucción de Miro AI:**

Copiar

```
Convierte el mapa de procesos seleccionado en nuestro tablero de Miro en una lista de verificación práctica que asegure que nada se pase por alto al ejecutar este proceso. Agrupa los elementos relacionados de manera lógica. Formato como documentos de Miro (con lista de verificación).
```

### Documentar lecciones aprendidas

**Para qué sirve:** Capturar aprendizajes para reutilizarlos y realizar mejoras futuras.

**Instrucción de Miro AI:**

Copiar

```
Captura las lecciones aprendidas del proyecto completado seleccionado en el tablero de Miro. Estructura las ideas en: qué funcionó bien, qué no funcionó, qué haríamos diferente y recomendaciones para futuros proyectos. Formato como un documento de Miro.
```
