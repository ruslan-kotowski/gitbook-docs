Web whiteboard es una pizarra online sencilla y gratuita que puedes usar sin registrarte o iniciar sesión.  Ejecuta tu próxima sesión de brainstorming o tutoría en Web whiteboard. Simplemente ve a webwhiteboard.com, crea un tablero y comparte el enlace con tu equipo.

:::note
Para obtener más información, también visita [webwhiteboard.com/home](https://webwhiteboard.com/home/).
:::

:::warning
La pizarra web no es compatible con el modo incógnito de Chrome ni con Safari.
:::

### ¿Qué es Web whiteboard?

Web whiteboard está disponible de manera gratuita para todos los usuarios, sin necesidad de registrarse, en dispositivos de escritorio y tabletas.  También puedes usarlo con un lápiz en tabletas, ya que es compatible con el rechazo de palma y Apple Scribble/span>[.](https://support.apple.com/guide/ipad/enter-text-with-scribble-ipad355ab2a7/ipados)

Para comenzar a usar Web whiteboard, abre [webwhiteboard.com](https://webwhiteboard.com/) en el navegador y crea un nuevo tablero.

Puedes compartir este enlace con tu equipo y tus compañeros podrán colaborar contigo en tiempo real sin necesidad de iniciar sesión o registrarse en Miro.  Para compartir el enlace, haz clic en el botón Compartir tablero/span> ubicado en la esquina superior derecha de tu pantalla. El enlace al tablero se copiará en tu portapapeles, y cualquier persona con el enlace obtendrá acceso para editar tu tablero.

share_webwhiteboard.jpg
/span>Cómo compartir un tablero en Web whiteboard

Los tableros de Web whiteboard están disponibles durante 24 horas.  Pasado este tiempo, se bloquean por 7 días.  Durante este tiempo puedes registrarte/iniciar sesión en Miro para desbloquear y guardar el tablero. Si no desbloqueas/guardas el tablero dentro de los 7 días, el mismo se borrará por completo.

Como alternativa, puedes descargar tu tablero como imagen o .pdf – simplemente haz clic en el icono Exportar este tablero, ubicado junto al logotipo de Web whiteboard en la esquina superior izquierda de tu pantalla y elige la **imagen** o el **PDF** en la ventana emergente.

:::warning
Ten presente que si no guardas o exportas tu tablero el mismo se **eliminará de manera permanente** al cabo de 7 días.
:::

### ¿Qué sucede cuando quieres guardar tu tablero?

Si eres un usuario registrado de Miro, tendrás la opción de guardar tu tablero y, si tienes múltiples equipos, elegir en cuál de ellos quieres guardarlo.

save_to_my_boards.jpg
/span>Guarda tu tablero en un equipo de Miro

Si eres usuario de Web whiteboard y aún no tienes un perfil de Miro, pasadas las 24 horas tendrás que registrarte en Miro para poder seguir editando tu tablero.

sign_up_to_Miro.jpg
/span>Registra un perfil de Miro para guardar en él tu tablero

El usuario que se registre en Miro primero se convertirá en el propietario del tablero que guarde.  Los demás colaboradores seguirán teniendo acceso a este tablero con el mismo enlace y podrán continuar trabajando en él como [visitantes](../sharing-boards/08-collaboration-with-visitors.md).

### Preguntas frecuentes

1. *¿Tengo que ser usuario de Miro para utilizar la Pizarra digital?*- No, no es así. Web whiteboard es una pizarra en línea gratuita que cualquier persona puede usar sin estar registrada.
2. *¿Cuánto tiempo puedo trabajar en mi tablero de Pizarra digital?*- Cada tablero de Pizarra digital vive 24 horas, después se bloquea y se elimina permanentemente al cabo de 7 días, a menos que inicies sesión y guardes el tablero. Si quieres seguir trabajando con tu tablero, puedes registrarte en el plan Free de Miro para guardar tu trabajo, o exportar tu tablero como imagen o .pdf.
3. *¿Tengo que pagar para seguir trabajando en mi tablero de Pizarra digital?*- No, simplemente tendrás que [suscribirte al plan Free de Miro](../../getting-started/start-here/02-how-to-register-with-miro.md) para seguir trabajando en tu tablero.
4. *¿En qué se diferencia la Pizarra digital de Miro?*- Pizarra digital es una versión más sencilla y ligera de Miro. Tiene menos funciones que el plan Free y que los [planes premium](../../plans-billing/miro-plans/09-free-plan.md) de Miro.
