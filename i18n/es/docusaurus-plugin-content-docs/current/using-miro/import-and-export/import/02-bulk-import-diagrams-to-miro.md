Puedes importar tus diagramas por lotes desde aplicaciones de origen como PDF o VSDX.

:::note
Para algunas aplicaciones de origen, solo se admite un tipo de archivo. Para verificar, consulta Compatibilidad de tipos de archivos de importación.
:::

## Cómo importar diagramas por lotes a Miro

Para importar tus diagramas a Miro, asegúrate de haber exportado el/los archivo(s) desde tu aplicación de origen como PDF o VSDX. Luego, completa el siguiente procedimiento.

1. En tu panel de Miro, para el espacio donde deseas importar diagramas, haz clic en **Crear nuevo** (**+**).
   ![](../../../../../../../docs/using-miro/import-and-export/import/images/32657459157138_image.png)
2. Haz clic en **Importar** > **Importar desde \{source\}**. Por ejemplo, **Importar desde Mural**.
   Se abre el cuadro de diálogo **Importar desde \{source\}**.
3. Sigue las instrucciones en pantalla.
4. (Opcional) Cambia el espacio de destino para la importación. O haz clic en el botón de más (**+**) para crear un nuevo espacio de destino.
5. Haz clic en **Importar** ***x*** **archivos**.

## Soporte de tipos de archivos de importación

| Fuente | Tipo de archivo |
| --- | --- |
| Conceptboard | PDF, VSDX |
| Lucidchart | PDF, VSDX |
| Lucidspark | PDF, VSDX |
| Mural | PDF |
| Visio | VSDX |
