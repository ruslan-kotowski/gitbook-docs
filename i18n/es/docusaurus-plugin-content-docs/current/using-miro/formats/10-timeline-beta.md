El cronograma es una herramienta de planificación interactiva que alinea estratégicamente a las partes interesadas y los equipos. Úsalo para elaborar un roadmap de tu proyecto, agregar visibilidad y alcanzar los hitos de manera más eficiente. Crea, gestiona y comparte tu cronograma directamente desde un tablero de Miro.

El cronograma visualiza tu proyecto como tareas, llamadas registros, y barras de tiempo. Cada registro representa una tarea y la barra de tiempo muestra claramente el tiempo esperado para completarla. El widget Cronograma también permite que varios usuarios interactúen con el cronograma al mismo tiempo.

Crea grupos para ordenar los registros de forma lógica y mueve los registros entre grupos. Por ejemplo, puedes ordenar tu proyecto por hito.

El widget Cronograma también interactúa con las [tarjetas de Miro](../essential-tools/02-cards.md).

:::note
El cronograma está en versión beta. Algunas de las funciones descritas o mostradas están sujetas a cambios o pueden no estar disponibles hasta el lanzamiento de la versión de disponibilidad general más adelante este año. Asegúrate de volver a consultar este artículo para conocer las actualizaciones a medida que el cronograma siga evolucionando.
:::

## Funciones principales

- **Personaliza un cronograma interactivo** en cualquier lugar de tu tablero de Miro.
- **Agrega y elimina registros** dentro del widget Cronograma.
- **Arrastra y suelta tarjetas de Miro, Jira y Azure** en el widget Cronograma.*
- **Crea grupos de registros** para organizar la información de manera lógica.
- **Cambia el tamaño de cada barra de tiempo** para cambiar las fechas de los registros individuales.
- **Escala la vista de cronograma y las barras de tiempo** automáticamente cuando ajustes las fechas.
- **Incluye varios widgets Cronograma** con diferentes orígenes de datos en el mismo tablero de Miro.
- **Comparte tu cronograma** con los miembros del equipo y las partes interesadas.

## Agregar un cronograma a tu tablero

1. Abre un tablero de Miro.
2. Selecciona **Más aplicaciones** (**+**) en la [barra de herramientas de creación](../../getting-started/start-here/your-first-board/05-toolbars.md).
3. Busca y selecciona **Cronograma**.
   El cursor ahora se muestra como el ícono de cronograma.
4. Selecciona cualquier lugar del tablero de Miro para colocar el widget Cronograma.

![](../../../../../../docs/using-miro/formats/images/19967187350162_674eabbc-5629-426a-aa7d-c6199cc9687a.png)

*Colocar el widget Cronograma*

*En la versión beta, la interacción del widget Cronograma con tarjetas de Jira es limitada. No está disponible la interacción con tarjetas de Azure.

## Interacciones con el cronograma

El widget Cronograma proporciona varios controles que te permiten gestionar el Planificador.

### Agregar un registro

Selecciona el signo más (**+**) encima de la columna de registros. Aparecerá un nuevo registro en el cronograma.

Para reposicionar un registro, arrástralo y suéltalo más arriba o más abajo en el Planificador. También puedes arrastrar y soltar la barra de tiempo correspondiente.

### Editar el texto del registro

Selecciona el registro o la barra de tiempo y, a continuación, selecciona el texto. El cursor parpadeante indica que el texto está listo para editar.

### Eliminar un registro

1. Selecciona el registro o la barra de tiempo que quieras editar.
2. Elimina el texto.
   Aparecerá un diálogo debajo del cronograma para advertirte que la eliminación es permanente.
3. Para eliminar el registro, selecciona **Eliminar de todos modos**.

:::warning
En la versión beta, no es posible deshacer la acción.
:::

### Cambiar las fechas de inicio y finalización

Selecciona el botón del calendario dentro del widget Cronograma y, a continuación, elige las fechas de inicio y finalización.

El Planificador se ajusta automáticamente según tu selección.

Para cambiar las fechas de inicio y finalización de un registro específico, selecciona y arrastra cualquiera de los extremos de la barra de tiempo.

![](../../../../../../docs/using-miro/formats/images/19967187352978_0c37764f-62f0-4a06-b031-e0b6229807be.png)

*Cambiar las fechas de inicio y finalización en el widget Cronograma*

### Cambiar el color del registro

Selecciona el círculo de color en la columna de registros y, a continuación, selecciona un color.

Se cambiará el color del registro y de la barra de tiempo para que coincida con tu selección.

### Reposicionar los registros

En la columna de registros, arrastra y suelta un registro para reposicionarlo en el Planificador. También puedes arrastrar y soltar una barra de tiempo.

### Crear un grupo de registros

Los grupos te permiten organizar los registros de forma lógica, por ejemplo, si quieres ordenar un roadmap por hito.

Para crear un grupo, selecciona los tres puntos (**...**) encima de la columna de registros y, a continuación, selecciona **Agregar grupo nuevo**.

![](../../../../../../docs/using-miro/formats/images/19967187355794_4f687249-7573-4110-9c27-bb8dd45c8454.png)

*Agregar un nuevo registro en el widget Cronograma*

**Consejo:** Puedes arrastrar y soltar un registro en otro grupo.

### Eliminar un grupo de registros

Selecciona los tres puntos (**...**) encima de la columna de registros y, a continuación, selecciona **Eliminar grupo**.

## Agregar tarjetas al cronograma

El widget Cronograma visualiza los datos de las tarjetas de Miro, Jira y Azure.

En tu tablero de Miro, simplemente arrastra y suelta cualquier tarjeta en un widget Cronograma.

&lt;screenshot&gt;

:::warning
En la versión beta, la interacción del widget Cronograma con tarjetas de Jira es limitada. No está disponible la interacción con tarjetas de Azure.
:::

## Compartir tu cronograma

En tu tablero de Miro, sigue estos pasos:

1. Selecciona el widget Cronograma que quieres compartir.
   Aparecerá el menú contextual encima del widget.
2. Selecciona el menú **Más** (**...**).
   Se abrirá un menú desplegable.
3. Selecciona **Copiar enlace**.
4. Comparte el enlace con cualquier persona que tenga permisos para ver el tablero.
