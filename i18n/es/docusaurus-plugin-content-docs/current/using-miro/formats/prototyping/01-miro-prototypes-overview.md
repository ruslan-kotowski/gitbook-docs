La creación de prototipos en Miro ayuda a los equipos a explorar ideas visualmente y a crear versiones iniciales de experiencias digitales. Miro proporciona herramientas básicas para la creación manual de pantallas, y un complemento opcional con **Miro Prototypes** que amplía estas funcionalidades con creación impulsada por IA y comportamientos interactivos.

Puedes usar ambos enfoques juntos a lo largo de tu flujo de trabajo.

## **Herramientas recomendadas para prototipado**

El flujo de trabajo de prototipado de Miro se basa en cuatro tipos de herramientas:

- **Componentes** — elementos de UI, dispositivos, iconos y componentes avanzados.
- **Métodos de creación** — creación manual de pantallas o generación impulsada por IA.
- **Interacción** — diseños estáticos o vistas previas interactivas con clics.
- **Formato** — Contenedor para tus prototipos con acceso rápido a modo sin distracciones y vistas previas.

Tu acceso depende de tu plan y la disponibilidad de complementos.

## **Cómo funcionan las herramientas juntas**

Las herramientas de prototipado de Miro están diseñadas para ser usadas de manera conjunta, no como caminos separados. La mayoría de los equipos combinan la creación manual con la creación potenciada por IA a lo largo de su flujo de trabajo.

Podrías:

- Generar un conjunto inicial de pantallas con IA.
- Reorganizar o ajustar pantallas manualmente.
- Agregar componentes a mano.
- Usar IA nuevamente para rediseñar o ampliar el prototipo.
- Agregar navegación interactiva para las sesiones de comentarios.
- Continuar refinando manualmente a medida que la idea se desarrolla.

Este enfoque híbrido te ofrece **velocidad, flexibilidad y control**.
