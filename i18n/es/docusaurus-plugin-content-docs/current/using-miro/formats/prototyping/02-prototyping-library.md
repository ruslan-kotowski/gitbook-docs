Usa la **biblioteca de prototipos** para construir diseños de prototipos directamente en el lienzo de Miro. La biblioteca incluye pantallas, componentes de interfaz de usuario e íconos que te ayudan a visualizar flujos y estructurar ideas desde el principio.

Puedes usar la biblioteca de prototipos para crear prototipos estáticos. Funciones como **componentes avanzados, líneas de conexión y vista previa interactiva** requieren el **complemento de Miro Prototypes**.

![prototyping-library.png](../../../../../../../docs/using-miro/miroverse/prototyping/images/31804538064914_prototyping-library.png)

*La biblioteca de Prototipos tiene todo lo que necesitas para crear manualmente flujos de una o varias pantallas en Miro*

## Abre la biblioteca de Prototipos

1. En el lienzo, desde la [barra de creación](../../working-on-the-board/02-miro's-new-simplified-user-interface.md) haz clic en **Herramientas, Medios e Integraciones** (![icon-tools.svg](../../../../../../../docs/using-miro/miroverse/prototyping/images/26758266547986_icon-tools.svg)).
2. Busca y encuentra **Prototipos**, luego haz clic en **Biblioteca de prototipos.**
3. Se abre el panel de la **Biblioteca de prototipos****.**

## ¿Qué contiene la biblioteca de prototipos?

La Biblioteca de prototipos está organizada en pestañas. Todos los usuarios pueden utilizar la biblioteca para ensamblar diseños de prototipos estáticos usando pantallas, componentes de interfaz de usuario e iconos.

:::tip
Para prototipos generados por IA y flujos interactivos, utiliza la biblioteca de Prototipos junto con [**Miro Prototypes**](03-miro-prototypes.md).
:::

### Pantallas

**Pantallas** son marcos prediseñados para flujos de prototipado. Puedes agregar pantallas de **Móvil**, **Tableta** o **Escritorio** a tu lienzo y construir diseños arrastrando elementos de interfaz de usuario sobre ellos.

#### **Trabajar con pantallas**

- **Mostrar u ocultar** el marco de la pantalla (para que parezca un marco de dispositivo o un simple marco)
- **Rotar** una pantalla
- **Redimensionar** una pantalla arrastrando para extender su altura (solo verticalmente)

### Componentes de IU

Los componentes de IU son elementos comunes de interfaz que puedes arrastrar a las pantallas, tales como botones, campos de entrada, barras de navegación y elementos de formularios.

Puedes:

- Arrastrar componentes a una pantalla
- Redimensionar y reposicionar componentes
- Editar texto y estilo básico desde el menú contextual

:::note
Las opciones del menú contextual varían dependiendo del elemento que selecciones.
:::

Cuando se habilita el [**Miro Prototypes add-on**](07-miro-prototypes-add-on.md), algunos componentes de la UI se vuelven **interactivos en modo de vista previa**. Por ejemplo, botones, deslizadores, campos de entrada y menús desplegables responden a las acciones del usuario según las líneas de conexión que hayas definido.

Algunos conjuntos de componentes, como los **componentes avanzados**, están disponibles solo con el **Miro Prototypes add-on**. Si el complemento no está habilitado, estos componentes pueden aparecer en la biblioteca con un indicador.

### Íconos

La pestaña de **Íconos** incluye una biblioteca de íconos que puedes buscar y usar en tus prototipos.

#### **Agregar o reemplazar un ícono**

1. Arrastra un ícono desde la biblioteca al lienzo.
2. Selecciona el ícono para actualizar su color desde el menú contextual.
3. Elige **Reemplazar ícono** para intercambiarlo por otro sin cambiar su posición ni tamaño.

### Esquemas de página (legado)

La pestaña de **Esquemas de página** contiene elementos de esquemas de página heredados. Estos elementos siguen disponibles y editables para los tableros existentes, pero los prototipos nuevos deben usar pantallas y componentes de interfaz de usuario de la biblioteca de prototipos.

## Líneas de conector e interactividad (complemento de Miro Prototypes)

**Las líneas de conexión** te permiten definir la navegación entre pantallas en un prototipo. Cuando el [**Miro Prototypes add-on**](07-miro-prototypes-add-on.md) está habilitado, puedes crear líneas de conexión entre elementos y pantallas para construir flujos de múltiples pasos.

Las líneas de conexión también habilitan la **vista previa interactiva**. En el modo de vista previa, las pantallas conectadas se comportan como un flujo clicleable, y las pantallas se desplazan verticalmente si se extienden más allá del viewport. Sin el add-on, las líneas de conexión y el comportamiento interactivo no están disponibles.

:::tip
Algunos elementos de la interfaz de usuario muestran un ícono de rayo cuando se añaden a una pantalla. En flujos de varias pantallas, arrastra el ícono de rayo para crear una línea de conexión entre pantallas.
:::

## Preguntas frecuentes

**¿Puedo agregar mis propios elementos a la biblioteca?**

No. Puedes agregar contenido personalizado a tu tablero, pero no puedes añadir nuevos elementos a la biblioteca de Prototipos.

**¿Qué diferencia hay con la nueva biblioteca de Prototipos?**

La biblioteca de Prototipos soporta pantallas, componentes de UI actualizados, iconos y vistas previas interactivas clicables. Las funciones avanzadas e interactivas requieren el complemento de Miro Prototypes.

**¿Está disponible la biblioteca de prototipos sin el complemento?**

Sí. Puedes usar la biblioteca de prototipos para crear diseños estáticos de prototipos. Las conexiones interactivas y los componentes avanzados requieren el complemento Miro Prototypes.

**¿Sigue estando disponible la biblioteca de wireframes?**

Sí. La pestaña de wireframes está disponible en la biblioteca de prototipos, y los wireframes existentes continúan funcionando.
