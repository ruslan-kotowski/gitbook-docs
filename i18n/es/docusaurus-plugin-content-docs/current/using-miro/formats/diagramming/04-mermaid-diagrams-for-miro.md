Con la aplicación Mermaid, puedes crear y embeber fácilmente diagramas ricos basados en código directamente en tus tableros de Miro. Esto te permite visualizar sistemas complejos, flujos de trabajo o estructuras de datos utilizando una sintaxis simple basada en texto, mejorando la colaboración y la comprensión.

![Demonstration of changing Mermaid diagram code and seeing a live preview in the Miro app.](../../../../../../../docs/using-miro/formats/diagramming/images/21017683206802_mermaid%20diagrams.gif)*Cambiando un código de diagrama y viendo la actualización de la vista previa en tiempo real*

## Instala la aplicación Mermaid

Puedes instalar la aplicación Mermaid desde el Miro Marketplace o directamente desde la barra de herramientas de Creación dentro de un tablero de Miro.

Para instalar desde el Marketplace de Miro:

1. Navega al [Marketplace de Miro](http://miro.com/marketplace) o sigue [este enlace directo a la aplicación Mermaid](https://miro.com/marketplace/mermaid/).
2. Selecciona un equipo de Miro para completar la instalación.

También puedes instalar la aplicación desde la barra de herramientas de creación:

1. En la barra de herramientas de creación a la izquierda de tu tablero, selecciona **Herramientas, Medios e Integraciones** (**+**). El panel de **Herramientas, medios e integraciones** se abrirá.
2. En la pestaña **Herramientas**, busca y selecciona **Diagramas de Mermaid**.
3. El panel de la aplicación **Mermaid Diagrams** se abrirá, y la aplicación se añadirá a tu barra de herramientas.

:::note
**Nota:** Los usuarios que no sean administradores no pueden instalar aplicaciones si la instalación de aplicaciones está restringida en los ajustes del equipo.
:::

## Crear y agregar diagramas a los tableros de Miro

Una vez instalada, la aplicación Mermaid te permite generar diagramas usando código basado en texto y agregarlos a tu tablero como imágenes.

Después de la instalación, encontrarás la aplicación Mermaid en la barra de herramientas de Creación. La aplicación se abre con un código de muestra predeterminado. A medida que modificas el código para construir tu diagrama, este se actualiza en el área de vista previa a la derecha, permitiéndote ver tus cambios en tiempo real.

La aplicación Mermaid incluye varios diagramas de muestra que puedes acceder desde la esquina inferior izquierda del panel de la aplicación. Puedes seleccionar una de estas muestras y luego personalizarla para que se ajuste a tus necesidades.

Puedes cambiar el tamaño del panel del editor de código arrastrando su borde derecho.

![Redimensionar el panel del editor de código para diagramas de Mermaid arrastrando su borde.](../../../../../../../docs/using-miro/formats/diagramming/images/21017653585426_change%20the%20panel%20width.gif)

A medida que termines de construir tu diagrama, haz clic en **Add to board**. El diagrama se añadirá a tu tablero como una imagen.

## Editar diagramas existentes

También puedes modificar diagramas de Mermaid que ya están en tu tablero de Miro.

1. Haz clic en la imagen del diagrama Mermaid en tu tablero para seleccionarla.
2. Haz clic en el icono de **Mermaid** en el menú contextual que aparece (o encuéntralo en la barra de herramientas de Creación).
3. El editor de Mermaid se abrirá con el código del diagrama. Haz tus cambios en el editor de código.
4. Haz clic en **Actualizar diagrama**.
5. Volverás a tu tablero de Miro, y el diagrama en el tablero se actualizará con tus cambios.

## Información adicional

Aquí tienes algunos recursos adicionales y detalles para trabajar con diagramas de Mermaid en Miro.

### Sintaxis de Mermaid y documentación

La aplicación Mermaid utiliza una sintaxis específica para generar diagramas a partir de texto. Para obtener información detallada sobre la sintaxis, incluidos los tipos de diagramas soportados y las opciones, consulta la [documentación oficial de Mermaid](https://mermaid-js.github.io/mermaid/). También puedes acceder a un enlace a esta documentación desde la esquina inferior izquierda del panel de la aplicación Mermaid dentro de Miro.

### Compartir y exportar diagramas

Una vez que un diagrama de Mermaid se añade a tu tablero, funciona como una imagen. Puedes descargar esta imagen directamente desde el tablero si es necesario. Para colaborar con otros, puedes [compartir el tablero de Miro que contiene el diagrama](../../sharing-boards/03-sharing-boards-and-inviting-collaborators.md).
