Si tienes problemas cuando usas Miro en un dispositivo híbrido con pantalla táctil o con un bolígrafo digital, asegúrate de revisar los ajustes del navegador. Ten presente que los pasos sugeridos aquí solo son útiles para un navegador.

## Google Chrome

1. Abre una nueva página en Google Chrome.
2. Ingresa **chrome://flags** en la barra de direcciones de Chrome e ingresa **t****ouch** en la línea de búsqueda.
3. Asegúrate de que **Touch UI Layout**(Diseño de UI táctil) esté **Enabled** (Habilitado)
4. Asegúrate de que **Touch initiated drag and drop**(Arrastrar y soltar con función táctil) esté **Enabled** (Habilitado).
5. Usa la pantalla táctil/bolígrafo digital para ver la diferencia.

## Edge

1. Abre una página nueva en Edge.
2. Ingresa **about:flags** en la barra de direcciones de Edge.
3. Presiona Ctrl + F para buscar eventos**táctiles**
4. Asegúrate de que **Touch events** (Eventos táctiles) esté **Always on** (Siempre activado).
5. Usa la pantalla táctil/bolígrafo digital para ver la diferencia.
