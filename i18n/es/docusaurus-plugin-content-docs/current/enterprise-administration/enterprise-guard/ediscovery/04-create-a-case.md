Crear un caso para retención legal es el primer paso crítico en el proceso de eDiscovery cuando se anticipa un litigio o una investigación. Un caso sirve como la base organizativa para gestionar el proceso de retención legal, permitiendo una clara identificación, documentación y supervisión de todas las actividades relacionadas con la conservación de datos. Si no se crea adecuadamente un caso, el proceso de retención legal carece de estructura, lo que puede ocasionar la pérdida o eliminación accidental de información crítica y generar riesgos y potenciales sanciones legales.

Como [eDiscovery Admin](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md), juegas un rol clave en la iniciación y gestión de las retenciones legales. Al crear un caso, estableces la estructura formal necesaria para asegurar que todos los tableros de Miro relevantes se conserven adecuadamente durante la duración del procedimiento legal. Uno de los propósitos de crear un caso es que actúa como un contenedor que permite a los admin agrupar varias retenciones legales bajo un solo caso. Esto puede ser especialmente útil en escenarios donde diferentes retenciones legales son parte de la misma investigación, como en una causa judicial.

En muchas ocasiones, es necesario colocar a varios usuarios bajo retención legal. A medida que la investigación o la causa legal avancen, es posible que necesites crear retenciones adicionales y mantener todo organizado bajo un solo caso. Agrupar todas las retenciones relacionadas en un solo caso permite una mejor gestión y supervisión, ya que todas las retenciones asociadas con una investigación específica se contienen dentro de una única estructura central.

Al crear y gestionar eficazmente un caso de retención legal, garantizas que todos los datos relevantes se conserven y optimizas el proceso de gestión de investigaciones complejas, reduciendo los riesgos legales para tu organización.

Para crear un caso, realiza los siguientes pasos:

:::note
Debes tener el [rol de admin de eDiscovery](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md) para realizar esta tarea. Para solicitar el rol de admin de eDiscovery, ponte en contacto con el admin de empresa.
:::

1. Ve a tus configuración de Miro.
2. En el panel izquierdo, bajo **Enterprise Guard**, haz clic en **eDiscovery**.
3. En la página de **eDiscovery**, haz clic en la pestaña **Casos**.
4. En la página de **Casos**, haz clic en **Crear caso**.
5. En la página **Crear caso**, ingresa la información adecuada para cada campo. La tabla siguiente enumera cada campo y su descripción.

   |  |  |
   | --- | --- |
   | **Campo** | **Descripción** |
   | Nombre del caso  **(obligatorio)** | Nombre del caso.  Longitud máxima: 60 caracteres. |
   | Descripción  **(opcional)** | Descripción para el caso.  Longitud máxima: 300 caracteres. |
6. Haz clic en **Crear caso**. El caso se crea y aparece en la lista de casos en la página de eDiscovery. Ahora puedes proceder a agregar una retención legal al caso.
