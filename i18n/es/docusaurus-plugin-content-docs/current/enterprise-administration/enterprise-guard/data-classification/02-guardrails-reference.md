## Barreras de protección del contenido

La tabla siguiente enumera las barreras de protección del contenido compatibles en la versión actual.

|  |  |  |
| --- | --- | --- |
| **Barrera de protección** | **Descripción** | **Usuarios afectados** |
| **Bloquear la replicación de contenido** | - Las opciones para gestionar la replicación de contenido tanto en la interfaz de usuario de Miro como en las API de Miro no están disponibles. Por ejemplo, la opción para actualizar quién puede copiar el contenido del tablero no está disponible en la interfaz de usuario y la opción para actualizar el acceso de copia a través de la API de actualización del tablero no está disponible.  - Las opciones para la replicación de contenido no están disponibles en la interfaz de usuario de Miro. Esto incluye:     - Duplicar un tablero a otros     equipos de usuarios     - Descargar archivos en el tablero     - Descargar imágenes en el tablero     - Descargar PDFs en el tablero     - Copiar contenido u objetos de      el tablero a otro tablero     - Exportar tableros como imagen     - Exportar tableros como PDF     - Guardar tableros como una personalizada      plantilla     - Replicación de contenido a través de APIs son      no disponible. La API devuelve un      error 403 como respuesta. | El propietario y los copropietarios del tablero no están restringidos. El propietario y los copropietarios del tablero pueden realizar acciones de replicación de contenido, ya que esto es necesario para que el propietario actualice el tablero y cree versiones sanitizadas de los tableros para una mayor colaboración.  Todos los demás están restringidos. |
| **Bloquear el uso de Miro AI** | Todas las funciones de Miro AI están deshabilitadas, lo que impide el acceso a funcionalidades impulsadas por inteligencia artificial, como la generación de texto, el reconocimiento de imágenes y las sugerencias inteligentes.  Los usuarios no podrán interactuar ni activar ninguna herramienta impulsada por inteligencia artificial dentro de Miro.  El contenido existente generado por Miro AI permanece sin cambios, y los usuarios pueden modificar o ampliar este contenido. Sin embargo, los usuarios ya no pueden usar Miro AI para editar o actualizar el contenido. | Todos están restringidos, incluidos el propietario y los copropietarios del tablero. |

## Barreras de protección de uso compartido

La siguiente tabla enumera las barreras de protección de uso compartido compatibles en la versión actual.

|  |  |  |
| --- | --- | --- |
| **Barrera de protección** | **Descripción** | **Usuarios afectados** |
| **Bloquear el uso compartido público** | La opción de compartir con *Cualquier persona con el enlace* no está disponible en la interfaz de usuario de Miro.  El uso compartido público a través de la API no está disponible. La API devuelve un error 403 como respuesta.  Bloquear el uso compartido público no es aplicable a los tableros insertados utilizando el enlace de acceso de Live Embed, ya que estos tableros no se consideran compartidos a través de enlace público. Para más información, consulta [Cómo permitir o restringir la inserción de los tableros de Miro en las aplicaciones compatibles.](../../managing-apps-on-enterprise-plan/05-how-to-allow-or-restrict-embedding-miro-boards-in-supported-apps.md) | Todos están restringidos, incluido el propietario del tablero. |
| **Bloquear el uso compartido con equipos** | - La opción de compartir con *Cualquier persona del equipo* no está disponible en la interfaz de Miro.  - El uso compartido con equipos a través de API no está disponible. La API devuelve un error 403 como respuesta. | Todos están restringidos, incluido el propietario del tablero. |
| **Bloquear el uso compartido con la organización** | - La opción de compartir con *Cualquier persona de la organización* no está disponible en la interfaz de Miro.  - El uso compartido con la organización a través de API no está disponible. La API devuelve un error 403 como respuesta. | Todos están restringidos, incluido el propietario del tablero. |
| **Bloquear el uso compartido fuera de los dominios permitidos** | - El uso compartido de tableros mediante invitación directa por correo electrónico está limitado a usuarios cuyas direcciones de correo electrónico pertenezcan a los dominios permitidos en esta lista. Esta barrera de protección no afecta el acceso otorgado a través de enlaces de equipo, organización o públicos, ya que estos están controlados por barreras de protección separadas.  Puedes agregar hasta 20 dominios permitidos en esta lista.  Este guardarraíl está diseñado para funcionar con la configuración de [**Seguridad > Uso compartido > Dominios permitidos**](../data-security/07-sharing-policy-on-enterprise-plan.md), la cual se puede configurar tanto a nivel de organización como de equipo. Esto significa que si tienes habilitada la configuración de **Dominios Permitidos**, debes asegurarte de que el dominio al que te gustaría permitir compartir tableros esté listado tanto en la configuración de Barreras de Protección Inteligentes como en la configuración de [**Seguridad > Uso compartido > Dominios permitidos**](../data-security/07-sharing-policy-on-enterprise-plan.md).   **Notas:**  Si el tablero ya fue compartido con direcciones de correo que no están en esta lista, los usuarios que ya tienen acceso al tablero seguirán teniendo acceso.  Los usuarios existentes que ya tienen acceso a un tablero, pero no están en la lista de dominios permitidos, se indican en la interfaz de administración de acceso al tablero. Puedes quitar el acceso a estos usuarios manualmente. Puedes ver fácilmente información sobre las restricciones de dominio aplicadas a través de la página de Clasificación.   **Ejemplo 1:** **Seguridad > Uso compartido > Dominios permitidos:** miro.com, gmail.com  **Dominios Permitidos en Guardarraíl:** miro.com  ***Resultado:*** El uso compartido de tableros mediante invitación directa por correo está limitado a correos que terminen en miro.com. Aunque gmail.com está permitido en la configuración de Seguridad > Uso compartido > Dominios permitidos, no está permitido por la barrera de protección.  **Ejemplo 2:** **Seguridad > Uso compartido > Dominios permitidos:** miro.com, gmail.com  **Dominios permitidos para Guardrail:** example.org, example.com  ***Resultado:*** El uso compartido de tableros a través de invitaciones directas por correo electrónico no está permitido para ningún dominio porque no hay solapamiento entre las dos listas. | El uso compartido de tableros a través de invitaciones directas por correo está limitado a los usuarios cuyas direcciones de correo pertenecen a los dominios permitidos en esta lista. Esta barrera de protección no afecta el acceso otorgado a través de enlaces de equipo, organización o públicos, ya que estos están controlados por barreras de protección separadas.  Si el tablero ya fue compartido con direcciones de correo que no están en esta lista, las personas que ya tienen acceso al tablero continuarán con ese acceso.   Esta barrera de protección está diseñada para funcionar con la configuración de [**Seguridad > Uso compartido > Dominios permitidos**](../data-security/07-sharing-policy-on-enterprise-plan.md), la cual se puede configurar tanto a nivel de organización como de equipo. Consulta la columna de descripción para obtener una descripción detallada y ejemplos. |
