Para ajustar qué etiquetas están bloqueadas o alternar el escaneo de código:

1. Ve a **Configuración** → **Enterprise Guard** → **Descubrimiento de datos** → **Configuración**.
2. En **Bloqueo de avisos**, selecciona **Administrar**.
3. En el panel lateral, realiza cualquiera de las siguientes acciones:
   - Activa o desactiva **Seleccionar todo**.
   - Marca o desmarca las categorías de etiquetas específicas que deseas bloquear.
   - Activa o desactiva **Escaneo de código**.
4. Selecciona **Aplicar cambios**.

Los cambios se aplican inmediatamente para todos los usuarios. Las instrucciones que contengan elementos recientemente desbloqueados procederán. Las instrucciones que contengan elementos aún bloqueados continuarán siendo detenidas.
