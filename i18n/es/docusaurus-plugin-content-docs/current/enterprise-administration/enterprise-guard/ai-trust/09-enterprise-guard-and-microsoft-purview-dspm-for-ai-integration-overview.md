Para las organizaciones que utilizan Microsoft Entra ID (anteriormente Azure AD) como su proveedor de identidad, Enterprise Guard reenvía de manera segura las instrucciones de IA y las respuestas a Microsoft Purview Data Security Posture Management (DSPM) para que los equipos de seguridad y cumplimiento puedan monitorear, auditar y controlar el uso de inteligencia artificial generativa desde una plataforma de confianza única, reduciendo la carga operativa, mitigando riesgos como la filtración y el mal uso de datos, y fortaleciendo la gobernanza de inteligencia artificial de nivel empresarial de Miro.

:::note
La versión Beta admite formatos de Miro AI, incluidos diagramas, mapas mentales, documentos, prototipos, notas adhesivas y tablas, pero no imágenes. Estamos trabajando para añadir soporte para imágenes y más funciones de IA en futuras versiones.
:::

## **Para quién es esto**

Esta función está disponible en la versión Beta para clientes de Enterprise Guard que gestionan Miro y Microsoft Entra ID (antes Azure AD)/Microsoft Purview.

## **Qué obtienes**

- **Visibilidad centralizada:** Ver el uso de Miro AI en el centro de IA de Microsoft Purview.
- **Auditabilidad:** Las instrucciones (entradas de usuario) y respuestas (salidas de IA) se registran para revisión.
- **Alineación con la gobernanza:** Usa tus flujos de trabajo existentes de Purview para monitoreo, alertas y retención.

Para más información, consulta [la documentación detallada aquí](../../enterprise-subscription-management/integrations/02-enterprise-guard-and-microsoft-purview-dspm-for-ai-integration-overview.md).
