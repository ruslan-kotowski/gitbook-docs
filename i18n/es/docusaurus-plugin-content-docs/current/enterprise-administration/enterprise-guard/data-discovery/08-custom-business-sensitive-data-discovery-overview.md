[Los admins de contenido sensible](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md) pueden aprovechar el descubrimiento de datos personalizados sensibles de la empresa para automatizar de manera eficiente la identificación y etiquetado de tableros de Miro que contengan información sensible de la empresa personalizada, incluyendo propiedad intelectual. Con el descubrimiento personalizado de datos sensibles de la empresa, puedes:

- Utiliza búsquedas personalizadas para detectar datos sensibles específicos de tu empresa.
- Agrega condiciones, como *contiene tarjetas de Jira*, *contiene* *bloques de código*, *contiene tarjetas de Azure*, o *contiene pantallas de prototipos*, junto con palabras clave para refinar los resultados del descubrimiento de datos y lograr mayor precisión.
- Gestiona todas las etiquetas sensibles de la empresa en una ubicación centralizada para facilitar la organización y el control.

:::note
Puedes crear hasta 100 etiquetas sensibles de la empresa.
:::

Para obtener información sobre cómo crear etiquetas personalizadas, consulta [nuestra documentación aquí](12-create-labels-and-keywords-for-custom-business-sensitive-information.md).
