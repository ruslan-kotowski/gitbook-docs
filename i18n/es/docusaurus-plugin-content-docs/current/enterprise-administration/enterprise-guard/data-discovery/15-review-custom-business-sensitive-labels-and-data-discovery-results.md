La página de **Descripción general del descubrimiento de datos** muestra una lista de todas las etiquetas personalizadas sensibles a los negocios configuradas, el estado de las etiquetas, el tipo de etiqueta, el admin que creó la etiqueta, la clasificación del tablero asociada a cada etiqueta, la cantidad de tableros etiquetados con cada etiqueta y el enlace para explorar los tableros. Además, los Admins de Contenido Sensible pueden editar etiquetas personalizadas sensibles al negocio y copiar las IDs de visualización de etiquetas desde la página **Visión General del Descubrimiento de Datos**.

:::note
Para ver los resultados del descubrimiento de datos confidenciales y personalizados, debes tener el [rol de admin de contenido sensible](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md). Para solicitar el rol de admin de contenido sensible, ponte en contacto con el admin de empresa.
:::

## Revisar tableros con datos sensibles para la empresa personalizados

Para explorar los tableros con datos confidenciales para la empresa, realiza los siguientes pasos:

1. Ve a tu [configuración de Miro](https://miro.com/app/settings).
2. En el panel izquierdo, bajo **Enterprise Guard,** haz clic en **Descubrimiento de datos**.
3. En la página de **descubrimiento de datos** **Resumen**, haz clic en el enlace de conteo de tableros. El explorador de contenido aparece con la lista de tableros. Para más información, consulta Revisar tableros con datos sensibles de la empresa.

## Copiar el ID de visualización de la etiqueta

Los nombres de las etiquetas no son visibles en los registros de auditoría. Si quieres ver o buscar registros de auditoría asociados con una etiqueta específica, debes usar el ID de visualización de la etiqueta.

Para obtener el ID de visualización de la etiqueta, realiza los siguientes pasos:

1. Ve a tu [configuración de Miro](https://miro.com/app/settings).
2. En el panel izquierdo, bajo **Enterprise Guard,**  haz clic en **descubrimiento de datos**.
3. En la página **Descripción general** de **descubrimiento de datos**, haz clic en el Elipsis (tres puntos) en la fila de la etiqueta para la que deseas copiar el ID de visualización de la etiqueta, y luego haz clic en **Copiar ID de visualización de la etiqueta**.
