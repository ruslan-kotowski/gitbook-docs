El flujo permite a los usuarios finales de tu organización solicitar acceso a ciertas aplicaciones e integraciones con Miro.  Los admins de empresa pueden optar por aprobar o denegar esas solicitudes.

> ***Actualización de la consola de admin por fases***
> La nueva consola de admin de Miro facilita los flujos de trabajo de administración esenciales con una configuración reorganizada y patrones de UX comunes mejorados. La nueva consola de admins se irá desplegando a lo largo de varias semanas.
>
> Para ver un resumen de todos los cambios, consulta [la nueva consola de admins de Miro (BETA](../managing-enterprise-teams-and-content/01-miro's-new-admin-console.md)).

> **Disponible para: [Plan Enterprise](../../plans-billing/miro-plans/04-enterprise-plan.md)**

### Guía del usuario

Si ciertas aplicaciones requieren la aprobación de un admin en el plan Enterprise de tu empresa, puedes solicitar acceso a las aplicaciones e integraciones con Miro.

Estos son los pasos para solicitar acceso:

1. Abre un tablero y haz clic en el icono **de Aplicaciones** de la barra de herramientas.  Selecciona la app que quieras utilizar.
   agregar_más_aplicaciones.jpg
   La opción de agregar más aplicaciones desde la barra de herramientas
   También puedes ir [al Marketplace de Miro](https://miro.com/marketplace/) y descubrir todas las apps disponibles.
2. Si una aplicación requiere aprobación por parte de un admin, verás la opción de enviar una solicitud a tu admin.
3. Aquí también puedes seleccionar el motivo de la instalación.
4. Haz clic en **Send request (enviar solicitud)** y tu admin recibirá una notificación.  Pueden aprobar o denegar tu solicitud.
   send_app_request.jpg
   La opción para enviar una solicitud a fin de instalar la aplicación en el plan Enterprise
5. Una vez que el admin haya tomado su decisión, recibirás una notificación informándote de si tu solicitud fue aprobada o denegada.

### Guía del admin

> **Configurado por: admins de empresa**

Los admins de empresa pueden configurar permisos de usuario para instalar aplicaciones y requerir aprobación de admin para la instalación de aplicaciones.  Para obtener más detalles, consulta esta guía/span>. Una vez que un usuario haya solicitado acceso para usar una aplicación, sigue los pasos siguientes para aprobar o denegar la solicitud.

1. Una vez que la solicitud haya sido enviada por un usuario, recibirás una notificación por email.  La notificación se enviará a todos los admins de empresa.
2. Si vas a Configuración de **la empresa** > **Apps e integraciones** > **Apps** > **Solicitudes de apps**, verás la lista de solicitudes de usuarios abiertas.
3. Podrás ver el nombre de la aplicación, el equipo, la fecha de solicitud y el nombre de usuario, así como más detalles sobre las necesidades específicas del usuario y los permisos de la aplicación.
4. Aquí puedes optar por aprobar o denegar cada solicitud.  Cuando apruebas la solicitud, la app también queda aprobada para que la instalen otros usuarios.
5. Una vez que apruebes o rechaces la solicitud, el usuario recibirá una notificación.
