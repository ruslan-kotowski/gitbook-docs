El programa de versión beta pública ofrece a los usuarios acceso anticipado a las funciones de Miro cuando aún no están disponibles de forma general. Como admin de empresa, puedes habilitar y deshabilitar el programa de versión beta pública para todos los usuarios de tu suscripción Miro Enterprise.

Podrán experimentar las últimas funciones de Miro y enviar comentarios durante el desarrollo, lo que garantiza un producto final óptimo para todos los usuarios de Miro.

> **Disponible para:** Enterprise
> **Quién puede hacerlo:** admins de empresa

## Funciones principales

Con el programa de versión beta pública habilitado, los usuarios Enterprise obtienen las siguientes funciones principales:

- **Habilitación de autoservicio**
  Los admins de empresa pueden habilitar o deshabilitar las funciones en versión beta pública para toda la organización.
- **Implementación automatizada**
  Las funciones beta se implementan automáticamente para los usuarios sin sobrecarga adicional.
- **Recopilación de comentarios**
  Los usuarios proporcionan comentarios sobre las funciones de Miro antes de que estén disponibles de forma general.

## Cómo habilitar o deshabilitar el programa de versión beta pública

Para habilitar o deshabilitar el programa de versión beta pública en tu organización, sigue estos pasos:

1. En la configuración de admin, haz clic en Organización y luego en **Activación de funciones**.
2. En **Programa de versión beta pública**, selecciona una de las siguientes opciones:
   - **No disponible**
     Ya deshabilitaste el programa de versión beta pública para tu organización.
   - **Disponible para todos**
     Ya habilitaste el programa de versión beta pública para tu organización.
