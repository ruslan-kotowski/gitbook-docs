El programa de licencias flexibles (FLP) es nuestro modelo de licencias más común. Con el FLP, tus licencias escalan a medida que aumenta su uso. Estima las necesidades de tu organización y añade o elimina licencias sin costos iniciales, costos retroactivos o cambios de contrato.

Obtén más información sobre nuestras [licencias Enterprise](02-enterprise-licensing.md).

## Cómo funciona el programa de licencias flexibles (FLP)

La revisión de tu suscripción FLP se realiza en función de la frecuencia de ajuste que hayas definido. Al acercarse tu periodo de ajuste, los clientes tendrán una charla basada en datos con su equipo de cuentas de Miro para decidir cuántos de sus nuevos usuarios necesitarán una licencia Estándar o Completa (heredada) en el futuro. El contrato se modificará con las licencias adicionales, sin tarifas retroactivas.

## Actualización de licencias FLP

Los usuarios pueden tener una licencia Estándar, Completa (heredada), Free, o una licencia gratuita limitada. Algunas acciones desencadenan una mejora de licencia en las suscripciones FLP.

Descubre más sobre [gestionar licencias en FLP](05-license-management-on-the-flexible-licensing-program-flp.md).

|  |  |  |  |
| --- | --- | --- | --- |
|  | **Estándar/** **Completa (legado)** | **Gratis** | **Gratis Restringida** |
| **Opciones de mejora** | Ya se mejoró al tipo de licencia de mayor nivel | **Mejoras automáticas** a una licencia estándar o completa (heredada) cuando:   - creas un tablero - editas un tablero compartido - eres invitado para editar un tablero - te convierten en copropietario del tablero - eres añadido a un [espacio](../../../using-miro/spaces/01-spaces.md) como editor | **Solicitud de mejora de licencia** se envía al admin cuando un usuario:   - trata de crear un tablero o espacio - solicita acceso para editar - recibe una invitación para editar un tablero - se lo asigna como propietario de un tablero |

:::warning
Las licencias de los invitados nunca se actualizan de forma automática.
:::

## Acceso de usuario al FLP

Cada usuario puede tener diferentes roles de Miro (miembro, invitado o visitante) en múltiples [equipos](../../../getting-started/start-here/miro-dashboard/04-profile-and-teams.md) dentro de un plan Enterprise.

Conoce más sobre los roles de Miro y los tipos de licencia en los [Niveles de acceso de usuario en el plan Enterprise](../../user-management/11-user-access-levels-on-enterprise-plan.md).

|  |  |  |  |
| --- | --- | --- | --- |
|  | **Estándar/** **Completa (anterior)** | **Gratis** | **Gratis Restringida** |
| **Miembro** | **Los miembros con una licencia Standard o Full (legacy) pueden:**   - Crear tableros, espacios y plantillas - Editar tableros compartidos - Ver tableros compartidos con el equipo | **Los miembros con una licencia gratuita pueden:**   - ser añadidos a espacios y tableros - ver los tableros compartidos con un equipo (y ver y comentar en los tableros compartidos en equipo) - convertirse automáticamente en miembros estándar o completos (legado) | **Los miembros con licencia gratuita limitada pueden:**   - sumarse a espacios y tableros - ver los tableros compartidos con un equipo (y ver y comentar en tableros compartidos en equipo) |
| **Invitado** | No disponible | **Los invitados con licencia gratuita pueden:**   - ver y comentar en tableros compartidos     **Los invitados con licencia gratuita no pueden:**   - crear o ver tableros compartidos con un equipo - ver o unirse a espacios compartidos con un equipo | **Los invitados con licencia gratuita limitada pueden:**   - ver y comentar |
| **Visitante** | **Los visitantes** no necesitan registrarse en Miro ni tener una licencia.   - Los visitantes pueden ver, comentar y editar tableros (con algunas [limitaciones](../../../using-miro/sharing-boards/08-collaboration-with-visitors.md)) - Los visitantes no pueden ver espacios, tableros o plantillas compartidas dentro de un equipo - Los visitantes no pueden ver la lista de equipos, miembros del equipo ni de los admins de equipo o empresa | | |
