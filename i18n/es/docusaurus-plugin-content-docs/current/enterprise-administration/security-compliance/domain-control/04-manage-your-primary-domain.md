Tu dominio corporativo ayuda a Miro a identificar quién pertenece a tu organización (usuarios internos) y quién no (usuarios externos). Los usuarios con direcciones de correo electrónico de tus dominios corporativos o verificados se consideran internos, mientras que aquellos de otros dominios se consideran externos, incluso si se les ha asignado una licencia de pago.

## ¿Qué es un dominio corporativo?

Un dominio corporativo es el dominio de correo electrónico principal que utiliza tu organización, por ejemplo, `tuempresa.com`. Miro utiliza tu dominio corporativo junto con cualquier dominio verificado para determinar si un usuario pertenece a tu organización.

## ¿Cómo se establece el dominio corporativo?

Miro asigna automáticamente un dominio corporativo cuando tu organización se crea o mejora a un plan Business o Enterprise. Este dominio se basa en la dirección de correo electrónico del creador de la organización. Por ejemplo, si el correo electrónico del creador es `john.smith@example.com`, Miro establece `example.com` como el dominio corporativo.

Para las organizaciones creadas antes de que se introdujera la gestión de dominios, Miro puede asignar un dominio corporativo basado en el dominio de correo electrónico del primer admin de empresa. Puedes conservar este dominio, verificarlo o contactar con soporte si necesitas cambiarlo.

## Gestiona tu dominio corporativo

Para ver y administrar tus dominios, ve a **Configuración de la empresa → Gestión de dominios**.

El dominio marcado con el icono de edificio indica tu dominio corporativo actual.

## Cambiar o eliminar tu dominio corporativo

Cada organización puede tener solo un dominio corporativo a la vez.

Solo puedes eliminar tu dominio corporativo si hay otro dominio verificado disponible. Cuando lo eliminas, uno de tus dominios verificados se convierte en el nuevo dominio corporativo.

Si no hay otro dominio verificado disponible, contacta a Miro Soporte para cambiar o eliminar tu dominio corporativo.

## Agregar y verificar dominios adicionales

Si tu organización utiliza más de un dominio de correo electrónico, puedes agregar y verificar dominios adicionales. Los dominios verificados también se tratan como dominios internos, asegurando que todos los usuarios con direcciones de correo electrónico de la compañía sean reconocidos como parte de tu organización.

## Usuarios externos y licencias

Los usuarios con direcciones de correo electrónico fuera de tus dominios corporativos o verificados se tratan como usuarios externos. Los usuarios externos aún pueden ser invitados como miembros y se les pueden asignar licencias. Ellos:

- siguen clasificados como externos
- acceden al contenido según los equipos asignados
- aparecen en la lista de usuarios como miembros

## Preguntas frecuentes

### ¿Puedo tener más de un dominio corporativo?

No. Cada organización puede tener solo un dominio corporativo. Puedes agregar múltiples dominios verificados.

### ¿Necesito verificar mi dominio corporativo?

No. Miro asigna un dominio corporativo automáticamente. Sin embargo, la verificación es necesaria para habilitar funciones como el inicio de sesión único (SSO) y las políticas de control de dominios.

### ¿Por qué ya veo un dominio corporativo?

Miro puede haber asignado automáticamente un dominio corporativo basado en el primer admin de empresa de tu organización. Esto ayuda a identificar a los usuarios internos desde el principio.

### ¿Qué ocurre si mi dominio ya ha sido reclamado por otra organización?

Aún puedes tener un dominio corporativo asignado, pero puede que necesites contactar con soporte para verificar o actualizar el dominio.

### ¿Qué pasa si mi organización fue creada usando un correo electrónico personal, por ejemplo, Gmail?

En este caso, Miro no puede identificar automáticamente un dominio de la empresa. Los usuarios son tratados como externos hasta que se añada y verifique un dominio corporativo.
