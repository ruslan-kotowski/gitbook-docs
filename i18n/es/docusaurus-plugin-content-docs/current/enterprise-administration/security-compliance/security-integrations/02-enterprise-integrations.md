**Integraciones para Enterprise** es un único lugar donde puedes configurar todas las funciones de admin del plan Enterprise, tales como el inicio de sesión único (SSO), SCIM, SIEM y SAM, para asegurar seguridad adicional y una gestión eficiente de usuarios y suscripciones. Garantiza una manera fácil de configurar integraciones con un solo clic sin requerir la creación de Equipos de Desarrolladores o aplicaciones privadas.

> **Disponible para:** [plan Enterprise](../../../plans-billing/miro-plans/04-enterprise-plan.md)
> **Configurado por:** Admins de empresa

Accede a las **Integraciones para Enterprise** desde la configuración de empresa de tu plan Enterprise, bajo **Aplicaciones e integraciones**.

En esta página, puedes configurar varias opciones de integración para Enterprise.

- **Sistema para la gestión de identidad entre dominios (SCIM)**. Configura el aprovisionamiento automatizado de usuarios y la gestión de usuarios a través de tu proveedor de identidad. [Más información sobre SCIM en Miro](../../security-integrations/system-for-cross-domain-identity-management-scim/02-scim.md).
- **Administración de información y eventos de seguridad.** Recopila y analiza registros de auditoría de tu organización Enterprise de Miro. [Aprende cómo configurarlo](../../security-integrations/security-information-and-event-management-siem/01-miro-app-for-splunk.md).
- **Gestión de activos de software.** Analiza el uso de tu suscripción y administra las licencias de manera eficiente configurando la integración con ServiceNow, Productiv o Zylo. [Aprende más sobre SAM en Miro](../../security-integrations/software-asset-management/01-software-asset-management-miro-enterprise.md).
