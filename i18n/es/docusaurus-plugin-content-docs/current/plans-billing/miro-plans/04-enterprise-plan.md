El [plan Enterprise](https://miro.com/enterprise/) de Miro es la mejor opción para uno o más equipos que crecerán con Miro a lo largo del tiempo. Este plan ofrece las características más robustas que apoyan la seguridad, la escalabilidad y el éxito.

Si quieres determinar si Miro Enterprise es adecuado para tu empresa, puedes probar las características de Enterprise de forma gratuita para ver cómo funcionan para tus equipos. [Comunícate con el equipo de ventas para empezar a usar una prueba de Enterprise.](https://miro.com/contact/sales/)

**Miro Enterprise incluye:**

- [Múltiples equipos dentro de una misma subscripción](../../enterprise-administration/managing-enterprise-teams-and-content/07-team-management-on-enterprise-plan.md)
- [Licencias flexibles](../../enterprise-administration/enterprise-subscription-management/enterprise-licensing/03-flexible-licensing-program-flp.md) disponibles después de la compra inicial sin compromisos por adelantado
- Conjunto completo de [seguridad](../../administration/security-compliance) y características de [administración](https://help.miro.com/hc/categories/4404653171218-Account-Administration):
  - SSO y SCIM
  - Control de dominio
  - Eliminar el uso compartido mediante enlace público
  - Gestión avanzada de usuarios y permisos
  - Gestión avanzada de plugin
  - Clasificación de datos para los tableros
  - Tiempo de espera de sesión inactiva
  - Registros de auditoría
  - Búsqueda avanzada y permisos de gestión de contenido
- [Consolidación de equipos](../../enterprise-administration/managing-enterprise-teams-and-content/06-self-serve-teams-to-enterprise-plan-consolidation.md)
- Integraciones exclusivas para Enterprise
  - AzureDevops, Splunk, ServiceNow
- Compra sin conexión con soporte de incorporación de proveedores
  - ACUERDO DE CONFIDENCIALIDAD, MCA, APÉNDICE DE PROCESAMIENTO DE DATOS
  - Revisión de seguridad
  - Facturación sin conexión para órdenes de compra
- Gerente de cuenta especializado para conversaciones comerciales
- Programa de éxito del cliente

### ¿Por qué elegir el plan Enterprise?

#### **Seguridad**

*Puedes estar tranquilo con protecciones de nivel empresarial*

El conjunto completo de características de seguridad te brinda el grado más alto de protección para tu contenido y usuarios.

*Aprovisionamiento de usuarios agilizado*

Las características de SSO, SCIM, control de dominio y gestión de solicitudes agilizan la administración y reducen los gastos administrativos generales.

#### **Escalabilidad**

*Libertad colaborativa y seguridad con equipos ilimitados*

Los espacios de equipo ilimitados ofrecen lo siguiente:

- Equipos separados para diferentes líneas empresariales
- La capacidad de colaborar transversalmente en los equipos con una licencia, todo mientras se gestiona de forma centralizada
- La flexibilidad de tener equipos separados para clientes externos, lo que proporciona seguridad adicional dentro de tu plan.

*Crece y escala a tu propio ritmo*

El programa de licencias flexibles permite a los nuevos usuarios, después de la compra inicial, "probar antes de comprar".

#### **Éxito**

*Asegúrate de alcanzar tu ROI*

El equipo de cuenta dedicado se asegurará de que tanto los administradores como los usuarios finales aprovechen al máximo su experiencia. Ofrecemos programas de incorporación y recursos de capacitación para que te asegures de alcanzar tus resultados comerciales esperados con Miro.
