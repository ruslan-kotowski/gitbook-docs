Con la **configuración de vista de estadísticas**, los administradores pueden elegir si mostrar u ocultar los nombres de usuario en las vistas de panel que incluyen actividades a nivel de usuario como los principales usuarios de IA. Para más información, consulta la [documentación de estadísticas](../../enterprise-administration/getting-started/admin-analytics/01-analytics-overview.md).
