Estamos introduciendo puntos finales adicionales en la API de exportación de tableros para ayudarte a gestionar las exportaciones de tableros de forma más eficiente. Podrás listar trabajos de exportación en toda tu organización, ver tareas para un trabajo de exportación específico, recuperar enlaces de descarga para tareas de exportación y cancelar trabajos de exportación que ya no sean necesarios. Estas actualizaciones harán que sea más fácil monitorear, controlar y automatizar tus flujos de trabajo de exportación de manera programática.
