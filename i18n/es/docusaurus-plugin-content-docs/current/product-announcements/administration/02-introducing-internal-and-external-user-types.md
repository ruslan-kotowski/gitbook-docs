Los admins pueden identificar el tipo de usuario como interno para los usuarios cuyo correo electrónico está verificado, y como externo para aquellos cuyo correo no lo está. La diferenciación visual entre los tipos de usuario internos y externos conducirá a mejoras funcionales en la gestión de usuarios por parte de los admins en el futuro. Para más información, consulta [Control de dominio](../../enterprise-administration/canvas-25-admin-features/domain-control/01-domain-control.md).
