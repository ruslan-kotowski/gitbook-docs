Miro está profundizando su asociación con Microsoft para lanzar una integración con Microsoft Purview Data Security Posture Management (DSPM) para IA desde el portal de Microsoft Purview. Diseñada para organizaciones que utilizan Azure como su proveedor de identidad, esta función envía indicaciones y respuestas de AI desde Miro directamente al Purview AI hub. Esto proporciona a los equipos de seguridad y cumplimiento una plataforma única y confiable para monitorear y controlar el uso del AI generativo, reduciendo la carga de trabajo, mitigando riesgos como filtraciones de datos y uso indebido, y reforzando la gobernanza de AI de nivel empresarial de Miro.
