Wprowadzamy dodatkowe punkty końcowe API eksportu tablic, aby pomóc Ci efektywniej zarządzać eksportami tablic. Będziesz mógł wymieniać zadania eksportowe w całej organizacji, wyświetlać zadania dla konkretnego zadania eksportowego, pobierać linki do pobierania zadań eksportowych i anulować zadania eksportowe, które nie są już potrzebne. Te aktualizacje ułatwią monitorowanie, kontrolowanie i automatyzację przepływów pracy eksportu w sposób programowy.
