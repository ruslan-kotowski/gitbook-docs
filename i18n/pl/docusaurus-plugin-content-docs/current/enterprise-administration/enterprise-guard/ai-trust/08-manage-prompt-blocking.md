Aby dostosować, które etykiety są blokowane lub aby przełączyć skanowanie kodu:

1. Przejdź do **Ustawienia** → **Enterprise Guard** → **Odkrywanie danych** → **Konfiguracja**.
2. W sekcji **Blokowanie podpowiedzi** wybierz **Zarządzaj**.
3. W panelu bocznym, wykonaj dowolne z poniższych działań:
   - Włącz lub wyłącz **Wybierz wszystko**.
   - Zaznacz lub odznacz kategorie etykiet, które chcesz zablokować.
   - Włącz lub wyłącz **Skanowanie kodu**.
4. Wybierz **Zastosuj zmiany**.

Zmiany zaczną obowiązywać natychmiast dla wszystkich użytkowników. Prompty zawierające odblokowane elementy będą kontynuowane. Prompty zawierające nadal zablokowane elementy nadal będą blokowane.
