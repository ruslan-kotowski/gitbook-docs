Użyj strony Ogłoszenia, aby wyświetlać wszystkie ogłoszenia, śledzić ich stan i zarządzać nimi w całym cyklu życia.

## Wyświetlanie i rozumienie ogłoszeń

Przejdź do **Konsola administratora > Organizacja > Ogłoszenia**. Tabela ogłoszeń zapewnia przegląd wszystkich ogłoszeń, w tym ich nazw, stanów, dat, odbiorców i twórców.

## Stany ogłoszeń

| Stan | Opis |
| --- | --- |
| **Szkic** | Zapisana, ale jeszcze nie opublikowana. |
| **Zaplanowane** | Opublikowana i ustawiona do wyświetlenia w późniejszym terminie. |
| **Na żywo** | Aktualnie widoczna dla użytkowników. |
| **Zakończone** | Nieaktywna po dacie zakończenia. |
| **Anulowane** | Zatrzymana przed datą rozpoczęcia. |

## Aktualizowanie ogłoszeń

### Edytuj ogłoszenie

1. Przejdź do **ogłoszenia**.
2. Wybierz ogłoszenie.
3. Kliknij **Edycja**.
4. Zaktualizuj szczegóły ogłoszenia.
   Możesz zaktualizować wiadomość, tekst linku, URL linku, odbiorców, harmonogram lub priorytet.
5. Kliknij **Publikuj**.
   Zmiany są stosowane natychmiast, także dla ogłoszeń na żywo.

### Publikuj ogłoszenie

1. Otwórz ogłoszenie.
2. Sprawdź szczegóły.
3. Kliknij **Publikuj**.
   Ogłoszenie zostaje **zaplanowane** jeśli data rozpoczęcia jest w przyszłości, lub **aktywne** jeśli data rozpoczęcia jest bieżąca lub już minęła.

## Ponowne użycie ogłoszeń

### Duplikowanie ogłoszenia

1. Na liście ogłoszeń otwórz menu **Operacje**.
2. Kliknij **Duplikuj**.
3. Zaktualizuj szczegóły ogłoszenia.
   Zmień nazwę, daty, odbiorców lub inne pola według potrzeb.
4. Kliknij **Zapisz jako szkic** lub **Opublikuj**.
   **Zapisz jako szkic** przechowuje ogłoszenie bez publikowania.
   **Opublikuj** sprawia, że ogłoszenie staje się widoczne lub jest zaplanowane na podstawie wybranych dat.

## Zarządzaj cyklem życia ogłoszenia

### Anuluj ogłoszenie

1. Na liście ogłoszeń otwórz menu **Akcje**.
2. Kliknij **Anuluj**.

Możesz anulować ogłoszenie w dowolnym stanie. Ogłoszenie nie jest już wyświetlane użytkownikom.

### Usuń ogłoszenie

1. Na liście ogłoszeń otwórz menu **Akcje**.
2. Kliknij **Usuń**.

Ogłoszenie jest trwale usunięte i nie można go odzyskać.

## Śledź zmiany

Każde ogłoszenie zawiera sekcję historii, która pokazuje zdarzenia cyklu życia i aktualizacji.

Historia zawiera takie działania jak:

- Utworzony
- Opublikowany lub uruchomiony
- Edytowany
- Anulowany

Te działania są również rejestrowane w dziennikach audytu.
