Możesz zbiorczo importować swoje diagramy z aplikacji źródłowych jako PDF lub VSDX.

:::note
Dla niektórych aplikacji źródłowych obsługiwany jest tylko jeden typ pliku. Aby sprawdzić, zobacz Obsługa typów plików do importu.
:::

## Jak zbiorczo importować diagramy do Miro

Aby zaimportować swoje diagramy do Miro, upewnij się, że wyeksportowałeś pliki z aplikacji źródłowej jako PDF lub VSDX. Następnie wykonaj poniższą procedurę.

1. Na pulpicie Miro, w przestrzeni, do której chcesz zaimportować diagramy, kliknij **Utwórz nową** (**+**).
   ![](../../../../../../docs/getting-started/migrating-content-to-miro/images/32654520716690_image.png)
2. Kliknij **Importuj** > **Importuj z \{source\}**. Na przykład, **Importuj z Murala**.
   Otworzy się okno modalne **Importuj z \{source\}**.
3. Postępuj zgodnie z instrukcjami na ekranie.
4. (Opcjonalnie) Zmień docelową przestrzeń do importu. Lub kliknij przycisk plus (**+**), aby utworzyć nową docelową przestrzeń.
5. Kliknij **Importuj** ***x*** **pliki**.

## Obsługiwane rodzaje plików do importu

| Źródło | Typ pliku |
| --- | --- |
| Conceptboard | PDF, VSDX |
| Lucidchart | PDF, VSDX |
| Lucidspark | PDF, VSDX |
| Mural | PDF |
| Visio | VSDX |
