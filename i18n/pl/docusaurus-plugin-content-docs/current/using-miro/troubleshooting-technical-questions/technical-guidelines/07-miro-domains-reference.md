Ten artykuł referencyjny zawiera listę każdej domeny używanej przez Miro w swojej aplikacji SaaS.

:::note
Niektóre aplikacje firm trzecich opracowane dla Miro oraz aplikacje Miroverse mogą opierać się na zewnętrznych domenach i usługach, nad którymi Miro nie sprawuje kontroli.
:::

## Globalne domeny produkcyjne

Organizacje korzystające z zabezpieczonej sieci muszą zezwolić na poniższe globalne domeny produkcyjne:

```
*.miro.com
Notatka: Uwzględnij pochodne, na przykład: *.api.miro.com | *.svc.miro.com
```

```
*.miro-apps.com
```

```
mirostatic.com
```

```
*.mirostatic.com
```

```
onlinewhiteboard.com
```

```
realtimeboard.com
```

```
*.realtimeboard.com
```

```
webwhiteboard.com
```

## Regionalne domeny produkcyjne

Organizacje korzystające z zabezpieczonej sieci muszą zezwolić na następujące regionalne domeny produkcyjne.

:::note
Oprócz światowych domen produkcyjnych oraz domen produkcyjnych narzędzi, należy również zezwolić na regionalne domeny produkcyjne ze względu na [miejsce przechowywania danych](../../../enterprise-administration/canvas-25-admin-features/data-residency/02-data-residency-at-miro.md) w Australii lub Stanach Zjednoczonych, w zależności od potrzeb.
:::

### Australia

```
*.au.miro.com
Nota: Uwzględnij pochodne, na przykład: *.api.au.miro.com | *.svc.au.miro.com
```

```
*.au01.miro.com
```

### Stany Zjednoczone

```
*.us.miro.com
Nota: Uwzględnij pochodne, na przykład: *.api.us.miro.com | *.svc.us.miro.com
```

```
*.us01.miro.com
```
