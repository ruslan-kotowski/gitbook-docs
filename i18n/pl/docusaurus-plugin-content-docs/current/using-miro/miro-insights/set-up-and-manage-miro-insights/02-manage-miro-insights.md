Ten przewodnik obejmuje bieżące zadania administracyjne dla Miro Insights, w tym ustawienia ogólne, zarządzanie zespołem, powiadomienia oraz dostęp do API. Jest przeznaczony dla administratorów firmy, którzy muszą zarządzać Miro Insights po zakończeniu początkowej konfiguracji.

Jeśli nie skonfigurowałeś jeszcze Miro Insights, zacznij od przewodnika [Konfiguracja Miro Insights (administrator)](../../miro-insights/set-up-and-manage-miro-insights/01-set-up-miro-insights.md).

## Wymagania wstępne

Aby zarządzać administracją Miro Insights, potrzebujesz:

- **Roli administratora firmy** w Miro.
- **Miro Insights musi być już skonfigurowane** dla Twojej organizacji.

## Profil firmy

W tej sekcji można zaktualizować informacje o firmie wyświetlane w Miro Insights.

- **Nazwa**: Nazwa Twojej organizacji.
- **Dozwolone domeny e-mail**: Domeny e-mail, które mogą uzyskać dostęp do Miro Insights.
- **Logo firmy**: Prześlij lub zmień logo swojej firmy.

## Zespół

Ta sekcja obejmuje ustawienia związane z zespołem Miro Insights. Jako administrator możesz zapraszać, dodawać lub usuwać użytkowników oraz zarządzać ich rolami.

## Powiadomienia

W tej sekcji możesz skonfigurować sposób i czas, w jakim Ty lub członkowie Twojego zespołu otrzymują powiadomienia o nowych opiniach, sugestiach AI i innych ważnych wydarzeniach.

Możesz ustawić metody powiadomień, takie jak Slack. Możesz skonfigurować rodzaje powiadomień według kategorii: funkcja lub feedback.

## Integracje i automatyzacje

W tej sekcji możesz zarządzać wszystkimi połączonymi integracjami i automatyzacjami. Możesz wyświetlić status każdej integracji, ponownie ją połączyć w razie potrzeby oraz dostosować ustawienia importu.

Szczegółowe instrukcje dotyczące konfiguracji znajdziesz w [przewodniku dla administratorów Miro Insights](../../miro-insights/set-up-and-manage-miro-insights/01-set-up-miro-insights.md).

## Klucze API

Tutaj możesz generować i zarządzać kluczami API dla programistycznego dostępu do danych Miro Insights. Możesz tworzyć nowe klucze oraz wycofywać stare lub zagrożone klucze.

:::warning
Tworząc klucz API, upewnij się, że nadano mu opisową nazwę i skopiowano go w bezpieczne miejsce. Nie będzie możliwe ponowne zobaczenie go po opuszczeniu strony.
:::

## Co dalej?

Po skonfigurowaniu tych ustawień administracyjnych, Twoja instancja Miro Insights powinna działać płynnie dla Twojego zespołu. Aby uzyskać dalsze wskazówki dotyczące użytkowania, zobacz [przewodnik dotyczący korzystania z Miro Insights](../../miro-insights/use-miro-insights).
