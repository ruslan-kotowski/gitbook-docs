Możesz zbiorczo zaimportować swoje diagramy z aplikacji źródłowych jako PDF lub VSDX.

:::note
Dla niektórych aplikacji źródłowych obsługiwany jest tylko jeden typ pliku. Aby zweryfikować, zobacz Importowanie obsługiwanych typów plików.
:::

## Jak zbiorczo zaimportować diagramy do Miro

Aby zaimportować diagramy do Miro, upewnij się, że wyeksportowałeś pliki z aplikacji źródłowej jako PDF lub VSDX. Następnie wykonaj poniższą procedurę.

1. Na swoim pulpicie Miro, dla przestrzeni, do której chcesz zaimportować diagramy, kliknij **Utwórz nową** (**+**).
   ![](../../../../../../../docs/using-miro/import-and-export/import/images/32657459157138_image.png)
2. Kliknij **Importuj** > **Importuj z \{source\}**. Na przykład, **Importuj z Mural**.
   Okno modalne **Importuj z \{source\}** otwiera się.
3. Postępuj zgodnie z instrukcjami wyświetlanymi na ekranie.
4. (Opcjonalnie) Zmień docelową przestrzeń dla importu. Lub kliknij przycisk plus (**+**), aby utworzyć nową docelową przestrzeń.
5. Kliknij **Importuj** ***x*** **plików**.

## Obsługiwane typy plików do importu

| Źródło | Typ pliku |
| --- | --- |
| Conceptboard | PDF, VSDX |
| Lucidchart | PDF, VSDX |
| Lucidspark | PDF, VSDX |
| Mural | PDF |
| Visio | VSDX |
