Panel poleceń umożliwia szybkie wyszukiwanie i uruchamianie narzędzi oraz aplikacji Miro. Panel poleceń pozwala również przeszukiwać ostatnie tablice.

Panel poleceń jest dostępny tylko dla użytkowników z [uprawnieniami do edycji](../sharing-boards/01-board-access-rights.md) i tylko w standardowym trybie tablicy. Nie będziesz mógł uruchomić panelu poleceń w trybie prezentacji.

## Jak używać panelu poleceń

1. Wybierz ikonę **menu z 3 kropkami** (![icon-main.svg](../../../../../../docs/using-miro/working-on-the-board/images/24005170925074_icon-main.svg)) na pasku narzędzi tablicy.
   Otworzy się menu główne.
2. Wybierz **Edycja** > **Polecenia**. Alternatywnie, użyj skrótu klawiszowego **Cmd** + **K**.
   Panel poleceń otwiera się.
3. W polu wyszukiwania zacznij wpisywać nazwę aplikacji lub narzędzia, albo przewiń listę.
4. Kliknij, aby uruchomić aplikację lub narzędzie.
