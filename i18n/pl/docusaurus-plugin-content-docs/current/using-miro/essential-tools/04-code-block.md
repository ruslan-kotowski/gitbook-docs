Dodaj bloki kodu do swoich tablic, aby wspólnie programować, debugować i rozwiązywać problemy. Nasz widżet bloku kodu zawiera najpopularniejsze języki programowania i jest konfigurowalny.

Połącz bloki kodu z naszymi [funkcjami mapowania i tworzenia diagramów](../formats/diagramming/01-miro-for-mapping-diagramming.md), aby przeglądać architekturę i przepływy."} Użyj także łączników do diagramów, aby podkreślić relacje między fragmentami kodu źródłowego.

**Użyj bloków kodu do:**

- Zwinne ceremonie
- Wspólne sesje rozwoju i debugowania
- Zdalne wywiady programistyczne

## Jak dodać blok kodu

1. Przejdź do paska narzędzi tworzenia po lewej stronie tablicy
2. Kliknij ikonę **Więcej aplikacji**
3. Wyszukaj **Blok kodu** lub przewiń w dół, aż zobaczysz Blok kodu
4. Kliknij ikonę aplikacji Blok kodu
5. Kliknij w dowolnym miejscu na tablicy, aby dodać blok kodu.

## Dostosowywanie bloku kodu

W menu kontekstowym bloku kodu możesz włączać i wyłączać linie, dostosowywać rozmiar czcionki oraz zmieniać języki programowania.

1. Kliknij blok kodu.
2. W menu kontekstowym wybierz język programowania z listy rozwijanej, zwiększ lub zmniejsz rozmiar czcionki i kliknij ikonę numerów linii, aby włączać i wyłączać linie.

![Customizing_a_code_block.gif](../../../../../../docs/using-miro/essential-tools/images/21016928890130_Customizing%20a%20code%20block.gif)*Dostosowywanie bloku kodu na tablicy*

## Często zadawane pytania

Jakie języki programowania są obecnie dostępne w blokach kodu?

JavaScript, TypeScript, Python, C++, Java, Go, Rust, PlainText, Swift, Ruby, SQL, HTML, CSS, JSON, GraphQL, Kotlin, YAML i Mermaid.
Regularnie dodajemy języki na podstawie próśb klientów; skontaktuj się z managerem ds. sukcesu klienta Miro, jeśli masz sugestie.
