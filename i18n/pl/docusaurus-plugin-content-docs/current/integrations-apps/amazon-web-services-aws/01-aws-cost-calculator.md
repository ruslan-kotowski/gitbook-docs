:::note
(Enterprise) AWS Cost Calculator jest dostępny tylko z licencjami Advanced. Więcej informacji znajdziesz w artykule [Understanding Enterprise licenses](../../plans-billing/miro-plans/05-understanding-enterprise-licenses.md).
:::

## Jak skonfigurować i używać AWS Cost Calculator

1. Zainstaluj [AWS Cost Calculator](https://miro.com/marketplace/aws-cost-calculator/) z Miro Marketplace.
2. Otwórz tablicę Miro, na której chcesz obliczyć koszty AWS.
3. Kliknij **Narzędzia, Media i Integracje** (**+**) w [pasku narzędzi](../../getting-started/start-here/your-first-board/05-toolbars.md) tworzenia i wyszukaj ‚AWS Cost Calculator’.
4. Wybierz **AWS Cost Calculator**. Panel AWS Cost Calculator otworzy się po lewej stronie tablicy.
5. Kliknij i przeciągnij, aby zaznaczyć wszystkie ikony AWS w diagramie. Kalkulator kosztów automatycznie wypełni się wszystkimi ikonami AWS w diagramie.
6. Dla każdej ikony AWS kliknij **Edycja**, aby określić szczegóły, takie jak region i typ magazynu, a następnie kliknij **Zapisz wybór usługi**.
7. Po edycji wszystkich ikon kliknij **Oblicz**, aby zobaczyć całkowite koszty AWS.
8. Aby lepiej zrozumieć swoje koszty, używaj górnych kart i menu rozwijanego, aby filtrować koszty według ramki czasowej (**Godzina**, **Miesiąc**, **Rok**) i **Region**.

## Wskazówki dotyczące dokładnych obliczeń

- **Bądź szczegółowy**: Im więcej szczegółów podasz, tym dokładniejsze będą szacowane koszty.
- **Regularnie sprawdzaj**: Ceny AWS mogą się zmieniać. Regularnie sprawdzaj i aktualizuj swoje oszacowania oraz zawsze potwierdzaj rzeczywiste koszty bezpośrednio u AWS.
