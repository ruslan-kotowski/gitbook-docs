Jako administrator firmy możesz włączyć i zatwierdzić integrację Microsoft Copilot dla zespołów w Twojej organizacji Miro.

Integracja Microsoft Copilot pozwala na połączenie Copilot jako [zasobu wiedzy](../../using-miro/miro-ai/09-knowledge.md) w Miro. Na przykład podłącz Microsoft Copilot, aby dostarczać informacje firmowe współpracownikom AI lub w przepływach.

Możesz także połączyć Copilot z samodzielnym czatem w Miro.

:::note
Aby uzyskać informacje o używaniu agenta Miro z Copilot w Microsoft Teams, zobacz [Agent Miro dla Copilot](microsoft-teams/03-miro-agent-for-copilot.md).
:::

Każdy członek zespołu musi posiadać licencję Copilot, aby korzystać z integracji.

Aby włączyć integrację Microsoft Copilot, wykonaj te kroki:

1. Jako administrator firmy przejdź do **Konsoli administratora**.
2. Przejdź do **Aplikacje i integracje** > **Aplikacje** > **Dodaj aplikacje**.
3. Wyszukaj i znajdź **Microsoft Copilot**.
   Jeśli nie możesz znaleźć aplikacji po nazwie, wyszukaj za pomocą następującego ID klienta: `5531308904693541040`.
4. W profilu aplikacji wybierz, czy dodać aplikację dla **Wszystkich zespołów**, czy wybierz **Określone zespoły**.
5. (Opcjonalnie) Sprawdź stronę uprawnień. Aplikacja Microsoft Copilot dla Miro jest rozwijana i utrzymywana przez Miro i nie wymaga specjalnych uprawnień.
6. Kliknij **Dodaj**.

:::note
Gdy członek zespołu po raz pierwszy połączy Microsoft Copilot jako zasób wiedzy, zostanie poproszony o uwierzytelnienie. Członek zespołu musi mieć licencję Copilot.
:::
