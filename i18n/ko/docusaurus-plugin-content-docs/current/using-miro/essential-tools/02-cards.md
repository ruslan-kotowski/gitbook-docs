Miro 카드는 작업을 정리하고 할당하고, 이해관계자를 조정하기 위한 세부 정보를 제공하고, 모든 것을 궤도에 유지할 수 있는 구조화된 방법을 제공합니다. [카드를 사용해 계획](../advanced-tools/02-columns-formerly-kanban.md) 또는 [스토리 매핑을](../advanced-tools/07-user-story-mapping.md) 하세요.

> **사용 가능 환경:** **데스크톱 브라우저, 데스크톱 앱, 태블릿 앱 및 모바일 앱의 제한된 기능**

## 카드 사용

### 툴바에 카드 앱 추가하기

보드에서 카드로 작업하는 경우 툴바에 카드 기능을 추가해 카드를 더 빠르게 생성하세요.

1. 보드 왼쪽의 제작 툴바로 이동하세요.
2. **앱** 추가 아이콘을 클릭하세요.
3. ‘카드’ 검색
4. **카드** 아이콘을 클릭해 툴바에 추가하세요

![Adding_the_card_app_to_the_toolbar.gif](https://help.miro.com/hc/article_attachments/21857841856146)*툴바에 카드 앱 추가하기*

### 보드에 카드 추가하기

보드에 카드를 추가하는 방법에는 세 가지가 있습니다.

제작 툴바에서 **카드 아이콘을** 드래그해 보드의 아무 곳에나 놓으세요.

![Dragging_the_card_icon_to_the_board.gif](https://help.miro.com/hc/article_attachments/21857841858194)*카드를 보드에 드래그하기*

**카드 아이콘을** 클릭한 다음 보드의 아무 곳이나 클릭하세요.

![Clicking_on_the_board_to_add_a_card.gif](https://help.miro.com/hc/article_attachments/21857852115090)*카드 아이콘을 클릭해 보드에 카드를 추가하세요*

**D 단축키를 사용해** 보드의 아무 곳이나 클릭하세요.

![Using_the_D_hotkey_to_add_a_card.gif](https://help.miro.com/hc/article_attachments/21857852117522)*D 단축키를 사용해 보드에 카드 추가*

:::tip
[치수를](../formats/diagramming/01-miro-for-mapping-diagramming.md) 활성화해 보드 전체에서 동일한 크기의 카드를 만드세요.
:::

### 보드에서 카드 삭제하기

1. 카드를 클릭하고 키보드에서 백스페이스를 누르세요
2. 컨텍스트 메뉴에서 점 3개 아이콘을 클릭할 수도 있습니다(**...**) > **삭제**

*![deleting_a_card.jpg](https://help.miro.com/hc/article_attachments/21857852119442)**카드 삭제하기*

### 다른 오브젝트를 카드로 변환하기

유형 전환 기능을 사용해 기존 [스티커 메모](14-sticky-notes.md), [텍스트 상자](16-text.md) 또는 [도형을](11-shapes.md) 카드로 변환할 수 있습니다.

1. 오브젝트를 클릭해 컨텍스트 메뉴를 여세요
2. **유형** 전환 아이콘을 클릭하세요.
3. 드롭다운 메뉴에서 카드 아이콘을 선택하세요.

![converting_a_sticky_into_a_card.gif](https://help.miro.com/hc/article_attachments/21857852120978)*스티커 메모를 카드로 변환하기*

**여러 오브젝트를 카드로 대량으로 변환하려면** 오브젝트를 클릭하고 드래그해 오브젝트를 선택하고 컨텍스트 메뉴에서 유형 전환 아이콘을 클릭하세요. 카드 아이콘을 선택하세요.

*![Bulk_converting_to_cards.gif](https://help.miro.com/hc/article_attachments/21857841874194)
여러 개의 스티커 메모를 카드로 일괄 변환*

:::tip
[카드를 Jira 카드로 변환할](../../integrations-apps/atlassian/03-jira-cards.md) 수 있습니다. 팀 브레인스토밍 세션이나 민첩한 행사 후 대량 변환을 사용해 여러 Jira 카드를 만드세요.
:::

### 카드 패널 열기

카드 패널을 열어 모든 카드 세부 정보를 확인하고 한 번에 모든 편집을 한 다음 설명을 추가하세요.

카드 패널을 열려면 카드 오른쪽 상단 모서리나 카드의 컨텍스트 메뉴에서 **확장** 아이콘을 클릭하세요. **단축키** + **Shift** **+** *Enter(Windows*) **Cmd** + **Shift** + **Enter(Mac)** 키를 사용할 수도 있습니다.

![Expanding_a_card.gif](https://help.miro.com/hc/article_attachments/21857852127122)*카드 패널 열기*

## 카드 편집 및 사용자 지정

### 카드 편집 방법

카드를 클릭해 컨텍스트 메뉴를 열거나 카드 패널을 여세요. 여기에서 카드의 색상과 크기를 변경하고, 태그, 링크 및 날짜를 추가하고, 카드를 사용자에게 할당할 수 있습니다.

![customizing_a_card.gif](https://help.miro.com/hc/article_attachments/21857841879826)*카드 편집하기*

### 카드 대량 편집하기

1. 선택 필드를 카드 위로 드래그하거나 **Shift** 또는 **Ctrl(Windows)** 또는 **Command(Mac)** 키를 누른 상태에서 카드를 하나씩 선택하세요.
2. 컨텍스트 메뉴가 열립니다
3. 컨텍스트 메뉴에서 도구를 선택해 편집하세요

![Bulk-editing_cards.gif](https://help.miro.com/hc/article_attachments/21857852130962)*한 번에 여러 카드 편집하기*

### 카드 크기 조정 또는 회전

카드를 클릭하고 흰색 점을 드래그하세요. 화살표 아이콘을 드래그해 카드를 회전할 수 있습니다.

![Changing_size_and_rotating_a_card.gif](https://help.miro.com/hc/article_attachments/21857852139666)*카드 크기 변경 및 카드 회전*

### 사용자에게 카드 할당하기

이메일 [초대](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md), [팀 공유](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md), [프로젝트를](../sharing-boards/16-projects.md) 통해 보드에 액세스할 수 있는 사용자에게 카드에 할당될 수 있습니다. 카드는 [방문자에게](../sharing-boards/08-collaboration-with-visitors.md) 할당될 수 없습니다.

1. 카드를 클릭해 컨텍스트 메뉴를 열거나 카드 패널을 여세요
2. **담당자** 추가 아이콘을 클릭하세요.
3. 드롭다운에서 사용자를 선택하세요

![adding_an_assignee.jpg](https://help.miro.com/hc/article_attachments/21857852145426)*사용자에게 카드 추가*

### 카드에서 태그 추가 및 제거하기

1. 카드를 클릭해 컨텍스트 메뉴를 열거나 카드 패널을 여세요
2. **태그** 추가 아이콘을 클릭하세요
3. 태그의 텍스트를 입력하고 태그 색상 선택하기
4. 키보드에서 생성을 클릭하거나 Enter 키를 누르세요
5. 태그를 클릭해 카드에서 제거하세요

:::tip
태그를 사용해 카드를 [검색하고](../working-on-the-board/19-searching-text-on-the-board.md) 필터링하세요.
:::

![managing_tags_on_cards.gif](https://help.miro.com/hc/article_attachments/21857852154130)*카드에서 태그 추가 및 제거하기*

### 카드 상태 업데이트

1. 카드를 클릭해 컨텍스트 메뉴를 열거나 카드 패널을 여세요
2. **상태** 추가 아이콘을 클릭하세요.
3. **드롭다운에서** **할 일**, 진행 중 또는 완료를 선택하세요.
4. 상태를 제거하려면 **상태 제거를** 클릭하세요

![Updating_the_status_of_a_card.gif](https://help.miro.com/hc/article_attachments/21857841904274)*카드 상태 업데이트하기*

### 카드에서 날짜 추가 및 제거하기

1. 카드를 클릭해 컨텍스트 메뉴를 열거나 카드 패널을 여세요
2. **날짜** 설정 아이콘을 클릭하세요.
3. 시작 날짜 및/또는 만료 날짜를 입력하세요.
4. 날짜를 지우려면 날짜 필드 옆의 **x를** 클릭하세요.

![Adding_dates_to_a_card.gif](https://help.miro.com/hc/article_attachments/21857841907346)*카드에 시작 날짜와 만료 날짜 추가하기*

### 카드 제목 및 설명

카드 설명 및 기호에 최대 20,000개의 텍스트 기호를 추가할 수 있습니다. 카드의 표기는 항상 표시됩니다. 사용자는 카드를 확장해 설명을 볼 수 있습니다.

#### **카드 제목 추가하기**

카드를 클릭하고 입력을 시작하세요. 카드 제목의 텍스트 글꼴과 크기를 변경할 수 없습니다.

![Adding_a_title_to_a_card.gif](https://help.miro.com/hc/article_attachments/21857841908882)*카드 제목 추가하기*

#### **카드 설명 추가하기**

확장 아이콘을 클릭해 카드 패널을 열고 **설명** 필드에 입력을 시작하세요. **Ctrl + C**/Ctrl **+** V(Windows) 또는 **Cmd + C/Cmd +** V(Mac)를 사용해 복사한 텍스트를 설명 필드에 직접 붙여넣을 수도 있습니다.

![Adding_a_description_to_the_card.gif](https://help.miro.com/hc/article_attachments/21857852167698)*카드 설명 추가하기*

## 카드 내보내기

1. 선택 필드를 카드 위로 드래그하거나 **Shift** 또는 **Ctrl(Windows)** 또는 **Command(Mac)** 키를 누른 상태에서 카드를 하나씩 선택하세요.
2. **내보내기** 아이콘 > **스프레드시트로** **내보내기(CSV)를** 클릭하세요.

![export_menu_cards_export_to_csv.gif](https://help.miro.com/hc/article_attachments/21857852173074)
*CSV로 카드 내보내기*

## 카드 단축키

- **D** + 클릭하여 보드에 새 카드를 추가하세요
- **Ctrl + Shift + *Enter(Windows)*, Cmd + Shift + *Enter(Mac)로*** 모든 카드를 엽니다
- **Tab** 키를 눌러 새 카드를 만들고 카드 목록을 편집하세요
- **Ctrl +** *B(Windows)*, **Cmd +** *B(Mac)* - 굵게
- **Ctrl +** *I(Windows)*, **Cmd +** *I(Mac) -* 기울임꼴
- **Ctrl +** *U(Windows)*, **Cmd +** *U(Mac) -* 밑줄
- **“-”** + 글머리 기호 목록 줄 시작 부분에 **공백**
- 번호가 매겨진 목록의 줄 시작 부분에 있는 **“1.”**
- 텍스트 및 **Ctrl +** *V(Windows) 또는* **Cmd +** *V(Mac)를* 선택해 하이퍼링크를 만드세요

## 자주 묻는 질문

**사용자에게 카드를 할당하면 이메일 알림을 받게 되나요?**

아니요, 사용자는 이메일 알림을 받지 않습니다.

**카드에 추가한 만료 날짜를 기준으로 이메일 알림을 구성할 수 있나요?**

현재는 불가능합니다.
