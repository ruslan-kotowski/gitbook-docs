보드에서 위젯을 실수로 삭제하거나 이동하셨나요? 걱정하지 마세요, 쉽게 실행 취소할 수 있습니다.

## 실행 취소 및 다시 실행 옵션

**실행 취소** 및 **다시 실행** 버튼은 작성 툴바에서 사용할 수 있습니다. 현재 세션 중 Miro에서 *최대 30번의 작업을* 실행 취소 및 다시 실행할 수 있습니다. 페이지를 새로 고치거나 보드를 다시 열면 **실행 취소** 및 **다시 실행** 명령어가 *사용 불가능하게 됩니다*.

:::tip
실수로 삭제한 콘텐츠를 복원해야 하는 경우, [이 가이드를 확인하세요](../working-on-the-board/18-restoring-board-content.md).
:::

![undo-redo.png](../../../../../../docs/using-miro/essential-tools/images/21537436796434_undo-redo.png)
*Miro 보드에서 실행 취소/다시 실행 옵션*

이전 작업을 **실행 취소**하려면, Windows에서는 **Ctrl + Z** (*for Windows*), Mac에서는 **Cmd** + **Z** (*for Mac*)를 눌러 원하는 작업까지 되돌리십시오. 키보드 단축키보다 마우스 내비게이션을 선호하신다면, **실행 취소** (![icon-undo.svg](../../../../../../docs/using-miro/essential-tools/images/27942193905298_icon-undo.svg)) 버튼을 클릭하세요.

실행 취소한 작업을 **다시 실행**하려면 **Ctrl + Shift + Z** (*Windows용*)/**Cmd** + **Shift** + **Z** (*Mac용*)를 누르거나 **다시 실행** (![icon-redo.svg](../../../../../../docs/using-miro/essential-tools/images/27942193906194_icon-redo.svg)) 버튼을 클릭하세요.

**다시 실행** 및 **실행 취소** 버튼은 보드에서 최소한 하나의 작업이 수행된 후에만 활성화됩니다. 사용자는 자신의 작업만 실행 취소/다시 실행할 수 있으며, 공동 작업자의 작업은 취소할 수 없습니다.

## 자주 묻는 질문

**전체 보드를 삭제한 것을 어떻게 실행 취소할 수 있나요?**

여기에 안내된 내용을 확인하세요. [삭제된 보드를 복원하는 방법](../managing-boards/08-how-to-restore-a-deleted-board.md).

**보드에서 콘텐츠 삭제를 실행 취소할 수 있나요?**

네, [여기에서 확인하세요](../working-on-the-board/18-restoring-board-content.md).

**다른 보드 편집자가 한 변경 사항을 실행 취소할 수 있습니까?**

아니요, 행동을 실행 취소만 할 수 있습니다.

**실행 취소/다시 실행 버튼이 활성 상태가 아닙니다. 이유?**

현재 작업 세션에서 보드에서 변경을 해야 버튼이 활성화된다는 점에 유의하세요. 새로운 세션을 시작할 때 활성화되지 않습니다(예: 페이지를 새로 고침). 버튼이 콘텐츠를 변경한 후에도 활성화되지 않으면, [문제 해결 가이드](../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md)를 확인하세요. iPad에서 툴바가 사라질 수 있습니다. - [자세히 알아보기](../../getting-started/apps-for-devices/11-tablet-app.md).
