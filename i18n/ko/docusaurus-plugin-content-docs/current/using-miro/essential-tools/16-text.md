Miro 보드에서 텍스트 도구를 사용하는 방법을 알아보세요.

:::note
이 글에서는 **텍스트** 도구에 사용할 수 있는 제어 기능을 설명합니다. [스티커 메모](14-sticky-notes.md), [테이블](../advanced-tools/05-grid.md), [도형](11-shapes.md), [카드](02-cards.md), [연결선](05-connection-lines.md), [마인드맵](../advanced-tools/03-mind-map.md)의 텍스트 서식 옵션에 대해 더 알아보려면 해당 기사를 확인하세요.
:::

### 텍스트 추가 및 편집

보드에 텍스트를 추가하는 간단한 두 가지 방법이 있습니다:

- 툴바에서 **텍스트**를 선택하거나 [키보드에서 T를 눌러](../working-on-the-board/06-shortcuts-and-hotkeys.md), 보드 내의 아무 곳이나 클릭하고 타이핑을 시작합니다
- 텍스트 위젯을 툴바에서 보드로 드래그 앤 드롭합니다

![text_on_the_toolbar.jpg](../../../../../../docs/using-miro/essential-tools/images/21017012885522_text%20on%20the%20toolbar.jpg)
*툴바의 텍스트 도구*

텍스트를 입력하는 동안, 그리고 텍스트 상자가 선택된 동안 포맷팅 옵션을 사용할 수 있습니다. 텍스트 폰트, 색상 및 불투명도를 선택하거나, 텍스트를 왼쪽 또는 오른쪽으로 정렬하고, 폰트 크기를 변경하고, 강조 표시를 할 수 있습니다.

:::note
텍스트 상자는 하나의 텍스트 상자당 6,000자 제한이 있습니다. 이 제한에는 공백과 코드 내의 모든 스타일 변경 사항이 포함되므로, 텍스트 서식이 입력 가능한 기호의 수를 줄일 수 있습니다. 제한을 초과하면 **텍스트 상자 제한에 도달했습니다. 일부 텍스트가 잘릴 수 있습니다**라는 메시지가 표시됩니다.
:::

![text_formatting.gif](../../../../../../docs/using-miro/essential-tools/images/21017042402578_text%20formatting.gif)
*텍스트 서식 옵션*

텍스트를 편집하거나 서식을 일부 변경하려면 텍스트 도구를 사용할 때 두 번 클릭하거나 한 번 클릭하세요. 글꼴이나 글자 크기를 변경하면 전체 텍스트 상자에 영향을 미칩니다.
![formatting_a_part_of_the_text.gif](../../../../../../docs/using-miro/essential-tools/images/21017042403090_formatting%20a%20part%20of%20the%20text.gif)
*텍스트 줄의 일부 편집*

텍스트 상자에서 텍스트를 교체하려면 선택한 후 입력을 시작하세요.

다음 텍스트 서식 지정 단축키도 사용할 수 있습니다:

- **Ctrl + B** *(Windows)*, **Cmd + B** *(Mac)* - 굵게
- **Ctrl + I** *(Windows)*, **Cmd + I** *(Mac)* - 기울임꼴
- **Ctrl + U** *(Windows)*, **Cmd + U** *(Mac)* - 밑줄

텍스트 크기를 변경하는 방법은 두 가지입니다: 상황에 맞는 메뉴를 사용하거나 흰색 점을 드래그하세요.

![changing_font_size.gif](../../../../../../docs/using-miro/essential-tools/images/21017042403858_changing%20font%20size.gif)
*텍스트 크기 변경*

텍스트 상자의 크기를 조정하려면 왼쪽 또는 오른쪽 경계를 드래그하세요. 집중 모드에서는 컨텍스트 메뉴의 **크기 조절** 아이콘을 클릭해 픽셀 단위로 텍스트 상자의 너비를 지정할 수 있습니다..

![resizing_a_text_box.gif](../../../../../../docs/using-miro/essential-tools/images/21017042404626_resizing%20a%20text%20box.gif)
*텍스트 상자 크기 변경*

텍스트를 회전하려면 화살표 아이콘을 드래그하세요.

![rotate_text.gif](../../../../../../docs/using-miro/essential-tools/images/21017042405650_rotate%20text.gif)
*텍스트 상자 회전*

맞춤형 [링크](../working-on-the-board/16-internal-and-external-linking.md)는 텍스트 상자에서 **링크 삽입** 옵션을 사용하거나 세 점 아이콘 아래의 **링크로 연결** 옵션을 통해 생성할 수 있습니다. 또한 텍스트를 선택하고 **Ctrl + V** (*Windows*) 또는 **Cmd + V** (*Mac*) 단축키로 링크를 붙여넣을 수 있습니다.

![linking_options.gif](../../../../../../docs/using-miro/essential-tools/images/21017012890002_linking%20options.gif)
*텍스트에 URL 링크 첨부*

### 글머리 기호 및 번호 매기기 목록

글머리 기호 및 번호 매기기 목록은 텍스트 블록을 쉽게 나누어 중요한 정보를 돋보이게 합니다. 글머리 기호 목록이나 번호 목록을 시작하려면 대시 또는 숫자를 입력하고 스페이스바를 누릅니다. 입력한 텍스트를 글머리 기호 목록 또는 번호 목록으로 변환하려면 컨텍스트 메뉴의 **목록 추가** 도구를 사용하세요. 목록을 사용자 지정하고 다단계로 만들 수 있습니다.

![number_points.gif](../../../../../../docs/using-miro/essential-tools/images/21017042407186_number%20points.gif)
*다단계 목록 만들기*

**Shift + Enter** (**Return**) 키를 눌러 번호 목록에 줄 바꿈을 추가합니다.

목록을 완료하려면 **Return** 또는 **Enter** 키를 두 번 누릅니다.

### 텍스트 및 스타일 복사하기

다른 보드나 서드-party 애플리케이션에서 **Ctrl+C**/**Ctrl+V** (*Windows용*) 또는 **Cmd+C/Cmd+V** (*Mac용*) 단축키를 사용해 텍스트를 복사하고 붙여넣을 수 있습니다. 보드에서 여러 개체를 선택하는 방법은 [여기](../working-on-the-board/10-working-with-objects.md)에서 배울 수 있습니다.

또한 보드 위의 모든 도형이나 텍스트 상자에 특정 스타일을 빠르게 적용할 수도 있습니다. 스타일을 복사하고 적용하려면 **Ctrl + Alt + C**와 **Ctrl + Alt + V** (*Windows용*) 또는 **Cmd + Alt + C**와 **Cmd + Alt + V** (*Mac용*) 단축키를 사용하세요. 또는 텍스트 컨텍스트 메뉴의 세 점 아이콘을 클릭한 후 옵션을 선택하세요.

![copy_paste_style.gif](../../../../../../docs/using-miro/essential-tools/images/21017042407826_copy%20paste%20style.gif)
*스타일 복사 및 붙여넣기*

서식은 타사 애플리케이션에서 복사할 수 없습니다. 예외는 글머리 기호와 번호가 매겨진 목록입니다.

### 맞춤법 검사

Miro [데스크톱 앱](../../getting-started/apps-for-devices/05-desktop-app.md)에는 내장된 맞춤법 검사기가 있습니다. 맞춤법 검사기를 끄려면 [이 가이드](../../getting-started/apps-for-devices/05-desktop-app.md)를 참조하세요.

브라우저를 사용하는 경우 맞춤법 검사는 브라우저에서 지원된다면 Miro에서도 지원됩니다. 브라우저 설정에서 맞춤법 검사를 활성화하세요.

- *Chrome*의 경우 브라우저 설정 > **고급** > **언어** > **맞춤법 검사**를 활성화하세요.

### 자주 묻는 질문

1. 1. *연결 선에 텍스트를 추가하는 방법은 무엇인가요?*
      - [여기에서](05-connection-lines.md) 선에 텍스트를 추가하는 방법을 확인하세요.
   2. *텍스트 상자의 테두리 색상을 변경할 수 있나요?*
      - 아니요, 현재 이 기능은 제공되지 않습니다. [도형](11-shapes.md)의 테두리 색상은 변경할 수 있습니다.
   3. *텍스트 상자를 클릭했을 때 모든 서식 옵션이 보이지 않는 이유는 무엇인가요?*
      - 이 문서에 나열된 일부 서식 옵션은 다른 텍스트 도구([도형](11-shapes.md), [마인드맵](../advanced-tools/03-mind-map.md), [카드](02-cards.md) 등)에서는 지원되지 않으니 유의하시기 바랍니다. 또한 반드시 [선택 모드로 전환](../working-on-the-board/21-work-smarter-not-harder.md)했는지 확인하세요.
   4. *텍스트 상자를 이동하는 방법은?*
      - [선택 모드로 전환](../working-on-the-board/21-work-smarter-not-harder.md)하고, 텍스트 상자를 클릭하여 드래그하세요. 잠금이 해제되어 있는지 확인해주세요.
   5. *보드의 모든 텍스트 상자 서식을 한 번에 변경할 수 있나요?*
      - 가능합니다. 보드의 모든 객체를 선택한 다음 (*Windows*는 **Ctrl + A**, *Mac*는 **Cmd + A**를 사용할 수 있습니다), [텍스트를 필터](../working-on-the-board/21-work-smarter-not-harder.md)하고 서식을 변경하세요.

:::note
텍스트와 관련된 버그나 문제가 발생할 경우, [이 문제 해결 기사](../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md)를 확인하세요.
:::
