동영상 파일을 직접 Miro 캔버스에 업로드하여 보드의 누구라도 언제든지 재생할 수 있습니다.

## 동영상 업로드

지원되는 동영상 파일을 캔버스로 직접 드래그 앤 드롭하여 업로드합니다. 또는 다음을 수행합니다:

1. **툴, 미디어 및 통합** 아이콘을 작성 툴바 하단에서 클릭하세요.
2. **동영상**을 검색해서 선택하세요.
3. 동영상을 업로드할 위치에 있는 캔버스를 클릭하세요.
   빈 동영상 위젯이 나타납니다.
4. 생성된 동영상 위젯에서 **동영상 업로드**를 클릭하여 파일 브라우저를 엽니다.
5. 업로드할 동영상 파일을 선택하고 **열기**를 클릭하세요.
6. 파일 크기에 따라 동영상 업로드에 몇 초 정도 소요될 수 있습니다.

:::tip
템플릿을 생성할 때는 위의 3단계 이후에 중단하여 템플릿 사용자가 나중에 자신의 동영상을 업로드할 수 있는 동영상 위젯 플레이스홀더를 만들 수 있습니다.
:::

업로드 옵션을 통해서도 동영상을 업로드할 수 있습니다.

1. 작성 툴바 하단에 있는 **툴, 미디어 및 통합** 아이콘을 클릭합니다.
2. **업로드 > 내 기기**를 검색하여 선택합니다.
3. 업로드할 파일을 찾아 **열기**를 클릭합니다.
4. 파일 크기에 따라 동영상 업로드에 몇 초가 소요될 수 있습니다.

:::note
업로드된 동영상 파일의 최대 크기는 150MB입니다.
:::

### 동영상 제목 변경

비디오 파일 이름이 보드의 미리보기 섬네일에 제목으로 표시됩니다. 더 설명적인 제목으로 변경하려면 다음과 같이 하세요:

1. 비디오를 클릭해 컨텍스트 메뉴 바를 표시합니다.
2. 컨텍스트 메뉴 바에서 **제목**을 클릭합니다.
3. 새로운 제목을 입력하고 **엔터**를 누릅니다.

업데이트된 제목이 비디오 미리보기에 표시됩니다.

## 지원되는 비디오 포맷

다음 비디오 포맷이 업로드 가능합니다:

- MP4
- MOV
- WebM

다음 비디오 코덱이 지원됩니다:

- h264
- h265
- av1
- vp8
- vp9

## 동영상 컨트롤

동영상 컨트롤에는 다음이 포함됩니다:

- 재생/일시정지
- 10초 단위 앞/뒤로 이동
- 오디오 켜기/끄기
- 전체 화면

전체 화면 모드에서는 키보드 컨트롤도 지원됩니다. **스페이스 바**를 사용해 동영상을 일시 정지하거나 재생할 수 있으며, **화살표 키**를 이용해 10초 간격으로 앞뒤로 이동하거나 **esc**를 눌러 전체 화면 모드를 종료할 수 있습니다.

## 자주 묻는 질문

**내 동영상을 캔버스에서 누가 볼 수 있나요?**

동영상 파일은 업로드된 후 다른 보드 공동 작업자만 볼 수 있습니다 (동영상은 보드 전체와 동일한 권한 설정을 가집니다).

**여러 보드 사용자가 동시에 동영상을 시청할 수 있나요?**

예, 하지만 각 사용자는 자신의 보드에서 **재생** 버튼을 눌러야 합니다. 보드 사용자는 이미 다른 사용자가 시청 중인 동영상을 비동기적으로 시청할 수 있습니다.

**동영상의 특정 부분에 댓글을 남기거나 주석을 달 수 있나요?**

현재로서는 불가능합니다. 하지만 동영상을 일시 정지하고 컨텍스트 메뉴를 클릭하여 **이미지로 복사**를 선택한 후 이미지를 보드에 붙여넣고 댓글을 남기거나 주석을 달 수 있습니다.
