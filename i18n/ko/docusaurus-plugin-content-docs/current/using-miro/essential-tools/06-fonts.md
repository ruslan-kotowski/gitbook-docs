Miro의 견고한 글꼴 모음을 확인해 보세요. 콘텐츠를 보다 시각적으로 매력적이고 효율적으로 만들어 줄 20개 이상의 베스트셀러 글꼴이 포함되어 있습니다. 텍스트의 주요 포인트를 강조하여 더 큰 흥미를 추가하세요.

## 글꼴 변경

:::tip
팀 콘텐츠 제작을 간소화하려면 글꼴을 업로드하세요 [브랜드 센터](../../administration/get-started-as-a-miro-admin/04-brand-center.md)에.
:::

Miro에서 텍스트의 글꼴을 변경하려면 텍스트 또는 도형을 강조 표시하고 드롭다운 메뉴에서 글꼴을 선택하세요.

![Miro_fonts.gif](../../../../../../docs/using-miro/essential-tools/images/21017592644754_Miro%20fonts.gif)
*텍스트 글꼴 변경*

텍스트 상자에서 특정 단어나 구문에 대해 글꼴을 선택할 수 없으며, 객체의 전체 텍스트에 적용됩니다. 문서, 슬라이드, [도형](11-shapes.md), [텍스트 상자](16-text.md)의 글꼴을 변경할 수 있습니다. [스티커 메모](14-sticky-notes.md)는 두 가지 글꼴 스타일을 지원합니다. [카드](02-cards.md), [연결선](05-connection-lines.md) 및 [마인드맵 노드](../advanced-tools/03-mind-map.md)는 여러 글꼴을 지원하지 않습니다.

## 자주 묻는 질문

Miro에 다른 글꼴을 추가할 수 있나요?

네, [브랜드 센터](../../administration/get-started-as-a-miro-admin/04-brand-center.md)를 통해 브랜드 폰트를 업로드할 수 있습니다.

글꼴 색상을 변경할 수 있나요?

[텍스트 상자](16-text.md), [도형](11-shapes.md), [마인드맵 노드](../advanced-tools/03-mind-map.md), 및 [연결선](05-connection-lines.md)의 글꼴 색상을 변경할 수 있습니다. 텍스트 색상은 [스티커 메모](14-sticky-notes.md)와 [카드](02-cards.md)에서 변경할 수 없습니다.

보드에 대한 기본 글꼴을 설정할 수 있나요?

텍스트 상자나 도형을 만들 때 사용하는 글꼴은 동일한 작업 세션에서 보드에 새 텍스트 상자나 도형을 만들 때에도 그대로 유지됩니다(보드를 다시 로드하기 전까지). 모든 기존 텍스트 상자나 도형의 글꼴을 변경하려면, 보드의 모든 객체를 선택하세요 ({**Ctrl + A** *Windows*에서 또는**Cmd + A** *Mac*에서 사용할 수 있습니다), [텍스트/도형 필터링](../working-on-the-board/21-work-smarter-not-harder.md), 그리고 서식을 변경하세요.
