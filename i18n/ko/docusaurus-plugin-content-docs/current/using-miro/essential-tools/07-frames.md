프레임을 사용해 보드의 콘텐츠를 구조화하세요. 프레임을 추가, 삭제, 사용자 지정할 수 있으며, 프레임을 사용해 보드에서 쉽게 콘텐츠를 탐색하고, 청중에게 프레임을 프레젠테이션하고, PDF로 내보낼 수 있습니다.

> 🚀 보드 정리 기술을 뽐내보세요. [Miroverse에 게시](https://miro.com/miroverse/submission/?backToUrl=/)하고 6천만 명 이상의 사용자가 작업을 시작할 수 있도록 도와주세요.

## 프레임 기본 사항

### 프레임 추가

:::tip
프레임 툴을 열고 **템플릿 보기**를 클릭하면 사전 설정된 다양한 프레젠테이션 및 슬라이드 [템플릿](../../getting-started/start-here/your-first-board/04-templates.md)을 사용할 수 있습니다.
:::

1. 보드 왼쪽의 [제작](../../getting-started/start-here/your-first-board/05-toolbars.md) 툴바에서 **F****rame** 아이콘을 클릭합니다.
2. 프레임 툴이 열립니다.
3. 프레임을 보드에 바로 끌어다 놓거나 F[단축키](../working-on-the-board/06-shortcuts-and-hotkeys.md)를 누른 상태에서 보드의 아무 곳이나 클릭해 프레임을 추가합니다. "또한 보드에서 클릭하고 드래그하여 프레임을 직접 만들 수 있습니다."

![adding-a-frame-to-the-board.gif](https://help.miro.com/hc/article_attachments/28871307962386)
*보드에 프레임 만들기*

기존 오브젝트 주위에 프레임을 추가할 수도 있습니다.

보드에 이미 콘텐츠를 추가한 경우 기존 오브젝트 주위에 프레임을 쉽게 만드세요. [오브젝트를 선택](../working-on-the-board/10-working-with-objects.md)하고 컨텍스트 메뉴에서 **세 점 아이콘** (**...**)을 클릭한 후 **프레임 만들기**를 선택합니다.

![create-a-frame.gif](https://help.miro.com/hc/article_attachments/28871298479250)
*보드 오브젝트 주위에 프레임 만들기*

:::tip
치수 [사용을 설정하면](../formats/diagramming/01-miro-for-mapping-diagramming.md) 보드 전체에서 동일한 프레임을 정밀하게 조정하며 만들 수 있습니다.
:::

### 프레임 삭제하기

1. 컨텍스트 메뉴에서 **세 점 아이콘**(**...**)을 클릭합니다.
2. 삭제를**선택합니다**.

![delete a frame.png](https://help.miro.com/hc/article_attachments/28871307967506)
*단일 프레임 삭제하기*

단축키를 사용할 수도 있습니다. 프레임 제목을 클릭하고 **Backspace** 키 또는 **Delete** 키를 누릅니다.

:::tip
실수로 프레임을 삭제한 경우 언제든지 [보드 변경 이력에서 복원](../working-on-the-board/18-restoring-board-content.md)할 수 있습니다.
:::

여러 프레임을 삭제하려면:

1. Shift 키를 누른 상태로 프레임을 선택하거나 선택 필드를 그립니다.</span> [오브젝트 선택](../working-on-the-board/10-working-with-objects.md)에 대해 자세히 알아보세요.
2. 컨텍스트 메뉴에서 필터를 사용해 **프레임**을 선택합니다.
3. 세 점 **아이콘** (**...**)을 클릭하세요.
4. **삭제**를 클릭하세요.

## **프레임 사용자 지정**

**프레임의 배치, 색상, 이름, 크기, 비율을 편집할 수 있습니다. 또한 프레임을 그룹화하고, 잠그고, 복제할 수 있습니다.**

### 프레임 이동 및 편집하기

프레임 이동하기:

1. [선택 도구](../working-on-the-board/05-using-miro-with-a-mouse-trackpad-or-touchscreen.md)로 전환하세요.
2. 프레임의 테두리 또는 제목을 클릭하고 드래그하세요.

프레임의 기본 색상은 흰색입니다. 컨텍스트 툴바에서 프레임의 크기와 색상을 변경할 수 있습니다.

### 프레임 이름 바꾸기

프레임 이름 바꾸기:

1. 프레임 제목을 두 번 클릭합니다.
2. 새 이름을 입력하기 시작합니다
3. 또는 컨텍스트 메뉴에서 **세 점** (**...**) 아이콘을 클릭합니다.
4. 클릭 **프레임 이름 바꾸기**.

### 프레임 크기 조정하기

프레임의 테두리 또는 제목을 클릭해서 프레임을 선택한 다음, 테두리를 드래그하여 프레임 크기를 조정합니다. 컨텍스트 메뉴에서 **세 점** (**...**) 아이콘을 클릭하여 프레임의 비율을 변경할 수 있습니다.

:::tip
[치수 사용](../formats/diagramming/01-miro-for-mapping-diagramming.md)을 설정하면 보드 전체에서 동일한 크기의 프레임을 정밀하게 생성할 수 있습니다.
:::

### 프레임 그룹화하기

프레임을 그룹화하려면:

1. Shift 키를 누른 상태에서 여러 프레임을 선택합니다.
2. 필터 옵션을 사용해 모든 프레임을 선택할 수도 있습니다.
3. 컨텍스트 메뉴에서 **그룹** 아이콘을 클릭하세요.

### 프레임 잠그기

프레임을 잠그면 실수로 프레임이 이동하는 것을 방지할 수 있습니다. 보드 편집자가 프레임 내 콘텐츠를 실수로 이동하지 못하도록 제한하려면 모든 오브젝트를 선택하고 잠급니다.

프레임 잠금 및 잠금 해제 옵션은 플랜 유형과 액세스 수준에 따라 달라집니다. 자세한 내용은 [보드에서 콘텐츠 잠그기](../working-on-the-board/17-locking-content-on-the-board.md)에서 알아보세요.

### 프레임 복제하기

프레임을 복제하려면 [단축키](../working-on-the-board/06-shortcuts-and-hotkeys.md) **Ctrl/Cmd + D**를 사용합니다. 프레임 이름에 날짜가 포함되어 있으면 자동으로 업데이트됩니다. 연도는 다음 연도로, 일은 다음 날로 변경됩니다.
![duplicating-a-frame.gif](https://help.miro.com/hc/article_attachments/28871307977234)
*프레임 복제하기*

### 프레임 내에서 복사해 붙여넣기

프레임 내에서 콘텐츠를 복사하여 붙여넣으면, 복사한 내용은 원본 프레임과 동일한 위치에 나타납니다. 프레임 간 복사하여 붙여넣기:

1. 복사할 콘텐츠를 선택합니다. Ctrl/Cmd 키를 눌러 여러 오브젝트를 선택합니다.
2. 컨텍스트 메뉴에서 **세 점 아이콘** (**...**) 아래에 있는 **복사**를 클릭합니다. 또는 키보드 단축키를 사용하세요: **Ctrl/Cmd-C**.
3. 대상 프레임을 선택합니다. (선택을 더 쉽게 하기 위해, 프레임을 미리 그룹화할 수 있습니다.)
4. 컨텍스트 메뉴에서 **세 점 아이콘** (**...**) 아래에 있는 **붙여넣기**를 클릭합니다. 또는 키보드 단축키를 사용하세요: **Ctrl/Cmd-V**.

대상 프레임의 크기가 원본 프레임 콘텐츠가 복사된 것과 다르면, 콘텐츠는 원본 x-y 좌표에 따라 대상 프레임의 왼쪽 상단 모서리를 기준으로 정렬됩니다. 이는 일부 콘텐츠가 프레임 밖에 나타나거나 프레임의 가장자리에 상대적으로 다른 위치에 있을 수 있음을 의미합니다.

## 프레임으로 프레젠테이션하기

### 프레젠테이션 모드

보드를 청중에게 프레젠테이션할 때 프레임 사이를 원활하게 이동할 수 있습니다. 프레젠테이션 모드를 켜려면 보드 오른쪽 상단에 있는 협업 툴바에서 Present 버튼을 클릭합니다.

전체 화면으로 바뀌고, 프레임은 슬라이드로 표시되며, 보드 툴과 프레임 제목은 숨겨집니다.

화살표를 사용해 프레임/슬라이드 사이를 탐색하세요.

### 프레임 숨기기 및 표시하기

> **실행 가능한 사용자:** 보드 소유자, 보드 공동 소유자 **해당 대상**: Education, Starter, Business, Enterprise 플랜

프레임 숨기기를 사용하면 워크숍과 회의 중에 공동 작업자와 청중에게 공개되는 콘텐츠를 제어할 수 있습니다.

프레임을 숨기면 보드의 어떤 사용자도 숨긴 프레임의 콘텐츠를 볼 수 없습니다. 프레임 숨기기는 회의를 기획하고 워크샵을 단계별로 구성할 때 유용합니다.

프레임이 숨겨지면 보드 참여자는 해당 콘텐츠를 볼 수 없습니다. 대신, 감은 눈 아이콘이 있는 빈 프레임이 표시됩니다.

사용자가 숨겨진 프레임 위에 오브젝트를 배치하면 해당 오브젝트는 플레이스홀더 프레임 아래로 이동하지만 여전히 편집할 수 있습니다.

:::tip
콘텐츠를 여러 프레임으로 분할해 회의나 워크숍에서 하나씩 공개할 수 있습니다. 비주얼 노트를 사용해 의제를 만들고 메모에 숨겨진 프레임을 추가할 수 있습니다.
:::

:::warning
프레임을 숨겨도 프레임의 댓글과 제목은 숨겨지지 않습니다.
:::

프레임을 숨기려면, 프레임을 클릭한 후 프레임의 오브젝트 메뉴에서 눈 아이콘을 클릭합니다.

![hiding-multiple-frames.gif](https://help.miro.com/hc/article_attachments/28871298494482)
*여러 프레임 숨기기*

프레임 패널은 내비게이션 툴바에서 접근할 수 있으며, 거기서 프레임을 숨길 수도 있습니다. **프레임** 아이콘을 클릭한 다음 **세 점** (**...**) 메뉴를 사용해 숨기기 기능에 접근하세요.

한 번에 여러 프레임을 숨기려면, 드래그해서 [프레임을 선택](../working-on-the-board/10-working-with-objects.md)하고 컨텍스트 메뉴에서 **눈** 아이콘을 클릭하세요.

숨겨진 프레임을 표시하려면, 컨텍스트 메뉴에서 **눈** 아이콘을 다시 클릭하세요.

:::warning
보드에서 숨겨진 프레임이 다시 표시되어도 [메모](17-visual-notes.md)에서는 자동으로 표시되지 않습니다. 프레임을 표시하려면 메모를 새로 고치세요.
:::

:::warning
보드 참여자는 프레임이 다시 표시될 때까지 숨겨진 프레임을 복사하거나 복제할 수 없습니다.
:::

## 빠른 프레임 프레젠테이션 기능

원활한 보드, 프레젠테이션, 워크숍을 위해 프레임을 빠르게 구성할 수 있는 많은 기능이 있습니다.

### 프레임 검토 및 재정렬하기

프레임 패널에서 프레임 간 빠르게 이동하고 프레임 순서를 재정렬하세요. 프레임의 순서를 변경하려면 프레임 패널에서 드래그하여 새로운 위치로 옮기세요.

![frames-button.png](https://help.miro.com/hc/article_attachments/28871298499730)
*내비게이션 툴바에서 프레임 패널 접근*

:::warning
모바일 및 기타 터치 장치의 태블릿 앱과 브라우저에서는 사이드바의 프레임 재정렬 기능을 사용할 수 없습니다.
:::

### 프레임 다중 선택

다중 선택을 사용하면 프레임 패널에서 여러 프레임을 선택해 일괄적으로 재정렬하거나 삭제할 수 있습니다. 여러 프레임을 선택하려면 **Ctrl** 키(Windows) 또는 **커맨드** 키(Mac)를 길게 누르세요.

![frame-multi-select.png](https://help.miro.com/hc/article_attachments/28871298502546)

*여러 프레임을 선택해 삭제, 숨기기 또는 이동하기*

프레임이 여러 개 있는 경우, 목록 보기로 정리하면 도움이 될 수 있습니다. 섬네일 대신 목록으로 프레임을 보려면 **세 점 아이콘** (**...**)을 클릭하고 **목록 보기**를 선택합니다.

![frames-list-view-2.png](https://help.miro.com/hc/article_attachments/28871298506130)

*목록 보기로 프레임 나열하기*

### 프레임 정리

프레임 정리는 보드의 프레임 순서를 읽고 사이드바에서 자동으로 정렬하여 프레젠테이션을 빠르게 준비할 수 있도록 도와줍니다. 매직 정리 알고리즘은 프레임이 보드에 배치된 순서(왼쪽에서 오른쪽, 위쪽에서 아래쪽)에 따라 프레임을 정렬합니다.

프레임을 정리하고 이전 프레임 순서로 돌아가려면, 보드 왼쪽에 있는 작성 툴바 아래의 [실행 취소](16-undoredo.md) 버튼을 클릭하세요.

![frames-organize.png](https://help.miro.com/hc/article_attachments/28871308006034)*세 점 (...) 메뉴에서 프레임을 자동으로 정리하세요*

### 특정 프레임의 링크 공유하기

보드를 공유할 때 상대방이 특정 프레임에 집중하도록 할 수 있습니다. 오브젝트 메뉴에서 특정 프레임의 링크를 복사할 수 있습니다: 오브젝트를 클릭하고 **세 점 아이콘** (**...**)을 클릭한 다음 **링크 복사**를 클릭합니다.

![copy link to a frame.png](https://help.miro.com/hc/article_attachments/28871308009234)
*보드에서 특정 프레임의 링크 복사하기*

## 프레임 내보내기

하나의 프레임만 내보내거나 여러 프레임을 선택해 내보낼 수 있습니다.

여러 프레임을 선택해 내보내려면:

1. Shift 키를 누른 상태로 내보낼 프레임을 선택하거나, 선택 상자를 드래그하여 프레임을 둘러쌉니다.
2. 컨텍스트 메뉴에서 필터 아이콘을 클릭하고 **프레임**을 선택합니다.
3. **세 점 아이콘** (**...**)을 클릭합니다.
4. 메뉴에서 내보내기 옵션을 선택하세요.

단일 프레임을 내보내려면, 프레임을 선택하고 **세 점 아이콘** (**...**)을 클릭한 다음 내보내기 옵션을 선택하세요.

### 보드 내보내기

프레젠테이션을 팀 외부로 공유하거나 외부 공동 작업자 및 공급업체와 공유할 수 있습니다. 이를 위해 전체 보드를 내보낼 수 있습니다. **추가 정보:** [보드를 내보내는 방법](../import-and-export/export/03-how-to-export-your-board.md).

## 자주 묻는 질문

**오브젝트가 프레임에 고정되지 않는 이유는 무엇인가요?**

가끔 오브젝트 위에 프레임을 추가할 때 서로 붙지 않는 경우가 있습니다. 오브젝트를 선택하고 조금 이동하면 프레임에 붙을 것입니다.

**프레임을 다른 보드로 복사하려면 어떻게 해야 하나요?**

Ctrl+C/Ctrl+V(Windows) 또는 Cmd+C/Cmd+V(Mac)를 사용해 프레임을 복사하고 다른 보드에 붙여넣으세요. 단, 보드 소유자가 보드 콘텐츠를 복사할 수 있도록 설정했는지 확인하세요.
