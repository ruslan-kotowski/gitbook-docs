스티커 메모는 빠르게 브레인스토밍하고, 메모를 작성하고, 정보를 시각적으로 정리하는 데 유용합니다. 칸반 보드 사용법에 익숙하거나 화이트보드에 스티커 메모를 붙이는 등 다른 사용법에 익숙하다면 편하게 사용할 수 있습니다.

> **사용 가능 환경:** 브라우저 버전, [데스크톱 앱](../../getting-started/apps-for-devices/05-desktop-app.md), [태블릿 앱](../../getting-started/apps-for-devices/11-tablet-app.md), [모바일 앱](../../getting-started/apps-for-devices/08-mobile-app.md)(일부 기능 제한)

### 시작하기

툴바에서 **스티커 메모** 아이콘을 클릭하거나 [키보드에서 N 키를 눌러](../working-on-the-board/06-shortcuts-and-hotkeys.md) 스티커 메모를 사용할 수 있습니다. 툴바에서 바로 스티커 메모를 끌어다 놓거나 보드를 클릭하고 마우스 왼쪽 버튼을 누른 채 커서를 드래그해 스티커 메모를 추가할 수도 있습니다.

![툴바 내 스티커 메모.png](images/21574848716562_sticky%20note%20on%20the%20toolbar.png)
*툴바 내 스티커 메모*

스티커 메모의 컨텍스트 메뉴에서 도형 아이콘을 클릭해 스티커 메모의 모양을 변경할 수 있습니다.

![스티커 메모 모양 변경.png](images/21574848725650_convert%20a%20sticky%20note.png)
*정사각형 모양의 스티커 메모를 직사각형 모양으로 변경하기*

스티커 메모에는 텍스트 가독성과 일관성 있는 보드 디자인을 위해 엄선된 16가지 색상이 제공됩니다(색상 사용자 지정 불가).

![스티커 메모 색상.png](images/21574848729490_sticky%20colors.png)
*스티커 메모 색상*

스티커 메모에 텍스트를 추가하려면 스티커 메모를 선택하고 입력을 시작합니다. 특수 기호는 텍스트 크기에 따라 스티커 메모당 약 3,000개까지 입력할 수 있습니다. 컨텍스트 메뉴에서 **자동** 글꼴 크기 기능을 사용할 수 있습니다.

![스티커 메모 글꼴 크기.png](images/21574848732050_sticky%20font%20size.png)
*스티커 메모의 자동 글꼴 크기 기능*

여러 개의 스티커 메모를 수정하려면(크기 및 색상 변경, 태그 추가 등) [이 가이드](../working-on-the-board/10-working-with-objects.md)의 안내를 따라 여러 개를 한번에 선택하세요.

![여러_스티커_메모_변경_회색배경.gif](images/21574848734098_changing_multiple_stickies_greybg.gif)
*여러 개의 스티커 메모 선택 및 수정하기*

:::tip
[치수 사용](../formats/diagramming/01-miro-for-mapping-diagramming.md)을 설정하면 보드 전체에서 동일한 크기의 스티커 메모를 정밀하게 조정하며 만들 수 있습니다.
:::

스티커 메모를 삭제하려면 컨텍스트 메뉴에서 세 점 아이콘을 클릭하고 **삭제**를 선택하거나, 간단하게 [스티커 메모를 선택](../working-on-the-board/21-work-smarter-not-harder.md)하고 **Backspace** 키를 누르면 됩니다.

![스티커 메모 삭제.png](images/21574848734866_delete%20a%20sticky.png)
*스티커 메모 삭제 옵션*

:::tip
여러 개의 스티커 메모를 하나의 스택으로 정렬하려면 [스티커 메모를 선택](../working-on-the-board/10-working-with-objects.md)하고 컨텍스트 메뉴에서 **정렬** 기능을 사용하세요.
:::

![스티커_메모_스택_회색배경.gif](images/21574819982866_stickies_stack_greybg.gif)
*스티커 메모 스택 만들기*

### 일괄 모드

여러 개의 스티커 메모를 연속으로 추가하려면 **스티커 메모** 아이콘을 클릭하고 **일괄 모드**를 선택한 다음 입력을 시작하세요. **Enter** 키를 눌러 아이디어를 구분하며 입력할 수 있습니다. 특수 기호는 글꼴 크기에 따라 입력 제한 개수가 달라집니다. 입력을 마치고 **완료**를 클릭하면 작성한 아이디어가 보드에 스티커 메모로 추가됩니다.

![일괄_모드_회색배경.gif](images/21574848737938_bulk_mode_greybg.gif)
*일괄 모드로 스티커 메모 추가하기*

### 스프레드시트에서 붙여넣기(Google Sheets, Excel 등)

스프레드시트에서 데이터를 복사해 보드에 스티커 메모 클러스터로 붙여넣을 수 있습니다. 각 스티커 메모는 하나의 셀을 나타냅니다.

1. **CTRL + C***(Windows)* 또는 **Cmd + C***(Mac)* 단축키를 사용해 스프레드시트에서 셀을 복사합니다.
2. Miro 보드를 열고 캔버스를 클릭합니다. 일괄 모드는 **열지 않아도** 됩니다.
3. **CTRL + V***(Windows)* 또는 **Cmd + V***(Mac)* 단축키를 누릅니다.
4. **스티커 메모로 붙여넣기**를 선택해 보드에 스티커 메모를 붙여넣습니다.

각 셀이 스티커 메모로 붙여넣어집니다. 한 번에 붙여넣을 수 있는 최대 셀 수는 **5,000개**(행 50개, 열 100개 이하)이며, 최대 문자 수는 **6,000자**입니다.

![스티커_메모로_내보내기_회색배경.gif](images/21574848740626_export_as_sticky_notes_greybg.gif)
*스프레드시트를 스티커 메모로 가져오기*

### 작성자 라벨

클릭 한 번으로 스티커 메모 작성자의 이름을 스티커에 쉽게 추가할 수 있습니다. 보드를 편집할 수 있는 모든 사용자는 컨텍스트 메뉴에서 **작성자 표시** 옵션을 활성화/비활성화해 스티커 메모의 작성자 라벨을 표시하거나 숨길 수 있습니다.

![작성자_라벨_회색배경.gif](images/21574819997330_author_label_greybg.gif)
*작성자 라벨 표시하기*

텍스트가 있는 스티커 메모의 작성자 라벨에는 스티커 메모를 만든 사용자의 이름이 표시됩니다. 그러나 스티커 메모의 텍스트를 다른 사용자가 편집하면 작성자 라벨이 자동으로 업데이트됩니다. 사용자 A가 만든 빈 스티커 메모를 사용자 B가 선택하고 작성자 라벨을 활성화하면 사용자 A가 아닌 사용자 B의 이름이 표시됩니다. [방문자](../sharing-boards/08-collaboration-with-visitors.md)가 스티커 메모에 텍스트를 입력하고 작성자 라벨을 활성화하면 작성자 라벨이 '방문자'로 표시됩니다. 단, [방문자의 이름이 설정](../sharing-boards/09-visitor-names-beta.md)되어 있거나 방문자가 Miro에 로그인한 경우는 해당하지 않습니다.

작성자 라벨은 기본적으로 비활성화되어 있으며 보드의 모든 사용자에게 작성자 라벨을 강제로 적용할 수는 없습니다. 그러나 [보드 변경 이력](../managing-boards/11-board-history-activity.md)을 확인하거나 컨텍스트 메뉴의 **정보**를 확인하는 방법으로 스티커 메모를 누가 만들고 편집했는지 추적할 수 있습니다.

### 태그

**태그**를 사용해 작업과 아이디어를 구조화하세요. 스티커 메모를 강조 표시하고 **태****그** 아이콘을 클릭해 새 태그를 만들거나 기존 태그를 선택하고 원하는 만큼 스티커 메모에 적용합니다. 태그 검색을 통해 스티커 메모 그룹을 빠르게 찾을 수 있습니다. 각 스티커 메모에 태그를 최대 8개까지 추가할 수 있습니다.

![스티커 메모에 태그 추가.png](images/21574819999506_add%20a%20tag%20to%20a%20sticky.png)
*태그 사용하기*

특정 태그가 포함된 스티커 메모를 모두 찾으려면 [보드 검색](../working-on-the-board/19-searching-text-on-the-board.md)을 사용하세요.

*![보드 검색.png](images/21574848744466_Board%20search.png)
보드의 왼쪽 상단 모서리에 있는 보드 검색 아이콘*

스티커 메모에서 태그를 삭제하려면 컨텍스트 메뉴에서 **태그 추가**를 선택하고 제거하려는 태그를 클릭합니다.

![태그_삭제_회색배경.gif](images/21574848745234_delete_a_tag_greybg.gif)
*스티커 메모에서 태그 삭제하기*

보드의 **모든** 오브젝트에서 태그를 **완전히** 제거하려면 펜 아이콘을 클릭하고 **태그 삭제**를 선택합니다.

![보드에서_태그_삭제_회색배경.gif](images/21574848746002_delete_a_tag_from_the_board_greybg.gif)
*보드에서 태그 삭제하기*

### 이모티콘 리액션

스티커 메모에 **이모티콘** 리액션을 추가해 메모에 응답할 수 있습니다. 이모티콘은 투표, 할 일 확인, 단순 재미 목적 등 다양한 용도로 사용할 수 있습니다.

이모티콘으로 반응하려면 스티커 메모를 선택하고 메뉴에서 **이모티콘 추가**를 찾으세요. 이모티콘을 선택하면 스티커 메모의 하단에 이모티콘이 표시됩니다. 기존 이모티콘에 투표를 추가하고 하나의 스티커 메모에 여러 개의 리액션을 추가할 수 있습니다.

![이모티콘 추가.png](images/21574848747538_add%20emoji.png)
*스티커 메모에 이모티콘 리액션 추가하기*

추가한 이모티콘을 제거하려면 [선택 툴](../working-on-the-board/05-using-miro-with-a-mouse-trackpad-or-touchscreen.md)을 사용해 클릭하기만 하면 됩니다.

![이모티콘_제거_회색배경.gif](images/21574820003858_remove_emoji_greybg.gif)
*스티커 메모에서 이모티콘 제거하기*

### 다이어그램 빠르게 생성하기

스티커 메모나 도형, 또는 카드를 선택하고 오브젝트 근처의 파란색 점 위로 마우스를 가져가면 새 오브젝트나 연결선을 생성할 수 있는 위치가 표시됩니다. 오브젝트나 연결선을 만들려면 파란색 점을 클릭합니다. 선택한 오브젝트를 기존의 다른 오브젝트에 연결하려면 점을 드래그합니다.

:::tip
다이어그램 작성 기능에 대해 자세히 알아보려면 [Miro에서 매핑 및 다이어그램 작성하기](../formats/diagramming/01-miro-for-mapping-diagramming.md)를 참고하세요.
:::

### 자주 묻는 질문

1. *스티커 메모 안에 있는 텍스트의 서식을 지정할 수 있나요?*
   - 스티커 메모 안에 있는 텍스트의 크기, 정렬, 스타일(굵게, 기울임꼴, 밑줄)을 변경할 수 있습니다. 다른 서식 옵션은 사용할 수 없습니다.
2. *스티커 메모의 텍스트를 내보낼 수 있나요?*
   - 네, [스티커 메모를 선택](../working-on-the-board/10-working-with-objects.md)하고 컨텍스트 메뉴에서 세 점 아이콘을 클릭한 다음 **CSV로 내보내기**를 선택하세요. [보드 콘텐츠를 이미지나 PDF로 내보내기](../import-and-export/export/03-how-to-export-your-board.md)할 수도 있습니다.
3. *[펜 그림](10-pen.md), 이미지, 아이콘이 스티커 메모에 자동으로 부착(고정)되도록 할 수 있나요?*
   - 아니요, 하지만 스티커 메모에 그림이나 이미지 등을 추가하고 [두 오브젝트를 모두 선택](../working-on-the-board/10-working-with-objects.md)해 [그룹화](../working-on-the-board/08-structuring-board-content.md)할 수 있습니다. 그러면 그림이 스티커 메모에 고정됩니다.
4. *[댓글 작성자](../sharing-boards/01-board-access-rights.md)도 스티커 메모와 이모티콘을 추가할 수 있나요?*
   - 아니요, 댓글 작성자는 [댓글](../facilitation-tools/asynchronous-tools/01-comments.md)만 남길 수 있으며 다른 위젯은 사용할 수 없습니다.
5. *보드에 여러 개의 스티커 메모를 추가하려면 어떻게 해야 하나요?*
   - 일괄 모드를 사용해 여러 스티커 메모에 텍스트를 작성한 뒤 추가하거나 **스티커 메모 팩** [템플릿](../../getting-started/start-here/your-first-board/04-templates.md)을 사용해 여러 개의 빈 스티커 메모를 추가할 수 있습니다. 스티커 메모 팩 템플릿은 [템플릿 선택기](../../getting-started/start-here/your-first-board/04-templates.md)에서 검색해 찾을 수 있습니다.
6. *툴바에서 스티커 메모 아이콘이 사라졌습니다. 어떻게 되돌릴 수 있나요?*
   - 툴바에서 세 점 아이콘을 클릭하고 검색 패널을 사용해 스티커 메모 툴을 찾으세요. 스티커 메모를 툴바로 드래그해 다시 놓을 수 있습니다. [여기](../../getting-started/start-here/your-first-board/05-toolbars.md)에서 자세히 알아보세요.
7. *갑자기 스티커 메모를 편집할 수 없습니다. 이유가 무엇인가요?*
   - 다음 사항을 확인하세요.
   - [편집자](../sharing-boards/01-board-access-rights.md) 권한이 취소되었는지 확인합니다. 툴바에서 다른 툴을 사용할 수 있다면 여전히 편집자 권한이 있다는 의미입니다.
   - 스티커 메모가 [잠겨](../working-on-the-board/17-locking-content-on-the-board.md) 있는지 확인합니다.
   - 스티커 메모를 편집하기 전에 [선택 툴](../working-on-the-board/05-using-miro-with-a-mouse-trackpad-or-touchscreen.md)로 전환했는지 확인합니다.
