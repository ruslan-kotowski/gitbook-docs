코드 블록을 추가하여 협력 프로그래밍, 디버깅 및 문제 해결을 보드에서 수행하세요. 우리 코드 블록 위젯은 가장 인기 있는 코딩 언어들을 제공하며 사용자 지정이 가능합니다.

코드 블록을 [매핑 및 다이어그램 작성](../formats/diagramming/01-miro-for-mapping-diagramming.md) 기능과 결합하여 아키텍처와 흐름을 검토하세요. 소스 코드 조각 간의 관계를 강조하려면 다이어그램 커넥터를 사용하세요.

**다음 용도로 코드 블록을 사용하세요:**

- 애자일 세리머니
- 협업 개발 및 디버깅 세션
- 원격 코딩 인터뷰

## 코드 블록 추가하기

1. 보드 왼쪽의 작성 툴바로 이동하세요
2. **앱 더 보기** 아이콘을 클릭하세요
3. '코드 블록'을 검색하거나, **'코드 블록'**이 나타날 때까지 아래로 스크롤하세요.
4. 코드 블록 앱 아이콘을 클릭하세요
5. 보드의 아무 곳이나 클릭해서 코드 블록을 추가하세요

보드에 코드 블록 추가하기*

## 코드 블록 사용자 지정하는 방법

코드 블록 컨텍스트 메뉴 내에서 줄을 켜고 끌 수 있으며, 글꼴 크기를 조정하고 프로그래밍 언어를 전환할 수 있습니다.

1. 코드 블록을 클릭하세요.
2. 컨텍스트 메뉴에서 드롭다운으로 프로그래밍 언어를 선택하고, 글꼴 크기를 조정하며, 아이콘으로 줄 번호를 켜거나 끕니다.

![Customizing_a_code_block.gif](../../../../../../docs/using-miro/essential-tools/images/21016928890130_Customizing%20a%20code%20block.gif)*보드에서 코드 블록 사용자 지정*

## 자주 묻는 질문

코드 블록에서 현재 사용할 수 있는 프로그래밍 언어는 무엇인가요?

JavaScript, TypeScript, Python, C++, Java, Go, Rust, PlainText, Swift, Ruby, SQL, HTML, CSS, JSON, GraphQL, Kotlin, YAML, 그리고 Mermaid.
저희는 고객 요청에 따라 정기적으로 언어를 추가합니다. 의견이 있으시면 Miro 고객 성공 매니저에게 문의하세요.
