픽셀 단위의 정확한 크기 조정을 위해 포맷에서 숫자 치수를 사용하여 위젯 크기를 조정하세요.

:::note
정밀한 크기 조정은 다이어그램 작성, Miro Prototypes, Miro 슬라이드 등의 특정 포맷에서 사용 가능합니다.
:::

## 정밀한 크기 조정

1. **집중 모드** 아이콘을 포맷의 컨텍스트 메뉴에서 클릭해 집중 모드로 들어갑니다.
2. 크기를 조정할 위젯을 클릭합니다. 지원되는 위젯으로는 텍스트, 이미지, 스티커 메모, 스텐실, 프로토타이핑 도형이 있습니다.
3. 위젯의 컨텍스트 메뉴에서 **크기 조정** 아이콘을 클릭합니다.
   그러면 메뉴 아래에 크기 조정 대화 상자가 열립니다.
4. **너비**와 **높이**에 대한 픽셀 수치를 입력합니다.
5. **Enter** 키를 눌러 변경 사항을 확정합니다.

:::note
텍스트 상자의 경우, 너비만 지정할 수 있으며 높이는 텍스트 상자 내용에 따라 자동으로 조정됩니다.
:::
