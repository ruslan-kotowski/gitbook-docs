Miro에 업로드한 이미지를 수정하려면 Miro AI를 사용하세요.

## 이미지 배경 제거하기

1. 보드에 업로드하거나 붙여넣은 이미지를 선택하세요.
   컨텍스트 메뉴가 표시됩니다.
2. 컨텍스트 메뉴에서 **Miro AI**를 선택하세요.
   드롭다운 메뉴가 열립니다.
3. **배경 제거**를 선택하세요.

## 이미지 대체 텍스트 제안 받기

1. 보드에 업로드되었거나 붙여넣어진 이미지를 선택합니다.
   컨텍스트 메뉴가 표시됩니다.
2. 컨텍스트 메뉴에서 **ALT**를 선택합니다.
   **이미지 설명** 대화 상자가 열리고, **Miro AI**가 자동으로 제안을 생성합니다.
3. **삽입**을 클릭합니다.
   생성된 제안이 자동으로 저장됩니다.
4. (선택 사항) 삽입된 제안을 편집합니다. 변경 사항은 자동으로 저장됩니다.
5. **이미지 설명** 대화 상자를 닫습니다.

:::note
Miro AI로 대체 텍스트를 생성하는 것은 AI 크레딧을 소모하지 않습니다.
:::

## 이미지를 다이어그램이나 Miro 프로토타입으로 변환하기 (제한된 사용 가능성)

Miro AI를 사용하여 다이어그램이나 Miro 프로토타입 이미지를 Miro 보드에서 완전히 편집 가능한 버전으로 변환할 수 있습니다. 다이어그램 이미지는 손으로 그린 스케치일 수도 있습니다.
