Miro AI가 처음이신가요? 콘텐츠 생성과 아이디어 도출을 위한 준비된 프롬프트부터 시작해 보세요. 각 사용 사례는 어떤 목적에 적합한지 설명하고, 복사에 적합한 Miro AI 프롬프트를 포함하고 있습니다.

## **아이디어 생성 및 확장**

아이디어 흐름을 촉진하고 처음 초안을 더 빠르게 작성하도록 Miro AI의 준비된 프롬프트를 사용하세요.

### 제품 기능 아이디어 생성

**용도:** 사용자 요구에 기초한 신속한 기능 목록 작성.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 사용자 페르소나의 주요 페인 포인트를 해결할 수 있는 10개의 혁신적인 제품 기능 아이디어를 생성하세요. 가치가 있으며 기술적으로 실현 가능한 기능에 중점을 두세요. 스티커 메모 형식으로 작성하세요.
```

### 워크숍 후속 질문 생성하기

**사용 목적:** 세션 이후 퍼실리테이션을 더 원활하게 진행하고 깊이 있는 탐색을 돕습니다.

**Miro AI 프롬프트:**

복사

```
우리 워크숍의 주제나 결정에 따라 Miro 보드에서 선택된 내용을 기반으로 5가지 심도 있는 후속 질문을 생성하세요. 이 주제에 대해 더 깊이 탐구하고 놓쳤을 수 있는 잠재적인 문제나 기회를 발견하는 데 도움이 됩니다. 포맷은 Miro 스티커 메모로 설정하세요.
```

### 추가 개념 또는 변형 생성

**용도:** 빠른 메모를 더 풍부한 아이디어 클러스터로 전환합니다.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 브레인스토밍 아이디어의 관련 개념이나 변형 3~5가지를 생성하여 추가로 탐색해야 합니다. 스티커 메모 형식으로 작성하세요.
```

### 대안 솔루션 생성

**용도:** 다양한 경로를 탐색한 후 결론을 내리기 위해.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 문제를 해결하기 위한 4가지 대안 접근법을 생성하세요. 현재 솔루션과 문제 진술의 맥락을 공유하세요. 각 대안에 대해 현재 플랜과 비교했을 때의 주요 트레이드오프를 한 가지씩 메모해두세요. 스티커 메모 형식으로 작성하세요.
```

## **회의 준비**

계획을 세우고, 효과적으로 진행하며, 후속 조치를 취합니다.

### 회의 안건 작성

**사용 목적:** 일관되고 시간 제한이 있는 안건으로 명확한 결과 확보.

**Miro AI 프롬프트:**

복사

```
Miro 보드에 선택된 회의 유형과 주요 목표에 대한 상세한 일정 템플릿을 만드세요. 시간 할당, 주요 논의 포인트, 실행 항목을 위한 스페이스를 포함하세요. Miro 문서 형식으로 작성하세요.
```

### 회고 토론 질문 생성

**용도:** 균형 잡힌 성찰과 미래 지향적 실행.

**Miro AI 프롬프트:**

복사

```
Miro 보드에 선택한 팀 회고의 초점 영역에 기초하여 8~10개의 흥미로운 토론 질문/아이디어를 만드세요. 반성적 질문과 미래지향적 질문을 모두 포함시켜 주세요. Miro 스티커 메모로 포맷하십시오.
```
