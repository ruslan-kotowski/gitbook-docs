새로운 Miro AI 사용자이신가요? 콘텐츠 분석 및 조직화를 위한 준비된 프롬프트로 시작해보세요. 각 사용 사례는 해당 목적을 설명하고 복사 가능한 Miro AI 프롬프트를 포함하고 있습니다.

## **콘텐츠 강화**

작업의 명확성, 완전성, 가정 항목을 강화합니다.

### 스티커 메모 명확성 향상

**목적:** 메모를 구체적이고, 간결하며, 실천적이게 만듭니다.

**Miro AI 프롬프트:**

복사

```
우리의 Miro 보드에서 선택한 스티커 메모나 콘텐츠를 원래 의도를 유지하면서 더욱 명확하고 구체적이며 실행 가능하게 재구성하세요. Miro 스티커 메모로 포맷하세요.
```

### 추가 프로젝트 고려사항 제안

**용도:** 리스크, 의존성 및 블라인드 스팟을 조기에 밝혀냅니다.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 현재 프로젝트 계획을 검토하세요. 우리가 놓치고 있는 중요한 고려사항, 위험 요소, 또는 종속사항이 무엇일까요? 추가적으로 검토해야 할 5-7가지 항목을 제안하세요. Miro 문서로 포맷하세요.
```

### 누락된 프로세스 요소 추천

**용도:** 단계, 의사결정, 피드백 루프의 공백을 메우기 위함.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 현재의 프로세스 흐름을 분석하고, 이를 더 완전하고 효과적으로 만들기 위해 추가해야 할 절차, 결정 지점, 피드백 루프를 제안하세요. Miro 플로차트 다이어그램으로 포맷하세요.
```

### 가정 검증 질문 생성

**목적:** 자원을 할당하기 전에 가정을 테스트합니다.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 프로젝트 계획의 가정마다 유효성을 검증할 수 있는 구체적인 질문이나 테스트를 생성하세요. Miro 스티커 메모로 포맷하세요.
```

## **의사 결정 지원**

구조화된 기준과 측정 가능한 결과로 정보에 근거한 결정을 내리세요.

### 장단점 목록 작성

**용도:** 옵션 간의 거래에 대한 균형 잡힌 시각 제공.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 결정이나 옵션에 대해 포괄적인 장단점 분석을 만드세요. 각 측면에 대한 잠재적인 단기 및 장기 영향을 포함하세요. Miro 문서로 포맷합니다.
```

### 리스크 평가 기준 생성

**목적:** 제안/계획 전반에 걸친 일관된 리스크 점수를 위한 것입니다.

**Miro AI 프롬프트:**

복사

```
위험 평가 기준 생성
프로젝트나 이니셔티브 유형에 따라 Miro 보드에서 선택된 5-7개의 주요 기준을 포함한 위험 평가 프레임워크를 만듭니다. 각 기준을 평가할 수 있는 채점 시스템과 가이드를 포함하세요. Miro 테이블 형식으로 작성합니다.
```

### 평가 프레임워크 개발

**목적:** 옵션 간의 가중치를 둔 객관적 비교.

**Miro AI 프롬프트:**

복사

```
평가 프레임워크 개발 Miro 보드에서 선택한 여러 옵션(아이디어, 솔루션, 벤더 등)에 대해 가중치 기준의 평가 프레임워크를 만들어 객관적이며 데이터 기반의 결정을 내리는 데 도움을 줍니다. Miro 테이블 형식으로 작성하십시오.
```

### 성공 지표 제안

**용도:** 선행 및 후행 지표를 처음부터 정의합니다.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 이니셔티브에 대해 5-8개의 구체적이고 측정 가능한 성공 지표를 제안하세요. 초기 신호(선행 지표)와 최종 결과(후행 지표)를 모두 포함하세요. Miro 테이블로 포맷하세요.
```

## **프로세스 문서화**

워크숍과 흐름을 실용적인 가이드와 체크리스트로 전환합니다.

### 브레인스토밍을 구조화된 플랜으로 전환하기

**용도:** 아이디어에서 우선순위가 설정된 실행 가능한 플랜으로 전환합니다.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 브레인스토밍 결과를 우선순위가 있는 실행 가능한 계획으로 변환하고, 시작일은 오늘 날짜로, 종료일은 2주 후로 설정하며, 자원 요구사항과 도움이 될 수 있는 모든 항목을 포함하세요. Miro 테이블로 포맷합니다.
```

### 단계별 가이드 만들기

**용도:** 팀의 누구든지 따를 수 있는 명확한 지침.

**Miro AI 프롬프트:**

복사

```
우리의 Miro 보드에서 선택한 워크플로 다이어그램을 기반으로 팀의 누구나 따라할 수 있는 세부 단계별 가이드를 작성하세요. 각 단계에 의사결정 포인트, 필요한 도구, 예상 결과를 포함하세요. Miro 문서 포맷으로 작성하세요.
```

### 프로세스 맵에서 체크리스트 생성


복사

```

```
