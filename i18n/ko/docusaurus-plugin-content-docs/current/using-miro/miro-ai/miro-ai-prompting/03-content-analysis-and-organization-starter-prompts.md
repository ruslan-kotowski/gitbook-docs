Miro AI를 처음 사용하시나요? 콘텐츠 분석 및 조직화를 위한 사전 준비된 프롬프트로 시작해보세요. 각각의 사용 사례는 목적을 설명하며 복사용 Miro AI 프롬프트를 포함하고 있습니다. 대괄호로 된 자리표시자([role], [artifact], [tone] 등)를 자신의 컨텍스트로 대체한 후 Miro AI에서 프롬프트를 실행하세요.

## **정보 처리 & 요약**

원시 메모를 깔끔한 요약, 테마 및 실행 가능한 목록으로 변환합니다.

### 토론 스레드 요약하기

**목적:** 긴 보드나 메모 클러스터의 빠르고 공유 가능한 요약.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 토론의 주요 내용을 3단락으로 간결하게 요약하세요. 주요 테마, 결론, 다음 단계 등을 포착하여 Miro 문서로 포맷팅하세요.
```

### 핵심 테마 식별 및 그룹화

**사용 목적:** 빠른 클러스터링을 통한 패턴 및 중요한 요소 파악.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 아이디어와 피드백 항목을 분석하세요. 반복적으로 등장하는 상위 5개 테마를 식별하고 관련 항목을 각 테마 아래에 그룹화하세요. 구조화된 목록으로 제공합니다. 스티커 메모 형식으로 포맷하세요.
```

### 실행 항목 추출 및 우선순위 지정

**목적:** 어수선한 메모에서 할 일, 담당자, 날짜 추출하기입니다.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 메모를 검토하세요. 모든 실행 항목을 추출하고, 작업 설명, 책임자(언급된 경우), 마감일(언급된 경우)로 구성하고 Miro 테이블 형식으로 정리하세요.
```

### 피드백 분류

**용도:** 명확한 우선순위를 가진 그룹으로 입력을 정리합니다.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 피드백을 논리적인 그룹으로 분류하고, 카테고리별 빈도와 영향을 기준으로 우선순위 수준(높음/중간/낮음)을 제안하세요. Miro 테이블 형식으로 구성합니다.
```

## **데이터 종합**

다양한 소스의 입력을 명확하고 결정을 내리기 쉽게 통합합니다.

### 사용자 연구 인사이트 통합

**목적:** 여러 세션을 간결한 인사이트 세트로 통합하기 위함입니다.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택된 여러 사용자 조사 세션의 주요 발견점을 5가지 주요 인사이트와 지지 증거로 요약하세요. 추가 조사가 필요한 상충되는 발견점을 강조하세요. Miro 문서로 포맷하세요.
```

### 요약서 작성

**용도:** 리더와 이해관계자를 위한 1페이지 요약.

**Miro AI 프롬프트:**

복사

```
리더 및 이해관계자를 위한 1페이지 간결한 요약본을 Miro 보드의 상세한 프로젝트 정보에 기반하여 작성하세요. 다룰 내용: 프로젝트 상태, 주요 성과, 현재 문제점 및 권장되는 다음 단계. 포맷으로 Miro 문서로 작성하세요.
```

### 상태 보고서 생성하기

**사용 목적:** 진행 상황, 방해 요소, 우선순위 포함 주간 업데이트.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 프로젝트 추적 정보를 사용하여 주간 상태 보고서를 생성하세요 (현재 상태, 완료된 작업, 다가오는 마일스톤). 진행 상황, 방해 요소, 다가오는 주간 우선순위를 강조하세요. Miro 테이블로 포맷하세요.
```

### 이해관계자 피드백 통합

**용도:** 관점을 일치시키고, 갈등과 해결 방안을 드러냅니다.

**Miro AI 프롬프트:**

복사

```
Miro 보드에서 선택한 다양한 이해관계자의 피드백을 요약하여 합의된 분야, 상충되는 관점, 제안된 해결책을 보여줍니다. Miro 다이어그램으로 포맷하세요.
```
