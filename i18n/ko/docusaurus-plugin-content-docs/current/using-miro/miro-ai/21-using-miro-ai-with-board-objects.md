Miro Assist는 [스티커 메모](../essential-tools/14-sticky-notes.md), 이미지, [코드 블록](../essential-tools/04-code-block.md), [카드](../essential-tools/02-cards.md), 시퀀스 다이어그램, [마인드맵](../advanced-tools/03-mind-map.md) 등 다양한 보드 오브젝트와 함께 사용할 수 있습니다. Miro Assist가 브레인스토밍을 돕고 팀의 창의력을 발휘할 수 있도록 도와주세요.

> **사용 가능 환경:** 브라우저, 데스크톱
>
> **해당 대상:** Free 플랜, Starter 플랜, Education 플랜, Business 플랜,Enterprise 플랜

:::warning
Miro Assist는 베타 버전이며 계속해서 발전하고 있습니다. 따라서 Miro Assist는 잘못되거나 편향된 정보를 생성하거나 지난 6~12개월 동안의 최근 발생한 사건을 알지 못해 부정확하거나 오래된 정보를 제공할 수 있습니다. Miro Assist를 사용할 때는 항상 결과를 다시 확인하고 점검하세요.
:::

:::note
Miro Assist는 멤버만 사용할 수 있습니다. 게스트와 방문자는 Miro Assist를 사용할 수 없습니다.
:::

## 스티커 메모로 Miro Assist를 사용하기

컨텍스트 메뉴에서 명령 팔레트에서

**단일 스티커 메모와 상호 작용하기**

1. 작업하려는 스티커 키를 클릭하세요.
2. 컨텍스트 메뉴에서 **Miro 인증** 버튼을 클릭하세요.
3. **비슷한 스티커 메모 추가를** 선택하세요.
4. 콘텐츠가 생성되고 보드에 배치됩니다. 새 스티커 메모를 볼 수 있는 공간이 없으면 **결과로 이동을** 클릭하세요. 결과에 만족한다면 **유지를** 클릭하세요.

**여러 스티커 메모와 상호 작용하기**

1. 작업할 스티커 메모를 선택하세요.
2. 컨텍스트 메뉴에서 **Miro 인증** 버튼을 클릭하세요.
3. **스티커 메모 요약하기를** 클릭하세요.
4. Miro Assist 측면 패널이 선택한 스티커 메모의 요약과 함께 열립니다.
5. 여기에서 **복사** 버튼을 사용해 요약을 텍스트로 복사하거나 보드에 요약을 스티커 메모로 배치할 수 있습니다. 이렇게 하려면 다음으로 **만들기를** 클릭하고 **스티커 메모를** 선택하세요.
6. 콘텐츠가 생성되고 보드에 배치됩니다.

3. 제안을 입력하거나 사전 작성된 예제 중 하나를 클릭하세요.
4. 스티커 메모가 생성되고 보드에 추가됩니다. 결과에 만족한다면 **유지를** 클릭하세요.

## 이미지로 Miro Assist 사용하기

이미지는 스티커 메모나 명령 팔레트에서 생성할 수 있습니다.

컨텍스트 메뉴에서 명령 팔레트에서

1. 이미지를 생성하려는 스티커 를 클릭하세요.
2. 컨텍스트 메뉴에서 **Miro 인증** 버튼을 클릭하세요.
3. **이미지 생성을** 클릭하세요.
4. 이미지가 생성되고 보드에 배치됩니다. 결과에 만족한다면 **유지를** 클릭하세요.

## 코드 블록으로 Miro Assist 사용하기

컨텍스트 메뉴에서 명령 팔레트에서

1. 제작 툴바를 사용해 보드에 빈 **코드 블록을** 추가하세요.
2. 코드 블록에 요청을 입력하세요. 예:

   ```
   웹 페이지에 Google Analytics 코드를 추가하는 예제를 보여주세요.
   ```
3. 컨텍스트 메뉴에서 **Miro 인증** 버튼을 클릭하세요. 버튼이 회색으로 표시된 경우 코드 블록 외부를 클릭하고 다시 클릭해 버튼을 활성화하세요.
4. **자연 언어에서 코드 생성을** 클릭하세요.
5. 코드 예제가 생성되어 보드에 새 코드 블록에 배치됩니다. 코드가 코드 블록에서 실행되면 **행 번호** 버튼을 클릭하세요.
   ![miro_assist_context_menu_generate_code_greybg.gif](images/21857707538066_miro_assist_context_menu_generate_code_greybg.gif)
*Miro Assist로 컨텍스트 메뉴에서 코드 생성하기*

1. 생성된 코드 샘플을 클릭하세요.
2. **Miro Assist** 버튼을 클릭하고 **코드 설명을** 선택하세요. 코드가 어떤 작업을 수행하는지 간략한 설명이 *표시됩니다.miro_assist_code_explainer_greybg.gifMiro Assist로 코드 예제 설명하기*altalt![](images/21857707541266_miro_assist_code_explainer_greybg.gif)

1. **CMD + K(Mac)** 또는 **CTRL + K(Windows)를** 눌러 커맨드 팔레트를 열거나 **메인 메뉴** 햄버거를 클릭하고 **커맨드 팔레트를** 선택하세요.
2. **코드 생성을** 클릭하세요.
3. 제안을 입력하거나 사전 작성된 예제 중 하나를 클릭하세요. 예:

4. 코드 블록이 생성되고 보드에 추가됩니다. 결과에 만족한다면 **유지를** 클릭하세요.

## 카드로 Miro Assist 사용하기

컨텍스트 메뉴에서 명령 팔레트에서

**카드에서 사용자 스토리 만들기:**

1. 제작 툴바를 사용해 보드에 빈 **카드를** 추가하세요.
2. 카드에 요청을 입력하세요. 예를 들어, *사용자는 색상과 글꼴을 변경할 수 있어야 합니다.*
3. 컨텍스트 메뉴에서 **Miro 인증** 버튼을 클릭하세요.
4. **사용자 스토리로 카드 생성을** 클릭하세요.
5. 사용자 스토리 카드가 보드에 추가됩니다. 결과에 만족한다면 **Keep***.miro_assist_context_menu_cards_user_stories_greybg.gifMiro Assist로 카드에서 사용자 스토리 생성*altalt![](images/21857707543698_miro_assist_context_menu_cards_user_stories_greybg.gif)

**카드에 수용 기준을 추가하려면:**

1. 이전에 생성된 사용자 스토리 카드를 클릭하세요.
2. 컨텍스트 메뉴에서 **Miro 인증** 버튼을 클릭하세요.
3. **이 카드에 수용 기준 추가를** 클릭하세요.
4. 카드가 열리고 허용 기준이 번호가 매겨진 *목록으로 추가됩니다.miro_assist_context_menu_cards_acceptance_criteria_greybg.gifMiro Assist로 카드 허용 기준 만들기*altalt![](images/21857675666578_miro_assist_context_menu_cards_acceptance_criteria_greybg.gif)

2. **사용자 스토리로 카드 생성을** 클릭하세요.

사용자 스토리 카드가 보드에 추가된 후 컨텍스트 메뉴에서 Miro Assist를 사용하여 수용 기준을 추가할 수 있습니다.

## 시퀀스 다이어그램으로 Miro Assist 사용하기

> 시퀀스 다이어그램은 명령 팔레트에서만 생성할 수 있습니다.

1. **CMD + K(Mac)** 또는 **CTRL + K(Windows)**를 눌러 커맨드 팔레트를 열거나 **메인 메뉴** 햄버거를 클릭하고 **커맨드 팔레트**를 선택하세요.
2. **시퀀스 다이어그램 생성을** 클릭하세요.
3. 다이어그램에 대한 설명(예: *SSO* 인증)을 입력하거나 사전 작성된 예제 중 하나를 클릭하세요.
4. 시퀀스 다이어그램이 생성되고 보드에 추가됩니다.

## Miro Assist를 사용하여 다이어그램 생성

1. 제작 툴바를 사용해 다이어그램 앱을 여세요.
2. **AI로 생성** 버튼을 클릭하세요.
3. 나열된 옵션에서 **다이어그램 유형을** 선택하세요.
4. 프롬프트 입력 필드에 만들려는 다이어그램을 설명하세요.
5. 다이어그램 생성을 클릭해 **보드에** 추가하세요.

## 마인드맵으로 Miro Assist를 사용하기

컨텍스트 메뉴에서 명령 팔레트에서

1. 제작 툴바에서 **더 많은 앱** 버튼을 사용하거나 명령 팔레트에서 **마인드맵을** 보드에 추가하세요.
2. 마인드맵에서 일부 노드를 입력하세요. 예를 들어, 첫 번째 기본 노드에서 *Agile 사례를* 입력한 다음 Enter 키를 누르세요. 보조 노드에 대해 *스크럼을* 입력한 다음 Enter 키를 누르세요. 다음 보조 노드의 경우 *테스트 기반 개발을* 입력한 다음 중지하세요.
3. 보조 노드를 선택하고 컨텍스트 메뉴에서 **Miro 보조** 버튼을 클릭하세요.
4. **질문/아이디어/주제로** 확장에서 옵션을 선택하세요.
5. 보조 노드에 여러 개의 새 노드가 추가됩니다. 결과에 만족한다면 **유지를** 클릭하세요.

## 텍스트로 Miro Assist 사용하기

1. 작업할 텍스트를 선택합니다.
2. 컨텍스트 메뉴에서 **Miro Assist** 버튼을 클릭하세요.
3. 텍스트 변경 방법을 선택하세요.
   - **문법 및 맞춤법 수정**
   - **텍스트 줄이기**
   - **명확성을 위해 다시 작성**
   - **다음으로 번역:** 독일어, 스페인어, 일본어, 프랑스어, 포르투갈어
   - **톤 변경**
4. 결과에 만족한다면 **유지를** 클릭하세요.

## Miro Assist를 사용해 이미지에 대한 대체 텍스트 제안

1. 설명하려는 이미지를 선택하세요.
2. 컨텍스트 메뉴에서 **ALT** 버튼을 클릭하세요.
3. 이미지 유형이 지원되면 제안이 제공됩니다.
4. 제안을 검토한 다음 **삽입을** 클릭하세요.
5. 제안은 텍스트 필드에 추가되며 필요한 경우 편집할 수 있습니다.
