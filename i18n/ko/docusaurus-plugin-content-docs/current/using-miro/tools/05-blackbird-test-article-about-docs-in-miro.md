보드 콘텐츠를 더 구조화된 문서 형식으로 변환하세요. 캔버스의 오브젝트를 입력으로 사용하여 인사이트를 조립하고 분석하는 시작점으로 요약, 연구 보고서, 제품 개요를 생성할 수 있습니다.

> 해당 대상 모든 Miro 플랜
> 사용 가능 환경: 데스크톱, 모바일, 인터랙티브 디스플레이

## 문서 액세스 방법

새 문서를 추가하려면, 더하기 아이콘을 클릭하고 문서를 검색한 후, 캔버스의 아무 곳이나 클릭하여 추가하세요. 일부 보드 템플릿에는 문서도 포함되어 있습니다.

![](../../../../../../docs/using-miro/tools/images/25640385657234_33fb246e-3278-4496-8a69-5bd34721a01e.png)

*아이콘에서 새 문서 추가하기*

Miro AI로 문서를 추가할 수도 있습니다.

![](../../../../../../docs/using-miro/tools/images/25640369208978_678b2f2a-4e6b-449d-af82-0074d85d6d85.png)

*Miro AI로 문서 추가하기*

컨텍스트 메뉴에서 Doc을 추가하려면:

1. 보드에서 여러 오브젝트(예: 스티커 메모)를 선택하여 문서를 만드세요.
2. 컨텍스트 메뉴에서 **Miro AI** 아이콘을 선택해 **문서**를 선택하여 하위 메뉴를 여세요.
3. 템플릿을 선택하거나 **사용자 지정 프롬프트**를 사용하세요.
4. 문서가 생성되어 보드에 배치됩니다.

![doc-from-stickies.png](../../../../../../docs/using-miro/tools/images/25640369209362_doc-from-stickies.png)

*컨텍스트 메뉴를 통해 문서 추가하기*

Miro AI를 사용해 Doc 추가하기:

1. **AI로 만들기** 패널을 여세요.
2. **문서** 콘텐츠 유형을 선택하세요.
3. 사전 정의된 프롬프트를 사용하거나 직접 작성하세요.
4. 필요한 경우 보드에서 스티커 메모와 같은 오브젝트를 선택해 컨텍스트를 추가하세요.
5. **문서 생성**을 클릭하세요.
6. 생성된 문서는 캔버스의 빈 영역에 표시됩니다.

## Miro 문서 템플릿

새 Doc을 시작할 때 사용할 수 있는 템플릿은 현재 네 가지입니다. 프로덕트 브리프, 회고 요약, 미팅 메모 및 연구 종합 분석.

새 문서를 만들고 템플릿을 선택하면 템플릿이 문서에 추가됩니다.

![docs-new.png](../../../../../../docs/using-miro/tools/images/25640385658642_docs-new.png)

*회고 요약 템플릿 예*

## 문서에서의 컨텍스트 메뉴

문서 작업을 할 때, **세 점** (**...**) 아이콘을 클릭해 컨텍스트 메뉴를 통해 추가 기능을 찾을 수 있습니다. 컨텍스트 메뉴에는 다음이 포함됩니다:

- 댓글 추가
- 링크 복사
- 복사 및 동기화
- 링크
- 정보
- 잠금
- 맨 앞으로 가져오기
- 앞으로 가져오기
- 뒤로 보내기
- 맨 뒤로 보내기
- 레이어로 이동
- 복사
- 이미지로 복사
- 복제
- CSV(Excel)로 내보내기
- 프레임 만들기
- 템플릿으로 저장
- 삭제

![docs-context-menu.png](../../../../../../docs/using-miro/tools/images/25640369210642_docs-context-menu.png)

*문서의 컨텍스트 메뉴*

## 전체 화면 모드에서 문서 작업하기

문서에만 집중하고 보드의 다른 콘텐츠는 보지 않고 싶을 때, 문서를 전체 화면 모드로 열 수 있습니다. 작업 중인 문서의 상단에 있는 **전체 화면 아이콘**을 클릭하세요.

![docs-전체 화면-아이콘.png](../../../../../../docs/using-miro/tools/images/25640369213074_docs-full-screen-icon.png)

*문서 전체 화면 아이콘*

전체 화면 모드에서는 여전히 텍스트 서식을 위한 컨텍스트 메뉴가 포함되어 있습니다. 보드 배경을 제거하여 잠재적인 방해 요소를 없앱니다.

전체 화면 모드를 종료하려면 화면 상단의 **캔버스에서 아이디어 생성** 버튼을 클릭하세요.

![docs-focus-mode.png](../../../../../../docs/using-miro/tools/images/25640385661202_docs-focus-mode.png)

### 글자 수 제한

Miro 문서에는 최대 80,000자를 담을 수 있습니다. 더 많은 스페이스가 필요하면, 동일한 보드에 추가 문서를 만들고 콘텐츠를 나누어 사용할 수 있습니다. 이렇게 하면 모든 정보를 한곳에 정리하면서도 한도를 지킬 수 있습니다.

## 문서로 내용 복사

다음 콘텐츠를 보드에서 문서로 끌어다 놓을 수 있습니다:

- 스티커 메모
- 텍스트 상자
- 이미지
- iFrame
- 미리보기
- 표
- 타임라인
- 다이어그램

> 문서는 스티커 메모와 텍스트 상자를 글머리 기호 목록으로 변환합니다.

![데이터 위젯을 Miro 문서로 드래그 앤 드롭합니다.](../../../../../../docs/using-miro/tools/images/25640385663122_docs-tables-widget.gif)

*데이터 위젯을 Doc에 끌어다 놓기*

### 문서의 다이어그램

Diagram을 문서에 드래그하여 놓으면, Miro는 [동기화 사본](../working-on-the-board/11-synced-copies.md)을 생성합니다. 이것은 보드에서 원본 다이어그램에 대한 변경 사항이 문서 내 복사본에 반영되지만, 그 반대는 아니라는 것을 의미합니다. 복사 콘텐츠를 변경하려면 원본 다이어그램의 콘텐츠를 수정하세요.

이를 통해 문서가 최신 시각 정보로 항상 업데이트된 상태를 유지할 수 있습니다.

### 문서의 기타 콘텐츠 동작

집중 모드가 있는 위젯, 예를 들어 표와 같은 경우에도 위젯이 문서 내에 있을 때 몰입 모드에 액세스할 수 있습니다. Doc 내부의 치수는 맞도록 조정되고 스크롤됩니다.

문서 밖으로 콘텐츠를 드래그하여 보드에 다시 배치할 수도 있습니다.

문서 내에서 서식을 지정하려는 텍스트를 선택하면 툴바가 열립니다.

## 문서에서 키보드 단축키 사용

키보드 단축키를 사용하여 텍스트에 제목과 목록 유형을 적용할 수 있습니다. (이 단축키는 문단 유형 하위 메뉴에서 볼 수 있습니다.)

변환 **cmd + opt + \{number\} 사용하기**

- 0 -> 단락
- 1 -> 제목 1
- 제목 2
- 제목 3
- 글머리 기호 목록
- 번호가 매겨진 목록
- 6 -> 체크리스트

키보드 단축키를 사용해 블록 선택을 할 수도 있습니다: 블록 선택 모드에 들어가려면 Escape 키를 한 번 누른 다음,

- **shift + 상/하** -> 선택 확장
- **cmd + opt + 위/아래** -> 선택 항목을 위아래로 이동

문서에서 핫키로 액세스할 수 있는 다른 기능은 다음과 같습니다:

|  |  |
| --- | --- |
| **⌘** + **엔터** | 포커스 텍스트 선택 메뉴 |
| **⌘** + **Shift** + **X** | 취소선 적용 |
| **⌘** + **shift** + **U** | 링크 추가 |
| **⌘** + **E** | 인라인 코드 적용 |
| **⌘** + **,** | 체크리스트 항목 선택/선택 해제 |
| **⌘** + **/** | 블록 컨텍스트 메뉴 열기 |
| **⌘** + **D** | 선택한 블록 복제 |
| **⌘** + **I** | 블록에 대한 링크 복사 |

Miro 앱 내에서 화면 오른쪽 하단의 **도움말 및 자료** 아이콘을 클릭해 전체 키보드 단축키 목록에 액세스할 수 있습니다.

![docs-keyboard-shortcuts.png](../../../../../../docs/using-miro/tools/images/25640369222418_docs-keyboard-shortcuts.png)

*도움말 및 리소스 아이콘을 통한 키보드 단축키*

## 문서에서 Miro AI 사용

Miro AI를 사용해 문서를 편집하면 편집 프로세스를 빠르게 하고 더 간결하고 읽기 쉬운 문서를 만들 수 있습니다.

문서에서 강조 표시된 텍스트를 수정하려면 Miro AI를 사용할 수 있습니다.

![](../../../../../../docs/using-miro/tools/images/25640369225490_image.png)

*Miro AI로 강조된 텍스트를 수정하세요.*

Miro AI 프롬프트를 위해 인라인 텍스트를 사용하려면, Miro 문서에서 텍스트를 강조 표시하세요. 컨텍스트 메뉴의 가장 오른쪽에서 **Miro AI로 개선**을 선택하세요. 드롭다운 메뉴에서 **커스텀 프롬프트** 또는 사용 가능한 프롬프트 중 하나를 선택하세요.

## Miro 문서에서의 협업

Miro 문서는 다른 사용자와 실시간 협업을 가능하게 합니다. 캔버스의 다른 콘텐츠와 마찬가지로 커서 추적이 활성화되어 있어 다른 사용자가 Doc의 어느 부분에서 작업 중인지 확인할 수 있습니다.

댓글에서도 다른 사용자에게 @멘션이 가능하며, 앱과 이메일을 통해 알림을 받게 됩니다. 댓글 스레드와 댓글 리액션도 활성화되었습니다.

### Miro 문서의 사용자 칩

사용자 칩을 사용하면 Doc 내에서 사용자에 대한 세부 정보를 제공할 수 있습니다. 예를 들어, 주요 팀원이나 이해관계자를 위해 @user 칩을 추가하세요.

Miro 문서에서 사용자 칩을 추가하려면 '@'를 입력하세요. 결과를 필터링하려면 사용자 이름을 계속 입력하거나 열리는 드롭다운 메뉴에서 사용자를 선택하세요.

![Miro 문서 어디에서든 사용자 칩 추가.](../../../../../../docs/using-miro/tools/images/25640369225490_image.png)

*어디에서나 Miro 문서에 사용자 칩을 추가하세요.*

@사용자 칩 위에 마우스를 올리면 사용자에 대한 정보를 볼 수 있습니다.

![사용자 칩에는 사용자에 대한 정보가 포함되어 있습니다.](../../../../../../docs/using-miro/tools/images/25640369225490_image.png)

*사용자 칩에는 사용자에 대한 정보가 포함되어 있습니다.*

사용자 칩은 댓글 내의 멘션과 별도로 작동합니다. 예를 들어, 사용자 칩은 지정된 사용자에게 알림을 보내지 않습니다.

## 문서 복사, 공유, 내보내기

문서는 보드 간에 복사할 수 있지만, 향후 변경 사항에 대해 동기화되지는 않습니다. 다시 말해, 하나의 보드에서 문서에 대한 편집을 진행하더라도 해당 문서가 복사된 다른 보드에는 이러한 편집이 반영되지 않습니다.

문서는 링크를 통해 다른 사용자와 공유할 수 있습니다.

문서는 컨텍스트 메뉴의 **더 보기 아이콘** (![icon-main.svg](../../../../../../docs/using-miro/tools/images/25640369228946_icon-main.svg))에서 PDF 형식으로 내보낼 수 있습니다.
