스티커 메모는 빠르게 브레인스토밍하고, 메모를 작성하고, 정보를 시각적으로 정리하는 데 유용합니다. 칸반 보드 사용법에 익숙하거나 화이트보드에 스티커 메모를 붙이는 등 다른 기법에 익숙하다면 편하게 사용할 수 있습니다.

> **사용 가능 환경:** 브라우저 버전, [데스크톱 앱](../../getting-started/apps-for-devices/05-desktop-app.md), [태블릿 앱](../../getting-started/apps-for-devices/11-tablet-app.md), [모바일 앱](../../getting-started/apps-for-devices/08-mobile-app.md) (제한된 기능)

### 시작하기

툴바에서 **스티커 메모** (![icon-sticky.svg](../../../../../../docs/using-miro/tools/images/25953100365714_icon-sticky.svg)) 아이콘을 클릭하거나 [키보드에서 N을 눌러](../working-on-the-board/06-shortcuts-and-hotkeys.md) 툴을 시작하세요. 툴바에서 바로 스티커 메모를 끌어다 놓거나 보드를 클릭하고 마우스 왼쪽 버튼을 누른 채 커서를 드래그해 스티커 메모를 추가할 수도 있습니다.

스티커 메모의 컨텍스트 메뉴에서 도형 아이콘을 클릭해 스티커 메모의 모양을 변경할 수 있습니다.

![sticky-switch-type.png](../../../../../../docs/using-miro/tools/images/25953100366994_sticky-switch-type.png)
*정사각형 모양의 스티커 메모를 직사각형 모양으로 변경하기*

스티커 메모에는 텍스트 가독성과 일관성 있는 보드 디자인을 위해 엄선된 16가지 색상이 제공됩니다(색상 사용자 지정 불가).

![sticky-fill-color.png](../../../../../../docs/using-miro/tools/images/25953130442642_sticky-fill-color.png)
*스티커 메모 색상*

스티커 메모에 텍스트를 추가하려면 스티커 메모를 선택하고 입력을 시작합니다. 텍스트 크기에 따라 스티커 메모당 특수 기호는 약 3,000개까지 입력할 수 있습니다. 컨텍스트 메뉴에서 **자동** 글꼴 크기 기능을 사용할 수 있습니다.

여러 개의 스티커 메모를 수정하려면(크기 및 색상 변경, 태그 추가 등) 이 [가이드](../working-on-the-board/10-working-with-objects.md)의 안내를 따라 여러 개를 한번에 선택하세요.

:::tip
[치수를 활성화](../formats/diagramming/01-miro-for-mapping-diagramming.md)해 보드 전체에서 동일한 크기의 스티커 메모를 정밀하게 만드세요.
:::

스티커 메모를 삭제하려면 컨텍스트 메뉴에서 세 점 아이콘을 클릭하고 **삭제**를 선택하거나, 간단하게 [스티커 메모를 선택](../working-on-the-board/21-work-smarter-not-harder.md)한 후 **Backspace** 키를 누르세요.

:::tip
여러 개의 스티커 메모를 가로 또는 세로로 정렬하려면, [스티커 메모를 선택](../working-on-the-board/10-working-with-objects.md)하고 컨텍스트 메뉴에서 **정렬** 기능을 사용하세요.
:::
