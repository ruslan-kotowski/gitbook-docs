보드에서 작업할 때, 작업 중인 변경 사항을 빠르게 누군가에게 알릴 필요가 있을 수 있습니다. 댓글이나 텍스트 오브젝트에 @멘션하여 그렇게 할 수 있습니다.

![A team being mentioned in a comment on a Miro board.](images/27048204561810_Screenshot%20background%20template%20%204%20(1).jpg)*댓글에서 언급된 팀*

## 멘션 이해하기

멘션을 사용해 주의를 끌거나, 피드백을 요청하거나, 작업을 할당할 수 있습니다. Miro의 여러 부분에서 멘션이 작동하며, 주로 댓글과 텍스트 오브젝트에서 약간 다른 알림 목적을 수행합니다.

## @멘션을 사용해 공동 작업자에게 알리세요.

이 섹션은 공동 작업자와 Miro 보드에서 @멘션을 효과적으로 사용하는 방법을 설명합니다.

### 보드를 공유해 사용자가 멘션될 수 있도록 보장하세요.

보드가 [공유](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)된 경우 보드에서 다른 사람을 멘션할 수 있습니다. 보드는 다음과 같습니다:

- [명시적으로 공유됨](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) 언급이 필요한 사용자와 함께.
- [Shared with the project](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md).
- [전체 팀과 공유됨](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md).

### 텍스트 오브젝트에 멘션 추가

:::note
모바일 앱에서는 텍스트 객체 언급이 현재 사용할 수 없습니다.
:::

보드에서 다른 사용자 및 사용자 그룹을 [스티커 메모](../essential-tools/14-sticky-notes.md), [도형](../essential-tools/11-shapes.md) 및 [텍스트](../essential-tools/16-text.md)와 같은 텍스트 기반 객체에서 참조할 수 있습니다. 이렇게 하려면 간단히 @를 입력하고 텍스트 객체 내에서 사용자 이름을 입력하세요. 사용자는 텍스트 객체 언급에 대해 피드 알림을 받지 않습니다. 텍스트 오브젝트 언급을 사용하려면:

- 어떤 사람을 언급하는지 지정하세요.
- 작업이나 대화에서의 참여를 명확히 하세요.
- 언급된 사용자의 즉각적인 입력이나 주의가 필요하지 않은 메모를 작성하세요.

### 댓글에 멘션 추가하기

[댓글](asynchronous-tools/01-comments.md)에서 본인, 다른 사용자, 보드, 팀 또는 프로젝트와 같은 그룹 전체를 멘션할 수 있습니다. 이렇게 하려면 댓글을 열고 @ 뒤에 사용자 또는 그룹 이름을 입력하세요. 댓글 멘션은 일상 커뮤니케이션이나 사용자가 알림을 받기를 원할 때 이상적입니다. 댓글 멘션을 사용하여:

- 대화를 시작하거나 피드백을 요청하세요.
- 사용자에게 작업 할당하기
- 특정 사용자에게 댓글을 지정하세요.

### 특정 멘션 명령 실행

:::tip
사용자 이름을 검색할 때, 더 나은 결과를 위해 4자 이상 입력하세요.
:::

**자신을 멘션하세요**

자신을 언급하려면 @을 입력한 후 **이름**을 입력하세요. 다음을 위해 유용합니다:

- 작업을 할당하세요.
- 작업 또는 대화에서의 참여를 강조하세요.
- 알림에서 자신에게 댓글 알림을 설정하세요(댓글에만 적용됩니다).

**특정 사용자 언급**

특정 사용자에게 알림을 보내려면 @을 입력한 후 **사용자 이름**을 입력하세요. 예를 들어, 이를 사용할 수 있습니다:

- 편집자에게 더 많은 세부 정보를 제공하도록 요청하세요.
- 작업이 완료되면 팀 멤버에게 검토를 요청하세요.
- 현재 작업 중인 분야에서 팀의 전문가에게 연락하세요.

> 사용자의 이름이 댓글에서 언급하려고 할 때 목록에 없으면 이메일을 통해 보드에 초대하거나, 보드가 [팀 공유](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)인 경우 팀에 초대하거나, 보드가 [프로젝트](../sharing-boards/16-projects.md)에 속해 있는 경우 프로젝트에 초대해야 합니다.

**보드의 모든 사람 언급**

현재 보드에 액세스할 수 있는 모든 사용자에게 알리려면 **@board**을 입력하세요. 이를 다음에 사용해보세요:

- 보드의 모든 참여자에게 의견을 요청하세요.
- 회의 후 보드에서 피드백 요청하기.
- 모든 보드 사용자에게 관련된 중요한 업데이트를 소통하세요.

**@board** 멘션은 보드가 프로젝트/팀 공유를 통해 그들에게 직접 공유되지 않는 한, 해당 프로젝트 멤버나 팀 멤버를 포함하지 않습니다.

**프로젝트 멤버 언급**

특정 [**프로젝트**](../sharing-boards/16-projects.md)의 모든 멤버에게 알리려면, **@프로젝트**를 입력하세요(보드가 프로젝트의 일부인 경우). 이는 다음에 도움이 될 수 있습니다:

- 프로젝트 멤버에게 프로젝트 상태 업데이트를 요청하세요.
- 기한 변경에 대해 프로젝트 팀에게 업데이트하기
- 프로젝트의 특정 부분을 담당할 새로운 팀 멤버를 소개합니다.

:::tip
**@프로젝트**와 직접 언급을 결합하여 여러 직종의 팀으로부터 인사이트를 얻을 수 있습니다.
:::

**팀 멤버 언급하기**

모든 팀원에게 알리려면 **@team**을 입력하세요. 이것을 사용하여:

- 팀원 모두를 초대해 일반 전략에 댓글을 달도록 하세요.
- 조직 구조 또는 프로세스 프로젝트 플랜에 대한 피드백을 수집합니다.
- 모든 사람에게 팀 차원의 아이디어 도출 세션에 참여를 요청하세요.

### 업데이트를 위해 댓글 스레드를 팔로우하세요

댓글의 답변에 대한 업데이트를 받으려면 해당 스레드를 팔로우할 수 있습니다. 다음 단계에 따라 이 작업을 수행할 수 있습니다:

1. 팔로우하려는 댓글을 찾으세요.
2. 댓글의 오른쪽 상단 모서리에 있는 **스레드 팔로우** 아이콘을 클릭하세요.

![Miro의 댓글에서 '팔로우 스레드' 아이콘.](../../../../../../docs/using-miro/facilitation-tools/images/21017416358290_start%20following%20a%20thread.jpg)*스레드 팔로우*

> 사용자 이름에 대한 언급이나 댓글에서 마우스를 가져가면 해당 사용자의 프로필 카드를 볼 수 있습니다.

## 멘션에 대한 추가 정보

이 섹션에서는 특정 멘션 기능 및 제한 사항에 대한 자세한 내용을 제공합니다.

### 기능 및 제한 사항

:::warning
보안상의 이유로, [게스트](../sharing-boards/07-collaboration-with-guests.md)는 보드에 직접 초대된 사용자만 찾고 @멘션할 수 있습니다. [방문자](../sharing-boards/08-collaboration-with-visitors.md)는 다른 사용자를 언급할 수 없습니다.
:::

### 제안된 멘션 기능

> **플랜:** Business, Enterprise, Education

댓글란에 **@**를 입력하면 Miro에서 제안된 멘션 목록을 표시할 수 있습니다. 이 목록에는 이전에 언급한 사용자와 현재 보드에 액세스할 수 있는 사용자가 포함되어 있습니다.

Enterprise 플랜에서 [팀 개인정보 보호](../../enterprise-administration/managing-enterprise-teams-and-content/11-manage-team-privacy-and-discovery-on-enterprise-plan.md)가 활성화된 경우, 같은 팀 내 사용자에게만 추천이 이루어집니다.
