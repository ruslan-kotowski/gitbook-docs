스타일을 이용하면 누구나 시각적으로 매력적인 프레젠테이션과 보드를 전문적인 느낌으로 만들 수 있습니다. 여러 변형이 포함된 14개의 색상 팔레트 중에서 선택하세요.

- 전체 보드를 손쉽게 스타일링
- 청중에게 깔끔한 작업물 제공
- 서식 작성 시간을 단축

> **사용 가능 대상:** Free, Starter, Business, Enterprise 및 Education 플랜

## 스타일 사용법

### 프레임에 스타일을 적용하는 방법

1. 보드에서 프레임 또는 여러 프레임을 선택하세요.
2. 컨텍스트 메뉴가 열립니다.
3. **스타일** 아이콘을 클릭하세요.
4. 스타일 패널이 열립니다.
5. 기본 스타일 중 하나를 선택하거나, [맞춤형 브랜드 스타일](../../administration/get-started-as-a-miro-admin/04-brand-center.md)**을 선택하세요.**
6. 선택한 스타일이 프레임과 프레임 안의 모든 객체에 적용됩니다.

![Applying-styles-to-frames.gif](../../../../../../docs/using-miro/facilitation-tools/images/21016020643090_Applying-styles-to-frames.gif)
*선택한 프레임에 스타일 적용하기*

### 다양한 스타일 변형 적용하기

여러 스타일 변형을 탐색하세요. **스타일** 패널을 다시 열고 **최근** 옆에 있는 스타일 위에 커서를 올려 **섞기**를 클릭하세요. 스타일 색상이 새로운 순서로 나타납니다.

![Trying-different-style-options-with-shuffle.gif](../../../../../../docs/using-miro/facilitation-tools/images/21016020640914_Trying-different-style-options-with-shuffle.gif)
*다양한 스타일 변형 적용*

:::note
우리의 콘텐츠가 모든 사용자에게 접근 가능하고 포용적일 수 있도록 일부 브랜드 색상이 조정될 수 있습니다. 이러한 변경은 접근성 표준을 준수하며, 모든 사용자에게 최적의 경험을 제공하기 위해 사용성을 우선시합니다.
:::

## 스타일 재설정

원하지 않는 변경 사항을 쉽게 실행 취소하고 보드의 원래 스타일로 복원하세요. 간단히 **스타일** 패널을 열고 **적용된 스타일** 옆에 있는 **스타일 제거**를 클릭하세요.
