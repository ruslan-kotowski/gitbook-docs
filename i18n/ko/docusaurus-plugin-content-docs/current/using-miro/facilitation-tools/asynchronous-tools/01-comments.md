댓글로 팀 협업을 강화하세요. 보드에 직접 생각과 아이디어를 공유하고, 의미 있는 토론을 진행하고, 모든 프로젝트를 보다 상호 작용적이고 생산적으로 만들어보세요.

- 댓글로 보드에서 바로 **대화를** 시작하세요.
- **스레드 토론에 참여하고** 쉽게 팀워크를 개선하세요.
- **@멘션을 사용해** 팀원에게 알리세요.
  - 댓글에 언급된 경우 @ 기호가 표시됩니다.
  - 새 멘션은 **파란색입니다**.
  - 읽기 멘션은 **흰색입니다**.
- **빠르게 따라잡기**:
  - 새 **댓글은 파란색입니다**.
  - 읽기 댓글은 **흰색입니다**.
  - 해결된 댓글에는 **확인** 표시가 있습니다.

## 댓글 미리 보기

진행 중인 대화나 피드백을 보드에서 바로 빠르게 살펴보세요. 간단히 댓글 위로 마우스를 가져가면 미리보기를 볼 수 있습니다.

![Preview-comments.gif](https://help.miro.com/hc/article_attachments/21857631715858)
*댓글 미리 보기*

## 댓글 추가

1. 왼쪽의 [제작 툴바에서](../../../getting-started/start-here/your-first-board/05-toolbars.md) **댓글** 아이콘을 클릭하거나 **C** [단축키를](../../working-on-the-board/06-shortcuts-and-hotkeys.md) 누르세요.
2. 댓글을 추가하려면 보드 또는 오브젝트의 아무 곳이나 클릭하세요. 클릭 후 입력을 시작하여 댓글 초안을 작성하세요.
3. [@멘션을](../01-@mentioning-people-on-the-board.md) 사용해 다른 사람에게 태그를 지정하세요. [제안된 멘션에는](../01-@mentioning-people-on-the-board.md) @를 입력하기만 하면 됩니다. 직접 태그를 지정해 [피드](../../managing-boards/10-feed.md) 알림에서 작업을 할당하고 알림을 설정할 수도 있습니다.
4. 댓글을 게시하려면 파란색 **게시** 버튼을 클릭하거나 **Enter** 키를 누르세요.

> **✏️** 오브젝트로 직접 작업하시나요? 보드의 오브젝트를 클릭해 컨텍스트 메뉴를 열고 댓글을 추가하세요.

> **✏️** 댓글에서 새 줄을 **시작하려면 Shift + Enter를** 사용하세요. 댓글에서는 텍스트 서식이 지원되지 않습니다.

![Comment-icon.png](https://help.miro.com/hc/article_attachments/21857631725458)*제작 툴바에서 댓글 아이콘을 클릭하세요*

### 댓글 초안 작성

**게시** 버튼을 클릭하거나 **Enter** 키를 누르지 않고 댓글에서 벗어나면 댓글이 초안으로 저장됩니다.

초안 댓글에 액세스하려면 보드를 클릭해 댓글 스레드를 여세요. 초안 텍스트가 표시됩니다. 초안이 기존 댓글 스레드에 대한 응답인 경우 댓글을 클릭해 스레드를 열고 초안을 찾기만 하면 됩니다.

![Draft-saved-notification.png](https://help.miro.com/hc/article_attachments/21857616528530)
*드래프트 저장된 알림*

### 댓글 편집

댓글을 편집하려면 텍스트 본문을 클릭하고 필요에 따라 업데이트한 다음 **저장을** 클릭하세요.

![Editing-a-comment.png](https://help.miro.com/hc/article_attachments/21857616535698)
*댓글 편집하기*

### 댓글 삭제

보드에서 댓글을 삭제하려면 댓글을 열고 점 3개 아이콘(**...**)을 클릭하고 **삭제를** 선택하세요.

:::warning
보드에서 여러 개의 댓글 또는 모든 댓글을 한 번에 삭제하는 것은 불가능합니다. 또한 팀에서 사용자를 제거해도 팀 보드에서 댓글이 자동으로 제거되지는 않습니다.
:::

![Deleting-a-comment.png](https://help.miro.com/hc/article_attachments/21857631741202)
*댓글 삭제하기*

### 댓글 색상 선택

색상으로 댓글을 사용자 지정해 팀의 중요도를 나타내거나 메시지를 분류하세요. 예를 들어, 아이디어에 파란색을 사용하고 토론에 초록색을 사용하세요. 댓글 색상을 변경하려면 댓글을 열고 상단의 옵션에서 색상을 선택하세요.

![Changing-the-color-of-a-comment.png](https://help.miro.com/hc/article_attachments/21857616542738)
*댓글 색상 변경하기*

## 댓글 패널

댓글 패널은 모든 멘션과 댓글을 하나로 불러옵니다. 댓글 패널을 열려면 오른쪽 [상단의 커뮤니케이션](../../../getting-started/start-here/your-first-board/05-toolbars.md) 툴바에서 **댓글** 아이콘을 클릭하세요. 패널에서 댓글을 선택하면 보드의 해당 위치로 즉시 이동합니다.

![Comments-panel.png](https://help.miro.com/hc/article_attachments/21857616546066)

## 오브젝트에 댓글 연결하기

오브젝트에 직접 댓글을 달아 보드 위에서 함께 이동하도록 하세요. 이렇게 하려면 원하는 오브젝트 위에 댓글을 배치하기만 하면 됩니다. 다른 오브젝트로 댓글을 이동해야 하는 경우 댓글을 클릭하고 새 위치로 드래그하세요.

![Comments-attached-to-objects.png](https://help.miro.com/hc/article_attachments/21857616550290)*도형 및 스티커 메모에 첨부된 댓글*

:::warning
오브젝트에 첨부된 댓글은 오브젝트와 함께 복사, 잘라내기 또는 붙여넣을 수 없습니다. 또한 주석은 내보낼 수 없습니다. 그러나 [보드를](../../managing-boards/03-how-to-duplicate-a-board.md) 복제하면 댓글이 함께 복사됩니다.
:::

## 알림 관리

대화에서 업데이트를 놓치지 마세요. 모든 스레드를 팔로우하거나 관심 있는 특정 스레드만 팔로우하세요. 댓글, 답글 또는 [@멘션된](../01-@mentioning-people-on-the-board.md) 경우 알림을 받게 됩니다. 업데이트 수신을 중지하려면 스레드 팔로우 기능을 끄기만 하면 됩니다.

:::tip
프로필 설정에서 [알림 환경설정을](../../managing-your-profile/02-miro-notifications.md) 조정할 수 있습니다.
:::

### 모든 댓글 스레드 팔로우

보드의 모든 스레드를 팔로우하려면 왼쪽 상단 모서리의 보드 헤더로 이동한 다음 **메인 메뉴** **아이콘을** 클릭하고 **환경 설정** 모든 **스레드** 팔로우를 켜세요.

![Follow-all-threads.png](https://help.miro.com/hc/article_attachments/21857616557842)
*모든 스레드를 팔로우하는 옵션*

### 특정 댓글 스레드 팔로우

특정 스레드를 팔로우하려면 댓글을 열고 오른쪽 상단 모서리의 **스레드** 팔로우 아이콘을 클릭하세요.

![Turning-on-follow-thread.png](https://help.miro.com/hc/article_attachments/21857616566162)
*특정 스레드를 따르는 옵션*

### 스레드 고정

토론과 브레인스토밍을 위해 보드에 댓글 스레드를 열어 두세요. 보드에 스레드를 연 상태로 유지하려면 댓글을 열고 점 3개 아이콘(**...**)을 클릭하고 **핀을** 선택하세요.

여러 개의 댓글을 고정해 보드에 여러 스레드를 동시에 열어 놓을 수 있습니다.

![Pinning-a-comment-to-keep-it-open.png](https://help.miro.com/hc/article_attachments/21857616570130)
*댓글 고정하기*

## 댓글 관리

댓글을 읽거나 읽지 않은 상태로 표시해 주의가 필요한 중요한 메시지와 작업에 집중하세요.

### 댓글을 읽지 않은 상태로 표시

댓글을 읽지 않은 상태로 표시하려면 댓글을 열고 점 3개 아이콘(**...**)을 클릭하고 **읽지 않은 상태로 표시를** 선택하세요.

![Marking-a-comment-as-unread.png](https://help.miro.com/hc/article_attachments/21857631784978)
*댓글 스레드를 읽지 않은 상태로 표시하기*

### 모든 댓글을 읽은 상태로 표시

모든 댓글을 읽음으로 표시하려면 댓글 패널을 열고 점 3개 아이콘(**...**)을 클릭하고 **모두 읽음으로 표시를** 선택하세요.

![Marking-all-comments-as-read.png](https://help.miro.com/hc/article_attachments/21857631788050)
*모든 댓글을 읽은 상태로 표시*

### 댓글 해결

가장 필요한 곳에 집중하세요. 모든 댓글 스레드를 해결된 항목으로 표시해 보드에서 숨길 수 있습니다. 댓글을 열고 왼쪽 상단 모서리에서 해결을 **켜세요.**

![Resolving-a-comment-thread.png](https://help.miro.com/hc/article_attachments/21857631794962)
*댓글 스레드 해결하기*

### 해결된 댓글 표시

해결된 댓글을 보려면 댓글 패널을 열고 **표시** 드롭다운을 클릭하고 해결된 댓글을 **표시하세요**.

![Show-resolved-comments.png](https://help.miro.com/hc/article_attachments/21857631800210)
*해결된 댓글 표시*

### 이모티콘으로 댓글에 반응하기

댓글 옆의 이모티콘 아이콘을 클릭해 반응을 추가하세요.

![Reacting-to-a-comment-with-emojis.png](https://help.miro.com/hc/article_attachments/21857616594834)
*댓글 에 리액션 추가하기*

### 보드에 댓글 숨기기

보드의 모든 댓글을 숨기려면 댓글 패널을 열고 점 3개 아이콘(**...**)을 클릭하고 **보드에 댓글 표시를** 끄세요.

![Hiding-comments-on-the-board.png](https://help.miro.com/hc/article_attachments/21857616602002)
*보드에 댓글 숨기기*

## 메모에 댓글 추가

추가 컨텍스트 및 피드백을 위해 [메모에](../../essential-tools/17-visual-notes.md) 댓글을 추가할 수 있습니다. 텍스트 옆의 **댓글** 아이콘을 클릭하기만 하면 됩니다.

![Adding-comments-in-notes.png](https://help.miro.com/hc/article_attachments/21857616612626)
*메모에 댓글 추가하기*

## 모바일 앱 댓글

댓글 및 스레드를 탐색하면 데스크톱 버전과 비슷한 원활한 경험을 제공하는 모바일 앱에 대한 토론에 쉽게 참여하세요.

**댓글 보기 및 답글 보내기:**

- **스레드 열기** : 댓글을 탭해 전체 스레드를 확인하세요.
- **답글 남기기**: 생각을 공유하고 대화에 참여하세요.
- **스레드 해결**: 토론을 완료된 것으로 표시하세요.
- **알림 관리**: 종 아이콘을 눌러 스레드 팔로우를 시작하거나 중지하세요.
- **표시 사용자 지정**: 더 쉽게 참조하고 정리하기 위해 댓글 색상을 변경하세요.

**새 댓글 추가하기:**

모바일에 댓글을 추가하는 프로세스는 데스크톱 환경과 약간 다릅니다.

1. 화면 오른쪽 하단 모서리에 있는 더하기 아이콘(**+**)을 탭하세요.
2. 댓글을 선택해 새로운 **생각이나** 아이디어를 공유하세요.
