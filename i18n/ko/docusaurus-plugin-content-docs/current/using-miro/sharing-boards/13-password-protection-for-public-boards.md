유료 플랜의 비밀번호 보호 기능에 대해 읽어보고 공개 보드에 비밀번호를 설정하는 방법을 알아보세요.

> **콘텐츠** [관리자](../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md) 권한이 있는 Enterprise 플랜의 보드 소유자, [보드 공동 소유자](06-co-owners-of-boards-and-spaces.md), 회사 관리자
> **해당 대상:** Starter, Business, Enterprise 및 Education 플랜
> **사용 가능 환경:** 브라우저, [데스크톱 앱](../../getting-started/apps-for-devices/05-desktop-app.md), [태블릿 앱](../../getting-started/apps-for-devices/11-tablet-app.md)

## 공개 보드용 비밀번호

공개 링크를 사용해 방문자를 보드에 초대하는 것은 팀 또는 회사 외부 사용자와 일회성 또는 단기 협업에 유용한 옵션이며, Miro가 아닌 사용자라도 공개 보드에 액세스할 수 있습니다.

공개 Miro 보드를 공유할 때 비밀번호를 설정해 보안 계층을 추가할 수 있습니다.

### 플랜을 기반으로 한 비밀번호 보호

비밀번호 보호 및 권한 수준은 플랜 유형에 따라 달라집니다.

|  |  |  |  |
| --- | --- | --- | --- |
|  | **Free** | **Starter, Business** | **Enterprise** |
| **비밀번호 활성화, 변경 또는 제거** | ✘ | ✔  보드 소유자, 공동 소유자 | ✔  보드 소유자, 공동 소유자, 회사 관리자* |
| **필수 비밀번호 활성화** | ✘ | ✘ | ✔  [필수 비밀번호 설정](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md) |

*[콘텐츠 관리자](../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md) 권한이 활성화되어 있어야 합니다.

:::note
Enterprise [플랜의 공유 정책에](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md) 대해 자세히 알아보세요.
:::

## 보드에 비밀번호 보호 추가하기

1. **링크가 있는 모든 사용자에** 대한 액세스를 활성화하면 **비밀번호** 설정 버튼을 클릭하세요.

2. 8자 이상의 영숫자 비밀번호를 입력한 다음 **설정을** 클릭하세요.

3. 비밀번호가 클립보드에 복사됩니다.

*![3-1-720p-10fps-s4-r20.gif](../../../../../../docs/using-miro/sharing-boards/images/20257248240274_3-1-720p-10fps-s4-r20.gif)
링크에서 공유된 보드에 비밀번호 설정하기*

:::note
Enterprise 플랜 관리자는 [구독 내의 모든 보드에 필수 비밀번호를 설정할](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md) 수 있습니다.
:::

## 비밀번호 보호가 사용자에게 작동하는 방법

보드 링크를 받고 연 후 방문자에게 비밀번호를 입력하라는 메시지가 표시됩니다.

![3-2-720p-10fps-s4-r20.gif](../../../../../../docs/using-miro/sharing-boards/images/20257248243730_3-2-720p-10fps-s4-r20.gif)

비밀번호를 입력하면 보드에 대한 전체 액세스 권한이 부여됩니다. 72시간마다 비밀번호를 다시 입력하기만 하면 됩니다.

사용자가 더 자주 로그인해야 하는 경우 회사 Miro 관리자가 보안을 강화하기 위해 [유휴 세션 시간](../tools/troubleshooting/19-why-does-miro-keep-logging-me-out.md) 초과를 활성화했을 수 있습니다.

보드가 비밀로 보호된 경우 사용자에게 표시되는 경우 별표 표시 및 최근 목록에만 표시된다는 점에 유의하세요.

사용자가 세션이 만료되면 보드를 사용할 수 없게 되고 별표 표시 및 최근 목록에서 제거됩니다. 사용자가 직접 링크를 통해 보드를 열고 보드 비밀번호를 다시 입력하면 보드가 관련 목록에 다시 표시됩니다.

## 공개 보드의 비밀번호 변경하기

비밀번호를 변경하면 현재 보드에 있는 모든 보드 방문자가 액세스한 권한이 즉시 취소됩니다.

:::note
비밀번호가 보호된 보드에 대한 링크를 공유할 수 있는 사용자는 보드 소유자나 공동 소유자가 아닌 경우 비밀번호를 변경할 수 없습니다.
:::

**공개 보드의 비밀번호 변경하기**

1. 공유 설정에서 **비밀번호 편집을** 클릭한 다음 **비밀번호 변경을** 클릭하세요.
![3-1.png](../../../../../../docs/using-miro/sharing-boards/images/20235526720658_3-1.png)
*공유 설정에서 보드 비밀번호 편집하기*
2. 확인 창이 나타나고 보드에 계속 액세스하려면 기존 공동 작업자와 새 비밀번호를 공유해야 한다는 메시지가 표시됩니다. **비밀번호 변경을** 클릭하세요.

![change_password.png](../../../../../../docs/using-miro/sharing-boards/images/20022115780754_change_password.png)
*비밀번호 확인 창 변경*
3. 8자 이상의 영숫자 비밀번호를 입력하세요.

4. **비밀번호 설정을** 클릭하세요.

:::note
비밀번호를 변경하면 현재 보드에 있는 모든 보드 방문자가 있어도 액세스 권한이 즉시 취소됩니다.
:::

## 공개 링크 비활성화하기

언제든지 [공개 보드 공유를 중지할](03-sharing-boards-and-inviting-collaborators.md) 수 있지만 보드의 비밀번호가 자동으로 초기화되지는 않습니다. 방문자는 공유 설정에서 비밀번호를 변경하지 않는 한 동일한 비밀번호로 보드에 액세스할 수 있습니다.

## 보드의 비밀번호를 잊었습니다

비밀번호를 잊으면 공유 설정에서 보드 비밀번호를 쉽게 변경할 수 있습니다.

:::note
모바일의 비밀번호 보호 기능은 백로그에 있습니다.
:::
