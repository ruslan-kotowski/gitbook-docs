프로젝트는 팀에 있는 보드의 모음입니다. 프로젝트를 사용하면 보드를 더 쉽게 정리하고, 찾고, 공유할 수 있습니다.

> 🚀  [Miroverse](https://miro.com/miroverse/submission/?backToUrl=/)에 프로젝트 템플릿을 게시하고 6천만 명 이상의 사용자가 체계적인 팀워크를 발휘할 수 있도록 영감을 주세요.

> **해당 플랜:** Starter, Education, Business, Enterprise 플랜

## 프로젝트 위치

모든 프로젝트는 대시보드의 왼쪽 탐색 창에 알파벳 순으로 나열됩니다. 프로젝트 이름을 클릭해 프로젝트 설정을 열고 세부 정보와 참여자를 볼 수 있습니다.

### 프로젝트 설정

1. 왼쪽 사이드바에서 **프로젝트**로 이동합니다.
2. 프로젝트 이름을 클릭합니다.
3. 프로젝트 대시보드 상단에서 프로젝트 이름을 다시 클릭합니다.
4. 프로젝트 설정이 열립니다.

![Miro_projects_greybg.gif](https://help.miro.com/hc/article_attachments/21830782617234)
*Miro에서 프로젝트를 열어 세부 정보 보기*

## 중요한 프로젝트 즐겨찾기

진행 중이거나 자주 사용하는 프로젝트를 즐겨찾기하면 쉽게 액세스할 수 있습니다. 처음으로 프로젝트의 별 아이콘을 클릭하면 **즐겨찾기한 프로젝트** 섹션이 새롭게 왼쪽 사이드바에 나타납니다. **즐겨찾기한 프로젝트**를 확장하거나 축소해 대시보드를 관리할 수 있습니다.

프로젝트를 즐겨찾기하려면 프로젝트 이름 옆의 **별** 아이콘을 클릭합니다.

![starred_projects_greybg.gif](https://help.miro.com/hc/article_attachments/21830736293522)
*프로젝트 즐겨찾기 설정하기*

## 프로젝트 만들기

1. 왼쪽 사이드바에서 **프로젝트**로 이동합니다.
2. **+ 추가** 버튼을 클릭합니다.
3. 프로젝트 대화 상자가 열립니다.
4. **프로젝트 이름**을 입력합니다.
5. **프로젝트** **만들기**를 클릭합니다.
6. 그 다음 보드 추가 및 멤버 추가를 할 수 있습니다.

![create_a_project_greybg.gif](https://help.miro.com/hc/article_attachments/21830736299794)
*새 프로젝트 만들기*

## 프로젝트에 보드 추가하기

1. 프로젝트 설정을 엽니다.
2. **보드 추가**를 클릭합니다.
3. 스크롤하거나 검색해 프로젝트에 추가할 보드를 찾고 선택합니다.
4. **보드 이동**을 클릭합니다.

![Add boards to a project.png](https://help.miro.com/hc/article_attachments/21830782639634)
*프로젝트 설정의 프로젝트에 보드 추가하기 옵션*

## 프로젝트 공유하기

### 팀 멤버와 프로젝트 공유하기

> **실행 가능한 사용자:** 프로젝트 소유자, 프로젝트 공동 소유자, 편집자

팀 멤버와 프로젝트를 공유하려면 프로젝트에 멤버를 추가하면 됩니다. 협업 수준에 따라 액세스 권한을 [보기 가능, 댓글 작성 가능, 편집 가능](../../getting-started/start-here/05-roles-in-miro.md)으로 설정할 수 있습니다. 선택한 액세스는 프로젝트의 모든 보드에 적용됩니다.

### 팀 전체와 프로젝트 공유하기

> **실행 가능한 사용자:** 프로젝트 소유자, 프로젝트 공동 소유자

1. 프로젝트 설정을 엽니다.
2. **팀 구성원 누구나 이 프로젝트를 볼 수 있습니다**를 켭니다.

:::note
팀 관리자는 새 프로젝트에 대한 [기본 공유 설정](11-default-sharing-settings.md)을 구성할 수 있습니다.
:::

![share project with the team.png](https://help.miro.com/hc/article_attachments/21830782643858)
*팀 전체와 프로젝트 공유하기*

### 프로젝트 내에서 보드 공유하기

보드 **공유** 대화 상자를 통해 프로젝트 멤버의 액세스 레벨을 변경할 수 있습니다. 예를 들어, 댓글 액세스 권한이 있는 프로젝트 멤버는 프로젝트의 특정 보드에 편집자로 초대될 수 있습니다. 프로젝트를 공유하든 프로젝트 내의 보드를 공유하든 상관없이 **항상 가장 높은 액세스 레벨이 적용**됩니다.

팀 또는 프로젝트 외부의 사용자를 보드 [방문자](08-collaboration-with-visitors.md) 또는 [게스트](07-collaboration-with-guests.md)로 초대해 보드를 공유할 수 있습니다.

### 비공개 프로젝트

Miro에서 프로젝트를 비공개로 설정하려면 멤버를 추가하지 않고 팀 액세스가 해제되어 있는지 확인한 다음, 팀 및 회사 공유 설정을 프로젝트 내의 모든 보드에 대해 **액세스 불가**로 조정합니다.

프로젝트를 공유하든 프로젝트 내의 보드를 공유하든 상관없이 **항상 가장 높은 액세스 레벨이 적용**됩니다. 예를 들면,

- 보드가 비공개 프로젝트에 있지만 팀 전체와 공유되면 모든 팀 멤버가 액세스할 수 있습니다.
- 보드가 명시적으로는 어떤 사용자와도 공유되지 않지만 팀과 공유하는 프로젝트 내에 저장되어 있으면 모든 팀 멤버가 액세스할 수 있습니다.

[공개 보드 vs 비공개 보드](12-public-boards-vs.-private-boards.md)에서 자세히 알아보세요.

## 프로젝트 멤버 추가 및 관리

:::note
팀 멤버만 프로젝트 멤버로 초대할 수 있습니다.
:::

프로젝트 멤버는 다음을 수행할 수 있습니다.

- 모든 기존 보드, 추가 또는 생성된 새 보드를 포함한 프로젝트 내의 모든 보드에 액세스
- 프로젝트 내에서 새 보드 만들기
- 프로젝트에 기존 보드 추가
- 프로젝트 내의 모든 보드에 대한 모든 변경 사항 알림 받기

### 프로젝트에 멤버 추가하기

> **실행 가능한 사용자:** 프로젝트 소유자, 프로젝트 공동 소유자, 편집자

1. 프로젝트 설정을 엽니다.
2. **멤버 추가**를 클릭합니다.
3. 스크롤하거나 검색해 추가할 팀 멤버를 찾고 선택합니다.
4. 멤버가 프로젝트에 추가되었을 때 **멤버에게 알림**을 보낼 수 있습니다.
5. **추가**를 클릭합니다.

![Adding members to a project.png](https://help.miro.com/hc/article_attachments/21830736308114)
*프로젝트에 멤버 추가하기*

### 사용자 액세스 레벨 변경하기

1. 프로젝트 설정을 엽니다.
2. 사용자 이름 옆의 액세스 레벨 드롭다운을 엽니다.
3. 액세스 레벨을 선택합니다(**공동 소유자임**, **편집 가능**, **댓글 작성 가능** 또는 **보기 가능**).

![Change a project member to project owner.png](https://help.miro.com/hc/article_attachments/21830736311314)
*프로젝트에 대한 사용자의 액세스 레벨 변경하기*

### 프로젝트 멤버 제거하기

:::warning
프로젝트 멤버를 제거해도 [이메일 초대](03-sharing-boards-and-inviting-collaborators.md)나 [팀, 회사, 또는 공개 링크 액세스](03-sharing-boards-and-inviting-collaborators.md)를 통해 프로젝트에 계속 액세스할 수 있습니다.
:::

1. 프로젝트 설정을 엽니다.
2. 사용자 이름 옆의 액세스 레벨 드롭다운을 엽니다.
3. **제거**를 선택합니다.

![Remove a project member.png](https://help.miro.com/hc/article_attachments/21830736316050)
*프로젝트에서 사용자 제거하기*

### 프로젝트 소유자 변경하기

> **실행 가능한 사용자:** 프로젝트 소유자, 프로젝트 공동 소유자

:::note
프로젝트 소유권을 다른 사용자에게 이전해도 프로젝트 내 개별 보드의 소유자는 변경되지 않습니다.
:::

1. 프로젝트 설정을 엽니다.
2. 사용자 이름 옆의 액세스 레벨 드롭다운을 엽니다.
3. **소유자임**을 선택합니다.

![Change a project member to project owner.png](https://help.miro.com/hc/article_attachments/21830736311314)
*프로젝트 소유자 액세스 권한 부여하기*

## 프로젝트로 보드 이동하기

> **실행 가능한 사용자:** 프로젝트 소유자, 프로젝트 공동 소유자, 편집자

:::note
보드를 프로젝트로 이동해도 보드 링크는 변경되지 않습니다.
:::

**보드 정보 카드에서 다음 작업을 수행합니다.**

1. 왼쪽 상단의 보드 헤더에서 보드 이름을 클릭합니다.
2. 보드 정보 카드가 열립니다.
3. **위치** 옆의 **프로젝트 이름**(또는 **프로젝트 없음**)을 클릭합니다.
4. 드롭다운에서 보드가 이동할 프로젝트를 선택합니다.
5. **이동**을 클릭합니다.

*![adding_a_board_to_a_project_greybg.gif](https://help.miro.com/hc/article_attachments/21830736318866)**보드 정보 카드에서 프로젝트로 보드 이동하기*

**대시보드에서 다음 작업을 수행합니다.**

1. 이동하려는 보드 위로 마우스를 가져갑니다.
2. 세 점 아이콘(**...**)을 클릭해 보드 메뉴를 엽니다.
3. **프로젝트로 이동**을 선택합니다.
4. 드롭다운에서 보드가 이동할 프로젝트를 선택합니다.
5. **이동**을 클릭합니다.

![move to project from dashboard.png](https://help.miro.com/hc/article_attachments/21830782659602)
*보드 정보 카드에서 프로젝트로 보드 이동하기*

## 프로젝트에서 새 보드 만들기

1. 왼쪽 사이드바에서 **프로젝트**로 이동합니다.
2. 프로젝트 이름을 클릭합니다.
3. 프로젝트 대시보드에서 + **새 보드**를 클릭합니다.

![Creating_a_new_board_in_a_project_greybg.gif](https://help.miro.com/hc/article_attachments/21830782663186)
*프로젝트 내에서 새 보드 만들기*

## 프로젝트에서 보드 제거하기

1. 오른쪽 상단의 보드 헤더에서 보드 이름을 클릭합니다.
2. 보드 정보 카드가 열립니다.
3. **위치** 옆의 프로젝트 이름을 클릭합니다.
4. 프로젝트 드롭다운에서 **없음**을 선택합니다.

*![Removing_a_board_from_a_project_greybg.gif](https://help.miro.com/hc/article_attachments/21830736324626)**프로젝트에서 보드 제거하기*

## 프로젝트 나가기 또는 삭제하기

> **실행 가능한 사용자:** 프로젝트 소유자

:::note
프로젝트를 삭제해도 해당 프로젝트의 보드가 삭제되지는 않습니다.
:::

1. 프로젝트 설정을 엽니다.
2. **프로젝트 삭제**를 선택합니다.

프로젝트 소유자가 *아닌* 다른 모든 프로젝트 멤버에게는 **프로젝트 나가기 옵션이 표시됩니다.** 프로젝트가 팀의 모든 사용자와 공유된 경우 사용자에게 프로젝트를 나가거나 삭제할 수 있는 옵션이 없습니다.

프로젝트를 나가거나 삭제한 후에도 사용자는 [이메일](03-sharing-boards-and-inviting-collaborators.md)이나 [팀 액세스](03-sharing-boards-and-inviting-collaborators.md)를 통해 공유된 해당 프로젝트 내의 모든 보드에 계속 액세스할 수 있습니다.

![delete a project.png](https://help.miro.com/hc/article_attachments/21830782672658)
*프로젝트 삭제하기*

## 프로젝트 복제하기

프로젝트를 복제할 수는 없지만, 프로젝트의 [보드를 복제](../managing-boards/03-how-to-duplicate-a-board.md)한 다음 새 프로젝트를 만들고 보드의 복사본을 새 프로젝트로 이동할 수 있습니다.

:::warning
무료 플랜으로 다운그레이드하면 더 이상 새 프로젝트를 만들거나 기존 프로젝트를 편집 또는 삭제할 수 없습니다.
:::

## 자주 묻는 질문

**프로젝트를 정리하려면 어떻게 해야 하나요?**

현재 프로젝트 보관, 프로젝트 링크 만들기, 프로젝트 내부에 프로젝트 만들기, 프로젝트 및 보드 순서 변경 옵션은 지원하지 않습니다. 대신 즐겨찾기한 프로젝트를 사용해 현재 프로젝트와 진행 중인 프로젝트를 정리해 관리할 것을 권장합니다.
