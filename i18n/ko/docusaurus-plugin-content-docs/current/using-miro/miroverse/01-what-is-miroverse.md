[Miroverse](https://miro.com/miroverse/)는 Miro 커뮤니티에 의해 생성되고 공유된 유용하고 혁신적인 보드 템플릿을 전시하는 커뮤니티 템플릿 갤러리입니다. 검색과 탐색 기능을 사용하여 다양한 워크플로, 프로젝트, 프레임워크를 찾아볼 수 있습니다. 마음에 드는 템플릿을 찾으면, 자신의 팀에 복사하여 바로 시작할 수 있습니다.

:::tip
더 많은 Miroverse 게시 팁과 리소스를 얻고, 크리에이터 커뮤니티와 이벤트에 접근하려면 [Miroverse 크리에이터 디자인 툴킷](https://miro.com/miroverse/miroverse-creator-design-toolkit/)을 방문하세요.
:::

:::tip
[자신의 보드를 게시](06-how-to-get-published-on-miroverse.md)하는 방법에 대해 더 알아보세요.
:::

:::warning
Miroverse는 미국 및 호주 데이터 레지던시에 등록된 고객에게는 제공되지 않습니다.
:::

## Miroverse와 템플릿 라이브러리 비교

Miroverse와 템플릿 라이브러리는 모두 기존 보드 템플릿을 복사하여 Miro 팀에 추가할 수 있게 해 줌으로써 보드를 처음부터 만들지 않고도 새 프로젝트를 시작할 수 있도록 도와줍니다. 하지만 각 갤러리에서 제공되는 템플릿의 기원과 목적은 다릅니다.

### 템플릿 라이브러리

- Miro팀이 제작한 템플릿.
- 다양한 일반적인 사용 사례에 적합.
- 산업 최고의 관행과 고객 피드백을 바탕으로 설계.

### Miroverse

- Miro 사용자가 제작.
- 개인 및 전문적인 도입 사례를 선보이는 공간.
- 각 사용자별로 매우 구체적인 작업 방식으로 구성.
- 실제 회사 및 산업 리더가 Miro를 사용하는 방식을 엿볼 수 있는 창.
