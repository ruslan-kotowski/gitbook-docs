Miroverse는 두 가지 주요 페이지 타입으로 구성되어 있어 원하는 항목을 찾는 데 도움이 됩니다: 템플릿 설명 페이지와 사용자 프로필 페이지.

### 템플릿 설명 페이지

Miroverse의 각 템플릿에는 보드와 크리에이터에 대한 자세한 정보를 확인할 수 있는 설명 페이지가 있습니다. 일부 템플릿에는 시작하는 데 도움이 되는 개인 투어와 추가적인 맥락을 제공하는 짧은 동영상 소개가 포함되어 있습니다.

템플릿 설명 페이지에서 커뮤니티가 템플릿과 어떻게 상호작용하는지 확인할 수도 있습니다. 템플릿이 받은 좋아요, 보기, 복사 수를 확인하고 다른 사용자들의 피드백도 검토할 수 있습니다.

### Miroverse 프로필 페이지

프로필 페이지를 통해 템플릿 크리에이터에 대해 더 알아보고 그들이 공개한 모든 보드를 볼 수 있습니다. 크리에이터의 프로필 페이지에서, 그들의 바이오, 프로필 사진, 소셜 미디어 링크 및 모든 게시된 템플릿을 볼 수 있습니다.

## Miroverse 콘텐츠를 활용하고 참여를 유도하세요

Miroverse의 템플릿을 사용하고 원하는 템플릿에 피드백을 제공하고 좋아요를 눌러 커뮤니티와 함께하세요.

### 템플릿 사용

사용할 템플릿을 찾으면, 시작하려면 **템플릿 사용**을 클릭하세요.

Miro 계정에 로그인된 경우, 새 보드는 마지막으로 활성화된 팀의 **모든 보드** 섹션에 자동으로 저장됩니다.

:::tip
생성된 템플릿을 [팀 간 또는 특정 스페이스로 쉽게 이동할 수 있습니다](../../getting-started/start-here/your-first-board/05-toolbars.md). 협업을 시작하려면 [사용자를 보드에 초대](https://help.miro.com/hc/articles/360017730693-Sharing-boards-and-inviting-collaborators)하거나 [링크를 통해 보드에 대한 공용 액세스를 활성화](../sharing-boards/08-collaboration-with-visitors.md)하세요.
:::

**추가 정보:** [Miroverse 템플릿 찾기 및 사용하기](04-find-and-use-miroverse-templates.md)를 참조하세요.

### 템플릿을 좋아요하고 피드백 보내기

Miro 프로필에 로그인한 사용자는 Miroverse의 템플릿에 좋아요와 피드백을 추가할 수 있습니다. 템플릿에 좋아요를 표시하면 감사를 표현하고 나중에 사용할 수 있도록 좋아하는 Miroverse 템플릿을 저장할 수 있습니다.

- 지원하려면 템플릿 카드나 템플릿 설명 페이지에서 **♡** 아이콘을 클릭하세요.
- 좋아요를 제거하려면 **♡** 아이콘을 다시 클릭하세요.
- 피드백을 주거나 템플릿에 댓글을 남기려면 메시지 아이콘을 클릭하세요.

### 좋아요 한 템플릿과 크리에이터 프로필 찾기

좋아한 템플릿을 찾는 주요 방법 두 가지는 다음과 같습니다:

- Miroverse 페이지의 오른쪽 상단 모서리에서 프로필 사진을 클릭하고 **좋아요**를 선택합니다.
- 공개된 Miroverse 프로필 페이지에서 **좋아요** 탭을 선택하세요.

Miroverse 크리에이터에 대해 더 알아보고 그들이 만든 모든 템플릿을 보려면, 템플릿 페이지 또는 템플릿 카드에서 그들의 이름을 클릭하세요. Miroverse 프로필에서 크리에이터의 좋아요를 받은 템플릿을 볼 수 있습니다. Miroverse 프로필에서 좋아요한 템플릿을 공유할 수도 있습니다. Miroverse 프로필이 없으면 좋아요한 템플릿은 귀하만 접근 가능한 비공개 갤러리에 저장됩니다.
