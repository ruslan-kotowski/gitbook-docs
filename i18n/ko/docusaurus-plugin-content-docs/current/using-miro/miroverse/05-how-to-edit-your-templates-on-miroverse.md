언제든지 템플릿을 편집할 수 있으며, 템플릿 이름, 범주, 설명, 동영상 링크, 표지 이미지 및 보드를 포함할 수 있습니다.

다음 동영상은 편집 프로세스의 설명을 제공합니다.

## 편집 모드로 들어가기

편집 모드로 들어가는 방법은 두 가지입니다:

1. 템플릿으로 이동하여 페이지 오른쪽 상단 미리보기 바로 위의 **편집**을 선택하세요.

   ![Entering the template editing mode](../../../../../../docs/using-miro/miroverse/images/19597178689938_template-1.png)

   *템플릿 편집 모드 입력*
2. 대안으로, Miroverse 프로필에서 게시된 템플릿을 직접 편집 모드로 전환하세요.

   ![Entering the template editing mode from your Miroverse profile](../../../../../../docs/using-miro/miroverse/images/19597178692498_template-2.png)

   *Miroverse 프로필에서 템플릿 편집 모드로 진입하기*

## 템플릿 콘텐츠 업데이트

템플릿 편집 폼에서 템플릿에 사용되는 보드를 변경하고 세부 정보를 업데이트할 수 있습니다.

![Template editing form](../../../../../../docs/using-miro/miroverse/images/19597178694034_template-3.png)

*템플릿 편집 양식*

### 템플릿 보드 변경하기

Miroverse에 템플릿을 제출하면 원본 보드의 복사본이 생성되어 실시간 버전이 됩니다. 템플릿에서 보드 콘텐츠를 변경하려면:

1. 먼저 Miro에서 보드를 편집하세요.
2. 필요한 편집을 완료했으면 Miroverse의 템플릿으로 돌아가 **Edit**을 클릭하세요.
3. 양식 상단에서 **보드 변경**을 선택하세요.
4. 업데이트된 보드를 선택하세요.

### 템플릿 세부정보 변경

이 편집 양식에서 템플릿의 다음 항목을 변경할 수도 있습니다:

- 이름
- 카테고리
- 설명
- 동영상 링크
- 커버 이미지

## 변경 사항 게시

템플릿 업데이트가 완료되면 변경 사항을 게시해 Miroverse에서 사용할 수 있도록 해야 합니다.

1. 편집에 만족하신다면 미리 보기 하세요.
2. **게시**를 선택해 게시하세요.

**게시**를 클릭하면 이메일로 확인 메시지를 받게 되며, 몇 분 내로 템플릿에 업데이트가 반영됩니다.
