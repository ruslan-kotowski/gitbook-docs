Miroverse는 다른 Miro 사용자가 만든 보드를 발견하고 사용할 수 있는 커뮤니티 템플릿 라이브러리입니다. 다양한 컬렉션, 역할, 사용 사례를 위한 템플릿을 찾아 작업을 시작해보세요.

[Miroverse](https://miro.com/miroverse/)에 직접 접속하거나 Miro 대시보드에서 접근할 수 있습니다:

1. 대시보드에서 **+ 새로 만들기**를 클릭하세요.
2. **Miroverse 둘러보기** 선택.

메인 페이지에는 인기 있는 템플릿 모음, 검색창, 카테고리 목록이 있어 필요에 맞는 완벽한 보드를 찾을 수 있도록 도와줍니다.

## 템플릿 찾기

이 섹션에서는 Miroverse에서 템플릿을 찾는 방법에 대해 설명합니다. 카테고리를 탐색하거나 검색 기능을 사용할 수 있습니다.

### 카테고리별 둘러보기

Miroverse 홈페이지에서 카테고리별로 템플릿을 둘러볼 수 있습니다.

1. 페이지 상단의 카테고리를 클릭해 해당 카테고리에 포함된 모든 템플릿을 확인하세요.
2. 카테고리 페이지에서 템플릿을 **최근 추가됨**, **가장 많이 사용됨**, **보기**, **좋아요**로 정렬할 수 있습니다.

### 템플릿 검색

검색 표시줄을 사용해 특정 템플릿을 찾을 수 있습니다.

1. 검색 상자에 검색어를 입력하세요. 귀하의 쿼리는 템플릿 제목, 프로필 이름, 회사 이름과 일치하게 됩니다. 결과에서 일치하는 용어가 강조 표시됩니다.
2. 검색 또는 카테고리 페이지에서 Miroverse 홈페이지로 돌아가려면 검색 창 옆의 **Miro | Miroverse**를 클릭하세요.

:::tip
검색 결과를 공유하려면 브라우저 주소창에서 생성된 URL을 복사하세요.
:::

## 템플릿 사용

마음에 드는 템플릿을 찾으면 미리 보기하고 새 보드나 기존 보드에 추가할 수 있습니다.

1. 템플릿 카드의 페이지를 열고 콘텐츠 미리보기를 보려면 클릭하세요.
2. 템플릿 페이지에서 두 가지 옵션이 있습니다:
   - 새 보드를 템플릿에서 생성하려면, **템플릿 사용**을 클릭하세요.
   - 이미 생성한 보드에 템플릿을 추가하려면 **템플릿 사용** 옆의 드롭다운 메뉴를 클릭하고 보드를 선택하세요.

> 만약 Miro 프로필이 없을 경우, 먼저 무료로 가입하라는 메시지가 표시됩니다. 프로필은 있으나 로그인하지 않은 경우, 템플릿을 사용하려면 로그인해야 합니다.

:::tip
자주 사용하는 템플릿에 빠르게 접근하려면 보드를 [맞춤 설정 템플릿](https://help.miro.com/hc/articles/360017737473-Custom-templates)으로 저장하세요.
:::
