[Zapier](http://zapier.com/)를 통해 Miro Insights를 수백 개의 도구와 연결하여 직접 통합이 없는 소스로부터 피드백과 데이터를 자동으로 수집할 수 있습니다. 이를 통해 전체 기술 스택 전반에서 고객 인사이트를 중앙 집중화할 수 있습니다.

Zapier 통합을 통해 다음과 같은 작업이 가능합니다:

- 고객 지원 티켓, 설문조사 또는 채팅 대화에서 자동으로 피드백 항목 생성.
- Zapier가 지원하는 모든 도구에서 Miro Insights에 직접 통합이 없더라도 데이터 수집.
- 자동화된 워크플로를 설정하여 수동 데이터 입력 감소.

## 피드백 생성

Zapier는 Miro Insights에서 피드백 항목을 생성하기 위한 두 가지 주요 기능을 제공합니다.

### 피드백 생성

Miro Insights에서 일반 피드백 항목을 생성하기 위한 표준 작업으로, 다음의 필드를 포함합니다:

- **피드백 제목**: 피드백에 대한 간단한 요약입니다.
- **내용**: 상세한 피드백 내용 또는 설명입니다.
- **제공자 이름**: 피드백을 제공한 사람의 이름입니다.
- **제공자 이메일**: 피드백 제공자의 이메일 주소입니다.
- **소유자 이메일**: 피드백의 내부 소유자 또는 담당자의 이메일입니다.
- **제공된 날짜 및 시간**: 피드백이 처음 제공된 시점.
- **출처 URL**: 원본 소스(티켓, 설문 응답 등)로의 링크.
- **회사명**: 피드백이 연관된 조직.
- **회사 도메인**: 회사의 웹사이트 도메인.

### 피드백 생성(통화)

통화 및 대화에서의 피드백 수집을 위해 특별히 설계된 작업. 이러한 필드를 포함합니다:

- **통화 제목**: 통화의 제목 또는 주제입니다.
- **통화 메모**: 통화 내용의 전체 메모 또는 요약입니다.
- **원본 URL**: 통화 녹화 또는 회의 세부 정보 링크입니다.
- **참여자**: 통화 참여자에 대한 정보입니다.
  - **이메일 주소**: 참여자의 이메일 주소입니다.
  - **이름**: 참여자의 이름입니다.
- **소유자의 이메일 주소**: 통화 피드백에 대한 내부 소유자 또는 담당자입니다.
- **시작 날짜 및 시간**: 통화가 발생한 시간.
- **회사 이름**: 통화와 관련된 조직.
- **회사 도메인**: 회사의 웹사이트 도메인.

## Zapier 통합 설정

Zapier와 Miro Insights를 시작하려면 다음 단계를 따르세요.

### 전제 조건

- 활성 Miro Insights 계정
- Zapier 계정(무료 또는 유료)
- 연결할 소스 도구에 대한 접근 권한

### 템플릿으로 빠르게 시작하기

Miro Insights는 Grain, Fathom, Fireflies와 같은 인기 대화 인텔리전스 툴을 위한 사전 제작된 Zapier 템플릿을 제공합니다.

템플릿을 사용하여 Zap을 설정하려면 다음을 따르세요:

1. Miro Insights 설정 > **통합 및 자동화** 섹션으로 이동합니다.
2. 대화 툴을 선택하세요. 예를 들어 Grain.
3. 필요한 경우 Zapier에 로그인하세요.
4. Grain계정을 연결합니다.
5. Grain에서 Miro Insights 필드로 필드를 매핑합니다.
6. 사전 구성된 통합을 테스트하고 활성화하세요.

템플릿을 사용하면 각 도구에 최적화된 필드 매핑을 통해 더 빠르게 설정할 수 있어 녹화된 대화에서 고객 피드백을 쉽게 수집할 수 있습니다.

### 기본 설정

1. **새로운 Zap을 생성하세요** Zapier 대시보드에서.
2. 귀하의 **트리거 앱**을 선택하세요. 피드백이 시작되는 도구입니다.
3. **Miro 인사이트** 를 작업 앱으로 선택하세요.
4. 액션 이벤트를 선택하세요:
   - "피드백 생성": 일반적인 피드백 항목을 위한 옵션입니다.
   - "피드백 생성 (콜)": 통화 관련 피드백을 위한 옵션입니다.
5. 프롬프트가 나오면 Miro Insights 계정을 연결하세요.
6. 트리거 앱의 필드를 Miro Insights 필드에 매핑하세요.
7. 데이터 흐름이 올바른지 확인하기 위해 통합 테스트를 진행하세요.
8. 자동 데이터 수집을 시작하기 위해 Zap을 활성화하세요.

### 필드 매핑 모범 사례

소스 툴에서 Miro Insights로 필드를 매핑할 때, 양질의 데이터 캡처를 보장하기 위해 다음 베스트 프랙티스를 고려하세요.

**필수 필드:**

- **피드백 제목**: 소스 데이터에서 명확하고 설명적인 제목을 사용하세요.
- **내용**: 주 피드백 내용을 매핑하거나 여러 필드를 결합하세요.

**권장 필드:**

- **기록자 정보**: 가능한 경우 고객의 연락처 정보를 캡처합니다.
- **회사 데이터**: 계정 기반 제품 관리를 위해 필수적입니다.
- **출처 URL**: 원본 소스로의 추적 가능성을 유지합니다.
- **제공 날짜**: 처리 날짜가 아닌 실제 피드백 날짜를 사용합니다.

**필드 매핑 팁:**

- Zapier의 포매터 도구를 사용하여 여러 소스 필드를 결합하세요.
- 명확성을 위해 제목이나 내용에 소스 도구명을 포함하세요.
- 날짜, 회사명, 카테고리에 일관된 형식을 사용하세요.
- 선택 필드에 대한 기본값을 설정하세요.
