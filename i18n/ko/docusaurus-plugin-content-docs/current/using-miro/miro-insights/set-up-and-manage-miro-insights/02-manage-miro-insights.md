이 가이드는 일반 설정, 팀 관리, 알림 및 API 접근을 포함한 Miro Insights의 지속적인 관리 작업을 다룹니다. 이는 초기 설정이 완료된 후 Miro Insights를 관리해야 하는 회사 관리자를 위한 것입니다.

Miro Insights를 아직 설정하지 않았다면, 먼저 [Miro Insights 설정 (관리자)](../../miro-insights/set-up-and-manage-miro-insights/01-set-up-miro-insights.md) 가이드를 시작하세요.

## 필수 조건

Miro Insights 관리를 위해 필요한 사항:

- **회사 관리자** 역할이 Miro에서 필요합니다.
- **귀 조직에 이미 Miro Insights가 설정되어 있어야 합니다**.

## 회사 프로필

이 섹션에서는 Miro Insights에 나타날 귀사의 정보를 업데이트할 수 있습니다.

- **이름**: 조직의 이름입니다.
- **허용된 이메일 도메인**: Miro Insights에 접근할 수 있는 이메일 도메인입니다.
- **회사 로고**: 회사 로고를 업로드하거나 변경할 수 있습니다.

## 팀

이 섹션에서는 Miro Insights 팀과 관련된 설정을 다룹니다. 관리자로서 사용자를 초대하거나 추가, 제거하며 그들의 역할을 관리할 수 있습니다.

## 알림

이 섹션에서는 새로운 피드백, AI 제안, 기타 중요한 이벤트에 대한 알림을 어떻게 받고 언제 받을지 설정할 수 있습니다.

Slack과 같은 알림 방법을 설정할 수 있습니다. 기능 또는 피드백과 같은 카테고리별로 알림 유형을 구성할 수 있습니다.

## 통합 및 자동화

이 섹션에서는 연결된 모든 통합과 자동화를 관리할 수 있습니다. 각 통합의 상태를 확인하고, 필요한 경우 다시 연결하며, 가져오기 설정을 조정할 수 있습니다.

자세한 설정 안내는 [Miro Insights 설정 (관리자) 가이드](../../miro-insights/set-up-and-manage-miro-insights/01-set-up-miro-insights.md)를 참조하세요.

## API 키

여기에서는 Miro Insights 데이터에 대한 프로그래밍 접근을 위해 API 키를 생성하고 관리할 수 있습니다. 새로운 키를 생성하고 기존 또는 손상된 키를 해지할 수 있습니다.

:::warning
API 키를 생성할 때는 설명이 잘 된 이름을 지정하고 안전한 장소에 복사하세요. 이 페이지를 나가면 다시 볼 수 없습니다.
:::

## 다음 단계는 무엇입니까?

이러한 관리 설정을 구성한 후, Miro Insights 인스턴스는 팀에 원활하게 작동할 것입니다. 지속적인 사용 안내는 [Miro Insights 사용 가이드](../../miro-insights/use-miro-insights)를 참조하세요.
