로드맵은 제품 계획에 대한 전략적인 보기를 제공하여 기능 개발 타임라인을 시각화하고 전달하는 데 도움을 줍니다. 백로그 항목이 전략적 이니셔티브 및 계획된 전달 기간에 어떻게 매핑되는지를 보여줍니다.

로드맵은 기능과 이슈를 **기간, 이펙트 영역, 이니셔티브, 상태**별로 정리하여 표시합니다.

## 로드맵 데이터 이해하기

백로그 데이터가 로드맵 보기로 어떻게 변환되는지 이해하는 것이 중요합니다. 로드맵은 계획 및 우선순위 설정을 위한 맥락을 제공하기 위해 백로그 항목에서 주요 정보를 가져옵니다.

### 주요 열

- **영향 영역**: 비즈니스 도메인 또는 전략적 목표.
- **이니셔티브**: 더 넓은 프로젝트 또는 주제.
- **기능**: 개발 중인 특정 기능.
- **상태**: 현재 상태 (조사 중, 진행 중, 출시됨 등).
- **우선순위**: 상대적 중요도 순위.
- **총 회사**: 이 기능을 요청한 회사 수.
- **총 피드백**: 고객 입력량.
- **기업**: 해당 기능에 관심 있는 특정 조직입니다.

### 시각적 표시

- **상태 색상**: 개발 진행 상황에 대한 빠른 시각적 참조
- **우선순위 지표**: 가장 중요한 항목 식별에 도움을 줌
- **고객 태그**: 요구 사항의 주체인 고객 표시

## 백로그에서 항목 추가

백로그에서 기능 및 이슈를 로드맵에 쉽게 추가할 수 있습니다:

1. **백로그에서 추가**를 선택해 선택 대화 상자를 엽니다.
2. **검색 및 필터**를 사용하여 백로그 항목을 필터링합니다:
   - 검색창에서 특정 기능을 찾습니다.
   - 상태 필터 (완료, 취소 등).
   - 목표 날짜 필터.
   - 기타 사용 가능한 기준.
3. **사용 가능한 항목을 탐색**하여 주요 지표를 확인하세요:
   - 달러 가치 영향.
   - 현재 상태 (아이디어, 진행 중 등).
   - 요청한 회사 수.
   - 피드백 양.
4. **항목 선택**하여 측면 패널에서 상세 정보를 확인하세요.
5. **선택한 항목에 대한 목표 분기**를 선택하세요.
6. 클릭하여 **로드맵에 추가**하여 플래닝에 포함시킵니다.

다른 방법으로, 원하는 열에서 기간, 영향 영역 또는 이니셔티브에 대해 **+** (플러스) 아이콘을 클릭하여 기능을 직접 로드맵 보기에 추가할 수 있습니다.

이 기능은 각 백로그 항목의 비즈니스 영향, 고객 수요, 현재 상태를 보여줌으로써 로드맵에 무엇을 포함할지를 결정하는 데 도움을 줍니다.

## 기능 직접 생성

로드맵 보기에서 기능이나 이슈를 직접 생성할 수도 있습니다:

1. **기능 생성**을 선택해 생성 대화 상자를 엽니다.
2. **기본 정보** 입력:
   - 기능 또는 이슈 제목
   - 설명
   - 유형(기능 또는 이슈)
3. **속성** 설정하기:
   - 상태 (아이디어, 진행 중, 등)
   - 우선순위 수준
   - 소유자 및 팀
   - 시작일 및 목표일
   - 크기 추정
4. **메타데이터로 조직화하기**:
   - 영향 범위
   - 이니셔티브
   - 스트림과 하위 스트림
   - 태그와 기능 영역
   - 외부 사양
   - 마일스톤
5. **기업 연결하기**:
   - 요청 기업 추가.
   - 수익 영향 설정 (신규 ARR, ARR 유지, ARR 손실).
   - 거래 금액 및 예상 종료 날짜 포함.
6. **외부 작업 연결하기** (예: Jira 티켓 등).
7. 로드맵에 새 항목을 직접 추가하려면 **생성**을 선택하세요.

이 워크플로는 로드맵 계획 세션 중 새로운 아이디어를 캡처하거나 전략적 이니셔티브를 위한 플레이스홀더 항목을 생성할 때 이상적입니다.

## 기간별 조직화

로드맵은 귀하의 계획 요구 사항에 맞게 다양한 기간으로 구성할 수 있습니다:

- **주간**: 단기 스프린트 계획 및 즉각적인 우선순위를 위해.
- **월간**: 중기 기능 개발 주기를 위해.
- **분기별**: 전략적 비즈니스 계획 및 장기 이니셔티브를 위해.

이 유연성은 출시 계획, 자원 할당, 그리고 이해관계자와의 커뮤니케이션에 도움이 됩니다.

## 필터링 및 그룹화

필터와 그룹화 옵션을 사용하여 로드맵 보기를 사용자 지정하여 귀하의 계획의 특정 측면에 집중할 수 있습니다.

### 필터링 옵션

다음을 필터로 적용하여 로드맵 보기를 정밀하게 조정하세요:

- **시간 기간**: 특정 주, 월, 분기에 집중합니다.
- **이니셔티브**: 전략적 테마의 진행 상황을 확인합니다.
- **상태**: 특정 개발 단계에 있는 항목을 확인합니다.
- **우선순위**: 가장 중요한 기능에 집중합니다.

### 그룹화 옵션

로드맵 보기를 다음 기준으로 구성합니다:

- **이니셔티브**: 전략적 테마 내 모든 기능 보기
- **영향 영역**: 비즈니스 목표별 그룹화
- **상태**: 개발 진행 단계별 정리
- **회사**: 요청한 고객별 기능 보기
