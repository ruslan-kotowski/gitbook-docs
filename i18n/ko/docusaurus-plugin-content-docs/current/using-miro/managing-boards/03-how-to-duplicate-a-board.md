대시보드나 보드 정보 창에서 보드를 복제할 수 있습니다.

> **사용 가능 환경:** 브라우저 버전(데스크탑, 태블릿), 데스크톱 앱, 태블릿 앱
> **설정 기준:** Free 플랜의 보드 - 팀 멤버
> Starter, Business, Enterprise, Education 플랜의 보드 - [보드 콘텐츠 설정에서](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) 보드를 복제할 수 있는 사용자

### Miro 보드 복제하기

보드에서 오른쪽으로 이동하려면 왼쪽 상단 모서리의 보드 이름을 클릭하면 정보 카드와 **복제** 옵션이 표시됩니다.

:::note
사용자가 보드를 복제하면 모든 [Talktrack도](../facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md) 새 보드에 복제됩니다.
:::

![duplicating_a_Miro_board.gif](images/21857666561298_duplicating%20a%20Miro%20board.gif)
*보드 정보 카드에서 복제 옵션*

> **✏️** 보드의 [게스트이고](../sharing-boards/07-collaboration-with-guests.md) 다른 Miro 팀에 멤버가 없거나 [제한된 무료](../../enterprise-administration/enterprise-subscription-management/enterprise-licensing/04-free-restricted-license.md) 라이선스가 있는 경우 새 Miro 팀을 만들어 보드 복사본을 저장하라는 메시지가 표시됩니다.

대시보드에서 보드를 복제하려면 보드 컨텍스트 메뉴를 열거나 보드 아이콘을 마우스 오른쪽 버튼으로 클릭하고 **복제를** 선택하세요.

![duplicate_from_dashboard.jpg](images/21857666566674_duplicate%20from%20dashboard.jpg)
*대시보드의 복제 옵션*

대시보드에서 복제를 선택하면 **복사본의** 새 이름을 설정할 수 있는 옵션이 표시됩니다. 동일한 사용자와 공유하고, 보드가 [프로젝트의](../sharing-boards/16-projects.md) 일부인 경우 동일한 프로젝트 폴더에 복사본을 배치할지 여부를 선택할 수 있습니다.

:::warning
보드 이름은 최대 문자 수 제한이 61입니다. 보드를 복제하면 보드 이름에 "복사본" 이 추가됩니다. 문자가 너무 많으면 보드가 복사되지 않습니다. 보드 이름을 줄이고 보드를 다시 복제하세요.
:::

![copy_board_modal.jpg](images/21857650224274_copy%20board%20modal.jpg)

## 자주 묻는 질문

1. *보드 복사본의 콘텐츠를 변경하면 원본 보드가 영향을 받나요?*
   - 아니요, 복사본의 콘텐츠는 원본 보드의 콘텐츠와 관련이 없습니다.
2. *기존 보드에 보드 콘텐츠를 복제하려면 어떻게 해야 하나요?*
   - [필요한 콘텐츠를](../working-on-the-board/10-working-with-objects.md) 선택해 복사해 다른 보드에 *붙여넣으세요(Windows에서는* **Ctrl+C/Ctrl + V** 또는 *Mac에서는* **Cmd + C/Cmd + V** 사용 가능).
3. *여러 보드를 일괄적으로 복제할 수 있나요?*
   - 아니요, 현재는 불가능합니다.
4. *보드를 다른 사용자와 템플릿으로 공유해 자신의 팀에 복제할 수 있나요?*
   - 네, [보드 콘텐츠 설정에서](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) 허용되는지 확인해야 합니다.
