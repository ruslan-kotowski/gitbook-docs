한 보드에서 팀의 워크플로를 관리하는 일은 다소 어려울 수 있습니다. 액티비티란 모든 팀원이 프로젝트에 추가한 입력을 추적하고 평가할 수 있는 기능입니다.

> **사용 가능 대상:** 브라우저 버전, [데스크톱 앱](../../getting-started/apps-for-devices/05-desktop-app.md), [태블릿 앱](../../getting-started/apps-for-devices/11-tablet-app.md)
> **설정 권한을 가진 사용자:** [이메일을 통해](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) 보드에 명시적으로 초대받았거나 Miro 내 [프로젝트](../sharing-boards/16-projects.md)나 [팀](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)에 속해 있어 보드에 액세스할 수 있는 편집자

### 보드 액티비티 목록

**액티비티**에서 보드의 최신 변경 사항을 확인할 수 있습니다. 열려면 **메인 메뉴** 아이콘 > **보드** > **보드 변경 이력**을 클릭합니다. 자리를 비운 동안 다른 사용자가 편집한 보드를 열면 보드 변경 이력 패널 하단에 **변경 사항 하이라이트** 옵션이 표시됩니다.

![메인_메뉴에서_보드_변경_이력_액티비티_액세스.gif](images/21574837425554_board_history_activity_access_from_main_menu.gif)*보드 변경 이력 열기*

**액티비티**는 [이메일을 통해](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) 보드에 명시적으로 초대받았거나 Miro 내 [프로젝트](../sharing-boards/16-projects.md)나 [팀](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)에 속해 있어 보드에 액세스할 수 있는 보드 편집자에게 표시됩니다. 즉, 보드에 대해 편집자 권한을 가진 [게스트](../sharing-boards/07-collaboration-with-guests.md)와 팀원에게 표시됩니다. [링크를 통해 회사와 공유](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)한 보드나 [공개 링크를 통해](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) 방문자와 공유한 보드의 경우, 회사와 방문자에게는 **액티비티**가 표시되지 않습니다. 뷰어와 댓글 작성자는 **액티비티**를 볼 수 없습니다.

자리를 비운 동안 다른 사용자가 최근에 변경한 내용을 하이라이트 표시하는 기능을 **액티비티** 패널 하단에서 켜거나 끌 수 있습니다. 변경 사항 강조 표시를 활성화하면 보드에서 가장 최근에 수정된 오브젝트로 자동 리디렉션됩니다.

![보드_변경_이력_액티비티_변경_사항_하이라이트.png](../../../../../../docs/using-miro/managing-boards/images/21016134524178_board_history_activity_highlight_changes.png)*변경 사항 하이라이트 표시*

보드 변경 사항은 *날짜 순서대로* 정렬되고 사용자별로 그룹화됩니다. 모든 변경 사항은 사용자의 **현지** 시간 기준으로 기록됩니다. 변경 사항에는 다음의 3가지 범주가 있습니다.

- 콘텐츠 추가 및 복제
- 콘텐츠 편집
- 콘텐츠 삭제([실행 취소](../essential-tools/16-undoredo.md) 작업 포함)

특정 작업을 찾으려면 목록을 아래로 스크롤해 편집 내용을 살펴보세요. 모든 텍스트 변경 사항이 작업 이름 아래 표시되어 참조할 수 있습니다. 프레임인 경우 [프레임](../essential-tools/07-frames.md) 이름이 표시됩니다.

목록에서 기록을 클릭하면 보드의 해당 오브젝트로 자동 리디렉션되고 확대되어 변경 사항을 자세히 볼 수 있습니다(**삭제** 기록 제외).

![보드_변경_이력_액티비티_변경_선택.gif](../../../../../../docs/using-miro/managing-boards/images/21016121177362_board_history_activity_selecting_edits.gif)*이벤트를 클릭해 업데이트된 오브젝트로 이동*

모든 면에서 콘텐츠 최적화를 실현하기 위해 항상 가장 최근 변경 사항만 표시되도록 목록을 제한했습니다. 한 오브젝트를 여러 번 수정하면 이전 수정 사항은 모두 목록에서 지워집니다.

현재 작업 중인 내용이 무엇이든 [댓글](../facilitation-tools/asynchronous-tools/01-comments.md)을 비롯한 모든 보드 오브젝트와 업로드한 파일은 편집 모드를 종료하는 즉시 **실시간으로** 등록 및 추적됩니다. 따라서 메뉴를 다시 열거나 보드를 새로 고칠 필요가 없습니다. 단, [움직이는 오브젝트](../working-on-the-board/10-working-with-objects.md)는 제외됩니다. 목록에서 이에 대한 기록은 찾을 수 없습니다.

**액티비티** 패널을 닫으려면 패널 오른쪽 상단 모서리에 있는 x자 모양아이콘을 클릭하기만 하면 됩니다.

오프라인 상태일 때 공동 작업자가 보드의 내용을 변경한 경우, 보드를 열면 **최근 변경 사항 보기** 버튼이 표시됩니다. **최근 변경 사항 보기**를 클릭하면 보드에서 분홍색으로 하이라이트된 모든 변경 사항을 확인할 수 있습니다. 또한 보드에 오브젝트를 추가하거나 수정한 공동 작업자의 이름과 그 작업을 수행한 시간이 표시됩니다. 하이라이트를 숨기려면 **변경 사항 하이라이트 숨기기**를 클릭합니다.

**최근 변경 사항 보기** 버튼을 30초 동안 클릭하지 않으면 사라집니다.

![최근_변경_사항_보기.jpg](../../../../../../docs/using-miro/managing-boards/images/21016134517394_see%20recent%20changes.jpg)*보드의 변경 사항 하이라이트 표시*

:::note
저장된 보드 변경 이력 액티비티는 90일 동안 저장됩니다.
:::

### 액티비티를 사용해 최근에 삭제한 보드 콘텐츠 복원하기

> **설정 권한을 가진 사용자:** 보드 편집자
> **사용 가능 대상:** 브라우저 버전, [데스크톱 앱](../../getting-started/apps-for-devices/05-desktop-app.md), [태블릿 앱](../../getting-started/apps-for-devices/11-tablet-app.md)

:::tip
지난 버전의 보드 전체(스냅샷)을 복원하는 옵션은 [보드 변경 이력: 버전](12-board-history-versions.md)을 참고하세요.
:::

> **⚠️**  [방문자](../sharing-boards/08-collaboration-with-visitors.md)는 이 기능을 사용할 수 없습니다.

최근에 삭제한 오브젝트를 복원하려면 **액티비티**를 열고 삭제된 위젯 옆의 **복원**을 클릭합니다. 그러면 삭제된 오브젝트가 삭제되기 전 위치 그대로 보드에 다시 나타나고 보드가 그 부분으로 확대됩니다.

![콘텐츠_복원.jpg](../../../../../../docs/using-miro/managing-boards/images/21016134518162_restore%20content.jpg)*삭제된 오브젝트 복원하기*

다음과 같은 콘텐츠를 복원할 수 있습니다.

- 현재 활성 세션 중에 보드에서 삭제된 모든 콘텐츠와 세션 종료 후 최대 30분 내 삭제된 콘텐츠
- 삭제 후 30분 이상 지난 경우 보드에서 삭제된 오브젝트 중 마지막 1,000개
- 동시에 선택 및 삭제된 모든 오브젝트의 경우 다음 1,000개의 오브젝트가 삭제될 때까지 무기한 복원 가능

예외적인 상황도 있을 수 있다는 점에 유의하세요. 자세한 내용은 [이 문서](../working-on-the-board/18-restoring-board-content.md)를 참고하세요.

### 자주 묻는 질문

1. *특정 보드의 액티비티 이력을 볼 수 있나요?*
   - 아니요, 하지만 오브젝트를 클릭하고 컨텍스트 메뉴에서 세 점 아이콘 아래의 **정보**를 선택하면 누가 언제 오브젝트를 만들었고 언제 마지막으로 수정했는지 확인할 수 있습니다.
2. *액티비티를 지울 수 있나요?*아니요, 현재는 불가능합니다.
3. *Miro에서 보드를 공개적으로 공유하지 않았는데 액티비티에 방문자가 표시됩니다. 이유가 무엇인가요?*- 보드가 다른 서비스(예: [Zoom](../../integrations-apps/zoom/02-miro-app-for-zoom-user-guide.md))에 임베드되어 **누구나 편집 가능. 로그인 필요 없음** 옵션이 적용된 경우 이러한 문제가 발생합니다.
4. *툴바에 보드 변경 이력 아이콘이 표시되지 않습니다. 이유가 무엇인가요?*
   - 보드 변경 이력은 [이메일을 통해](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) 보드에 명시적으로 초대받았거나 Miro의 [프로젝트](../sharing-boards/16-projects.md) 또는 [팀](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)에 속해 있어 보드에 액세스할 수 있는 보드 편집자에게만 표시됩니다. 보드 변경 이력은 뷰어, 댓글 작성자, [방문자](../sharing-boards/08-collaboration-with-visitors.md)에게는 표시되지 않습니다.
5. *최근 변경 사항 보기 버튼이 표시되지 않습니다. 이유가 무엇인가요?*
   - 최근 변경 사항 보기 버튼은 내가 보드에 없는 동안 다른 사용자가 콘텐츠를 편집한 경우에만 표시됩니다. 마지막 방문 이후 변경 사항이 없는 경우 이 버튼이 표시되지 않습니다.
