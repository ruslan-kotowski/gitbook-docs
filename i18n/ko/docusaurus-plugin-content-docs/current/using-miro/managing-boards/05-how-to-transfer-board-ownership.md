Miro의 보드 소유자는 보드의 소유권을 다른 팀원에게 빠르고 쉽게 이전할 수 있습니다.

> **실행 가능한 사용자**: [콘텐츠 관리자 역할이 활성화](../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md)된 보드 소유자, Enterprise 플랜의 회사 멤버
> **사용 가능 환경**: 브라우저, [데스크톱 앱](../../getting-started/apps-for-devices/05-desktop-app.md), [태블릿 앱](../../getting-started/apps-for-devices/11-tablet-app.md)

### 다른 사용자에게 보드 재할당하기

:::warning
소유권 이전을 확정한 후에는 이 작업을 취소할 수 없습니다.
:::

1. 새 소유자가 보드에 초대되지 않은 경우 이메일이나 Slack을 통해 보드를 공유하세요. 보드 **공유** 대화 상자를 열고 사용자의 이메일 주소를 입력한 다음 **보내기**를 클릭합니다.
   ![share_via_email__1_.gif](images/21830711607954_share%20via%20email%20(1).gif)
   *Miro 보드에 사용자 초대하기*

2. 보드 **공유** 대화 상자에서 **공유 설정**을 클릭합니다.
3. 사용자 이름 옆의 **소유자**를 선택하고 **소유권 변경**을 클릭해 확정합니다.
   ![change_board_owner.gif](../../../../../../docs/using-miro/managing-boards/images/21017043185042_change%20board%20owner.gif)
   *다른 팀원에게 보드 소유권 이전하기*

:::warning
보드가 속한 팀의 멤버에게만 재할당할 수 있습니다. 재할당할 사용자가 팀 멤버가 아닌 경우 직접 초대하거나 Miro 관리자에게 해당 사용자를 초대하도록 요청해야 합니다.
:::

### 보드 소유자가 퇴사한 경우

Miro 팀 멤버가 더 이상 활동하지 않게 되어 해당 보드의 소유권을 가져와야 하는 경우 팀 관리자에게 문의하세요.

관리자는 팀 및 구독에서 해당 사용자를 제거하고 콘텐츠를 다른 멤버나 자신에게 재할당할 수 있습니다. [Enterprise 플랜에서 관리자가 사용자를 제거하는 방법](../../enterprise-administration/user-management/10-remove-users-on-enterprise-plan.md)이나 [다른 Miro 플랜에서 사용자를 제거하는 방법](../../administration/user-management/08-remove-users.md)을 알아보세요.

[콘텐츠 관리자 역할](../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md)이 활성화된 Enterprise 플랜의 회사 멤버인 경우, 위의 가이드를 따라 보드를 다른 사용자에게 재할당할 수 있습니다.
