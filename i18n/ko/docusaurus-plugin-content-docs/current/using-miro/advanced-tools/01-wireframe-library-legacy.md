:::note
와이어프레임 라이브러리가 새로운 프로토타입 라이브러리로 업그레이드되고 있습니다. 현재, 와이어프레임 라이브러리는 Miro 프로토타입 베타에 속하지 않은 Enterprise 플랜에서만 볼 수 있습니다.

**자세한 정보:** [프로토타입 라이브러리](../miroverse/prototyping/02-prototyping-library.md), [프로토타입 개요](../miroverse/prototyping/01-miro-prototypes-overview.md), 그리고 [Miro 프로토타입 (베타)](../miroverse/prototyping/03-miro-prototypes.md)를 참조하세요.
:::

**와이어프레임 라이브러리**가 더 강력하고 유연한 인터랙티브 화면 제작 도구 세트를 제공하는 새로운 **프로토타이핑 라이브러리**로 업그레이드되고 있습니다.

와이어프레임 라이브러리로 이미 생성한 모든 것은 보드에서 계속 작동합니다. 하지만 일부 오래된 컴포넌트와 디바이스 프레임은 툴바에서 더 이상 사용할 수 없으며, 향후 업데이트도 받지 않습니다.

![legacy-wireframe-library.png](../../../../../../docs/using-miro/advanced-tools/images/28175966882194_legacy-wireframe-library.png)

*이전의 와이어프레임 라이브러리*

### 변경 사항

- **와이어프레임 라이브러리**가 **프로토타이핑 라이브러리**로 통합되었습니다.
- 와이어프레임 라이브러리의 모든 **컴포넌트**는 이제 프로토타이핑 라이브러리의 **와이어프레임** 탭 아래에 포함되어 있습니다.
- **아이콘**은 프로토타이핑 라이브러리의 **아이콘** 탭에서 사용할 수 있습니다.
- **모바일**, **태블릿**, **브라우저 디바이스 프레임**이 새롭게 개편되어 **모바일**, **태블릿**, **데스크톱 스크린**으로 대체되었습니다.
- 프로토타이핑 라이브러리 **스크린**과 **컴포넌트**는 이제 다음과 같은 새로운 **기능**을 지원합니다:
  - 클릭스루 미리보기 모드.
  - AI 기반 스크린 생성.
  - 스크린샷에서 편집 가능한 목업.

:::note
*만약 **Enterprise 플랜을 사용 중이고 아직 Miro 프로토타입 베타에 등록되지 않은** 경우, 기존 라이브러리가 보일 수 있습니다.*
:::

### 작업에 미치는 영향

- 기존 와이어프레임은 안전하며 계속 작동합니다.
- 와이어프레임의 업데이트는 새로운 **프로토타입 라이브러리**를 사용해야 합니다.

## 자주 묻는 질문

**와이어프레임 라이브러리가 여전히 사용 가능한가요?**

아니요. 대부분의 구성 요소와 새로운 기능들이 포함된 프로토타입 라이브러리로 대체되었습니다. Enterprise 플랜에 등록되어 있지 않고 아직 Miro 프로토타입 베타에 등록하지 않은 경우, 기존 라이브러리를 여전히 볼 수 있을 수 있습니다.

**버튼이나 입력을 포함한 UI 요소들은 어떻게 되었나요?**

이제 프로토타입 라이브러리의 **와이어프레임 탭**에 있습니다.

**내 이전 와이어프레임은 여전히 작동하나요?**

네, 사용 중인 보드에 이미 있는 모든 것은 그대로 유지됩니다. 그러나 앞으로 계속 추가하거나 편집하려면 프로토타이핑 라이브러리를 사용해야 합니다.

**새 라이브러리에서 달라진 점은 무엇인가요?**

새로운 프로토타이핑 라이브러리에서는 AI 생성, 클릭을 통한 미리보기, 스크린샷에서 편집 가능한 목업, 업데이트된 비주얼을 지원합니다. 이는 팀이 아이디어에서 프로토타입으로 더 빠르게 진행할 수 있도록 설계되었습니다.

**와이어프레임 라이브러리처럼 Prototyping Library도 Free 플랜에서 계속 사용할 수 있나요?**

네. Prototyping Library (구 와이어프레임 라이브러리)의 UI 구성 요소를 포함한 기본적인 와이어프레임 도구는 모든 플랜에서 계속 사용할 수 있습니다. 대화형 미리보기 모드와 AI 기반 기능(예: 프롬프트에서 생성, 스크린샷에서 프로토타입 생성, AI 테마화)과 같은 고급 기능은 무료 베타가 종료된 후 Prototyping 애드온이 필요할 수 있습니다.
