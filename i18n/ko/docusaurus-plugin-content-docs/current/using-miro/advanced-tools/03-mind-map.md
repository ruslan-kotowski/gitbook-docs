[Miro 마인드맵](https://miro.com/mind-map-software/)을 사용하면 글로벌한 다이어그램 툴을 적용해 콘텐츠를 계층적이고 시각적으로 구성할 수 있습니다.

> **사용 가능 환경:** 브라우저 버전, [데스크톱 앱](../../getting-started/apps-for-devices/05-desktop-app.md), [태블릿 앱](../../getting-started/apps-for-devices/11-tablet-app.md), [모바일 앱](../../getting-started/apps-for-devices/08-mobile-app.md)(일부 기능 제한)

### Miro 마인드맵 만들기

작성 툴바에서 Miro Assist(베타) 사용하기

1. 작성 툴바에서 **마인드맵**을 찾습니다. 편하게 사용하기 위해 아이콘을 툴바로 드래그할 수 있습니다.![mindmap_on_the_toolbar.gif](https://help.miro.com/hc/article_attachments/21830621501202)*툴바의 마인드맵*
2. **마인드맵**을 선택하고 보드의 아무 곳이나 클릭해 마인드맵의 시작 지점인 상위 노드를 추가합니다. 각 측면에 있는 더하기 기호는 분기를 시작할 수 있고 하위 노드를 만들 수 있는 위치를 표시합니다. 수직 또는 수평 마인드맵을 만들 수 있습니다.![starting_a_mindmap.gif](https://help.miro.com/hc/article_attachments/21830610973202)*상위 노드 생성 및 수평 마인드맵 만들기*

다음 단축키를 사용해 제작 프로세스 속도를 높이세요.

- **Enter** 키로 형제 노드를 만들고 바로 편집을 시작할 수 있습니다.
- **Shift + Enter** 키로 노드 내에서 줄바꿈을 할 수 있습니다.
- **Tab** 키로 새 하위 노드를 만들 수 있습니다.
- **화살표** 키로 노드 간 이동할 수 있습니다.
- **Ctrl + C** 및 **Ctrl + V**(*Windows*)/**Cmd + C** 및 **Cmd + V**(*Mac*) 단축키로 노드를 복제할 수 있습니다.
- **Esc** 키로 편집 모드를 종료할 수 있습니다.
- **Delete** 키로 모든 노드를 삭제할 수 있습니다.
- **Ctrl**(*Windows*)/**Cmd**(*Mac*) 키를 누르면서 이동하면 자동 재할당을 중지할 수 있습니다.

노드를 선택하고 드래그해 캔버스에서 노드의 위치를 변경할 수 있습니다.

1. **CMD + K(Mac)** 또는 **CTRL + K(Windows)** 단축키를 눌러 커맨드 팔레트를 열거나 **메인 메뉴** 햄버거 아이콘을 클릭하고 **커맨드 팔레트**를 선택하세요.
2. **마인드맵 생성**을 클릭합니다.
3. 제안(예: *비행 앱의 사용자 경험 여정*)을 입력하거나 사전 작성된 예제 중 하나를 클릭하세요.
4. 마인드맵이 생성되고 보드에 추가됩니다. 결과에 만족한다면 **유지**를 클릭하세요.
   Miro Assist를 계속 사용해 노드를 원하는 만큼 확장할 수 있습니다.
   ![miro_assist_mind_map_command_palette.gif](https://help.miro.com/hc/article_attachments/14401241998738)
*Miro Assist로 커맨드 팔레트에서 마인드맵 만들기*

## 마인드맵 작업하기

원하는 만큼 노드를 마인드맵에 추가할 수 있습니다. 필요에 맞게 노드를 이동하거나 자동 레이아웃을 사용해 깔끔하게 표시할 수 있습니다. 하위 노드를 다른 상위 노드에 재할당하거나 노드를 모두 삭제할 수도 있습니다.

### 노드 이동, 크기 조정, 추가, 삭제하기

마인드맵에서 노드를 재정렬하면 모든 하위 노드가 자동으로 정렬됩니다. 이는 **자동 레이아웃**이 기본적으로 켜져 있기 때문입니다. 자동 레이아웃을 켜거나 끄려면 상위 노드를 클릭하고 컨텍스트 메뉴에서 **자동 레이아웃** 기능을 클릭해 전환하세요.

![image1.gif](https://help.miro.com/hc/article_attachments/21830610984722)*자동 레이아웃을 사용해 노드에 변경 사항 정렬하기*

**자동 레이아웃이 꺼져 있어도** 모든 하위 노드를 정렬할 수 있습니다. 마인드맵 구성을 완료한 후 상위 노드를 클릭한 다음 컨텍스트 메뉴에서 세 점 아이콘을 클릭하고 **노드 레이아웃**을 선택합니다.

![image2.gif](https://help.miro.com/hc/article_attachments/21830611007250)

하위 노드를 다른 상위 노드로 재할당하려면 노드를 드래그하기만 하면 됩니다.

:::note
노드를 재할당하는 대신 이동하려면 **Ctrl**(*Windows*)/**Cmd**(*Mac*) 키를 누른 채로 이동하세요.
:::

![reassign_nodes.gif](https://help.miro.com/hc/article_attachments/21830611010962)*노드 재할당하기*

복잡한 개념을 시각화할 때 노드 연결을 사용해 아이디어 간의 종속성을 마인드맵에 표시하세요.

![create_dependencies.gif](https://help.miro.com/hc/article_attachments/21830621525778)*노드 연결하기*

마인드맵을 [선택하고](../working-on-the-board/10-working-with-objects.md) 흰색 점을 드래그해 마인드맵의 크기를 변경할 수도 있습니다.

![changing_size.gif](https://help.miro.com/hc/article_attachments/21830621529874)*마인드맵 크기 변경하기*

노드에 텍스트를 추가하려면 노드를 두 번 클릭합니다.

:::note
노드 내에서 줄바꿈하려면 **Shift + Enter** 단축키를 사용하세요.
:::

노드에서 글머리 기호 목록을 만들려면 **-** 기호를 입력하고 스페이스바를 누르세요. 번호가 매겨진 목록을 만들려면 행의 시작 부분에 **1.**을 입력하세요.
두 번째(또는 세 번째/네 번째 등) 줄부터 글머리 기호 목록을 만들려면 **Cmd + Enter**(*Mac*) 또는 **Ctrl + Enter**(*Windows*) 단축키로 새 줄을 만드세요.

![adding_text_to_a_node.gif](https://help.miro.com/hc/article_attachments/21830621534226)*노드에 추가 텍스트 삽입하기*

노드를 삭제하려면 **삭제**를 누르거나 컨텍스트 메뉴에서 세 점 아이콘을 클릭하고 **삭제**를 선택하세요. 그러면 해당 노드와 그 하위 노드가 모두 삭제됩니다.

![delete_a_node.jpg](https://help.miro.com/hc/article_attachments/21830621536402)*노드 삭제하기*

:::warning
마인드맵 노드는 [잠그거나](../working-on-the-board/17-locking-content-on-the-board.md) [그룹화](../working-on-the-board/08-structuring-board-content.md)할 수 없습니다.
:::

### 마인드맵 요소 서식 지정하기

마인드맵의 스타일을 선택하고 방향을 변경할 수 있습니다. 노드는 곡선이나 직선 중 선택할 수 있습니다. 다채롭고 화려한 색상의 마인드맵을 만들려면 **무작위화** 툴을 사용하세요.

![changing_mind_map.gif](https://help.miro.com/hc/article_attachments/21830611037074)*마인드맵 스타일*

모든 마인드맵의 주요 구성 요소는 텍스트이므로 축소된 버전에서 다양한 텍스트 스타일 옵션을 적용할 수 있습니다. 마인드맵의 시각적 일관성을 유지하려면 상위 노드의 텍스트 크기를 변경해 마인드맵을 전체적으로 바꿔보세요.

![mind_map_font_size.gif](https://help.miro.com/hc/article_attachments/21830621542546)*마인드맵의 글꼴 크기 변경하기*

컨텍스트 메뉴에서 스타일 및 색상 변경, 텍스트 강조 표시, URL 추가 등의 다양한 옵션을 사용해 개별 노드를 변경할 수 있습니다. 현재 글꼴 변경은 불가능합니다.

![changing_a_node.gif](https://help.miro.com/hc/article_attachments/21830621545106)*노드 변경하기*

### 노드 유형 변경하기

노드의 시각적 스타일에는 다음과 같은 네 가지 유형이 있습니다.

- **없음** - 어떤 모양도 적용되지 않음
- **알약** - 타원형 알약 모양
- **둥근 직사각형** - 모서리가 둥근 직사각형 모양
- **직사각형** - 직사각형 모양

노드 유형 추가하기:

1. 유형을 바꿀 노드를 선택하세요.
2. 툴바에서 **노드 유형** 버튼을 클릭하세요.
3. 원하는 노드 유형을 선택하세요.
4. 스타일이 적용되고 노드가 분기와 동일한 색상으로 채워집니다.
5. 노드의 색상과 채우기 불투명도를 변경해 시각적 효과를 높일 수도 있습니다.
   ![mind_map_changing_node_type.gif](https://help.miro.com/hc/article_attachments/21830621549330)*노드 유형 및 색상 옵션 변경하기*

### 마인드맵 확장 및 축소하기

세부 사항까지 놓치지 않는 모든 크기의 마인드맵을 구축하세요. 분기를 확장 및 축소하면 다음과 같은 이점이 있습니다.

- 마인드맵의 전체적인 개요를 더 잘 파악할 수 있습니다.
- 작업하는 동안 적절한 수준의 세부 사항에 집중할 수 있습니다.
- 사용자가 마인드맵을 쉽게 탐색할 수 있도록 지원할 수 있습니다.
- 특정 수준의 세부 정보만 청중에게 표시할 수 있습니다.

**분기 축소 및 확장하기**

축소하려면 분기 위로 마우스를 가져가 빼기( **-** ) 버튼을 클릭하세요. 해당 분기에 첨부된 모든 댓글도 숨겨집니다.

분기를 축소하면 숨겨진 노드 및 댓글 수를 나타내는 숫자가 표시됩니다. 분기를 다시 확장하려면 숫자를 클릭하기만 하면 됩니다.

![Expand_and_collapse.gif](https://help.miro.com/hc/article_attachments/21830611050898)*마인드맵 분기 확장 및 축소하기*

### 마인드맵 내보내기

마인드맵을 이미지나 PDF 파일로 내보낼 수 있습니다. [이 페이지](../import-and-export/export/03-how-to-export-your-board.md)에서 내보내기 기능에 대해 자세히 알아보세요.

마인드맵을 이미지로 내보내려면 다음을 수행하세요.

1. **이 보드 내보내기** 아이콘을 클릭하세요. 아무 것도 선택하지 않아도 됩니다.
2. **이미지로 저장**을 선택하세요.
3. 드래그 핸들을 사용해 마인드맵을 선택하세요.
4. 원하는 크기를 선택하고 **내보내기**를 클릭하세요. 여기에서 PDF를 선택할 수도 있습니다.
5. 보드 이름과 동일한 이름의 파일이 로컬 하드 드라이브에 저장됩니다.
   ![main_menu_mindmap_export_image.gif](https://help.miro.com/hc/article_attachments/21830611053458)
*마인드맵을 이미지로 내보내기*

마인드맵을 PDF로 내보내려면 다음을 수행하세요.

1. **이 보드 내보내기** 아이콘을 클릭하세요. 아무 것도 선택하지 않아도 됩니다.
2. **PDF로 저장을 선택합니다.** 마인드맵에 아직 프레임이 없는 경우 생성하라는 메시지가 표시됩니다.
3. 프레임을 만들려면 팝업 상자에서 **프레임 만들기** 버튼을 클릭하세요. 왼쪽의 옵션에서 스타일을 선택합니다. 프레임 크기를 조정해 마인드맵을 모두 포함시킵니다.
4. **이 보드 내보내기**를 다시 클릭하고 **PDF로 저장하기**를 선택하세요.
5. 가장 적합한 PDF 옵션을 선택하고 **내보내기**를 클릭하세요.
   ![main_menu_mindmap_export_pdf.gif](https://help.miro.com/hc/article_attachments/21830621565970)
*마인드맵을 PDF 파일로 내보내기*

마인드맵을 선택하고 마우스 오른쪽 버튼을 클릭한 다음 **이미지로 복사**를 선택하면 전체 보드가 아닌 선택한 오브젝트만 복사됩니다. 이렇게 하면 마인드맵은 내보내지지 않지만 복사본이 보드에 배치됩니다.

## 자주 묻는 질문

최대 노드 수는 몇 개나 되나요?

생성할 수 있는 노드(상위 또는 하위) 수에는 제한이 없습니다.

노드를 이동/재할당할 수 있나요?

네, 노드를 드래그하기만 하면 됩니다.

노드에 이미지를 첨부할 수 있나요?

이미지를 노드에 연결하는 옵션은 없지만 백로그에서는 가능합니다.

마인드맵의 데이터를 인텔리전트 CSV 데이터로 내보낼 수 있나요?

네, [마인드맵 다운로더](https://miro.com/marketplace/mindmapdownloader/?backUrl=%2Fmarketplace%2F)를 사용하세요.

여러 노드가 동일한 하위 노드에 연결될 수 있나요?

[연결선](../essential-tools/05-connection-lines.md)을 사용해 하위 노드를 여러 개의 상위 노드에 연결할 수 있습니다.

마인드맵을 다른 Miro 보드에 복사할 수 있나요?

네, 다른 콘텐츠와 마찬가지로 복사하고 붙여넣을 수 있습니다. 상위 노드를 선택하고 컨텍스트 메뉴에서 세 점 아이콘을 클릭한 다음 **복사**를 선택한 뒤 다른 보드에 해당 위젯을 붙여넣으세요. **[Ctrl + C/Ctrl + V](../working-on-the-board/06-shortcuts-and-hotkeys.md)**[*(Windows)*](../working-on-the-board/06-shortcuts-and-hotkeys.md) **[또는 Cmd + C/Cmd + V](../working-on-the-board/06-shortcuts-and-hotkeys.md)***[(Mac)](../working-on-the-board/06-shortcuts-and-hotkeys.md)* 단축키를 사용해도 됩니다. 보드 소유자가 [보드 콘텐츠를 복사하도록 허용](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)했는지 꼭 확인하세요.

보드 위에서 전체 마인드맵을 이동시키려면 어떻게 해야 하나요?

상위 노드를 선택하고 이동하세요.

개별 하위 노드의 텍스트 크기를 변경할 수 있나요?

아니요, 현재는 상위 노드의 텍스트 크기만 변경할 수 있으며 이를 변경하면 전체 마인드맵의 크기도 변경됩니다.

[스티커 메모](../essential-tools/14-sticky-notes.md), [텍스트 블록](../essential-tools/16-text.md), [카드](../essential-tools/02-cards.md) 및 기타 위젯을 마인드맵 노드로 변환할 수 있나요?

아니요, 현재는 불가능합니다. 스티커 메모/카드/텍스트 블록에서 텍스트를 복사해 노드에 붙여넣을 수는 있습니다.

기존 두 노드 사이에 노드를 삽입하려면 어떻게 해야 하나요?

노드 중 하나를 다른 노드로 일시적으로 재할당하고, 새 노드를 만든 다음 노드를 다시 재할당하세요.
