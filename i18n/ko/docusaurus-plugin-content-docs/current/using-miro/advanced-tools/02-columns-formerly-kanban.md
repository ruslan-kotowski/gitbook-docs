우리의 [칸반 프레임워크](https://miro.com/templates/kanban-framework/)를 사용하여 워크플로를 시각화하고 팀으로서 더 많은 작업을 완료하세요. Miro의 칸반은 애자일 개발에서 개인 작업 추적에 이르기까지 다양한 도입 사례에서 사용할 수 있습니다.

## 칸반 추가하기

보드에 칸반을 추가하려면 **툴, 미디어 또는 통합** (![icon-tools.svg](../../../../../../docs/using-miro/advanced-tools/images/29029892260754_icon-tools.svg))에서 선택하거나 툴바에서 선택하고 필요한 위치에 보드를 클릭합니다.

칸반의 크기는 가장자리를 드래그하여 조정할 수 있습니다.

## 열 및 스윔레인

칸반에서 열과 스윔레인을 추가하고 정리하려면 다음을 수행하세요:

1. 칸반을 클릭하여 컨텍스트 메뉴를 여세요.
2. 칸반에 추가하려면 **열 추가** 또는 **스윔레인 추가** 아이콘을 클릭하세요.
   열은 오른쪽에, 스윔레인은 아래쪽에 추가됩니다.
3. 세 **점 아이콘** (**...**)을 클릭하고 필요한 **이동** 방향을 선택하여 열이나 스윔레인을 재배치하세요.
4. 열 제목을 두 번 클릭하여 이름을 변경하세요.

세 **점 아이콘** (**...**) 메뉴에서 열과 스윔레인을 추가, 이동, 이름 변경, 삭제하거나 열의 색상을 변경할 수 있습니다.

## 카드

:::tip
[Miro 카드](../essential-tools/02-cards.md)에 대해 더 알아보기
:::

카드를 추가하려면 [카드](../essential-tools/02-cards.md)의 더하기 아이콘을 스윔레인 내에서 클릭하세요. 또는 보드에서 기존 카드를 끌어와 칸반에 두세요.

카드를 드래그하여 다른 열/스윔레인으로 이동하세요.

:::warning
칸반 내의 카드는 [잠글 수](../working-on-the-board/17-locking-content-on-the-board.md) 없고 [그룹화할 수도](../working-on-the-board/08-structuring-board-content.md) 없습니다.
:::

 단축키를 사용해 작업 속도를 높이세요: [단축키](../working-on-the-board/06-shortcuts-and-hotkeys.md):

- **Enter/Return** 키를 눌러 새 카드를 만드세요
- **Tab** 키를 눌러 해당 열의 다음 카드로 이동하세요
- **Tab** + **Shift** 키를 눌러 해당 열의 이전 카드로 이동하세요
- **←→****↑↓** 키로 카드를 선택하세요
- **Ctrl** + **C** 및 **Cmd** + **V** (*Windows의 경우*), **Cmd + C** 및 **Cmd + V** (*Mac의 경우*) 키로 카드를 복제하세요
- **Ctrl + ↑↓** (*Windows의 경우*), **Cmd + ↑↓** (*Mac의 경우*) 키로 위쪽 또는 아래쪽에 새 카드를 추가하세요
- **Escape** 키로 편집 모드를 종료하세요

## 자주 묻는 질문

**칸반에 이미지를 추가할 수 있는 옵션이 있나요?**

아니요, [카드](../essential-tools/02-cards.md)만 추가할 수 있습니다.

**칸반에 [Jira 카드](../../integrations-apps/atlassian/03-jira-cards.md)를 추가할 수 있나요?**

네, [Asana 카드](../../integrations-apps/asana/01-asana-cards-legacy.md)나 [Azure 카드](../../integrations-apps/microsoft/03-azure-cards.md)처럼 Jira 카드를 추가할 수 있습니다. Jira 카드를 설정하는 방법을 알아보려면 [이 페이지](../../integrations-apps/atlassian/12-deprecated-–-set-up-and-disable-jira-cards-using-oauth-1.0.md)를 확인하세요.

**카드 기한 날짜에 따라 자동으로 알림을 받을 수 있나요?**

아니요, 현재는 지원되지 않습니다.
