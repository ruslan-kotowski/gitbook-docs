Miro 표는 보드 콘텐츠를 빠르고 효율적으로 정리할 수 있도록 도와줍니다.

- 위젯과 텍스트를 사용해 시각적인 표를 만들어 보드 콘텐츠를 정리하세요.
- 쉽게 편집 가능한 전문적인 템플릿을 디자인하여 반복 가능한 프로세스를 구현하세요.

> **사용 가능 환경:** 브라우저,데스크톱 앱, 태블릿 앱

## 표 사용 방법

1. 보드 왼쪽의 [제작 툴바](../../getting-started/start-here/your-first-board/05-toolbars.md)로 이동하세요.
2. **툴, 미디어, 통합** 아이콘 (![icon-zoom-in.svg](https://help.miro.com/hc/article_attachments/28749603852690))을 클릭하고 **표**를 검색하세요.
3. **표 앱**을 엽니다. 빠르게 액세스하려면 표 앱을 클릭하고 작성 툴바로 드래그할 수도 있습니다.

보드에 표를 추가하려면 작성 툴바에서 표 아이콘을 클릭하고 보드에서 원하는 위치를 클릭하세요.

툴바에서 표의 크기를 바로 선택할 수 있습니다. 표당 최대 셀 수는 2,500개입니다.

## Excel 파일을 표로 변환

1. Miro 보드 열기
2. 작성 툴바에서 **툴, 미디어, 통합** 아이콘(**+**)을 클릭하세요.
   툴, 미디어, 통합 패널이 열립니다.
3. 검색하여 **업로드**를 선택하세요.
   업로드 패널이 열립니다.
4. **내 기기**를 선택하세요.
5. 업로드하려는 Excel 파일(.xlsx)로 이동하여 선택하세요.
6. 또는 Excel 파일을 보드에 끌어다 놓아 업로드하세요.
7. 옵션이 있는 모달이 열립니다:
   1. 테이블로 변환
   2. 표로 변환
   3. 파일로 추가.
8. **표로 변환**을 선택하세요.
9. **선택**을 클릭하세요.
10. Excel 파일의 데이터를 사용하여 보드에 표가 생성됩니다.

:::warning
Excel 파일을 업로드할 때, 최대 500개의 행과 30개의 열 제한이 있습니다.
:::

## 표와 상호 작용하기

- 한 번 클릭하면 전체 표를 선택할 수 있습니다.
- 한 번 더 클릭하면 하나의 셀을 선택할 수 있고, 클릭한 채로 드래그하면 여러 셀을 선택할 수 있습니다.
- 세 번 클릭하면 셀 안의 텍스트를 편집할 수 있습니다. 또는 셀을 연속으로 두 번 클릭해도 편집할 수 있습니다.

## 표 이동 또는 크기 조정하기

표를 이동하려면 한 번 클릭해 전체를 선택한 다음 보드 위로 드래그합니다.

표 크기를 조정하려면 한 번 클릭해 전체를 선택한 다음 모서리 쪽으로 드래그합니다.

## 콘텐츠 추가

스티커 메모, 도형, 카드, 이미지 등의 콘텐츠를 표에 추가하려면 콘텐츠를 표 위로 드래그하세요. 셀 크기는 콘텐츠에 맞게 자동 조정됩니다.

표 안에 다른 표를 추가할 수는 없습니다.

![adding_content_greybg.gif](https://help.miro.com/hc/article_attachments/21574820157586)*표에 콘텐츠 추가하기*

자동 크기 조정 기능은 기본적으로 켜져 있습니다. 기능을 끄려면 컨텍스트 메뉴에서 **셀 크기 조정** > **수동**을 클릭하거나, 오브젝트를 표 위로 드래그하는 동안 **Ctrl/Cmd**를 누르세요. 다시 켜려면 **셀 크기 조정** > **자동**을 클릭합니다.

:::warning
표 내 콘텐츠는 [잠금](../working-on-the-board/17-locking-content-on-the-board.md) 또는 [그룹화](../working-on-the-board/08-structuring-board-content.md)할 수 없습니다. [오브젝트 정렬 버튼](../working-on-the-board/08-structuring-board-content.md) 및 [자동 레이아웃 옵션](../working-on-the-board/08-structuring-board-content.md)은 표 내에서 사용할 수 없습니다.
:::

## 열 및 행

:::note
열이나 행, 셀을 선택할 수 없는 경우 [선택 모드](../working-on-the-board/21-work-smarter-not-harder.md)를 켜고 확대해보세요. 많은 작은 셀들은 높은 줌 레벨에서 편집이 불가능합니다.
:::

열 또는 행을 추가하려면 다음 작업을 수행할 수 있습니다.

- 컨텍스트 메뉴에서 **열 추가** 또는 **행 추가** 아이콘을 클릭합니다.
- 표의 오른쪽 또는 하단에 있는 **더하기 아이콘** (![icon-zoom-in.svg](https://help.miro.com/hc/article_attachments/28749603852690))을 사용합니다.
- 열이나 행 옆에 표시되는 세 점 아이콘 옆의 더하기 아이콘을 클릭합니다.

세 점 아이콘을 끌어다 놓아 표의 열과 행 위치를 조정합니다.

![moving_a_row_greybg.gif](https://help.miro.com/hc/article_attachments/21574820163730)*위로 행 이동하기*

## 색상 및 크기 사용자 지정하기

열, 행, 셀의 색상을 변경하려면 행이나 열 옆에 있는 세 점 아이콘을 클릭하고 드롭다운 메뉴에서 색상을 선택하세요.

셀, 행, 열 또는 전체 표의 색상을 변경할 수 있습니다.

열 또는 행의 너비를 조정하려면 테두리를 클릭한 채로 드래그합니다. [선택 모드](../working-on-the-board/05-using-miro-with-a-mouse-trackpad-or-touchscreen.md)가 켜져 있는지 확인하세요.

![chaning_the_row_width_greybg.gif](https://help.miro.com/hc/article_attachments/21574820167058)*행 크기 조정하기*

모든 행이나 열의 크기를 함께 조정하려면 전체 표를 선택하고 테두리를 드래그합니다.

열 또는 행을 삭제하려면 근처에 표시되는 세 점 아이콘을 클릭한 다음 컨텍스트 메뉴에서 휴지통 아이콘을 클릭합니다.

## 셀 병합하기

셀을 병합하려면 셀을 선택하고 컨텍스트 메뉴에서 **셀 병합**을 선택합니다. 셀은 언제든지 병합 해제할 수 있습니다.

![merge_and_unmerge_cells_greybg.gif](https://help.miro.com/hc/article_attachments/21574848914450)*표에서 셀 병합 및 병합 해제*

## 텍스트 작업하기

텍스트를 추가하려면 셀을 두 번 클릭하고 입력을 시작하세요. 기존 텍스트를 변경하려면 셀을 두 번 클릭합니다. 텍스트의 크기, 색상, 정렬을 조정하고, 글머리 기호 목록을 만들 수 있습니다.

표에 수직 방향 텍스트를 추가하려면 컨텍스트 메뉴에서 수직 방향 텍스트를 선택합니다.

![vertical alignment.png](https://help.miro.com/hc/article_attachments/21574820172562)*텍스트 수직 정렬*

전체 표 또는 전체 행이나 열의 텍스트 서식을 변경할 수 있습니다.

:::note
모든 셀에는 기호를 최대 6,000개까지 입력할 수 있습니다. 이 개수 제한에는 공백과 모든 스타일 변경으로 인한 코드도 포함되므로 텍스트 서식을 변경하면 입력할 수 있는 기호의 개수가 줄어들 수 있습니다.
:::

:::note
텍스트에 링크를 삽입하려면 텍스트를 선택하고 **Ctrl** + **V** (*Windows용*) 또는 **Cmd + V** (*Mac용*)를 누르세요.
:::

:::tip
[단축키](../working-on-the-board/06-shortcuts-and-hotkeys.md)를 사용해 작업 속도를 높이세요:
**- Ctrl** + **B** (*Windows용*) 또는 **Cmd + B** (*Mac용*): 텍스트 굵게 만들기
**- Ctrl + I** (*Windows용*) 또는 **Cmd + I** (*Mac용*): 텍스트 기울임꼴로 만들기
**- Ctrl + U** (*Windows용*) 또는 **Cmd + U** (*Mac용*): 텍스트에 밑줄 추가하기
**- 화살표**(*Mac용*): 셀 간 이동하기
:::

## Microsoft Excel 또는 Google 스프레드시트에서 가져오기

스프레드시트에서 Miro 보드로 콘텐츠 가져오기

1. 스프레드시트에서 셀을 복사합니다.
2. 보드를 열고 **Ctrl + V** *(Windows)* 또는 **Cmd + V** *(Mac)*를 누릅니다.
3. 콘텐츠를 [스티커 메모](../essential-tools/14-sticky-notes.md)나 표로 붙여넣을 수 있습니다. **표로 붙여넣기**를 선택합니다. 2,500개 이상의 셀이 있는 테이블을 복사할 때는 행보다 열에 우선순위가 부여됩니다.

또한 스프레드시트에서 셀을 복사한 다음 기존 Miro 표에서 셀을 선택하고 **Ctrl + V** *(Windows)* 또는 **Cmd + V** *(Mac)을 누릅니다.* 그러면 스프레드시트의 콘텐츠가 표에 복사됩니다.
