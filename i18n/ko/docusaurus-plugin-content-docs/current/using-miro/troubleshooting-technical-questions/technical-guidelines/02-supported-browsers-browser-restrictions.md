이 문서는 Miro에서 지원하는 데스크톱 및 모바일 브라우저에 관한 정보를 제공합니다.

:::note
Miro는 주요 브라우저의 모든 버전을 최소 12개월 동안 지원하며, 활성화된 장기 지원 릴리스도 포함됩니다. 이전 브라우저 버전은 개발자 지원이 종료되었을 수 있으며, 이는 Miro 사용 경험에 영향을 미칠 수 있습니다. 최적의 Miro 경험을 위해서는 브라우저를 최소 1년에 한 번 업데이트하세요.
:::

Miro에서 공식적으로 지원하는 브라우저는 다음과 같습니다:

- **데스크톱**
  - Chrome
  - MS Edge
  - Firefox
  - Opera
  - Yandex Browser
- **모바일**
  - Chrome
  - Safari
  - Samsung Internet

:::note
모바일 브라우저에서 접속한 보드는 보기 전용입니다. 할당된 권한으로 접근하려면 [Miro 모바일 앱](../../../getting-started/apps-for-devices/08-mobile-app.md)을 다운로드하세요.
:::

:::warning
인터넷 익스플로러는 지원하지 않습니다.
:::

## Safari에서 보드 로딩 문제

Safari v. 15.2, OS Monterey에서 보드가 멈추거나 로딩되지 않는 문제가 발생할 경우 아래의 단계를 따라주세요 ("*문제가 발생하여 웹 페이지가 다시 로드되었습니다*" 또는 "*이 웹 페이지와 다른 페이지 하나가 응답하지 않습니다*"라는 오류 메시지를 받을 수 있습니다):

1. Safari > 환경설정 > **개발자** > **실험적 기능** 으로 이동하세요.
2. **GPU 프로세스: 캔버스 렌더링** 기능을 **끄세요.**

   ![](/attachments/token/45hImX8u1weQZnUaPOXtAT971/?name=inline1581405683.png)

   > ✏️ ​개발자 **메뉴** 가 [메뉴 막대](https://support.apple.com/en-gb/guide/safari/aside/glos33eb8abd/15.1/mac/12.0) 에 보이지 않는 경우, Safari > 환경설정으로 이동하여 **고급** 을 클릭한 다음 **메뉴 막대에서 개발자 메뉴 보기**를 선택하세요.
