Miro는 팀워크를 위해 구축되었으며 많은 사용자가 하나의 보드에서 함께 효과적으로 작업할 수 있도록 합니다. 이 섹션에서는 많은 참여자와 협업할 때 예상할 수 있는 사항을 설명합니다.

Miro는 협업을 위해 만들어졌으며 동일한 보드에서 여러 사용자가 안정적으로 작업할 수 있도록 지원합니다.

우리의 주요 사용 사례 중 일부는 PI 계획 및 워크숍으로, 몇백 명의 참여자가 포함될 수 있습니다. 따라서 대규모 협업을 위해 지속적으로 성능을 최적화하고 있습니다.

지금까지 주최한 가장 큰 세션에는 377명의 사용자가 참여했습니다. 이 경우는 조금 극단적일 수 있지만, 보드는 정상적으로 운영되었고 협업이 성공적으로 이루어졌습니다. 우리가 매주 거의 자주 보는 더 일반적인 시나리오는 **약 200명의 사용자(편집자/댓글 작성자)가** 동시에 같은 보드에서 작업하는 것입니다.

저희 앱은 정기적으로 더 많은 사용자 수로 테스트하지만, 공동 작업자가 300명을 초과할 경우 모든 사용자의 경험이 원활할지에 대해서는 아직 조심스럽습니다.

보드는 사용자 수가 증가하거나 사용자 활동이 집중적으로 이루어질 때 점진적으로 느려질 수 있음을 고려하십시오. 오래되고 성능이 낮은 장치를 사용하는 참여자는 더 빨리 속도가 느려질 것입니다.

## 귀하의 경험을 최적화하고 최신 정보를 유지하세요.

대규모 협업 세션 동안 최상의 성능을 보장하고 지속적인 최적화 정보에 대해 숙지하려면 다음 리소스를 참고하세요.

[협업 세션 동안 성능을 개선하는 방법](../../tools/troubleshooting/04-board-performance-and-loading-issues.md)에 대한 팁을 꼭 확인하세요.

성능을 최적화하며 이 문서를 업데이트하겠습니다.
