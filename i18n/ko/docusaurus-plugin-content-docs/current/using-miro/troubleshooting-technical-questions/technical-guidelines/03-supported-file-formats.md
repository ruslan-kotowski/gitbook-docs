다음 파일 포맷으로 Miro에 콘텐츠를 업로드할 수 있습니다:

| 파일 유형 | 파일 포맷 |
| --- | --- |
| 이미지 | **bmp**, **gif**, **svg**(고체 이미지로), **jpeg**, **jpg**, **png**, **psd**, **heic, heif**, **pdf** |
| 테이블 및 스프레드시트 | **xls, xlsx, csv**, **ods** |
| 텍스트 문서 | **doc**, **docx**, **odt, rtf** |
| 발표 자료 | **ppt, pptx, odp** |
| 동영상 | **MP4, MOV, WebM** |

모든 소스에서 파일은 최대 30MB까지 업로드할 수 있습니다. 모든 소스에서 이미지의 최대 해상도는 32MP입니다. 이미지의 최대 크기 제한은 8192x4096 픽셀입니다.

파일을 보드에 업로드하는 방법 알아보기: [보드에 파일 업로드하기](../../import-and-export/import/05-uploading-files-to-boards.md), [콘텐츠 추가 방법](../../working-on-the-board/07-ways-to-add-content.md).

PDF 파일을 업로드하는 데 문제가 있는 경우, [이 문제 해결 가이드](../../import-and-export/import/05-uploading-files-to-boards.md)를 확인하세요. 다른 종류의 파일을 업로드하는 데 문제가 있을 경우, [이 문제 해결 단계](../../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md)를 참조하세요.

:::tip
**PDF 파일**을 업로드할 때 [페이지 넘기기 또는 페이지별 보기](../../working-on-the-board/21-work-smarter-not-harder.md) 옵션을 사용할 수 있습니다.
:::

:::tip
**Google 문서**(스프레드시트, 문서, 슬라이드)를 [Google Drive 통합](../../../integrations-apps/google/05-google-drive.md)을 통해 가져오고 보드에서 바로 편집할 수 있습니다.
:::

:::tip
**스프레드시트**를 가져오는 여러 가지 방법이 있습니다: [업로드 메뉴](../../import-and-export/import/05-uploading-files-to-boards.md)를 통해 가져오거나, [스티커 메모](../../essential-tools/14-sticky-notes.md)로 가져오거나, [Miro 테이블](../../advanced-tools/05-grid.md)로 가져올 수 있습니다.
:::

:::tip
**SVG** 이미지를 사용할 때 텍스트를 선으로 변환하여 공동 작업자들이 사용하는 기기에 설치된 글꼴에 따라 파일의 시각적 요소가 달라지지 않도록 하세요.
:::

## 플랜별 동영상 업로드

[동영상 업로드](../../essential-tools/01-video-upload-and-playback-beta.md)는 현재 Business 및 Education 플랜, 베타 기능이 활성화된 Enterprise 구독에서 사용 가능한 베타 기능입니다.

Free 플랜의 멤버들은 베타 기간 동안 동영상을 업로드할 수 있습니다. 베타가 종료되면 Free 멤버들은 베타 기간 동안 업로드된 동영상을 계속 시청할 수 있지만, 업그레이드하지 않으면 새로운 동영상을 업로드할 수 없습니다.

**추가 정보:** [동영상 업로드 및 재생 (BETA)](../../essential-tools/01-video-upload-and-playback-beta.md)를 참조하세요.

## 자주 묻는 질문

Miro에서 투명 PNG 이미지를 업로드할 수 있나요?

네, 투명 이미지를 보드에 업로드할 수 있습니다.

애니메이션 GIF가 Miro 보드에서 표시되나요?

네, [GIF](../../working-on-the-board/21-work-smarter-not-harder.md)에 대해 자세히 알아보세요.

Miro에 ZIP 포맷을 업로드할 수 있나요?

아니요, 파일을 Miro에 업로드하기 전에 압축을 해제해야 합니다. 페이지 상단의 지원되는 파일 포맷 목록을 참조하세요.

Miro 보드에 PDF를 임베드한 후 원본 PDF를 변경하면 임베드된 버전이 자동으로 업데이트됩니까?

아니요. 업로드된 데스크탑 또는 클라우드 기반의 PDF 파일과 Miro 간의 연결은 단방향입니다. 변경 사항이 있으면 PDF를 다시 임베드해야 합니다.

Mac의 Keynote, Pages, Numbers 포맷을 Miro 보드로 가져올 수 있습니까?

지원 파일 목록에 이 포맷들은 포함되어 있지 않지만, 워크어라운드로 Powerpoint/Word/Excel 포맷으로 내보내기하여 Miro에 파일을 드래그할 수 있습니다. *파일* > *내보내기* > *Powerpoint...*를 클릭하여 파일을 내보낸 후, Miro로 파일을 드래그하세요.
