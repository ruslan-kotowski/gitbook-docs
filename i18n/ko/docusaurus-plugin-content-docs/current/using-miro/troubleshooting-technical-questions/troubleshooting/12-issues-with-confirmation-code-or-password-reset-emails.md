확인 코드나 비밀번호 초기화 이메일을 받지 못했다면 여러 가지 이유가 있을 수 있습니다. 아래의 정보는 시도해볼 수 있는 옵션을 제공하고 있으며, 이러한 문제 상황을 해결하는 데 도움이 될 수 있습니다.

## 코드나 이메일이 도착하지 않는 일반적인 이유

비밀번호 초기화 이메일을 받지 못하거나 새 확인 코드를 요청할 수 없는 가장 일반적인 두 가지 이유는 다음과 같습니다.

1. 회사에서 방화벽을 사용하고 있으며, 방화벽이 miro.com 도메인의 이메일을 차단하고 있습니다. IT 관리자에게 [miro.com](http://miro.com/) 도메인의 이메일을 허용하도록 요청하세요. 본인이 관리자인 경우 아래 섹션에서 Miro의 도메인을 허용 목록에 추가하는 방법에 대한 지침을 확인하세요.
2. 회사에서 SSO를 사용하고 있습니다. 이 문제를 해결하는 방법에 대한 지침은 아래 섹션을 참고하세요.

## 이메일/확인 코드 분실 문제 해결하기

1. 회사에서 SSO를 사용하는 경우 회사 SSO 신원 정보로 로그인해야 합니다. Miro로 비밀번호를 초기화하려고 하면 SSO 로그인 페이지로 다시 리디렉션될 것입니다. 이 경우 회사 SSO 신원 정보를 사용해보세요. 그래도 문제가 해결되지 않으면 아래 내용을 읽고 문제 해결을 계속 진행하세요.
2. 방화벽으로 인해 이메일이 받은 편지함에 도착하지 못할 수 있습니다. 시스템 관리자에게 문의해 다음 도메인을 허용하도록 요청하세요. Miro 도메인 및 하위 도메인: miro.com*, *.miro.com, mirostatic.com*, *.mirostatic.com, realtimeboard.com*, *.realtimeboard.com

   전용 IP 목록: 198.2.178.132, 198.2.178.117, 198.2.128.203, 198.2.178.252, 198.2.178.205 [Miro 이메일 허용 목록](../../tools/troubleshooting/02-allowlist-miro-mailers.md)에 대해 자세히 알아보세요.
3. 입력한 이메일에 오타가 없는지 확인합니다. 오타가 있는 경우 [프로필을 다시 등록](../../../getting-started/start-here/02-how-to-register-with-miro.md)하거나 올바른 이메일 주소를 사용해 비밀번호를 초기화하세요.
4. 이메일 공급자의 **스팸, 프로모션,** **정크, 소셜**, **업데이트** 폴더를 확인하세요.
5. Google, Slack, Office 365, Apple, Facebook과 같은 대체 가입/로그인 옵션을 사용해 등록하거나 로그인할 수도 있습니다.
   > ⚠️ 대체 로그인은 회사 SSO 로그인과 연결되어 있지 **않습니다**. 회사 환경에서 Miro를 사용하고 있다면 Miro 관리자가 설정한 신원 정보를 사용하세요.

   ![새_로그인_서드파티.png](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21017725436050_new-sing-in-third-party.png)
   *사용 가능한 인증 방법*

다른 인증 방법으로 가입하거나 로그인할 수 없는 경우 다음 항목을 확인하세요.

- 받은 편지함이 가득 찼거나 이메일 저장 한도에 도달하지 않았는지 확인하세요. 저장 공간이 가득 찬 경우 새 이메일을 받으려면 일부 이메일을 삭제해야 할 수 있습니다. 이메일을 삭제한 후 등록 페이지로 돌아가서 **코드 다시 보내기**를 클릭하세요.
- 그러면 즉시 이메일을 받을 수 있습니다. 이메일이 바로 오지 않는다면, 최대 24시간까지 기다려야 할 수 있습니다.
- 회사 SSO 신원 정보를 사용하고 있는데 로그인할 수 없는 경우 [일반적인 SSO 오류 및 해결 방법](../../tools/troubleshooting/10-i-can't-log-in-via-sso.md)을 읽어보세요.

### 기타 확인 문제

코드가 유효하지 않습니다

입력한 코드가 **유효하지 않은 경우** 다음 항목을 확인하세요.

1. 받은 편지함을 확인하고 가장 최근에 받은 코드를 입력했는지 확인합니다. 코드가 여전히 유효하지 않은 경우 **코드 다시 보내기**를 클릭하고 새로 온 이메일의 코드를 입력하세요.
2. 등록을 완료하는 또 다른 방법은 확인 코드가 있는 이메일에서 **이메일 확인**을 클릭하는 것입니다. 이 경우 확인 코드가 필요하지 않습니다.
   ![이메일 확인 버튼.png](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21017725339026_confirm%20email%20button.png)
   *이메일 확인 옵션*

이메일 확인 시도 횟수가 초과되었습니다

이메일 확인을 4번 시도한 후에도 실패한 경우 등록 페이지에 **이메일 확인 시도 횟수가 초과되었습니다**라는 메시지가 표시됩니다.

60초 동안 기다린 후 **코드 다시 보내기**를 클릭합니다. 그러면 새 코드가 생성됩니다. 코드를 입력하고 등록을 완료합니다.

실수로 확인 코드를 입력했던 탭을 닫았습니다

등록할 때 입력한 이메일과 비밀번호를 사용해 [로그인](https://miro.com/login/)하면 [확인 페이지](https://miro.com/email-confirm/)로 다시 리디렉션됩니다.

:::note
이메일을 확인하지 않으면 12시간 후와 24시간 후에 알림을 받게 됩니다. 7일 이내에 이메일을 확인하지 않으면 **프로필이 삭제됩니다**. 동일한 이메일 주소를 사용해 새 프로필을 등록할 수 있습니다.
:::

:::note
확인 코드는 이메일로만 전송됩니다.
:::

:::note
계속 문제가 발생하면 [Miro 지원에 문의](https://miro.com/contact/recover/)하세요.
:::
