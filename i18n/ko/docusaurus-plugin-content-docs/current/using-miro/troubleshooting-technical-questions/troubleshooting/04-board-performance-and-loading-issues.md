협업 세션과 대형 보드에서 보드 성능을 개선하는 팁에 대해 살펴보고, 성능 및 조작성 저하, 보드 멈춤 현상, 무한 로딩 등의 문제를 해결하세요.

## 보드 성능 개선하기

많은 사용자가 참여하는 **협업 세션**뿐만 아니라 많은 콘텐츠가 포함된 **대형 보드**에서도 보드 성능이 저하될 수 있습니다.

협업 세션 진행 팁 대형 보드 사용 팁

보드의 사용자 수가 증가하고 활동이 집중되면 보드 성능에 영향을 미칠 수 있습니다. 오래되고 성능이 낮은 장치를 사용하는 경우에는 성능 저하를 겪을 위험이 더 높습니다.

**협업 세션에 참여할 때 다음 사항을 확인하세요.**

- [데스크톱 브라우저](../technical-guidelines/02-supported-browsers-browser-restrictions.md)에서 보드 열기
- 불필요한 탭 및 창 닫기
- 공동 작업자 커서 숨기기 및 모든 사이드바 닫기

  *![커서_및_툴바_숨기기.gif](images/21301614217234_hiding%20cursors%20and%20toolbars.gif)
  공동 작업자 커서 및 툴바 숨기기*
- 여러 보드 오브젝트를 동시에 선택하거나 변경하지 않기
- 보드 간 탐색 최소화
- 노트북에서 Miro를 사용하는 경우 절전 모드 대신 고성능 모드를 사용 중인지 확인

**Miro에서 협업 세션을 계획하고 있다면 다음 사항을 확인하세요.**

- 편집 액세스 권한이 필요하지 않은 사용자는 뷰어로 초대하세요. 보드 액세스 권한을 설정하는 방법은 [여기](../../sharing-boards/01-board-access-rights.md)에서 확인할 수 있습니다.
- 보드 콘텐츠를 깔끔하게 정리하세요. 관련 지침을 보려면 위의 두 번째 탭에 있는 **대형 보드 사용 팁**을 읽어보세요.

보드에 추가할 수 있는 최대 오브젝트 수는 100,000개입니다. 오브젝트 수 1,000개부터 성능에 영향을 미칠 수 있으므로 더 쾌적한 경험을 위해 보드의 오브젝트 수를 5,000개 미만으로 유지하는 것이 좋습니다.

**보드 오브젝트 수 확인하기**

- 보드의 모든 오브젝트를 선택합니다. Windows에서는 ctrl-A, Mac에서는 cmd-A를 사용하세요. 또는 선택 상자를 드래그해 모든 오브젝트를 선택할 수 있습니다.
- 선택을 완료하면 오브젝트 수를 나타내는 컨텍스트 메뉴가 표시됩니다.
- **필터**를 클릭해 유형별 오브젝트 수를 확인하세요.

![보드에_있는_오브젝트의_수.gif](images/21301605536402_Number%20of%20objects%20on%20the%20board.gif)
*보드에 있는 오브젝트의 수 측정하기*

오브젝트 수 외에도 용량이 크거나, 업로드된 파일과 문서 등 복잡한 오브젝트도 보드 조작 속도를 저하시킬 수 있습니다.

**대형 보드 성능 가속화를 위해 보드 정리하기**

- 불필요한 콘텐츠, 특히 대용량으로 업로드된 파일 및 문서(예: 세부 정보가 많은 벡터 PDF나 고해상도 이미지)를 삭제합니다.
- 대용량 PDF와 고해상도 이미지를 PNG/JPG 파일로 변환하고 보드에 다시 업로드합니다.
- 보드 콘텐츠를 100%로 확대/축소했을 때 너무 크게 보이면 다음 방법으로 축소하세요.

- 오른쪽 하단 모서리의 맵으로 이동한 다음 확대/축소 수준을 100%로 설정합니다.
- 100% 설정에서 너무 크게 보이는 경우 **CTRL + A**(Windows) 또는 **Cmd + A**(Mac)를 사용해 콘텐츠를 선택한 다음 축소합니다.
- 큰 이미지 축소도 고려하세요.

  *![콘텐츠_크기_축소하기.gif](images/21301605537810_downscaling%20content.gif)**콘텐츠 크기 축소하기*

- [댓글을 해결 처리](../../facilitation-tools/asynchronous-tools/01-comments.md)합니다.
- 다음 방법으로 [펜](../../essential-tools/10-pen.md) 필기를 이미지로 변환합니다.

- 펜으로 그린 그림의 스크린샷을 만드세요.
- 보드에 스크린샷을 업로드하세요.
- 처음 그림을 삭제합니다.

- 가능한 경우 다음 방법으로 보드를 여러 개로 분할합니다.

- 보드 콘텐츠 일부를 선택하고 **Ctrl + C**(Windows) 또는 **Cmd + C**(Mac) 키를 눌러 복사하세요.
- [새 보드를 만들고](../../../getting-started/start-here/your-first-board/01-create-a-miro-board.md) 보드에 콘텐츠를 붙여넣으세요.
- 원본 보드에서 복사한 콘텐츠를 삭제합니다.

## 성능 저하 또는 무한 로딩 문제 해결하기

장치, 인터넷 연결, 브라우저, 기타 요인이 보드 성능과 로드 속도에 영향을 미칠 수 있습니다. 성능 저하가 발생하거나 보드 또는 대시보드가 브라우저, 데스크톱 앱, 태블릿 또는 모바일 장치에서 로드되지 않는 경우 Miro가 제공하는 문제 해결 단계를 사용해보세요.

:::warning
아래 솔루션을 살펴보기 전에 [Miro 서비스 상태 페이지](https://status.miro.com/)에서 성능 저하 보고서를 확인하세요.
:::

브라우저 데스크톱 앱 태블릿, 모바일

1. [시크릿](https://support.google.com/chrome/answer/95464)**(비공개) 모드** 또는 **다른 브라우저****에서 Miro를 엽니다.**Miro가 시크릿 모드나 다른 브라우저에서 작동하는 경우 브라우저의 캐시 및 쿠키를 지웁니다.

**Chrome에서 Miro 웹사이트 데이터 지우기**

1. `https://miro.com/`으로 이동해 Chrome의 **개발자 도구**를 엽니다. *(Mac에서는* **Command + Option + J**, *Windows에서는* **Ctrl + Shift + J**)
2. **애플리케이션 > 스토리지** 탭을 선택해 **사이트 데이터 삭제**를 클릭하세요. 그러면 Chrome 브라우저에 저장된 모든 Miro 데이터가 제거되고 새 세션을 시작할 수 있습니다. 이때 Miro 프로필에서는 로그아웃됩니다.

![사이트_데이터_삭제.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21017725432466_clear%20site%20data.jpg)*Chrome의 사이트 데이터 삭제 옵션*

브라우저를 최신 버전으로 업데이트하거나 특정 확장 프로그램을 비활성화해야 할 수도 있습니다. [지원되는 브라우저](../technical-guidelines/02-supported-browsers-browser-restrictions.md) 목록을 확인하세요.

2. **인터넷 연결**을 확인합니다. 네트워크 대역폭이 최소 8Mb/s에 도달하지 않는다면 더 빠른 다른 네트워크로 전환하는 것이 좋습니다.

3. 장치가 **[시스템 요구 사항](../technical-guidelines/01-system-requirements.md)**을 충족하는지 확인합니다.

- CPU - 3Ghz(코어 2개/스레드 4개)
- RAM 메모리 - 8GB

4. 노트북에서 Miro를 사용할 때 절전 모드 대신 **고성능** 모드를 사용 중인지 확인합니다.

5. 특정 보드에서 문제가 발생하면 **[보드를 복제](../../managing-boards/03-how-to-duplicate-a-board.md)**한 다음 복사본에서도 문제가 지속되는지 확인합니다.

**Miro를 로드할 수 없고 Miro에 액세스할 수 없는 사용자의 경우**

6. 연결이 **WebSockets**을 지원하는지 확인합니다. WebSockets 관련 설명과 문제 해결 단계를 자세히 알아보려면 [허용된 앱에 Miro 추가하기](../../tools/troubleshooting/01-add-miro-to-allowed-apps.md)를 참조하세요.

7. 회사가 Miro를 차단하는 **방화벽**이나 **프록시**를 사용하고 있는지 IT 부서에 문의합니다. [허용된 앱에 Miro 추가하기](../../tools/troubleshooting/01-add-miro-to-allowed-apps.md)의 지침에 따라 Miro를 허용 목록에 추가하거나 우회 경로를 지정합니다.

문제가 지속되면 [Miro 고객 지원에 문의](../../tools/troubleshooting/06-contacting-miro-support.md)하고 [브라우저 콘솔 로그](../../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md)를 보내주세요.

1. **[웹 버전](https://miro.com/app/dashboard/)**을 사용할 때 성능이 느려지거나 무한 로딩이 발생하는지 확인합니다. 웹 버전에서 Miro에 액세스할 수 없다면 **브라우저용** 문제 해결 가이드를 참고하세요.
2. 브라우저에서 문제가 발생하지 않는다면 **애플리케이션 데이터를 초기화**합니다.


   **Windows에서 앱 데이터 초기화하기**

   Alt 키를 누르고 오른쪽 상단 모서리의 **도움말**을 클릭한 다음 **애플리케이션 데이터 초기화**를 선택하세요.


   ![Windows에서_앱_데이터_초기화.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21017725434514_reset%20app%20data%20on%20Windows.jpg)
   *Windows용 데스크톱 앱에서 앱 데이터 초기화하기*

   메뉴를 찾을 수 없다면 MS Store에서 다운로드한 앱을 사용하고 있을 가능성이 높습니다. 이 경우 앱 데이터를 초기화하려면 Windows **설정** > **앱** > **앱 및 기능** > 목록에서 **Miro** 찾기 > **고급 옵션** > **초기화**를 선택하세요.

   **macOS에서 앱 데이터 초기화하기**

   Miro 앱의 상단 메뉴에서 **도움말**을 클릭하고 **애플리케이션 데이터 초기화**를 선택하세요.


   ![Mac에서_앱_데이터_초기화.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21017695741458_reset%20app%20data%20on%20Mac.jpg)
   *Mac에서 앱 데이터 초기화하기*
3. 문제가 지속되면 앱을 삭제하고 [**다시 설치**](https://miro.com/apps/)해보세요.

여전히 문제가 해결되지 않는다면 [Miro 고객 지원에 문의](../../tools/troubleshooting/06-contacting-miro-support.md)하고 [앱 콘솔 로그](../../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md)를 보내주세요.

1. **인터넷 연결**을 확인합니다. 네트워크 대역폭이 최소 8Mb/s에 도달하지 않는다면 더 빠른 다른 네트워크로 전환하는 것이 좋습니다.
2. 장치가 **기술 요구 사항**을 충족하는지 확인합니다.

- 태블릿에서 Miro를 사용하는 경우
  - 6GB RAM
  - iOS 12.0 이상, Android 6.0 이상, Windows 10 버전 1607 이상
  - 화면 해상도 768×1024 픽셀 이상
- 모바일에서 Miro를 사용하는 경우
  - iOS 12.0 이상
  - Android 6.0 이상

- 장치에서 앱을 삭제한 후 **다시 설치**합니다

**iPad 사용자인 경우**
iPad에서의 보드 성능 저하는 iPad RAM 제한으로 인해 발생할 수 있습니다. 다음 방법을 시도해보세요.

1. Miro 사용 전에 불필요한 백그라운드 애플리케이션 모두 닫기 - 성능이 향상됩니다
2. 작은 크기의 보드에서 작업하기 - 시스템에서 앱의 부하를 줄일 수 있습니다
3. RAM 성능이 더 좋은 다른 장치(노트북 또는 컴퓨터)로 전환해 브라우저 버전으로 Miro 사용하기

## 일반적인 문제 해결하기

동기화 중... 잠시만 기다려주세요 연결이 복원되었습니다

팝업 알림으로 **동기화 중... 잠시만 기다려주세요**가 나타나면 일반적으로 과부하가 발생해 예상 시간 내에 프로세스를 완료하는 데 필요한 성능이 부족하다는 의미입니다. 따라서 많은 오브젝트를 한꺼번에 이동하는 등 리소스를 많이 필요로 하는 대용량 보드에서 작업하는 중이거나 패킷 손실이 있는 경우 이 메시지가 표시될 수 있습니다. 단순해 보이는 보드여도 고해상도 이미지, PDF 파일 또는 펜 그림(렌더링하기 어려운 벡터 그래픽), 테이블 등 용량이 큰 오브젝트가 성능을 저하시켜 이 메시지가 나타날 수 있습니다.

콘텐츠를 복사하고 새 보드에 붙여넣은 다음, 보드를 작은 보드 여러 개로 나누고 문제가 지속되는지 확인하세요. 그래도 해결되지 않는 경우 다음 내용을 참조하세요.

- 장치가 최소 시스템 요구 사항을 충족하는지, 브라우저가 최신 버전으로 업데이트되었는지 확인합니다.
- 브라우저에 여러 개의 탭이 열려 있다면 Miro에서 작업하기 전에 탭을 닫거나 일시 중지해보세요. 브라우저의 처리 성능이 여러 탭에 분산되지 않고 Miro 앱에 집중되도록 할 수 있습니다.
- 브라우저 확장 프로그램의 간섭 가능성을 제외하기 위해 시크릿(비공개) 모드를 사용해보거나 다른 브라우저에서 Miro를 테스트합니다. 필요한 경우 백그라운드에서 실행 중인 모든 브라우저 탭과 애플리케이션을 닫습니다.
- 브라우저의 캐시 및 쿠키를 지우고 브라우저를 다시 시작한 다음, F5(또는 CTRL / Cmd + R)를 여러 번 눌러 페이지를 새로 고칩니다.
- 특정 보드에서 문제가 발생하면 보드를 복제하고 복제본에서도 문제가 지속되는지 확인합니다. 항목이 더 적은 보드나 크기가 작은 보드를 열어 문제가 계속 발생하는지 확인해보세요.
- VPN을 사용하는 경우 VPN을 끈 후에도 문제가 지속되는지 확인합니다.
- 보드를 복제하고 새 보드에서도 오류가 재현되는지 확인합니다.

일반적으로 **다시 연결 중...**, **연결이 복원되었습니다** 오류는 다음과 같은 경우에 나타납니다.

- 사용자 측에 연결 문제가 있는 경우: 네트워크 연결이 최소 요구 사항을 충족하는지 확인합니다. 가능하다면 더 빠른 네트워크로 전환해보세요.
- 한 브라우저에서 용량이 큰 보드를 여러 개 열고 작업하는 경우: 이 경우 브라우저의 모든 추가 탭과 실행 중인 애플리케이션을 닫고 브라우저 페이지를 새로 고침하세요.

WebSocket 연결도 확인해보세요. 특히 가장 작은 보드를 포함해 모든 보드에서 문제가 발생하는 경우에는 이를 확인해보는 것이 좋습니다. IT 부서에 연락해 포트 80 및 443(SSL)에서 WebSocket 연결을 사용하도록 요청하고 [다른 원인이 있는지 다시 확인](../../tools/troubleshooting/01-add-miro-to-allowed-apps.md)하세요.

## 자주 묻는 질문

*보드 성능은 사용 중인 플랜(무료/유료)에 따라 달라지나요?*

아니요, 보드 성능은 플랜의 영향을 받지 않습니다.

*보드의 공유 설정이 성능에 영향을 주나요?*

공유 설정은 보드 성능에 영향을 주지 않지만, 보드의 사용자 수는 영향을 줄 수 있습니다. 위의 협업 세션 진행 팁을 참고해주세요.
