프로필 잠금은 모든 Miro 사용자와플랜에 기본으로 적용되며, 커스터마이징은 불가능합니다. 외부 ID 공급자를 통해 [인증](../../../enterprise-administration/security-integrations/single-sign-on-sso/09-single-sign-on-sso.md)하는 사용자에게는 이 기능이 적용되지 않습니다.

프로필에 잘못 로그인한 후에는 이메일-비밀번호 쌍에 대해 정확한 비밀번호 입력을 시도할 수 있는 기회가 **10회** 주어집니다. 처음 5회 시도는 추가 복잡성 없이 표준으로 제공됩니다.

다음 시도부터는 캡차가 추가됩니다(웹 및 데스크톱 앱만 해당). 이메일-비밀번호 쌍에 대해 **10회 연속**으로 올바른 비밀번호를 제공하지 못하면 사용자 프로필이**1시간** 동안 잠겨 해당 시간 동안 올바른 비밀번호를 입력해도 로그인 시도가 실패합니다.

:::tip
계정 잠금 시간 동안 패스워드 없는 로그인이나 소셜 로그인 제공자를 통해 로그인을 시도할 수 있습니다.
:::

사용자 프로필이 잠기면, Miro에서 프로필 잠금을 해제할 수 있는 6자리 코드가 포함된 이메일을 발송합니다. 이메일의 링크는 6자리 코드를 입력해야 하는 확인 페이지로 연결됩니다. 코드가 올바르게 입력되면 프로필이 잠금 해제되고 시도 횟수가 초기화됩니다. 이메일에는 비밀번호를 변경할 것을 권장하는 내용도 포함되어 있습니다.

잠긴 프로필은 **자동으로** 1시간 후에 해제되며, 모든 실패 시도가 초기화됩니다.

### 코드를 받지 못한 경우 해야 할 일

이메일을 받은 편지함에서 찾을 수 없다면 다음의 문제 해결 단계를 시도해 보세요:

- 입력한 이메일 주소에 오타가 없는지 확인하세요. 오타를 발견하면 올바른 주소로 로그인해보세요.
- 스팸, **프로모션, 정크, 소셜**, 그리고 **업데이트** 폴더를 열어 Miro 확인 이메일이 있는지 확인하세요.
- 이메일 수신함이 꽉 차지 않았는지 확인하여 메일 메모리 제한에 도달하지 않았는지 확인하세요. 꽉 찼다면, 기존 이메일 일부를 삭제해야 새 이메일을 받을 수 있습니다. 이메일을 삭제한 후 **"코드 다시 보내기"**를 클릭하여 등록 이메일을 받으세요.
- 이메일이 메일함에 도착하지 못하도록 방화벽이 차단하고 있을 수 있습니다. *시스템 관리자*에게 문의하여 우리의 도메인 및 하위 도메인인 [miro.com](http://miro.com/)*, *.[miro.com](http://miro.com/), [mirostatic.com](http://mirostatic.com/)*, *.[mirostatic.com](http://mirostatic.com/) 및 [realtimeboard.com](http://realtimeboard.com/)*, *.[realtimeboard.com](http://realtimeboard.com/)를 허용 목록에 추가하도록 요청하세요. [여기에서 허용 목록 설정에 대한 자세한 정보를 확인할 수 있습니다](../../tools/troubleshooting/02-allowlist-miro-mailers.md).
- AOL/CompuServe 사용자: 메일 컨트롤이 인터넷에서 이메일을 받을 수 있도록 설정되어 있는지 확인하세요. 인터넷 이메일 수신이 차단되어 있는 경우 AOL 또는 CompuServe에서 **메일 컨트롤**에 들어가 설정을 변경하세요. 그런 후, 등록 양식을 다시 방문하여 확인 코드를 재전송하세요
- 보통 코드는 즉시 도착하지만, 특정 메일 시스템의 특성상 24시간까지 기다려야 할 수도 있습니다
- 어느 것도 도움이 되지 않았다면, [Miro 지원에 이슈를 보고하세요](../../tools/troubleshooting/06-contacting-miro-support.md).
