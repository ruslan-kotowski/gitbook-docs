테이블은 Miro에서 콘텐츠를 구조화하여 아이디어를 실행 가능한 계획으로 전환하는 인터랙티브 도구입니다.

> ***사용 가능 환경:** 모든 기기*
> ***사용 가능 대상:** 모든 Miro 플랜*
> ***실행 가능한 사용자:** 보드 소유자와 편집자*

## 주요 기능

테이블에는 다음과 같은 주요 기능이 포함됩니다:

- **사용자 지정 필드 생성**
  사용자 지정 필드로 정보를 체계적으로 구성하세요.
- **Miro 카드로 레코드 생성**
  T 테이블 위젯에 Miro 카드를 드래그 앤 드롭하여 새 레코드를 만드세요.
- **스티커 메모로 레코드 생성**
  테이블에 Miro 카드 또는 스티커 메모 추가하기를 참조하세요.
- **Jira 카드로 동기화된 레코드 생성**
  테이블에 Jira 카드 추가하기를 참조하세요.
- **고급 필터 및 정렬 기능**
  레코드를 조직하고 우선순위를 지정하기 위해 테이블을 필터링하고 정렬합니다.
- **기록 그룹화**
  테이블의 기록을 필드별로 구성하여 정보를 논리적으로 그룹화합니다.
- **여러 보드에서 동기화된 테이블 생성**
  테이블을 복사하여 붙여넣어 동일한 기록의 동기화된 보기를 생성합니다.
- **타임라인 보기**
  데이터를 새로운 레이아웃으로 보기 위해 타임라인 보기로 전환합니다.
- **열 계산**
  데이터를 한눈에 분석할 수 있도록 숫자 필드의 합계, 평균 등을 계산합니다.
- **시각적 숫자 형식**
  숫자를 진행 표시바, 백분율 또는 통화 표시로 포맷하고 특정 조건을 충족하는 값을 강조하기 위해 조건부 서식을 사용합니다. [테이블에서 시각적 숫자](04-visual-numbers-in-tables.md)를 참조하세요.
- **종속성**
  "차단됨" 및 "차단" 필드를 사용하여 프로젝트 간의 레코드 간 의존성을 매핑하고 시각화합니다.
- **대량 작업**
  편집, 이동, 복제, 삭제와 같은 작업을 한 번에 여러 레코드에 수행하거나 여러 레코드를 카드로 캔버스로 드래그합니다.

## 보드에 테이블 추가

:::warning
게스트 편집자는 테이블을 추가하거나 편집할 수 없습니다.
:::

1. Miro 보드를 엽니다.
2. 작성 툴바에서 **툴, 미디어, 통합** 아이콘 (**+**)을 클릭합니다.
   툴, 미디어, 통합 패널이 열립니다.
3. **테이블**을 검색하고 선택합니다.
   이제 커서가 테이블 아이콘으로 바뀝니다.
4. Miro 보드의 원하는 위치를 클릭하여 테이블 위젯을 배치합니다.

## Excel 파일을 테이블로 변환하기

1. Miro 보드 열기.
2. 작성 툴바의 **툴, 미디어, 통합** 아이콘(**+**) 클릭.
   툴, 미디어, 통합 패널이 열립니다.
3. 검색 및 **업로드** 선택.
   업로드 패널이 열립니다.
4. **내 장치** 선택.
5. 업로드할 Excel 파일(.xlsx)을 찾아 선택합니다.
6. 옵션이 있는 모달이 열립니다:
   1. 테이블로 변환.
   2. 표로 변환.
   3. 파일로 추가.
7. **테이블로 변환** 을 선택하고 **첫 번째 행을 헤더로 사용**할지 선택합니다.
8. **선택**을 클릭합니다.
9. 엑셀 파일의 데이터로 보드에 테이블이 생성됩니다.

:::warning
엑셀 파일을 업로드할 때, 500개의 행과 30개의 열의 제한이 있습니다.
:::

## 테이블 복사해 붙여넣기

테이블을 복사하고 붙여넣을 때는 보드 내에서 하거나 보드 간에 할 수 있는 두 가지 기본 옵션이 있습니다. 첫 번째 옵션은 각 위치에서 업데이트가 표시되는 동기화된 테이블을 만드는 것이고, 두 번째 옵션은 템플릿처럼 작동하는 비동기화된 테이블을 만드는 것입니다.

1. 복사할 테이블을 선택하세요.
2. 컨텍스트 메뉴 (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg))에서 "복사"를 클릭합니다. 또는 Windows에서는 Ctrl + C, Mac에서는 Command + C 키보드 단축키를 사용할 수 있습니다.
3. 테이블을 붙여넣을 보드로 이동하세요.
4. 오른쪽 클릭하여 "붙여넣기"를 선택하세요. 또는 Windows에서는 Ctrl + V, Mac에서는 Command + V 단축키를 사용할 수 있습니다.
   팝업이 열립니다.
5. 팝업에서 동기화 테이블을 만들지 새 테이블을 만들지를 선택하세요.

## 테이블 권한 관리

여러 Miro 보드에 걸쳐 테이블의 동기화 뷰를 생성하는 경우, 새로운 보드에 테이블의 동기화 뷰를 추가할 때 누가 그 테이블을 편집하고 볼 수 있는지를 관리하기 위해 권한을 설정해야 합니다. 테이블의 동기화 뷰에 대한 권한은 해당 테이블이 최초로 생성된 보드인 홈 보드에서 관리됩니다.

새로운 보드에 테이블을 동기화 뷰로 붙여 넣을 때, 보드의 모든 사용자가 그 테이블을 볼 수 있거나 편집할 수 있는 권한이 없는 경우, 팝업이 표시됩니다. 테이블의 권한을 보거나 편집하려면, 테이블이 나타나는 원래 보드로 이동하여 변경을 수행합니다.

사용자가 원본 테이블이 만들어진 홈 보드에 접근 권한이 없는 경우, 해당 테이블은 접근 불가 상태로 표시됩니다. 사용자가 홈 보드에 대한 조회 권한만 있는 경우, 새 보드에서 테이블을 볼 수는 있지만 기록을 편집하거나 필터 설정, 정렬, 그룹화 등을 적용하여 보기를 변경할 수는 없습니다.

## 테이블 상호작용하기

테이블 위젯은 원하는 콘텐츠를 생성하고, 사용 사례에 가장 효과적으로 구조화하고 조직화할 수 있는 유연성을 제공합니다.

Miro 보드에서 새 테이블을 만들면 기본 필드 세트가 제공되며, 이는 Miro 카드에 있는 기존 필드와 매핑됩니다. 이러한 필드를 삭제, 편집, 숨기거나 새 필드를 생성할 수 있습니다.

### 필드 생성하기

새 필드를 생성하려면 다음 단계에 따르십시오:

1. 테이블의 가장 오른쪽 열 상단에 있는 + 아이콘을 클릭합니다.
   메뉴가 열립니다.
   ![tables-adding-fields.png](../../../../../../docs/using-miro/formats/images/25142699942930_tables-adding-fields.png)
   *테이블에 새로운 필드 추가하기*
2. 메뉴에서 생성할 필드 유형을 클릭합니다. Miro 필드와 맞춤형 필드 유형 옵션이 제공됩니다.
   옵션 대화 상자가 열립니다.
3. 대화 상자에 필드 정보(필드 이름과 선택 필드의 경우 드롭다운 옵션)를 입력하고 저장을 클릭합니다.

:::note
링크 필드 유형은 Business 및 Enterprise 플랜에서만 사용 가능합니다.
:::

### 필드 이름 또는 옵션 편집

1. 필드 이름 위에 커서를 올립니다.
   세 점 (...) 아이콘이 나타납니다.
2. **세 점** (**...**) 아이콘을 클릭합니다.
   메뉴가 열립니다.
3. **필드 편집**을 클릭합니다.
   편집 옵션이 포함된 대화 상자가 열립니다.
4. 필드 이름 및/또는 옵션을 편집하고 **저장**을 클릭합니다.

### 필드 삭제

1. 필드 이름 위에 커서를 올립니다.
   세 점 (...) 아이콘이 나타납니다.
2. **세 점** (**...**) 아이콘을 클릭합니다.
   메뉴가 열립니다.
3. 삭제를 클릭합니다.

:::warning
삭제된 필드는 실행 취소할 수 없습니다. 삭제되면 현재 테이블과 모든 동기화된 버전에서 즉시 삭제됩니다.
:::

### 필드를 숨기거나 표시하기

단일 필드를 숨기거나 표시하려면 다음 단계를 따르세요:

1. 필드 이름 위에 마우스를 올리세요.
   세 점 (...) 아이콘이 나타납니다.
2. **세 점** (**...**) 아이콘을 클릭하세요.
   메뉴가 열립니다.
3. **필드 숨기기**를 클릭하세요.
   필드가 숨겨집니다.
4. 필드를 다시 표시하려면 위의 단계를 반복하되, **필드 표시하기**를 클릭하세요.

여러 필드를 동시에 숨기거나 표시할 수도 있습니다.

여러 필드를 숨기거나 표시하려면 다음 단계를 따르세요:

1. 테이블 상단에 있는 **숨기기** 아이콘을 클릭합니다.
   테이블에 있는 필드 목록이 나타납니다.
2. 목록에서 숨기거나 보이게 하려는 필드를 선택합니다.

### 레코드 편집

1. 편집할 레코드를 더블클릭합니다.
   레코드가 편집 가능해집니다.
2. 레코드를 편집하고 엔터를 누릅니다.

레코드 내 텍스트에 서식을 적용하거나 링크를 추가하려면:

1. 편집하려는 레코드를 더블 클릭합니다.
   레코드를 편집할 수 있게 됩니다.
2. 포맷하려는 텍스트를 하이라이트합니다.
   컨텍스트 메뉴가 나타납니다.
3. 컨텍스트 메뉴를 통해 또는 [키보드 숏컷](../working-on-the-board/06-shortcuts-and-hotkeys.md)을 사용하여 텍스트에 포맷을 적용하거나 링크를 추가합니다.
4. Enter 키를 눌러 레코드를 저장합니다.

텍스트 포맷팅은 레코드를 편집할 때 측면 패널에서도 적용할 수 있습니다.

### 여러 레코드 일괄 편집

1. 행 위에 커서를 가져가면 왼쪽에 체크박스가 나타납니다.
2. 각 해당 행의 체크박스를 사용하여 편집할 항목을 선택합니다.
   편집 옵션이 있는 툴바가 나타납니다.
3. 툴바에서 해당 항목을 동시에 편집, 이동, 또는 복제할 수 있습니다.

### 항목 삭제하기

1. 삭제하려는 항목 위에 커서를 가져다 놓습니다.
2. 메뉴를 열려면 육점 아이콘을 클릭합니다.
3. **삭제**를 선택합니다.

### 다수 항목 삭제하기

1. 행 위에 마우스를 올려 왼쪽의 체크박스를 표시합니다.
2. 각 관련 행의 체크박스를 사용해 편집할 기록을 선택합니다.
   편집 옵션이 있는 툴바가 나타납니다.
3. 툴바에서 **삭제** 아이콘을 클릭하여 선택된 모든 기록을 삭제합니다.

### 테이블에 댓글 추가

논의하고 싶은 테이블의 부분에 직접 댓글을 추가하여 협업을 간소화하세요.

1. 댓글을 추가하고 싶은 행으로 마우스를 가져가세요.
   첫 번째 셀 오른쪽에 댓글 추가 아이콘이 나타납니다.
2. **댓글 추가** 아이콘을 클릭하세요.
   왼쪽에 측면 패널이 열립니다.
3. 패널에서 댓글을 추가하고 Enter 키를 누르세요.

새 댓글이 추가되면 각 행에 댓글 추가 아이콘 옆에 댓글 수가 표시됩니다. 아이콘을 클릭하여 댓글 패널을 엽니다.

댓글 패널에서 다음 작업을 할 수 있습니다:

- 댓글에 답글을 달기.
- 댓글에 리액션 추가.
- 댓글 스레드를 해결하기.
- 댓글 링크 복사.
- 댓글 스레드를 팔로우하여 알림 받기.
- 댓글 스레드를 삭제하기.
- 내가 남긴 댓글 편집.

### 테이블에 Miro 카드 또는 스티커 메모 추가하기

테이블에서 Miro 카드 또는 스티커 메모를 사용하여 레코드를 생성할 수 있습니다.

1. 테이블에 복사할 카드 또는 스티커 메모를 선택하세요.
2. 카드 또는 스틱을 테이블 위로 드래그 앤 드롭하세요.
   새로운 항목이 추가될 위치에 파란색 선이 나타납니다.
3. 새로운 레코드가 생성되며, 카드는 적절한 필드에 내용이 매핑됩니다.
   스티커 메모의 경우, 내용이 첫 번째 필드에 채워집니다.

### 테이블에 Jira 카드 추가

Jira 카드를 테이블로 드래그 앤 드롭하여 Jira와 동기화된 레코드를 생성할 수 있습니다. 이렇게 하면 Miro와 Jira의 작업을 결합하여 하나의 테이블 또는 타임라인 보기에서 전체 팀의 작업을 한 곳에서 관리하고 추적할 수 있습니다.

1. 캔버스에서 관련된 Jira 카드를 찾습니다.
2. 카드를 테이블로 드래그하십시오.
3. 카드를 테이블의 목표 행에 놓습니다.

Miro에서의 변경 사항은 Jira에 반영되며, 그 반대도 마찬가지입니다. 테이블 내 다음 필드는 Jira와 동기화됩니다:

- 제목
- 설명
- 추정
- 시작일
- 종료일
- 담당자 (베타)
- 상태 (베타)

표의 다른 모든 필드는 Miro에만 저장되며 Jira와 동기화되지 않습니다.

**자세한 정보:** [Jira 카드 자주 묻는 질문](../../integrations-apps/atlassian/17-jira-cards-faq.md)을 참조하세요.

### Jira 카드를 일괄 처리하기

Jira와 동기화된 기록을 일괄 편집할 때는 Jira 통합에서 지원하는 작업 및 필드만 사용할 수 있습니다. 지원되지 않는 작업은 일괄 작업 메뉴에서 숨겨지거나 비활성화됩니다.

### 테이블 필터링

작업할 보기/기록을 좁히기 위해 테이블의 내용을 하나 이상의 필드로 필터링할 수 있습니다.

1. 테이블 상단의 **필터 아이콘**을 클릭합니다.
   대화 상자가 열립니다.
2. **필터 추가** 또는 **필터 그룹 추가**를 선택합니다.
   대화 상자가 열립니다.
3. 필터의 매개변수를 지정합니다: 필터 기준 필드, 필터 논리, 필터할 구체적인 내용을 설정합니다.
   테이블이 실시간으로 필터링됩니다.
4. 필터 대화 상자 밖의 아무 곳이나 클릭하여 닫습니다.

### 테이블 정렬하기

1. 필드 이름 위에 커서를 올려놓습니다.
   세 점 (...) 아이콘이 나타납니다.
2. **세 점** (**...**) 아이콘을 클릭합니다.
   메뉴가 열립니다.
3. **오름차순 정렬** 또는 **내림차순 정렬**을 클릭합니다.

테이블에서 정렬을 제거하려면:

1. 테이블 상단의 **정렬 아이콘**을 클릭합니다.
   대화 상자가 열립니다.
2. **정렬 삭제**를 클릭합니다.

### 테이블에서 검색

1. Table의 상단 툴바에서 **검색** 아이콘을 클릭하세요.
2. 검색어를 입력하세요.
3. 입력할 때마다 관련 검색 결과가 표시됩니다.
4. 검색창의 화살표 아이콘을 사용하거나 Table을 스크롤하여 결과를 탐색할 수 있습니다.
5. **지우기** (**X**) 아이콘을 클릭하여 전체 Table로 돌아갑니다.

### 필드별 레코드 그룹화

1. 테이블 상단의 **그룹** 아이콘을 클릭하세요.
   메뉴가 열립니다.
   ![table-group-records.png](../../../../../../docs/using-miro/formats/images/25142699944338_table-group-records.png)
   *테이블에서 항목을 그룹화*
2. 기준이 될 필드를 선택하세요.
   선택한 필드를 기준으로 테이블의 항목이 그룹화됩니다.

:::note
항목을 기존 그룹으로 드래그하면 해당 필드 값이 해당 그룹에 맞게 업데이트됩니다.
:::

테이블에서 그룹화를 제거하려면 다음 단계를 따르세요:

1. 테이블 상단의 **그룹** 아이콘을 클릭합니다.
   메뉴가 열립니다.
2. **그룹 해제**를 클릭합니다.

### 동기화 카드

테이블에서 레코드를 드래그하여 캔버스로 가져오면 동기화 카드가 생성됩니다.

1. 동기화 카드를 만들고자 하는 레코드 위로 마우스를 가져갑니다.
   레코드의 왼쪽에 아이콘이 표시됩니다.
2. 점 아이콘을 클릭하고 캔버스로 드래그합니다.
   해당 레코드의 정보가 포함된 카드가 생성됩니다.
3. 테이블의 레코드가 업데이트되면 카드도 함께 업데이트되고, 그 반대도 마찬가지입니다.

카드가 테이블에 동기화되어 있는지 여부는 카드 오른쪽 하단에 나타나는 데이터베이스 아이콘으로 알 수 있습니다.

레코드를 삭제하면 해당 동기화된 카드는 보드에 남지만 이제 빈 양식으로 표시됩니다.

캔버스의 동기화된 카드를 삭제하면 레코드는 테이블에 남아 있습니다.

기존의 동기화된 카드를 원래의 테이블로 드래그하면, 해당 테이블의 고유한 레코드로 처리되기 때문에 작동하지 않습니다. 그러나 기존의 동기화된 카드를 새로운 테이블에 드래그하면 테이블에 새로운 비동기 레코드로 나타납니다.

### 테이블을 타임라인 보기로 변환하기

타임라인 보기로 전환하려면 다음 단계를 따르세요:

1. 테이블 상단에서 **테이블** 아이콘을 클릭합니다.
   대화 상자가 열립니다.
2. **타임라인 보기**를 선택하거나 **테이블 보기**로 전환합니다.

타임라인 보기로 전환하면 기본 시작일과 종료일이 설정되어 있을 경우 테이블의 항목이 타임라인에서 해당 막대로 표시됩니다. 제목 필드와 담당자 필드는 막대에 항목 이름과 담당자를 표시하는 데 사용됩니다.

**자세한 정보:** [타임라인](15-timeline.md)

## 열 계산

> **적용 플랜:** Business, Enterprise

열 계산을 통해 테이블의 숫자 필드에서 집계 기능을 수행할 수 있어 데이터를 분석하고 요약하는 데 도움이 됩니다. 숫자 열에 대해 합계, 평균, 개수, 최소값, 최대값, 중앙값을 계산할 수 있습니다.

1. 데이터가 포함된 열 헤더를 클릭하여 필드 옵션 메뉴를 엽니다.
2. 메뉴에서 **열 계산 표시**를 선택합니다.
3. 적용할 계산 유형을 선택하세요:
   1. 합계: 열의 모든 값을 더합니다.
   2. 평균: 모든 값의 평균을 계산합니다.
   3. 수: 항목의 수를 셉니다.
   4. 최소: 가장 작은 값을 표시합니다.
   5. 최대: 가장 큰 값을 표시합니다.
   6. 중앙값: 중간 값을 표시합니다.
4. 계산 결과는 테이블 하단의 푸터 행에 나타납니다.

열 계산을 제거하려면:

1. **계산** 옵션을 테이블 하단의 푸터 행에서 클릭합니다.
2. **없음**을 선택합니다.
3. 마지막 계산까지 모두 없음으로 설정될 때까지 반복합니다.

:::note
각 열에 계산을 한 가지씩 적용할 수 있습니다. 테이블을 필터하거나 그룹화하면 계산은 자동으로 업데이트되어 보이는 레코드만 반영합니다. 그룹화된 보기에서는 각 그룹과 전체 합계를 모두 볼 수 있습니다.
:::

열 계산은 시각적 숫자 형식과 원활하게 작동합니다. 계산된 열에 시각적 형식을 적용하면, 결과가 사용자 지정 서식 규칙에 따라 진행률 표시줄로 표시됩니다. [테이블의 시각적 숫자](04-visual-numbers-in-tables.md)를 참조하세요.

## 다중 열 수식

> **대상 플랜:** Business, Enterprise

열 계산 외에도 여러 열에 걸쳐 수식을 사용할 수 있는 필드를 만들 수 있습니다. 수식 필드는 같은 행의 여러 열을 계산합니다.

수식 필드를 만들려면:

1. **+** 아이콘을 클릭해 새로운 필드를 추가합니다.
2. **수식** 형식을 선택합니다.
3. 시각적 수식 생성기를 사용하여 필드, 상수 및 연산자(+, -, ×, ÷, ())를 선택합니다.
4. 수식이 자동으로 각 행에 대해 계산됩니다.

:::note
수식 필드는 현재 숫자 필드와 상수만 지원합니다.
:::

## 관계 (종속성)

> **적용되는 플랜:** Business, Enterprise

이 관계 필드 유형을 사용하면 '막힘' 및 '막고 있음' 필드를 통해 테이블에서 기록 간의 의존성을 맵핑할 수 있습니다. 이를 통해 프로젝트의 관계를 추적하고 작업 항목이 서로 어떻게 의존하는지를 이해할 수 있습니다.

### 종속성 필드 생성

1. **+ 아이콘**을 클릭해 새 필드를 추가하세요.
2. 다음 중 하나를 선택하세요:
   1. **차단된 항목** - 이 레코드 전에 완료해야 할 항목을 표시합니다.
   2. **차단 중인 항목** - 이 레코드를 기다리고 있는 항목을 표시합니다.
3. 필드 이름을 정하고 생성 버튼을 클릭하세요.

### 레코드 간의 종속성 추가

종속성 필드를 생성한 후, 다음 단계에 따라 레코드를 연결할 수 있습니다:

1. **차단한** 또는 **차단받은** 열의 셀을 클릭하세요.
2. 드롭다운 메뉴에서 연결할 항목을 선택하세요.
3. 셀 밖을 클릭하여 저장합니다.

:::note
항목은 여러 개의 차단 및 차단받은 관계를 가질 수 있습니다. 종속성은 모든 동기화된 테이블에서 동기화되어, 보기와 보드 간의 일관성을 보장합니다.
:::

:::warning
**현재 제한 사항 (베타):**

- Jira와 동기화된 레코드나 다른 타사 통합에 대한 의존성은 아직 지원되지 않습니다
- 동기화된 카드에는 의존성에 대한 시각적 표시기가 아직 표시되지 않습니다
- 의존성을 기반으로 한 자동 날짜 조정은 아직 사용할 수 없습니다
:::

## 관계 (중첩) (베타)

> **적용 플랜:** Business, Enterprise

중첩 관계 필드 유형을 사용하면 테이블 내의 레코드 간에 **부모** 및 **자식** 필드를 사용하여 계층 구조를 만들 수 있습니다.

### 계층 필드 생성

1. **+** 아이콘을 클릭하여 새 필드를 추가합니다.
2. 아래 옵션 중 선택하세요:
   1. **상위**: 이 필드를 사용하여 기록을 상위 항목에 연결합니다 (예: 기능을 에픽에 연결).
   2. **하위**: 이 필드를 사용하여 기록을 하위 항목에 연결합니다 (예: 이니셔티브의 하위 작업).
3. 필드 이름을 지정하고 **생성**을 클릭하세요.

### 상위 및 하위 기록 연결

1. **상위** 또는 **하위** 열의 셀을 클릭하세요.
2. 드롭다운 메뉴에서 연결할 항목을 선택하세요.
3. 셀 밖을 클릭해 저장합니다.

### 계층 구조 시각화

1. **테이블 설정** 아이콘을 클릭하세요.
2. **중첩** 기능을 켜세요.

상위 항목 옆의 **꺾쇠**를 사용해 하위 항목을 표시하거나 숨길 수 있습니다.

:::note
*중첩과 계층 구조는 기본적으로 숨겨져 있습니다. 이러한 설정에서 켜야 합니다.*
:::

### 다른 계층 구조 생성 방법

1. 각 행의 왼쪽에 있는 **6점 메뉴**에서 **하위 항목 추가**를 클릭합니다.
2. 중첩이 기본적으로 켜집니다.

   > ✏️ 부모 및 자식 필드가 생성되지만 숨겨집니다. 이러한 필드를 숨기지 않으려면 테이블 헤더의 필드 숨김 메뉴로 이동합니다.

   > ✏️ 중첩을 끄려면 테이블 헤더의 설정 보기로 이동합니다.
3. 부모 및 자식 필드를 통해 계층 구조를 관리할 수 있습니다.
4. 중첩이 켜져 있을 때 끌어놓기를 통해 계층 구조를 만들 수도 있습니다.

:::warning
*부모 레코드를 삭제하면 해당 레코드의 모든 자식 레코드도 삭제됩니다. 필요 시 실행 취소 기능을 사용해 복구하세요.*
:::

부모와 자식 필드가 숨겨지지 않은 경우, 측면 패널에서 볼 수 있습니다. 타임라인 보기를 사용하여 포트폴리오가 시간에 따라 펼쳐지는 것을 확인할 수 있습니다.

:::warning
***현재 제한 사항 (베타):***

- *계층의 최대 깊이는 네 단계입니다.*
- *아직 Jira 동기화 레코드나 다른 제3자 통합에 대한 중첩이 지원되지 않습니다.*
- *동기화된 카드에는 중첩에 대한 시각적 표시가 아직 나타나지 않습니다.*
:::

## 집중 모드

테이블을 집중 모드(전체 화면)에서 편집하고 볼 수 있습니다. 위젯 상단의 **대각선 화살표 아이콘**을 클릭하세요. 필터, 정렬, 그룹 및 필드 숨기기와 같은 설정은 오른쪽 상단에 위치해 있습니다.

캔버스로 돌아가려면 상단의 **캔버스로 이동**을 클릭하세요.

## 구조적 데이터 위젯 제한 사항

각 Miro 보드에는 총 250개의 구조적 데이터 위젯이 최대 한도로 설정되어 있으며, 이는 테이블, 타임라인, 동기화된 카드의 총합계입니다. 각 테이블은 최대 1,000개의 행과 50개의 열로 제한됩니다. 행의 한도에 도달하면 추가 행을 추가할 수 없다는 메시지가 표시됩니다.

최적의 성능을 위해 테이블을 200행 이하로 유지하는 것이 좋습니다. 많은 열을 사용할 때에는 그룹화, 정렬, 필터링 같은 작업이 이 이상에서는 속도가 느려질 수 있습니다. 이러한 제한은 Miro 보드에서 최적의 성능과 안정성을 보장하는 데 도움이 됩니다.

### 데이터 위젯 제한에 도달하면 어떻게 될까요?

보드가 250개의 구조화된 데이터 위젯 제한에 도달하거나 이를 초과하면 다음과 같은 문제가 발생할 수 있습니다:

- 추가적인 구조화된 데이터 위젯을 추가하려고 할 때 오류 메시지가 표시됩니다.
- 기존 데이터 위젯 로딩이 불안정할 수 있습니다.
- 변경사항 저장에 문제가 발생할 수 있습니다.
- 성능 저하가 발생할 수 있습니다.

### 데이터 위젯 제한 관리 팁

구조화된 데이터 위젯 한도에 도달했거나 초과한 경우 다음을 시도해보세요:

**위젯을 여러 보드에 분산하십시오:**

- 관련 콘텐츠를 별도의 보드에 그룹화합니다.
- 내비게이션이 쉽도록 의미 있는 보드 이름을 사용합니다.
- 모든 관련 보드에 대한 링크가 포함된 "마스터" 보드를 만듭니다.

**유사한 데이터를 통합하십시오:**

- 유사한 구조를 가진 테이블을 병합합니다.
- 다른 보기를 위해 별도의 테이블을 만드는 대신 필터를 사용합니다.
