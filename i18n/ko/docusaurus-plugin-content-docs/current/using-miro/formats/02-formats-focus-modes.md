포맷 및 집중 모드를 사용하면 팀이 자유롭게 브레인스토밍과 구조화된 문서, 테이블, 타임라인, 다이어그램 및 슬라이드 간에 원활하게 전환할 수 있습니다. 빈 캔버스나 구조화된 포맷에서 시작하고, 집중 모드를 사용해 산만함을 줄이고 흐름을 유지하세요. 모든 사용자가 보드를 열 때 원하는 위치에 도착하도록 기본 보기를 포맷으로 설정하세요.

각 포맷에 대한 더 많은 정보를 여기서 확인할 수 있습니다:

## **포맷 접근**

캔버스에 새로운 포맷을 추가하려면:

1. 툴바에서 **툴, 미디어 및 통합** (![icon-tools.svg](../../../../../../docs/using-miro/formats/images/29210901366418_icon-tools.svg) **아이콘**)을 클릭하세요.
2. 필요한 포맷을 선택하세요: **문서**, **테이블**, **타임라인**, **다이어그램**, **프로토타입**,또는 **슬라이드**.
3. 캔버스의 원하는 위치를 클릭해 선택한 포맷을 추가하세요.

## **집중 모드**

모든 포맷은 작업 중인 포맷에만 집중하고 보드의 다른 내용을 보지 않으려면 **집중 모드** (전체 화면)로 열 수 있습니다. 집중 모드에 접근하려면:

1. 집중 모드로 진입하려는 포맷을 캔버스에서 클릭하세요.
2. 컨텍스트 메뉴에서 **집중 모드** 아이콘을 클릭하세요.
3. 집중 모드를 종료하려면, 화면 상단의 **캔버스로 이동** 버튼을 클릭하세요.

## **포맷을 기본 보기로 설정하기**

각 포맷은 보드의 기본 보기로 설정할 수 있습니다 — 보드를 열 때 모든 사용자가 먼저 문서, 테이블, 타임라인, 다이어그램, 또는 슬라이드를 보게 됩니다.

포맷을 기본 보기로 설정하려면:

1. 집중 모드에 들어가고자 하는 포맷에 아무 곳이나 클릭하세요.
2. **세 점 아이콘** (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg))을 클릭하세요.
3. **기본 보기로 설정**을 선택하세요.
4. 모달에서 **기본 보기 설정**을 클릭하세요.

### 기본 보기 잠그기

보드 소유자는 기본 보기를 잠가서 뷰어가 보드의 나머지 부분에 접근하지 못하게 할 수 있습니다. 방법은 다음과 같습니다:

1. 집중 모드에 진입하려는 포맷에서 아무 곳이나 클릭합니다.
2. **세 점 아이콘** (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg))을 클릭합니다.
3. **기본 보기로 설정**을 선택합니다.
4. 열린 모달에서 **기본 보기 잠금** 설정을 클릭합니다.
5. **기본 설정**을 클릭합니다.

## **집중 모드로 링크 공유하기**

캔버스에서 집중 모드를 유지하고 싶다면, 포맷의 집중 모드 링크만 공유할 수 있습니다:

1. 진입할 집중 모드의 포맷에서 클릭하세요.
2. **세 점 아이콘** (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg)) 아이콘을 클릭합니다.
3. **집중 모드 링크 복사**를 선택합니다.

## **대시보드 또는 스페이스에서 포맷 만들기**

대시보드, 스페이스 개요, 또는 스페이스 사이드바에서 직접 포맷을 생성할 수 있습니다. 이렇게 하면 포맷이 기본 보기로 자동 설정되며, 보드에 참여하는 모든 사용자는 해당 포맷의 집중 모드로 진입하게 됩니다.

1. **대시보드** 또는 **스페이스** 개요를 엽니다.
2. **새로 만들기** 메뉴를 클릭합니다.
3. **문서**, **다이어그램**, **프로토타입**, **타임라인**, **테이블**, **슬라이드** 중 원하는 포맷을 선택합니다.

## **스페이스 사이드바에서 포맷 생성하기**

보드 작업 중에 **스페이스 사이드바**에서 새로운 포맷을 생성할 수 있습니다. 새 포맷은 동일한 스페이스 내에서 생성됩니다.

1. 보드 바에서 [사이드바 열기](../working-on-the-board/02-miro's-new-simplified-user-interface.md) **햄버거 메뉴**를 선택하세요. **스페이스 사이드바**가 열립니다.
2. **새로 만들기** 아이콘을 클릭하세요.
3. 생성할 포맷을 선택하세요: **Doc**, **Diagram**, **Prototype,** **Timeline**, **Table**, 또는 **Slides**.

:::tip
포맷을 스페이스에 고정할 수 있습니다. 고정된 포맷은 스페이스 사이드바에 나타납니다.
:::
