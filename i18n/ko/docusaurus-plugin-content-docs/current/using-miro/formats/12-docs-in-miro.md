보드 콘텐츠를 더 구조화된 문서 형식으로 가져오세요. 캔버스에 있는 객체를 입력으로 사용하여 요약, 연구 보고서, 제품 개요 문서를 작성하여 인사이트 수집 및 분석을 시작할 수 있습니다.

## 문서 액세스

새 문서를 추가하려면:

1. **툴, 미디어 및 통합** (![icon-tools.svg](https://help.miro.com/hc/article_attachments/28774504912274)) 아이콘을 클릭합니다.
2. **문서**를 검색하여 선택합니다.
3. 캔버스의 아무 곳이나 클릭하여 추가합니다.

템플릿의 일부 보드에는 문서가 포함되어 있습니다.

![](https://help.miro.com/hc/article_attachments/26368753474450)

*문서 아이콘에서 새 문서 추가*

Miro AI로 문서를 추가할 수도 있습니다:

1. **Miro AI** (![icon-ai.svg](https://help.miro.com/hc/article_attachments/28774468468882)) 아이콘을 작성 툴바에서 클릭합니다.
2. **Formats** 탭을 선택합니다.
3. **Doc**을 선택합니다.
4. 프롬프트를 입력하거나 미리 준비된 옵션 중에서 선택한 후 필요에 맞게 사용자 지정합니다.
5. **Enter** 키를 눌러 Miro AI로 문서를 생성합니다.

![miro-ai-docs.png](https://help.miro.com/hc/article_attachments/28774504916754)

*Miro AI로 문서 추가하기*

컨텍스트 메뉴에서 문서를 추가하려면:

1. 보드에서 여러 오브젝트(예: 스티커 메모)를 선택하여 Doc을 생성합니다.
2. 컨텍스트 메뉴에서 **Miro AI** (![icon-ai.svg](https://help.miro.com/hc/article_attachments/28774468468882)) 아이콘을 클릭합니다.
3. 서브 메뉴에서 **문서**를 선택합니다.
4. 템플릿을 선택하거나 **사용자 정의 프롬프트**를 사용합니다.
5. Doc이 생성되어 보드에 배치됩니다.

![doc-from-stickies.png](https://help.miro.com/hc/article_attachments/26368753485074)

*컨텍스트 메뉴를 통한 Doc 추가*

Miro AI로 Doc을 추가하려면:

1. **AI로 생성** 패널을 엽니다.
2. **문서** 콘텐츠 유형을 선택합니다.
3. 미리 정의된 프롬프트를 사용하거나 직접 작성합니다.
4. 필요한 경우 보드에서 스티커 메모와 같은 객체를 선택하여 컨텍스트를 추가합니다.
5. **문서 생성**을 클릭합니다.
6. 생성된 문서는 캔버스의 빈 영역에 나타납니다.

Microsoft Word (.docx) 파일에서 Doc을 추가하려면:

1. **툴, 미디어 및 통합** (**+**) 아이콘을 클릭합니다.
2. **업로드**를 검색하여 선택합니다.
3. 업로드 패널에서 **내 장치**를 선택합니다.
4. 가져오고 싶은 파일로 이동하여 선택합니다.
5. 또는 파일을 Miro 보드로 드래그 앤 드롭하여 업로드합니다.
6. 대화 상자에서 **문서로 변환**을 선택합니다.
7. **선택**을 클릭합니다.
8. 파일이 Miro 문서로 변환되어 편집할 준비가 완료됩니다.

## Miro 문서 템플릿

현재 새 문서를 시작할 때 사용할 수 있는 네 가지 템플릿은 제품 개요, 회고 요약, 메모, 리서치 종합 분석입니다.

새 문서를 만들고 템플릿을 선택하면, 그 템플릿이 문서에 추가됩니다.

![docs-new.png](https://help.miro.com/hc/article_attachments/26368753488146)

*회고 요약 템플릿의 예*

## 문서의 컨텍스트 메뉴

문서 작업 시, **세 점 아이콘** (**...**)을 클릭하여 추가 기능을 위한 컨텍스트 메뉴에 접근할 수 있습니다. 컨텍스트 메뉴를 통해 복사, 동기화, 레이어 이동 및 우선 순위 설정, 내보내기 및 공유, 댓글 작성, 템플릿으로 저장 등의 기능에 접근할 수 있습니다.

## 문서를 집중 모드에서 작업하기

집중(전체 화면) 모드는 작업 중인 문서에만 집중하고 보드의 다른 콘텐츠로부터 벗어나고자 할 때 문서를 열 수 있는 모드입니다. 이 모드를 사용하려면 작업 중인 문서 위에 있는 **집중 모드 아이콘**을 클릭하십시오.

![docs-full-screen-icon.png](https://help.miro.com/hc/article_attachments/26368753496722)

*문서 집중 모드 아이콘*

집중 모드에서는 텍스트 서식을 위한 컨텍스트 메뉴가 그대로 제공됩니다. 이는 보드 배경을 제거하여 집중을 방해할 수 있는 것을 없앱니다.

문서에 대한 집중 모드는 Miro 모바일 앱에서도 사용할 수 있습니다. 모바일에서는 보드에서 문서를 볼 수 있지만, 편집은 집중 모드에서만 가능합니다.

집중 모드를 종료하려면 화면 상단의 **캔버스에서 아이디에이트** 버튼을 클릭하세요.

![docs-focus-mode.png](../../../../../../docs/using-miro/formats/images/21909726410514_docs-focus-mode.png)

### 문서의 글자 수 제한

Miro 문서는 최대 80,000자까지 포함할 수 있습니다. 더 많은 공간이 필요하면 동일한 보드에 추가 문서를 만들어 콘텐츠를 배분할 수 있습니다. 이를 통해 하나의 장소에 모든 정보를 조직적으로 관리할 수 있습니다.

## 콘텐츠를 문서로 복사하기

보드에서 다음 콘텐츠를 드래그 앤 드롭하여 문서에 추가할 수 있습니다:

- 스티커 메모
- 텍스트 상자
- 이미지
- iFrame
- 미리보기
- 테이블
- 타임라인
- 다이어그램

:::note
문서는 스티커 메모와 텍스트 상자를 글머리 기호 목록으로 변환합니다.
:::

![Drag and drop data widgets into a Miro Doc.](https://help.miro.com/hc/article_attachments/26368753506706)

*데이터 위젯을 문서로 드래그 앤 드롭*

### 문서에서의 다이어그램

다이어그램을 문서에 드래그 앤 드롭하면 Miro는 [동기화 사본](../working-on-the-board/11-synced-copies.md)을 생성합니다. 이는 보드에서 원본 다이어그램에 변경 사항이 생길 경우 문서 안의 사본에도 반영되지만, 반대 방향으로는 적용되지 않음을 의미합니다. 사본의 내용을 변경하려면 원본 다이어그램의 내용을 수정해야 합니다.

이를 통해 문서가 최신 비주얼 정보로 항상 업데이트되도록 합니다.

### 문서 내 다른 콘텐츠 작동 방식

테이블과 같은 집중 모드가 있는 위젯의 경우, 문서 안에서도 몰입 모드로 접근할 수 있습니다. 크기가 자동으로 조정되어 문서 안에서 스크롤 가능합니다.

또한 콘텐츠를 문서 밖으로 드래그해 다시 보드에 배치할 수 있습니다.

## 문서의 형식 지정

문서에서는 텍스트를 읽기 쉽고 이해하기 쉽게 만들기 위한 기본적인 텍스트 서식 옵션을 제공합니다.

문서 내에서 서식 설정을 원하는 텍스트를 선택하면 툴바를 열 수 있습니다:

![docs-formatting-toolbar.png](https://help.miro.com/hc/article_attachments/26368753513362)

*문서의 서식 툴바*

**텍스트 스타일** 아이콘을 클릭하여 텍스트를 굵게, 밑줄, 기울임꼴, 취소선 스타일로 설정할 수 있습니다:

![docs-formatting.png](https://help.miro.com/hc/article_attachments/26368741826706)

*문서의 텍스트 스타일 아이콘 메뉴*

여러 종류의 제목과 목록 유형을 선택하여 문서에 구조를 더할 수 있습니다:

![docs-headings.png](https://help.miro.com/hc/article_attachments/26368753525906)

*문서 내 제목 및 목록 유형 하위메뉴*

문서 내에서 단락 또는 다른 블록을 강조 표시(Callout)로 포맷할 수 있습니다. 강조 표시로 변환할 블록을 선택한 후 텍스트 포맷 메뉴에서 **강조 표시**를 선택하세요. 이 블록에 아이콘과 배경색을 적용합니다. 블록의 오른쪽 상단에 있는 선택기를 사용하여 배경색을 변경할 수 있습니다.

슬래시 메뉴(또는 **/**을 입력하거나 **+** 아이콘을 클릭한 후 **강조 표시**를 선택)를 통해서도 강조 표시를 추가할 수 있습니다.

### 이모티콘 사용하기

문서에 이모티콘을 추가하려면 콜론 "**:**"을 입력한 후 원하는 이모티콘 이름의 두 글자 이상을 입력하세요. 예를 들어, "**:sm**"입니다. 그러면 Miro가 관련 이모티콘 제안을 팝업으로 표시하여 적절한 이모티콘을 빠르게 선택하고 삽입할 수 있습니다.

:::note
이모티콘은 유니코드 텍스트로 삽입되며, 운영 체제에 따라 약간의 시각적 차이가 있을 수 있습니다.
:::

콜론을 일반적으로 사용하려면 콜론 "**:**"을 입력한 후 아무 이모티콘도 선택하지 않고 계속 입력하십시오.

## 문서에서 키보드 단축키 사용하기

키보드 단축키를 사용해 텍스트에 머리글 및 목록 유형을 적용할 수 있습니다 (이 단축키는 단락 유형 하위 메뉴에서 확인 가능합니다):

변환: **cmd + opt + \{number\} 사용**

- 0 -> 단락
- 1 -> 제목 1
- 2 -> 제목 2
- 3 -> 제목 3
- 4 -> 글머리 기호 목록
- 5 -> 번호 매기기 목록
- 6 -> 체크 리스트

키보드 단축키를 사용하여 블록 선택 모드로 전환할 수도 있습니다. Escape 키를 한 번 눌러 블록 선택 모드로 들어간 후 다음을 따라 하세요:

- **shift + 위/아래** -> 선택 영역 확장
- **cmd + opt + 위/아래** -> 선택 영역 위아래로 이동

다음은 핫키를 통해 접근할 수 있는 문서 내의 다른 기능들입니다:

|  |  |
| --- | --- |
| **⌘** + **enter** | 포커스 텍스트 선택 메뉴 |
| **⌘** + **shift** + **X** | 취소선 적용 |
| **⌘** + **shift** + **U** | 링크 추가 |
| **⌘** + **E** | 인라인 코드 적용 |
| **⌘** + **,** | 체크리스트 항목 체크/체크 해제 |
| **⌘** + **/** | 블록 컨텍스트 메뉴 열기 |
| **⌘** + **D** | 선택한 블록 복제 |
| **⌘** + **I** | 블록에 대한 링크 복사 |

화면 오른쪽 아래의 **도움말 및 리소스** 아이콘을 클릭하여 Miro 앱 내에서 모든 키보드 단축키 목록에 접근할 수 있습니다:

![docs-keyboard-shortcuts.png](https://help.miro.com/hc/article_attachments/26368741839890)

*도움말 및 리소스 아이콘을 통한 키보드 단축키*

## 문서에서 Miro AI 활용하기

Miro AI를 사용하여 문서를 편집하는 것은 편집 과정을 빠르게 하고 간결하고 읽기 쉬운 문서를 만드는 훌륭한 방법입니다.

Miro AI를 사용하여 문서에서 강조 표시된 텍스트를 수정할 수 있습니다.

![](https://help.miro.com/hc/article_attachments/26368753534610)

*Miro 문서에서 강조된 텍스트를 수정하도록 Miro AI에 요청하기*

인터넷 문서에서 텍스트를 강조하여 Miro AI를 프롬프트하는 방법은 간단합니다. 문서 내에서 텍스트를 강조 표시한 후, 컨텍스트 메뉴에서 맨 오른쪽에 있는 **Miro AI로 향상**을 선택하세요. 드롭다운 메뉴에서 **사용자 정의 프롬프트** 또는 제공된 프롬프트 중 하나를 선택하세요.

Miro AI를 사용하여 전체 Miro 문서를 변경할 수도 있습니다. 이렇게 하려면 문서 위의 **더 많은 메뉴**를 클릭하고 **AI 도우미**를 선택하세요. 드롭다운 메뉴에서 제공된 프롬프트 중 하나를 선택하세요. AI가 생성한 텍스트가 있는 새 Miro 문서가 원본 문서 옆에 생성됩니다.

## Miro 문서에서의 협업

Miro 문서는 다른 사용자와 실시간으로 협업할 수 있게 해줍니다. 캔버스의 다른 콘텐츠와 마찬가지로, 커서 추적이 활성화되어 다른 사용자가 문서의 어느 부분에서 작업하고 있는지 볼 수 있습니다.

댓글 스레드와 댓글 리액션이 활성화되어 있으며, @멘션을 통해 다른 사용자에게 알림을 보낼 수도 있습니다 (앱 내 알림과 이메일로 통보됩니다).

### Miro 문서의 사용자 칩

사용자 칩을 사용하면 문서 내에서 사용자에 대한 정보를 제공할 수 있습니다. 예를 들어, 주요 팀 구성원이나 이해관계자에 대해 @사용자 칩을 추가할 수 있습니다.

Miro 문서에서 사용자 칩을 추가하려면 '@'을 입력합니다. 사용자명을 계속 입력하여 결과를 필터하거나 열리는 드롭다운 메뉴에서 사용자를 선택할 수 있습니다.

![Add user chips anywhere in a Miro doc.](https://help.miro.com/hc/article_attachments/26368753545618)

*Miro 문서 어디에나 사용자 칩을 추가하세요*

@사용자 칩에 마우스를 올리면 사용자에 대한 정보를 볼 수 있습니다.

![User chips include information about the user.](https://help.miro.com/hc/article_attachments/26368741853330)

*사용자 칩은 사용자에 대한 정보를 포함합니다*

사용자 칩은 댓글의 멘션과는 다르게 작동합니다. 예를 들어, 사용자 칩은 해당 사용자에게 알림을 보내지 않습니다.

### Miro 문서의 날짜 칩

날짜 칩은 **@** 기호를 입력하여 Miro 문서에 추가할 수 있습니다. 메뉴가 나타나며, 사용자 옵션 아래에 날짜 옵션이 제공됩니다.

*Miro 문서에 날짜 칩 추가*

## 문서 복사, 공유, 내보내기

문서는 보드 간에 복사할 수 있지만, 이후 변경 사항에 대해 동기화되지 않습니다. 즉, 하나의 보드에서 문서에 대한 편집을 진행하더라도 그 문서가 복사된 다른 보드에는 변경이 반영되지 않습니다.

문서는 링크를 통해 다른 사용자와 공유할 수 있습니다.

문서는 컨텍스트 메뉴의 **더보기 아이콘**(![icon-main.svg](https://help.miro.com/hc/article_attachments/26368753554450))에서 PDF 또는 Markdown 포맷으로 내보낼 수 있습니다.

문서를 Markdown으로 내보낼 때, 모든 텍스트 포맷이 변환됩니다. 문서에 임베드된 보드 객체는 원본 문서의 위젯으로 돌아가는 링크로 대체됩니다.
