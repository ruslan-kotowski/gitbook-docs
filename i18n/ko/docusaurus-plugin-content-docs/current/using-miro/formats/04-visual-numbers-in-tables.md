비주얼 숫자는 사용자가 숫자를 시각적 진행률 막대로 변환할 수 있게 해줍니다. 사용자는 맞춤형 색상으로 조건부 서식 규칙을 설정할 수 있으며, 보다 나은 데이터 시각화를 위해 최소/최대 범위를 설정할 수 있습니다. 비주얼 숫자는 또한 백분율 또는 통화 형식으로 숫자를 포맷할 수 있습니다.

## 숫자를 시각적으로 포맷하기

비주얼 숫자 포맷은 숫자 데이터를 진행률 막대로 변환하여 트렌드를 쉽게 파악하고 진행 상황을 한눈에 추적할 수 있게 합니다. 사용자는 숫자를 백분율 또는 통화로 표시하고, 사용자 지정 범위를 설정하고, 조건부 서식 규칙을 적용할 수 있습니다.

숫자 필드에 시각적 포맷을 적용하기:

1. 숫자 또는 수식 필드 이름 위로 커서를 이동하면 **세 점 아이콘** (**...**)이 표시됩니다.
2. **세 점 아이콘** (**...**)을 클릭하고 **필드 편집**을 선택하세요.
3. 대화 상자의 **표시 형식** 섹션에서 **막대**를 클릭하세요.
   숫자가 진행률 막대로 표시될 것입니다.
4. 형식을 선택하세요:
   1. 백분율 (%): 완료율, 진행 추적에 적합합니다.
   2. 통화: 주요 통화 중에서 선택하세요 ($, €, £, ¥ 등).
5. 진행률 막대의 **최소** 및 **최대** 범위를 설정하세요. 백분율의 경우, 일반적으로 0-100을 사용합니다. 통화의 경우, 데이터에 적합한 최소/최대 값을 설정하세요.
6. 색상 선택기에서 막대 색상을 선택하세요.
7. 숫자 레이블을 켜거나 끄세요:
   1. 켜짐: 진행률 막대와 함께 숫자 값을 표시합니다.
   2. 꺼짐: 깔끔한 보기를 위해 진행률 막대만 표시합니다.
8. **저장**을 클릭하세요.

## 조건부 서식 적용

조건부 서식을 사용하면 정의한 규칙에 따라 진행률 막대가 자동으로 색상이 지정되어 신속하게 주의가 필요한 값을 식별할 수 있습니다.

1. **필드 설정**을 열어 숫자 또는 수식 필드를 조정합니다.
2. **조건부 색상** 기능을 활성화합니다.
3. **규칙 추가**를 클릭합니다.
4. 규칙 정의:
   1. 조건을 선택하세요 (같다, 같지 않다, 크다, 작다, 크거나 같다, 작거나 같다, 비어 있다, 비어 있지 않다).
   2. 비교할 값을 입력하세요 (적용 가능한 경우).
   3. 이 규칙과 일치하는 값에 대한 색상을 선택하세요.
5. 필요에 따라 여러 규칙을 추가하세요. 우선순위를 설정하기 위해 규칙을 드래그하여 놓으세요. 상단에 있는 규칙이 우선 적용됩니다.
6. **저장**을 클릭하세요.

조건부 서식은 테이블 보기와 개별 레코드 보기 시 측면 패널에 나타납니다.

시각적 숫자 포맷팅은 현재 테이블 보기와 측면 패널에서만 사용할 수 있습니다.

타임라인, 칸반, 카드 보기는 표준 숫자 포맷팅을 표시합니다.
