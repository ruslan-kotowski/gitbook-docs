칸반 보기는 작업을 열에 따라 정리할 수 있어 진행 상황을 쉽게 파악하고 병목 현상을 찾아내어 팀의 일치성을 유지하는 데 도움이 됩니다. 칸반, 타임라인, 테이블 보기를 무리 없이 전환하여 한 곳에서 계획, 실행, 적응하세요.

## 주요 기능

- **칸반 보드 맞춤 설정**을 Miro 보드 어디에서나 수행할 수 있습니다.
- **카드 추가, 편집, 삭제**를 칸반 위젯 내에서 할 수 있습니다.
- **열 추가, 편집, 삭제 및 숨기기**를 칸반 위젯 내에서 할 수 있습니다.
- **스윔레인 생성**을 칸반 위젯 내에서 할 수 있습니다.
- **스티커 메모, Miro 카드, Jira 카드를 드래그 앤 드롭**하여 칸반 위젯에 넣을 수 있습니다.
- **카드 그룹화, 정렬 및 필터링**하여 정보를 논리적으로 구성할 수 있습니다.
- **테이블 또는 타임라인 레이아웃으로 전환**하여 데이터를 다양한 방식으로 시각화합니다.
- **여러 칸반 위젯 포함**하여 동일한 Miro 보드에 다양한 데이터 소스를 배치합니다.
- **전체 화면 모드에서 칸반 보드를 보고 편집**하여 집중력을 높입니다.

## 보드에 칸반 추가

:::warning
게스트 편집자는 칸반을 추가하거나 편집할 수 없습니다.
:::

1. Miro 보드 열기.
2. [작성 툴바](../../getting-started/start-here/your-first-board/05-toolbars.md)에서 **툴, 미디어 및 통합**(*![icon-tools.svg](../../../../../../docs/using-miro/formats/images/29210901366418_icon-tools.svg)*) 선택.
3. **칸반**을 검색하여 선택.
   커서가 칸반 아이콘으로 바뀝니다.
4. Miro 보드에 칸반 보드를 배치할 지점을 클릭.

## 칸반 카드 작업

칸반 위젯은 작업 관리에 사용할 수 있는 여러 카드 컨트롤을 제공합니다.

### 카드 추가

컬럼의 **더하기 기호** (**+**)를 클릭하세요. 새 카드가 컬럼에 나타납니다.

### 카드 이동

카드를 재배치하거나 이동하려면 카드를 드래그 앤 드롭하세요. 카드가 다른 컬럼으로 이동되면, 카드의 컬럼 필드도 변경됩니다.

### 카드 텍스트 편집

카드를 선택한 후 텍스트를 선택하세요. 커서가 깜박이면 텍스트를 편집할 준비가 된 것입니다.

카드 내 텍스트에 서식을 적용하거나 링크를 추가하려면:

1. 수정하려는 카드를 더블 클릭합니다.
   해당 항목이 편집 가능 상태가 됩니다.
2. 형식을 지정할 텍스트를 선택합니다.
   컨텍스트 메뉴가 나타납니다.
3. 컨텍스트 메뉴에서 형식을 적용하거나 [키보드 단축키](../working-on-the-board/06-shortcuts-and-hotkeys.md)를 사용하여 링크를 추가합니다.
4. Enter를 눌러 항목을 저장합니다.

텍스트 형식은 카드 편집 시 측면 패널에서도 적용할 수 있습니다.

### 카드 색상 변경

1. 카드를 클릭하면 **색상 원**이 나타납니다.
2. **색상 원**을 클릭해 색상 선택기를 엽니다.
3. 색상을 선택합니다.

### 카드 필드 편집

1. 카드를 선택합니다.
2. **측면 패널에서 레코드 열기** 아이콘을 클릭해 측면 패널을 엽니다.
3. 필요에 따라 카드 필드를 편집합니다.
4. 또한, 표 레이아웃으로 전환해 테이블의 행으로 칸반 카드를 더 자세히 볼 수 있습니다.

칸반 카드에서 표시할 카드 필드를 결정할 수도 있습니다:

1. 칸반 헤더에서 필드 숨기기 아이콘을 클릭해 메뉴를 엽니다.
2. 칸반 카드에서 표시할 필드를 선택하여 표시 또는 숨깁니다.
   카드는 실시간으로 업데이트됩니다.

### 카드 삭제하기

1. 카드를 선택합니다.
2. 키보드에서 삭제 또는 백스페이스를 누릅니다. 또는 레코드를 클릭해 휴지통 아이콘을 통해 삭제할 수 있습니다.
3. 레코드가 이제 삭제되었습니다.

## 칸반 열 작업

칸반 위젯 내에서 작업을 더 효과적으로 관리하기 위한 여러 열 작업이 있습니다.

### 칸반 열 추가하기

1. 칸반의 가장 오른쪽에서 **열 생성**을 클릭하세요.
2. 또는 열 이름 옆의 **세 점 아이콘** (**...**) 메뉴에서 칸반 열을 추가할 수 있습니다.

### 칸반 열 편집

1. **열 이름**을 클릭하세요.
2. 열 이름을 바꾸고, 열 색상도 여기에서 변경할 수 있습니다.
3. 또한, 열 이름 옆의 **세 점 아이콘** (**...**) 메뉴에서 칸반 열 이름을 바꿀 수 있습니다.

### 열 숨기기

1. 열 이름 옆 **세 점** (**...**) 아이콘을 클릭합니다
2. 메뉴에서 **열 숨기기**를 클릭합니다.
3. 오른쪽에 있는 **눈 모양** 아이콘을 클릭하여 열을 다시 보이게 합니다

### 열 이동

1. 열 이름 옆 **세 점** (**...**) 아이콘을 클릭합니다.
2. **왼쪽으로 이동** 또는 **오른쪽으로 이동**을 클릭합니다.

드래그 앤 드롭 기능은 곧 제공될 예정입니다.

### 열 삭제

1. 열을 클릭합니다 **세 점 아이콘** (**...**).
2. **열 삭제**를 클릭합니다.

### 사용할 열 변경

1. 칸반 헤더에서 **열 필드** 아이콘을 클릭합니다.
2. 열로 사용할 단일 선택 필드 중 원하는 필드를 선택합니다.
3. 또는, 열로 사용할 새 필드를 편집하거나 생성할 수 있습니다.

:::note
현재는 단일 선택 필드만 열로 사용할 수 있습니다.
:::

### 스윔레인 생성

1. 칸반 헤더에서 **그룹** 아이콘을 클릭합니다.
2. 스윔레인으로 사용할 필드를 선택합니다.
3. 또는, 스윔레인으로 사용할 새로운 필드를 생성할 수 있습니다.
4. 스윔레인을 제거하려면 **그룹** 아이콘을 다시 클릭하고 **그룹 해제**를 클릭합니다.

### 포커스(전체 화면) 모드

포커스(전체 화면) 모드에서 칸반을 편집하고 볼 수 있습니다. 위젯 상단의 **대각선 화살표 아이콘** 을 클릭하기만 하면 됩니다. 필터, 정렬, 그룹화, 필드 숨기기 등의 설정은 헤더에 위치합니다.

캔버스로 돌아가려면 상단의 **캔버스로 이동** 을 클릭합니다.

## 칸반에 Jira 카드 추가하는 방법 (베타)

Jira 카드를 칸반으로 드래그 앤 드롭하면 Jira와 연동된 기록을 생성할 수 있습니다. 이를 통해 Miro와 Jira의 작업을 칸반 보기에 결합하여 팀 전체의 작업을 한 곳에서 관리하고 추적할 수 있습니다.

칸반에 Jira 카드를 추가하려면 다음을 따르세요:

1. 캔버스에서 관련된 Jira 카드를 찾습니다.
2. 카드를 칸반 위로 드래그합니다.
3. 카드를 칸반의 대상 칼럼에 드롭합니다.

Miro에서 이루어진 변경사항은 Jira에서도 반영되며 그 반대도 마찬가지입니다. 테이블이나 타임라인 내에서 다음 필드가 Jira와 동기화됩니다:

- 제목
- 설명
- 추정
- 시작일
- 종료일
- 담당자 (베타)
- 상태 (베타)

**추가 정보:** [Jira 카드 자주 묻는 질문](../../integrations-apps/atlassian/17-jira-cards-faq.md)을 참조하세요.
