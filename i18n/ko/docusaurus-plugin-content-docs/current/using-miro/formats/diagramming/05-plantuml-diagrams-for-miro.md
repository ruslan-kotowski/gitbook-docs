Miro의 PlantUML 앱은 코드 기반 다이어그램을 직접 Miro 보드에 생성하고 임베드할 수 있게 해줍니다. 이 통합은 Miro 환경을 떠나지 않고 텍스트 기반 설명에서 다이어그램을 생성할 수 있도록 지원하여 워크플로를 간소화합니다.

## PlantUML 앱 설치

Miro 보드에서 다이어그램을 생성하려면 PlantUML 앱을 설치할 수 있습니다. 앱은 Miro 마켓플레이스 또는 Miro 보드의 작성 툴바에서 직접 사용할 수 있습니다.

1. 작성 툴바에서 **툴, 미디어, 통합**(**+**)을 선택하세요. **툴, 미디어, 통합** 패널이 열립니다.
2. **도구** 탭에서 **PlantUML 다이어그램**을 검색하여 선택하세요. **PlantUML Diagrams** 패널이 열립니다.
3. 메시지가 표시되면 Miro 팀을 선택하고 **설치 및 승인**을 클릭해 설치를 완료하세요.

:::warning
관리자가 아닌 사용자는 팀 설정에서 허용하지 않는 경우 앱을 설치할 수 없습니다.
:::

앱은 [Miro 마켓플레이스](http://miro.com/marketplace)나 [이 링크](https://miro.com/marketplace/plantUML/)를 통해 직접 설치할 수도 있습니다.

## Miro 보드에 다이어그램을 만들고 추가하기

PlantUML 앱을 설치하면 작성 툴바에서 찾을 수 있습니다. 이 단계에 따라 다이어그램을 만들고 추가하세요.

![PlantUML Diagrams app on the Creation toolbar](../../../../../../../docs/using-miro/formats/diagramming/images/21537438798994_plantuml-entry-point.png)
*작성 툴바의 PlantUML 다이어그램 앱*

1. 작성 툴바에서 PlantUML 앱을 여세요.
2. 편집기에 PlantUML 코드를 입력하세요. 앱에는 시작할 수 있는 기본 샘플이 포함되어 있습니다. 코드를 입력하거나 수정할 때 오른쪽 패널의 다이어그램 미리 보기가 자동으로 업데이트됩니다.

![PlantUML 다이어그램 변경](../../../../../../../docs/using-miro/formats/diagramming/images/21017043137938_PlantUML%20diagram.gif)
*다이어그램 변경하기*

3. 코드 편집기 패널의 크기는 필요에 따라 오른쪽 끝을 드래그해 조정하세요.

![PlantUML 편집기의 너비 변경](../../../../../../../docs/using-miro/formats/diagramming/images/21017013630226_change%20the%20width%20of%20editor.gif)
*코드 편집기의 크기 변경하기*

4. 다이어그램이 준비되면 **보드에 추가** 버튼을 클릭하세요. 이 작업은 다이어그램의 이미지를 생성하여 Miro 보드에 배치합니다.

![보드에 PlantUML 다이어그램 추가하기](../../../../../../../docs/using-miro/formats/diagramming/images/21017013631250_add%20PlantUML%20diagram%20to%20board.gif)
*보드에 다이어그램 추가하기*

다이어그램을 보드에 추가한 후 이미지를 다운로드하거나 [보드를 공동 작업자와 공유](../../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)할 수 있습니다.

## 기존 다이어그램 편집

Miro 보드에 이미 있는 PlantUML 다이어그램을 편집할 수 있습니다. 다이어그램 수정하기:

1. 보드에서 다이어그램을 클릭하여 선택하세요.
2. 작성 툴바에서 **PlantUML** 아이콘을 클릭하세요. PlantUML 편집기가 다이어그램 코드와 함께 열립니다.
3. 코드에 변경 사항을 적용하세요.
4. **다이어그램 업데이트**를 클릭하세요. 귀하의 Miro 보드로 돌아가며, 다이어그램이 변경 사항으로 업데이트됩니다.

![Miro 보드에서 PlantUML 다이어그램을 편집하기](../../../../../../../docs/using-miro/formats/diagramming/images/21017013632530_diagrams_editing_plantuml_diagrams.gif)
*Miro에서 다이어그램 직접 편집하기*

## 추가 정보

PlantUML의 구문 및 기능에 대한 자세한 정보는 [공식 PlantUML 문서](https://plantuml.com/)를 참조하세요. Miro의 앱 패널 왼쪽 하단 모서리에 있는 링크를 통해 PlantUML 문서에 빠르게 접근할 수 있습니다.
