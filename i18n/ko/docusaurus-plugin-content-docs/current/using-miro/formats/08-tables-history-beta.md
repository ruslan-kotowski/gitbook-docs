테이블 기록 및 버전 관리 기능을 통해 테이블에서 누가, 무엇을, 언제 변경했는지 확인할 수 있습니다. 팀 내 모든 필드 변경, 열 추가 및 데이터 업데이트를 추적하여 Miro를 벗어나지 않고도 안전하게 협업하고 신속하게 문제를 해결하며 규정 준수를 충족할 수 있습니다.

## 테이블 기록 보기

1. 테이블을 클릭해 컨텍스트 메뉴를 표시하세요.
2. 컨텍스트 메뉴에서 더보기 아이콘을 클릭하세요.
3. 메뉴에서 버전 기록을 선택하세요.
   버전 기록 패널이 보드 옆에 열립니다.
4. 날짜 옆의 화살표를 클릭하여 해당 날짜의 버전 기록과 편집한 사람을 확인하세요.

:::warning
베타 버전에서는 이전 버전의 미리보기가 제공되지 않습니다. 대신, "사본으로 복원" 기능을 사용하여 테이블의 이전 버전을 검토할 수 있습니다.
:::

### 버전 복원하기

1. 버전 기록 패널에서 날짜 옆의 화살표를 클릭해 버전 기록을 확인합니다.
2. 복원하고자 하는 버전 옆의 복원 아이콘을 클릭합니다.
3. 열리는 대화 상자에서 보드에 **복사본으로 복원**할지 **현재 버전 대체 복원**할지를 선택합니다.

:::note
**복사본으로 복원**하면 현재 테이블 버전 옆에 테이블 복사본이 생깁니다.
:::
