프로필 설정에서 몇 번의 클릭만으로 Miro에서 언어를 업데이트할 수 있습니다. 언어 설정은 Miro 보드, 대시보드, 설정에 반영됩니다.

## 지원되는 언어

Miro는 현재 다음 언어를 지원합니다.

- 영어
- 프랑스어
- 독일어
- 일본어
- 스페인어
- 포르투갈어

> **사용 가능**: 모든 플랜
> **사용 가능 환경**: 데스크톱 브라우저, 데스크톱 앱, 태블릿 앱의 일부 제한 사항

## Miro에서 언어 변경하기

1. [프로필 설정으로](https://miro.com/app/settings/user-profile) 이동하세요.
2. 아래로 스크롤해 **언어로** 이동합니다.
3. 드롭다운 메뉴에서 선호하는 언어를 선택하세요.

:::note
언어 설정은 현재 브라우저에서만 사용할 수 있으며 Miro 보드, 대시보드, 설정의 사용자 인터페이스에도 적용됩니다.
:::

![Miro-language-settings.png](images/21857780534418_Miro-language-settings.png)

## 미등록 Miro 사용자를 위한 언어 설정

등록된 Miro 사용자가 아니거나 로그인하지 않아 프로필 설정에 액세스할 수 없는 경우에도 선호하는 언어를 사용해 협업할 수 있습니다.

보드 메뉴 > **환경 설정** > **언어에서** 언제든지 언어 설정을 조정하세요.

![Langauge-settings-for-non-registered-users.png](../../../../../../docs/using-miro/managing-your-profile/images/21017005473042_Langauge-settings-for-non-registered-users.png)
*로그인하지 않은 사용자의 Miro 언어 설정*

## 자주 묻는 질문

**모든 기능이 내 언어에 맞게 현지화되지 않는 이유는 무엇인가요?**

Miro를 지역화하는 여정을 시작하는 중입니다. 학습 센터, 알림, 도움말 센터, 기타 여러 영역을 포함한 추가 기능 및 재설정을 계속 업데이트하려면 저희에게 문의하세요. Miro는 더 나은 사용자 경험을 제공하기 위해 지속적으로 업데이트되므로 다국어 업데이트 사이에 지연이 있을 수 있습니다. 최신 정보는 영어 버전을 확인하세요.

**웹 사이트가 다른 언어로 제공되는 이유는 무엇인가요?**

웹사이트 및 제품 언어 사용 가능 여부는 다를 수 있습니다. [커뮤니티 위시 목록에서](https://community.miro.com/ideas) 다음에 보고 싶은 언어에 관심을 가져보세요.

**언어 설정이 사용자에 대해 자동으로 선택되어 있나요?**

원활한 사용자 경험을 즐기기 위해 저희는 귀하가 선호하는 언어를 검색하기 위해 최선을 다하고 있습니다. Miro 프로필 설정에서 언제든지 언어 기본 설정을 업데이트할 수도 있습니다.
