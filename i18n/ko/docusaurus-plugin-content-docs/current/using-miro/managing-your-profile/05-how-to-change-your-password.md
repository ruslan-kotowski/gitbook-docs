Miro 비밀번호는 언제든지 변경할 수 있습니다.

:::note
[SSO](../../enterprise-administration/security-integrations/single-sign-on-sso/09-single-sign-on-sso.md)(통합로그인) 방식으로 Miro에 접속하는 경우, 비밀번호 변경 옵션을 사용할 수 없습니다.
:::

:::note
비밀번호를 변경하면 다른 모든 기기에서의 Miro 세션이 종료됩니다.
:::

### 프로필 설정에서 비밀번호 변경 방법

1. 프로필 설정을 [열기](https://miro.com/app/account/profile/).
2. **비밀번호**로 스크롤하고, **변경**을 클릭합니다.
3. 새 비밀번호와 현재 비밀번호를 입력하세요.
4. **비밀번호 저장**을 클릭합니다.

![change_password_in_Miro.jpg](../../../../../../docs/using-miro/managing-your-profile/images/21017013080210_change%20password%20in%20Miro.jpg)*Miro 프로필 설정에서 비밀번호 변경*

### 비밀번호를 재설정하는 방법

1. 비밀번호를 재설정하려면 [Miro 로그인 페이지](https://miro.com/login/)에서 **비밀번호****를 잊으셨나요?**를 클릭합니다.
   ![](../../../../../../docs/using-miro/managing-your-profile/images/33980392064530_image.png)***비밀번호를 잊으셨나요?**는 비밀번호 재설정 안내로 연결됩니다. 하단의 **비밀번호 재설정**을 클릭할 수도 있습니다.*
2. Miro에 로그인할 때 사용하는 이메일 주소를 입력하고 **계속**을 클릭합니다. 비밀번호 재설정 안내를 보내드립니다.
3. 받은 이메일 속 링크를 클릭합니다.
4. 새 비밀번호를 만들고 **계속**을 클릭하세요.
5. 새 비밀번호로 로그인하세요.

## Miro 비밀번호 요구 사항

Miro 비밀번호는 다음의 요구 사항을 충족해야 합니다:

- 최소 8자
- 대문자 최소 1자
- 소문자 최소 1자
- 숫자 최소 1자
- 특수문자 최소 1자

![](../../../../../../docs/using-miro/managing-your-profile/images/33980392064530_image.png)*Miro는 실시간으로 비밀번호 요건 충족 여부를 표시합니다.*

## 자주 묻는 질문

- *비밀번호를 재설정하려 했으나 복구 이메일을 받지 못했습니다. 어떻게 해야 하나요?*
  - 제출한 이메일 주소에 오타가 없는지 확인하세요. 오타를 발견했다면 비밀번호 복구를 다시 시도하세요. **스팸, 프로모션, 정크, 소셜**, 그리고 **업데이트** 폴더를 열어 Miro 확인 이메일이 있는지 확인하세요.
  또한 방화벽이 이메일이 받은편지함에 도달하지 못하게 할 수도 있습니다. 관리자를 통해 필요한 [도메인과 하위 도메인](../troubleshooting-technical-questions/technical-guidelines/07-miro-domains-reference.md)을 허용 목록에 추가하도록 요청하세요.
- *복구 이메일의 링크를 클릭하면 "문제가 발생했습니다! 사용 중인 복구 코드가 올바르지 않습니다."라는 오류 메시지가 표시됩니다. 비밀번호를 어떻게 재설정할 수 있나요?*
  - 브라우저의 시크릿 모드에서 [Miro 로그인 페이지](https://miro.com/login/)와 이메일을 열어주세요. **비밀번호를 잊으셨나요**를 클릭해 비밀번호 재설정 이메일을 요청하세요. 받은 새 이메일에서 링크를 클릭하세요.

문제가 지속되면 [Miro 지원팀에 문의하세요](../tools/troubleshooting/06-contacting-miro-support.md).
