## 여러 오브젝트 선택

[선택 툴](21-work-smarter-not-harder.md)을 활성화했는지(또는 **V** 키를 눌러 활성화) 확인하고 필요한 오브젝트 전체로 선택 필드를 드래그하세요. 그러면 선택된 모든 오브젝트가 선택됩니다 (단, [USM](../advanced-tools/07-user-story-mapping.md), [칸반](../advanced-tools/02-columns-formerly-kanban.md), [마인드맵](../advanced-tools/03-mind-map.md), [테이블](../advanced-tools/05-grid.md)은 제외하며, 이러한 오브젝트를 선택하려면 선택 필드가 90% 이상 포함되어야 합니다.) [모바일](../../getting-started/apps-for-devices/08-mobile-app.md) 또는 [태블릿 앱](../../getting-started/apps-for-devices/11-tablet-app.md)에서 작업하거나 터치스크린을 사용하는 경우 **길게** 탭하고 드래그하세요.

오브젝트 필터 기능을 사용해 이동할 특정 오브젝트 유형을 선택할 수도 있습니다. 모든 오브젝트를 클릭하고 드래그하여 선택한 다음 컨텍스트 메뉴에서 **필터**를 클릭하고 오브젝트 유형을 선택하세요. 선택 필드가 조정되고, 필터링한 오브젝트만 이동할 수 있습니다.

![object-select.png](../../../../../../docs/using-miro/working-on-the-board/images/25827368311698_object-select.png)
*오브젝트 유형별 필터*

표면의 90% 이상을 차지하는 오브젝트만 포함된 *정확한* 선택을 시작하려면 길게 클릭/누르고 드래그하세요. 이 기능은 다른 배경 도형 위에서 오브젝트를 선택해야 하는 경우에 유용합니다.

키보드로 작업하는 경우 **Shift** 또는 **Ctrl***(Windows)/***Command***(Mac)* 키를 누른 상태에서 특정 오브젝트를 하나씩 클릭하여 선택할 수도 있습니다.

### 정확한 선택

정확한 선택 기능은 오브젝트의 표면을 90% 이상 덮을 때만 오브젝트를 선택할 수 있게 해줍니다.

정확한 선택을 사용하려면 선택 툴을 사용하고 있는지 확인하세요. 그런 다음 마우스 버튼을 길게 클릭하거나 길게 누르세요. 이제 정확한 선택을 사용해 선택 툴을 드래그할 수 있습니다.

## 라소 툴을 사용해 여러 오브젝트 선택

오브젝트를 선택하는 또 다른 방법은 라소 툴을 사용하는 것입니다. 오브젝트를 선택 영역에 포함하려면 그 중 90% 이상을 선택 영역에 포함해야 합니다.

:::tip
**Ctrl+A** / **Cmd+A** [단축키](06-shortcuts-and-hotkeys.md)를 사용해 보드의 모든 요소를 선택하세요.
:::

## 선택한 오브젝트 수정하기

선택한 오브젝트를 함께 이동하고 크기를 조정할 수 있습니다. 오브젝트를 [align](08-structuring-board-content.md), [그룹화](08-structuring-board-content.md), [잠금](17-locking-content-on-the-board.md), 필터링할 수 있으며(아래 참조), 메뉴에서 다른 옵션을 사용할 수 있습니다.

:::note
선택하려는 오브젝트가 [잠겨](17-locking-content-on-the-board.md) 있지 않은지 확인하세요. 그렇지 않으면 오브젝트를 클릭하고 **잠금 해제**를 선택해 먼저 잠금을 해제해야 합니다.
:::

:::warning
[테이블](../advanced-tools/05-grid.md) 내의 오브젝트 또는 서로 다른 [프레임](../essential-tools/07-frames.md)에 있는 오브젝트는 그룹화할 수 없습니다.
:::

:::warning
[방문자](../sharing-boards/08-collaboration-with-visitors.md)는 보드의 오브젝트를 잠그거나 잠금 해제할 수 없습니다. 오브젝트에 [보호 잠금](17-locking-content-on-the-board.md)이 활성화되어 있으면 보드 소유자/[공동 소유자](../sharing-boards/06-co-owners-of-boards-and-spaces.md)만 잠금을 해제할 수 있습니다.
:::

:::tip
오브젝트를 함께 이동하는 또 다른 방법은 하나의 프레임에 배치하고 프레임을 이동하는 것입니다. [Miro의 프레임](../essential-tools/07-frames.md)에 대해 자세히 알아보세요.
:::

스마트 복제

**Ctrl + D** 단축키를 사용해 보드의 오브젝트를 빠르고 쉽게 복제해 작업 속도를 높이세요.

:::note
**Alt + 화살표**를 사용해 오브젝트를 수직 또는 수평으로 복제할 수도 있습니다.
:::

## 오브젝트 잠금

오브젝트를 잠그어 실수로 이동, 편집 또는 삭제되는 것을 방지하세요. 보호 잠금을 사용해 다른 사용자가 콘텐츠를 변경하지 못하도록 하세요. 문서에서 자세히 알아보세요. [보드의 콘텐츠 잠금](17-locking-content-on-the-board.md).

## 오브젝트 정렬

이 옵션을 켜면 이동하는 모든 오브젝트에 대한 정렬 가이드가 생성되어 보드 오브젝트를 깔끔하고 균형있게 보이게 할 수 있습니다.

메인 메뉴에서 기능을 활성화/비활성화할 수 있습니다. **세 점 아이콘**(**...**) > **환경 설정** > **오브젝트 정렬**을 클릭하세요.

![align-objects.png](../../../../../../docs/using-miro/working-on-the-board/images/25827368311954_align-objects.png)
*보드 설정에서 오브젝트 정렬 활성화 옵션*

## 오브젝트 정렬

보드에 오브젝트를 정렬하세요. 이 기능은 특히 겹쳐 있는 콘텐츠가 많은 경우 보드 및 다이어그램의 스타일을 정확하게 지정하는 데 도움이 됩니다.

1. 오브젝트를 선택합니다.
2. 컨텍스트 메뉴에서 세 점 아이콘(**...**)을 클릭해 **추가** 메뉴를 여세요.
3. 다음 옵션 중 하나를 선택하세요.

- **맨 앞으로 가져오기:** 오브젝트를 모든 오브젝트 앞으로 이동하세요.
- **맨 뒤로 보내기:** 오브젝트를 모든 오브젝트의 뒤로 이동하세요.
- **앞으로 가져오기:** 오브젝트를 오브젝트 바로 앞쪽으로 이동하세요.
- **뒤로 보내기:** 오브젝트를 오브젝트 바로 뒤로 이동하세요.

:::note
이 기능은 프레임에서 사용할 수 없습니다. 프레임은 항상 보드 오브젝트 뒤에 배치됩니다.
:::

## 오브젝트 회전

보드의 오브젝트를 쉽게 회전시켜 콘텐츠를 조정하세요. 오브젝트 왼쪽 하단 모서리에서 회전 아이콘을 찾아 클릭하고 드래그하여 위치를 변경하세요.

![rotate-object.png](../../../../../../docs/using-miro/working-on-the-board/images/25827368312338_rotate-object.png)
*오브젝트 회전하기*

## 콘텐츠 지우기

여러 위젯(예: 스티커 메모, 도형, 카드)의 콘텐츠를 동시에 지울 수 있습니다. 이 기능은 선택한 위젯에서 모든 텍스트, 태그, 이모티콘, 작성자, 담당자, 마감일을 제거하여 원래 상태로 되돌리고 스타일(색상, 크기 등)은 유지합니다.

콘텐츠 지우기:

1. 지우려는 위젯을 선택하세요.
2. 마우스 오른쪽 버튼을 클릭하여 컨텍스트 메뉴를 여세요.
3. 메뉴에서 "콘텐츠 지우기"를 선택하세요.
4. 또는 단축키 Cmd + Backspace (Mac) 또는 Ctrl + Backspace (Windows)를 사용하세요.

콘텐츠 지우기 기능은 다른 위젯(예: 텍스트, 테이블 위젯)과 Jira 또는 Azure 카드에는 작동하지 않습니다. 사용자가 여러 스티커 메모, 도형, 카드를 선택하면 Jira/Azure 카드를 제외한 모든 위젯의 콘텐츠가 삭제됩니다.

## 자주 묻는 질문

1. *선택 필드를 드래그할 수 없습니다. 어떻게 해야 하나요?*  - [선택 툴](21-work-smarter-not-harder.md)로 전환하세요.
2. *선택한 오브젝트를 그룹화할 수 없습니다. 왜 그렇죠?*  - [테이블 내의 오브젝트](../advanced-tools/05-grid.md)와 다른 [프레임</a>에 있는 오브젝트는 그룹화할 수 없습니다.](../essential-tools/07-frames.md)
3. *그룹 내에서 개별 오브젝트를 선택하고 이동할 수 있나요?*  - 네, 오브젝트를 두 번 클릭하고 드래그하세요. 이 페이지에서 [어떻게 하는지 보세요](08-structuring-board-content.md).
