오브젝트를 외부 웹사이트나 보드 내 다른 오브젝트에 연결해 보드 콘텐츠를 더욱 풍부하게 만들어보세요.

다음으로 연결 옵션을 사용하면 다음과 같은 작업을 수행할 수 있습니다:

- 인터랙티브 프로토타입 만들기
- 보드 내 탐색 단순화
- 참조 및 유용한 소스에 대한 링크 추가
- [스티커 메모](../essential-tools/14-sticky-notes.md)나 [카드](../essential-tools/02-cards.md)를 작업 추적기 링크에 연결하세요.

## 오브젝트 연결

1. 연결하려는 오브젝트를 선택한 후 , 컨텍스트 메뉴에서 **세 점** (**...**) 아이콘을 클릭하세요
2. 컨텍스트 메뉴에서 **링크 복사**를 선택합니다.
3. 링크하고자 하는 오브젝트를 선택 **하고**, 컨텍스트 메뉴에서 **세 점** (**...**) 아이콘을 클릭합니다
4. 다음으로 연결**을 선택하거나** **Option +** **Cmd + K** (*Mac*) 또는 **Alt +** **Cmd + K** (*Windows*) 단축키를 사용합니다.
5. 링크하고자 하는 URL을 삽입하거나 보드에서 다른 오브젝트를 클릭하세요

:::tip
커맨드 팔레트를 사용해 오브젝트를 빠르게 연결하세요. 오브젝트를 클릭하고 **Cmd + K**를 탭하면 **오브젝트로 연결**이 메뉴의 첫 번째 항목으로 표시됩니다. 텍스트 필드에 링크를 단순히 붙여넣고 **Enter** 키를 누르세요.
:::

![linking_in_Miro.gif](../../../../../../docs/using-miro/working-on-the-board/images/21016057152146_linking%20in%20Miro.gif)
*스티커 메모에 Miro 블로그 링크 연결하기*

보드의 오브젝트는 *하나의* 웹 사이트나 Miro 오브젝트로만 연결할 수 있다는 점에 유의하세요. 외부 웹사이트, 다른 Miro 보드, 보드의 특정 오브젝트로 링크를 생성할 수 있습니다.
연결된 URL로 이동하려면 링크 아이콘을 클릭하기만 하면 됩니다.

![Link_to_Google_Calendar.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016043778834_Link%20to%20Google%20Calendar.jpg)
*링크 아이콘은 연결된 사이트의 로고를 표시합니다*

링크를 삭제하거나 편집하려면:

1. 컨텍스트 메뉴에서 세 점 아이콘을 클릭하세요.
2. **편집 링크**를 선택합니다.![edit_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057155218_edit%20link.jpg)*링크 편집 옵션*
3. 링크를 변경하거나 팝업에서 **링크 삭제**를 클릭합니다.![change_or_delete_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057156242_change%20or%20delete%20link.jpg)*링크 삭제 옵션*

## 보드의 오브젝트로 연결되는 링크

보드의 모든 오브젝트([프레임](../essential-tools/07-frames.md), 이미지, [도형](../essential-tools/11-shapes.md) 등)에 바로 연결되는 링크를 얻을 수 있습니다. 이 링크를 공동 작업자와 공유해 보드의 정확한 위치로 주의를 집중시키세요.

1. 연결하려는 오브젝트를 클릭하여 컨텍스트 메뉴를 표시하세요.
2. **세 점 아이콘** (**...**)을 클릭하세요.
3. **링크 복사**를 선택하세요.![copy_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057158162_copy%20link.jpg)*프레임의 링크 복사하기*

링크된 오브젝트가 삭제되면 링크를 누른 사용자에게 "*죄송합니다. 링크된 항목이 이 보드에서 삭제되었습니다*"라는 메시지가 표시됩니다. 액티비티 목록에서 [삭제된 콘텐츠를 복원](18-restoring-board-content.md)할 수 있습니다.

## 보드에 링크 붙여넣기

단축키를 사용해 보드에 링크를 붙여넣을 수 있습니다. **Ctrl + V** (*Windows 용*) 또는 **Cmd + V** (*Mac 용*). 링크에 미리보기가 표시됩니다.

*![link_to_help_center.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057159186_link%20to%20help%20center.jpg)
보드에 표시된 Miro 도움말 센터 링크*

미리 보기 없이 보드에 링크를 붙여넣으려면 [텍스트 툴](../essential-tools/16-text.md) 을 사용해 링크를 텍스트 상자에 붙여넣으세요.

## 텍스트에 링크 연결하기

텍스트가 포함된 오브젝트를 작업하는 경우 컨텍스트 메뉴에서 **링크** 아이콘을 클릭해 텍스트에 링크를 삽입하세요.

![insert_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016043786642_insert%20link.jpg)
 *링크 삽입 옵션*

텍스트를 선택하고 **Ctrl + V** (*Windows용*)/**Cmd + V** (*Mac용*)을 사용하여 링크를 붙여넣을 수도 있습니다.

![insert_link.gif](../../../../../../docs/using-miro/working-on-the-board/images/21016057161490_insert%20link.gif)
*텍스트 줄에 링크 삽입하기*

:::note
보드에서 두 오브젝트를 **링크 삽입** 옵션을 통해 연결한 후,보드를 복제하면 복사된 보드의 링크는 원본 보드로 연결됩니다. 그러나 다음으로 연결 옵션을 통해 보드의 두 오브젝트를 링크로 연결한 다음 보드를 복제하면, 복사된 보드의 링크는 내부에 남아 있습니다 (즉, 복사본 보드의 동일한 오브젝트로 연결됩니다).
:::

## 자주 묻는 질문

다른 Miro 보드로 연결되는 링크를 보드에 추가할 수 있나요?

네, 보드의 링크를 복사하거나 보드 내 특정 개체의 링크를 복사한 다음, 해당 링크를 원본 보드에 붙여넣으세요(또는 개체에 링크 추가하거나 [메모에 추가](../essential-tools/17-visual-notes.md)하세요). 또한 [Miro 보드를 임베드](../import-and-export/export/02-embed-a-miro-board.md)할 수 있습니다.

보드의 링크를 복사하려면 어떻게 해야 하나요?

보드 [공유 대화 상자](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)를 열고 **보드 링크 복사**를 클릭하세요. 간단히 브라우저 주소창에서 링크를 복사하는 방법도 있습니다. [데스크톱 앱](../../getting-started/apps-for-devices/05-desktop-app.md)에서 보드를 연 경우 **파일 > 보드 링크 복사**를 클릭합니다.

보드 내 특정 영역의 링크를 만들려면 어떻게 해야 하나요?

해당 영역을 포함하는 [프레임](../essential-tools/07-frames.md)을 만들고 프레임의 링크를 복사할 수 있습니다. [보드에 액세스할 수 있는 사용자](../sharing-boards/05-who-has-access-to-my-board.md)는 보드의 다른 영역도 탐색하고 볼 수 있다는 점에 유의하세요.

보드의 모든 링크를 한 번에 제거할 수 있나요?

캔버스에 붙여넣은 모든 링크를 클릭 몇 번으로 제거할 수 있습니다. [모든 오브젝트를 선택](10-working-with-objects.md)하고, 컨텍스트 메뉴에서 **필터**를 선택한 다음 **미리보기**를 선택하고 선택된 링크 오브젝트를 삭제합니다.
![filter_perviews.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057163410_filter%20perviews.jpg)
*선택한 오브젝트에서 미리보기 필터링하기*

컴퓨터의 로컬 파일에 연결할 수 있나요?

아니요. 보안상의 이유로 클라우드 기반 서비스에 파일을 업로드하고 해당 위치의 링크를 연결하세요.

Miro는 이메일 주소의 하이퍼링크를 mailto: 링크로 인식할 수 있나요?

현재로서는 지원되지 않는 기능입니다.
