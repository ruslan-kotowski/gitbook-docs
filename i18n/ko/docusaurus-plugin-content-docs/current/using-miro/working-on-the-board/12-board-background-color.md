Miro 보드의 배경색을 변경해 보다 편안한 시청 경험을 하거나 작업에 개인적인 감각을 더하세요. 11개의 배경 색상 중에서 선택하세요.

보드의 배경색을 변경하면 시각적 매력을 향상시킬 수 있습니다. 회색이나 검정색과 같은 어두운 색을 사용하면 눈의 피로를 줄이는 데 도움이 될 수 있습니다.

:::note
보드의 배경색을 변경하면 보드의 모든 사용자가 업데이트된다는 점에 유의하세요. 어두운 배경색은 눈의 피로를 줄이는 데 도움이 되지만, 전체 어두운 모드 경험을 복제하지는 않습니다.
:::

## 보드 배경색 변경

1. 보드 바에서 세 점 아이콘을 선택하세요.
   **메인** 메뉴가 열립니다.
2. **보드** > **배경색** 선택
3. 색상을 선택하세요.
   배경색이 자동으로 업데이트됩니다.

## 기능 제한 사항

- 보드를 내보낼 때 보드 배경색은 포함되지 않습니다.
- 보드 배경색은 [보드 변경 이력](../managing-boards/11-board-history-activity.md)에 반영되지 않습니다.

## 자주 묻는 질문

보드 배경색을 변경하는 옵션이 표시되지 않는 이유는 무엇인가요?

보드 편집 권한이 없을 수 있습니다. 보드 소유자에게 문의하여 편집 액세스를 요청하거나 배경색 변경을 요청하세요.
