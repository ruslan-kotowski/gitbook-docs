Miro에서 **마우스**, **트랙패드**, **터치스크린**으로 작업할 수 있습니다.

마우스를 사용하는 경우:

- 보드 위에서 이동하려면 마우스 오른쪽 버튼을 누르고 드래그하세요.
- 확대/축소하려면 마우스 휠을 스크롤하세요.
- 선택 필드를 만들려면 선택 툴로 전환한 뒤 캔버스를 클릭하고 드래그하세요.

트랙패드를 사용하는 경우:

- 두 손가락으로 밀어 보드 위에서 이동하세요.
- 핀치로 확대/축소
- 오브젝트를 선택하려면 선택 툴로 전환한 후, 캔버스를 누르고 드래그하세요.

터치스크린을 사용하는 경우:

- 캔버스를 드래그해 보드 위에서 이동하세요.
- 핀치로 확대/축소
- 길게 눌러 드래그해 오브젝트를 선택하세요.

팁을 보려면 **메인 메뉴** 햄버거 아이콘 > **환경설정** > **마우스 또는 트랙패드** > **자세히 알아보기**를 클릭하세요.

**자동 전환**으로 기본 설정되어 있지만, **마우스** 또는 **트랙패드**로 변경할 수 있습니다. 탐색 모델은 모든 사용자에 대해 개별적으로 설정되며 현재 브라우저의 모든 탭에 적용됩니다.

- Apple 매직 마우스로 작업하는 경우 **마우스**를 선택하세요. **마우스**를 선택하고 트랙패드를 사용하는 경우 두 손가락으로 슬라이드하면 확대/축소됩니다.
- 마우스나 그래픽 태블릿과 함께 트랙패드를 사용하는 경우 **트랙패드**를 선택하세요. 트랙패드 모드는 평소 휠로 스크롤하고 마우스 휠 + **Ctrl** (*Windows용*)/**Cmd** (*Mac용*)으로 확대하는 데 익숙한 경우 가장 편리합니다.

![new-mouse-trackpad.png](../../../../../../docs/using-miro/working-on-the-board/images/28438517225618_new-mouse-trackpad.png)
*마우스와 트랙패드 간 내비게이션 전환*

보드의 아무 곳에서나 마우스 오른쪽 버튼으로 클릭하고 **마우스 또는 트랙패드**를 선택해 컨트롤을 열 수도 있습니다.

터치 이벤트는 마우스 또는 트랙패드 이벤트와 자동으로 구별되므로 터치스크린 장치에 특정 탐색 모드를 설정할 필요가 없습니다.

### 이동 및 선택 도구 간 전환하기

보드 주위를 이동하려면 손 모드로 전환하세요. 오브젝트를 선택하려면 선택 모드를 활성화하세요. 툴바에서 선택 툴을 활성화/비활성화하거나 [단축키](21-work-smarter-not-harder.md) **V** 및 **H**를 사용해 두 모드 사이를 전환할 수 있습니다.

![select_and_hand_mode.gif](../../../../../../docs/using-miro/working-on-the-board/images/4604597173522_select%20and%20hand%20mode.gif)*이동 및 선택 툴 간 전환하기*

Miro에서 인증되지 않았거나 [보드 콘텐츠 설정](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)에서 보드 오브젝트를 복사할 수 없도록 허용된 뷰어/댓글 작성자는 선택 툴을 사용할 수 없습니다.

마우스를 사용하면 보드 주위를 이동할 수도 있습니다.

- 마우스 오른쪽 버튼을 누른 상태에서
- 스페이스 바를 누른 상태에서 마우스 왼쪽 버튼을 사용합니다.
- 마우스 휠을 누른 상태에서 마우스 왼쪽 버튼을 눌러 이동(일부 마우스만 사용 가능)

### 보드에서 탐색하기

보드 오른쪽 하단 모서리에서 탐색 컨트롤을 찾으세요. 컨트롤을 사용하면 확대 수준을 변경하고 보드 콘텐츠를 화면에 맞출 수 있으며, **M** 핫키를 통해 미니맵을 열고 탐색할 수 있으며 홍보하거나 숨길 수도 있습니다. 또한 전체 화면 모드를 시작하거나 종료할 수 있습니다.

## 자주 묻는 질문

**탐색 설정에서 터치스크린 모드를 찾을 수 없습니다. 터치스크린에서 Miro를 사용할 수 있나요?**

네, 모든 터치스크린 장치에서 Miro를 사용할 수 있습니다. Miro는 터치 이벤트를 자동으로 감지하고 마우스/트랙패드 이벤트와 구별합니다. 터치스크린은 설정에서 선택한 마우스나 트랙패드와 관계없이 항상 위에서 설명한 대로 작동합니다.

**Miro는 그래픽 태블릿과 호환되나요?**

Miro는 그래픽 태블릿으로 사용할 수 있지만 전용 탐색 모드는 제공하지 않습니다. 그래픽 태블릿 펜은 마우스로 인식되며 특정 기능을 지원하지 않고 기본적으로 작동합니다.

**트랙패드가 동작하지 않아 Miro 보드를 확대/축소할 수 없습니다. 어떻게 해결해야 하나요?**

Mac의 경우 화면 왼쪽 상단 모서리에서 Apple 메뉴를 클릭하고 > **시스템 설정** > **트랙패드** > **스크롤 및 확대/축소**를 선택한 다음 **확대 또는 축소** 토글을 껐다가 다시 켜세요. Windows의 경우, 화면 왼쪽 하단의 메뉴를 열고 > **설정** >  **장치** > **Touchpad** > 토글을  **터치패드**를 껐다가 다시 켜세요.

**보드 주위를 이동하려고 하면 보드 객체를 이동하게 됩니다. 이 문제를 어떻게 해결할 수 있나요?**

마우스 오른쪽 버튼을 클릭하고 드래그해 보드 위에서 이동할 수 있습니다.
