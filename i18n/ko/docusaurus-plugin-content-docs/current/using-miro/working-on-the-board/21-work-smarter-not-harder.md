Miro는 보드의 오브젝트 작업을 거의 무한한 가능성을 제공하므로 목표를 더 쉽고 빠르게 달성하는 방법에 대한 몇 가지 팁을 소개합니다.

## 보드 탐색

### 미니 맵 사용

보드 오른쪽 하단 모서리에서 찾을 수 있는 미니 맵을 사용하세요(또는 **M** [단축키를](06-shortcuts-and-hotkeys.md) 눌러 열거나 닫으세요).

![navigation_bar.gif](https://help.miro.com/hc/article_attachments/21857838007442)*보드 미니맵*

### 선택/이동 모드 간 전환

[단축키를](06-shortcuts-and-hotkeys.md) 사용해 특정 오브젝트를 선택하거나 보드 전체에서 이동하세요. **V** 및 **H** 단축키를 사용해 **선택/편집** 모드(커서 툴)와 **손/이동** 모드 사이를 전환하세요. 툴바에서 선택 모드를 활성화할 수도 있습니다.

:::tip
[이 문서에서](05-using-miro-with-a-mouse-trackpad-or-touchscreen.md) 보드를 탐색하는 방법에 대해 자세히 알아보세요.
:::

![work_smarter_select_tool.png](https://help.miro.com/hc/article_attachments/21857797954962)*툴바의 선택 툴*

## 오브젝트 작업하기

### 스마트 복제

**Ctrl + D** 단축키를 사용해 보드의 오브젝트를 빠르고 쉽게 복제해 작업 속도를 높이세요.

![smart_duplicating.gif](https://help.miro.com/hc/article_attachments/21857797957138)*스마트 복제*

:::note
**Alt + 화살표를** 사용해 오브젝트를 수직 또는 수평으로 복제할 수도 있습니다.
:::

### 정확한 다이어그램 작성을 위한 오브젝트 치수

전문 다이어그램을 더 빠르고 쉽게 제공하세요. [오브젝트 치수를](../formats/diagramming/01-miro-for-mapping-diagramming.md) 사용해 보드 전체에서 동일한 크기의 오브젝트를 정밀하게 생성하세요.

![Using_dimensions_in_Miro.gif](https://help.miro.com/hc/article_attachments/21857797958802)

### 오브젝트 잠금

오브젝트를 잠그어 실수로 이동, 편집 또는 삭제되는 것을 방지하세요. 보호 잠금을 사용해 다른 사용자가 콘텐츠를 변경하지 못하도록 하세요. 문서에서 자세히 알아보세요. [보드에서 콘텐츠 잠그기](17-locking-content-on-the-board.md)

![lock_content.jpg](https://help.miro.com/hc/article_attachments/21857797960594)*잠금 옵션*

### 오브젝트 정렬

이 옵션을 켜면 이동하는 모든 오브젝트에 대한 정렬 가이드가 생성되어 보드 오브젝트를 깔끔하고 균형있게 보이게 할 수 있습니다.

![main_menu_work_smarter_align_objects.gif](https://help.miro.com/hc/article_attachments/21857797968530)*보드 상에서 오브젝트 정렬하기*

메인 메뉴에서 기능을 활성화/비활성화할 수 있습니다. **햄버거 아이콘** > **환경 설정** > **오브젝트 정렬을** 클릭하세요.

![main_menu_work_smarter_align_objects.png](https://help.miro.com/hc/article_attachments/21857838020754)*보드 설정에서 오브젝트 정렬 활성화 옵션*

### 오브젝트 정렬

보드에 오브젝트를 정렬하세요. 이 기능은 특히 겹치는 콘텐츠가 많은 경우 보드 및 다이어그램의 스타일을 정확하게 지정하는 데 도움이 됩니다.

1. 오브젝트를 선택합니다.
2. 컨텍스트 메뉴에서 점 3개 아이콘(**...**)을 클릭해 **추가** 메뉴를 여세요.
3. 다음 옵션 중 하나를 선택하세요.

- **맨 앞으로 가져오기:** 오브젝트를 모든 오브젝트 앞으로 이동하세요.
- **뒤로 보내기:** 오브젝트를 모든 오브젝트의 뒤로 이동하세요.
- **앞으로 가져오기:** 오브젝트를 오브젝트 바로 앞에서 이동하세요.
- **뒤로 보내기:** 오브젝트를 오브젝트 바로 뒤로 이동하세요.

:::note
이 기능은 프레임에서 사용할 수 없습니다. 프레임은 항상 보드 오브젝트 뒤에 배치됩니다.
:::

오브젝트 선택 및 필터링

필터는 여러 항목을 선택하고 컨텍스트 메뉴에서 **필터를** 클릭하거나 오브젝트 유형을 선택해 특정 오브젝트 유형을 일괄 변경해야 하는 경우 매우 유용합니다. [이 문서에서](10-working-with-objects.md) 오브젝트 선택에 대해 자세히 알아보세요.

![Miro_filters.gif](https://help.miro.com/hc/article_attachments/21857797977746)*여러 오브젝트 선택, 필터링 및 수정하기*

오브젝트 회전

보드의 오브젝트를 쉽게 회전시켜 콘텐츠를 조정하세요. 오브젝트 왼쪽 하단 모서리에서 아이콘을 클릭하고 드래그해 아래 그림과 같이 위치를 변경하세요.

![rotate_an_object.gif](https://help.miro.com/hc/article_attachments/21857838025234)*오브젝트 회전하기*

## 문서 작업하기

### 여러 페이지 문서 분할

> **사용 가능 환경:** 브라우저 버전, [데스크톱 앱](../../getting-started/apps-for-devices/05-desktop-app.md)

문서나 PDF, Powerpoint 파일에서 협업할 수 있는 방법 모든 페이지를 확장해 보드에 표시한 다음 페이지에 댓글을 남길 수 있습니다.

PDF 또는 Powerpoint 파일을 특정 수의 페이지로 나누기:

1. 보드에 파일을 업로드하세요.
2. 파일을 클릭하고 컨텍스트 메뉴에서 ****페이지 추출을**** 선택하세요.
   > ✏️ 옵션은 [커서(선택)](#mini) 모드에서만 사용할 수 있습니다. 옵션이 메뉴에 표시되지 않으면 **V** 키를 누르거나 툴바에서 커서를 선택하고 오브젝트를 다시 클릭하세요.

   ![extract_pages.jpg](https://help.miro.com/hc/article_attachments/21857797983634)*PDF 컨텍스트 메뉴에서 페이지를 추출하는 옵션*
3. 파일 분할 방식을 **선택하세요(모두** 또는 특정 페이지만 해당).
   ![extract_pages.gif](https://help.miro.com/hc/article_attachments/21857797989010)*페이지 추출하기*

확장된 페이지는 원본 파일 바로 아래에 표시됩니다. 원본 파일에 필요하지 않은 경우 삭제할 수 있습니다. 추출된 모든 페이지가 보드에 유지됩니다.

페이지 고정

보드에 문서의 특정 페이지를 고정하려면 문서의 컨텍스트 메뉴에서 이 페이지로 전환하고 **핀을** 선택한 **다음 현재 페이지로 시작을** 선택하세요. 보드를 열 때마다 이 페이지가 첫 번째 페이지로 설정됩니다.

> **✏️** **현재 설정으로** [커서(선택)](#pan) 모드에서만 사용할 수 있습니다. 옵션이 회색으로 표시된 경우 **V를** 누르거나 툴바에서 커서를 선택하고 오브젝트를 다시 클릭하세요.

![pin_pages.jpg](https://help.miro.com/hc/article_attachments/21857838032402)*페이지 고정하기*

## 이미지 작업하기

### 이미지 바꾸기

캔버스의 다른 오브젝트에 영향을 주지 않고 보드의 모든 이미지를 교체할 수 있습니다.

1. 이미지를 클릭해 컨텍스트 메뉴를 여세요.
2. **이미지** 바꾸기 아이콘을 클릭하고 다음 옵션 중 하나를 선택하세요.

- **라이브러리에서 교체:** [이미지 및 아이콘](../essential-tools/08-images-and-icons.md) 앱이 열리고 새 이미지를 선택할 수 있습니다.
- **보드에서 교체:** 보드에 이미 있는 다른 이미지를 선택하라는 메시지가 표시됩니다.
- **장치에서 업로드:** 이미지를 업로드하고 장치의 이미지를 대체하세요.
- **URL을 통해 업로드:** 이미지의 URL을 대화 상자에 입력하여 이미지를 호스팅된 온라인 이미지로 대체하세요.

![Replace-images.png](https://help.miro.com/hc/article_attachments/21857838034450)

### 이미지 잘라내기

Miro에는 도구가 있으므로 타사 소프트웨어를 사용해 이미지를 자를 필요가 없습니다. 이미지를 선택하거나 컨텍스트 메뉴에서 **자르기를** 선택하세요. 이렇게 하면 **직사각형** 선택을 편집할 수 있는 자르기 모드가 활성화됩니다. 이미지 레이아웃이 시각적으로 선명하게 유지되도록 테두리를 주변 보드 콘텐츠에 맞춰보세요. 보드의 다른 콘텐츠와의 정렬을 유지하지 않고 자르는 이미지의 위치와 축척을 업데이트할 수 있습니다. 완료되면 보드의 아무 곳이나 클릭하기만 하면 됩니다.

![crop_image.gif](https://help.miro.com/hc/article_attachments/21857838035602)*이미지 자르기*

다양한 모양(예: 원, 사각형 **등)으로 이미지를 자를** 수 있습니다. 이미지를 선택하고 컨텍스트 메뉴에서 자르기 아이콘을 클릭한 다음 드롭다운에서 도형을 선택하세요.

![cropping_in_shapes.gif](https://help.miro.com/hc/article_attachments/21857838037650)*이미지를 원으로 자르기*

**다양한 모양으로 이미지를 일괄 자를** 수도 있습니다. 클릭한 다음 드래그해 이미지를 선택하고 컨텍스트 메뉴에서 자르기 아이콘을 클릭한 다음 드롭다운에서 도형을 선택하세요.

![](https://help.miro.com/hc/article_attachments/21857798000530)*이미지를 원으로 대량 자르기*

:::tip
잘라낸 이미지를 원래 크기로 되돌릴 수 있습니다. 두 번 클릭만 해 선택 영역을 원래 크기로 확장하면 됩니다.
:::

### 이미지 테두리

업로드한 이미지와 스크린샷에 테두리를 추가하거나 보드에 붙여넣어 눈에 띄게 띄게 하세요.

1. 이미지를 클릭하세요
2. 컨텍스트 메뉴에서 테두리 아이콘을 클릭하세요.
3. 색상을 선택하고 테두리 두께를 조정하세요

![Image_borders.gif](https://help.miro.com/hc/article_attachments/21857838041362)
*스크린샷에 이미지 테두리 추가하기*

### 이미지 크기 일괄 조정

보드의 여러 이미지의 높이 또는 너비로 한 번에 크기를 조정하세요. 그런 다음 [자동 레이아웃을](08-structuring-board-content.md) 사용해 즉시 정렬하세요.

**이미지 크기 조정**

1. 커서를 드래그해 크기를 조정할 모든 이미지를 선택하세요
2. 컨텍스트 메뉴에서 크기 조정 아이콘을 클릭하세요. 크기 조정 옵션이 표시되기 전에 여러 이미지를 선택해야 합니다
3. **높이 일치 또는 **너비** 일치를 선택합니다**
4. 오른쪽 상단 모서리의 회색 **자동 레이아웃** 아이콘을 클릭하세요.

*![Bulk_resizing_images.gif](https://help.miro.com/hc/article_attachments/21857838043154)**높이 또는 폭으로 이미지 대량 크기 조정*

### GIF 추가하기

Miro 보드에 GIF를 추가해 재미있는 애니메이션 콘텐츠로 아이디어를 실현하세요. 개별 사용자가 보드에 추가되거나 사용자가 마우스를 가져가면 8초 동안 또는 1회 루프를 재생할 수 있습니다. GIF는 보드와 상호 작용하는 각 사용자만 실시간으로 재생되는 것이 아니라 모든 사용자가 재생됩니다.

GIF 자동 재생을 비활성화하려면 [동작 감소를](../../getting-started/accessibility-in-miro/06-reduce-motion.md) 켜세요.

> 프레젠테이션과 [Miro Talktrack](../facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md)의 💡 GIF는 화면에 표시되는 동안 자동으로 재생되고 무한 루프됩니다.

   - 아니요, 현재는 불가능합니다.
