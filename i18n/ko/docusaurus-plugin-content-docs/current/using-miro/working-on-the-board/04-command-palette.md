커맨드 팔레트를 사용하면 Miro 툴과 앱을 빠르게 검색하고 실행할 수 있습니다. 커맨드 팔레트를 사용하면 최근 보드를 검색할 수도 있습니다.

커맨드 팔레트는 [편집 권한](../sharing-boards/01-board-access-rights.md)이 있는 사용자와 표준 보드 모드에서만 사용할 수 있습니다. 프레젠테이션 모드에서는 커맨드 팔레트를 실행할 수 없습니다.

## 커맨드 팔레트 사용 방법

1. 보드 툴바에서 **세로 세 점** (![icon-main.svg](../../../../../../docs/using-miro/working-on-the-board/images/24005170925074_icon-main.svg)) 아이콘을 선택하세요.
   메인 메뉴가 열립니다.
2. **편집** > **커맨드**를 선택하세요. 대신 **Cmd** + **K** 키보드 단축키를 사용하세요.
   커맨드 팔레트가 열립니다.
3. 검색 필드에 앱이나 툴 이름을 입력하기 시작하거나 목록을 스크롤하세요.
4. 클릭해 앱이나 툴을 실행하세요.
