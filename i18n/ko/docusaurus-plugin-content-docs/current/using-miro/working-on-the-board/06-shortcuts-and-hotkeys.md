### Windows 및 Mac 단축키

다음 표에는 Mac 및 Windows의 모든 단축키가 나와 있습니다.

텍스트 단축키는 보드 내 텍스트를 선택하거나 편집할 때 작동합니다.

1~9 숫자 키를 사용해 툴바에서 기본 순서대로 툴을 전환할 수 있습니다. 번호가 매겨진 단축키는 다시 매핑할 수 없습니다. 예를 들어, 숫자 키 **2**는 항상 템플릿 화면을 엽니다.
