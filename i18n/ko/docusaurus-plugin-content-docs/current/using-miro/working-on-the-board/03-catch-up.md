캐치업은 사용자가 마지막으로 보드를 본 이후로 발생한 변화를 AI 기반으로 간략하게 보여줍니다.

> ***사용 가능 플랜:** 모든 플랜*
> ***사용 가능 대상:** 데스크톱 앱, 데스크톱 브라우저*
> ***실행 가능한 사용자:** 모든 사용자*

## 주요 기능

캐치업에는 다음과 같은 주요 기능이 포함되어 있습니다:

- **시각적 강조 보기**
  주요 업데이트가 보드에 강조 표시됩니다.
- **간단한 변경 요약**
  변경 사항과 조치가 필요한 사항을 즉시 확인합니다.
- **단계별 안내**
  보드의 섹션 별로 편집 및 변경 내역을 단계별로 안내합니다.

## 캐치업 사용 방법

다음 단계에 따라 캐치업에 액세스하고 사용하는 방법을 안내합니다.

1. 오른쪽 상단 툴바에서 **활동** (![icon-activity.svg](../../../../../../docs/using-miro/working-on-the-board/images/24093924443794_icon-activity.svg)) 아이콘을 클릭합니다.
   활동 메뉴가 열립니다.
2. **캐치업** 버튼을 클릭합니다.
   캐치업 대화 상자가 보드에 열립니다.

   ![catch-up-new.png](../../../../../../docs/using-miro/working-on-the-board/images/27120802154642_catch-up-new.png)*보드에서의 캐치업 대화 상자*
3. **최근 변경 사항**과 함께 개요가 표시됩니다.
4. 최근 변경 사항을 클릭하여 해당 패널로 바로 이동합니다.
5. **세부정보 보기**를 클릭하여 변경 사항을 검토하기 시작합니다.
6. 대화 상자 내에서 앞뒤 **화살표** 버튼을 사용하여 캐치업을 탐색합니다.
7. 변경 사항에 대한 해당 섹션을 보려면 숫자 링크를 클릭합니다.
8. 드롭다운 메뉴를 사용해 다른 기간별 데이터를 선택합니다: 지난주, 지난 2주, 또는 지난달.

### 캐치업에 접근하는 대체 방법

캐치업에 접근하는 추가 방법은 다음 단계를 따르세요.

1. 보드 **메인 메뉴** (![icon-main.svg](../../../../../../docs/using-miro/working-on-the-board/images/24005170925074_icon-main.svg)) 아이콘을 클릭합니다.
   메인 메뉴가 열립니다.
2. **보드** 버튼 위에 마우스를 올립니다.
   보드 하위 메뉴가 열립니다.
3. **캐치업** 버튼을 클릭합니다.
   캐치업 대화 상자가 열립니다.

## 자주 묻는 질문

**왜 캐치업에 접근할 수 없나요?**

캐치업은 Miro AI를 활성화한 사용자만 사용할 수 있습니다. 관리자가 Miro AI를 활성화하지 않은 경우, 캐치업에 접근하려면 관리자가 이를 활성화해야 합니다. 활성화 방법은 [기능 활성화](../../enterprise-administration/managing-enterprise-teams-and-content/06-feature-activation.md)에서 확인할 수 있습니다.
