[스페이스 개요](02-space-overview.md)는 스페이스에 접근하는 모든 사용자에게 기본 진입점이 됩니다. 대시보드를 생성하여 스페이스 내부의 액티비티와 콘텐츠를 구조적으로 보여줄 수 있습니다.

![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)

*스페이스 개요 대시보드*

이 문서는 스페이스 개요를 위한 대시보드 생성 방법을 설명합니다. 스페이스 개요에 대해 더 알아보려면 [스페이스 개요](02-space-overview.md)를 참조하세요.

## 주요 기능

- **자동 레이아웃**
  위젯을 행과 열에 자동으로 조정 및 배치합니다.
- **드래그 앤 드롭 구성**
  위젯을 드래그하여 대시보드에 쉽게 콘텐츠를 구성할 수 있습니다.

## 스페이스 개요 대시보드 생성하기

1. [Miro 보드를 스페이스 개요로 설정](02-space-overview.md)합니다.
2. 보드에서, 생성 바의 **도구, 미디어 및 통합** (**+**)을 클릭하세요.
3. 검색하고 **대시보드**를 선택합니다.
4. 대시보드를 배치할 캔버스를 클릭합니다.
5. 대시보드를 구축하려면 지원되는 Miro 포맷 또는 객체를 드래그하세요. 예를 들어, 테이블, 타임라인, 텍스트 등을 추가할 수 있습니다. 또한 동기화 사본도 추가할 수 있습니다.
   ![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)*대시보드가 자동으로 포맷이나 객체의 크기를 조정합니다.*
6. (선택 사항) 각 위젯을 드래그하여 대시보드를 재배치하세요.
7. (선택 사항) 스페이스 개요에 처음으로 접속할 때 대시보드를 기본 보기로 설정하려면, **대시보드** 컨텍스트 메뉴에서 세 개의 점(**...**)을 클릭하고, **기본 보기로 설정**을 선택하세요.

:::tip
대시보드를 프로젝트 템플릿으로 사용하려면, [맞춤형 프로젝트 플랜](05-custom-blueprints.md)에 스페이스 개요와 대시보드를 포함시킬 수 있습니다.
:::
