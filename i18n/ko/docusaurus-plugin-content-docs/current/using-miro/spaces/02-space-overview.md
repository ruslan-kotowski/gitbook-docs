스페이스에서는 특정 보드를 스페이스 개요로 설정할 수 있습니다. 개요로 설정된 보드는 스페이스에 접근하는 모든 사용자가 처음 확인하는 기본 진입 지점이 되어 명확한 컨텍스트와 안내 역할을 제공합니다. 스페이스 개요는 팀의 정렬을 도와주며, 스페이스를 스마트하고 역동적인 워크스페이스로 만들어줍니다.

이 문서에서는 스페이스 개요 기능과 스페이스 개요를 만드는 방법을 설명합니다. 스페이스에 대해 더 알고 싶다면, [스페이스](01-spaces.md)를 참조하세요.

![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)

*스페이스 사이드바에서 스페이스 개요에 접근할 수 있습니다.*

## 주요 기능

- **향상된 조직 화**
  스페이스 개요를 모든 스페이스 활동과 리소스를 모아두는 중앙 허브로 활용하세요. 이해관계자를 위한 스페이스 개요를 정기적으로 업데이트할 수 있습니다.
- **가시성**
  스페이스 개요는 모든 스페이스 멤버가 볼 수 있으며, 스페이스 사이드바 최상단에서 바로 접근할 수 있습니다. 개요는 회의 중이든 회의 사이든 중요한 기준점이 됩니다.
- **향상된 팀 커뮤니케이션 및 정렬**
  스페이스 내 보드, 결정 사항, 리소스 등을 연결하세요.

## 스페이스 개요 만들기

1. 소유자 또는 공동 소유자로 있는 스페이스를 엽니다.
   스페이스 보기가 열립니다.
2. 스페이스 개요로 설정하려는 보드 옆의 세 점 아이콘(**...**)을 클릭합니다.
3. **설정**>**개요로**를 클릭합니다.
   스페이스 개요 보드는 이름을 그대로 유지하며 스페이스 사이드바의 상단에 고정됩니다.

:::tip
스페이스 내에서 보드를 열고, 스페이스 사이드바에서 스페이스 개요로 지정하려는 보드의 세 점 아이콘(**...**)을 클릭해 지정할 수도 있습니다.
:::

![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)

*스페이스 사이드바에서 보드를 선택해 스페이스 개요로 설정할 수 있습니다.*

## 스페이스 개요 제거하기

1. 소유자 또는 공동 소유자인 스페이스를 엽니다.
2. 스페이스 사이드바에서 **개요** 항목의 세 점 아이콘(**...**)을 클릭합니다.
3. **개요에서 제거**를 클릭합니다.
   제거된 스페이스 개요는 스페이스 수준으로 돌아가며, 아이콘도 원래 상태로 돌아갑니다.

:::note
스페이스 개요로 지정된 보드가 휴지통으로 이동되거나 스페이스 외부로 이동되면, 해당 보드는 자동으로 스페이스 개요에서 제거됩니다.
:::
