## 이미지로 저장

:::warning
Edge(버전 79 미만)는 **벡터 내보내기**만 지원합니다. Free 플랜은 크기가 작은 내보내기만 지원합니다. Free 플랜 사용자는 Chrome, Firefox, Opera, Safari, 데스크톱 앱 또는 태블릿 앱에서 보드를 내보낼 수 있습니다.
:::

**보드를 JPG 이미지로 내보내기**:

1. 보드 왼쪽 상단 모서리에서 내보내기 메뉴를 엽니다
2. **이미지로 저장**을 선택합니다
3. 이미지로 저장하려는 보드 영역을 선택합니다
4. 이미지 크기를 선택합니다. 플랜에 따라 보드를 **작음**, **중간**, **큼**, **벡터** 크기로 내보낼 수 있습니다. 벡터 품질은 PDF 파일로 저장됩니다. 큰 보드를 내보낼 때 벡터 내보내기로 이미지 품질을 유지할 수 있습니다
5. **내보내기**를 클릭합니다

![main_menu_export_board_as_image_greybg.gif](images/21016928501010_main_menu_export_board_as_image_greybg.gif)
*보드 일부를 이미지로 저장합니다*

**개별 프레임을 이미지로 내보내기:**

1. 프레임을 선택합니다
2. 컨텍스트 메뉴에서 점 3개 아이콘을 클릭합니다
3. **이미지로 내보내기**를 선택합니다
4. 파일 크기를 선택하고 **내보내기**를 클릭합니다

![image.png로 내보내기 ](../../../../../../../docs/using-miro/import-and-export/export/images/21016928433042_export%20as%20image.png)
*프레임을 이미지로 저장합니다*

**전체 보드를 이미지로 내보내기 :**

1. 단축키로 보드상 오브젝트를 전체선택합니다 **Ctrl + A** (Windows) 또는 **⌘** + **A** (Mac)
2. 점 3개 아이콘을 클릭하여 점 주위에 프레임을 만듭니다
3. 프레임의 컨텍스트 메뉴에서 점 3개 아이콘을 클릭하고 **이미지로 내보내기**를 선택합니다

*![export_the_whole_board_greybg.gif](https://help.miro.com/hc/article_attachments/21016941468178)
선택한 오브젝트 주위에 프레임 만들기*

## PDF로 저장합니다

:::warning
Edge(버전 79 미만)는 **최고(벡터) 품질**로만 내보냅니다. Free 플랜은 크기가 작은 내보내기만 지원합니다. Free 플랜 사용자는 Chrome, Firefox, Opera, Safari, 데스크톱 앱 또는 태블릿 앱에서 보드를 내보낼 수 있습니다.
:::

[프레임](../../essential-tools/07-frames.md)을 **작음** 또는 **최고**(**벡터**) 품질 PDF로 내보냅니다.

**보드를 PDF 파일로 내보내기:**

1. 하나 이상의 프레임을 만듭니다. 각 프레임은 저장된 PDF 문서의 개별 페이지가 됩니다
2. PDF 문서에 프레임이 나열되는 순서를 확인하려면 왼쪽 하단 모서리에서 보드 개요를 엽니다. 내보낸 PDF에서 페이지 순서를 변경하려면, 패널에서 프레임 순서를 드래그하여 변경합니다
   ![main_menu_reorder_frames_greybg.gif](https://help.miro.com/hc/article_attachments/21016941469970)
*프레임 순서 변경*
3. 보드 왼쪽 상단 모서리에서 내보내기 메뉴를 엽니다
4. **PDF로 저장**을 선택합니다
5. 파일 크기를 선택합니다: **작은 크기의 파일** 또는 **최고 품질**
6. **내보내기**를 클릭합니다

![main_menu_export_as_pdf.png](images/21016928503314_main_menu_export_as_pdf.png)
*보드를 PDF로 저장*

PDF로 보드 내보내기는 모든 프레임을 한 파일로 내보냅니다.

**특정 프레임을 PDF로** **내보내기**:

1. **Shift** 키를 누른 채 내보내려는 프레임을 선택합니다. 또는, 내보내려는 콘텐츠에 선택 영역을 드래그 > 컨텍스트 메뉴에서 **필터** 클릭 > **프레임**을 선택합니다
2. 컨텍스트 메뉴에서 점 3개 아이콘을 클릭하고 **PDF로 내보내기**를 선택합니다

![export_certain_frames_greybg.gif](https://help.miro.com/hc/article_attachments/21016941471890)
*특정 프레임을 PDF로 내보내기*

**전체 보드를 1페이지짜리 PDF로 내보내기:**

유료, Education 플랜 Free 플랜

1. 단축키로 보드상 오브젝트를 전체선택합니다 **Ctrl + A** (Windows) 또는 **⌘** + **A** (Mac)
2. 컨텍스트 메뉴에서 점 3개 아이콘을 클릭하여 점 주위에 프레임을 만듭니다
3. 프레임의 컨텍스트 메뉴에서 점 3개 아이콘을 클릭하고 **이미지로 내보내기**를 선택합니다
4. **벡터** 품질을 선택하고 **내보내기를 클릭합니다
   ![main_menu_export_board_as_vector_greybg.gif](../../../../../../../docs/using-miro/import-and-export/export/images/21016928435346_main_menu_export_board_as_vector_greybg.gif)
*전체 보드를 PDF로 내보내기***

보드에 **프레임이 없는** 경우:

1. 단축키로 보드상 오브젝트를 전체선택합니다 **Ctrl + A** (Windows) 또는 **⌘** + **A** (Mac)
2. 컨텍스트 메뉴에서 점 3개 아이콘을 클릭하여 점 주위에 프레임을 만듭니다
3. 보드 왼쪽 상단 모서리에서 내보내기 메뉴를 열고 **PDF로 저장**을 선택합니다
4. **내보내기**를 클릭합니다

![export_the_whole_board_as_PDF_free_plan_greybg.gif](../../../../../../../docs/using-miro/import-and-export/export/images/21016941396370_export_the_whole_board_as_PDF_free_plan_greybg.gif)
*보드에 다른 프레임이 없을 때 Free 플랜에서 전체 보드를 PDF로 내보내기*

이미 보드에 **프레임이 있는** 경우*:*

1. 단축키로 보드상 오브젝트를 전체선택합니다 **Ctrl + A** (*Windows*) 또는 **⌘ + A** (*Mac*) 또는 선택 영역 드래그
2. 컨텍스트 메뉴에서 **필터**를 클릭하고 **프레임**을 선택합니다
3. 프레임을 삭제합니다(콘텐츠는 유지)
4. 단축키로 보드상 오브젝트를 전체선택합니다 **Ctrl + A** (*Windows*) 또는 **⌘ + A** (*Mac*) 또는 선택 영역 드래그
5. 보드 왼쪽 상단 모서리에서 내보내기 메뉴를 열고 **PDF로 저장**을 선택합니다
6. **내보내기**를 클릭합니다
7. 왼쪽 도구 막대 아래의 **실행 취소** 버튼을 두 번 클릭하여 프레임 생성을 취소하고 프레임을 제거합니다.

*![export_all_content_as_PDF_Free_plan_greybg.gif](../../../../../../../docs/using-miro/import-and-export/export/images/21016928435730_export_all_content_as_PDF_Free_plan_greybg.gif)**무료 플랜에서 보드를 PDF로 내보내기*

:::note
오브젝트가 많은 프레임을 내보내면 내보내기 프로세스가 중단될 수 있습니다(예: 내보낸 PDF 파일의 일부 텍스트 누락 가능성 등). 최적의 성능을 위해 큰 보드를 여러 개로 나누고 각 보드를 별도로 내보낼 것을 권장합니다*.* [보드 내보내기 문제](../../tools/troubleshooting/03-board-export-issues.md)를 확인하여 보드 내보내기 최적화 팁을 더 확인하세요.
:::

## 스프레드시트(CSV)로 내보내기

> **사용 가능 플랫폼:** [Chrome, Safari, Firefox 브라우저](../../troubleshooting-technical-questions/technical-guidelines/02-supported-browsers-browser-restrictions.md), [데스크톱 앱](../../../getting-started/apps-for-devices/05-desktop-app.md)

보드의 텍스트(스티커 메모, 테이블, 카드, 텍스트 상자, 도형)는 CSV 파일로 내보낼 수 있습니다.

**텍스트를 CSV 파일로 내보내기:**

1. 프레임 또는 보드 콘텐츠를 선택합니다. 선택 영역을 드래그하거나 **Shift** 키를 누른 상태로 [보드 콘텐츠를 선택](../../working-on-the-board/10-working-with-objects.md)할 수 있습니다
2. 컨텍스트 메뉴에서 점 3개 아이콘을 클릭합니다
3. **CSV로** **내보내기**를 선택합니다
4. 그러면, 보드 콘텐츠가 텍스트, [카드](../../essential-tools/02-cards.md) 설명/URL, 스티커 메모/카드 태그 순서로 한 열에 들어가는 CSV 파일이 생성됩니다

![Miro_CSV_export_gif_greybg.gif](../../../../../../../docs/using-miro/import-and-export/export/images/21016941398162_Miro_CSV_export_gif_greybg.gif)
*CSV 파일로 프레임 내보내기*

보드 **내보내기** 메뉴에서 **스프레드시트로 내보내기(CSV)** 옵션을 선택하여 전체 보드를 CSV로 내보낼 수도 있습니다.

![main_menu_export_as_csv.png](images/21016928512658_main_menu_export_as_csv.png)
*보드를 스프레드시트(CSV)로 내보내는 옵션*

## 내보낸 파일이 저장된 위치

브라우저에서 Miro를 사용하면 브라우저 다운로드 파일이 기본적으로 저장되는 폴더에 파일이 저장됩니다(브라우저 설정에 설정).

Miro 데스크톱 앱을 사용한다면, 장치의 다운로드 폴더를 확인하세요.

## 제한 사항

- Miro 보드 내보내기는 [보드 콘텐츠 설정](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)에서 사용자별로 제한될 수 있습니다
- 워터마크 없는 고품질 해상도 내보내기는 Miro Free 플랜에서는 사용할 수 없습니다
- Edge(버전 79 미만)는 벡터 내보내기만 지원합니다
- 태블릿과 모바일 장치에서 Opera, Edge(버전 79 미만) 이용 시 CSV로의 Miro 내보내기가 지원되지 않습니다
- [개발자 팀에서는](https://miro.com/api/) Miro 보드 내보내기가 지원되지 않습니다
- 모바일 장치에서는 Miro 보드 내보내기가 지원되지 않습니다
- **벡터** 품질로 내보낸 PDF 파일에서만 링크를 클릭할 수 있습니다
- 보드 비트맵 이미지는 업로드 중에 압축되지만, Miro에서 만든 오브젝트(도형, 스티커, 텍스트, 링크 등)는 품질을 유지합니다

## 자주 묻는 질문

*Miro 보드를 내보낼 수 있는 옵션이 없습니다. 왜일까요?*

보드 소유자는 [보드 콘텐츠](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) 설정에서 내보내기 옵션을 제한할 수 있습니다. 보드 콘텐츠 설정에서 보드 내보내기가 허용 상태인데도 여전히 내보내기 옵션 일부가 보이지 않는다면, 플랜과 장치 , 브라우저에서 보드 내보내기를 지원하는지 확인하세요. 내보내기 가능 여부 확인하기

*보드 공동 작업자가 보드를 내보내도록 하려면 어떻게 해야 하나요?*

[보드 콘텐츠 설정](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)을 확인하고 보드 참여자가 보드 복사 옵션을 사용할 수 있는지 확인하세요. 관리자에게 [팀 외부 사용자에게 보드 콘텐츠 복사를 허용하도록](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) 요청해야 할 수도 있습니다.

*보드를 PPT/PNG/SVG 형식으로 내보낼 수 있나요?*

아니요, 현재 보드는 PDF/JPG/CSV 파일로 저장할 수 있습니다.

*내보낸 문서에 댓글도 포함되나요?*

아니요, 하지만 백로그에 해당 기능이 있습니다.

*내보낸 문서에 프레임 제목이 표시되나요?*

아니요, 하지만 프레임 제목을 문서에 표시할 [텍스트 위젯](../../essential-tools/16-text.md)으로 바꿀 수는 있습니다.

*투표 결과를 내보낼 수 있나요?*

아니요, 스크린샷을 찍으시기 바랍니다.

*보드 작업 중에 모든 변경 사항은 자동으로 저장되나요?*

네. 또한 [보드 백업](05-how-to-save-board-backup.md)을 저장하고 보드를 내보내서 실수로 콘텐츠가 삭제되는 일이 없도록 하는 것이 좋습니다. [웹 화이트보드](../../special-features/10-web-whiteboard.md)에서 작업하는 데 Miro 프로필이 없다면, [Miro에 가입하여](../../../getting-started/start-here/02-how-to-register-with-miro.md) 보드를 저장하고 24시간 후 작업을 계속하세요.

*개별 요소 또는 요소 세트를 내보내려면 어떻게 해야 하나요?*

보드 **내보내기** 메뉴에서 **이미지로 저장**을 선택하고 캡처할 이미지가 있는 영역을 선택할 수 있습니다. 또는 [오브젝트를 선택](../../working-on-the-board/10-working-with-objects.md)하고 주위에 [프레임을 만든](../../essential-tools/07-frames.md) 다음 내보내는 방법도 있습니다.

*인텔리전스 데이터가 있는 보드를 CSV로 내보낼 수 있나요?*

현재 CSV 내보내기는 보드 구조와 관계를 유지하지 않습니다. 그러나, [테이블](../../advanced-tools/05-grid.md)을 CSV 파일로 내보내면 구조가 저장됩니다.

*보드에 업로드한 파일을 내보낼 수 있나요?*

네, [보드 콘텐츠 설정](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)에서 허용하면 그럴 수 있습니다. 옵션에 제한이 없다면, 파일을 선택하고 컨텍스트 메뉴에서 다운로드 아이콘을 클릭합니다.

:::note
Miro 보드 내보내기 문제가 발생하면 [보드 내보내기 문제](../../tools/troubleshooting/03-board-export-issues.md) 문서에서 가능한 해결책을 찾아보세요.
:::
