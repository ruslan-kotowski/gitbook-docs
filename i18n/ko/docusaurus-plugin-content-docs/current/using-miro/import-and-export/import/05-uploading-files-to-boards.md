보드에 파일을 추가하는 가장 쉬운 방법은 데스크톱에서 파일을 드래그앤드롭하는 것입니다. 이미지를 비롯하여 PDF 파일, Google Drive 문서, MS Office 파일을 추가할 수 있습니다. 지원되는 파일 형식의 전체 목록은 [이 문서](../../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md)에서 확인할 수 있습니다. 새로운 파일은 컴퓨터나 웹에서 추가할 수 있으며, 파일의 최대 크기는 30MB이고, 최대 이미지 해상도는 32MP, 최대 크기는 8192x4096 픽셀입니다.

> **설정 가능:** [보드 편집자](../../sharing-boards/01-board-access-rights.md)
> **사용 가능 플랜:**모든 Miro 플랜 (임베드된 비디오 재생 불가능한 Free 플랜 제외)

### 장치에서 파일 추가하기

장치에서 파일을 업로드하려면 작성 툴바에서 **업로드**를 선택하세요. 이 옵션이 숨겨져 있으면, **더 많은 도구** 화살표(>>>)를 클릭하여 버튼을 툴바에 추가하세요. **내 장치**를 클릭합니다.

![upload_on_the_toolbar_greybg.gif](../../../../../../../docs/using-miro/import-and-export/import/images/21016967591442_upload_on_the_toolbar_greybg.gif)
*툴바의 업로드 버튼*

그러면 파일을 보드에 업로드하기 위해 선택할 수 있는 대화 상자가 열립니다. 파일을 선택하고 **열기**를 클릭하면 파일이 업로드되어 보드에 나타납니다.

컴퓨터에서 파일을 업로드하는 또 다른 간단한 방법은 파일을 보드로 드래그해서 놓는 것입니다.

:::note
지원되는 파일 포맷 목록은 [여기](../../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md)에서 확인하세요.
:::

업로드한 파일과 상호작용할 수 있습니다: 크기를 조정하거나, 회전시키거나, 페이지를 이동하거나 추출할 수 있습니다.

![change_an_uploaded_object_greybg.gif](https://help.miro.com/hc/article_attachments/21574815371154)
*업로드한 PDF 파일과 상호작용*

[모바일 앱](../../../getting-started/apps-for-devices/08-mobile-app.md)을 사용하는 경우, 보드의 오른쪽 하단에 있는 플러스 아이콘을 누르고 **업로드**를 선택하세요. 클립보드에서 파일을 붙여넣거나, 사진을 찍거나, 모바일 라이브러리에서 이미지를 선택할 수 있습니다. 모바일 기기로 PDF 파일을 업로드하는 것은 현재 지원되지 않습니다.

![upload on mobile.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005106578_upload%20on%20mobile.png)
*모바일 기기에서 파일 업로드하기*

### URL 링크를 통한 파일 추가

웹에서 소스의 직접 링크를 사용하여 파일을 업로드하려면 **URL로 업로드**를 선택하세요.

*![Upload via URL.png](https://help.miro.com/hc/article_attachments/21574815372050)**툴바에서 **URL로 업로드**하기*

그 후, YouTube나 Vimeo 동영상과 같은 웹에서 직접 URL 링크를 붙여 넣으세요.

![upload via URL modal.png](https://help.miro.com/hc/article_attachments/21574815373458)
*URL 링크를 통한 업로드*

:::note
임베드한 동영상은 Free 플랜 사용자와 베이직 라이선스 사용자에게는 재생할 수 없습니다.
:::

동영상을 시청하려면 **재생** 아이콘을 더블 클릭하세요 (추가된 파일은 자동 재생되지 않습니다). **원본**페이지로 이동하여 컨텍스트 메뉴의 다른 기능도 사용할 수 있습니다.

Miro에 추가된 동영상은 빨리 감기할 수 있으며, 자막을 추가하고 동영상 품질을 변경할 수 있습니다 — 보드에서 업로드한 동영상을 직접 관리할 수 있습니다.

![video embed.png](https://help.miro.com/hc/article_attachments/21574815373970)
*동영상 원본 페이지로 이동할 수 있는 옵션*

다른 방법으로는 **Ctrl+C**/**Ctrl+V**(*Windows용*) 또는 **Cmd+C/Cmd+V**(*Mac용*) 단축키를 사용해 파일 링크를 보드에 직접 게시할 수 있습니다.

보드에서 미리 보기를 하지 않고 URL 링크를 붙여 넣으려면 [텍스트](../../essential-tools/16-text.md) 도구를 사용하여 텍스트 상자에 링크를 붙여넣으세요.

### 다른 서비스에서 파일 업로드하기

또한 [Google Drive](../../../integrations-apps/google/05-google-drive.md), [Dropbox](../../../integrations-apps/more-integrations/06-dropbox.md), [Box](../../../integrations-apps/more-integrations/05-box-legacy.md), [OneDrive](../../../integrations-apps/microsoft/06-onedrive.md), [Adobe CC](../../../integrations-apps/adobe/02-adobe-creative-cloud.md)에서 파일을 업로드할 수 있습니다. 모든 옵션은 **업로드** 메뉴에서 사용 가능합니다. 더 자세한 내용은 관련 기사를 참조하세요.

[방문자](../../sharing-boards/08-collaboration-with-visitors.md)는 이 옵션을 사용할 수 없습니다.

![upload from other services.png](https://help.miro.com/hc/article_attachments/21574815375378)
*다양한 저장 서비스에서 파일을 업로드하는 옵션*

### 업로드한 파일을 라이브러리에 저장하기

팀이 향후 사용할 수 있도록 업로드한 파일을 Miro 라이브러리에 저장하려면 파일을 선택하고, 세 점 아이콘을 클릭한 후 **Saved Files에 추가**를 선택하세요. 이 기능은 PDF, 이미지, 프레젠테이션, Google 문서 및 기타 파일에서도 작동합니다.

![add to saved files.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005108882_add%20to%20saved%20files.png)
*파일을 Saved Files에 추가하는 옵션*

저장된 파일은 툴바의 **업로드** 메뉴에 있는 **저장된 파일** 폴더에서 확인할 수 있습니다. 라이브러리에서 파일을 추가하려면 해당 파일을 클릭하거나 보드에 드래그 앤 드롭하세요. 저장된 파일은 저장된 보드가 속한 팀의 보드에서만 접근할 수 있습니다.

![saved files.png](https://help.miro.com/hc/article_attachments/21574815378578)
*툴바의 저장된 파일*

라이브러리에서 파일을 삭제하려면 마우스를 파일 위로 움직이고 **휴지통** 아이콘을 클릭하세요.

![delete a saved file.png](https://help.miro.com/hc/article_attachments/21574815381010)
*휴지통 아이콘을 클릭하여 저장된 파일 삭제*

**Saved files에 추가** 옵션이 비활성화(회색)되고 오류 메시지에 **이 도구는 이 보드에서 사용할 수 없습니다**라고 나오면, 이는 해당 보드가 저장된 팀의 멤버가 아니기 때문에 작업을 완료할 권한이 부족하다는 의미입니다.

### 여러 페이지 문서 분할하기

> **사용 가능 환경:** 브라우저 버전, [데스크톱 앱](../../../getting-started/apps-for-devices/05-desktop-app.md)

팀이 문서, PDF 또는 Powerpoint 파일에서 협업할 수 있는 방법으로, 페이지를 확장하여 보드에 배치하고 페이지에 직접 댓글을 남길 수 있습니다.

PDF 또는 Powerpoint 파일을 특정 페이지 수로 나누는 방법:

1. 파일을 보드에 업로드합니다.
2. 파일을 클릭하고, 컨텍스트 메뉴에서 **페이지 추출** 아이콘을 선택합니다.

   > ✏️ 옵션은 [커서(선택) 모드](#mini)에서만 사용할 수 있습니다. 메뉴에 옵션이 나타나지 않으면 **V**를 누르거나 툴바에서 커서를 선택한 후 개체를 다시 클릭하세요.
3. 대화 상자에서 파일을 전체 페이지 혹은 특정 페이지로 분할할지 선택하고 **추출**을 클릭하세요.

추출된 페이지는 원본 파일 바로 아래에 나타납니다. 원본 파일이 필요 없으면 삭제할 수 있으며, 추출된 모든 페이지는 보드에 남아있습니다.

### PDF 파일 업로드 시 발생할 수 있는 문제

일부 PDF 파일은 Miro 보드에 업로드되지 않으며, 로딩 휠에서 멈추거나 오류 표시가 있는 회색 이미지로 나타납니다. 이 문제가 발생하면, 다음을 확인해 주세요:

- PDF 파일이 30MB 이하인지 확인하세요
- 안정적인 인터넷 연결을 사용하고 있는지 확인하세요
- 장치가 최소 [시스템 요구 사항](../../troubleshooting-technical-questions/technical-guidelines/01-system-requirements.md)

보드에 파일을 업로드하는 데 어려움을 겪고 있다면, 문제는 파일 자체에 있을 수 있습니다. 일부 복잡한 PDF 파일은 기술적 제한으로 인해 보드에서 렌더링될 수 없습니다. 이는 보통 많은 요소나 세부 사항이 들어있는 PDF에서 발생합니다. 당사는 렌더링 도구를 개선하기 위해 노력하고 있지만, 현재로서는 다음과 같은 우회 방법을 사용하세요:

- 파일을 만든 소프트웨어에서 PNG 또는 JPEG 포맷으로 파일을 저장합니다
- 또는 PDF 파일을 온라인 파일 변환기를 사용해 PNG 또는 JPEG로 변환합니다 (아무 변환기나 사용할 수 있습니다, 예: `https://www.freepdfconvert.com/pdf-to-png`, `https://cloudconvert.com/`)

:::note
Miro 보드에 파일을 업로드하는 데 문제가 있으면 [이 문서의](../../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md) 문제 해결 단계를 시도해 보세요.
:::

## 자주 묻는 질문

**제가 Miro 보드에 내 기기에서 동영상 파일을 업로드할 수 있나요?**

아니요, 그러나 동영상은 쉽게 임베드할 수 있습니다. 이 가이드를 확인해 보세요: [보드에 미디어 임베드하기](../../../integrations-apps/integrations-basics/03-embed-integrations-on-a-miro-board.md).

**엑셀 또는 CSV 파일에서 편집 가능한 데이터를 가져올 수 있나요?**

스프레드시트, .xslx 및 CSV 파일은 보기 전용 파일로 가져오거나 테이블 또는 그리드 작성에 사용될 수 있습니다. 자세한 내용은 다음을 참조하세요: [테이블](../../formats/14-tables.md) 또는 [표](../../advanced-tools/05-grid.md).

**보드에서 파일을 다운로드할 수 있나요?**

네, 보드 콘텐츠 설정[에서 허용한 경우 가능합니다](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md). 파일을 다운로드하려면 파일을 선택하고 상황별 메뉴에서 **다운로드**를 선택하세요.

**업로드된 PDF 파일의 링크를 클릭할 수 있나요?**

아니요, 현재는 지원되지 않습니다.
