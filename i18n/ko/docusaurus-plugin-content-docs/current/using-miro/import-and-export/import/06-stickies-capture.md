스티커 메모 변환을 통해 실제 스티커 메모를 완전히 편집 가능한 [Miro 스티커 메모](../../essential-tools/14-sticky-notes.md)로 전환할 수 있습니다. 실시간으로 공유하여 협업하고, [Jira 작업](../../../integrations-apps/atlassian/03-jira-cards.md)으로 전환하거나 디지털 다이어그램, [템플릿](../../../getting-started/start-here/your-first-board/04-templates.md) 등의 일부로 만드세요.

:::warning
스티커 메모 변환을 사용하려면 Miro AI가 활성화되어야 합니다.
:::

### 스마트폰에서 스티커 메모 변환하는 방법

1. [Miro 모바일 앱](../../../getting-started/apps-for-devices/08-mobile-app.md)을 다운로드하세요 ([iOS](https://apps.apple.com/us/app/miro-formerly-realtimeboard/id1180074773), [Android](https://play.google.com/store/apps/details?id=com.realtimeboard)용).
2. 스티커 메모를 배치할 보드를 여세요.
3. 더하기 기호를 눌러 메뉴를 열고 **스티커 메모 변환** 아이콘을 선택하세요.
   ![stickies_capture_on_mobile.jpg](../../../../../../../docs/using-miro/import-and-export/import/images/21017004784146_stickies%20capture%20on%20mobile.jpg)
   *모바일 앱의 툴바에서 스티커 메모 변환*
4. 기존 사진을 선택하거나 새로 찍으세요. 최대 15MB 크기의 파일을 업로드할 수 있습니다.
   ![choose_a_photo.jpg](../../../../../../../docs/using-miro/import-and-export/import/images/21016967314578_choose%20a%20photo.jpg)*사진을 찍거나 라이브러리에서 선택해 스티커 메모를 캡처하는 옵션*
5. 일부 스티커 메모가 정확하게 인식되지 않은 경우, 이러한 스티커 메모를 탭해 윤곽선을 추가하거나 편집하세요. 그런 다음 **보드에 추가**를 탭하세요. **텍스트로 변환** 스위치를 켜 스티커 메모를 보드에서 편집 가능하게 하세요. *![capture_stickies.jpg](../../../../../../../docs/using-miro/import-and-export/import/images/21017004786578_capture%20stickies.jpg)**스티커 메모 캡처하기*
   > 💡 스티커 메모 선택을 편집하는 데 많은 시간을 쓰지 마세요. 어차피 Miro 스티커 메모로 변환됩니다.
6. 캡처한 스티커 메모가 보드에 표시됩니다. 다음을 편집할 수 있습니다: 텍스트 변경, 색상 변경 등.
    ![디지털화된 스티커.jpg](../../../../../../../docs/using-miro/import-and-export/import/images/21016967316498_digitized%20stickies.jpg)
   *Miro 스티커 메모 변환으로 디지털화된 스티커 메모*

:::warning
스티커 메모의 텍스트가 인식되지 않은 경우, 이 메모는 이미지로 보드에 표시됩니다.
:::

:::note
스티커 메모 변환은 *영어* 텍스트만 디지털화할 수 있습니다. 하지만 5단계에서 **텍스트로 변환** 토글을 끄면 스티커 메모를 이미지로 디지털화할 수 있습니다.
:::

### [태블릿 앱](../../../getting-started/apps-for-devices/11-tablet-app.md) 또는 웹 버전에서 스티커 메모 변환하는 방법

1. 스티커 메모를 추가하려는 보드를 여세요.
2. 툴바에서 **스티커 메모 변환** 아이콘을 탭하세요.
   ![stickies_capture.jpg](../../../../../../../docs/using-miro/import-and-export/import/images/21016967310738_stickies%20capture.jpg)
   *태블릿 앱의 툴바에서 스티커 메모 변환*
3. 장치에 있는 기존 사진 선택
4. 일부 스티커 메모가 제대로 인식되지 않으면, 해당 스티커 메모를 클릭해 윤곽을 추가하거나 편집하세요. 그런 다음 **보드에 추가**를 탭하세요.
5. 캡처한 스티커 메모가 보드에 표시됩니다. 편집할 수 있습니다: 텍스트, 색상 변경, 태그 추가 등.

:::tip
간단한 규칙을 따르면 디지털 스티커 메모가 훨씬 더 좋아 보입니다.

- 진한 펠트펜을 사용해 메모를 작성하세요. 메모 색과 대비를 이룹니다.
- 스티커 메모를 겹치지 마세요
- 단색 배경에 메모를 따로 붙이기
- T 밝은 조명에서 사진을 찍고 어두운 그림자를 피하세요.
:::
