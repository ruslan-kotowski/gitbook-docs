미리 정의된 관리자 역할을 할당하면 조직 내 다른 사용자에게 권한을 부여하는 간단한 방법입니다. 각 관리자 역할은 하나 이상의 권한을 제공하여 특정 Miro 기능을 수행할 수 있게 합니다.

Miro는 현재 조직 수준에서 미리 정의된 네 가지 관리자 역할을 제공합니다. 즉, 회사 관리자, 사용자 관리자, 콘텐츠 관리자, 보안 관리자가 포함됩니다.

다음 표는 각 역할과 연관된 권한을 나열합니다.

:::note
이 역할과 권한 목록은 계속 업데이트됩니다. 이 페이지를 정기적으로 확인하세요.
:::
