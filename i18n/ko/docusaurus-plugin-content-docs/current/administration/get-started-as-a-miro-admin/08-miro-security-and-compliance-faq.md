우리는 데이터 프라이버시와 보안을 중요하게 생각하며, 우리의 보안 관행이 업계 선두주자와 동등한 수준을 유지하도록 노력하고 있습니다. 데이터 프라이버시와 보안에 대해 자주 묻는 질문을 읽어보세요.

### Miro의 데이터는 어디에 저장되나요?

EU 데이터 센터 레지던시에서, 컴퓨팅 인프라와 모든 고객 콘텐츠(프로덕션 데이터, 백업 데이터, 메타데이터)는 기본적으로 EU 내에서 호스팅됩니다.

:::note
데이터 레지던시는 호주와 미국에서도 가능합니다. 자세한 내용은 [Miro의 데이터 레지던시](https://help.miro.com//hc/articles/23084283851026)를 참조하세요.
:::

**추가 정보:** 참조하십시오 [Miro의 데이터 레지던시](https://help.miro.com//hc/articles/23084283851026).

### 우리가 제작하는 콘텐츠는 매우 민감합니다. Miro 팀 외부로 보드를 공유하지 않으려면 어떻게 해야 하나요?

[Miro Enterprise](../../plans-billing/miro-plans/04-enterprise-plan.md) 는 다음과 같은 기능을 제공하여 팀원들이 Miro 내에서 보안을 유지하며 협업할 수 있도록 돕습니다.

- [공유 정책](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md) 을 통해 신뢰할 수 있는 도메인 목록을 설정할 수 있습니다. 나열된 도메인의 이메일을 사용하는 사용자만 구독에 초대할 수 있습니다.
- [링크 접근 제어](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md) 를 사용하면 사용자가 공개 링크를 통해 보드를 공유하는 것을 막을 수 있으며, 이를 통해 구독에 포함된 사용자만 특정 보드에 액세스할 수 있도록 보장합니다.
- [도메인 제어](../../enterprise-administration/canvas-25-admin-features/domain-control/01-domain-control.md) 를 통해 기업 도메인의 소유권을 확인하고 중앙 집중식 관리가 가능한 Enterprise 구독을 유지할 수 있습니다.

### Miro 직원이 제 보드에 접근할 수 있나요?

아니요, 아무도 요청과 허가 없이는 보드 내용을 볼 수 없습니다. Miro는 제한된 IP 주소와 직원에게만 프로덕션 환경 접근 권한을 부여합니다.

### 내 보드에 접근할 수 있는 사람이 나뿐이게 하려면 어떻게 하나요?

[비공개 보드를 만드는 방법](../../using-miro/sharing-boards/15-make-a-miro-board-private.md)을 알아보세요. 항상 [보드 공유 대화창](../../using-miro/sharing-boards/01-board-access-rights.md)에서 누가 보드에 접근할 수 있는지 확인할 수 있습니다.

### 모든 사용자에게 동일한 수준의 데이터 보호를 제공하나요?

네, Miro 플랜에 관계없이 귀하의 데이터는 안전하게 관리되고 보관됩니다. 데이터는 이동 시 TLS 1.2 이상의 보안 프로토콜로, 저장 시 AES 256으로 보호되며, GDPR과 CCPA 표준에 따라 최고 수준으로 보안이 유지됩니다. 이는 추가 비용 없이 제공됩니다.
고급 보안, 개인정보 보호, 관리 제어에 대한 추가 정보는 [여기에서 문의](https://miro.com/contact/sales/?utm_source=security)하시거나 [Miro Enterprise](https://miro.com/enterprise/?utm_source=security)를 확인하세요.

### 제3자 판매업체에 데이터를 판매하나요?

아니요, [개인정보 취급방침](https://miro.com/legal/privacy-policy/)에 명시된 바와 같이 사용자의 데이터를 판매하지 않습니다.

### Miro는 일반 데이터 보호 규정(GDPR) 요구 사항을 준수하나요?

네, 자세한 내용은 [개인정보 취급방침](https://miro.com/legal/privacy-policy/)을 확인해주세요.

### SOC3 보고서는 어디에서 다운로드할 수 있나요?

[시스템 및 조직 제어 보고서(SOC 3)](https://assets.ctfassets.net/w6r2i5d8q73s/1wSVE3U0GqAZOVKKBLcUhR/250dd4c346b99dfb56b729c1c8eaa78e/2021_Miro_SOC3_TypeII_Final__4_.pdf)를 읽고 다운로드하세요.

### 내 클라이언트들이 내 Miro 보드에 접근할 수 있게 해야 하는데, 그들의 방화벽이 이를 차단할 수 있습니다. 어떻게 접근을 허용하나요?

[Miro를 허용된 도메인에 추가하는 방법](../../using-miro/tools/troubleshooting/01-add-miro-to-allowed-apps.md)을 알아보세요.

### Miro에 관한 법률 정보는 어디에서 접근할 수 있나요?

Miro의 서비스 약관, 개인정보 취급방침, 데이터 처리 부속서(DPA), 쿠키 정책은 [Miro 보안 센터](https://miro.com/trust/)에서 확인하실 수 있습니다.

### 버그 바운티 프로그램이 있나요?

네, Miro는 Intigriti에서 버그 바운티 프로그램을 운영합니다. 참여를 원하시는 경우 Intigriti 계정으로 로그인하여 [Miro Intigriti 프로그램 페이지](https://app.intigriti.com/researcher/program-redirect/miro/miro)를 방문해 주세요. 보상금 신청은 프로그램 규칙에 따라 처리됩니다. 보고서를 제출하기 전에 규칙을 꼭 확인해 주세요.
