:::note
영구 삭제 기간을 업데이트하면 업데이트된 기간은 새로 휴지통으로 이동하는 보드에만 적용됩니다. 이미 휴지통에 있는 보드는 기존 삭제 기간을 유지합니다.
:::

1. Miro 대시보드에서 오른쪽 끝에 있는 아바타를 클릭하고 **관리자 콘솔**로 이동합니다.
2. **보안 및 규정 준수**에서 **콘텐츠 수명 주기**를 클릭합니다.
   ![Figure 1: 콘텐츠 수명 주기 > 휴지통 영구 삭제 및 설정](images/26539812920338_trash_settings.png)*관리자 콘솔에서 영구 삭제 기간 설정*
3. **영구 삭제**를 위해, 휴지통에 있는 보드가 자동으로 영구 삭제될 일수를 선택하세요.
4. **저장**을 클릭합니다.
