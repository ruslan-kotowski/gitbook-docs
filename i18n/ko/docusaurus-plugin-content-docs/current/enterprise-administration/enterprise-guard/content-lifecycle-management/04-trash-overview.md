Miro의 휴지통 기능은 보드의 수명 주기에 대한 가시성과 제어를 향상시킵니다. 사용자가 더 이상 필요하지 않은 보드를 삭제할 수 있도록 하여 데이터를 즉시 잃지 않고도 보유 정책을 지원합니다.

이 기능은 자동화된 보드 삭제 일정과 권한이 있는 직원에게만 영구 삭제를 제한하여 Enterprise 리스크를 최소화하는 데 도움이 됩니다.

권한이 있는 사용자는 보드가 실수로 삭제된 경우 이를 복원할 수 있는 기능이 있어 중요한 작업이 손실되지 않도록 할 수 있습니다.

## 주요 기능

- **제어된 삭제**
  불필요한 보드를 제거하여 워크스페이스를 정리하면서 데이터를 지정된 기간 동안 보관하세요.
- **리스크 완화**
  자동 삭제와 함께 승인된 영구 삭제를 결합하여 회사 데이터를 보호합니다.
- **데이터 복구**
  권한 있는 사용자가 실수로 삭제된 보드를 복원할 수 있도록 합니다.
- **규정 준수 지원**
  지정된 기간(30일, 60일, 90일 또는 180일) 후에 보드를 자동으로 영구삭제하도록 설정하여 데이터 거버넌스, 규정 준수 또는 규제 요구 사항에 맞춥니다.

## 보드 삭제 방법

Miro는 보드를 삭제할 수 있는 두 가지 기본적인 방법을 제공합니다.

이 삭제 방법을 이해하는 것은 Miro 환경 내에서 효과적인 보드 수명 주기 관리와 데이터 거버넌스를 위해 매우 중요합니다.

- **자동 영구삭제**휴지통에 있는 보드는 사전 설정된 기간 후 자동으로 영구 삭제됩니다. 기본 기간은 90일이지만, 관리자가 30일, 60일 또는 180일로 조정할 수 있습니다. 자동화된 프로세스는 특정 보유 정책에 따라 데이터를 관리하는 데 도움이 됩니다.
- **영구 삭제**보드 소유자나 관리 권한이 있는 사용자는 언제든지 휴지통에서 보드를 수동으로 삭제할 수 있습니다. 이 작업은 보드와 그 콘텐츠를 영구적으로 삭제하며, 되돌릴 수 없습니다.
