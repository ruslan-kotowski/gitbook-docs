:::note
보유 정책을 추가하려면, [데이터 거버넌스 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)가 필요합니다. 데이터 거버넌스 관리자 역할을 요청하려면, 회사 관리자에게 문의하세요.
:::

보유 정책을 추가하려면, 다음 단계를 수행하세요.

1. [Miro 설정](https://miro.com/app/settings)으로 이동합니다.
2. 왼쪽 패널의 **Enterprise Guard** 아래에서 **콘텐츠 라이프사이클**을 클릭합니다.
3. **보유** 탭을 클릭합니다.
   **보유 정책** 페이지가 표시됩니다.
4. **보유 정책 추가**를 클릭합니다.
   **기준 정의** 페이지가 나타납니다.
5. 각 필드에 적절한 정보를 추가하거나 선택하세요. 다음 표에서는 각 필드와 그 설명을 나열하고 있습니다.

   |  |  |
   | --- | --- |
   | **필드** | **설명** |
   | **이름**  **(필수)** | 보유 정책의 이름입니다.  최대 길이: 60자. |
   | **설명**  **(선택 사항)** | 이 보유 정책의 설명입니다.  최대 길이: 300자. |
   | **보유 기간**  **(필수 사항)** | 다음 기준 중 하나를 기반으로 특정 기간 동안 보드가 영구 삭제되지 않도록 방지합니다: **마지막 접근**, **마지막 수정**, 또는 **생성 시**. 숫자를 선택한 후 **월** 또는 **년**을 선택한 다음 보유 기간이 계산되는 이벤트를 선택하세요.  보유 기간을 월 단위로 지정하는 경우 1개월에서 120개월 사이의 보유 기간을 선택해야 합니다.  보유 기간을 연 단위로 지정하는 경우 1년에서 10년 사이의 보유 기간을 선택해야 합니다. |
   | **범위**  **(필수)** | 이 보유 정책의 범위를 선택하세요. 범위는 이 보유 정책이 적용되는 보드를 나타냅니다. 조직 내 모든 보드에 대해 또는 특정 보드 분류 수준에 대해 보유 정책의 범위를 설정할 수 있습니다.  **조직 내 모든 보드에 대해 보유 정책 설정** 조직 내 모든 보드에 대해 보유 정책의 범위를 설정하려면, **범위** 목록에서 **조직 내 모든 보드**를 선택하세요.  **조직 내 하나 이상의 팀에 대해 보유 정책 설정** 조직 내 하나 이상의 팀에 대해 보유 정책의 범위를 설정하려면 다음 단계를 수행하세요:  1. **범위** 목록에서 **팀**을 선택합니다. 2. 팀 입력 상자를 클릭하고, 보유 정책을 적용할 각 팀을 선택합니다. 선택한 팀 옆에 체크 표시가 나타나 보유 정책과 연관됨을 나타냅니다.   ✏️ - 보유 정책에 대해 여러 팀을 선택할 수 있습니다. 하지만, 특정 팀은 한 번에 하나의 보유 정책에만 연결될 수 있습니다.  - 삭제된 팀을 포함하여 모든 팀을 보유 정책 설정의 범위로 선택할 수 있습니다.   - 보유 정책의 범위로 선택된 팀은 범위에서 제거되기 전까지 영구 삭제할 수 없습니다.  **보드 분류 수준에 보유 정책 설정**  ✏️ 보유 정책의 범위를 특정 보드 분류 수준으로 설정하려면, 데이터 분류 기능이 켜져 있는지 확인해야 합니다. 보유 정책에 보드 분류 수준이 사용되면 데이터 분류 기능을 끌 수 없습니다. 자세한 내용은 [데이터 분류](https://help.miro.com/hc/sections/15451275412498-Auto-classification) 문서를 참조하십시오.  특정 보드 분류 수준에 대해 보유 정책 범위를 설정하려면 다음 단계를 수행하세요:  1. **범위** 목록에서 **분류**를 선택합니다. 2. **분류** 목록 옆 리스트를 클릭한 후, 보유 정책을 적용할 분류 수준을 선택합니다. 분류 수준을 검색한 후 선택할 수도 있습니다.  선택한 분류 수준 옆에 체크 표시가 나타나며, 이는 보유 정책과 연결됨을 뜻합니다.  ✏️ **Notes:** - 여러 분류 수준을 한 번에 선택할 수 있습니다. - 동일한 분류 수준을 서로 다른 보유 정책에 설정할 수 없습니다. 특정 분류 수준이 이미 보유 정책과 관련이 있는 경우, 해당 분류 수준은 비활성화 상태로 표시됩니다.  - 보드 분류 수준을 사용 중인 보유 정책에서는 데이터 분류 기능을 비활성화할 수 없습니다.  - 분류 수준이 보유 정책과 연결되면 해당 특정 분류 수준을 삭제할 수 없습니다. - 보드가 조직 범위와 분류 범위 보유 정책 모두에 의해 관리되는 경우, 보유 기간이 더 긴 정책이 적용됩니다. |
6. 다음**을** 클릭합니다.
    **영향 검토 페이지**가 나타납니다.
7. 보유 정책의 영향을 검토합니다. 검토 영향 페이지는 다음 정보를 제공합니다:
   - **요약:** 정책 이름, 보유 기간, 범위와 같은 보유 정책 구성.
   - **정책 영향:** 이 정책에 의해 관리될 보드의 수. 보유 정책은 휴지통에 있는 보드에도 적용되며, 검토 영향 계산에 포함됩니다.

   > ✏️ 보드가 시간 기반 및 등급 기반 보유 정책 모두에 의해 관리되는 경우, 더 긴 보유 기간을 가진 정책이 적용됩니다.
8. 구성을 저장하고 보유 정책을 적용하려면 **게시**를 클릭하세요.

:::note
정책을 생성하거나 업데이트 또는 삭제할 때 보유 정책 프로세스가 작동하며 완료하는 데 24시간까지 소요될 수 있습니다. 그러나 정책의 이름이나 설명을 업데이트하는 것은 즉시 이루어지며, 이러한 작업은 보유 정책 프로세스를 작동시키지 않습니다.
:::
