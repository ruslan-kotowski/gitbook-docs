:::note
처분 정책을 추가하려면 [데이터 거버넌스 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 필요합니다. 데이터 거버넌스 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
:::

처분 정책을 추가하려면 다음 단계를 수행하세요:

1. Miro [설정](https://miro.com/app/settings)으로 이동합니다.
2. 좌측 패널의 **Enterprise Guard** 아래에서 **Content lifecycle**을 클릭합니다.
3. **처분** 탭을 클릭합니다.
   **처분 정책** 페이지가 나타납니다.
4. **처분 정책 추가**를 클릭합니다.
5. 각 필드에 적합한 정보를 입력하거나 선택하세요. 아래 표는 각 필드와 그 설명을 나열한 것입니다.

   |  |  |
   | --- | --- |
   | **필드** | **설명** |
   | **이름**  **(필수)** | 처분 정책의 이름.  최대 길이: 60자. |
   | **설명**  **(선택 사항)** | 이 처분 정책에 대한 설명입니다.  최대 길이: 300자. |
   | **처분 기간**  **(필수 사항)** | 보드가 자동으로 휴지통으로 이동되는 시점을 지정하세요. 숫자를 선택하고, **개월** 또는 **년**을 선택한 다음, 기간을 보드의 **마지막 수정** 날짜 또는 **마지막 접속** 날짜를 기준으로 계산할지 선택합니다.  처분 기간을 개월 단위로 지정한 경우, 1개월에서 120개월 사이에서 선택해야 합니다.  처분 기간을 연 단위로 지정한 경우, 1년에서 10년 사이에서 선택해야 합니다.  예를 들어, 1년 동안 보드가 수정되지 않았을 경우 휴지통으로 이동되도록 설정하려면 1년을 선택하고 **마지막 수정**을 선택할 수 있습니다. |
   | **범위**  **(필수)** | 이 처분 정책에 대한 범위를 선택하세요. 범위는 이 처분 정책이 적용될 보드를 나타냅니다. 조직의 모든 보드에 대한 범위를 설정하거나 특정 보드 분류 수준에 대한 범위를 설정할 수 있습니다.  **조직의 모든 보드에 대한 처분 정책 설정** 처분 정책의 범위를 조직의 모든 보드로 설정하려면, **범위** 목록에서 **조직의 모든 보드**를 선택하세요.  **조직 내 하나 이상의 팀에 대한 처분 정책 설정** 조직 내 하나 이상의 팀에 대한 처분 정책 범위를 설정하려면 다음 단계를 수행하세요:  1. **범위** 목록에서 **팀**을 선택합니다. 2. **팀 입력** 상자를 클릭하고 처분 정책을 적용할 각 팀을 선택합니다. 해당 팀을 처분 정책과 연결시키면 팀 옆에 체크 표시가 나타납니다.   ✏️ - 여러 팀에 대해 처분 정책을 선택할 수 있습니다. 그러나 하나의 팀은 한 번에 하나의 처분 정책에만 연계될 수 있습니다.  - 팀이 삭제되었더라도 처분 정책을 설정할 때 범위로 선택할 수 있습니다.   - 처분 정책의 범위로 선택된 팀은 범위에서 제거되기 전까지 영구 삭제될 수 없습니다.  **보드 분류 수준에 대한 처분 정책 설정**  ✏️ 특정 보드 분류 수준에 처분 정책의 범위를 설정하려면 분류 기능을 활성화해야 합니다. 일단 보드 분류 수준을 사용하는 처분 정책이 설정되면 분류 기능을 비활성화할 수 없습니다. 자세한 내용은 [데이터 분류](https://help.miro.com/hc/sections/15451275412498-Auto-classification)에 대한 설명서를 참조하세요.  특정 보드 분류 수준에 대한 처분 정책의 범위를 설정하려면 다음 단계를 수행하세요:  1. **범위** 목록에서 **분류**를 선택합니다. 2. **분류** 목록 옆에 있는 목록을 클릭한 다음, 처분 정책을 적용할 분류 수준을 선택합니다. 분류 수준을 검색한 후 선택할 수도 있습니다.  선택한 분류 수준 옆에 체크 표시가 나타나면서 처분 정책과 연결됩니다.  ✏️ **참고:** - 여러 분류 수준을 한 번에 선택할 수 있습니다. - 동일한 분류 수준을 다른 처분 정책에 설정할 수 없습니다. 특정 분류 수준이 이미 처분 정책과 연관되어 있는 경우, 해당 분류 수준은 회색으로 표시됩니다. - 보드 분류 수준이 처분 정책에 사용되면 데이터 분류 기능을 끌 수 없습니다. -일단 분류 수준이 처분 정책과 연결되면, 그 특정 분류 수준을 삭제할 수 없습니다. - 보드가 조직 범위 내의 모든 보드와 분류 범위 처분 정책 모두에 의해 관리되는 경우, 더 긴 처분 기간을 가진 정책이 적용됩니다. |
6. **다음**을 클릭하세요.
   **영향 검토 페이지**가 나타납니다.
7. 처분 정책의 영향을 검토합니다. 검토 영향 페이지는 다음 정보를 제공합니다:
   - **요약:** 정책 이름, 처분 기간, 범위와 같은 처분 정책 구성.
   - **정책 영향:** 이 정책에 의해 관리될 보드의 수.
8. 구성을 저장하고 처분 정책을 적용하려면 **게시**를 클릭하세요.
   **처분 알림 켜기** 대화 상자가 나타납니다.
9. **처분 알림**은 사용자가 보드가 비활성으로 인해 자동으로 휴지통으로 이동되기 전에 사전 경고를 받을 수 있도록 합니다. 이러한 알림은 사용자가 콘텐츠를 유지하고자 할 경우 조치를 취하도록 도와줍니다.

   처분 알림을 활성화하려면 다음을 수행하세요:

   a. **알림**을 클릭하십시오.

   b. 몇 일 전에 알림을 보낼지 구성합니다—**1~30일** 사이의 어느 값이든 가능합니다.

   알림을 활성화했을 때 **일부 보드가 즉시 휴지통으로 이동**할 경우(이미 임계값을 넘었기 때문), 해당 보드에 대해 사용자에게 알릴지를 물어봅니다. 아래 옵션을 선택할 수 있습니다:

   - **예** – 해당 보드가 즉시 휴지통으로 이동하더라도 보드 소유자 및 공동 소유자에게 알림을 보냅니다.

   -**아니오** – 즉시 이동하는 것에 대한 알림을 보내지 않고 보드를 이동시킵니다.

   알림을 활성화하면, 알림이 켜진 모든 처분 정책 범위 내의 보드를 가진 사용자는 다음을 수행합니다:

   - 설정된 검사 기간 동안 Miro **알림 피드**에서 알림을 받습니다.

   - 알림에서 보드를 직접 열 수 있습니다.

   - 다가오는 자동 휴지통 이동에 대한 경고를 보드에서 **배너**로 보게 되며, 원하는 사용자는 **보드 유지** 옵션을 선택할 수 있습니다.

:::note
정책을 생성, 업데이트 또는 삭제하면 처분 정책이 자동으로 시작되며, 이 과정은 최대 24시간까지 걸릴 수 있습니다. 그러나 정책의 이름이나 설명을 업데이트하는 것은 이 처분 정책 프로세스를 유발하지 않기 때문에 즉시 변경됩니다.
:::
