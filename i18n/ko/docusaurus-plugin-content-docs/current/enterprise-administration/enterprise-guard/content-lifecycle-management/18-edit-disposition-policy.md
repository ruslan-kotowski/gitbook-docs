:::note
처분 정책을 편집하려면 [데이터 거버넌스 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 필요합니다. 데이터 거버넌스 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
:::

처분 정책을 편집하려면 다음 단계를 수행하세요:

1. [Miro 설정](https://miro.com/app/settings)으로 이동합니다.
2. 왼쪽 창에서 **Enterprise Guard** 아래에 있는 **콘텐츠 라이프사이클**을 클릭합니다.
3. **처분** 탭을 클릭합니다.
   **처분 정책** 페이지가 나타납니다.
4. **처분 정책** 페이지에서 편집할 처분 정책을 클릭합니다.
   정책 관련 정보가 표시된 페이지가 나타납니다.
5. 페이지 오른쪽 위에서 **편집**을 클릭하고 필요한 필드를 편집합니다. 다음 표는 각 필드와 설명을 나열합니다.

   |  |  |
   | --- | --- |
   | **필드** | **설명** |
   | **이름**  **(필수)** | 처분 정책의 이름입니다.  최대 길이: 60자. |
   | **설명**  **(선택 항목)** | 이 처분 정책의 설명입니다.  최대 길이: 300자. |
   | **처분 기간**  **(필수 항목)** | 보드가 자동으로 휴지통으로 이동되는 시점을 지정하십시오. 숫자를 선택하고 **개월** 또는 **년**을 선택한 다음, 보드의 **마지막 수정 날짜** 또는 **마지막 액세스 날짜** 중에서 기간을 계산할 기준을 선택합니다.  처분 기간을 개월 단위로 지정할 경우, 1개월에서 120개월 사이의 처분 기간을 선택해야 합니다.  처분 기간을 년 단위로 지정할 경우, 1년에서 10년 사이의 처분 기간을 선택해야 합니다.  예를 들어, 보드가 1년 동안 수정되지 않았을 때 휴지통으로 이동되도록 설정하려면, 1년을 선택하고 **마지막 수정**을 선택하면 됩니다. |
   | **범위**  **(필수)** | 이 처분 정책의 범위를 선택하세요. 범위는 이 처분 정책이 적용되는 보드를 나타냅니다. 조직의 모든 보드에 대해 처분 정책의 범위를 설정하거나 특정 보드 분류 수준에 대해 설정할 수 있습니다.  **조직 내 모든 보드에 대해 처분 정책 설정** 조직 내 모든 보드에 대해 처분 정책의 범위를 설정하려면, **범위** 목록에서 **모든 보드 in the organization**을 선택하세요.  **조직 내 한 개 이상의 팀에 대해 처분 정책 설정하기** 조직 내 한 개 이상의 팀의 처분 정책 범위를 설정하려면 다음 단계를 수행하세요:  1. **범위** 목록에서 **팀**을 선택합니다. 2. **팀 입력** 상자를 클릭하고 처분 정책을 적용할 각 팀을 선택합니다. 선택한 팀 옆에 체크 표시가 나타나 처분 정책과 연관됩니다.   ✏️ - 하나의 처분 정책에 대해 여러 팀을 선택할 수 있습니다. 그러나 특정 팀은 한 번에 하나의 처분 정책에만 연계될 수 있습니다.  - 처분 정책을 설정할 때 범위로 삭제된 팀을 포함한 모든 팀을 선택할 수 있습니다.   - 처분 정책의 범위로 선택된 팀은 범위에서 제거되기 전까지 영구 삭제될 수 없습니다.  **보드 분류 수준에 대한 처분 정책 설정**  ✏️ 처분 정책의 범위를 특정 보드 분류 수준으로 설정하려면, 등급 분류 기능이 켜져 있어야 합니다. 처분 정책이 보드 분류 수준을 사용하게 되면, 등급 분류 기능을 끌 수 없습니다. 자세한 내용은 [등급 분류](https://help.miro.com/hc/sections/15451275412498-Auto-classification)에 관한 문서를 참조하세요.  처분 정책의 범위를 특정 보드 분류 수준으로 설정하려면 다음 단계를 수행하세요:  1. **범위** 목록에서 **분류**를 선택합니다. 2. **분류** 목록 옆의 목록을 클릭한 다음, 처분 정책을 적용할 분류 수준을 선택합니다. 분류 수준을 검색한 후 선택할 수도 있습니다.  선택한 분류 수준 옆에 체크 표시가 되어 처분 정책에 연결됩니다.  ✏️ **노트:** - 여러 분류 수준을 동시에 선택할 수 있습니다. - 같은 분류 수준을 다른 처분 정책에 설정할 수 없습니다. 특정 분류 수준이 이미 처분 정책에 연관된 경우, 그 분류 수준은 회색으로 표시됩니다.  - 처분 정책에서 보드 분류 수준이 사용되면, 데이터 분류 기능을 비활성화할 수 없습니다.  - 분류 수준이 특정 처분 정책과 연관되면 해당 분류 수준을 삭제할 수 없습니다. - 조직의 모든 보드에 대한 범위의 처분 정책 및 분류 범위의 처분 정책이 적용될 때, 처분 기간이 더 긴 정책이 적용됩니다. |
6. **다음**을 클릭합니다.
   **영향 검토 페이지**가 나타납니다.
7. 처분 정책의 영향을 검토합니다. 검토 영향 페이지는 다음 정보를 제공합니다:
   - **요약:** 정책 이름, 처분 기간, 및 범위와 같은 처분 정책 구성.
   - **정책 영향:** 이 정책으로 관리될 보드의 수.
8. 구성을 저장하고 처분 정책을 적용하려면 **게시**를 클릭하세요.
   처분 알림이 활성화되어 있지 않으면, **처분 알림 켜기** 대화 상자가 나타납니다.
9. **처분 알림**은 사용자가 비활성으로 인해 보드가 자동으로 휴지통으로 이동하기 전에 사전 알림을 받을 수 있게 해줍니다. 이러한 알림은 사용자가 콘텐츠를 유지하도록 조치를 취할 수 있도록 돕습니다.

   처분 알림을 활성화하려면:

   a. **알림**을 클릭합니다.

   b. 알림이 전송되기 며칠 전인지 구성합니다 — **1일에서 30일** 사이의 값을 선택하세요.

   알림을 활성화할 경우, **일부 보드가 즉시 휴지통으로 이동**해야 하는 상황이 발생할 수 있습니다(이미 기준을 초과한 경우). 이 경우 해당 보드들에 대해 사용자에게 알릴지 여부를 묻습니다. 선택할 수 있는 옵션은 다음과 같습니다:

   - **예** – 보드 소유자 및 공동 소유자에게 보드가 바로 휴지통으로 이동하더라도 알립니다.

   -**아니요** – 이 즉각적인 조치에 대한 알림을 보내지 않고 보드를 이동시킵니다.

   알림이 활성화되면, 알림이 활성화된 처분 정책의 범위 내 보드를 가진 사용자는 다음과 같습니다:

   - 설정된 검사 기간 동안 Miro **알림 피드**에서 알림을 수신하게 됩니다.

   - 알림에서 보드를 직접 열 수 있습니다.

   - 곧 자동으로 휴지통에 이동될 보드에 대한 경고 **배너**가 보드에 표시되며, 보드를 유지하고자 하는 경우 **보드 보관** 옵션도 제공됩니다.

:::note
정책을 생성, 업데이트, 또는 삭제하면 처분 정책 프로세스가 시작되며 완료까지 최대 24시간이 소요될 수 있습니다. 그러나 정책의 이름이나 설명을 업데이트하는 것은 처분 정책 프로세스를 유발하지 않으므로 즉시 반영됩니다.
:::
