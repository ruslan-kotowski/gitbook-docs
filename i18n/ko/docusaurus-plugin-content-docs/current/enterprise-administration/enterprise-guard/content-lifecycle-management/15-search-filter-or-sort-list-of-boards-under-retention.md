때로는 보유 중인 긴 보드 목록이 표시되어 특정 요구 사항에 맞춰 결과 목록을 사용자 지정하고자 할 수 있습니다. [데이터 거버넌스 관리자](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)는 이제 다양한 기준에 따라 보드 목록을 검색하거나 필터링, 정렬할 수 있는 기능을 가지며, 이를 통해 콘텐츠 수명 주기 관리 작업의 주요 측면에 집중할 수 있는 능력을 향상시킬 수 있습니다.

## 특정 보드를 검색하세요

보드 목록 페이지 상단에 위치한 검색창에 보드 이름이나 보드 ID의 키워드를 입력하여 특정 보드를 검색할 수 있습니다.

**팁:** 보드 URL에서 쉽게 보드 ID를 얻을 수 있습니다.

## 보드 목록 정렬

보드 목록을 특정 기준에 따라 오름차순 또는 내림차순으로 정렬할 수 있습니다. 예를 들어, 보유 날짜를 기준으로 보드 목록을 오름차순으로 정렬할 수 있습니다.

보드 목록을 정렬하려면 **정렬 기준** 레이블 옆의 버튼을 클릭하고 적절한 정렬 기준을 선택하세요. 예를 들어, 보유 날짜를 기준으로 보드 목록을 오름차순으로 정렬하려면 **정렬 기준** 레이블 옆에 있는 버튼을 클릭하고 **오름차순**을 선택한 다음 **보유일**을 클릭하세요.

## 보드 목록 필터

필터 옵션(그림 4)에는 보드, 팀, 소유자 기준뿐만 아니라 보드 사용 및 보유 관련 기준도 포함됩니다.

### 빠른 필터

빠른 필터를 사용해 한 번의 클릭만으로 보드 목록을 필터링할 수 있습니다.

### 스마트 필터

팀, 소유자, 분류 수준, 보드 상태, 사용 기준(마지막 편집일 등을 포함한)과 같은 여러 보드 관련 기준에 따라 목록을 좁힐 수 있는 스마트 필터를 사용하여 보드 목록을 필터링할 수도 있습니다. 보유 정책이 적용된 경우나 보유 시작 및 종료 날짜와 같은 보유 또는 처분 정책 기준에 따라 콘텐츠를 필터링할 수도 있습니다.

Additionally, you can can select and combine multiple filter criteria at once. 다양한 필터링 옵션을 통해 데이터 거버넌스 관리자는 분석을 간소화하고 특정 콘텐츠 수명 주기 관리 작업을 신속하게 분리하고 해결할 수 있습니다.

:::note
콘텐츠 탐색기 결과 목록을 필터링하려면, [데이터 거버넌스 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 있어야 합니다. 데이터 거버넌스 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
:::

보드 목록에서 스마트 필터를 사용하려면 다음 단계를 수행하세요:

1. 프로필 아바타를 클릭한 다음 **관리자 콘솔**을 클릭하세요.
2. 왼쪽 사이드바에서 **Enterprise Guard**를 클릭한 다음, **콘텐츠 수명 주기**를 클릭하세요.
3. **콘텐츠 수명 주기 개요** 페이지에서 **보유** 헤더를 클릭합니다.
   **보유 및 처분** 페이지에 보드 목록이 나타납니다.
4. **보유 및 처분** 페이지에서, 보드 목록 상단에 있는 **필터** 버튼을 클릭합니다.
5. **필터** 상자가 나타납니다.
6. 필터 기준 중에서 요구 사항을 충족하는 적절한 항목을 클릭하세요. 다음을 수행할 수 있습니다:
   다양한 기준에 따라 보드 목록을 필터링합니다. 예를 들어 보드 위치 및 소유자 기준(팀, 소유자, 분류 수준, 보드 상태)이나 보드 사용 기준(마지막 편집 기간, 마지막 편집 시작일 및 마지막 편집 종료일) 등을 포함할 수 있습니다.
   - 보유 또는 처분 정책 기준에 따라 콘텐츠 필터링하기, 적용된 보유 또는 처분 정책, 보유 시작 및 종료 날짜와 같은 기준 포함.
   - 여러 기준을 한 번에 기반으로 필터링할 수 있습니다.

   보드 목록은 필터 기준에 맞춰 결과 목록을 실시간으로 업데이트합니다.
