콘텐츠 수명 주기 대시보드는 관리자에게 보드의 생성부터 삭제까지의 전체 수명 주기를 모니터링하고 관리할 수 있는 중앙 집중형 보기를 제공하며, 조직의 데이터 보유 정책에 맞춰 조정됩니다. 각 보드의 현재 수명 주기 단계를 확인하여 적절한 콘텐츠 처리가 이루어질 수 있도록 돕습니다.

관리자는 또한 보유 및 처분 정책에 의해 관리되는 보드를 추적하고 정책 적용의 역사적 추세를 볼 수 있습니다. 대시보드에는 다가오는 자동 수명 주기 작업에 대한 사전 계획을 가능하게 하는 처분 예측이 포함되어 있습니다. 이를 통해 조직 전체에 일관된 정책 기반의 콘텐츠 관리를 적용할 수 있습니다.

> Enterprise Guard의 모든 지표는 휴지통에 있는 팀의 보드와 법적 보존 조치 중인 보드를 제외합니다.

## 오류, 빈 상태, 변경 이력 이해하기

Enterprise Guard 대시보드의 지표를 정확히 해석하려면 빈 상태와 오류 메시지를 해석하는 방법을 이해해야 합니다.

### 설정 변경 시 과거 데이터의 동작 방식 이해하기

데이터가 수집된 후 데이터 검색이 비활성화된 경우, 과거 지표는 여전히 활성 기간의 값을 표시합니다. 예를 들어, 4월에 데이터 검색이 활성화되어 있었고 5월에 비활성화한 경우:

- 4월의 데이터 값은 계속해서 대시보드에 표시됩니다.
- 5월의 그래프는 데이터 수집이 중단되었기 때문에 **데이터가 없습니다**.
