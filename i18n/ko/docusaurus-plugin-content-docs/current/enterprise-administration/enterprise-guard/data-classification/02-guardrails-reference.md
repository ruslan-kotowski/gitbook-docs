## 콘텐츠 보안 가드레일

다음 표에서는 현재 릴리스에서 지원되는 콘텐츠 보안 가드레일을 나열합니다.

|  |  |  |
| --- | --- | --- |
| **가드레일** | **설명** | **영향을 받는 사용자** |
| **콘텐츠 복제 차단** | - Miro UI와 Miro API 모두에서 콘텐츠 복제를 관리하는 옵션을 사용할 수 없습니다. 예를 들어, 누가 보드 콘텐츠를 복사할 수 있는지 업데이트하는 옵션은 UI에서 사용할 수 없으며, 보드 API 업데이트를 통해 복사 액세스를 업데이트하는 옵션도 사용할 수 없습니다.  - Miro UI에서는 콘텐츠 복제 옵션을 사용할 수 없습니다. 여기에는 다음이 포함됩니다:     - 다른 사용자의 팀에 보드 복제하기     사용자의 팀     - 보드에서 파일 다운로드     - 보드에서 이미지 다운로드     - 보드에서 PDF 다운로드     - 콘텐츠나 오브젝트 복사      보드에서 다른 보드로     - 보드를 이미지로 내보내기     - 보드를 PDF로 내보내기     - 보드를 맞춤형으로 저장하기      템플릿     - API를 통한 콘텐츠 복제는      사용할 수 없습니다. API가 반환하는      응답으로 오류 403을 | 보드 소유자 및 공동 소유자는 제한되지 않습니다. 보드 소유자 및 공동 소유자는 콘텐츠 복제 작업을 수행할 수 있습니다. 이는 보드 소유자가 보드를 업데이트하고, 향후 협업을 위해 보드의 정리된 버전을 만드는 데 필요합니다.  다른 모든 사용자는 제한됩니다. |
| **Miro AI 사용 차단** | - 모든 Miro AI 기능이 비활성화되어 텍스트 생성, 이미지 인식 및 스마트 제안과 같은 AI 기반 기능에 액세스할 수 없습니다.  - 사용자는 Miro 내에서 AI 기반 도구와 상호작용하거나 활성화할 수 없습니다.  - 기존 Miro AI 생성 콘텐츠는 변경되지 않으며, 사용자는 이 콘텐츠를 수정하거나 확장할 수 있습니다. 그러나 사용자는 더 이상 Miro AI를 사용하여 콘텐츠를 편집하거나 업데이트할 수 없습니다. | 보드 소유자 및 공동 소유자를 포함한 모든 사용자에게 제한이 적용됩니다. |

## 공유 가드레일

다음 표는 현재 릴리스에서 지원되는 공유 가드레일을 나열합니다.

|  |  |  |
| --- | --- | --- |
| **가드레일** | **설명** | **영향받는 사용자** |
| **공개 공유 차단** | - Miro UI에서는 *링크를 가진 모든 사람*과 공유하는 옵션을 사용할 수 없습니다.  - API를 통한 공개 공유는 사용할 수 없습니다. API는 응답으로 오류 403을 반환합니다.  - 라이브 임베드의 액세스 링크를 사용하여 임베드된 보드에는 공개 공유 차단이 적용되지 않습니다. 이러한 보드는 공개 링크를 통해 공유된 것으로 간주되지 않습니다. 자세한 내용은 [지원되는 앱에 Miro 보드를 임베드 허용 및 제한하는 방법](../../managing-apps-on-enterprise-plan/05-how-to-allow-or-restrict-embedding-miro-boards-in-supported-apps.md)을 참조하세요. | 보드 소유자를 포함한 모든 사용자에게 제한이 적용됩니다. |
| **팀과의 공유 차단** | - Miro UI에서 *팀 멤버 모두*와 공유하는 옵션은 사용할 수 없습니다.  - API를 통한 팀과의 공유는 사용할 수 없습니다. API가 오류 403을 응답으로 반환합니다. | 보드 소유자를 포함한 모든 사용자에게 제한이 적용됩니다. |
| **조직과의 공유 차단** | - OMiro UI에서 *조직의 모든 구성원*과 공유하는 옵션은 사용할 수 없습니다.  - API를 통한 조직과의 공유는 사용할 수 없습니다. API가 오류 403을 응답으로 반환합니다. | 보드 소유자를 포함한 모든 사용자에게 제한이 적용됩니다. |
| **허용된 도메인 이외의 도메인에서 공유 차단** | - 보드 공유는 이 목록에 포함된 허용된 도메인의 이메일 주소를 가진 사용자로만 제한됩니다. 이 가드레일은 별도의 가드레일에 의해 제어되는 팀, 조직 또는 공개 링크를 통한 액세스에는 영향을 미치지 않습니다.  이 목록에 최대 20개의 도메인을 추가할 수 있습니다.  이 가드레일은 [**보안 > 공유 > 허용된 도메인**](../data-security/07-sharing-policy-on-enterprise-plan.md) 설정과 함께 작동하도록 설계되었으며, 조직 및 팀 수준에서 구성할 수 있습니다. 이는 **허용된 도메인** 설정이 활성화된 경우 공유를 허용하고자 하는 도메인이 인텔리전트 가드레일 설정과 [**보안 > 공유 > 허용된 도메인**](../data-security/07-sharing-policy-on-enterprise-plan.md) 설정 모두에 나열되어 있어야 함을 의미합니다.   **참고:**  보드가 이 목록에 없는 이메일 주소와 이미 공유된 경우, 이미 보드에 액세스할 수 있는 사용자는 계속 액세스할 수 있습니다.  이미 보드에 액세스 권한이 있지만 허용된 도메인 목록에 포함되지 않은 기존 사용자는 보드 액세스 관리 UI에 표시됩니다. 사용자에 대한 액세스를 수동으로 제거할 수 있습니다. 등급 분류 페이지를 통해 적용된 도메인 제한 정보를 쉽게 볼 수 있습니다.   **예시 1:** **보안 > 공유 > 허용된 도메인:** miro.com, gmail.com  **가드레일 허용 도메인:** miro.com  ***결과:*** 직접 이메일 초대를 통한 보드 공유는 miro.com으로 끝나는 이메일 주소로 제한됩니다. gmail.com은 보안 > 공유 > 허용된 도메인 설정에 포함되지만, 가드레일에서는 허용되지 않습니다.  **예시 2:** **보안 > 공유 > 허용된 도메인:** miro.com, gmail.com  **가드레일 허용 도메인:** example.org, example.com  ***결과:*** 이메일 초대를 통한 보드 공유는 두 목록이 겹치는 부분이 없기 때문에 어떤 도메인에도 허용되지 않습니다. | 이메일 초대를 통한 보드 공유는 이 목록에 있는 허용된 도메인에 속한 이메일 주소의 사용자로 제한됩니다. 이 가드레일은 팀, 조직, 또는 공개 링크를 통한 액세스에는 영향을 미치지 않습니다. 이러한 경우는 별도의 가드레일로 관리됩니다.  보드가 이미 이 목록에 없는 이메일 주소로 공유된 경우, 보드에 이미 액세스 권한이 있는 사용자들은 계속 액세스할 수 있습니다.   이 가드레일은 [**보안 > 공유 > 허용된 도메인**](../data-security/07-sharing-policy-on-enterprise-plan.md) 설정과 함께 작동하도록 설계되었으며, 이는 조직 및 팀 수준에서 구성할 수 있습니다. 상세한 설명과 예시는 설명 열을 참조하세요. |
