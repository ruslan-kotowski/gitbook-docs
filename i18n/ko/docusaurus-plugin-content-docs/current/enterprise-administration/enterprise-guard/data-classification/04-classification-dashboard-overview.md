등급 분류 대시보드는 관리자가 조직 전체의 보드 등급 분류를 추적하고 관리할 수 있는 중앙 집중화된 보기를 제공합니다. 대시보드는 분류된 보드와 아직 분류되지 않은 보드를 명확하게 분류하여 포괄적인 커버리지를 보장하고 주의가 필요한 영역을 식별하는 데 도움을 줍니다.

관리자는 보드가 어떻게 분류되고 있는지 이해하기 위해 수동, 자동, 비분류 여부에 따라 사용된 분류 방법을 모니터링할 수 있습니다. 또한, 등급 분류 방법 이력은 시간이 지남에 따라 변화를 시각화하여 트렌드와 지속적인 보드 분류의 효과에 대한 인사이트를 제공합니다.

:::note
지표에 관한 메모:

- Enterprise Guard의 모든 지표는 휴지통에 있는 팀의 보드와 법적 보존 조치 중인 보드를 제외합니다.
- 모든 분류 지표는 템플릿과 휴지통에 있는 보드를 제외합니다.
:::

## 오류, 빈 상태, 변경 이력 이해하기

Enterprise Guard 대시보드의 지표를 정확히 해석하려면 빈 상태와 오류 메시지를 해석하는 방법을 이해해야 합니다.

### 설정 변경 시 과거 데이터의 동작 방식 이해하기

데이터가 수집된 후 기능(예: 등급 분류)이 비활성화된 경우, 과거 지표는 여전히 활성 기간의 값을 표시합니다. 예를 들어, 4월에 등급 분류가 활성화되어 있었고 5월에 비활성화했을 때, 20개의 보드가 등급 분류되었습니다.

- 4월의 데이터 값은 계속해서 대시보드에 표시됩니다.
- 5월의 그래프는 **데이터가 없습니다**로 표시될 것이며, 이는 데이터 수집이 중단되었기 때문입니다.
