가드레일 정의는 자동 분류 및 가드레일 구성 흐름의 세 번째 단계입니다. 이 흐름의 이 단계에서는 각 분류 수준에 적용되는 제한 사항인 가드레일을 구성하게 됩니다. 예를 들어, 공개 공유 차단, 팀과의 공유 차단, 조직과의 공유 차단, 콘텐츠 복제 차단 등이 있습니다. 예를 들어, 가드레일을 구성하여 공공 공유를 차단하고, 팀과의 공유를 차단하고, 조직과의 공유를 차단하고, 기밀로 분류된 보드의 사용자의 콘텐츠 복제를 차단할 수 있습니다.

### 필수 요구 사항

- 자동 분류 및 가드레일 흐름의 첫 번째와 두 번째 단계를 완료해야 합니다, [1: 분류 수준 정의](07-define-classification-levels.md) 및 [2: 자동 분류 정의하기](07-define-classification-levels.md).
- 보안 및 거버넌스 요구 사항에 따라 각 분류 수준에 할당할 가드레일을 알아야 합니다.
- [민감한 콘텐츠 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 있어야 합니다. 민감한 콘텐츠 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.

관리자는 조직 내에서 인텔리전트 가드레일을 도입할 수 있는 두 가지 옵션이 있습니다.
- **기본 모드:** 기본적으로 가드레일은 보드의 활성 공유 옵션에 영향을 주지 않으며, 이는 자동 분류 중 보드가 재분류될 때를 포함하여 진행 중인 협업이 방해받지 않도록 하기 위함입니다.

- **엄격 모드:** 엄격 모드에서 가드레일 적용 토글을 켜면 가드레일이 모든 활성 공유 옵션을 무시합니다. 이는 관리자에게 가장 엄격한 수준의 제어를 제공하지만, 일부 사용자가 즉시 보드 접근 권한을 잃을 수 있습니다.

## 가드레일 지정

분류 수준에 가드레일을 할당하려면 다음 단계를 수행하세요:

1. **가드레일 정의** 페이지에서, 가드레일을 할당하려는 분류 수준의 **편집** 아이콘을 클릭하세요. 예를 들어, CONFIDENTIAL 분류 수준에 가드레일을 지정하려면 CONFIDENTIAL 분류 수준의 행에 있는 편집 아이콘을 클릭하세요.
2. 할당하려는 각 가드레일 레이블에 대한 체크박스를 선택하여 분류 수준을 지정하세요. 예를 들어, 공개 공유 차단, 팀과의 공유 차단, 조직과의 공유 차단, 기밀로 분류된 보드 사용자의 콘텐츠 복제 차단, 허용된 도메인 외부에서의 공유 차단, Miro AI 사용 차단을 원하시면, 다음 체크박스를 선택하세요:
   - **콘텐츠 복제 차단**- **Miro AI 사용 차단 (베타)**
   - **공개 공유 차단**
   - **팀과의 공유 차단**
   **조직과의 공유 차단**
   **- 허용된 도메인 외부에서 공유 차단 (베타)**
   이 확인란을 선택한 후에는 조직에서 허용된 도메인 목록에서 입력 및 선택하거나, 박스에 새 도메인을 입력한 다음, **추가**를 클릭하여 허용할 도메인을 추가해야 합니다.
3. 기본적으로 가드레일은 보드를 재분류하는 경우를 포함하여 진행 중인 협업이 방해받지 않도록 활성화된 공유 옵션에 영향을 주지 않습니다.

   활성화된 모든 공유 옵션을 무시하고 가드레일을 엄격하게 적용하려면 **엄격 모드에서 가드레일 적용** 전환을 켜세요. 이로 인해 사용자가 보드에 액세스하지 못할 수 있습니다. 이렇게 하면 관리자에게 가장 엄격한 수준의 제어를 제공하지만 일부 사용자는 즉시 보드 접근 권한을 잃을 수 있습니다.
   ![가드레일.png](images/26201337432722_guardrails.png)
4. **완료**를 클릭하세요.
   구성이 저장되었지만, [**영향 검토**](06-review-impact.md) 페이지에서 **게시**를 클릭해야만 적용됩니다.
5. 여러 분류 수준에 대한 가드레일 정의가 완료되면, [가드레일 구성 완료](05-define-guardrails.md)로 진행하세요.

## 가드레일 구성 완료

다른 분류 수준에 대한 가드레일 할당을 완료한 후, **다음**을 클릭하세요. 구성이 저장되었지만, [영향 검토](06-review-impact.md) 페이지에서 **게시**를 클릭해야만 적용됩니다.
