## Enterprise Guard 관리자 역할 할당

:::note
사용자가 Enterprise Guard 관리자 역할을 할당받으려면 **회사 관리자**여야 합니다.
:::

1. **프로필 설정**으로 이동:

   - 보드에서: **메인 메뉴 > 환경설정 > 프로필 설정**.
   - 대시보드에서: 오른쪽 상단에서 **아바타**를 클릭하고 **설정**을 클릭하십시오.
   - URL로 직접 접속: `https://miro.com/app/settings`로 이동한 후, 왼쪽 상단의 목록에서 **회사**를 선택합니다.
2. **사용자 관리**에서 **관리자 역할**을 클릭합니다.
3. 오른쪽 창에서 할당할 관리 역할을 찾습니다 (예: **데이터 거버넌스 관리자**, **민감한 콘텐츠 관리자**, 또는 **eDiscovery 관리자**).
4. 역할 옆의 **줄임표 (… )**를 클릭하고 **역할 할당**을 선택합니다.
5. 역할을 할당할 사용자를 선택합니다.
6. 창을 아래로 스크롤하여 **지정**을 클릭합니다.

## Enterprise Guard에 대한 사용자 지정 관리자 역할

사용자 지정 관리자 역할을 통해 회사 관리자는 폭넓은 관리자 역할을 부여하지 않고도 개별 Enterprise Guard 기능에 액세스할 수 있습니다. 이는 조직이 내부 거버넌스, 보안 또는 규정 준수 책임에 따라 접근을 조정할 수 있게 합니다.

회사 관리자는 사용자 지정 관리자 역할을 생성하거나 편집할 때, 해당 역할이 접근하고 관리할 수 있는 Enterprise Guard 기능을 결정하는 권한을 선택할 수 있습니다. 이러한 권한은 데이터 분류, 데이터 검색, 콘텐츠 수명 주기 관리, eDiscovery 같은 여러 Enterprise Guard 도메인에 걸쳐 있습니다.

조직에서는 필요한 권한만 할당하여 민감한 콘텐츠 검토, 분류 설정 관리, 수명 주기 정책 구성, eDiscovery 도구 액세스 같은 관리 업무를 적절한 팀에 위임할 수 있습니다. 아래 표는 사용자 지정 관리자 역할을 구성할 때 할당할 수 있는 권한을 나열하고 있습니다.
