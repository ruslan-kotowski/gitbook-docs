## 맞춤형 서비스 약관 생성

:::note
메모:

- 관리자가 맞춤형 서비스 약관을 보기 및 관리하려면 다음과 같은 Enterprise Guard 권한이 필요합니다:
  - 민감한 콘텐츠 관리자는 기본 권한을 보유합니다.
  - 사용자 지정 관리자 역할에는 다음이 포함되어야 합니다:
    - 맞춤형 서비스 약관 보기
    - 맞춤형 서비스 약관 관리
- 게스트와 외부 사용자는 제외됩니다.
- Miro는 약관 대신 링크와 메타데이터만 저장합니다.
:::

1. **설정** > **Enterprise Guard** > **맞춤형 서비스 약관**으로 이동합니다.
2. 맞춤형 서비스 약관을 처음 만드는 경우, **서비스 약관 추가**를 클릭합니다.
   이미 설정이 있는 경우, 목록 보기에서 **새로 만들기**를 클릭하여 추가합니다.
3. **설정** → **조건**:
   - **트리거**: **성공적인 로그인**과 **AI 사용** 중에서 선택합니다.
     **성공적인 로그인**

     - 로그인 직후에 대화 상자가 나타납니다.
     - 사용자는 **계속하기**를 클릭하여 수락하고 진행하거나 **로그아웃**할 수 있습니다.

     **AI 사용**

     - 사용자가 AI 레이아웃 토글, AI 측면 패널 열기, AI 도구 또는 액션(예: AI 팀원) 시작 등 Miro AI와 상호작용할 때 대화 상자가 나타납니다.
     - 사용자는 **계속**을 클릭하여 AI 기능을 수락하고 사용할 수 있습니다. 사용자가 **취소**를 클릭하면, 로그인이 유지되며 AI 기능 이외의 모든 기능을 계속 사용할 수 있습니다.
   - **범위**: **조직 내 모든 사용자와 관리자**입니다.
   - **반복 주기**: 숫자를 입력하고 **일**, **주**, 또는 **개월**을 선택하세요.기본값: 2주.
     사용자는 반복 주기가 끝나거나 약관이 업데이트될 때까지 다시 프롬프트 되지 않습니다.
4. **설정** → **콘텐츠**에서:
   - **제목** (최대 32자)
   - **설명** (최대 200자)
   - **링크:** 정책 링크 (외부 호스팅됨). 추가 링크를 포함하려면 +링크 추가를 클릭하세요. 최대 3개까지 지원됩니다. 각 링크 URL은 고유해야 합니다.
   - **링크 텍스트** (최대 60자). 각 링크 텍스트는 고유해야 합니다.
5. **미리보기 표시** (우측 상단)을 클릭하여 사용자 지정 서비스 약관 대화 상자의 내용을 확인합니다. 필요하면 사용자 지정 서비스 약관 내용을 조정하세요.
6. 맞춤형 서비스 약관 내용 준비가 완료되면, **다음**을 클릭하세요.
7. 맞춤형 서비스 약관을 검토하고, 설정 및 내용을 확인한 후 **게시**를 클릭하세요.
   선택된 트리거에 대해 즉시 적용됩니다.

## 맞춤형 서비스 약관 편집하기

1. **설정** > **Enterprise Guard** > **맞춤형 서비스 약관**을 엽니다.
2. 목록에서 업데이트하려는 맞춤형 서비스 약관 구성을 선택한 다음, **편집**을 클릭합니다.
3. **조건** 및 **내용**에서 필요한 대로 필드를 업데이트합니다.
4. 맞춤형 서비스 약관을 업데이트하고 모든 사용자 승인 내역을 즉시 초기화하려면 **즉시 게시**를 클릭합니다.
   설정된 반복 주기가 끝난 후 사용자에게 다시 알리려면 아래 화살표를 클릭하고 **다음 주기에 게시**를 선택한 후, **다음 주기에 게시**를 클릭합니다.

## 맞춤형 서비스 약관 삭제

삭제하면 맞춤형 서비스 약관이 즉시 비활성화되며 복원할 수 없습니다.

1. **설정** > **Enterprise Guard** > **맞춤형 서비스 약관**을 엽니다.
2. 리스트에서 제거할 맞춤형 서비스 약관 구성을 선택한 후 **삭제**를 클릭합니다.
3. 선택한 맞춤형 서비스 약관을 영구적으로 삭제하려면 **약관 삭제**를 클릭합니다.
