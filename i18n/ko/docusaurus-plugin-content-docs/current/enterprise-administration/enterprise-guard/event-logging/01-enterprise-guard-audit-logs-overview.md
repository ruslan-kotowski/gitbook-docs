감사 로그는 관리자에게 Enterprise Guard와 관련된 모든 이벤트의 종합적인 기록을 제공합니다. 이 로그는 효율적인 문제 해결에 유용한 리소스이며, 휴지통 유효 기간 정책 및 휴지통 보드 권한 정책 업데이트, 조직의 보유 정책 생성, 업데이트 또는 삭제, 휴지통에서의 보드 영구 삭제와 같은 중요한 이벤트에 대한 상세한 인사이트를 제공합니다. 이러한 활동을 체계적으로 추적함으로써 모니터링, 분석 및 유지보수가 강화되어 안전하고 잘 관리된 시스템을 보장합니다.

## 감사 로그의 Enterprise Guard 이벤트

기존에 기록된 [이벤트 외에도](../../security-integrations/security-management/01-audit-logs.md), 감사 로그에는 다음 이벤트 카테고리 및 Enterprise Guard와 관련된 이벤트에 대한 기록이 포함됩니다.

### 폐기 정책

다음 표에는 조직의 폐기 정책 구성 요소에 대해 기록된 이벤트 카테고리와 이벤트 작업이 나열되어 있습니다.

|  |  |
| --- | --- |
| **이벤트 카테고리** | **이벤트 작업** |
| 관리 | 조직의 휴지통 유효 기간 정책이 변경되었습니다. |
| 관리 | 조직의 휴지통 보드 권한 정책이 변경되었습니다. |

*표 1: 조직 폐기 정책 구성 요소에 대한 이벤트 카테고리와 이벤트 작업이 기록됩니다*폐기 정책에 대한 자세한 정보는 [문서](https://help.miro.com/hc/articles/13860817985426-Trash-Policy)를 참조하세요.

### 보유 정책

다음 표는 콘텐츠 보유 정책 구성 요소에 대해 기록된 이벤트 카테고리와 이벤트 작업을 나열합니다.

|  |  |
| --- | --- |
| **이벤트 카테고리** | **이벤트 작업** |
| 관리 | 조직을 위한 보유 정책 생성 |
| 관리 | 조직의 보유 정책이 업데이트되었습니다. |
| 관리 | 조직의 보유 정책이 삭제되었습니다. |

*표 2: 콘텐츠 보유 정책 구성 요소에 대해 기록된 이벤트 카테고리와 이벤트 작업*보유 정책에 대한 자세한 정보는 [문서](https://help.miro.com/hc/articles/16855776325778-Retention-Beta)를 참조하세요.

### 데이터 검색

다음 표는 콘텐츠 발견 구성 요소에 대해 기록된 이벤트 카테고리와 이벤트 작업을 나열합니다.

|  |  |
| --- | --- |
| **이벤트 카테고리** | **이벤트 작업** |
| 관리 | 조직의 개인 정보 보호 감지 변경  (활성화/비활성화) |
| 관리 | 조직에서 데이터 검색 항목을 억제했습니다. |

*표 3: 콘텐츠 발견 구성 요소에 대해 기록된 이벤트 카테고리와 이벤트 작업*

데이터 검색에 대한 자세한 내용은 [문서](../../canvas-25-admin-features/data-discovery/01-data-discovery-overview.md)를 참조하세요.

### 인텔리전트 가드레일

다음 표에는 인텔리전트 가드레일 구성 요소에 대해 기록된 이벤트 카테고리와 이벤트 작업이 나와 있습니다.

|  |  |
| --- | --- |
| **이벤트 카테고리** | **이벤트 작업** |
| 인텔리전트 가드레일 | 보드의 인텔리전트 가드레일이 변경되었습니다. |

*표 4: 인텔리전트 가드레일 구성 요소에 대해 기록된 이벤트 카테고리와 이벤트 작업*

인텔리전트 가드레일에 대한 자세한 정보는 [문서](../../canvas-25-admin-features/data-classification/01-intelligent-guardrails-overview.md)를 참조하세요.

### eDiscovery

다음 표에는 eDiscovery 구성 요소에 대해 기록된 이벤트 카테고리와 이벤트 작업이 나와 있습니다.

|  |  |
| --- | --- |
| **이벤트 카테고리** | **이벤트 작업** |
| 관리 | 조직을 위한 사례 생성 |
| 관리 | 조직에 대한 사례 종료 |
| 관리 | 조직에 대한 법적 보존 조치가 생성되었습니다. |
| 관리 | 조직에 대한 법적 보존 조치가 종료되었습니다. |
| 관리 | 보드에 법적 보존 조치가 적용되었습니다. 보드가 법적 보존 조치에서 해제되었습니다. |

*표 3: 이벤트 카테고리 및 이벤트 작업이 eDiscovery 구성 요소에 대해 기록됩니다.*

추가 정보는 [관련 문서](https://help.miro.com/hc/sections/22049853357842-eDiscovery-Legal-Hold-Beta)를 참조하세요.
