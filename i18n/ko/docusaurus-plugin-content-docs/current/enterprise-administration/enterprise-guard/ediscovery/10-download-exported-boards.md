보드를 개별적으로 내보내기 다운로드 하거나 일괄 다운로드를 이용해 시간을 절약할 수 있습니다. 일괄 다운로드를 사용하면 시스템이 내보내기 작업의 모든 보드를 하나의 아카이브로 패키징하여 각각의 보드를 따로 다운로드할 필요가 없습니다. 이 옵션은 보드를 한 곳에 모아 보관, 공유, 액세스하기 쉽게 만들어 관리자들이 대규모 내보내기를 더 효율적으로 관리할 수 있도록 도와줍니다.

## 보드를 하나의 아카이브로 내보내기 다운로드 (일괄 다운로드)

일괄 다운로드를 사용하면 완료된 내보내기 작업의 모든 보드를 하나의 아카이브에 저장할 수 있어 각 보드를 개별적으로 다운로드할 필요가 없습니다.

:::note
메모:

- 내보낸 보드는 **14일** 동안 사용할 수 있습니다.
- 일괄 다운로드는 내보내기 작업의 모든 보드가 완료되고 내보내기 결과가 만료되기 전에만 사용할 수 있습니다.
- 총 아카이브 크기가 50GB를 초과하면 시스템이 자동으로 파일을 여러 작은 아카이브로 분할합니다.
:::

1. 프로필 아바타를 클릭하고 **관리자 콘솔**을 클릭하세요.
2. 왼쪽 사이드바에서 Enterprise Guard를 클릭하고 **eDiscovery**를 클릭하세요.
3. **케이스** 탭을 클릭하세요.
   케이스 목록이 나타납니다.
4. 내보내기가 시작된 케이스를 엽니다.
5. **내보내기** 탭을 클릭하세요.
6. 다운로드하려는 보드를 포함하는 내보내기 작업을 클릭하세요.
   내보내기 작업 세부 정보 페이지가 나타납니다.
7. 내보내기 작업이 완료되면, **보드 다운로드** 버튼이 활성화됩니다. **보드 다운로드**를 클릭해 보드 내보내기 작업에서 모든 보드를 하나의 아카이브로 다운로드하세요.

   다운로드를 시작하면 시스템이 아카이브를 준비합니다. 다운로드가 완료되면, 아카이브 파일을 열어 보드에 액세스하세요. 각 보드는 패키지 내에 별도의 폴더로 저장됩니다.

## 개별적으로 보드 내보내기 다운로드

1. 프로필 아바타를 클릭한 후, **관리자 콘솔**을 클릭하세요.
2. 왼쪽 사이드바에서 Enterprise Guard를 클릭한 다음, **eDiscovery**를 클릭하세요.
3. **케이스** 탭을 클릭하세요.
   케이스 목록이 나타납니다.
4. 내보내기를 시작한 케이스를 여세요.
5. **내보내기** 탭을 클릭하세요.
6. 다운로드할 보드를 포함하는 내보내기 작업을 클릭하세요.
   내보내기 작업 세부 페이지가 나타납니다.
7. 보드를 다운로드할 준비가 되면 다운로드 아이콘이 활성화되어 나타납니다(회색 처리되지 않음). 다운로드하려는 각 보드에 대해 다운로드 버튼을 클릭하세요.

:::note
내보내기된 보드는 **14일** 동안 사용할 수 있습니다.
:::
