법적 보존 조치를 위한 케이스를 만드는 것은 소송이나 조사가 예상될 때 eDiscovery 프로세스의 첫 번째 중요한 단계입니다. 케이스는 법적 보존 조치 프로세스를 관리하기 위한 조직적 기초 역할을 하며, 데이터 보존과 관련된 모든 활동을 명확하게 식별하고 문서화하며 감독할 수 있습니다. 케이스를 제대로 만들지 않으면 법적 보존 조치 프로세스가 구조적으로 부족할 수 있으며, 이는 중요한 정보의 우발적 손실이나 삭제로 이어져 잠재적인 법적 위험과 처벌을 초래할 수 있습니다.

[eDiscovery 관리자](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)로서 법적 보존 조치를 시작하고 관리하는 데 중요한 역할을 합니다. 사례를 생성함으로써 관련 Miro 보드가 법적 문제의 기간 동안 적절히 보존될 수 있도록 공식적인 구조를 설정할 수 있습니다. 사례의 목적 중 하나는 관리자가 여러 법적 보존 조치를 하나의 사례로 그룹화할 수 있는 컨테이너 역할을 한다는 것입니다. 이는 서로 다른 법적 보존 조치가 같은 조사, 예를 들어 법정 소송의 일부인 경우 매우 유용합니다.

많은 경우 여러 사용자를 법적 보존 조치에 포함시켜야 합니다. 조사나 법적 사건이 진행됨에 따라 추가 보존 조치를 생성해야 할 수도 있으며, 이때 모든 보존 조치를 하나의 케이스 아래 정리하면 더 효과적으로 관리할 수 있습니다. 관련된 모든 보존 조치를 단일 케이스로 그룹화하면, 특정 조사가 하나의 중앙 구조 내에 포함되므로 관리 및 감독이 용이해집니다.

법적 보존 케이스를 효과적으로 생성하고 관리함으로써 모든 관련 데이터를 보존하고, 복잡한 조사를 관리하는 과정을 간소화하여 조직의 법적 위험을 줄일 수 있습니다.

케이스를 생성하려면 다음 단계를 수행하세요:

:::note
이 작업을 수행하려면 [eDiscovery 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 필요합니다. eDiscovery 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
:::

1. Miro 설정으로 이동합니다.
2. **Enterprise Guard**의 왼쪽 패널에서 **eDiscovery**를 클릭합니다.
3. **eDiscovery** 페이지에서 **케이스** 탭을 클릭합니다.
4. **케이스** 페이지에서 **케이스 생성**을 클릭합니다.
5. **케이스 생성** 페이지에서 각 필드에 필요한 정보를 입력합니다. 다음 표는 각 필드와 그 설명을 나열합니다.

   |  |  |
   | --- | --- |
   | **필드** | **설명** |
   | 조사 이름  **(필수)** | 사건의 이름입니다.  최대 길이: 60자. |
   | 설명  **(선택)** | 사건에 대한 설명입니다.  최대 길이: 300자. |
6. **사례 생성**을 클릭합니다. 사례가 생성되어 eDiscovery 페이지의 사례 목록에 나타납니다. 이제 사례에 법적 보존 조치를 추가할 수 있습니다.
