사례를 편집하면 eDiscovery 관리자가 사례 세부 정보를 최신 상태로 유지하고 법적 문제의 변화하는 범위에 맞출 수 있습니다. 조사가 진행됨에 따라, 초점, 용어 또는 내부 문서화 기준의 변경 사항을 반영하기 위해 사건 이름이나 설명을 업데이트해야 할 수도 있습니다.

사례가 하나 이상의 법적 보존 조치의 중심 컨테이너 역할을 하므로, 그 정보를 최신 상태로 유지하는 것은 법적 절차에 관련된 모든 이해관계자에게 명확성, 일관성, 그리고 더 쉬운 내비게이션을 보장하는 데 도움이 됩니다.

케이스를 편집하려면 다음 단계를 수행하세요:

:::note
이 작업을 수행하려면 [eDiscovery 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 필요합니다. eDiscovery 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
:::

1. Miro 설정으로 이동합니다.
2. 왼쪽 창에서 **Enterprise Guard** 아래의 **eDiscovery**를 클릭합니다.
3. **eDiscovery** 페이지에서 **조사** 탭을 클릭하세요.
4. 편집하려는 케이스의 행에서 세 점 아이콘을 클릭한 후 **케이스 편집**을 클릭하세요.
5. **케이스 편집** 페이지에서 각 필드에 적절한 정보를 입력하세요. 다음 표에는 각 필드와 해당 설명이 나와 있습니다.

   |  |  |
   | --- | --- |
   | **필드** | **설명** |
   | 케이스 이름  **(필수)** | 사례 이름.  최대 길이: 60자 |
   | 설명  **(선택 사항)** | 설명  최대 길이: 300자 |
6. **저장**을 클릭합니다.
   사건 세부 정보가 업데이트되어 eDiscovery 페이지의 사건 목록에 표시됩니다.
