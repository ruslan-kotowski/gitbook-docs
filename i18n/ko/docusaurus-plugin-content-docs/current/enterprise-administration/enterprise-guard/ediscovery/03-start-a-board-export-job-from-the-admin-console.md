1. 프로필 아바타를 클릭한 다음 **관리자 콘솔**을 클릭하세요.
2. 왼쪽 사이드바에서 Enterprise Guard를 클릭한 다음 **eDiscovery**를 클릭하세요.
3. **케이스** 탭을 클릭하세요.
   케이스 목록이 표시됩니다.
4. 내보내려는 하나 이상의 법적 보존 조치가 포함된 케이스를 클릭하세요.
   케이스에 속한 법적 보존 조치 목록이 표시됩니다.
5. 다음 방법 중 하나로 보드를 내보낼 수 있습니다:
   - 법적 보존 조치 목록 보기에서: 법적 보존 조치 목록 페이지에서 페이지 상단에 있는 **콘텐츠 내보내기** 버튼을 클릭한 다음, 내보내려는 법적 보존 조치를 클릭해 모든 관련 보드를 내보냅니다.
     대화 상자가 표시됩니다. 6단계로 계속 진행하세요.
   - 법적 보존 조치 세부 정보 페이지에서: 법적 보존 조치 목록 페이지에서, 열려는 법적 보존 조치 이름을 클릭한 다음 페이지 상단의 내보내기 버튼을 클릭하세요.
     대화 상자가 표시됩니다. 6단계로 진행하세요.
6. **내보내기 이름** 상자에 이 보드 내보내기 작업의 내보내기 이름을 입력하세요.
7. **형식** 목록에서 보드를 내보낼 파일 형식을 선택하세요. SVG, PDF 또는 HTML 파일로 내보낼 수 있습니다. 기본 설정으로 형식은 SVG로 지정되어 있습니다.
8. (선택 사항) 내보내기 작업의 각 보드에 대한 [콘텐츠 로그](06-content-logs-overview.md)를 포함하려면 **콘텐츠 로그 포함**을 선택하세요.
9. **내보내기**를 클릭하세요.
   내보내기 작업은 사례 페이지의 **내보내기** 탭에 나타납니다. 내보내기 작업 모니터링 및 내보내기 상태 보기 정보는 [이 문서를 참조하세요](07-monitor-board-export-jobs-and-view-status-from-the-admin-console.md).
