콘텐츠 로그는 엔터프라이즈 고객이 보드에서의 사용자 활동에 대한 상세 기록을 수집하여 조사나 규정 보관에 활용할 수 있게 합니다.

콘텐츠 로그는 법적, 규정 준수, 보안 목적에 맞춰 제작된 다양한 도구로 수집될 수 있습니다. 사용자 활동 데이터를 대규모로 내보낼 수 있는 솔루션을 제공함으로써, Miro는 고객의 위험을 줄이고, 엄격한 보안과 규정 준수 요구사항을 준수하면서도 더 많은 지적 근로자들이 Miro의 협업 능력을 경험할 수 있는 기회를 제공합니다.

## 콘텐츠 로그 데이터

사용자가 보드에서 위젯을 업데이트하면 사용자 작업 시간, 사용자 세부 정보, 작업 유형(생성, 업데이트, 삭제), 보드 및 위젯 ID, 사용자 작업 결과로 위젯 상태와 관련된 기타 정보를 포함한 로그 항목이 생성됩니다. 콘텐츠 로그는 위젯 위치, 크기, 회전의 업데이트를 *기록하지 않습니다*.

## 콘텐츠 로그 수집

이벤트는 관리자가 콘텐츠 로그 수집을 활성화하는 순간부터 기록됩니다. 수집된 이벤트는 기본적으로 30일 동안 저장됩니다.

콘텐츠 로그 수집을 활성화하려면 다음 단계를 수행하세요:

1. 회사 설정으로 이동합니다.
2. 왼쪽 패널에서 **보안** > **감사 로그**를 클릭합니다.
3. **감사 로그** 아래에서 **설정** 탭을 클릭합니다.
4. **콘텐츠 로그** 섹션 아래에서 **콘텐츠 로그 수집**을 위해 토글을 클릭하여 활성화합니다.

   *콘텐츠 로그 수집 활성화*

## API를 통한 콘텐츠 로그 액세스

관리자는 조직 내에서 [콘텐츠 로그 API](https://developers.miro.com/reference/board-content-logs)를 사용하여 프로그래밍 방식으로 콘텐츠 로그 데이터를 액세스할 수 있습니다. 관리자들은 Smarsh나 Theta Lake 같은 지원되는 통합을 이용하여 콘텐츠 로그 데이터를 수집할 수도 있습니다.

API에 대한 접근을 인증하기 위해, 관리자는 다음 옵션 중에서 선택할 수 있습니다:

- 기업 통합에서 eDiscovery 토글을 활성화합니다.
- 플랫폼 애플리케이션을 생성하고 콘텐츠 로그: 읽기 권한을 부여합니다.
- 마켓플레이스에서 eDiscovery 통합 중 하나를 설치하고 권한을 부여합니다.

## 콘텐츠 로그 삭제

관리자는 콘텐츠 로그의 보유 정책을 30, 90, 180 또는 365일 중에서 선택하여 설정할 수 있습니다. 기본적으로 보유 기간은 30일로 설정됩니다.

:::note
콘텐츠 로그가 삭제된 후에는 복구할 수 없습니다.
:::

삭제 기간을 설정하려면 다음 단계를 수행하세요:

1. 회사 설정으로 이동합니다.
2. 왼쪽 패널에서 **보안** > **감사 로그**를 클릭합니다.
3. **감사 로그** 아래에서 **설정** 탭을 클릭합니다.
4. **콘텐츠 로그** 아래에서 드롭다운 목록에서 옵션을 선택합니다. 선택을 확인하라는 요청이 표시됩니다.
   ![content_logs_duration.png](images/34049665919634_content_logs_duration.png)
   *콘텐츠 로그 보유 정책 설정*
