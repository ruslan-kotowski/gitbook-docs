법적 보존 조치를 편집하면 eDiscovery 관리자가 사건 요구 사항의 변동에 따라 진행 중인 법적 보존 노력을 조정하고 개선할 수 있습니다. 새로운 관리자 식별 여부, 추가적인 Miro 보드의 관련성 여부, 혹은 기존 보드나 사용자가 더 이상 범위에 포함되지 않는 경우, 법적 보존 조치를 편집하면 정확한 데이터가 법적 절차 내내 보존되고 방어될 수 있습니다.

관리자는 법적 보존 조치의 이름이나 설명을 업데이트하고 필요에 따라 사용자와 보드를 추가하거나 제거할 수 있습니다. 이 유연성은 동적인 법률 워크플로를 지원하며 보존이 법률 사안의 범위와 정확하게 일치되고 최신 상태를 유지할 수 있도록 보장하여 규정 준수를 유지하면서 불필요한 데이터 보유를 피할 수 있도록 합니다.

법적 보존 조치가 편집될 때:

- 보류에 새로 추가된 보드는 그 시점부터 버전이 보존되기 시작합니다.
- 보드 또는 사용자가 보존 조치에서 제거되는 경우 더 이상 보존되지 않으며, 그들의 버전도 해당 법적 보존 조치의 일부로 보존되지 않습니다.
- 보존 조치가 적용된 보드는 모든 버전이 계속해서 보존되며, 조치 후 발생하는 삭제도 포함됩니다.

이 접근 방식은 사건이 진행됨에 따라 조직이 법적 요구에 정확성과 책임감을 가지고 대응할 수 있도록 보장합니다.

법적 보존 조치를 편집하려면 다음 단계를 수행하세요:

:::note
이 작업을 수행하려면 [eDiscovery 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 필요합니다. eDiscovery 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
:::

1. Miro 설정으로 이동합니다.
2. 왼쪽 창에서 **Enterprise Guard** 아래의 **eDiscovery**를 클릭합니다.
3. **eDiscovery** 페이지에서 **Cases** 탭을 클릭하세요.
4. 편집하려는 법적 보존 조치가 있는 케이스를 클릭하세요.
   사건 내 법적 보존 조치 목록이 나타납니다.
5. 편집하려는 법적 보존 조치의 행에 있는 세 점 아이콘을 클릭한 다음, **법적 보존 조치 편집**을 클릭하세요.
6. **법적 보존 조치 편집** 페이지에서 각 필드에 대해 적절한 정보를 입력하거나 선택하세요. 다음 표에는 각 필드와 그 설명이 나와 있습니다.

   |  |  |
   | --- | --- |
   | **필드** | **설명** |
   | 법적 보존 조치 이름  **(필수)** | 법적 보존 조치의 이름.  최대 길이: 60자 |
   | 기준  **(필수)** | 이 법적 보존 조치에 포함된 콘텐츠 유형. 이번 릴리스는 모든 콘텐츠만 지원합니다. |
   | **콘텐츠를 소유, 공동 소유, 액세스, 수정하거나 생성한 사용자**  **(필수)** | 법적 보존 조치를 적용할 사용자를 추가하세요. 필드를 클릭해 이름이나 이메일로 검색하세요. 법적 보존 조치당 최대 200명의 사용자를 포함할 수 있으며, 법적 보존 조치 업데이트 시 추가된 사용자도 포함됩니다.  **메모:**  법적 보존 조치 상태의 사용자가 보드를 열거나 수정하거나 이름 변경 또는 콘텐츠 추가와 같은 방식으로 보드와 상호 작용할 때, 해당 보드는 플래그 표시되고 보존됩니다. 예를 들어, 보드의 이름이 변경되거나 콘텐츠가 업데이트되면 자동으로 법적 보존 조치가 적용됩니다. 추가로, 보드 소유 및 보드 생성이 일시 중지됩니다.  법적 보존 조치가 편집되면, 보존 조치 당시 관리자가 생성, 소유, 공동 소유한 보드에 적용됩니다. 또한, 보류 상태가 적용된 후 보드 보관인이 접근하여 수정하는 모든 보드도 포함됩니다. 현재 릴리스에서는 보드 액세스 및 업데이트 세부 정보를 확인할 수 없습니다.  단계 9에서 법적 보존 조치 업데이트를 저장하면 새로 추가된 보드의 버전이 보존되기 시작합니다.  - 법적 보존 조치에서 제거된 보드나 사용자는 더 이상 보존되지 않으며, 이들의 버전도 유지되지 않습니다.  보존 조치가 적용된 보드에는 삭제된 내용을 포함하여 모든 버전이 계속 보존됩니다. |
7. **다음**을 클릭하세요. **영향 검토** 페이지가 나타납니다.
8. 법적 보존 조치 생성의 영향을 검토하십시오, 예를 들어:
   보류 중인 보드 수, 보류에서 해제될 보드 수, 보류에 추가될 보드 수
   보드를 소유, 공동 소유, 액세스, 수정 또는 생성한 사용자.
   보류 기준
   - 보존 중인 보드 목록

   **메모:**
   보존 중인 보드는 여전히 액세스하여 편집할 수 있지만 모든 버전이 저장됩니다. 콘텐츠를 삭제해도 보존 조치 하에서는 여전히 사용 가능합니다. 보존 조치 중인 콘텐츠 항목 수는 향후 사용자 작업에 따라 늘어날 수 있습니다.

   법적 보존 조치 상태의 사용자가 보드를 열거나 수정하거나 어떤 방식으로든 조작(이름 변경 또는 콘텐츠 추가)하면 해당 보드에 플래그가 지정되고 보존됩니다. 예를 들어, 보드의 이름이 변경되거나 콘텐츠가 업데이트되면 자동으로 법적 보존 조치가 적용됩니다. 또한, 보드 소유 및 보드 생성이 보류됩니다.

   법적 보존 조치가 생성되면, 이는 보존 시점에 관리자가 생성, 소유 또는 공동 소유한 보드에 적용됩니다. 홀드가 설정된 후, 보드 관리자가 접근하여 수정한 모든 보드도 포함됩니다. 히스토리 보드 액세스 및 업데이트 세부 정보는 이번 릴리스에서 사용할 수 없습니다.
9. 생성 중인 법적 보존 조치의 영향을 검토한 후, **법적 보존 조치 저장**을 클릭하세요.
   사례 페이지에 법적 보존 조치에 대한 업데이트가 표시됩니다. 여기에는 법적 보존 조치의 이름, 법적 보존 조치로 영향을 받는 콘텐츠 유형, 이 법적 보존 조치에 속한 사용자 수, 법적 보존 조치가 생성된 날짜, 법적 보존 조치의 상태 및 법적 보존 조치에 속한 보드 수가 포함됩니다.
