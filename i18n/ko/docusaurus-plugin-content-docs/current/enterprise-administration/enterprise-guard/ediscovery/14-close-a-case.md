사건 종료는 eDiscovery 프로세스의 최종 단계로, 법적 문제나 조사 완료를 의미합니다. [eDiscovery 관리자](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)는 사건을 종료하기 전에 관련된 모든 법적 보존 조치가 종료되었는지 확인해야 합니다.

사건을 종료하려면 다음 단계를 수행하세요:

:::note
이 작업을 수행하려면 [eDiscovery 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 필요합니다. eDiscovery 관리자 역할을 요청하려면 회사 관리자에게 연락하세요.
:::

1. 해당 사례와 관련된 모든 법적 보존 조치가 종료되었는지 확인하세요. 자세한 정보는 [법적 보존 조치 종료](12-close-a-legal-hold.md)를 참조하세요.
2. [Miro 설정](https://miro.com/app/settings)으로 이동하세요.
3. 왼쪽 메뉴에서 **Enterprise Guard** 아래에 있는 **eDiscovery**를 클릭하세요.
4. **eDiscovery** 페이지에서 닫고자 하는 사례를 클릭하세요.
5. 닫고자 하는 사례의 행에서 세 점 아이콘을 클릭한 후 **사례 닫기**를 클릭하세요.
6. **사례 닫기** 확인 창이 나타나며, 이 사례에 대한 모든 세부 정보가 삭제된다는 내용이 표시됩니다.  ![closecaseconfirmationbox.png](images/26679466410002_closecaseconfirmationbox.png)
7. 케이스를 닫기로 결정하셨다면, **케이스 닫기**를 클릭하세요.
   케이스가 삭제됩니다.
