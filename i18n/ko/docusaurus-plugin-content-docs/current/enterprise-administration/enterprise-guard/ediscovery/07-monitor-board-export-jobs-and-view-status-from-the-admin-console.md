1. 프로필 아바타를 클릭한 후 **관리자 콘솔**을 클릭하세요.
2. 왼쪽 사이드바에서 Enterprise Guard을 클릭한 후, **eDiscovery**를 클릭하세요.
3. **케이스** 탭을 클릭하세요.
   케이스 목록이 표시됩니다.
4. 내보내기가 시작된 케이스를 엽니다.
5. **내보내기** 탭을 클릭하세요.
6. 내보내기 작업 목록을 검토하세요:
   - 작업 이름, 상태 및 포함된 보드 수를 확인하세요.
   - 보드가 처리되는 동안 실시간 업데이트를 확인하세요.
7. (선택 사항) **필터**를 클릭하여 다음 기준에 따라 내보내기 작업을 필터링하세요:
   - **내보내기 상태**
     진행 중이거나, 취소되었거나, 완료된 작업을 필터링합니다.
   - **작성자**
     작업 소유자로 필터링합니다.
8. 내보내기 작업을 클릭하여 세부정보를 보세요:
   - 내보내기 작업에 포함된 보드
   - 등급 분류, 소유자, 내보내기 상태.
   - 내보내기 크기와 다운로드 가능성. 내보낸 보드를 다운로드하는 방법에 대한 자세한 내용은 [이 문서](10-download-exported-boards.md)를 참조하세요.
9. (선택 사항) 내보내기 작업을 취소하려면 오른쪽의 점 세 개 (**...**)를 클릭하고 **내보내기 취소**를 선택하세요.
