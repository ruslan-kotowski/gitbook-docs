[eDiscovery 관리자](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)에게 법적 보존 조치 생성은 소송이나 조사가 예상될 때 중요한 절차입니다. 법적 보존 조치는 관련 있는 Miro 보드가 수정, 삭제 또는 제거되지 않도록 보존하고 보호합니다. 이는 법적 및 규제 요구 사항을 준수하고 중요한 데이터의 손실이나 수정을 방지하며, 법적 문제의 전체 기간 동안 주요 증거를 보호하는 데 필수적입니다. 법적 보존 조치는 관리자가 데이터를 잠궈 모든 관련 Miro 보드를 언제든지 검토할 수 있도록 보장합니다.

법적 보존 조치를 설정하는 것은 사건과 관련된 사용자 및 Miro 보드를 식별하고, 수정이 불가능하도록 보존 조치를 적용하는 작업을 포함합니다. 관리자는 사건 내 여러 보존 조치를 관리하여 모든 필요한 데이터를 체계적으로 그룹화하고 보존할 수 있습니다. 이 절차는 데이터의 무결성과 책임성을 유지하며, 조직이 법적 절차를 완벽히 준수하고 준비할 수 있도록 합니다.

법적 보존 조치 중인 Miro 보드는 여전히 액세스하고 편집할 수 있지만 모든 버전이 보존됩니다. 콘텐츠가 삭제되면 여전히 법적 보존 조치 내에서 사용 가능하며, 미래 사용자 작업에 따라 보존 조치 중인 콘텐츠 항목 수가 증가할 수 있습니다. 보드에 법적 보존 조치가 적용된 이후에는 모든 버전이 보존되며, 보존 조치가 해제될 때까지 무기한 유지됩니다.

법적 보존 조치를 설정하려면 다음 단계를 수행하세요:

:::note
이 작업을 수행하려면 [eDiscovery 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 있어야 합니다. eDiscovery 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
:::

1. Miro 설정으로 이동합니다.
2. 왼쪽 메뉴에서 **Enterprise Guard** 아래에 있는 **eDiscovery**를 클릭합니다.
3. **eDiscovery** 페이지에서 **사례** 탭을 클릭합니다.
4. **사례 생성** 페이지에서 법적 보존 조치를 추가하려는 사례를 클릭합니다.
5. **법적 보존 조치 추가**를 클릭합니다.
6. **법적 보존 조치 추가** 페이지에서 각 필드에 적합한 정보를 입력하거나 선택합니다. 다음 테이블에는 각 필드와 그 설명이 나와 있습니다.

   |  |  |
   | --- | --- |
   | **항목** | **설명** |
   | 법적 보존 조치 이름  **(필수)** | 법적 보존 조치의 이름입니다.  최대 길이: 60자. |
   | 기준  **(필수)** | 이 법적 보존 조치에 포함되는 콘텐츠 유형. 이번 릴리스는 모든 콘텐츠만 지원합니다. |
   | **콘텐츠를 소유, 공동 소유, 액세스, 수정, 생성한 사용자**  **(필수)** | 법적 보존 조치에 추가할 사용자를 등록하세요. 이름이나 이메일 주소로 검색하려면 필드를 클릭하세요. 한 번에 최대 200명의 사용자를 추가할 수 있습니다.    **참고:**  - 법적 보존 조치 대상 사용자가 보드를 열거나 수정 또는 명칭 변경, 컨텐츠 추가 등으로 상호작용하면, 해당 보드는 자동으로 플래그 처리되고 보존됩니다. 예를 들어, 보드의 이름이 변경되거나 컨텐츠가 업데이트된 경우, 자동으로 법적 보존 조치에 포함됩니다. 또한 보드 소유 및 보드 생성도 보류됩니다.  - 법적 보존 조치가 생성되면 관리자가 보유했거나 보유 중인 보드도 영향을 받습니다. 보존 조치 이후에 관리자들이 접근하고 수정한 보드도 포함되며, 기존의 보드 접근 및 수정 내역은 이번 릴리즈에 포함되지 않습니다. |
7. **다음**을 클릭합니다. **영향 검토** 페이지가 나타납니다.
8. 이 법적 보존 조치 생성의 영향을 검토합니다. 예를 들어 보존될 기존 보드의 수와 보드를 소유, 공동 소유, 접근, 수정, 생성한 사용자를 검토합니다.

   **참고:**
   - 보존 조치 중인 보드는 계속 접근하고 편집할 수 있지만 모든 버전이 보존됩니다. 콘텐츠가 삭제되더라도 보존 조치 하에서는 여전히 사용 가능합니다. 보존 조치 중인 콘텐츠 항목 수는 향후 사용자 작업에 따라 늘어날 수 있습니다.

   - 법적 보존 조치 하에 있는 사용자가 보드를 열거나 수정하거나 어떤 방식으로든 상호 작용하면 (이름 변경이나 콘텐츠 추가) 해당 보드는 플래그가 지정되고 보존됩니다. 예를 들어 보드 이름이 변경되거나 콘텐츠가 업데이트되면 자동으로 법적 보존 조치에 넣어집니다. 또한, 보드 소유 및 생성이 보류됩니다.

   - 법적 보존 조치가 생성되면, 이는 보존 조치가 설정된 시점에 관리자가 생성, 소유, 공동 소유한 보드에 적용됩니다. 또한, 보존 조치가 적용된 이후 관리자가 접근하고 수정한 모든 보드도 포함됩니다. 그러나 이번 릴리스에서는 과거의 보드 접근 및 업데이트 세부 사항은 제공되지 않습니다.
9. 생성 중인 법적 보존 조치의 영향을 검토한 후, **법적 보존 조치 추가**를 클릭합니다.
   케이스 페이지가 나타나며, 포함된 법적 보존 조치와 각 법적 보존 조치에 대한 정보가 표시됩니다. 이는 법적 보존 조치의 이름, 영향을 받는 콘텐츠 종류, 해당 법적 보존 조치에 포함된 사용자 수, 법적 보존 조치가 생성된 날짜, 법적 보존 조치의 상태, 보존 중인 보드의 수 등을 포함합니다.
