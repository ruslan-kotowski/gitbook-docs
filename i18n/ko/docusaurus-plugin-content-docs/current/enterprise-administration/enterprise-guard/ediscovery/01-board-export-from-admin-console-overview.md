이제 eDiscovery 관리자는 관리자 콘솔에서 직접 법적 보존 조치 대상 보드를 내보낼 수 있습니다.
이 기능은 eDiscovery 관리자에게 다음을 가능하게 합니다.

- 관리자 콘솔에서 보드 내보내기 시작
- 각 케이스 내 **내보내기** 탭에서 실시간으로 내보내기 작업의 진행 상황을 모니터링하세요.
- 내보내기 작업을 상태와 제작자로 필터링하고, 어떤 보드가 포함되어 있는지 확인하세요.
- 내보낸 각 보드에 대한 전체 콘텐츠 로그를 받으세요.
- 내보낸 보드와 그 메타데이터 목록(분류, 소유자, 내보내기 상태)을 보세요.
- 개별적으로 내보낸 보드를 관리자 콘솔에서 직접 다운로드하세요.
- API나 통합에 의존하지 않고 내보내기 워크플로를 완료하세요.
- 대기 중인 내보내기 작업이나 진행 중인 작업을 취소하세요.

:::note
보드를 내보내고 내보내기 작업을 관리하려면 [eDiscovery 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 필요합니다. 민감한 콘텐츠 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
:::

## **보드 내보내기 기능**

- 각 **내보내기 작업**에는 최대 **1,000개 보드**가 포함될 수 있습니다.
- **플랜별 내보내기 제한**:

  - **Enterprise Guard:** 최대 **100**개의 활성 내보내기 작업.
  - **Enterprise:** 최대 **10**개의 활성 내보내기 작업.
- **병렬 처리 제한**:

  - **Enterprise Guard**: 최대 **5**개의 내보내기 작업이 병렬로 처리됩니다.
  - **Enterprise**: **1**개의 내보내기 작업이 한 번에 처리됩니다.
- **내보내기 작업의 콘텐츠 로그:** 내보내기에는 각 내보낸 보드에 대한 전체 콘텐츠 로그를 선택적으로 포함할 수 있습니다.
- **내보내기 작업 필터**: 내보내기 작업을 필터링하고 포함된 보드를 확인하세요.
- **진행 중이거나 대기 중인 내보내기 작업 취소**: 내보내기 대역폭을 효율적으로 관리하세요.
  > 내보내기를 취소하면 진행 중인 모든 보드가 완료되어 다운로드할 수 있게 됩니다. 시작되지 않은 보드는 내보내기되지 않습니다.

- **다운로드 액세스**: 결과는 **14일간** 다운로드할 수 있습니다.
- **관리자 콘솔 범위**: 관리자 콘솔을 통해 시작된 내보내기만 **내보내기** 탭에 표시됩니다. API 기반 내보내기 작업은 관리자 콘솔 목록에 포함되지 않습니다.
