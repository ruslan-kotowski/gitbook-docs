차단할 레이블을 조정하거나 코드 스캐닝을 전환하려면:

1. **설정** → **Enterprise Guard** → **데이터 검색** → **구성**으로 이동합니다.
2. **프롬프트 차단**에서 **관리**를 선택합니다.
3. 측면 패널에서 다음 중 하나를 수행합니다:
   - **전체 선택**을 켜거나 끕니다.
   - 차단할 특정 레이블 범주를 선택하거나 선택 해제합니다.
   - **코드 스캔**을 켜거나 끕니다.
4. **변경사항 적용**을 선택합니다.

변경 사항은 모든 사용자에게 즉시 적용됩니다. 새롭게 차단 해제된 항목이 포함된 프롬프트는 진행되며, 계속 차단된 항목을 포함하는 프롬프트는 계속 중지됩니다.
