조직에서 프롬프트 차단을 활성화하려면:

1. Miro에서 **설정** → **Enterprise Guard** → **데이터 검색** → **구성**으로 이동합니다.
2. **프롬프트 차단**에서 **활성화**를 클릭합니다.
3. 측면 패널에서 **전체 선택**을 유지하거나 차단할 특정 레이블 카테고리를 선택합니다.
4. (선택 사항) 소스 코드가 포함된 프롬프트를 차단하기 위해 **코드 스캔**을 켭니다 (최소 5줄). 자세한 내용은 [코드 스캔](../../enterprise-guard/ai-trust/06-prompt-blocking-overview.md)을 참조하세요.
5. **활성화**를 클릭합니다.

프롬프트 차단이 조직에 대해 활성화되었습니다. 선택된 모든 카테고리는 즉시 적용됩니다.
