Miro 보드에서 식별하고 찾고자 하는 키워드나 위젯과 같은 조건을 정의하기 위해 레이블을 생성하세요. 총 100개의 맞춤형 비즈니스 민감 레이블을 생성할 수 있습니다. 레이블을 생성하려면 다음 단계를 수행하세요.

:::note
맞춤형 레이블을 생성하려면 [민감한 콘텐츠 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 있어야 합니다. 민감한 콘텐츠 관리자 역할이 필요하면 회사 관리자에게 요청하세요.
:::

1. [Miro 설정](https://miro.com/app/settings)으로 이동합니다.
2. 왼쪽 창에서 **Enterprise Guard** 아래에 있는 **데이터 검색**을 클릭합니다.
3. **데이터 검색** 페이지에서 **구성** 탭을 클릭합니다.
4. **사용자 정의 비즈니스 민감** 섹션에서 **생성** 버튼을 클릭합니다.
5. **맞춤형 레이블 정의** 페이지에서 레이블 세부 정보를 추가합니다.

   |  |  |
   | --- | --- |
   | **필드** | **설명** |
   | **레이블 이름** | **최대 길이:** 80자  사용자 지정 레이블에 대한 설명적인 이름. 이 레이블은 로그에 나타나지 않으므로 회사 내부 프로젝트 이름을 사용할 수 있습니다.  **참고:** 레이블 이름은 감사 로그에 표시되지 않습니다. 이 레이블과 관련된 감사 로그를 검색하거나 보려면 레이블 ID를 사용할 수 있습니다. |
   | **단축명** | **최대 길이:** 영숫자로 10자  레이블 이름의 단축형입니다. 이 단축명은 데이터 검색, 콘텐츠 탐색기, 데이터 등급 분류에서 이 맞춤형 레이블을 참조하는 데 사용됩니다. **참고:** 단축명은 감사 로그에 표시되지 않습니다. 이 레이블과 관련된 감사 로그를 검색/보기 원하시면, 레이블 ID를 사용할 수 있습니다. |
   | **설명** | **최대 길이:** 500자  이 레이블이 감지하는 정보에 대한 설명입니다. 이 정보는 다른 관리자에게 유용합니다. |
   | **조건** | 감지하고자 하는 키워드와 위젯 유형을 추가하여 Miro 보드에서 감지되었을 때 이 레이블을 추가하십시오. 최소 1개의 조건을 추가해야 합니다.  키워드만 추가하고 특정 위젯 체크박스를 선택하지 않으면 데이터 검색은 제공한 키워드가 정확히 일치하는 모든 지원되는 위젯을 포함하는 보드를 감지합니다. 현재 릴리스에서는 키워드 감지를 위해 스티커 메모, 카드, Jira 카드, 코드 블록, 댓글, 프레임, 테이블, 커넥터/라인, 도형, 텍스트 블록, 칸반 보드, 유저 스토리맵 등의 보드 항목을 지원합니다.  키워드를 추가하지 않고 코드 블록, Jira 카드, Azure 카드 또는 프로토타입 화면만 감지하도록 선택할 수도 있습니다. 그러면 데이터 검색이 이러한 위젯을 포함하는 모든 보드를 감지합니다.  키워드와 위젯을 모두 조건으로 추가하면 데이터 검색이 보드를 감지하려면 키워드와 위젯 기준 모두 충족해야 합니다. 이를 통해 맞춤형 레이블을 사용하여 검색을 세분화하고 보드를 보다 정확하게 타겟팅할 수 있습니다.  **예시:**  - 제품 개발 관련 보드를 구체적으로 검출하고 싶으나 마케팅 관련 보드는 제외하고 싶다면, 보드에 프로젝트 이름 *Enterprise* *Guard*가 포함되어야 하며, 또한 제품 개발과 관련된 Jira 카드가 포함된 보드만을 찾고자 할 경우, 이 레이블에 키워드 *Enterprise* *Guard*를 포함시키고 Jira 카드 체크박스를 선택합니다. 데이터 검색은 그러면 *Enterprise* *Guard* 키워드와 Jira 카드가 포함된 보드를 찾습니다. 또한, 제목이나 설명에 *Enterprise* *Guard* 키워드가 포함된 Jira 카드가 있는 보드도 검색하게 됩니다. 만약 보드에 *Enterprise* *Guard* 키워드만 포함되어 있고 Jira 카드는 포함되지 않은 경우, 주어진 조건을 모두 충족시키지 않기 때문에 해당 보드는 검출되지 않습니다.  - 보드에 포함된 위젯 유형에 관계없이 *Enterprise* *Guard*라는 단어가 포함된 모든 보드를 감지하려면 **키워드 추가** 섹션에서 키워드 **Enterprise** **Guard**를 추가하세요. 이 예에서는 위젯 유형을 추가할 필요가 없습니다.  - 특정 내용에 관계없이 Jira 카드가 포함된 모든 보드를 감지하려면 **위젯 유형 추가** 섹션에서 **Jira 카드** 체크박스를 선택하세요. 이 예에서는 키워드를 추가할 필요가 없습니다.    **키워드 추가 방법:**  1. **키워드 추가**를 클릭하세요.  2. 키워드를 쉼표로 구분해 입력하세요. **참고:**  - 키워드는 영숫자 및 유니코드 문자를 지원합니다. - 최대 100개의 키워드 또는 구문을 추가할 수 있습니다. - 키워드의 앞뒤에 있는 여분의 스페이스는 무시됩니다. - 데이터 검색은 대소문자 구분 없이 제공된 키워드의 정확히 일치하는 항목을 검색합니다. - 키워드 앞에 스페이스를 추가하면 데이터 검색은 키워드 앞에 스페이스가 있는 정확히 일치하는 항목도 찾습니다.  - 현재 릴리스에서는 다음 보드 항목에 대한 키워드 검색을 지원합니다: 스티키, 카드, Jira 카드, 코드 블록, 프레임, 테이블, 커넥터/라인, 도형, 텍스트 블록, 칸반 보드, 유저 스토리맵. 메모와 댓글은 현재 데이터 검색 항목에 포함되지 않으며, 향후 기능 개선 릴리스에 포함될 예정입니다.  **예시:** *confidential* 또는 *internal* 키워드를 포함한 보드를 식별하고 레이블을 지정하려면, 다음 키워드를 추가하세요: *confidential, internal* (각 키워드는 쉼표로 구분합니다). 데이터 검색은 이러한 키워드를 포함한 모든 보드를 찾아냅니다.  **위젯 유형 추가 방법:**  1. **위젯 유형 추가**를 클릭합니다.  2. Miro 보드에서 탐지하고자 하는 위젯 유형의 체크박스를 선택하세요.  **예시:** Jira 카드를 포함한 보드를 탐지 및 레이블을 지정하고자 한다면, **Jira 카드** 체크박스를 선택하세요. |
6. **다음**을 클릭합니다.
7. 맞춤형 레이블 세부 정보를 검토하세요.

   맞춤형 레이블 세부 정보를 편집하려면 **이전** 버튼을 클릭하세요.

   맞춤형 레이블 세부 정보가 정확하면 **맞춤형 레이블 생성** 버튼을 클릭하세요.

   레이블을 만들면 첫 번째 스캔이 자동으로 시작됩니다. 선택한 조건과 일치하는 결과는 조직의 Miro 보드 수에 따라 몇 분 또는 몇 시간 후에 제공됩니다.
