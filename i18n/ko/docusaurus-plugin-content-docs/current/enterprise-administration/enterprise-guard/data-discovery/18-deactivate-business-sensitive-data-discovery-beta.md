비즈니스 민감 데이터 검색을 비활성화하면 Miro의 내장된 머신 러닝 레이블을 사용하여 민감한 비즈니스 정보의 일반적인 카테고리를 손쉽게 식별하고 레이블 지정하는 기능이 비활성화됩니다.

비즈니스 민감 데이터 검색 레이블을 자동 등급 분류에 사용 중이라면 비즈니스 민감 데이터 검색 기능을 비활성화할 수 없습니다. 이는 비즈니스 민감 데이터 검색 비활성화가 콘텐츠에 적용된 자동 분류 및 가드레일에 영향을 미칠 수 있기 때문입니다. 비활성화하려면 먼저 자동 등급 분류에서 모든 비즈니스 민감 데이터 검색 레이블을 제거해야 합니다. 비즈니스 민감 데이터 검색을 비활성화하면 관리자는 자동 등급 분류에서 비즈니스 민감 데이터 검색 레이블을 구성하는 기능을 상실하게 되며, 데이터 검색 개요 페이지와 콘텐츠 탐색기에서 관련 보드나 일치하는 항목을 더 이상 볼 수 없습니다.

비즈니스 민감 데이터 검색을 비활성화하려면 다음 단계를 수행하세요:

:::note
비즈니스 민감 데이터 검색을 비활성화하려면 [민감한 콘텐츠 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 필요합니다. 민감한 콘텐츠 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
:::

1. [Miro 설정](https://miro.com/app/settings)으로 이동합니다.
2. 왼쪽 패널에서 **Enterprise Guard** 하에 **데이터 검색**을 클릭합니다.
3. **데이터 검색** 페이지에서 **구성** 탭을 클릭합니다.
4. **비즈니스 민감** 섹션에서 **관리** 버튼을 클릭합니다.
5. 슬라이드 아웃 패널에서 **비활성화**를 클릭합니다.
