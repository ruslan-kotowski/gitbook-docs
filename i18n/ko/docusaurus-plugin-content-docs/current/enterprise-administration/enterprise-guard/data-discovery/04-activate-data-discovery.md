## 개인정보 관련 데이터 검색

개인정보 관련 데이터 검색을 활성화하면 Miro 보드에서 신용카드 번호, 사회보장번호, 여권 번호, 인증 토큰과 같은 고도 민감 데이터를 자동으로 발견, 분류, 보호할 수 있습니다. 이를 통해 기업 전반에 걸친 데이터 확산 및 유출과 관련된 위험을 줄이면서 비즈니스를 느리게 하지 않고도 비규정 준수 문제를 방지할 수 있습니다.

데이터 검색 주기는 최소 한 시간에 한 번 실행되며, 모든 보드 업데이트에 대해 고도 민감 정보를 스캔합니다. 이전 데이터 검색 주기에서 이미 스캔된 보드도 포함됩니다.

자세한 내용은 [개인정보 관련 데이터 검색 활성화](13-activate-privacy-related-data-discovery.md)에 대한 문서를 참조하세요.

## 비즈니스 민감 데이터 검색

비즈니스 민감 데이터 검색을 활성화하면 민감한 콘텐츠 관리자가 정확히 어떤 정보를 검색해야 하는지 알 필요 없이 중요한 비즈니스 데이터를 손쉽게 식별하고 분류하며 보호할 수 있습니다. 단 한 번의 토글 클릭으로 민감한 콘텐츠 관리자는 내장된 Miro의 기계 학습 레이블을 활용해 일반적인 범주의 민감한 비즈니스 정보를 효율적으로 자동 식별 및 레이블 지정할 수 있습니다.

- 아키텍처 및 데이터 흐름, 데이터 모델, 보안 아키텍처를 포함한 기술 설계.
- 고객 라이선스, 계정 갱신, 사용 지표, 계정 가격 책정, 유연한 라이선싱을 포함한 고객 정보.
- 회사 OKR, 계획 및 목표, 회사 목표, 연간 로드맵, 주요 책임을 포함한 회사 전략.

자세한 내용은 [비즈니스 민감 데이터 검색](10-activate-business-sensitive-data-discovery-beta.md) 활성화에 관한 문서를 참조하세요.

## 사용자 지정 비즈니스 민감 데이터 검색

[민감한 콘텐츠 관리자](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)는 맞춤형 비즈니스 민감 데이터 검색을 활용하여 지적 재산을 포함한 맞춤형 비즈니스 민감 정보를 포함하는 Miro 보드를 효율적으로 자동 식별하고 레이블을 지정할 수 있습니다. 맞춤형 비즈니스 민감 데이터 검색을 통해 다음을 수행할 수 있습니다:

- 사용자 지정 검색을 통해 귀사의 특정 민감한 데이터를 탐지합니다.
- *Jira 카드를 포함* 또는 *코드 블록을 포함*과 같은 조건과 키워드를 추가하여 데이터 검색 결과를 보다 정밀하게 조정합니다.
- 모든 맞춤형 비즈니스 민감 레이블을 한 곳에서 손쉽게 조직하고 관리합니다.

맞춤 비즈니스 민감 정보의 레이블과 키워드를 생성하는 방법에 대한 문서는 [여기](12-create-labels-and-keywords-for-custom-business-sensitive-information.md)에서 자세히 알아보세요.
