데이터 검색 대시보드는 [민감한 콘텐츠 관리자](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)가 감지된 개인정보 관련 데이터 발생을 검토하고 결과를 검증할 수 있도록 합니다.

:::note
개인정보 관련 데이터를 포함한 보드를 검토하려면 [민감한 콘텐츠 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md).</span> 민감한 콘텐츠 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
:::

개인정보 관련 데이터를 포함한 보드를 검토하려면 다음 단계를 수행하세요:

1. [Miro 설정](https://miro.com/app/settings)으로 이동합니다.
2. 왼쪽 창에서 **Enterprise Guard** 아래에 있는 **데이터 검색**을 클릭하세요.
3. **데이터 검색** **개요** 페이지에서 메트릭 아래의 섹션으로 스크롤한 후 검토하려는 보드 카테고리의 보드 수를 클릭하세요.
   새로운 페이지에 보드 목록과 그 정보가 표시됩니다.
4. 검토할 보드를 클릭하세요.
   화면 오른쪽에 슬라이드 아웃 패널이 나타납니다.
5. 슬라이드아웃 패널을 사용하여 다음 작업을 수행할 수 있습니다:
   **개인정보 관련****정보** **표시 또는 숨기기:** 기본적으로 개인정보 관련 정보가 가려져 있습니다. 개인정보 보호 관련 정보를 보려면 **민감 정보 표시** 토글을 클릭하여 켭니다.
   프라이버시 관련 정보가 표시되면, 프라이버시 관련 정보를 숨기려면 **민감 정보 표시** 토글을 클릭해 끕니다.

   **데이터 범주를 기반으로** **개인정보 관련** **정보를 필터링하세요:** 특정 레이블에 속하는 개인정보 보호 관련 정보를 보려면 **개인정보 보호 관련 정보** 탭을 클릭한 후, 탭 아래의 적절한 민감도 레이블을 클릭하세요.

   **- 거짓 긍정 일치를 억제:** 개인정보 관련 데이터 검색 과정에서 시스템이 기술적으로는 정확하지만, 여러 보안 정책과 조직의 특정 필요에 따라 관련성이 없거나 민감한 데이터로 간주되지 않는 일치 항목을 생성하는 상황에 직면할 수 있습니다. 보안이나 개인정보 위험을 초래하지 않는 일치를 억제하는 것은 조직의 특정 데이터 보안 및 개인정보 요구사항에 맞춰 데이터 검색 프로세스를 맞추는 데 있어 중요합니다.

   시스템이 보드의 데이터를 잘못 민감 정보로 플래그할 때도 있습니다(오탐일 가능성). 이러한 발생에는 관련 용어의 근접성이나 프라이버시 관련 데이터의 형식 같은 다양한 요소가 기여합니다. 거짓 양성 일치를 억제할 수도 있습니다.

   매치를 억제할 때 업데이트는 실시간으로 이루어집니다. 보드 등급 분류와 적용된 가드레일도 자동 분류 및 인텔리전트 가드레일 설정에 따라 업데이트됩니다.

   오탐지를 억제하려면, 억제하려는 개인정보 관련 데이터 매치 옆의 줄임표(...)를 클릭한 다음, **매치 숨기기**를 선택합니다. 업데이트가 실시간으로 이루어지는 점에 유의하세요. 보드 분류와 적용된 가드레일은 자동 분류 및 인텔리전트 가드레일 설정에 따라 업데이트됩니다.
6. 콘텐츠 탐색기 결과 목록에서 작업할 보드를 클릭하고 필요한 작업을 수행하거나 패널 오른쪽 상단의 **닫기** 버튼을 클릭하여 슬라이드 아웃 패널을 닫습니다.
