콘텐츠 탐색기를 사용하면 [민감한 콘텐츠 관리자](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)는 비즈니스 민감 데이터 또는 사용자 지정 비즈니스 민감 데이터 일치 항목을 검토할 수 있습니다.

:::note
- 비즈니스 민감 데이터 또는 사용자 정의된 비즈니스 민감 데이터가 있는 보드를 검토하려면 [민감한 콘텐츠 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 필요합니다. 민감한 콘텐츠 관리자 역할을 요청하려면 회사 관리자에게 연락하세요.
- 비즈니스 민감 데이터 일치는 고객(CUSTOMER), 기술(TECH), 전략(STRATEGY)으로 태그가 부여되며, 결과 목록의 상단에 표시됩니다.

- 맞춤형 비즈니스 민감 데이터 일치는 해당 맞춤 레이블로 태그가 지정됩니다.
:::

비즈니스 민감 데이터 또는 맞춤형 비즈니스 민감 데이터 일치가 있는 보드를 검토하려면 다음 단계를 수행합니다:

1. **콘텐츠 탐색기** 페이지에 있는 경우 2단계로 건너뛰세요.
   **콘텐츠 탐색기** 페이지에 있지 않은 경우:
   a. [Miro 설정](https://miro.com/app/settings)으로 이동합니다.
   b. 왼쪽 창에서 **Enterprise Guard** 아래에 있는 **콘텐츠 탐색기**를 클릭합니다.
   c. **데이터 발견**을 클릭합니다.
2. **Content explorer/Data discovery** 페이지에서 검토하려는 보드를 클릭하세요.
   화면 오른쪽에 슬라이드 아웃 패널이 나타납니다.
3. 슬라이드 아웃 패널을 통해 다음 작업을 수행할 수 있습니다:

   - 맞춤형 비즈니스 민감 데이터 매치에 대해서: **비즈니스 민감 정보** **표시 또는 숨기기**
   기본적으로 맞춤형 비즈니스 민감 정보는 블랙아웃 처리됩니다. 맞춤형 비즈니스 민감 데이터 정보를 보려면, **민감 정보 표시** 토글을 켜세요.
   맞춤형사업 중요 데이터가 보일 때는 **민감 정보 보기** 토글을 클릭하여 이를 비활성화하여 데이터를 숨길 수 있습니다.

   > ✏️ - 사업 중요 데이터 매치는 고객(CUSTOMER), 기술(TECH), 전략(STRATEGY)으로 태그되며 결과 리스트의 상단에 표시됩니다.
   > - 맞춤형 사업 중요 데이터 매치는 해당되는 적절한 맞춤형 레이블로 태그됩니다.

   - 비즈니스 민감 정보와 맞춤형 비즈니스 민감 정보 일치 항목 모두에 대해: **비즈니스 민감 데이터 카테고리 기반 정보 필터링**
   특정 카테고리에 속하는 비즈니스 민감 데이터를 보려면 **비즈니스 민감 정보** 탭을 클릭한 후 탭 아래에 있는 적절한 필터 버튼을 클릭하세요.

   -비즈니스 민감 정보와 일치하는 항목만: **허위 긍정 결과 억제**
   비즈니스 민감 데이터 검색 과정에서 기술적으로는 정확하지만 조직의 보안 정책과 특정 요구에 맞지 않아 민감한 데이터로 간주되지 않는 경우가 발생할 수 있습니다. 보안이나 비즈니스 위험을 초래하지 않는 일치를 억제하는 것은 데이터 검색 프로세스를 조직의 특정 데이터 보안과 비즈니스 요구에 맞추기 위해 필수적입니다.

   시스템이 보드의 데이터를 잘못하여 민감한 정보로 잘못 지목(오탐)하는 경우도 있습니다. 이러한 상황은 관련 용어의 근접성이나 비즈니스 관련 데이터의 포맷 등의 여러 요인으로 발생할 수 있습니다. 오탐을 억제할 수도 있습니다.

   매치를 억제하면, 업데이트는 실시간으로 이루어집니다. 보드의 등급 분류와 적용된 가드레일도 자동 등급 분류 및 인텔리전트 가드레일 설정에 따라 업데이트됩니다.

   오탐 매칭을 억제하려면, 억제하려는 업무 관련 데이터 매칭 옆의 말줄임표를 클릭한 다음, **매칭 숨기기**를 선택하세요. 업데이트는 실시간으로 이루어집니다. 자동 등급 분류 및 인텔리전트 가드레일 구성에 따라 보드 등급 분류와 적용된 가드레일도 업데이트됩니다.
4. 콘텐츠 탐색기 결과 목록에서 작업하려는 다음 보드를 클릭하고 필요한 작업을 수행하거나, 패널 오른쪽 상단에 있는 **닫기** 버튼을 클릭하여 슬라이드 아웃 패널을 닫습니다.
