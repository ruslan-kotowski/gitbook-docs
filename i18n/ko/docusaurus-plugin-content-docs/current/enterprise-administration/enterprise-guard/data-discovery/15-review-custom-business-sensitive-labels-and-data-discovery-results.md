**데이터 검색 개요** 페이지는 구성된 모든 맞춤형 비즈니스 민감 레이블의 목록, 레이블 상태, 레이블 유형, 레이블을 생성한 관리자, 각 레이블과 관련된 보드 분류, 각 레이블이 태그된 보드 수 및 보드를 탐색하는 링크를 표시합니다. 추가로, 민감한 콘텐츠 관리자는 사용자 지정 비즈니스 민감 레이블을 편집하고 **데이터 검색 개요** 페이지에서 레이블 표시 ID를 복사할 수 있습니다.

:::note
맞춤형 비즈니스 민감 데이터 검색 결과를 보려면 [민감한 콘텐츠 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 필요합니다</span><span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Helvetica, Arial, sans-serif;">.</span> 민감한 콘텐츠 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
:::

## 맞춤형 비즈니스 민감 데이터가 포함된 보드 검토

맞춤형 비즈니스 민감 데이터를 포함한 보드를 탐색하려면 다음 단계를 수행하세요:

1. [Miro 설정](https://miro.com/app/settings)으로 이동합니다.
2. 왼쪽 창에서 **Enterprise Guard** 아래에 있는 **데이터 검색**을 클릭합니다.
3. **데이터 검색** **개요** 페이지에서 보드 수 링크를 클릭하세요. 콘텐츠 탐색기가 보드 목록과 함께 나타납니다. 자세한 내용은 비즈니스 민감 정보가 포함된 보드 검토를 참조하세요.

## 레이블 표시 ID 복사

레이블 이름은 감사 로그에서 보이지 않습니다. 특정 레이블과 관련된 감사 로그를 보거나 검색하려면 레이블 표시 ID를 사용해야 합니다.

레이블의 표시 ID를 얻으려면 다음 단계들을 수행하세요:

1. [Miro 설정](https://miro.com/app/settings)으로 이동하세요.
2. 왼쪽 창에서 **Enterprise Guard** 아래에 있는 **데이터 검색**을 클릭합니다.
3. **데이터 검색** **개요** 페이지에서, 레이블 표시 ID를 복사하려는 레이블의 행에 있는 세 점 아이콘을 클릭한 다음, **레이블 표시 ID 복사**를 클릭하세요.
