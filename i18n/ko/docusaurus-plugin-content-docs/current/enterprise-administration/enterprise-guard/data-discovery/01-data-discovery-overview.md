데이터 디스커버리는 기업 내에서 강력한 데이터 보안을 보장하는 데 있어 중추적인 역할을 합니다. 이 중요한 프로세스는 조직 내 모든 Miro 보드를 주기적으로 스캔하여 Miro 보드에 포함된 개인정보 관련 데이터 또는 비즈니스 민감 정보를 자동으로 식별하고 레이블링하는 것입니다.

개인 정보 관련 데이터 검색은 조직 내 모든 Miro 보드를 정기적으로 스캔하여 신용카드 번호, 주민등록번호, 운전면허 번호, 은행 정보와 같이 개인 정보 보호 규정의 대상이 될 수 있는 민감 정보를 식별하고 위치를 찾는 과정을 포함합니다. 조직의 Miro 보드를 체계적으로 탐색하고 분석하여 민감한 데이터와 관련된 잠재적 위험을 사전에 식별할 수 있습니다. 개인 정보 관련 데이터 검색을 활성화하면 비즈니스 운영에 지장을 주지 않으면서 비준수 문제를 방지할 뿐만 아니라 데이터 확산 및 유출과 관련된 위험을 완화할 수 있습니다. 또한 민감한 데이터가 식별되면 콘텐츠 탐색기를 사용하여 식별된 항목을 탐색하고, 자동 분류 기능을 활용하여 보드를 자동으로 분류할 수 있으며 성격과 중요도에 따라 보드를 자동 분류하고, 인텔리전트 가드레일[을](../data-classification/01-intelligent-guardrails-overview.md) 사용해 리스크 조정 보안 통제를 적용할 수 있습니다. 자세한 내용은 [개인정보 관련 데이터 검색의 자세한 설명서](https://help.miro.com/hc/sections/21607994053266)를 참조하세요.

콘텐츠 관리자들은 맞춤형 데이터 검색을 이용해 지적 재산권을 포함한 비즈니스 민감 정보가 포함된 Miro 보드를 효율적으로 자동 식별하고 레이블을 지정할 수 있습니다. 비즈니스 민감 정보 데이터 검색을 통해 할 수 있는 작업은 다음과 같습니다:

- 귀사의 특정 민감 데이터를 감지하기 위해 키워드 검색을 사용합니다.
- JIRA 카드 포함 또는 코드 블록 포함 등의 조건을 키워드와 함께 추가하여 데이터 검색 결과를 더 정밀하게 개선합니다.
- 모든 맞춤형 키워드 레이블을 한곳에서 중앙 집중 관리하여 쉽게 조직하고 제어할 수 있습니다.

자세한 내용은 [비즈니스 민감 정보 데이터 검색에 대한 상세 문서](https://help.miro.com/hc/sections/21608065021074)를 참조하세요.
