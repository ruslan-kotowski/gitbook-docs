개인정보 관련 데이터 검색은 귀 조직의 모든 Miro 보드를 주기적으로 스캔하여 신용카드 번호, 주민등록번호, 운전면허 번호, 은행 정보 등의 개인정보보호 규정을 준수해야 할 민감한 정보를 식별하고 찾아내는 과정입니다. 귀 조직의 Miro 보드를 체계적으로 탐색하고 분석함으로써 민감한 데이터와 관련된 잠재적인 위험을 사전에 식별할 수 있습니다. 개인정보 관련 데이터 검색 기능을 활성화하면 비즈니스 운영을 저해하지 않고도 규정 미준수 문제를 예방할 뿐만 아니라, 데이터 확산 및 누출과 관련된 위험을 완화할 수 있습니다.

또한, 개인정보 관련 데이터가 식별되면 콘텐츠 탐색기를 사용하여 확인한 사례를 탐색하고, 자동 분류 기능을 활용하여 그 성격과 중요도에 기반해 보드를 자동으로 등급 분류한 후, [인텔리전트 가드레일](../data-classification/01-intelligent-guardrails-overview.md)로 리스크 조정 보안 통제를 적용할 수 있습니다.
