비즈니스에 민감한 데이터 검색을 활성화하면 민감한 콘텐츠 관리자가 검색 대상 정보를 정확히 알 필요 없이 중요한 비즈니스 데이터를 원활하게 식별, 분류 및 보호할 수 있습니다. 한 번의 토글 클릭으로 민감한 콘텐츠 관리자는 Miro의 내장된 머신 러닝 레이블을 활용하여 민감한 비즈니스 정보의 공통 범주를 효율적으로 자동 식별 및 레이블 붙이기를 할 수 있습니다. 이 범주에는 다음과 같은 정보가 포함됩니다:

- 아키텍처 및 데이터 흐름, 데이터 모델, 보안 아키텍처를 포함한 기술 설계.
- 고객 라이선스, 계정 갱신, 사용 지표, 계정 요금제, 유연한 라이선스를 포함한 고객 정보.
- 회사 OKR, 계획 및 목표, 회사 목표, 연간 로드맵, 주요 책임을 포함한 회사 전략.

비즈니스 민감 데이터 검색을 활성화하려면 다음 단계를 수행하세요:

:::note
비즈니스 민감 데이터 검색을 활성화하려면 [민감한 콘텐츠 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 있어야 합니다. 민감한 콘텐츠 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
:::

1. [Miro 설정](https://miro.com/app/settings)으로 이동합니다.
2. 왼쪽 패널에서 **Enterprise Guard** 아래의 **데이터 검색**을 클릭합니다.
3. **데이터 검색** 페이지에서 **구성** 탭을 클릭합니다.
4. **Business-sensitive** 섹션에서 **활성화** 버튼을 클릭합니다.
   슬라이드 아웃 패널이 나타납니다.
5. 슬라이드 아웃 패널의 하단에 있는 **활성화** 버튼을 클릭합니다.
   Business-sensitive 데이터 검색을 활성화하면 첫 번째 스캔이 자동으로 시작됩니다. 결과는 조직 내 Miro 보드 수에 따라 몇 분 또는 몇 시간 후에 제공됩니다. 결과는 **데이터 검색 개요** 페이지나 **콘텐츠 탐색기**에서 볼 수 있습니다.
