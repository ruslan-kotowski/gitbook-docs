:::note
레이블을 분류 수준과 연결하기 전에만 편집하는 것을 권장합니다.
:::

식별하고 위치를 찾고자 하는 키워드나 위젯과 같은 조건을 업데이트하려면 레이블을 편집하세요. 레이블을 편집하려면 다음 단계를 수행하세요:

:::note
사용자 지정 레이블을 편집하려면 [민감한 콘텐츠 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 필요합니다. 민감한 콘텐츠 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
:::

1. Miro [설정](https://miro.com/app/settings)으로 이동합니다.
2. 왼쪽 패널에서 **Enterprise Guard** 아래 **데이터 검색**을 클릭합니다.
3. **데이터 검색** **개요** 페이지에서 편집하려는 레이블 열의 세 점 아이콘을 클릭한 다음, **레이블 편집**을 클릭합니다.
4. **맞춤형 레이블 편집** 페이지에서 레이블 세부 정보를 편집합니다.

   |  |  |
   | --- | --- |
   | **필드** | **설명** |
   | **레이블 이름** | **최대 길이:** 80자  맞춤형 레이블에 대한 설명적 이름입니다. 이 레이블은 로그에 표시되지 않으므로 회사 내부 프로젝트 이름을 사용할 수 있습니다.  **참고:** 레이블 이름은 감사 로그에 표시되지 않습니다. 이 레이블과 관련된 감사 로그를 검색/보기하려면 레이블 ID를 사용할 수 있습니다. |
   | **짧은 이름** | **최대 길이:** 영숫자로 최대 10자  레이블 이름의 짧은 버전입니다. 데이터 검색 및 콘텐츠 탐색기에서 이 맞춤형 레이블을 참조하는 데 사용됩니다. **참고:** 짧은 이름은 감사 로그에 표시되지 않습니다. 이 레이블과 관련된 감사 로그를 검색하거나 보려면 레이블 ID를 사용할 수 있습니다. |
   | **설명** | **최대 길이:** 500자  이 레이블이 감지하는 정보에 대한 설명입니다. 이 정보는 다른 관리자들에게 유용합니다. |
   | **조건** | 검색할 키워드와 보드에서 발견 시 레이블을 추가할 위젯 유형을 추가하세요. 최소 하나의 조건을 추가해야 합니다.  키워드만 추가하고 위젯 체크박스를 선택하지 않으면, 데이터 검색은 제공된 키워드와 정확히 일치하는 모든 지원되는 위젯이 포함된 보드를 탐지합니다. 현재 버전에서는 키워드 탐지를 위해 다음 보드 항목을 지원합니다: 스티커 메모, 카드, Jira 카드, 코드 블록, 댓글, 프레임, 테이블, 커넥터/라인, 도형, 텍스트 블록, 칸반 보드, 유저 스토리맵.  또한, 키워드를 추가하지 않고 코드 블록, Jira 카드, Azure 카드 또는 프로토타입 화면만 탐지하도록 선택할 수도 있습니다. 이 경우 데이터 검색은 그러한 위젯이 포함된 모든 보드를 탐지합니다.  키워드와 위젯을 조건으로 모두 추가하면, 데이터 검색이 보드를 감지하기 위해서는 키워드와 위젯 조건 모두를 충족해야 합니다. 이렇게 하면 맞춤형 레이블을 사용하여 검색을 세분화하고 보드를 더 정밀하게 대상으로 할 수 있습니다.  **예시:**  - 제품 개발 관련 보드만 탐지하고 마케팅 관련 보드는 탐지하지 않으려면, 보드에 프로젝트 이름 *Enterprise* *Guard*가 포함되어 있어야 하고, 제품 개발과 관련된 Jira 카드가 있는 보드만 찾고자 한다면, 이 레이블에 *Enterprise* *Guard* 키워드를 포함시키고 Jira 카드 체크박스를 선택합니다. 그러면 데이터 검색이 *Enterprise* *Guard* 키워드와 Jira 카드를 포함하는 보드를 찾아냅니다. 데이터 검색은 제목이나 설명에 *Enterprise* *Guard* 키워드가 있는 Jira 카드가 포함된 보드도 찾아냅니다. 만약 보드에 *Enterprise* *Guard* 키워드만 포함되어 있고 Jira 카드가 없다면, 두 조건을 모두 충족하지 않기 때문에 해당 보드는 탐지되지 않습니다.  - 모든 지원되는 위젯 유형에 대해 *Enterprise* *Guard*라는 단어가 포함된 모든 보드를 감지하려면, **키워드 추가** 섹션에서 키워드 **Enterprise** **Guard**를 추가합니다. 이 예시에서는 위젯 유형을 추가할 필요가 없습니다.  - 특정 콘텐츠와 상관없이 Jira 카드가 포함된 모든 보드를 감지하려면, **위젯 유형 추가** 섹션에서 **Jira 카드** 체크박스를 선택합니다. 이 예시에서는 키워드를 추가할 필요가 없습니다.    **키워드 추가 방법:**  1. **키워드 추가**를 클릭합니다.  2. 키워드를 쉼표로 구분해 입력하거나 붙여넣습니다. **참고:**  - 키워드는 영숫자 및 유니코드 문자를 지원합니다.  - 최대 100개의 키워드나 구문을 추가할 수 있습니다. - 데이터 검색은 제공한 키워드를 대소문자 구분 없이 정확히 탐지합니다. - 현재 릴리즈에서는 키워드 탐지를 위해 다음 보드 항목을 지원합니다: 스티커 메모, 카드, Jira 카드, 코드 블록, 프레임, 표, 연결선/라인, 도형, 텍스트 블록, 칸반 보드, 유저 스토리맵. 현재 메모와 댓글은 데이터 검색 스캔에 포함되지 않습니다. 다가오는 기능 향상 릴리즈에서 메모와 댓글을 포함할 예정입니다.  **예:** *기밀* 또는 *내부* 키워드를 포함하는 보드를 식별하고 라벨링하려면 다음 키워드를 추가하세요: *기밀, 내부* (각 키워드를 쉼표로 구분). 데이터 검색은 이들 키워드를 포함하는 모든 보드를 찾습니다.  **위젯 유형 추가 방법:**  1. **위젯 유형 추가**를 클릭합니다.  2. Miro 보드에서 감지하려는 위젯 유형의 체크박스를 선택합니다.  **예:** Jira 카드가 포함된 보드를 감지하고 레이블을 지정하려면, **Jira 카드** 체크박스를 선택하세요. |
5. **다음**을 클릭합니다.
6. 맞춤형 레이블 세부 정보를 검토합니다.

   맞춤형 레이블 세부 정보를 업데이트하려면 **이전** 버튼을 클릭하세요.

   맞춤형 레이블 세부 정보가 올바르면 **맞춤형 레이블 업데이트** 버튼을 클릭하세요.

   맞춤형 레이블을 업데이트한 후에는 스캔이 자동으로 시작됩니다. 선택한 조건에 맞는 결과는 조직의 Miro 보드 수에 따라 몇 분 또는 몇 시간 후에 제공됩니다.
