민감한 콘텐츠 관리자는 이제 데이터 검색 스캔을 설정할 때 특정 레이블을 쉽게 활성화하거나 비활성화할 수 있어 조직의 요구에 맞게 결과를 조정할 수 있습니다. 예를 들어, GDPR 레이블에만 집중할 수 있습니다. 스캐닝 환경설정을 저장하면, 활성화 또는 비활성화한 데이터 유형을 반영하여 스캔이 자동으로 업데이트됩니다. 이는 관리자가 스캔 출력에 대한 제어 권한을 더 많이 갖게 하여 관련 없는 발견으로 인한 소음을 줄일 수 있게 도와줍니다. 기본적으로 모든 데이터 유형/민감도 레이블이 활성화되어 있습니다.

데이터 유형 스캐닝을 관리하려면 다음 단계를 수행하세요:

:::note
- 데이터 검색 스캔에 대한 레이블을 활성화하거나 비활성화하려면 [민감한 콘텐츠 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 필요합니다. 민감한 콘텐츠 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.
- 데이터 분류에 사용되는 레이블을 비활성화할 수 없습니다. 비활성화하면 콘텐츠에 적용된 자동 분류 및 가드레일에 영향을 미칠 수 있기 때문입니다. 비활성화하기 전에 분류 기준에서 제거하세요.
:::

1. [Miro 설정](https://miro.com/app/settings)으로 이동합니다.
2. 왼쪽 창에서 **Enterprise Guard** 아래의 **데이터 검색**을 클릭합니다.
3. **데이터 검색** 페이지에서 **구성** 탭을 클릭하세요.
4. 개인정보 관련 데이터 유형이나 레이블을 활성화 또는 끄려면 **개인정보 관련** 섹션에서 **관리** 버튼을 클릭하세요.
   비즈니스 민감 데이터 유형/레이블을 활성화하거나 비활성화하려면, **비즈니스 민감** 섹션에서 **관리** 버튼을 클릭합니다.
   측면 패널이 나타납니다.
5. 데이터 유형/민감도 레이블 끄기: 클릭하여 데이터 유형/레이블의 체크 박스를 해제하세요.
   데이터 유형/민감도 레이블을 활성화하려면: 데이터 유형/레이블의 체크 박스를 선택하려면 클릭하세요.
6. **변경 사항 적용** 버튼을 클릭합니다.
   업데이트는 최대 24시간이 소요될 수 있습니다.
