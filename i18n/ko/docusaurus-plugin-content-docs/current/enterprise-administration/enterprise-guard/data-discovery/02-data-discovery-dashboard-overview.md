> Enterprise Guard의 모든 지표는 휴지통에 있는 팀과 법적 보존 조치 중인 보드를 제외합니다.

## 오류, 빈 상태, 변경 이력을 이해하기

Enterprise Guard 대시보드의 지표를 정확히 해석하려면 빈 상태와 오류 메시지를 해석하는 방법을 이해해야 합니다.

### 설정 변경 시 과거 데이터의 동작 방식 이해하기

데이터가 수집된 후 데이터 검색이 비활성화된 경우, 과거 지표는 여전히 활성 기간의 값을 표시합니다. 예를 들어, 4월에 데이터 검색이 활성화되어 있었고 5월에 비활성화한 경우:

- 4월의 데이터 값은 계속해서 대시보드에 나타납니다.
- 5월의 그래프는 데이터 수집이 중단되었기 때문에 **데이터가 없습니다**가 표시됩니다.

## 데이터 검색 결과 보기

데이터 검색 주기는 최소 매시간 한 번 실행되며, 데이터 검색 구성에 따라 모든 보드 업데이트를 스캔해 개인정보 보호, 비즈니스 민감 정보 또는 사용자 지정 비즈니스 민감 정보를 탐지합니다. 이에는 이전 데이터 검색 주기에 이미 스캔된 보드도 포함됩니다.

데이터 검색 결과는 지표 차트 아래에 표시됩니다. 레이블 이름, 상태, 유형, 분류, 보드 수 등의 정보를 볼 수 있습니다.

개인정보 관련 문서를 포함해 보드를 검토하는 방법에 대한 자세한 정보는 [이 문서](16-review-boards-with-privacy-related-information.md)를 참조하세요.

비즈니스 민감 정보와 맞춤형 비즈니스 민감 데이터 정보를 검토하는 방법에 대한 자세한 내용은 [이 문서](14-review-boards-with-business-sensitive-and-custom-business-sensitive-information-beta.md)를 참조하세요.

사용자 지정 비즈니스 민감 레이블이 있는 보드를 검토하는 방법에 대한 자세한 내용은 [이 문서](15-review-custom-business-sensitive-labels-and-data-discovery-results.md)를 참조하세요.

:::note
- 데이터 검색 결과를 보려면 [민감한 콘텐츠 관리자 역할](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)이 필요합니다. 민감한 콘텐츠 관리자 역할을 요청하려면 회사 관리자에게 문의하세요.

기술 파트너 및 고객과 함께 민감한 콘텐츠 감지 시스템을 개선하기 위해 지속적으로 노력하고 있지만, 보드의 모든 민감한 데이터를 100% 탐지 및 표시할 수 있다고 보장할 수는 없습니다. 민감한 콘텐츠 감지 시스템은 패턴 및 기타 기준을 사용해 일치 가능성을 판단합니다. 시스템이 보드에 있는 데이터를 민감한 내용일 가능성이 있는 것으로 잘못 표시하거나(오탐지), 민감한 내용이라고 표시하지 않는 경우(누락)가 있을 수 있습니다. 이는 관련 용어 간의 근접성 또는 민감한 데이터의 서식과 같은 다양한 요인에 의해 발생할 수 있습니다.

오탐지된 일치를 숨기는 방법에 대한 자세한 내용은 [민감한 콘텐츠 일치 항목 숨기기](11-suppress-a-sensitive-content-match.md)를 참조하세요.
:::
