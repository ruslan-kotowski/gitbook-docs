데이터 레지던시가 유럽 연합(EU) 외부인 Enterprise 플랜의 팀은 인터랙티브 디스플레이에서 적절한 지역을 선택할 수 있습니다.

이 문서에서는, 인터랙티브 디스플레이 브라우저를 적절한 데이터 레지던시 지역에 연결하는 방법과 적절한 지역의 Windows 및 Android 디스플레이에서 Miro 앱을 사용하는 방법을 설명합니다.

인터랙티브 디스플레이에 대한 정보는 [인터랙티브 디스플레이](../../../getting-started/apps-for-devices/07-interactive-displays.md)를 참조하세요.

데이터 레지던시에 대해 더 알아보려면 [미로의 데이터 레지던시](../../canvas-25-admin-features/data-residency/02-data-residency-at-miro.md)를 참조하세요.

## 인터랙티브 디스플레이 브라우저를 지역에 연결하기

1. 디스플레이 브라우저를 엽니다.
2. 사용자 지역에 맞는 URL로 이동합니다:
   - (기본) **유럽 연합**
     `https://miro.com/displays/?useAsAppDefaultOrigin`
   - **호주**
     `https://au.miro.com/displays/?useAsAppDefaultOrigin`
   - **미국**
     `https://us.miro.com/displays/?useAsAppDefaultOrigin`
3. 화면의 지시에 따릅니다.

## Windows 인터랙티브 디스플레이에서 Miro 앱 지역 변경하기

1. Windows 인터랙티브 디스플레이에서 Miro 앱을 엽니다.
2. 키보드에서 **ALT** 키를 누릅니다.
   컨텍스트 메뉴가 열립니다.
3. **도움말** > **공용 디바이스** > **공용**을 선택합니다.
   Miro가 인터랙티브 디스플레이 모드로 변경됩니다.
4. **도움말** > **공용 디바이스** > **기본 지역**을 선택합니다.
5. 다음 중 하나를 선택합니다:
   - (기본) **글로벌**
     유럽 연합 지역에 연결됩니다.
   - **호주**
     호주 지역에 연결됩니다.
   - **미국**
     미국 지역에 연결됩니다.

## Android 인터랙티브 디스플레이에서 Miro 앱 지역 변경하기

1. Android 인터랙티브 디스플레이에서 Miro 앱을 엽니다.
2. 시작 화면의 오른쪽 위에 있는 톱니바퀴 아이콘을 탭합니다.
3. **지역 선택**을 탭합니다.
   **다른 지역 선택** 모달이 열립니다.
4. 다음 중 하나를 선택합니다:
   - (기본) **글로벌**
     유럽 연합 지역에 연결됩니다.
   - **호주**
     호주 지역에 연결됩니다.
   - **미국**
     미국 지역에 연결됩니다.
