> **EU 데이터 레지던시:** 모든 플랜에서 사용 가능
>
> **US 및 AU 데이터 레지던시:** Enterprise 플랜에서만 사용 가능

데이터 레지던시를 사용하면 고객이 콘텐츠가 호스팅되고 저장되는 위치를 제어해 데이터 관리 및 개인정보 보호 의무를 준수할 수 있습니다.

## Miro의 데이터 레지던시 이해하기

데이터 레지던시는 은행 및 금융 서비스, 의료 및 정부 등 데이터 보호가 중요하거나 규제되는 산업에 있는 고객에게 필수적입니다.

Miro의 데이터 레지던시 프로그램은 두 가지 기능적 기둥으로 설계되었습니다:

- **지역 내 저장소**
  Miro는 필요 데이터, 백업 데이터, 메타데이터를 로컬 데이터 센터에 저장하여 고객이 규정 준수 요건을 충족하도록 돕습니다.
- **지역 내 컴퓨팅 인프라**
  Miro는 지역 내 컴퓨팅 인프라를 사용하여 IT 요소 간의 이 지역 외 데이터 전송을 제거하고 제품 성능을 최적화합니다.

## 데이터 레지던시 지역

Miro는 다음 지역에서 데이터 레지던시를 제공합니다:

- (기본값) **유럽 연합**
  Miro는 유럽 연합(EU)에 두 개의 데이터 센터를 운영합니다. 주요 데이터 센터는 아일랜드에 위치하고 있으며, 백업 데이터 센터는 독일에 위치하고 있습니다.
- **미국**
  Miro는 미국(US)에 두 개의 데이터 센터를 운영합니다. 주요 데이터 센터는 오하이오에 위치하고 있으며, 백업 데이터 센터는 버지니아에 위치하고 있습니다.
- **호주**
  Miro는 호주에 두 개의 데이터 센터를 운영합니다. 주요 데이터 센터는 시드니에 위치하고 있으며, 백업 데이터 센터는 멜버른에 위치하고 있습니다.

:::note
Miro는 백업 데이터 센터의 위치를 추가하거나 업데이트할 수 있습니다. 백업 데이터 센터는 항상 해당 주요 센터와 동일한 지역에 위치합니다. 예를 들어, 호주에 추가된 백업 데이터 센터는 호주에 위치합니다.
:::

## Miro 데이터 거버넌스

다음 표는 일반적으로 사용 가능한(GA) Miro 기능 중 어떤 것이 데이터 레지던시의 지역 내 저장의 영향을 받는지, 어떤 것이 그렇지 않은지를 보여줍니다.

| 데이터 | 관리되는 항목 | 관리되지 않는 항목 |
| --- | --- | --- |
| **보드 및 보드 콘텐츠** | - Miro AI - 멘션이 있는 댓글 - 멘션이 없는 댓글 - 데이터 테이블 - 문서 - 임베드 파일 - Miro 자체 통합 - 프레임 - 레이어 - 메타데이터(보드 이름, 섬네일 등) - 도형 - 스티커 - 스티커 메모 - Talktrack - 텍스트 상자 - 타임라인 - 위젯 | - 알림 - 써드 파티 통합 데이터(예: Miro 보드에 임베드된 Google 시트 또는 보드에 대한 변경 사항 알림이 Slack으로 발송되는 경우) |
| **조직 세부 정보 및 설정** | - 액세스 요청 - 앱 토큰 및 Miro 자체 앱 데이터 - 로그, 감사, 콘텐츠 및 AI 상호 작용 로그 포함 - 보드 분류 수준 - 브랜드 센터 - 회사 프로필 - eDiscovery - 기능 활성화 - 애널리틱스 - 역할 - 공유 설정 | - 클레임된 도메인 - 도메인 제어 정책 - 조직 도메인 - 조직 ID - 조직 로고 - 조직 이름 - SCIM 통합 - SSO(통합로그인) 통합 - 타사 Miro 앱 데이터 |
| **팀** | - 팀 앱 및 통합 - 팀 권한 - 팀 프로필 - 팀 사용자 | - 해당 없음 |
| **사용자** | - 해당 없음 | - 아바타 - 얼리 액세스 설정 - 이메일 - 이름 - 알림 설정 - 조직 멤버십 - 개인용 앱 - 개인용 통합 |

> **참고:** Miro AI 데이터는 데이터 레지던시 약속에 따라 지역 내에 저장됩니다. 그러나 처리 과정은 선택한 지역 외부에서 이루어질 수 있습니다. 데이터 레지던시는 일반적으로 사용 가능한(GA) 기능에만 적용되며, 베타 또는 프리뷰 기능은 제외됩니다.

> **참고:** 서드파티 앱과 통합 설정은 Miro 데이터 레지던시 외부에서 정보를 저장하고 처리할 수 있습니다.

### Miro AI와 데이터 레지던시

"Miro AI"는 머신 러닝이나 생성 AI 모델을 사용해 Miro의 고객 데이터를 기반으로 콘텐츠를 분석, 변환, 생성하는 제품 기능을 의미합니다.

Miro AI에서 사용하는 데이터는 데이터 레지던시 약속에 따라 지역 내에 저장됩니다. 일부 AI 모델은 아직 지역 내에서 사용할 수 없기 때문에 처리 과정이 선택한 지역 외부에서 발생할 수 있습니다.

## 데이터 레지던시 지역 선택

고객은 전담 Miro 담당자와 데이터 레지던시에 대해 논의할 수 있습니다.

## 데이터 레지던시 추가 비용

EU의 기본 데이터 레지던시에는 추가 비용이 없습니다.

EU 외부의 지역에서의 데이터 레지던시는 Enterprise 고객에게만 제공됩니다.
