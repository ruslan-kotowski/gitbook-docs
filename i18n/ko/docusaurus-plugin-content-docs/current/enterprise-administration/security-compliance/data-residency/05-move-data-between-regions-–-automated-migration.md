:::note
자동화된 마이그레이션은 전문 서비스와 함께하는 유료 서비스입니다. 견적을 받으시려면 전담 Miro 연락처에 문의하세요.
:::

이 문서는 자동화된 데이터 마이그레이션을 설명합니다. 지역 간 데이터 이동의 다른 옵션에 대해 알아보려면 [지역 간 데이터 이동](../../canvas-25-admin-features/data-residency/03-move-data-between-regions.md)을 참조하세요.

## 자동화된 지역 간 마이그레이션에 포함된 데이터

다음 목록은 자동화된 지역 간 마이그레이션에 포함되는 데이터를 보여줍니다:

- 보드, 보드 콘텐츠 및 보드 공유 설정
- 콘텐츠 계층 구조, 팀, 스페이스 및 스페이스 섹션 포함
- 조직, 팀 및 보드 설정
- 사용자, 사용자 프로필 및 사용자 설정, 게스트 포함
- 감사 로그, 데이터 등급 분류, 콘텐츠 보안 설정

## 교차 지역 데이터 마이그레이션 준비하기

교차 지역 데이터 마이그레이션을 준비하려면 다음 단계를 따르세요:

1. 도메인 내 모든 사용자를 관리할 수 있도록 소유한 모든 도메인을 DNS 인증으로 확인하세요.
2. **자체 구독 차단** 도메인 제어 정책을 활성화하여 사용자가 이전 지역에서 실수로 무료 Miro 구독을 생성하지 않도록 합니다.
3. 팀 및/또는 조직을 하나의 구독을 가진 단일 조직으로 통합하세요.
4. 조직에서 사용하는 통합 기능을 감사하고, 새 지역에서 다시 구성할 각 통합 기능의 일정 계획을 세우세요.

## 크로스 리전 데이터 마이그레이션의 작동 방식과 소요 시간

크로스 리전 마이그레이션은 다음의 다섯 가지 단계로 이루어집니다:

- **준비**
  보통 4-8주 소요. Miro의 지원을 받으며 회사 관리자가 조직의 이주를 준비하고, 이주 중단 시간을 예약하며 최종 사용자에게 이를 공지합니다.
- **이주**
  보통 8시간 이하의 중단 시간. 조직과 데이터가 새로운 지역으로 이주됩니다.

  > ✏️ Miro 팀이 이주 날짜를 정하기 위해 귀하와 협력합니다. 만약 이주가 어떤 이유로든 실패하는 경우, 원본 지역에 대한 접근이 복원되며, Miro는 귀하와 함께 새로운 이주 날짜를 조정하여 재시도합니다.
- **확인 및 구성**
  일반적으로 2-3주. 관리자는 새로운 지역에서 SSO와 같은 특정 통합을 재구성해야 합니다. 관리자와 사용자들은 그들의 보드와 데이터가 새로운 지역에 제대로 도착했는지 확인합니다.
- **교육**
  일반적으로 2-3주. 사용자가 새로운 Miro 조직에 어떻게 접근해야 하는지를 교육받습니다.
- **준수**
  이동일로부터 120일 이내 - Miro는 조직의 데이터가 원래 지역에서 삭제되었는지 확인합니다.

## 지역 간 데이터 이동 후 해야 할 일

지역 간 데이터 이동 후, 다음 사항을 확인하세요:

- 새로운 지역의 하위 도메인에 대해 SSO(통합로그인)를 즉시 재구성합니다. 예를 들어, au.miro.com.

  > ✏️ IDP 측에서 SSO가 재구성될 때까지 사용자는 새로운 지역에 로그인할 수 없습니다.
- 새로운 지역의 하위 도메인에 대해 SCIM을 재구성합니다. 예를 들어, au.miro.com.
- 도메인 제어 설정에서 **자체 구독 허용 안함**이 켜져 있는지 확인합니다.
- 다른 도메인 제어 설정을 확인합니다.
- 관련 애플리케이션과 통합을 다시 설치하고 구성합니다.

## 자동화된 지역 간 데이터 마이그레이션에 대한 자주 묻는 질문

**교차 지역 데이터 마이그레이션이란 무엇인가요?**

교차 지역 데이터 마이그레이션은 고객 데이터를 한 지리적 지역에서 다른 지역으로 자동으로 이동시키는 과정입니다. 교차 지역 마이그레이션의 최종 결과는 대상 Miro 고객 데이터가 새로운 지역에서 저장되고 처리된다는 것입니다.

**작동 방식과 소요 시간은 어떻게 되나요?**

교차 지역 데이터 마이그레이션의 작동 원리와 소요 기간을 참조하세요.

**누가 자격을 갖추고, 누가 그렇지 않은가?**

Cross-region 마이그레이션을 자동화하기 위해서는 Enterprise 고객이어야 합니다. 그러나 Enterprise Guard와 EKM을 사용하는 Enterprise 고객은 자격이 없습니다. 자세한 내용은 Miro의 담당자에게 문의하십시오.

**자동화된 cross-region 데이터 마이그레이션에 어떤 데이터가 포함되나요?**

자동화된 cross-region 마이그레이션에 어떤 데이터가 포함되는지 알아보려면 자동화된 cross-region 마이그레이션에 포함된 데이터를 참조하십시오.

**자동화된 크로스 리전 데이터 마이그레이션에 포함되지 않는 데이터는 무엇입니까?**

자동화된 크로스 리전 마이그레이션에는 다음 데이터가 포함되지 않습니다:

- 새로운 지역에 맞게 재구성해야 하는 앱 및 통합, SSO(통합 로그인) 및 SCIM을 포함
- Talktrack
- 앱 내 알림이 삭제됩니다

**추가 비용이 발생합니까?**

네. 자동 크로스 리전 마이그레이션은 Miro 서비스의 유료 참여로 진행됩니다. 더 많은 정보를 얻으려면 Miro 담당자에게 문의하세요.

**Miro는 어떻게 조직의 데이터를 원본 지역에서 제거하나요?**

크로스 지역 마이그레이션 후 원본 지역에서 데이터를 제거하기 위해, Miro는 다음 프로토콜을 따릅니다:

- 마이그레이션 문제 발생 시 신뢰할 수 있는 백업을 보장하기 위해 데이터는 원본 지역에 30일 동안 남아 있습니다.
- 30일 후, Miro는 원본 지역에서 데이터를 삭제하기 시작합니다.
- 최초 마이그레이션 날짜로부터 최대 120일 후, Miro는 원본 지역의 모든 데이터를 삭제합니다.

**지역 간 데이터 마이그레이션 중 사용자는 무엇을 보게 되나요?**

마이그레이션 중 사용자 경험에 대해 알아보려면, [지역 간 데이터 이동 시 사용자 경험](../../canvas-25-admin-features/data-residency/04-user-experience-while-moving-data-between-regions.md)을 참조하세요.

**마이그레이션이 실패하면 어떻게 되나요?**

어떤 이유로든 마이그레이션이 실패하면, Miro는 원본 지역에 대한 접근을 복구하고 마이그레이션을 다시 시도하기 위한 새로운 날짜를 조율합니다.
