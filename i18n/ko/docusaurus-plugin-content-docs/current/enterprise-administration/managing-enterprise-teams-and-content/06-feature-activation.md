조직을 위해 최신 Miro 도구를 사용해보세요. 관리자 설정에서 직접 Miro 기능에 대한 접근 권한을 사용자에게 부여하세요.

> **사용 가능 대상:** Enterprise 플랜
> **실행 가능한 사용자:** 회사 관리자

## 기능 활성화 작동 방식

조직의 Miro 기능 접근을 쉽게 관리하세요. 기능의 능력을 평가하기 위해 접근 권한을 부여하고, 회사와 팀의 고유한 필요에 따라 언제든지 접근을 업데이트하세요.

- 기능을 회사의 모든 사람이나 특정 팀에 사용할 수 있게 하거나, 모두에 대한 접근 권한을 철회할 수 있습니다.
- 기능이 베타 버전일 때 접근 권한을 부여했다면, 출시 후에도 설정은 동일하게 유지됩니다.
- 기능에 대한 접근 권한을 철회하더라도 사용 중에 생성된 콘텐츠는 삭제되지 않습니다.

> **💡** 감사 로그에서 사용자에게 어떤 기능이 제공되었는지 추적하세요. [감사 로그](../security-integrations/security-management/01-audit-logs.md).

## 기능 활성화 방법

1. **계정** 설정으로 이동합니다.
2. **조직**을 클릭합니다.
3. **기능 활성화**를 클릭합니다.
4. 관리하려는 **기능** 아래에서 **사용 불가**, **모두 사용 가능**, 또는 **특정 팀 사용 가능**을 선택합니다.
5. **특정 팀 사용 가능**을 선택한 경우, **+ 팀 추가**를 클릭합니다.
   드롭다운이 열립니다.

- 검색하거나 스크롤하여 액세스를 부여할 팀을 찾고 선택하세요. 팀을 추가하려면 **+**를 클릭하세요. 팀을 제거하려면 팀 이름 옆의 **x**를 클릭하세요.
:::note
조직 내 모든 팀에 기능 활성화를 부여할 수 있습니다. 권장되는 방법은 하나의 팀으로 시작하여 기능을 테스트한 다음 다른 팀으로 확장하는 것이며, 조직 전체에 출시하기 전에 진행하는 것이 좋습니다.
:::

## 사용 가능한 기능 액세스 제어

### Miro AI

Miro는 기계 학습 모델과 사용자의 입력을 활용하여 Miro 보드에서 콘텐츠를 생성합니다. Miro AI는 사용자가 보드에서 콘텐츠 생성, 조직 및 요약을 자동화할 수 있도록 지원합니다. Miro AI 섹션 내에서 베타 기능을 켜거나 끌 수 있는 옵션이 있습니다.

**더 많은 정보:**

- [Miro AI](../../using-miro/miro-ai/03-create-with-ai.md)
- [Miro AI 관리자 보안](../canvas-25-admin-features/data-security/04-miro-ai-admin-security.md)

### Talktrack

Miro 보드를 상호작용 비디오 형식으로 녹화하여 아이디어를 전달하세요. 회의에 추가 시간을 투자하지 않고 아이디어를 공유할 수 있습니다. Talktrack의 기능을 탐구하여 팀의 협업 노력을 더욱 생산적이고 효율적으로 만들 수 있는 방법을 알아보세요.
