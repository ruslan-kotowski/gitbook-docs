팀 콘텐츠 관리자는 특정 팀의 모든 콘텐츠를 감독할 수 있게 해줍니다. 팀 콘텐츠 관리자로서는 특정 팀의 스페이스, 보드, 템플릿에 대한 접근을 관리할 수 있습니다.

팀 콘텐츠 관리자는 팀 수준의 권한 설정입니다. 조직 수준의 권한 설정에 대해서는 [콘텐츠 관리자 권한](12-content-admin-permissions.md)을 참조하세요.

## 팀 콘텐츠 관리자 권한

팀 콘텐츠 관리자는 다음과 같은 팀 권한을 가지고 있습니다:

- 모든 콘텐츠(보드와 스페이스 포함) 관리
- 모든 보드와 스페이스에 대한 콘텐츠 메타데이터 및 액세스 권한 관리
- 맞춤 설정 템플릿 만들기
- 보드 아카이브 내보내기

모든 팀 콘텐츠 관리자 권한을 확인하고 다른 관리자 역할과 비교하려면, [관리자 역할과 권한 이해하기](../../administration/get-started-as-a-miro-admin/02-understand-admin-roles-and-their-privileges.md)를 참조하세요.

## 팀 콘텐츠 관리자 역할 할당 방법

1. 회사 관리자 또는 사용자 관리자로서 관리자 콘솔에서 **사용자** > **관리자 역할**로 이동합니다.
2. **팀 역할** 탭을 클릭합니다.
3. **팀 콘텐츠 관리자** 행의 아무 위치나 클릭하세요.
   **팀 콘텐츠 관리자** 화면이 열립니다.

   > 💡 또는 **팀 역할** 탭 끝에 있는 **...** 메뉴를 클릭할 수도 있습니다.
4. **역할 할당**을 클릭합니다.
   **팀 콘텐츠 관리자 역할 할당** 모달이 열립니다.
5. 팀 콘텐츠 관리자를 할당하려는 팀을 선택합니다.

- **다음**을 클릭하세요.
  선택한 팀의 각 멤버가 **사용자 선택** 단계에 나열됩니다.
- 사용자 이름 또는 이메일 주소로 검색하여 할당할 팀 멤버를 선택하세요. 최대: 50명.
- **할당**을 클릭합니다.
  **사용자** 탭의 **콘텐츠 관리자** 보기로 돌아갑니다. 콘텐츠 관리자 역할이 할당된 모든 사용자를 볼 수 있습니다.

## 콘텐츠 관리자 역할 제거 방법

1. 회사 관리자 또는 사용자 관리자로서 관리자 콘솔에서 **사용자** > **관리자 역할** > **팀 역할** 탭으로 이동합니다.
2. **콘텐츠 관리자**를 클릭합니다.
3. **사용자** 아래, 제거하려는 콘텐츠 관리자의 경우 행 끝에 있는 세 개의 점(**...**)을 클릭합니다.
4. **사용자에서 역할 제거**를 클릭합니다.
