모든 라이선스 요청을 하나의 장소에서 관리하세요. 라이선스 요청을 Miro에서 직접 수신함으로써, 조직 내 라이선스 사용 및 승인 절차를 간소화할 수 있습니다.

## 라이선스 요청 설정

귀하의 **접근 요청** 설정에서 현재 모든 **라이선스 요청** 현황을 확인할 수 있습니다. 이러한 라이선스 요청은 사용자가 Free 제한에서 Advanced, Standard 또는 Full (레거시) 라이선스로 업그레이드가 필요할 경우 시작됩니다.

라이선스 요청 세부 정보에는 다음이 포함됩니다:

- 라이선스 요청 대상 사용자의 이름
- 사용자가 배정될 결제 그룹의 이름(있을 경우)
- 요청자의 이름
- 요청 날짜

요청은 라이선스 업그레이드가 필요한 개인이나 다른 사람을 대신하여 제출할 수 있습니다. Enterprise 플랜의 다양한 라이선스 업그레이드 시나리오에 대해 알아보세요.

:::note
Miro에서 직접 라이선스 요청을 받으려면 [요청 관리](09-request-management-on-enterprise-plan.md) 환경설정을 업데이트하세요.
:::

## 라이선스 요청을 수락하거나 거절하는 방법

:::note
모든 요청은 30일 후 자동으로 만료되어 제거됩니다.
:::

1. Miro 설정으로 이동합니다.
2. **회사**를 클릭합니다.
3. **사용자** 아래에서 **접근 요청**을 클릭합니다.
4. **라이선스 요청** 탭을 선택합니다. 여기에서 모든 대기 중인 라이선스 요청을 확인할 수 있습니다.
5. **작업** 열에서 체크 마크(**✓**)를 클릭하여 요청을 수락하거나, X 표시(**x)**)를 클릭하여 요청을 거절합니다.
6. (선택 사항) 라이선스 요청을 일괄 승인하려면, **이름** 열 옆의 체크박스를 클릭하여 모든 요청을 선택하고, **일괄 승인**을 클릭합니다.
7. 요청을 승인하거나 거절할 때, 모달 창이 열리며 요청자 정보와 라이선스 요청의 대상자 정보를 확인할 수 있습니다.
8. **승인**을 클릭하여 요청을 승인하거나, **거절**을 클릭하여 요청을 거절합니다. 요청을 승인하거나 거절하면, 해당 요청은 라이선스 요청 개요에서 제거됩니다.
9. 라이선스 요청이 승인되면, 사용자는 Free Restricted 라이선스에서 Advanced, Standard 또는 Full (이전 버전) 라이선스로 업그레이드됩니다.

## License upgrade scenarios

Miro 내의 특정 작업이나 이벤트로 인해 사용자가 라이선스 업그레이드 요청을 제출하게 됩니다. 아래에 나열된 시나리오들은 Enterprise 플랜 사용자에 대해 이러한 요청이 어떻게 시작되는지를 설명합니다. 요청이 승인되면 사용자의 라이선스는 Free Restricted에서 Advanced, Standard, 또는 Full (legacy) 라이선스로 업그레이드됩니다. 사용자는 이전에 속해 있던 팀의 멤버십을 유지하게 됩니다.

:::note
현재 라이선스 사용량을 보려면 **사용자 관리** > **활성 사용자**로 이동하세요.
:::
