Enterprise 구독을 통해, 관리되는 사용자는 귀사의 인증된 도메인 내의 모든 사용자입니다.

도메인 인증 절차에 대해 더 알아보려면, [도메인 제어](../canvas-25-admin-features/domain-control/01-domain-control.md) 관련 기사를 방문하세요.

회사의 사용자를 Enterprise 조직에 할당하는 방법은 다양하며, 도메인 제어, SCIM, JIT, 이메일을 통한 수동 초대가 포함됩니다. [자세히 알아보기](13-user-provisioning-on-enterprise-plan.md).

Managed 사용자들은 Enterprise 회사 관리자에 의해 감독될 수 있으며, 조직은 Miro에서 접근하는 방법과 내용을 포함하여 사용자의 전반적인 소유권에 대해 정책과 통제를 수립할 수 있습니다. 예를 들어, 팀에 할당하고, 콘텐츠를 관리하고, 액티비티를 분석하며, 사용자를 삭제할 수 있습니다.

:::note
사용자 세부사항에는 **내부** 또는 **외부** 등급 분류가 포함됩니다. 내부 사용자는 확인된 도메인의 이메일 주소로 로그인합니다. 외부 사용자는 그렇지 않습니다. 자세한 사항은 [도메인 제어: 내부와 외부 사용자](../canvas-25-admin-features/domain-control/01-domain-control.md)를 참조하세요.
:::

Miro는 다음과 같은 사용자 관리 기회를 제공합니다:

- 도메인 제어 기능:
  - Enterprise 조직에 아직 귀속되지 않은 회사 도메인 사용자에 대한 인사이트 획득
  - 도메인에서 Enterprise 구독으로 사용자 자동 조치
  - 관리 사용자가 Enterprise 조직 외부에서 새로운 Miro 구독을 생성하지 못하도록 제한
- 라이선스 관리
  - 사용자에게 [고급, 일반, 전체(레거시), 또는 제한된 플랜 접근 권한을 부여할지 정의하고](../enterprise-subscription-management/enterprise-licensing/04-free-restricted-license.md) 관리 사용자의 라이선스를 변경합니다
- 사용자 접근
  - [비활성화](01-deactivated-users.md) 및 [삭제](10-remove-users-on-enterprise-plan.md) 사용자
  - 조직 내 팀에 대한 사용자 접근 관리
  - [비활성화된 관리 사용자의 모든 Miro 접근 차단](02-block-deactivated-users.md)
- 보고
  - 관리자 설정에서 Enterprise 플랜에 포함된 관리 사용자를 필터링하고 CSV 파일로 사용자 목록 다운로드
