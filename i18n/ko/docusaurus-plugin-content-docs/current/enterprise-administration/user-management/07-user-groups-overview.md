사용자 그룹은 회사 관리자가 사용자 관리를 단순화하여 개별 사용자에게 각각 콘텐츠를 공유할 필요 없이 그룹의 모든 사용자에게 공유할 수 있도록 해줍니다.

예를 들어, 조직 내 모든 디자이너와 프로젝트 보드를 공유하고 싶다면, 사용자 그룹을 생성하고 모든 디자이너를 추가한 다음, 그룹과 공유하면 됩니다. 그룹의 모든 구성원에게 편집, 댓글, 보기 등 지정한 접근 권한이 동일하게 부여됩니다.

사용자 그룹을 생성하는 방법을 알아보려면 [사용자 그룹](08-user-groups.md)을 참조하세요.

![](../../../../../../docs/enterprise-administration/user-management/images/23921780232082_image.png)

*회사 관리자가 관리자 콘솔에서 사용자 그룹을 생성할 수 있습니다.*

사용자 그룹은 그룹 내 모든 사용자가 동일한 콘텐츠에 접근할 수 있도록 하여 각 사용자에게 보드를 개별적으로 공유할 필요가 없게 해줍니다. 또한 팀에 사용자 그룹을 추가할 수도 있습니다.

:::note
SCIM을 통해 사용자 그룹을 관리하는 방법에 대해 알아보려면, Miro 고객 성공 매니저나 지원팀에 문의하세요.
:::

## 주요 기능

- **사용자 그룹 생성 및 관리**
  관리자 콘솔에서 회사 관리자는 사용자 그룹을 생성, 검토, 편집, 구성원 추가 및 삭제할 수 있습니다. 자세한 내용은 [사용자 그룹](08-user-groups.md)을 참조하세요.
- **보드 및 스페이스를 사용자 그룹과 공유**
  팀 구성원은 [사용자 그룹과 보드 또는 스페이스를 공유](08-user-groups.md)하고 권한을 설정할 수 있습니다.
- **API로 사용자 그룹 관리**
  사용자 그룹 API를 사용하여 관리자는 사용자 그룹을 프로그래밍적으로 생성, 편집 및 제거할 수 있습니다.
- **댓글에 사용자 그룹 언급하기**
  어떤 보드에서든 사용자 그룹을 언급하세요. 그룹의 모든 사용자가 알림을 받습니다.
- **보드에서 사용자 그룹 멤버 보기**
  보드에서 그룹을 언급할 때 사용자 그룹의 모든 멤버를 보고 검토할 수 있습니다.
