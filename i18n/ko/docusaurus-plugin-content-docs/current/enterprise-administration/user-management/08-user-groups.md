회사 관리자로서, 사용자 그룹을 통해 각 개인 구성원이 아닌 사용자 그룹으로 콘텐츠에 대한 접근을 관리할 수 있습니다. 조직의 모든 구성원은 당신이 만든 사용자 그룹과 함께 콘텐츠를 보고 공유할 수 있습니다.

이 글에서는 사용자 그룹과 콘텐츠를 생성, 관리, 공유하는 방법을 설명합니다. 기능에 대한 일반적인 정보를 확인하려면 [사용자 그룹 개요](07-user-groups-overview.md)를 참조하세요.

:::note
SCIM을 통한 사용자 그룹 관리에 대해 알아보려면, Miro 고객 성공 매니저 또는 지원에 문의하세요.
:::

## 회사 관리자 가이드

### 사용자 그룹 생성

1. 회사 관리자로서, 관리자 콘솔로 이동하세요.
2. **사용자** > **그룹**으로 이동하세요.
3. 오른쪽 상단에서 **+ 그룹 생성**을 클릭하세요.
   **새 그룹 생성** 모달이 열립니다.
4. 그룹의 이름을 지정하세요.
5. (선택 사항) 새 그룹에 대한 설명을 추가하세요. 나중에 설명을 추가하거나 편집할 수 있습니다.
6. **그룹 생성**을 클릭하세요.
   새 그룹이 **그룹** 보기 화면에 추가됩니다.

### 사용자 그룹에 사용자 추가

1. 관리자 콘솔에서 **사용자** > **그룹**으로 이동합니다.
2. 관리하려는 사용자 그룹의 행 끝에 있는 세 점(**...**)을 선택합니다.
3. **사용자 추가**를 클릭합니다.
   **사용자 추가** 모달이 열립니다.
4. 사용자를 찾으려면 이름이나 이메일 주소로 검색합니다.
5. 추가할 각 사용자를 선택합니다.
6. **선택한 사용자 추가**를 클릭합니다.
   선택한 사용자가 사용자 그룹에 추가됩니다.

### 사용자 그룹을 팀에 추가

1. 관리자 콘솔에서 **사용자** > **그룹**으로 이동합니다.
2. 관리할 사용자 그룹의 행 끝에 있는 점 세 개 (**...**)를 선택합니다.
3. **팀에 추가**를 클릭합니다.
   **그룹을 팀에 추가** 모달이 열립니다.
4. 팀을 찾기 위해 이름으로 검색합니다.
5. 사용자 그룹이 참여할 각 팀을 선택합니다.
6. **추가**를 클릭합니다.
   선택한 모든 팀에 사용자 그룹이 추가되었습니다.

   > ✏️ 사용자 그룹 멤버들은 선택한 각 팀의 모든 콘텐츠에 대한 편집 권한을 가집니다.

### 사용자 그룹 편집

1. 관리자 콘솔에서 **사용자** > **그룹**으로 이동하세요.
2. 관리할 사용자 그룹의 행 끝에 있는 세 개의 점(**...**)을 선택하세요.
3. **그룹 편집**을 클릭하세요.
   **그룹 편집** 모달이 열립니다.
4. (선택 사항) 그룹 이름을 변경하세요.
5. (선택 사항) 새로운 그룹에 대한 설명을 추가하세요.
6. **저장**을 클릭하세요.

### 사용자 그룹 삭제

:::warning
사용자 그룹 삭제는 실행 취소할 수 없습니다. 사용자 그룹을 삭제하면 일부 사용자가 일부 팀에서 제거될 수 있습니다.
:::

1. 관리자 콘솔에서 **사용자** > **그룹**으로 이동합니다.
2. 관리할 사용자 그룹의 행 끝에 있는 세 점(**...**)을 선택합니다.
3. **그룹 삭제**를 클릭합니다.
   **\{User Group name\} 삭제** 모달이 열립니다.
4. **삭제**를 클릭합니다.
   사용자 그룹이 영구적으로 삭제됩니다.

## 사용자 가이드

### 보드를 사용자 그룹과 공유

팀 멤버는 조직 내 어느 사용자 그룹과도 보드를 공유할 수 있습니다. 보드는 해당 사용자 그룹의 모든 멤버와 공유됩니다.

다음의 절차를 따르세요:

1. Miro 보드의 우측 상단에서 **공유**를 클릭하세요.
   모달이 열립니다.
2. 대상 사용자 그룹의 이름을 입력하세요.
3. 자동으로 채워진 옵션에서 사용자 그룹을 선택하세요.
4. (선택 사항) 권한을 업데이트하세요. 기본값: **편집**.
5. (선택 사항) 사용자 지정 메시지를 추가하세요.
6. **초대 발송**을 클릭하세요.
   사용자 그룹의 각 사용자는 보드에 접근할 수 있는 이메일 초대를 받습니다.

### 스페이스를 사용자 그룹과 공유하기

팀 멤버는 조직 내 모든 사용자 그룹과 스페이스를 공유하고 권한을 지정할 수 있습니다. 스페이스는 해당 사용자 그룹의 모든 멤버와 공유됩니다.

다음 단계를 따르세요:

1. Miro 대시보드에서 공유할 스페이스에 대해 세로로 된 점 세 개를 클릭하여 **옵션** 메뉴를 엽니다.

   > 💡 다른 방법으로, 스페이스 사이드바에서 위에 있는 세로점 세 개를 클릭하여 **옵션** 메뉴를 엽니다.
2. **공유**를 클릭합니다.
   **스페이스 '\{Space Name\}' 공유** 모달이 열립니다.
3. 사용자 그룹 이름을 입력합니다.
4. (선택 사항) 권한을 업데이트합니다. 기본값: **편집 가능**.
5. (선택 사항) 맞춤형 메시지를 추가합니다.
6. **초대장 보내기**를 클릭합니다.
   사용자 그룹의 각 멤버는 스페이스에 접근할 수 있는 이메일 초대장을 받습니다.

:::note
사용자 그룹에 추가된 멤버들은 자동으로 공유된 스페이스에 접근할 수 있습니다. 사용자 그룹에서 제거된 멤버들의 접근은 자동으로 해제됩니다.
:::
