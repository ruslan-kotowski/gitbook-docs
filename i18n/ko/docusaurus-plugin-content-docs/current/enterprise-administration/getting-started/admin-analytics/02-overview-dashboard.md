개요 대시보드는 조직의 활동을 이해하고 도입을 추적할 수 있는 인사이트를 다음 지표를 통해 제공합니다:

- **보드:** 보드의 총 개수 확인, 사용 중인 활동 보드 개수 확인, 그리고 과거의 트렌드 추적.
- **사용자:** Miro와 적극적으로 상호작용하는 사용자 수를 시간에 따라 추적합니다. 또한 멤버, 회사 관리자, 게스트, 팀 게스트 등 특정 사용자 역할에 따라 추적할 수 있습니다.
- **팀:** 팀 수를 모니터하고 활동 수준을 확인합니다.
- **라이선스:** 할당된 라이선스 종류를 추적하고 이것의 경과를 확인합니다.
- **템플릿:** 조직 내에서 가장 많이 사용되는 템플릿을 알아봅니다.

## 개요 대시보드 사용하기

개요 대시보드에서 지표를 작업할 때 다음 사항을 유의하세요:

- **시간 범위 선택기:** 분석 페이지 상단 오른쪽의 선택기를 사용하여 개요 대시보드에 표시할 시간 범위를 조정할 수 있습니다(일별, 주별, 월별, 분기별).
- **분석 보기 설정:** 시간 범위 선택기 옆에 있는 **기어 아이콘**을 클릭하여 설정을 엽니다. **사용자 개인정보**에서 사용자의 활동을 포함한 분석 대시보드(예: AI 상위 사용자)에서 사용자 이름을 표시할지 숨길지를 선택합니다. **기본적으로 사용자가 표시됩니다.** 변경 사항을 적용하려면 **저장**을 클릭하세요.
- **마지막 업데이트:** 지표는 매일 새로고침됩니다. 각 대시보드에는 마지막 업데이트 타임스탬프가 표시됩니다.
- **부분 데이터:** 선택한 기간의 일부 동안 기능이 꺼져 있었을 경우, 지표 내역에서 부분 데이터를 볼 수 있습니다 (예: 기능이 한 달 중간에 활성화된 경우).
- **데이터 없음:** 특정 기간(일, 주, 월) 동안에 기록된 활동이 없었던 경우, 차트는 해당 기간에 대한 데이터를 표시하지 않습니다.
- **히스토리 데이터 표시:**

  - 히스토리 데이터를 표시하는 모든 위젯은 각 기간의 마지막 날의 데이터를 나타냅니다. 예를 들어, 선택한 기간이 매월일 경우, 보드 차트는 각 월 말에 보드의 수를 보여줍니다.
  - 현재 진행 중인 기간은 히스토리 차트에 표시되지 않습니다. 예를 들어, 선택한 기간이 매월이고 현재 월이 9월인 경우, 차트는 8월(마지막 완료된 기간)까지의 데이터만 표시합니다.
  - 히스토리 데이터는 최대 1년 또는 데이터가 존재하는 가장 오래된 시점까지 볼 수 있습니다. 더 오래된 데이터가 없는 경우, Miro 지원에 백필 검증 요청을 하세요.

## 보드 분석

보드 차트는 전체 보드 수, 사용 측면에서의 활성 보드 수를 표시하며, 과거 추세를 확인하고 분석할 수 있습니다. 다음 표에는 보드 차트에서 제공되는 정보가 나열되어 있습니다.

| 메트릭 이름 | 설명 |
| --- | --- |
| (1) 총 | 총 보드 수. 휴지통에 있는 보드는 제외됩니다. |
| (2) 이 기간 내 활성 (분기/월/주/어제 중 선택) | 선택된 기간 시작 시점부터 열렸던 고유 보드의 총 수. 휴지통으로 이동된 보드도 포함됩니다. |
| (3) 차트에 표시된 총 보드 | 플롯된 날짜 또는 월의 끝에 있는 총 보드 수. 휴지통에 있었던 보드는 제외됩니다. |
| (4) 차트에 표시된 활성 보드 | 플롯된 날짜 또는 월의 시작부터 열렸던 고유 보드의 총 수. 휴지통으로 이동된 보드도 포함됩니다. |

*참고: 이 지표는 최소 24시간마다 업데이트됩니다. 분석 페이지의 왼쪽 상단에 있는 '마지막 업데이트' 정보는 가장 최근 지표 업데이트 시점을 나타냅니다.*

## 사용자 분석

사용자 차트는 사용자가 Miro를 얼마나 적극적으로 사용하고 있는지를 시간에 따라 보여줍니다. 또한 멤버, 회사 관리자, 게스트, 팀 게스트와 같은 특정 사용자 역할을 기준으로 사용자 분석을 추적할 수 있습니다. 다음 표는 사용자 차트에서 확인할 수 있는 정보를 나열합니다.

| 측정 항목 이름 | 설명 |
| --- | --- |
| (1) 총계 | 멤버, 회사 관리자, 게스트, 팀 게스트를 포함한 총 사용자 수입니다. 선택한 사용자 유형에 따라 총계가 변경됩니다. |
| (2) 이번 <선택한 기간> 동안 활성 (분기/월/주/어제 중 선택) | 선택한 기간의 시작부터 최소 한 번 보드를 연 고유 사용자 수입니다. 여기에는 현재 비활성화된 사용자도 포함됩니다.  선택한 사용자 유형에 따라 총계가 변경됩니다. |
| (3) 차트에 표시된 총 사용자 | 각 기간 종료 시점의 멤버, 회사 관리자, 게스트, 팀 게스트를 포함한 총 사용자 수입니다.  선택한 사용자 유형에 따라 총계가 변경됩니다. |
| (4) 차트에 그려진 활성 사용자 | 각 그려진 기간의 시작부터 최소 한 번 보드를 연 고유 사용자의 총 수입니다.  여기에는 지금 비활성화된 사용자도 포함됩니다. 선택한 사용자 유형에 따라 총 수가 변경됩니다. |

*참고: 이 지표는 최소 24시간마다 한 번 이상 업데이트됩니다. 분석 페이지의 왼쪽 상단에 있는 "마지막 업데이트" 정보는 가장 최근의 지표 업데이트 시점을 나타냅니다.*

## 팀 분석

팀 차트는 팀 수 및 활동 수준을 표시합니다. 아래 표는 팀 차트에 있는 정보를 나열합니다.

| 메트릭 이름 | 설명 |
| --- | --- |
| (1) 총 | 총 팀 수.  이는 휴지통에 있는 팀은 제외됩니다. |
| (2) 이번 <선택한 기간> 동안 활동 (분기/월/주/어제 중 하나) | 선택한 기간의 시작 이후 적어도 한 번 보드를 연 회원이 있는 고유 팀의 총 수.  이에는 휴지통으로 이동된 팀도 포함됩니다. |
| (3) 차트에 표시된 총 팀 | 플롯된 날짜 또는 월 말에 있는 총 팀 수.  이에는 휴지통에 있는 팀은 제외됩니다. |
| (4) 차트에 표시된 활동 팀 | 플롯된 날짜 또는 월 시작 이후 적어도 한 번 보드를 연 회원이 있는 팀의 총 수.  이에는 휴지통으로 이동된 팀도 포함됩니다. |

*참고: 이 지표는 24시간마다 최소 한 번씩 업데이트됩니다. 애널리틱스 페이지 좌상단의 '마지막 업데이트' 정보는 가장 최근의 지표 업데이트 시점을 나타냅니다.*

## 라이선스 분석

라이선스 차트는 할당된 여러 종류의 라이선스를 표시하며, 시간에 따른 라이선스 할당 변화를 추적할 수 있습니다. 다음 표는 라이선스 차트에서 확인할 수 있는 정보를 나열합니다.

| 지표 이름 | 설명 |
| --- | --- |
| 할당됨 | 고급, 표준, 풀(구 버전), Free, Free 제한 라이선스를 포함한 총 할당된 라이선스 수입니다. 이는 현재 조직에서 사용 중인 라이선스 수를 나타냅니다.  총 수치는 목록에서 선택한 라이선스 유형에 따라 변경됩니다. |
| 차트에 표시된 할당 이력 | 각 표시된 기간 말에 할당된 총 라이선스 수.  선택한 라이선스 유형에 따라 총 라이선스 수가 변경됩니다. |

*참고: 이 지표는 최소 24시간마다 한 번씩 업데이트됩니다. 분석 페이지의 왼쪽 상단에 있는 "마지막 업데이트" 정보는 가장 최근에 지표가 업데이트된 시간을 나타냅니다.*

## 템플릿 분석

가장 인기 있는 템플릿 섹션은 조직 내에서 가장 자주 사용된 템플릿을 보여줍니다. 현재 이 데이터는 보드에서 직접 추가된 템플릿만 포함하며, miro.com/templates와 같은 다른 출처의 데이터는 포함되지 않습니다. 추가적인 출처 지원은 향후 릴리스에 포함될 예정입니다.

*참고: 이러한 지표는 24시간마다 한 번 이상 업데이트됩니다. 애널리틱스 페이지 왼쪽 상단의 '마지막 업데이트' 정보를 통해 가장 최근 지표 업데이트 시점을 확인할 수 있습니다.*
