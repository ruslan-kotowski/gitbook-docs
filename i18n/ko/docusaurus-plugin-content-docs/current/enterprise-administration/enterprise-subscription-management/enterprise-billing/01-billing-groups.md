결제 그룹은 회사 관리자가 사용자들을 내부 예산에 매핑할 수 있도록 합니다. 각 사용자는 하나의 그룹에만 할당될 수 있기 때문에, 관리자는 각 비용 센터가 사용하는 라이선스의 수를 손쉽게 추적할 수 있습니다. 관리자는 각 결제 그룹에 사용할 수 있는 라이선스에 대해 유연 할당량 제한을 설정할 수도 있습니다. 이는 팀을 위한 라이선스 조정, 갱신 및 환급 절차 등을 간소화합니다.

> **사용 가능 대상:** Enterprise 플랜
> **실행 가능한 사용자:** 회사 관리자

## 결제 그룹 설정

결제 그룹 설정에서는 라이선스 사용에 대한 포괄적인 개요를 볼 수 있습니다. 예를 들어 모든 기존 결제 그룹의 세부 정보, 사용자 수, 각 라이선스 유형별 수량, 할당된 경우 각 그룹에 할당된 [유연 할당량 제한](02-billing-groups-soft-quotas.md) 등이 포함됩니다. 검색 필드를 사용해 특정 결제 그룹을 빠르게 찾을 수 있습니다.

### 결제 그룹을 찾는 방법

결제 그룹 설정을 찾으려면 **회사** **설정** > **구독** > **결제 그룹**으로 이동하세요.

:::note
결제 그룹에 할당되지 않은 사용자는 기본 회사 결제 그룹에 자동으로 배치됩니다. 결제 그룹 설정 상단 배너에서 할당된 활성 사용자 수를 확인할 수 있습니다.
:::

## 결제 그룹 생성 방법

1. **회사 설정** > **구독** > **결제 그룹**으로 이동합니다.
2. 클릭 **결제 그룹 생성**.
3. 결제 그룹 이름을 입력합니다.
4. (선택 사항) 이 결제 그룹에 할당된 라이선스에 유연 할당량 제한을 설정하려면 표준 라이선스용 할당량 추가 또는 고급 라이선스용 할당량 추가를 선택하고 숫자를 입력하세요.
   유연 할당량 제한에 대해 더 알고 싶다면 이 글의 끝에 있는 자주 묻는 질문을 참조하세요.
5. 결제 그룹에 새 사용자를 추가하려면, 사용자 이메일 주소 목록이 포함된 CSV 파일을 업로드하거나 나중에 사용자를 할당할 수 있습니다.
6. (선택 사항) 결제 그룹의 연락처를 지정합니다. 연락처는 라이선스 사용 정보 문의에 이용됩니다.
7. **결제 그룹 만들기**를 클릭합니다.

## 결제 그룹 편집 방법

결제 그룹 이름을 편집하거나, 유연 할당량 제한을 설정 또는 업데이트하고, 결제 그룹의 연락처를 변경하며, 사용자들을 결제 그룹에 추가할 수 있습니다.

:::note
새 결제 그룹에 사용자를 추가하면 자동으로 이전 그룹에서 이동됩니다.
:::

1. **회사 설정** > **구독** > **결제 그룹**으로 이동합니다.
2. 결제 그룹 옆의 세 점 아이콘을 클릭하고 **편집**을 선택합니다.
3. 결제 그룹 속성을 편집합니다. 결제 그룹에 사용자를 추가하려면, 사용자 이메일 주소 리스트가 포함된 CSV 파일을 업로드하거나 나중에 사용자를 지정합니다.
4. **저장**을 클릭합니다.

## 결제 그룹 삭제 방법

1. **회사** 설정 > **구독** > **결제 그룹**으로 이동합니다.
2. 결제 그룹 옆의 세 점 아이콘을 클릭하고 **삭제**를 선택합니다.
3. 삭제를 확인합니다.
4. 이 결제 그룹에 속해 있던 모든 사용자는 메인 계정으로 지정되며, 어떤 결제 그룹의 멤버도 아니게 됩니다.

## 결제 그룹에 사용자 할당 방법

사용자는 조직 내에서 하나의 결제 그룹에만 소속될 수 있습니다.

1. **Company** 설정 > **Active users**로 이동하세요.
2. 사용자 옆의 세 점 아이콘을 클릭하세요.
3. **결제 그룹 변경**을 선택하세요.
4. 결제 그룹을 선택하고 **사용자 할당**을 클릭하세요. 사용자가 새 결제 그룹에 추가됩니다.

## 사용자를 결제 그룹에 일괄 할당하는 방법

여러 사용자를 한 번에 결제 그룹에 할당하세요.

1. **회사** 설정 > **활성 사용자**로 이동합니다.
2. 사용자를 수동으로 선택하거나 필터를 적용하여 한 번에 최대 50명까지 선택합니다.
3. **일괄 작업**을 클릭하고 **결제 그룹 할당**을 선택합니다.
4. 그룹을 선택하고 **사용자 할당**을 클릭합니다. 일부 사용자가 이미 다른 결제 그룹의 멤버인 경우, 이들을 선택 해제하거나 결제 그룹 할당을 변경할 수 있습니다.

## 결제 그룹에 있는 사용자를 확인하는 방법

결제 그룹에 포함된 사용자를 확인하여 사용자 접근과 결제를 더 효과적으로 관리합니다.

1. **회사** 설정 > **구독** > **결제 그룹**으로 이동합니다.
2. 특정 결제 그룹을 클릭하여 할당된 사용자를 확인합니다.

## 결제 그룹에서 사용자를 제거하는 방법

사용자가 특정 결제 그룹에 할당되지 않거나 제거되면, 자동으로 회사의 기본 계정 결제 그룹으로 이동합니다.

1. **회사** 설정 > **활성 사용자**로 이동합니다.
2. 사용자 옆의 세 점 아이콘을 클릭합니다.
3. **결제 그룹 변경**을 선택합니다.
4. **기본 계정 결제 그룹**을 선택합니다. 사용자는 결제 그룹에서 제거되어 회사의 기본 결제 그룹에 속하게 됩니다.

## CSV 파일을 통해 사용자에게 결제 그룹 할당하는 방법

사용자 이메일 주소가 포함된 CSV 파일을 업로드하여 여러 사용자를 결제 그룹에 할당할 수 있습니다. 사용자가 이미 다른 결제 그룹의 일부인 경우, 새로 할당된 결제 그룹으로 이동됩니다.

:::note
CSV 파일에 'email' 헤더가 하나의 열로만 되어 있는지 확인하세요. 이 열에는 결제 그룹에 추가할 이메일 목록이 포함되어야 합니다. 또한 CSV가 쉼표로 값을 구분하는지 확인하세요. 추가 열의 정보는 처리되지 않습니다. Miro는 CSV 파일을 저장하지 않습니다.
:::

1. **회사** 설정 > **구독** > **결제 그룹**으로 이동합니다.
2. 결제 그룹 옆에 있는 세 점 아이콘을 클릭하고 **편집**을 선택합니다.
3. 사용자 이메일 주소 목록이 포함된 CSV 파일을 업로드합니다.
4. **저장**을 클릭합니다.

## 결제 그룹에 SCIM을 통해 사용자 할당하는 방법

[SCIM](../../security-integrations/system-for-cross-domain-identity-management-scim/02-scim.md)을 설정하여 사용자들이 비용 센터에 따라 결제 그룹에 자동으로 할당되도록 하세요.

#### 2단계: ID 공급자(IdP) 구성

IdP가 Miro에 비용 센터를 추가하도록 설정되어 있는지 확인하세요. 가이드를 참조하세요:

- [OKTA를 사용한 자동 프로비저닝 설정](../../security-integrations/system-for-cross-domain-identity-management-scim/05-setting-up-automated-provisioning-with-okta.md)
- [Azure AD를 사용한 자동 프로비저닝 설정](../../security-integrations/system-for-cross-domain-identity-management-scim/03-setting-up-automated-provisioning-with-entra-id.md)

#### 2단계: 비용 센터를 결제 그룹에 할당하기

하나 이상의 비용 센터를 결제 그룹에 추가하세요. 이러한 비용 센터의 현재 및 미래 사용자들은 자동으로 결제 그룹에 참여하게 됩니다.

**비용 센터 추가 방법**

1. **결제 그룹 수정** 페이지를 엽니다.
2. **비용 센터 입력**란에 비용 센터를 입력하세요.
3. 키보드에서 **Enter** 키를 누릅니다.
4. 필요에 따라 추가 비용 센터를 추가합니다.
5. **저장**을 클릭합니다.

:::note
*Miro는 입력한 비용 센터 정보를 확인하지 않습니다. 비용 센터 이름을 정확히 입력하세요. 이 필드는 대소문자를 구분하지 않습니다.*
:::

### SCIM에서 관리되는 사용자의 배지

결제 그룹에 연결된 비용 센터가 할당된 사용자들은 **SCIM에서 관리됨**으로 표시됩니다. 이 배지는 사용자 이름 옆에서 확인할 수 있습니다.

이 사용자들은 결제 그룹에 수동으로 추가될 수 없으며, SCIM 업데이트를 통해서만 비용 센터에 할당될 수 있습니다.

### 비용 센터 및 결제 그룹 지침

- 하나의 결제 그룹에는 여러 비용 센터를 포함할 수 있지만, 하나의 비용 센터는 단 하나의 결제 그룹과만 연결될 수 있습니다.
- 비용 센터를 재할당하려면, 먼저 현재 결제 그룹에서 비용 센터를 제거해야 합니다.
- 비용 센터에 따라 결제 그룹에 할당된 사용자는 다른 결제 그룹에 수동으로 할당될 수 없습니다.
- 결제 그룹에서 비용 센터를 제거하면 그 결제 그룹에서 데이터를 받은 모든 사용자도 함께 제거됩니다.
- SCIM 프로비저닝이 되지 않은 사용자는 어느 결제 그룹이든 수동으로 할당될 수 있습니다.

### 결제 그룹에서 비용 센터를 제거하는 방법

1. **결제 그룹 편집** 페이지를 엽니다.
2. 제거하려는 비용 센터 옆의 **X**를 클릭합니다.
3. **저장**을 클릭합니다.

## 결제 그룹 데이터 내보내기 방법

기업 관리자는 **회사** 설정 > **활성 사용자**에서 사용자 목록이 포함된 CSV 파일을 내보낼 수 있습니다. 그런 다음 내보낸 CSV 스프레드시트에서 결제 그룹 속성을 사용하여 예산을 필터링할 수 있습니다.

## 자주 묻는 질문

내 사용자가 ID 공급자(IdP) 측에서 비용 중심을 변경하면 어떻게 되나요?

SCIM 업데이트 후:

- 이 새로운 비용 중심이 결제 그룹에 할당된 경우, 사용자는 자동으로 이 새로운 결제 그룹으로 이동합니다.
- 이 새로운 비용 중심이 결제 그룹에 할당되지 않았거나 IdP에서 사용자에게서 비용 중심이 제거된 경우, 사용자는 자동으로 기본 회사 결제 그룹으로 이동합니다.

SCIM을 결제 그룹에 도입한 후, 결제 그룹에 수동으로 할당된 사용자에게는 어떤 일이 발생하나요?

새로운 결제 그룹에 해당하는 비용 센터에 따라 자동으로 할당되며, 해당 비용 센터가 없거나 일치하지 않는 사용자는 현재의 결제 그룹에 남아 있습니다.

왜 더 이상 사용자를 결제 그룹에 수동으로 할당할 수 없나요?

SCIM 비용 센터를 통해 결제 그룹에 할당된 사용자는 다른 그룹으로 수동 이동할 수 없습니다.

IdP가 Miro로 비용 센터 속성을 동기화하지 않으면 어떻게 되나요?

새 사용자는 동기화된 비용 센터 없이 결제 그룹에 자동 할당되지 않지만, 동기화가 재개될 때까지 수동으로 할당할 수 있습니다.

결제 그룹의 유연 할당량 제한이란 무엇인가요?

유연 할당량 제한은 결제 그룹에 대해 Advanced, Standard, 또는 Full(과거 버전) 라이선스의 수를 선택적으로 제한할 수 있는 기능입니다.

결제 그룹을 생성하거나 편집할 때 **Standard 라이선스 할당량 추가** 또는 **Advanced 라이선스 할당량 추가**를 활성화하고 숫자를 입력할 수 있습니다.

유연 할당량 제한은 설정한 숫자와 소비를 나타내는 진행 표시줄로 결제 그룹 개요 상단에 표시됩니다.

유연 할당량 제한에 대해 더 알고 싶다면, [결제 그룹 유연 할당량 제한](02-billing-groups-soft-quotas.md)을 참조하세요.
