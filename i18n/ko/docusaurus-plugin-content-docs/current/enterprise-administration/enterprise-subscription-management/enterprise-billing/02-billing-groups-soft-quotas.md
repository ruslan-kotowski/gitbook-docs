## 개요

유연 할당량 제한은 결제 그룹의 새로운 UI 업데이트로, 관리자가 결제 그룹에 할당된 라이선스 수에 대해 선택적인 유연 제한을 설정할 수 있도록 합니다. 이 기능은 라이선스 할당을 관리하는 데 있어 더 큰 투명성과 실행 가능한 데이터를 제공합니다.

유연 할당량 제한은 결제 그룹 내에서 라이선스 할당을 관리하는 유연하고 유익한 방법으로, 관리자가 정보에 입각하여 결정을 내리는 데 필요한 데이터를 보장합니다.

## 유연 할당량 제한 설정

### 유연 할당량 추가하기

관리자들은 결제 그룹을 생성하거나 편집할 때 유연 할당량 제한을 설정할 수 있습니다. 이 제한은 할당된 라이선스 수와 사용 가능한 총 라이선스 수를 기준으로 합니다.
각 결제 그룹의 전체 유연 할당량 제한은 결제 그룹 개요 상단에 숫자 값과 진행률 바 형태로 표시됩니다.

유연 할당량 제한이 설정되면 결제 그룹 테이블에 표시됩니다.

### 시각적 지표

- **녹색 바:** 결제 그룹이 할당된 라이선스 제한 내에 있음을 나타냅니다.
- **빨간색 바와 경고 아이콘:** 결제 그룹이 할당된 라이선스 제한을 초과했음을 나타냅니다.

## 유연 할당량 제한 관리

### 제한 초과

유연 할당량 제한을 초과한다고 해서 라이선스 할당 방식에 영향을 미치지는 않습니다. 이는 관리자에게 투명성과 실행 가능한 데이터를 제공하기 위함입니다.

### 빠른 필터

관리자는 다음 기준으로 결제 그룹을 필터링할 수 있습니다:

- **설정된 할당량:** 유연 할당량 제한이 설정된 그룹 보기.
- **초과된 할당량:** 유연 할당량 제한을 초과한 그룹 보기.
