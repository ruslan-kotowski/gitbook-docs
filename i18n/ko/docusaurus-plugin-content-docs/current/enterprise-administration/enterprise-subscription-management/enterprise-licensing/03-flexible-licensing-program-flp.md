플렉시블 라이선싱 프로그램(FLP)은 가장 흔한 라이선스 모델입니다. FLP를 사용하면 사용량이 늘어남에 따라 라이선스가 확장됩니다. 조직의 필요를 예측해 사전 비용, 소급 비용, 계약 변경 없이 라이선스를 추가하거나 제거하세요.

[Enterprise 라이선싱](02-enterprise-licensing.md)에 대해 더 알아보기.

## 플렉시블 라이선싱 프로그램(FLP)이 작동하는 방식

정기적인 조정 주기에 따라 FLP 구독의 검토가 이루어집니다. 조정 주기가 가까워지면, 고객은 Miro 계정 팀과 함께 데이터를 기반으로 새로운 사용자 중 어느 정도가 앞으로 표준 또는 전체(이전) 라이선스를 필요로 하는지 논의하게 됩니다. 계약은 추가 라이선스로 수정되며, 소급 비용은 없습니다.

## FLP 라이선스 업그레이드

사용자는 표준, 전체(이전), Free, 제한된 무료 라이선스를 가질 수 있습니다. 특정 행동이 FLP 구독에서 라이선스 업그레이드를 촉발할 수 있습니다.

FLP에서 라이선스를 관리하는 방법에 대해 더 알아보세요. [여기에서](05-license-management-on-the-flexible-licensing-program-flp.md)

|  |  |  |  |
| --- | --- | --- | --- |
|  | **표준/** **전체 (구버전)** | **무료** | **무료 제한** |
| **업그레이드 옵션** | 이미 가장 높은 라이선스로 업그레이드됨 | **자동 업그레이드**됩니다. 다음의 경우 Standard 또는 Full (legacy) 라이선스로:   - 보드를 생성할 때 - 공유 보드를 편집할 때 - 보드 편집에 초대될 때 - 보드 공동 소유자로 지정될 때 - 편집자로 [스페이스](../../../using-miro/spaces/01-spaces.md) 에 추가될 때 | **라이선스 업그레이드 요청**이 사용자가 다음을 시도할 때 관리자에게 전송됩니다:   - 보드 또는 스페이스를 만들려고 할 때 - 편집 액세스 권한을 요청할 때 - 보드 편집 초대를 받을 때 - 보드 소유자가 될 때 |

:::warning
게스트는 자동으로 업그레이드되지 않습니다.
:::

## FLP 사용자 접근

각 사용자는 하나의 Enterprise 플랜 내에 여러 Miro [팀](../../../getting-started/start-here/miro-dashboard/04-profile-and-teams.md)에서 다양한 Miro 역할(멤버, 게스트, 또는 방문자)을 가질 수 있습니다.

Miro 역할과 라이선스 유형에 대한 자세한 내용은 [Enterprise 플랜의 사용자 액세스 수준](../../user-management/11-user-access-levels-on-enterprise-plan.md)을 참조하세요.

|  |  |  |  |
| --- | --- | --- | --- |
|  | **스탠다드** **풀 (레거시)** | **무료** | **제한된 무료** |
| **멤버** | **표준 또는 정식 (레거시) 라이선스를 가진 멤버는 다음을 수행할 수 있습니다:**   - 보드, 스페이스, 템플릿 만들기 - 공유된 보드 편집 - 팀과 공유된 보드 보기 | **무료 라이선스 멤버는 다음을 할 수 있습니다:**   - 스페이스와 보드에 추가될 수 있습니다 - 팀과 공유된 보드를 보고 댓글을 달 수 있습니다 - 자동으로 스탠다드 또는 풀(레거시) 멤버로 전환할 수 있습니다 | **제한된 무료 라이선스의 멤버 권한:**   - 스페이스와 보드에 추가 가능 - 팀에 공유된 보드를 보고 댓글 작성 가능 |
| **게스트** | 사용 불가 | **무료 라이선스의 게스트는 다음을 수행할 수 있습니다:**   - 공유된 보드 보기 및 댓글 작성     **무료 라이선스의 게스트는 다음을 수행할 수 없습니다:**   - 팀과 공유된 보드 생성 또는 보기 - 팀과 공유된 스페이스 보기 또는 참여 | **제한된 무료 라이선스의 게스트는 다음을 수행할 수 있습니다:**   - 보기 및 댓글 작성 |
| **방문자** | **방문자**는 Miro에 가입하거나 라이선스가 필요하지 않습니다.   - 방문자는 보드를 보고, 댓글을 달고, 편집할 수 있습니다 (일부 [제한 사항](../../../using-miro/sharing-boards/08-collaboration-with-visitors.md)이 있습니다) - 방문자는 팀 내에서 공유된 스페이스, 보드 또는 템플릿을 볼 수 없습니다 - 방문자는 팀, 팀원 또는 팀 및 회사 관리자 목록을 볼 수 없습니다 | | |
