엔터프라이즈 플랜 고객은 비유연적 또는 플렉시블 라이선싱을 선택할 수 있습니다. 당사의 라이선싱 옵션 및 구독 관리에 미치는 영향을 알아보세요.

:::note
고급 라이선스는 플렉시블 라이선싱 프로그램(FLP)에서 지원되지 않으며, 항상 비 FLP(하드 리미트) 모델로 운영됩니다. 조직에서 구매한 고급 라이선스 수만큼만 할당 가능합니다.

표준에 대해 FLP를 사용하는 조직은 계속 사용할 수 있으며 고급을 하드 리미트로 유지하여 혼합 라이선스 모델을 허용합니다: 표준은 FLP로 유지되고(무료 라이선스를 무제한으로 제공하고 무료 제한으로 다운그레이드), 고급은 구매한 라이선스 수량에 고정됩니다. 고급 기능이 필요한 사용자는 명시적으로 고급 라이선스를 할당받아야 하며(또는 조직의 업그레이드/요청 흐름을 따릅니다).
:::

## 라이선스 모델

### 플렉시블 라이선싱 프로그램 (FLP)

Miro Enterprise 플랜 고객에게 가장 일반적인 라이선스 모델은 [플렉시블 라이선싱 프로그램](03-flexible-licensing-program-flp.md)입니다. FLP를 통해 조직의 필요를 예측하고 추가 비용 없이 라이선스를 추가할 수 있습니다. 사용량이 증가함에 따라 라이선스가 확장됩니다.

Miro는 정기적으로 귀하와 연락을 유지합니다. 매년 두 번, 조직에 필요한 라이선스 수를 재평가할 수 있으며, 필요하지 않은 라이선스를 제거할 수 있습니다. 소급 청구되지 않습니다.

- Standard 또는 Full (legacy) 라이선스 무제한
- 무료 라이선스 무제한
- Standard 또는 Full (legacy) 라이선스로 자동 업그레이드
- 외부 게스트 편집 가능

FLP는 모든 새로운 사용자에게 무제한 무료 및 제한된 무료 라이선스를 제공합니다.

:::note
외부 게스트란 회사 도메인 외부의 게스트를 의미합니다. 이들은 외부 회사 이메일 주소를 가집니다.
:::

### 비플렉시블 라이선스(비-FLP)

비플렉시블 라이선스 모델은 사전 지정된 라이선스 수에 대해 연간 청구되며, 사용 가능한 라이선스가 소진되면 추가 라이선스를 구매해야 합니다(주로 주문서를 통해).

제한된 무료 [라이선스](04-free-restricted-license.md)로 새 사용자가 가입할 때, 비FLP 구독의 라이선스가 모두 소비되면 모든 신규 사용자는 제한된 무료 라이선스로 가입하게 됩니다. 이러한 사용자는 추가 라이선스를 구매하거나 다른 회원을 제거하여 라이선스를 해제하면 다른 유형의 라이선스로 전환할 수 있습니다.

- Standard 또는 Full 라이선스는 제한됩니다
- 모든 추가 라이선스는 제한된 무료 라이선스입니다
- 게스트는 보기와 댓글만 가능합니다

## 라이선스 모델 개요

|  |  |  |
| --- | --- | --- |
| **라이선스 유형** | **비유연한 라이선스(non-FLP)** | **플렉시블 라이선스 프로그램(FLP)** |
| **고급** | 정해진 계약 라이선스 수. | 정해진 계약 라이선스 수. |
| **표준** | 정해진 계약 라이선스 수. | 무제한 사용. |
| **풀 (레거시)** | 설정된 수의 계약 라이선스. | 무제한 사용. |
| **무료** | 이용 불가 | **FLP** 플랜의 무료 라이선스는 관리자와 사용자에게 더 많은 유연성을 제공합니다. 사용자가 다음 작업을 수행할 때 이 라이선스는 자동으로 스탠다드 또는 풀(레거시) 라이선스로 업그레이드됩니다:    - 보드 만들기 - 보드 공동 소유권 부여받기 - 보드 편집 - 보드 편집 초대 - [프로젝트](../../../using-miro/sharing-boards/16-projects.md)에 편집자로 추가됨 |
| **제한된 무료** | **제한된 무료** 라이선스는 구독에 있는 유료 표준 또는 **전체** (레거시) 라이선스가 부족할 때만 신규 사용자에게 할당됩니다.  제한된 무료 라이선스에서는 사용자 액세스가 제한됩니다. | **제한된 무료** 라이선스는 회사 관리자가 언제든지 수동으로 할당할 수 있으며, 신규 사용자에게 기본* 라이선스로 할당할 수도 있습니다.  제한된 무료 라이선스에서는 사용자 액세스가 제한됩니다. |
| **게스트** | 댓글 및 보기 가능. | 외부 게스트는 (Miro에서 허용하는 경우 팀 설정에서 활성화하면) 편집할 수 있습니다. |

* 기본 라이선스 설정 및 라이선스 변환에 대한 자세한 내용을 보려면 [플렉시블 라이선싱 프로그램의 라이선스 관리](05-license-management-on-the-flexible-licensing-program-flp.md)를 참조하세요.
