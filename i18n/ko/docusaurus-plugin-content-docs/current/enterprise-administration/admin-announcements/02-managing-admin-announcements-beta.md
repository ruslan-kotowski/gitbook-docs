"공지" 페이지를 사용하여 모든 공지를 확인하고, 상태를 추적하며, 전체 수명 주기에 걸쳐 관리하세요.

## 공지 확인 및 이해

**관리 콘솔 > 조직 > 공지**로 이동합니다. 공지 테이블은 모든 공지의 개요를 제공하며, 이름, 상태, 날짜, 대상자, 크리에이터 등이 포함됩니다.

## 공지 상태

| 상태 | 설명 |
| --- | --- |
| **초안** | 저장되었지만 아직 게시되지 않음. |
| **예약됨** | 게시되었으며 나중에 표시되도록 설정됨. |
| **라이브** | 현재 사용자에게 표시됨. |
| **종료됨** | 종료 날짜 이후로 더 이상 활성화되지 않음. |
| **취소됨** | 시작 날짜 이전에 중지됨. |

## 공지 업데이트

### 공지 편집

1. **공지**로 이동합니다.
2. 공지를 선택합니다.
3. **편집**을 클릭합니다.
4. 공지 내용을 업데이트합니다.
   메시지, 링크 텍스트, 링크 URL, 대상, 일정, 우선순위를 업데이트할 수 있습니다.
5. **게시**를 클릭합니다.
   변경 사항이 즉시 반영되며, 라이브 공지에도 적용됩니다.

### 공지 게시

1. 공지를 엽니다.
2. 세부 정보를 검토합니다.
3. **게시**를 클릭합니다.
   시작일이 미래일 경우 공지는 **예정**으로, 현재 또는 과거일 경우 **실시간**으로 전환됩니다.

## 공지 재사용

### 공지를 복제하기

1. 공지 목록에서 **작업** 메뉴를 엽니다.
2. **복제**를 클릭합니다.
3. 공지 세부정보를 업데이트합니다.
   필요에 따라 이름, 날짜, 대상자 혹은 다른 필드를 변경합니다.
4. **임시 저장** 또는 **게시**를 클릭합니다.
   **임시 저장**은 공지를 게시하지 않고 저장합니다.
   **게시**는 선택한 날짜에 따라 공지를 게시하거나 예약합니다.

## 공지 수명 주기 관리

### 공지 취소하기

1. 공지 목록에서 **작업** 메뉴를 엽니다.
2. **취소**를 클릭합니다.

공지 상태에 상관없이 공지를 취소할 수 있습니다. 공지는 더 이상 사용자에게 표시되지 않습니다.

### 공지 삭제

1. 공지 목록에서 **작업** 메뉴를 엽니다.
2. **삭제**를 클릭합니다.

공지가 영구적으로 삭제되며 복구할 수 없습니다.

## 변경 사항 추적

각 공지에는 수명 주기 및 업데이트 이벤트가 표시되는 기록 섹션이 포함되어 있습니다.

기록에는 다음과 같은 작업이 포함됩니다:

- 생성일
- 공개됨
- 편집됨
- 취소되었습니다

이러한 작업은 감사 로그에도 기록됩니다.
