프롬프트 차단 기능은 민감한 콘텐츠 관리자가 사용자가 민감한 정보를 포함한 AI 프롬프트를 제출하지 못하도록 차단할 수 있게 해 주며, 이를 통해 조직 전반에서 Miro AI에 민감한 데이터가 전달되는 것을 방지합니다. Miro는 사용자가 프롬프트 입력 창에 입력하는 텍스트와 보드에서 추가하는 텍스트 기반 콘텐츠를 스캔합니다. 해당 내용이 프롬프트 차단 구성에서 선택한 민감도 레이블 또는 소스 코드 패턴과 일치하면, Miro는 프롬프트 제출을 차단합니다.
