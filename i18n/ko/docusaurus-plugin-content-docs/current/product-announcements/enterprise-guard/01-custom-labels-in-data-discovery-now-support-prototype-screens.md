**데이터 검색**의 맞춤형 레이블이 이제 **프로토타입 화면**을 위젯 형식 조건으로 지원합니다. 관리자는 보드에서 프로토타입 화면이 감지되면 자동으로 레이블이 적용되도록 설정할 수 있으며, Jira 카드, Azure 카드, 코드 블록과 같은 다른 지원 위젯 유형과 함께 프로토타입 콘텐츠로 데이터 검색 범위를 확장할 수 있습니다.

이 업데이트로 관리자는 다음을 수행할 수 있습니다:

- 맞춤형 레이블의 조건을 정의할 때 프로토타입 화면을 포함합니다.
- 프로토타입 관련 콘텐츠를 포함하는 보드를 자동으로 식별합니다.
- 더 많은 보드 요소에 걸쳐 민감한 정보나 비즈니스상 중요 정보의 범위를 향상시킵니다.

자세한 내용은 [맞춤형 레이블](../../enterprise-administration/canvas-25-admin-features/data-discovery/08-custom-business-sensitive-data-discovery-overview.md)에 대한 문서를 참조하세요.
