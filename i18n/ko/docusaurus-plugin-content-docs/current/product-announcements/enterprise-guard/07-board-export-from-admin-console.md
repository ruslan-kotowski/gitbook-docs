관리자 콘솔에서 보드 내보내기가 이제 일반적으로 사용할 수 있게 되었다는 소식을 전해드리게 되어 기쁩니다. Enterprise Guard 관리자는 이제 관리자 콘솔에서 직접 보드를 내보낼 수 있어, 조직에서는 규정 준수, 거버넌스, 법적 요구 사항을 보다 간편하게 충족할 수 있습니다. 이 릴리스는 관리자가 추가 도구를 사용하지 않고도 직접 보드를 내보낼 수 있는 접근을 제공하며, 거버넌스 워크플로에 대한 더 나은 통제를 제공하고 규정 준수와 법적 준비를 간소화합니다.

또한, 보드 내보내기에 대해 일괄 다운로드 기능을 출시합니다. 보드를 개별적으로 다운로드하는 것 외에도, 관리자는 이제 모든 내보낸 보드를 하나의 아카이브로 다운로드할 수 있습니다. 이번 업데이트는 대규모 내보내기를 보다 쉽게 처리하고 보드 패키지를 구성하는 데 도움을 줍니다. 또한, 아카이브가 50GB 이상일 경우 자동으로 여러 파일로 분할해 지원합니다.
