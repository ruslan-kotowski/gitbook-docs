Miro AI 관리자 제어 기능을 사용하면 Enterprise 플랜의 회사 관리자(Company Admin)가 조직에서 어떤 AI 기능을 사용할 수 있는지 결정하고, 사용 권한을 관리할 수 있습니다. 또한 관리자들은 각 AI 기능을 작동시키는 모델도 확인할 수 있습니다. Enterprise Guard 애드온과 함께하면, Miro AI 제어 기능은 각 기능 범주 내에서 개별 기능 수준까지 확장되어, 조직의 요구와 보안 요구 사항에 따라 기능 우선순위를 설정하는 데 도움이 됩니다. 전체 Miro AI 기능 범주뿐 아니라, 개별 Miro AI 기능도 활성화, 제한, 비활성화할 수 있습니다. 예를 들어, 이미지 카테고리 내에서 AI로 이미지 만들기 기능을 활성화하고 배경 제거 기능을 끌 수 있습니다. 이러한 제어 기능을 활용해 안전하게 AI를 도입하고 보안 요구 사항을 충족하면서 AI 기능 활용을 촉진할 수 있습니다.
