민감한 콘텐츠 관리자는 이제 데이터 검색 스캔을 구성할 때 특정 레이블을 쉽게 활성화하거나 끌 수 있어, 조직의 요구에 맞게 결과를 조정할 수 있습니다. 예를 들어, GDPR 레이블에만 집중할 수 있습니다. 스캔 기본 설정을 저장하면 선택에 따라 스캔이 자동으로 업데이트됩니다. 이는 관리자에게 스캔 결과에 대한 더 큰 제어 권한을 부여하고 관련 없는 발견에서 발생하는 소음을 줄이는 데 도움이 됩니다.
