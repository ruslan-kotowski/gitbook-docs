User Groups 기능은 관리자가 사용자 그룹을 생성하고 이를 ID 공급자와 동기화할 수 있도록 해줍니다. 관리자는 팀에 그룹을 할당하고 특정 콘텐츠에 대한 그룹 접근 권한을 부여할 수 있습니다.

팀 멤버는 User Groups를 활용하여 다른 그룹과 보드를 공유할 수 있으며, 특정 사용자 그룹만 콘텐츠에 접근할 수 있도록 보장합니다. 새로운 사용자와 보드를 다시 공유하는 대신 적합한 User Group에 사용자를 추가할 수 있습니다.

## 주요 기능

- **사용자 그룹 생성 및 관리**
  관리자 콘솔에서 회사 관리자가 사용자 그룹을 생성, 검토, 편집, 멤버 추가, 삭제할 수 있습니다. 자세한 내용은 [사용자 그룹](../../enterprise-administration/user-management/08-user-groups.md)을 참조하세요.
- **보드 및 스페이스를 사용자 그룹과 공유**
  팀 멤버는 [임의의 보드 및 스페이스를 사용자 그룹과 공유](../../enterprise-administration/user-management/08-user-groups.md)하고, 권한을 설정할 수 있습니다.
- **API로 사용자 그룹 관리**
  사용자 그룹 API는 관리자가 사용자 그룹을 프로그래밍 방식으로 생성, 편집, 삭제할 수 있게 합니다.
- **댓글에서 사용자 그룹 언급**
  사용자 그룹을 보드에서 언급하면 그룹의 모든 사용자가 알림을 받습니다.
- **보드에서 사용자 그룹 멤버 확인**
  보드에서 그룹을 언급할 때 사용자 그룹의 모든 멤버를 확인하고 검토할 수 있습니다.
