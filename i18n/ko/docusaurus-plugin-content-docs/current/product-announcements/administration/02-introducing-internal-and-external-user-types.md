관리자는 이메일이 인증된 사용자를 내부 사용자로, 이메일이 인증되지 않은 사용자를 외부 사용자로 식별할 수 있습니다. 이러한 내부 및 외부 사용자 유형 간의 시각적 구분은 향후 관리자가 사용자 관리를 강화하는 기능적 개선으로 이어질 것입니다. 자세한 내용은 [도메인 제어](../../enterprise-administration/canvas-25-admin-features/domain-control/01-domain-control.md)를 참조하세요.
