보드 내보내기를 더 효율적으로 관리할 수 있도록 추가적인 보드 내보내기 API 엔드포인트를 도입하고 있습니다. 조직 전체의 내보내기 작업을 목록으로 정리하고, 특정 내보내기 작업의 태스크를 보고, 내보내기 작업에 대한 다운로드 링크를 가져오고, 더 이상 필요하지 않은 내보내기 작업을 취소할 수 있습니다. 이 업데이트를 통해 내보내기 워크플로를 더 쉽게 모니터링하고 제어하며, 프로그램적으로 자동화할 수 있습니다.
