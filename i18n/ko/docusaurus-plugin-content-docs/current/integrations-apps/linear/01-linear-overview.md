Miro에서 제공하는 Linear 통합은 Miro 보드와 Linear 이슈 간의 원활한 양방향 동기화를 통해 협업 워크플로를 강화합니다. 이 통합을 통해 애플리케이션 간 전환 없이 Miro 내에서 Linear 이슈를 가져오고, 보고, 편집할 수 있습니다. 주된 목표는 이슈 관리를 간소화하여 프로젝트 워크플로가 항상 최신 상태로 유지되며 팀이 일치되고 생산성을 유지하도록 하는 것입니다.

## 주요 기능

Linear 통합은 다음 기능을 제공합니다:

- **Linear 이슈 가져오기:** 이슈를 Miro 보드로 가져와서 담당자, 프로젝트 또는 상태별로 이슈 피커를 사용하여 필터하세요.
- **새 이슈 생성:** Miro 보드에서 Linear 이슈를 직접 생성하세요.
- **Miro에서 이슈 편집:** 제목, 유형, 상태, 담당자, 마감일, 프로젝트, 태그, 설명 등 이슈 세부 정보를 편집하세요.
- **양방향 동기화:** Miro나 Linear에서 이슈에 대한 변경 사항이 자동으로 동기화됩니다.
- **시각적 이슈 조직화:** 이슈를 테이블, 타임라인, 컬럼 및 유저 스토리맵 레이아웃으로 배치하세요.
- **빠른 접근:** 소스 아이콘을 사용하면 원본 Linear 이슈를 한 번의 클릭으로 열 수 있습니다.
- **유연한 보기:** 이슈 세부 정보를 위해 측면 패널과 모달 창 보기 간 전환이 가능합니다.
- **시각적 구성:** 우선순위나 상태를 구별하기 위해 이슈에 색상을 지정할 수 있습니다.
- **안전한 접근:** Linear 계정으로 인증하여 Linear 접근 권한에 맞춘 권한을 사용합니다.
- **관리자 제어:** Miro 팀이나 조직에서 통합 접근 권한을 관리할 수 있습니다.

## 제한 사항

Linear 통합의 다음과 같은 제한 사항이 있습니다:

- **맞춤형 필드:** 통합은 Linear 이슈 내의 맞춤형 필드를 보기, 편집 또는 생성하는 것을 지원하지 않습니다.
- **열 위젯:** 열 위젯에서 이슈를 이동해도 Linear 이슈 상태가 업데이트되지 않습니다.
- **초기 동기화:** 큰 Linear 계정의 초기 동기화는 몇 분에서 몇 시간까지 소요될 수 있습니다.
- **설치 요건:**
  - Linear가 사전 설치되어 있지 않은 경우 마켓플레이스에서 설치해야 할 수 있습니다.
  - 조직에서 앱 설치를 제한하는 경우 관리자 승인이 필요합니다.
