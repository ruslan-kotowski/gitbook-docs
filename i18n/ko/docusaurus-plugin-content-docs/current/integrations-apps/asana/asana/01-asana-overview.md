Miro의 Asana 통합은 Miro 보드와 Asana 작업 간의 원활한 양방향 동기화를 가능하게 하여 협업 워크플로를 크게 향상시킵니다. 이 기능을 통해 Miro 환경 내에서 Asana 작업을 직접 가져오고, 보고, 편집할 수 있으므로 애플리케이션 간 빈번한 전환이 필요하지 않습니다. 이 통합의 주된 목표는 업무 관리를 간소화하여 프로젝트 워크플로를 지속적으로 업데이트하고 팀의 정렬과 생산성을 유지하는 데 있습니다.

## 주요 기능

Miro + Asana 통합은 데이터 일관성과 협업적 과제 관리를 강화하기 위한 견고한 기능 세트를 제공합니다:

- **Asana 작업 가져오기:** 특정 Asana 작업을 Miro 보드로 가져와 팀 진행 상황의 시각적 조직과 관리를 촉진합니다. 통합된 "티켓 선택기" 기능을 사용하면 과제 담당자, 프로젝트, 상태별로 작업을 필터링해 효율적으로 검색하고 선택할 수 있습니다.
- **새 작업 생성:** Miro 보드에서 직접 Asana에 새 작업을 생성하여 작업 시작 프로세스를 간소화할 수 있습니다.
- **Miro에서 Asana 작업 편집:** 통합 기능을 통해 Miro 보드 인터페이스에서 제목, 유형, 상태, 담당자, 기한, 프로젝트, 태그 및 설명을 포함한 Asana 작업 세부 정보를 직접 편집할 수 있습니다.
- **양방향 동기화:** Miro나 Asana에서 작업에 대한 변경 사항이 두 플랫폼 간에 자동으로 동기화되어 정보가 항상 최신으로 유지되고 정확하게 유지됩니다.
- **액션 숏컷:** 작업 선택기 열기 또는 새로운 작업 생성 시작을 빠르게 수행하기 위해 사용자 지정 가능한 액션 숏컷을 생성할 수 있으며, 워크플로 효율성을 높입니다.
- **프레임워크에서 작업 정리:** 가져온 Asana 작업은 Miro의 유연한 프레임워크 내에서 시각적으로 정리할 수 있으며, 예를 들어 테이블, 타임라인, 칼럼(이전의 칸반), 유저 스토리맵 레이아웃을 활용합니다. 이는 워크플로 또는 작업 상태 변화에 따라 직관적으로 드래그 앤 드롭하여 재배열할 수 있도록 합니다.
- **원본 Asana 작업 열기:** "Source" 아이콘을 통해 Miro 보드의 Asana 카드에서 직접 Asana 애플리케이션 내의 전체 작업 세부정보로 빠르게 이동할 수 있습니다.
- **세부 보기 전환:** 작업 정보를 표시할 때 측면 패널의 세부 보기와 모달 창을 오가며 유연하게 상호작용할 수 있습니다.
- **카드 색상 변경:** Miro 보드에 있는 Asana 카드는 색상으로 구분할 수 있어, 작업의 우선순위나 상태를 시각적으로 구분할 수 있습니다.
- **보안 접근:** 통합은 모든 사용자가 본인의 서드 파티 Asana 계정으로 인증해야 하며, 해당 사용자의 기존 Asana 권한에 따라 접근이 엄격히 관리됩니다.
- **관리자 제어:** 관리자는 Miro팀이나 조직 내에서 통합에 대한 접근 권한을 관리할 수 있습니다.

## 제한 사항

현재 Miro + Asana 통합 상태에 내재된 다음과 같은 제한 사항을 알고 있어야 합니다:

- **사용자 지정 필드:** 통합에서는 Asana 시스템에서 지원 및 활용되는 경우에도 Asana 작업 내에서 사용자 지정 필드를 보는 것, 편집하는 것 또는 생성하는 것이 지원되지 않습니다. 이는 Asana의 사용자 지정 필드에 크게 의존하는 팀들에게 눈에 띄는 기능적 제한을 나타냅니다.
- **열(이전의 칸반):** 열 위젯에서 Asana 카드 위젯을 이동하는 것이 Asana 카드의 상태를 업데이트 하지 않습니다.
- **초기 동기화 지연:** Asana 계정을 처음 연결한 후, 동기화 과정은 꽤 오랜 시간이 소요될 수 있으며, 특히 큰 규모의 Asana 계정일 경우 몇 분에서 몇 시간까지 걸릴 수 있습니다. 동기화가 완료되면 이메일로 알려드립니다.
- **관리자 요구사항:** 많은 경우, Asana는 조직 차원에서 미리 설치됩니다. 그렇지 않은 경우, 사용자 또는 관리자가 마켓플레이스에서 앱을 직접 설치해야 합니다. 팀이나 조직 차원에서 설치되면, 개별 팀원들이 통합 기능을 사용할 수 있습니다.

  조직에서 앱 설치를 제한하면, 앱 사용 전에 관리자의 승인이 필요합니다.
