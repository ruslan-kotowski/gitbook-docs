스마트 스크린샷을 사용하면 Miro 보드와 위젯을 Microsoft Word, PowerPoint, Excel에 이미지로 직접 붙여넣을 수 있으며, 콘텐츠를 동기화 상태로 유지하는 향상된 기능을 제공합니다.

## Miro 스마트 스크린샷

:::note
귀하의 Microsoft 관리자가 조직 또는 팀을 위해 [Miro Microsoft Office 애드온](https://miro.com/marketplace/microsoft-office/)을 설치해야 할 수 있습니다. 사용할 수 없는 경우 관리자에게 문의하세요.
:::

Miro 측면 패널 통합을 사용하면 문서를 나가지 않고도 Miro 보드 콘텐츠를 Microsoft Word, PowerPoint, Excel 파일에 직접 임베드할 수 있습니다. 이 기능은 Miro 보드에 원활하게 액세스할 수 있게 해주며, 향상된 기능으로 시각적 콘텐츠를 삽입할 수 있도록 도와줍니다.

## Miro 측면 패널

Microsoft Word, PowerPoint, Excel의 Miro 측면 패널에는 다음과 같은 기능이 포함되어 있습니다:

- **보드 직접 액세스:** Miro 보드를 애플리케이션 전환 없이 Microsoft Word, PowerPoint, Excel에서 직접 액세스하세요.
- **보드 선택:** "임베드할 Miro 보드 선택" 버튼을 사용해 사용할 수 있는 Miro 보드 중에서 선택하세요.
- **인터랙티브 프리뷰:** Miro 보드에서 특정 콘텐츠를 삽입하기 전에 보고 선택하세요.
- **정확한 배치:** 문서 내 커서가 위치한 곳에 콘텐츠를 정확히 삽입하세요.
- **스마트 기능:** 임베드된 콘텐츠는 원본 Miro 보드와의 연결을 유지합니다.

## Miro 측면 패널 사용 방법

1. Microsoft Word, PowerPoint, Excel 파일에서 Miro 콘텐츠를 삽입하려는 위치에 커서를 배치하세요.
2. **Miro 통합 아이콘**을 클릭해 오른쪽 패널을 여세요.
3. **임베드할 Miro 보드 선택**을 클릭해 사용할 수 있는 Miro 보드를 선택하세요.
4. 보드 미리보기에서 임베드할 특정 영역, 프레임 또는 콘텐츠를 찾아 선택하세요.
5. 사용 가능한 드롭다운 옵션을 사용하여 다른 보기 설정 또는 선택 항목을 선택하세요.
6. **확인**을 클릭하여 커서 위치에 콘텐츠를 삽입하세요.

임베드된 콘텐츠는 문서에 원본 Miro 보드와 스마트 칩 연결로 스크린샷으로 표시됩니다.

:::note
Miro 측면 패널을 사용하려면 [Miro Microsoft Office 애드온](https://miro.com/marketplace/microsoft-office/)을 설치해야 합니다. 이 기능은 Microsoft Word, PowerPoint, Excel과 함께 작동합니다.
:::

## 애드온을 관리자 권한으로 관리하기

Miro 애드온을 관리하는 Microsoft 관리자라면 다음 사항을 검토하세요:

- Microsoft Office 애드온은 Microsoft 측에서만 설치하거나 제거할 수 있습니다.
- Microsoft Office 스마트 스크린샷에 대한 액세스를 제한하려면 Microsoft 측에서 진행해야 합니다. Miro는 사용자가 스마트 스크린샷을 설치하고 사용하는 것에 대해 제어할 수 없습니다.

## 자주 묻는 질문

**어떤 Microsoft Office 애플리케이션이 Miro 통합을 지원하나요?**

Miro 측면 패널은 Microsoft Word, PowerPoint, Excel과 함께 작동합니다.

**임베드된 Miro 보드 요소는 어떻게 업데이트 상태를 유지하나요?**

Miro 측면 패널을 통해 임베드된 콘텐츠는 원본 Miro 보드와의 연결을 유지합니다. 자동으로 동기화되지는 않지만, 임베드된 콘텐츠를 새로고침하여 Miro 보드의 최신 버전을 반영할 수 있습니다.

**Miro 측면 패널은 어떻게 작동하나요?**

Miro 측면 패널을 통해 문서를 나가지 않고도 Miro 보드에 직접 액세스할 수 있습니다. Miro 통합 아이콘을 클릭해 오른쪽 측면 패널을 열고, "임베드할 Miro 보드 선택"을 사용해 가능한 보드 중에서 선택하세요. 패널을 통해 문서에 삽입하기 전에 특정 영역이나 프레임을 미리 보고 선택할 수 있습니다.
