Microsoft Copilot 내의 Miro 에이전트는 인공지능 기능과 협업 워크플로를 연결하는 데 있어 중요한 발전을 보여줍니다. 이 통합 기능은 AI가 생성한 인사이트를 Miro 내에서 실행 가능한 공유 콘텐츠로 변환하여 조직이 AI 도구로부터 실질적인 비즈니스 가치를 입증하고 AI 결과물을 일상 워크플로에 원활하게 통합할 수 있도록 돕습니다.

## Copilot용 Miro 에이전트 이해하기

Microsoft Copilot 내의 Miro 에이전트는 Copilot의 AI 기반 정보를 Miro의 비주얼 협업 환경과 연결하여 협업을 강화하도록 특별히 설계되었습니다. 이는 사용자가 대화와 AI가 생성한 정보를 Miro 내에서 역동적인 협업 워크플로로 변환할 수 있도록 하는 중요한 연결 고리로 작용합니다.

조직은 AI 도구로 인한 실질적인 비즈니스 가치를 입증하거나, AI 산출물을 일상적인 워크플로에 통합하고, 초기의 열정과 파일럿 프로그램 이후에도 사용자 채택을 유지하는 데 자주 어려움을 겪습니다. Miro 에이전트의 설계는 이러한 과제를 직접적으로 해결하며, AI를 기업 워크플로 내에서 더 실용적이고 가치 있게 만들기 위한 전략적 솔루션을 제공합니다.

이 통합의 가치 제안에는 다음이 포함됩니다:

- **정보 접근 속도 가속화:** Microsoft Teams 및 Office 365 내에서 직접 관련 Miro 보드와 콘텐츠를 찾아 팀이 필요한 정보를 즉시 액세스할 수 있도록 보장합니다. 콘텐츠 검색에 소요되는 시간을 줄여 워크플로를 간소화하고, 의사 결정과 프로젝트 진행을 가속화합니다.
- **아이디어의 협업 워크플로로의 전환:** Microsoft 도구에서 생성된 AI 인사이트와 진행 중인 대화를 Miro 내에서 플로차트, 스티커 메모, 문서로 변환하세요. 에이전트는 AI 기반 이해와 인간 중심 협업 간의 격차를 메우는 Copilot의 인텔리전스를 위한 "액션 레이어" 역할을 합니다.
- **팀 연계성 강화:** 시각적, 공유된 컨텍스트를 AI 출력에 추가하여 팀이 아이디어에 맞춰 정렬하고, 변경 사항을 추적하며, 공통의 시각적 이해를 통해 더 효과적으로 함께 발전할 수 있도록 돕습니다.

## 주요 기능

Miro의 현재 Copilot 내 제공은 "선언형 에이전트"로 특징지어집니다. 이 설계는 사용자가 특정 명령 대신 자연어 프롬프트를 통해 원하는 결과를 명확하게 표현할 수 있도록 합니다. 에이전트는 이러한 프롬프트를 해석하고 필요한 작업을 실행하여 전문 기술 지식이 없는 사용자도 접근할 수 있도록 합니다.

현재 사용할 수 있는 주요 기능은 다음과 같습니다:

- **Miro 정보 적시:** Microsoft Teams와 Microsoft Word에 완벽하게 통합된 Miro 보드 및 콘텐츠를 찾아보세요. 예를 들어, 특정 회의에서 사용되었거나 설정된 기간 내의 보드를 찾아보고, 논의 중 관련 시각적 맥락이 쉽게 제공되도록 합니다.
- **아이디어를 Miro 콘텐츠로 전환하기:** Microsoft 도구의 대화와 AI로 생성된 인사이트를 문서, 다이어그램, 스티커 메모 같은 시각적인 Miro 포맷으로 변환하세요. 이로써 팀이나 Word에서의 비구조적인 논의를 Miro 내의 구조적이고 시각적이며 협력적인 포맷으로 전환합니다.

## Copilot용 Miro 에이전트 설정하기

Microsoft Copilot에서 Miro 에이전트를 사용하려면 먼저 Miro가 Microsoft Teams 계정에 연결되어 있고, Copilot에서 에이전트를 활성화해야 합니다. 초기 설정에는 Miro 계정을 연결하기 위한 일회성 인증 과정이 필요합니다.

### Miro를 Microsoft Teams에 연결하기 (사전 준비 단계)

Copilot에서 Miro 에이전트를 활성화하기 전에 Microsoft Teams에 Miro 애플리케이션을 추가하고 Miro 계정을 연결해야 합니다. 아직 이 작업을 완료하지 않았다면, 다음 단계를 따르세요:

:::note
Microsoft 관리자가 이 앱을 조직에 사용할 수 있도록 활성화해야 Teams에 추가할 수 있습니다.
:::

1. Microsoft Teams에서 **앱** 아이콘(보통 **+** 기호 또는 그리드 아이콘으로 표시됨)을 선택하세요.
   **앱** 패널이 열립니다.
2. 앱 패널 내 검색 표시줄에서 "Miro"를 검색하세요.
3. 검색 결과에서 Miro를 찾아 **추가**를 선택하세요.
   Miro 앱 설치 모달이 열립니다.
4. 모달에서 다시 **추가**를 선택하세요.
   Microsoft Teams 내의 Miro 앱 보기로 리디렉션됩니다.
5. Miro 앱 보기에서 안내에 따라 Miro 계정에 로그인하세요.
   로그인하면 Miro 계정이 Microsoft Teams에 연결됩니다.

   이제 Miro 앱을 Microsoft Teams에 성공적으로 추가하고 계정을 연결했습니다.

### Copilot에서 Miro 에이전트를 활성화하기

Miro가 Microsoft Teams에 연결되면, Microsoft Copilot 내에서 직접 Miro 에이전트를 활성화할 수 있습니다.

1. Microsoft Copilot에서 채팅 대화 상자를 찾아 플러그인 메뉴 아이콘을 선택하세요(이 아이콘은 퍼즐 조각 모양이나 플러그인을 나타내는 유사한 아이콘일 수 있습니다).
   **플러그인** 대화 상자나 패널이 열립니다.
2. 플러그인 대화 상자에서 "Miro"를 검색하세요.
3. Miro 에이전트를 목록에서 찾아 스위치를 **켜짐**으로 전환하세요.

   Miro 에이전트를 Microsoft Copilot에 성공적으로 활성화했습니다.

## Copilot용 Miro 에이전트 사용하기

설정을 완료하면 자연어 프롬프트로 Miro 에이전트를 사용하기 시작할 수 있습니다. 에이전트는 보드 제목과 메타데이터를 통해 검색하여 관련 콘텐츠를 찾는 데 도움을 줍니다. 다음은 에이전트와 상호 작용하는 몇 가지 예입니다:

- **주제별로 보드 찾기**
  예시 프롬프트: "Copilot 관련 보드 찾기" 또는 "프로젝트 계획 관련 보드 보여줘"
- **기간별로 검색**
  예시 프롬프트: "지난주에 생성된 보드 찾기" 또는 "최근 수정된 보드 보여줘"
- **대화를 변환하기**
  예시 프롬프트: "프로젝트 요구 사항에 대한 이 Teams 채팅을 Miro 다이어그램으로 전환하기"
- **시각적 콘텐츠 생성하기**
  예시 프롬프트: 회의 메모를 Miro 보드의 스티커 메모로 변환

**메모:** 처음 사용할 때 Miro 계정을 연결하려면 1회 인증 과정을 완료해야 합니다.

## 보안 및 규정 준수

Miro 에이전트는 Microsoft Copilot에서 엔터프라이즈 보안 및 규정 준수 요구 사항을 염두에 두고 구축되었습니다:

- **개인정보 보호:** 에이전트는 Microsoft의 기존 보안 프레임워크 내에서 작동하며 엔터프라이즈 데이터 처리 프로토콜을 따릅니다.
- **액세스 제어:** 사용자는 권한이 있는 Miro 콘텐츠만 액세스할 수 있으며, 기존의 보안 경계를 유지합니다.
- **인증:** 통합은 기존 Microsoft 및 Miro 인증을 활용하여 추가 신원 정보 관리 없이 안전한 액세스를 보장합니다.
- **규정 준수:** 이 솔루션은 조직의 기존 규정 준수 정책과 프레임워크 내에서 작동하도록 설계되었습니다.

IT 관리자는 표준 Microsoft 365 관리자 제어를 통해 Miro 에이전트를 관리할 수 있으며, 조직의 AI 도구 전체에 걸쳐 일관된 거버넌스를 보장합니다.

**추가 정보:** Microsoft Teams에서 앱을 추가하고 관리하는 방법에 대해 자세히 알아보려면 [공식 Microsoft 지원 문서](https://support.microsoft.com/office/add-an-app-to-microsoft-teams-b2217706-f7ed-4e64-8e96-c413afd02f77)를 참조하세요 (외부 링크).
