회사 관리자로서, Miro 조직 내 팀을 위해 Microsoft Copilot 통합을 활성화하고 승인할 수 있습니다.

Microsoft Copilot 통합을 통해 Miro에서 Copilot을 [지식](../../using-miro/miro-ai/09-knowledge.md) 자원으로 연결할 수 있습니다. 예를 들어, Microsoft Copilot을 연결하여 AI 팀원이나 워크플로에 회사 정보를 제공할 수 있습니다.

또한 Miro 내 독립형 채팅에 Copilot을 연결할 수 있습니다.

:::note
Microsoft Teams에서 Copilot과 함께 Miro 에이전트를 사용하는 방법에 대한 정보는 [Miro 에이전트 가이드](microsoft-teams/03-miro-agent-for-copilot.md)를 참조하세요.
:::

모든 팀 구성원은 통합 기능을 사용하기 위해 Copilot 라이선스를 보유해야 합니다.

Microsoft Copilot 통합을 활성화하려면 다음 단계를 따르세요:

1. 회사 관리자님은 **관리자 콘솔**로 이동하세요.
2. **앱 및 통합** > **앱** > **앱 추가**로 이동하세요.
3. **Microsoft Copilot**을 검색하고 찾습니다.
   앱 이름으로 찾을 수 없으면 다음 클라이언트 ID로 검색하세요: `5531308904693541040`.
4. 앱 프로필에서 **모든 팀**을 위한 앱을 추가할지, 아니면 **특정 팀**을 선택할지를 선택하세요.
5. (선택 사항) 권한 페이지를 검토하세요. Miro에서 개발 및 유지보수되는 Microsoft Copilot 앱은 특별한 권한이 필요 없습니다.
6. **추가**를 클릭합니다.

:::note
팀원이 최초로 Microsoft Copilot을 지식 리소스로 연결할 때, 인증이 요구됩니다. 팀원은 Copilot 라이선스를 보유해야 합니다.
:::
