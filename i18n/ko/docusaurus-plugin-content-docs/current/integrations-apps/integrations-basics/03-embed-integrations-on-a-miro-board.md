## 주요 기능

Miro의 임베디드 콘텐츠에는 다음과 같은 주요 기능이 포함됩니다:

- **통합 UX 및 스마트 링크**
  동일한 단계에 따라 타사 통합을 임베드하세요.
- **컨텍스트 메뉴**
  에셋 선택기를 사용하고, 집중 모드를 열고, 북마크 보기로 변경하세요.
- **인텔리전트 템플릿 액션 숏컷**
  단축키로 타사 도구의 데이터를 가져오는 템플릿 만들기

## Miro에서 서드파티 콘텐츠를 임베드하는 방법

다음 절차는 타사 통합에서 콘텐츠를 임베드하는 방법을 설명합니다.

**필수 조건**

- 사용하려는 서드 파티 통합을 회사 관리자, 콘텐츠 관리자, 혹은 팀 관리자가 허용했는지 확인하세요.
- 임베드하려는 서드파티 콘텐츠에 대한 액세스 권한이 있는지 확인하세요.

조직 내 사용자를 위해 관리자가 통합 기능을 활성화하는 방법을 배우려면 [앱 관리](../../enterprise-administration/managing-apps-on-enterprise-plan/02-app-management.md)를 참조하세요.

**절차**

다음 중 하나를 수행하세요:

- [타사 통합](02-miro-apps-and-integrations-overview.md)에서 URL을 복사하여 Miro 캔버스에 붙여넣기
- **툴**을 생성 바에서 선택하세요. 임베드할 지원 서드파티 툴을 검색하고 선택하세요. 모달이 열리면 타사 URL을 입력할 수 있습니다.
- 제작 바에서 **툴**을 선택하세요. **업로드**를 검색하고 선택한 후, **URL을 통해 업로드**합니다.
- 대시보드에서 **+ 새로 만들기**를 선택한 다음 **임베드**를 클릭하세요.
- 보드에서 **스페이스** 사이드바의 **+**를 선택한 다음 **임베드**를 선택하세요.

  Miro를 처음 연결하는 경우 화면의 지침을 따르세요. 임베드하려는 콘텐츠에 액세스하려면 제3자 툴에 로그인해야 하거나 액세스를 요청해야 할 수 있습니다.

  Miro 보드에 타사 콘텐츠를 성공적으로 임베드했습니다.

## 통합을 위한 iFrame 컨텍스트 메뉴

iFrame 컨텍스트 메뉴는 임베드 위젯 위에 나타납니다.

![figma.png](../../../../../../docs/integrations-apps/integrations-basics/images/26673893830418_figma.png)

*iFrame 컨텍스트 메뉴입니다.*

iFrame 컨텍스트 메뉴에는 다음 옵션이 포함됩니다:

- **집중 모드**
  iFrame을 전체 화면으로 열어 집중하세요. 집중 모드에 들어가려면 확장 버튼을 선택하세요. 집중 모드에서 나가려면 **캔버스로 이동**을 선택하세요.
- **북마크 보기**
  iFrame을 북마크로 축소하여 나중에 확장할 수 있습니다. 북마크 보기에 접근하려면 세로 점 버튼을 선택한 다음, 동작 메뉴에서 **북마크 보기로 전환**을 선택하세요.
- **자산 선택기**
  다른 에셋 또는 모든 에셋을 선택해 임베드하세요. 예를 들어 Figma 프레임 또는 Power BI 차트를 임베드할 수 있습니다. 애셋 선택기를 열려면 세로 쪽 점 버튼을 선택한 다음 작업 메뉴에서 **원본에서 애셋 추출**을 선택하세요. 자산 선택기에서는 다음 통합을 지원합니다:
  - Figma 프레임 및 섹션
  - Google Slides
  - Looker 차트
  - MS Excel 탭
  - MS PowerPoint 슬라이드
  - MS Word 페이지
  - Power BI 차트

iFrame 설정 메뉴에는 추가 옵션을 열 수 있는 세로 점 버튼도 포함되어 있습니다.
