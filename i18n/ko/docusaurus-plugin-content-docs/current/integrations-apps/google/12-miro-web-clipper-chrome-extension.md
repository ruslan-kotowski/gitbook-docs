:::note
Miro Web Clipper는 2026년 2월 1일부터 설치 및 유지 관리가 중단됩니다. 이전에 설치한 사용자에게는 "현재 상태 그대로" 작동합니다.

이미지 업로드, 클립보드에서 붙여넣기 또는 캔버스로 드래그하여 Miro에 스크린샷을 추가할 수 있습니다.
:::

Chrome에서 웹 페이지를 캡처하고 최소한의 노력으로 Miro 라이브러리에 저장하세요!

### 확장 기능 사용하기

1. 웹사이트의 스크린샷을 Miro의 라이브러리에 바로 저장하고 싶을 때는 Chrome에서 **Web Clipper 아이콘**을 클릭해 확장을 열고, 스크린샷을 저장할 **팀**을 선택한 후 저장할 영역을 선택하세요: **보이는 영역**, **선택한 영역**, 또는 **전체 페이지**.

![Web_clipper_menu.jpg](../../../../../../docs/integrations-apps/google/images/21016020037138_Web%20clipper%20menu.jpg)
*Miro Web Clipper 메뉴*

2. 저장된 웹 페이지를 Miro 보드에 추가할 준비가 되면 보드를 엽니다. 이때, 보드는 스크린샷을 촬영할 때 선택한 팀에 속해야 합니다.

3. 생성 바에서 **툴, 미디어 및 통합**(**+**)**.**패널이 열립니다. **툴** 탭에서 Web Clipper를 검색하세요. **업로드**를 선택한 후 **Web Clipper**를 선택하세요.
저장된 스크린샷 갤러리가 열립니다. 필요한 스크린샷을 클릭하거나 드래그하여 보드에 놓을 수 있습니다.

![Miro_web_clipper.gif](../../../../../../docs/integrations-apps/google/images/21016020034962_Miro%20web%20clipper.gif)
*툴바의 Web Clipper*

Miro Web Clipper의 최대 잠재력을 활용하려면 다음을 확인하세요:

- Miro 프로필에 로그인되어 있어야 합니다 (확장 프로그램 아이콘이 활성화되어 있으면 로그인된 상태입니다)
- 확장 프로그램을 설치한 후 보드 웹 페이지가 열려 있는 경우 새로고침합니다 (한 번만 필요합니다)

:::warning
승인 인증이 필요한 페이지에서는 Web Clipper가 작동하지 않습니다.
:::

### 자주 묻는 질문

1. *스크린샷을 저장했는데 왜 Web Clipper 라이브러리에 나타나지 않나요?*
   - 스크린샷을 저장할 때 올바른 팀을 선택했는지 확인하세요. 스크린샷은 이 팀에 있는 보드의 Web Clipper 라이브러리에 속하게 됩니다.
   또한, 확장은 권한이 필요한 페이지에서는 작동하지 않는다는 점을 유의하세요.
   확장이 어떤 페이지에서도 작동하지 않으면, **확장을 제거하고 다시 설치**해 보세요.
