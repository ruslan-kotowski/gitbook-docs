Google Workspace™와 Miro를 연결하면 어느 위치에서든 비주얼 협업을 강화하여, 회의에서의 참여도 및 창의성을 높일 수 있습니다. 이 통합을 통해 Miro를 Google Drive, 문서, Meet, 및 Calendar와 연결할 수 있습니다.

## 주요 기능

Miro 애드온을 설치하면, 워크플로를 간소화하는 여러 가지 주요 기능을 활용할 수 있습니다:

- [Google Calendar](08-miro-for-google-calendar.md) 초대에 Miro 보드 추가하기.
- [Google Meet](09-miro-for-google-meet.md)에서 직접 보드를 보고 공동 작업하기.
- [Google 문서](10-smart-chips-smart-screenshots-for-google.md)에 Miro 스마트 칩을 통해 보드 미리보기 임베드하기.
- [Google Drive](05-google-drive.md)에 Miro 보드를 저장하기.
- [Google Chat](01-miro-for-google-chat.md)을 통해 알림을 받고, Miro 보드 링크를 펼치거나, Miro 보드를 생성합니다.

:::note
Google Workspace 관리자가 Miro 애드온을 귀하의 Google Workspace 조직이나 팀에 설치해야 할 수 있습니다. 사용 가능하지 않을 경우 관리자에게 문의하세요.
:::

## Miro 애드온 설치

Miro 애드온을 Google Workspace 제품에 연결하려면 먼저 설치해야 합니다. Google Docs 또는 달력의 사이드바에서 Miro 'M' 로고가 있는지 확인하여 애드온이 이미 설치되었는지 확인할 수 있습니다.

애드온을 설치하려면:

1. [Google 워크스페이스 마켓플레이스](https://workspace.google.com/marketplace/app/miro/1062019541050)로 이동합니다.
2. **설치**를 클릭합니다.
3. 애드온에 연결할 Google 계정을 선택합니다.

애드온이 설치되면 사이드바에 Miro 아이콘이 표시됩니다. 이는 설치가 성공적으로 완료되었음을 의미합니다.

## Google API 서비스 사용자 데이터 정책

Google 워크스페이스에서 Miro는 Google API에서 받은 정보를 사용함에 있어, [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)을 포함하여 제한적 사용 요구 사항을 준수합니다. Google 워크스페이스 API는 일반화된/비개인화된 AI 및/또는 ML 모델을 개발, 개선, 또는 훈련하는 데 사용되지 않습니다.

## 자주 묻는 질문

Google 워크스페이스용 Miro 애드온 설치에 대한 일반적인 질문에 대한 답변은 다음과 같습니다.

저는 Miro 관리자입니다. 제 조직을 위해 Miro 애드온을 어떻게 설치할 수 있나요?

Google 워크스페이스 관리자는 조직 내 사용자들을 위해 애드온을 설치하고 관리할 수 있습니다. 자세한 내용은 [Google 워크스페이스 마켓플레이스](https://support.google.com/a/topic/1056395?hl=en&ref_topic=27380)를 참고하세요.

왜 Miro 애드온을 설치할 수 없나요?

관리자가 애드온을 비활성화했거나 관리자에게 애드온을 설치하도록 요청해야 할 수도 있습니다.
