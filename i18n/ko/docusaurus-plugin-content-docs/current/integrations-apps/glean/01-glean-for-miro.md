주요 기능

Glean 통합은 기업 및 공공 지식을 Miro 워크플로에 직접 가져와 혁신 프로세스를 개선하고 관련 인사이트에 대한 빠르고 효율적인 접근을 제공하는 것을 목표로 합니다.

- **채팅 기반 인터페이스:** 대화형 채팅 인터페이스에서 Glean과 상호 작용하여 응답을 반복하고 출력을 세밀하게 조정할 수 있습니다.
- **인사이트 요약:** 작업과 관련된 인사이트 요약을 한 번의 클릭으로 작성하여 생산성과 의사결정을 향상시킵니다.
- **소스 탐색:** 정보를 생성하는 데 사용된 소스를 쉽게 검토하고 Miro에서 직접 원본 데이터를 내비게이션할 수 있습니다. 또한, 소스의 링크를 보고 복사하고, 이를 캔버스로 드래그 앤 드롭할 수 있습니다.

## Glean 통합 사용하기

관리자가 통합 설정을 완료하면, Miro 보드 내에서 Glean을 사용할 수 있습니다.

1. 생성 바에서 **도구, 미디어 및 통합** (**+**)을 선택하세요.
2. **Glean**을 검색하세요.
3. 앱을 처음 사용하는 경우 **Glean 연결**을 선택해 승인 절차를 시작하세요.
   SSO(통합 로그인) 승인을 위한 대화창으로 이동됩니다.
4. 채팅 기반 인터페이스를 사용하여 연결된 업무용 앱에서 질문하고 정보를 찾으세요.
   - 프롬프트를 수정하여 Glean의 응답을 세밀하게 조정하여 생성된 콘텐츠가 특정 요구 사항에 부합되도록 보장하세요.
   - 채팅 기반 인터페이스에서 소스로 직접 이동하거나 그것들을 캔버스로 드래그 앤 드롭하세요.
5. Glean의 응답을 보드에 직접 [Miro Doc](../../using-miro/formats/12-docs-in-miro.md)으로 변환하세요. 또는 **Miro AI로 생성**을 선택해 [스티커 메모](../../using-miro/essential-tools/14-sticky-notes.md) 또는 [다이어그램](../../using-miro/formats/diagramming/02-miro-diagrams.md)을 생성하세요.

:::note
**Miro AI로 생성하기**는 [Miro AI](../../using-miro/miro-ai)가 활성화된 경우에만 사용할 수 있습니다.
:::

## 제한 사항

- 현재 저희는 Okta, Azure, Google과 같은 SSO(통합로그인) 공급자를 지원합니다.
- 이 통합의 일부 기능은 베타 버전입니다.

## 피드백과 맞춤형 설정

- 통합을 개선할 수 있도록 앱의 피드백 메커니즘을 통해 피드백을 제공해 주시기 바랍니다.
- 조직에서 맞춤형 앱을 사용하는 경우, [Miro Developer Platform](https://developers.miro.com/)을 사용하여 Miro를 자체 대형 언어 모델(LLM)과 연결할 수 있습니다.
