Box와의 통합을 통해 Box 계정의 파일을 사용하여 Miro 보드에 추가하고, 이를 통해 추가 논의와 협업을 진행할 수 있습니다. 보드에서 토론을 진행하고, 이미지와 문서 위에 피드백을 표시하며, 사용자를 멘션하여 더욱 빠르게 반복하세요.

> **사용 가능 대상:** Personal 및 Enterprise Box 계정을 보유한 모든 사용자
> **사용 가능 환경**: 브라우저 버전, [데스크톱 앱](../../getting-started/apps-for-devices/05-desktop-app.md)

### 플러그인 설치하기

플러그인을 사용하려면 팀 차원에서 플러그인을 설치하고 Box 계정을 Miro에 연결해야 합니다. 플러그인은 마켓플레이스 또는 Miro 보드에서 설치할 수 있습니다.

:::warning
관리자 이외의 사용자는 **앱 및 통합** 설정에서 허용되지 않으면 앱을 설치할 수 없습니다.
:::

[Miro 마켓플레이스](https://miro.com/marketplace/box/?backUrl=%2Fmarketplace%2F)로 이동하여 **앱 가져오기**를 클릭하세요. 앱을 설치할 팀을 선택하라는 메시지가 표시됩니다. 설치를 완료할 팀을 선택하세요.

![install_Box_plugin.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591350930_install%20Box%20plugin.jpg)
*Box 플러그인 팀 선택하기*

보드에서 앱 설치하기:

1. 생성 바에서 **툴, 미디어, 통합**(**+**)을 선택합니다.**툴, 미디어, 통합** 패널이 열립니다.
2. **툴** 탭에서 **업로드**를 검색합니다.
3. **업로드** 패널에서 **Box**를 선택하세요.

![업로드 진입점.png](../../../../../../docs/integrations-apps/more-integrations/images/21537452824210_uploads-entry-point.png)
*툴바의 Box 아이콘*

팝업 창에서 **앱 받기**를 클릭하면 플러그인이 팀에 설치됩니다.

Box 계정을 Miro에 연결하려면 **업로드** 메뉴에서 **Box**를 선택하세요. Miro에서 Box를 처음으로 사용하는 경우 Box 계정을 승인하라는 팝업 메뉴가 표시됩니다.

![authorize_box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591352338_authorize%20box.jpg)
*Box 인증 창*

프로필의 [통합 페이지](https://miro.com/app/account/profile/integrations/)에서 Box 계정을 연결하거나 연결 해제할 수 있습니다.

![connect_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591356946_connect%20Box.jpg)
*Box를 Miro에 연결하기*

### 파일 추가하기

파일을 보드에 추가하려면 툴바에서 **업로드** 메뉴를 열고, **Box**를 클릭한 다음 Box 계정에서 문서나 사진을 선택하고 **선택**을 클릭하세요.

![Box에서 파일 추가.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019535297298_adding%20files%20from%20Box.jpg)
*Box에서 Miro 보드로 파일 추가하기*

보드에서 파일을 새로 고치려면 파일에서 **업데이트** 버튼을 클릭하세요.

![update_a_Box_file.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019535299218_update%20a%20Box%20file.jpg)
*Box 파일이 Miro 보드에 업데이트되었습니다*

### 플러그인 비활성화하기

팀의 플러그인을 제거하려면 팀 설정의 **앱 및 통합** 섹션에서 Box를 찾고 **팀 제거**를 클릭하세요.

![uninstall_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591362962_uninstall%20Box.jpg)
*팀 설정에서 Box 제거하기*

Box 계정의 연결을 끊으려면 프로필 [통합 페이지](https://miro.com/app/account/profile/integrations/)로 이동해 **로그아웃**을 클릭하세요.

![disconnect_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591364498_disconnect%20Box.jpg)
*Miro에서 Box 연결 끊기*
