OmniGraffle에서 Miro로 다이어그램을 쉽게 가져와 하나의 통합된 툴에서 협업을 시작하세요. OmniGraffle와 Miro는 서로 다른 객체 모델과 스타일링 시스템을 사용하기 때문에, 가져온 보드는 원본 파일과 정확히 같지 않을 수 있습니다. 가져온 후에는 포맷을 검토하고 조정해야 할 수 있습니다. 자세한 내용은 [Miro에서 OmniGraffle 객체 매핑 이해하기](#h_omni_mapping) 및 [알려진 제한사항](#h_omni_known_limitations) 섹션을 참조하세요.

## 시작하기 전에

- Miro에서 보드를 생성할 수 있는지 확인하세요.
- OmniGraffle 7.25.1(2025년 9월) 또는 그 이상의 버전을 사용하세요. 버전을 확인하려면 **OmniGraffle > About OmniGraffle**로 이동합니다.
- 숨겨진 콘텐츠와 레이어를 가져오기 전에 검토하세요. 숨김 및 레이어된 요소도 가져오며 보드에 나타납니다. 요소가 겹치는 경우 가져온 후 재배치하세요.
- 내보내기 전에 그라디언트 채우기를 단색으로 변환하세요. 그라디언트는 지원되지 않습니다.

## OmniGraffle 파일을 Miro 보드에 가져오기

1. OmniGraffle을 열고, 다이어그램을
   **.graffle Single File (Zipped)** 포맷으로
   내보내기하여 기기에 저장합니다.

   **참고사항:** 저희는
   **Single File (Zipped)** 포맷만 지원합니다.
   **Package** 및 **Legacy** 포맷은 지원
   불가합니다. 이전에 지원되지 않는 파일을 내보냈다면
   OmniGraffle에서 파일을 열고 나서
   **.graffle Single File (Zipped)** 포맷으로 다시
   내보내기할 수 있습니다.
2. 다이어그램을 추가하려는 Miro 보드를 엽니다.
3. **.graffle Single File (Zipped)** 포맷 파일을 Miro 보드 위로 드래그 앤 드롭합니다.

## 여러 OmniGraffle 파일을 Miro 대시보드로 일괄 가져오기

1. Miro 대시보드를 엽니다.
2. 오른쪽 상단에서 **+ 새로 만들기**를 클릭합니다.
3. **가져오기** > **OmniGraffle에서 가져오기**를 클릭합니다.
4. 가져오기 대화 상자에서 **가져올 위치**에 OmniGraffle 파일을 가져올 Miro 보드를 생성할 스페이스를 선택합니다.
5. **.graffle** 파일을 업로드 영역에 드롭하거나 **찾아보기**를 클릭해 컴퓨터에서 파일을 선택하세요.

   **참고:** 우리는 **싱글 파일(압축)** 포맷만 지원합니다. **패키지** 및 **레거시** 포맷은 지원하지 않습니다. 이전에 저장했던 지원하지 않는 내보낸 파일이 있다면, OmniGraffle에서 파일을 열고 **.graffle 싱글 파일(압축)** 포맷으로 내보내기 할 수 있습니다.
6. **[X]**개의 파일을 가져오려면 **가져오기**를 클릭하세요.
7. **보드를 가져오고 있습니다** 메시지가 나타나면 **대시보드로 돌아가기**를 클릭하세요.

### 가져오기 시작 후

- 가져오기는 백그라운드에서 실행됩니다.
- 새로운 보드는 처리 완료 후 가져오기 과정에서 선택한 스페이스에 나타납니다.
- 보드가 생성되면 해당 스페이스로 직접 연결되는 링크와 함께 이메일을 통해 알림을 받게 됩니다.

## 가져온 콘텐츠 확인

가져오기가 완료된 후 다음을 확인하세요:

- 예상된 수의 보드가 생성되었습니다.
- 콘텐츠가 읽기 쉽고 제대로 배치되어 있습니다.
- 연결선이 올바르게 연결되어 있습니다.
- 텍스트 형식이 예상대로 표시됩니다.
- 중요한 시각적 부분이 온전합니다.

시간이 지남에 따라 발전할 다이어그램의 경우, 더 나은 장기 편집 가능성을 위해 Miro의 기본 객체를 사용하여 복잡한 부분을 다시 구축하는 것을 고려하세요.

## 자주 묻는 질문 (FAQ)

여러 파일을 한 번에 가져올 수 있나요?

네, 가능합니다. **.graffle 단일 파일(압축)** 형식을 여러 개 한 번에 가져올 수 있습니다. 자세한 내용은 [여러 OmniGraffle 파일을 Miro 대시보드에 일괄 가져오기](#h_omni_bulk_import)를 참조하세요.

내 일괄 보드 가져오기는 어디에 있나요?

일괄 가져오기에서 생성된 보드는 [가져오기 과정](#h_omni_bulk_import) 중에 선택한 스페이스에 만들어집니다. 보드가 생성될 때 받은 이메일 알림의 링크를 클릭하여 빠르게 접근할 수도 있습니다. 마지막으로 가져오기 과정 중 스페이스를 지정하지 않았고 이메일 알림도 없을 경우, **가져온 파일** 스페이스에서 보드를 검색할 수 있습니다.

다이어그램이 가져온 후에도 정확히 똑같이 보일까요?

대부분의 경우 그렇지만 항상 그렇지는 않습니다. 글꼴, 연결선, 복잡한 형식이 가져올 때 변경될 수 있습니다. 자세한 내용은 [알려진 제한](#h_omni_known_limitations) 및 [Miro에서 OmniGraffle 객체 매핑 이해하기](#h_omni_mapping) 섹션을 참조하세요.

가져오기는 얼마나 걸리나요?

처리 시간은 파일 크기와 복잡성에 따라 다릅니다. 보드가 생성되면 스페이스로 가는 직접 링크를 포함한 이메일을 받게 되어 보드를 빠르게 액세스할 수 있습니다.

내 일괄 가져오기가 성공했는지 실패했는지 어떻게 알 수 있나요?

**일괄 가져오기가 성공한 경우**, 보드가 생성되면 이메일 알림을 받게 되며, 스페이스로 바로 접근할 수 있는 링크가 포함됩니다.

**일괄 가져오기가 실패한 경우**, 가져오기 오류가 발생한 파일에 대해 이메일로 안내받게 됩니다.

다음 단계:

- Miro 관리자나 Miro 지원 팀에 연락하여 이 오류에 대해 알리세요.
- 가능하면 문제 해결에 도움이 되도록 Miro 관리자에게 OmniGraffle 파일의 **수정된** 버전을 제공하세요.

가져오기를 실행 취소할 수 있나요?

가져오기는 실행 취소할 수 없습니다. 필요한 경우 생성된 보드를 삭제할 수 있습니다.

## 문제 해결

가져오기 메뉴에 OmniGraffle에서 가져오기 옵션이 보이지 않음

- Miro에서 보드를 만들 수 있는 권한이 있는지 확인하세요.
- 캐시를 지우고 브라우저를 새로고침한 후 다시 시도하세요.
- 기능이 귀하의 조직에 대해 활성화되어 있는지 회사 관리자에게 확인하세요.

파일이 업로드되지 않아요

- OmniGraffle 파일을 **.graffle 단일 파일(압축됨)** 포맷으로 내보냈는지 확인하세요.

  **참고:** 저희는 **단일 파일(압축됨)** 포맷만 지원합니다. **패키지** 및 **레거시** 포맷은 지원하지 않습니다. 지원되지 않는 형식으로 내보낸 파일이 있는 경우 OmniGraffle에서 파일을 열고 **.graffle 단일 파일(압축됨)** 포맷으로 내보내세요.
- 한 번에 여러 파일 대신 단일 파일을 업로드해 보세요.
- 큰 OmniGraffle 다이어그램은 더 작은 항목으로 나누세요.

이메일을 받지 못했습니다

- [스팸 또는 필터로 분류된 받은편지함을 확인하세요.](../../using-miro/tools/troubleshooting/02-allowlist-miro-mailers.md)
- 새로 생성된 보드를 확인할 스페이스를 확인하세요.

레이아웃이 잘못되어 보입니다

- 폰트가 대체된 경우 폰트를 다시 적용하세요.
- 연결선이나 라인을 수동으로 다시 연결하세요.
- 필요한 경우 기본 Miro 도형을 사용하여 중요 부분을 편집하세요.

## 알려진 제한 사항

이 릴리스에서는 OmniGraffle 파일을 Miro로 가져올 때 두 플랫폼 간의 차이로 인해 구조, 스타일, 동작에서 차이를 발견할 수 있습니다.

### 도형 및 기하학 매핑

**제한 사항**

- OmniGraffle 도형은 Miro로 SVG 또는 커스텀 도형으로 가져와지며, Miro의 전환형 기능을 지원하지 않습니다. 도형이 인식되지 않고 대체 기하가 없는 경우, 기본적으로 사각형이 됩니다.

**해결 방법**

- 완전한 편집 및 QDC 지원을 복원하려면 가져온 후에 중요한 도형을 네이티브 Miro 도형으로 교체하세요.
- Miro의 내장 도형 및 프로토타이핑 라이브러리를 사용하여 다양한 도입 사례에 맞는 수백 개의 도형을 사용해보세요.
- 가져온 후 복잡한 다이어그램을 검토하고 기본 사각형으로 설정된 도형을 수동으로 조정하세요.

### 시각 충실도 및 스타일링

**제한 사항**

- 그라데이션은 지원되지 않습니다. 그라데이션 채우기는 가져오는 동안 평탄화됩니다.
- 그림자는 지원되지 않으며 가져오는 동안 제거됩니다.
- 지원되지 않는 폰트는 시스템 폰트로 대체됩니다.

**해결 방법**

- 내보내기 전에 단색 채우기를 사용하여 그라데이션을 대체하세요.
- 시각적 정밀도가 중요한 경우 내보내기 전에 OmniGraffle에서 그림자 효과를 제거하세요.
- 폰트 대체를 줄이기 위해 널리 지원되는 시스템 폰트를 사용하세요.
- 가져온 후 타이포그래피와 간격을 검토하고 Miro에서 스타일을 직접 조정하세요.

### 연결기 및 주석

**제한 사항**

- 라인 캡션이 가져온 후 올바르게 감지되거나 배치되지 않을 수 있습니다.
- 라인이 분할되거나, 약간 정렬이 맞지 않거나, 도형을 통과할 수 있습니다.
- 그룹화된 스텐실 도형 내 방향 화살표가 변환 중에 가끔 손실될 수 있습니다.

**해결 방법**

- 가져온 후 연결 라인의 텍스트 레이블을 수동으로 재배치하세요.
- 정렬 문제가 발생하면 Miro 연결기를 다시 연결하거나 경로를 수정하세요.

### 파일 포맷

**제한 사항**

- 우리는 **Single File (Zipped)** 포맷만을 지원합니다. **Package** 및 **Legacy** 포맷은 지원하지 않습니다.
- PNG 내보내기는 단순 이미지로 불러와 편집할 수 없습니다.

**해결 방법**

- **Single File (Zipped)** 내보내기 포맷을 사용하면 최상의 결과를 얻을 수 있습니다.
- 지원하지 않는 내보내기 파일이 저장되어 있는 경우, OmniGraffle에서 파일을 연 후 **.graffle Single File (Zipped)** 포맷으로 내보내기 하십시오.
- 편집 가능한 객체가 필요하면 PNG 내보내기를 피하십시오.

### 일괄 내보내기 동작

**제한 사항**

- 일괄 가져오기 시 이메일 알림이 하드 바운스 문제로 인해 가끔 실패할 수 있습니다.
- 일괄 가져오기가 완료된 후 가져온 콘텐츠가 즉시 보드에 나타나지 않을 수 있습니다.

**해결 방법**

- 알림이 수신되지 않으면 스팸 또는 이메일 필터링 규칙을 확인하세요.
- 일괄 가져오기가 완료된 후 브라우저를 새로고침 하세요.
