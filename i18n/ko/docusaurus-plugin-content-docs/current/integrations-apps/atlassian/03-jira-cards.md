Jira 카드는 미로 보드 내에서 Jira 이슈를 직접 활용할 수 있게 해줍니다. 이 통합은 회고, 사용자 스토리 크기 조정, 백로그 우선순위 설정, 사용자 스토리 매핑 및 기타 팀 활동을 위한 협업 공간으로 Jira 이슈를 가져와 팀의 워크플로를 간소화합니다.

![Jira cards in user story mapping](../../../../../../docs/integrations-apps/atlassian/images/21017348097170_Jira%20cards%20in%20USM.png)

## 보드에 Jira 이슈 가져오기

보드에 Jira 이슈를 가져오는 방법은 두 가지입니다:

1. Jira 이슈 URL을 복사하여 보드에 붙여넣습니다.
2. 작성 툴바에서 **툴, 미디어 및 통합** (**+**) 아이콘을 클릭하고 **Jira 카드**를 선택한 다음, 하나 이상의 이슈를 선택하고 **추가**를 클릭합니다.

처음으로 이슈를 가져오는 경우, Jira 계정을 연결해야 합니다:

1. 나타나는 대화 상자에서 **인증**을 클릭합니다.
2. Jira 계정에 신원 정보로 로그인합니다.
3. Miro와 Jira 간의 연결을 승인합니다.

인증이 완료되면, Jira 카드 선택기에서 접근 가능한 모든 Jira 이슈를 볼 수 있습니다.

:::note
Jira 계정을 인증하지 않은 사용자는 담당자 아바타가 없는 간단한 카드 보기를 보게 됩니다.
:::

## 새로운 Jira 이슈 만들기

Miro에서 직접 Jira 이슈를 생성할 수 있는 두 가지 방법이 있습니다.

### Jira 앱을 사용하여 생성하기

1. 작성 툴바의 **Tools, Media and Integrations** (**+**) 아이콘을 클릭합니다.
2. **Jira Cards**를 선택합니다.
3. **Create issue**를 클릭합니다.
4. 필수 필드를 채웁니다.
5. **Create**를 클릭합니다.

### 기존 항목을 Jira 이슈로 변환하기

보드에 있는 기존 스티커 메모나 카드를 Jira 이슈로 변환할 수 있습니다.

1. 최대 50개의 스티커 메모나 카드를 선택하세요.
2. 컨텍스트 메뉴에서 **변환** > **Jira**를 클릭하세요.
3. 기본 값(이슈 유형, 우선순위, 담당자 등)을 설정하세요.
4. **변환**을 클릭하세요.

:::warning
참고:

- USM 작업 라인의 카드는 Jira 이슈로 변환할 수 없습니다.
- 변환 중, Miro 카드의 태그와 시작 날짜는 보존되지 않습니다.
- 변환 후에는 담당자 정보를 다시 설정해야 합니다.
:::

## Jira 이슈 보기 및 편집

:::warning
데스크톱 또는 모바일 앱에서는 Jira 카드 편집이 지원되지 않습니다.
:::

Jira 카드를 보는 두 가지 방법이 있습니다:

- 측면 보기
- 중앙 보기

### Miro에서 이슈 편집

1. **측면 패널 열기** 또는 **중앙 패널 열기** 아이콘을 클릭하세요.
2. 변경사항을 만드세요.
3. **업데이트**를 클릭하여 저장하세요.

### 이슈 상태 변경

1. **워크플로우** 아이콘을 클릭하세요.
2. 원하는 **상태**와 **댓글**을 선택하세요.
3. **업데이트**를 클릭하여 저장하세요.

### Jira에서 편집

1. 카드를 선택하고 **소스** 아이콘을 클릭하세요.
2. 새 브라우저 탭에서 Jira의 이슈를 편집합니다.
3. 변경 사항은 자동으로 Miro 카드에 동기화됩니다.

## Miro와 Jira 간 동기화

|  |  |
| --- | --- |
| **Jira 인스턴스 업데이트 vs Miro 카드 업데이트** | **업데이트 시기** |
| OAuth 1.0 및 OAuth 2.0을 통한 Jira 업데이트 | Miro Jira 카드는 [웹훅](https://help.miro.com/hc/articles/360017731113)을 통해 즉시 업데이트됩니다. |
| Miro에서 업데이트 | Miro Jira 카드는 즉시 업데이트되며 해당 Jira 이슈도 동시에 업데이트됩니다. |

## Jira 카드 맞춤화

### 카드 색상 변경

1. 하나 이상의 Jira 카드를 선택하세요.
2. 컨텍스트 메뉴에서 **채우기 색상**을 클릭하세요.
3. 원하는 색상을 선택하세요.

### 사용자 지정 필드 구성

1. 작성 툴바에서 **도구, 미디어 및 통합** (**+**) 아이콘을 클릭합니다
2. **Jira 카드**를 선택합니다.
3. **카드 구성**을 선택합니다.
4. 표시할 필드를 선택합니다.
5. **저장**을 클릭합니다.

:::note
필드에 대한 중요한 사항:

- 설정은 현재 보드에서만 적용됩니다.
- 기본 필드(담당자, 이슈 유형, 우선순위, 상태)는 제거할 수 없습니다.
- 필드에 값이 없거나 이슈 유형에 유효하지 않은 경우 필드가 표시되지 않을 수 있습니다.
- 일부 필드 유형(예: 색상 사용자 지정 필드)은 지원되지 않습니다.
:::

## Jira 이슈 검색

Jira 카드 선택기는 최근 작업을 먼저 보여주며, 여러 정렬 옵션을 제공합니다:

- 이슈 유형
- 우선순위
- 키
- 요약
- 담당자
- 상태

특정 이슈를 찾기 위해 키워드를 사용하거나 **Jira Query Language** (JQL)를 사용해 복잡한 검색을 수행하세요:

1. 검색창에서 **고급 검색** 토글을 선택하세요.
2. JQL 쿼리를 입력하세요.

결과는 쿼리에 따라 업데이트됩니다.
