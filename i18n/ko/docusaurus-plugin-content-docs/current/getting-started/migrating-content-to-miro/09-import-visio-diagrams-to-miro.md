MS Visio에서 다이어그램을 Miro로 손쉽게 옮겨 하나의 통합 도구에서 협업을 시작하세요.

가져온 다이어그램은 완전히 기능적이어서 필요에 따라 편집, 색상 변경, 이동, 디자인 변경이 가능합니다.

:::warning
가져온 다이어그램을 편집하는 것은 일방적입니다. Miro에서 변경한 내용은 Visio에 반영되지 않습니다.
:::

## Visio 다이어그램을 새 Miro 보드로 가져오기

개별 Visio 다이어그램을 가져오려면 이러한 단계를 따르세요. 가져온 다이어그램이 새 Miro 보드를 생성합니다:

1. Visio에서 내보내려는 다이어그램을 엽니다.
2. **파일** 메뉴를 선택하고 **다른 이름으로 저장**을 선택합니다. 위치를 선택하고 파일을 `.vsdx` 형식으로 저장하세요.
3. 가져오기를 시작하려는 Miro 보드로 이동하세요. 이것은 어떤 보드라도 될 수 있으며, 가져오기를 통해 새 보드가 생성됩니다.
4. 왼쪽 작성 툴바에서 **도형** > **더 많은 도형**을 선택한 다음, 도형 라이브러리 패널의 오른쪽 상단에 있는 **다이어그램 가져오기** 아이콘을 선택하세요.
5. 나타나는 대화 상자에서 `.vsdx` Visio 파일을 드래그 앤 드롭하거나, **파일 선택** 버튼을 클릭하여 시스템에서 파일을 선택하세요.
6. **가져오기** 선택
   가져오기가 완료되면, **파일이 가져왔습니다** 대화 상자가 표시됩니다.
7. **보드로 이동**을 클릭하여 가져온 다이어그램을 포함하는 새 Miro 보드를 여세요.

## 일괄적으로 Visio 다이어그램 여러 개 가져오기

대시보드에서 Miro로 여러 Visio 다이어그램을 동시에 가져올 수도 있습니다. 각 다이어그램은 원본 파일 이름을 따서 명명된 새 Miro 보드로 가져옵니다.

1. [Miro 대시보드](https://miro.com/app/dashboard/)로 이동하세요.
2. **+ 새로 만들기** > **가져오기** > **다이어그램 가져오기**를 선택합니다.
3. `.vsdx` 파일을 지정된 영역으로 드래그하거나, **파일 선택** 링크를 사용해 여러 Visio 다이어그램을 선택하세요. 파일을 가져오기 전에 여전히 제거할 수 있습니다.
4. **파일 가져오기** 선택.
   가져오기가 완료되면 **파일 가져오기 완료** 대화 상자가 표시됩니다.
5. **완료** 선택하기.

이 작업은 각 다이어그램에 대해 원본 파일명으로 명명된 새 보드를 만듭니다.
