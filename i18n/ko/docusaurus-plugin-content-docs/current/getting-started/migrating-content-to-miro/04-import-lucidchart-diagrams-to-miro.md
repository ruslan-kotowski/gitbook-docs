Lucidchart에서 다이어그램을 Miro로 가져와서 팀과 협업하고 Miro의 다양한 기능을 활용할 수 있습니다. 이 가이드에서는 콘텐츠를 가져오는 두 가지 방법을 보여줍니다: Miro 보드에서 가져오기 또는 대시보드에서 직접 가져오기.

:::warning
가져온 콘텐츠를 편집하는 것은 일방적인 과정입니다. Miro에서 변경한 내용은 Lucidchart에 다시 동기화되지 않습니다.
:::

:::note
Free 또는 제한된 무료 라이선스가 있는 Lucidchart 보드를 마이그레이션할 수 있습니다.
:::

## Miro 보드에서 가져오기

Miro 보드에서 작업하면서 Lucidchart 다이어그램을 가져오려면 다음 단계에 따르세요.

1. Lucidchart에서 원하는 다이어그램을 **VSDX** 형식으로 내보내고 파일을 장치에 저장하세요.
2. 다이어그램을 추가하려는 Miro 보드를 여세요.
3. 왼쪽 작성 툴바에서 **도형** (![icon-shapes.svg](../../../../../../docs/getting-started/migrating-content-to-miro/images/25121485636114_icon-shapes.svg))을 클릭하고, **더 많은 도형**을 선택한 후, 다이어그램 작성 패널의 오른쪽 상단에서 **다이어그램 가져오기** 아이콘을 클릭합니다.
4. 가져오기 대화 상자에서 Lucidchart에서 내보낸 `.vsdx` 파일을 드래그 앤 드롭하거나, **파일 선택**을 클릭해 수동으로 선택하세요. 한 번에 여러 파일을 가져올 수 있습니다.
5. **가져오기**를 클릭하세요. 가져온 각 `.vsdx` 파일에 대해 새 보드가 생성됩니다.

> 대부분의 콘텐츠는 원활하게 전송되지만, 스타일링과 서식에 약간의 조정이 필요할 수 있습니다. 자세한 내용은 Lucidchart 오브젝트가 Miro에 나타나는 방식 섹션을 참조하세요.

## Miro 대시보드에서 불러오기

보드를 먼저 열지 않고도 Miro 대시보드에서 다이어그램을 직접 가져올 수 있습니다.

1. Lucidchart에서 다이어그램을 `.vsdx` 파일로 내보내려면 **파일 > 내보내기 >** `.vsdx`로 이동하세요.
2. Miro 대시보드로 이동합니다.
3. **새로 만들기** 버튼을 클릭하고, **가져오기**를 선택한 다음 **Lucidchart에서 가져오기**를 선택하세요.
4. 열리는 창에 `.vsdx` 파일을 드래그 앤 드롭하거나 **찾아보기**를 클릭해 선택하세요.
5. (선택 사항) **스페이스 선택** 드롭다운을 사용하여 가져온 보드의 [스페이스](../../using-miro/spaces/01-spaces.md)를 선택하세요. 하나를 선택하지 않으면 보드가 귀하의 주요 팀 스페이스에 추가됩니다.
6. **보드 만들기**를 클릭해 가져오기를 시작하세요.
7. 가져오기가 진행 중임을 확인하는 메시지가 표시됩니다. 새로운 Miro 보드가 준비되면 이메일 알림을 받게 됩니다.

## 제한 사항

Lucidchart와 Miro는 비슷한 기능을 제공하지만, 몇 가지 차이점이 있을 수 있습니다.

- Miro 텍스트 상자에는 공백을 포함하여 최대 6,000자까지 입력할 수 있습니다. 이 한도를 넘어가는 텍스트는 모두 잘립니다.
- Miro 스티커 메모는 회전, 색상 팔레트 조정 또는 텍스트 글머리 기호 기능을 지원하지 않습니다.
- 일부 도형 팩은 Lucidchart에서 사용할 수 있지만 Miro에서는 사용할 수 없습니다. 이 도형들은 여전히 ​​가져올 수 있으며, 사용자들은 이 도형들을 복제하고 편집할 수 있습니다. 그러나 Miro의 도형 라이브러리에서는 사용할 수 없습니다.
- Lucidchart에서 Miro로 댓글, 메모 및 주석을 가져올 수 없습니다. Lucidchart에서는 이를 내보내지 않기 때문입니다.

:::note
Lucidchart 이전에 대한 추가 질문 및 지원은 [Miro 지원](../../using-miro/tools/troubleshooting/06-contacting-miro-support.md)에 문의하거나 Miro 고객 성공 매니저에게 직접 문의하세요.
:::
