소스 애플리케이션에서 PDF 또는 VSDX 형식으로 다이어그램을 일괄 가져올 수 있습니다.

:::note
일부 소스 애플리케이션에서는 한 가지 파일 형식만 지원됩니다. 자세한 내용은 파일 형식 지원 확인을 참고하세요.
:::

## Miro로 다이어그램을 일괄 가져오는 방법

Miro로 다이어그램을 가져오려면 먼저 소스 애플리케이션에서 파일을 PDF 또는 VSDX로 내보냈는지 확인한 다음 아래 절차를 완료하세요.

1. 원하는 스페이스의 Miro 대시보드에서 다이어그램을 가져오려면 **새로 만들기** (**+**)를 클릭하세요.
   ![](../../../../../../docs/getting-started/migrating-content-to-miro/images/32654520716690_image.png)
2. **가져오기** > **\{source\}에서 가져오기**를 클릭하세요. 예: **Mural에서 가져오기**.
   **\{source\}에서 가져오기** 모달창이 열립니다.
3. 화면에 표시되는 지침을 따르세요.
4. (선택 사항) 가져올 스페이스를 변경하거나, 플러스 (**+**) 버튼을 클릭해 새 스페이스를 만드세요.
5. **가져오기** ***x*** **파일**을 클릭합니다.

## 파일 유형 지원

| 소스 | 파일 유형 |
| --- | --- |
| Conceptboard | PDF, VSDX |
| Lucidchart | PDF, VSDX |
| Lucidspark | PDF, VSDX |
| Mural | PDF |
| Visio | VSDX |
