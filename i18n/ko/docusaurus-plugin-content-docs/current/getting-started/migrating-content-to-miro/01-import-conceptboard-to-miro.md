Conceptboard의 콘텐츠를 Miro로 원활하게 마이그레이션하여 보다 강력한 협업 경험을 즐기세요. 이를 통해 작업을 통합하고 Miro의 광범위한 기능을 활용할 수 있습니다.

:::warning
가져온 콘텐츠를 편집하는 것은 일방적입니다. Miro에서 변경한 내용은 Conceptboard에 다시 동기화되지 않습니다.
:::

:::note
Free 또는 제한된 무료 라이선스의 Conceptboard 보드는 마이그레이션할 수 있습니다.
:::

## Conceptboard 보드 가져오기

Conceptboard 보드를 Miro로 가져오기 전에, Conceptboard에서 PDF 파일로 내보냈는지 확인하세요. 이를 위해 Conceptboard에서는 내보내려는 보드를 열고, **보드** > **내보내기**를 클릭한 다음, **보드를 PDF로 내보내기**를 선택하세요.

PDF 파일을 준비했으면 다음 단계를 따라 Miro에 가져오세요.

1. Miro **홈** 대시보드에서 **+ 새로 만들기**를 선택합니다.
   > 💡 보드를 열 때 사이드바에서 **새로 만들기** (**+**) 메뉴에 액세스할 수도 있습니다.
2. **가져오기**를 선택하거나 위로 마우스를 가져가세요.
3. **Conceptboard에서 가져오기**를 선택하세요. 가져오기 절차를 자세히 설명하는 화면이 열립니다.
4. **찾아보기**를 선택하여 파일 선택기를 열고 PDF 파일을 선택하거나, PDF 파일을 모달로 드래그 앤 드롭하세요.
5. **스페이스에 보드 추가**를 위해 드롭다운 메뉴에서 스페이스를 선택하세요.
6. **보드 가져오기** 선택 보드가 가져오는 중임을 알리는 창이 나타납니다. 가져오기가 완료되고 새로운 Miro 보드가 준비되면 이메일 알림을 받게 됩니다.

## Conceptboard 오브젝트가 Miro에 표시되는 방식

Conceptboard와 Miro는 비슷한 기능을 가지고 있지만, 가져오기 후 스타일 및 서식 지정 옵션에 차이가 있을 수 있습니다. 이 표는 일반적인 Conceptboard 객체가 Miro 객체로 번역되는 방식을 비교합니다:

| **강력한 Conceptboard** | **Miro** |
| --- | --- |
| 공동 작업자 및 공유 | 수동으로 재생성할 수 있습니다. |
| 댓글 | 수동으로 재생성할 수 있습니다. |
| 커넥터 | 커넥터 |
| 문서 | 🟠 수동으로 다시 생성할 수 있습니다 |
| 그리기 | 선 |
| 이미지 | 이미지 |
| 마인드맵 | 도형 및 커넥터 |
| 섹션 | 프레임 및 도형 |
| 도형 | 도형 및 이미지 |
| 스티커 메모 | 스티커 메모 |
| 테이블 | 테이블/도형 및 연결선 |
| 텍스트 | 텍스트 |
| 동영상 및 기타 URL | 수동으로 생성 가능합니다. |

## 제한 사항

가져오기 프로세스가 최대한 원활하게 진행되도록 하지만, Conceptboard에서 가져올 때 다음 제한 사항을 염두에 두세요.

- Miro 텍스트 상자에는 스페이스를 포함하여 최대 6,000자까지 입력할 수 있습니다. 이 한도를 넘어가는 텍스트는 모두 잘립니다.
- 색상과 불투명도 수준이 Miro의 가장 가까운 매치에 매핑됩니다.
- Miro 스티커 메모는 Conceptboard에 있었을 수 있는 회전이나 색상 팔레트 조정 기능을 지원하지 않습니다.

:::note
Conceptboard 이전에 대한 추가 질문은 [Miro 지원](../../using-miro/tools/troubleshooting/06-contacting-miro-support.md)에 문의하거나 Miro 고객 성공 매니저에게 직접 문의하세요.
:::
