Draw.io에서 생성한 다이어그램을 Miro로 쉽게 옮길 수 있어 하나의 통합 툴에서 협업할 수 있습니다. 가져온 다이어그램은 완전히 기능적으로 편집, 색상 변경, 이동, 재설계 모두 가능한 상태로 Miro 내에서 작업할 수 있습니다.

:::note
현재 Miro는 Lucidchart, MS Visio, 그리고 Draw.io에서의 다이어그램 가져오기만 지원합니다. 새 Miro 보드에만 다이어그램을 가져올 수 있으며, 기존 보드에는 가져올 수 없습니다.
:::

:::warning
가져온 다이어그램은 Miro에서만 편집할 수 있습니다. Miro에서 수행한 변경 사항은 원본 Draw.io 다이어그램에 반영되지 않습니다. Miro에서 직접 새로 편집 가능한 Draw.io 다이어그램을 만들려면, [draw.io diagrams 앱](../../using-miro/formats/diagramming/03-draw.io-diagrams-by-miro.md)을 사용하세요.
:::

## 새 보드로 Draw.io 다이어그램 가져오기

단일 Draw.io 다이어그램을 새 Miro 보드로 가져오려면 다음 단계를 따르세요:

1. Draw.io에서 다이어그램을 `.vsdx` 파일로 내보냅니다.
2. 다이어그램을 가져올 Miro 보드로 이동합니다.
3. 왼쪽의 작성 툴바에서 **도형 및 선**을 클릭하고, **더보기**를 선택한 후 **다이어그램 가져오기** 아이콘을 **다이어그램 작성** 패널의 오른쪽 상단에서 클릭합니다.
4. **새 보드로 다이어그램 가져오기** 대화 상자에서 `.vsdx` 파일을 드래그 앤 드롭하거나 **파일 선택** 버튼을 클릭하여 `.vsdx` 파일을 찾아 선택합니다.
5. 파일이 선택되면, **가져오기**를 클릭합니다.
6. 가져오기가 완료되면, **보드로 이동하기**를 클릭하여 다이어그램이 포함된 새 보드를 엽니다.

## 대시보드에서 Draw.io 다이어그램을 일괄 가져오기

여러 개의 Draw.io 다이어그램을 한 번에 Miro 대시보드에서 가져올 수도 있습니다. 각 가져온 다이어그램은 원본 파일 이름으로 새로운 Miro 보드를 생성합니다. 다중 가져오기는 대시보드에서만 가능합니다:

1. Miro 대시보드로 이동합니다: `https://miro.com/app/dashboard/`.
2. 오른쪽 상단에서 **+ 새로 만들기**를 선택합니다.
3. **가져오기**를 선택한 다음, **다이어그램 가져오기**를 선택합니다.
   **다이어그램 가져오기** 모달이 열립니다.
4. `.vsdx` 파일을 모달로 드래그하거나 **파일 선택** 링크를 사용합니다.
5. 가져오기가 완료되면 **완료**를 클릭하여 대시보드로 돌아가거나 **모든 보드 열기**를 클릭하여 다이어그램을 가져온 보드들을 실행합니다. 각 보드는 브라우저에서 개별 탭으로 열립니다.
