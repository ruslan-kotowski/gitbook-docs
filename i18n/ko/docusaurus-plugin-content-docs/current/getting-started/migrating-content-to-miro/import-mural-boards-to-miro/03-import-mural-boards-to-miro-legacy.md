이 글은 보관될 예정임을 유의하세요. Mural 콘텐츠를 Miro로 가져오는 최신 정보는 [Mural에서 Miro로 가져오기 가이드 – PDF](02-mural-to-miro-import-guide-–-pdf.md) 또는 [Mural에서 Miro로 가져오기 가이드 – 복사 및 붙여넣기](01-mural-to-miro-import-guide-–-copy-paste.md)를 참조하세요.
:::

> **사용자:** Mural과 Miro 모두에 편집 액세스 권한을 가진 사용자
> **플랜:** Free, Starter, Business, Education, Enterprise 플랜(복사 붙여넣기용); Starter, Business, Education, Enterprise 플랜(PDF로 일괄 가져오기용)
> **플랫폼:** 브라우저, 데스크톱

Mural에서 Miro로 콘텐츠를 매끄럽게 전송하여 익숙한 콘텐츠로 새로운 환경에서 협업을 계속할 수 있습니다. 이 가이드는 Mural 보드를 가져오는 두 가지 방법을 설명합니다: 콘텐츠를 직접 복사하고 붙여넣는 방법 또는 PDF 파일로 일괄 가져오기 기능을 사용하는 방법.

:::warning
가져온 콘텐츠를 편집하는 것은 일방적인 과정입니다. Miro에서 변경한 내용은 Mural에 동기화되지 않습니다.
:::

> 제한된 무료 라이선스 또는 풀 라이선스가 있는 Mural 보드는 다음 방법으로 Miro로 이전할 수 있습니다.

## Mural 콘텐츠를 복사해 붙여넣어 가져오기

Mural 보드의 콘텐츠를 직접 복사해 Miro 보드에 붙여넣을 수 있습니다. 이 방법은 개별 보드나 특정 콘텐츠 선택을 마이그레이션하는 데 적합합니다.

:::note
소스 Mural 보드와 대상 Miro 보드 모두에 편집 액세스 권한이 있는 사용자는 이 작업을 수행할 수 있습니다.
:::

1. 내보내려는 콘텐츠가 포함된 Mural 보드를 여세요.
2. 이동할 콘텐츠를 모두 선택하세요. 키보드 단축키 **Ctrl + A**(Windows) 또는 **커맨드 + A**(Mac)를 사용해 보드의 모든 항목을 선택할 수 있습니다.
3. 선택한 콘텐츠를 마우스 오른쪽 버튼으로 클릭하고 **복사**를 선택하거나, 키보드 단축키 **Ctrl + C** (Windows) 또는 **커맨드 + C** (Mac)를 사용하세요.
4. 기존 Miro 보드를 열거나 새 보드를 만들어 콘텐츠를 가져옵니다.
5. 미로 보드의 빈 영역을 마우스 오른쪽 버튼으로 클릭하고 **붙여넣기**를 선택하거나, 키보드 단축키 **Ctrl + V** (Windows) 또는 **Command + V** (Mac)를 사용하세요.
6. Miro 보드에서 가져온 콘텐츠를 검토하세요. Mural과 Miro 간에는 스타일 및 서식 옵션의 차이가 있을 수 있으므로 조정을 해야 할 수도 있습니다. 오브젝트 매핑에 대한 자세한 내용은 Mural 오브젝트가 Miro에 나타나는 방식(복사-붙여넣기) 섹션을 참고하세요.

## PDF 내보내기를 사용하여 Mural 보드를 일괄 가져오기

여러 Mural 보드를 이전하려면, Mural의 PDF 내보내기를 수용하는 Miro의 일괄 가져오기 기능을 사용할 수 있습니다.

> 이 일괄 가져오기 기능은 Starter, Business, Education, Enterprise 플랜 사용자에게 제공됩니다.

1. 내보내려는 Mural 보드에 액세스하세요.
2. 각 Mural 보드에 대해, **다운로드**를 클릭하고, 보드를 **PDF** 파일로 저장하세요.
3. Miro 대시보드를 여세요.
4. 오른쪽 상단 모서리에서 **+ 새로 만들기** 버튼을 클릭한 후, **가져오기**를 선택하세요.
5. 옵션에서 **Mural에서 가져오기**를 선택합니다.
6. 모달 창이 나타나면 **찾아보기**를 클릭하여 시스템의 파일 선택기를 열고 PDF 파일을 선택할 수 있으며, PDF 파일을 모달로 직접 끌어다 놓을 수도 있습니다.
7. (선택 사항) **보드를 스페이스에 추가** 드롭다운 메뉴를 사용해 보드를 가져올 Miro 내의 특정 [스페이스](../../../using-miro/spaces/01-spaces.md)를 선택하세요. 스페이스를 선택하지 않으면 보드가 기본적으로 메인 팀 영역에 추가됩니다.
8. **보드 가져오기** 버튼을 클릭해 가져오기를 시작하세요.
9. 모달 창에서 보드가 가져오는 중임을 알려줍니다. 가져오기가 완료되면 새 Miro 보드를 사용할 준비가 되었음을 알리는 이메일 알림을 받게 됩니다.
10. 가져온 후, 새 Miro 보드의 콘텐츠를 검토하세요. Murobject가 Miro에 나타나는 방법 (PDF를 통한 일괄 가져오기) 섹션을 참고하여 Murobject가 번역되는 방법에 대한 지침을 확인하세요.

## 제약 및 고려 사항

Miro는 가져오기 프로세스를 최대한 원활하게 처리하려고 노력하고 있지만, Mural에서 콘텐츠를 마이그레이션할 때 다음 제한 사항을 유의하세요.

- **텍스트 제한:** Miro 텍스트 상자에는 스페이스를 포함하여 최대 6,000자까지 입력할 수 있습니다. 이 한도를 넘어서는 모든 텍스트는 가져올 때 잘립니다.
- **스티커 메모 도형:** Mural의 원형 스티커 메모는 Miro에서 정사각형 스티커 메모로 변환됩니다.
- **색상 및 불투명도:** Mural의 색상과 불투명도 수준이 Miro에서 가장 적합한 매치로 매핑됩니다. 일부 시각적 차이가 발생할 수 있습니다.
- **스티커 메모 서식:** Miro 스티커 메모는 현재 회전, 기본 설정을 초과한 색상 팔레트 조정 또는 스티커 메모 내 텍스트 글머리 기호를 지원하지 않습니다.

### Mural과 Miro 콘텐츠 구조 비교

Mural과 Miro에서 콘텐츠가 조직되는 방식의 차이를 이해하면 더 효과적으로 마이그레이션 계획을 세울 수 있습니다.

|  |  |
| --- | --- |
| **뮈럴 요소** | **Miro 동등한 요소** |
| 워크스페이스:  - 회사 관리자에 의해 생성됨 - 팀 관리자에 의해 관리됨 | 팀  - 회사 관리자 작성 - 팀 관리자에서 관리 |
| 방:  - Mural 워크스페이스 내에서 사용자가 작성 - 사용자가 관리 | 스페이스:  - Miro 팀 내 사용자에 의해 생성 - 사용자가 관리 - 중첩될 수 없습니다 |
| 폴더:  - 사용자가 Mural 워크스페이스 내에서 생성했습니다. - 사용자 관리 - 룸에 중첩될 수 있습니다 | 프로젝트(조직에 사용할 수 있지만 Miro 스페이스는 팀 내 주요 컨테이너입니다). Miro에는 Mural의 방 내 중첩 폴더와 직접적으로 대응되는 기능이 없습니다. |
| 벽화 (보드):  - Mural 워크스페이스 내에서 사용자가 생성함 - 사용자가 관리 | 보드:  - Miro 팀 내 사용자 생성 - 사용자에 의해 관리됨 |
