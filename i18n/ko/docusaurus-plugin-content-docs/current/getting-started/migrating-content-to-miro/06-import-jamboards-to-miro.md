Jamboard의 아이디어와 프로젝트를 Miro로 쉽게 이전하세요. 워크플로를 보완하는 Miro의 강력한 기능을 써 보세요.

:::warning
가져온 콘텐츠를 편집하는 것은 일방적입니다. Miro에서 변경된 내용은 Jamboard로 다시 동기화되지 않습니다.
:::

:::note
풀 라이선스를 보유한 Miro 사용자만 Jamboard에서 Miro로 콘텐츠를 이전할 수 있습니다. [제한된 무료](../../enterprise-administration/enterprise-subscription-management/enterprise-licensing/04-free-restricted-license.md) 라이선스가 있는 Miro 사용자와 [게스트](../../using-miro/sharing-boards/07-collaboration-with-guests.md) 사용자는 Jamboard를 Miro로 이전할 수 없습니다.
:::

## Jamboard에서 Miro로 가져오기

해당 섹션은 Jamboard 파일을 Miro로 가져와 각 가져온 Jamboard마다 새 Miro 보드를 만드는 단계를 안내합니다:

1. Miro **Home** 대시보드에서 **+ 새로 만들기**를 선택하세요.
   > 💡 Miro 보드를 열었을 때 사이드바에서 **새로 만들기** (**+**) 메뉴에 액세스할 수도 있습니다.
2. 메뉴에서 **가져오기**를 선택하거나 마우스를 가져가세요.
3. **Jamboard에서 가져오기**를 선택합니다. 가져오기 절차에 대한 세부 정보가 포함된 모달 창이 열립니다.
4. **Jamboard 가져오기**를 클릭하여 계속합니다.
5. Google 계정에 로그인하고 Jamboard 이전에 Google 드라이브 액세스 권한을 승인하라는 메시지가 표시됩니다.
6. Google 승인이 완료되면 Google 드라이브에 연동되어 모든 Jamboard에 액세스할 수 있습니다. 가져오려는 Jamboard를 최대 10개 선택하고 **선택**을 클릭하세요.
7. 선택한 Jamboard의 모든 콘텐츠가 이제 Miro에 편집 가능한 형식으로 가져왔습니다. 가져오는 각 Jamboard마다 새 Miro 보드가 자동으로 생성됩니다.
8. 새로운 Miro 보드에서 가져온 콘텐츠를 검토하고 필요한 조정을 하세요. Miro는 다양한 기능을 제공하지만, 스타일 및 서식 지정 옵션은 Jamboard와 약간의 차이가 있을 수 있습니다. 가능한 변형에 대한 안내는 Miro에서 Jamboard 오브젝트 매핑 이해하기 섹션을 참조하세요.

## Miro에서 Jamboard 오브젝트 매핑 이해하기

이 표는 Jamboard의 오브젝트가 Miro에 보통 어떻게 가져오고 표현되는지를 종합적으로 비교해 보여줍니다.

|  |  |
| --- | --- |
| **Jamboard** | **Miro** |
| 브러쉬, 형광펜, 마커 | 도형 또는 스텐실 |
| 커넥터 | 커넥터 |
| 이모티콘 | 이미지 |
| 프레임 | 프레임 |
| 이미지 | 이미지 |
| 페이지 | 이미지 |
| 도형 | 도형 또는 스텐실 |
| 스티커 메모 | 스티커 메모 |
| 텍스트 | 텍스트 |

## 가져오기 제한 사항

Jamboard에서 가져올 때 몇 가지 기능상의 차이점과 제한 사항을 알고 있는 것이 중요합니다:

- Miro 텍스트 상자에는 스페이스를 포함하여 최대 6,000자까지 입력할 수 있습니다. Jamboard 텍스트 오브젝트의 추가 텍스트는 잘려나갑니다.
- Miro 스티커 메모는 Jamboard와 같은 회전, 색상 팔레트 조정 또는 텍스트 글머리 기호 기능을 지원하지 않으므로 일부 시각적인 차이가 발생할 수 있습니다.

## Jamboard 장치 전환 준비하기

Google이 Jamboard 장치를 단종하기 때문에, Miro를 사용한 협업을 계속하기 위한 전환과 지원되는 하드웨어 옵션에 관한 중요한 정보를 안내드립니다.

2024년 12월부터 Google은 Jamboard 55 장치 지원을 중단합니다. 협업을 계속하려면 2024년 현재 Miro를 지원하는 Google Meet Series One Board 65 및 Desk 27 장치로의 전환을 고려해 보세요.

:::tip
Jamboard 이전에 대한 추가 질문은 [Miro 지원](../../using-miro/tools/troubleshooting/06-contacting-miro-support.md)에 문의하거나 Miro 고객 성공 매니저에게 직접 문의하세요. 다른 Jamboard 이전 업데이트에 대한 알림을 받으려면 [등록 양식](https://miro-survey.typeform.com/to/f5EQKroq?typeform-source=www.google.com)에 연락처 정보를 입력해주세요.
:::
