사용자 지정 템플릿을 만들고 공유해 프로세스를 표준화하고 작업을 중복하지 않도록 하세요.

> 🚀  사용자 지정 템플릿을 전 세계와 공유하세요. [Miroverse에 게시](https://miro.com/miroverse/submission/?backToUrl=/)하고 6천만 명 이상의 사용자가 작업을 시작할 수 있도록 도와주세요.

> **해당 대상:**Starter, Business, Enterprise, Education 플랜 **사용 가능 대상:** 팀 멤버

## 맞춤 설정 템플릿 만들기

보드 전체에서 부터  보드의 모든 부분에서 처음부터

1. 템플릿으로 전환할 보드로 이동하세요
2. **내보내기** 아이콘을 클릭하세요.
3. **보드를 템플릿으로 저장을** 선택하고 선택적으로 템플릿 세부 정보를 업데이트한 다음 **저장을** 클릭하세요.

:::warning
[메모의](../../../using-miro/essential-tools/17-visual-notes.md) 콘텐츠는 사용자 지정 템플릿의 일부로 저장되지 않습니다.
:::

![export_menu_custom_templates_save_as_template.png](https://help.miro.com/hc/article_attachments/21857708174738)*내보내기 메뉴에 템플릿으로 저장 옵션*

1. 템플릿으로 저장하려는 [오브젝트 그룹을](../../../using-miro/working-on-the-board/10-working-with-objects.md) 선택하세요. 잠금 해제되어 있는지 확인하세요. 잠긴 오브젝트를 사용하려면 먼저 잠금을 해제하고 템플릿을 저장한 다음 편집 모드에서 다시 잠그세요.
2. 컨텍스트 메뉴에서 점 3개 아이콘을 클릭하세요.
3. **템플릿으로 저장을** 선택하고 선택적으로 템플릿 세부 정보를 업데이트한 다음 **저장을** 클릭하세요.

![save_objects_as_template_.jpg](https://help.miro.com/hc/article_attachments/21857709899538)*오브젝트의 컨텍스트 메뉴에 템플릿으로 저장 옵션*

1. 제작 툴바에서 **템플릿** 아이콘을 클릭하세요.
2. 템플릿 선택기에서 사용자 지정 템플릿 섹션으로 이동합니다.
3. 플랜(회사, 팀, 개인)에 따라 요구 사항에 맞는 옵션을 클릭하세요.
   > ✏️ 표시되는 옵션은 플랜에 따라 달라집니다. Starter 플랜에는 사용자 지정 템플릿에 "개인" 및 "팀" 옵션이 표시됩니다.
   > Business, Enterprise, Education 플랜에서 "회사", "팀" 및 "개인" 옵션을 사용할 수 있습니다.
4. **새 템플릿 만들기를** 클릭하세요. 새 보드가 열리며 처음부터 새 템플릿을 만들 수 있습니다.

![custom_templates_create_new_template.gif](https://help.miro.com/hc/article_attachments/21857708180242)
*새 템플릿 만들기*

기본적으로 **템플릿이 새 템플릿으로** 지정됩니다.

템플릿 세부 정보(이름, 설명, 공유 상태, 미리보기)를 업데이트하려면 다음을 수행하세요.

1. 왼쪽 상단 모서리에서 템플릿 이름을 선택하세요.
2. **변경한 다음 변경 사항 저장을*![](https://help.miro.com/hc/article_attachments/21857709903122)
*클릭해*업데이트하세요.customizing_template_info.gif새 템플릿 저장*

:::note
사용자 지정 템플릿은 현재 보드가 속한 팀의 라이브러리에 저장됩니다. 한 팀에 사용자 지정 템플릿을 저장하면 별도로 생성하거나 템플릿이 Enterprise 플랜 및 Business 플랜 전체와 공유되지 않는 한 다른 팀에서 액세스할 수 없습니다.
:::

## 템플릿 사용 및 관리

### 템플릿 혼합 및 일치

보드에 원하는 만큼 템플릿을 추가할 수 있습니다. 프로젝트의 요구 사항에 가장 잘 맞는 템플릿을 자유롭게 혼합하세요.

### 미리 보기, 세부 정보 보기, 맞춤 설정 템플릿 사용

사용자 지정 템플릿을 볼 때 템플릿 작성자의 이름과 프로필 사진이 템플릿 카드 아래에 표시됩니다. 템플릿 위로 마우스를 가져가면 사용 또는 템플릿 미리보기를 볼 수 있는 옵션이 표시됩니다.

![custom_templates_preview.png](https://help.miro.com/hc/article_attachments/21857708188690)*템플릿 선택기의 사용자 지정 템플릿*

미리 보기를 사용하면 보드에 추가하기 전에 올바른 템플릿을 쉽게 식별할 수 있습니다. 미리보기에는 템플릿 이름, 설명, 템플릿 예제가 표시됩니다. 여기에서 템플릿을 편집하고 삭제할 수도 있습니다.

:::note
보드 미리보기 영역을 변경하려면 템플릿을 편집하고 [시작 보기 영역을](../../../using-miro/sharing-boards/03-sharing-boards-and-inviting-collaborators.md) 초기화하세요.
:::

![custom_template_preview.png](https://help.miro.com/hc/article_attachments/21857708192402)*사용자 지정 템플릿 미리보기*

### 템플릿 편집 및 삭제

> **설정 권한을 가진 사용자:** 템플릿 소유자, 콘텐츠 [관리자 권한이](../../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md) 있는 회사 관리자(Enterprise 플랜 전용)

:::warning
콘텐츠 관리자 권한이 있는 회사 관리자는 템플릿을 삭제하고 보드 세부 정보를 편집할 수만 있으며 보드의 콘텐츠를 편집할 수 없습니다.
:::

만든 템플릿을 쉽게 수정하거나 제거할 수 있습니다. 템플릿을 편집하거나 삭제하려면:

1. 템플릿 갤러리에서 편집하거나 삭제할 템플릿으로 이동하세요.
2. 영향을 주려는 템플릿 위로 마우스를 가져간 다음 컨텍스트 메뉴에서 점 3개 아이콘을 클릭하세요. 다음 옵션이 표시됩니다.
   - 편집
   - Delete템플릿 선택기에서 ![](https://help.miro.com/hc/article_attachments/21857709912722)*편집 및 삭제*
3. 템플릿 세부 정보를 편집하려면 **편집** 옵션을 클릭하세요.
4. 왼쪽 상단 모서리에서 템플릿 이름을 클릭하세요. 이름, 설명, 미리보기 영역, 공유 옵션을 변경할 수 있습니다. 작업이 완료되면 **변경 사항 저장을** 클릭하세요.
5. 템플릿을 삭제하려면 **삭제** 옵션을 클릭하세요. 그러면 템플릿이 즉시 삭제됩니다. 이 삭제를 취소하려면 보드 하단에 삭제 취소 옵션과 함께 메시지가 표시됩니다.

#### **협업 템플릿 편집**

> 사용 가능 대상: 보드 소유자 및 편집자, 공유 권한이 있는 모든 사용자

이제 사용자 지정 템플릿을 편집하여 버전 관리 및 이메일을 받지 않아도 됩니다. 공유 및 협업 툴을 통해 팀은 원활하게 작업하여 그룹 또는 회사 전체를 위한 템플릿을 만들 수 있습니다.

공유 및 협업을 활성화하려면 다음을 수행하세요.

1. 제작 툴바에서 **임시(** ) 아이콘을 클릭하세요.
2. 편집하려는 템플릿을 선택하고 템플릿 오른쪽 상단 모서리에서 **...** **을** 클릭하고 편집을 선택하세요.
3. 템플릿이 로드되면 고유한 URL이 생성됩니다. 이제 **공유** 버튼을 클릭하고 협업하기 위해 초대할 사용자를 선택할 수 있습니다.
4. 이제 사용자와 공동 작업자는 "공동 작업자 커서 표시" 및 "댓글" 툴바 버튼 표시가 표시되며 초대된 모든 사용자가 템플릿에서 함께 작업할 수 있습니다.
5. 편집을 완료하면 보드 왼쪽 상단 모서리에서 **저장을** 클릭하고 종료를 클릭하여 변경 사항을 ![custom_templates_sharing_collaboration.gif](https://help.miro.com/hc/article_attachments/21857708203794)저장하세요.
   *사용자 지정 템플릿에서 협업 활성화*

### 회사 및 팀 템플릿 액세스

더 쉽게 탐색하기 위해 회사 및 팀 템플릿은 이제 사용자 지정 템플릿 섹션에서 개인화된 단일 회사 이름으로 찾을 수 있습니다. 회사 설정에서 회사 이름과 '템플릿'이라는 단어가 표시된 후 '템플릿'이라는 단어가 **표시됩니다.**

이 영역에 액세스하면 오른쪽 패널 상단에 두 개의 탭이 표시됩니다. **회사** 및 **팀**. 아래에서 생성되었거나 팀과 공유된 모든 템플릿은 팀 탭에서 찾을 수 있습니다. 회사와 공유된 모든 템플릿은 Compay 탭에서 찾을 수 ![custom_templates_company_and_team_tabs.png](https://help.miro.com/hc/article_attachments/21857708208018)있습니다.
*회사 및 팀 탭으로 사용자 지정 템플릿 탐색*

### 맞춤 설정 템플릿 기능

> **해당 대상:**Starter, Business, Enterprise 플랜 **사용 가능 대상:** 회사 관리자

회사 관리자는 내부 모범 사례와 고유한 작업 방식을 지원하는 템플릿을 활용할 수 있습니다. 추천 템플릿은 파란색 배지가 있으며 사용자 지정 템플릿 폴더 상단에 표시됩니다. 사용자는 추천 사용자 지정 템플릿을 쉽게 찾고 재사용할 수 있습니다.

템플릿을 사용하려면 템플릿 페이지를 열고 아래로 스크롤해 **이 템플릿** 정보로 이동한 다음 **추천으로 지정을** 클릭하세요**.**

![Making_a_template_a_featured_template.jpg](https://help.miro.com/hc/article_attachments/21857708216722)*사용자 지정 템플릿 제공*

## 맞춤 설정 템플릿 공유하기

### 템플릿의 레벨 액세스

작업을 중복하지 않도록 템플릿을 비공개로 유지하거나 팀이나 회사와 공유하세요.

사용자 지정 템플릿에는 세 가지 액세스 레벨이 있습니다. *개인*, *팀*, *회사*.

- **개인** 템플릿은 작성자만 볼 수 있습니다
- **팀 템플릿과 공유된** 템플릿은 모든 팀 멤버가 사용할 수 있습니다
- **회사 템플릿과 공유된** 템플릿은 구독 내의 모든 팀에서 공유됩니다

:::note
Business 플랜에서는 모든 팀 구성원이 사전 관리자 승인 없이 **회사 템플릿을** 게시할 수 있습니다. 이 설정은 기본적으로 적용됩니다.
:::

편집 모드를 입력하여 템플릿 선택기에서 액세스 레벨을 업데이트할 수 있습니다.

1. 제작 툴바에서 **템플릿** 버튼을 클릭하세요.
2. 템플릿이 있는 액세스 레벨(개인, 팀, 회사)을 선택하세요.
3. 템플릿 오른쪽 상단 모서리의 **점 3개 아이콘을** 클릭하고 **편집을** 선택하세요.
4. 보드 왼쪽 상단 모서리에서 템플릿 이름을 클릭하고 액세스 레벨을 변경한 다음 **변경 사항 저장을** 클릭하여 업데이트하세요.

### 템플릿 링크 공유

링크를 공유하면 다른 사용자가 올바른 템플릿을 빠르게 찾고 권장 리소스의 도달 범위를 확장하며 비공개 [Miroverse를](../../../using-miro/miroverse/01-what-is-miroverse.md) 만드는 데 도움이 됩니다.

공유하려는 템플릿으로 이동하고 공유 링크를 두 가지 방법으로 복사하세요.

- 컨텍스트 메뉴에서 점 3개 아이콘을 클릭하고 **링크** 복사를 선택하세요.
- 미리보기를 클릭하여 템플릿 세부 정보를 확인하고 링크 **복사를** 선택해 오른쪽 상단에서 **공유하세요.**

![copy_template_link.png](https://help.miro.com/hc/article_attachments/21857709925394)*템플릿 미리보기에서 템플릿 링크를 복사하는 옵션*

링크를 열면 팀 멤버가 템플릿 미리보기 페이지에 표시됩니다. 팀 및 회사 템플릿에 대한 링크만 복사할 수 있습니다.

:::note
가시성 메모는 특정 사용자 지정 템플릿을 볼 수 있는 사용자를 나타냅니다. 템플릿 카드의 점 3개 아이콘(볼 수 있음)과 템플릿 미리보기에서 볼 수 있는 점 3개 아이콘(볼 수 있음)을 클릭해 표시됩니다. 예를 들어, 개발자 팀만 템플릿을 만드는 경우 다른 사용자가 템플릿을 미리 보면 "개발자 팀만 볼 수 있음"이 표시됩니다.
:::

## 회사 템플릿 및 관리자 기능

> **해당 대상:** Enterprise 플랜, Business 플랜 **설정 기준:** 회사 관리자

회사 관리자는 다음과 같은 여러 가지 템플릿 기능을 사용할 수 있습니다.

- 회사 템플릿 만들기
- 공유 회사 / 팀 템플릿 관리(편집 및 삭제)
- 템플릿 사용에 대한 관리자 인사이트 얻기

> [Enterprise 플랜에서 정책 공유](../../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md) 에 대해 자세히 알아보세요.

회사 템플릿 만들기 공유 템플릿 관리 관리자 인사이트 얻기

Enterprise 및 Business 플랜에서는 회사 관리자가 기존 팀과 미래의 모든 팀 사용자가 사용할 수 있도록 사용자 지정 템플릿을 회사 전체와 공유할 수 있습니다.

Business 플랜의 모든 팀 멤버는 템플릿을 만들고 회사와 공유할 수 있습니다.

Enterprise 플랜의 팀 멤버의 경우 회사 [관리자가 설정한 옵션에](../../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md) 따라 이 기능이 달라집니다.

![share_custom_template_company.png](https://help.miro.com/hc/article_attachments/21857708221202)*회사 관리자는 회사 전체와 맞춤 템플릿을 공유할 수 있습니다*

**회사** 태그가 지정된 회사 템플릿을 쉽게 식별할 수 있습니다. 회사 태그는 템플릿 검색 결과에만 표시됩니다.

![custom_templates_company_label.png](https://help.miro.com/hc/article_attachments/21857708226194)
*태그가 있는 회사 템플릿*

Enterprise 플랜에서 콘텐츠 관리자 권한이 활성화되어 있으면 [팀 또는 회사와 공유된](04-templates.md) 사용자 지정 템플릿을 변경해 특정 팀 외부에서 공유되지 않아야 하는 템플릿을 숨길 수 있습니다. **사용자 지정 템플릿** 섹션으로 이동하여 적절한 옵션을 선택하면 여기에서 만든 템플릿을 편집하거나 삭제할 수 있습니다. [콘텐츠 관리자 권한에](../../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md) 대해 자세히 알아보세요.
:::note
회사 관리자는 템플릿 설정 모드에서 모든 항목을 편집할 수 있지만 보드 콘텐츠 자체를 편집할 수는 없습니다.
:::

가장 자주 사용되는 템플릿과 사용자가 사용자 지정 템플릿을 사용하고 있는지 확인하세요. [Enterprise](../../../plans-billing/miro-plans/04-enterprise-plan.md) 플랜의 회사 관리자는 지난 1년 동안 Miro, Miroverse, 사용자 지정 템플릿이 관리자 인사이트 패널에서 지난 30일 동안 회사에서 사용된 횟수를 확인할 수 있습니다. [관리자 인사이트 패널에](../../../enterprise-administration/getting-started/admin-analytics/05-admin-insights-deprecated.md) 대해 자세히 알아보세요. ![template_insights.gif](https://help.miro.com/hc/article_attachments/21857709941522)*인사이트의 인기 템플릿*

## 자주 묻는 질문

사용자 지정 템플릿을 다른 사용자와 공유할 수 있나요?

네. 템플릿을 미리 볼 때 링크 복사 옵션을 사용하는 것이 가장 빠릅니다. Business 플랜을 사용하고 있다면 템플릿 선택기를 통해 팀 또는 조직과 템플릿을 공유할 수 있습니다. 템플릿이 무엇인지 알려주면 팀 템플릿과 검색 표시줄을 통해 찾을 수 있습니다.
Enterprise 플랜을 사용하고 있다면 회사 [관리자가 선택한 설정에](../../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md) 따라 공유가 달라집니다.

링크를 통해 보드를 템플릿으로 공유할 수 있나요?

네, 올바른 보드 콘텐츠 설정을 사용하면 이제 누구나 링크만 사용하여 보드의 복사본을 만들 수 있습니다.

1. 보드 **공유** 메뉴 > **공유 설정 >** **권한을** 여세요.
2. 보드 액세스 권한이 있는 모든 사용자가 보드 콘텐츠를 복사할 수 있도록 허용(메뉴는 유료 플랜에서만 사용할 수 있으며 [무료](../../../plans-billing/miro-plans/09-free-plan.md) 플랜에서는 보드에서 사용할 수 있음).
3. [공개 보기를](../../../using-miro/sharing-boards/03-sharing-boards-and-inviting-collaborators.md) 위해 보드를 공유하세요.
4. 보드 링크를 공유한 후 등록된 Miro 사용자는 이제 보드를 복제하는 옵션을 찾을 수 있는 보드로 이동할 수 있습니다.

다른 사용자의 템플릿을 Miro로 가져올 수 있나요?

네. 템플릿을 선택하고 복사해 자신의 보드에 붙여넣거나 템플릿 보드를 자신의 팀에 복제하고 템플릿으로 저장하기만 하면 됩니다. 콘텐츠 및 보드 복사 옵션은 보드 소유자가 제한할 수 있습니다.
[템플릿을 복사하거나 내보내는 기능을 끄는 방법에](../../../using-miro/sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) 대해 자세히 알아볼 수도 있습니다.

템플릿을 삭제하려면 어떻게 해야 하나요?

1. 템플릿 선택기를 열고 사용자 지정 템플릿 영역에서 템플릿을 찾으세요.
2. 템플릿에서 점 3개 아이콘을 클릭하고 **삭제를** 선택하세요. Enterprise 플랜에서 콘텐츠 관리자 권한이 있는 템플릿 소유자와 회사 관리자만 템플릿을 삭제할 수 있습니다.

구독이 만료되었습니다. 사용자 지정 템플릿을 잃게 되나요?

유료 구독이 만료되면 구독을 갱신해야 사용자 지정 템플릿을 사용할 수 있습니다. 이미 보드에 삽입된 템플릿은 그대로 유지됩니다.
