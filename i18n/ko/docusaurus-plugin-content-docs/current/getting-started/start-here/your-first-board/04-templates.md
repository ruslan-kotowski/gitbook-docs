영감의 불꽃에서 프로젝트의 빠른 시작까지, Miro는 창의력과 생산성을 높이는 다양한 **t****템플릿**을 제공합니다.

디자인 싱킹 연습, 애자일 의례, 의사 결정 프레임워크에서, 우리의 [템플릿 라이브러리](https://miro.com/templates/)는 일상적인 사용 사례에 맞춰 설계된 300개 이상의 맞춤형 템플릿을 보유하고 있어, 몇 초 만에 협업을 시작할 수 있습니다.

Miro는 스페이스를 위한 템플릿도 제공하며, 이를 프로젝트 플랜이라고 합니다. 워크플로에 가장 적합한 보드와 포맷이 사전에 구조화된 스페이스를 선택할 수 있습니다. 프로젝트 플랜에 대해 더 알아보려면 프로젝트 플랜을 참고하세요.

> **사용 가능 환경**: 브라우저 버전, [데스크톱 앱](../../apps-for-devices/05-desktop-app.md), [태블릿 앱](../../apps-for-devices/11-tablet-app.md)

:::tip
필요한 템플릿을 찾지 못하셨나요? [아이디어를 보내주시면](https://community.miro.com/wish-list-32) 우리가 도서관에 추가할 수 있습니다.
:::

:::tip
[Miroverse](https://miro.com/miroverse/) - Miro 커뮤니티 보드 중 가장 우수한 템플릿을 모아놓은 갤러리를 살펴보세요. 직접 [Miroverse에 템플릿을 게시](../../../using-miro/miroverse/06-how-to-get-published-on-miroverse.md)하는 방법도 알아보세요.
:::

## 템플릿을 찾고 사용하여 시작하기

템플릿 갤러리를 살펴보면서 사전 제작된 프레임워크로 시작하거나 여러 템플릿을 결합하여 프로젝트를 계속 진행하세요.

맞춤 설정 템플릿을 생성하거나, Miro에서 제공하는 [템플릿](02-custom-templates.md)을 사용하여 협업 모드를 더 빠르게 시작하세요. 템플릿은 아래 네 가지 영역 중 하나에 위치합니다:

- 대시보드는 새로운 시작을 위한 출발점입니다.
- 템플릿 피커. 맞춤 설정 템플릿 외에도 선택된 Miro 제작 템플릿 및 커뮤니티 제작 'Miroverse' 템플릿을 사용할 수 있습니다.
- Miro 웹사이트. 모든 Miro 제작 템플릿은 [miro.com/templates](https://miro.com/templates/)에서 찾을 수 있습니다.
- [Miroverse](../../../using-miro/miroverse/01-what-is-miroverse.md). 모든 커뮤니티 제작 템플릿은 [miro.com/miroverse](https://miro.com/miroverse/)에서 찾을 수 있습니다.

### 대시보드에서 시작

대시보드에서 템플릿 보드를 추가하려면 원하는 템플릿을 선택하거나 **템플릿 탐색**을 클릭해 템플릿 피커를 엽니다. 템플릿을 선택하면 새 보드가 생성됩니다.

![explore-templates.png](https://help.miro.com/hc/article_attachments/26199204599186)
*Miro 대시보드의 템플릿*

### 템플릿 피커에서 – 템플릿과 프로젝트 플랜

기존 보드에 템플릿을 추가하거나 팀을 위한 프로젝트 플랜을 선택하려면 툴바에서 **템플릿** (![icon-templates.svg](https://help.miro.com/hc/article_attachments/26199204603794)) 아이콘을 선택합니다. 템플릿 피커에서 템플릿이나 프로젝트 플랜을 선택하세요.

템플릿 피커를 사용하면 Miro의 **300****+개의 템플릿**, Miroverse 크리에이터가 만든 최고 등급의 템플릿을 쉽게 둘러볼 수 있습니다. 필요한 템플릿을 검색하여 손쉽게 찾으세요. 검색은 모든 [맞춤 설정 템플릿](02-custom-templates.md)에 적용됩니다.

![template-picker.png](https://help.miro.com/hc/article_attachments/26199198845970)
*템플릿 피커*

카테고리, 주제 태그, 추천 템플릿을 사용하여 주요 도입 사례를 둘러보세요. 템플릿 작성자, 상호 작용 가능한 미리보기, 교육 자료를 통해 템플릿에 대해 알아보세요.

일부 템플릿에 제공되는 예제 콘텐츠를 사용하는 것과 빈 템플릿으로 시작하는 것 중에서 선택하세요.

![pre-filled-template.png](https://help.miro.com/hc/article_attachments/26199204613906)
*템플릿 미리보기에서 예제 콘텐츠와 빈 템플릿 중 선택 가능한 옵션*

보드를 처음부터 시작하고 싶다면, **새 보드 생성 시 표시**를 선택 취소하면 됩니다. 그러면 새 보드를 만들 때마다 템플릿 피커가 나타나지 않게 됩니다. 언제든지 툴바에서 다시 템플릿 피커를 열 수 있습니다.

![new-board-template.png](https://help.miro.com/hc/article_attachments/26199198854674)
*보드를 만들 때마다 템플릿 피커를 표시하는 옵션*

### 프로젝트 플랜

템플릿 피커를 사용하면 [프로젝트 플랜](../../../using-miro/spaces/04-blueprints-beta.md)도 선택할 수 있습니다.

프로젝트 플랜은 스페이스를 위한 템플릿입니다. 워크플로와 팀의 필요에 맞게 보드와 포맷이 미리 구성된 스페이스 프로젝트 플랜을 선택할 수 있습니다. 보드와 포맷에는 필요한 모든 것이 미리 설정되어 워크플로를 시작할 수 있습니다.

대시보드에서 프로젝트 플랜에 접근하려면, 오른쪽에서 **템플릿 탐색**을 선택합니다. 템플릿 피커가 열리면, **프로젝트 플랜**을 선택합니다.

:::tip
Miro 보드에서도 템플릿 피커와 프로젝트 플랜에 접근할 수 있습니다. 작성 툴바에서 **템플릿** (![icon-templates.svg](https://help.miro.com/hc/article_attachments/26199204603794))을 선택하세요. 그러면 템플릿 피커가 열립니다.
:::

:::note
프로젝트 플랜은 Free 플랜에서 사용할 수 없습니다. Free 플랜 사용자는 프로젝트 플랜 기능을 확인할 수 있으며, 플랜 업그레이드 옵션을 볼 수 있습니다.
:::

### 템플릿 패널에서

템플릿은 프레임, 스티커 메모, 테이블, 마인드맵에 내장되어 있어 쉽게 접근할 수 있습니다. 빠르게 만들려면, [작성 툴바](05-toolbars.md)에서 이 도구 중 하나를 열고 **템플릿**을 클릭하세요.

![sticky-templates.png](https://help.miro.com/hc/article_attachments/26199198858002)
*스티커 메모 패널에서 템플릿 접근*

### 템플릿 혼합 및 조합하기

필요한 만큼의 템플릿을 보드에 추가할 수 있습니다. 여러 템플릿에서 프레임워크와 액티비티를 조합하여 동일한 보드에서 자연스럽게 협업을 계속해보세요. 선택한 보드에서 템플릿 피커로 이동하여 사전 제작 템플릿 또는 [자신만의 맞춤 설정 템플릿](02-custom-templates.md)을 선택하세요.

템플릿이 추가되면 요소가 자동으로 그룹 해제됩니다. 각 개체를 클릭하여 이동하거나 편집할 수 있습니다. 여러 개체를 한 번에 이동하려면 [그룹](../../../using-miro/working-on-the-board/08-structuring-board-content.md)으로 묶거나 [프레임을 만들어](../../../using-miro/essential-tools/07-frames.md) 사용할 수 있습니다. 템플릿 요소를 복사해 유사한 항목을 추가할 수 있습니다. 필요하지 않은 경우 [템플릿의 모든 요소를 선택](../../../using-miro/working-on-the-board/10-working-with-objects.md)하여 이동하거나 삭제할 수 있습니다.

:::tip
고유한 스타일을 유지하고 일관성을 만들기 위해 [색상](../../../using-miro/working-on-the-board/14-colors.md) 및/또는 [글꼴](../../../using-miro/essential-tools/06-fonts.md)을 업데이트하세요.
:::

## 사전 입력된 콘텐츠 지우기

템플릿의 개체에 콘텐츠가 미리 채워져 있는 경우, 여러 위젯(예: 스티커 메모, 도형, 카드)의 콘텐츠를 한 번에 지울 수 있습니다. 이 기능을 활용하면 선택한 위젯의 모든 텍스트, 태그, 이모티콘, 작성자, 담당자, 마감일을 제거하여 스타일(색상, 크기 등)을 유지한 채 빈 상태로 되돌릴 수 있습니다.

콘텐츠를 지우려면:

1. 지우려는 위젯을 선택합니다.
2. 마우스 오른쪽 버튼을 클릭하여 컨텍스트 메뉴를 엽니다.
3. 메뉴에서 "콘텐츠 지우기"를 선택합니다.
4. 또는 단축키 Cmd + Delete (Mac) 또는 Ctrl + Delete (Windows)를 사용합니다.

## 인텔리전트 템플릿 작업

인텔리전트 템플릿은 스프린트 계획, 회고, 로드맵 작성과 같은 액티비티 동안 워크플로를 더 효율적으로 하고 팀의 참여를 유지하도록 설계되었습니다. 인텔리전트 템플릿은 하나의 통합된 경험으로 AI, 인터랙티브 툴, 통합 기능을 포함합니다.

인텔리전트 템플릿의 기능은 다음을 포함합니다:

- 회의 요약을 문서로 생성합니다.
- 회고에서 다음 단계를 생성합니다.
- 사용자 목록 위젯으로 팀 멤버를 카드에 추가합니다.
- 사용자 리서치에서 인사이트를 도출합니다.
- 아이디어에 대한 피드백을 얻습니다.

새 보드나 기존 보드에 인텔리전트 템플릿을 추가할 수 있는 방법은 일반 템플릿을 접근하는 방법과 동일합니다: 대시보드나 템플릿 피커를 통해 추가할 수 있습니다. 인텔리전트 템플릿 전용 섹션이 있거나 템플릿 카테고리 내에 섞여 있습니다. 템플릿 섬네일의 왼쪽 상단에서 **Intelligent** 배너를 찾으세요.

![intelligent-templates.png](../../../../../../../docs/getting-started/start-here/your-first-board/images/20601246331666_intelligent-templates.png)

*템플릿 피커 내 인텔리전트 템플릿의 예*

## 템플릿 공유 링크

몇 시간씩 걸리는 것이 아니라 단 몇 초 만에 팀원들이 Miro를 사용하는 방법을 소개하세요. 공유 링크를 통해 다른 사람들이 적절한 템플릿을 빠르게 찾고 추천 자원을 확장할 수 있도록 도와줍니다.

공유하고자 하는 템플릿으로 이동하여 두 가지 방법으로 공유 링크를 복사할 수 있습니다:

- 템플릿 섬네일에서 세 점 아이콘을 클릭하고 **링크 복사**를 선택합니다.
- **미리보기**를 클릭하여 템플릿 세부 정보를 확인하고 오른쪽 상단에서 **공유할 링크 복사**를 선택합니다.

## 맞춤 설정 템플릿 만들기

반복적으로 재구성하거나 같은 액티비티를 반복하는 일이 많거나, 사용자들이 많이 복사-붙여넣기 하는 경우에는 맞춤 설정 템플릿이 필요합니다. 프로세스를 표준화하고 반복 작업에 낭비되는 시간을 줄이려면, 사용자와 팀이 볼 수 있는 맞춤 설정 템플릿을 만드세요. [맞춤 설정 템플릿을 만들고, 공유하고, 편집하는 방법을 알아보세요.](02-custom-templates.md)

:::note
Starter 플랜에서는 맞춤 설정 템플릿 아래에 "개인" 및 "팀" 옵션을 볼 수 있습니다.
"회사", "팀", "개인" 옵션은 Starter, Business, Enterprise, Education 플랜에서 사용할 수 있습니다.
:::

## 자주 묻는 질문

**다른 서비스의 템플릿을 Miro로 가져올 수 있나요?**

아니요, 하지만 Miro 템플릿 라이브러리에서 템플릿을 자유롭게 활용하거나 맞춤 설정 템플릿을 만드실 수 있습니다.

**모바일 앱에서 템플릿 피커에 접근할 수 있나요?**

아니요, 현재는 불가능합니다.

**Miro 템플릿은 무료인가요?**

네, 라이브러리와 선택 도구의 템플릿은 무료로 제공됩니다. 맞춤 설정 템플릿은 유료 및 Education 플랜에서만 지원됩니다. 스마트 다이어그램 도형 팩이 포함된 템플릿은 Business, Enterprise, Education 플랜에서만 사용할 수 있습니다.

**다른 사용자가 팀으로 복사할 수 있는 템플릿 보드를 만들 수 있나요?**

네, 보드 설정에서 보드 복사를 활성화하고 다른 사용자와 보드를 공유하세요. 등록된 Miro 사용자는 보드를 자신의 팀으로 복제할 수 있습니다.
팀에 맞춤 설정 템플릿이 가능한 경우, 직접 템플릿을 만들어 팀과 공유할 수 있습니다. 자세히 알아보기.
