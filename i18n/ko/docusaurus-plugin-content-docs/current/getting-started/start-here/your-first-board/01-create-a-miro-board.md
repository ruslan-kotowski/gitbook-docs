Miro 보드는 아이디어를 시각화하고 개인이나 팀과 함께 프로젝트를 진행할 수 있는 온라인 워크스페이스입니다.

Miro에 [가입](../02-how-to-register-with-miro.md)하면 첫 번째 보드가 자동으로 생성되어 자신의 무료 팀이나 초대받은 팀에 저장됩니다. 대시보드에서 "나의 첫 보드"를 찾아보세요.

## Miro 보드를 만드는 방법

대시보드나 브라우저 주소창에서 원하는 만큼 새 보드를 만들 수 있습니다.

### 대시보드에서 보드 만들기

대시보드에서 보드를 만들려면 다음 단계를 따르세요.

1. 대시보드를 여세요.
   1. 여러 팀에 속해 있다면 보드를 저장할 팀을 선택하세요.
   2. 특정 스페이스에서 보드를 만들려면 스페이스를 여세요.
2. **+ 새로 만들기**를 클릭하세요.
   메뉴가 열립니다.
3. **보드**를 클릭하세요.
   새 보드가 생성됩니다.

### 템플릿에서 보드 만들기

템플릿에서 보드를 만들려면 다음 단계를 따르세요:

1. 대시보드에서 **+ 새로 만들기**를 클릭하세요.
   메뉴가 열립니다.
2. **템플릿 둘러보기**를 클릭하세요.
   템플릿 선택기가 열립니다.
3. 적절한 템플릿을 찾아보거나 검색하세요.
4. **템플릿 사용**을 클릭해 템플릿으로 새 보드를 여세요. 또는 **미리보기**를 클릭해 템플릿에 대한 더 많은 정보를 확인하세요.
5. 템플릿 미리보기에서 **템플릿 사용**을 클릭해 새 보드를 여세요.

### 브라우저 주소창에서 보드 만들기

브라우저 주소창에서 보드를 만들려면 다음 단계를 따르세요:

1. 브라우저 주소창에 **miro.new**를 입력하세요.
   새 보드가 브라우저 창에서 열립니다.
2. 여러 팀에 속한 경우, 팀 전환을 클릭해 보드를 저장할 팀을 선택하세요.
3. 로그인되어 있지 않으면, 새 보드가 열리기 전에 로그인하라는 메시지가 표시됩니다.

## 문제 해결: 왜 보드를 만들 수 없을까요?

보드를 만들 수 없는 이유는 세 가지입니다: 팀 멤버가 아니거나, 올바른 라이선스 유형이 없거나, 팀 설정 때문에 불가능한 경우입니다.

**팀 멤버가 아님**

- 팀의 게스트이므로 새 콘텐츠를 만들 수 없습니다. 보드 소유자에게 팀에 참여할 수 있도록 요청하거나 대시보드에서 팀 참여를 시도해보세요.
- 아직 Miro 팀의 멤버가 아닙니다. 나만의 Miro 팀을 만들려면 대시보드의 사이드바에서 플러스 아이콘을 클릭하세요.
- 팀에 초대되지 않은 상태로 보드에 초대되었습니다. 해당 팀에 새 보드를 만들려면 팀 참여 요청을 클릭하세요.

**라이선스 유형이 잘못되었습니다**

Enterprise 플랜의 멤버이며 제한된 무료 라이선스가 있으므로 보드를 만들 수 없습니다. 보드를 만들려면 편집 액세스 권한을 요청하고 회사 관리자에게 풀 라이선스로 전환해 달라고 요청하세요.

**팀 설정으로 불가능합니다**

Enterprise 플랜 팀의 멤버이며 회사 관리자가 팀 설정에서 콘텐츠 작성을 제한했기 때문에 보드를 만들 수 없습니다. 보드를 만들려면 회사 관리자에게 콘텐츠 생성 권한 부여를 요청하세요.

## 자주 묻는 질문

**보드를 복사하려면 어떻게 해야 하나요?**

왼쪽 상단 툴바에서 **메인 메뉴** 아이콘을 클릭한 후 **보드**를 클릭하고 하위 메뉴에서 **복사하기**를 선택하세요.

**추가 정보:** [보드 복제하는 방법](../../../using-miro/managing-boards/03-how-to-duplicate-a-board.md)을 참조하세요.

**한 보드에서 다른 보드로 콘텐츠를 복사할 수 있나요?**

네, 복사할 [콘텐츠를 선택](../../../using-miro/working-on-the-board/10-working-with-objects.md)한 다음 Windows에서는 Ctrl + C/Ctrl + V, Mac에서는 Cmd + C/Cmd + V를 사용하세요.

**보드를 삭제하려면 어떻게 해야 하나요?**

왼쪽 상단 툴바에서 **메인 메뉴** 아이콘을 클릭한 후 **보드**를 클릭하고 하위 메뉴에서 **삭제**를 클릭하세요.
