Miro에 가입하는 즉시 팀과 보드를 만들고 다른 사용자를 플랫폼에 초대할 수 있습니다. 등록은 무료입니다.

## 가입 방법

Miro에 참여하라는 초대를 받은 경우 이메일 내에서 초대를 수락하세요. Miro 비밀번호를 설정하라는 메시지가 표시되고 즉시 협업을 시작하기 위해 팀 또는 보드로 리디렉션됩니다.

초대장을 받지 못했다면 이메일 주소나 Google, Slack, Office 365, Apple ID 또는 Facebook으로 등록한 다음 새 팀을 만들거나 기존 팀에 참여할 수 있습니다.

이메일 타사 로그인 SSO

1. [가입 페이지](https://miro.com/signup/) 열기
2. **이름**, **회사 이메일,** **비밀번호** 필드를 입력하세요.
3. **Miro 약관 및 개인정보 보호정책을** 읽고 확인란을 선택하세요
4. 제품 릴리스를 최신 상태로 유지하기 위해 **Miro 뉴스 및 업데이트 수신에 동의함** 확인란을 선택하세요
5. **지금 시작하기를** 클릭하세요

- 조직에서 [SSO(통합로그인)를](../../using-miro/tools/troubleshooting/10-i-can't-log-in-via-sso.md) 사용하는 경우 SSO를 통해 로그인하도록 리디렉션됩니다. ID 공급자 자격 증명을 사용해 가입하세요
- 이메일이 이미 Miro에 등록되어 있으면 해당 메시지가 표시됩니다. 프로필에 액세스하려면 이메일로 [Miro에](https://miro.com/login/) 로그인하세요. 기억이 나지 않으면 [비밀번호를 초기화할](../../using-miro/managing-your-profile/05-how-to-change-your-password.md) 수 있습니다. 비밀번호를 복구할 수 없는 경우 [이메일 초기화 문제](../../using-miro/tools/troubleshooting/12-issues-with-confirmation-code-or-password-reset-emails.md)

4. 이메일이 Miro에 처음 가입하고 SSO를 통해 로그인할 필요가 없는 경우 확인 코드를 제출하기 위해 페이지로 리디렉션됩니다

*![signing_up_with_email_to_Miro.gif](../../../../../../docs/getting-started/start-here/images/21017429154962_signing%20up%20with%20email%20to%20Miro.gif)
이메일 확인 페이지*

5. 받은 편지함에서 확인 코드가 있는 이메일을 확인하세요. 이메일에 **이메일** 확인을 클릭하거나 확인 코드 페이지에 코드를 입력할 수 있습니다

*![complete_registration_email.jpg](../../../../../../docs/getting-started/start-here/images/21017429149714_complete%20registration%20email.jpg)
확인 코드*

확인 코드를 받지 못했다면 [확인 코드 이메일 문제](../../using-miro/tools/troubleshooting/12-issues-with-confirmation-code-or-password-reset-emails.md) 문서의 문제 해결 단계를 시도해 보세요.

7일 이내에 이메일을 확인하지 않으면 빈 프로필이 삭제됩니다.

기존 **Google, Facebook, Slack, Office 365** 계정 또는 **Apple** ID로 가입해 등록 프로세스 속도를 높이세요.

1. [가입 페이지](https://miro.com/signup/) 열기
2. 가입 및 로그인할 서비스를 선택하세요

![third-party_sign-in.jpg](../../../../../../docs/getting-started/start-here/images/21017416082706_third-party%20sign-in.jpg)
*타사 로그인*

:::note
Apple ID로 처음 가입할 때 이메일을 공유할지 아니면 이메일을 숨길지 선택할 수 있습니다. **내 이메일 공유를** 선택하면 Apple ID 이메일이 Miro 프로필 이메일로 사용됩니다. **내 이메일** 숨기기를 선택하면 프로필에 새 이메일이 생성되므로 이 이메일을 사용해 Miro에 로그인해야 합니다. Miro 알림은 여전히 Apple ID와 연결된 이메일에 표시됩니다. Apple은 iPhone(iOS 13 이상), iPad(iPadOS 13 이상), 웹 버전, [데스크톱 앱에서](../apps-for-devices/05-desktop-app.md) 사용할 수 있습니다.
:::

회사가 회사 도메인을 사용하는 사용자를 위해 Miro [SSO(통합로그인)를](../../enterprise-administration/security-integrations/single-sign-on-sso/09-single-sign-on-sso.md) 설정하면 ID 공급자 자격 증명을 입력할 수 있는 SSO 로그인 페이지로 자동 리디렉션됩니다. 문제가 발생하면 [SSO를 통해 로그인할 수 없는](../../using-miro/tools/troubleshooting/10-i-can't-log-in-via-sso.md) 문서를 확인하세요.

## Miro 팀 만들기 또는 참여

Miro의 팀은 사용자가 보드와 프로젝트를 생성, 저장 및 공유할 수 있는 공간입니다.

프로필을 등록하기 전에 Miro 팀에 초대되거나 프로비저닝된 경우 가입한 후 즉시 팀에 리디렉션되어 동료 및 친구들과 협업할 수 있습니다. 추가 팀을 만들어야 하는 경우 [Miro에서 팀을 만드는 방법](miro-dashboard/02-how-to-create-a-team-in-miro.md) 문서를 확인하세요.

어떤 팀에도 초대되지 않은 경우 처음으로 가입할 때 하나를 만들거나 회사 팀에 참여하라는 메시지가 표시됩니다.

첫 번째 팀을 만들면 공동 작업자를 즉시 추가할 수 있습니다.

![invite_teammates.jpg](../../../../../../docs/getting-started/start-here/images/21017416083986_invite%20teammates.jpg)
*Miro 팀을 만들 때 팀 멤버 초대*

[도메인 내의](../../administration/team-management/02-manage-team-signup-mode.md) 사용자가 열려 있는 팀이 있으면 팀에 참여하거나 팀에 대한 액세스를 요청할 수 있습니다. 요청은 관리자에게 전송됩니다. 관리자의 승인을 기다리는 동안 자신의 팀을 만들 수 있습니다.

![Join_other_teams.jpg](../../../../../../docs/getting-started/start-here/images/21017429153554_Join%20other%20teams.jpg)
*Miro에 등록할 때 회사 팀에 참여하거나 새 팀에 만들 수 있는 옵션*

## 프로필 세부 정보 추가하기

프로필을 만든 후 [프로필 설정으로](../../using-miro/managing-your-profile/01-profile-settings.md) 이동하여 사진과 프로필 정보를 추가하세요.

:::note
2주 동안 Miro 프로필에 활동이 없으면 보안을 위해 자동으로 Miro에서 로그아웃됩니다.
:::
