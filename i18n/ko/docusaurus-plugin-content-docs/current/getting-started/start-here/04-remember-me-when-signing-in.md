Miro에 로그인할 때, 이메일 주소와 인증 방법을 기억하도록 선택해 나중에 보다 빠르게 로그인할 수 있습니다. 이렇게 하면 최근 로그인한 세 가지 프로필을 기억할 수 있습니다.

1. 로그인할 때, 이메일 주소를 입력한 후 **Remember Me** 체크박스를 선택하세요. ![remember-me-checkbox.png](../../../../../../docs/getting-started/start-here/images/20716822838290_remember-me-checkbox.png)*로그인 시 '로그인 상태 유지' 선택*
2. Miro에 다시 로그인하면 최근에 저장된 세 개의 로그인 프로필이 표시됩니다. 세 개의 프로필을 추가한 후에 추가 프로필을 기억하도록 선택하면 가장 오래된 프로필이 잊혀집니다.
3. 선호하는 프로필을 클릭하여 로그인 프로세스를 완료하세요.![remember-me.gif](../../../../../../docs/getting-started/start-here/images/20716818238994_remember-me.gif)*Signing in to Miro using a remembered profile*

기억된 프로필에서 로그인을 잊으려면:

1. 프로필 옆의 **세 점 아이콘** (![icon-main.svg](../../../../../../docs/getting-started/start-here/images/26092786370706_icon-main.svg))을 클릭하세요.
2. **이 방법 잊기**를 선택하세요.![forget-this-account.gif](../../../../../../docs/getting-started/start-here/images/26092786370962_forget-this-account.gif)*기억된 로그인 방법 잊기*
