Miro 검색을 사용해 보드나 스페이스를 쉽게 찾으세요.

:::tip
특정 보드에서 검색하는 방법을 배우려면 [이 문서](../../../using-miro/working-on-the-board/19-searching-text-on-the-board.md)를 확인하세요.
:::

## 검색 사용 방법

[대시보드](https://miro.com/app/dashboard/)에서 보드나 스페이스를 찾으려면 페이지 왼쪽 패널 상단의 **검색창**을 클릭하거나 **Ctrl + E** *(Windows용)*/**Cmd + E** *(Mac용)*를 누르세요. 보드나 스페이스 이름을 입력하세요. 최근에 열었던 보드와 스페이스가 검색창 아래에 나타납니다. 현재 팀에서 귀하와 공유된 모든 검색 결과를 보게 됩니다.

특정 보드에 대한 세부 정보를 보려면:

1. 보드 이름 옆에 있는 **세 점** (**...**) 아이콘을 클릭합니다.
2. **보드 세부 정보**를 선택합니다.
   다음 정보가 포함된 모달이 열립니다.
   1. 보드 분류
   2. 보드 소유자
   3. 보드 설명
   4. 보드 생성일
   5. 마지막 수정일
   6. 보드 위치 (팀 이름 > 스페이스 이름)

검색을 **소유자**나 **스페이스**로 좁힐 수 있습니다 (Free 플랜에서는 소유자로만 검색 가능). 필터를 적용하려면 **모든 필터**를 클릭하거나 검색창 아래의 드롭다운 목록에서 소유자를 선택하세요. 필터를 제거하려면 **X**를 클릭하세요.

검색 창은 현재 속한 팀을 기반으로 결과를 표시합니다.

검색 결과에서 바로 메뉴를 통해 [공유](../../../using-miro/sharing-boards/03-sharing-boards-and-inviting-collaborators.md), 이름 변경, [보드 이동](../../../using-miro/managing-boards/04-how-to-move-a-board.md) 및 기타 주요 작업을 수행할 수 있습니다. 모든 옵션이 포함된 메뉴는 보드 이름 옆의 **세 점** (**...**)을 클릭하면 열립니다.

*![search-three-dots-menu.png](../../../../../../../docs/getting-started/start-here/miro-dashboard/images/21262219090578_search-three-dots-menu.png)
검색 결과의 보드 컨텍스트 메뉴*

:::tip
이 기능을 검색 필터와 함께 사용하여 보드 구성을 간소화하세요. 예를 들어, 소유자별로 보드를 필터링하여 팀이나 프로젝트에 더 빠르게 이동할 수 있습니다.
:::

:::tip
Miro용 [Chrome 검색 확장 프로그램](https://miro.com/marketplace/chrome-search/?backUrl=%2Fmarketplace%2F)을 설치해보세요. 확장 프로그램이 추가되면 브라우저 주소창에 'M*iro'*라고 입력하고 **탭** 키를 누르세요. 이 확장 프로그램을 통해 주소창에서 바로 Miro 보드를 빠르게 검색할 수 있습니다.
:::

## 고급 검색

> **사용 가능:** Education, Starter, Business, Enterprise 플랜

Education, Starter, Business, Enterprise 플랜 사용자들은 검색창을 이용하여 보드 및 스페이스 제목, 설명, 위젯, 댓글, 보드의 스티커 메모 내 특정 단어 또는 구문을 찾을 수 있습니다.

Business 또는 Enterprise 플랜을 사용 중이라면, 대시보드에서 모든 팀을 검색하여 조직 전체의 관련 콘텐츠를 찾을 수 있습니다.

검색 창은 찾고자 하는 단어 또는 구문이 포함된 모든 콘텐츠 항목을 표시합니다. **콘텐츠** 섹션 아래의 각 항목을 클릭하여 검색 결과를 보고, 보드 이름 왼쪽의 화살표를 클릭하여 일치 항목 목록을 확장할 수 있습니다.

이 섹션에서 특정 검색 결과를 클릭하면 그 검색 결과가 있는 보드의 특정 위치로 보드가 열리므로, 따로 찾을 필요가 없습니다.
