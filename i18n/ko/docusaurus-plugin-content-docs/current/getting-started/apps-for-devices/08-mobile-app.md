## 제한된 가용성 또는 기능을 가진 기능들

일부 Miro 기능은 모바일에서 지원되지 않습니다. 여기에는 템플릿, 보드 내보내기, 프레젠테이션 모드, 화상 채팅, 투표 및 즐겨찾기한 보드가 포함됩니다. 모바일 앱이나 모바일 브라우저에서는 구독을 변경하거나 라이선스를 추가할 수 없습니다.

모바일 앱은 현재 일부 기능에 대해 *제한된 기능*을 제공합니다.

|  |  |
| --- | --- |
| **기능** | **기능 제한** |
| 보드 생성 및 공유 | [방문자](../../using-miro/sharing-boards/08-collaboration-with-visitors.md)는 편집 권한 없음 |
| 스페이스 | [스페이스](../../using-miro/spaces/01-spaces.md)로 보드 필터링 |

## 모바일 요구 사항

- **iOS 사용자:** iOS 16 이상
- **Android 사용자:** Android 7 이상

앱이 휴대전화와 호환되지 않을 경우, 모바일 브라우저를 통해 다음의 Miro 기능을 이용할 수 있습니다:

- **보드 보기:** 콘텐츠에 접근하고 볼 수 있습니다.
- **댓글 작성:** 화면을 탭하고 손가락을 대고 있으면 댓글을 추가할 수 있습니다.

## 앱에서 보드 작업하는 방법

### 모바일 앱 터치 제스처

- **스와이프**하여 보드를 이동하세요.
- **길게 탭**하고 드래그하여 여러 객체를 선택하세요.
- **핀치**하여 확대하거나 축소하세요.
- **더블 탭**하여 보드를 확대하세요.
- **더블 탭 후 위나 아래로 스와이프****하여** 확대하거나 축소하세요.
- **화면 가장자리에서 위아래로 스와이프**하여 확대하거나 축소하세요.
- 객체를 선택하고 **편집**을 탭하여 객체를 편집하세요.
- **더블 탭**하여 객체에 텍스트를 추가하세요.
- **길게 탭**하여 객체를 이동하세요.

### 보드 객체 편집 방법

모바일 앱에서 보드를 열면 기본적으로 보기 전용 모드입니다. 이는 객체를 이동하지 않고도 보드를 쉽게 탐색할 수 있도록 합니다.

1. 객체를 선택하고 **편집**을 누릅니다.
2. 객체를 더블 탭하여 텍스트를 추가하기 시작합니다.
3. 객체를 길게 탭하여 즉시 이동시킵니다.

### 보드 간에 복사하고 붙여 넣는 방법

하나의 보드에서 다른 보드로 요소를 복사하는 것은 같은 보드에서 요소를 복사하고 붙여 넣는 것만큼 간단합니다.

1. 객체를 복사하려는 보드를 엽니다.
2. 객체를 선택한 다음 하단 툴바에 있는 **세 개의 세로 점** 메뉴를 누릅니다.
3. **복사**를 선택합니다.
4. 객체를 붙여넣을 보드를 엽니다.
5. **추가(+) 아이콘**을 누른 다음 **붙여넣기**를 누릅니다.
6. 붙여넣은 객체를 보드의 적절한 위치로 이동시킵니다.

Miro 외부에서 이미지, 파일 또는 텍스트가 아닌 콘텐츠를 복사하여 붙여넣기 하려면, 복사 및 붙여넣기 대신 **업로드** 기능을 사용해야 합니다. 업로드 옵션은 **추가 (+)** 메뉴에서 찾을 수 있습니다.

### 연결선 그리기 방법

객체 사이에 연결선을 그리면 객체가 보드 내에서 이동하더라도 두 객체 간의 링크가 유지됩니다.

1. 연결을 시작하려는 객체를 선택합니다.
2. **편집** 아이콘을 누릅니다.
3. 객체 아래에 나타나는 **파란 점**을 드래그하여 연결하려는 객체로 끌어갑니다.
4. 객체가 연결된 화살표가 나타납니다.
   ![connector-lines.gif](https://help.miro.com/hc/article_attachments/29363391615634)
5. 연결선을 삭제하려면 그것을 선택한 후 하단 툴바의 **휴지통** 아이콘을 클릭합니다.

### 보드 세부 정보 보기 방법

오른쪽 상단 구석의 점 3개 메뉴를 눌러 보드 세부 정보를 보고, 보드 표지를 변경하고 보드 접근 권한을 업데이트합니다.

### 편집 액세스 요청

누군가 보드에 대한 편집 액세스를 요청하면 보드 소유자는 Miro 앱에서 푸시 알림을 받습니다. 소유자는 알림을 클릭하여 보드로 쉽게 이동해 요청자에게 편집 액세스를 부여할 수 있습니다.

## 보드 보이스오버 지원

시각적 요소에 대한 지원이 필요한 사용자는 iOS와 Android에서 보이스오버 기능을 사용할 수 있습니다. 전화 설정에서 보이스오버를 켜서 Miro와 함께 사용하세요.

보이스오버를 켜면 화면에 있는 항목을 선택할 때 내용을 읽어줍니다. 이를 통해 앱에서의 내용을 들을 수 있어, 콘텐츠를 더 쉽게 생성하고 볼 수 있습니다.

## 푸시 알림

앱에 처음 로그인할 때, 푸시 알림을 켤지를 물어봅니다. 이를 통해 팀원이 보드에서 당신을 언급할 때마다 알림을 받을 수 있습니다. 이 알림은 앱 **설정**에서 언제든지 끌 수 있습니다.

이 내용은 스마트폰에서의 푸시 알림에만 해당됩니다. [이메일 알림과 뉴스레터](../../using-miro/managing-your-profile/02-miro-notifications.md)를 끄는 방법을 알아보세요.

## 자주 묻는 질문

모바일 앱을 사용하여 보드에 웹 링크를 추가할 수 있나요?

네, 링크를 추가하려면 먼저 복사하세요. 그런 다음, 보드 오른쪽 아래에 있는 만들기 (**+**) 버튼을 탭하세요. **업로드**를 선택하고 **클립보드에서 붙여넣기**를 선택하면 링크가 보드에 붙여넣어집니다.

다크 모드는 어떻게 켜나요?

기본적으로 다크 모드는 휴대전화 설정에 따라 활성화됩니다. Miro 모바일 앱에 대해 다크 모드를 켜거나 끄고 싶으시면, 앱 홈 화면의 배너에 있는 **모드 전환** 버튼을 클릭한 다음, **다크 모드** 또는 **라이트 모드**를 선택하세요.
