홈 화면에서 Miro 데스크톱 앱을 몇 초 만에 실행하고, 방해 없이 보드 작업을 진행하세요. 이 앱은 브라우저 버전의 기본 기능을 모두 지원합니다.

:::tip
[우리 웹사이트](https://miro.com/apps/)에서 Miro 앱을 다운로드하세요.
:::

## Miro 데스크톱 앱 다운로드

### Windows

- Windows 64비트 - [앱을 다운로드](https://desktop.miro.com/platforms/win32-nsis-pu/Miro-setup.exe)

:::note
Windows 32비트는 더 이상 사용할 수 없습니다.
:::

### macOS

- Apple 실리콘 칩을 탑재한 Mac - [앱 다운로드](https://desktop.miro.com/platforms/darwin-arm64/Install-Miro.dmg)
- Intel 칩을 탑재한 Mac - [앱 다운로드](https://desktop.miro.com/platforms/darwin/Install-Miro.dmg)

사용하는 프로세서 종류를 확인하려면 다음 단계를 따르세요:

1. Mac의 왼쪽 상단에 있는 Apple 아이콘을 클릭합니다.
2. 드롭다운 메뉴가 나타납니다. 여기에서 **이 Mac에 관하여** 옵션을 클릭하세요.

창에는 필요한 정보, 프로세서 유형(인텔 또는 Apple 실리콘)을 포함한 세부사항이 표시됩니다.

## Miro를 여러 기기에 배포하기

Miro는 IT 관리자가 수천 대의 기기에 배포할 수 있는 다양한 설치 프로그램 버전을 제공합니다. 이러한 방법에는 두 가지 기본 방식이 있습니다: 사용자별 설치 또는 기기별 설치입니다. 각 방식에는 자동 업데이트 기능이 있는 버전과 없는 버전이 포함되어 있습니다. 자동 업데이트가 있는 버전은 앱이 발표되자마자 업데이트된 Miro 버전을 사용자에게 제공합니다. 자동 업데이트가 없는 버전은 직원들이 사용하는 Miro의 버전을 보다 제어할 수 있게 해줍니다.

### Windows용

#### Miro를 Program Files에 배포하기

Miro를 또한 프로그램 파일 디렉토리에 설치하여 장치의 모든 사용자가 사용할 수 있도록 하면서도, 각 사용자의 프로필은 별도로 유지할 수 있습니다. 하나의 머신에 Miro 앱을 단일 설치로 배포하면, 대규모로 봤을 때 하드 드라이브의 공간을 적게 차지하면서도 모든 사용자가 Miro를 사용할 수 있도록 합니다. 자동 업데이트 버전을 선택할 경우, 업데이트를 설치하는 데 관리자 권한이 필요하다는 점에 유의하세요.

- Windows MSI 64비트 자동 업데이트 포함 버전 - [앱 다운로드](https://desktop.miro.com/platforms/win-nsis/Miro-setup.msi)
- Windows MSI 64비트 자동 업데이트 미포함 버전 - [앱 다운로드](https://desktop.miro.com/platforms/win-nsis/Miro-no-updates.msi)

#### 특정 사용자용 Miro 배포

Miro는 IT 관리자가 특정 사용자에게 Miro를 배포할 수 있는 다양한 설치 프로그램 버전을 제공합니다. 이 버전은 관리자 권한 없이 업데이트할 수 있으며, 선택한 특정 사용자에게만 설치됩니다.

- 자동 업데이트가 포함된 Windows MSI 64비트 - [앱 다운로드](https://desktop.miro.com/platforms/win32-nsis-pu/Miro-setup.msi)
- 자동 업데이트가 포함되지 않은 Windows MSI 64비트 - [앱 다운로드](https://desktop.miro.com/platforms/win32-nsis-pu/Miro-no-updates.msi)

### MacOS용

- Apple Silicon Mac(자동 업데이트 없음) - [앱 다운로드](https://desktop.miro.com/platforms/darwin-arm64/Install-Miro-no-updates.dmg)
- Intel Mac(자동 업데이트 없음) - [앱 다운로드](https://desktop.miro.com/platforms/darwin/Install-Miro-no-updates.dmg)

## 앱 시스템 요구 사항

### Windows용

|  |  |  |
| --- | --- | --- |
|  | **최소 사양** | **권장 사양** |
| **CPU** | 3 GHz (2 코어/4 스레드) | 2.8 GHz (4 코어/8 스레드) |
| **RAM** | 8 GB | 16 GB (DDR4) |
| **OS** | Windows 10 이상 (Microsoft Store에서 앱 다운로드) + Microsoft .NET 프레임워크 4.5 (ARM 버전의 Windows는 지원되지 않음) | 최신 OS |
| **네트워크** | 8 Mb/s 이상 | 32 Mb/s |

### macOS용

|  |  |  |
| --- | --- | --- |
|  | **최소 사양** | **권장 사양** |
| **CPU** | 64비트 인텔 또는 애플 M1 |  |
| **운영 체제** | MacOS 12 (Monterey) 이상 | 최신 운영 체제 |
| **네트워크** | 8 Mb/s 이상 | 32 Mb/s |

해당 앱은 장치에서 여러 인스턴스를 실행하게 됩니다:

- 메인 프로세스
- 창 프로세스 (UI 렌더러)
- 하드웨어 가속
- 크래시 핸들러
- + 열려 있는 각 탭마다 1개의 프로세스 (각 탭에는 웹뷰가 있기 때문)

예를 들어, 작업 중에 3개의 탭을 열어놓았다면, Miro.exe의 인스턴스가 7개 보일 것입니다. 이 아키텍처에 대한 자세한 정보는 [여기](https://www.electronjs.org/docs/glossary#process)와 [여기](https://www.chromium.org/developers/design-documents/multi-process-architecture)에서 확인할 수 있습니다.

## 앱 전용 단축키

데스크톱 앱에는 추가적인 [단축키](../../using-miro/working-on-the-board/06-shortcuts-and-hotkeys.md)가 있습니다:

- **Ctrl + R** *(Windows에서는)* / **Cmd + R** *(Mac에서는)* 탭을 새로고침
- **Ctrl + W** *(Windows에서는)* / **Cmd + W** *(Mac에서는)* 탭 닫기
- **Ctrl + Q** *(Windows에서는)* / **Cmd + Q** *(Mac에서는)* 앱 종료
- **Ctrl + Shift + L** *(Windows에서는)* / **Cmd + Shift + L** *(Mac에서는)* 보드 링크 복사
- **Ctrl + ~** *(Windows에서는)* **/ Cmd + ~** *(Mac에서는)* 확대/축소

### 사용 불가 작업

다음 작업은 Miro 데스크톱 앱에서 사용할 수 없습니다:

- 방문자는 로그인할 수 없습니다.

  > ✏️ 등록된 Miro 사용자만 데스크톱 앱에 로그인할 수 있습니다.
- Sketch에서 복사 붙여넣기 옵션 없음
- 일부 Jira 서버 버전에서는 보안상 이유로 Jira 카드를 편집할 수 없습니다.

## 맞춤법 검사

데스크톱 앱에서 자동 맞춤법 검사 기능을 끄고 싶으시면, 다음 단계를 따르세요:

- **Alt** 키를 누릅니다 (*Windows 전용*)
- 상단의 주 내비게이션 바에서 **보기**를 클릭합니다
- **맞춤법 검사 표시** 버튼의 선택을 해제합니다

Microsoft Store에서 다운로드한 앱에는 맞춤법 검사를 비활성화하는 옵션이 없습니다.

## 발생할 수 있는 문제와 해결 방법

### 앱 데이터를 재설정하는 방법

문제가 발생할 경우(특히 로그인 절차에 어려움이 있는 경우), **앱 데이터를 초기화하여** 앱의 메모리를 비우면 도움이 됩니다.

:::tip
데이터를 초기화한 후에도 문제가 지속된다면, 최신 버전을 [다운로드](https://miro.com/apps/)하여 앱을 삭제하고 다시 설치하는 것을 고려해보세요.
:::

#### Windows의 경우

**Alt > Help**를 누르고 아래 스크린샷에 표시된 대로 애플리케이션 데이터를 초기화하세요:

​​
![reset app data on Windows.png](../../../../../../docs/getting-started/apps-for-devices/images/21016134171922_reset%20app%20data%20on%20Windows.png)
*Windows용 데스크톱 앱의 데이터 초기화*

메뉴를 찾지 못하는 경우, 아마도 MS Store에서 다운로드한 앱을 사용 중일 가능성이 있습니다. 이런 경우, 앱 데이터를 초기화하려면 Windows **설정** > **앱** > **앱 및 기능** > 목록에서 **Miro**를 찾아 **고급 옵션** > **초기화**를 엽니다.

이 방법으로 문제가 해결되지 않으면 **C:\Users\username\AppData\Roaming\RealtimeBoard**와 **C:\Users\username\AppData\Local\Programs\RealtimeBoard**의 모든 앱 파일을 삭제하세요.

> **✏️** **Appdata** 폴더가 숨겨져 있으면, [여기](https://support.microsoft.com/windows/view-hidden-files-and-folders-in-windows-10-97fbc472-c603-9d90-91d0-1166d1d9f4b5)를 참조하여 폴더를 표시할 수 있습니다.

#### macOS용

상단 메뉴에서 Miro를 클릭하고 아래 스크린샷과 같이 **애플리케이션 데이터 재설정** 을 선택합니다:

![reset app data on Mac.png](../../../../../../docs/getting-started/apps-for-devices/images/21016120799378_reset%20app%20data%20on%20Mac.png)
*Mac에서 애플리케이션 데이터 재설정*

그 후, 앱에 다시 로그인하여 문제가 해결되었는지 확인하세요.

리셋해도 문제가 바로 해결되지 않는 경우, Finder 창을 열고 **Command + Shift + G**를 누른 다음 **~/Library/Application Support/RealtimeBoard**를 붙여 넣고 모든 앱 파일을 삭제하세요.

Mac에서 MDM을 사용하는 경우

앱이 로드되지 않거나 무한 루프에 빠지는 문제가 발생할 경우, 자동 업데이트가 수행될 수 있도록 설정되어 있는지 확인하세요. `https://github.com/Squirrel/Squirrel.Mac`은 다음과 같은 권한이 필요합니다:

- `Application` 디렉토리에 대한 읽기, 쓰기 및 실행 권한,
- `~/Application Support/Caches/`에서 `com.electron.realtimeboard.ShipIt` 디렉토리에 작업할 수 있도록 읽기 및 쓰기 권한을 포함하여 임시 디렉토리 `private/var/folders`와 작업할 수 있는 권한이 필요합니다.

업데이트 과정에서 문제가 발생하면 Squirrel은 `~/Application Support/Caches/com.electron.realtimeboard.ShipIt`에 `ShipIt_stderr.log`를 생성합니다. 문제에 대한 추가 정보는 해당 파일에서 확인할 수 있습니다.
Skype와 Slack도 유사한 업데이트 프로세스를 사용하니, 이미 이들에 대한 MDM 설정을 완료했다면, 동일한 설정을 Miro 데스크톱 앱에 적용할 수 있습니다.

## 자주 묻는 질문

1. *데스크톱 앱은 어디에서 다운로드할 수 있나요?*
   - [저희 웹사이트](https://miro.com/apps/)에서 다운로드하세요.
2. *브라우저에서 Miro를 시작할 때 데스크톱 앱을 열라는 팝업을 제거하려면 어떻게 해야 하나요?*
   - [이 문서](../../using-miro/troubleshooting-technical-questions/technical-guidelines/04-how-to-disable-miro-desktop-app-pop-up-in-your-browser.md)에 있는 단계를 시도해보세요.
3. *Linux용 데스크톱 앱 버전이 있나요?*
   - 아니요, 현재는 해당 버전이 없습니다.
4. *데스크톱 앱에서 열려 있는 보드의 링크를 어떻게 복사할 수 있나요?*
   - 보드의 **공유** 메뉴를 열고 거기에서 보드 링크를 복사할 수 있습니다. 또 다른 방법은 오른쪽 위의 **파일**을 클릭하고 > **보드 링크 복사**를 선택하는 것입니다. **Ctrl + Shift + L** *(Windows) /* **Cmd + Shift + L** *(Mac)* 단축키도 사용할 수 있습니다.
5. *Windows 데스크톱 앱에서 **Alt** 키를 눌렀을 때 메뉴가 나타나지 않습니다. 어떻게 하면 될까요?*
   - Microsoft Store에서 다운로드한 앱에서는 메뉴가 지원되지 않습니다. Windows 설정에서 앱 데이터를 초기화할 수 있습니다 (**시스템 > 앱 및 기능 > Miro 찾기 > 고급 옵션 > 초기화**) 또는 [원본 앱 버전을 설치](https://miro.com/apps/)하세요.
6. *데스크톱 앱을 삭제하면 내 보드도 삭제되나요?*
   - 아닙니다, 귀하의 콘텐츠는 Miro 프로필에 연동되어 있습니다. 이를 브라우저, [태블릿 앱](11-tablet-app.md), [모바일 앱](08-mobile-app.md)에서도 액세스할 수 있습니다.
