키보드 명령을 사용해 Miro 보드를 매끄럽게 탐색하세요.

## 툴바 및 패널

- **Tab** 키를 눌러 [툴바](../start-here/your-first-board/05-toolbars.md) 및 패널을 탐색하세요.
- 화살표 키를 사용해 툴바 항목 및 메뉴를 탐색하세요.
- 위쪽 및 아래쪽 화살표를 사용하여 [작성 툴바](../start-here/your-first-board/05-toolbars.md)를 탐색하세요.

## 키보드 네비게이션

### 한 글자 숏컷 켜기/끄기 전환

기본적으로, 한 글자 숏컷은 켜져 있습니다. 이를 끄려면 (화면 읽기 프로그램 같은 보조 기술과의 간섭을 방지하기 위해):

1. 보드 툴바에 있는 **메인 메뉴** (![icon-main.svg](../../../../../../docs/getting-started/accessibility-in-miro/images/31688274627218_icon-main.svg)) 아이콘을 클릭합니다.
2. **접근성** 메뉴 옵션을 선택하여 서브메뉴를 엽니다.
3. 서브메뉴에서 **한 글자 숏컷**을 켜기/끄기를 전환합니다.

### 보드 접근

- **Tab** 키를 눌러 보드 위 첫 번째 객체로 건너뛰기 버튼으로 이동한 후 **Enter**를 누르시거나,
- **B**를 툴바나 패널에 포커스가 맞춰진 상태에서 눌러 보드로 포커스를 이동시킵니다. 보드에 포커스가 맞춰진 상태에서 다음을 수행할 수 있습니다:
  - **Ctrl+/Cmd+** 및 **Ctrl-/Cmd-**로 확대/축소합니다.
  - 화살표 키로 보드를 패닝합니다.
  - macOS에서는 **Cmd + Shift + Down**으로 보드 위의 첫 번째 객체를 선택합니다.
  - Windows에서는 **Ctrl + Shift + Down**으로 보드 위의 첫 번째 객체를 선택합니다.

### 툴바로 돌아가기

- **Escape**를 누르세요.

### 보드를 순차적으로 탐색하기

- **탭**을 사용해 왼쪽 위에서 오른쪽 아래로 순서대로 보드 객체를 이동하세요.
- **Shift + 탭**을 사용해 역순으로 이동하세요.

### 보드를 공간적으로 탐색하기

macOS

**Cmd + 화살표 키**를 사용해 보드 객체를 공간 순서대로 이동하십시오:

- **Cmd + Right** 현재 객체의 오른쪽 요소로 이동합니다.
- **Cmd + Up** 현재 객체의 위쪽 요소로 이동합니다.
- **Cmd + Down** 현재 객체의 아래쪽 요소로 이동합니다.
- **Cmd + Left** 현재 객체의 왼쪽 요소로 이동합니다.

Windows

**Ctrl + 화살표 키**를 사용하여 보드 요소를 공간 순서로 이동합니다:

- **Ctrl + 오른쪽** 현재 객체 오른쪽의 요소로 이동
- **Ctrl + 위쪽** 현재 객체 위의 요소로 이동
- **Ctrl + 아래쪽** 현재 객체 아래의 요소로 이동
- **Ctrl + 왼쪽** 현재 객체 왼쪽의 요소로 이동

### 첫 번째 또는 마지막 객체로 이동

macOS

- **Option + Shift + 왼쪽 화살표**, 또는 **Option + Home**, 현재 컨테이너의 첫 번째 객체로 이동
- **Option + Shift + 오른쪽 화살표**, 또는 **Option + End**, 현재 컨테이너의 마지막 객체로 이동

Windows

- **Alt + Shift + 왼쪽 화살표**, 또는 **Alt + Home**, 현재 컨테이너의 첫 번째 객체로 이동
- **Alt + Shift + 오른쪽 화살표**, 또는 **Alt + End**, 현재 컨테이너의 마지막 객체로 이동

### 컨테이너 객체에 들어가거나 나가기

컨테이너 오브젝트는 프레임과 그룹화된 오브젝트를 포함합니다. 컨테이너 오브젝트 안에 있을 때, 모든 내비게이션은 그 컨테이너에 한정됩니다.

macOS

- **Cmd + Shift + Down** 키로 컨테이너 오브젝트에 진입합니다.
- **Cmd + Shift + Up** 키로 컨테이너 오브젝트를 나옵니다.

Windows

- **Ctrl + Shift + Down** 키로 컨테이너 오브젝트에 진입합니다.
- **Ctrl + Shift + Up** 키로 컨테이너 오브젝트를 나옵니다.

### 오브젝트 텍스트 편집

- **Enter** 키를 눌러 오브젝트 (예: 스티커 메모)를 편집하세요.
- **Escape** 키를 눌러 오브젝트 (예: 스티커 메모) 편집을 중단합니다.

:::note
키보드 내비게이션은 오브젝트가 선택될 때만 작동하며, 편집 중에는 작동하지 않습니다.
:::

### 오브젝트 이동

- **화살표 키**로 오브젝트를 이동하세요.
- **Shift + 화살표 키**를 사용하여 오브젝트를 더 멀리 이동하세요.

### 여러 보드 오브젝트 선택

macOS

- 첫 번째 오브젝트를 선택하세요.
- **Cmd** + **Option** + **Shift** + **화살표**를 눌러 추가 오브젝트를 선택하세요.

Windows

- 첫 번째 오브젝트를 선택하세요.
- **Ctrl** + **Alt** + **Shift** + **화살표**를 눌러 추가 오브젝트를 선택하세요.

### 보드 오브젝트 크기 조정

macOS

- 크기를 조정할 보드 객체를 선택합니다.
- **Cmd** + **Option** + **Shift** + **Plus/Minus**를 누릅니다.

Windows

- 크기를 조정할 보드 객체를 선택합니다.
- **Ctrl** + **Alt** + **Shift** + **Plus/Minus**를 누릅니다.

### 객체 컨텍스트 메뉴 입력 및 탐색하기

객체의 컨텍스트 메뉴에는 색상, 유형, 혹은 텍스트 스타일 변경과 같이 객체를 사용자 지정할 수 있는 추가 기능이 포함되어 있습니다. 객체를 선택하면 해당 컨텍스트 메뉴가 객체 위에 수평으로 나타나 이러한 옵션에 접근할 수 있습니다.

macOS

- **Cmd + Enter** 키를 눌러 객체의 컨텍스트 메뉴로 포커스를 이동합니다.
- **좌/우 화살표 키**로 객체의 컨텍스트 메뉴를 탐색하고, **Enter/Space**로 항목을 선택합니다.

Windows

- **Ctrl + Enter** 키를 눌러 객체의 컨텍스트 메뉴로 초점을 이동합니다.
- **왼쪽/오른쪽 화살표 키**를 사용하여 객체의 컨텍스트 메뉴를 탐색하고 **Enter/스페이스** 키를 눌러 항목을 선택합니다.

### 새 객체 만들기

새 객체를 추가하는 가장 쉬운 방법은 커맨드 팔레트를 사용하는 것입니다:

macOS

- **Cmd+K**를 눌러 커맨드 팔레트를 엽니다.
- 객체의 이름을 입력하기 시작합니다. 예를 들어, 스티커 메모.
- **화살표 키**를 사용해 객체를 선택합니다.
- **Enter 키**를 누르면 객체가 보드의 중앙에 추가됩니다.

Windows

- **Ctrl+K**를 눌러 커맨드 팔레트를 엽니다.
- 객체 이름을 입력하기 시작합니다(예: 스티커 메모).
- **화살표 키**를 사용해 객체를 선택합니다.
- **Enter 키**를 누르면 객체가 보드의 중앙에 추가됩니다.

키보드를 사용해 객체를 생성하는 다른 방법:

- [작성 툴바](../start-here/your-first-board/05-toolbars.md)까지 탭 이동한 후, **위/아래 화살표**를 눌러 원하는 객체 유형(도형, 스티커 메모 등)에 도달하면 **Enter** 키를 누르고 **탭**을 눌러 객체를 선택한 다음 다시 **Enter** 키를 눌러 객체를 생성합니다. 객체가 보드에 배치됩니다.
- 객체와 관련된 키보드 단축키(예: 스티커 메모의 경우 **N**)를 누른 후 **탭**을 눌러 객체를 선택하고 **Enter** 키를 누릅니다. 객체가 보드에 배치됩니다.
- 기존 요소를 **Ctrl**/**Cmd+C**로 복사한 후 **Ctrl/Cmd+V**로 붙여넣기합니다.
- **Ctrl/Cmd+D**로 기존 객체를 복제합니다.
- 스티커 메모를 편집하려면 **Enter**를 누릅니다. 그런 다음 **Tab** 키를 누르면 선택한 객체 옆에 새 객체가 생성됩니다.

### 다이어그램 연결 생성

보드에서 객체 간의 연결선을 만들 수 있습니다.

- 연결할 첫 번째 객체로 탭 이동합니다.
- 커맨드 팔레트를 열려면 Cmd+K(Mac) 또는 Ctrl+K(Windows)를 누릅니다.
- "**연결할 대상 만들기**"를 입력하고 선택합니다.
- 두 번째 객체로 탭 이동합니다.
- 커맨드 팔레트를 열려면 Cmd+K(Mac) 또는 Ctrl+K(Windows)를 누릅니다.
- "**이 객체와 연결하기**"를 입력하고 선택합니다.

### 댓글

macOS

- **Option+탭**을 눌러 댓글을 앞으로 탐색합니다.
- **Option+Shift+탭**을 눌러 댓글을 앞으로 탐색합니다.
- **Option+**C를 눌러 현재 객체에 댓글을 추가합니다.

Windows

- **Alt + C**를 눌러 현재 객체에 댓글을 추가합니다.

## 보조 기술 명령어

다음 키보드 명령어는 스크린 리더와 같은 보조 기술을 사용할 때만 사용할 수 있습니다.

### 보드 요약

보드 요약은 스크린 리더 사용자에게 보드에 있는 객체들에 대한 간략한 개요를 제공합니다.

macOS

- **Option + S** 를 눌러 보드에 있는 개체의 수와 유형에 대한 정보를 받습니다.

Windows

- **Alt + S**를 눌러 보드에 있는 개체의 수와 유형에 대한 정보를 받습니다.

### 추가 개체 정보

이 작업은 화면 판독기 사용자가 현재 선택된 개체에 대한 추가 정보를 받을 수 있게 해줍니다.

macOS

- **Option + I**를 눌러 추가 개체 정보를 받습니다.

Windows

- **Alt + I**를 눌러 추가적인 객체 정보를 얻으세요.

### 객체 선택 공지

보드 객체 선택 시 제공되는 정보를 반복하여 들을 수 있습니다.

macOS

- **Option + R**을 눌러 선택 공지를 반복하세요.

Windows

- **Alt + R**을 눌러 선택 공지를 반복하세요.
