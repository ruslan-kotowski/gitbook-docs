Miro는 키보드 제어, 화면 읽기 프로그램, 음성 인식 소프트웨어를 지원합니다. 이 문서에서는 Miro를 보조 기술과 함께 사용하는 방법을 설명합니다.

> **💡** [Miro 접근성 허브](https://miro.com/accessibility-statement/)를 방문하여 자세한 정보를 얻고 최근 개발 소식을 확인하세요.

:::tip
우리는 사용자의 접근성 경험을 지속적으로 개선하기 위해 노력하고 있습니다. [accessibility@miro.com](mailto:accessibility@miro.com)으로 피드백을 보내주세요.
:::

## 권장 브라우저 및 화면 읽기 프로그램

:::note
Miro 접근성 팀은 보조 기술과의 호환성을 향상시키기 위해 꾸준히 노력하고 있으며, 다른 브라우저, 스크린 리더, 디바이스와의 호환성이 강화됨에 따라 이 목록을 지속적으로 업데이트할 예정입니다.
:::

최상의 경험을 위해 데스크톱에서 다음 브라우저와 스크린 리더를 사용할 것을 권장합니다:

### 브라우저

- Chrome
- Firefox
- Safari

### 스크린 리더

- Microsoft Windows용 NVDA
- Microsoft Windows용 JAWS
- macOS 내장 VoiceOver

### 음성 인식

- macOS용 음성 제어
- Microsoft Windows용 Voice Access

:::note
현재 모바일 및 태블릿 장치에 대한 보조 기술 지원은 제한적입니다.
:::

## 음성을 텍스트로 변환

### macOS용 음성 제어

MacOS에서 음성 제어를 활성화하면 Miro 보드에 **보드 콘텐츠 탐색** 버튼이 나타납니다.

:::note
MacOS에서 음성 제어를 활성화하는 방법은 [Apple 지원](https://support.apple.com/en-gb/102225)을 참조하세요.
:::

:::tip
Mac에서 **설정**에서 **음성 제어**를 활성화할 때 **오버레이**를 **항목 이름**으로 설정했는지 확인하세요.
:::

명령을 시작하려면 *"Explore board content"을 눌러*라고 말하세요. Miro는 보드의 각 도구 및 객체에 대해 항목 이름을 보여줍니다.

예를 들어, *"Explore board content"을 눌러*라고 말한 다음, 다음 명령을 실행하여 텍스트가 포함된 스티커 메모를 추가하세요:

1. ***스티커 메모** 누르기*
2. ***밝은 노란색 스티커 메모 배치** 누르기*
3. ***Enter** 키 누르기*
4. *“Hello World”*
5. ***Escape** 키 누르기*

### Microsoft Windows에서의 음성 액세스

Windows에서 음성 액세스를 활성화하면, *숫자 표시*라고 말합니다. 화면 중앙에 표시되는 숫자를 말하고 *클릭*을 수행하세요. 예를 들어, *클릭 44*라고 말합니다. Miro가 음성 액세스에 대해 활성화됩니다.

:::note
MS Windows용 음성 접근성 활성화 방법은 [Microsoft 지원](https://support.microsoft.com/en-gb/windows/use-voice-recognition-in-windows-83ff75bd-63eb-0b6c-18d4-6fae94050571)을 참조하세요.
:::

명령어를 시작하려면 *번호 보기*라고 말하세요. 그런 다음 사용하고자 하는 도구나 객체의 번호를 *클릭*이라고 말합니다.

## 스크린 리더

Miro 보드는 다음과 같이 구성되어 있습니다:

- 툴바
- 보드의 첫 번째 오브젝트로 건너뛰기 버튼
- 보드 내용 개요/목차
- 보드 내용

## 툴바

미로 보드에는 다섯 개의 툴바가 있습니다:

- 보드 메뉴 및 설정
- 협업 툴바
- 작성 툴바
- 보드 개요
- 확대/축소 및 내비게이션 툴바

> **💡**전체 개요는 [툴바 아티클](../start-here/your-first-board/05-toolbars.md)을 참고하세요.

### 툴바 사용 방법

- 툴바를 탐색하려면 **Tab** 키를 누르세요.
- 툴바 내에서 탐색하려면 **화살표 키**를 사용하세요.
- 항목을 활성화하려면 **Enter** 키를 누르세요.

## 보드의 첫 번째 오브젝트로 건너뛰기

**보드의 첫 번째 오브젝트로 건너뛰기** 버튼을 활성화하면 포커스가 보드의 첫 번째 오브젝트로 이동합니다.

### '보드의 첫 번째 오브젝트로 건너뛰기' 사용 방법

- Miro 보드의 첫 번째 오브젝트로 포커스를 이동하려면 **Enter** 키를 누르세요.
- **Escape** 키를 눌러 다시 툴바로 돌아가세요.

## 보드 콘텐츠 탐색

**보드 콘텐츠 탐색**은 목차처럼 보드 구조에 대한 개요를 제공하며, 이를 통해 보드 객체로 직접 이동할 수 있습니다.

### '보드 콘텐츠 탐색' 사용하는 방법

- 보드 개요를 활성화하려면, **보드 콘텐츠 탐색** 버튼에서 **Enter** 키를 누르세요.
- 화면 읽기 프로그램 내비게이션을 사용하여 개요를 탐색합니다. 예를 들어:
  - JAWS:
    - **화살표 키**를 사용하여 모든 객체를 탐색합니다.
    - **H**를 눌러 프레임과 같은 모든 컨테이너 객체를 탐색합니다.
    - **F**를 눌러 스티커 메모와 같은 모든 편집 가능한 보드 객체를 탐색합니다.
- 보드 객체로 초점을 이동하려면 **Enter** 키를 누릅니다. 그러면 Miro 보드의 객체로 초점이 이동합니다.
- 객체를 편집하려면 **Enter** 키를 다시 누릅니다.
- **Escape** 키를 눌러 보드 개요로 포커스를 이동하세요.
