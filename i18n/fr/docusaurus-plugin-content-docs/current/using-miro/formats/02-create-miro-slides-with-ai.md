Utilisez Miro IA pour accélérer le processus de création de [diapositives Miro](13-miro-slides.md).

## Créer des diapositives avec l'IA

1. Cliquez sur l'icône **Créer avec l'IA** (![icon-ai.svg](../../../../../../docs/using-miro/formats/images/30040246629394_icon-ai.svg)) au-dessus de la barre d'outils Création.
2. Dans le panneau des partenaires d'IA qui s'ouvre, cliquez sur l'onglet **Formats**.
3. Sélectionnez le format **Diapositives**.
4. Suivez les invites de l'IA pour générer une présentation.
5. Sélectionnez les objets du tableau pour les ajouter comme contexte à vos diapositives.

## Créer des diapositives à partir du contenu sélectionné

Pour créer des diapositives directement à partir du contexte fourni par les objets sur votre tableau :

1. Sélectionnez les objets du tableau que vous souhaitez inclure.
2. Dans la barre d'outils contextuelle, cliquez sur l'icône **Miro IA**.
3. Dans le menu déroulant, cliquez sur **Diapositives**.

## Créer des diapositives avec un partenaire d'IA

Pour créer des diapositives avec un partenaire d'IA :

1. Ouvrez le **partenaire d'IA** que vous souhaitez utiliser.
2. Cliquez sur l'icône **Diapositives** en bas de la boîte de prompt.
3. Entrez votre prompt et appuyez sur entrée.
4. Vos diapositives seront créées sur le tableau.

## Modifier les diapositives avec l'IA

Avant d'ajouter vos diapositives sur le tableau, vous pouvez utiliser Miro IA pour modifier des diapositives individuelles.

1. Dans le prompt de l'IA, cliquez sur **Modifier une diapositive**.
2. Sélectionnez la diapositive que vous souhaitez modifier.
3. Entrez un prompt pour apporter des modifications à la diapositive et appuyez sur entrée.
4. Examinez les modifications et itérez si nécessaire.

## Ajouter des diapositives avec l'IA

Si vous devez ajouter des diapositives supplémentaires, vous pouvez le faire avec Miro IA avant d'ajouter vos diapositives sur le tableau.

1. Dans le prompt IA, cliquez sur **Ajouter une diapositive**.
2. Entrez le sujet ou d'autres informations dans le prompt et appuyez sur Entrée.
3. Passez en revue la nouvelle diapositive et itérez si nécessaire.

## Ajouter les diapositives au canevas

Lorsque vous avez terminé d'utiliser Miro IA pour modifier ou ajouter des diapositives, cliquez sur le bouton **Ajouter au canevas** pour valider le résultat sur votre tableau.

![slides-ai.png](../../../../../../docs/using-miro/formats/images/30139722399122_slides-ai.png)

*Cliquez sur Ajouter au canevas pour valider les diapositives sur le tableau*

Une fois les diapositives ajoutées au canevas, vous pouvez modifier manuellement n'importe laquelle de vos diapositives si nécessaire.

## Exporter des diapositives en tant qu'image

Pour apprendre à exporter vos diapositives sous forme d'images depuis votre diaporama Miro, consultez [diapositives Miro](13-miro-slides.md).

## Meilleures pratiques pour générer des diapositives IA

Pour obtenir les meilleurs résultats des diapositives IA, suivez ces astuces :

- **Définissez les couleurs de votre marque** : Configurez votre palette de marque dans le [Centre de marque Miro](../../administration/get-started-as-a-miro-admin/04-brand-center.md) pour que les diapositives IA appliquent automatiquement les couleurs de votre marque.
- **Personnalisez les couleurs dans votre prompt** : Si vous n'avez pas configuré le Centre de marque, ou souhaitez utiliser d'autres couleurs, mentionnez-les dans votre prompt - soit en décrivant la couleur, soit en utilisant un code HEX.
- **Définissez la structure et la disposition** : Vous pouvez guider l'IA en spécifiant le déroulement souhaité (par exemple, « présentation de 5 diapositives : aperçu, défis, solution, résultats, prochaines étapes »).
- **Définir l'audience et le ton** : Indiquez pour qui la présentation est destinée (par exemple, "pour les dirigeants," "pour un pitch client") afin que l'IA ajuste le ton et le style en conséquence.
