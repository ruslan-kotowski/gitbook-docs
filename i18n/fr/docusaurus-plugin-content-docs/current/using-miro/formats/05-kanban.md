La vue Kanban vous permet d'organiser vos tâches en colonnes, ce qui facilite le suivi de l'avancement, l'identification des goulets d'étranglement et le maintien de l'alignement de votre équipe. Passez sans effort de Kanban à Planning et à Table pour planifier, exécuter et vous adapter en un seul endroit.

## Fonctionnalités clés

- **Personnaliser une fonctionnalité Kanban** n'importe où sur votre tableau Miro.
- **Ajouter, modifier et supprimer des cartes** dans la fonctionnalité Kanban.
- **Ajouter, modifier, supprimer et masquer des colonnes** dans la fonctionnalité Kanban.
- **Créer des couloirs** dans la fonctionnalité Kanban.
- **Glisser et déposer des pense-bêtes, des cartes Miro, et des cartes Jira** dans la fonctionnalité Kanban.
- **Grouper, trier et filtrer les cartes** pour organiser les informations de manière logique.
- **Passer au format table ou Planning** pour visualiser vos données de différentes manières.
- **Inclure plusieurs widgets Kanban** avec différentes sources de données sur le même tableau Miro.
- **Consulter et modifier votre tableau Kanban en mode plein écran** pour une concentration maximale.

## Ajouter la fonctionnalité Kanban à votre tableau

:::warning
Les éditeurs invités n’ont pas la possibilité d’ajouter ou de modifier la fonctionnalité Kanban.
:::

1. Ouvrez un tableau Miro.
2. Sélectionnez **Outils, Médias et Intégrations**(*![icon-tools.svg](../../../../../../docs/using-miro/formats/images/29210901366418_icon-tools.svg)*) dans la [barre d'outils de création](../../getting-started/start-here/your-first-board/05-toolbars.md).
3. Recherchez et sélectionnez **Kanban.**
   Votre curseur s'affiche maintenant sous forme d'icône Kanban.
4. Cliquez n’importe où sur le tableau Miro pour placer votre tableau Kanban.

## Actions sur les cartes Kanban

La fonctionnalité Kanban offre plusieurs contrôles pour les cartes, vous permettant de gérer votre travail.

### Ajouter une carte

Cliquez sur le **signe plus** (**+**) dans une colonne. Une nouvelle carte apparaîtra dans la colonne.

### Déplacer une carte

Pour repositionner ou déplacer une carte, faites glisser et déposez la carte. Une fois qu'une carte a été déplacée vers une autre colonne, le champ de colonne de la carte changera également.

### Modifier le texte d'une carte

Sélectionnez la carte, puis sélectionnez le texte. Le curseur clignotant indique que le texte est prêt à être modifié.

Pour appliquer un formatage ou ajouter un lien à du texte au sein d’une carte :

1. Double-cliquez sur la carte que vous souhaitez modifier.
   L'entrée devient modifiable.
2. Sélectionnez le texte que vous souhaitez mettre en forme.
   Un menu contextuel s’affiche.
3. Appliquez le formatage ou ajoutez un lien au texte depuis le menu contextuel ou en utilisant des [raccourcis clavier](../working-on-the-board/06-shortcuts-and-hotkeys.md).
4. Appuyez sur Entrée pour enregistrer l’entrée.

Le formatage de texte peut également être appliqué dans le volet latéral lors de la modification d’une carte.

### Changer la couleur de la carte

1. Cliquez sur la carte et un **cercle de couleur** apparaîtra.
2. Cliquez sur le **cercle de couleur** pour accéder au sélecteur de couleur.
3. Sélectionnez une couleur.

### Modifier les champs de la carte

1. Sélectionnez la carte.
2. Cliquez sur l’icône **Ouvrir l'entrée dans le panneau latéral** pour ouvrir le panneau latéral.
3. Modifiez les champs de la carte selon vos besoins.
4. Alternativement, vous pouvez passer à l’affichage en Table pour voir vos cartes Kanban en tant que lignes dans une Table.

Vous pouvez également déterminer quels champs de carte vous souhaitez afficher sur les cartes Kanban :

1. Dans l'en-tête de la fonctionnalité Kanban, cliquez sur l'icône Masquer les champs pour ouvrir le menu.
2. Sélectionnez les champs que vous souhaitez afficher ou masquer sur les cartes Kanban.
   Les cartes sont mises à jour en temps réel.

### Supprimer une carte

1. Sélectionnez une carte.
2. Appuyez sur la touche Supprimer ou Retour arrière de votre clavier. Vous pouvez également cliquer sur l'entrée et supprimer via l'icône de la corbeille.
3. L'entrée est maintenant supprimée.

## Actions sur les colonnes Kanban

Il existe plusieurs actions sur les colonnes que vous pouvez effectuer pour mieux gérer votre travail dans le widget Kanban.

### Ajouter une colonne Kanban

1. Cliquez sur **Créer une colonne** tout à droite du Kanban.
2. Vous pouvez également ajouter une colonne Kanban dans le menu **trois points** (**...**) à côté du nom d'une colonne.

### Modifier une colonne Kanban

1. Cliquez sur le **nom de la colonne**.
2. Renommez la colonne. Vous pouvez également changer la couleur de la colonne ici.
3. Vous pouvez également renommer le nom d'une colonne Kanban dans le menu **trois points** (**...**) à côté du nom d'une colonne.

### Masquer les colonnes

1. Cliquez sur l'icône **trois points** (**...**) à côté du nom de la colonne
2. Cliquez sur **Masquer la colonne** dans le menu.
3. Cliquez sur l'icône **œil** à droite pour afficher de nouveau les colonnes

### Déplacer les colonnes

1. Cliquez sur l'icône **trois points** (**...**) à côté du nom de la colonne.
2. Cliquez sur **Déplacer à gauche** ou **Déplacer à droite**.

Fonctionnalité de glisser-déposer à venir.

### Supprimer les colonnes

1. Cliquez sur l'icône **trois points** (**...**) à côté du nom de la colonne.
2. Cliquez sur **Supprimer la colonne**.

### Modifier les colonnes utilisées

1. Cliquez sur l'icône **Champ de colonne** dans l'en-tête du Kanban.
2. Sélectionnez le champ (parmi tous les champs à sélection unique) que vous souhaitez utiliser comme colonnes.
3. Alternativement, vous pouvez modifier ou créer un nouveau champ à utiliser comme colonnes.

:::note
Actuellement, seuls les champs à sélection unique sont disponibles comme colonnes.
:::

### Créer des couloirs

1. Cliquez sur l’**icône Group** dans l’en-tête de la fonctionnalité Kanban.
2. Sélectionnez les champs que vous souhaitez utiliser comme vos couloirs.
3. Vous pouvez également créer un nouveau champ à utiliser comme couloir.
4. Pour supprimer des couloirs, cliquez à nouveau sur l’**icône Group** puis sur **Supprimer le groupement**.

### Mode immersif (plein écran)

Vous pouvez modifier et consulter votre Kanban en mode immersif (plein écran). Cliquez simplement sur l’**icône de la flèche diagonale** en haut du widget. Les paramètres tels que Filtre, Trier, Grouper et Masquer les champs sont situés dans l'en-tête.

Pour revenir au canevas, cliquez sur **Aller au canevas** en haut.

## Comment ajouter des cartes Jira dans le Kanban (bêta)

Vous pouvez faire glisser et déposer des cartes Jira dans un Kanban pour créer des entrées synchronisées avec Jira. Cela signifie que vous pouvez combiner le travail de Miro et de Jira dans une vue Kanban pour gérer et suivre le travail de toute l’équipe en un seul endroit.

Pour ajouter une carte Jira à votre Kanban, suivez ces étapes :

1. Trouvez la carte Jira pertinente sur le canevas.
2. Faites glisser la carte sur le Kanban.
3. Déposez la carte dans la colonne cible au sein du Kanban.

Toutes les modifications effectuées dans Miro seront répercutées dans Jira et vice versa. Les champs suivants dans le Tableau ou le Planning seront synchronisés avec Jira :

- Titre
- Description
- Estimation
- Date de début
- Date de fin
- Responsable (bêta)
- État (bêta)

**Plus d'informations :** Voir [FAQ sur les cartes Jira](../../integrations-apps/atlassian/17-jira-cards-faq.md).
