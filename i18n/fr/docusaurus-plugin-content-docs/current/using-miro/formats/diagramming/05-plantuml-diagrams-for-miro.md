L'application PlantUML pour Miro vous permet de créer et d'intégrer des diagrammes basés sur du code directement dans vos tableaux Miro. Cette intégration simplifie votre flux de travail en vous permettant de générer des diagrammes à partir de descriptions textuelles sans quitter votre environnement Miro.

## Installer l’application PlantUML

Vous pouvez installer l'application PlantUML pour commencer à créer des diagrammes sur vos tableaux Miro. L'application est disponible depuis le Marketplace de Miro ou directement depuis la barre d'outils de création de votre tableau Miro.

1. Dans la barre de création, sélectionnez **Outils, médias et intégrations** (**+**). Le panneau **Outils, médias et intégrations** s’ouvre.
2. Dans l’onglet **Outils**, recherchez et sélectionnez **Diagrammes PlantUML**. Le panneau **Diagrammes PlantUML** s’ouvre.
3. Si demandé, sélectionnez une équipe Miro et cliquez sur **Installer et autoriser** pour terminer l’installation.

:::warning
Les utilisateurs non-admins ne peuvent pas installer d’applications si cela n’est pas autorisé dans les paramètres de l’équipe.
:::

Vous pouvez également installer l'application directement depuis le [Marketplace de Miro](http://miro.com/marketplace) ou en suivant [ce lien](https://miro.com/marketplace/plantUML/).

## Créer et ajouter des diagrammes aux tableaux Miro

Une fois l'application PlantUML installée, vous la trouverez dans la barre d'outils de Création. Procédez comme suit pour créer et ajouter vos diagrammes :

![PlantUML Diagrams app on the Creation toolbar](../../../../../../../docs/using-miro/formats/diagramming/images/21537438798994_plantuml-entry-point.png)
*L’application Diagrammes PlantUML dans la barre d’outils Création*

1. Ouvrez l'application PlantUML depuis la barre d'outils de création.
2. Saisissez votre code PlantUML dans l'éditeur. L’application inclut un exemple par défaut pour vous aider à démarrer. Au fur et à mesure que vous tapez ou modifiez le code, le diagramme dans le panneau de droite se met à jour automatiquement.

![Changing a PlantUML diagram](../../../../../../../docs/using-miro/formats/diagramming/images/21017043137938_PlantUML%20diagram.gif)
*Modification d’un diagramme*

3. Ajustez la taille du panneau de l'éditeur de code en faisant glisser son bord de droite si nécessaire.

![Modification de la largeur de l'éditeur PlantUML](../../../../../../../docs/using-miro/formats/diagramming/images/21017013630226_change%20the%20width%20of%20editor.gif)
*Modification de la taille de l’éditeur de code*

4. Lorsque votre diagramme est prêt, cliquez sur **Ajouter au tableau** (ou un bouton portant un nom similaire). Cette action génère une image de votre diagramme et la place sur votre tableau Miro.

![](../../../../../../../docs/using-miro/formats/diagramming/images/21017013631250_add%20PlantUML%20diagram%20to%20board.gif)Ajouter un diagramme PlantUML au tableau"/>
*Ajout d’un diagramme au tableau*

Après avoir ajouté le diagramme au tableau, vous pouvez télécharger l'image ou [partager le tableau avec vos collaborateurs](../../sharing-boards/03-sharing-boards-and-inviting-collaborators.md).

## Modifier les diagrammes existants

Vous pouvez modifier les diagrammes PlantUML déjà présents sur votre tableau Miro. Pour modifier un diagramme :

1. Cliquez sur le diagramme sur le tableau pour le sélectionner.
2. Cliquez sur l’icône **PlantUML** dans la barre d’outils de création. L'éditeur PlantUML s'ouvrira avec le code du diagramme.
3. Apportez vos modifications au code.
4. Cliquez sur **Mettre à jour le diagramme**. Vous retournerez à votre tableau Miro et le diagramme sera mis à jour avec vos modifications.

![Modifier un diagramme PlantUML depuis le tableau Miro](../../../../../../../docs/using-miro/formats/diagramming/images/21017013632530_diagrams_editing_plantuml_diagrams.gif)
*Modification d'un diagramme directement à partir de Miro*

## Informations supplémentaires

Pour des informations détaillées sur la syntaxe et les capacités de PlantUML, reportez-vous à la [documentation officielle de PlantUML](https://plantuml.com/). Vous pouvez également accéder rapidement à la documentation de PlantUML via le lien dans le coin inférieur gauche du panneau de l'application dans Miro.
