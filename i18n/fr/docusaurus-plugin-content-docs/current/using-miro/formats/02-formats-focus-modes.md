Les formats et les modes immersifs permettent à votre équipe de passer facilement du brainstorming libre aux documents structurés, tables, Plannings, diagrammes et diapositives. Commencez par un canevas vierge ou un format structuré, et utilisez le mode immersif pour minimiser les distractions et rester concentré. Définissez un format comme vue par défaut pour vous assurer que chaque personne ouvrant le tableau atterrit là où vous le souhaitez.

Vous pouvez trouver plus d'informations sur chacun des formats ici :

- [Documents dans Miro](12-docs-in-miro.md)
- [Tables](14-tables.md)
- [Planning](15-timeline.md)

## **Accéder aux formats**

Pour ajouter un nouveau format au canevas :

1. Cliquez sur l'**icône Outils, Médias et Intégrations** (![icon-tools.svg](../../../../../../docs/using-miro/formats/images/29210901366418_icon-tools.svg))dans la barre d'outils.
2. Sélectionnez le format dont vous avez besoin : **Documents Miro**, **Table**, **Frise chronologique**, **Diagramme**, **Prototype**,ou **Diapositives**.
3. Cliquez n'importe où sur le canevas pour ajouter le format sélectionné.

## **Mode immersif**

Tous les formats peuvent être ouverts en **mode immersif** (plein écran) lorsque vous souhaitez vous concentrer uniquement sur le format sur lequel vous travaillez et non sur les autres contenus du tableau. Pour accéder au mode immersif :

1. Cliquez n'importe où sur le format pour entrer en mode immersif.
2. Cliquez sur l'icône **Mode immersif** dans le menu contextuel.
3. Pour quitter le mode immersif, cliquez sur le bouton **Aller au canevas** en haut de l'écran.

## **Définissez un format comme vue par défaut**

N'importe lequel des formats peut être défini comme vue par défaut pour le tableau – ce qui signifie que toute personne ouvrant le tableau verra d'abord le document Miro, la table, le planning, le diagramme ou les diapositives.

Pour définir le format comme vue par défaut :

1. Cliquez n'importe où sur le format avec lequel vous souhaitez entrer en mode immersif.
2. Cliquez sur l'icône des **trois points verticaux** (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg)).
3. Sélectionnez **Définir comme vue par défaut**.
4. Dans la fenêtre modale, cliquez sur **Définir par défaut**.

### Verrouiller la vue par défaut

Les propriétaires de tableau peuvent verrouiller la vue par défaut afin que les lecteurs ne puissent pas accéder au reste du tableau. Pour ce faire :

1. Cliquez n'importe où sur le format avec lequel vous souhaitez entrer en mode immersif.
2. Cliquez sur l'icône des **trois points verticaux** (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg)).
3. Sélectionnez **Définir comme vue par défaut**.
4. Dans la fenêtre modale qui s'ouvre, cliquez sur le basculeur pour **Verrouiller la vue par défaut**.
5. Cliquez sur **Définir par défaut**.

## **Partager un lien vers le mode immersif**

Si vous souhaitez garder l'attention sur le canevas, vous pouvez toujours partager simplement un lien vers le mode immersif de votre format :

1. Cliquez n'importe où sur le format avec lequel vous souhaitez entrer en mode immersif.
2. Cliquez sur l'icône des **trois points verticaux** (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg)).
3. Sélectionnez **Copier le lien du mode immersif**.

## **Créer des formats depuis le Tableau de bord ou l'Espace**

Vous pouvez également créer tout format directement depuis votre Tableau de bord, l'aperçu de votre Espace ou la barre latérale des Espaces. Cela créera automatiquement le format comme vue par défaut—toute personne vous rejoignant sur le tableau arrivera dans le mode immersif de votre format.

1. Ouvrez votre **Tableau de bord** ou la vue d'ensemble de votre **Espace**.
2. Cliquez sur le menu **Créer nouveau**.
3. Sélectionnez le format que vous souhaitez créer : **Document**, **Diagramme**, **Prototype**, **Chronologie**, **Tableau** ou **Diapositives**.

## **Créer des formats à partir de la barre latérale des Espaces**

Lorsque vous travaillez sur un tableau, vous pouvez créer de nouveaux formats à partir de la **barre latérale des Espaces**. Le nouveau format sera créé dans le même Espace.

1. Dans la [Barre de tableau](../working-on-the-board/02-miro's-new-simplified-user-interface.md), sélectionnez le menu hamburger **Ouvrir la barre latérale**. La **barre latérale des espaces** s'ouvrira.
2. Cliquez sur l'icône **Créer un nouveau**.
3. Sélectionnez le format que vous souhaitez créer : **Doc**, **Diagramme**, **Prototype**, **Chronologie**, **Table** ou **Diapositives**.

:::tip
Vous pouvez épingler un format à votre espace. Le format épinglé apparaît dans la barre latérale des espaces.
:::
