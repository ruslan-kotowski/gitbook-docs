L'historique des tables et la gestion des versions vous permettent de voir qui a modifié quoi dans vos tables et quand. Suivez toutes les modifications de champs, ajouts de colonnes et mises à jour de données pour votre équipe, afin de collaborer en toute confiance, de résoudre rapidement les problèmes et de respecter les exigences de conformité sans quitter Miro.

## Voir l'historique des tables

1. Cliquez sur votre Table pour afficher le menu contextuel.
2. Cliquez sur l’icône Plus dans le menu contextuel.
3. Sélectionnez Historique des versions dans le menu.
   Le volet Historique des versions s’ouvrira sur le côté de votre tableau.
4. Cliquez sur la flèche à côté d'une date pour révéler l'historique des versions pour cette date, y compris qui a fait des modifications.

:::warning
Pendant la version bêta, les aperçus des versions précédentes ne sont pas disponibles. Vous pouvez toutefois Restaurer en tant que copie pour consulter les versions antérieures de votre Table.
:::

### Restaurer une version

1. Depuis le panneau de l'historique des versions, cliquez sur la flèche à côté d'une date pour afficher l'historique des versions.
2. Cliquez sur l'icône Restaurer à côté de la version que vous souhaitez restaurer.
3. Dans la boîte de dialogue qui s'ouvre, sélectionnez si vous souhaitez **Restaurer sous forme de copie** sur le tableau ou **Restaurer et remplacer** la version actuelle.

:::note
**Restaurer sous forme de copie** placera une copie du tableau à côté de votre version actuelle du tableau.
:::
