Vous pouvez modifier un modèle à tout moment, y compris le nom de votre modèle, ses catégories, sa description, ses liens vidéo, son image de couverture et son tableau.

La vidéo suivante fournit un aperçu du processus de modification.

## Entrer en mode édition

Vous pouvez entrer en mode édition de l'une des deux façons suivantes :

1. Accédez à votre modèle et sélectionnez **Modifier** en haut à droite de la page, juste au-dessus de l'aperçu.

   ![Entering the template editing mode](../../../../../../docs/using-miro/miroverse/images/19597178689938_template-1.png)

   *Activation du mode de modification du modèle*
2. Vous pouvez également activer le mode de modification d'un modèle publié directement depuis votre profil Miroverse.

   ![Entering the template editing mode from your Miroverse profile](../../../../../../docs/using-miro/miroverse/images/19597178692498_template-2.png)

   *Activation du mode de modification du modèle depuis votre profil Miroverse*

## Mettre à jour le contenu du modèle

Depuis le formulaire de modification du modèle, vous pouvez changer le tableau utilisé pour le modèle et mettre à jour ses détails.

![Formulaire de modification du modèle](../../../../../../docs/using-miro/miroverse/images/19597178694034_template-3.png)

*Formulaire de modification de modèle*

### Changer le modèle de tableau

Lorsque vous soumettez un modèle au Miroverse, une copie de votre tableau original est créée, qui devient la version active. Pour modifier le contenu du tableau dans votre modèle :

1. D'abord, modifiez votre tableau dans Miro.
2. Une fois que vous avez apporté les modifications nécessaires, retournez à votre modèle sur Miroverse et cliquez sur **Modifier**.
3. Choisissez **Modifier le tableau** en haut du formulaire.
4. Sélectionnez votre tableau mis à jour.

### Modifier les détails du modèle

Depuis ce formulaire de modification, vous pouvez également changer votre modèle :

- Nom
- Catégories
- Description
- Liens vidéo
- Image de couverture

## Publiez vos modifications

Une fois que vous avez fini de mettre à jour votre modèle, vous devez publier les modifications pour les rendre disponibles dans Miroverse.

1. Une fois que les modifications vous conviennent, prévisualisez-les.
2. Sélectionnez **Publier** pour les mettre en ligne.

Après avoir cliqué sur **Publier**, vous recevrez une confirmation par e-mail et vos mises à jour seront reflétées dans votre modèle en quelques minutes.
