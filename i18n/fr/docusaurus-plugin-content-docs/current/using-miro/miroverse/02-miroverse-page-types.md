Le Miroverse se compose de deux types de pages principales pour vous aider à trouver ce dont vous avez besoin : les pages de description de modèle et les pages de profil utilisateur.

### Pages de description de modèle

Chaque modèle dans Miroverse a sa propre page de description où vous pouvez trouver des informations détaillées sur le tableau et son créateur. Certains modèles incluent également une courte introduction vidéo qui offre une visite personnelle et un contexte supplémentaire pour vous aider à bien démarrer.

Depuis une page de description de modèle, vous pouvez également voir comment la communauté interagit avec un modèle. Vous pouvez vérifier le nombre de likes, de vues et de copies d'un modèle, et également consulter les avis d'autres utilisateurs.

### Pages de profil du Miroverse

Les pages de profil vous permettent d'en savoir plus sur les créateurs et créatrices de modèles et de voir tous les tableaux qu'ils ont publiés. Depuis la page de profil d'un créateur, vous pouvez consulter sa biographie, sa photo de profil, les liens vers ses réseaux sociaux et tous ses modèles publiés.

## Utilisez et interagissez avec le contenu du Miroverse

Vous pouvez utiliser les modèles du Miroverse et interagir avec la communauté en fournissant des retours et en aimant vos modèles préférés.

### Utiliser un modèle

Lorsque vous trouvez un modèle que vous souhaitez utiliser, cliquez sur **Utiliser le modèle** pour commencer.

Si votre compte Miro est connecté, le nouveau tableau sera automatiquement enregistré dans la section **Tous les tableaux** sous votre dernière équipe active.

:::tip
Vous pouvez facilement [déplacer le modèle créé entre des équipes](../../getting-started/start-here/your-first-board/05-toolbars.md) ou vers un espace spécifique. Pour commencer à collaborer, [invite des utilisateurs au tableau](https://help.miro.com/hc/articles/360017730693-Sharing-boards-and-inviting-collaborators) ou [active l'accès public au tableau via un lien](../sharing-boards/08-collaboration-with-visitors.md).
:::

**Plus d’informations :** Voir [Trouver et utiliser les modèles Miroverse](04-find-and-use-miroverse-templates.md).

### Aimer les modèles et donner votre avis

Toute personne connectée à son profil Miro peut ajouter des likes et des avis à un modèle dans Miroverse. Aimer un modèle est un moyen de montrer votre appréciation et d'enregistrer vos modèles Miroverse préférés pour plus tard.

- Pour montrer votre soutien, cliquez sur l’icône **♡** sur une carte de modèle ou sur la page de description du modèle.
- Pour supprimer un like, cliquez à nouveau sur l’icône **♡**.
- Pour donner votre avis ou laisser un commentaire sur un modèle, cliquez sur l'icône de message.

### Trouver des modèles aimés et des profils de créateurs

Il existe deux manières principales de trouver les modèles que vous avez likés :

- Dans le coin supérieur droit de n’importe quelle page du Miroverse, cliquez sur votre image de profil et sélectionnez **Likes**.
- Sélectionnez l’onglet **Likes** depuis n’importe quelle page de profil publique du Miroverse.

Pour en savoir plus sur un créateur ou une créatrice Miroverse et voir tous les modèles qu’il ou elle a créés, cliquez sur son nom sur n’importe quelle page ou carte de modèle. Vous pouvez consulter les modèles likés de n’importe quel créateur ou créatrice depuis leur profil Miroverse. Vous pouvez également partager vos modèles aimés depuis votre profil Miroverse. Si vous n'avez pas de profil Miroverse, vos modèles aimés sont enregistrés dans une galerie privée à laquelle seul vous pouvez accéder.
