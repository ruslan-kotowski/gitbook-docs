Miroverse est une bibliothèque de modèles de la communauté où vous pouvez découvrir et utiliser des tableaux créés par d'autres utilisateurs de Miro. Trouvez des modèles pour diverses collections, rôles et cas d’utilisation afin de démarrer votre travail.

Vous pouvez accéder au [Miroverse](https://miro.com/miroverse/) directement ou depuis votre tableau de bord Miro :

1. Sur votre tableau de bord, cliquez sur **+ Créer nouveau**.
2. Sélectionner **Explorer le Miroverse**.

La page principale présente une collection de modèles populaires, une barre de recherche et une liste de catégories pour vous aider à trouver le tableau parfait pour vos besoins.

## Trouver un modèle

Cette section décrit comment trouver des modèles dans le Miroverse en parcourant les catégories ou en utilisant la fonction de recherche.

### Parcourir par catégorie

Sur la page d'accueil du Miroverse, vous pouvez parcourir les modèles par catégorie.

1. Cliquez sur une catégorie en haut de la page pour voir tous les modèles inclus dans cette catégorie.
2. Depuis une page de catégorie, vous pouvez trier les modèles par **Ajoutés récemment**, **Les plus utilisés**, **Vues**, et **Likes**.

### Rechercher un modèle

Vous pouvez utiliser la barre de recherche pour trouver des modèles spécifiques.

1. Entrez vos termes de recherche dans le champ de recherche. Votre requête sera comparée aux titres des modèles, aux noms de profils ou aux noms d'entreprise. Les termes correspondants sont mis en évidence dans les résultats.
2. Pour revenir à la page d’accueil de Miroverse depuis une page de recherche ou de catégorie, cliquez sur **Miro | Miroverse** à côté de la barre de recherche.

:::tip
Pour partager les résultats de recherche, copiez l’URL générée dans la barre d’adresse de votre navigateur.
:::

## Utiliser un modèle

Une fois que vous trouvez un modèle qui vous plaît, vous pouvez le prévisualiser et l’ajouter à un nouveau tableau ou à un tableau existant.

1. Cliquez sur la carte d’un modèle pour ouvrir sa page et prévisualiser le contenu.
2. Sur la page de modèle, vous avez deux options :
   - Pour créer un nouveau tableau à partir du modèle, cliquez sur **Utiliser le modèle**.
   - Pour ajouter le modèle à un tableau que vous avez déjà créé, cliquez sur le menu déroulant à côté de **Utiliser le modèle** et sélectionnez le tableau.

:::note
Si vous n’avez pas de profil Miro, vous serez invité à vous inscrire gratuitement. Si vous avez un profil mais que vous n'êtes pas connecté, vous devez vous connecter pour utiliser un modèle.
:::

:::tip
Pour un accès rapide aux modèles que vous utilisez régulièrement, enregistrez le tableau en tant que [modèle personnalisé](https://help.miro.com/hc/articles/360017737473-Custom-templates).
:::
