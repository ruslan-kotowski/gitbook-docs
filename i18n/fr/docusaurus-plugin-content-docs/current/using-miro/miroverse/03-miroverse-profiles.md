## Créer un profil dans Miroverse

1. Aller au Miroverse
2. Cliquez sur **Connexion** dans le coin supérieur droit. Connectez-vous avec votre nom d'utilisateur et votre mot de passe Miro.
3. Une fois connecté, cliquez sur l'avatar dans le coin supérieur droit pour ouvrir le menu déroulant et sélectionnez **Créer un profil**.
4. Mettez à jour les valeurs Profile name (Nom de profil) **et** Username (Nom d’utilisateur)**, puis cliquez sur** Create profile (Créer un profil).

![create_profile.jpg](../../../../../../docs/using-miro/miroverse/images/21020253872402_create%20profile.jpg)*L'option de création d'un profil Miroverse*

Vous pouvez alors accéder à votre page de profil Miroverse et la modifier. Pour ouvrir votre profil Miroverse, cliquez sur l'image de profil ou l'avatar dans le coin supérieur droit.

:::note
Les informations du profil Miroverse ne sont pas connectées à votre profil Miro.  Toutes les mises à jour apportées à votre profil Miroverse public ne seront pas reflétées sur votre profil utilisateur Miro et vice versa.
:::

:::note
Votre profil n’est pas détectable dans les recherches sur Miroverse tant qu’au moins un modèle n’est pas publié sur votre profil Miroverse.
:::

## Paramètres Miroverse

Pour accéder à vos paramètres Miroverse, cliquez sur votre image de profil ou votre avatar dans le coin supérieur droit, puis cliquez sur **Paramètres**.

Dans vos paramètres Miroverse, vous pouvez modifier les détails de votre profil et gérer vos préférences en matière de notification.

![Miroverse-settings.png](../../../../../../docs/using-miro/miroverse/images/21020264880658_Miroverse-settings.png)*Ouverture des paramètres du profil Miroverse*

### Modifier votre profil

Vous pouvez modifier les informations suivantes de votre profil Miroverse :

- **Image de profil** Votre image de profil sera affichée à côté de votre nom, chaque fois qu'il apparaîtra. JPG ou PNG. Taille maximale : 5MB
- **Nom du profil** Votre nom apparaîtra sur votre page de profil public et à côté de vos tableaux. Il s’agit de la personne à qui vos tableaux seront attribués
- **Titre du poste**: Par exemple Chef de produit ou Plateforme de collaboration visuelle. Ces informations seront affichées à côté de votre nom.
- **Nom de l’entreprise**Cette information sera affichée à côté de votre titre de poste
- **Description :** C'est ici que vous pouvez indiquer des informations vous concernant
- **Liens vers les réseaux sociaux** Ces liens seront affichés sur votre page de profil public.

Sélectionnez les notifications par e-mail que vous souhaitez recevoir. Vous pouvez choisir de recevoir des mises à jour sur les **modèles**, ainsi que des **notifications sur les fils.**

![Miroverse-notification-settings.png](../../../../../../docs/using-miro/miroverse/images/21020264878866_Miroverse-notification-settings.png)*Paramètres de notification de la Miroverse*

## Afficher les badges de l’Académie Miro

Terminer des cours de l’[Académie Miro](https://academy.miro.com/) vous permet de remporter des badges. Ces badges sont mis en valeur sur votre profil Miroverse.

![badges_academie_miroverse.png](../../../../../../docs/using-miro/miroverse/images/21020253874322_miroverse_academy_badges.png)*Badges de l'Académie Miro dans la Miroverse*

## Pages de profil Miroverse pour les Experts Miro

Mettez en valeur vos services sur mesure ainsi que vos modèles les plus performants grâce à un profil unique conçu exclusivement pour les Experts Miro.

Les pages de profil de l'expert Miro affichent des informations clés sur votre entreprise, notamment son expertise, sa taille, les langues que vous prenez en charge, ainsi que vos liens vers les médias sociaux, vos modèles et vos likes.

Les utilisateurs peuvent vous contacter directement en cliquant sur le bouton " **Prendre contact"** de votre profil.

:::note
Lorsque vous consultez votre propre profil vous verrez le bouton **Submit** (Soumettre) au lieu du bouton **Get in touch** (Contactez-nous).  Pour prévisualiser la façon dont les autres utilisateurs voient votre profil, vous pouvez soit vous déconnecter, soit ouvrir votre profil en navigation privée.
:::

:::tip
En savoir plus et postuler à notre programme d'[experts Miro](../../plans-billing/miro-special-pricing/07-miro-experts.md).
:::

![Miroverse-expert-profile.pngProfil Miroverse](../../../../../../docs/using-miro/miroverse/images/21020264881810_Miroverse-expert-profile.png)
*d'un expert Miro*

:::note
L'annuaire des experts restera inchangé, mais la page d'accueil de chaque expert sera désormais redirigée vers sa page de profil Miroverse.
:::

### Modifier le profil d’Expert Miro dans Miroverse

Outre les champs de profil standard, les experts Miro peuvent modifier leurs profils Miroverse pour y inclure les détails suivants :

- Image de couverture
- Titre
- E-mail de contact (pour le bouton " **Get in touch"** )
- Taille de l’entreprise
- Langues
- Expertise

## Soumettre un modèle à Miroverse

Pour soumettre un nouveau modèle, cliquez sur **Soumettre un modèle** dans le coin supérieur droit de votre profil Miroverse. En savoir plus sur le dépôt d’un modèle Miroverse.

## Foire aux questions

**Comment puis-je supprimer mon profil Miroverse ?**

Pour supprimer votre profil Miroverse, vous devez nous envoyer un e-mail à l’adresse suivante : miroverse@miro.com. Le fait de supprimer votre profil Miroverse n’effacera pas votre profil Miro ou les tableaux existants.

**Puis-je céder à quelqu'un mon profil Miroverse ?**

Oui, le propriétaire d’un profil Miroverse peut en céder la propriété à un autre utilisateur enregistré sur Miro. Veuillez envoyer un e-mail à l’adresse miroverse@miro.com afin de demander le transfert de propriété, en incluant le nom et l’e-mail du nouveau propriétaire du profil.
