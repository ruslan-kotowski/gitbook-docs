Les widgets intelligents ajoutent de nouvelles fonctionnalités à votre canevas Miro. Il existe plusieurs widgets disponibles, y compris le vote par points, le sondage, le bloc de pense-bêtes, la roue, l’échelle d’alignement, la carte à retourner, et plus encore. Ces widgets peuvent rendre vos réunions plus efficaces et engageantes.

## Ajout de widgets intelligents

Ajouter un widget intelligent se fait via l'icône Outils, médias et intégrations (+) dans la barre d'outils.

1. Cliquez sur l’icône **Outils, médias et intégrations** (**+**).
2. Recherchez le type de widget que vous souhaitez ajouter.
3. Une fois que vous avez sélectionné le type de widget, cliquez à l'endroit où vous souhaitez placer le widget sur votre tableau.

![adding-widgets.gif](../../../../../../docs/using-miro/facilitation-tools/images/22406194748562_adding-widgets.gif)

*Ajout d'un widget avec l’icône Outils, médias et intégrations (+)*

Lorsque vous supprimez les widgets Personnes, vote par points, story points ou tailles de T-shirt, les éléments déplacés de ces widgets vers d'autres endroits sur le tableau resteront et seul le widget lui-même sera supprimé.

## Widget Personnes

Le widget Personnes vous permet d'ajouter facilement les membres de votre équipe à un objet sur votre canevas Miro. Utilisez-le à tout moment lorsque vous avez besoin d'attribuer une tâche ou d'ajouter un membre de l’équipe à un objet.

Lorsque vous faites glisser un membre de l'équipe sur un objet, son avatar apparaîtra automatiquement. Si vous faites glisser un membre de l'équipe sur une carte Jira ou Miro, le champ de l'assigné sera automatiquement mis à jour avec leurs informations.

Si vous devez changer le membre de l'équipe, vous pouvez le faire en cliquant sur l'avatar, puis sur l'icône Changer de personne dans le menu contextuel. La couleur du bord de l'avatar peut également être modifiée depuis le menu contextuel.

Les utilisateurs du tableau en ligne apparaîtront automatiquement dans le widget Personnes. Vous pouvez également rechercher une personne dans votre organisation pour l'ajouter via le widget Personnes. Épingler une personne dans votre organisation afin qu'elle reste dans le widget Personnes.

![people-widget.png](../../../../../../docs/using-miro/facilitation-tools/images/27670288049042_people-widget.png)

*Un exemple du widget Personnes*

## Widget de vote par points

Le widget Vote par points facilite le vote des membres de l'équipe lors des réunions, comme les rétrospectives. Plusieurs personnes peuvent voter en même temps avec le widget Vote par points. Le processus de vote est plus efficace depuis que les utilisateurs peuvent faire glisser et déposer des points (plutôt que de copier et coller une image).

![dot-voting.gif](../../../../../../docs/using-miro/facilitation-tools/images/22406184592402_dot-voting.gif)

*Le vote par points se fait par un simple glisser-déposer*

Lorsqu'un Point est fait glisser sur un pense-bête ou une carte, il s'y attachera. Si l'objet est déplacé, le point se déplace avec lui. Cela facilite la réorganisation ou la réorganisation des objets sans perdre de vue leurs votes.

![dot-voting-move.gif](../../../../../../docs/using-miro/facilitation-tools/images/22406194758930_dot-voting-move.gif)

*Déplacer un pense-bête déplace les votes en même temps*

## Widget de story points

Lors de la tenue d'une réunion de planification de sprint, le widget de Story points facilite le vote des membres de l'équipe sur les story points pour chaque tâche ou projet. Similaire au widget Vote par points, le widget Story Points permet aux membres de l'équipe de glisser et déposer leurs votes de story points directement sur une carte ou un Sticky. Plusieurs membres de l'équipe peuvent voter simultanément.

Lorsqu'une estimation est déposée sur une carte ou un pense-bête, elle s'attache à l'objet. Si les objets sont réarrangés ou déplacés, leurs points d'estimation se déplaceront avec eux.

Lorsque vous faites glisser un story point sur une carte Jira ou Miro, le champ des story points sur la carte sera automatiquement mis à jour.

![story-points.gif](../../../../../../docs/using-miro/facilitation-tools/images/22406194759698_story-points.gif)

*Les story points glissés sur une carte remplissent automatiquement le champ pertinent*

## Widget de taille de T-shirt

Le widget de taille de T-shirt facilite l'utilisation des tailles de T-shirt pour estimer les story points sur les cartes dans un tableau Miro. C'est similaire au widget Story points, mais utilise les tailles de T-shirt XS, S, M, L et XL pour les estimations de charge de travail.

Cela fonctionne de la même manière que le widget Story points. Faites glisser et déposez la taille de t-shirt sur la carte que vous souhaitez estimer.

![widgets-tshirt-sizes.gif](../../../../../../docs/using-miro/facilitation-tools/images/22406184595730_widgets-tshirt-sizes.gif)

*Les tailles de T-shirt peuvent être glissées directement sur les cartes*

## Widget Sondage

Le widget Poll vous permet d'intégrer des questions d'enquête directement sur vos tableaux.

![sondage-start.png](../../../../../../docs/using-miro/facilitation-tools/images/22406184597522_polling-start.png)
*Le premier panneau affiché lors de la création d'un sondage*

Pour créer un sondage :

1. Saisissez votre question de l'enquête.
2. Saisissez vos options de réponse au sondage. Vous devrez entrer au moins 2 options, mais vous pouvez en ajouter jusqu'à 10.
3. Cliquez sur **Démarrer le vote** pour activer le vote pour les autres utilisateurs.

Lorsque les utilisateurs ont voté et que votre sondage est terminé, vous pouvez finaliser le sondage et les résultats seront affichés sur le tableau.

## Bloc de pense-bêtes widget

Les pense-bêtes peuvent être créés en les glissant depuis la pile et en les plaçant sur le tableau.

![sticky-stack.gif](../../../../../../docs/using-miro/facilitation-tools/images/22916436919314_sticky-stack.gif)

*Le widget Bloc de pense-bêtes permet d'ajouter des pense-bêtes au tableau en un seul geste*

Le bloc de pense-bêtes peut être ajouté via l'icône Pense-bête :

1. Cliquez sur l’icône **Notes autocollantes** dans la **barre d’outils de création**.
2. Cliquez sur **Empiler** dans le panneau qui s'ouvre.
3. Cliquez sur le tableau où vous souhaitez placer le bloc de pense-bêtes.
4. Une fois que vous avez placé le bloc de pense-bêtes, vous pouvez utiliser le menu contextuel pour changer la forme (rectangulaire ou carrée), la taille (petite, moyenne ou grande) et la couleur des pense-bêtes.

Les blocs de pense-bêtes peuvent se voir attribuer des étiquettes via le menu contextuel. Le menu contextuel vous permet également d'afficher ou de masquer l'auteur pour chaque note adhésive extraite de la pile.

## Widget Roue

Sélectionnez une personne ou une option au hasard sur une roue en rotation sur le canevas. La roue ajoute automatiquement les personnes actuellement sur le tableau, ou vous pouvez l'utiliser avec un texte personnalisé. Jusqu'à 20 personnes ou options de texte peuvent être incluses.

Vous pouvez modifier les options pour la Roue via l'icône **Modifier** dans le menu contextuel. Pour choisir entre des personnes ou des options personnalisées, allez au menu déroulant en haut du panneau de modification.

Vous avez besoin d'au moins deux personnes ou options pour faire tourner la roue. Les éléments sont retirés de la roulette une fois qu'ils sont sélectionnés par défaut. Cela peut être modifié dans le menu Modifier.

![widgets-spinner.gif](../../../../../../docs/using-miro/facilitation-tools/images/22406184606738_widgets-spinner.gif)

*Utilisez le widget Roue pour sélectionner au hasard des personnes ou des options*

## Widget Échelle d’alignement

Évaluer le sentiment de l'équipe sur un sujet lors d'une session collaborative est plus facile avec le widget d'échelle d’alignement. Les utilisateurs sur le tableau peuvent s'ajouter à tout moment le long de l'échelle d'alignement pour indiquer où ils se situent sur l'échelle. Le titre et les étiquettes d'échelle peuvent être modifiés en cliquant dessus. Il existe cinq options de palettes de couleurs dégradées parmi lesquelles choisir.

Vous pouvez supprimer votre vote en cliquant sur votre avatar. Les votes peuvent être modifiés en cliquant ailleurs sur l'échelle ou en faisant glisser-déposer votre avatar.

Le vote anonyme peut être activé ou désactivé en cliquant sur l'icône Voter anonymement dans le menu contextuel. Les votes peuvent également être effacés depuis le menu contextuel.

![alignment-scale.gif](../../../../../../docs/using-miro/facilitation-tools/images/22916390309906_alignment-scale.gif)

*Utilisez le widget Échelle d’alignement pour évaluer visuellement le sentiment de l’équipe*

## Widget carte à retourner

Le widget de carte à retourner vous offre une manière dynamique et interactive de révéler du texte sur le canevas. Le widget de carte à retourner vous permet de créer des cartes retournables avec un titre et un texte de chaque côté. La couleur et l'orientation des cartes à retourner peuvent être personnalisées.

![flip-card.gif](../../../../../../docs/using-miro/facilitation-tools/images/25980844620306_flip-card.gif)

*Utilisation d'une carte à retourner sur le canevas*

Si vous devez randomiser l'ordre de vos cartes à retourner, vous pouvez le faire en utilisant mélanger. Sélectionnez les cartes que vous souhaitez mélanger, puis cliquez sur l'icône **Mélanger** dans le menu contextuel.
