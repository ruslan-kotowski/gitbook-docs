Lorsque vous travaillez sur un tableau, vous pouvez avoir besoin de notifier rapidement quelqu’un des changements que vous apportez. Vous pouvez le faire en les @mentionnant dans un commentaire ou un objet texte.

![A team being mentioned in a comment on a Miro board.](images/21017429414418_Screenshot%20background%20template%20%204%20(1).jpg)*L’équipe mentionnée dans un commentaire*

## Comprendre les mentions

Vous pouvez utiliser les mentions pour attirer l’attention, demander des retours ou assigner des tâches. Les mentions fonctionnent dans différentes parties de Miro, principalement dans les commentaires et les objets textuels, chacun servant des objectifs de notification légèrement différents.

## Utilisez les @mentions pour informer vos collaborateurs.

Cette section explique comment utiliser efficacement les @mentions pour communiquer avec vos collaborateurs sur un tableau Miro.

### Assurez-vous que les utilisateurs peuvent être mentionnés en partageant le tableau

Vous pouvez mentionner quelqu'un sur un tableau si le tableau est [partagé](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) avec elle. Le tableau peut être :

- [Partagé explicitement](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) avec l’utilisateur qui doit être mentionné.
- [Shared with the project">Partagé avec le projet](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md).
- [Partagé avec toute l'équipe](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md).

### Ajouter une mention dans un objet texte

:::note
Les mentions d’objet texte ne sont pas disponibles sur l’application mobile à l’heure actuelle.
:::

Vous pouvez faire référence à d'autres utilisateurs et groupes d'utilisateurs sur le tableau dans des objets textuels tels que les [pense-bêtes](../essential-tools/14-sticky-notes.md), les [formes](../essential-tools/11-shapes.md) et le [texte](../essential-tools/16-text.md). Pour ce faire, tapez simplement @ suivi du nom de l'utilisateur dans l'objet texte. Les utilisateurs ne recevront pas de notifications dans le fil d’actualité pour les mentions d’objet texte. Utilisez les mentions d’objet texte lorsque vous souhaitez :

- Spécifiez qui est visé.
- Clarifiez l’implication dans une tâche ou une discussion
- Prenez une note sans avoir besoin d'entrée ou d'attention immédiate de la personne mentionnée.

### Ajouter une mention dans un commentaire

Vous pouvez vous mentionner, mentionner d'autres utilisateurs ou des groupes entiers comme le tableau, l'équipe ou le projet dans les [commentaires](asynchronous-tools/01-comments.md). Pour ce faire, ouvrez un commentaire, tapez @ suivi du nom de l’utilisateur ou du groupe. Les mentions de commentaire sont idéales pour la communication quotidienne et lorsque vous souhaitez que les utilisateurs reçoivent des notifications. Utilisez les mentions de commentaire pour :

- Démarrez une discussion ou demandez des retours
- Assignez des tâches aux personnes
- Adressez des commentaires à des personnes spécifiques.

### Exécuter des commandes de mention spécifiques

:::tip
Lorsque vous recherchez des noms d'utilisateur, tapez quatre caractères ou plus pour obtenir de meilleurs résultats.
:::

**Mentionnez-vous**

Pour vous mentionner, tapez @ suivi de **votre nom**. C'est utile pour :

- Assignez-vous des tâches
- Indiquez votre implication dans une tâche ou une discussion.
- Définissez des rappels pour vous-même dans les notifications (fonctionne uniquement pour les commentaires).

**Mentionner un utilisateur spécifique**

Pour notifier une personne spécifique, tapez @ suivi du **nom de l'utilisateur**. Vous pouvez par exemple utiliser cela pour :

- Pour demander à un éditeur de partager davantage de détails.
- Pour demander à un membre de votre équipe de réviser votre travail une fois que vous avez terminé.
- Pour joindre un expert de votre équipe au sujet d’un domaine sur lequel vous travaillez actuellement.

:::note
Si le nom d'un utilisateur ne figure pas dans la liste lorsque vous essayez de le mentionner dans un commentaire, vous devriez l'inviter au tableau par e-mail, dans l'équipe (si le tableau est [partagé avec l'équipe](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)) ou dans le projet (si le tableau appartient à un [projet](../sharing-boards/16-projects.md)).
:::

**Mentionner tout le monde sur le tableau**

Pour notifier toutes les personnes ayant accès au tableau actuel, tapez **@tableau**. Considérez d'utiliser ceci pour :

- Demandez les avis de toutes les personnes participantes sur le tableau.
- Pour demander des retours après une réunion tenue sur le tableau.
- Communiquez des mises à jour importantes pertinentes pour tout le monde sur le tableau.

Une mention **@tableau** n'inclut pas les membres de votre projet ou de votre équipe si le tableau n'est pas partagé avec eux directement ou via le partage de projet/équipe qui leur donne accès à ce tableau spécifique.

**Mentionner les membres du projet**

Pour notifier tous les membres d’un [**projet**](../sharing-boards/16-projects.md) spécifique, tapez **@projet** (si le tableau fait partie d’un projet). Cela peut vous aider à :

- Demandez des mises à jour sur l'état du projet auprès des membres du projet.
- Pour informer une équipe de projet des modifications éventuelles en matière d’échéances.
- Pour présenter un nouveau membre de l’équipe qui se charge d’une partie spécifique du projet.

:::tip
Vous pouvez combiner **@project** et des mentions directes pour obtenir des informations d'une équipe interfonctionnelle.
:::

**Mentionner des membres d’équipe**

Pour notifier tous les membres de votre équipe, tapez **@équipe**. Utilisez ceci pour :

- Pour inviter tout le monde dans l’équipe à commenter une stratégie générale.
- Recueillir des retours sur une structure organisationnelle ou un plan de processus.
- Demandez à tout le monde de donner son avis pendant les sessions d'idéation à l’échelle de l’équipe.

### Suivez les fils de commentaires pour les mises à jour

Pour rester informé des réponses à un commentaire, vous pouvez suivre son fil de discussion. Vous pouvez le faire en suivant ces étapes :

1. Localisez le commentaire que vous souhaitez suivre.
2. Cliquez sur l'icône **Suivre le fil de discussion** dans le coin supérieur droit du commentaire.

![The 'Follow thread' icon on a comment in Miro.](../../../../../../docs/using-miro/facilitation-tools/images/21017416358290_start%20following%20a%20thread.jpg)*Suivre un fil de discussion*

:::tip
Survolez le nom d’un utilisateur dans une mention ou un commentaire pour voir sa carte de profil.
:::

## Informations supplémentaires sur les mentions

Cette section fournit plus de détails sur les fonctionnalités spécifiques de mention et leurs restrictions.

### Mentionner les capacités et les restrictions

:::warning
Pour des raisons de sécurité, [les invités](../sharing-boards/07-collaboration-with-guests.md) peuvent uniquement trouver et @mentionner les utilisateurs directement invités au tableau. [Les visiteurs](../sharing-boards/08-collaboration-with-visitors.md) ne peuvent pas mentionner les autres utilisateurs.
:::

### Fonction de mentions suggérées

> **Forfaits :** Business, Enterprise, Education

Lorsque vous tapez **@** dans la barre de commentaires, Miro peut vous montrer une liste de mentions suggérées. Cette liste comprend les utilisateurs que vous avez mentionnés auparavant et qui ont actuellement accès au tableau.

Si la [confidentialité de l'équipe](../../enterprise-administration/managing-enterprise-teams-and-content/11-manage-team-privacy-and-discovery-on-enterprise-plan.md) est activée sur un plan Enterprise, seuls les utilisateurs de la même équipe seront suggérés.
