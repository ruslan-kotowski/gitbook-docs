Vous avez besoin de décider rapidement quelle option ou quelle idée votre équipe préfère ? Organisez une session de vote directement dans le tableau Miro grâce à notre outil de vote.

> **Disponible pour :** les forfaits Starter, Business, Enterprise et Education
> **Disponible sur :** Version navigateur, [application de bureau](../../getting-started/apps-for-devices/05-desktop-app.md), [application pour tablette](../../getting-started/apps-for-devices/11-tablet-app.md)
> **Installation par :** Les membres de l’équipe ayant des droits de modification. Tous les utilisateurs peuvent participer à la session de vote.

### Configurer une session de vote

L'outil est disponible dans le coin supérieur droit, dans la barre d'outils de collaboration, sous l'icône **Outils de facilitation et Réactions**.

![voting-entry-point.pngV](../../../../../../docs/using-miro/facilitation-tools/images/21537451582994_voting-entry-point.png)*icône de vote dans la barre d'outils de collaboration*

:::note
Si le vote n’est pas disponible pour vous, assurez-vous que le tableau est stocké dans une équipe disposant d’un forfait payant ou Education.
:::

Le panneau de vote s’affiche sur le côté droit de votre tableau. Vous pouvez y accéder aux paramètres de vote, dont la plupart sont facultatifs. Avant de commencer la session :

- définissez les objets sur lesquels vous souhaitez que vos participants votent en paramétrant la zone de vote. Filtrez rapidement les objets sur lesquels voter et sélectionnez des sous-catégories comme des pense-bêtes
- fixez le nombre de votes par personne en utilisant les boutons **+** et **-** ou en saisissant le nombre (notez que le vote est anonyme, le nombre maximum de votes est de 99)
- définissez la durée de la session de vote en utilisant les boutons **+** et **-** ou en saisissant le nombre, choisissez entre les minutes, les heures et les jours
- si chaque participant ne doit émettre qu’un seul vote par objet, activez la bascule correspondante (facultatif)

Une fois les paramètres définis, cliquez sur **Start** (Démarrer).

![installation_de_vote.jpg](../../../../../../docs/using-miro/facilitation-tools/images/21017042464914_voting%20setup.jpg)*Mise en place d’une session de vote*

Vous pouvez également organiser une session de vote et la sauvegarder pour une présentation ultérieure. Configurez la session de vote comme vous le feriez normalement, mais au lieu de cliquer sur **Démarrer**, cliquez sur **Ajouter au tableau**.

### Vote en cours

Vous et vos collaborateurs du tableau pourrez participer à la session ou l’ignorer. Dès que vous avez mis en place le vote, les participants au tableau (y compris les utilisateurs enregistrés et les utilisateurs non enregistrés) verront une fenêtre contextuelle les informant que la session de vote a commencé et leur indiquant le temps dont ils disposent pour voter.

Si un utilisateur a accidentellement ignoré le vote, il peut y participer en cliquant sur l’icône de vote dans la barre d’outils. L’icône indique le temps restant.

Ceux qui rejoignent la session pourront voter sur les objets en cliquant sur les icônes plus adjacentes. Tous les votes sont **anonymes**. Un participant peut signaler qu’il a voté en cliquant sur **I’m done** (J’ai terminé). Les participants peuvent voir la progression des autres utilisateurs (qui ont fini de voter) en cliquant sur **Participants**.

![voting-in-progress.pngSéance](../../../../../../docs/using-miro/facilitation-tools/images/21537435599250_voting-in-progress.png)
*de*

Vous pouvez modifier vos votes pendant la session de vote en cliquant sur les icônes plus et moins sur les objets sélectionnés. Si vous avez fermé le panneau de vote, vous pouvez rouvrir la session de vote en cliquant sur le bouton de vote dans la barre d’outils.

### Comment ça marche pour l’animateur

L’auteur du vote verra la progression du vote sur dans le coin supérieur droit du tableau. Cliquez sur **Participants** pour connaitre le nombre de votes par personne et savoir si les participants ont fini de voter. Vous pouvez également **mettre fin à la session de vote** à tout moment et ajouter des minutes en cliquant sur les boutons correspondants.

Si vous devez réinitialiser la session de vote en cours, mettez fin à la session et démarrez-en une nouvelle.

### Résultats du vote

Une fois la session terminée, tous les participants au vote peuvent voir les trois meilleurs résultats et cliquer sur le bouton **See all results** (Voir tous les résultats).

Si vous cliquez sur **Voir tous les résultats**, vous verrez la liste des résultats de la session sur le panneau de vote. Votre historique de vote et les résultats des autres sessions sont disponibles dans l’onglet correspondant. Vous pouvez également choisir de garder les résultats du vote visibles sur le tableau en utilisant la bascule de l'onglet **Résultats.**

![résultats du vote-tenir.png](../../../../../../docs/using-miro/facilitation-tools/images/21537451600658_voting-results-keep.png)

*La case à cocher Afficher les résultats sur le tableau dans l'onglet Résultats*

Pour renommer une session de vote ou supprimer des résultats de vote, ouvrez une session et cliquez sur les icônes correspondantes.

## Foire aux questions

1. *Puis-je exporter les résultats des votes ?*
   - Il n’y a pas d’option pour exporter les résultats du vote, mais vous pouvez faire une capture d’écran pour contourner le problème.
2. *Qui peut participer à une session de vote ?*
   - Tous les utilisateurs du tableau.
3. *Je suis éditeur d’un tableau mais je ne peux pas lancer une session de vote. Pourquoi ?*
   - Vous ne pouvez pas lancer une session de vote si vous êtes un invité au tableau ou un visiteur qui peut modifier. Seuls les membres de l’équipe disposant de droits d’édition peuvent mettre en place un vote.
4. *Si je [duplique mon tableau](../managing-boards/03-how-to-duplicate-a-board.md), les résultats de la session de vote seront-ils sauvegardés sur la copie du tableau ?*
   - Non, ils ne le feront pas.
5. *Comment faire pour que les participants puissent voter pour des mots/phrases distincts dans une zone de texte ?*
   - Notez qu’un utilisateur peut voter pour une zone de texte entière. Si vous souhaitez qu’ils votent pour des mots/phrases distincts dans la boite, veuillez placer chaque mot ou phrase dans une boite de texte séparée.
6. *Fournissez-vous un outil de vote par points ?*
   - Essayez d’utiliser [ce modèle](https://miro.com/templates/dot-voting/) à partir de la bibliothèque de modèles ou ajoutez le modèle à partir du [sélecteur de modèles](../../getting-started/start-here/your-first-board/04-templates.md).
