Les propriétaires et les copropriétaires de tableaux peuvent contrôler l’utilisation des outils de collaboration du tableau en définissant qui peut lancer [le minuteur](16-timer.md), [le vote](19-voting.md) et le [chat vidéo](18-video-chat.md) et qui peut utiliser [la gestion de l’attention](04-attention-management.md) sur un tableau.  Cela vous permet de définir le groupe d’utilisateurs qui devrait avoir accès au kit d’animation de réunion. Bien que seuls les utilisateurs sélectionnés puissent lancer ces outils de collaboration, les autres personnes participant au tableau peuvent les utiliser. Par exemple, un propriétaire de tableau peut lancer le vote pour permettre à toutes les personnes participant à la réunion de voter.

Ouvrez le menu **Partager** d’un tableau et allez dans **Paramètres de partage**, basculez sur **Autorisations** et sélectionner une option dans le menu déroulant sous **Qui peut démarrer les outils de collaboration**.  Vous pouvez autoriser tous les éditeurs (sauf les visiteurs invités via un lien) ou uniquement les propriétaires et les copropriétaires de tableau.
