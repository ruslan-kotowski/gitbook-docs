Stimulez la collaboration au sein de l’équipe grâce aux commentaires. Partagez vos pensées et vos idées directement sur vos tableaux, engagez des discussions fructueuses et rendez chaque projet plus interactif et plus productif.

- **Entamez des conversations** directement sur le tableau avec des commentaires.
- **Participez aux discussions** et améliorez le travail d’équipe en toute simplicité.
- **Utilisez les @mentions** pour informer vos coéquipiers.
  - Si vous êtes mentionné dans un commentaire, celui-ci comportera le symbole @.
  - Les nouvelles mentions sont **bleues**.
  - Les mentions de lecture sont **blanches**.
- **Rattrapez rapidement votre retard**:
  - Les nouveaux commentateurs sont **en bleu**.
  - Les commentateurs sont **blancs**.
  - Les commentaires résolus sont **vérifiés**.

## Comment ajouter des commentaires ?

1. Cliquez sur l’icône **Commentaire** dans la [barre d’outils Création](../../../getting-started/start-here/your-first-board/05-toolbars.md) à gauche, ou appuyez sur la [touche de raccourci](../../working-on-the-board/06-shortcuts-and-hotkeys.md) **C.**
2. Pour ajouter un commentaire, cliquez n’importe où sur le tableau ou sur un objet. Après avoir cliqué, commencez à taper pour rédiger votre commentaire.
3. Utilisez les [@mentions](../01-@mentioning-people-on-the-board.md) pour taguer quelqu’un. Pour les [mentions suggérées](../01-@mentioning-people-on-the-board.md), commencez simplement à taper @. Vous pouvez également vous taguer vous-même pour vous assigner des tâches et définir des rappels dans les notifications de votre [flux](../../managing-boards/10-feed.md).
4. Pour publier votre commentaire, cliquez sur le bouton bleu **Publier** ou appuyez sur **Entrée.**

> **✏️** Travailler directement avec des objets ? Cliquez sur n’importe quel objet du tableau pour ouvrir son menu contextuel et ajouter un commentaire.

> **✏️** Utilisez **Shift + Enter** pour commencer une nouvelle ligne dans votre commentaire. La mise en forme du texte n’est pas prise en charge dans les commentaires.

![Icône de commentaire.png](https://help.miro.com/hc/article_attachments/21016057404306)*Cliquer sur l’icône du commentaire dans la barre d’outils Création*

### Rédiger un commentaire

Si vous quittez le commentaire sans cliquer sur le bouton **Publier** ou appuyer sur **Entrée**, votre commentaire sera enregistré en tant que brouillon.

Pour accéder à votre projet de commentaire, cliquez sur le tableau pour ouvrir le fil des commentaires. Vous verrez le projet de texte. Si votre projet est une réponse à un fil de commentaires existant, il vous suffit de cliquer sur le commentaire pour ouvrir le fil et trouver votre projet.

![Draft-saved-notification.png](https://help.miro.com/hc/article_attachments/21016057406226)
*Notification de projet sauvegardé*

### Modifier un commentaire

Pour modifier un commentaire, cliquez sur le corps du texte, mettez-le à jour si nécessaire, puis cliquez sur **Enregistrer.**

![Editing-a-comment.png](https://help.miro.com/hc/article_attachments/21016057407250)
*Editer un commentaire*

### Supprimer un commentaire

Pour supprimer un commentaire du tableau, ouvrez-le, cliquez sur les trois points (**...**) et sélectionnez **Supprimer.**

:::warning
Il n’est pas possible de supprimer plusieurs commentaires ou tous les commentaires à la fois du tableau. En outre, la suppression d’un utilisateur d’une équipe ne supprime pas automatiquement ses commentaires sur les tableaux de l’équipe.
:::

![Deleting-a-comment.png](https://help.miro.com/hc/article_attachments/21016044041746)
*Supprimer un commentaire*

### Choisir une couleur pour commenter

Personnalisez vos commentaires avec des couleurs pour signifier l’importance ou catégorisez les messages pour votre équipe. Par exemple, utilisez le bleu pour les idées et le vert pour les discussions. Pour modifier la couleur d’un commentaire, ouvrez-le et sélectionnez une couleur dans les options situées en haut.

![Changing-the-color-of-a-comment.png](https://help.miro.com/hc/article_attachments/21016057408658)
*Changer la couleur d’un commentaire*

## Panel de commentateurs

Le panneau Commentaires rassemble toutes vos mentions et commentaires. Pour ouvrir le panneau Commentaires, cliquez sur l'icône **Activité** dans la barre d'outils Collaboration en haut à droite. En sélectionnant un commentaire dans le tableau, vous accédez instantanément à son emplacement sur le tableau.

![commentaires-points d'entrée.png](https://help.miro.com/hc/article_attachments/21857915019666)

## Attacher des commentaires aux objets

Attachez un commentaire directement à n’importe quel objet pour vous assurer qu’ils se déplacent ensemble sur le tableau. Pour ce faire, il suffit de positionner le commentaire sur l’objet souhaité. Si vous devez déplacer un commentaire vers un autre objet, cliquez dessus et faites-le glisser vers le nouvel emplacement.

![Commentaires attachés à des objets.png](https://help.miro.com/hc/article_attachments/21016044059154)*Commentaires attachés à une forme et à une pense-bête*

:::warning
Les commentaires attachés aux objets ne peuvent pas être copiés, coupés ou collés avec les objets. En outre, les commentaires ne peuvent pas être exportés. Toutefois, si vous [dupliquez un tableau](../../managing-boards/03-how-to-duplicate-a-board.md), tous les commentaires seront copiés avec lui.
:::

## Gestion des notifications

Ne manquez jamais une mise à jour de la conversation. Suivez toutes les discussions ou seulement celles qui vous intéressent. Dès que vous laissez un commentaire, répondez ou êtes [@mentionné](../01-@mentioning-people-on-the-board.md), vous recevrez une notification. Lorsque vous souhaitez ne plus recevoir de mises à jour, il vous suffit de désactiver la fonction de suivi du fil de discussion.

:::tip
Vous pouvez ajuster vos [préférences de notification](../../managing-your-profile/02-miro-notifications.md) dans les paramètres de votre profil.
:::

### Suivez tous les fils de commentaires

Pour suivre toutes les discussions d'un tableau, allez dans l'en-tête du tableau dans le coin supérieur gauche, cliquez sur l'icône des trois points (**.**..) **et**, sous **Préférences**, activez l'option **Suivre toutes les discussions.**

![comments-follow.pngL'](https://help.miro.com/hc/article_attachments/21857915026578)
*option permettant de suivre tous les fils de discussion*

### Suivre un fil de commentaires spécifique

Pour suivre un fil de discussion spécifique, ouvrez le commentaire et cliquez sur l’icône **Suivre le fil de discussion** dans le coin supérieur droit.

![Turning-on-follow-thread.png](https://help.miro.com/hc/article_attachments/21016044049682)
*L’option de suivre un fil de discussion spécifique*

### Épingler un fil

Laissez des fils de commentaires ouverts sur le tableau pour la discussion et le brainstorming. Pour garder un fil de discussion ouvert sur le tableau, ouvrez le commentaire, cliquez sur les trois points (**...**) et sélectionnez **Épingler.**

En épinglant plusieurs commentaires, vous pouvez garder plusieurs fils de discussion ouverts simultanément sur votre tableau.

![Pinning-a-comment-to-keit-open.png](https://help.miro.com/hc/article_attachments/21016057423378)
*Épingler un commentaire*

## Gestion des commentaires

Marquez les commentaires comme lus ou non lus pour mieux vous concentrer sur les messages importants et les tâches qui requièrent votre attention.

### Marquer un commentaire comme non lu

Pour marquer un commentaire comme non lu, ouvrez le commentaire, cliquez sur les trois points (**...**) et sélectionnez **Marquer comme non lu.**

![Marking-a-comment-as-unread.png](https://help.miro.com/hc/article_attachments/21016057419666)
*Marquer un fil de commentaires comme non lu*

### Marquer tous les commentaires comme lus

Pour marquer tous les commentaires comme lus, ouvrez le panneau Commentaires, cliquez sur l'icône **Paramètres** et sélectionnez **Marquer tous comme lus.**

![comments-mark-as-read.pngMarquer](https://help.miro.com/hc/article_attachments/21857915028882)
*tous les commentaires comme lus*

### Résoudre un commentateur

Concentrez votre attention là où elle est le plus nécessaire. Vous pouvez marquer n’importe quel fil de commentaires comme résolupour le masquer du tableau. Ouvrez le commentaire et, dans le coin supérieur gauche, cliquez sur **Résoudre.**

![Resolving-a-comment-thread.png](https://help.miro.com/hc/article_attachments/21016044056978)
*Résoudre un fil de commentaires*

### Afficher les commentaires résolus

Pour afficher les commentaires résolus, ouvrez le panneau Commentaires, cliquez sur le menu déroulant **Afficher** et activez l’option **Afficher les commentaires résolus**.

![Show-resolved-comments.png](https://help.miro.com/hc/article_attachments/21016044060050)
*Afficher les commentaires résolus*

### Réagir aux commentaires avec des émojis

Cliquez sur l’icône d’émoji à côté d’un commentaire pour ajouter une réaction.

![Reacting-to-a-comment-with-emojis.png](https://help.miro.com/hc/article_attachments/21016044058002)

### Masquer les commentaires sur le tableau

Pour masquer tous les commentaires sur le tableau, ouvrez le panneau Commentaires, cliquez sur l'icône **Paramètres** et désactivez l'option **Afficher les commentaires sur le tableau.**

## Commentaires dans l’application mobile

Participez sans effort aux discussions sur notre application mobile, où la navigation dans les commentaires et les fils de discussion offre une expérience transparente similaire à celle de la version de bureau.

**Consulter les commentaires et y répondre :**

- **Fils ouverts**: Tapez sur un commentaire pour afficher l’ensemble du fil de discussion.
- **Laissez une réponse**: Faites part de vos réflexions et contribuez à la conversation.
- **Résoudre le problème**: Marquez les discussions comme terminées.
- **Gérer les notifications**: Commencez ou arrêtez de suivre le fil en appuyant sur l’icône de la cloche.
- **Personnalisez la visibilité**: Modifiez la couleur du commentaire pour en faciliter la consultation et l’organisation.

**Ajout d’un nouveau commentateur :**

Le processus d’ajout d’un commentaire sur mobile diffère légèrement de l’expérience sur ordinateur :

1. Appuyez sur l’icône plus**(+)** située dans le coin inférieur droit de votre écran.
2. Choisissez **Commentaire** pour partager votre nouvelle pensée ou idée.
