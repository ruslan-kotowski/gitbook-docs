Les Activités sont la fonctionnalité principale de Miro Engage, un outil d'engagement pour les réunions et ateliers conçu pour booster l'engagement de l'audience et récolter des insights des participants à grande échelle. Les Activités permettent aux animateurs de réaliser des exercices interactifs (comme des questions à choix multiples ou ouvertes) depuis leurs tableaux Miro.

Les utilisateurs peuvent participer directement sur le tableau ou rejoindre via mobile en scannant un code QR ou en entrant un code (aucun compte ou téléchargement d'application nécessaire).

Les réponses sont visualisées en temps réel, rendant vos ateliers et présentations plus inclusifs et dynamiques.

Les activités fonctionnent mieux avec les diapositives Miro, mais peuvent être placées n'importe où sur votre tableau. Elles peuvent également être utilisées avec les flux d’IA et les partenaires d'IA.

:::note
Les activités sont gratuites pendant la phase bêta.
:::

## Ajouter des activités au canevas

Les activités peuvent être ajoutées directement au canevas. Pour les ajouter :

1. Cliquez sur l'icône **Outils, Médias et Intégrations** ou sur l'icône **Cadres** dans la barre d'outils Créer.
2. Recherchez et sélectionnez **Activités** ou, si vous accédez via le menu Cadres, sélectionnez **Activités**.
3. Des diapositives seront ajoutées au canevas avec une diapositive d'instructions de participation et une deuxième diapositive où vous pourrez choisir quelle activité ajouter.
4. Sélectionnez l'activité que vous souhaitez ajouter sur la deuxième diapositive.
5. Pour ajouter des diapositives d'activité supplémentaires dans le cadre, cliquez sur l'icône **Ajouter un modèle** à côté d'une diapositive existante, puis sélectionnez l'onglet **Activités**.
6. Dans l'onglet **Activités**, sélectionnez l'activité que vous souhaitez ajouter.

## Ajouter des Activités aux Diapositivess

1. Créez un nouveau jeu de diapositives Miro sur votre tableau ou ouvrez un tableau existant contenant les diapositives que vous allez utiliser. **Plus d'information :** [Diapositives Miro](../formats/13-miro-slides.md).
2. Cliquez sur l'icône **Ajouter un modèle** à côté d'une diapositive existante pour ouvrir une fenêtre modale vous permettant d'ajouter de nouvelles diapositives.
3. Passez à l'onglet **Activités** dans la fenêtre modale.
4. Sélectionnez l'une des options :
   1. **Diapositive d'instructions de connexion :** Affiche les codes QR et de session pour que les participants puissent se joindre.
   2. **Sondage à choix multiples :** Créez des questions de vote avec plusieurs options de réponse.
   3. **Questions ouvertes :** Collectez des réponses écrites de votre audience.
   4. **Nuage de mots :** Visualisez les réponses les plus fréquentes recueillies.
5. Ajoutez le contenu applicable à votre nouvelle diapositive Activités.

## Ajouter des activités individuelles au canevas

Les activités fonctionnent également sur le canevas. Pour les ajouter :

1. Cliquez sur l’icône **Outils, médias et intégrations**.
2. Recherchez et sélectionnez soit **Choix multiples**, **Questions ouvertes**, ou **Nuage de mots**. Vous pouvez également rechercher les Activités pour voir les options disponibles.
3. Cliquez sur le tableau où vous souhaitez placer votre activité.
4. Ajoutez le contenu adapté à votre nouvelle activité.

## Activités disponibles

### **Instructions de connexion**

L'activité Instructions pour rejoindre est disponible lors de l'ajout d'une nouvelle diapositive. Elle inclut un code QR et un lien avec un code qui permet aux utilisateurs sur un appareil mobile de se joindre aux activités pendant votre présentation.

### **Choix multiple**

L'activité ``choix multiple`` vous permet de réaliser un sondage pour recueillir des opinions et parvenir à un consensus sur un sujet.

Après avoir ajouté une activité de choix multiple :

1. Entrez la question ou le sujet du sondage dans le champ approprié.
2. Ajoutez vos options dans les champs **Options**. Ajoutez d'autres options avec le bouton **Ajouter une option** en bas de la liste.
3. Cliquez sur **Terminer la modification** pour finaliser la diapositive.

**Paramètres**

- Afficher les résultats sous forme de % : Affiche la proportion des votes, au lieu du nombre de votes.
- Votes anonymes : Masque le nom et l'avatar sur les votes placés pour des entrées anonymes.
- Autoriser plusieurs votes : Vous permet de définir le nombre de votes par personne pour sélectionner plusieurs options. Valeur maximale de 20.

Lorsque les utilisateurs votent sur des appareils mobiles, ils peuvent cocher et décocher des cases avant de cliquer sur **Soumettre**. Sur le canevas, les participants peuvent voter (ou changer leur vote) jusqu'à ce que l'Activité soit arrêtée.

### **Réponses ouvertes**

L'activité de réponses ouvertes vous permet de collecter des réponses textuelles libres pour partager des réflexions sur un sujet.

Après avoir ajouté une activité de Réponses ouvertes :

1. Saisissez le texte dans le champ **Saisir la question du sondage**.
2. Cliquez sur **Terminer la modification** pour ajouter la diapositive Open-ended au canevas.

**Paramètres**

- Réponses anonymes : Masque le nom et l'avatar sur les réponses soumises pour les entrées anonymes.
- Limiter les réponses par personne : Vous permet de définir le nombre de réponses par personne. Par défaut, il n'y a pas de limite.

Lorsque l'Activité est lancée, les utilisateurs peuvent ajouter leurs réponses depuis un appareil ou sur le canevas. Les réponses soumises ne peuvent pas être modifiées.

### **Nuage de mots**

L'activité de nuage de mots vous permet de visualiser les pensées les plus populaires sur un sujet. Les mots utilisés plus fréquemment apparaîtront en plus grand dans le nuage de mots.

Après avoir ajouté une activité de nuage de mots :

1. Entrez le texte dans le champ **Entrez votre question**.
2. Cliquez sur **Terminer la modification** pour ajouter la diapositive de nuage de mots au canevas.

**Réglages**

- Réponses anonymes : Cache le nom et l'avatar sur les réponses soumises pour des entrées anonymes.
- Limiter les réponses par personne : Vous permet de définir le nombre de réponses par personne. Par défaut, il n'y a pas de limite.

## Présenter avec les Activités

Cliquez sur **Démarrer la présentation** dans le menu contextuel des diapositives Miro.

Lorsque vous arrivez sur la diapositive **Instructions pour rejoindre**, les participants peuvent se joindre depuis n'importe quel appareil (téléphone, ordinateur portable, tablette) en procédant ainsi :

1. Scanner le code QR avec l'appareil photo de leur téléphone.
2. Visiter miro.com/join et entrer le code de session. Pour des raisons de sécurité, le code de participation à 6 chiffres change toutes les 10 minutes.

Naviguez à travers les diapositives comme dans une présentation normale. Les participants verront et interagiront avec les activités au fur et à mesure .

:::note
Lorsqu'une diapositive est présentée sans activité, les participants voient un écran **En attente d'activité**.
:::

## Participer aux Activités

### Depuis un appareil mobile

Vous pouvez rejoindre les **Activités** en scannant le code QR partagé par l'animateur ou en entrant le code à 6 chiffres sur [miro.com/join](http://miro.com/join). Vous n'avez pas besoin d'un compte Miro pour participer.

En rejoignant, vous serez invité à entrer votre nom.

Lorsque l'animateur ne présente pas d'Activité, vous verrez une page **En attente de la prochaine activité**.

Lorsque l'animateur démarre une Activité, la page sera mise à jour pour que vous puissiez participer.

Vous pouvez changer votre nom et votre langue sur les appareils connectés (via [miro.com/join](http://miro.com/join)) en cliquant sur l'avatar en haut à droite et en ajustant les Paramètres du profil.

### Sur le tableau

Les collaborateurs peuvent participer aux Activités directement sur le tableau. Les présentateurs doivent s'assurer que les participants ont été invités au tableau avant de commencer toute Activité.

## Utilisation des Activités

Lors de la présentation, les participants peuvent rejoindre les Activités en utilisant le lien de participation et le code visible dans la barre supérieure de la diapositive d'Activités. Le code QR peut également être affiché pour permettre aux utilisateurs mobiles de rejoindre plus facilement en cliquant sur l'icône du code QR.

![activities.png](../../../../../../docs/using-miro/facilitation-tools/images/31128769665682_activities.png)

*Rejoignez les Activités via la barre d'outils en haut d'une diapositive*

Les activités peuvent être fermées en cliquant sur l'icône **Arrêter l'activité** dans le menu contextuel. Elles peuvent être redémarrées en cliquant sur l'icône **Démarrer l'activité**.

Les activités peuvent être réinitialisées une fois qu'elles ont des réponses en arrêtant l'activité depuis la barre d'outils de contexte et en cliquant ensuite sur l'icône **Réinitialiser**. Cela supprimera toutes les réponses mais conservera la configuration de l'activité (comme le titre et les options) ainsi que les paramètres.

Une fois stoppées, les activités peuvent être modifiées en cliquant sur l'icône **Modifier** dans la barre d'outils de contexte. Si l'activité contient des réponses, elle doit être réinitialisée pour effectuer des modifications.

### **Exporter les réponses des activités****s**

Choisissez les diapositives à partir desquelles vous souhaitez recueillir les contributions des participants, puis cliquez sur l'icône **Exporter** dans le menu contextuel. Les réponses peuvent être exportées vers des pense-bêtes ou vers une table.
