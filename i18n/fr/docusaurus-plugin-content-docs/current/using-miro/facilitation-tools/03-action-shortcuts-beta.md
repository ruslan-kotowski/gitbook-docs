Les raccourcis d'action vous permettent d'ajouter des fonctionnalités personnalisées et des raccourcis d'IA à vos tableaux et modèles à l'aide d'un seul bouton. Les raccourcis d'action permettent de rationaliser plus facilement les tâches et fonctions répétitives sur vos tableaux.

> ***Disponible sur :** le navigateur de bureau, l’application de bureau
> ***Disponible pour :** tous les forfaits
> ***Qui peut le faire ?** Les propriétaires et éditeurs de tableaux peuvent définir des raccourcis d'action ; tous les utilisateurs peuvent utiliser des raccourcis d'action.***

## Fonctionnalités principales

Les raccourcis d'action comprennent les éléments clés suivants :

- **Raccourcis des fonctionnalités**
  Permet d'accéder rapidement sur le tableau à plus de 40 fonctions normalement cachées dans les menus.
- **Créez avec Miro IA**
  Ajoutez des boutons qui créent des Stickies, des documents, des images ou des diagrammes, en utilisant éventuellement le contenu du tableau comme entrée.

## Comment ajouter des raccourcis d'action à votre tableau

La procédure suivante explique comment ajouter des raccourcis d'action à votre tableau.

**Procédure**

Suivez les étapes suivantes :

1. Cliquez sur l'icône **Outils, médias et intégrations** (![icon-tools.svg](../../../../../../docs/using-miro/facilitation-tools/images/25581014501266_icon-tools.svg)) dans la barre d'outils de création.
2. Recherchez et cliquez sur Raccourcis d'action.
   Votre curseur se transforme en icône Raccourcis d'action.
3. Cliquez sur le tableau où vous souhaitez placer votre raccourci d'action.
   Une boîte de dialogue s’ouvre.

   Vous avez ajouté avec succès un bouton d'action. Vous apprendrez ensuite à configurer le bouton Action.

## Comment configurer les raccourcis d'action pour déclencher des fonctionnalités ?

La procédure suivante explique comment configurer les raccourcis d'action pour déclencher une fonction sur votre tableau.

**Procédure**

Suivez les étapes suivantes :

1. Dans la boîte de dialogue de configuration, saisissez une **étiquette de bouton.**
2. Dans le menu déroulant **Action**, sélectionnez **Créer un raccourci**.
   Un nouveau champ de fonctionnalité Miro apparaît.
3. Sélectionnez la **fonction Miro** que vous souhaitez ajouter à votre raccourci d'action. Vous pouvez rechercher ou faire défiler la liste à l'aide des touches fléchées.
4. **Cliquez sur Enregistrer.

   Vous avez ajouté avec succès un bouton Action à votre tableau.**

## Comment configurer les raccourcis d'action pour Create avec Miro IA

La procédure suivante explique comment configurer les raccourcis d'action pour créer avec les tableaux Miro IA sur votre tableau.

**Procédure**

Suivez les étapes suivantes :

1. Dans la boîte de dialogue de configuration, saisissez une **étiquette de bouton.**
2. Dans le menu déroulant **Action**, sélectionnez **Créer avec Miro IA.**
   Un nouveau champ " **Que voulez-vous créer ?"** apparaît.
3. Sélectionnez le type de sortie que vous souhaitez créer avec votre raccourci d'action. Vous avez le choix entre Documents, Pensées-bêtes, Images et Diagrammes.
4. Sélectionnez une source et/ou une destination optionnelle pour votre raccourci d'action, si nécessaire.
   1. Vous pouvez sélectionner un cadre pour la source ou la destination.
   2. Si aucun cadre n'est sélectionné pour la source, le contenu du tableau entier sera utilisé.
   3. Si aucun cadre n'est sélectionné pour la destination, la sortie sera placée sur le tableau près du bouton Action.
5. Saisissez le prompt que Miro IA utilisera pour créer la sortie.
6. **Cliquez sur Enregistrer.

   Vous avez ajouté avec succès un bouton d'action pour Créer avec Miro IA à votre tableau.**
