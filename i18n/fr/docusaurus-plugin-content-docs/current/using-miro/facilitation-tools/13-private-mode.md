Que vous réfléchissiez ensemble à de nouvelles idées ou que vous meniez une rétrospective, le mode privé peut réduire les problèmes comme les préjugés de groupe, aider les utilisateurs à être authentiques dans leurs commentaires et offrir aux participants la possibilité de formuler leurs pensées en toute discrétion.

Cet article sera mis à jour lorsque le déploiement sera terminé.

> **Disponible pour :** les forfaits Starter, Business, Enterprise et Education

## Comment utiliser le mode privé ?

Les utilisateurs disposant d’un [accès de modification](../sharing-boards/01-board-access-rights.md) peuvent activer le mode privé à tout moment. Dès que le mode privé démarre, toutes les nouvelles pense-bêtes et toutes les modifications apportées aux pense-bêtes existantes sont masquées. Une fois le mode privé désactivé, tous les pense-bêtes masqués sont révélés. Un widget de mode privé peut également être ajouté au tableau pour rendre l'activation du mode privé plus efficace pendant une réunion.

:::warning
Bien que le mode privé masque les identités et d'autres informations sur le tableau, il ne s'agit pas d'une fonction de protection des données.
:::

### Options disponibles lors du démarrage du mode privé

> **Qui peut le faire ?** Éditeurs du tableau

Lorsqu’un utilisateur démarre le mode privé, deux options s’offrent à lui pour personnaliser davantage l’expérience des participants :

#### **Masquer les noms**

L'option " **Rendre les noms anonymes"** permet de créer un espace sûr pour une communication ouverte et honnête entre les utilisateurs.

Lorsque l’option est activée, le texte des pense-bêtes est rendu anonyme et reste anonyme pour toujours, même après la désactivation du mode privé.

- [Le badge d’auteur](../essential-tools/14-sticky-notes.md) n’est plus disponible.
- [Suivre](04-attention-management.md) n’est plus disponible.
- Pense-bête les noms des curseurs et les avatars sont anonymes
- Les positions du curseur sur le tableau sont réorganisées dès que le mode privé démarre.
- Les détails des pense-bêtes de type Créé/Modifié par sont anonymes.
- Le contenu anonyme est exclu de l’[historique du tableau](../managing-boards/11-board-history-activity.md) et les noms ne sont pas révélés dans [les modifications mises en avant](../managing-boards/11-board-history-activity.md).

#### **Autoriser toute personne à désactiver**

Le paramètre **Autoriser n’importe qui à éteindre** vous permet de contrôler qui peut mettre fin à la session en mode privé. Vous pouvez choisir de l’activer ou de le désactiver lorsque vous démarrez le mode privé.

**Lorsque cette option est activée, les autres utilisateurs peuvent mettre fin à la session en mode privé.**

**Lorsque cette option est désactivée, vous êtes le seul à pouvoir mettre fin à la session en mode privé.**  [Toutefois, les propriétaires de tableaux et les admins d’entreprise sous Enterprise Plan peuvent toujours mettre fin à la session à tout moment, indépendamment de ce paramètre.](../sharing-boards/01-board-access-rights.md)/span>

### Options disponibles après le lancement du mode privé

> **Qui peut le faire ?** Éditeurs du tableau

#### **Tout le monde peut révéler ses pense-bêtes**

Lorsque le mode privé est lancé par un utilisateur, l’option **Anyone can reveal their stickies** devient disponible dans la boite de dialogue du mode privé. Lorsqu’ils activent la fonction, un bouton **Révéler toutes mes pense-bêtes** apparait pour tous les utilisateurs. Ils peuvent ensuite cliquer sur ce bouton pour révéler leurs propres pense-bêtes à tout moment, même lorsque le mode privé est encore actif. Toutes les autres pense-bêtes resteront cachées.

Cette fonction est utile lors des rétrospectives ou d’autres exercices de collaboration en équipe, où les participants peuvent souhaiter discuter à tour de rôle de leurs points, observations ou commentaires.

## Comment lancer le mode privé ?

1. Allez dans la [barre d’outils de collaboration](../../getting-started/start-here/your-first-board/05-toolbars.md), dans le coin supérieur droit du tableau.
2. Cliquez sur l'icône **Outils de facilitateur et réactions.**
3. Sélectionnez **Private mode (Mode privé).**
   ![mode privé-point d'entrée.png](../../../../../../docs/using-miro/facilitation-tools/images/21537455192082_private-mode-entry-point.png)
   *Le bouton "mode privé" de la barre d'outils de collaboration*
4. Une boite de dialogue **Mode privé** s’ouvre.
5. Activez ou désactivez Masquer les noms.
6. Activez ou désactivez Autoriser toute personne à désactiver.
7. Cliquez sur **Activer le mode privé pour tous***![private-mode-turn-on.pngActiver](../../../../../../docs/using-miro/facilitation-tools/images/21537455195026_private-mode-turn-on.png)
*le mode privé**

## À quoi ressemble le mode privé pour les utilisateurs ?

Lorsque le mode privé est activé, les utilisateurs voient apparaitre un message contextuel et la boite de dialogue **Mode privé** s’ouvre. Ils peuvent également voir qui a lancé le mode privé.

Lorsque le mode privé est activé, les utilisateurs ne peuvent voir que leurs propres pense-bêtes. Tous les autres textes de la pense-bête sont masqués.

L’icône de l’œil fermé dans le coin supérieur gauche d’un pense-bête indique que le contenu est privé et visible uniquement par l’auteur.

## Comment arrêter le mode privé ?

Si vous ne voyez pas l’option permettant de mettre fin au mode privé, l’option **Autoriser quiconque à mettre fin** a été désactivée lors du lancement de la session. Une fois le mode privé terminé, tout le contenu sera visible pour les utilisateurs.

Si la fonction Masquer les noms était activée pendant le mode privé, les noms des auteurs des pense-bêtes resteront anonymes pour toujours.

1. Ouvrez ou naviguez jusqu’à la boite du **mode privé**
2. Cliquez sur **Désactiver le mode privé.**
3. Une deuxième boite de dialogue s’ouvre. Cliquez sur Désactiver pour tous
4. Les utilisateurs voient une notification leur indiquant la fin du mode privé, ainsi que l’identité de la personne qui a mis fin à la session.
5. Un compte à rebours de 5 secondes apparait dans la boite de dialogue du mode privé. Une fois le minuteur terminé, les pense-bêtes sont dévoilées.
