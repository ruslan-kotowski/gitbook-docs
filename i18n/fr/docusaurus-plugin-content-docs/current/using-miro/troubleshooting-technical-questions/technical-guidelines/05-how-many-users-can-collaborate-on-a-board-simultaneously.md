Miro est conçu pour le travail d'équipe et permet à de nombreux utilisateurs de collaborer efficacement sur un même tableau. Cette section décrit ce à quoi vous pouvez vous attendre lorsque vous collaborez avec un grand nombre de participants.

Miro est conçu pour la collaboration, il permet à plusieurs utilisateurs de collaborer sur un même tableau tout en leur offrant une expérience de travail stable.

Deux de nos cas d’utilisation fréquents — les plannings PI et les ateliers — peuvent impliquer quelques centaines de participants, nous optimisons donc constamment la performance pour une collaboration à grande échelle.

La plus grande session que nous avons hébergée jusqu'à présent comptait 377 utilisateurs. Ce cas de figure est un peu extrême, mais le tableau est demeuré opérationnel et a permis une collaboration réussie. Le scénario plus commun que nous rencontrons presque chaque semaine compte **environ 200 utilisateurs (éditeurs/commentateurs)** qui travaillent simultanément sur le même tableau.

Nous testons régulièrement notre application avec un nombre plus élevé d’utilisateurs, mais il est trop tôt pour dire que l’expérience de chacun sera fluide si vous dépassez 300 collaborateurs.

Attendez-vous à ce que le tableau ralentisse progressivement avec le nombre d'utilisateurs ou qu'il y ait un certain décalage lors d'une activité utilisateur intensive. Les utilisateurs disposant d'appareils plus anciens et moins puissants connaîtront un ralentissement plus tôt.
