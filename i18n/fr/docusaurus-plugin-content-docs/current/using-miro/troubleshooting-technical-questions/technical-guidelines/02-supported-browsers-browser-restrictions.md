Cet article fournit des informations sur les navigateurs de bureau et mobiles pris en charge par Miro.

:::note
Miro prend en charge toutes les versions des principaux navigateurs pendant au moins 12 mois, y compris les versions actives avec support à long terme. Les versions antérieures des navigateurs peuvent ne plus être prises en charge par les développeurs, ce qui pourrait affecter votre expérience Miro. Pour garantir une expérience Miro optimale, mettez à jour vos navigateurs au moins une fois par an.
:::

Miro prend officiellement en charge les navigateurs suivants :

- **Bureau**
  - Chrome
  - MS Edge
  - Firefox
  - Opera
  - Navigateur Yandex
- **Mobile**
  - Chrome
  - Safari
  - Samsung Internet

:::note
Les tableaux accessibles sur les navigateurs mobiles sont en lecture seule. Pour garantir l'accès avec vos privilèges assignés, téléchargez l'[application mobile de Miro](../../../getting-started/apps-for-devices/08-mobile-app.md).
:::

:::warning
Internet Explorer n’est pas pris en charge.
:::

## Problème de chargement de tableau dans Safari

Veuillez essayer de suivre les étapes ci-dessous si vous rencontrez des problèmes de chargement/de gel de vos tableaux dans Safari v. 15.2, OS Monterey (vous pouvez également voir les messages d’erreur suivants : "*This web page was reloaded because a problem occurred*" ou "*This web page and one other page are not responding*"):

1. Accédez à Safari > Préférences > **Développement** > **Fonctionnalités expérimentales.**
2. Désactivez **la fonctionnalité** **GPU Process: Canvas Rendering** .

   ![](/attachments/token/45hImX8u1weQZnUaPOXtAT971/?name=inline1581405683.png)

   > ✏️ ​Si vous ne voyez pas le **menu Développement** dans la [barre de menu](https://support.apple.com/en-gb/guide/safari/aside/glos33eb8abd/15.1/mac/12.0), ouvrez Safari > Préférences, cliquez sur **Avancé**, puis sélectionnez **Afficher le menu Développement dans la barre de menu**.
