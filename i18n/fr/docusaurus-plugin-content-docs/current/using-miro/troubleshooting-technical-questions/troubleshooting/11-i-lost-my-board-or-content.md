Voici ce que vous devez faire si vous ne parvenez pas à retrouver un tableau Miro ou si une partie du contenu du tableau a disparu.

:::tip
Pour protéger votre contenu, assurez-vous d’enregistrer des [sauvegardes de votre tableau](../../import-and-export/export/05-how-to-save-board-backup.md).
:::

## Le tableau a disparu

Si vous avez supprimé un tableau Miro par erreur ou si l’un de vos tableaux a disparu, vous pouvez le retrouvez en utilisant différentes méthodes.

### Vérifiez vos équipes Miro et utilisez la recherche

Si vous êtes membre de plusieurs équipes Miro, essayez de [passer d'une équipe à l'autre](../../../getting-started/start-here/miro-dashboard/04-profile-and-teams.md) sur la barre latérale gauche de votre tableau de bord. Cliquez ensuite sur **Tableaux dans cette équipe** pour voir tous les tableaux d’une équipe spécifique.

![switch_between_Miro_teams.gif](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21017417242386_switch%20between%20Miro%20teams.gif)
*Passer d'une équipe Miro à une autre*

Vous pouvez également utiliser [la fonction de recherche](../../../getting-started/start-here/miro-dashboard/03-how-to-search-in-miro.md) pour retrouver un tableau.

![Searching for board name in Miro.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21017417250834_Searching%20for%20board%20name%20in%20Miro.jpg)

Vous devrez peut-être appliquer le filtre Owned by anyone (Appartenant à tout le monde) pour vous assurer de visualiser tous les tableaux. Les filtres peuvent également vous aider à restreindre votre recherche aux tableaux que vous possédez et à ceux appartenant à tout le monde.

![sorting options.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/26846573077906_sorting%20options.jpg)
*Filtrage des tableaux sur le tableau de bord*

### Trouvez le lien du tableau dans l’historique de votre navigateur ou dans votre boîte de réception

Si vous ne retrouvez toujours pas le tableau, recherchez le lien du tableau dans l'historique de votre navigateur ou dans votre boîte de réception. Tant que vous êtes le propriétaire du tableau, vous pouvez [restaurer un tableau en ouvrant le lien](../../managing-boards/08-how-to-restore-a-deleted-board.md). Les tableaux peuvent être restaurés dans les 90 jours suivant leur suppression.

### Vérifiez la corbeille

Si vous êtes un utilisateur au sein d’un plan payant et que vous ne parvenez toujours pas à retrouver votre tableau ou à en trouver l’URL, vous pouvez essayer de [le restaurer à partir de la corbeille](../../managing-boards/08-how-to-restore-a-deleted-board.md).

![trash bin.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/26846558784530_trash%20bin.jpg)
*La corbeille dans le tableau de bord de Miro*

### Vérifiez vos modèles personnalisés

Si le tableau était dans une équipe payante ou Education, vérifiez les [modèles personnalisés](../../../getting-started/start-here/your-first-board/02-custom-templates.md) portant un nom similaire - il est possible que vous ayez d'abord créé un modèle et non un tableau.

### Vérifiez si les accès au tableau n’ont pas été modifiés

Il est possible que vous ayez été retiré de l’équipe où se trouvait votre tableau et que vous ayez perdu l’accès à celui-ci. Lors de la suppression d'un utilisateur, l'Admin peut réaffecter les tableaux de l'utilisateur ou les supprimer. Si le tableau n'a pas été supprimé, vous pouvez suivre le lien du tableau et [demander un accès auprès de son propriétaire actuel](../../sharing-boards/01-board-access-rights.md). Si le tableau a été supprimé, vous pouvez demander à l’admin d’équipe de [récupérer le tableau supprimé](../../managing-boards/08-how-to-restore-a-deleted-board.md) dans les 90 jours.

## Le contenu du tableau est manquant

Si une partie du contenu de votre tableau a disparu, voici quelques conseils qui pourraient vous aider à le retrouver.

### Vérifiez l’historique de votre tableau

Ouvrez le tableau et cliquez sur l’icône **Open sidebar** dans le coin inférieur gauche. Dans l’aperçu du tableau ouvert, cliquez sur l’icône **Board history**. Si vous voyez le contenu manquant, vous pouvez normalement le restaurer facilement en cliquant sur l’icône de restauration. Toutefois, il existe quelques [limitations relatives à la restauration du contenu](../../working-on-the-board/18-restoring-board-content.md).

:::tip
Les utilisateurs de comptes payants peuvent également essayer d’utiliser la [fonction de versioning des tableaux](../../managing-boards/12-board-history-versions.md).
:::

![restore_board_content_restore_feature.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/26846573080338_restore_board_content_restore_feature.jpg)
*Restauration du contenu à partir de l’historique du tableau*

### Vérifiez votre tableau sur la mini-carte

Si vous ne trouvez pas le contenu manquant dans l'historique du tableau, il est possible que le contenu soit toujours quelque part sur votre tableau.

Jetez un œil sur la mini-carte. La mini-carte se trouve dans le coin inférieur droit de votre tableau, accessible via le menu de zoom, et vous offre une vue d'ensemble de votre contenu. Ainsi, si quelque chose a échappé au cadre, vous pourrez le repérer là-bas.

![minimap.gif](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/26846495500178_minimap.gif)
*Un aperçu général du contenu de votre tableau peut être trouvé sur la mini-carte*
