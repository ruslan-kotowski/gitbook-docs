Suivez ce guide si vous ne pouvez plus accéder à un tableau Miro ou si vous n’avez plus le droit de le modifier.

### Je ne peux pas accéder à un tableau Miro

Si vous n’avez plus accès à un tableau Miro, vous verrez peut-être l’un des messages suivants. Cliquez sur un message pour découvrir les solutions possibles.

**No access to board.**  Demandez au propriétaire du tableau de vous accorder la permission de le lire

no_access_to_boards.jpg
Si vous voyez ce message, vous pouvez encore récupérer votre accès au tableau. Essayez les étapes suivantes :

1. **Demandez l’accès** en cliquant sur le bouton bleu de la fenêtre contextuelle. La demande sera envoyée au propriétaire du tableau.
   Si l'accès au tableau vous a été donné par e-mail, vous pouvez également contacter directement la personne qui vous a invité et lui demander de partager à nouveau le tableau. Pour trouver le nom de l'utilisateur, recherchez l'e-mail d'invitation au tableau dans votre boîte aux lettres électronique.
   Si le tableau est stocké dans un compte Enterprise, n'importe quel admin d'entreprise peut vous accorder l'accès si [les autorisations d'administrateur de contenu](../../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md) sont activées. Contactez l’admin d’entreprise et demandez-lui de partager le tableau avec vous.
2. Si vous avez une autre adresse e-mail enregistrée chez Miro, connectez-vous à votre autre profil et vérifiez si vous pouvez accéder au tableau avec cette adresse e-mail.
3. Si vous avez créé le tableau et que vous n'y avez plus accès, il est possible que vous ayez été retiré de l'équipe où le tableau est stocké.
   Contactez votre admin d'Miro et demandez-lui de vous réinviter dans l'équipe et de vous redonner accès au tableau. Si le tableau a été supprimé, les admins peuvent [le restaurer](../../managing-boards/08-how-to-restore-a-deleted-board.md) eux-mêmes dans un délai de 90 jours ou, si le tableau a été réaffecté à un autre utilisateur, demander au nouveau propriétaire du tableau de le restaurer.

**Le tableau a été supprimé**

board_has_been_deleted.jpg
Les tableaux supprimés peuvent être restaurés dans un délai de 90 jours. Suivez les étapes suivantes :

1. Contactez le propriétaire du tableau et demandez-lui de [récupérer le tableau](../../managing-boards/08-how-to-restore-a-deleted-board.md). Si vous avez initialement reçu une invitation au tableau par e-mail, vous pouvez essayer de trouver le nom du propriétaire du tableau en cherchant l’e-mail d'invitation dans votre boîte de réception.
2. Si le propriétaire initial ne peut pas récupérer le tableau, il est fort probable que le propriétaire ait supprimé son profil Miro en même temps que le tableau ou que le propriétaire ait été supprimé de l'équipe en même temps que son contenu.
   Contactez vos administrateurs Miro et vérifiez s'ils peuvent [restaurer le tableau à](../../managing-boards/08-how-to-restore-a-deleted-board.md) partir de la corbeille ou en suivant le lien du tableau.
   Les admins peuvent également [réattribuer un tableau à un nouveau propriétaire lors de la suppression d'un utilisateur.](../../../administration/user-management/08-remove-users.md) Dans ce cas, le nouveau propriétaire du tableau pourra restaurer le tableau.

   Si le tableau est stocké dans un compte Enterprise, n'importe quel admin d'entreprise peut activer les [autorisations d'administration du contenu](../../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md) et restaurer le tableau via le lien du tableau s'il a été supprimé il y a moins de 90 jours.

**Board does not exist (Le tableau n’existe pas)**

board_does_not_exist.jpg
Assurez-vous que vous utilisez le bon lien pour accéder au tableau. Vous pouvez trouver le lien du tableau dans l’historique de votre navigateur ou dans les notifications que Miro vous a envoyées par e-mail.

Si le lien vers le tableau est correct, le tableau a très probablement été supprimé en même temps qu’une équipe. Supprimer une équipe entraîne la suppression des tableaux. N’oubliez pas d’[exporter vos tableaux](../../import-and-export/export/03-how-to-export-your-board.md) ou [de les sauvegarder](../../import-and-export/export/05-how-to-save-board-backup.md) avant de supprimer votre équipe.

**This board is no longer shared or has been removed (Ce tableau n’est plus partagé ou a été supprimé)**

this_board_is_no_longer_shared.jpg

Assurez-vous que vous utilisez le bon lien pour accéder au tableau. Vous pouvez trouver le lien du tableau dans l’historique de votre navigateur ou dans vos notifications Miro.

Si le lien du tableau est correct, le tableau a très probablement été supprimé il y a plus de 90 jours seul, ou avec une équipe. Supprimer une équipe entraîne la suppression des tableaux. N’oubliez pas d’[exporter vos tableaux](../../import-and-export/export/03-how-to-export-your-board.md) ou [de les sauvegarder](../../import-and-export/export/05-how-to-save-board-backup.md) avant de supprimer votre équipe.

**Access revoked (Accès révoqué)**

access_revoked.jpg

Le message **Access revoked** (Accès révoqué) signifie que votre accès au tableau a été supprimé.

1. Contactez le propriétaire ou le copropriétaire du tableau et demandez-lui de [vous accorder l’accès au tableau](../../sharing-boards/03-sharing-boards-and-inviting-collaborators.md). Pour trouver le nom du propriétaire du tableau, cherchez l’e-mail d'invitation dans votre boîte de réception.
2. Si l’erreur apparaît sur un tableau qui vous appartient ou sur des tableaux auxquels vous avez normalement accès :

- Si vous obtenez l’erreur Access revoked (Accès révoqué) lorsque vous essayez d’accéder à un tableau Miro sur une tablette ou un appareil mobile, essayez de supprimer et de réinstaller l’application.
- Si le problème se produit dans le navigateur d’un ordinateur de bureau, il est possible que des bloqueurs locaux sur votre appareil de travail vous empêchent d’accéder aux ressources spécifiques du tableau dans le navigateur. Vous devrez peut-être contacter votre service informatique et lui demander d’autoriser l’accès. Découvrez les limitations appliquées aux connexions réseau ou aux environnements dans [Ajouter Miro aux applications autorisées](../../tools/troubleshooting/01-add-miro-to-allowed-apps.md).

Vous pouvez également essayer d’ouvrir le tableau sur [l’application de bureau Miro](../../../getting-started/apps-for-devices/05-desktop-app.md), ou d’accéder temporairement à Miro sur un autre appareil.

**Chargement interminable**

Si vous faites face à un chargement sans fin lorsque vous essayez d’ouvrir un tableau, découvrez comment [améliorer les performances du tableau et résoudre les problèmes de chargement](../../tools/troubleshooting/04-board-performance-and-loading-issues.md).

### Je ne peux plus modifier un tableau Miro

Si vous aviez des droits de modification sur un tableau, mais que vous ne pouvez maintenant que le lire ou le commenter, examinez les raisons possibles et les solutions ci-dessous.

1. Votre niveau d’accès a peut-être été modifié dans les paramètres de partage du tableau. Demandez les droits de modification au propriétaire du tableau. Vous pouvez le faire en cliquant sur **Demander des droits d'éditeur** dans le coin supérieur droit du tableau.
   Screenshot_background_template__1202__1_.jpg
   *Demander des droits d'édition sur le tableau*
   Si l'accès au tableau vous a été accordé par e-mail, vous pouvez contacter la personne qui vous a initialement invité et lui demander de vous accorder un accès de modification. Pour trouver le nom de l'utilisateur, recherchez l'e-mail d'invitation au tableau dans votre boîte aux lettres électronique.

   Si le tableau est stocké dans un compte Enterprise, n'importe quel administrateur d'entreprise peut activer les [autorisations d'administrateur de contenu](../../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md) et vous accorder un accès de modification au tableau.
2. Vérifiez si vous pouvez modifier le tableau à partir d’un autre profil Miro. Si vous avez une autre adresse e-mail enregistrée chez Miro, connectez-vous avec cette adresse e-mail.
3. Essayez de dupliquer le tableau. Si le propriétaire/copropriétaire du tableau autorise la [copie du contenu](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) du tableau et que celui-ci se trouve dans une équipe active, vous pouvez [dupliquer le tableau](../../managing-boards/03-how-to-duplicate-a-board.md) pour le modifier.
4. Si vous êtes sur le plan Free, vous ne pouvez peut-être pas modifier le tableau, car vous avez atteint la limite de tableaux dans votre équipe ou parce que le tableau privé a été déplacé vers une équipe gratuite. Consultez l’article [Le tableau est verrouillé](../../tools/troubleshooting/15-the-board-is-locked.md).
5. Les tableaux sont verrouillés en mode lecture seule seulement lorsqu’un abonnement Miro expire. Contactez votre admin Miro et assurez-vous que l’abonnement de votre équipe est actif. S'il a expiré, l’admin doit le renouveler ou [passer à un plan Free](../../../plans-billing/manage-your-subscription-and-plan/04-downgrade-your-plan.md).

:::note
Si vous pensez avoir rencontré un bug en essayant de modifier le contenu de votre tableau, consultez le guide [des bugs et des dépannages](../../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md).
:::
