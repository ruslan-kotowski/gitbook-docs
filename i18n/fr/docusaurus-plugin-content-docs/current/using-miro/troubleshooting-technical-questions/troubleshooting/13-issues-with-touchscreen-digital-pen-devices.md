Si vous rencontrez des problèmes lors de l’utilisation de Miro sur un appareil hybride avec un écran tactile ou un stylo numérique, veuillez vérifier les paramètres de votre navigateur. À noter que les étapes suggérées ici sont uniquement utiles pour un navigateur.

## Google Chrome

1. Ouvrez une nouvelle page dans Google Chrome.
2. Tapez **chrome://flags** dans la barre d’adresse de Chrome et entrez **touch**(tactile) dans la ligne de Recherche.
3. Assurez-vous que l’option **Touch UI Layout**(Mise en page de l’interface utilisateur tactile) est définie sur **Enabled** (Activé).
4. Assurez-vous que l’option **Touch initiated drag and drop** (Glisser-déposer tactile) est définie sur **Enabled** (Activé).
5. Essayez à nouveau l’écran tactile ou le stylo numérique pour constater la différence.

## Edge

1. Ouvrir une nouvelle page dans Edge
2. Tapez **about:flags** dans la barre d’adresse d’Edge.
3. Appuyez sur Ctrl + F et recherchez les **événements tactiles**.
4. Assurez-vous que les **Touch events** (Événements tactiles) sont définis sur **Always on** (Toujours allumé)
5. Essayez à nouveau l’écran tactile ou le stylo numérique pour constater la différence.
