Pour éviter l’interruption des notifications de Miro, vérifiez que les adresses e-mail suivantes sont autorisées :

| Serveur de messagerie | Marketo | Braze (Marketing) | Braze (Notifications) |
| --- | --- | --- | --- |
| Envoyé par | m.miro.com | mail.miro.com, insights.miro.com | notification.miro.com, product.miro.com, updates.miro.com |
| Adresses IP | 130.248.172.35 | 137.22.241.8, 137.22.240.64 | 137.22.241.90, 137.22.241.129, 137.22.240.227, 137.22.240.244 |
| Type de communication | Communication d’entreprise, évènements, e-mails marketing | E-mails d’onboarding, Miroverse, sondages, autres e-mails marketing | Notifications système, codes de vérification, invitations, demandes d’accès, notifications de mentions |
| Domaines | m.miro.com | mail.miro.com, insights.miro.com | notification.miro.com, product.miro.com, updates.miro.com |

:::note
Si vous devez gérer/arrêter les notifications de Miro, consultez [ce guide](../../managing-your-profile/02-miro-notifications.md).
:::
