Parfois, lorsque les utilisateurs tentent de se connecter à Miro via Google (avec leur compte ou les intégrations Google) reçoivent le message d’erreur suivant :

Google_authorization_error.jpg
Message d’erreur apparaissant lors d’une autorisation Google

Pour remédier à ce problème, il convient de supprimer tous les comptes Google associés à Miro et de les configurer à nouveau. Voici comment procéder :

1. 1. Rendez-vous sur votre **compte Google.**

Google_account.jpg
/strong>Accès aux paramètres d’un compte Google

2. 2. Ouvrez l’onglet **S****ecurity**(Sécurité).

security_tab.jpg
Paramètres de sécurité d’un compte Google

3. 3. Rendez-vous dans la section **Third-party apps****with account access**(Applications tierces ayant accès à votre compte) et cliquez sur **Manage third party access** (Gérer les accès tiers).

third-party_apps.jpg
Option permettant de gérer les accès tiers dans les paramètres Google

4. 4. Trouvez Miro dans la liste. Cliquez sur **Remove Access** (Supprimer l’accès).

remove_Miro_access.jpg
Option permettant de supprimer l’accès de Miro à Google

Vous pouvez également passer par une étape supplémentaire : connectez-vous à votre compte Miro et supprimez toutes les intégrations Google dans la section [Integrations](https://realtimeboard.com/app/account/profile/integrations/)(Intégrations) de la page **Profile settings** (Détails du profil) de votre compte Miro.

log_out_from_Google_accounts.jpg
Déconnexion de vos comptes Google

Après avoir terminé les étapes suggérées, n’hésitez pas à associer à nouveau votre profil Miro à votre compte Google.

Nous sommes conscients que cette procédure puisse sembler fastidieuse et chronophage, mais elle permet d’assurer à nouveau le bon fonctionnement de votre intégration Google Drive.

:::note
Si vous n’êtes pas en mesure de vous connecter à votre profil Miro via Google, veuillez essayer de vous connecter à l’aide de vos identifiants standard (nom d’utilisateur et mot de passe). Si vous avez oublié votre mot de passe, vous pouvez le restaurer en suivant les instructions partagées dans [ce guide](../../managing-your-profile/05-how-to-change-your-password.md).
:::
