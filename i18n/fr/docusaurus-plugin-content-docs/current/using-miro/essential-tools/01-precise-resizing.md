Redimensionnez les widgets en utilisant des dimensions numériques pour un dimensionnement au pixel près dans les formats.

:::note
Le redimensionnement précis est disponible dans certains formats, notamment la fonctionnalité Diagrammes, Miro Prototypes et les diapositives Miro.
:::

## Redimensionnement précis

1. Entrez en **mode immersif** en cliquant sur l'icône **mode immersif** dans le menu contextuel de votre format.
2. Cliquez sur le widget que vous souhaitez redimensionner. Les widgets pris en charge incluent le texte, les images, les pense-bêtes, les stencils et les formes pour le prototypage.
3. Dans le menu contextuel du widget, cliquez sur l'icône **Redimensionner**.
   Une boîte de dialogue pour les dimensions s'ouvrira sous le menu.
4. Entrez les dimensions en pixels pour la **largeur** et la **hauteur**.
5. Appuyez sur **entrer** pour valider les modifications.

:::note
Dans les zones de texte, seule la largeur peut être spécifiée. La hauteur s'ajustera automatiquement en fonction du contenu de la zone de texte.
:::
