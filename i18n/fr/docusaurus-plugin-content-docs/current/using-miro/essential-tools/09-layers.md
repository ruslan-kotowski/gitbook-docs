Les calques permettent d’organiser des sections distinctes de contenu sur le tableau, essentiel pour gérer la complexité des diagrammes et permettre un travail plus précis et plus structuré.

## Accès aux calques

Pour accéder au **panneau Calques** :

1. Cliquez sur l’icône **Médias, outils et intégrations** (![icon-tools.svg](../../../../../../docs/using-miro/essential-tools/images/23227364594834_icon-tools.svg)) dans la barre d’outils de création.
2. Recherchez **Calques**, puis cliquez sur l’outil Calques.
3. Vous pouvez conserver l’outil Calques dans la barre d’outils de création en cliquant avec le bouton droit de la souris sur l’icône **Calques**, puis en sélectionnant **Épingler à la barre d’outils**.

![layers-new-entry-point.png](../../../../../../docs/using-miro/essential-tools/images/22431635505426_layers-new-entry-point.png)

*Le menu Calques est accessible en cliquant sur l’icône Cadres et calques*

Lorsque vous cliquez sur l’**icône Calques**, un panneau s’ouvre sur le côté droit du canevas. Ici, vous pouvez activer un calque, nommer vos calques existants ou créer de nouveaux calques.

![layers-panel.png](../../../../../../docs/using-miro/essential-tools/images/21594007565842_layers-panel.png)

*Le menu Calques apparait sur le côté droit du canevas*

### Qui peut utiliser les calques ?

La fonctionnalité des calques est basée sur le rôle de l’utilisateur.

- Les lecteurs et les commentateurs (y compris les invités disposant de ces autorisations) ne peuvent pas accéder aux calques.
- Les éditeurs (y compris les invités disposant des droits d’éditeur) peuvent créer, modifier, masquer et supprimer des calques.
  - Les éditeurs invités par e-mail ont également la possibilité de verrouiller et de déverrouiller les calques.
- Les propriétaires et copropriétaires de tableaux disposent de toutes les capacités des éditeurs, ainsi que de la possibilité de verrouiller et de déverrouiller les calques et d’utiliser le verrouillage protégé.

## Utilisation des calques

Le contenu peut être sélectionné et ajouté à un nouveau calque ou à un calque existant, ce qui vous permet d’organiser le contenu connexe.

1. Sélectionnez le contenu que vous souhaitez ajouter à un nouveau calque ou à un calque existant.
2. Cliquez sur le menu **Calques**.
3. Pour ajouter le contenu à un nouveau calque : cliquez sur **+ Déplacer vers un nouveau calque**. Vous pouvez ensuite renommer le nouveau calque.
4. Pour déplacer le contenu vers un calque existant : cliquez sur les **trois points** (**...**) à côté du nom du calque et choisissez **Déplacer la sélection vers le calque**.

![layers-move-to.gif](../../../../../../docs/using-miro/essential-tools/images/21594007570962_layers-move-to.gif)

*Ajouter du contenu à un calque existant*

Lorsque vous ajoutez du contenu que vous souhaitez inclure dans un calque particulier, sélectionnez d’abord le calque. De nouveaux contenus seront automatiquement ajoutés à ce calque.

Vous pouvez également ajouter du contenu à un nouveau calque ou à un calque existant en :

1. Sélectionnez le contenu que vous souhaitez ajouter.
2. Cliquez sur le menu **trois points** (**...**) dans le menu contextuel.
3. Sélectionnez l’option **Déplacer vers le calque**.

![](../../../../../../docs/using-miro/essential-tools/images/21593982256018_803bbedc-722c-45ef-afb8-e9c46ba8a857.png)

*L’option **Déplacer vers le calque** se trouve sous les trois points (**...**) dans le menu contextuel*

Les calques peuvent être masqués, verrouillés, renommés ou dupliqués selon vos besoins.

1. Cliquez ou survolez le nom du calque dans le menu des calques.
2. Pour **masquer** un calque : Cliquez sur l’**icône de l’œil** pour masquer le calque. L’icône passe d’un œil ouvert à un œil fermé. Tout le contenu du calque sélectionné disparaitra du canevas. (Notez que le contenu caché disparaitra du canevas pour tous les utilisateurs, et restera caché lors du rechargement de la page.)
3. Pour rendre le calque visible, cliquez sur l’**icône Œil fermé**. Le contenu caché réapparaitra sur le canevas.![layers-eye.png](../../../../../../docs/using-miro/essential-tools/images/21593982258450_layers-eye.png)
   *Le masquage d’un calque s’effectue à l’aide de l’icône de l’œil*
4. Pour **verrouiller** un calque : Cliquez sur l’**icône du cadenas** pour verrouiller le calque. L’icône passe d’un cadenas ouvert à un cadenas fermé. Lorsqu’un calque est verrouillé, aucune modification ne peut être apportée au contenu de ce calque (y compris le déplacement ou la suppression de contenu).
5. Cliquez à nouveau sur l’**cadenas fermé** **icône de verrouillage** pour déverrouiller le contenu du calque.![layers-lock.png](../../../../../../docs/using-miro/essential-tools/images/21594007576466_layers-lock.png)
   *L’icône de verrouillage est utilisée pour verrouiller ou déverrouiller un calque.*
6. Pour **dupliquer** un calque : Cliquez sur les trois points (**...**) à droite du calque.
7. Cliquez sur **Dupliquer le calque**.
8. Une deuxième instance de votre calque apparait sur le tableau, directement au-dessus du calque d’origine.
9. Pour déplacer le calque dupliqué, assurez-vous que le calque est sélectionné dans le menu Calques, puis cliquez sur le contenu du calque dans le canevas et faites-le glisser jusqu’à l’emplacement souhaité.
   ![layers-three-dots.png](../../../../../../docs/using-miro/essential-tools/images/21593982264594_layers-three-dots.png)
   *La duplication d’un calque se fait par le menu à trois points (...)*

Pour renommer un calque :

1. Double-cliquez sur le nom du calque dans le menu des calques.
2. Modifiez le nom du calque.
3. Appuyez sur Entrée

## Calques dans le format Diagramme

Les calques dans le format Diagramme fonctionnent indépendamment des calques du canevas. Cette séparation est conçue pour rationaliser le processus de création de diagrammes et éviter toute confusion entre le contenu général du tableau et les composants spécifiques d'un diagramme. Pour en savoir plus sur le fonctionnement spécifique des calques dans les diagrammes, veuillez consulter notre article détaillé sur le [format Diagramme](../formats/diagramming/02-miro-diagrams.md).

- **Canevas vs. Calques du diagramme**: Alors que les calques du canevas sont utilisés à des fins générales, comme les présentations, les calques au sein d'un diagramme sont gérés séparément pour organiser les éléments propres au diagramme.
- **Parent** : Une fois qu'un élément fait partie d'un diagramme, il ne peut pas être ajouté à un calque du canevas car il dépend du format du diagramme lui-même.

## Réorganiser les calques

Les calques peuvent être réorganisés dans le panneau, ce qui affecte le contenu du calque qui s’affiche en haut. Pour réorganiser les calques, il suffit de les faire glisser dans le panneau Calques dans l’ordre de votre choix.

Il s’agit d’un outil puissant pour créer des diagrammes lorsque vous avez besoin de deux versions des mêmes parties d’un diagramme, avec un contenu légèrement différent. En plaçant les calques directement l’un au-dessus de l’autre, vous pouvez modifier l’affichage en réorganisant les calques.

## Le calque par défaut

Le calque par défaut est toujours visible et les nouveaux widgets sont ajoutés au calque par défaut si aucun autre calque n’est actif. Lorsque vous ne travaillez pas sur un calque en particulier, vous travaillez sur le calque par défaut.

Le calque par défaut diffère des autres calques car il ne peut être ni masqué ni verrouillé.
