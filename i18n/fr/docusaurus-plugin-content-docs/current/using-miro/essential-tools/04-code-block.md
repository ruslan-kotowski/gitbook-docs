Ajoutez des zones de code à votre tableau pour une séance collaborative de programmation, de débogage ou de résolution de problèmes. Notre widget de zone de code dispose des langues de programmation les plus populaires et il est personnalisable.

Combinez les blocs de code avec nos [fonctionnalités de cartographie et de diagrammes](../formats/diagramming/01-miro-for-mapping-diagramming.md) pour revoir l'architecture et les flux. Utilisez des connecteurs de diagramme pour mettre en évidence les relations entre les différentes parties de code source.

**Utilisez les zones de code pour :**

- Cérémonies agiles
- Les séances collaboratives de développement et de débogage
- Les entretiens de programmation à distance

## Comment ajouter une zone de code

1. Rendez-vous dans la barre d’outils de création sur la partie gauche du tableau
2. Cliquez sur l’icône **Plus d’applications**
3. Recherchez **Code block (Zone de code)** ou faites défiler vers le bas jusqu'à Code block (Zone de code)
4. Cliquez sur l’icône de l’application Code block
5. Cliquez n’importe où sur le tableau pour ajouter un bloc de code

Ajout d’une zone de code sur le tableau*

## Comment personnaliser une zone de code

Dans le menu contextuel du bloc de code, vous pouvez activer et désactiver les lignes, ajuster la taille de la police et passer d'une langue de programmation à une autre.

1. Cliquez sur la zone de code.
2. Dans le menu contextuel, choisissez une langue de programmation dans la liste déroulante, augmentez ou réduisez la taille de la police et cliquez sur l'icône de numéros de ligne pour activer ou désactiver les lignes.

![Customizing_a_code_block.gif](../../../../../../docs/using-miro/essential-tools/images/21016928890130_Customizing%20a%20code%20block.gif)*Personnalisation d’une zone de code sur le tableau*

## Foire aux questions

Quelles langages de programmation sont actuellement disponibles dans les blocs de code ?

JavaScript, TypeScript, Python, C++, Java, Go, Rust, PlainText, Swift, Ruby, SQL, HTML, CSS, JSON, GraphQL, Kotlin, YAML et Mermaid.
Nous ajoutons régulièrement des langues en fonction des demandes des clients ; contactez votre responsable Customer Success Miro si vous avez des suggestions.
