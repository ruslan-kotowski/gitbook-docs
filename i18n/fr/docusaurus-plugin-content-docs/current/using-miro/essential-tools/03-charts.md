Créez des tableaux de bord pour les réunions opérationnelles, appuyez vos idées avec des données et présentez vos chiffres clés grâce aux graphiques modifiables de Miro.

### Comment utiliser les graphiques

Cliquez sur **charts** (graphiques) dans la barre d’outils, sélectionnez un type de graphique, puis cliquez dessus ou faites-le glisser dans le tableau.

charts.jpg
Les graphiques dans la barre d’outils

Sélectionnez l’objet pour ouvrir le menu contextuel, cliquez sur les trois points, puis cliquez sur **Edit** (Modifier) ou double-cliquez sur l’objet pour passer enmode édition.

edit_a_chart.jpg
Activation du mode édition

Choisissez le nom de votre graphique et personnalisez sa légende pour y apporter davantage d’informations. Activez ou désactivez les éléments **Title** (Titre) et **Legend** (Légende). Vous pouvez également effacer toutes les notes en un clic.

editing_a_chart.gif
Modification d’un graphique

Pour supprimer une ligne, sélectionnez toutes les cellules de cette ligne, cliquez sur l’icône **Trash** (Corbeille) et choisissez **Delete row** (Supprimer la ligne).

delete_a_row.gif
Suppression d’une ligne

### Foire aux questions

1. *Puis-je ajouter des valeurs négatives aux graphiques ?*- Non, vous ne pouvez additionner que des nombres positifs.
2. *Puis-je changer la couleur des éléments du graphique ?*- Non, les couleurs sont choisies automatiquement.
3. *Comment exporter mon graphique ?*- Veuillez consulter les options d'exportation du tableau [ici.](../import-and-export/export/03-how-to-export-your-board.md)
