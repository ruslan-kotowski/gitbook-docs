Le programme de parrainage de Miro permet aux utilisateurs existants de gagner de l'argent en recommandant de nouvelles entreprises à Miro. Ce programme de partage des revenus offre des paiements allant jusqu'à 500 dollars par recommandation réussie.

## Comment fonctionne le programme de parrainage

**Pour vous (référent) :**

- Recevez 10 % des paiements mensuels du compte parrainé pour chaque nouvelle entreprise qui s'inscrit avec votre code de parrainage, jusqu'à 500 $ par parrainage.

**Pour le compte parrainé (Invité) :**

- Les invités bénéficient d'une réduction de 10 % sur leur abonnement pendant 11 mois consécutifs.
- Les invités devront appliquer le code promotionnel lors de l'inscription à un abonnement payant afin de bénéficier de la réduction.

## Utilisation du programme de parrainage

1. Cliquez sur l'icône **Programme de parrainage** dans le coin supérieur droit de votre tableau de bord.
2. Cliquer sur **Copier le lien d’invitation**.
   ![image.png](../../../../../../docs/using-miro/special-features/images/23383406736146_image.png)
   *Copiez le lien d’invitation à envoyer à vos contacts potentiels*
3. Envoyez le lien à des contacts dans d'autres entreprises via e-mail, réseaux sociaux ou applications de messagerie.

### Recevez une commission pour vos parrainages

Avant de pouvoir collecter des paiements pour vos parrainages, vous devrez ajouter vos informations de paiement.

1. Cliquez sur l'icône **Programme de parrainage** dans le coin supérieur droit de votre tableau de bord.
2. Cliquez sur l’onglet **Récompenses**.
3. Cliquez sur **Ajouter des informations de paiement**.
4. Sélectionnez votre pays/région de paiement dans le menu déroulant.
5. Sélectionnez votre méthode de paiement préférée parmi les options disponibles.
6. Saisissez vos informations de paiement.
7. Accepter les conditions d'utilisation de Cello.
8. Cliquez sur **Enregistrer la méthode de paiement**.
   ![image (1).png](images/22141687372434_image%20(1).png)
   *Configurez vos informations de paiement pour activer le paiement de vos parrainages*

:::note
Vous pouvez mettre à jour votre méthode de paiement à tout moment en cliquant sur le bouton **Mettez à jour vos informations de paiement** dans l'onglet **Récompenses**.
:::

### Suivi de vos parrainages

Vous pouvez consulter vos parrainages sur le tableau de bord du **Programme de Parrainage**.

1. Cliquez sur l'icône du **Programme de parrainage** dans le coin supérieur droit de votre tableau de bord.
2. Cliquez sur l’onglet **Récompenses**.
3. Vous verrez un récapitulatif de votre total de Récompenses en haut, ainsi qu'une liste des parrainages actifs et le montant de leur paiement.
   ![image (2).png](images/22141687374354_image%20(2).png)
   *Les gains du programme de parrainage seront affichés dans l'onglet Récompenses*

## Politiques du programme

- **Critères d’éligibilité :**
  - Les invités doivent être de nouvelles entreprises s'inscrivant avec une adresse e-mail professionnelle.
  - Les invités doivent utiliser le code promotionnel avant son expiration.
  - Les recommandations à des collègues de votre propre entreprise (même domaine de messagerie) ne sont pas éligibles.
- **Détails du code promotionnel :**
  - Les codes promotionnels expirent 60 jours après leur émission.
  - Les codes promotionnels doivent être appliqués lors du passage à la caisse pour tout forfait payant.
  - Cumulez des paiements de parrainage jusqu’à un total de 500 dollars.
  - La réduction de l'invité est active pendant 11 mois après l'inscription.
- **Modifications du programme :**
  - Nous nous réservons le droit de modifier ou de mettre fin au programme de parrainage à tout moment.
  - Les modifications seront communiquées par e-mail ou publiées sur notre site Web.
- **Prévention des abus :**
  - Toute activité frauduleuse ou utilisation abusive entraînera une disqualification du programme.
- **Disponibilité régionale :**
  - Le programme de parrainage est disponible dans les pays suivants : Autriche, Belgique, Brésil, Canada, Tchéquie, Danemark, Finlande, France, Allemagne, Grèce, Hongrie, Irlande, Italie, Inde, Pays-Bas, Norvège, Pologne, Philippines, Portugal, Roumanie, Espagne, Suède, Suisse, Royaume-Uni, États-Unis.

## Foire aux questions

**Y a-t-il une limite au nombre d'entreprises que je peux recommander ?**

Il n'y a pas de limite au nombre d'entreprises que vous pouvez recommander. Cependant, la réduction maximale que vous pouvez obtenir est de 500 dollars par parrainage.

**Et si le contact oublie d’appliquer le code promo ?**

Le code promotionnel est essentiel pour la réduction de l'invité et le paiement du référent. Rappelez-leur de l'appliquer directement lors de l'inscription ou dans les 60 jours suivant l'envoi du code.

**Combien de temps le code promo est-il valide ?**

Le code promo expire 60 jours après son émission. Assurez-vous que votre contact l'utilise pendant cette période.

**Puis-je référer quelqu'un de la même entreprise ?**

Non, les parrainages doivent provenir de différentes entreprises. Les invités doivent utiliser une adresse e-mail professionnelle avec un domaine différent du vôtre pour être éligibles.

**Comment suivre les réductions que j'ai obtenues ?**

Cliquez sur l'icône du Programme de parrainage sur le tableau de bord de votre compte Miro pour voir les parrainages réussis et les paiements accumulés.

**Recevrai-je une notification lorsqu'une entreprise parrainée utilisera mon lien de parrainage et mon code promo ?**

Oui, vous recevrez une notification dans le tableau de bord du programme de parrainage une fois que l'entreprise parrainée s'inscrit avec succès et applique le code promo.

**Que se passe-t-il si le code promo expire avant son utilisation ?**

Si le code promotionnel expire, l'invité ne recevra pas la remise. Ils auraient besoin d’un nouveau lien de parrainage et d’un code promo pour participer.

**Ma récompense change-t-elle si l'entreprise référencée annule son abonnement ?**

Si le compte annule un abonnement, les paiements mensuels reçus pour cette recommandation s'arrêteront.

**Que dois-je faire si je rencontre des problèmes avec ma réduction de parrainage ?**

Contactez notre équipe du service d’assistance pour obtenir de l’aide.

**Puis-je référer plusieurs contacts au sein du même compte d'entreprise ?**

Les parrainages doivent concerner de nouveaux comptes. Les contacts multiples au sein du même compte seront comptés comme une seule recommandation.

**Que faire si je n'ai pas reçu ma récompense de parrainage ?**

Si vous pensez que vous auriez dû recevoir une récompense mais qu'elle n'a pas été appliquée, veuillez contacter notre service d’assistance pour obtenir de l’aide. Le premier paiement doit être reçu au moins un mois après la création d'un nouveau compte payant enregistré.
