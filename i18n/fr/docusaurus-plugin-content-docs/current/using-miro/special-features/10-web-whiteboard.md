Le tableau blanc Web est un tableau blanc en ligne simple et gratuit que vous pouvez utiliser sans avoir à vous inscrire ou à vous connecter.  Organisez votre prochaine session de brainstorming ou de tutorat en ligne sur le tableau blanc web. Il vous suffit de vous rendre sur webwhiteboard.com, de créer un tableau et de partager son lien avec votre équipe.

:::note
Pour en savoir plus, visitez également [webwhiteboard.com/home](https://webwhiteboard.com/home/).
:::

:::warning
Le tableau blanc Web n’est pas pris en charge en mode incognito de Chrome ou sur Safari.
:::

### Qu’est-ce que le tableau blanc web ?

Le tableau blanc web est disponible gratuitement pour tous les utilisateurs, sans inscription nécessaire, pour les ordinateurs de bureau et les tablettes.  Vous pouvez également l’utiliser avec un stylet si vous travaillez sur tablette, car il prend en charge le rejet de paume et Apple Scribble/span>[.](https://support.apple.com/guide/ipad/enter-text-with-scribble-ipad355ab2a7/ipados)

Pour commencer à utiliser le tableau blanc Web, ouvrez [webwhiteboard.com](https://webwhiteboard.com/) dans le navigateur et créez un nouveau tableau.

Vous pouvez partager ce lien avec les membres de votre équipe et ils pourront collaborer avec vous en temps réel sans avoir à s’inscrire ou à se connecter sur Miro.  Pour partager le lien, cliquez sur le bouton Share board/span> (Partager le tableau) dans le coin supérieur droit de votre écran : le lien du tableau sera copié dans votre presse-papiers et toute personne qui détient ce lien aura accès à votre tableau avec des droits de modification.

share_webwhiteboard.jpg
/span>Partage d’un tableau sur le tableau blanc web

Les tableaux du tableau blanc web sont disponibles pendant 24 heures.  Une fois cette période écoulée, ils sont verrouillés pendant 7 jours.  Pendant ce temps, vous pouvez vous inscrire/vous connecter sur Miro pour les déverrouiller et les enregistrer. Si un tableau n’est pas déverrouillé/enregistré dans les 7 jours, il sera complètement supprimé.

Parallèlement, vous pouvez télécharger votre tableau en tant qu’image ou au format .pdf. Il vous suffit de cliquer sur l’icône Export this board (Exporter ce tableau) à côté du logo du tableau blanc web dans le coin supérieur gauche de votre écran et de choisir l’option **image** ou **PDF** dans la fenêtre contextuelle.

:::warning
Veuillez noter que si vous n’enregistrez pas ou n’exportez pas votre tableau, il sera **définitivement supprimé** après 7 jours.
:::

### Que se passe-t-il lorsque vous souhaitez enregistrer votre tableau ?

Si vous possédez un compte utilisateur enregistré sur Miro, vous aurez la possibilité d’enregistrer votre tableau et de choisir l’équipe dans laquelle vous souhaitez l’enregistrer, si vous avez plusieurs équipes.

save_to_my_boards.jpg
/span>Enregistrement de votre tableau dans une équipe Miro

Si vous utilisez le tableau blanc web et que vous n’avez pas encore de profil Miro, vous devrez vous inscrire sur Miro pour continuer à modifier votre tableau une fois les premières 24 heures écoulées.

sign_up_to_Miro.jpg
/span>Création d’un profil Miro pour y enregistrer votre tableau

Le premier utilisateur qui s’inscrit sur Miro deviendra le propriétaire du tableau qu’il sauvegarde.  Les autres personnes qui ont collaboré sur le tableau conserveront leur accès à ce tableau via le même lien et pourront continuer à y travailler en tant que [visiteurs](../sharing-boards/08-collaboration-with-visitors.md).

### Foire aux questions

1. *Dois-je être un utilisateur de Miro pour utiliser le tableau blanc Web?*- Non, ce n’est pas le cas. Le tableau blanc web est un tableau blanc en ligne gratuit pour tous, sans inscription nécessaire.
2. *Combien de temps puis-je travailler sur mon tableau blanc Web?*- Chaque tableau blanc Web a une durée de vie de 24 heures, après quoi il est verrouillé et définitivement supprimé au bout de 7 jours, sauf si vous vous connectez et sauvegardez le tableau. Si vous souhaitez continuer à travailler sur votre tableau, vous pouvez soit vous inscrire sur Miro sous un plan Free pour enregistrer votre travail, soit exporter votre tableau sous forme d’image ou au format .pdf.
3. *Dois-je payer pour continuer à travailler sur mon tableau blanc Web?*- Non, vous devrez simplement vous [inscrire au plan Miro Free](../../getting-started/start-here/02-how-to-register-with-miro.md) pour continuer à travailler sur votre tableau.
4. *En quoi le tableau blanc Web est-il différent de Miro ?*- Le tableau blanc Web est une version plus simple et plus légère de Miro. Il dispose de moins de fonctionnalités que le plan Free et [les plans premium](../../plans-billing/miro-plans/09-free-plan.md) de Miro.
