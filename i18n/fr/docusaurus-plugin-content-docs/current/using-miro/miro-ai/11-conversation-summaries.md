Le résumé de conversation génère un résumé des fils de commentaires longs sur votre tableau Miro. Pour les tableaux avec beaucoup d'activité, utilisez le résumé de conversation pour passer en revue rapidement et hiérarchiser des insights spécifiques.

Vous pouvez utiliser le résumé de conversation pour tout commentaire de plus de 200 caractères et ayant plus de deux réponses.

Les résumés de conversation sont propulsés par [Miro IA](01-miro-ai-overview.md).

## Accéder aux résumés de conversation

1. Survolez le commentaire.
   Le bouton **Résumer** apparaît.
   ![Miro AI Conversation Summary button.](images/21965877122194_Snap-to-grid-canvas%20(1).png) *Le bouton Résumer Miro IA.*
2. Sélectionnez **Résumer**.
   Miro IA génère un résumé de conversation.

:::note
Le bouton **Résumer** n'apparaît pas si vous êtes le seul commentateur dans le fil.
:::

## FAQ

**Les résumés de conversation utilisent-ils des crédits Miro IA ?**

Oui, les résumés de conversation consomment des crédits Miro IA. Pour en savoir plus, consultez les [Crédits Miro IA et module complémentaire d’IA](../../plans-billing/billing-and-payments/03-miro-ai-credits.md).

**Comment Miro IA et les résumés de conversation utilisent-ils mes données ?**

Les résumés de conversation s'appuient sur Miro IA, qui génère une réponse à partir des données saisies par l'utilisateur. Les données soumises, y compris le contenu et les données d'utilisation, ne sont pas utilisées pour l'entraînement des modèles. Pour en savoir plus, consultez la [Politique de confidentialité IA de Miro](https://miro.com/legal/privacy-policy/#miro-ai).

**En tant qu'admin d'un forfait Enterprise ou Education, comment puis-je désactiver Miro IA ?**

Les admins peuvent désactiver toutes les fonctionnalités de Miro IA dans leurs Paramètres du profil. Pour savoir comment, consultez [la sécurité Admin de Miro IA](../../enterprise-administration/canvas-25-admin-features/data-security/04-miro-ai-admin-security.md).

**Quel modèle d'IA est utilisé pour les résumés de conversation ?**

Les résumés de conversation utilisent GPT 4.0. Pour en savoir plus, consultez la [référence Miro IA](18-miro-ai-reference.md).
