Utilisez Miro IA pour modifier les images que vous chargez sur Miro.

## Supprimer l'arrière-plan des images

1. Sélectionnez une image chargée ou collée sur votre tableau.
   Le menu contextuel s’affiche.
2. Dans le menu contextuel, sélectionnez **Miro IA**.
   Un menu déroulant s’ouvre.
3. Sélectionnez **Supprimer l’arrière-plan**.

## Obtenez des suggestions de texte alternatif pour les images

1. Sélectionnez une image téléchargée ou collée sur votre tableau.
    Le menu contextuel s’affiche.
2. Dans le menu contextuel, sélectionnez **ALT**.
    La **boîte de dialogue Description de l’image** s’ouvre. **Miro IA** génère automatiquement une suggestion.
3. Cliquez sur **Insérer**.
    La suggestion générée est automatiquement enregistrée.
4. (Facultatif) Modifiez la suggestion insérée. Les modifications sont automatiquement enregistrées.
5. Fermez la **boîte de dialogue Description de l’image**.

:::note
La génération de texte alt avec Miro IA ne consomme pas de crédits d’IA.
:::

## Convertir les images en diagrammes ou en Miro Prototypes (Disponibilité limitée)

Miro IA vous permet de convertir des images de diagrammes ou de Miro Prototypes en versions entièrement modifiables sur votre tableau Miro. Vos images de diagrammes peuvent même être des esquisses dessinées à la main.
