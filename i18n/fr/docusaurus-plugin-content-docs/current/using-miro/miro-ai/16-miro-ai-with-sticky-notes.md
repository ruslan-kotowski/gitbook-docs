Utilisez Miro IA avec les pense-bêtes pour générer, regrouper, résumer ou créer des documents Miro en fonction de votre sélection sur le tableau. Vous pouvez également utiliser Sticky Capture, qui vous permet de charger une image de pense-bêtes avec du contenu pour générer des pense-bêtes entièrement modifiables sur votre tableau.

## Générer des pense-bêtes et Sticky Capture

Vous pouvez utiliser un prompt pour que Miro IA génère des pense-bêtes. Vous pouvez également charger une image de pense-bêtes pour produire des versions modifiables en tant que pense-bêtes sur votre tableau Miro, ou utiliser Sticky Capture.

Suivez les étapes suivantes :

1. Au-dessus de la barre de création, cliquez sur **Créer avec l’IA**.
   Le panneau **Créer avec l’IA** s'ouvre**.**
2. Cliquez sur **formats** &gt; **pense-bêtes**.
   Le panneau de prompt s’ouvre.
3. Sous **Par où voulez-vous commencer ?**,sélectionnez l'une des options suivantes :
   - **Un prompt textuel**
     Suivez les instructions à l’écran pour composer votre prompt.
   - (Sticky Capture) **Une image de pense-bêtes**
     1. Cliquez sur **choisir un fichier**.
     2. Depuis votre ordinateur, choisissez une image PNG ou JPG de pense-bêtes.
4. Dans le champ de saisie, cliquez sur la flèche ou appuyez sur **ENTRÉE** sur votre clavier.
   Vos pense-bêtes sont ajoutés au tableau Miro.

## Regrouper les pense-bêtes

1. Sur votre tableau Miro, sélectionnez un groupe de pense-bêtes.
   Un menu contextuel s'affiche au-dessus de votre sélection.
2. Cliquez sur **Miro IA** &gt; **Regrouper.**
3. Cliquez sur l’une des options suivantes :
   - **Par mots-clés**
     Miro IA regroupe vos pense-bêtes par mots-clés.
   - **Par sentiment**
     Miro IA regroupe vos pense-bêtes par sentiment.

:::tip
Vous pouvez éventuellement renommer chaque regroupement.
:::

## Résumer un groupe de pense-bêtes

1. Sur votre tableau Miro, sélectionnez un groupe de pense-bêtes.
   Le menu contextuel s’affiche au-dessus de votre sélection.
2. Cliquez sur **Miro IA** > **Document** > **Résumé**.
   Miro IA génère un résumé basé sur vos pense-bêtes sélectionnés.

## Générer un document à partir de pense-bêtes

1. Sélectionnez un groupe de pense-bêtes.
   Le menu contextuel s’affiche au-dessus de votre sélection.
2. Cliquez sur **Miro IA** > **Document**.
3. Sélectionnez le type de document que vous souhaitez générer.
   Miro IA génère votre document.
