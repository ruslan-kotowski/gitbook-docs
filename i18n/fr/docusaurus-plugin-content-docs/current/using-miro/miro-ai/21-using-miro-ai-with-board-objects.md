Utilisez Miro IA avec une grande variété d’objets du tableau, notamment des [pense-bêtes](../essential-tools/14-sticky-notes.md), des images, des diagrammes et des [cartes mentales](../advanced-tools/03-mind-map.md).

> **Disponible sur :** Navigateur, Bureau
>
> **Disponible pour :** les forfaits Free, Starter, Education, Business etEnterprise

:::warning
Miro IA est en constante évolution. Miro IA peut produire des informations incorrectes, des informations biaisées ou ne pas connaître les événements récents des 6 à 12 mois précédents, ce qui se traduit par des informations inexactes ou obsolètes. Vérifiez toujours vos résultats lorsque vous utilisez Miro IA.
:::

:::note
Miro IA est uniquement disponible pour les membres. Les invités et visiteurs ne peuvent pas l’utiliser.
:::

## Utilisation de Miro IA avec des pense-bêtes

Miro IA vous permet de :

- Générer des pense-bêtes
- Regrouper les pense-bêtes par mot-clé, auteur, étiquette, couleur ou sentiment
- Générer un document à partir de pense-bêtes
- Résumer un groupe de pense-bêtes

### Comment utiliser Miro IA pour générer des pense-bêtes ?

Suivez les étapes suivantes :

1. Au-dessus de la barre d’outils de création, sélectionnez **Créer avec AI.**
2. Sélectionnez le bouton **Pense-bêtes**.
3. (Facultatif) Sélectionnez un type.
4. Effectuez l’une des opérations suivantes pour prompt Miro IA :
   - Saisir une description
   - Sélectionner des objets sur le tableau
5. Sélectionnez **Générer des pense-bêtes**.
   Vos pense-bêtes sont ajoutées au tableau Miro.

   Vous avez utilisé avec succès Miro IA pour générer des pense-bêtes.

### Comment utiliser Miro IA pour regrouper des pense-bêtes

Suivez les étapes suivantes :

1. Utilisez l’outil **Sélectionner** pour sélectionner un groupe de pense-bêtes.
   Le menu contextuel s’affiche au-dessus de votre sélection.
2. Dans le menu contextuel, sélectionnez le bouton **Objets de regroupement**.
3. Effectuez l’une des opérations suivantes :
   - Sélectionnez une option de regroupement.
     Vos pense-bêtes sont regroupées en fonction de votre sélection.
   - Sélectionnez **Créer un regroupement**.
     Vos pense-bêtes sont regroupées. Pour donner du contexte, vous pouvez éventuellement renommer votre regroupement.

     Vous avez réussi à utiliser Miro IA pour regrouper des pense-bêtes.

### Comment utiliser Miro IA pour générer un document à partir de pense-bêtes ?

Suivez les étapes suivantes :

1. Utilisez l’outil **Sélectionner** pour sélectionner un groupe de pense-bêtes.
   Le menu contextuel s’affiche au-dessus de votre sélection.
2. Dans le menu contextuel, sélectionnez **Miro IA**.
3. Passez la souris sur **Document**.
   Un menu déroulant s’ouvre.
4. Sélectionnez un type de document.
   Miro IA génère votre document.

   Vous avez utilisé avec succès Miro IA pour générer un document à partir d’une sélection de pense-bêtes.

### Comment utiliser Miro IA pour résumer un groupe de pense-bêtes ?

Suivez les étapes suivantes :

1. Utilisez l’outil **Sélectionner** pour sélectionner un groupe de pense-bêtes.
   Le menu contextuel s’affiche au-dessus de votre sélection.
2. Dans le menu contextuel, sélectionnez **Miro IA**.
3. Passez la souris sur **Document**.
   Un menu déroulant s’ouvre.
4. Sélectionnez **Résumé**.
   Miro IA génère votre résumé.

   Vous avez utilisé avec succès Miro IA pour générer un résumé sur la base d’une sélection de pense-bêtes.

## Utilisation de Miro IA pour supprimer les arrière-plans des images

Utilisez Miro IA pour supprimer l’arrière-plan d’une image.

Suivez les étapes suivantes :

1. Sélectionnez une image sur votre tableau.
   Le menu contextuel s’affiche.
2. Dans le menu contextuel, sélectionnez **Miro IA**.
   Un menu déroulant s’ouvre.
3. Sélectionnez **Supprimer l’arrière-plan**.

   Vous avez utilisé avec succès Miro IA pour supprimer l’arrière-plan d’une image.

## Utilisation de Miro IA pour générer un diagramme

Utilisez Miro IA pour générer un diagramme.

Suivez les étapes suivantes :

1. Au-dessus de la barre d’outils Création, sélectionnez **Créer avec AI.**
2. Sélectionnez le bouton **Diagramme**.
3. (Facultatif) Sélectionnez le type de diagramme.
4. Saisissez une description pour prompt Miro IA.
5. Sélectionnez **Générer un diagramme**.

   Vous avez réussi à utiliser Miro IA pour générer un digramme.

## Utilisation de Miro IA pour transformer un croquis dessiné à la main en un diagramme

Miro IA comprend Digitize Diagram (bêta), une fonction qui convertit vos croquis de diagrammes dessinés à la main en diagrammes entièrement modifiables dans Miro.

Suivez les étapes suivantes :

1. Chargez une image de votre diagramme dessiné à la main sur un tableau Miro.
2. Sélectionnez l'image.
   Le menu contextuel s’affiche.
3. Dans le menu contextuel, sélectionnez **Miro IA**.
4. Sélectionnez **Numériser le diagramme**.
   Miro IA génère une version entièrement modifiable de votre diagramme. Assurez-vous d'inspecter le résultat et de procéder à tout ajustement ou réalignement nécessaire.

   Vous avez réussi à transformer un diagramme dessiné à la main en un diagramme entièrement modifiable dans Miro.

## Utiliser Miro IA avec des cartes mentales

Utilisez Miro IA pour générer une **carte mentale** à partir d’un nœud racine.

Suivez les étapes suivantes :

1. Ajoutez une **carte mentale** à votre tableau.
2. Ajoutez du texte au nœud racine.
3. Sélectionnez le nœud racine.
   Le menu contextuel s’affiche.
4. Dans le menu contextuel, sélectionnez **Miro IA**.
   Un menu déroulant s’ouvre.
5. Dans le menu déroulant, sélectionnez **Générer une carte mentale**.
   Une **carte mentale** apparaît en fonction de votre nœud racine.
6. Indiquez si vous souhaitez **conserver**, **réessayer** ou **rejeter** la **carte mentale** générée.

   Vous avez réussi à utiliser Miro IA pour générer une **carte mentale.**

**Plus d’informations :** Voir [carte mentale](../advanced-tools/03-mind-map.md).

## Utilisation de Miro IA pour éditer du texte

Utilisez Miro IA pour apporter les modifications suivantes au texte de votre tableau :

- Corriger la grammaire et l’orthographe
- Raccourcir le texte
- Réécrire pour plus de clarté
- Ajustez le ton pour qu’il soit amical, professionnel, commercial ou amusant.
- Traduisez en anglais et dans 17 autres langues prises en charge, dont le français, l'allemand, le japonais, l'italien et le turc. Pour voir toutes les langues que Miro IA traduit, consultez l'[édition de texte optimisée par l'IA](18-miro-ai-reference.md).

**En savoir plus :** Voir l'[aperçu de la création et de la modification avec l'IA](03-create-with-ai.md).

## Utiliser Miro IA pour suggérer des textes alt pour les images

Miro IA peut générer du texte alt pour vos images.

Suivez les étapes suivantes :

1. Sélectionnez une image sur votre tableau.
   Le menu contextuel s’affiche.
2. Dans le menu contextuel, sélectionnez **ALT**.
   La boîte de dialogue **Description de l’image** s’ouvre. **Miro IA** génère automatiquement une suggestion.
3. Sélectionnez **Insérer**.
   La suggestion générée est automatiquement enregistrée.
4. (Facultatif) Modifiez la suggestion insérée. Les modifications sont automatiquement enregistrées.
5. Fermez la boîte de dialogue **Description de l’image**.

   Vous avez utilisé avec succès Miro IA pour suggérer un texte alt pour une image.

:::note
La génération de texte alt avec Miro IA ne consomme pas de crédits d’IA.
:::
