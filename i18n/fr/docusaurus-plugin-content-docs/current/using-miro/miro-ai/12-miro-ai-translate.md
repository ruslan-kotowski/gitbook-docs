Miro IA vous permet de traduire le texte de votre canevas dans l’une des langues suivantes :

- Arabe
- Danois
- Néerlandais
- Anglais
- Finnois
- Français
- Allemand
- Italien
- Japonais
- Coréen
- Norvégien
- Polonais
- Portugais
- Russe
- Espagnol
- Suédois
- Thaï
- Turc

:::note
Pour utiliser cette fonction, votre admin d’entreprise doit avoir activé Miro IA pour votre organisation.
:::

## Traduire du texte sur le canevas avec Miro IA

1. Sélectionnez un ou plusieurs objets sur votre canevas Miro, tels que des pense-bêtes.
   Un menu contextuel s’affiche.
2. Cliquez sur **Miro IA**.
3. Placez le curseur sur **Traduire**, puis sélectionnez une langue.
   Miro IA traduit le texte dans vos objets sélectionnés.

   > 💡 Le menu déroulant **Traduire** affiche les 8 langues les plus utilisées. Cliquez sur **Afficher plus** pour voir la liste complète des langues disponibles. Votre dernière langue utilisée est épinglée en haut.

## Consommation de crédits pour Miro IA

Traduire avec Miro IA consomme 1 crédit d’IA par action de traduction.

Si vous sélectionnez un objet sur votre canevas avec 1 mot ou 100 mots, vous consommez exactement 1 crédit d’IA lorsque vous traduisez tout le texte en une seule action.

Si vous avez sélectionné plusieurs objets et effectuez une action de traduction, vous consommez 1 crédit d’IA Miro.
