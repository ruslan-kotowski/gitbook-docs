Les partenaires d’IA sont des assistants personnels pilotés par l'IA au sein de Miro. Utilisez les partenaires d’IA pour résoudre des problèmes ouverts ou améliorer les travaux d'exploration dans Miro.

Cet article explique comment utiliser les partenaires d’IA. Pour des informations générales, consultez [Vue d'ensemble des partenaires d’IA](06-sidekicks-overview.md) et [Partenaires d’IA par forfait](06-sidekicks-overview.md).

## ACCÉDEZ AUX PARTENAIRES D’IA

Lors de l'ouverture d'un nouveau tableau ou tableau vide en mode IA :

1. Cliquez sur le lien Eexplorer les partenaires d’IA sous la boîte de prompt IA. Alternativement, entrez un prompt dans la boîte, cela vous mènera à un partenaire d’IA approprié.
2. Utilisez le partenaire d’IA général ou explorez d’autres partenaires d’IA dans la bibliothèque.
3. Alternativement, cliquez sur l’icône **parfaite d’IA** (![icon-ai.svg](../../../../../../docs/using-miro/miro-ai/images/30139618342418_icon-ai.svg)) au-dessus de la barre d’outils de création.
   Un partenaire d’IA à usage général sera lancé.

Lors de l'ouverture d'un tableau existant en mode IA, cliquez sur l'icône **partenaire d’IA** (![icon-ai.svg](../../../../../../docs/using-miro/miro-ai/images/30139618342418_icon-ai.svg)) au-dessus de la barre d'outils Création pour lancer les partenaires d’IA.

Lors de l'ouverture d'un tableau non enregistré en mode IA, cliquez sur l'icône **partenaire d’IA** (![icon-ai.svg](../../../../../../docs/using-miro/miro-ai/images/30139618342418_icon-ai.svg)) au-dessus de la barre d'outils Création pour lancer les partenaires d’IA.

## Sélectionnez un partenaire d’IA préfabriqué

Des partenaires d’IA préfabriqués par Miro et d’autres utilisateurs peuvent être utilisés pour une aide plus spécialisée sur votre tableau. Ils peuvent également être utilisés pour créer des formats ou accéder aux connaissances de votre organisation.

Pour sélectionner un partenaire d’IA préfabriqué :

1. Cliquez sur l'icône des **partenaires d’IA** (![icon-ai.svg](../../../../../../docs/using-miro/miro-ai/images/30139618342418_icon-ai.svg)) au-dessus de la barre d'outils de création.
2. En haut du panneau des partenaires d’IA, cliquez sur **Partenaire d’IA** pour ouvrir le menu de sélection.
3. Sélectionnez parmi les **partenaires d’IA récemment utilisés** ou cliquez sur **Explorer d’autres partenaires d’IA**.
4. Dans le panneau Explorer d’autres partenaires d’IA, vous pouvez également accéder à **Mes partenaires d’IA**, **Formats** et **Connaissance**.
5. Sélectionnez le partenaire d’IA que vous souhaitez utiliser et le panneau de prompt se chargera avec votre partenaire d’IA choisi.

## Créer un partenaire d’IA

1. Cliquez sur l’icône **Partenaires d’IA** (![icon-ai.svg](../../../../../../docs/using-miro/miro-ai/images/30139618342418_icon-ai.svg)) au-dessus de la barre d'outils de création.
2. En haut du panneau Partenaires d’IA, cliquez sur **Partenaire d’IA** pour ouvrir le menu de sélection.
3. Cliquez sur **Explorer plus de partenaires d’IA** dans le menu déroulant.
4. Dans le panneau Explorer plus de partenaires d’IA, sélectionnez **Mes partenaires d’IA**.
5. Cliquez sur le bouton **Créer**.
6. Entrez un **nom de partenaire d’IA**, une **description**, des **instructions** et des **amorceurs de conversation**. Vous pouvez utiliser l'IA pour aider à améliorer vos instructions ou générer des amorceurs de conversation.
7. Vous pouvez, si vous le souhaitez, sélectionner le **modèle** LLM que vous souhaitez utiliser et joindre des **sources de connaissance**.
8. Cliquez sur **Créer** pour terminer. Vous pourrez définir des autorisations pour votre partenaire d’IA afin de le partager avec votre équipe.

Lors du chargement d'une **source de connaissance** vers un partenaire d’IA personnalisé, gardez à l'esprit les éléments suivants :

- Chaque fichier peut atteindre jusqu'à 10 Mo.
- Les fichiers combinés ne doivent pas dépasser 50k tokens.
- Les fichiers peuvent être au format .pdf, .txt, .csv, ou .md (les fichiers .txt et .md devraient offrir les meilleurs résultats).

:::tip
En moyenne, 1 token ≈ 0,75 mot (en anglais). Ainsi, 50k tokens représentent environ 37 500 mots. (Cela correspond à peu près à la taille de *The Great Gatsby* de F. Scott Fitzgerald.)
:::

## Inclure le contexte du tableau

Lors de l'utilisation d'un partenaire d'IA, vous pouvez inclure le contexte du tableau dans votre prompt. Ce contexte peut comprendre tous les objets du tableau, y compris les pense-bêtes, formats, images et autres objets.

Pour inclure le contexte, sélectionnez un ou plusieurs objets sur le tableau avant de saisir votre prompt.

## Créer un format avec les partenaires d’IA

Les partenaires d’IA peuvent être utilisés pour créer des formats (Diagramme ou Carte heuristique, Document, Image, Prototype, Diapositives, Pense-bêtes ou Table) sur votre tableau.

1. Cliquez sur l’icône **Partenaires d'IA** (![icon-ai.svg](../../../../../../docs/using-miro/miro-ai/images/30139618342418_icon-ai.svg)) au-dessus de la barre d'outils de création.
2. En haut du panneau des partenaires d’IA, cliquez sur **Partenaire d'IA** pour ouvrir le menu de sélection.
3. Sélectionnez **Explorer d'autres partenaires d’IA**.
4. Dans le panneau Explorer d'autres partenaires d’IA, cliquez sur l'onglet **Formats**.
5. Sélectionnez le format que vous souhaitez créer.
6. Le panneau de prompts s’ouvrira avec le partenaire d’IA Format sélectionné.
7. Suivez les instructions pour créer votre nouveau Format.

## Ajouter des Connaissances aux partenaires d’IA

Les Connaissances vous permettent de connecter Glean, Amazon Q, Miro Insights, et de récupérer les connaissances de l’entreprise directement sur le canevas.

1. Cliquez sur l’icône **partenaires d’IA** (![icon-ai.svg](../../../../../../docs/using-miro/miro-ai/images/30139618342418_icon-ai.svg)) au-dessus de la barre d'outils de création.
2. En haut du panneau des partenaires d’IA, cliquez sur **partenaire d’IA** pour ouvrir le menu de sélection.
3. Sélectionnez **Explorer d’autres partenaires d’IA**.
4. Dans le panneau Explorer plus de partenaires d’IA, cliquez sur l’onglet **Connaissances**.
5. Cliquez sur la source de **connaissances** que vous souhaitez ajouter.
6. Il vous sera demandé de vous connecter à la source et de la connecter à Miro.
7. Une fois la source ajoutée, vous pourrez y accéder en suivant les étapes 1-5 ci-dessus.

**Plus d'informations :** Voir [Connaissances](09-knowledge.md).
