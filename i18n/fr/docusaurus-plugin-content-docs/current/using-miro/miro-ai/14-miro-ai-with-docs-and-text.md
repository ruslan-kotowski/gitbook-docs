Utilisez Miro IA pour générer des documents. Par exemple, vous pouvez inviter Miro IA à générer un cahier des charges, une proposition, un résumé de recherche ou des notes basées sur le contenu sélectionné.

Vous pouvez également utiliser Miro IA pour modifier et traduire du texte.

## Créer un document

1. Au-dessus de la barre de création, sélectionnez **Créer avec l’IA**.
   Le panneau **Créer avec l’IA** s'ouvre.
2. Cliquez sur **formats** > **Doc**.
   Le panneau de prompts s'ouvre.
3. Sélectionnez l'un des prompts de démarrage pour commencer votre description. Dans le panneau de prompts, décrivez le Doc que vous souhaitez créer. Vous pouvez éventuellement sélectionner l'un des prompts de démarrage pour commencer votre description.
4. Appuyez sur **ENTRÉE** sur votre clavier ou cliquez sur la flèche de réponse.
   Miro IA génère un Doc basé sur votre description.

:::tip
Le panneau de prompts reste ouvert, vous permettant d'affiner votre description et d'obtenir le meilleur résultat.
:::

## Modifier et traduire le texte avec Miro IA

Utilisez Miro IA pour apporter les modifications suivantes au texte de votre tableau :

- Corriger la grammaire et l’orthographe
- Raccourcir le texte
- Réécrire pour plus de clarté
- Changer le ton pour qu’il soit amical, professionnel, commercial ou amusant
- Traduire le texte en 17 langues prises en charge, y compris le français, l’allemand, le japonais, l’italien et le turc. Pour en savoir plus, voir [Miro IA Traduire](12-miro-ai-translate.md).

Suivez les étapes suivantes :

1. Sur votre tableau Miro, sélectionnez n’importe quel texte.
   Le menu contextuel s’affiche.
2. Cliquez sur **Miro IA**.
   Pour le texte dans un document, sélectionnez comment vous souhaitez que Miro IA modifie le texte.
   Pour le texte dans un autre format, sous **Ajuster**, sélectionnez votre modification.
