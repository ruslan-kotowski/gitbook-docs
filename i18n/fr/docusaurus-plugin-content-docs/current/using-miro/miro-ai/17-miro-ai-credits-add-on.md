Le module complémentaire de crédit d’IA Miro est un abonnement payant qui augmente votre limite mensuelle de crédits d’IA.

Votre forfait alloue un nombre défini de crédits d’IA chaque mois. Pour les forfaits Starter, Business et Enterprise, le module complémentaire de crédit d’IA Miro permet d’augmenter votre utilisation de l’IA dans Miro.

**Plus d'informations :** Voir [crédits d'IA Miro](../../plans-billing/billing-and-payments/03-miro-ai-credits.md) pour des informations générales sur les crédits d'IA Miro.

:::note
Le module complémentaire Miro IA augmente la limite de crédit d'IA pour votre équipe. Le module complémentaire n'offre pas de fonctionnalités. Pour en savoir plus sur chaque module complémentaire, consultez [Achat et gestion des modules complémentaires](../../plans-billing/miro-add-ons/01-purchase-and-manage-add-ons.md).
:::

## Acheter le module complémentaire Miro IA

### Free

Les équipes sur un forfait Free doivent changer de forfait pour être éligibles au module complémentaire de crédit d'IA Miro.

### Forfaits Starter et Business

Pour savoir comment acheter le module complémentaire de crédit d'IA Miro, consultez [Achat et gestion des modules complémentaires](../../plans-billing/miro-add-ons/01-purchase-and-manage-add-ons.md).

### Forfaits Enterprise

Contactez votre équipe de compte pour demander un abonnement au module complémentaire Miro IA.

**Plus d'informations :** Voir [Crédits Miro IA pour les Forfaits Enterprise](../../enterprise-administration/enterprise-subscription-management/enterprise-billing/03-miro-ai-credits-for-enterprise-plans.md).
