Vous pouvez travailler sur Miro avec une **souris**, **un pavé tactile** ou un **écran tactile**.

Si vous utilisez une souris :

- Pour vous déplacer sur le tableau, appuyez sur le bouton droit de la souris et faites glisser.
- Pour zoomer, faites tourner la molette de la souris.
- Pour créer le champ de sélection, basculez sur l'outil de sélection, cliquez et faites glisser le canevas.

Si vous utilisez un pavé tactile :

- Faites glisser deux doigts pour vous déplacer sur le tableau.
- Pincez pour zoomer.
- Pour sélectionner des objets, basculez sur l’outil de sélection, appuyez et faites glisser le canevas.

Si vous utilisez l'écran tactile :

- Faites glisser le canevas pour vous déplacer.
- Pincez pour zoomer.
- Appuyez longuement et faites glisser pour sélectionner des objets.

Pour consulter les conseils, cliquez sur l’icône de hamburger **Menu principal** > **Préférences** > **Souris ou pavé tactile** > **En savoir plus**.

**Basculement automatique** est sélectionné par défaut, mais vous pouvez modifier cette option pour **Souris** ou **Pavé tactile**. Le modèle de navigation est configuré individuellement pour chaque utilisateur et s’applique à tous les onglets du navigateur actuel.

- Sélectionnez **Souris** si vous travaillez avec la souris magique Apple. Si vous choisissez **Souris** et utilisez le pavé tactile, vous effectuerez un zoom en glissant avec deux doigts.
- Sélectionnez **Pavé tactile** si vous utilisez le pavé tactile en combinaison avec une souris ou une tablette graphique. Le mode Pavé tactile est plus pratique lorsque vous avez l’habitude de faire défiler vers le bas avec la molette et de zoomer avec la molette de la souris + **Ctrl** (*pour Windows*)/**Cmd** (*pour Mac*)

![new-mouse-trackpad.png](../../../../../../docs/using-miro/working-on-the-board/images/28438517225618_new-mouse-trackpad.png)
*Passer de la souris au pavé tactile dans les commandes de navigation*

Vous pouvez également ouvrir les commandes en faisant un clic droit n’importe où sur le tableau et en choisissant **Souris ou pavé tactile.**

Les événements tactiles se distinguent automatiquement des événements de souris ou de pavé tactile. Vous n’avez donc pas besoin de définir un mode de navigation spécifique pour votre appareil à écran tactile.

### Basculer entre l’outil de déplacement et de sélection

Pour vous déplacer sur le tableau, assurez-vous de passer en mode main. Pour sélectionner un objet, activez le mode sélection. Vous pouvez basculer entre les deux modes en activant/désactivant l’outil de sélection sur la barre d’outils (voir ci-dessous) ou en utilisant [les touches de raccourci](21-work-smarter-not-harder.md) **V** et **H.**

![select_and_hand_mode.gif](../../../../../../docs/using-miro/working-on-the-board/images/4604597173522_select%20and%20hand%20mode.gif)*Basculer entre l’outil de déplacement et de sélection*

L’outil de sélection n’est pas disponible pour les lecteurs ou les commentateurs qui ne sont pas autorisés dans Miro ou qui ne sont pas autorisés à copier les objets du tableau dans les [paramètres de contenu du tableau](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md).

Si vous utilisez une souris, vous pouvez également vous déplacer sur le tableau

- en maintenant le bouton droit enfoncé
- avec le bouton gauche tout en maintenant la barre Espace enfoncée
- avec le bouton gauche tout en maintenant la molette de la souris enfoncée (disponible uniquement pour certaines souris)

### Navigation sur le tableau

Trouvez les commandes de navigation dans le coin inférieur droit de votre tableau. Les commandes vous permettent de modifier le niveau de zoom, d’adapter le contenu du tableau à l’écran, d’ouvrir et de naviguer autour de la mini-carte (qui peut également être affichée ou masquée via la touche de raccourci **M**), d’entrer et de sortir du mode plein écran.

## Foire aux questions

**Je ne vois pas le mode écran tactile dans les paramètres de navigation. Puis-je utiliser Miro sur un écran tactile ?**

Oui, vous pouvez utiliser Miro sur tous les appareils à écran tactile. Miro détecte automatiquement les événements tactiles et les distingue des événements de souris/pavé tactile. L’écran tactile fonctionne toujours comme décrit ci-dessus, indépendamment de la souris ou du pavé tactile sélectionné dans les paramètres.

**Miro est-il compatible avec les tablettes graphiques ?**

Miro peut être utilisé avec les tablettes graphiques mais nous ne fournissons pas de mode de navigation particulier pour elles. Un stylo de tablette graphique est accepté comme une souris et fonctionne au niveau de base sans prise en charge de ses fonctionnalités spécifiques.

**Mon pavé tactile ne répond plus, ce qui m'empêche de zoomer ou de dézoomer sur les tableaux de Miro. Comment résoudre ce problème ?**

Sur Mac, cliquez sur le menu Apple dans le coin supérieur gauche de l'écran > **Paramètres système** > **Pavé tactile** > **Défilement et zoom**, puis désactivez et réactivez **Zoom et dézoome**. Pour Windows, ouvrez le menu en bas à gauche de l'écran > **Paramètres** >  **Appareils** > **Pavé tactile** > désactivez et réactivez  **Pavé tactile**.

**Lorsque j’essaie de me déplacer sur le tableau, je déplace les objets du tableau à la place. Comment résoudre ce problème ?**

Cliquez avec le bouton droit de la souris et faites glisser pour vous déplacer sur le tableau.
