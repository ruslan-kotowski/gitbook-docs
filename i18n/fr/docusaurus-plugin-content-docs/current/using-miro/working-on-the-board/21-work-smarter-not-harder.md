Miro vous propose des options très variées pour travailler avec des objets sur un tableau. Découvrez ici quelques astuces qui vous permettront d’atteindre vos objectifs plus facilement et plus rapidement.

## Navigation sur le tableau

### Utiliser la minimap

Utilisez la minimap, qui se trouve dans le coin inférieur droit du tableau en cliquant sur l'icône de pourcentage, puis sur **Afficher la minimap** (ou appuyez simplement sur la [touche de raccourci](06-shortcuts-and-hotkeys.md) **M** pour l'ouvrir/la fermer).

![navigation-toolbar-minimap.png](https://help.miro.com/hc/article_attachments/21999288589458)

*Afficher la mini-carte*

### Passer du mode sélection au mode déplacement

Essayez d’utiliser les [raccourcis clavier](06-shortcuts-and-hotkeys.md) pour sélectionner un objet spécifique ou pour vous déplacer sur le tableau. Utilisez les raccourcis clavier **V** et **H** pour alterner entre les modes **sélectionner/modifier** (outil de curseur) et les modes **main**/**déplacement**. Vous pouvez également activer le mode de sélection dans la barre d’outils.

> Pour plus d’informations à propos de la navigation sur le tableau, consultez [cet article](05-using-miro-with-a-mouse-trackpad-or-touchscreen.md).

![outil_de_sélection_de_travail_plus_intelligent.png](../../../../../../docs/using-miro/working-on-the-board/images/21016720033170_work_smarter_select_tool.png)*L’outil de sélection dans la barre d’outils*

## Travailler avec des objets

### Duplication intelligente

Accélérez votre travail grâce aux raccourcis **Ctrl + D** pour dupliquer rapidement et facilement des objets du tableau.

![duplication_intelligente.gif](https://help.miro.com/hc/article_attachments/21017429553938)*Duplication intelligente*

:::note
Vous pouvez également utiliser **Alt + flèches** pour dupliquer un objet verticalement ou horizontalement.
:::

### Dimensions de l’objet pour des diagrammes précis

Produisez des diagrammes professionnels plus rapidement et plus facilement. Utilisez les [dimensions de l’objet](../formats/diagramming/01-miro-for-mapping-diagramming.md) pour créer des objets de même taille avec précision sur votre tableau.

![Using_dimensions_in_Miro.gif](../../../../../../docs/using-miro/working-on-the-board/images/21016720042386_Using%20dimensions%20in%20Miro.gif)

### Verrouiller un objet

Évitez que les objets soient accidentellement déplacés, modifiés ou supprimés en les verrouillant. Utilisez un verrou de protection pour empêcher les autres utilisateurs de modifier votre contenu. Pour en savoir plus, consultez l’article : [Verrouillage du contenu sur le tableau](17-locking-content-on-the-board.md).

![lock_content.jpg](https://help.miro.com/hc/article_attachments/21017429555090)*Option de verrouillage*

### Aligner les objets

L’activation de cette option crée des guides d’alignement pour tous les objets que vous déplacez, ce qui contribue à donner aux objets du tableau un aspect propre et équilibré.

![main_menu_work_smarter_align_objects.gif](../../../../../../docs/using-miro/working-on-the-board/images/21016720045458_main_menu_work_smarter_align_objects.gif)*Alignement d’objets sur le tableau*

Vous pouvez activer/désactiver la fonctionnalité dans le menu principal. Cliquez sur les **trois points** (**...**) > **Préférences** > **Aligner les objets**.

![align-objects.pngL'](https://help.miro.com/hc/article_attachments/21858032492562)
*option permettant d'activer l'alignement des objets dans les tableaux.*

### Disposition des objets

Disposez les objets sur votre tableau. Cette fonction vous aide à styliser avec précision les tableaux et les diagrammes, en particulier lorsque le contenu se chevauche en grande partie.

1. Sélectionnez l’objet.
2. Dans le menu contextuel, cliquez sur les trois points (**..**.) pour ouvrir le menu **Plus.**
3. Choisissez l’une des options suivantes :

- **Mettre au premier plan :** Déplacez un objet devant tous les autres objets.
- **Mettre à l’arrière-plan :** Déplacez un objet à l’arrière de tous les objets.
- **Avancer :** Déplacez un objet devant l’objet situé juste devant lui.
- **Reculer :** Déplacez un objet derrière l’objet qui se trouve directement derrière lui.

:::note
Cette fonction n’est pas disponible pour les cadres. Les cadres sont toujours placés derrière les tableaux.
:::

Sélectionner et filtrer les objets

Les filtres sont extrêmement utiles si vous devez modifier simultanément plusieurs objets d’un certain type dans un groupe : sélectionnez plusieurs éléments, cliquez sur **Filtrer** dans le menu contextuel et choisissez un type d’objet. Pour en savoir plus sur la sélection d’objets, consultez [cet article](10-working-with-objects.md).

![Miro_filters.gif](https://help.miro.com/hc/article_attachments/21017429555858)*Sélection, filtrage et modification de plusieurs objets*

Faire pivoter des objets

Faites facilement pivoter les objets sur le tableau pour ajuster votre contenu. Cherchez l’icône dans le coin inférieur gauche de l’objet, cliquez dessus et déplacez-la pour modifier la position comme indiqué ci-dessous.

![rotation_d’un_objet.gif](https://help.miro.com/hc/article_attachments/21017429556498)*Rotation d’un objet*

### Nettoyage du contenu

Vous pouvez effacer simultanément le contenu de plusieurs widgets (tels que les pense-bêtes, les formes et les cartes). Cette fonction vous permet de supprimer tout le texte, les balises, les émojis, les auteurs, les assignés et les dates d'échéance des widgets sélectionnés, en les ramenant à leur état d'origine tout en conservant leur style (couleurs, tailles, etc.).

Pour effacer le contenu :

1. Sélectionnez les widgets que vous souhaitez effacer.
2. Cliquez avec le bouton droit de la souris pour ouvrir le menu contextuel.
3. Choisissez "Effacer le contenu" dans le menu.
4. Vous pouvez également utiliser le raccourci Cmd + Retour arrière (Mac) ou Ctrl + Retour arrière (Windows).

Le contenu en clair ne fonctionne pas sur d'autres widgets (par exemple, texte, widgets de tableau) et ne fonctionne pas sur les cartes Jira ou Azure. Si un utilisateur sélectionne plusieurs pense-bêtes, formes et cartes, le contenu sera supprimé sur tous les widgets à l'exception des cartes Jira/Azure.

## Travailler avec des documents

### Séparer les pages d’un document

> **Disponible sur :** version pour navigateur, [application de bureau](../../getting-started/apps-for-devices/05-desktop-app.md)

Un moyen pour votre équipe de collaborer sur des documents ou des fichiers PDF ou Powerpoint : agrandissez et disposez les pages sur le tableau et laissez des commentaires directement sur chaque.

Pour diviser un fichier PDF ou Powerpoint en un certain nombre de pages :

1. Chargez le fichier sur le tableau.
2. Cliquez sur le fichier. Dans le menu contextuel, choisissez ****Extraire les pages.****
   > ✏️ Cette option est disponible en [mode curseur (sélection)](#mini)  uniquement. Si l’option n’apparaît pas dans le menu, appuyez sur la touche **V** ou sélectionnez le curseur dans la barre d’outils, puis cliquez à nouveau sur l’objet.

   ![extraire_pages.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016688251154_extract%20pages.jpg)*L’option d’extraction des pages dans le menu contextuel du PDF*
3. Choisissez la manière dont vous souhaitez diviser le fichier - toutes les pages ou seulement certaines d’entre elles - et cliquez sur **Extraire**.
   ![extraire_pages.gif](https://help.miro.com/hc/article_attachments/21017429552914)*Extraction des pages*

Les pages agrandies apparaîtront juste en dessous du fichier original. Si le fichier original est inutile, vous pouvez le supprimer. Toutes les pages extraites resteront sur le tableau.

Épingler des pages

Pour épingler une page donnée d’un document sur un tableau, cliquez sur cette page dans le menu contextuel du document, sélectionnez **Épingler** et choisissez **Définir cette page comme page de démarrage**. Chaque fois que vous ouvrirez le tableau, cette page sera la première.

> **✏️** L’option **Définir cette page comme page de démarrage** est uniquement disponible en [mode curseur (sélection)](#pan). Si l’option est grisée, appuyez sur la touche **V** ou sélectionnez le curseur dans la barre d’outils et cliquez à nouveau sur l’objet.

![pin_pages.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016688258706_pin%20pages.jpg)*Épingler une page*

## Travailler avec des images

### Remplacer des images

Vous pouvez remplacer n’importe quelle image du tableau sans que cela n’affecte les autres objets du canevas.

1. Cliquez sur l’image pour ouvrir le menu contextuel.
2. Cliquez sur l’icône **Remplacer l’image** et sélectionnez l’une des options suivantes :

- **Remplacer à partir de la bibliothèque :** L’[application Images et icônes](../essential-tools/08-images-and-icons.md) s’ouvre et vous pouvez sélectionner une nouvelle image.
- **Remplacer depuis le tableau :** Vous serez invité à sélectionner une autre image déjà présente sur le tableau.
- **Charger depuis votre appareil :** Chargez et remplacez l’image par celle de votre appareil.
- **Chargez via l’URL :** Remplacez l’image par une image hébergée en ligne en saisissant l’URL de l’image dans la boîte de dialogue.

![Remplacer les images.png](https://help.miro.com/hc/article_attachments/21017429570706)

### Recadrer des images

Il n’est pas nécessaire d’utiliser un logiciel tiers pour recadrer les images, car Miro dispose d’un outil dédié. Sélectionnez une image ou choisissez **Recadrer** dans le menu contextuel. Cela active le mode  recadrage, qui permet de modifier la sélection **rectangulaire**. Les limites de recadrage s’adaptent au contenu du tableau environnant pour garantir que la disposition des images est bien nette. Vous pouvez modifier la position et la taille des images que vous recadrez tout en conservant l’alignement avec les autres contenus du tableau. Lorsque c’est fait, il vous suffit de cliquer n’importe où sur le tableau.

![recadrer_image.gif](../../../../../../docs/using-miro/working-on-the-board/images/21016688266130_blobid1.gif)*Recadrage d’une image*

Vous pouvez **recadrer les images sous plusieurs formes** (par exemple un cercle, un carré, etc.). Sélectionnez l’image, cliquez sur l’icône **Recadrer** dans le menu contextuel et sélectionnez une forme dans le menu déroulant.

![recadrage_dans_les_formes.gif](https://help.miro.com/hc/article_attachments/21017429560850)*Recadrage d’une image dans un cercle*

Vous pouvez également **recadrer plusieurs images en même temps, sous plusieurs formes**. Cliquez et faites glisser pour sélectionner les images. Cliquez ensuite sur l’icône **Recadrer** dans le menu contextuel et choisissez une forme dans le menu déroulant.

![](https://help.miro.com/hc/article_attachments/21017429561874)*Recadrer plusieurs images en cercle en même temps*

:::tip
Vous pouvez toujours revenir à l’original de votre image recadrée, il suffit de double-cliquer et de développer la sélection de recadrage à sa taille d’origine.
:::

### Bordures d’image

Ajoutez des bordures aux images et aux captures d’écran que vous chargez ou collez sur votre tableau pour les faire ressortir.

1. Cliquez sur l’image.
2. Dans le menu contextuel, cliquez sur l’icône de bordure.
3. Sélectionnez la couleur et ajustez l’épaisseur de votre bordure.

![Image_borders.gif](../../../../../../docs/using-miro/working-on-the-board/images/21016688270610_Image%20borders.gif)
*Ajouter une bordure d’image à une capture d’écran*

### Redimensionner plusieurs images en même temps

Redimensionnez la hauteur ou la largeur de plusieurs images en même temps sur votre tableau. Utilisez ensuite [Mise en page automatique](08-structuring-board-content.md) pour les aligner instantanément.

**Comment redimensionner plusieurs images en même temps**

1. Faites glisser le curseur pour sélectionner toutes les images à redimensionner.
2. Cliquez sur l’icône redimensionner dans le menu contextuel. Vous devez sélectionner plusieurs images avant que l’option redimensionner n’apparaisse.
3. Sélectionnez **Conserver la hauteur** ou Conserver la largeur.
4. Cliquez sur l’icône grise **Mise en page automatique** dans le coin supérieur droit.

*![Redimensionnement en masse des images.gif](https://help.miro.com/hc/article_attachments/21017429560594)**Redimensionnement en masse des images en hauteur ou en largeur*

### Ajouter des GIF

Ajoutez des GIF à vos tableaux Miro pour donner vie à vos idées grâce à un contenu animé amusant. Les GIF sont lus pour chaque utilisateur pendant 8 secondes ou le temps d’une boucle lorsqu’ils sont ajoutés au tableau, et lorsque les utilisateurs les survolent. Les GIF sont uniquement lus pour les utilisateurs qui interagissent avec le tableau, et non pour tout le monde en temps réel.

Activez la fonction de [réduction du mouvement](../../getting-started/accessibility-in-miro/06-reduce-motion.md) pour désactiver la lecture automatique des GIF.

> Les GIF dans les présentations et les [enregistrements Miro](../facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md) sont lus automatiquement et continuent en boucle tant qu’ils sont visibles à l’écran.

## Foire aux questions

1. *Puis-je aligner des objets sur le tableau ?*
   - Oui, vous trouverez plus de détails sur [cette page](08-structuring-board-content.md).
2. *Puis-je faire pivoter le [texte](../essential-tools/16-text.md)?*
   - Oui, vous pouvez faire pivoter les zones de texte en faisant glisser l’icône de la flèche.
3. *Puis-je recadrer des fichiers PDF ?*
   - Non, ce n’est pas possible pour le moment.
