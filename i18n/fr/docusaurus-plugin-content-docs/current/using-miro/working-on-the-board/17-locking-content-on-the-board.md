Empêchez les objets d'être accidentellement déplacés, modifiés ou supprimés en les verrouillant sur votre tableau Miro. Les éditeurs qui ont été invités à un tableau [par e-mail](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) ou qui ont accès parce qu'ils font partie d'un [projet](../sharing-boards/16-projects.md) ou d'une [équipe](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) peuvent verrouiller et déverrouiller des objets.

Pour une protection supplémentaire, les propriétaires et copropriétaires de tableaux sur des forfaits payants ou Education peuvent utiliser le verrouillage protégé. Cette fonctionnalité garantit que seul le propriétaire ou le copropriétaire du tableau qui a verrouillé un élément peut le déverrouiller, empêchant ainsi les autres éditeurs de déplacer ou de supprimer accidentellement du contenu important.

:::warning
Les visiteurs ne peuvent pas verrouiller ou déverrouiller des objets sur le tableau. Le contenu des [tables](../advanced-tools/05-grid.md), [tableaux Kanban](../advanced-tools/02-columns-formerly-kanban.md), [cartes mentales](../advanced-tools/03-mind-map.md), [cartes user story](../advanced-tools/07-user-story-mapping.md), et [couloirs](../formats/diagramming/01-miro-for-mapping-diagramming.md) ne peuvent pas non plus être verrouillés.
:::

## Verrouiller et déverrouiller des objets

Vous pouvez verrouiller et déverrouiller un ou plusieurs objets sur votre tableau.

Pour verrouiller un objet, sélectionnez-le et cliquez sur l'icône **Verrouiller** dans le menu contextuel. Vous pouvez également utiliser le raccourci **Ctrl + Maj + L** (*pour Windows*) ou **Cmd + Maj + L** (*pour Mac*). Sur mobile, l'option Verrouiller est accessible via le menu des trois points verticaux (![icon-main.svg](../../../../../../docs/using-miro/working-on-the-board/images/24005170925074_icon-main.svg)) après avoir appuyé sur un objet.

![L'option de verrouillage sur le menu contextuel d'un objet.](../../../../../../docs/using-miro/working-on-the-board/images/21016057891346_lock%20in%20Miro.jpg)
*L'option Verrouiller dans le menu contextuel*

Pour verrouiller plusieurs objets, sélectionnez les objets concernés, puis cliquez sur l'icône **Verrouiller** dans le menu contextuel ou utilisez le raccourci clavier.

Pour déverrouiller un objet, appuyez longuement sur l'icône **Verrouiller** dans le menu contextuel. Vous pouvez également utiliser à nouveau le même raccourci, ou cliquer avec le bouton droit sur l'objet et choisir **Déverrouiller**.

:::note
Si un objet a un verrouillage protégé activé, seul le propriétaire ou copropriétaire du tableau qui l'a verrouillé peut le déverrouiller.
:::

![Appuyer longuement sur l’icône de verrouillage pour déverrouiller un objet.](../../../../../../docs/using-miro/working-on-the-board/images/21016057894418_long%20press%20to%20unlock.jpg)
*Appuyez longuement sur l'icône pour déverrouiller un objet*

### Déverrouiller tous les objets

Pour déverrouiller tous les objets du tableau en une seule fois, cliquez avec le bouton droit de la souris sur une zone vide du tableau et sélectionnez **Déverrouiller tout**. Vous pouvez également cliquer sur les trois points dans le menu contextuel de tout objet verrouillé et choisir la même option.

:::note
Les éléments verrouillés protégés ne seront pas déverrouillés à moins que vous ne soyez le propriétaire ou copropriétaire du tableau qui a activé le verrouillage.
:::

![L'option pour déverrouiller tous les objets sur le tableau.](../../../../../../docs/using-miro/working-on-the-board/images/21016044523410_unlock%20all.jpg)
*Déverrouillage de tous les éléments sur le tableau*

## Utiliser le verrouillage protégé

> **Configuré par :** les propriétaires de tableaux, [copropriétaires de tableaux](../sharing-boards/06-co-owners-of-boards-and-spaces.md)

Utilisez un verrou protégé pour empêcher les autres collaborateurs de déverrouiller le contenu important du tableau.

Pour activer le verrouillage protégé, verrouillez d'abord un élément comme d'habitude. Puis, cliquez sur l'icône de bouclier qui apparaît dans le menu contextuel. Une fois que le bouclier est actif, les autres personnes sur le tableau ne pourront pas déverrouiller l'objet. Vous pouvez désactiver le verrouillage protégé à tout moment en déverrouillant l'article vous-même.

![Un utilisateur activant la fonctionnalité de verrouillage protégé sur un objet verrouillé.](../../../../../../docs/using-miro/working-on-the-board/images/21016044524434_protected%20lock.gif)
*Activation du verrouillage protégé sur un objet*

### Ce que voient les collaborateurs

Les objets avec un verrou protégé apparaissent différemment pour les autres collaborateurs sur le tableau. Pour les autres utilisateurs, l'option permettant de déverrouiller l'objet n'est pas disponible, et un message indique que l'élément est protégé par le propriétaire du tableau.
