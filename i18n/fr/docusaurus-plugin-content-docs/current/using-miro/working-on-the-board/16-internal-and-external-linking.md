Enrichissez le contenu de votre tableau en associant des objets à un site Web externe ou à un autre objet du tableau.

Avecl’option **Lien vers**, vous pouvez :

- Créer des prototypes interactifs
- Simplifier la navigation sur le tableau
- Ajouter des liens vers des références et des ressources utiles
- Lier des [pense-bêtes](../essential-tools/14-sticky-notes.md) ou des [cartes](../essential-tools/02-cards.md) à des liens de suivi des tâches.

## Lier des objets

1. Sélectionnez l'objet que vous souhaitez lier à, puis cliquez sur les **trois points** (**...**) dans le menu contextuel
2. Dans le menu contextuel, choisissez **Copier le lien**
3. Sélectionnez un objet à partir duquel vous souhaitez établir **un lien**, puis cliquez sur l'icône **trois points** (**...**) dans le menu contextuel
4. Choisissez **Lien vers** ou utilisez **Option +** **Cmd + K** (*pour Mac*) ou **Alt +** **Cmd + K** (*pour Windows*)
5. Insérez l'URL ou cliquez sur un autre objet du tableau que vous souhaitez lier

:::tip
Lier rapidement des objets grâce à la palette de commandes. Cliquez sur l’objet, appuyez sur **Cmd + K** et **lier à l’objet** apparaîtra comme la première option du menu. Il suffit de coller votre lien dans le champ texte et d'appuyer sur **Entrée**.
:::

Veuillez noter qu’un objet sur le tableau ne peut être lié qu’à *un* seul site Web ou objet Miro. Vous pouvez créer des liens vers des sites Web externes, vers d’autres tableaux Miro, vers des objets spécifiques sur des tableaux.
Pour aller à l’URL liée, il vous suffit de cliquer sur l’icône du lien.

1. Cliquez sur les trois points dans le menu contextuel.

3. Changez le lien ou cliquez sur **Supprimer le lien** dans la fenêtre contextuelle.![change_or_delete_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057156242_change%20or%20delete%20link.jpg)*L’option permettant de supprimer un lien*

## Liens vers des objets sur le tableau

Vous pouvez obtenir un lien direct vers n’importe quel objet du tableau ([cadres](../essential-tools/07-frames.md), images, [formes](../essential-tools/11-shapes.md), etc.). Partagez ce lien avec vos collaborateurs pour attirer leur attention sur l’endroit exact du tableau.

1. Cliquez sur l'objet que vous souhaitez lier pour afficher le menu contextuel.
2. Cliquez sur l’icône des **trois points** (**...**).
3. Choisissez **Copier le lien**.![copy_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057158162_copy%20link.jpg)*Copie du lien vers un cadre*

Si l'objet lié est supprimé, les utilisateurs qui suivent le lien verront le message "*L’élément lié a été supprimé de ce tableau*". Il est possible de [restaurer du contenu supprimé](18-restoring-board-content.md) via la liste des activités.

## Coller des liens sur le tableau

Vous pouvez coller un lien sur votre tableau à l’aide des raccourcis : **Ctrl + V** (*pour Windows*) ou **Cmd + V** (*pour Mac*). Le lien affichera un aperçu.

*![link_to_help_center.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057159186_link%20to%20help%20center.jpg)
Le lien vers le centre d'assistance Miro sur le tableau*

Pour coller un lien sur un tableau sans l'aperçu, utilisez l' [outil de texte](../essential-tools/16-text.md) et collez le lien dans la zone de texte.

## Lier du texte

Lorsque vous travaillez avec des objets qui contiennent du texte, cliquez sur l’icône **lien** dans le menu contextuel pour insérer un lien dans le texte.

![insert_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016043786642_insert%20link.jpg)
 *L’option permettant d’insérer un lien*

Vous pouvez également sélectionner le texte et utiliser **Ctrl + V** (*pour Windows*) / **Cmd + V** (*pour Mac*) pour coller un lien.

![insert_link.gif](../../../../../../docs/using-miro/working-on-the-board/images/21016057161490_insert%20link.gif)
*Insertion d’un lien dans une ligne de texte*

:::note
Si vous liez deux objets sur un tableau via l’option **Insert link**et que vous dupliquez ensuite le tableau, le lien sur la copie du tableau mènera au tableau d'origine. Cependant, lorsque vous liez deux objets sur le tableau via l’option Lier à, puis dupliquez le tableau, le lien sur la copie restera interne (il mènera à l'objet du même tableau).
:::

## FAQ

Puis-je lier mon tableau à un autre tableau Miro ?

Oui, copiez le lien vers le tableau (ou un objet particulier du tableau) et collez-le sur le tableau d'origine (ou ajoutez le lien à un objet ou à des [notes](../essential-tools/17-visual-notes.md)). Vous pouvez également [intégrer des tableaux Miro](../import-and-export/export/02-embed-a-miro-board.md).

Comment puis-je copier un lien vers mon tableau ?

Ouvrez le [dialogue Partager](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) du tableau et cliquez sur **Copier le lien du tableau**. Vous pouvez aussi simplement copier le lien à partir de la barre d’adresse du navigateur. Si vous avez un tableau ouvert dans l’[application de bureau](../../getting-started/apps-for-devices/05-desktop-app.md), cliquez sur **Fichier > Copier le lien du tableau**.

Comment créer un lien vers une zone spécifique de mon tableau ?

Vous pouvez créer un [cadre](../essential-tools/07-frames.md) qui couvre la zone et copier un lien vers le cadre. Notez que [les utilisateurs qui ont accès à votre tableau](../sharing-boards/05-who-has-access-to-my-board.md) pourront également naviguer et voir d’autres zones du tableau.

Puis-je supprimer tous les liens de mon tableau en une seule fois ?

Vous pouvez supprimer tous les liens qui ont été collés sur le canevas en plusieurs clics. [Sélectionnez tous les objets](10-working-with-objects.md), choisissez **Filtrer** dans le menu contextuel, sélectionnez **Aperçu,** et supprimez les objets de lien sélectionnés.
![filter_perviews.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057163410_filter%20perviews.jpg)
*Filtrer les aperçus dans les objets sélectionnés*

Puis-je créer un lien vers des fichiers locaux sur mon ordinateur ?

Non. Il est préférable, pour des raisons de sécurité, de télécharger vos fichiers vers un service dans le cloud et de créer un lien à partir de là.

Miro reconnaît-il les hyperliens des adresses e-mail comme des liens mailto: ?

Cette fonctionnalité n’est pas prise en charge pour le moment.
