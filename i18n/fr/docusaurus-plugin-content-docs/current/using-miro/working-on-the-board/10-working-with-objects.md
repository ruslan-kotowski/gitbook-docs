## Sélectionner plusieurs objets

Assurez-vous d’avoir activé l’[outil de sélection](21-work-smarter-not-harder.md) (ou appuyez sur **V** pour l’activer) et faites glisser le champ de sélection sur les objets nécessaires. Cela sélectionnera chaque objet touché par la sélection (à l'exception de l'[USM](../advanced-tools/07-user-story-mapping.md), du [Kanban](../advanced-tools/02-columns-formerly-kanban.md), des [cartes mentales](../advanced-tools/03-mind-map.md) et des [tables](../advanced-tools/05-grid.md) - pour sélectionner ces objets, couvrez au moins 90 % avec le champ de sélection). Si vous travaillez dans l’[application mobile](../../getting-started/apps-for-devices/08-mobile-app.md) ou l’[application pour tablette](../../getting-started/apps-for-devices/11-tablet-app.md) ou si vous utilisez un écran tactile, faites un **appui long** et faites glisser.

Vous pouvez également utiliser la fonctionnalité de filtre d’objet pour sélectionner des types d’objets spécifiques à déplacer. Cliquez et faites glisser pour sélectionner tous les objets, puis cliquez sur **Filtre** dans le menu contextuel et sélectionnez un type d’objet. Le champ de sélection s'ajustera, et vous pourrez ne déplacer que les objets que vous avez filtrés.

![object-select.png](../../../../../../docs/using-miro/working-on-the-board/images/25827368311698_object-select.png)
*Filtrer par type d'objet*

Pour effectuer une sélection *précise* qui n'inclut un objet que si 90 % ou plus de sa surface est couverte, cliquez/appuyez longuement et faites glisser. Ceci est utile si vous devez sélectionner des objets se trouvant au-dessus d’une autre forme de fond.

Si vous travaillez avec un clavier, vous pouvez également sélectionner des objets particuliers en cliquant dessus un par un tout en maintenant enfoncée la touche **Maj** ou **Ctrl** *(pour Windows)/***Commande** *(pour Mac).*

### Sélection précise

La sélection précise vous permet de sélectionner des objets uniquement lorsque vous couvrez plus de 90 % de leur surface.

Pour utiliser la sélection précise, assurez-vous d'utiliser l'outil de sélection. Puis appuyez longuement sur le bouton de votre souris. Vous pouvez maintenant faire glisser l'outil de sélection en utilisant la sélection précise.

## Utilisation de l’outil lasso pour sélectionner plusieurs objets

L’outil Lasso constitue une autre façon de sélectionner des objets. Pour inclure un objet dans la sélection, vous devez inclure au moins 90 % de celui-ci dans la zone de sélection.

:::tip
Sélectionnez tous les éléments du tableau à l’aide du raccourci **Ctrl+A** / **Cmd+A** [raccourci](06-shortcuts-and-hotkeys.md).
:::

## Modifier les objets sélectionnés

Les objets sélectionnés peuvent être déplacés et redimensionnés ensemble. Vous pouvez [align](08-structuring-board-content.md), [grouper](08-structuring-board-content.md), [verrouiller](17-locking-content-on-the-board.md) et filtrer les objets (voir ci-dessous), ou utiliser d'autres options du menu.

:::note
Assurez-vous qu’aucun des objets que vous souhaitez sélectionner n’est [verrouillé](17-locking-content-on-the-board.md). Sinon, vous devrez d'abord les déverrouiller en cliquant sur l'objet et en choisissant **Déverrouiller**.
:::

:::warning
Vous ne pouvez pas grouper des objets au sein de [tables](../advanced-tools/05-grid.md) ni des objets situés sur différents [cadres](../essential-tools/07-frames.md).
:::

:::warning
[Les visiteurs](../sharing-boards/08-collaboration-with-visitors.md) ne peuvent pas verrouiller/déverrouiller des objets sur le tableau. Si le [verrouillage protégé](17-locking-content-on-the-board.md) est activé sur un objet, seul le propriétaire du tableau/[copropriétaire](../sharing-boards/06-co-owners-of-boards-and-spaces.md) peut le déverrouiller.
:::

:::tip
Une autre façon de déplacer des objets ensemble consiste à les placer sur un cadre unique et à déplacer le cadre. [En savoir plus](../essential-tools/07-frames.md) sur les cadres dans Miro.
:::

Duplication intelligente

Accélérez votre travail en utilisant le raccourci **Ctrl + D** pour dupliquer rapidement et facilement des objets sur le tableau.

:::note
Vous pouvez également utiliser **Alt + flèches** pour dupliquer un objet verticalement ou horizontalement.
:::

## Verrouiller un objet

Évitez que les objets soient accidentellement déplacés, modifiés ou supprimés en les verrouillant. Utilisez un verrou de protection pour empêcher les autres utilisateurs de modifier votre contenu. Pour en savoir plus, consultez l’article : [Verrouiller le contenu sur le tableau](17-locking-content-on-the-board.md).

## Aligner les objets

L’activation de cette option crée des guides d’alignement pour tous les objets que vous déplacez, ce qui contribue à donner aux objets du tableau un aspect propre et équilibré.

Vous pouvez activer/désactiver la fonctionnalité dans le menu principal. Cliquez sur les **trois points** (**...**) > **Préférences** > **Aligner les objets.**

![align-objects.png](../../../../../../docs/using-miro/working-on-the-board/images/25827368311954_align-objects.png)
*L’option permettant d’activer l’alignement des objets dans les paramètres du tableau*

## Disposition des objets

Disposez les objets sur votre tableau. Cette fonctionnalité vous aide à styliser avec précision les tableaux et les diagrammes, en particulier avec une grande quantité de contenu qui se chevauche.

1. Sélectionnez l’objet.
2. Dans le menu contextuel, cliquez sur les trois points (**...**) pour ouvrir le menu **plus**.
3. Choisissez l’une des options suivantes :

- **Mettre au premier plan :** Déplacez un objet devant tous les autres objets.
- **Mettre à l’arrière-plan :** Déplacez un objet à l’arrière de tous les objets.
- **Avancer :** Déplacez un objet devant l’objet situé juste devant lui.
- **Reculer :** Déplacez un objet derrière l’objet qui se trouve directement derrière lui.

:::note
Cette fonction n’est pas disponible pour les cadres. Les cadres sont toujours placés derrière les objets du tableau.
:::

## Faire pivoter des objets

Faites facilement pivoter les objets sur le tableau pour ajuster votre contenu. Trouvez l'icône de rotation dans le coin inférieur gauche de l'objet, cliquez dessus et faites-la glisser pour changer la position.

![rotate-object.png](../../../../../../docs/using-miro/working-on-the-board/images/25827368312338_rotate-object.png)

## Effacement du contenu

Vous pouvez effacer le contenu de plusieurs widgets (tels que les pense-bêtes, formes et cartes) simultanément. Cette fonctionnalité vous permet de supprimer tous les textes, étiquettes, émojis, auteurs, personnes assignées et dates d’échéance des widgets sélectionnés, les ramenant à leur état original tout en conservant leur style (couleurs, tailles, etc.).

Pour effacer le contenu :

1. Sélectionnez les widgets que vous souhaitez effacer.
2. Cliquez avec le bouton droit pour ouvrir le menu contextuel.
3. Choisissez "Effacer le contenu" dans le menu.
4. Vous pouvez également utiliser le raccourci Cmd + Retour arrière (Mac) ou Ctrl + Retour arrière (Windows).

Effacer le contenu ne fonctionne pas sur d'autres widgets (par exemple, texte, widgets de tableau) et ne fonctionne pas sur les cartes Jira ou Azure. Si un utilisateur sélectionne plusieurs pense-bêtes, formes et cartes, le contenu sera supprimé sur tous les widgets sauf pour les cartes Jira/Azure.

## Foire aux questions

1. *Je ne peux pas faire glisser le champ de sélection. Que faire ?*  - Veuillez vous assurer de passer à l'[outil de sélection](21-work-smarter-not-harder.md).
2. *Je ne peux pas grouper les objets sélectionnés. Pourquoi ?*  - Veuillez noter qu'il n'est pas possible de regrouper des objets dans des [tables](../advanced-tools/05-grid.md) et des objets situés sur différents [cadres.](../essential-tools/07-frames.md)
3. *Puis-je sélectionner et déplacer des objets individuels à l’intérieur d’un groupe ?*  - Oui, double-cliquez sur un objet et faites-le glisser. Regardez comment faire cela [sur cette page](08-structuring-board-content.md).
