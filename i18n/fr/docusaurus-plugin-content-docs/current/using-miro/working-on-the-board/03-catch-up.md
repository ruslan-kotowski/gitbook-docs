Le Récapitulatif donne aux utilisateurs une vue d’ensemble simplifiée, alimentée par l’IA, des modifications apportées au tableau depuis la dernière fois qu’il a été consulté.

> ***Disponible pour :** Tous les forfaits*
> ***Disponible pour :** Application de bureau, navigateur de bureau*
> ***Qui peut l’utiliser :** Tous les utilisateurs*

## Fonctionnalités clés

La fonctionnalité Récapitulatif comprend les fonctionnalités clés suivantes :

- **Voir les mises en évidence visuelles**
  Les mises à jour importantes sont mises en évidence sur le tableau.
- **Résumé rapide des modifications**
  Voir immédiatement ce qui a changé et ce qui nécessite une action.
- **Présentation détaillée étape par étape**
  Obtenez une présentation détaillée des modifications et changements, organisés par sections sur le tableau.

## Comment utiliser le Récapitulatif

Procédez comme suit pour accéder et utiliser le Récapitulatif.

1. Cliquez sur l’icône **Activité** (![icon-activity.svg](../../../../../../docs/using-miro/working-on-the-board/images/24093924443794_icon-activity.svg)) dans la barre d'outils en haut à droite.
   Le menu Activité s’ouvre.
2. Cliquez sur le bouton **Récapitulatif**.
   La boite de dialogue du récapitulatif s’ouvre sur le tableau.

   ![catch-up-new.png](../../../../../../docs/using-miro/working-on-the-board/images/27120802154642_catch-up-new.png)*La boite de dialogue Récapitulatif sur le tableau*
3. Les **modifications récentes** seront affichées avec la vue d’ensemble.
4. Cliquez sur une modification récente pour accéder directement à ce panneau.
5. Cliquez sur **Afficher les détails** pour commencer à examiner les modifications.
6. Utilisez les boutons de **flèche** avant et arrière dans la boite de dialogue pour naviguer dans le Récapitulatif.
7. Cliquez sur les liens numériques pour consulter la section pertinente sur le tableau.
8. Utilisez le menu déroulant pour sélectionner une autre période à consulter : la semaine dernière, les deux dernières semaines, ou le mois dernier.

### Procédure alternative pour accéder au récapitulatif

Procédez comme suit pour accéder de manière supplémentaire au récapitulatif.

1. Cliquez sur l'icône du **menu principal** (![icon-main.svg](../../../../../../docs/using-miro/working-on-the-board/images/24005170925074_icon-main.svg)).
   Le menu principal s’ouvre.
2. Passez le curseur sur le bouton **Tableau**.
   Le sous-menu du tableau s’ouvre.
3. Cliquez sur le bouton **Récapitulatif**.
   La boite de dialogue du récapitulatif s’ouvre.

## FAQ

**Pourquoi ne puis-je pas accéder au Récapitulatif ?**

Le Récapitulatif est uniquement disponible pour les utilisateurs ayant Miro IA activé. Si votre admin n’a pas activé Miro IA, il devra le faire pour que vous puissiez accéder au Récapitulatif. Les instructions pour cela se trouvent ici : [Activation de la fonctionnalité](../../enterprise-administration/managing-enterprise-teams-and-content/06-feature-activation.md).
