L’outil de regroupement organise les pense-bêtes en conteneurs, les triant par étiquette, par couleur, par auteur ou par mots-clés. Vous pouvez également créer votre propre regroupement.

## Comment regrouper des pense-bêtes

1. Faites glisser le champ de sélection sur les cartes, ou sélectionnez les cartes une à une tout en maintenant enfoncée la touche **Maj** ou **Ctrl** *(Windows)* ou **Commande** *(Mac)*.
2. Cliquez sur **Cluster objects** (Regroupement d’objets) dans le menu contextuel
3. Sélectionnez Cluster by (Regroupement par) **Color (Couleur), Tag (Étiquette), Author (Auteur), Keywords (Mots-clés) ou Create a cluster (Créer un cluster)**

### Comment regrouper des pense-bêtes par couleur

Si vous regroupez par couleur, vous devez ajouter un titre manuellement à chaque groupe de pense-bêtes.

Clustering_by_color.gif
Regroupement par couleur

### Comment regrouper des pense-bêtes par étiquette

Si vous regroupez par [étiquette](../essential-tools/14-sticky-notes.md), les titres sont générés automatiquement. Si un pense-bête comporte plusieurs étiquettes, il sera dupliqué dans chaque regroupement. Si certains pense-bêtes ne comportent pas d’étiquette, ils seront groupés dans un regroupement dont le titre par défaut sera « no tag » (sans étiquette).

![Regroupement_par_tag.gif](../../../../../../docs/using-miro/working-on-the-board/images/21019592732562_Clustering%20by%20tag.gif)*Regroupement par étiquette*

### Comment regrouper des pense-bêtes par auteur

Si vous regroupez par auteur, le titre de chaque regroupement sera le nom de l’auteur qui a créé ces pense-bêtes.

cluster_by_author.jpg

### Comment regrouper des pense-bêtes en fonction de votre sélection

Si vous choisissez l’option **create a cluster** (créer un cluster), tous les pense-bêtes sélectionnés seront automatiquement groupés dans un même regroupement. Une fois que le regroupement est créé, vous pouvez le déplacer n’importe où dans votre tableau.

1. Faites glisser le champ de sélection sur les cartes, ou sélectionnez les cartes une à une tout en maintenant enfoncée la touche **Maj** ou **Ctrl** *(Windows)* ou **Commande** *(Mac)*.
2. Cliquez sur **Cluster objects** (Regroupement d’objets) dans le menu contextuel
3. **Cliquez sur** **C****reate a cluster (Créer un cluster)**

### Comment regrouper par mots-clés

Utilisez le regroupement par mots-clés pour organiser les idées et les thèmes des pense-bêtes. Cet outil est parfait pour les sessions de brainstorming, les ateliers avec de nombreux participants ou les projets de recherche utilisateur. Cette fonctionnalité gérée par l’IA peut vous aider à identifier les schémas initiaux, ce qui vous permet d’affiner les données clés et d’accéder aux informations essentielles.

Le regroupement par mots-clés est pris en charge pour toutes les langues disponibles sur l’application Miro. Vous pouvez même regrouper des pense-bêtes comprenant du texte dans différentes langues.

#### **Comment regrouper par mots-clés**

1. Faites glisser le curseur pour sélectionner les pense-bêtes que vous souhaitez regrouper.
2. Cliquez sur l’icône **C****luster objects** (Regroupement d’objets) dans le menu contextuel.
3. Cliquez sur **Keywords (Mots-clés)**
4. Miro regroupera les pense-bêtes similaires et suggérera des mots-clés dans les titres. Tous les pense-bêtes qui ne sont pas similaires seront regroupés dans un groupe #uncategorized.
5. Vous pourrez alors facilement déplacer les clusters de pense-bêtes triés par catégorie sur le tableau

![Regroupement de stickies par mots-clés.gif](../../../../../../docs/using-miro/working-on-the-board/images/21019603734034_Clustering%20stickies%20by%20keywords.gif)*Regroupement des stickies par mots-clés*

### Comment regrouper par sentiment

Vous pouvez utiliser Cluster by sentiment (Regroupement par sentiment) pour organiser des groupes d’opinions ou de points de vue similaires. Cet outil géré par l’IA permet à votre équipe de voir rapidement ce qui parle aux utilisateurs et ce qui ne leur parle pas. Le regroupement est organisé en trois conteneurs : Positif, Neutre et Négatif. Les conteneurs peuvent être renommés pour répondre aux besoins de votre équipe.

Le regroupement par sentiment est pris en charge dans toutes les langues de l’application Miro. Vous pouvez même regrouper des pense-bêtes comprenant du texte dans différentes langues.

#### **Comment regrouper par sentiment**

1. Faites glisser le curseur pour sélectionner les pense-bêtes que vous souhaitez regrouper.
2. Cliquez sur l’icône **C****luster objects** (Regroupement d’objets) dans le menu contextuel.
3. Cliquez sur **Sentiment**
4. Miro regroupera les stickies similaires dans trois conteneurs : Positif, neutre, négatif. Tous les pense-bêtes qui ne sont pas similaires tombent généralement dans le conteneur Neutres.
5. Vous pouvez ensuite facilement déplacer sur le tableau les groupes de pense-bêtes ainsi triés ou les renommer en fonction des besoins de votre équipe

## Conteneurs de regroupement

Lorsque vous regroupez des objets sur le tableau, ils sont rassemblés dans des conteneurs. Tous les objets regroupés dans un conteneur peuvent facilement être déplacés ensemble sur le tableau.

![Mots clés regroupés dans des conteneurs.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21019592716690_Keywords%20clustered%20into%20containers.jpg)*Mots-clés regroupés dans des conteneurs*

Pour **renommer un cluster**, double-cliquez sur le titre et saisissez un nouveau nom.

![Renommer_un_conteneur.gif](../../../../../../docs/using-miro/working-on-the-board/images/21019603739154_Renaming%20a%20container.gif)*Renommer un regroupement*

Pour **déplacer un cluster**, cliquez sur le titre du conteneur et faites-le glisser.

![Déplacer_un_cluster_autour_du_tableau.gif](../../../../../../docs/using-miro/working-on-the-board/images/21019603743122_Moving%20a%20cluster%20around%20the%20board.gif)*Déplacement d'un conteneur autour du tableau*

Pour **redimensionner le conteneur,** cliquez sur le titre, puis faites glisser ses bordures pour en ajuster la taille.

![Redimensionnement d'un conteneur.gif](../../../../../../docs/using-miro/working-on-the-board/images/21019592723346_Resizing%20a%20container.gif)*Redimensionnement d'un conteneur*

Vous pouvez toujours **réorganiser le contenu regroupé** en sortant ou en insérant des objets individuels dans un conteneur.

![Déplacement d'objets individuels entre conteneurs.gif](../../../../../../docs/using-miro/working-on-the-board/images/21019603747218_Moving%20individual%20objects%20between%20containers.gif)*Déplacement d'un objet entre des conteneurs*
