La recherche de texte avancée de Miro vous aide à trouver et à organiser rapidement les informations sur votre tableau.

## Accéder à la fonction Rechercher

Vous pouvez accéder à la fonction **Rechercher** de deux manières :

- Cliquez sur l'icône des trois points (**...**) dans le menu du tableau, puis accédez au sous-menu **Modifier**.
- Utilisez le raccourci clavier : **Cmd + F** (pour Mac) ou **Ctrl + F** (pour Windows) [^1].

## Recherche d'objets sur un tableau

Pour rechercher des objets :

1. Lancez la fonction Rechercher en utilisant l'une des méthodes ci-dessus.
2. Tapez votre terme de recherche dans le champ de recherche.
3. Une liste de résultats apparaîtra, incluant les widgets Miro contenant votre terme de recherche.
4. Les objets trouvés seront mis en surbrillance sur le tableau, tandis que le reste du contenu sera atténué. Les résultats sont également listés sous le champ de recherche.
5. Cliquez sur n'importe quel résultat de recherche pour naviguer directement vers cet objet sur le tableau.

## Filtrage des résultats de recherche

Vous pouvez affiner votre recherche en filtrant les résultats. Par exemple, vous pouvez rechercher spécifiquement des pense-bêtes avec une étiquette particulière ou uniquement parmi les notes de texte. Pour filtrer :

1. Cliquez sur l'option de filtre à côté du champ de recherche.
2. Changez **Tout le contenu** pour une autre catégorie dans le menu déroulant.

## FAQ

**Y a-t-il une option pour « rechercher et remplacer » dans le tableau ?**

Non, pour le moment cette option n’existe pas.

**Comment puis-je trouver un mot en particulier dans une zone de texte/un pense-bête ?**

Vous pouvez utiliser cette solution alternative dans votre navigateur : accédez au mode de modification du texte en cliquant sur la zone de texte/le pense-bête et utilisez la recherche intégrée du navigateur (par exemple, dans Chrome, vous pouvez appuyer sur **Ctrl + F** (pour Windows)/ **Cmd + F** (pour Mac).
