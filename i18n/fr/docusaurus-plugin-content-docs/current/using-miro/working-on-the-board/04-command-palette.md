La palette de commandes vous permet de rechercher et de lancer rapidement les outils et applications Miro. La palette de commandes vous permet également de rechercher des tableaux récents.

La palette de commandes n’est disponible que pour les utilisateurs disposant de [droits de modification](../sharing-boards/01-board-access-rights.md) et uniquement en mode tableau standard. Il n'est pas possible de lancer la palette de commandes en mode présentation.

## Comment utiliser la palette de commandes

1. Sélectionnez l'icône **trois points verticaux** (![icon-main.svg](../../../../../../docs/using-miro/working-on-the-board/images/24005170925074_icon-main.svg)) dans la barre d'outils du tableau.
   Le menu principal s’ouvre.
2. Sélectionner **Modifier** > **Commandes**. Vous pouvez également utiliser le raccourci clavier **Cmd** + **K**.
   La palette de commandes s'ouvre.
3. Dans le champ de recherche, commencez à saisir le nom d’une application ou d’un outil, ou faites défiler la liste.
4. Cliquez pour lancer l’application ou l’outil.
