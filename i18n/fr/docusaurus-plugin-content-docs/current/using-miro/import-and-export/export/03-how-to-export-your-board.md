## Enregistrer en tant qu’image

:::warning
Edge (version < 79) prend uniquement en charge l’**exportation de vecteur**. Le forfait Free ne permet d’exporter qu’en petite taille. Les utilisateurs de l’offre Free peuvent exporter des tableaux dans Chrome, Firefox, Opera, Safari, l’application bureau ou l’application tablette.
:::

**Pour exporter un tableau sous forme d’image JPG**:

1. Ouvrez le sous-menu d'exportation en cliquant sur l'icône des trois points (**..**.), puis sur le sous-menu **Tableau** dans le coin supérieur gauche du tableau.
2. Choisissez **Enregistrer en tant qu’image**.
3. Sélectionnez la zone du tableau que vous souhaitez enregistrer en tant qu’image.
4. Sélectionnez la taille de l’image. Selon votre forfait, vous pouvez exporter votre tableau au format **Small**, **Medium**, **Large** ou **Vector** . La qualité vectorielle est sauvegardée sous forme de fichier PDF. Grâce à l’exportation vectorielle, vous pouvez préserver la qualité de l’image lors de l’exportation de tableaux de grande taille
5. Cliquez sur **Exporter**.

![export-entry-point.pngEnregistrement de](https://help.miro.com/hc/article_attachments/22040657464722)
*la partie du tableau sous forme d'image*

**Pour exporter un cadre individuel sous forme d’image :**

1. Sélectionnez un cadre.
2. Cliquez sur les trois points du menu contextuel.
3. Choisissez **Exporter en tant qu’image**.
4. Sélectionnez la taille du fichier et cliquez sur **Exporter**.

![export as image.png](../../../../../../../docs/using-miro/import-and-export/export/images/21016928433042_export%20as%20image.png)
*Enregistrement du cadre en tant qu’image*

**Pour** **exporter tout le tableau sous forme d’image :**

1. Sélectionnez tous les objets de votre tableau avec le raccourci **Ctrl + A** (Windows) ou **⌘** + **A** (Mac).
2. Cliquez sur les trois points pour créer un cadre autour d’eux.
3. Cliquez sur les trois points du menu contextuel du cadre et sélectionnez **Exporter en tant qu’image**.

*![export_the_whole_board_greybg.gif](../../../../../../../docs/using-miro/import-and-export/export/images/21016928437650_export_the_whole_board_greybg.gif)
Création d’un cadre autour des objets sélectionnés*

## Enregistrer au format PDF

:::warning
Edge (version < 79) exporte en **qualité Best (Vector)** uniquement. Le forfait Free ne permet d’exporter qu’en petite taille. Les utilisateurs de l’offre Free peuvent exporter des tableaux dans Chrome, Firefox, Opera, Safari, l’application bureau ou l’application tablette.
:::

Exportez les [cadres](../../essential-tools/07-frames.md) au format PDF en qualité **Petite** ou **Optimale** (**Vectorielle**).

**Pour exporter un tableau sous forme de fichier PDF :**

1. Créez au moins un cadre. Chaque cadre deviendra une page distincte dans le document PDF enregistré.
2. Pour vérifier l’ordre dans lequel vos cadres seront listés dans le document PDF, ouvrez l’aperçu du tableau dans le coin inférieur gauche. Pour modifier l’ordre des pages dans le PDF exporté, changez l’ordre des cadres sur le panneau en les faisant glisser
3. Ouvrez le sous-menu d'exportation en cliquant sur l'icône des trois points (**..**.), puis sur le sous-menu **Tableau** dans le coin supérieur gauche du tableau.
4. Choisissez **Enregistrer au format PDF**.
5. Sélectionnez la taille du fichier : Fichier de petite taille/span> **ou** Meilleure qualité Notez que les fichiers PDF de petite taille ne prennent pas en charge les liens intégrés.
6. Cliquez sur **Exporter**.

Si votre tableau **possède déjà des cadres** :

1. Sélectionnez tous les objets de votre tableau avec le raccourci **Ctrl + A** (*Windows*) ou **⌘ + A** (*Mac*), ou en faisant glisser le champ de sélection.
2. Dans le menu contextuel, cliquez sur **Filtrer** et sélectionnez **Cadres**.
3. Supprimez les cadres (mais conservez le contenu).
4. Sélectionnez tous les objets de votre tableau avec le raccourci **Ctrl + A** (*Windows*) ou **⌘ + A** (*Mac*), ou en faisant glisser le champ de sélection.

6. Cliquez sur **Exporter**.
7. Annulez la création du cadre et la suppression des cadres en cliquant deux fois sur le bouton **Annuler** dans la barre d’outils gauche.

## Exporter vers une feuille de calcul (.csv)

> **Disponible en :** [Navigateurs Chrome, Safari et Firefox](../../troubleshooting-technical-questions/technical-guidelines/02-supported-browsers-browser-restrictions.md), [application de bureau](../../../getting-started/apps-for-devices/05-desktop-app.md)

Le texte de votre tableau (sur les pense-bêtes, dans les tableaux, cartes, zones de texte ou formes) peut être exporté dans un fichier CSV.

**Pour exporter du texte dans un fichier CSV :**

1. Sélectionnez un cadre ou le contenu d’un tableau. Vous pouvez [sélectionner le contenu du tableau](../../working-on-the-board/10-working-with-objects.md) en faisant glisser la zone de sélection ou en maintenant la touche **Majuscule** enfoncée.
2. Cliquez sur les trois points du menu contextuel.
3. Choisissez **Exporter** **au format .csv**.
4. Cela vous donnera un fichier CSV du tableau dont le contenu se trouve dans des colonnes dans l’ordre suivant : texte, [carte](../../essential-tools/02-cards.md) description/URL, pense-bêtes/étiquette de carte.

## Où sont enregistrés les fichiers exportés

Si vous utilisez Miro dans un navigateur, les fichiers seront stockés dans le dossier dans lequel votre navigateur enregistre les téléchargements par défaut (configuré dans les paramètres du navigateur).

Si vous utilisez l’application de bureau Miro, examinez le dossier Téléchargements de votre appareil.

## Restrictions

- L’exportation de tableaux Miro peut être limitée pour les utilisateurs dans les [paramètres de contenu du tableau](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md).
- L’exportation en résolution de haute qualité sans filigrane n’est pas disponible sur le forfait Free de Miro.
- Edge (version < 79) prend uniquement en charge l’exportation vectorielle.
- L’exportation Miro au format CSV n’est pas prise en charge sur Opera, Edge (< 79), sur les tablettes et les appareils mobiles.
- L’exportation de tableaux Miro n’est pas prise en charge dans [les équipes de développeurs](https://miro.com/api/).
- L’exportation de tableaux Miro n’est pas prise en charge sur les appareils mobiles.
- Il n’est possible de cliquer sur les liens des fichiers PDF que lorsqu’ils sont exportés en qualité **vectorielle**.
- Les images bitmap du tableau sont compressées pendant le chargement, alors que les objets créés dans Miro (formes, autocollants, texte, liens, etc.) conservent leur qualité.

## Foire aux questions

*Je n’ai pas la possibilité d’exporter un tableau Miro. Pourquoi ?*

L’option d’exportation peut être restreinte dans les [tableaux](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) par le propriétaire du tableau. Si l’exportation du tableau est autorisée dans les paramètres de contenu du tableau mais que certaines options d’exportation sont toujours manquantes, assurez-vous que votre forfait, votre appareil et votre navigateur prennent en charge l’exportation du tableau - vérifier la disponibilité de l’exportation.

*Comment autoriser les collaborateurs de mon tableau à exporter ?*

Vérifiez les [paramètres du contenu de votre tableau](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) et assurez-vous que l’option de copie du tableau est disponible pour les participants au tableau. Vous devrez peut-être également demander à votre admin de [d’autoriser la copie du contenu du tableau par des utilisateurs extérieurs à l’équipe](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md).

*Puis-je exporter mon tableau au format PPT/PNG/SVG ?*

Non, pour le moment, vous pouvez enregistrer vos tableaux sous forme de fichiers PDF/JPG/CSV.

*Les commentaires sont-ils inclus dans le document exporté ?*

Non, mais nous avons cette fonctionnalité dans notre backlog.

*Le titre des cadres est-il indiqué sur le document exporté ?*

Non, mais vous pouvez remplacer le titre des cadres par des [widgets de texte](../../essential-tools/16-text.md) qui seront affichés dans le document.

*Puis-je exporter des résultats de vote ?*

Non, veuillez effectuer une capture d’écran.

*Lorsque je travaille sur mon tableau, tous les changements que j’apporte sont-ils automatiquement enregistrés ?*

Oui. Nous vous recommandons également d’enregistrer les [sauvegardes du tableau](05-how-to-save-board-backup.md) et d’exporter le tableau pour vous assurer que votre contenu n’est pas supprimé accidentellement. Si vous travaillez sur [Tableau blanc Web](../../special-features/10-web-whiteboard.md) et que vous n’avez pas de profil Miro, [enregistrez-vous auprès de Miro](../../../getting-started/start-here/02-how-to-register-with-miro.md) pour sauvegarder votre tableau et continuer à y travailler après 24 heures.

*Comment exporter un élément unique ou un ensemble d’éléments ?*

Vous pouvez choisir **Enregistrer sous forme d’image** dans le menu **Exportation** du tableau et sélectionner la zone où se trouve l’image à capturer. Une autre méthode consiste à [sélectionner le ou les objets](../../working-on-the-board/10-working-with-objects.md), à [créer un cadre autour d’eux](../../essential-tools/07-frames.md) et à l’exporter.

*Puis-je exporter mon tableau dans un fichier CSV avec des données intelligentes ?*

Pour l’instant, l’exportation CSV ne conserve pas la structure et les relations des tableaux. Toutefois, si vous exportez les [tableaux](../../advanced-tools/05-grid.md) sous forme de fichier CSV, la structure est sauvegardée.

*Puis-je exporter des fichiers chargés sur le tableau ?*

Oui, si cela est autorisé dans les [tableaux des paramètres de contenu](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md). Si l’option n’est pas limitée, sélectionnez le fichier et cliquez sur l’icône de téléchargement dans le menu contextuel.

:::note
Si vous rencontrez des problèmes pour exporter votre tableau Miro, explorez les solutions possibles dans l’article [Problèmes d’exportation du tableau](../../tools/troubleshooting/03-board-export-issues.md).
:::
