Lorsque vous intégrez du contenu Miro sur un autre site, celui-ci peut avoir besoin d'accéder aux cookies de Miro sur votre appareil. Ces cookies permettent de maintenir les sessions des utilisateurs, leurs préférences et d'autres fonctionnalités. Les utilisateurs peuvent choisir d'autoriser les tableaux intégrés à utiliser les cookies de Miro.com.

## Avantages de l'autorisation des cookies

- Les utilisateurs connectés à Miro le restent pour les tableaux intégrés.
- Après actualisation, les utilisateurs restent connectés aux tableaux intégrés.
- Garantit la pleine fonctionnalité des fonctions de Miro qui dépendent des cookies.

## Comment autoriser les cookies

1. Rendez-vous sur le site web ou l'application avec le tableau Miro intégré.
2. Lorsque vous y êtes prompt, cliquez sur **Autoriser les cookies**, puis confirmez toute autre invite de votre navigateur.
3. Si vous étiez déjà connecté à Miro, vous le resterez pour le tableau intégré. Si ce n'est pas le cas, il vous suffit de vous reconnecter, et vous serez connecté la prochaine fois que vous accéderez au tableau intégré.

:::note
Les utilisateurs doivent se connecter à Miro pour accéder aux tableaux privés, tandis que les tableaux publics sont accessibles sans connexion.
:::

## Résolution des problèmes

Si le message " **Les cookies n'ont pas été autorisés"** s'affiche, suivez les étapes de dépannage de votre navigateur pour donner votre accord.

![Cookies-not-allowed-error-embedded-boards.pngMessage](../../../../../../../docs/using-miro/import-and-export/export/images/21017725810578_Cookies-not-allowed-error-embedded-boards.png)
*d'erreur concernant refusés*

### Dépannage pour Firefox et Safari

Firefox Safari

1. Cliquez sur l'icône **Permissions** dans la barre d'adresse de votre navigateur Firefox. Si vous voyez **Bloqué** ou **Bloqué temporairement** à côté de Miro, cliquez sur le **X** pour le supprimer.

   ![Firefox-embed-cookies-troubleshooting.pngUnblocage des](../../../../../../../docs/using-miro/import-and-export/export/images/21017696085010_Firefox-embed-cookies-troubleshooting.png)
*cookies pour miro.com dans Firefox*
2. Si le problème persiste, effacez tout l'historique de votre navigateur :
   1. Ouvrez Firefox, cliquez sur **Historique** dans le menu supérieur, puis sur **Effacer l'historique récent**.
   2. Définissez l'intervalle de temps sur **Tout**, assurez-vous que l'option **Paramètres du site** est sélectionnée et cliquez sur **Effacer maintenant.**
   3. Rechargez la page web avec le tableau Miro intégré et suivez les étapes pour autoriser les cookies.

![Clear-history-firefox.pngEffacer l](../../../../../../../docs/using-miro/import-and-export/export/images/21017696089234_Clear-history-firefox.png)
*'historique de Firefox*

1. Assurez-vous d'avoir récemment visité le site miro.com à l'aide de Safari. Le navigateur peut refuser les autorisations si le site Miro.com n'a pas été consulté au cours des 30 derniers jours. Après avoir visité le site miro.com, rechargez la page web avec le tableau Miro intégré et suivez les étapes pour autoriser les cookies.
2. Si le problème persiste, effacez tout l'historique de votre navigateur :
   1. Ouvrez Safari, cliquez sur **Historique** dans le menu supérieur, puis sur **Effacer l'historique**.
   2. Choisissez **Tout l'historique** comme plage de temps et confirmez en cliquant à nouveau sur **Effacer l'historique**.
   3. Rechargez la page web avec le tableau Miro intégré et suivez les étapes pour autoriser les cookies.
