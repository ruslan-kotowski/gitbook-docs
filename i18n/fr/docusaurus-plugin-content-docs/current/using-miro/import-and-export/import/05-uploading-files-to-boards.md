Pour ajouter facilement des fichiers sur vos tableaux, il vous suffit de les faire glisser depuis votre bureau et de les déposer sur votre tableau. Vous pouvez ajouter des images, des fichiers PDF, des documents Google Drive et des fichiers MS Office. La liste complète des types de fichiers pris en charge est disponible dans [cet article](../../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md). De nouveaux fichiers peuvent être ajoutés depuis votre ordinateur ou depuis le Web (la taille maximale des fichiers est de 30 Mo, la résolution maximale des images est de 32 MP et les dimensions maximales sont de 8192x4096 pixels).

> **Configuré par :** [les éditeurs de tableau](../../sharing-boards/01-board-access-rights.md)
> **Disponible pour :**Tous les forfaits Miro (les forfaits Free ne peuvent pas lire de vidéos intégrées)

### Ajouter des fichiers depuis votre appareil

Pour charger des fichiers à partir de votre appareil, sélectionnez **Charger** dans la barre d’outils de création. Si l’option est masquée, cliquez sur les flèches **plus d’outils** (>>) et ajoutez le bouton dans la barre d’outils. Cliquez sur **Mon appareil**.

![upload_on_the_toolbar_greybg.gif](../../../../../../../docs/using-miro/import-and-export/import/images/21016967591442_upload_on_the_toolbar_greybg.gif)
*Le bouton Charger sur la barre d’outils*

Une boîte de dialogue s’ouvrira et vous pourrez y sélectionner les fichiers que vous souhaitez charger sur le tableau. Après avoir sélectionné les fichiers et cliqué sur **Open**, ces derniers seront chargés et apparaîtront sur le tableau.

Vous pouvez également charger des fichiers depuis votre ordinateur en les faisant glisser et en les déposant sur le tableau.

:::note
Consultez la liste des formats de fichier pris en charge [ici](../../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md).
:::

Vous pouvez interagir avec les fichiers chargés : modifier leur taille, les faire pivoter, tourner et extraire des pages.

![change_an_uploaded_object_greybg.gif](../../../../../../../docs/using-miro/import-and-export/import/images/21016967592850_change_an_uploaded_object_greybg.gif)
*Interactions avec un fichier PDF chargé*

Si vous utilisez l'[application mobile](../../../getting-started/apps-for-devices/08-mobile-app.md), appuyez sur l'icône plus en bas à droite du tableau, choisissez **Charger**. Vous pouvez coller un fichier à partir du presse-papiers, prendre une photo ou choisir une image dans la bibliothèque mobile. Le téléchargement de fichiers PDF à partir d'appareils mobiles n'est actuellement pas pris en charge.

![upload on mobile.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005106578_upload%20on%20mobile.png)
*Chargement d’un fichier depuis un appareil mobile*

### Ajouter des fichiers via des liens URL

Pour charger des fichiers depuis le web à l’aide d’un lien direct vers la source, choisissez **Charger via** **URL.**

*![Upload via URL.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005103890_Upload%20via%20URL.png)**Charger via URL sur la barre d’outils*

Collez ensuite un lien URL direct vers un fichier du web, comme une vidéo YouTube ou Vimeo.

![upload via URL modal.png](../../../../../../../docs/using-miro/import-and-export/import/images/21016967594898_upload%20via%20URL%20modal.png)
*Chargement via une URL*

:::note
La lecture de vidéos intégrées n'est pas disponible dans les forfaits Free et pour les utilisateurs avec une licence basique.
:::

Pour regarder une vidéo, double-cliquez sur l’icône **Play** (Lire) (le fichier ajouté ne sera pas automatiquement lu). Vous pourrez également vous rendre sur la page **Source** et utiliser d’autres fonctions disponibles dans le menu contextuel.

Vous pouvez gérer les vidéos ajoutées à Miro directement depuis vos tableaux : utilisez l’option d’avance rapide, ajoutez des sous-titres et modifiez leur qualité.

![video embed.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005108114_video%20embed.png)
*L’option permettant d’accéder à la source vidéo*

Vous pouvez également publier un lien menant vers un fichier directement sur un tableau en utilisant les raccourcis **Ctrl+C**/**Ctrl+V**(*pour Windows*) ou **Cmd+C/Cmd+V**(*pour Mac*).

Pour coller une URL sur le tableau sans aperçu, utilisez l'[outil de texte](../../essential-tools/16-text.md) et collez le lien dans la zone de texte.

### Charger des fichiers depuis d'autres services

Vous pouvez également charger des fichiers depuis [Google Drive](../../../integrations-apps/google/05-google-drive.md), [Dropbox](../../../integrations-apps/more-integrations/06-dropbox.md), [Box](../../../integrations-apps/more-integrations/05-box-legacy.md), [OneDrive](../../../integrations-apps/microsoft/06-onedrive.md), [Adobe CC](../../../integrations-apps/adobe/02-adobe-creative-cloud.md). Toutes les options sont disponibles dans le menu **Téléchargement**. Consultez les articles correspondants pour en savoir plus.

Notez que les [visiteurs](../../sharing-boards/08-collaboration-with-visitors.md) ne peuvent pas utiliser cette option.

*L’option permettant de charger des fichiers depuis différents services de stockage*

### Enregistrer des fichiers chargés dans la bibliothèque

Vous pouvez enregistrer les fichiers chargés dans votre bibliothèque Miro pour une utilisation ultérieure au sein de l’équipe en sélectionnant le fichier, en cliquant sur les trois points du menu contextuel et en sélectionnant **Ajouter dans les fichiers enregistrés**. Cette fonctionnalité est disponible pour les fichiers PDF, les images, les présentations, les documents Google et d’autres fichiers.

![add to saved files.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005108882_add%20to%20saved%20files.png)
*L’option permettant d’ajouter un fichier aux fichiers enregistrés*

Les fichiers enregistrés sont disponibles dans le dossier **Saved files** (Fichiers enregistrés) du menu **Upload** (Téléchargement) sur la barre d’outils. Pour ajouter un fichier depuis la bibliothèque, cliquez dessus ou faites-le glisser et déposez-le sur le tableau. Veuillez noter que les fichiers enregistrés ne seront accessibles que pour les tableaux de l’équipe où est stocké le tableau à partir duquel les fichiers ont été enregistrés.

![saved files.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005109522_saved%20files.png)
*Fichiers enregistrés dans la barre d’outils*

Pour supprimer un fichier de la bibliothèque, passez votre souris sur ce fichier et cliquez sur l’icône de **corbeille**.

![delete a saved file.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005111314_delete%20a%20saved%20file.png)
*Suppression d’un fichier des fichiers enregistrés en cliquant sur l’icône de **corbeille***

Si l’option **Ajouter aux fichiers enregistrés** est inactive (grisée) et que le message d’erreur indique **Cet outil est indisponible sur ce tableau**, cela signifie que vous n’avez pas assez de droits pour effectuer l’action car vous n’êtes pas un membre de l’équipe où le tableau est stocké.

### Séparer les pages d’un document

> **Disponible sur :** version navigateur, [application de bureau](../../../getting-started/apps-for-devices/05-desktop-app.md)

Un moyen pour votre équipe de collaborer sur des documents ou des fichiers PDF ou Powerpoint : agrandissez et disposez les pages sur le tableau et laissez des commentaires directement sur chaque page.

Pour diviser un fichier PDF ou Powerpoint en un certain nombre de pages :

1. Chargez le fichier sur le tableau.
2. Cliquez sur le fichier, dans le menu contextuel, choisissez l'icône **Extraire les pages**.

   > ✏️ L'option est disponible uniquement en [mode curseur (sélection)](#mini). Si l'option n'apparaît pas dans le menu, appuyez sur **V** ou sélectionnez le curseur dans la barre d'outils et cliquez à nouveau sur l'objet.
3. Dans la boîte de dialogue, choisissez comment vous souhaitez diviser le fichier — toutes les pages ou seulement des pages spécifiques, puis cliquez sur **Extraire.**

Les pages agrandies apparaîtront juste en dessous du fichier original. Si le fichier original est inutile, vous pouvez le supprimer — toutes les pages extraites resteront sur le tableau.

### Problèmes possibles lors du chargement de fichiers PDF

Le chargement de certains fichiers PDF sur un tableau Miro échoue : la roue de chargement tourne sans fin ou les fichiers se transforment en images grisées surmontées d’un signe d’erreur. Si vous rencontrez ce problème, veuillez vérifier les éléments suivants :

- Votre fichier PDF ne dépasse pas les 30 Mo
- Votre connexion Internet est stable
- Votre appareil respecte la [configuration requise](../../troubleshooting-technical-questions/technical-guidelines/01-system-requirements.md)

Si vous rencontrez toujours des problèmes lors du chargement d’un fichier sur votre tableau, il se peut que le fichier lui-même soit à l’origine du problème. Certains fichiers PDF complexes ne peuvent pas être affichés sur les tableaux en raison de nos limitations techniques. Ce problème survient généralement avec les fichiers PDF qui contiennent de nombreux éléments ou petits détails. Nous nous efforçons d’améliorer notre outil de rendu, mais pour l’instant, veuillez utiliser l’une de ces solutions :

- Enregistrez le fichier sous format PNG ou JPEG dans le logiciel que vous avez utilisé pour le créer
- Ou convertissez un fichier PDF au format PNG ou JPEG à l’aide d’un convertisseur en ligne (vous pouvez utiliser n’importe quel convertisseur de votre choix, par exemple, `https://www.freepdfconvert.com/pdf-to-png` ou `https://cloudconvert.com/`)

:::note
Si vous rencontrez d'autres problèmes pour charger des fichiers sur les tableaux Miro, veuillez essayer les étapes de dépannage de [cet article](../../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md).
:::

## Foire aux questions

**Puis-je charger des fichiers vidéo de mon appareil sur les tableaux Miro ?**

Non, mais vous pouvez facilement intégrer des vidéos. Veuillez consulter ce guide : [Intégrer des médias dans les tableaux](../../../integrations-apps/integrations-basics/03-embed-integrations-on-a-miro-board.md).

**Puis-je importer des données modifiables à partir d'un fichier Excel ou CSV ?**

Les feuilles de calcul, y compris les fichiers .xlsx et CSV, peuvent être importées en lecture seule, ou peuvent être utilisées pour créer une Table ou une Grille. Pour plus d’informations : [Table](../../formats/14-tables.md) ou [Grille](../../advanced-tools/05-grid.md).

**Puis-je télécharger des fichiers à partir d'un tableau ?**

Oui, si cela est autorisé dans les [paramètres de contenu du tableau](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md). Pour télécharger un fichier, sélectionnez-le et cliquez sur **Télécharger** dans le menu contextuel.

**Puis-je cliquer sur des liens dans les fichiers PDF chargés ?**

Non, cela n’est pas possible actuellement.
