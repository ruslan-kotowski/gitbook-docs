Importez le contenu de votre tableau dans le format plus structuré d'un doc. À partir des objets sur le canevas, vous pouvez créer des résumés, des rapports de recherche et des fiches produits pour démarrer l'assemblage et l'analyse de vos idées.

> Disponible pour : Tous les forfaits Miro
> Disponible sur : Bureau, mobile, affichages interactifs

## Comment accéder aux documents

Pour ajouter un nouveau doc, cliquez sur l’icône plus, recherchez "Docs", puis cliquez n’importe où sur le canevas pour l’ajouter. Les documents sont également inclus dans certains modèles de tableaux.

![](../../../../../../docs/using-miro/tools/images/25640385657234_33fb246e-3278-4496-8a69-5bd34721a01e.png)

*Ajout d’un nouveau document depuis l’icône Docs*

Vous pouvez également ajouter un document avec Miro AI.

![](https://help.miro.com/hc/article_attachments/25640673716498)

*Ajouter un document avec Miro IA*

Pour ajouter un Doc depuis le menu contextuel :

1. Créez un document en sélectionnant plusieurs objets sur le tableau (comme des Stickies).
2. Sélectionnez **Document** depuis l'icône **Miro IA** dans le menu contextuel pour ouvrir le sous-menu.
3. Choisissez un modèle ou utilisez un **Prompt personnalisé**.
4. Le document est créé et placé sur le tableau.

![doc-from-stickies.png](https://help.miro.com/hc/article_attachments/25640673718418)

*Ajout d'un document via le menu contextuel*

Pour ajouter un document avec Miro IA :

1. Ouvrez le panneau **Créer avec l’IA**.
2. Sélectionnez le type de contenu **Document**.
3. Utilisez l'une des propositions prédéfinies ou rédigez la vôtre.
4. Sélectionnez des objets (tels que des pense-bêtes) sur le tableau pour ajouter du contexte, si nécessaire.
5. Cliquez sur **Générer le document**.
6. Votre document généré apparaitra dans une zone vierge sur le canevas.

## Modèles de Miro Docs

Il y a actuellement quatre modèles disponibles lorsque vous commencez un nouveau Doc : Document produit, Résumé de rétrospective, Comptes-rendus de réunion, et Synthèse de recherche.

Lorsque vous créez un nouveau document et sélectionnez un modèle, le modèle est ajouté au document.

## Travailler sur des documents en mode plein écran

Les documents peuvent être ouverts en mode plein écran lorsque vous souhaitez vous concentrer uniquement sur le document sur lequel vous travaillez et non sur d'autres contenus du tableau. Pour accéder à ce mode, cliquez sur l’**icône plein écran** au-dessus du Doc sur lequel vous travaillez.

![docs-full-screen-icon.png](../../../../../../docs/using-miro/tools/images/25640369213074_docs-full-screen-icon.png)

*L'icône Docs en plein écran*

Le mode plein écran inclut toujours les menus contextuels pour formater le texte. Il supprime le fond du tableau, éliminant ainsi les distractions potentielles.

Pour quitter le mode plein écran, cliquez sur le bouton **Idéation sur le canevas** en haut de l'écran.

![docs-focus-mode.png](../../../../../../docs/using-miro/tools/images/25640385661202_docs-focus-mode.png)

### Limite de caractères

Les Miro Docs peuvent contenir jusqu’à 80 000 caractères. Si vous avez besoin de plus d'espace, vous pouvez créer des Docs supplémentaires sur le même tableau et diviser votre contenu en conséquence. Cela vous aide à rester dans la limite tout en organisant toutes vos informations en un seul endroit.

## Copier le contenu vers Docs

Vous pouvez faire glisser et déposer le contenu suivant de votre tableau vers un Document :

- pense-bête
- Boite de texte
- Image
- iFrame
- Aperçu
- Tableau
- Frise chronologique
- Diagramme

:::note
Docs convertit les pense-bêtes et les zones de texte en liste à puces.
:::

### Diagrammes dans Docs

Lorsque vous faites glisser et déposez un diagramme dans un document, Miro crée une [copie synchronisée](../working-on-the-board/11-synced-copies.md). Cela signifie que les modifications apportées au diagramme original sur le tableau seront répercutées dans la copie au sein du document, mais pas l'inverse. Pour modifier le contenu de la copie, modifiez le contenu du Diagramme original.

Cela garantit que votre documentation reste à jour avec les dernières informations visuelles.

### Autres comportements liés au contenu dans Docs

Pour les widgets avec mode focalisation, comme un tableau, vous pouvez toujours accéder au mode immersif lorsque le widget se trouve à l'intérieur d'un document. Les dimensions s'ajustent pour s'adapter et défilent à l'intérieur du document.

Vous pouvez également glisser le contenu en dehors du Doc pour le replacer sur votre tableau.

## Utilisation des raccourcis clavier dans Docs

Les raccourcis clavier peuvent être utilisés pour appliquer des types de titre et de liste au texte (ces raccourcis peuvent être consultés dans le sous-menu des types de paragraphe) :

Transformer en **Utilisation de cmd + opt + \{number\}**

- 0 -> Paragraphe
- Titre 1
- Titre 2
- Titre 3
- Liste de 4 éléments
- Liste numérotée
- 6 -> Liste de vérification

Vous pouvez également utiliser des raccourcis clavier pour la sélection de blocs : appuyez une fois sur Échap pour entrer en mode de sélection de blocs, puis :

- **maj + haut/bas** -> agrandir votre sélection
- **cmd + opt + haut/bas** -> déplacer votre sélection vers le haut et vers le bas

Voici d'autres fonctionnalités dans Docs accessibles via des raccourcis clavier :

|  |  |
| --- | --- |
| **⌘** + **entrée** | Focus sur le menu de sélection du texte |
| **⌘** + **Maj** + **X** | Activer/désactiver le texte barré |
| **⌘** + **maj** + **U** | Ajouter un lien |
| **⌘** + **E** | Activer/désactiver le code en ligne |
| **⌘** + **,** | Cocher/Décocher l’élément de la liste |
| **⌘** + **/** | Ouvrir le menu contextuel du bloc |
| **⌘** + **D** | Dupliquer les blocs sélectionnés |
| **⌘** + **I** | Copier le lien vers un bloc |

Vous pouvez accéder à la liste complète des raccourcis clavier depuis l'application Miro en cliquant sur l'icône **Aide et ressources** dans le coin inférieur droit de l'écran :

![docs-raccourcis-clavier.png](https://help.miro.com/hc/article_attachments/25640673733266)

## Utiliser Miro IA dans les documents

Utiliser Miro IA pour éditer vos documents est un excellent moyen d'accélérer le processus de révision et de créer des documents plus concis et faciles à lire.

Vous pouvez utiliser Miro IA pour modifier le texte surligné dans un document.

![](https://help.miro.com/hc/article_attachments/25640673738898)

*Demander à Miro IA de modifier le texte mis en évidence dans un document Miro.*

Pour utiliser du texte en ligne pour prompt Miro IA, surlignez le texte dans votre Miro Doc. Dans le menu contextuel, à l'extrémité droite, sélectionnez **Améliorer avec Miro IA**. Dans le menu déroulant, sélectionnez **Demande personnalisée** ou l'une des demandes disponibles.

## Collaboration dans Miro Docs

Miro Docs permet une collaboration en temps réel avec d'autres utilisateurs. Comme pour les autres contenus sur le canevas, le suivi du curseur est activé, vous permettant de voir où dans le Doc les autres utilisateurs travaillent.

Les commentaires en ligne sont également possibles, avec la possibilité de Mentionner d’autres utilisateurs (ce qui les notifie à la fois dans l'application et par e-mail). Les fils de commentaires et les réactions aux commentaires sont également activés.

### Participants dans Miro Docs

Les puces utilisateur vous permettent de fournir des détails sur les utilisateurs à l'intérieur d'un document. Par exemple, ajoutez des tags @user pour les membres clés de l’équipe ou les parties prenantes.

Pour ajouter une puce utilisateur, tapez '@' dans un document Miro. Continuez à taper le nom d'utilisateur pour filtrer les résultats, ou sélectionnez un utilisateur dans le menu déroulant qui s'ouvre.

![Ajouter des puces utilisateur n'importe où dans un document Miro.](https://help.miro.com/hc/article_attachments/25640657760914)

*Ajoutez des pastilles utilisateur n'importe où dans un document Miro.*

Survolez une puce @utilisateur pour voir des informations sur l'utilisateur.

![Les indicateurs utilisateur incluent des informations sur l'utilisateur.](https://help.miro.com/hc/article_attachments/25640673747346)

*Les puces d’utilisateur incluent des informations sur l’utilisateur.*

Les jetons utilisateur fonctionnent séparément des mentions dans un commentaire, par exemple, les jetons utilisateur n'envoient pas de notifications à un utilisateur donné.

## Copier, partager et exporter des Docs

Les documents peuvent être copiés entre les tableaux, mais ne sont pas synchronisés pour les changements ultérieurs. En d'autres termes, toute modification apportée au document sur un tableau ne sera pas répercutée sur les autres tableaux auxquels le document a été copié ou à partir desquels il a été copié.

Les documents peuvent être partagés via un lien avec d’autres utilisateurs.

Les documents peuvent être exportés au format PDF à partir de l’**icône Plus** (![icon-main.svg](https://help.miro.com/hc/article_attachments/25640673749906)) dans le menu contextuel.
