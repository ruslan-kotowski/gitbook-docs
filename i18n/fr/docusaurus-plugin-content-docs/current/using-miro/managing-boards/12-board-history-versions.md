Toutes les versions de vos tableaux Miro sont automatiquement enregistrées dans l’historique de votre tableau. Vous pouvez passer en revue et récupérer les modifications à tout moment.

### Fonctionnalités principales

- Les tableaux sont sauvegardés toutes les heures si une modification a été apportée, ainsi qu’à la fin de chaque session collaborative.
- Les versions enregistrées de l'historique du tableau sont stockées pendant *90 jours*
- Le tableau d’origine *n’est* pas modifié. La version restaurée est créée en tant que tableau *séparé* et son titre est daté par défaut.

:::warning
Occasionnellement, des problèmes de réseau imprévus peuvent empêcher la sauvegarde d’un tableau. Assurez-vous de disposer d’une connexion Internet stable pour des sauvegardes cohérentes.
:::

### Restaurer une version précédente d’un tableau

Pour restaurer une version précédente :

1. Dans la barre du tableau, sélectionnez les **trois points** verticaux.
   Le menu **principal** s’ouvre.
2. Sélectionnez **Tableau** > **Historique**.
   Le panneau **Historique** s’ouvre. L’onglet **Activité** est ouvert par défaut.
3. Sélectionnez **Versions**.
4. Sélectionnez une version.
   La fenêtre modale **Restaurer en tant que tableau séparé** s’ouvre.
5. (Facultatif) Suivez les instructions à l’écran.
6. Sélectionnez **Restaurer**.

### Limiter ou désactiver la restauration des versions précédentes du tableau

- La fonctionnalité est disponible pour les [propriétaires](../sharing-boards/01-board-access-rights.md), copropriétaires, et peut être activée pour les [éditeurs](../sharing-boards/01-board-access-rights.md) qui sont membres de l’équipe où se trouve le tableau
- La fonctionnalité dépend des [paramètres de contenu du tableau](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) : l’option est disponible pour les membres de l’équipe uniquement si le propriétaire du tableau permet aux membres de l’équipe de copier le contenu du tableau. Ceci peut être configuré sur le tableau **Partager** > **Paramètres de partage** > **Autorisations**
- [Autorisations d’admin de contenu](../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md) sur le [forfait Enterprise](../../plans-billing/miro-plans/04-enterprise-plan.md) – lorsqu’elles sont activées – permettent aux admins d’entreprise d’accéder aux **Versions** du tableau même lorsqu’elles sont désactivées par les paramètres de contenu en [réattribuant la propriété du tableau à eux-mêmes](../sharing-boards/01-board-access-rights.md)

Si vous n’avez pas la permission d’utiliser l’option, vous verrez le message correspondant dans l’onglet **Versions**. Contactez le propriétaire du tableau pour activer la fonctionnalité.

## FAQ

**J'ai récemment [changé de forfait pour mon équipe](../../plans-billing/manage-your-subscription-and-plan/03-upgrade-your-plan.md) Puis-je restaurer une version du tableau créée lorsque mon équipe était sur un forfait Free ?**

Oui, après avoir changé de forfait, vous pouvez restaurer les versions créées lorsque vous étiez sur un forfait Free.

**Je n’ai pas de versions dans l’historique du tableau. Pourquoi ?**

Veuillez noter que la fonctionnalité n’est pas prise en charge dans les [équipes Free](../../plans-billing/miro-plans/09-free-plan.md). En plus de cela, assurez-vous que votre rôle sur le tableau vous permet de restaurer les versions (vous devez être le [propriétaire du tableau](../sharing-boards/01-board-access-rights.md), [copropriétaire](../sharing-boards/06-co-owners-of-boards-and-spaces.md), ou [éditeur](../sharing-boards/01-board-access-rights.md) et être membre de l’équipe où se trouve le tableau). En outre, le propriétaire ou le copropriétaire du tableau doit permettre aux membres de l’équipe de copier le contenu du tableau.
Si vous avez supprimé un objet, vous pouvez également le restaurer : consultez [ce guide](../working-on-the-board/18-restoring-board-content.md).
