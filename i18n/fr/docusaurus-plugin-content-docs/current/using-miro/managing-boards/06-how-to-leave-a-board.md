### Quitter un tableau Miro

L’option permettant de quitter un tableau est disponible pour les *équipes payantes et Education*.  Les membres des équipes Free ne peuvent pas quitter les tableaux de leurs pairs, car le *forfait Free* ne prend pas en charge la confidentialité des tableaux. Si vous ne souhaitez pas accéder au tableau d’une équipe Free, vous pouvez quitter l’équipe.

Si vous reçu une invitation à un tableau et que vous souhaitez quitter ce dernier, suivez les étapes ci-dessous :

1. Trouvez le tableau que vous souhaitez quitter sur votre [tableau de bord](https://miro.com/app/dashboard/).
2. Cliquez sur les trois points et choisissez **Leave board** **(Quitter le tableau).**
3. Vous verrez un message d’avertissement indiquant que cette action ne peut pas être annulée.
4. Après avoir cliqué sur **Leave**(Quitter), vous perdrez l’accès au tableau et ne le verrez pas sur votre [tableau de bord](https://miro.com/app/dashboard/).

## Foire aux questions

1. *J’ai cliqué sur le bouton **Leave board** (Quitter le tableau), mais je peux toujours voir le tableau sur mon tableau de bord.*  Pourquoi ?
   [Pourquoi ?](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)- Le tableau en question est partagé avec l’ensemble de l’équipe (les instructions relatives à la désactivation/l’activation de cette option se trouvent ici).
2. *Je n'ai pas le bouton " **Quitter le tableau"**, que dois-je faire ?*
   - Si le tableau appartient à une [équipe Free](../../plans-billing/miro-plans/09-free-plan.md), il sera partagé avec l'équipe par défaut car la confidentialité du tableau n'est pas disponible sur le plan Free. Vous pouvez [mettre à niveau votre équipe](../../plans-billing/manage-your-subscription-and-plan/03-upgrade-your-plan.md) pour créer vos propres tableaux privés. Vous pouvez également trier vos tableaux par propriété de tableau (veuillez consulter [ces directives](../../getting-started/start-here/miro-dashboard/01-what-is-on-your-dashboard.md)). Si vous ne souhaitez pas avoir accès au tableau de l'équipe Free, vous pouvez [quitter l'équipe.](../managing-your-profile/06-how-to-leave-a-team.md)

   Si le tableau appartient à une équipe payante mais que vous ne voyez pas l'option de le quitter, essayez d'inviter votre e-mail au tableau (si vous avez l'autorisation de partager le tableau), puis quittez-le.

   Veuillez noter que si vous êtes le propriétaire du tableau, vous verrez le bouton **Supprimer** à la place.
3. *Je suis le propriétaire du tableau, mais je ne veux pas supprimer mon tableau, juste le laisser. Comment puis-je faire cela ?
   -* Pour quitter le tableau que vous avez créé, vous devez d'abord en transférer la propriété. Veuillez consulter cet article pratique qui vous explique comment procéder.
4. *J’ai reçu une invitation pour un tableau Miro, mais j’aimerais avoir ma propre équipe.* Existe-t-il un moyen de l'obtenir ?
   - Si vous avez été invité à un ou plusieurs tableaux spécifiques sans être ajouté à l'équipe elle-même, et que vous n'avez pas d'autres équipes sur votre [tableau de bord](https://miro.com/app/dashboard/), il vous suffit de quitter le(s) tableau(x). Si aucun tableau ni aucune équipe ne sont disponibles, Miro vous proposera de créer votre propre équipe.Si vous avez été invité dans l'équipe en tant que membre, vous devrez quitter l'ensemble de l'équipe. Pour ce faire, veuillez consulter cet article.
5. *Je suis un admin d’équipe, mais je ne peux pas supprimer ou déplacer les tableaux d’autres utilisateurs.* Que dois-je faire ?
   - Seul le propriétaire du tableau peut [supprimer](07-how-to-delete-a-board.md) ou [déplacer son tableau.](04-how-to-move-a-board.md) Comme solution de rechange, vous pouvez supprimer le propriétaire du tableau de l’équipe, Miro vous donnera la possibilité de supprimer ses tableaux en même temps que lui.
6. *J’aimerais déplacer mes tableaux vers mon propre espace privé.*  Comment faire ?
   - Consultez cet article : Comment déplacer un tableau
