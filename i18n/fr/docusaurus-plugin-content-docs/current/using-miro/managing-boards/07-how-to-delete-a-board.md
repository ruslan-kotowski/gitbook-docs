### Deux façons de supprimer un tableau

Vous pouvez supprimer un tableau à partir du tableau de bord ou de sa fiche d’information.

![Supprimer](../../../../../../docs/using-miro/managing-boards/images/21017348565650_Delete%20a%20board.png)*Supprimer un tableau du bord en cliquant sur les trois points et en choisissant l’option souhaitée*

![Delete_a_board.gif](../../../../../../docs/using-miro/managing-boards/images/21017348564882_Delete%20a%20board.gif)
*Suppression d’un tableau depuis sa carte d’information*

Une fois le tableau supprimé, il est envoyé dans la corbeille (pour les forfaits payants) d’où [il peut être restauré](08-how-to-restore-a-deleted-board.md). Sur les [forfaits Free](../../plans-billing/miro-plans/09-free-plan.md), un tableau supprimé peut être restauré si le propriétaire suit le lien du tableau. Les tableaux peuvent être restaurés via l’interface dans les 90 jours suivant leur suppression.

Si vous n’êtes pas le propriétaire du tableau et que vous n’êtes pas un admin d’entreprise doté des [autorisations de responsable de contenu](../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md) (article disponible uniquement en anglais), vous **ne pouvez pas** le supprimer comme illustré ci-dessus. Plutôt que de voir le bouton **Delete** (Supprimer), certains utilisateurs d’équipes payantes qui ne sont pas les propriétaires du tableau peuvent voir l’option **Leave board** (Quitter le tableau) à la place. Obtenez davantage d’informations dans cet article sur la [manière de quitter un tableau](06-how-to-leave-a-board.md) (disponible uniquement en anglais). Notez que les membres de forfaits gratuits ne peuvent pas quitter les tableaux.

![Quitter](../../../../../../docs/using-miro/managing-boards/images/21017348566290_Leave%20a%20board.png)
*L’option permettant de quitter un tableau*

:::note
Les admins peuvent supprimer les membres de l’équipe avec leurs tableaux.
:::

## Foire aux questions

1. *Je n’ai pas la possibilité de supprimer un tableau. Pourquoi ?*
   - Si vous n’avez pas cette possibilité, vous n’êtes pas le propriétaire du tableau. L’option de suppression d’un tableau n’est disponible que pour les *propriétaires du tableau* et les  *[admins de contenu](../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md) du forfait Enterprise.*
2. *Je n’ai pas la possibilité de quitter un tableau. Pourquoi ?*- Veuillez noter qu’il n’est pas possible de quitter les tableaux qui sont stockés dans les [équipes Free](../../plans-billing/miro-plans/09-free-plan.md) ou les tableaux auxquels vous n’avez pas été invité par e-mail.
3. *Je suis un admin. Puis-je supprimer les tableaux des membres de mon équipe ?*
   - Non, cette option n’est disponible que pour les admin d’entreprise du forfait Enterprise dont les [droits d’admin de contenu](../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md) sont activés. En tant qu’admin sur n’importe quel autre forfait, vous pouvez [supprimer le propriétaire du tableau](../../administration/user-management/08-remove-users.md) et ses tableaux ou prendre possession de ses tableaux lors de la suppression.
4. *Un employé a quitté notre entreprise et nous devons retirer ses tableaux de l’équipe. Comment procéder ?*
   - L’admin peut [supprimer l’utilisateur](../../administration/user-management/08-remove-users.md) ainsi que son contenu. Il peut également attribuer ce contenu à un autre admin ou à lui-même lors de la suppression.
5. *Puis-je supprimer plusieurs tableaux en bloc ?*
    - Non, ce n’est pas possible actuellement.
