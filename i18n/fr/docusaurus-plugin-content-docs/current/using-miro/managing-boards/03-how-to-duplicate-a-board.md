Vous pouvez dupliquer un tableau à partir du tableau de bord ou de la fenêtre d’information du tableau.

> **Disponible sur :** version navigateur (bureau, tablette), application de bureau, application pour tablette.
> **Mise en place par :** pour les tableaux avec le forfait Free, par les membres de l’équipe ;
> pour les tableaux avec les forfaits Starter[,](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) Business, Enterprise et Education, par les utilisateurs autorisés à dupliquer le tableau dans les paramètres de contenu du tableau.

### Comment dupliquer un tableau Miro

Pour dupliquer un tableau à partir du tableau lui-même :

1. Cliquez sur l'icône du **menu principal** (![icon-main.svg](../../../../../../docs/using-miro/managing-boards/images/22781142146322_icon-main.svg)) dans la barre d'outils en haut à gauche.
2. Cliquez sur le sous-menu **Tableau**.
3. Cliquez sur **Dupliquer**.
   Une boîte de dialogue s’ouvre.
4. Saisissez le nouveau nom du tableau, indiquez si vous souhaitez conserver les paramètres de partage sur le tableau dupliqué, puis cliquez sur **Copier**.

Vous pouvez également dupliquer un tableau à partir de la boîte de dialogue Détails du tableau :

1. Cliquez sur l'icône du **menu principal** (![icon-main.svg](../../../../../../docs/using-miro/managing-boards/images/22781142146322_icon-main.svg)) dans la barre d'outils en haut à gauche.
2. Cliquez sur le sous-menu **Tableau**.
3. Cliquez sur **Détails**.
   Une boîte de dialogue s’ouvre.
4. Cliquez sur le bouton **Dupliquer** en bas.
   Une boîte de dialogue s’ouvre.
5. Saisissez le nouveau nom du tableau, indiquez si vous souhaitez conserver les paramètres de partage sur le tableau dupliqué, puis cliquez sur **Copier**.

:::note
[Lorsque les utilisateurs dupliquent un tableau, les enregistrements seront aussi dupliqués vers le nouveau tableau.](../facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md)
:::

> **[✏️](../sharing-boards/07-collaboration-with-guests.md)** Si vous disposez du rôle d’[invité](../../enterprise-administration/enterprise-subscription-management/enterprise-licensing/04-free-restricted-license.md) pour ce tableau et que vous ne faites pas partie d’autres équipes Miro ou que vous avez une Licence gratuite restreinte (article disponible uniquement en anglais), il vous sera suggéré de créer une nouvelle équipe Miro pour y enregistrer la copie du tableau.

Pour dupliquer un tableau à partir du tableau de bord :

1. Survolez la vignette du tableau supprimé.
2. Cliquez sur l'icône de menu à **trois points** (.**..**).
3. Cliquez sur **Dupliquer**.
   Une boîte de dialogue s’ouvre.
4. Saisissez le nouveau nom du tableau, indiquez si vous souhaitez conserver les paramètres de partage sur le tableau dupliqué, puis cliquez sur **Copier**.

:::warning
Les noms des tableaux ont une limite maximale de 61 caractères. Lors de la duplication de tableaux, la mention "Copie de..." sera ajoutée au nom du tableau. S’il y a trop de caractères, le tableau ne sera pas copié. Raccourcissez le nom de votre tableau et dupliquez-le à nouveau.
:::

## Foire aux questions

1. *Si je modifie le contenu de la copie du tableau, le tableau original sera-t-il affecté ?*
   - Non, le contenu de la copie n’a aucun rapport avec le contenu du tableau original.
2. *Comment puis-je dupliquer le contenu d’un tableau vers un autre tableau existant ?*
   - Veuillez [sélectionner le contenu nécessaire](../working-on-the-board/10-working-with-objects.md), le copier et le coller sur un autre tableau (vous pouvez utiliser **Ctrl+C/Ctrl + V** *pour Windows* ou **Cmd + C/Cmd + V** *pour Mac*).
3. *Puis-je dupliquer plusieurs tableaux en vrac ?*
   - Non, ce n’est pas possible pour le moment.
4. *Puis-je partager mon tableau avec d’autres utilisateurs en tant que modèle afin qu’ils puissent le dupliquer dans leurs propres équipes ?*
   - Oui, vous devez vous assurer que cela est autorisé dans les [paramètres de contenu de votre tableau](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md).
