**Récupérez les tableaux Miro manquants ou supprimés. Vous pouvez restaurer un tableau supprimé dans un délai de** **90 jours****.**

:::tip
Vous pouvez protéger vos tableaux en [enregistrant des sauvegardes](../import-and-export/export/05-how-to-save-board-backup.md).
:::

## Restaurer un tableau à l’aide du lien du tableau

> **Qui peut le faire :** propriétaire du tableau
>
> **Pertinent pour :** tous les forfaits
>
> **Disponible sur :** navigateur

### Comment restaurer un tableau à l’aide du lien

Si vous avez accidentellement supprimé votre tableau ou que votre tableau a disparu, vous pouvez le restaurer à l’aide du lien du tableau.

Exemple d’un lien de tableau Miro :

```
https://miro.com/app/board/o9L_kSnC_0=/
```

Vous pouvez essayer de trouver le lien du tableau en tapant le nom du tableau :

- Dans la barre d’adresse de votre navigateur
- Dans l’historique de recherche de votre navigateur
- Dans la recherche de votre boite e-mail

![searcing_for_a_Miro_board_in_your_browser.gif](../../../../../../docs/using-miro/managing-boards/images/21017515436050_searcing%20for%20a%20Miro%20board%20in%20your%20browser.gif)*Rechercher un tableau Miro*

Une fois que vous aurez trouvé le lien et que vous l’aurez ouvert dans votre navigateur, vous verrez un message indiquant que le tableau a été supprimé.

![board_deleted_modal.jpg](../../../../../../docs/using-miro/managing-boards/images/21017515434258_board%20deleted%20modal.jpg)
*Message indiquant que le tableau a été supprimé*

Cliquez sur **restaurer le tableau**. Vous retournerez sur votre tableau de bord Miro, où vous pourrez ouvrir le tableau récupéré.

![restoring_a_Miro_board_via_link.gif](../../../../../../docs/using-miro/managing-boards/images/21017528446354_restoring%20a%20Miro%20board%20via%20link.gif)*Restaurer un tableau Miro à l’aide du lien du tableau*

## Restaurer un tableau depuis la corbeille

> **Qui peut le faire :** propriétaire du tableau
>
> **Pertinent pour : les forfaits** Starter, Business, Enterprise et Education
>
> **Disponible sur :** **navigateur,** application de bureau, application pour tablette

### Où trouver la fonctionnalité Corbeille

La [fonctionnalité Corbeille](../../getting-started/start-here/miro-dashboard/01-what-is-on-your-dashboard.md) est uniquement disponible pour les forfaits payants et Education. Si vous avez un forfait Free, vous pouvez [restaurer un tableau à l’aide du lien du tableau.](08-how-to-restore-a-deleted-board.md)

La corbeille vous permet de parcourir et de restaurer tous les tableaux récemment supprimés. **La corbeille** est accessible depuis votre [tableau de bord](../../getting-started/start-here/miro-dashboard/01-what-is-on-your-dashboard.md) en cliquant sur votre avatar dans le coin supérieur droit.

![trash.png](../../../../../../docs/using-miro/managing-boards/images/23122133552402_trash.png)
*L’icône de la corbeille*

### Comment restaurer un tableau depuis la corbeille

1. Ouvrez la **Corbeille** en cliquant sur votre avatar dans le coin supérieur droit du tableau de bord pour voir les tableaux supprimés.
2. Cliquez sur le menu des **trois points** (**...**) à côté du tableau souhaité pour voir l’option **Restaurer**.
3. Cliquez sur **Restaurer**.
4. Le tableau sera restauré à son propriétaire et à son équipe d’origine.

![trash-restore.png](../../../../../../docs/using-miro/managing-boards/images/23122118937362_trash-restore.png)
*Restaurer un tableau depuis la corbeille*

## Restaurer un tableau d’un ancien utilisateur

Si un utilisateur a été supprimé de l’équipe et que ses tableaux ont été supprimés, demandez à votre admin Miro de vous aider. L’admin pourra voir les tableaux supprimés dans la corbeille et **restaurer le tableau** **dans les 90 jours suivant sa suppression**. L’admin deviendra propriétaire du tableau restauré.

:::note
N’oubliez pas d’[exporter vos tableaux](../import-and-export/export/03-how-to-export-your-board.md) ou d’en [faire des sauvegardes](../import-and-export/export/05-how-to-save-board-backup.md) avant de supprimer votre équipe.
:::
