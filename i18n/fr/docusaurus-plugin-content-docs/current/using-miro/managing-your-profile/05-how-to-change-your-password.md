Vous pouvez changer votre mot de passe Miro à tout moment.

:::note
Il n’est pas possible de changer votre mot de passe si vous accédez à Miro via [authentification unique (SSO)](../../enterprise-administration/security-integrations/single-sign-on-sso/09-single-sign-on-sso.md).
:::

:::note
Notez que la modification de votre mot de passe entraîne la fin de votre session Miro sur tous vos autres appareils.
:::

### Comment modifier votre mot de passe dans les paramètres du profil

1. Ouvrez vos [Paramètres du profil](https://miro.com/app/account/profile/).
2. Faites défiler jusqu'à **Mot de passe**, puis cliquez sur **Modifier**.
3. Saisissez votre nouveau mot de passe et votre mot de passe actuel.
4. Cliquez sur **Sauvegarder le mot de passe.**

![change_password_in_Miro.jpg](../../../../../../docs/using-miro/managing-your-profile/images/21017013080210_change%20password%20in%20Miro.jpg)*Modifier un mot de passe dans les paramètres du profil Miro*

### Comment réinitialiser votre mot de passe

1. Pour réinitialiser votre mot de passe, sur la [page de connexion Miro](https://miro.com/login/) cliquez sur **Mot de passe** **oublié ?**
   ![](../../../../../../docs/using-miro/managing-your-profile/images/33980392064530_image.png)***Mot de passe oublié ?** pointe vers les instructions de réinitialisation du mot de passe. Vous pouvez également cliquer sur **réinitialiser votre mot de passe** en bas.*
2. Saisissez l'adresse e-mail que vous utilisez pour vous connecter à Miro et cliquez sur **Continuer**. Nous vous enverrons les instructions de réinitialisation du mot de passe.
3. Cliquez sur le lien dans l'e-mail reçu.
4. Créez un nouveau mot de passe, puis cliquez sur **Continuer**.
5. Connectez-vous avec le nouveau mot de passe.

## Exigences pour le mot de passe Miro

Votre mot de passe Miro doit répondre aux exigences suivantes :

- Minimum de 8 caractères
- Au moins 1 lettre majuscule
- Au moins 1 lettre minuscule
- Au moins 1 chiffre
- Au moins 1 caractère spécial

![](../../../../../../docs/using-miro/managing-your-profile/images/33980392064530_image.png)*Miro indique en temps réel les exigences de mot de passe qui sont remplies.*

## Foire aux questions

- *J’ai essayé de réinitialiser mon mot de passe, mais je n’ai pas reçu d’e-mail de récupération. Que dois-je faire ?*
  - Assurez-vous de ne pas avoir fait de fautes de frappe dans l’adresse e-mail que vous avez saisie. Si vous remarquez une erreur, essayez de récupérer à nouveau votre mot de passe. Ouvrez vos dossiers **Spam, Promotions, Indésirables, Réseaux sociaux** et **Mises à jour** et vérifiez si votre e-mail de confirmation Miro s’y trouve.
  Il se peut également qu’un pare-feu empêche l’e-mail d’atteindre votre boîte de réception. Demandez à votre administrateur système d’ajouter les [domaines et sous-domaines](../troubleshooting-technical-questions/technical-guidelines/07-miro-domains-reference.md) nécessaires à la liste blanche.
- *Lorsque je clique sur le lien dans l’e-mail de récupération, je reçois un message d’erreur "Un problème est survenu ! Le code de récupération que vous utilisez est incorrect". Comment puis-je réinitialiser mon mot de passe ?*
  - Ouvrez la [page de connexion Miro](https://miro.com/login/) et votre boîte de réception en mode incognito de votre navigateur. Demandez de recevoir l’e-mail de réinitialisation du mot de passe en cliquant sur **J’ai oublié mon mot de passe**. Passez sur votre boîte de réception et cliquez sur le lien dans le nouvel e-mail que vous recevrez.

Si les problèmes persistent, [contactez le service d’assistance Miro](../tools/troubleshooting/06-contacting-miro-support.md).
