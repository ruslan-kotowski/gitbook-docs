Vous pouvez mettre à jour votre langue dans Miro en quelques clics à partir des paramètres de votre profil. Vos paramètres linguistiques seront reflétés dans vos tableaux, votre tableau de bord et vos paramètres Miro.

## Langues prises en charge

Miro prend actuellement en charge les langues suivantes :

- Anglais
- Français
- Allemand
- Japonais
- Espagnol
- Portugais
- Coréen
- Polonais

> **Disponible pour**: tous les forfaits
> **Disponible sur**: navigateur de bureau, application de bureau (quelques limitations), application pour tablettes

## Comment modifier votre langue dans Miro

1. Allez dans les [paramètres de votre profil](https://miro.com/app/settings/user-profile).
2. Faites défiler jusqu’à **Language** (Langue).
3. Choisissez votre langue préférée dans le menu déroulant.

:::note
Les paramètres de langue sont actuellement pris en charge dans votre navigateur uniquement et s’appliquent à l’interface utilisateur de vos tableaux Miro, de votre tableau de bord et de vos paramètres.
:::

## Paramètres linguistiques pour les utilisateurs non enregistrés de Miro

Si vous n’êtes pas un utilisateur Miro enregistré ou si vous n’avez pas ouvert de session et n’avez donc pas accès aux paramètres du profil, vous pouvez tout de même collaborer dans votre langue préférée.

Ajustez vos paramètres linguistiques à tout moment à partir du menu de votre tableau > **Préférences** > **Langue.**

## Foire aux questions

**Pourquoi toutes les fonctionnalités ne sont-elles pas localisées dans ma langue ?**

Nous ne faisons que commencer la localisation de Miro dans votre langue. Nous apprécions votre patience tandis que nous continuons à mettre à jour des fonctionnalités et des ressources supplémentaires, notamment le Centre d’apprentissage, les notifications, le Centre d’assistance et quelques autres domaines. Étant donné que Miro est constamment mis à jour pour offrir une meilleure expérience utilisateur, les mises à jour multilingues peuvent avoir du retard. Veuillez consulter la version anglaise pour obtenir les informations les plus récentes.

**Pourquoi le site Web est-il disponible dans différentes langues ?**

Les langues disponibles sur le site et au sein du produit peuvent différer. Sur la [liste de souhaits de la communauté](https://community.miro.com/ideas), vous pouvez indiquer quelles langues vous aimeriez voir apparaitre.

**Les paramètres de langue sont-ils automatiquement sélectionnés pour les utilisateurs ?**

Pour garantir une expérience utilisateur fluide, nous faisons de notre mieux pour détecter votre langue préférée. Vous pouvez également mettre à jour vos paramètres de langue à tout moment depuis vos Paramètres du profil Miro.
