Pour permettre aux utilisateurs de gérer le travail sur plusieurs tableaux et de trouver du contenu plus facilement, Miro introduit les espaces—la nouvelle expérience de gestion de contenu dans Miro.

Les espaces réimaginent le tableau de bord et la barre latérale pour permettre une gestion du contenu contextuelle et hiérarchique.

:::note
Les espaces remplacent les projets comme principal moyen pour les équipes d’organiser leur contenu Miro. Tous les projets existants sont automatiquement convertis en espaces.
:::

Chaque organisation Miro peut avoir plusieurs équipes et une équipe peut avoir plusieurs espaces — un espace pour chaque contexte d'affaires qu'elle souhaite représenter dans l'espace de travail pour l'innovation de Miro.

Vous pouvez créer votre propre espace, ou choisir un modèle d’espace, appelé [plan d’action](04-blueprints-beta.md).

:::tip
Pour des informations générales, consultez la FAQ.
:::

## Fonctionnalités clés

- **Espaces**
  Organisez votre contenu selon des objectifs commerciaux spécifiques.
- **Sections**
  Créez des sections dans votre espace pour organiser davantage votre contenu.
- **Réordonner les tableaux et les sections**
  Faites glisser et déposez une section ou un autre contenu pour changer l'ordre à l'intérieur d'un espace.
- **Barre latérale ciblée**
  Permet une navigation rapide et efficace entre tous les contenus à l'intérieur d'un espace.
- **Espaces épinglés**
  Épinglez vos espaces préférés à la barre latérale pour un accès rapide.
- **Partager des espaces**
  Partagez avec les membres clés de l'équipe. Contrôlez l'accès à votre espace avec le même processus et les mêmes paramètres que vous utilisiez pour les projets.
- **Aperçu de l'espace**
  Définissez un tableau comme aperçu de votre espace, ce qui vous permet de faire apparaître le contexte et la clarté pour le contenu de l'espace. Vous pouvez également créer un [tableau de bord](03-space-overview-dashboard-beta.md) personnalisé.

## Guide des espaces

Le tableau de bord d'accueil est simplifié et vous permet de trier et filtrer tous les tableaux de l'équipe, y compris ceux qui ne sont pas dans un espace.

![Spaces-home-dash-anonymous.png](../../../../../../docs/using-miro/spaces/images/21102202591762_Spaces-home-dash-anonymous.png)
*Tableau de bord d'accueil avec espaces*

Pour créer un nouvel espace ou tableau Miro, importer du contenu ou explorer des modèles et le Miroverse, sélectionnez le bouton **Créer un nouveau**.

Vous pouvez également choisir un modèle d'espace, appelé [plan d’action](04-blueprints-beta.md).

:::note
Lorsque vous créez un tableau à partir de la bande de modèles, celui-ci n'appartient à aucun espace. Pour apprendre comment déplacer un tableau dans un espace, voir Comment déplacer des tableaux entre les espaces**.**
:::

:::tip
Depuis le tableau de bord des espaces, vous pouvez changer d'équipe Miro. Sélectionnez le nom de votre équipe dans le coin supérieur gauche pour accéder au sélecteur d'équipe.
:::

### Tableaux sans espace

Avant les Espaces, vous aviez peut-être des tableaux Miro qui n’étaient inclus dans aucun projet, ce qui signifie qu’aucun espace n’inclut actuellement ces tableaux.

Pour localiser un tableau qui n'est pas dans un espace, dans la zone **Accueil**, réglez **Filtrer par :** sur **Tableaux non inclus dans un espace**. Le tableau de bord d'accueil se met à jour pour afficher tous les tableaux non inclus dans un espace.

### Barre latérale des espaces

Lorsque vous ouvrez un tableau à l'intérieur d'un espace, la barre latérale affiche les autres contenus dans l'espace. Vous pouvez également créer de nouvelles sections.

:::note
Si vous accédez à un tableau via un lien, la barre latérale est fermée par défaut.
:::

Pour accéder à la barre latérale des espaces, ouvrez un tableau à l'intérieur d'un espace. Si la barre latérale est réduite, cliquez dans la [barre du tableau](../working-on-the-board/02-miro's-new-simplified-user-interface.md) sur le menu hamburger **Ouvrir la barre latérale**.

![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)

*Sur votre tableau Miro, la barre de tableau inclut le menu hamburger **Ouvrir la barre latérale**.*

Dans la barre latérale des espaces, vous pouvez ouvrir le menu **Créer** (**+**), qui vous permet de créer un nouveau tableau à l'intérieur de l'espace, créer une nouvelle section, déplacer des tableaux vers l'espace, importer et explorer des modèles et le Miroverse.

:::tip
Dans le menu **Créer** (**+**)**,** sélectionnez un format comme Documents ou Diapositives pour créer un nouveau tableau avec votre sélection en mode immersif.
:::

Si vous accédez à un tableau qui n'est pas dans un espace, alors la barre latérale affiche **Récents**, qui répertorie le contenu récemment visité regroupé par période.

Pour rechercher et filtrer le contenu dans la barre latérale, que ce soit dans un espace ou sous **Récents**, sélectionnez la loupe en haut à droite de la barre latérale.

Pour fermer la barre latérale, sélectionnez le **X** dans le coin supérieur droit.

### Espaces épinglés

Dans la barre latérale, les **Espaces épinglés** permettent d'accéder rapidement à vos espaces favoris. Pour épingler un Espace, survolez un Espace et sélectionnez l'icône d'épingle.

:::note
Vos projets précédemment ajoutés aux favoris sont maintenant des espaces épinglés.
:::

### Options des espaces

Pour accéder au menu **Options** des Espaces, ouvrez un espace et sélectionnez les trois points (...) dans le coin supérieur droit.

Le menu **Options** des Espaces vous permet de sélectionner les actions suivantes :

- **Copier le lien de l’espace**
  Copiez un lien vers votre espace immédiatement et partagez-le.
- **Partager**
  Invitez des membres de l’équipe à partager l’accès à votre espace et attribuez des rôles. Vous pouvez également définir **Aucun accès** ou **Peut consulter** pour tous les autres membres de votre équipe.
- **Renommer**
  Renommez votre espace.
- **Supprimer**
  Supprimez votre espace.

:::tip
Vous pouvez également sélectionner les trois points (**...**) pour un espace dans la barre latérale pour accéder au menu **Options** de l’espace.
:::

### Rôles dans les espaces

Un rôle spécifie quels privilèges un utilisateur a pour les tableaux existants et nouvellement créés à l'intérieur de l'espace. Vous pouvez utiliser les rôles pour configurer l'accès à votre espace à tout moment.

:::note
Toutes les autorisations existantes pour vos projets sont reportées aux espaces.
:::

Vous pouvez avoir l'un des rôles suivants pour un espace :

- **Propriétaire**
  Peut modifier et supprimer l'espace, ajouter et retirer des tableaux, définir la visibilité pour l'ensemble de l'équipe, attribuer des rôles au niveau de l'espace et du tableau, et transférer la propriété à un autre utilisateur. Un propriétaire d'espace est automatiquement un éditeur pour tout le contenu à l'intérieur de l'espace.
- **Copropriétaire**
  Peut mettre à jour le rôle au niveau de l'espace pour un utilisateur donné, et attribuer des rôles au niveau de l'espace. Un copropriétaire d'espace est automatiquement un éditeur pour tout le contenu à l'intérieur de l'espace.
- **Éditeur**
  Peut modifier tout tableau dans l'espace et attribuer des rôles au niveau du tableau.
- **Commentateur**
  Peut commenter sur tout tableau dans l'espace.
- **Consultant**
  Peut consulter tout tableau dans l'espace.

Un utilisateur peut déjà avoir un rôle au niveau du tableau spécifié pour un tableau donné. S'il reçoit un rôle de niveau espace supérieur, le rôle supérieur est prioritaire pour tous les tableaux dans l'espace. Si le membre perd son rôle de niveau espace, il conserve son rôle original au niveau du tableau.

**Plus d'informations :** Voir [Les rôles dans Miro](../../getting-started/start-here/05-roles-in-miro.md).

### Comment créer un espace

Vous pouvez rapidement créer un nouvel espace pour votre équipe.

:::tip
Vous pouvez également choisir un modèle d’espace, appelé [plan d’action](04-blueprints-beta.md).
:::

Suivez ces étapes :

1. Choisissez l’une des options suivantes :
   - Dans le tableau de bord **Accueil**, en haut à droite, sélectionnez **+ Créer nouveau**. Puis sélectionnez **Espace**.
   - Dans la barre latérale à côté de **Autres espaces**, sélectionnez le signe plus (**+**).
     La fenêtre modale **Nouvel espace** s'ouvre.
2. Nommez votre nouvel espace.
   Max. : 60 caractères.
3. Sélectionnez **Créer un espace**.
   La fenêtre modale **Inviter à &lt;Nom&gt;** s'ouvre.
4. Effectuez l’une des opérations suivantes :
   - Utilisez la recherche pour localiser et sélectionner un membre de l'équipe par adresse e-mail.

     > 💡 Vous pouvez sélectionner plusieurs membres de l'équipe.
   - Cliquez sur **l'équipe** dans la barre de recherche pour sélectionner des membres individuels ou l'ensemble de l'équipe, puis sélectionnez **Choisir**.
5. Sélectionnez **Ajouter à l'espace**.
6. Sélectionnez les autorisations que vous souhaitez accorder.

   > ✏️ Les autorisations que vous accordez s'appliquent à tous les tableaux Miro à l'intérieur de l'espace. Pour en savoir plus, consultez la FAQ.
7. Sélectionnez **Terminé**.
   Vous avez créé un espace avec succès.

### Comment partager un Espace

En tant que propriétaire et copropriétaire d'un espace, vous pouvez partager un espace donné avec les membres de votre équipe et attribuer des rôles.

Suivez ces étapes :

1. Ouvrez le menu **Options** de l’espace.
2. Sélectionnez **Partager**.
   La fenêtre modale **Inviter à l’espace de &lt;Name&gt;** s'ouvre.
3. Effectuez l’une des opérations suivantes :
   - Utilisez la recherche pour trouver un membre de l’équipe par adresse e-mail, puis sélectionnez le membre de l’équipe.

     > 💡 Vous pouvez rechercher et sélectionner plusieurs membres de l’équipe.
   - Cliquez sur **l’équipe** dans la barre de recherche pour sélectionner des membres individuels ou tous les membres de l’équipe, puis sélectionnez **Choisir**.
4. Sélectionnez les autorisations que vous souhaitez accorder.

   > ✏️ Le rôle et les autorisations que vous accordez s'appliquent à tous les tableaux à l'intérieur de l'espace. Pour en savoir plus, consultez la FAQ.
5. (Facultatif) Ajoutez un message personnalisé.
6. Sélectionnez **Envoyer les invitations**.

   Vous avez partagé un espace avec succès avec votre ou vos membres d'équipe.

### Comment modifier l'accès à l'espace pour toute une équipe

Vous pouvez mettre à jour si toute votre équipe peut accéder à votre espace.

:::note
Les autorisations pour les membres que vous invitez individuellement sont gérées séparément.
:::

Suivez les étapes suivantes :

1. Ouvrez le menu **Options** de l'espace.
2. Sélectionnez **Partager**.
3. Pour une équipe sous **ACCÈS À L’ESPACE**, spécifiez l'une des options suivantes :
   - **Peut consulter**
     Tous les membres de l'équipe peuvent consulter votre espace et tous les tableaux à l'intérieur de l'espace.
   - **Peut commenter**
     Tous les membres de l'équipe peuvent commenter sur n'importe quel tableau à l'intérieur de l'espace. Inclut consulter.
   - **Peut modifier**
     Tous les membres de l'équipe peuvent modifier votre espace et tous les tableaux à l'intérieur de l'espace. Inclut consulter et commenter.
   - **Pas d'accès**
     Aucun membre de l'équipe, à l'exception de ceux que vous invitez individuellement, ne peut accéder à votre espace.

     Vous avez modifié avec succès l'accès à l'espace pour toute votre équipe.

### Comment gérer l'accès à un espace

En tant que propriétaire ou copropriétaire d'un espace, vous pouvez gérer l'accès à un espace donné et attribuer des rôles.

Vous pouvez gérer l'accès et les permissions pour des membres individuels de l'équipe, ainsi que gérer l'accès pour tous les autres membres de l'équipe.

Suivez les étapes suivantes :

1. Ouvrez le menu **Options** de l'espace.
2. Sélectionnez **Partager**.
3. Sous **ACCÈS À L'ESPACE**, sélectionnez **Gérer l'accès**.
   La vue **Gérer l'accès des personnes** s'ouvre.
4. Modifiez les permissions pour les membres invités de l'équipe.

   > 💡 Pour ajouter des membres de l'équipe, sélectionnez **Ajouter des personnes**.
5. Pour confirmer vos modifications, sélectionnez **Terminé**.
   Vous revenez au début de la fenêtre modale.
6. (Optionnel) Sous **ACCÈS À L'ESPACE**, spécifiez l'accès pour tout le reste de l'équipe.

   Vous avez géré avec succès l'accès à un espace.

**Plus d'informations :** Voir Rôles dans les espaces.

### Comment créer des sections à l'intérieur des espaces

Pour organiser votre contenu, vous pouvez éventuellement créer des sections à l'intérieur de votre espace.

Les sections apparaissent uniquement dans la barre latérale des espaces. Vous devez ouvrir un tableau dans votre espace pour consulter et gérer les sections.

Suivez les étapes suivantes :

1. Dans la barre latérale Espaces, sélectionnez **Créer nouveau** (**+**).
2. Sélectionnez **Ajouter une section**.
   Une section sans titre est ajoutée à la barre latérale.
3. Nommez votre nouvelle section, et appuyez sur **Entrée**.

   Vous avez réussi à créer une section.

Dans la barre latérale Espaces, vous pouvez maintenant glisser-déposer du contenu vers votre nouvelle section. Pour un tableau donné, vous pouvez également sélectionner les trois points (**...**) pour ouvrir le menu contextuel **Options**, et sélectionner **Déplacer vers la section**.

Pour renommer ou supprimer une section, sélectionnez les trois points (**...**) pour la section que vous souhaitez modifier, et sélectionnez **Renommer** ou **Supprimer**.

:::note
Les membres de l’espace avec l’accès Éditeur ou supérieur peuvent créer, renommer et supprimer des sections, et déplacer des tableaux vers une autre section. Les admins de contenu peuvent gérer n'importe quelle section à l'intérieur d'un espace dont ils sont membres.
:::

### Comment réorganiser le contenu et les sections à l'intérieur d'un espace

Vous pouvez changer l'ordre des sections et du contenu à l'intérieur d'un espace.

Par défaut, Miro classe tout le contenu et les sections à l'intérieur d'un espace par ordre de création décroissant. Le contenu le plus récent est en haut.

Pour réorganiser le contenu à l'intérieur d'un espace, dans la barre latérale des espaces, faites glisser et déposez votre sélection vers le haut ou le bas. Vous pouvez sélectionner n'importe quelle section, ou tout contenu à l'intérieur d'une section.

:::tip
Pour déplacer une section, vous pouvez également accéder au menu contextuel. Sélectionnez les trois points (**...**), puis choisissez **Déplacer vers le haut** ou **Déplacer vers le bas**.
:::

### Comment définir un aperçu d’un espace

Vous pouvez désigner n’importe quel tableau de votre espace comme étant l’aperçu de l’espace, ce qui fournit un point d’entrée par défaut pour quiconque accède à l’espace.

Pour savoir comment définir un aperçu d’un espace, consultez [Aperçu de l’espace](02-space-overview.md). Vous pouvez également créer un [tableau de bord](03-space-overview-dashboard-beta.md) unique pour l’aperçu de votre espace.

### Comment déplacer des tableaux entre les espaces

Vous pouvez déplacer votre tableau Miro d’un espace à un autre.

:::tip
La procédure suivante s’applique également aux tableaux qui ne se trouvent dans aucun espace.
:::

Suivez les étapes suivantes :

1. Dans la barre de tableau en haut à gauche de votre tableau Miro, sélectionnez les trois points verticaux.
   Le **menu Principal** s'ouvre.
   ![Move a board to another Space from the Main menu.](../../../../../../docs/using-miro/spaces/images/21061987239954_spaces-move-space.png) *Déplacer le tableau vers un autre espace*
2. Sélectionnez **Tableau** > **Déplacer vers** > **Un autre espace**.
   La **fenêtre modale Déplacer le tableau vers un espace** s'ouvre.
3. Sélectionnez un espace dans la liste déroulante.

   > ✏️ Seuls les espaces pour lesquels vous disposez des droits de modification sont affichés.
4. (Facultatif) Sélectionnez **Notifier les membres** pour envoyer un e-mail à tous les membres de votre espace cible.
5. Sélectionnez **Déplacer**.
   Vous avez déplacé votre tableau vers un autre espace avec succès.

Vous pouvez également déplacer votre tableau vers un autre espace depuis la barre latérale.

Suivez les étapes suivantes :

1. Dans la barre latérale du tableau, survolez le tableau que vous souhaitez déplacer et sélectionnez les trois points (**...**) pour accéder au menu contextuel.
   ![Move a board to another Space from the sidebar menu.](../../../../../../docs/using-miro/spaces/images/21061987243794_spaces-move-space-board-sidebar.png) *Depuis la barre latérale du tableau, déplacez le tableau vers un autre espace*
2. Sélectionnez **Déplacer vers Espace**.
   La fenêtre modale **Déplacer le tableau vers l'espace** s'ouvre.
3. Sélectionnez un espace dans la liste du menu déroulant.

   > ✏️ Seuls les espaces pour lesquels vous disposez des droits de modification sont affichés.
4. (Optionnel) Sélectionnez **Notifier les membres** pour envoyer un e-mail à tous les membres de votre espace cible.
5. Sélectionnez **Déplacer**.
   Votre tableau a été déplacé avec succès vers un autre espace.

### Comment déplacer plusieurs tableaux entre les espaces

Vous pouvez déplacer plusieurs tableaux d'un espace à un autre.

Suivez les étapes suivantes :

1. Dans la barre latérale du tableau de bord, sélectionnez la croix (**+**) pour ouvrir le menu **Créer un nouveau**.
2. Sélectionnez **Déplacer les tableaux ici**.
   La fenêtre modale **Déplacer les tableaux vers &lt;nom de l'espace&gt;** s'affiche.
3. (Facultatif) Pour rechercher uniquement les tableaux que vous possédez, sélectionnez **Rechercher uniquement les tableaux dont je suis propriétaire**.
4. Sélectionnez les tableaux — ou utilisez la recherche pour localiser et sélectionner les tableaux — que vous souhaitez déplacer vers votre espace.
5. (Facultatif) Sélectionnez **Notifier les membres**.
6. Sélectionnez **Déplacer les tableaux**.
   Vous avez transféré avec succès plusieurs tableaux Miro d'un espace à un autre.

:::tip
Vous pouvez également déplacer plusieurs tableaux à partir du menu Paramètres des espaces. Dans le menu Paramètres des espaces, sélectionnez Ajouter des tableaux.
:::

### Comment supprimer un espace

En tant que propriétaire de l'espace, vous pouvez supprimer votre espace. Les tableaux créés par d'autres membres de l'équipe dans votre espace sont déplacés au niveau de l'équipe.

Vous pouvez choisir de déplacer les tableaux que vous possédez au niveau de l'équipe ou de les envoyer à la corbeille.

![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)

*Les propriétaires d'espaces peuvent choisir de conserver les tableaux qu'ils possèdent au niveau de l'équipe ou de les envoyer à la corbeille.*

Suivez les étapes suivantes :

1. Dans les options des espaces, cliquez sur **Supprimer**.
   La fenêtre modale de suppression s'ouvre. **Déplacer les tableaux vers la corbeille** est sélectionné par défaut.
2. (Optionnel) Pour conserver les tableaux que vous possédez au niveau de l’équipe, désélectionnez **Déplacer les tableaux vers la corbeille**.
3. Cliquez sur **Supprimer l’espace**.
   Votre espace est supprimé. Les tableaux créés par d'autres membres sont déplacés au niveau de l’équipe. Si vous avez passé l'étape 2, vos propres tableaux sont déplacés vers la corbeille.

## Conclusion

Les espaces ne se contentent pas de remplacer les projets. Ils transforment radicalement la manière dont vous gérez le contenu sur Miro. En particulier pour une organisation comptant des centaines d'utilisateurs et potentiellement des milliers de tableaux Miro, les espaces simplifient la découverte et la gestion du contenu.

En effet, les espaces font progresser l'expérience de la plateforme Miro en tant que plateforme d'innovation de classe mondiale.

## FAQ

**Qu'est-il arrivé aux projets ?**

Vos projets sont automatiquement migrés vers les espaces. La création de contenu, les permissions et le partage fonctionnent de la même manière.

**Qu'en est-il des tableaux qui n'étaient pas dans un projet ? Où sont-ils maintenant ?**

Pour trouver des tableaux qui ne sont pas dans un espace, depuis le **tableau de bord** principal, filtrez par **Tableaux non inclus dans un espace**. Les tableaux qui n'étaient pas dans un projet ne sont pas inclus dans un espace.

**Qu'en est-il de mes projets favoris ?**

Les projets que vous aviez ajoutés aux favoris sont maintenant des espaces épinglés.

**Les espaces utilisent-ils les mêmes rôles et permissions que les projets ?**

Les espaces améliorent l'administration existante des tableaux de Miro. Les permissions définies pour les projets sont conservées dans les espaces. Le Content Admin, admin de projet—maintenant admin d'espace—et les rôles d'accès restent inchangés.

**Que se passe-t-il si je reçois un lien vers un tableau qui appartenait auparavant à un projet ?**

Le lien vous dirige vers le tableau, maintenant à l'intérieur de l'espace converti. Le lancement des espaces convertit chaque projet en espace. Toutes les autorisations de tableau définies précédemment s'appliquent toujours.

**Je veux migrer des projets vers mon compte Enterprise. Est-ce sûr ?**

Oui, c'est sûr. Vos projets deviendront des espaces.

**Que se passe-t-il si un utilisateur a des autorisations plus élevées sur un tableau que sur un espace ?**

L'utilisateur obtient le rôle de niveau le plus élevé. Par exemple, si l'utilisateur n'a que des autorisations de commentaire pour un espace, mais qu'il a des autorisations d'éditeur pour un tableau dans cet espace, alors l'utilisateur conserve les autorisations d'éditeur pour ce tableau. Inversement, si l'utilisateur a un accès de consultation à un tableau dans un espace, et un accès d'éditeur à cet espace, alors l'utilisateur a un accès d'éditeur à ce tableau.

**Qui peut voir les tableaux dans mon espace ?**

Tout tableau que vous avez dans un espace est visible par tout utilisateur ayant accès à cet espace.

**Quelles permissions de contenu un propriétaire ou copropriétaire a-t-il à l'intérieur d'un espace ?**

Un propriétaire ou copropriétaire d'espace a des privilèges d'édition pour tout le contenu enfant à l'intérieur d'un espace.

**Où puis-je en savoir plus sur tous les autres changements simplifiés de l'interface utilisateur ?**

Pour en savoir plus sur les améliorations de l'interface utilisateur des tableaux de Miro, consultez [la nouvelle interface utilisateur simplifiée de Miro](../working-on-the-board/02-miro's-new-simplified-user-interface.md).
