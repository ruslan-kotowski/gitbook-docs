Ce guide couvre les tâches administratives en cours pour Miro Insights, y compris les paramètres généraux, la gestion d’équipe, les notifications et l’accès API. Il est destiné aux admins d’entreprise qui doivent gérer Miro Insights après que le paramétrage initial soit terminé.

Si vous n’avez pas encore configuré Miro Insights, commencez par le [guide Configuration de Miro Insights (admin)](../../miro-insights/set-up-and-manage-miro-insights/01-set-up-miro-insights.md) d’abord.

## Prérequis

Pour gérer l’administration de Miro Insights, vous avez besoin de :

- **Rôle d'admin d’entreprise** dans Miro.
- **Miro Insights doit déjà être configuré** pour votre organisation.

## Profil de l’entreprise

Dans cette section, vous pouvez mettre à jour les informations de votre entreprise qui apparaissent dans Miro Insights.

- **Nom** : Nom de votre organisation.
- **Domaines de courriel autorisés** : Domaines de courriel qui peuvent accéder à Miro Insights.
- **Logo de l'entreprise** : Charger ou changer le logo de votre entreprise.

## Équipe

Cette section couvre les paramètres liés à votre équipe Miro Insights. En tant qu'administrateur, vous pouvez inviter, ajouter ou supprimer des utilisateurs, et gérer leurs rôles.

## Notifications

Dans cette section, vous pouvez configurer comment et quand vous ou les membres de votre équipe recevez des notifications sur les nouveaux retours, les suggestions AI et d'autres événements importants.

Vous pouvez définir des méthodes de notification, telles que Slack. Vous pouvez configurer les types de notifications par catégorie : fonctionnalité ou avis.

## Intégrations & automatisations

Cette section vous permet de gérer toutes les intégrations et automatisations connectées. Vous pouvez consulter l'état de chaque intégration, reconnecter si nécessaire et ajuster les paramètres d'importation.

Pour des instructions détaillées de configuration, consultez le guide [Configurer Miro Insights (admin)](../../miro-insights/set-up-and-manage-miro-insights/01-set-up-miro-insights.md).

## Clés API

Ici, vous pouvez générer et gérer des clés API pour un accès programmatique aux données de Miro Insights. Vous pouvez créer de nouvelles clés et révoquer les clés anciennes ou compromises.

:::warning
Lors de la création d'une clé API, assurez-vous de lui donner un nom descriptif et de la copier dans un endroit sûr. Vous ne pourrez plus la voir après avoir quitté la page.
:::

## Et ensuite ?

Une fois que vous avez configuré ces paramètres administratifs, votre instance Miro Insights devrait fonctionner sans problème pour votre équipe. Pour des conseils d'utilisation continue, veuillez consulter le guide [Utiliser Miro Insights](../../miro-insights/use-miro-insights).
