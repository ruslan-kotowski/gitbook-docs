Miro vous permet de partager vos tableaux avec vos collaborateurs n’importe où. Il existe plusieurs façons d’inviter des utilisateurs dans vos tableaux. Étudions chacune d’entre elles.

<iframe allowfullscreen="" frameborder="0" height="315" src="//fast.wistia.com/embed/iframe/clvhobou8c" width="560"></iframe>

## Comment inviter à un tableau

> **Qui peut le faire : les membres de l'équipe ayant des droits de modification et d'invitation dans [les permissions de partage du tableau](02-who-can-share-a-miro-board.md)**

Par défaut, les éditeurs de tableau qui sont membres de l’équipe peuvent partager le tableau avec d’autres utilisateurs. Les propriétaires de tableaux et [copropriétaires](06-co-owners-of-boards-and-spaces.md) disposant de forfaits payants peuvent [restreindre cette option pour les éditeurs de tableaux](02-who-can-share-a-miro-board.md).

Vous pouvez partager un tableau de deux manières différentes :

À partir du tableau même À partir du tableau de bord

Cliquez sur **Partager** dans le coin supérieur droit.

![share menu.png](https://help.miro.com/hc/article_attachments/21019790963602)
*Option Partager dans le coin supérieur droit du tableau*

Depuis le **tableau de bord** Accueil, sélectionnez les trois points (**...**) du tableau que vous souhaitez partager. Ensuite, sélectionnez **Partager.**
![share from the dashboard.png](https://help.miro.com/hc/article_attachments/21019735206802)
*Partagez votre tableau directement depuis le tableau de bord*

## Moyens de partager des tableaux Miro

Partagez des tableaux Miro via Slack, par e-mail, par un lien privé, publiquement, avec l’ensemble de l’équipe, avec l’entreprise et par le biais d’un projet.

### Inviter à partir de Slack

Comment inviter des utilisateurs à partir de Slack

1. Cliquez sur le bouton **Partager** dans le coin supérieur droit du tableau.
2. Sous l'onglet **Inviter**, cliquez sur **Slack**.
3. Cela vous amènera jusqu’à la page d’autorisation.

![2-1.png](https://help.miro.com/hc/article_attachments/22206753984018)
*Partage d’un tableau Miro par Slack*
Une fois l’autorisation réussie, vous verrez une liste de vos contacts Slack. Choisissez une personne (ou plusieurs pour une invitation en masse) avec laquelle vous souhaitez partager un tableau, spécifiez le niveau de [droits d'accès](01-board-access-rights.md) et cliquez sur **Envoyer les invitations**.

![invite from Slack modal.png](https://help.miro.com/hc/article_attachments/21019735209618)
*Inviter un contact Slack à modifier le tableau*

### Inviter par e-mail

Comment inviter par e-mail

Pour inviter quelqu’un personnellement par e-mail :

1. Cliquez sur le bouton **Partager** dans le coin supérieur droit du tableau.
2. Sous l’onglet **Inviter**, entrez les adresses e-mail de vos invités et définissez leurs [droits d’accès](01-board-access-rights.md). Ajoutez des espaces pour séparer les e-mails.
3. Cliquez sur **Envoyer les invitations.**

![2-2.png](https://help.miro.com/hc/article_attachments/22206753989394)
*Invitation de collaborateurs à partir de la boîte de dialogue de partage du tableau*

Vos invités recevront une notification concernant l’invitation (les utilisateurs enregistrés recevront l’invitation si cela est autorisé dans leurs [paramètres de notification](../managing-your-profile/02-miro-notifications.md)).</span> Si une personne invitée n’est pas encore inscrite, elle peut suivre les instructions contenues dans l’e-mail qui la guideront à travers[la procédure d’inscription](../../getting-started/start-here/02-how-to-register-with-miro.md) puis accéder au tableau.

:::tip
Pour faciliter le processus d’invitation par e-mail, associez votre compte Gmail pour activer la fonction de remplissage automatique. [En savoir plus sur l’association de Gmail à Miro](../../integrations-apps/google/04-google-contacts.md).
:::

**Inviter en tant qu’invité ou membre**

Lorsque vous partagez un tableau par e-mail ou par Slack avec un utilisateur qui n'est pas membre de votre équipe, vous pouvez soit l'inviter dans votre équipe, soit en faire [un invité pour ce tableau](07-collaboration-with-guests.md) en fonction de votre forfait et des paramètres d'invitation. [Découvrez si l’option pour convier des invités est disponible pour vous](07-collaboration-with-guests.md).

### Partage de tableaux via un lien public

Comment partager à l’aide d’un lien public

Vous pouvez partager un tableau avec n’importe qui, y compris des personnes qui ne sont pas inscrites sur Miro, en rendant le tableau accessible via un lien public pour les [visiteurs](08-collaboration-with-visitors.md).

1. Cliquez sur le bouton **Partager** dans le coin supérieur droit du tableau.
2. Sous l’onglet **Inviter**, allez à **Quiconque ayant le** **lien**, et choisissez entre l'accès à la consultation, aux commentaires, et à la modification pour les visiteurs de votre tableau.
3. Cliquez sur **Copier le lien du tableau** et envoyez-le à vos futurs collaborateurs.

:::note
Le partage des tableaux avec les visiteurs peut ne pas être possible si votre administrateur d'entreprise a [restreint le partage public](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md). Veuillez contacter votre admin si cette option de partage n’est pas disponible pour vous.
:::

:::note
Les tableaux partagés via un lien public paramétré sur **tous les utilisateurs peuvent modifier** sont modifiables par les utilisateurs disposant d’une [licence Free Restricted](../../enterprise-administration/enterprise-subscription-management/enterprise-licensing/04-free-restricted-license.md).
:::

:::note
L’option de partage par un lien public avec droits de commentaire/modification n’est pas disponible avec le [forfait Free](../../plans-billing/miro-plans/09-free-plan.md).
:::

![2-3.png](https://help.miro.com/hc/article_attachments/22206753992466)
*Autoriser l’accès du public au tableau*

Les personnes qui suivent votre lien n’auront pas besoin de s’enregistrer sur Miro pour accéder au tableau. En savoir plus sur [le partage des tableaux Miro avec les visiteurs](08-collaboration-with-visitors.md).

:::warning
Miro s’efforce d’empêcher les tableaux publics d’être indexés par des moteurs de recherche tels que Google ou Bing. Cependant, toute personne disposant du lien peut accéder à ces tableaux et le lien risque d’être partagé au-delà de votre public cible. En fonction de votre forfait Miro, vous pouvez renforcer la sécurité en définissant un [mot de passe pour votre tableau public](13-password-protection-for-public-boards.md).
:::

### Partager des tableaux et inviter à rejoindre l’équipe via un lien

Comment partager et inviter à rejoindre l'équipe via un lien

> **Pertinent pour :** les forfaits Free, Starter et Education

Pour activer le partage par un lien, l’admin doit accéder à **Réglages de l’équipe > Autorisations >** **Paramètres des invitations** et activer **Activer le lien d’invitation de l’équipe**.

![team invite link.png](https://help.miro.com/hc/article_attachments/21019790969234)
*Les admins peuvent activer le lien d’invitation de l’équipe*

1. Cliquez sur le **bouton Partager** dans le coin supérieur droit du tableau.
2. Sous l’onglet **Inviter**, allez à **Inviter à l’équipe et au tableau**.
3. Définissez le niveau d’accès.
4. Cliquez sur **Copier le lien d’invitation de l’équipe** et envoyez-le aux membres de votre équipe. Lorsqu’un invité clique sur le lien, il lui est demandé de se connecter à Miro. L’utilisateur deviendra membre de votre équipe et bénéficiera d’un accès instantané au tableau.

![2-4.png](https://help.miro.com/hc/article_attachments/22206748653074)
*Partager le tableau et inviter l’équipe via un lien*

Tant que le lien d’invitation de l’équipe est activé dans les paramètres, les utilisateurs peuvent rejoindre les tableaux et l’équipe grâce au lien. Une fois cette option désactivée, tous les liens d’invitation envoyés précédemment vont expirer et les nouveaux utilisateurs ne pourront plus rejoindre les tableaux et l’équipe avec ce lien.

Si un admin d’équipe empêche les membres de l’équipe non-admins d’inviter de nouveaux utilisateurs mais autorise toujours le lien d’invitation de l’équipe dans les [paramètres d’invitation](../../administration/user-management/02-invitation-settings.md), l’option pour copier le lien disparaîtra du menu Partager pour les membres de l’équipe non-admins. Les utilisateurs pourront toutefois continuer de rejoindre l’équipe par le lien si celui-ci leur avait été communiqué précédemment (sauf si l’admin désactive le lien dans les paramètres de l’équipe).

### Partager des tableaux et inviter à rejoindre l’équipe par un lien Invité

**Comment partager et inviter à rejoindre l’équipe par un lien Invité**

> **Disponible pour :** Forfait Business

Conviez des invités à accéder à un tableau ou à rejoindre votre équipe à l’aide d’un lien privé. Cette option n’apparaît dans la boîte de dialogue Partager que si les invités sont autorisés dans les [paramètres d’invitation de l’équipe](../../administration/user-management/02-invitation-settings.md).

1. Cliquez sur le bouton **Partager** dans le coin supérieur droit du tableau.
2. Sous l’onglet **Invitation**, à côté de **Inviter des invités**, cliquez sur le menu déroulant pour accorder un accès de type **Consulter**, **Commenter**, **Modifier** ou **Aucun accès**.
3. Cliquez sur **Copier le lien invité**
4. Partagez le lien directement avec l'utilisateur que vous souhaitez inviter en tant qu'invité.

![2-5.png](https://help.miro.com/hc/article_attachments/22206754001170)
*Création d'un lien invité*

:::note
Pour des raisons de sécurité, les liens d'invités expirent après 30 jours. Pour garantir l'accès après 30 jours, vous devez générer un nouveau lien et le renvoyer aux invités.
:::

Partager un tableau avec toute votre équipe

**Comment partager un tableau au niveau de l’équipe**

Vous pouvez facilement rendre n’importe quel tableau disponible pour toute l’équipe.

1. Cliquez sur le bouton **Partager** dans le coin supérieur droit du tableau.
2. Sous l’onglet **Inviter**, allez sur **Toute personne de l’équipe [nom de l’équipe]**, et choisissez **Peut consulter/commenter/modifier** dans le menu déroulant.
3. Les membres de votre équipe verront immédiatement le tableau sur leur tableau de bord.

L’option pour notifier tous les membres de l’équipe s’affiche pour les petites équipes jusqu’à 31 membres dans les forfaits Starter, Business et Education. Si vous cliquez sur **Notifier les membres**, tous les membres de l'équipe recevront une notification par e-mail.

![2-6.png](https://help.miro.com/hc/article_attachments/22206754004242)
*Partager un tableau avec une équipe*

Les tableaux du [forfait Free](../../plans-billing/miro-plans/09-free-plan.md) sont accessibles par défaut à tous les membres de l’équipe. Pour les autres forfaits, les admins d’équipe peuvent configurer les [paramètres de partage par défaut](11-default-sharing-settings.md) pour les tableaux nouvellement créés et rendre tous les nouveaux tableaux visibles pour toute l’équipe.

:::warning
L’option n’est pas disponible pour les utilisateurs du forfait Enterprise si l’admin [l’a bloquée dans les paramètres](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md).
:::

### Partager un tableau avec toute l’entreprise

**Comment partager un tableau au niveau de l’entreprise**

> **Disponible pour :** Forfait Enterprise

Vous pouvez rendre n’importe quel tableau disponible pour tous les utilisateurs d’une organisation Enterprise.

1. Cliquez sur le bouton **Partager** dans le coin supérieur droit du tableau.
2. Trouvez **toute personne ayant le lien à l’entreprise** dans la boîte de dialogue Partage du tableau et sélectionnez **Peut consulter/commenter/modifier**.

Chaque membre de votre forfait Enterprise pourra trouver le tableau dans les [résultats de recherche](../../getting-started/start-here/miro-dashboard/03-how-to-search-in-miro.md) et y accéder par un lien (connexion requise). Les membres de l’équipe où le tableau est stocké le verront également sur le tableau de bord de l’équipe.

![2-7.png](https://help.miro.com/hc/article_attachments/22206748667154)
*Partager un tableau avec une entreprise*

:::warning
L'option permettant de partager un tableau avec l'ensemble de l'entreprise n'est pas visible pour les utilisateurs si l'admin l'a [bloquée dans les paramètres](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md) ou a activé la [Confidentialité de l'équipe](../../enterprise-administration/managing-enterprise-teams-and-content/11-manage-team-privacy-and-discovery-on-enterprise-plan.md)*.*
:::

:::note
[Les invités](07-collaboration-with-guests.md) ne peuvent pas accéder aux tableaux partagés de l’entreprise (sauf si les tableaux sont partagés avec eux par d’autres moyens).
:::

### Déplacement des tableaux vers un espace

> **Disponible pour :** les forfaits Starter, Business, Enterprise et Education

**Comment inviter à partir de votre répertoire Microsoft**

> **Disponible pour :** les forfaits Free, Starter, Education et Business

Ouvrez la boîte de **dialogue** Partager dans le coin supérieur droit de votre tableau. Dans la ligne d'invitation par e-mail de la boîte de dialogue de partage, cliquez sur **inviter à partir de Microsoft****.** Vous arrivez sur une fenêtre d’autorisation.

Une fois l’autorisation accordée, vous aurez accès à la liste de vos contacts Microsoft. Sélectionnez une personne (ou plusieurs pour une invitation en masse), spécifiez ses droits d’accès (peut consulter, peut commenter ou peut modifier), puis cliquez sur **Envoyer l’invitation**.

## Vue de démarrage

> **Qui peut le faire :** les éditeurs de tableaux qui [peuvent partager le tableau](02-who-can-share-a-miro-board.md)

La définition d’un affichage de départ est un excellent moyen de focaliser l’attention d’un collaborateur sur une partie spécifique de votre tableau. Lorsque vous partagez un tableau pour la première fois, vous pouvez définir l’affichage de départ **du tableau.** Il s’agit de l’endroit du tableau où les utilisateurs nouvellement invités arrivent lorsqu’ils accèdent au tableau pour la première fois. Si vous ne définissez pas d’affichage de départ, le tableau est affiché dans son intégralité.

![setting start view.png](https://help.miro.com/hc/article_attachments/21019735247634)
*Définir la vue démarrage*

### Comment réinitialiser l’affichage de départ

Pour réinitialiser la vue de démarrage, dans la barre du tableau, sélectionnez les trois points verticaux. Le **Menu principal** s'ouvre. Sélectionnez **Tableau** >**Vue de démarrage**. Vous pouvez maintenant réinitialiser la vue de départ.

## Arrêter le partage d'un tableau

Vous pouvez interrompre le partage d'un tableau avec vos collaborateurs à tout moment. Pour modifier l’accès d’un utilisateur individuel :

1. Cliquez sur le bouton **Partager** dans le coin supérieur droit du tableau (ou utilisez l'icône des trois points (**...**) à partir du tableau de bord, puis cliquez sur **Partager**.)
2. Cliquez sur **Gérer l’accès** dans la boîte de dialogue de partage.
3. Choisissez la personne dont vous souhaitez modifier les droits et définissez son nouveau niveau d'accès (modifier, commenter, consulter) ou cliquez sur **Supprimer**.

Si le tableau est partagé par d'autres moyens (avec toute l'équipe, un projet, une entreprise, ou publiquement), l'utilisateur dont les droits ont été restreints peut **conserver le niveau d'accès précédent** par l'intermédiaire de l'équipe/du projet/de l'entreprise/du partage public. Découvrez comment voir [qui a accès à votre tableau](05-who-has-access-to-my-board.md).

![2 Remove contributor v2.gif](https://help.miro.com/hc/article_attachments/22206748673554)
*Suppression de l’accès d’un utilisateur à un tableau*

:::tip
Si vous êtes propriétaire du tableau, vous pouvez également [transférer la propriété](../managing-boards/05-how-to-transfer-board-ownership.md) à un autre utilisateur.
:::

## Publiez votre tableau

Vous pouvez également partager un tableau en l'enregistrant comme modèle pour que votre équipe l'utilise, ou le publier sur [Miroverse](../miroverse/01-what-is-miroverse.md).

1. Cliquez sur le bouton **Partager** dans le coin supérieur droit du tableau.
2. Sous l’onglet **Publier**, choisissez soit **Enregistrer comme modèle**, soit **Publier le modèle**.

:::note
L'option **Enregistrer comme modèle** n'est pas disponible sur le forfait Free.

## Foire aux questions

**Comment partager des tableaux avec des personnes extérieures à l’équipe sans les y ajouter ?**

Vous pouvez inviter des utilisateurs en tant qu’invités ou visiteurs en partageant le tableau publiquement. Pour en savoir plus, consultez l’article [Partager avec des utilisateurs en dehors de votre équipe](04-sharing-with-users-outside-your-team.md).

**Combien de collaborateurs peuvent travailler simultanément sur un même tableau ?**

Le scénario habituel que nous observons presque toutes les semaines est d'environ 200 utilisateurs (éditeurs/commentateurs) travaillant simultanément sur un même tableau. Pour en savoir plus, lisez l'article [Combien d’utilisateurs peuvent collaborer sur un tableau](../troubleshooting-technical-questions/technical-guidelines/05-how-many-users-can-collaborate-on-a-board-simultaneously.md).

**Quelle est la différence entre Peut consulter/commenter/modifier ?**

Les éditeurs peuvent modifier le contenu des tableaux, les commentateurs peuvent laisser des commentaires, tandis que les lecteurs ne peuvent que consulter les tableaux Miro. En savoir plus concernant les [droits d'accès au tableau](01-board-access-rights.md).

**J’ai partagé un tableau avec les membres de mon équipe, mais ils ne le voient pas sur leurs tableaux de bord. Pourquoi ?**

Il se peut que les membres de votre équipe voient le tableau de bord d'une autre équipe. Demandez aux utilisateurs de [passer à la bonne équipe](../../getting-started/start-here/miro-dashboard/04-profile-and-teams.md) depuis la barre latérale gauche de leurs tableaux de bord.

**Puis-je partager un tableau afin que les invités puissent le dupliquer et l’utiliser comme modèle ?**

Oui, les utilisateurs enregistrés peuvent [dupliquer un tableau partagé](../managing-boards/03-how-to-duplicate-a-board.md) si cela est autorisé par le propriétaire du tableau dans les [paramètres de contenu du tableau](14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md). Si vous êtes le propriétaire du tableau, ouvrez la boîte de dialogue **Partager** > **Paramètres de partage** > passez à **Autorisations**. Choisissez qui peut copier le contenu de votre tableau. Notez qu’il est possible que l’option **Toute personne ayant accès au tableau** soit bloquée par les admins d’équipe.

**Quel est le meilleur moyen de partager un tableau avec les personnes participant à un atelier ?**

Si vous partagez votre tableau pour [modifications publiques](08-collaboration-with-visitors.md), les utilisateurs pourront y accéder immédiatement en tant que visiteurs et commencer la collaboration. Découvrez plus de conseils et d’astuces pour [organiser un atelier avec Miro](../../getting-started/feature-intros/03-miro-for-workshops-meetings.md).

**Comment puis-je partager un tableau dans l'application mobile ?**

Ouvrez le tableau et appuyez sur les trois points dans le coin supérieur droit de l'écran pour voir les options de partage du tableau.

**De nombreuses options de partage manquent dans la boîte de dialogue Partage de mon tableau. Comment puis-je les récupérer ?**

Le problème peut être causé par les extensions de blocage de publicités activées dans votre navigateur. Essayez de les désactiver sur les pages Miro et voyez si la boîte de dialogue Partage complète apparaît.
