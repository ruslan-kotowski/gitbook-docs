Les utilisateurs de Miro peuvent partager leurs tableaux avec leurs collaborateurs et restreindre l’accès à ces tableaux à tout moment.

### Comment vérifier les paramètres de partage de votre tableau

Pour savoir qui a accès à votre tableau, ouvrez la boîte de dialogue **Partage du** tableau. Vous pouvez vous y rendre depuis le tableau de bord ou le tableau lui-même.

*Ouverture de la boîte de dialogue Partage du tableau à partir du tableau de bord*

share_menu.jpg
Le bouton Share (Partager) dans le coin supérieur droit du tableau

Un tableau comprend différents niveaux de partage :

- [Team](03-sharing-boards-and-inviting-collaborators.md) (équipe) (toute personne faisant partie de l’équipe peut lire/commenter/modifier).
- [Company (Entreprise)](03-sharing-boards-and-inviting-collaborators.md) (toute personne peut accéder au tableau via un lien, disponible uniquement pour le [plan Enterprise](../../plans-billing/miro-plans/04-enterprise-plan.md)).
- [Public](03-sharing-boards-and-inviting-collaborators.md#partage-de-tableaux-via-un-lien-public) (publique) (toute personne disposant du lien du tableau peut lire/commenter/modifier en tant que [visiteur](08-collaboration-with-visitors.md)).
- [Espaces](../spaces/01-spaces.md) (chaque participant à l'espace peut voir/commenter/modifier en fonction de son rôle dans l'espace)
- Board (tableau) (les utilisateurs spécifiques qui ont été invités sur le tableau [par e-mail](03-sharing-boards-and-inviting-collaborators.md)).

Cliquez sur **Sharing settings** (Paramètres de partage) pour voir les adresses e-mail des utilisateurs qui ont été invités sur le tableau par e-mail. Dans l’exemple ci-dessous, chaque membre de **My Team** (Mon équipe) peut [commenter](01-board-access-rights.md) sur le tableau alors que **Jane** peut le [modifier](01-board-access-rights.md).

who_has_access_to_the_board.gif
Les paramètres de partage montrant les adresses e-mail des utilisateurs invités sur le tableau

Un tableau peut être partagé sur différents niveaux en même temps. Le niveau doté de l’**accès le plus élevé** s’applique à un utilisateur. Voici quelques exemples :

- Si un membre de l’équipe a été invité sur un tableau par e-mail en tant que **commentateur** *et* que toutes les personnes faisant partie de l’équipe **peuvent modifier** le tableau, le niveau d’accès de l’équipe s’applique pour cet utilisateur et il **peut modifier** le tableau.
- Si un tableau est partagé publiquement avec des droits de modification (l’option Anyone with the link **can edit** (Toute personne ayant le lien peut modifier)), tous les utilisateurs du tableau peuvent en modifier le contenu.

:::tip
A [pprenez à créer un tableau privé](15-make-a-miro-board-private.md).
:::

### Qui peut modifier les paramètres de partage du tableau

Les propriétaires du tableau, les [copropriétaires](06-co-owners-of-boards-and-spaces.md) et les éditeurs membres de l’équipe où le tableau est enregistré peuvent partager le tableau et en restreindre l’accès. Les propriétaires et les [copropriétaires](06-co-owners-of-boards-and-spaces.md) du tableau des plans payants peuvent configurer les [autorisations de partage](02-who-can-share-a-miro-board.md) et empêcher les éditeurs de modifier l’accès au tableau et d’y inviter d’autres utilisateurs.

### Accès au tableau sur le plan Free

Veuillez noter que les tableaux enregistrés dans les [équipes gratuites](../../plans-billing/miro-plans/09-free-plan.md) sont accessibles à tous les membres de l’équipe. Pour pouvoir créer des tableaux privés, veuillez mettre votre équipe à niveau.
