Invitez des personnes dans des tableaux publics de Miro et activez l’option permettant de spécifier leur vrai nom. C’est le moyen le plus rapide et le plus simple d’identifier des visiteurs non enregistrés et de collaborer avec eux.

Découvrez [comment inviter des visiteurs](08-collaboration-with-visitors.md).

> ***Disponible pour :* Plans pour l'éducation, les affaires et les entreprises**

### Comment activer les noms des visiteurs

> **Configuré par :** les propriétaires du tableau

> **✏️**Cette fonctionnalité n’est pas disponible pour [les tableaux Miro intégrés](../import-and-export/export/02-embed-a-miro-board.md), y compris les tableaux intégrés dans des applications prises en charge et via un code d’intégration (iFrame).

Ouvrez la boîte de dialogue **Partage d'** un tableau et passez aux **paramètres de partage**. Dans la liste déroulante sous **Adding visitor names if the board is public** (Ajouter les noms des visiteurs si le tableau est public), sélectionnez **Visitors can add their names** (Les visiteurs peuvent ajouter leurs noms).

### Comment les visiteurs peuvent ajouter leurs noms

Si l’option permettant d’ajouter des noms est activée pour un tableau partagé en modification publique, les visiteurs non inscrits qui l’ouvrent pourront se présenter avant d’entrer sur le tableau. S'ils laissent le champ vide, ils seront des utilisateurs anonymes sur le tableau et recevra des noms générés de manière aléatoire (par ex : As de l’invention

Le nom du collaborateur sera affiché à côté de son curseur et dans la barre d’outils de communication dans le coin supérieur droit du tableau.

Si l’option permettant d’ajouter les noms des visiteurs est désactivée, tous les utilisateurs non inscrits recevront des noms générés aléatoirement sur le tableau. Si ces utilisateurs **s’inscrivent**, leurs noms réels apparaîtront sur le tableau.
