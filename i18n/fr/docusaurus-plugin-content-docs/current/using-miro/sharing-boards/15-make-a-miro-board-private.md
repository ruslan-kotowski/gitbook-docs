Si vous démarrez un projet individuel ou souhaitez travailler sur un tableau avant de le partager avec votre équipe, vous pouvez créer un tableau Miro privé ou rendre privé un tableau partagé existant.

## Comprendre les tableaux privés

Les tableaux privés sont des tableaux qui ne sont partagés avec personne et qui sont uniquement accessibles par le propriétaire du tableau. Cette fonctionnalité est disponible pour les forfaits Starter, Education, Business et Enterprise.

Sur le forfait Free, tous les tableaux créés au sein d'une équipe sont visibles par tous les membres de l'équipe. Vous pouvez voir qui est dans votre équipe dans les [paramètres de l'équipe](../../administration/get-started-as-a-miro-admin/01-i-am-a-new-miro-admin.-where-to-start.md) à l'onglet **Utilisateurs actifs**. Si vous souhaitez un tableau privé avec un forfait Free, vous devez être le seul membre de cette équipe.

## Gérer la confidentialité du tableau

Vous pouvez créer un nouveau tableau avec un accès privé dès le départ ou modifier les paramètres d'un tableau existant pour le rendre privé.

### Créer un nouveau tableau privé

Pour que le tableau soit privé dès sa création, suivez ces étapes.

1. **Pour les Admins : Définir les paramètres de partage par défaut (facultatif).** Si vous êtes admin d'équipe ou admin d'entreprise sur un forfait Starter, Business, Enterprise ou Education, vous pouvez définir tous les nouveaux tableaux comme privés par défaut.
   1. Rendez-vous dans **Paramètres de l'équipe** > **Autorisations** > **Paramètres de partage**.
   2. Sous **Paramètres par défaut pour le partage du tableau**, choisissez **Seul le propriétaire du tableau peut y accéder**.
      ![Paramètres de partage par défaut dans Miro.](images/22275650717970_default sharing settings.jpg)
      *Paramètres de partage par défaut*
2. **Vérifiez l'emplacement du tableau.** Avant de créer votre tableau, assurez-vous d'être dans la section **Tableaux de l'équipe** de votre tableau de bord. Si vous créez un tableau dans un [espace](../spaces/01-spaces.md) partagé, le tableau sera automatiquement partagé avec tous les membres de cet espace.
   > ✏️ Si vous avez un espace privé qui n'est partagé avec personne, vous pouvez y créer votre tableau en toute sécurité.
3. **Confirmer les paramètres de confidentialité.** Après avoir créé votre tableau, ouvrez la boîte de dialogue **Partager**. Ici, vous pouvez vérifier si le tableau est [partagé avec votre équipe](03-sharing-boards-and-inviting-collaborators.md). Si c'est le cas, définissez le niveau d’accès de l'équipe sur **Aucun accès**.
   ![Animation montrant comment retirer l'accès d'une équipe à un tableau dans Miro.](../../../../../../docs/using-miro/sharing-boards/images/21016134729874_7-1-720p-10fps-s4-r20.gif)
   *Suppression de l’accès de l’équipe à un tableau*

### Rendre un tableau partagé privé

Pour rendre un tableau existant privé sur un forfait Starter, Business, Enterprise ou Education, vous devez supprimer l'accès pour tous les collaborateurs. Ouvrez la boîte de dialogue **Partager** et cessez de partager le tableau à tous les niveaux :

- Définir l'accès de l'équipe à **Aucun accès**.
- (Sur Enterprise) Définir l'accès de l'entreprise en **Aucun accès**.
- Désactiver tout lien public (réglé sur **Aucun accès**).
- Si le tableau se trouve dans un espace, déplacez-le ou désactivez le partage de l'espace.
- Supprimez tous les utilisateurs individuels répertoriés dans les **Paramètres de partage** jusqu'à ce qu'il ne reste plus que vous (le propriétaire).

:::note
Si vous n'êtes **pas** le propriétaire du tableau mais que vous avez besoin de rendre le tableau privé, vous devez [vous inviter vous-même par e-mail](03-sharing-boards-and-inviting-collaborators.md) sur le tableau avant de supprimer l'accès de l'équipe, de l'espace ou de l'entreprise. Si vous ne réussissez pas à le faire, vous perdrez l'accès au tableau dès que vous modifierez les paramètres de partage.
:::

![Animation montrant comment rendre un tableau Miro partagé privé.](../../../../../../docs/using-miro/sharing-boards/images/21016121409426_7-2-720p-10fps-s4-r20.gif)
*Paramétrer un tableau Miro partagé comme privé*

Vous pouvez toujours [check who has access to your board">vérifier qui a accès à votre tableau](05-who-has-access-to-my-board.md) dans la fenêtre **Partager**.

## FAQ

Pourquoi mes tableaux se sont-ils verrouillés après le passage au forfait Free ?

Le forfait Free ne permet pas les tableaux privés. Partagez le tableau avec votre équipe pour le déverrouiller. Plus d'informations dans cet article
[Le tableau est verrouillé](../tools/troubleshooting/15-the-board-is-locked.md).

J'ai vu l'option pour changer de forfait afin de rendre mon tableau privé. Mon tableau est-il public par défaut ?

Sur le forfait Free, il est partagé par défaut avec toute l’équipe. Cela ne concerne que vos tableaux « partagés avec l’équipe » au sein de votre équipe Free.

Peut-on trouver mes tableaux publics en ligne ?

Miro s'efforce d'empêcher les tableaux publics d'être indexés par des moteurs de recherche tels que Google ou Bing. Cependant, toute personne disposant du lien peut accéder à ces tableaux et le lien risque d’être partagé au-delà de votre public cible. En fonction de votre forfait Miro, vous pouvez renforcer la sécurité en [définissant un mot de passe](13-password-protection-for-public-boards.md) pour votre tableau public.

Je suis membre d’une équipe gratuite et d’une équipe payante. Est-ce que je peux déplacer mes tableaux de l'équipe gratuite à la payante pour les rendre privés ?

Oui, vous pouvez [déplacer vos tableaux Miro](../managing-boards/04-how-to-move-a-board.md).

Peut-on dupliquer mes tableaux publics ?

Oui, si cela est autorisé dans les [paramètres de contenu de votre tableau](14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md).

Lorsque je partage publiquement un tableau, dois-je payer pour les utilisateurs qui y accéderont à l’aide d’un lien du tableau ?

Non, les visiteurs pourront accéder gratuitement au tableau. Découvrez comment vous pouvez [partager publiquement vos tableaux](08-collaboration-with-visitors.md).
