Le programme bêta public offre aux utilisateurs un accès Early aux fonctionnalités de Miro avant qu’elles ne soient disponibles pour tout le monde. En tant qu’admin d’entreprise, vous pouvez activer ou désactiver le programme bêta public pour tous les utilisateurs de votre abonnement Miro Enterprise.

Vos utilisateurs peuvent utiliser les dernières fonctionnalités de Miro et faire des retours au fil de leur développement, pour contribuer à l’optimisation du produit final pour tous les utilisateurs de Miro.

> **Disponible pour :** Enterprise
> **Qui peut le faire :** les admins d’entreprise

## Fonctionnalités clés

Si le programme bêta public est activé, les utilisateurs Enterprise bénéficient des fonctionnalités clés suivantes :

- **Activation en libre-service**
  Les admins d’entreprise peuvent activer ou désactiver les fonctionnalités bêta publiques pour l’ensemble de leur organisation.
- **Déploiement automatisé**
  Les fonctionnalités bêta sont automatiquement déployées pour les utilisateurs, sans frais supplémentaires.
- **Retours**
  Les utilisateurs formulent leurs retours sur les fonctionnalités de Miro avant qu’elles ne soient disponibles au grand public.

## Comment activer ou désactiver le programme bêta public

Pour activer ou désactiver le programme bêta public de votre organisation, procédez comme suit :

1. Dans les paramètres d’admin, cliquez sur Organisation, puis sur **Activation des fonctionnalités**.
2. Sous **Programme bêta public**, sélectionnez l’une des options suivantes :
   - **Personne ne peut l’utiliser**
     Vous avez bien désactivé le programme bêta public de votre organisation.
   - **Tout le monde peut l’utiliser**
     Vous avez bien activé le programme bêta public pour votre organisation.
