Gérez toutes les demandes de licences depuis un seul endroit. En recevant les demandes de licences directement dans Miro, vous pouvez simplifier l'utilisation et les processus d'approbation des licences au sein de votre organisation.

## Paramètres des demandes de licences

Dans vos paramètres de **Demandes d'accès**, vous trouverez un aperçu de toutes les **Demandes de licences** actuelles. Ces demandes de licences sont initiées lorsqu'un utilisateur doit passer d'une licence Free Restricted à une licence Advanced, Standard ou Full (legacy).

Les détails de la demande de licence incluent :

- Le nom de l’utilisateur pour lequel la demande de licence est faite
- Le nom du groupe de facturation (le cas échéant) auquel l’utilisateur sera affecté
- Le nom du demandeur
- La date de la demande

Les demandes peuvent être soumises soit par la personne ayant besoin de changer de forfait, soit au nom de quelqu’un d’autre. Découvrez les différents scénarios de changement de forfait pour le forfait Enterprise.

:::note
Pour recevoir directement les demandes de licence dans Miro, mettez à jour vos préférences de [gestion des demandes](09-request-management-on-enterprise-plan.md).
:::

## Comment accepter ou refuser les demandes de licence

:::note
Toutes les demandes expireront automatiquement et seront supprimées après 30 jours.
:::

1. Accédez à vos paramètres Miro.
2. Cliquez sur **Entreprise**.
3. Sous **Utilisateurs**, cliquez sur **Demandes d'accès**.
4. Sélectionnez l'onglet **Demandes de licence**. Vous pouvez y consulter toutes les demandes de licence en attente.
5. Dans la colonne **Actions**, cliquez sur la coche (**✓**) pour accepter ou sur la croix (**x**) pour refuser la demande.
6. (facultatif) Pour accepter en bloc les demandes de licence, à côté de la colonne **Nom**, cochez la case pour sélectionner toutes les demandes, et cliquez sur **Approbation en masse**.
7. Lorsque vous acceptez ou refusez des demandes, une fenêtre modale s’ouvre avec les détails du demandeur ainsi que pour qui la demande de licence est faite.
8. Cliquez sur **Approuver** pour approuver la demande ou sur **Refuser** pour refuser la demande. Une fois que vous aurez accepté ou refusé une demande, celle-ci sera supprimée de votre aperçu des demandes de licence.
9. Une fois la demande de licence approuvée, l'utilisateur passera d'une licence Free restreinte à une licence Avancée, Standard ou Complète (legacy).

## Scénarios de changement de licence

Certaines actions ou événements dans Miro incitent les utilisateurs à soumettre des demandes de changement de forfait. Les scénarios décrits ci-dessous expliquent comment ces demandes sont initiées pour les utilisateurs du forfait Enterprise. Une fois approuvée, la licence de l'utilisateur sera changée de Free Restricted à une licence Advanced, Standard ou Full (legacy). Les utilisateurs conserveront leur appartenance aux mêmes équipes dont ils faisaient déjà partie.

:::note
Pour consulter l'utilisation actuelle de votre licence, allez dans **Gestion des utilisateurs** > **Utilisateurs actifs**.
:::

|  |  |  |
| --- | --- | --- |
| **Type d'utilisateur** | **Action** | **Scénario** |
| **Membres existants (licence gratuite restreinte)** | Créer un tableau ou un projet | L'utilisateur avec licence gratuite restreinte essaie de créer un nouveau tableau ou projet au sein d'une équipe |
| Accès de modification | L'utilisateur avec licence gratuite restreinte demande l'accès de modification à un tableau |
| Invité à modifier | Un membre existant demande un accès de modification pour l’utilisateur sous licence Free Restricted |
| Propriétaire du tableau | Un utilisateur sous licence Free Restricted se voit attribuer le rôle de [propriétaire du tableau](../../getting-started/start-here/05-roles-in-miro.md) par un admin d’équipe |
