## Types de licences

Le [programme de licences flexibles (FLP)](../enterprise-subscription-management/enterprise-licensing/03-flexible-licensing-program-flp.md) comprend l’avantage supplémentaire d’avoir un nombre illimité de licences **gratuites** et la possibilité de rétrograder vers des licences gratuites restreintes à tout moment.

|  |  |  |
| --- | --- | --- |
| **Complète** | **Free (FLP uniquement)** | **Gratuite restreinte** |
| L’utilisateur dispose des droits de [consulter, de commenter et de modifier](../../using-miro/sharing-boards/01-board-access-rights.md) ainsi que de la possibilité de créer des tableaux. | Les utilisateurs peuvent [consulter et commenter](../../using-miro/sharing-boards/01-board-access-rights.md) et sont automatiquement mis à niveau vers une licence **complète** une fois qu’ils [modifient ou créent un tableau, sont invités à modifier un tableau, se voient accorder la copropriété d’un tableau ou sont ajoutés à un](../../using-miro/sharing-boards/16-projects.md) projet en tant qu’éditeur. | Les utilisateurs ne peuvent que [consulter et commenter](../../using-miro/sharing-boards/01-board-access-rights.md) mais font partie de l’équipe et peuvent consulter tous les tableaux partagés. Ils peuvent demander à changer de forfait |

## Rôles Miro

Les rôles Miro définissent le niveau d’accès d’un utilisateur aux paramètres de votre forfait Enterprise.

:::note
Les admins d’entreprise et les admins d’équipe sont toujours des membres et disposent des mêmes autorisations que les membres.
:::

|  |  |  |  |
| --- | --- | --- | --- |
| **les admins d’entreprise** | **Admins d’équipe** | **Membres** | **Invités** |
| **peuvent** voir toutes les équipes et gérer les paramètres de l’équipe et de l’entreprise. | **peuvent** voir et gérer les paramètres pour une équipe spécifique. | **peuvent** [consulter, commenter et modifier les tableaux](../../using-miro/sharing-boards/01-board-access-rights.md)  **ne peut pas** gérer les paramètres de l'équipe ou de l'entreprise | **peuvent** [afficher, commenter et/ou modifier](../../using-miro/sharing-boards/01-board-access-rights.md) les tableaux partagés (en fonction du [modèle de licences](../enterprise-subscription-management/enterprise-licensing/02-enterprise-licensing.md)).  **ne peuvent pas** créer ou posséder des tableaux, voir les détails des autres équipes et de l’entreprise, gérer les paramètres de l’équipe ou de l’entreprise ou demander une licence. |

## Foire aux questions

**Comment rétrograder la licence d’un utilisateur ?**

Pour les abonnements Enterprise FLP, les administrateurs d'entreprise peuvent rétrograder la licence d'un utilisateur en licence gratuite restreinte dans Paramètres de l'entreprise > **Utilisateurs** > **Tous les utilisateurs** ou **Équipes**, sélectionnez l'équipe dont l'utilisateur fait partie, puis recherchez l'utilisateur dans la liste.

**Pour être membre de deux équipes, dois-je disposer d’une licence dans chaque ?**

Si les équipes font partie d’un même abonnement Enterprise, vous n’avez besoin que d’une seule licence. Si les équipes sont associées à des abonnements différents, vous devez obtenir une licence pour chaque équipe.

**De quel type de licence un admin a-t-il besoin ?**

Les admins sur les forfaits FLP peuvent disposer d’une licence complète, Free ou Gratuite restreinte.  Les admins sur les forfaits non-FLP peuvent disposer d’une licence gratuite restreinte ou complète.
