Les Groupes d'utilisateurs simplifient la gestion des utilisateurs pour les admins d’entreprise, leur permettant de partager du contenu avec tous les membres d'un groupe plutôt que de le faire individuellement avec chaque utilisateur.

Par exemple, vous souhaitez partager un tableau de projet avec tous les designers de votre organisation. Vous pouvez créer un Groupe d'utilisateurs en y ajoutant tous les designers et partager avec le groupe. Tous les membres du groupe auront le même accès que vous spécifiez : Modifier, Commenter ou Consulter.

Pour savoir comment créer des Groupes d'utilisateurs, consultez [les Groupes d'utilisateurs](08-user-groups.md).

![](../../../../../../docs/enterprise-administration/user-management/images/23921780232082_image.png)

*Les admins peuvent créer des Groupes d’utilisateurs dans la console d’admin.*

Les Groupes d’utilisateurs garantissent que tous les utilisateurs d’un groupe ont accès au même contenu, sans avoir besoin de partager les tableaux avec chaque utilisateur individuellement. Vous pouvez également ajouter un Groupe d’utilisateurs à une équipe.

:::note
Pour en savoir plus sur la gestion des Groupes d’utilisateurs via SCIM, contactez votre responsable Customer Success ou le service d'assistance Miro.
:::

## Fonctionnalités clés

- **Créer et gérer des groupes d’utilisateurs**
  Dans la console d’admin, les admins d’entreprise peuvent créer, passer en revue, modifier, ajouter des membres et supprimer des groupes d’utilisateurs. Pour plus d'informations, consultez [Groupes d’utilisateurs](08-user-groups.md).
- **Partager des tableaux et espaces avec des groupes d’utilisateurs**
  Les membres de l’équipe peuvent [partager tout tableau ou espace avec un groupe d’utilisateurs](08-user-groups.md), et définir les permissions.
- **Gérer les groupes d’utilisateurs via l’API**
  Les API de groupes d’utilisateurs permettent aux admins de créer, modifier et supprimer des groupes d’utilisateurs de manière programmatique.
- **Mentionner les groupes d’utilisateurs dans les commentaires**
  Mentionnez un groupe d’utilisateurs sur n’importe quel tableau. Tous les utilisateurs du groupe reçoivent une notification.
- **Voir les membres d’un groupe d’utilisateurs sur les tableaux**
  Vérifiez tous les membres d’un groupe d’utilisateurs lorsque vous mentionnez un groupe sur un tableau.
