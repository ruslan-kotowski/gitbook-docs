Le tableau de bord Overview fournit des insights qui vous permettent de suivre l'adoption et de comprendre l'activité de votre organisation à travers les métriques suivantes :

- **Tableaux :** Consultez le total des tableaux, voyez combien de tableaux sont actifs en termes d'utilisation et suivez les tendances historiques.
- **Utilisateurs :** Suivez combien d'utilisateurs s'engagent activement avec Miro au fil du temps. Vous pouvez également suivre en fonction d'un rôle d'utilisateur spécifique, tel que membre, admin d’entreprise, invité ou invité d’équipe.
- **Équipes :** Surveillez le nombre d'équipes et vérifiez les niveaux d'activité.
- **Licences :** Suivez les différents types de licences allouées et voyez comment cela évolue au fil du temps.
- **Modèles :** Découvrez quels modèles sont le plus utilisés dans votre organisation.

## Travailler avec le tableau de bord d’aperçu

Gardez à l'esprit les considérations suivantes lorsque vous travaillez avec les indicateurs dans le tableau de bord d’aperçu :

- **Sélecteur de plage temporelle :** Utilisez le sélecteur en haut à droite de la page d'analyse pour ajuster la plage temporelle affichée dans le tableau de bord d’aperçu (quotidienne, hebdomadaire, mensuelle ou trimestrielle).
- **Paramètres de vue analytique :** Cliquez sur l’**icône en forme de roue dentée** à côté du sélecteur de plage temporelle pour ouvrir les paramètres. Sous **Confidentialité des utilisateurs**, choisissez d'afficher ou de masquer les noms d'utilisateurs dans les tableaux de bord qui incluent l'activité au niveau utilisateur, comme les principaux utilisateurs d'IA. **Les noms d’utilisateurs sont affichés par défaut.** Cliquez sur **Enregistrer** pour appliquer vos modifications.
- **Dernière mise à jour :** Les métriques sont actualisées quotidiennement. Un horodatage de la dernière mise à jour est affiché dans chaque tableau de bord.
- **Données partielles :** Si une fonctionnalité a été désactivée pendant une partie de la période sélectionnée, vous pourrez voir des données partielles dans l'historique des mesures (par exemple, si une fonctionnalité a été activée en milieu de mois).
- **Aucune donnée :** Si aucune activité n'a été enregistrée pendant une période donnée (jour, semaine ou mois), le graphique n'affichera aucune donnée pour cette période.
- **Affichage des données historiques :**

  - Dans tous les widgets qui affichent des données historiques, les valeurs représentent les données au dernier jour de chaque période. Par exemple, si le type de période sélectionné est mensuel, le graphique des tableaux montre le nombre de tableaux à la fin de chaque mois.
  - La période en cours n'est pas affichée dans les graphiques historiques. Par exemple, si le type de période sélectionné est mensuel et le mois actuel est septembre, le graphique affichera les données uniquement jusqu'à août (la dernière période terminée).
  - Les données historiques sont disponibles jusqu'à un an en arrière ou aussi loin que les données existent. Si des données plus anciennes semblent manquer, contactez le service d’assistance de Miro pour demander une vérification de restitution des données.

## Analyse des tableaux

Le graphique des tableaux affiche le nombre total de tableaux, le nombre de tableaux actifs en termes d'utilisation, et vous permet de consulter et d'analyser les tendances historiques. Le tableau suivant répertorie les informations disponibles dans le graphique des tableaux.

| Nom de la métrique | Description |
| --- | --- |
| (1) Total | Nombre total de tableaux. Cela exclut les tableaux qui sont dans la corbeille. |
| (2) Actifs lors de ce <plage de temps sélectionnée> (soit trimestre/mois/semaine/hier) | Nombre total de tableaux uniques qui ont été ouverts depuis le début de la période sélectionnée. Cela inclut les tableaux qui ont pu être déplacés vers la corbeille. |
| (3) Nombre total de tableaux tracés dans le graphique | Nombre total de tableaux à la fin de la date ou du mois tracé. Cela exclut les tableaux qui étaient dans la corbeille. |
| (4) Tableaux actifs tracés dans le graphique | Nombre total de tableaux uniques qui ont été ouverts depuis le début de la date ou du mois tracé. Cela inclut les tableaux qui ont pu être déplacés vers la corbeille. |

*Remarque : Ces métriques sont mises à jour au moins une fois toutes les 24 heures. L'information "Dernière mise à jour" en haut à gauche de la page Analytics indique quand la mise à jour des métriques a été effectuée pour la dernière fois.*

## Analyse des utilisateurs

Le graphique des utilisateurs affiche combien d'utilisateurs interagissent activement avec Miro au fil du temps. Vous pouvez également suivre les analyses des utilisateurs en fonction d'un rôle spécifique, tel que membre, admin d’entreprise, invité ou invité d'équipe. Le tableau suivant répertorie les informations disponibles dans le graphique des utilisateurs.

| Nom de la métrique | Description |
| --- | --- |
| (1) Total | Nombre total d'utilisateurs, y compris les membres, les admins d'entreprise, les invités et les invités d'équipe. Le nombre total change en fonction du type d'utilisateur que vous sélectionnez dans la liste. |
| (2) Actif ce <plage de temps sélectionnée> (soit trimestre/mois/semaine/hier) | Nombre total d'utilisateurs uniques qui ont ouvert un tableau au moins une fois depuis le début de la période sélectionnée. Cela inclut les utilisateurs désormais désactivés.  Le nombre total change en fonction du type d'utilisateur que vous sélectionnez dans la liste. |
| (3) Utilisateurs totaux tracés dans le graphique | Nombre total d'utilisateurs, y compris les membres, les admins d'entreprise, les invités et les invités d'équipe, à la fin de chaque période tracée.  Le nombre total change en fonction du type d'utilisateur que vous sélectionnez dans la liste. |
| (4) Utilisateurs actifs représentés sur le graphique | Nombre total d'utilisateurs uniques qui ont ouvert un tableau au moins une fois depuis le début de chaque période représentée sur le graphique.  Cela inclut les utilisateurs qui sont maintenant désactivés. Le nombre total change en fonction du type d'utilisateur que vous sélectionnez dans la liste. |

*Remarque : Ces métriques sont mises à jour au moins une fois toutes les 24 heures. L'information "Dernière mise à jour" en haut à gauche de la page Analytics indique la date de la dernière mise à jour des métriques.*

## Analyse des équipes

Le graphique des équipes affiche le nombre d'équipes et les niveaux d'activité. Le tableau suivant liste les informations disponibles dans le graphique des équipes.

| Nom de la métrique | Description |
| --- | --- |
| (1) Total | Nombre total d’équipes.  Cela exclut les équipes qui se trouvent dans la corbeille. |
| (2) Actives pour cette <période sélectionnée> (soit trimestre/mois/semaine/hier) | Nombre total d’équipes uniques dont les membres ont ouvert un tableau au moins une fois depuis le début de la période sélectionnée.  Cela inclut les équipes qui ont peut-être été déplacées vers la corbeille. |
| (3) Total des équipes tracées sur le graphique | Nombre total d’équipes à la fin de la date ou du mois tracé. Cela exclut les équipes qui étaient dans la corbeille. |
| (4) Équipes actives tracées sur le graphique | Nombre total d’équipes dont les membres ont ouvert un tableau au moins une fois depuis le début de la date ou du mois tracé.  Cela inclut les équipes qui ont peut-être été déplacées vers la corbeille. |

*Remarque : Ces métriques sont mises à jour au moins une fois toutes les 24 heures. L'information « Dernière mise à jour » en haut à gauche de la page Analytics indique quand la mise à jour de métrique la plus récente a été effectuée.*

## Analyse des licences

Le graphique des licences affiche différents types de licences allouées et vous permet de suivre les changements d'allocation de licences au fil du temps. Le tableau suivant répertorie les informations disponibles dans le graphique des licences.

| Nom de la métrique | Description |
| --- | --- |
| Allouée | Nombre total de licences allouées, y compris les licences Advanced, Standard, Full (ancienne version), Free et Free Restricted. Cela indique le nombre de licences actuellement utilisées dans votre organisation.  Le nombre total change en fonction du type de licence que vous sélectionnez dans la liste. |
| Historique des allocations tracé dans le graphique | Nombre total de licences allouées à la fin de chaque période tracée.  Le nombre total change en fonction du type de licence que vous choisissez dans la liste. |

*Remarque : Ces métriques sont mises à jour au moins toutes les 24 heures. Les informations Dernière mise à jour en haut à gauche de la page Analytics indiquent quand la mise à jour la plus récente a été effectuée.*

## Analyse des modèles

La section Modèles les plus populaires montre les modèles les plus fréquemment utilisés au sein de votre organisation. Actuellement, ces données incluent uniquement les modèles ajoutés directement à partir d’un tableau, pas à partir d’autres sources telles que miro.com/templates. La prise en charge d’autres sources sera ajoutée dans les futures versions.

*Remarque : Ces métriques sont mises à jour au moins toutes les 24 heures. L'information « Dernière mise à jour » en haut à gauche de la page Analytics indique quand la mise à jour la plus récente des métriques a été effectuée.*
