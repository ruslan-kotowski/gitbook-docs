Vous pouvez télécharger les tableaux exportés individuellement ou utiliser le téléchargement groupé pour gagner du temps. Avec le téléchargement groupé, le système regroupe tous les tableaux d'un travail d'exportation en un seul archive, vous n'avez donc pas besoin de télécharger chaque tableau un par un. Cette option aide les admins à gérer les exports de grande taille plus efficacement en gardant tous les tableaux ensemble dans un seul endroit, ce qui les rend plus faciles à stocker, partager et accéder.

## Télécharger les tableaux exportés dans une seule archive (téléchargement groupé)

Le téléchargement groupé vous permet de sauvegarder tous les tableaux d'un travail d'export achevé dans une seule archive, au lieu de télécharger chaque tableau individuellement.

:::note
Notes :

- Les tableaux exportés sont disponibles pendant **14 jours**.
- Le téléchargement groupé est disponible uniquement après que tous les tableaux de la tâche d'exportation soient terminés et avant l'expiration des résultats de l'exportation de tableau.
- Si la taille totale de l'archive dépasse 50 Go, le système divise automatiquement le fichier en plusieurs archives plus petites.
:::

1. Cliquez sur votre avatar de profil, puis cliquez sur **Console d’admin**.
2. Dans la barre latérale gauche, cliquez sur Enterprise Guard, puis cliquez sur **eDiscovery**.
3. Cliquez sur l’onglet **Enquêtes**.
   La liste des enquêtes s’affiche.
4. Ouvrez l'enquête où l'export a été initié.
5. Cliquez sur l’onglet **Exports**.
6. Cliquez sur le travail d'exportation qui contient les tableaux que vous souhaitez télécharger.
   La page des détails du travail d'exportation s’affiche.
7. Lorsque le travail d'exportation est terminé, le bouton **Télécharger les tableaux** apparaît actif. Cliquez sur le bouton **Télécharger les tableaux** pour télécharger tous les tableaux du travail d'exportation dans une seule archive.

   Le système prépare l'archive après le début du téléchargement. Une fois le téléchargement terminé, ouvrez le fichier d'archive pour accéder à vos tableaux. Chaque tableau est stocké comme un dossier séparé dans le package.

## Télécharger les tableaux exportés individuellement

1. Cliquez sur votre avatar de profil, puis sur **console d’admin**.
2. Dans la barre latérale gauche, cliquez sur Enterprise Guard, puis sur **eDiscovery**.
3. Cliquez sur l’onglet **Enquêtes**.
   La liste des enquêtes s’affiche.
4. Ouvrez l'enquête où l'export a été initié.
5. Cliquez sur l'onglet **Exports**.
6. Cliquez sur la tâche d'export qui contient les tableaux que vous souhaitez télécharger.
   La page des détails de l'export s’affiche.
7. Lorsque le tableau est prêt à être téléchargé, l'icône de téléchargement apparaît active (pas grisée). Cliquez sur le bouton de téléchargement pour chaque tableau que vous souhaitez télécharger.

:::note
Les tableaux exportés sont disponibles pendant **14 jours**.
:::
