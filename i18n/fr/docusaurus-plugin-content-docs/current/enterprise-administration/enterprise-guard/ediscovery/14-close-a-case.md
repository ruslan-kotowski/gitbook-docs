Fermer une enquête est la dernière étape du processus d'eDiscovery, marquant la conclusion d'une affaire ou d'une enquête légale. [Les admin eDiscovery](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md) doivent s'assurer que toutes les mises en suspens juridiques associées à l'enquête sont levées avant de clôturer l'affaire.

Pour fermer une enquête, procédez comme suit :

:::note
Vous devez avoir le rôle d’[admin eDiscovery](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md) pour effectuer cette tâche. Pour demander le rôle d’admin eDiscovery, contactez l’admin d’entreprise.
:::

1. Assurez-vous que toutes les mises en suspens juridiques associées à l'enquête sont fermées. Pour plus d'informations, consultez [Fermer une mise en suspens juridique](12-close-a-legal-hold.md).
2. Accédez à vos [paramètres Miro](https://miro.com/app/settings).
3. Dans le volet de gauche, sous **Enterprise Guard**, cliquez sur **eDiscovery**.
4. Sur la page **eDiscovery**, cliquez sur l'enquête que vous souhaitez clôturer.
5. Cliquez sur l'icône (trois points) sur la ligne de l'enquête que vous souhaitez clôturer, puis cliquez sur **Clôturer l'enquête**.
6. La boîte de confirmation de **Clôturer l'enquête** apparaît, vous informant que tous les détails concernant cette enquête seront supprimés.  ![closecaseconfirmationbox.png](images/22388722646546_closecaseconfirmationbox.png)
7. Une fois que vous êtes sûr de vouloir fermer l'enquête, cliquez sur **Fermer l'enquête**.
   L'enquête est supprimée.
