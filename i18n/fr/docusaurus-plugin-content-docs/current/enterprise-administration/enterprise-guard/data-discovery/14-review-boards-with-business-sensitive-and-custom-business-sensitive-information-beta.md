L'explorateur de contenu permet aux [admins de contenu sensible](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md) d'examiner les occurrences de données sensibles de l’entreprise ou de données sensibles de l’entreprise personnalisées.

:::note
- Pour examiner les tableaux avec des correspondances de données sensibles ou sur mesure à l'entreprise, vous devez avoir le [rôle d’admin de contenu sensible](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md). Pour demander le rôle d’admin de contenu sensible, contactez l’admin de votre entreprise.
- Les correspondances de données sensibles à l'entreprise sont étiquetées comme CLIENT, TECH ou STRATEGIE et les résultats sont répertoriés en haut de la liste de résultats.

- Les correspondances de données sensibles sur mesure de l’entreprise sont étiquetées avec les badges personnalisés appropriés applicables.
:::

Pour examiner un tableau avec des données sensibles de l’entreprise ou des données sensibles personnalisées de l’entreprise, suivez les étapes suivantes :

1. Si vous êtes sur la page de l’**explorateur de contenu**, passez à l’étape 2.
   Si vous n’êtes pas sur la page de l’**explorateur de contenu** :
   a. Accédez à vos [paramètres Miro](https://miro.com/app/settings).
   b. Dans le volet de gauche, sous **Enterprise Guard**, cliquez sur **explorateur de contenu**.
   c. Cliquez sur **découverte de données**.
2. Sur la page **Explorateur de contenu/Découverte de données**, cliquez sur le tableau que vous souhaitez réviser.
   Un panneau coulissant apparaît à droite de l'écran.
3. Le panneau coulissant vous permet d'effectuer les actions suivantes :

   - Pour les correspondances de données sensibles de l’entreprise personnalisées uniquement : **Afficher ou masquer** **les informations sensibles de l’entreprise**
   Par défaut, les informations sensibles de l’entreprise sont masquées. Si vous souhaitez consulter les données sensibles de l’entreprise personnalisées, activez l'option **Afficher les informations sensibles** pour les afficher.
   Lorsque les données sensibles de l’entreprise personnaliséesdonnées sensibles de l'entreprise sont visibles, vous pouvez masquer les données en cliquant sur le bouton bascule **Afficher les informations sensibles** pour le désactiver.

   > ✏️ - Les correspondances de données sensibles de l'entreprise sont étiquetées comme CLIENT, TECH, ou STRATÉGIE et les résultats sont listés en haut de la liste des résultats.
   > - Les correspondances personnalisées de données sensibles de l'entreprise sont étiquetées avec les badges personnalisés appropriés.

   - Pour les données sensibles de l’entreprise et les correspondances personnalisées de données sensibles de l’entreprise : **Filtrer les informations selon la catégorie de données sensibles de l’entreprise**
   Pour consulter les données sensibles de l’entreprise appartenant à une catégorie spécifique, cliquez sur l’onglet **Informations sensibles de l’entreprise**, puis sur le bouton de filtre approprié sous l’onglet.

   –Pour les correspondances de données sensibles de l’entreprise uniquement : **Supprimer les faux positifs**
   Dans le processus de découverte de données sensibles de l’entreprise, vous pourriez rencontrer des situations où le système génère des correspondances qui, bien que techniquement correctes, peuvent ne pas être considérées comme des données sensibles ou pertinentes selon les différentes politiques de sécurité et les besoins spécifiques d'une organisation. Supprimer une correspondance qui ne pose aucun risque de sécurité ou d’affaires devient crucial pour adapter le processus de découverte de données aux exigences de sécurité des données et aux besoins commerciaux spécifiques de l’organisation.

   Il peut également arriver que le système signale par erreur des données sur vos tableaux comme étant probablement sensibles (un faux positif). Divers facteurs contribuent à ces occurrences, y compris la proximité de termes connexes ou le formatage de données d'affaires. Vous pouvez également supprimer les correspondances de faux positifs.

   Lorsque vous supprimez une correspondance, les mises à jour se produisent en temps réel. La classification du tableau et les mesures de protection appliquées sont également mises à jour selon la configuration d'Auto-classification et de mesures de protection intelligentes.

   Pour supprimer une correspondance faussement positive, cliquez sur l'ellipse à côté de la correspondance de données sensible de l’entreprise que vous souhaitez masquer, puis sélectionnez **Masquer la correspondance**. Notez que les mises à jour se font en temps réel. La classification du tableau et les règles de sécurité appliquées sont également mises à jour selon la configuration de l'Auto-classification et des Gardefous Intelligents.
4. Cliquez sur le prochain tableau sur lequel vous souhaitez travailler dans la liste des résultats de l'explorateur de contenu et effectuez les actions nécessaires, ou fermez le panneau déroulant en cliquant sur le bouton **Fermer** en haut à droite du panneau.
