L'activation de la découverte de données sensibles de l’entreprise permet aux admins de contenu sensible d’identifier, de classifier et de sécuriser de manière fluide les données critiques de l’entreprise, sans avoir besoin de savoir exactement quoi rechercher. D'un simple clic sur un interrupteur, les admins de contenu sensible peuvent exploiter les étiquettes intégrées à Miro pour automatiser efficacement l’identification et le balisage des catégories courantes d’informations sensibles de l’entreprise appartenant à l’une des catégories suivantes :

- Conceptions techniques, y compris les flux d’architecture et de données, modèles de données, architecture de sécurité
- Informations clients, y compris les licences clients, renouvellements de comptes, mesures d’utilisation, tarification des comptes, licences flexibles
- Stratégie d'entreprise, y compris les OKR de l'entreprise, planification et objectifs, objectifs de l'entreprise, roadmaps annuelles, responsabilités clés

Pour activer la découverte de données sensibles de l’entreprise, suivez les étapes suivantes :

:::note
Pour activer la découverte de données sensibles de l’entreprise, vous devez avoir le rôle d’[admin de contenu sensible](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md). Pour demander ce rôle, contactez l’admin de votre entreprise.
:::

1. Accédez à vos [paramètres Miro](https://miro.com/app/settings).
2. Dans le volet de gauche, sous **Enterprise Guard**, cliquez sur **Découverte de données**.
3. Sur la page **Découverte de données**, cliquez sur l’onglet **Configuration**.
4. Dans la section **Sensible de l’entreprise**, cliquez sur le bouton **Activer**.
   Un panneau coulissant apparaît.
5. Cliquez sur le bouton **Activer** au bas du panneau coulissant.
   Une fois que vous avez activé la découverte de données sensibles de l’entreprise, le premier scan démarre automatiquement. Les résultats seront disponibles après quelques minutes ou heures, selon le nombre de tableaux Miro dans votre organisation. Vous pouvez consulter les résultats sur la page **Aperçu de la découverte de données** ou dans l’**Explorateur de contenu**.
