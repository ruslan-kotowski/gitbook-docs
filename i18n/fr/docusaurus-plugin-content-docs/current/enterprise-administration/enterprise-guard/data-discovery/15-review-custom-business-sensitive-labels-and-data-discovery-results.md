La page **Aperçu de la Découverte des Données** affiche une liste de tous les badges personnalisés sensibles pour l'entreprise configurés, le statut des badges, le type de badge, l'admin qui a créé le badge, la classification du tableau associée à chaque badge, le nombre de tableaux étiquetés avec chaque badge et le lien pour explorer les tableaux. De plus, les admins de contenu sensible peuvent modifier les badges personnalisés sensibles à l'entreprise, et copier les identifiants d'affichage des badges depuis la page **Vue d'ensemble de la découverte des données**.

:::note
Pour consulter les résultats de découverte de données sensibles pour l'entreprise, vous devez avoir le rôle [d’admin de contenu sensible](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)."} Pour demander le rôle d’admin du contenu sensible, contactez l’admin de votre entreprise.
:::

## Réviser les tableaux avec des données sensibles de l'entreprise personnalisées

Pour explorer les tableaux avec des données sensibles personnalisées à l'entreprise, procédez comme suit :

1. Allez dans vos [paramètres Miro](https://miro.com/app/settings).
2. Dans le volet de gauche, sous **Enterprise Guard,** cliquez sur **Découverte des données**.
3. Sur la page **Découverte de données** **Aperçu**, cliquez sur le lien du compteur de tableaux. L’explorateur de contenu apparaît avec la liste des tableaux. Pour plus d’informations, consultez les tableaux de révision avec des données sensibles de l’entreprise.

## Copier l’identifiant à afficher pour le badge

Les noms des badges ne sont pas visibles dans les journaux d’audit. Si vous souhaitez consulter ou rechercher les journaux d'audit associés à un badge spécifique, vous devez utiliser l'ID d'affichage du badge.

Pour obtenir l'ID d'affichage du badge, procédez comme suit :

1. Rendez-vous dans vos [paramètres Miro](https://miro.com/app/settings).
2. Dans le volet de gauche, sous **Enterprise Guard,** cliquez sur **Découverte des données**.
3. Sur la page **Vue d'ensemble** de **Data Discovery**, cliquez sur l'Ellipsis (trois points) sur la ligne du badge pour lequel vous souhaitez copier l'ID d'affichage du badge, puis cliquez sur **Copier l'ID d'affichage du badge**.
