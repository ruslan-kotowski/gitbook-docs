Désactiver la découverte de données sensibles de l'entreprise désactive l'identification et l'étiquetage fluides des catégories courantes d'informations commerciales sensibles à l'aide des badges de machine learning intégrés de Miro.

Si vous utilisez des badges de découverte de données sensibles de l'entreprise dans la classification automatique, vous ne pouvez pas désactiver cette fonctionnalité. Cela s'explique par le fait que la désactivation de la découverte de données sensibles de l'entreprise pourrait affecter la classification automatique et les garde-fous appliqués au contenu. Pour la désactiver, vous devez d'abord retirer tous les badges de découverte de données sensibles de l'entreprise de la classification automatique. Une fois que vous désactivez la découverte de données sensibles de l'entreprise, les administrateurs perdent la capacité de configurer les badges de découverte de données sensibles dans la classification automatique, et ils ne peuvent plus consulter les tableaux ou correspondances associés dans la page Aperçu de la découverte de données et dans l'Explorateur de contenu.

Pour désactiver la découverte de données sensibles de l’entreprise, effectuez les étapes suivantes :

:::note
Pour désactiver la découverte de données sensibles de l’entreprise, vous devez avoir le rôle d’[admin de contenu sensible](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md). Pour demander le rôle d’admin de contenu sensible, contactez l’admin de votre entreprise.
:::

1. Allez dans vos [paramètres Miro](https://miro.com/app/settings).
2. Dans le volet de gauche, sous **Enterprise Guard,** cliquez sur **Découverte de données**.
3. Dans la page **Découverte de données,** cliquez sur l'onglet **Configuration**.
4. Dans la section **Sensible de l’entreprise,** cliquez sur le bouton **Gérer**.
5. Dans le panneau coulissant, cliquez sur **Désactiver**.
