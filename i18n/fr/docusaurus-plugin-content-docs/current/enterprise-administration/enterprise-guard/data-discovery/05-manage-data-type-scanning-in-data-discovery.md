Les admins de contenu sensible peuvent désormais facilement activer ou désactiver des badges spécifiques lors de la configuration des analyses de découverte de données, ce qui permet d'adapter les résultats aux besoins de votre organisation. Par exemple, vous pouvez choisir de vous concentrer uniquement sur les badges GDPR. Une fois vos préférences de numérisation enregistrées, les numérisations sont automatiquement mises à jour pour refléter le type de données que vous avez activé ou désactivé. Cela donne aux admins un meilleur contrôle sur les résultats d'analyse et aide à réduire le bruit des conclusions non pertinentes. Par défaut, tous les types de données/badges de sensibilité sont activés.

Pour gérer la numérisation du type de données, procédez comme suit :

:::note
- Pour activer ou désactiver les badges pour la découverte de données, vous devez avoir le [rôle d’admin de contenu sensible](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md).</span> Pour demander le rôle d’admin du contenu sensible, contactez l’admin de votre entreprise.
- Vous ne pouvez pas désactiver les badges utilisés pour la classification des données, car leur désactivation pourrait affecter la classification automatique et les garde-fous appliqués au contenu. Supprimez-les des critères de classification avant de les désactiver.
:::

1. Rendez-vous dans vos [paramètres Miro](https://miro.com/app/settings).
2. Dans le volet de gauche, sous **Enterprise Guard,** cliquez sur **Découverte de données**.
3. Sur la page **Découverte de données**, cliquez sur l'onglet **Configuration**.
4. Si vous voulez activer ou désactiver les types de données/ badges liés à la confidentialité, dans la section **Liée à la confidentialité**, cliquez sur le bouton **Gérer**.
   Si vous souhaitez activer ou désactiver les types de données/étiquettes sensibles aux affaires, dans la section **Sensibles pour les affaires**, cliquez sur le bouton **Gérer**.
   Un panneau latéral s'affiche.
5. Pour désactiver un badge de types/labels de sensibilité : Cliquez pour effacer la case à cocher pour le type de données/étiquette.
   Pour activer un type de données/un badge de sensibilité : Cliquez pour sélectionner la case à cocher pour le type de données/badge.
6. Cliquez sur le bouton **Appliquer les modifications**.
   Les mises à jour peuvent prendre jusqu’à 24 heures.
