Pour les organisations utilisant Microsoft Entra ID (anciennement Azure AD) comme fournisseur d’identité, Enterprise Guard transfère en toute sécurité les prompts et les réponses de l'IA vers Microsoft Purview Data Security Posture Management (DSPM) pour la sécurité et la conformité des équipes. Celles-ci peuvent alors surveiller, auditer et contrôler l'utilisation de l'IA générative à partir d'une plateforme de confiance unique, réduisant ainsi les charges opérationnelles, atténuant les risques tels que les fuites de données et les utilisations abusives, et renforçant la gouvernance d'IA de niveau entreprise de Miro.

:::note
La version Bêta prend en charge les formats de Miro IA, y compris les diagrammes, les cartes mentales, les documents, les prototypes, les pense-bêtes et les tables, mais pas les images. Nous travaillons à ajouter la prise en charge des images et d'autres fonctionnalités IA dans les prochaines versions.
:::

## **À qui cela s'adresse-t-il**

Cette fonctionnalité est disponible dans la version bêta pour les clients d'Enterprise Guard qui gèrent Miro et Microsoft Entra ID (anciennement Azure AD)/Microsoft Purview.

## **Ce que vous obtenez**

- **Visibilité centralisée  :** Consultez l'utilisation de Miro IA dans le hub IA de Microsoft Purview.
- **Auditabilité  :** Les prompts (entrées utilisateur) et les réponses (sorties IA) sont enregistrés pour examen.
- **Alignement de la gouvernance  :** Utilisez vos workflows Purview existants pour la surveillance, les alertes et la conservation.

Pour plus d'informations, consultez la [documentation détaillée ici](../../enterprise-subscription-management/integrations/02-enterprise-guard-and-microsoft-purview-dspm-for-ai-integration-overview.md).
