Pour ajuster quels badges sont bloqués ou pour basculer l'analyse du code :

1. Accédez à **Paramètres** → **Enterprise Guard** → **Découverte de données** → **Configuration**.
2. Dans **Blocage des invites**, sélectionnez **Gérer**.
3. Dans le panneau latéral, effectuez l'une des actions suivantes :
   - Activez ou désactivez **Sélectionner tout**.
   - Cochez ou décochez les catégories de badges spécifiques que vous souhaitez bloquer.
   - Activez ou désactivez **Analyse de code**.
4. Sélectionnez **Appliquer les modifications**.

Les modifications prennent effet immédiatement pour tous les utilisateurs. Les prompts contenant des éléments récemment débloqués seront traités. Les prompts contenant des éléments encore bloqués continueront d'être arrêtés.
