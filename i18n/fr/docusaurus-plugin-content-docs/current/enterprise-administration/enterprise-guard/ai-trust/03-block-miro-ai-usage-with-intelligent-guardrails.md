Utilisez les Protection Intelligente pour bloquer toutes les interactions alimentées par IA dans Miro lorsque vous devez protéger des données sensibles ou confidentielles. Ce paramètre désactive l'IA dans tout l'espace de travail tout en permettant aux équipes de continuer à travailler sans assistance IA.

**Ce qui change**

- Toutes les fonctionnalités de Miro IA sont désactivées, y compris la génération de texte, la reconnaissance d'image et les suggestions intelligentes.
- Les utilisateurs ne peuvent pas accéder, activer ou invoquer des outils alimentés par IA.
- Le contenu généré par l'IA existant reste sur les tableaux. Les utilisateurs peuvent le consulter, le déplacer ou le modifier manuellement, mais ne peuvent pas utiliser Miro IA pour le mettre à jour.
- S'applique à tout le monde, y compris les propriétaires et co-propriétaires de tableau.

Pour en savoir plus, consultez la [vue d'ensemble des garde-fous intelligents](../../canvas-25-admin-features/data-classification/01-intelligent-guardrails-overview.md). Pour les instructions de configuration, voir [Définir les garde-fous](../../canvas-25-admin-features/data-classification/05-define-guardrails.md).
