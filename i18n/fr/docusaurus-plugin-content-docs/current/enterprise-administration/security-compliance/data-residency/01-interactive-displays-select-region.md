Les équipes ayant un forfait Enterprise avec une résidence des données en dehors de l'Union Européenne (UE) peuvent sélectionner la région appropriée sur les écrans interactifs.

Cet article explique comment connecter le navigateur d'un écran interactif à la région de résidence des données appropriée, et comment commencer à utiliser l'application Miro sur un écran Windows et Android dans la région appropriée.

Pour en savoir plus sur les écrans interactifs, consultez [Écrans interactifs.](../../../getting-started/apps-for-devices/07-interactive-displays.md)

Pour en savoir plus sur la résidence des données, consultez [Résidence des données chez Miro](../../canvas-25-admin-features/data-residency/02-data-residency-at-miro.md).

## Connecter le navigateur de l'écran interactif à une région

1. Ouvrez le navigateur de l'écran.
2. Accédez à l'URL suivante pour votre région :
   - (Par défaut) **Union Européenne**
     `https://miro.com/displays/?useAsAppDefaultOrigin`
   - **Australie**
     `https://au.miro.com/displays/?useAsAppDefaultOrigin`
   - **États-Unis**
     `https://us.miro.com/displays/?useAsAppDefaultOrigin`
3. Suivez les instructions à l'écran.

## Changer la région de l'application Miro sur un écran interactif Windows

1. Sur votre écran interactif Windows, ouvrez l'application Miro.
2. Sur votre clavier, appuyez sur la touche **ALT**.
   Un menu contextuel s'ouvre.
3. Sélectionnez **Aide** > **Appareil public** > **Public**.
   Miro passe en mode expérience d'écran interactif.
4. Sélectionnez **Aide** > **Appareil public** > **Région par défaut**.
5. Sélectionnez l'une des options suivantes :
   - (Par défaut) **Global**
     Se connecte à la région Union Européenne
   - **Australie**
     Se connecte à la région Australie
   - **États-Unis**
     Se connecte à la région États-Unis

## Changer la région de l'application Miro sur un écran interactif Android

1. Sur votre écran interactif Android, ouvrez l'application Miro.
2. Sur l'écran de lancement, touchez l'icône en forme d'engrenage dans le coin supérieur droit.
3. Touchez **Sélectionner la région**.
   La fenêtre modale **Sélectionner une autre région** s'ouvre.
4. Sélectionnez l'une des options suivantes :
   - (Par défaut) **Global**
     Se connecte à la région Union Européenne
   - **Australie**
     Se connecte à la région Australie
   - **États-Unis**
     Se connecte à la région États-Unis
