Les clients de Miro peuvent avoir besoin de [résidence des données](../../canvas-25-admin-features/data-residency/02-data-residency-at-miro.md) en dehors de leur région actuelle. En dehors de l'Union européenne (UE), Miro propose la résidence des données en Australie (AU) et aux États-Unis (US).

## Options pour déplacer les données entre régions

Le processus de déplacement de la résidence des données est appelé migration inter-régions. Pour migrer votre organisation vers une nouvelle région, Miro propose les voies suivantes :

- **Exportation et importation manuelles**
  Le service d’assistance Miro crée une nouvelle organisation dans la nouvelle région. L'admin d'entreprise reconfigure tous les paramètres de l'organisation et de l'équipe et réinvite les utilisateurs. Les utilisateurs finaux téléchargent manuellement leurs tableaux Miro depuis l'ancienne région et les chargent dans la nouvelle. Pour en savoir plus, consultez [Déplacer des données entre les régions – Exportation et importation manuelles](../../canvas-25-admin-features/data-residency/06-move-data-between-regions-–-manual-export-and-import.md).
- **Migration automatique des données**
  Disponible sous forme de service payant avec les services Miro. Automatise la migration de l'ensemble de l'organisation, y compris tout le contenu de l'organisation, la hiérarchie du contenu, les utilisateurs et les paramètres. Pour en savoir plus, consultez [Déplacer les données entre les régions – Migration automatisée](../../canvas-25-admin-features/data-residency/05-move-data-between-regions-–-automated-migration.md).
  > ✏️ La migration automatique des données n'est actuellement pas disponible pour les [entreprises en gestion des clés de chiffrement](../../canvas-25-admin-features/encryption-key-management/01-encryption-key-management-overview.md).

Pour décider quel chemin de migration est le plus adapté pour vous, contactez votre interlocuteur Miro dédié ou envoyez un e-mail à [support@miro.com](mailto:support@miro.com).

## Comparer les options pour déplacer des données entre les régions

Le tableau suivant compare vos options automatisées et manuelles pour déplacer des données entre les régions :

|  | Automatisé | Manuel |
| --- | --- | --- |
| Coût | Engagement payant avec les services de Miro. | Aucun coût supplémentaire. L(es) admin(s) d’entreprise et les utilisateurs finaux déplacent leur contenu de tableau d'une région à l'autre. |
| Portée | La majorité de l’organisation et de ses données est migrée, y compris les données suivantes. Pour une liste complète des données incluses, voir [l'article automatisé pour les admins].  - Données de l'organisation - Profils utilisateurs - Teams et paramètres de Team - Adhésion à l'équipe - Tableaux - Journaux d’audit - Classification des données - Paramètres de sécurité du contenu | Les admins doivent reconfigurer les paramètres de l’organisation, recréer les équipes et appliquer les paramètres d’équipe, réinviter les utilisateurs et attribuer des licences, et réinstaller les applications et intégrations. Les utilisateurs finaux doivent déplacer manuellement leurs tableaux vers la nouvelle région. |
| Durée | En général, moins de 8 heures de temps d'arrêt. L'organisation et ses données sont migrées vers la nouvelle région. | Varie en fonction de la rapidité avec laquelle l'admin d’entreprise effectue la configuration manuelle et les utilisateurs déplacent leurs tableaux. |
