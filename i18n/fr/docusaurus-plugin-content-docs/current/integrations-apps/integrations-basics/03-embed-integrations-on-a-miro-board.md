## Fonctionnalités principales

Le contenu intégré dans Miro comprend les principales caractéristiques suivantes :

- **UX unifiée et liens intelligents**
  Suivez les mêmes étapes pour intégrer toute intégration tierce.
- **Menu contextuel**
  Utilisez le sélecteur de ressources, ouvrez le mode de mise au point et passez à l'affichage des signets.
- **(Modèles intelligents) Raccourcis d'action**
  Créez des modèles avec des raccourcis qui récupèrent des données à partir d'un outil tiers.

## Comment intégrer du contenu de tiers dans Miro ?

La procédure suivante explique comment incorporer du contenu provenant d'une intégration tierce.

**Prérequis**

- Assurez-vous que votre admin d'entreprise ou de contenu, ou votre admin d'équipe, a autorisé la ou les intégration(s) tierce(s) que vous souhaitez utiliser.
- Assurez-vous d'avoir accès au contenu tiers que vous souhaitez intégrer.

Pour savoir comment les applications peuvent être activées par les administrateurs pour les utilisateurs de leur organisation, voir [Gestion des applications](../../enterprise-administration/managing-apps-on-enterprise-plan/02-app-management.md).

**Procédure**

Effectuez l’une des opérations suivantes :

- Copiez et collez une URL provenant d'[une intégration tierce](02-miro-apps-and-integrations-overview.md) sur le canevas Miro.
- Dans la barre de création, sélectionnez **Outils.** Recherchez et sélectionnez l'outil tiers pris en charge que vous souhaitez intégrer. Une fenêtre modale s'ouvre pour vous permettre de saisir l'URL d'un tiers.
- Dans la barre de création, sélectionnez **Outils.** Recherchez et sélectionnez **Charger**, puis **Charger via url**.
- Dans le tableau de bord, sélectionnez **+ Créer nouveau**, puis **Intégrer**.
- Sur le tableaudans la barre latérale des **Espaces**, sélectionnez **+,** puis **Embed**.

  Si Miro se connecte pour la première fois, suivez les instructions qui s'affichent à l'écran. Il se peut que vous deviez vous connecter à votre outil tiers ou demander l'accès au contenu que vous souhaitez intégrer.

  Vous avez réussi à intégrer du contenu tiers à votre tableau Miro.

## Menu contextuel iFrame pour les intégrations

Le menu contextuel iFrame apparaît au-dessus du widget d'intégration.

![figma.png](../../../../../../docs/integrations-apps/integrations-basics/images/26673893830418_figma.png)

*Le menu contextuel de l'iFrame.*

Le menu contextuel iFrame comprend les options suivantes :

- **Mode immersif**
  Concentrez votre attention avec l'iFrame en plein écran. Pour passer en mode de mise au point, sélectionnez la touche d'expansion. En mode Mise au point, pour quitter, sélectionnez **Aller au canevas**.
- **Affichage des signets**
  Réduire l'iFrame en un signet que vous pourrez développer ultérieurement. Pour accéder à l'affichage des signets, sélectionnez le bouton des points verticaux, puis sélectionnez **Basculer vers l'affichage des signets** dans le menu d'actions.
- **Sélectionneur d'actifs**
  Choisissez une autre ressource ou toutes les ressources à intégrer, comme un cadre Figma ou un graphique Power BI. Pour ouvrir le sélecteur de ressources, cliquez sur les points verticaux, puis sélectionnez **Extraire les ressources de la source** dans le menu d'actions. Le sélecteur d'actifs prend en charge les intégrations suivantes :
  - Cadres et sections Figma
  - Google Slides
  - Graphiques Looker
  - Onglets MS Excel
  - Diapositives MS Powerpoint
  - Pages MS Word
  - Graphiques Power BI

Le menu des paramètres de l'iFrame comprend également un bouton de points verticaux qui ouvre des options supplémentaires.

## Raccourcis d'action pour les intégrations sur les modèles intelligents

Les raccourcis d'action sont des boutons que vous créez pour déclencher des événements sur votre tableau. Vous pouvez définir un raccourci d'action qui lance immédiatement une intégration.

**En savoir plus :** Voir [Raccourcis d'action.](../../product-announcements/canvas-and-collaboration/101-action-shortcuts.md)
