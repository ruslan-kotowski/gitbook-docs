L'intégration de Linear dans Miro améliore la collaboration en permettant une synchronisation bidirectionnelle fluide entre les tableaux Miro et les tickets Linear. Importez, consultez et modifiez les tickets directement dans Miro, pour que vos workflows restent à jour et que les équipes demeurent alignées et productives.

> **Remarque :**Les administrateurs doivent autoriser l'intégration Linear pour leur équipe Miro. Les membres de l’équipe peuvent utiliser l’intégration uniquement après son installation au niveau de l’équipe.

## Prérequis

Avant de commencer à utiliser l'intégration Linear, assurez-vous d'avoir :

- Un compte Miro actif ([inscrivez-vous ici](https://miro.com/) si nécessaire)
- Un compte Linear actif
- L'approbation de l'administrateur si votre organisation limite l'installation d'applications

## Connecter Linear à Miro

Pour commencer avec l'intégration Linear, vous devrez connecter votre compte Linear à Miro. Ouvrez un tableau Miro et cliquez sur **Outils > Médias & Intégrations (+)** dans la barre de création. Recherchez **Linear** et cliquez sur **Connecter**.

Lors de l'authentification, vous pouvez choisir de :

- Utiliser vos identifiants (recommandé)
- Utiliser votre clé API ou votre jeton d'accès

Après avoir terminé le processus d’authentification, votre compte Linear commencera à se synchroniser avec Miro. Cette première synchronisation peut prendre plusieurs minutes à plusieurs heures pour les comptes de grande taille. Vous recevrez un e-mail lorsque la synchronisation sera terminée.

## Ajouter des tickets Linear à votre tableau

Une fois la connexion établie, vous pouvez commencer à ajouter des tickets Linear à vos tableaux Miro. Accédez au sélecteur de tickets Linear via **Outils > Médias & Intégrations (+)** et recherchez **Linear**. Le sélecteur vous permet de filtrer les tickets par État, Responsable et Projet avant de les importer en tant que Widgets de tickets Linear.

Notez que le sélecteur n'affiche que les tickets auxquels vous avez accès dans Linear.

## Travailler avec les tickets Linear

### Modifier les tickets dans Miro

Vous pouvez modifier les tickets Linear directement dans Miro. Cliquez sur n'importe quel widget de ticket Linear et utilisez l'icône du panneau latéral pour ouvrir les détails du ticket. À partir de là, vous pouvez modifier les propriétés et cliquer sur **Mettre à jour** pour synchroniser les changements avec Linear.

### Organisez votre workflow

Miro offre plusieurs outils pour vous aider à organiser efficacement vos tickets Linear :

Les outils [Table](../../using-miro/formats/14-tables.md), [Planning](../../using-miro/formats/15-timeline.md), [Colonnes](../../using-miro/advanced-tools/02-columns-formerly-kanban.md) et [User story map](../../using-miro/advanced-tools/07-user-story-mapping.md) offrent différentes manières de structurer votre workflow. Il vous suffit de glisser-déposer les tickets Linear dans ces outils pour les organiser en fonction de vos besoins.

Notez que bien que vous puissiez déplacer des tickets dans le widget Colonnes, cette action n'actualise pas automatiquement leur état dans Linear.

### Naviguer et personnaliser les tickets

L'intégration avec Linear offre plusieurs façons de travailler avec vos tickets :

Pour consulter les détails complets d'un ticket dans Linear, cliquez sur l'icône **Source** dans la vue détaillée ou le panneau latéral. Vous pouvez alterner entre le panneau latéral et les fenêtres modales à l'aide de l'icône **Changer la vue**, et utiliser l'icône **Couleur de remplissage** pour code couleur les tickets pour une meilleure organisation visuelle.

## Fonctionnalités supplémentaires

### Raccourcis d’action

L'intégration Linear prend en charge les [raccourcis d’action](../../using-miro/facilitation-tools/03-action-shortcuts-beta.md), vous permettant de rapidement :

Ouvrez le sélecteur de tickets Linear ou créez de nouveaux tickets Linear avec des raccourcis personnalisés.

## Désinstaller l’intégration

Vous pouvez supprimer l’intégration Linear au niveau de l’équipe ou de l’individu.

Pour supprimer au niveau de l’équipe :

1. Accédez à **Paramètres de l’équipe** > **Applications et intégrations**
2. Trouvez **Linear** et cliquez sur **Désinstaller pour l’équipe**

Pour supprimer au niveau individuel :

1. Allez dans **Applications et intégrations** dans vos paramètres
2. Trouvez **Linear** et cliquez sur **Désinstaller pour moi**

## Foire aux questions

### Qui peut utiliser l'intégration ?

L'intégration Linear est accessible aux utilisateurs autorisés dans votre équipe ou organisation Miro qui ont les permissions appropriées sur Linear.

### Qui peut voir les tickets Linear dans Miro ?

Tout utilisateur ayant accès au tableau (permissions de consultation, de commentaire ou de modification) peut voir les tickets Linear importés. Aucune autorisation Linear n'est requise pour consulter les tickets sur le tableau.

### Comment les permissions Linear fonctionnent-elles dans Miro ?

L'intégration respecte vos permissions Linear. Bien que vous puissiez uniquement rechercher, importer ou modifier des tickets en fonction de vos droits d'accès Linear, tous les tickets que vous importez sur un tableau Miro deviennent visibles pour tous les utilisateurs du tableau. Modifier ces tickets nécessite toujours les permissions adéquates de Linear.
