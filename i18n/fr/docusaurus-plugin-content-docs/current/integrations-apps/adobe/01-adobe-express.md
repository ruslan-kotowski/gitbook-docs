L'intégration d'Adobe Express vous permet de travailler en continu sur des images et des vidéos au sein d'Adobe Express sans quitter votre tableau Miro. Cela permet un workflow créatif plus fluide, gardant tous vos actifs et discussions de projet dans un espace collaboratif unique.

Offrez à votre équipe deux manières flexibles d'améliorer les visuels dans Miro grâce à Adobe Express :

- **Éditeur d'images rapide**
  Effectuez des modifications rapides telles que le recadrage, la suppression d'objets, les réglages d'image et des outils alimentés par l'IA sans quitter le tableau. La plupart des outils fonctionnent sans connexion à Adobe.
- **Expérience complète Adobe Express**
  Lancez l'espace de travail créatif complet à l'intérieur de Miro pour accéder aux modèles, kits de marque, conception multi-pages et outils vidéo. Idéal pour les équipes qui ont besoin de contenu éditable et conforme à la charte graphique.

Les deux options gardent les ressources connectées à votre tableau, facilitant la mise à jour des visuels, la cohérence et l'avancement du travail en un seul endroit.

## Fonctionnalités principales

Découvrez les capacités puissantes de l'intégration d'Adobe Express dans Miro :

- Lisez les vidéos Adobe Express directement sur votre tableau pour obtenir rapidement des avis et des retours.
- Accédez à une version allégée pour des modifications rapides d'images ou à la version complète d'Adobe Express directement depuis le canevas.
- Modifiez les images en mode immersif au sein d'Adobe Express, avec des changements qui se synchronisent instantanément avec Miro une fois enregistrés.
- Choisissez de mettre à jour les ressources existantes sur votre tableau ou d'enregistrer de nouvelles versions (lors de l'utilisation de la version complète) pour conserver le travail précédent.
- Gardez les plannings de projet, les directives de marque et les ressources créatives consolidés dans un espace partagé unique sur votre tableau Miro.

## Modifier des images avec la version allégée d'Adobe Express

Pour modifier les images déjà présentes sur votre tableau Miro à l'aide d'Adobe Express, suivez cette procédure :

1. Sélectionnez une image existante sur votre canevas Miro.
   Le menu contextuel de l'image apparaîtra.
2. Cliquez sur l'icône **Crayon** dans le menu contextuel.
3. La version légère d'Adobe Express se lancera.
4. Une fois vos modifications terminées, cliquez sur **Enregistrer**.
   Une boîte de dialogue de confirmation avec les options d'image s'ouvrira.
5. Sélectionnez le **Format de fichier** dans le menu déroulant et cliquez sur **Enregistrer** pour synchroniser instantanément les modifications avec votre tableau Miro.

La même procédure s'applique lors de la modification d'images initialement ajoutées à votre canevas depuis Adobe Express.

## Accédez à l'intégration complète d'Adobe Express

Vous pouvez facilement accéder à l'intégration complète d'Adobe Express directement depuis votre barre d'outils de création Miro. Voici comment procéder :

1. Cliquez sur l'icône **Outils, médias et intégrations** (![Tools, Media and Integrations icon](../../../../../../docs/integrations-apps/adobe/images/24271064782354_icon-tools.svg)) sur la barre d'outils de création.
   Le panneau Outils, médias et intégrations s'ouvre.
2. Dans le panneau, recherchez **Adobe Express**.
3. Cliquez sur le résultat de recherche Adobe Express.
   L'intégration Adobe Express s'ouvrira directement sur votre canevas Miro.
4. Apportez des modifications et choisissez entre **Sauvegarder comme nouveau** ou **Sauvegarder et remplacer**.
5. Une fois les projets ajoutés au tableau, vous pouvez y accéder à nouveau via l'**icône crayon** ou l'**icône Adobe Express** dans le menu contextuel.

:::tip
Vous pouvez savoir si une image sur le canevas a été créée à l'origine dans Adobe Express quand l'icône Adobe Express apparaît dans le menu contextuel.
:::

## Modifier des vidéos avec Adobe Express

Vous pouvez également modifier des fichiers vidéo provenant d'Adobe Express sur votre tableau à l'aide de l'intégration Adobe Express. Voici comment :

1. Sélectionnez un actif vidéo Adobe Express existant sur votre canevas Miro.
   Le menu contextuel pour la vidéo apparaîtra.
2. Cliquez sur l’icône **Crayon** dans le menu contextuel.
3. Choisissez l'une des options disponibles pour modifier la vidéo avec Adobe Express.

## Collaborer sur des projets Adobe Express

Découvrez comment inviter d'autres personnes à collaborer sur vos projets Adobe Express directement via l'intégration Miro :

1. Ouvrez le projet Adobe Express depuis votre tableau Miro.
2. Dans l'interface d'édition d'Adobe Express, cliquez sur l'option **Inviter**.
3. Un lien partageable pour votre projet sera généré.
4. Partagez ce lien avec vos collaborateurs.

   > ✏️ Seule la personne qui a initié la session collaborative peut enregistrer les modifications sur le tableau Miro.

:::warning
Lorsqu'une personne commence à modifier un élément Adobe Express sur votre tableau Miro, cet élément se verrouille automatiquement pour éviter les modifications simultanées. Cependant, si un utilisateur modifie le projet directement dans Adobe Express (hors de Miro) tandis qu'une autre personne l'édite via l'intégration Miro, la dernière personne à enregistrer ses modifications annulera toutes les modifications précédentes.
:::

## FAQs

**Ai-je besoin d'un compte Adobe Express pour utiliser la fonctionnalité ?**

Aucun compte n'est requis pour des modifications d'image basiques comme le recadrage, le redimensionnement ou les ajustements de luminosité et de contraste. Une connexion Adobe Express est nécessaire uniquement pour accéder aux outils d'IA générative ou à l'expérience complète d'Express.

**Comment saurai-je si une image ou une vidéo est déjà liée à un projet Adobe Express ?**

Lorsque vous sélectionnez l'image ou la vidéo sur votre tableau Miro, vous verrez le logo Adobe Express dans le menu contextuel si elle est liée.

**Que verront les autres personnes sans accès à la modification ?**

Les utilisateurs qui n'ont pas accès à la modification du tableau verront vos images et vidéos comme ils le feraient pour tout autre élément. Cependant, l'option de modification de ces éléments avec Adobe Express ne leur sera pas disponible.

**Pourquoi les titres de mes ressources Adobe Express n'apparaissent-ils pas dans Miro ?**

Les titres donnés aux images ou vidéos dans Adobe Express ne sont pas automatiquement transférés vers Miro. Une fois placés sur le tableau Miro, ils apparaîtront comme « Ressource sans titre », mais vous pouvez les renommer directement sur le tableau.

**Pourquoi ma vidéo ne s'enregistre-t-elle pas sur Miro depuis Adobe Express ?**

Pour fonctionner correctement dans Miro, les vidéos doivent être inférieures à 30 Mo. Si votre vidéo dépasse cette limite, Miro affichera un message d'erreur et n'enregistrera pas la vidéo sur votre tableau. Cependant, toutes les modifications apportées à votre vidéo seront toujours enregistrées dans Adobe Express, même si la vidéo est trop volumineuse pour Miro.

**Puis-je activer Adobe Express uniquement pour certaines équipes ?**

Pas pour l'instant. Adobe Express est préconfiguré pour tous les utilisateurs de Miro.

**Comment fonctionne l'intégration ?**

Cette intégration fonctionne comme une intégration iFrame. Cela signifie que l'intégration fournit simplement un composant visuel du site web externe à l'intérieur de Miro, sans aucun partage de données entre Miro et le site web externe. L'authentification est gérée par le site web lui-même.
