L’application Miro pour Zoom permet aux équipes de créer une salle de réunion numérique tout-en-un et de collaborer efficacement pendant les réunions et les ateliers.  L’application assure les capacités de collaboration de Miro dans Zoom. Pour les personnes arrivant tout juste sur Miro, nous proposons un tableau blanc avec un accès sans inscription.

Dès que vous aurez installé l’application dans Zoom, vous pourrez commencer à partager des tableaux Miro lors de vos réunions Zoom et à en créer de nouveaux directement dans Zoom.

Miro_app_for_Zoom_.jpg
L’application Miro pour Zoom permet de travailler sur des tableaux Miro avec les personnes participant aux réunions sur Zoom.

:::note
Consultez [le guide pour responsable de l’application Miro pour Zoom](01-miro-app-for-zoom-admin-guide.md) (article disponible uniquement en anglais) pour voir comment les responsables Zoom et Miro peuvent activer l’expérience pour leurs utilisateurs.
:::

> **Disponible pour :** tous les plans Miro, tous les plans Zoom
> *Pour les plans Zoom Business et Enterprise, l'admin peut avoir besoin de pré-approuver l'application Miro.
> **Disponible sur**: version de bureau

## Comment installer l’application

Les utilisateurs peuvent trouver l’application Miro pour Zoom sur [la page d’accueil Zoom de Miro](https://miro.com/works-with-zoom/) ou sur le [Marketplace](http://miro.com/marketplace/zoom-app) de Miro (disponibles uniquement en anglais).

**À noter** : * pour les plans Business et Enterprise de Zoom, un admin peut avoir besoin de pré-approuver l’utilisation de l’application Miro dans votre organisation.

Cliquez sur le bouton **Request pre-approve** (Demande de pré-approbation) pour faire la demande d’accès à l’administrateur Zoom de votre entreprise.

request_pre-aprove.jpg
/span>Demande de pré-approbation pour l’application Miro

Une fois l'application approuvée, les utilisateurs peuvent autoriser l’application Miro pour Zoom lors de l’installation.

Miro_access_request.jpg
/span>Permettre à Miro d’accéder à votre compte Zoom



## Comment utiliser l’application Miro dans le client de bureau de Zoom

Une fois l'autorisation obtenue, l'application vous redirige vers votre application de bureau Zoom et affiche l'application Miro nouvellement installée. Notez que vous devez avoir le [client de bureau](https://zoom.us/download) **[Zoom](https://zoom.us/download) (Version : 5.7.3 ou supérieur)** installé et être connecté à votre compte Zoom pour ajouter l'application.

### Créer un tableau sans profil Miro

Nous proposons aux utilisateurs de Zoom qui découvrent Miro la possibilité d’essayer un tableau blanc en ligne simple et gratuit sans inscription en créant un tableau Miro. Cette expérience est une version plus simple et plus légère de Miro, parfaite pour une idéation et une collaboration immédiates. Ces tableaux sont disponibles pendant 24 heures. Si vous souhaitez continuer à les utiliser par la suite, il suffit de vous connecter ou de vous inscrire à Miro pour sauvegarder votre travail.

/span>Tableaux sans inscription dans Zoom

### Connexion pour accéder à votre profil Miro

Les utilisateurs existants de Miro doivent **se connecter** pour voir leurs tableaux. Cela les redirigera vers leur navigateur pour qu’ils se connectent à Miro ou autorisent directement l’application dans Miro. Vous pouvez choisir d’installer l’application pour n’importe quelle équipe.

Vous redirection automatique vous renverra vers l’application de bureau Zoom où vous verrez un sélecteur contenant vos tableaux.

## Comment utiliser l’application lors des réunions

### Utiliser un tableau pendant une réunion

Les utilisateurs de Miro peuvent profiter de l’expérience complète dans Zoom. Après s’être connectées et avoir connecté Miro à Zoom, les personnes participantes peuvent créer un tableau ou /span>en choisir un existant.

Miro_app_for_Zoom_.jpg
/span>Choix d’un tableau pour l’ouvrir dans Zoom

### Définir les paramètres d’accès au tableau

Définissez les autorisations appropriées pour le partage de ce tableau dans Zoom. Vous pouvez choisir parmi quatre options :

- Anyone in Zoom can edit (Les personnes participant à la réunion Zoom peuvent modifier).
- Anyone in the Zoom meeting can comment (Les personnes participant à la réunion Zoom peuvent uniquement commenter) (à noter que cette option n’est pas disponible si vous partagez un tableau depuis une [équipe gratuite](../../plans-billing/miro-plans/09-free-plan.md) - article disponible uniquement en anglais).
- Anyone in the Zoom meeting can view only (Les personnes participant à la réunion Zoom peuvent uniquement visualiser le tableau).
- Private, Request access (Privé, accès sur demande) (cela signifie que les paramètres de partage seront les mêmes que sur Miro).
  > ✏️ En choisissant le paramètre d’accès Anyone can edit/comment/view (Tout le monde peut modifier/commenter/visualiser), vous partagez gratuitement le tableau avec les personnes participant à la réunion Zoom.

  > ✏️ Si vous sélectionnez Private (Privé) dans ce flux, mais que le tableau est [rendu public sur Miro](../../using-miro/sharing-boards/03-sharing-boards-and-inviting-collaborators.md#partage-de-tableaux-via-un-lien-public), il sera rendu également public par défaut dans Zoom. Toutefois, le niveau d’accès que vous avez défini pour le tableau intégré sur Zoom n’affecte pas les paramètres de partage du tableau sur Miro. [En savoir plus](../integrate-miro-with-other-apps/01-user-permissions-for-boards-embedded-in-third-party-apps.md).

access_settings_for_board_in_Zoom.jpg
Configuration des paramètres d’accès pour votre tableau

> ️✏️ Pour les utilisateurs Miro [du plan Enterprise](../../enterprise-administration/user-management/05-manage-user-invitations-on-enterprise-plan.md), vos paramètres d’accès suivront les contrôles d’accès à l’échelle de l’entreprise, il est donc possible que vous ne puissiez partager le tableau que selon les paramètres du tableau uniquement. En savoir plus : Gestion de la politique de partage de l’entreprise pour les intégrations embarquées.

/span>L’option d’intégration des tableaux peut être limitée par les responsables d’entreprise dans le cadre du forfait Enterprise.

Si vous devez modifier les droits d’accès d’un tableau intégré, supprimez-le en cliquant sur l’icône en forme de croix (x) dans l’onglet du tableau et réintroduisez-le avec un niveau d’accès différent.  Lorsque vous cliquez sur x, vous reviendrez à l’écran **Choisir un tableau**.

![miro_for_zoom_remove_board.png](../../../../../../docs/integrations-apps/zoom/images/21017317928210_miro_for_zoom_remove_board.png)*Supprimez un tableau et réajoutez-le en cliquant sur **x dans l'** onglet du tableau.*

### Partager des tableaux et collaborer sur des tableaux avec les personnes participant à la réunion

Utilisez les contrôles de l’application Zoom pour partager le tableau ou collaborer dessus avec les personnes participantes :

- **Share screen** (Partager l’écran) - fonctionne comme l’écran de partage standard et vous permet de partager la fenêtre dans laquelle se trouve votre tableau Miro. Recommandé lorsque vous souhaitez uniquement partager du contenu, mais sans autoriser l’accès au tableau.
- **Send** (Envoyer) - vous permet de partager le tableau avec les personnes participantes pour qu’elles accèdent au tableau et collaborent sur celui-ci dans Zoom. Chaque destinataire devra installer l’application et pourrait avoir besoin de se connecter pour collaborer sur le tableau.
- **Expand** (Étendre) - vous permet d’étendre le tableau Miro sur l’écran principal de la réunion afin de pouvoir collaborer sur le tableau tout en gardant les personnes participantes dans le champ de vision.
- **Collapse** (Réduire) - ramène l’application Zoom à un panneau latéral plus petit.

/span>Utilisez les contrôles de l’application Zoom pour partager ou collaborer avec les personnes participantes selon vos besoins.

### Comment cela fonctionne pour les personnes participant à votre réunion

Après que vous avez cliqué sur **Invite** (Inviter) et spécifié le groupe d’utilisateurs à notifier, les personnes participant à la réunion recevront une notification les invitant à consulter le tableau.

**Cliquez sur Invite (Inviter) pour inviter les personnes participant à la réunion sur votre tableau Miro.**

Les personnes participantes seront invitées à installer l’application et pourraient avoir besoin de se connecter pour collaborer sur le tableau (en fonction des paramètres d’accès que vous avez configurés pour le tableau intégré).

Vous pouvez basculer entre plusieurs tableaux pendant votre réunion à l’aide du menu en haut à gauche de la fenêtre de l’application Miro.

:::note
Seul le tableau actif lors de l’envoi est disponible pour les autres personnes participantes.
:::

### Accéder à l’application Miro avant ou après une réunion

Vous pouvez également accéder à l’application Miro depuis le client Zoom en dehors des réunions. Cliquez sur l’icône **Apps** (Applications) depuis l’écran d’accueil de votre Zoom et sélectionnez Miro. Vous pouvez sélectionner les tableaux à partir de l’application.

Miro_in_Zoom_apps.jpg
/span>Miro dans les applications Zoom

:::note
Tous les tableaux ouverts en dehors de la réunion dans le client principal seront automatiquement disponibles dans l’application Miro pour Zoom s’ils sont ouverts lors d’une réunion.
:::

## Comment désinstaller l’application

### Désinstaller dans Zoom

1. Connectez-vous à votre compte Zoom et naviguez vers **Solutions** > Zoom App **Marketplace**.
   Zoom_marketplace.jpg
   *Ouverture de Zoom Marketplace*
2. Cliquez **sur Manage (Gérer) > Installed Apps (Applications installées)** ou recherchez l’application Miro.
3. Cliquez sur **Désinstaller**.
   uninstall_Miro_app_for_Zoom.jpg
   *L'option de désinstallation de l'application Miro Zoom dans Zoom*

### Désinstaller dans Miro

1. Connectez-vous à Miro et rendez-vous sur les [Team settings](../../administration/get-started-as-a-miro-admin/01-i-am-a-new-miro-admin.-where-to-start.md) (Paramètres de l’équipe).
2. Allez dans **Apps & Integrations** (Applications & Intégrations).
3. Recherchez l’application Miro pour Zoom.
4. Désinstallez l'application pour vous ou pour toute l'équipe.
   uninstall_in_Miro.jpg
   *L'option de désinstallation de l'application Miro Zoom dans Miro*

## Restrictions

Les fonctionnalités suivantes ne sont actuellement pas prises en charge sur les tableaux Miro dans Zoom :

- Téléchargement de contenu dans l’application Zoom
- Applications tierces sur le Marketplace (par ex. Clusterizer)
- Applications privées créées uniquement pour votre équipe
- Intégration du contenu externe (prototypes iframed à partir d’autres outils)

:::note
Ces fonctionnalités ne sont pas prises en charge en raison des exigences de sécurité de Zoom.
:::

## Problèmes éventuels et comment les résoudre

1. *Lorsque j’essaie d’utiliser l’application, je reçois le message d’erreur «* *Unable to get Miro access token.*  Zoom user not found".
   - Essayez de désinstaller l'application Zoom et d'installer la dernière version du client Zoom Desktop à partir d'[ici.](https://zoom.us/download)

   /span>
2. *Lorsque je clique sur la section des applications dans Zoom, une redirection automatique ouvre Miro dans un navigateur.* Je me connecte pour sélectionner une équipe Miro./em> Lorsque je clique sur le bouton d'installation, le lien me dirige vers une page vide avec le message d'erreur "This link is invalid".
   - Assurez-vous que vous êtes connecté à votre client Zoom Desktop et au navigateur sous la même adresse e-mail.
3. *J'essaie de mettre en place l'intégration Miro-Zoom mais j'obtiens l'erreur "Miro sera bientôt de retour" pendant le processus d'inscription pour choisir le tableau Miro.*
   - Essayez de vous déconnecter de Zoom dans le navigateur et dans l'application Zoom, connectez-vous et configurez à nouveau le plugin. Si cela ne résout pas le problème, consultez la page d’état de Miro/span> (disponible uniquement en anglais) pour voir s’il y a des problèmes de performance connus./span>
