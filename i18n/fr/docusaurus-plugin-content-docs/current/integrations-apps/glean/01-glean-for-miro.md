Fonctionnalités principales

L'intégration Glean vise à intégrer les connaissances d'entreprise et publiques directement dans les workflows Miro, en améliorant le processus d'innovation grâce à un accès rapide et efficace aux insights pertinents.

- **Interface basée sur le chat :** Interagissez avec Glean dans une interface de chat conversationnelle, vous permettant de peaufiner les réponses et d'affiner les résultats.
- **Résumés d'insights :** Créez des résumés d'insights pertinents pour votre travail d'un simple clic, améliorant la productivité et la prise de décision.
- **Navigation des sources :** Consultez facilement les sources utilisées pour générer des informations et naviguez directement vers les données originales depuis Miro. Vous pouvez également voir et copier les liens vers les sources, et les faire glisser-déposer sur le canevas.

## Utiliser l'intégration Glean

Une fois l'intégration configurée par votre administrateur, vous pouvez commencer à utiliser Glean dans vos tableaux Miro.

1. Dans la barre de création, sélectionnez **Outils, médias et intégrations** (**+**).
2. Recherchez **Glean**.
3. Si c'est votre première utilisation de l'application, sélectionnez **Connecter Glean** pour initier l'autorisation.
   Vous serez redirigé vers une fenêtre de dialogue avec votre authentification unique (SSO).
4. Utilisez l'interface basée sur le chat pour poser des questions et trouver des informations à partir de vos applications professionnelles connectées.
   - Affinez les réponses de Glean en modifiant les prompts pour garantir que le contenu généré réponde à vos besoins spécifiques.
   - Accédez directement aux sources depuis l'interface basée sur le chat ou glissez-déposez-les directement sur le canevas.
5. Convertissez la réponse de Glean en un [document Miro](../../using-miro/formats/12-docs-in-miro.md) directement sur votre tableau. Sinon, sélectionnez **Créer avec Miro IA** pour générer [des pense-bêtes](../../using-miro/essential-tools/14-sticky-notes.md) ou un [diagramme](../../using-miro/formats/diagramming/02-miro-diagrams.md).

\{1>Restrictions<1\}

- Nous vous encourageons à fournir des retours pour améliorer l'intégration via les mécanismes de feedback de l'application.
- Si votre organisation utilise des applications personnalisées, vous pouvez utiliser la [plateforme de développement de Miro](https://developers.miro.com/) pour lier Miro à votre propre Modèle de Langue de Grande Taille (LLM).
