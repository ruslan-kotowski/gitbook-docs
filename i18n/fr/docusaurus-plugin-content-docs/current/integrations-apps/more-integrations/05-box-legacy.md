L'intégration avec Box vous permet d'utiliser les fichiers de votre compte Box et de les ajouter aux tableaux Miro pour continuer la discussion et la collaboration. Vous pouvez mener des discussions sur le tableau, inscrire les commentaires sur vos images et documents, mentionner des personnes et itérer plus rapidement.

> **Disponible pour :** tous les utilisateurs avec un compte Box Personal & Enterprise
> **Disponible sur** : version navigateur, [application de bureau](../../getting-started/apps-for-devices/05-desktop-app.md)

### Installation du plugin

Pour commencer à utiliser le plugin, vous devez installer le plugin au niveau de l’équipe et connecter votre compte Box à Miro. Le plugin peut être installé depuis le Marketplace ou depuis un tableau Miro.

:::warning
Les utilisateurs non administrateurs ne peuvent pas installer l'application si cela n'est pas autorisé dans les paramètres **Apps & Integrations**.
:::

Rendez-vous sur [Miro Marketplace](https://miro.com/marketplace/box/?backUrl=%2Fmarketplace%2F) et cliquez sur **Get App** (Obtenir l’application). Il vous sera suggéré de choisir une équipe pour laquelle installer l’application. Sélectionnez une équipe pour terminer l’installation.

![installer_plugin_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591350930_install%20Box%20plugin.jpg)
*Choix d’une équipe pour le plugin Box*

Pour installer l'application à partir d'un tableau :

1. Dans la barre de création, sélectionnez **Outils, médias et intégrations** (**+**). **Le panneau **Outils, médias et intégrations** s’ouvre.**
2. Dans l’onglet **Outils**, recherchez **Téléchargements**.
3. Dans le panneau **Téléversements**, sélectionnez **Boîte**.

![uploads-entry-point.png](../../../../../../docs/integrations-apps/more-integrations/images/21537452824210_uploads-entry-point.png)
*L'icône Box dans la barre d'outils*

Cliquez sur **Get app** dans la fenêtre contextuelle et le plugin sera installé pour l’équipe.

Pour connecter votre compte Box à Miro, choisissez **Box** dans le menu **Upload** (Téléchargement). S’il s’agit de la première fois que vous utilisez Box avec Miro, vous verrez un menu contextuel vous demandant d’autoriser votre compte Box.

![autoriser_box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591352338_authorize%20box.jpg)
*Fenêtre d’authentification de Box*

Vous pouvez également connecter ou déconnecter un compte Box depuis la [page Intégrations](https://miro.com/app/account/profile/integrations/) de votre profil.

![connect_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591356946_connect%20Box.jpg)
*Connexion de Box à Miro*

### Ajouter des fichiers

Pour ajouter des fichiers au tableau, ouvrez le menu **Upload** dans la barre d’outils, cliquez sur **Box**, sélectionnez des documents ou des images depuis votre compte Box, et cliquez sur **Choose**.

![ajouter_des_fichiers_depuis_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019535297298_adding%20files%20from%20Box.jpg)
*Ajouter des fichiers de Box aux tableaux Miro*

Pour actualiser vos fichiers sur le tableau, cliquez sur le bouton **Update** d’un fichier.

![mettre_à_jour_un_fichier_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019535299218_update%20a%20Box%20file.jpg)
*Actualisation des fichiers Box importés dans les tableaux Miro*

### Désactiver le plugin

Si vous souhaitez désinstaller le plugin pour une équipe, accédez à Paramètres de l’équipe, trouvez Box dans la section **Applications et intégrations** et cliquez sur **Désinstaller pour l’équipe**.

![uninstall_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591362962_uninstall%20Box.jpg)
*Désinstallation de Box dans les paramètres d’équipe*

Pour déconnecter votre compte Box, rendez-vous sur la [page Intégrations](https://miro.com/app/account/profile/integrations/) du profil et cliquez sur **Se déconnecter**.

![deconnecter_Boite.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591364498_disconnect%20Box.jpg)
*Déconnecter Box de Miro*
