L’application Miro pour Webex permet aux équipes de créer, de cocréer et de se connecter, le tout au sein d’une expérience fluide.  L’intégration conjugue le tableau blanc infini de Miro avec Webex pour une expérience de collaboration optimale en réunion. Cette expérience est disponible pour tous les utilisateurs de Webex à travaers Webex Messaging et Webex Meetings.

- Miro pour Webex Meetings Ouvrez de nouveaux tableaux Miro ou des tableaux existants pendant les réunions Webex pour cocréer, faire du brainstorming et collaborer avec votre équipe en temps réel.
- Miro pour Webex Messaging Ajoutez des tableaux Miro collaboratifs en direct sous forme d'onglets dans les espaces d'équipe Webex pour saisir des idées avec votre équipe sans passer d'une application à l'autre. Accédez aux tableaux existants ou en créez des nouveaux pour vous et votre équipe Webex avec les bons paramètres d’accès. Les utilisateurs non inscrits ou non connectés peuvent collaborer facilement en tant que visiteurs dans Miro, dans l’onglet Webex.

> **Disponible pour :** les utilisateurs de tous les plans Miro et les utilisateurs non-Miro ; disponible par défaut pour tous les plans et utilisateurs Webex, sauf si les applications Webex sont désactivées par l’admin

### Utilisation de l’intégration

**Contrôles de l’administrateur**

Les utilisateurs de Webex auront automatiquement accès à Miro dans l’espace de réunion Webex Meeting sans avoir besoin de pré-approbation. *L’accès à l’application Miro peut être désactivé à l’aide des commandes d’admin Webex.*

**Expérience visiteur**

Si une personne de votre équipe ne dispose pas de profil Miro, elle peut toujours collaborer sur le tableau Miro en tant que visiteur. Pour ce faire, vous pouvez choisir parmi les droits de modification, de commentaire ou de consultation avant d’ouvrir le tableau dans votre réunion Webex.

**Expérience de collaboration**

- Lorsqu’un tableau Miro est ajouté à une réunion Webex Meeting en cours et que l’organisateur ou l’organisatrice de la réunion a cliqué sur **Open together** (Ouvrir ensemble), toutes les personnes participantes auront la possibilité de lire et de modifier le tableau Miro.
- Si l’organisateur ou l’’organisatrice de la réunion clique sur **Stop session (Arrêter la séance)**, toutes les personnes participantes perdront l’accès au tableau.

**Collaboration avec des organisations externes**

- Si l’admin de votre organisation a activé l’application Miro et que vous travaillez dans Webex avec une autre organisation qui n’a pas activé les applications, l’organisation externe tout de même voir le contenu de Miro et participer dans Miro.
- Si votre administrateur d’organisation n’a pas activé l’application Miro, l’organisation externe ne pourra pas accéder à Miro dans Webex

### Comment désactiver Miro dans Webex Meetings

Par défaut, les utilisateurs de Webex auront accès à Miro en tant qu’application intégrée. Si vous ne souhaitez pas que les utilisateurs aient accès à Miro dans Webex Meetings, vous pouvez le désactiver dans le panneau d’administration. N’oubliez pas que la désactivation des applications intégrées désactivera Miro et toutes les autres applications intégrées pour votre organisation.

1. Du point de vue du client sur [https://admin.webex.com](https://admin.webex.com/), allez sur **Apps** (Applications).
2. Sous **Embedded Apps (Applications intégrées)**, cliquez sur l’interrupteur à bascule pour désactiver toutes les applications. Cela supprimera l’accès des applications intégrées pour toutes les applications (y compris Miro) et cela pour tous les utilisateurs de votre organisation.

## Miro pour Webex Messaging

### Ajouter Miro à Webex Messaging

En savoir plus sur les options de paramétrage de l’onglet Miro sur le [Centre d’assistance Webex.](https://help.webex.com/n83vamf/Webex-Miro-Integration-for-Webex)

#### Instructions d’utilisation

1. Dans Webex, allez sur **Messaging** (Messagerie) et choisissez un espace individuel ou de groupe.
2. En haut de l'espace, cliquez sur l'onglet **+Applications**. Dans la fenêtre **Ajouter une application**, cliquez sur **Miro**, puis sur **Continuer.**
3. Connectez-vous à Miro ou créez un nouveau profil.
4. Sélectionnez le tableau que vous souhaitez ajouter à l’espace de messagerie Webex - ou créez un nouveau tableau.
5. Sélectionnez les autorisations que vous souhaitez accorder aux membres votre équipe.
6. Votre tableau Miro fait maintenant partie de l’espace de messagerie Webex.

**Contrôles de l’administrateur**

Les utilisateurs de Webex auront automatiquement accès au Webex App Hub dans l’application Webex pour ajouter Miro à leur espace d’équipe Webex.  L’accès à l’application Miro peut être désactivé à l’aide des commandes d’admin Webex./span>

### Utilisation de l’intégration

**Expérience de connexion**

Les utilisateurs de Miro peuvent profiter de l’expérience complète dans Webex.  Après s’être connectés et avoir connecté Miro à Webex, les membres de l’équipe peuvent créer un nouveau tableau ou en choisir un existant.

Définissez les paramètres d’accès appropriés pour votre tableau Miro depuis Webex.  Vous pouvez choisir parmi quatre options : N'importe qui dans Webex peut modifier/commenter/visualiser ou Privé (ce qui signifie que les paramètres de partage seront les mêmes que du côté de Miro).

**Expérience de collaboration**

Lorsqu’un tableau Miro est ajouté en tant qu’onglet dans votre espace d’équipe Webex et que les paramètres d’accès sont configurés, tous les membres de l’équipe dans l’espace Webex pourront interagir avec le tableau Miro.

Pour collaborer en tant qu’utilisateur enregistré, les membres de l’équipe peuvent se connecter à Miro ou créer un profil Miro.  Ou encore, les membres de votre espace Webex peuvent collaborer en tant que visiteurs/span> [sur un tableau.](../../using-miro/sharing-boards/08-collaboration-with-visitors.md)

### Comment désactiver Miro dans Webex Messaging

Par défaut, les membres peuvent ajouter des onglets et des applications aux tableaux Miro. En savoir plus sur Webex Tab controls (Contrôles de l’onglet Webex). Si vous ne souhaitez pas que les utilisateurs aient accès au Web par le biais du navigateur intégré dans Webex Messaging, vous pouvez désactiver l’option dans le Control Hub (Panneau de contrôle).

1. Du point de vue du client sur [https://admin.webex.com](https://admin.webex.com/), allez sur **Apps** (Applications).
2. Dans **Tabs** (Onglets), désactivez l’interrupteur à bascule.

:::note
En désactivant l’interrupteur à bascule, vous ne faites que retirer les applications de la vue. Si vous l’allumez à nouveau plus tard, toutes les applications et tous les onglets qui avaient déjà été ajoutés aux espaces sont restaurés.
:::

## Foire aux questions

**Puis-je utiliser Miro dans des séances Webex Meeting Breakout ?**

Non, ce n’est pas pris en charge pour le moment.

**Puis-je utiliser l’intégration Webex sur tablette ou mobile ?**

L’intégration Webex ne fonctionne pas actuellement sur les tablettes ni les mobiles.
