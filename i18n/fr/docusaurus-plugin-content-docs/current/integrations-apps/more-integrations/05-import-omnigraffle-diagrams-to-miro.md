Importez facilement vos diagrammes depuis OmniGraffle vers Miro et commencez à collaborer dans un outil unifié. Comme OmniGraffle et Miro utilisent des modèles d'objets et des systèmes de style différents, les tableaux importés peuvent ne pas ressembler exactement aux fichiers d'origine. Vous devrez peut-être réviser et ajuster le formatage après l'importation. Pour plus d'informations, consultez les sections [Comprendre la cartographie des objets OmniGraffle dans Miro](#h_omni_mapping) et [Limites connues](#h_omni_known_limitations).

## Avant de commencer

- Assurez-vous que vous pouvez créer des tableaux dans Miro.
- Utilisez OmniGraffle 7.25.1 (septembre 2025) ou une version ultérieure. Pour vérifier votre version, allez dans **OmniGraffle > À propos d’OmniGraffle**.
- Vérifiez le contenu caché et les calques avant l'importation. Les éléments cachés et superposés sont également importés et apparaîtront sur le tableau. Si les éléments se chevauchent, réorganisez-les après l'importation.
- Convertissez les remplissages en dégradé en couleurs unies avant l'exportation. Les dégradés ne sont pas pris en charge.

## Importer un fichier OmniGraffle dans un tableau Miro

1. Ouvrez OmniGraffle, exportez le diagramme au format
   **.graffle Single File (Zipped)** et enregistrez le fichier
   sur votre appareil.

   **Remarque :** Nous prenons en charge uniquement le format
   **Single File (Zipped)**. Les formats
   **Package** et **Legacy** ne sont pas pris en charge. Si vous avez
   un fichier exporté non pris en charge enregistré précédemment, vous pouvez ouvrir ce fichier dans
   OmniGraffle, puis exporter au format **.graffle Single File (Zipped)**.
2. Ouvrez le tableau Miro où vous souhaitez ajouter le diagramme.
3. Faites glisser et déposez le fichier au format **.graffle Single File (Zipped)** format
   sur le tableau Miro.

## Importation en masse de plusieurs fichiers OmniGraffle dans le tableau de bord Miro

1. Ouvrez votre tableau de bord Miro.
2. Cliquez sur **+ Créer nouveau** dans le coin supérieur droit.
3. Cliquez sur **Importer** > **Importer depuis OmniGraffle**.
4. Dans la boîte de dialogue d'importation, sous **Importer vers**, sélectionnez l'espace où vous souhaitez créer les tableaux Miro pour vos fichiers OmniGraffle importés.
5. Déposez vos fichiers **.graffle** dans la zone de chargement, ou cliquez sur **parcourir** pour sélectionner des fichiers depuis votre ordinateur.

   **Note :** Nous ne prenons en charge que le format **Single File (Zipped)**. Les formats **Package** et **Legacy** ne sont pas pris en charge. Si vous avez enregistré un fichier exporté non pris en charge précédemment, vous pouvez ouvrir le fichier dans OmniGraffle, puis l'exporter au format **.graffle Single File (Zipped)**.
6. Cliquez sur **Importer [X] fichiers**, où **[X]** est le nombre réel de fichiers que vous importez.
7. Lorsque vous voyez le message **Nous importons vos tableaux**, cliquez sur **Retour au tableau de bord**.

### Après avoir démarré l'import

- L'importation se fait en arrière-plan.
- De nouveaux tableaux apparaissent dans l’Espace que vous avez sélectionné lors du processus d'importation une fois le traitement terminé.
- Vous recevrez une notification par e-mail une fois les tableaux créés, incluant un lien direct vers l’Espace afin que vous puissiez y accéder rapidement.

## Vérifiez le contenu importé

Après la fin de l'importation, vérifiez les éléments suivants :

- Le nombre de tableaux attendus a été créé.
- Le contenu est lisible et correctement positionné.
- Les connecteurs sont attachés correctement.
- Le formatage du texte apparaît comme prévu.
- Les sections visuelles clés sont intactes.

Pour les diagrammes qui évolueront avec le temps, envisagez de reconstruire les zones très complexes à l'aide d'objets natifs de Miro pour une meilleure éditabilité à long terme.

## Foire aux questions (FAQ)

Puis-je importer plusieurs fichiers à la fois ?

Oui. Vous pouvez importer plusieurs fichiers au format **.graffle Single File (Zipped)** à la fois. Pour plus d'informations, consultez [Importer en masse plusieurs fichiers OmniGraffle vers le tableau de bord de Miro](#h_omni_bulk_import).

Où se trouvent les tableaux de mon importation en masse ?

Les tableaux de votre importation en masse sont créés dans l'espace que vous avez sélectionné lors du [processus d'importation](#h_omni_bulk_import). Vous pouvez également cliquer sur le lien dans la notification par e-mail que vous avez reçue lorsque les tableaux ont été créés, pour y accéder rapidement. Enfin, si vous n'avez pas spécifié l'espace durant le processus d'importation et que vous n'avez pas la notification par e-mail sous la main, vous pouvez rechercher vos tableaux dans l'espace **Fichiers importés**.

Mon diagramme sera-t-il exactement identique après importation ?

La plupart du temps, oui, mais pas toujours. Les polices, les connecteurs et les formats complexes peuvent changer pendant l'importation. Pour plus d'informations, consultez les sections [Limitations connues](#h_omni_known_limitations) et [Comprendre la cartographie des objets OmniGraffle dans Miro](#h_omni_mapping).

Combien de temps dure l'importation ?

Le temps de traitement dépend de la taille et de la complexité du fichier. Vous recevez un e-mail une fois que vos tableaux sont créés, incluant un lien direct vers l'espace pour accéder rapidement aux tableaux.

Comment savoir si mon importation en masse a réussi ou échoué ?

**Si votre importation en masse a réussi**, vous recevrez une notification par e-mail une fois les tableaux créés, incluant un lien direct vers l'espace afin d'y accéder rapidement.

**Si votre importation en masse a échoué**, vous recevrez un e-mail vous informant des fichiers pour lesquels des erreurs d'importation se sont produites.

Étapes suivantes :

- Contactez votre admin Miro ou le service d’assistance Miro et informez-les de cette erreur.
- Si possible, fournissez une version **expurgée** du fichier OmniGraffle à votre admin Miro, car cela aidera à résoudre votre erreur d'importation.

Puis-je annuler une importation ?

Vous ne pouvez pas annuler une importation. Vous pouvez supprimer les tableaux créés, si nécessaire.

## Résolution des problèmes

Je ne vois pas l'option Importer de OmniGraffle dans le menu Importer

- Confirmez que vous avez la permission de créer des tableaux dans Miro.
- Videz votre cache, actualisez votre navigateur et réessayez.
- Contactez votre admin d’entreprise pour confirmer que la fonctionnalité est activée pour votre organisation.

Mon fichier ne se télécharge pas

- Assurez-vous d'exporter le fichier OmniGraffle au format **.graffle Single File (Zipped)**.

  **Remarque :** Nous ne prenons en charge que le format **Single File (Zipped)**. Les formats **Package** et **Legacy** ne sont pas pris en charge. Si vous avez enregistré un fichier exporté non pris en charge plus tôt, vous pouvez l'ouvrir dans OmniGraffle, puis l'exporter au format **.graffle Single File (Zipped)**.
- Essayez de charger un seul fichier au lieu de plusieurs fichiers à la fois.
- Divisez les diagrammes OmniGraffle plus grands en éléments plus petits.

Je n’ai pas reçu d’e-mail

- [Vérifiez les spams ou les boîtes de réception filtrées.](../../using-miro/tools/troubleshooting/02-allowlist-miro-mailers.md)
- Vérifiez l'espace sélectionné pour les tableaux nouvellement créés.

L’agencement semble incorrect

- Réappliquez les polices si des substitutions ont eu lieu.
- Reconnectez manuellement les connecteurs ou les lignes.
- Modifiez les sections critiques en utilisant les formes natives de Miro si nécessaire.

## Limitations connues

Dans cette version, lors de l'importation de fichiers OmniGraffle dans Miro, vous pourriez remarquer des différences de structure, de style ou de comportement en raison des différences entre les deux plateformes.

### Cartographie de forme et de géométrie

**Limitations**

- Les formes OmniGraffle sont importées dans Miro en tant que SVG ou formes personnalisées, qui ne prennent pas en charge la fonctionnalité de changement de type de Miro. Si une forme ne peut être reconnue et qu'aucune géométrie de remplacement n'existe, elle est remplacée par un rectangle.

**Solutions de contournement**

- Remplacez les formes critiques par des formes natives de Miro après l'importation pour restaurer la pleine édition et le support QDC.
- Essayez d'utiliser les bibliothèques intégrées de formes et de prototypage de Miro avec des centaines de formes pour de nombreux cas d'utilisation.
- Passez en revue les diagrammes complexes après l'importation et ajustez manuellement les formes qui ont été remplacées par des rectangles.

### Fidélité visuelle et style

**Limitations**

- Les dégradés ne sont pas pris en charge. Les remplissages en dégradé sont aplanis lors de l'importation.
- Les ombres ne sont pas prises en charge et sont supprimées lors de l'importation.
- Les polices non prises en charge par défaut transitionnent vers une police système.

**Solutions**

- Utilisez des couleurs de remplissage unies au lieu de dégradés avant l'exportation.
- Supprimez les effets d'ombre dans OmniGraffle avant l'exportation si la précision visuelle est essentielle.
- Utilisez des polices système largement prises en charge pour réduire la substitution des polices.
- Revoyez la typographie et l'espacement après l'importation et ajustez les styles directement dans Miro.

### Connecteurs et annotations

**Restrictions**

- Les légendes de ligne peuvent ne pas être détectées ou positionnées correctement après l'importation.
- Les lignes peuvent apparaître fragmentées, légèrement désalignées ou traverser des formes.
- Les flèches directionnelles au sein de formes groupées peuvent parfois être perdues lors de la conversion.

**Solutions de contournement**

- Repositionnez manuellement les étiquettes de texte sur les lignes de connexion après importation.
- Reconnectez ou réacheminez les connecteurs Miro si des problèmes d'alignement surviennent.

### Formats de fichier

**Restrictions**

- Nous ne prenons en charge que le format **Single File (Zipped)**. Les formats **Package** et **Legacy** ne sont pas pris en charge.
- Les exportations au format PNG sont importées comme des images plates et non modifiables.

**Solutions**

- Utilisez le format d'exportation **Single File (Zipped)** pour obtenir les meilleurs résultats.
- Si vous avez un fichier exporté non pris en charge sauvegardé précédemment, vous pouvez ouvrir le fichier dans OmniGraffle, puis l'exporter au format **.graffle Single File (Zipped)**.
- Évitez les exportations au format PNG si vous avez besoin d’objets modifiables.

### Comportement de l'importation en masse

**Limitations**

- Les notifications par e-mail pour les imports en masse peuvent parfois échouer en raison de rebonds durs.
- Après la fin d'un import en masse, le contenu importé peut ne pas apparaître immédiatement sur le tableau.

**Solutions**

- Vérifiez les spams ou les règles de filtrage des e-mails si vous ne recevez pas les notifications.
- Rafraîchissez votre navigateur après la fin de l'import en masse.
