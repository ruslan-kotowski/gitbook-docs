[L’intégration avec **Dropbox**](https://miro.com/works-with-dropbox/) vous permet d’importer des fichiers de votre compte Dropbox et de les ajouter aux tableaux pour approfondir vos discussions et votre collaboration. Démarrez une conversation sur le tableau, ajoutez des [commentaires](../../using-miro/facilitation-tools/asynchronous-tools/01-comments.md) à vos fichiers, vos images et vos documents, mentionnez des gens et répétez plus rapidement.

> **Disponible pour**: tous les utilisateurs disposant d'un compte Dropbox Basic ou Pro
> **Disponible****sur**: version navigateur (desktop et tablette), [application de bureau.](../../getting-started/apps-for-devices/05-desktop-app.md)

Pour commencer à utiliser le plugin dans une équipe, vous devrez l’installer pour l’équipe et connecter votre compte Dropbox à Miro.

### Installer le plugin

Vous pouvez installer l’application à partir du [Marketplace](https://miro.com/marketplace/dropbox/). Trouvez Dropbox et cliquez sur **Get application.** Vous devrez choisir une équipe Miro pour laquelle vous souhaitez installer le plugin.

:::warning
Les utilisateurs sans rôle d’administrateur ne peuvent pas installer les applications si cela n’est pas autorisé dans les paramètres des **Apps & Integrations** (Applications et Intégrations).
:::

install_Dropbox.jpg
Choix de l’équipe lors de l’installation du plugin Dropbox

Vous pouvez également installer l’application à partir d’un tableau.

Suivez les étapes suivantes :

1. Dans la barre de création, sélectionnez Outils, médias et intégrations **(+).** **Le panneau Outils, médias et intégrations s’ouvre.**
2. Dans l’onglet Outils, recherchez et sélectionnez Téléchargements.
   La fenêtre **Chargements** s'ouvre.
3. Sélectionnez **Dropbox** dans le panneau.

![uploads-entry-point.png](../../../../../../docs/integrations-apps/more-integrations/images/21537452824210_uploads-entry-point.png)
L’icône Dropbox sur la barre d’outils

Cliquez sur **Get app** (Obtenir l’application) sur le prochain modal. L’application sera installée pour l’équipe correspondante.

L’étape suivante consiste à autoriser vos identifiants Dropbox dans Miro.    Vous pouvez le faire en cliquant sur Dropbox dans le menu **Upload** (Télécharger).  Si c’est la première fois que vous utilisez Dropbox avec Miro, vous verrez un menu contextuel vous demandant d’autoriser votre compte Dropbox.

authprize_Dropbox_in_Miro.jpg
Fenêtre d’authentification Dropbox

Vous pouvez également connecter votre compte Dropbox avec Miro sur la [page Integrations](https://miro.com/app/account/profile/integrations/) (Intégrations) de votre profil : défilez vers le bas jusqu’à Dropbox et cliquez sur **Connect** (Connecter).

connect_Dropbox.jpg
Connexion de Dropbox à Miro

### Ajouter des fichiers

Pour ajouter des fichiers au tableau, cliquez sur l’icône **Upload** (Télécharger) de la barre d’outils, choisissez **Dropbox**, sélectionnez les fichiers de votre Dropbox et cliquez sur **Choose** (Choisir).

add_Dropbox_files.jpg
Le menu contextuel du dossier Dropbox

### Désactiver le plugin

Pour désinstaller le plugin d’une équipe, rendez-vous dans la rubrique **Team settings** (Paramètres de l’équipe), trouvez Dropbox dans la section **Apps & Integrations** (Applications et intégrations) et cliquez sur **Unistall for team** (Désinstaller pour l’équipe).

uninstall_Dropbox.jpg
Désinstallation de Dropbox dans les paramètres d’une équipe

Pour déconnecter votre compte Dropbox, rendez-vous sur la [page Integrations](https://miro.com/app/account/profile/integrations/) (Intégrations) de votre profil et cliquez sur **Log out** (Se déconnecter).
