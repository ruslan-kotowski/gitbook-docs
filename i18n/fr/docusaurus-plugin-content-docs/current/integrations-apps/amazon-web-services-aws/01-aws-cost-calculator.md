L’application AWS Cost Calculator offre un moyen simple d’estimer les coûts des services AWS directement sur vos tableaux Miro. Il est particulièrement utile pour les chefs de projet et les professionnels de l’informatique, car il simplifie l’estimation des coûts pour une planification efficace.

:::note
(Enterprise) AWS Cost Calculator est disponible uniquement avec des licences avancées. Pour plus d'informations, consultez [Comprendre les licences Enterprise](../../plans-billing/miro-plans/05-understanding-enterprise-licenses.md).
:::

## Comment configurer et utiliser le calculateur de coûts AWS ?

1. Installez l'[AWS Cost Calculator](https://miro.com/marketplace/aws-cost-calculator/) depuis le Marketplace de Miro.
2. Ouvrez le tableau Miro dans lequel vous souhaitez calculer vos coûts AWS.
3. Cliquez sur **Outils, Médias et Intégrations** (**+**) dans la barre d'outils de [création](../../getting-started/start-here/your-first-board/05-toolbars.md) et recherchez ‘AWS Cost Calculator’.
4. Sélectionnez **AWS Cost Calculator**. Le panneau "AWS Cost Calculator" s’ouvre sur la gauche du tableau.
5. Cliquez et faites glisser pour sélectionner toutes les icônes AWS dans votre diagramme. Le calculateur de coûts remplira automatiquement toutes les icônes AWS de votre diagramme.
6. Pour chaque icône AWS, cliquez sur **Modifier** pour spécifier des détails tels que la région et le type de stockage, puis cliquez sur **Enregistrer la sélection de service**.
7. Après avoir modifié toutes les icônes, cliquez sur **Calculer** pour afficher le total de vos coûts AWS.
8. Pour mieux comprendre vos coûts, utilisez les onglets supérieurs et le menu déroulant pour filtrer les coûts par cadre temporel (**heure**, **mois**, **année**) et par **région**.

## Conseils pour des calculs précis

- **Soyez précis** : Plus vous fournirez de détails, plus votre estimation des coûts sera précise.
- **Révision régulière** : Les prix des AWS peuvent changer. Vérifiez et mettez régulièrement à jour vos estimations, et confirmez toujours les coûts réels directement auprès d’AWS.

## Donnez votre avis sur le calculateur de coûts AWS

Vos commentaires sont essentiels pour nous permettre d’améliorer le calculateur de coûts AWS et de le rendre plus utile à vos besoins.

1. Ouvrez le panneau **AWS Cost Calculator** dans votre tableau Miro.
2. Cliquez sur l'icône de feedback située en bas à droite du panneau pour évaluer votre expérience.
3. Dans le champ de texte ouvert, ajoutez toute remarque supplémentaire, y compris les icônes AWS que vous aimeriez voir prises en charge dans les prochaines mises à jour.
