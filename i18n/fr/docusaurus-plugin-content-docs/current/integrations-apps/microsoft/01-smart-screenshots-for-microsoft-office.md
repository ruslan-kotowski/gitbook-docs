Les captures d'écran intelligentes vous permettent de coller directement des tableaux et widgets Miro sous forme d'images dans Microsoft Word, PowerPoint et Excel, avec une fonctionnalité améliorée pour garder le contenu synchronisé.

## Captures d'écran intelligentes de Miro

:::note
Votre administrateur Microsoft devra peut-être installer le [module complémentaire Miro pour Microsoft Office](https://miro.com/marketplace/microsoft-office/) pour votre organisation ou équipe. Consultez votre administrateur si ce n'est pas disponible.
:::

L'intégration du panneau latéral Miro vous permet d'intégrer le contenu des tableaux Miro directement dans les fichiers Microsoft Word, PowerPoint et Excel sans quitter votre document. Cette fonctionnalité offre un accès transparent à vos tableaux Miro et vous permet d'insérer du contenu visuel avec une fonctionnalité améliorée.

## Panneau latéral Miro

Le panneau latéral Miro dans Microsoft Word, PowerPoint et Excel comprend les fonctionnalités suivantes :

- **Accès direct au tableau :** Accédez directement à vos tableaux Miro depuis Microsoft Word, PowerPoint et Excel sans changer d'application.
- **Sélection de tableau :** Choisissez parmi vos tableaux Miro disponibles en utilisant le bouton « Sélectionner le tableau Miro à intégrer ».
- **Aperçu interactif :** Consultez et sélectionnez le contenu spécifique de votre tableau Miro avant de l'insérer.
- **Placement précis :** Insérez le contenu exactement là où votre curseur est positionné dans le document.
- **Fonctionnalité intelligente :** Le contenu intégré maintient la connexion avec le tableau Miro d'origine.

## Comment utiliser le panneau latéral Miro

1. Dans votre fichier Microsoft Word, PowerPoint et Excel, positionnez votre curseur dans le document à l'endroit où vous souhaitez insérer le contenu Miro.
2. Ouvrez le panneau latéral droit en cliquant sur l'icône **d'intégration Miro**.
3. Cliquez sur **Sélectionner le tableau Miro à intégrer** pour choisir parmi vos tableaux Miro disponibles.
4. Parcourez et sélectionnez la zone, le cadre ou le contenu spécifique que vous souhaitez intégrer à partir de l'aperçu du tableau.
5. Utilisez les options disponibles dans le menu déroulant pour choisir différents réglages d'affichage ou sélections.
6. Cliquez sur **Confirmer** pour insérer le contenu à la position de votre curseur.

Le contenu intégré apparaîtra comme une capture d'écran dans votre document avec une connexion intelligente au tableau Miro original.

:::note
Le panneau latéral Miro nécessite l'installation du [module complémentaire Miro Microsoft Office](https://miro.com/marketplace/microsoft-office/). La fonctionnalité fonctionne avec Microsoft Word, PowerPoint et Excel.
:::

## Gérer le module complémentaire en tant qu'administrateur

Examinez ces points si vous êtes un administrateur Microsoft gérant le module complémentaire Miro :

- Le module complémentaire Microsoft Office peut être installé ou supprimé uniquement du côté de Microsoft.
- Si vous souhaitez restreindre l'accès aux captures d'écran intelligentes de Microsoft Office, cela doit être fait du côté de Microsoft ; Miro n'a aucun contrôle sur les utilisateurs qui installent et utilisent les captures d'écran intelligentes.

## FAQ

**Quelles applications Microsoft Office prennent en charge l'intégration de Miro ?**

Le panneau latéral Miro fonctionne avec Microsoft Word, PowerPoint et Excel.

**Comment les éléments intégrés du tableau Miro restent-ils à jour ?**

Le contenu intégré via le panneau latéral Miro maintient une connexion avec le tableau Miro original. Bien qu'il ne se synchronise pas automatiquement, vous pouvez actualiser le contenu intégré pour vous assurer qu'il reflète la dernière version de votre tableau Miro.

**Comment le panneau latéral Miro fonctionne-t-il&nbsp;?**

Le panneau latéral Miro offre un accès direct à vos tableaux Miro sans quitter votre document. Cliquez sur l'icône d'intégration Miro pour ouvrir le panneau de droite, puis utilisez "Sélectionner le tableau Miro à intégrer" pour choisir parmi vos tableaux disponibles. Le panneau vous permet de prévisualiser et de sélectionner des zones spécifiques ou des cadres avant de les insérer dans votre document à la position de votre curseur.
