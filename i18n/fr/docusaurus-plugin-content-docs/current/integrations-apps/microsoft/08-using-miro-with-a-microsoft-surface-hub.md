Utilisez Miro avec votre appareil Microsoft Surface Hub pour une collaboration à distance, en personne et hybride avec votre équipe. Découvrez comment utiliser Miro sur Surface Hub ci-dessous.

Miro est compatible avec les appareils Microsoft Surface Hub 84" et 55" et Microsoft Surface Hub 2S 50" et 85".

:::note
Assurez-vous que vous utilisez la version la plus récente de Microsoft Edge.
:::

## Comment utiliser Miro avec une Microsoft Surface Hub

Il existe deux façons d’utiliser Miro sur une Surface Hub :

1. Sur un navigateur Microsoft Edge
2. Installer Windows 10/11 sur une Surface Hub et installer l’application Miro pour Windows

### Utiliser Microsoft Edge

1. Assurez-vous que votre Surface Hub est dotée de **la version la plus récente de Windows** ([Mise à jour 2022 pour Windows 10 Collaboration](https://learn.microsoft.com/surface-hub/surface-hub-2022-update))
2. Lancez le **navigateur Microsoft Edge** le plus récent. Découvrez comment installer ce navigateur sur un affichage Surface Hub
   > ✏️ Une autorisation de niveau admin peut être nécessaire pour mettre à jour Windows ou Microsoft Edge vers leurs versions les plus récentes.
3. Vous pourrez ensuite vous connecter à Miro via miro.com/login. Vous pouvez également utiliser notre [expérience de connexion rapide](../../getting-started/apps-for-devices/10-send-to-display.md) pour ouvrir les tableaux Miro depuis votre appareil personnel vers votre Surface Hub encore plus vite

### Utiliser la Surface Hub avec l’application Miro pour Windows

1. Installez [Windows 10/11 sur la Surface Hub](https://learn.microsoft.com/surface-hub/surface-hub-2s-migrate-os) (au lieu de Windows 10 Collaboration)
2. Installez l’[application Miro pour Windows](../../getting-started/apps-for-devices/05-desktop-app.md)

:::warning
Il n’existe pour l’heure aucune application Miro pour Surface Hub compatible avec la version « Windows 10 Collaboration ».
:::
