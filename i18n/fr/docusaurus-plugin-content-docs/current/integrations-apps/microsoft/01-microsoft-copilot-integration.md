En tant qu'admin d’entreprise, vous pouvez activer et approuver l’intégration de Microsoft Copilot pour les équipes de votre organisation Miro.

L’intégration de Microsoft Copilot vous permet de connecter Copilot comme [ressource de connaissances](../../using-miro/miro-ai/09-knowledge.md) dans Miro. Par exemple, connectez Microsoft Copilot pour fournir des informations d’entreprise aux partenaires d’IA ou aux flux.

Vous pouvez également connecter Copilot au chat autonome dans Miro.

:::note
Pour des informations sur l'utilisation d'un agent Miro avec Copilot dans Microsoft Teams, voir [Agent Miro pour Copilot](microsoft-teams/03-miro-agent-for-copilot.md).
:::

Chaque membre de l'équipe doit posséder une licence Copilot pour utiliser l'intégration.

Pour activer l'intégration de Microsoft Copilot, suivez ces étapes :

1. En tant qu'admin d'entreprise, allez dans **Console d’administration**.
2. Allez dans **Applications & intégrations** > **Applications** > **Ajouter des applications**.
3. Cherchez et trouvez **Microsoft Copilot**.
   Si vous ne trouvez pas l'application par son nom, recherchez avec l'ID client suivant : `5531308904693541040`.
4. Dans le profil de l'application, sélectionnez l'option pour ajouter l'application pour **Toutes les équipes**, ou sélectionnez **Équipes spécifiques**.
5. (Facultatif) Examinez la page des autorisations. L'application Microsoft Copilot pour Miro est développée et maintenue par Miro, et ne nécessite pas d'autorisations spéciales.
6. Cliquez sur **Ajouter**.

:::note
Lorsqu'un membre de l'équipe connecte Microsoft Copilot en tant que ressource de connaissance pour la première fois, il lui sera demandé de s'authentifier. Le membre de l'équipe doit disposer d'une licence Copilot.
:::
