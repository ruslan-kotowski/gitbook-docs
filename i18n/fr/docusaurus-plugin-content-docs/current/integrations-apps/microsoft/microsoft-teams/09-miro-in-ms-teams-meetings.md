Incorporez un tableau Miro nouveau ou existant dans une réunion Microsoft Teams (MS Teams). Commencez à collaborer instantanément sans quitter l'appel.

## Comment ajouter un tableau Miro à une réunion Microsoft Teams ?

#### Prérequis

Veillez à remplir les conditions préalables suivantes :

- Vous avez activé Miro pour Microsoft Teams. Pour savoir comment procéder, consultez la [présentation de Miro pour Microsoft Teams](06-miro-for-microsoft-teams-overview.md).
- Vous êtes membre de l'équipe Miro qui possède le tableau que vous souhaitez intégrer.
- Vous êtes le propriétaire ou l'éditeur du tableau que vous souhaitez intégrer.

#### Procédure

Suivez les étapes suivantes :

1. Dans Microsoft Teams, sélectionnez une équipe.
2. Sélectionnez l'icône plus**(+)**
   La fenêtre modale **Ajouter un onglet** s'ouvre.
3. Sélectionnez **Miro**.
4. Sélectionnez **Get Started**.
   Vous êtes prompt à vous connecter à Miro si vous ne l'êtes pas déjà.
5. Sélectionnez un tableau Miro ou créez un nouveau tableau à intégrer.
   > ✏️ Vous devez avoir le rôle de propriétaire ou d'éditeur du tableau et être membre de l'équipe Miro qui possède le tableau que vous souhaitez intégrer.
6. Sélectionnez les autorisations pour tous les membres de l'équipe.
   ![Sélection des autorisations pour l'intégration de Miro dans Microsoft Teams](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22476127831698_image.png)
7. Sélectionnez **Enregistrer**.
   Le tableau s'intègre dans un onglet de MS Teams.

   Vous avez ajouté avec succès un tableau Miro à une réunion Microsoft Teams.
