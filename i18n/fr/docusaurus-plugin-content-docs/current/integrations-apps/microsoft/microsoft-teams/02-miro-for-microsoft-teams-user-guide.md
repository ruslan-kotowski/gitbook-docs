Miro pour Microsoft Teams permet aux utilisateurs de recevoir des notifications en temps réel ainsi que de collaborer sur des tableaux Miro intégrés dans les réunions Teams, les canaux, les chats et les invitations du calendrier.

Miro prend également en charge les cartes adaptatives grâce au déploiement de liens et aux extensions de messages de recherche, ce qui donne aux utilisateurs plus de contexte sur les tableaux partagés et permet de gérer rapidement l'accès aux tableaux, le tout sans quitter leur espace Microsoft Teams.

- [Ajoutez un tableau Miro en tant qu'onglet](04-add-miro-as-a-tab-in-microsoft-teams.md) dans les réunions, les discussions, les canaux et les événements du calendrier de Microsoft Teams.
- Recevez les notifications de Miro dans Microsoft Teams
- Partagez les liens Miro en tant que cartes adaptatives grâce au déploiement des liens et à l'extension des messages de recherche

:::note
Votre admin doit activer l'application Miro dans les paramètres de Microsoft Teams et dans les paramètres de gestion de l'application Miro. Si Miro n'est pas approuvé, il ne sera pas disponible pour les utilisateurs. Visitez le site [Miro pour Microsoft Teams (guide d'administration)](01-miro-for-microsoft-teams-admin-guide.md) pour voir comment les administrateurs de Teams et de Miro peuvent activer l'expérience pour leurs utilisateurs.
:::

## Installer l’application

1. Trouvez Miro dans [Microsoft AppSource](https://appsource.microsoft.com/product/Office365/WA104381906) ou suivez le [lien direct](https://teams.microsoft.com/dl/launcher/launcher.html?url=%2F_%23%2Fl%2Fapp%2F8216e453-3db5-48ee-a3d6-5122f505c8a3&type=app&deeplinkId=660e2c79-d07b-46b9-b56f-473431aa9dd9&directDl=true&msLaunch=true&enableMobilePage=true&suppressPrompt=true).
2. Cliquez sur **Ajouter** pour installer l'application.

Une fois l'application Miro installée, vous devrez connecter votre compte pour commencer à ajouter des tableaux aux onglets et recevoir des notifications.
Dans le cadre du processus d'installation, vous pouvez ensuite vous rendre sur le chat Miro où vous pourrez terminer la configuration de l'application en connectant votre compte. Vous pourrez configurer les notifications Miro.

:::note
En savoir plus sur l'ajout de tableaux Miro dans Microsoft Teams.
:::

## Configurer les notifications dans Microsoft Teams

Grâce à l’application, vous pouvez suivre les événements suivants :

- Les personnes que vous avez invitées s’inscrivent.
- Un tableau a été partagé avec vous.
- Un nouveau commentaire a été publié ou quelqu’un a répondu à l’un de vos commentaires sur un tableau.
- Quelqu’un vous @mentionne dans un commentaire ou une réponse.
- Des demandes d’accès à un tableau ont été reçues et approuvées.

Les notifications sont reçues par l'intermédiaire du chat bot de Miro. Pour configurer le chat du robot Miro :

1. Connectez votre compte. Tapez la commande **Connect**(Connecter), puis cliquez sur Connect Miro to Microsoft Teams (Connecter Miro à Microsoft Teams).
2. Dans le nouvel onglet, vous devrez autoriser votre profil Miro. Une fois que vous avez connecté votre compte avec succès, vous verrez un message d'accueil du robot indiquant que tout est en place.
3. Vous commencerez à recevoir des notifications pour les nouveaux commentaires et mentions.
4. Partage de tableaux Miro dans Microsoft Teams.

Grâce à l'application Miro pour Microsoft Teams, vous pouvez partager des liens vers des tableaux Miro sous forme de cartes adaptatives :

- Déroulement du lien
- Recherche d'extensions de messages

Les cartes adaptatives fournissent aux utilisateurs des informations détaillées sur le tableau, telles que le titre, le propriétaire et la dernière mise à jour. Les utilisateurs peuvent également prendre des mesures telles que la gestion des autorisations du tableau et l'exploitation de [Miro IA](../../../using-miro/miro-ai/03-create-with-ai.md) pour résumer les principaux points à retenir dans un document.

Les tableaux Miro se déploient automatiquement dans une carte adaptative lorsqu'un lien de tableau est collé dans la boîte de composition de message dans les canaux Microsoft Teams lorsque vous avez installé et connecté l'application Miro.

Si vous avez installé l'application mais que vous n'avez pas encore connecté votre compte Miro, vous verrez l'option de connexion. Si vous n'avez pas encore installé l'application, suivez les étapes [ici.](04-add-miro-as-a-tab-in-microsoft-teams.md)

## Foire aux questions

Que dois-je faire si j'ai des difficultés avec l'intégration ?

Si vous rencontrez des difficultés avec l'intégration, veuillez essayer de reconnecter votre équipe via le chat Miro. Cela permet souvent de résoudre les problèmes de connectivité les plus courants.

Que faire si la reconnexion ne résout pas le problème ?

Si la reconnexion par le biais du chat Miro ne résout pas le problème, veuillez contacter l'assistance Miro pour obtenir de l'aide supplémentaire. Ils sont équipés pour traiter toute une série de questions techniques et peuvent fournir des conseils plus spécifiques.
