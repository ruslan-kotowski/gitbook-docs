Incorporer un tableau Miro dans une équipe Microsoft Teams (MS Teams). Vous pouvez centraliser la collaboration Miro et organiser la prise de décision sans changer d'application. Ajoutez un onglet à votre canal MS Teams et intégrez tout tableau Miro dont vous êtes le propriétaire ou le copropriétaire.

## Comment ajouter un tableau Miro en tant qu'onglet dans un canal Microsoft Teams ?

#### Prérequis

1. Vous êtes le propriétaire ou le copropriétaire du tableau Miro que vous souhaitez intégrer.
2. Vous êtes membre de l'équipe Miro qui possède le tableau que vous souhaitez intégrer.
3. Assurez-vous que l'option Miro pour Microsoft Teams est activée. Pour savoir comment procéder, consultez la [présentation de Miro pour Microsoft Teams](06-miro-for-microsoft-teams-overview.md).

#### Procédure

Suivez les étapes suivantes :

1. Dans Microsoft Teams, sélectionnez une équipe.
2. Sélectionnez l'icône plus**(+)**.
   La fenêtre modale **Ajouter un onglet** s'ouvre.
3. Sélectionnez **Miro**.
4. Sélectionnez **Démarrer**.
   Vous êtes prompt à vous connecter à Miro si vous ne l'êtes pas déjà.
5. Sélectionnez un tableau Miro ou créez un nouveau tableau à intégrer.
   > ✏️ Vous devez avoir le rôle de propriétaire ou d'éditeur du tableau et être membre de l'équipe Miro qui possède le tableau que vous souhaitez intégrer.
6. Sélectionnez les autorisations d'utilisateur pour le tableau intégré.
   ![image.png](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22476127831698_image.png)
7. Sélectionnez **Enregistrer**.

   Vous avez ajouté avec succès un tableau Miro en tant qu'onglet dans une chaîne MS Teams.
