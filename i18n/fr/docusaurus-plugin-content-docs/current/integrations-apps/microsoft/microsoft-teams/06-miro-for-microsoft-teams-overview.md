Intégrez Miro à Microsoft Teams (MS Teams) de manière transparente pour permettre aux équipes de faire du brainstorming, de la planification et de la cocréation avec Miro directement dans l'environnement MS Teams. Le canevas intelligent Miro simplifie la gestion des projets sans changer d'application.

> **Disponible pour :** Tous les forfaits Certaines fonctionnalités avancées ne sont disponibles que dans le cadre de plans payants.
> **Qui peut le faire ? Tous les utilisateurs Nécessite l'installation d'un administrateur Microsoft.**

## Fonctionnalités principales

L'intégration de Miro pour Microsoft Teams offre les fonctionnalités clés suivantes :

- **Plugin Miro Copilot pour la recherche dans MS Teams**
  Recherchez du contenu Miro avec Copilot et prévisualisez instantanément un tableau de référence avec des métadonnées.
- **Bot de notification**
  Recevez des mises à jour instantanées de Miro dans le chat de MS Teams, comme de nouveaux commentaires ou une réponse sur votre tableau, ainsi que des demandes d'accès que vous pouvez approuver directement dans le chat.
- **Réunions MS Teams**
  Ouvrez ou créez un tableau Miro et commencez à interagir sur le canevas à tout moment pendant un appel.
- **Calendrier MS Teams**
  Intégrez un tableau Miro dans une invitation de calendrier MS Teams, définissez des autorisations et donnez accès aux collaborateurs avant la réunion.
- **Onglets MS Teams**
  Incorporer un tableau Miro en tant qu'onglet dans MS Teams.
- **Chat MS Teams**
  Ajoutez un tableau Miro en tant que carte adaptative dans le chat de MS Teams.

## Comment configurer Miro pour Microsoft Teams ?

En tant qu'admin de Microsoft Teams, vous pouvez activer l'intégration de Miro pour MS Teams.

Suivez les étapes suivantes :

1. Dans MS Teams, sélectionnez **Applications****(+)**.
   Le panneau **Applications** s'ouvre.
2. Recherchez Miro.
3. Dans les résultats de la recherche, pour Miro, sélectionnez **Ajouter.**
   La fenêtre modale de l'application Miro s'ouvre.
4. Sélectionnez **Ajouter**.
   Vous êtes redirigé vers l'application Miro.
5. À partir de la vue de l'application Miro, connectez-vous à votre compte Miro.
   Votre compte Miro se connecte aux équipes MS.

   Vous avez ajouté avec succès l'application Miro à MS Teams et connecté votre compte.

Pour utiliser une intégration Miro spécifique pour Microsoft Teams, consultez l'article relatif à l'intégration concernée.
