Ajoutez du contexte aux e-mails Outlook grâce aux liens Miro étendus. Grâce à cette intégration, les utilisateurs peuvent obtenir plus d’informations sur chaque lien Miro envoyé via l’e-mail Outlook.

> **Disponible pour :** Tous les forfaits Miro
> **Disponible sur :** Bureau

:::note
Les utilisateurs doivent activer l’intégration Miro pour Microsoft Teams avant de pouvoir utiliser l’expérience Outlook. Reportez-vous à la documentation de [Microsoft Teams](microsoft-teams/01-miro-for-microsoft-teams-admin-guide.md) pour plus d’informations.
:::

## Fonctionnement de Miro pour Microsoft Outlook

Miro pour Microsoft Outlook comprend deux fonctionnalités importantes qui améliorent l’expérience de l’utilisateur : le déploiement des liens et les extensions des messages de recherche.

Lorsque les utilisateurs ajoutent un lien Miro dans un e-mail, le lien se déploie en une carte adaptative, où les utilisateurs peuvent obtenir plus d’informations sur le tableau, telles que le titre, le propriétaire du tableau et l’heure de la dernière mise à jour.

![](../../../../../../docs/integrations-apps/microsoft/images/20647652622098_9d5d21ee-76f3-4e99-9740-6095aa310079.png)

*Les liens Miro se transforment automatiquement en cartes adaptatives*

Depuis la surface de composition des e-mails, les utilisateurs peuvent accéder à l’intégration Miro via le menu de l’application pour rechercher un tableau Miro, qui peut ensuite être ajouté à l’e-mail sous la forme d’une carte adaptative.

![](../../../../../../docs/integrations-apps/microsoft/images/20647667523090_5d17d2ad-8790-47d0-9b5c-7025ecde97d5.png)

*Les tableaux peuvent être recherchés et insérés dans les e-mails à partir d’Outlook.*
