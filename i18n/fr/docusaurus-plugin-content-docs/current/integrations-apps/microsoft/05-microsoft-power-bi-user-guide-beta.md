Associez la force collaborative de Miro à la puissance analytique de Power BI. Grâce aux rapports et tableaux de bord Power BI intégrés directement dans les tableaux Miro, votre équipe peut rationaliser les processus de décision, visualiser les stratégies basées sur les données et piloter les projets avec clarté et précision.

- Utilisez les données intégrées de Power BI pour obtenir des informations en temps réel et prendre des décisions éclairées.
- Collaborez efficacement avec les membres de l’équipe en mettant à jour et en ajoutant des graphiques aux tableaux Miro comportant des données Power BI.

## Comment intégrer les rapports Microsoft Power BI dans Miro

:::tip
Vérifiez auprès de votre admin d’entreprise que l’intégration de Power BI a été effectuée pour votre organisation.
:::

1. Allez à Microsoft Power BI, puis copiez le lien du rapport ou du tableau de bord à partir de la barre d’adresse du navigateur (et non à partir du menu Partager, car il n’est pas pris en charge actuellement).
2. Collez le lien copié sur n’importe quel tableau Miro.
3. Cliquez sur **Se connecter** pour autoriser l’application Miro dans Microsoft Power BI.
4. Une fois la connexion établie, une boite de dialogue s’ouvrira pour vous inviter à sélectionner les graphiques à intégrer. Assurez-vous que la liste correspond au rapport original.
5. Cliquez sur **Ajouter tous les graphiques** pour les intégrer dans le tableau.
6. Les graphiques seront ajoutés sous forme d’images à votre tableau Miro.

## Conditions pour intégrer les données Power BI dans Miro

Pour intégrer un rapport ou un tableau de bord Power BI dans un tableau Miro, vous devez :

- faire partie d’une équipe ou d’un compte Miro où l’intégration de Power BI est activée ;
- avoir accès au rapport ou au tableau de bord Power BI précis que vous souhaitez intégrer ;
- vérifier que le tableau Miro où vous souhaitez intégrer les données Power BI n’est pas partagé via un lien public ;
- disposer d’un service Power BI Cloud pris en charge (SKU Power BI Premium par capacité ou SKU de réservation de capacité Fabric). Le service sur site n’est pas pris en charge.

## Visualiser et modifier les données Power BI intégrées

Les utilisateurs qui ont accès au tableau Miro comportant des données Power BI intégrées peuvent consulter les données, quel que soit le statut de leur autorisation ou de leur licence Power BI. Cela inclut les utilisateurs disposant des droits de consulter, de commenter ou de modifier le tableau.

Si vous disposez du droit de modifier un tableau Miro comportant des données Power BI intégrées, vous pouvez l’actualiser via la fonctionnalité **Mettre à jour** ou ajouter des graphiques via la fonctionnalité **Ajouter des graphiques**, y compris si vous n’avez pas accès au contenu Power BI original. Toutefois, il n’est pas possible d’explorer ou d’accéder aux données originales du graphique ni de modifier les filtres via l’intégration.

## Conservation des données

Les données Power BI intégrées suivent la politique de conservation standard de Miro appliquée à toutes les données des clients. Lisez notre [Addenda Miro sur le traitement de données](https://miro.com/legal/documents/Miro-Data-Processing-Addendum.pdf).

## Dépannage

Suivez ces étapes de dépannage pour résoudre les problèmes courants rencontrés lors de l’utilisation de l’intégration Power BI dans Miro.

Problèmes d’autorisation et d’approbation de l’admin

Si vous ne pouvez pas autoriser l’application ou si vous recevez une invitation à demander l’approbation de l’admin sans pouvoir le faire, contactez votre admin d’entreprise pour activer les demandes d’approbation. Si vous voyez une fenêtre **Besoin d’une approbation d’admin**, demandez une approbation via cette fenêtre.

Problèmes d’intégration

Si les graphiques n’apparaissent pas comme prévu, contactez votre admin d’entreprise pour vérifier si vous disposez de l’abonnement Microsoft Power BI adéquat.

Vérification des liens

Pour les éléments manquants, vérifiez le lien utilisé et assurez-vous qu’il a été copié directement à partir de la barre d’adresse du navigateur.
