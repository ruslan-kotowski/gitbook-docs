L’intégration de Trello pour Miro améliore la collaboration en permettant une synchronisation bidirectionnelle fluide entre les tableaux Miro et les cartes Trello. Importez, consultez et modifiez facilement des cartes sans changer d’outil, garantissant que vos workflows restent à jour. Cette intégration est conçue pour améliorer la gestion des cartes, facilitant l'alignement et la productivité des équipes.

:::warning
Les administrateurs peuvent avoir besoin d’autoriser l’intégration Trello pour leur équipe Miro. Les membres de l’équipe peuvent utiliser l’intégration Trello uniquement si elle est installée au niveau de l’équipe.
:::

## Autoriser et synchroniser le compte Trello

Avant d’installer l’intégration Trello, assurez-vous que vous avez un compte Miro et Trello actif. Si vous n'avez pas de compte Miro, [inscrivez-vous ici](https://miro.com/).

1. Ouvrez un tableau Miro.
2. Dans la **barre de création**, sélectionnez **Outils > Médias & Intégrations (+)**.
3. Recherchez **Trello**.
4. Cliquez sur **Connecter** pour autoriser l’intégration Trello et suivez les instructions.

Une fois connecté, vous recevrez un message vous indiquant que votre compte est en cours de synchronisation. Ce processus peut durer de plusieurs minutes à plusieurs heures.

Une fois synchronisé, vous recevrez un e-mail vous informant que la synchronisation de votre compte Trello est terminée.

## Importer et utiliser des cartes Trello

Après avoir connecté et synchronisé Miro à votre compte Trello, vous pouvez ajouter des cartes Trello à vos tableaux Miro :

1. Ouvrez un tableau Miro.
2. Dans la **barre de création**, sélectionnez **Outils > Médias & Intégrations (+)**.
3. Recherchez **Trello**.

   Le sélecteur de cartes Trello apparaîtra, vous permettant de filtrer les cartes par Liste, Tableau et Badge.
4. Sélectionnez les cartes à importer, et elles apparaîtront sous forme de widgets de carte Trello sur votre tableau Miro.

:::note
Le sélecteur affichera uniquement les cartes auxquelles vous avez accès dans Trello. Si un utilisateur Miro ouvre la page source d'une carte à laquelle il n'a pas accès, un message indiquant qu'elle est inaccessible apparaîtra.
:::

## Modifier les cartes Trello

Pour modifier les cartes Trello sur un tableau Miro :

1. Cliquez sur un widget **Trello** cartepour ouvrir le menu contextuel.
2. Cliquez sur l'**icône du panneau latéral**.
   Un panneau latéral avec les détails de la carte s'ouvre.
3. Modifiez les propriétés de la carte directement dans Miro, puis cliquez sur **Mettre à jour**.
   Les modifications seront répercutées dans Trello.

## Gérer les cartes Trello

Lorsque vous importez des cartes Trello dans Miro, vous pouvez les gérer de différentes manières.

### Organiser les cartes dans les outils Miro

Utilisez des outils comme la [Table](../../using-miro/formats/14-tables.md), le [Planning](../../using-miro/formats/15-timeline.md), [les Colonnes](../../using-miro/advanced-tools/02-columns-formerly-kanban.md), ou [le User story mapping](../../using-miro/advanced-tools/07-user-story-mapping.md) pour organiser les cartes Trello :

1. Importez des cartes Trello dans votre tableau Miro.
2. **Faites glisser et déposez les cartes Trello** dans l'outil que vous avez choisi. Par exemple, une table.
3. **Réorganisez les cartes Trello** selon les besoins pour refléter le workflow de votre équipe ou l'état des cartes.

### Ouvrir la carte Trello d'origine

Vous pouvez naviguer rapidement vers la carte complète dans Trello :

1. Cliquez sur un widget de **Trello** pour ouvrir la vue détaillée.
2. Dans la vue détaillée, localisez et cliquez sur l'icône **Source**.
3. La carte s'ouvrira dans un nouvel onglet du navigateur dans l'interface Trello.

Alternativement, cliquez sur l'icône **Source** dans le panneau latéral des détails de la carte.

### Basculer entre les vues détaillées

Choisissez comment vous préférez voir les détails de la carte dans Miro :

1. Cliquez sur un widget de carte **Trello**.
2. Par défaut, la carte s'ouvre dans le volet de détails latéral.
3. Cliquez sur l’icône **Changer de vue** pour ouvrir la carte dans une **fenêtre modale** au lieu du volet latéral.

Pour revenir au volet latéral, cliquez de nouveau sur **Changer de vue**.

### Modifier la couleur d’une carte

Le codage couleur des cartes peut aider à distinguer visuellement la priorité ou l’état :

1. Sélectionnez la carte Trello que vous souhaitez recolorer.
2. Dans le menu contextuel, cliquez sur l'icône **Couleur de remplissage**.
3. Sélectionnez la couleur désirée dans la palette.

### Créer des raccourcis d'action

Vous pouvez créer des [raccourcis d’action](../../using-miro/facilitation-tools/03-action-shortcuts-beta.md) pour :

- Ouvrir le sélecteur de cartes Trello.
- Créer une nouvelle carte Trello.

## Comment désinstaller l'intégration Trello

Vous pouvez désinstaller l'intégration Trello au niveau de l’équipe ou individuellement.

### Désinstallation au niveau de l'équipe

1. Ouvrez **Paramètres de l'équipe** > **Applications & Intégrations**.
2. Trouvez **Trello** ou **Gestion des cartes Trello** dans la liste des applications installées.
3. Faites défiler vers le bas et cliquez sur **Désinstaller pour l’équipe**.

### Désinstallation individuelle

1. Allez dans **Applications & Intégrations** dans vos paramètres Miro.
2. Localisez **Trello** ou **Gestion des cartes Trello** et cliquez sur **Désinstaller pour moi**.

En suivant ces étapes, vous pouvez intégrer et gérer vos cartes Trello dans Miro en toute simplicité, améliorant ainsi l'efficacité du workflow et la collaboration sur les deux plateformes.

## Foire aux questions

- **Quels utilisateurs Trello peuvent utiliser l'intégration Trello au sein de Miro ?** Seuls les utilisateurs autorisés qui font partie de l'équipe ou de l'organisation Miro où le tableau est hébergé peuvent utiliser l'intégration Trello. De plus, ces utilisateurs doivent posséder les permissions nécessaires au sein de Trello pour interagir avec les cartes.
- **Qui peut voir les cartes Trello une fois qu'elles sont importées dans un tableau Miro ?** Tout utilisateur ayant accès au tableau Miro (c'est-à-dire ceux qui ont des droits de consultation, de commentaire ou de modification pour le tableau) peut voir les données Trello importées. Il est important de noter que les utilisateurs n'ont pas besoin d'une autorisation Trello ou d'une licence Trello pour simplement consulter les données de carte importées affichées sur le tableau Miro.
- **Puis-je accéder aux cartes Trello ou les consulter via l'intégration Miro si je n'ai pas d'accès direct à celles-ci dans Trello ?** Non, chaque utilisateur interagit avec l'intégration Trello en utilisant son propre compte Trello. Cela signifie que les utilisateurs ne peuvent rechercher, importer ou modifier les cartes Trello dans Miro qu'en fonction des autorisations qu'ils détiennent déjà dans le système Trello. Cependant, une fois que les cartes sont importées sur un tableau Miro, elles deviennent visibles pour tous les autres utilisateurs qui ont accès à ce tableau Miro spécifique.
