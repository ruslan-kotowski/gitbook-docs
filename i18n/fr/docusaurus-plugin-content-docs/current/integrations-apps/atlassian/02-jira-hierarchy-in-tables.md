Vous pouvez importer vos tickets Jira dans le format de table Miro. Une table vous permet d'avoir une visibilité de bout en bout sur vos initiatives stratégiques et vos workflows, des épopées à un haut niveau de détail aux spécificités des tickets.

**Plus d'informations :** [FAQ sur les cartes Jira](https://help.miro.com/hc/articles/360013463739).

## Importer des tickets Jira dans votre tableau sous forme de table

1. Sur un tableau Miro, dans la barre de création, cliquez sur Outils, Médias et Intégrations (+).
2. Recherchez et sélectionnez Cartes Jira.
   Si vous vous connectez à Jira pour la première fois, une authentification est requise.
   La fenêtre modale **Sélectionner les tickets** s'ouvre.
3. Recherchez et sélectionnez votre ou vos ticket(s) Jira.
   **Sélectionner les tickets** inclut uniquement les tickets Jira que vous avez la permission d'accéder.
4. Ajoutez votre ou vos ticket(s) au Format **Table**.
   ![](../../../../../../docs/integrations-apps/atlassian/images/32535032016146_image.png) *Le sélecteur d'ajout vous permet de choisir le Format Table.*
5. Cliquez sur **Ajouter** ***x**.*

## Importer les enregistrements enfants Jira

Après avoir importé les tickets parents sous forme de table, vous pouvez importer les tickets enfants.

Suivez les étapes suivantes :

1. Dans la table, pour la ligne où vous souhaitez importer des tickets enfants, cliquez sur les six points verticaux de la première colonne. Un menu s’ouvre.
2. Cliquez sur **Importer les entrées enfants**.
   Le modal de **Sélection des tickets** s’ouvre.
   ![](../../../../../../docs/integrations-apps/atlassian/images/32535032016146_image.png) *Après avoir importé des tickets, vous pouvez importer des tickets enfants dans votre table.*
3. Sélectionnez les tickets enfants que vous souhaitez importer.
4. Cliquez sur **Ajouter** ***x*****.**

### Basculer en vue imbriquée

Pour activer la vue hiérarchique pour les tickets parent et enfant, cliquez sur le bouton **Paramètres de la vue**. Ensuite, activez l'option **Hiérarchisation**.

![](../../../../../../docs/integrations-apps/atlassian/images/32535032016146_image.png) *Activez l'affichage hiérarchique pour les tickets parent et enfant.*

:::tip
En mode hiérarchique, vous pouvez réduire et développer les enregistrements enfants. Un ticket parent a un indicateur pour montrer si des tickets enfants existent.
:::

## Changer la disposition de la table

Pour changer la disposition de la table, cliquez sur le bouton **Disposition**. Puis sélectionnez une disposition.

Par exemple, vous souhaitez une disposition en arbre.

![](../../../../../../docs/integrations-apps/atlassian/images/32535032016146_image.png) *Changez la disposition pour votre table de tickets Jira.*

:::note
(Enterprise) La vue arborescente est en bêta publique et disponible uniquement avec une licence Enterprise Advanced. Pour plus d'informations, consultez [Comprendre les licences Enterprise](https://help.miro.com/hc/articles/33311996124306).
:::
