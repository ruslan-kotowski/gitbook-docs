L’intégration d’Asana à Miro améliore la collaboration en permettant une synchronisation bidirectionnelle fluide entre les tableaux Miro et les tâches Asana. Importez, consultez et modifiez facilement vos tâches sans changer d’outil, garantissant ainsi la mise à jour de vos workflows. Cette intégration est conçue pour améliorer la gestion des tâches, facilitant ainsi l’alignement et la productivité des équipes.

:::warning
Les administrateurs peuvent devoir autoriser l’intégration d’Asana pour leur équipe Miro. Les membres de l’équipe peuvent utiliser l’intégration Asana uniquement si elle est installée au niveau de l’équipe.
:::

## Autoriser et synchroniser le compte Asana

Avant d'installer l'intégration Asana, assurez-vous d'avoir un compte Miro et Asana actif. Si vous n'avez pas de compte Miro, [inscrivez-vous ici](https://miro.com/).

1. Ouvrez un tableau Miro.
2. Dans la **barre de création**, sélectionnez **Outils > Médias & Intégrations (+)**.
3. Recherchez **Asana**.
4. Cliquez sur **Connecter** pour autoriser l'intégration Asana et suivez les instructions.

Une fois connecté, un message s'affichera pour indiquer que votre compte est en cours de synchronisation. Ce processus peut prendre de quelques minutes à plusieurs heures.

![miro.com_app_board_uXjVIN5eQsE=_ (9) copy.png](images/30598024179986_miro.com_app_board_uXjVIN5eQsE=_%20(9) copy.png)

Une fois synchronisé, vous recevrez un e-mail indiquant que la synchronisation de votre compte Asana est terminée.

## Importer et utiliser des tâches Asana

Après que Miro est connecté et synchronisé avec votre compte Asana, vous pouvez ajouter des tâches Asana à vos tableaux Miro :

1. Ouvrez un tableau Miro.
2. Dans la **barre de création**, sélectionnez **Outils > Médias & Intégrations (+)**.
3. Recherchez **Asana**.

   Le sélecteur de tâches Asana apparaîtra, vous permettant de filtrer les tâches par État, Assignation, et Projet.
4. Sélectionnez les tâches à importer, et elles apparaîtront sous forme de cartes Asana sur votre tableau Miro.

![miro.com_app_board_uXjVIN5eQsE=_ (11).png](images/30598024186642_miro.com_app_board_uXjVIN5eQsE=_%20(11).png)
:::note
Le sélecteur affichera uniquement les tâches auxquelles vous avez accès dans Asana. Si un utilisateur Miro ouvre la page source d’une tâche à laquelle il n’a pas accès, un message lui indiquera que cette tâche lui est inaccessible.
:::

## Modifier des tâches Asana

Pour modifier des tâches Asana sur un tableau Miro :

1. Cliquez sur un **widget** de **carte Asana** pour ouvrir le menu contextuel.

   ![Screenshot 2025-04-03 at 16.07.08.png](../../../../../../../docs/integrations-apps/asana/asana/images/25791747832338_Screenshot%202025-04-03%20at%2016.07.08.png)
2. Cliquez sur l'**icône du panneau latéral**.
   Cela ouvre un panneau latéral avec les détails du ticket.
3. Modifiez les propriétés de la tâche directement dans Miro, puis cliquez sur **Mise à jour**.
   Les changements seront répercutés dans Asana.

![Screenshot 2025-04-03 at 16.17.21.png](../../../../../../../docs/integrations-apps/asana/asana/images/25791747834258_Screenshot%202025-04-03%20at%2016.17.21.png)

## Gérer les cartes Asana

Lorsque vous importez des tâches Asana dans Miro, vous pouvez les gérer de différentes façons.

### Organiser les tâches avec les outils de Miro

Utilisez des outils tels que la [table](../../../using-miro/formats/14-tables.md), le [planning](../../../using-miro/formats/15-timeline.md), [colonnes](../../../using-miro/advanced-tools/02-columns-formerly-kanban.md), ou [(User) story map](../../../using-miro/advanced-tools/07-user-story-mapping.md) pour organiser les tâches Asana :

1. Importez des tâches Asana sur votre tableau Miro.
2. **Glissez-déposez les cartes** Asana dans l'outil de votre choix. Par exemple, une table.
3. **Réorganisez les cartes Asana** selon vos besoins pour refléter le workflow ou l'état de votre équipe.

### Ouvrir la tâche Asana originale

Vous pouvez naviguer rapidement vers la tâche complète dans Asana :

1. Cliquez sur une **carte** Asana pour ouvrir la vue détaillée.
2. Dans la vue détaillée, trouvez et cliquez sur l'icône **Source**.
3. La tâche s'ouvrira dans un nouvel onglet du navigateur dans l'interface Asana.

![Screenshot 2025-04-03 at 16.36.26.png](../../../../../../../docs/integrations-apps/asana/asana/images/25792468716178_Screenshot%202025-04-03%20at%2016.36.26.png)

Alternativement, cliquez sur l'icône **Source** dans le panneau latéral des détails des tickets.

### Basculer entre les vues détaillées

Choisissez comment vous préférez consulter les détails des tâches dans Miro :

1. Cliquez sur une carte **Asana**.
2. La tâche s'ouvre par défaut dans une vue de détail en panneau latéral.
3. Cliquez sur l'icône **Changer de vue** pour ouvrir la tâche dans une **fenêtre modale** au lieu du panneau latéral.

![Screenshot 2025-04-03 at 16.43.13.png](../../../../../../../docs/integrations-apps/asana/asana/images/25792504519058_Screenshot%202025-04-03%20at%2016.43.13.png)

Pour revenir au panneau latéral, cliquez à nouveau sur **Changer de vue**.

### Modifier la couleur d’une carte

Le codage couleur des tâches peut vous aider à distinguer visuellement la priorité ou l'état :

1. Sélectionnez la carte Asana que vous souhaitez recolorer.
2. Dans le menu contextuel, cliquez sur l’icône **Couleur de remplissage**.
3. Sélectionnez la couleur désirée dans la palette.

### Créer des raccourcis d’action

Vous pouvez créer des [raccourcis d’action](../../../using-miro/facilitation-tools/03-action-shortcuts-beta.md) pour :

- Ouvrir le sélecteur de tickets Asana.
- Créer une nouvelle carte Asana.

## Comment désinstaller l’intégration Asana

Vous pouvez désinstaller l’intégration Asana au niveau de l’équipe ou de manière individuelle.

### Désinstallation au niveau de l’équipe

1. Ouvrez **Paramètres d'équipe** > **Applications & intégrations**.
2. Trouvez **Asana Ticketing** dans la liste des applications installées.
3. Faites défiler vers le bas et cliquez sur **Désinstaller pour l’équipe**.

### Désinstallation individuelle

1. Accédez à **Applications & Intégrations** dans vos paramètres Miro.
2. Trouvez **Asana** **Ticketing** et cliquez sur **Désinstaller pour moi**.

En suivant ces étapes, vous pouvez intégrer et gérer facilement vos tâches Asana dans Miro, améliorant ainsi l'efficacité du workflow et la collaboration sur les deux plateformes.

## Foire aux questions

- **Quels utilisateurs Asana peuvent utiliser l’intégration Asana avec Miro ?** Seuls les utilisateurs autorisés qui font partie de l’équipe ou de l’organisation Miro où le tableau est hébergé peuvent utiliser l’intégration Asana. En outre, ces utilisateurs doivent disposer des permissions nécessaires au sein d’Asana pour interagir avec les tâches.
- **Qui peut voir les tâches Asana une fois importées dans un tableau Miro ?** Tout utilisateur ayant accès au tableau Miro (c’est-à-dire ceux ayant des permissions de consultation, de commentaire ou de modification pour le tableau) peut voir les données Asana importées. Il est important de noter que les utilisateurs n’ont pas besoin d’une autorisation Asana ou d’une licence Asana pour simplement voir les données des tâches importées affichées sur le tableau Miro.
- **Puis-je accéder ou consulter les tâches Asana via l'intégration Miro si je n'y ai pas accès directement dans Asana ?** Non, chaque utilisateur interagit avec l'intégration Asana en utilisant son propre compte Asana. Cela signifie que les utilisateurs peuvent uniquement rechercher, importer ou modifier les tâches Asana dans Miro en fonction des autorisations qu'ils détiennent déjà dans le système Asana. Cependant, une fois que les tâches sont importées sur un tableau Miro, elles deviennent visibles pour tous les autres utilisateurs ayant accès à ce tableau spécifique de Miro.
