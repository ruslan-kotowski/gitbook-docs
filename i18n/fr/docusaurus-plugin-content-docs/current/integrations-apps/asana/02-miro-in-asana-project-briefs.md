**Fonctionnalités clés**

- Les tableaux Miro intégrés dans Asana peuvent accorder des autorisations de lecture, de commentaire ou de modification à d’autres utilisateurs.
- Interagissez avec le contenu du tableau, y compris en y ajoutant des commentaires, du texte ou des formes ou en utilisant l’outil de dessin pour laisser des retours.
- Zoomez et dézoomez facilement pour voir autant de contenu du tableau que vous le souhaitez.

> **Disponible pour :** tous les plans Miro

### Comment installer et autoriser l’application Miro dans Asana

Autorisez et installez l’application Miro à partir de [Asana Marketplace](https://app.asana.com/-/install_platform_ui_app?app_id=1201153108289813).

### Comment intégrer Miro dans les briefs de projet Asana

Ouvrez le tableau Miro que vous souhaitez intégrer.  Cliquez sur le bouton de partage en haut à droite. Cliquez sur Copy board link/span> (Copier le lien du tableau) dans la boîte de dialogue qui apparaît.

copy_board_link.jpg
/span>L’option permettant de copier le lien du tableau

Vous pouvez également copier le lien du tableau à partir de la barre d’adresse de votre navigateur ou à partir de votre tableau de bord.

copy_link_from_dashboard.jpg
/span>Copie du lien sur le menu du tableau

Dans Asana, ouvrez le projet dans lequel vous souhaitez intégrer votre tableau.  Rendez-vous sur l’onglet Overview/span> (Aperçu).

Dans la section **Key resources** (Ressources clés), cliquez sur **Create project brief** (Créer un brief de projet).  Si vous avez déjà un brief de projet, cliquez partout sur son titre.

create_project_brief.jpg
/span>L’option permettant de créer un brief de projet dans Asana

Cliquez sur l’endroit où vous voulez intégrer le tableau dans le brief.  Collez l'URL et un aperçu du tableau s'affichera en dessous. Cliquez sur l'aperçu pour charger le tableau.

board_preview.jpg
/span>Aperçu du tableau Miro dans un brief de projet Asana
