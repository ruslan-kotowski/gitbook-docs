Connecter Google Workspace™ et Miro améliore votre collaboration visuelle de n'importe où, en fournissant des outils puissants et faciles à utiliser qui renforcent l'engagement et la créativité lors des réunions. Avec cette intégration, vous pouvez connecter Miro à Google Drive, Docs, Meet et Agenda.

## Fonctionnalités principales

Une fois le module complémentaire Miro installé, vous pouvez exploiter plusieurs fonctionnalités clés pour rationaliser vos workflows :

- Ajouter un tableau Miro à une [invitation dans Google Agenda](08-miro-for-google-calendar.md).
- Consulter et collaborer sur des tableaux directement dans [Google Meet](09-miro-for-google-meet.md).
- Intégrer une puce intelligente Miro avec un aperçu du tableau dans un [document Google](10-smart-chips-smart-screenshots-for-google.md).
- Enregistrer vos tableaux Miro dans [Google Drive](05-google-drive.md).
- Recevez des notifications, développez les liens des tableaux Miro ou créez un tableau Miro via [Google Chat](01-miro-for-google-chat.md).

:::note
Votre admin Google Workspace devra peut-être installer le module complémentaire Miro pour votre organisation ou équipe Google Workspace. Consultez votre admin si ce module n’est pas disponible.
:::

## Installer le module complémentaire Miro

Pour connecter le module complémentaire Miro aux produits de votre Google Workspace, vous devez d'abord l'installer. Vous pouvez vérifier si le module complémentaire est déjà installé en cherchant le logo « M » de Miro dans la barre latérale de Google Docs ou Calendrier.

Pour installer le module complémentaire :

1. Accédez au [Marketplace Google Workspace](https://workspace.google.com/marketplace/app/miro/1062019541050).
2. Cliquez sur **Installer**.
3. Sélectionnez le compte Google que vous souhaitez associer au module complémentaire.

Une fois le module complémentaire installé, vous verrez l’icône Miro dans votre barre latérale, confirmant l’installation réussie.

## Politique d'utilisation des données utilisateur des services API Google

L'utilisation par Miro de l'information reçue des API Google pour Google Workspace respectera les [Règles d'utilisation des données utilisateur des services API Google](https://developers.google.com/terms/api-services-user-data-policy), y compris les exigences d'utilisation limitée. Les API Google Workspace ne sont pas utilisées pour développer, améliorer ou entraîner des modèles AI et/ou ML généralisés/non personnalisés.

## Foire aux questions

Voici des réponses aux questions courantes sur l'installation du module complémentaire Miro pour Google Workspace.

Je suis un admin Miro. Comment installer le module complémentaire Miro pour mon organisation ?

Les admins Google Workspace peuvent installer et gérer le module complémentaire au nom des utilisateurs de leur organisation. Pour plus de détails, consultez le [Marketplace Google Workspace](https://support.google.com/a/topic/1056395?hl=en&ref_topic=27380).

Pourquoi ne puis-je pas installer le module complémentaire Miro ?

Votre admin a peut-être désactivé le module complémentaire, ou vous devez peut-être lui demander de l’installer pour vous.
