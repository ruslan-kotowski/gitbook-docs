:::note
À partir du 1er février 2026, le Miro Web Clipper ne sera plus disponible à l'installation ni maintenu. Pour les utilisateurs l'ayant déjà installé, il reste fonctionnel "tel quel".

Vous pouvez ajouter des captures d'écran à Miro en les chargeant, en les collant depuis le presse-papier ou en les faisant glisser dans le canevas.
:::

Capturez les pages web dans Chrome et sauvegardez-les très facilement dans votre bibliothèque Miro !

### Utilisation de l’extension

1. Chaque fois que vous souhaitez enregistrer une capture d’écran d’un site web directement dans votre bibliothèque Miro, cliquez sur l’**icône Web Clipper** dans votre navigateur Chrome pour ouvrir l’extension, choisissez une **équipe** où la capture sera stockée et sélectionnez la zone à enregistrer : **Zone visible**, **Zone sélectionnée** ou **Page complète**.

![Web_clipper_menu.jpg](../../../../../../docs/integrations-apps/google/images/21016020037138_Web%20clipper%20menu.jpg)
*Le menu de Miro Web Clipper*

2. Lorsque vous souhaitez ajouter les pages web enregistrées dans un tableau Miro, ouvrez le tableau. Notez que le tableau doit appartenir à l’équipe que vous avez sélectionnée au moment de prendre la capture d’écran.

3. Dans la barre de création, sélectionnez **Outils, Médias et Intégrations** (**+**)**.** Un panneau s'ouvre. Dans l'onglet **Outils**, recherchez Web Clipper. Sélectionnez **Upload**, puis sélectionnez **Web Clipper**.
Une galerie des captures d’écran enregistrées s’ouvre. Vous pouvez cliquer sur celles dont vous avez besoin et les faire glisser et déposer sur votre tableau.

![Miro_web_clipper.gif](../../../../../../docs/integrations-apps/google/images/21016020034962_Miro%20web%20clipper.gif)
*Web Clipper dans la barre d’outils*

Veuillez noter que vous tirerez le meilleur parti du Miro Web Clipper si :

- Votre profil Miro est connecté (si l’icône de l’extension est active, c’est que votre compte est connecté)
- Après avoir installé l’extension, vous avez actualisé les pages web du tableau si elles étaient ouvertes au moment de l’installation (vous n’avez besoin de le faire qu’une seule fois)

:::warning
Web Clipper ne fonctionne pas pour les pages qui nécessitent une autorisation.
:::

### Foire aux questions

1. *J’ai enregistré une capture d’écran, mais elle ne s’affiche pas dans la bibliothèque Web Clipper. Pourquoi ?*
   - Veuillez vous assurer d’avoir choisi la bonne équipe lorsque vous avez enregistré la capture d’écran. La capture d’écran fera partie de la bibliothèque Web Clipper sur les tableaux situés dans cette équipe.
   Veuillez également garder à l’esprit que l’extension ne fonctionne pas sur les pages nécessitant une autorisation.
   Si l'extension ne fonctionne sur aucune page, essayez de **la supprimer et la réinstaller** à nouveau.
