Téléchargez des factures comportant les coordonnées de votre entreprise à des fins fiscales ou pour tout besoin comptable. Vous pouvez télécharger des factures directement depuis vos e-mails de facturation ou depuis les paramètres de votre forfait.

> **Réalisé pour** : les forfaits Starter et Business
> **Qui peut le faire :** les admins d'équipe, les admins d'entreprise, les admins de facturation

:::note
Si vous n'avez pas accès aux paramètres de facturation, contactez votre admin Miro pour obtenir de l'aide.
:::

## Comment trouver une facture

Toutes les factures sont générées par notre fournisseur de paiement, Stripe. Vous trouverez toutes vos factures et vos reçus dans les paramètres de votre forfait. Vous recevrez également toutes vos factures et reçus dans vos e-mails de facturation Miro.

1. Cliquez sur votre avatar de profil, puis cliquez sur **Console d’administration**.
2. Dans la barre latérale gauche, cliquez sur **Facturation**.
   La page Vue d’ensemble de la facturation s’affiche.
3. Cliquez sur l’onglet **Factures** en haut.

:::warning
Si vous avez rétrogradé vers le Free Plan, vous n'aurez plus accès aux paramètres de facturation. Pour consulter vos anciennes factures, essayez de rechercher dans votre boîte de réception les [e-mails de facturation Stripe](07-understanding-your-invoice.md).
:::

## Comment télécharger une facture

Il existe deux façons de télécharger une facture.

Paramètres de facturation E-mails de facturation

1. Suivez les étapes ci-dessus pour trouver votre facture.
2. À côté de la facture, cliquez sur **Télécharger.**
3. La facture sera enregistrée dans le dossier par défaut pour les téléchargements de votre navigateur. En fonction des paramètres de votre navigateur, il se peut qu'on vous demande où enregistrer le fichier avant le téléchargement.

**Carte de crédit**

Lorsque vous payez par carte de crédit, vous recevrez un e-mail de facturation. Dans cet e-mail, vous aurez les options **Télécharger la facture** et **Télécharger le reçu**.

![Credit-card-billing-email.png](../../../../../../docs/plans-billing/billing-and-payments/images/21020264720914_Credit-card-billing-email.png)
*Télécharger une facture depuis un e-mail de facturation*

**Facturation**

Si vous payez par facturation, vous recevrez un e-mail de facturation contenant l’option **Télécharger la facture**. Une fois la facture payée, vous recevrez un deuxième e-mail contenant le reçu de paiement.

:::warning
Si vous devez modifier les informations de votre entreprise pour régler une facture, veuillez [contacter le service d'assistance Miro](../../using-miro/tools/troubleshooting/06-contacting-miro-support.md).
:::
