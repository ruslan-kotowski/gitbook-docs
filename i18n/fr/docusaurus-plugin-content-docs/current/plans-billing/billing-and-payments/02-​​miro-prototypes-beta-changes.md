Miro Prototypes est un [module complémentaire payant](../miro-add-ons/01-purchase-and-manage-add-ons.md) pour les forfaits Starter, Business et Enterprise.

Cet article explique ce qui change pour Miro Prototypes, quand, et comment cela impacte votre équipe.

:::note
Pendant la bêta, ces capacités étaient appelées Miro Prototyping. Elles s’appellent maintenant Miro Prototypes.
:::

## Qu'est-ce qui change ?

- **Enterprise (octobre 2025)**
  Le programme bêta prend fin. Pour activer Miro Prototypes pour votre organisation, en tant qu'admin d'entreprise ou admin de facturation, faites l'un des suivants :
  - Contactez votre représentant commercial Miro.
  - Complétez [ce formulaire](https://miro.com/prototyping/contact/sales/).
- **Starter et Business (août 2025)**
  Pour continuer à utiliser les fonctionnalités de Miro Prototypes, en tant qu'admin d'entreprise ou admin de facturation, vous devez acheter le module complémentaire.
- **Free et Education (août 2025)**
  Pour être éligible à l'achat du module complémentaire Miro Prototypes, les admins doivent changer de forfait vers un plan payant.

:::note
Les prototypes existants restent modifiables dans tous les forfaits. Seules les fonctionnalités avancées, comme les outils AI, les lignes de connexion et le mode aperçu, sont désactivées si vous n'achetez pas le module complémentaire Miro Prototypes.
:::

## Aperçu des tarifs

Le module complémentaire Miro Prototypes inclut un prix de base et des packs flexibles de crédits d’IA. Cela vous permet de choisir le nombre de crédits adapté aux besoins de votre équipe.

Le module complémentaire est facturé avec votre forfait et se renouvelle automatiquement sauf si vous l’annulez.

Voici comment fonctionnent la facturation et les crédits :

- Ajouté aux abonnements Starter, Business ou Enterprise
- Votre pack choisi augmente votre limite mensuelle de crédits d’IA
- Les crédits se réinitialisent chaque mois
- Les crédits sont partagés entre toutes les fonctionnalités Miro IA, y compris Prototypes

Si vous annulez votre abonnement Starter ou Business, votre module complémentaire Prototypes sera également annulé. Pour Enterprise, la facturation et les renouvellements suivent les modalités de votre contrat.

Les admins d’entreprise d’Enterprise peuvent [contacter leur équipe de vente Miro](https://miro.com/prototyping/contact/sales/) pour discuter de tarifs personnalisés.

**Plus d'informations :** Consultez [Gérer et acheter des modules complémentaires](../miro-add-ons/01-purchase-and-manage-add-ons.md).

:::note
La bibliothèque de composants des Prototypes (Wireframing) reste gratuite pour tous les utilisateurs.
:::

## Obtention du module complémentaire

- **Enterprise**
  [Contactez votre représentant commercial Miro](https://miro.com/prototyping/contact/sales/) pour l'achat et l'activation. Les fonctionnalités de Miro Prototypes continueront de fonctionner jusqu'à la fin du programme bêta, après quoi elles nécessiteront le module complémentaire.
- **Starter et Business**
  Gérez dans les Paramètres de facturation. Vous pouvez éventuellement vous inscrire à un [essai gratuit de 7 jours](../../using-miro/miroverse/prototyping/07-miro-prototypes-add-on.md).

## Foire aux questions

**Vais-je perdre l'accès à mes prototypes si je n'achète pas le module complémentaire ?**

Non, vous pourrez toujours modifier les cadres et le contenu de l'appareil. Seules les fonctionnalités avancées, telles que les outils d'IA, les lignes de connexion et le mode aperçu seront désactivées si le module complémentaire n'est pas actif.

**Puis-je essayer le module complémentaire avant de l'acheter ?**

Oui. Avec un forfait Starter ou Business, vous pouvez démarrer un essai gratuit de 7 jours depuis vos paramètres de facturation. Les clients Enterprise peuvent demander un essai via leur représentant commercial Miro.

**Qui peut acheter et gérer le module complémentaire ?**

Pour les forfaits Starter et Business, les admins d’entreprise et les admins de facturation peuvent acheter dans leurs paramètres de facturation. Pour Enterprise, les admins d’entreprise peuvent acheter via leur représentant de l’équipe de vente Miro. Les admins d’entreprise Enterprise peuvent également surveiller le module complémentaire dans les paramètres de facturation de la console d’admin.

**Les invités et les lecteurs ont-ils accès aux fonctionnalités de Miro Prototypes ?**

[Les invités](../../using-miro/sharing-boards/07-collaboration-with-guests.md) peuvent voir et interagir avec les prototypes, mais seuls les membres ayant une licence complète peuvent créer et modifier avec l’IA.

**Comment fonctionnent les crédits d’IA avec le module complémentaire Miro Prototypes ?**

Le module complémentaire inclut des packs de crédits d’IA flexibles. Les crédits sont partagés entre toutes les fonctionnalités de Miro IA, y compris Prototypes. Pour en savoir plus sur les crédits Miro IA, consultez [crédits Miro IA](03-miro-ai-credits.md).
