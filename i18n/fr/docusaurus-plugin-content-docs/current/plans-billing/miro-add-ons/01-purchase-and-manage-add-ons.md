Les modules complémentaires débloquent des fonctionnalités et des capacités qui améliorent la plateforme Miro. Par exemple, le module complémentaire Miro Prototypes vous permet d'utiliser les fonctionnalités avancées d’IA et de prototypage.

Miro propose actuellement les modules complémentaires suivants :

- [**Module complémentaire de crédits Miro IA**](../../using-miro/miro-ai/17-miro-ai-credits-add-on.md)
  Augmente votre allocation mensuelle de crédits Miro IA.
- [**Module complémentaire Miro Prototypes**](../../using-miro/miroverse/prototyping/07-miro-prototypes-add-on.md)
  Génère des prototypes IA à partir de captures d'écran, de diagrammes, de documents, d'images ou d'objets de brainstorming sélectionnés, et inclut des crédits supplémentaires d'IA.
- (Enterprise uniquement) [**Enterprise Guard**](../../enterprise-administration/enterprise-subscription-management/enterprise-guard-overview/02-enterprise-guard-introduction.md)
  Améliore la sécurité et la gouvernance pour aider les organisations à identifier et gérer le contenu sensible au sein de leur abonnement.

## Acheter des modules complémentaires

En tant qu'admin de facturation ou admin d’entreprise, vous pouvez acheter des modules complémentaires pour votre organisation à tout moment pendant votre période de facturation.

:::note
Pour les abonnements Enterprise, les admins d’entreprise doivent contacter leur équipe de compte.
:::

Suivez ces étapes :

1. Depuis votre tableau de bord, en haut à droite, cliquez sur **Mettre à niveau**.
2. Une fenêtre modale s'ouvre, affichant les tarifs des forfaits et modules complémentaires.
3. Faites défiler vers le bas pour examiner les modules complémentaires.
4. Pour le module complémentaire que vous souhaitez acheter, cliquez sur **Ajouter à l'abonnement**.
5. Si applicable, choisissez le nombre de crédits que vous souhaitez inclure avec votre module complémentaire.

   > ✏️ Le module complémentaire Miro Prototypes inclut un minimum de 350 crédits d’IA par mois, qui sont alloués à votre organisation. Pour plus d'informations, consultez [Miro Prototypes add-on](../../using-miro/miroverse/prototyping/07-miro-prototypes-add-on.md).
6. Pour finaliser votre achat, suivez les instructions à l'écran.
   Vous êtes facturé en utilisant le mode de paiement mis en place pour votre organisation.

## Facturation et renouvellements des modules complémentaires

Les modules complémentaires sont facturés avec votre abonnement existant et liés à votre organisation. Vous pouvez acheter un module complémentaire à tout moment pendant votre période de facturation et payer un montant calculé au prorata pour le temps restant avant votre prochain renouvellement. Vos modules complémentaires se renouvellent automatiquement avec votre abonnement dans une facture unique.

- Pour les forfaits mensuels, le module complémentaire se renouvelle chaque mois au tarif mensuel.
- Pour les forfaits annuels, le module complémentaire se renouvelle chaque année.

:::tip
Les tarifs des modules complémentaires annuels incluent une remise de 20 %.
:::

## Utilisation des crédits d’IA

La limite de crédits d’IA pour votre organisation inclut les crédits du forfait et des modules complémentaires. Vos crédits d’IA s’appliquent à l’organisation et peuvent être utilisés pour toute action IA dans Miro par tout membre disposant d’une licence complète.

Pour les forfaits mensuels et annuels, les crédits d’IA sont réinitialisés mensuellement.

**Plus d'informations :** Voir [crédits Miro IA](../billing-and-payments/03-miro-ai-credits.md).

## Annuler les modules complémentaires

Vous pouvez annuler les modules complémentaires à tout moment. Après l'annulation, les modules complémentaires restent actifs sur votre compte jusqu'à la fin de votre période de facturation actuelle.

Suivez ces étapes :

1. Depuis votre tableau de bord Miro, cliquez sur votre avatar dans le coin supérieur droit.
2. Sélectionnez **Console d'administration | Paramètres**.
3. Dans la barre latérale gauche, cliquez sur **Facturation**.
4. Dans la section **Actions de facturation**, pour le module complémentaire que vous souhaitez annuler, cliquez sur **Annuler le module complémentaire**.
5. Une boite de dialogue s'ouvre.
6. Cliquez sur **Continuer pour annuler**.
   La vue **Facturation** affiche maintenant la date à laquelle le module complémentaire sera supprimé à la fin de votre période de facturation actuelle. Lorsque le module complémentaire est supprimé, la limite de crédits d’IA pour votre organisation est réduite à celle de votre allocation de forfait.

:::note
Vous pouvez réactiver le module complémentaire à tout moment avant le renouvellement.
:::

## Forfaits éligibles pour les modules complémentaires

Les modules complémentaires sont disponibles pour les abonnements mensuels ou annuels payants, à savoir les forfaits Starter, Business, et Enterprise.

Si vous êtes sur un plan Free, apprenez comment [changer de forfait](../manage-your-subscription-and-plan/03-upgrade-your-plan.md).

Si votre forfait a expiré, vous devez alors [réactiver votre abonnement](../manage-your-subscription-and-plan/08-reactivate-your-subscription.md).

Si vous êtes actuellement en période d'essai gratuite du plan Business, attendez la fin de l'essai pour ensuite acheter vos add-ons.

:::note
Pour les abonnements Enterprise, les admins d’entreprise doivent contacter leur équipe de compte.
:::

## Foire aux questions

**Comment ajouter plus de crédits au forfait actuel (augmenter le solde de crédits) ?**

Quand votre compte est à court de crédits d’IA, une fenêtre modale s'ouvre dans Miro pour vous présenter vos options pour des crédits d’IA supplémentaires, y compris le module complémentaire payant [Miro IA](../../using-miro/miro-ai/17-miro-ai-credits-add-on.md). Vous pouvez changer de forfait pour déverrouiller plus de crédits d’IA ou demander le module complémentaire Miro IA pour obtenir plus de crédits via le formulaire de contact du service d’assistance. Les admins du forfait Enterprise doivent contacter leur équipe de compte pour obtenir le [module complémentaire Miro IA](../../using-miro/miro-ai/17-miro-ai-credits-add-on.md).

**Puis-je activer des modules complémentaires sur une base mensuelle si mon forfait est actuellement annuel ?**

Non, la période de facturation des modules complémentaires doit être la même que celle de l'abonnement de votre forfait de base. Pour activer des modules complémentaires sur une base mensuelle, vous devez [rétrograder vers un forfait mensuel](../manage-your-subscription-and-plan/04-downgrade-your-plan.md).
