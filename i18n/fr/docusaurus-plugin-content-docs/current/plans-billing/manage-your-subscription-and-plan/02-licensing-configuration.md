En tant qu’admin d’entreprise, vous pouvez définir la configuration des licences pour votre organisation. Votre configuration de licences spécifie si n'importe qui dans votre organisation peut inviter de nouveaux membres à rejoindre leur équipe.

:::note
La configuration des licences est un réglage disponible dans les forfaits Business. Pour en savoir plus sur la définition de la politique de partage pour un forfait Enterprise, consultez [Politique de partage sur le forfait Enterprise](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md).
:::

La configuration des licences est un paramètre au niveau de l’organisation. Si activé, chaque équipe peut éventuellement permettre à tous ses membres d'ajouter des licences.

Une licence est ajoutée à votre abonnement lorsqu'un utilisateur extérieur à votre organisation accepte une invitation d'un membre de l'équipe existant.

Dans la console admin, lorsque vous activez votre configuration de licences, une bannière apparaît en haut des sections **Facturation** et **Utilisateurs actifs**, et sous les **Paramètres d'invitation de l'équipe** dans les autorisations de l'équipe.

Pour les forfaits Business, la configuration des licences est activée par défaut. Pour vérifier votre configuration des licences, consultez Configurer la configuration des licences.

:::tip
Dans les paramètres d'équipe, les admins d’entreprise peuvent spécifier si tous les membres ou seulement les admins peuvent ajouter des licences pour une équipe donnée.
:::

## Définir la configuration des licences

### Forfait Business

1. Depuis votre tableau de bord Miro, cliquez sur votre avatar dans le coin supérieur droit, puis sélectionnez **Console admin**.
2. Allez sur **Facturation**.
3. Sous **Configuration des licences**, basculez l’option **Tout le monde peut agrandir l’équipe** sur la position activée. Pour désactiver, basculez sur la position off.

## Et ensuite ?

Avec la configuration des licences activée pour votre organisation, chaque équipe de votre abonnement peut décider si elle autorise tous les membres à ajouter de nouvelles licences, à savoir des membres nouvellement invités.

:::note
Les équipes nouvellement créées ont **tous les membres de l'équipe** dans les autorisations de l'équipe activé par défaut.
:::

Lorsqu'un membre partage un tableau avec un invité, il voit le message suivant l'informant que l'ajout d'un nouveau membre entraîne une augmentation des licences et des coûts.

**Plus d’informations :** Voir [Partager des tableaux](../../using-miro/sharing-boards).
