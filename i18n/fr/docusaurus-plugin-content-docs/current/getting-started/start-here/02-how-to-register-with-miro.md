Dès que vous vous connectez à Miro, vous pouvez créer votre équipe et des tableaux et inviter d’autres utilisateurs sur la plateforme. L’inscription est gratuite.

## Comment vous inscrire

Si une invitation à rejoindre Miro vous a été envoyée par e-mail, acceptez-la directement à partir de cet e-mail. Vous devrez ensuite configurer un mot de passe pour Miro avant que votre profil nouvellement créé soit redirigé dans une équipe ou sur un tableau pour que vous puissiez commencer à collaborer immédiatement.

Si vous n’avez pas reçu d’invitation, vous pouvez vous inscrire sur Miro avec votre adresse e-mail ou avec votre compte Google, Slack, Office 365, Apple ID ou Facebook, puis créer une nouvelle équipe ou en rejoindre une existante.

Adresse e-mail Connexion via un tiers SSO

1. Ouvrez la [page d’inscription](https://miro.com/signup/).
2. Remplissez les champs **Name (Nom)**, **Work email (Adresse e-mail professionnelle)** et **Password (Mot de passe)**.
3. Lisez **les conditions d’utilisation et la politique de confidentialité de Miro**, puis cochez la case.
4. Cochez la case **I agree to receive Miro news and updates (J’accepte de recevoir les nouvelles et les mises à jour de Miro)** pour rester au courant de nos dernières sorties de produits.
5. Cliquez sur **Get started now (Démarrer)**.

- Si votre organisation utilise la [connexion unique](../../using-miro/tools/troubleshooting/10-i-can't-log-in-via-sso.md), la page de connexion via le SSO s’ouvrira par redirection automatique. Utilisez les identifiants de votre fournisseur d’identité pour vous inscrire.
- Si votre adresse e-mail est déjà enregistrée dans Miro, vous verrez le message correspondant. [Connectez-vous à Miro](https://miro.com/login/) à l’aide de votre adresse e-mail pour accéder à votre profil. Vous pouvez [réinitialiser votre mot de passe](../../using-miro/managing-your-profile/05-how-to-change-your-password.md) (article disponible uniquement en anglais) si vous ne vous en souvenez plus. Consultez l’article [Problèmes liés aux e-mails de réinitialisation de mot de passe](../../using-miro/tools/troubleshooting/12-issues-with-confirmation-code-or-password-reset-emails.md) si vous ne parvenez pas à récupérer votre mot de passe.

4. Si votre adresse e-mail n’est pas encore enregistrée dans Miro et si vous ne devez pas vous connecter via le SSO, vous devrez soumette votre code de confirmation dans une nouvelle page qui s’ouvrira automatiquement.

*![signing_up_with_email_to_Miro.gif](../../../../../../docs/getting-started/start-here/images/21017429154962_signing%20up%20with%20email%20to%20Miro.gif)
Page de confirmation de l’e-mail*

5. Trouvez l’e-mail contenant le code de confirmation dans votre boîte de réception. Vous pouvez soit cliquer sur le bouton **Confirm your email (Confirmez votre adresse e-mail)** situé dans l’e-mail, soit saisir le code sur la page du code de confirmation.

*![email_complet_enregistrement.jpg](../../../../../../docs/getting-started/start-here/images/21017429149714_complete%20registration%20email.jpg)
Code de confirmation*

Si vous n’avez pas reçu de code de confirmation, essayez les étapes de dépannage de l’article [Problèmes avec les e-mails de code de confirmation](../../using-miro/tools/troubleshooting/12-issues-with-confirmation-code-or-password-reset-emails.md).

Si vous ne confirmez pas votre adresse e-mail dans les 7 jours, votre profil vide sera supprimé.

Accélérez le processus d’inscription en vous connectant avec votre compte **Google, Facebook, Slack, Office 365** existant ou encore avec votre **identifiant Apple**.

1. Ouvrez la [page d’inscription](https://miro.com/signup/).
2. Choisissez le service avec lequel vous souhaitez vous inscrire et connectez-vous.

![third-party_sign-in.jpg](../../../../../../docs/getting-started/start-here/images/21017416082706_third-party%20sign-in.jpg)
*Signature d’un tiers*

:::note
Lorsque vous utilisez l’option des identifiants Apple pour la première fois, vous pouvez choisir de partager votre adresse e-mail ou de la masquer. Si vous choisissez **Share my email (Partager mon adresse e-mail)**, l’adresse e-mail de votre identifiant Apple sera utilisée comme adresse e-mail de votre profil Miro. Si vous sélectionnez **Hide my email (Masquer mon adresse e-mail)**, une nouvelle adresse e-mail sera générée pour votre profil : vous devrez utiliser cette adresse pour vous connecter à Miro. Les notifications Miro seront toujours envoyées à l’adresse e-mail associée à votre identifiant Apple. L’inscription avec Apple est disponible pour les appareils iPhone (iOS 13 et ultérieur), iPad (iPadOS 13 et ultérieur), la version Web ou l’[application de bureau](../apps-for-devices/05-desktop-app.md).
:::

Si votre entreprise a configuré l’[authentification unique](../../enterprise-administration/security-integrations/single-sign-on-sso/09-single-sign-on-sso.md) sur Miro pour les utilisateurs disposant de votre domaine d’entreprise, la page de connexion par SSO s’ouvrira automatiquement et vous pourrez y saisir les identifiants de votre fournisseur d’identité pour continuer sur Miro. Si vous rencontrez des problèmes, consultez l’article [Je ne parviens pas à me connecter via l’authentification unique (SSO)](../../using-miro/tools/troubleshooting/10-i-can't-log-in-via-sso.md).

## Créer ou rejoindre une équipe Miro

Une équipe dans Miro est un espace où les utilisateurs peuvent créer, stocker et partager leurs tableaux et leurs projets.

Si vous avez reçu une invitation à une équipe ou si votre profil a été provisionné dans une équipe Miro avant l’enregistrement de votre profil, ce dernier sera automatiquement redirigé vers cette équipe pour que vous puissiez commencer à collaborer avec vos collègues et vos amis immédiatement. Si vous devez créer des équipes supplémentaires, consultez l’article [Comment créer une équipe dans Miro](miro-dashboard/02-how-to-create-a-team-in-miro.md).

Si vous n’avez pas reçu d’invitation à une équipe, vous aurez la possibilité d’en créer une ou de rejoindre votre équipe d’entreprise dès que vous vous connecterez pour la première fois.

Lors de la création de votre première équipe, vous pouvez directement y ajouter des collaborateurs.

![invite_teammates.jpg](../../../../../../docs/getting-started/start-here/images/21017416083986_invite%20teammates.jpg)
*Inviter des membres de l’équipe lors de la création d’une équipe Miro*

Si des équipes sont ouvertes aux utilisateurs [au sein de votre domaine](../../administration/team-management/02-manage-team-signup-mode.md), vous pourrez les rejoindre ou demander à les rejoindre. Cette demande sera envoyée aux admins. En attendant l’approbation du Responsable, vous pouvez créer votre propre équipe.

![Join_other_teams.jpg](../../../../../../docs/getting-started/start-here/images/21017429153554_Join%20other%20teams.jpg)
*Les options permettant de rejoindre une équipe d’entreprise ou d’en créer une nouvelle lors de l’inscription à Miro*

## Ajouter des détails à votre profil

Une fois votre profil créé, rendez-vous dans [Profile settings (Détails du profil)](../../using-miro/managing-your-profile/01-profile-settings.md) pour ajouter une photo et des informations de profil.

:::note
S’il n’y a pas d’activité dans votre profil Miro pendant deux semaines, votre session Miro sera automatiquement déconnectée pour des raisons de sécurité.
:::
