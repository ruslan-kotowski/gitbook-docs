Créez et partagez des modèles personnalisés pour uniformiser les processus et éviter d’effectuer du travail en double.

> 🚀 Partagez vos modèles personnalisés avec le monde entier. [Publiez sur Miroverse](https://miro.com/miroverse/submission/?backToUrl=/) et aidez plus de 60 millions d’utilisateurs à démarrer leur travail.

> **Disponible pour :**les forfaits Starter, Business, Enterprise et Education **Qui peut le faire ?** Membres d’équipe

## Créer un modèle personnalisé

À partir d’un tableau entier  À partir d’une partie d’un tableau  À partir de zéro

1. Sélectionnez les trois points verticaux dans la barre du tableau.
   Le menu **principal** s'ouvre.
2. Sélectionnez **Tableau** > **Exporter** > **Enregistrer le tableau comme modèle**.
   La fenêtre modale **Enregistrer comme modèle** s'ouvre.
3. Suivez les instructions qui s'affichent à l'écran.
4. Sélectionnez **Enregistrer le modèle**.

:::warning
Le contenu des [notes](../../../using-miro/essential-tools/17-visual-notes.md) n’est pas enregistré dans un modèle personnalisé.
:::

1. [Sélectionnez un groupe d’objets](../../../using-miro/working-on-the-board/10-working-with-objects.md) que vous souhaitez enregistrer en tant que modèle. Assurez-vous qu’ils sont déverrouillés. Si vous souhaitez utiliser des objets verrouillés, déverrouillez-les d’abord et enregistrez le modèle, puis reverrouillez-les en mode édition.
2. Cliquez sur les trois points dans le menu contextuel.
3. Choisissez **Enregistrer comme modèle**, mettez éventuellement à jour les détails de votre modèle, puis cliquez sur **Enregistrer**.

![enregistrer_les_objets_comme_modèle_.jpg](../../../../../../../docs/getting-started/start-here/your-first-board/images/4810085542802_save%20objects%20as%20template%20.jpg)*Option "Enregistrer comme modèle" dans le menu contextuel de l’objet*

1. Cliquez sur l’icône **Modèles** dans la barre d’outils de création.
2. Naviguez jusqu’à la section **MODÈLES PERSONNALISÉS** du sélecteur de modèles.
3. Cliquez sur l’option qui vous convient en fonction de votre forfait (Entreprise, Équipe ou Personnel).
   > ✏️ Les options que vous voyez dépendent de votre forfait. Pour le forfait Starter, les options "Personnel" et "Équipe" sont disponibles dans la rubrique Modèles personnalisés.
   > Les options "Entreprise", "Équipe" et "Personnel" seront disponibles pour les forfaits Business, Enterprise et Education.
4. Cliquez sur **Créer un nouveau modèle**. Un nouveau tableau s’ouvre, dans lequel vous pouvez créer un nouveau modèle à partir de zéro.

![custom_templates_create_new_template.gif](../../../../../../../docs/getting-started/start-here/your-first-board/images/14706321586834_custom_templates_create_new_template.gif)
*Créer un nouveau modèle à partir de zéro*

Votre modèle est nommé **Nouveau modèle** par défaut.

Pour mettre à jour les détails de votre modèle (nom, description, état de partage, aperçu), procédez comme suit :

1. Sélectionnez le nom du modèle dans le coin supérieur gauche.
2. Effectuez vos modifications, puis cliquez sur **Enregistrer les modifications** pour mettre à jour.![customizing_template_info.gif](../../../../../../../docs/getting-started/start-here/your-first-board/images/9624752195218_customizing_template_info.gif)*Enregistrement d’un nouveau modèle*

:::note
Les modèles personnalisés sont enregistrés dans la bibliothèque de l’équipe à laquelle appartient votre tableau actuel. Si vous enregistrez votre modèle personnalisé dans une équipe, vous ne pourrez pas y accéder depuis une autre équipe, sauf si vous créez le modèle séparément ou s’il est partagé avec l’ensemble de l’entreprise (avec les forfaits Enterprise et Business).
:::

## Utiliser et gérer vos modèles

### Mélanger et associer les modèles

Vous pouvez ajouter autant de modèles que vous le souhaitez à votre tableau. N’hésitez pas à mélanger les modèles pour répondre au mieux aux besoins de votre projet.

### Afficher un aperçu, obtenir des détails et utiliser un modèle personnalisé

Lorsque vous visualisez des modèles personnalisés, le nom et la photo de profil du créateur du modèle s’affichent sous la carte du modèle. Passez la souris sur un modèle pour voir les options d’utilisation ou l’aperçu du modèle.

![custom_templates_preview.png](../../../../../../../docs/getting-started/start-here/your-first-board/images/9625843845010_custom_templates_preview.png)*Modèles personnalisés dans le sélecteur de modèles*

L’aperçu permet d’identifier facilement le bon modèle avant de l’ajouter à un tableau. L’aperçu montre le nom du modèle, sa description et un petit exemple du modèle. Vous pouvez également modifier et supprimer votre modèle ici.

:::note
Si vous souhaitez modifier la zone d’aperçu du tableau, modifiez votre modèle et [réinitialisez la zone de la vue de démarrage](../../../using-miro/sharing-boards/03-sharing-boards-and-inviting-collaborators.md).
:::

![custom_template_preview.png](../../../../../../../docs/getting-started/start-here/your-first-board/images/11167923149074_custom_template_preview.png)*Aperçu du modèle personnalisé*

### Modifier et supprimer votre modèle

> **Installation par :** Propriétaires de modèles, admins d’entreprise avec [Administrateur de contenu](../../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md) (sur le forfait Enterprise)

:::warning
Les administrateurs de contenu peuvent supprimer des modèles et modifier les détails du tableau. S’ils souhaitent modifier le contenu d’un modèle, ils doivent s’ajouter au tableau par le biais des paramètres de partage.
:::

Vous pouvez facilement modifier ou supprimer les modèles que vous avez créés. Pour modifier ou supprimer un modèle :

1. Naviguez dans la galerie de modèles jusqu’au modèle que vous souhaitez modifier ou supprimer.
2. Passez la souris sur le modèle que vous souhaitez modifier et cliquez sur les trois points du menu contextuel. Les options suivantes apparaissent :
   - Éditer
   - Supprimer![custom_templates_edit_template.png](../../../../../../../docs/getting-started/start-here/your-first-board/images/14706321594770_custom_templates_edit_template.png)*Boutons Modifier et Supprimer dans le sélecteur de modèles*
3. Pour modifier les détails du modèle, cliquez sur l’option **Modifier**.
4. Cliquez sur le nom du modèle dans le coin supérieur gauche. Vous pouvez modifier le nom, la description, la zone de prévisualisation et les options de partage. Cliquez sur **Enregistrer les modifications** lorsque vous avez terminé.
5. Pour supprimer un modèle, cliquez sur l’option **Supprimer.** Cela supprimera immédiatement votre modèle. Si vous souhaitez annuler cette suppression, un message apparaîtra au bas de votre tableau avec une option permettant d’annuler la suppression.

#### **Édition collaborative de modèles**

> Qui peut le faire : Propriétaires et éditeurs de tableaux, toute personne disposant d’une autorisation de partage

La modification des modèles personnalisés peut désormais se faire en collaboration, ce qui élimine le besoin de contrôle des versions et les allers-retours par e-mail. Grâce aux outils de partage et de collaboration, les équipes peuvent travailler en toute transparence pour créer des modèles pour leurs groupes ou pour l’ensemble de l’entreprise.

Pour permettre le partage et la collaboration, procédez comme suit :

1. Cliquez sur l’icône **Tempates** dans la barre d’outils de création.
2. Sélectionnez le modèle que vous souhaitez modifier, cliquez sur **...** dans le coin supérieur droit du modèle et choisissez **Modifier**.
3. Lorsque le modèle sera chargé, il aura sa propre URL. Vous pouvez maintenant cliquer sur le bouton **Partager** et choisir les personnes que vous souhaitez inviter à collaborer avec vous.
4. Vous et vos collaborateurs verrez maintenant les boutons "Afficher les curseurs des collaborateurs" et "Commenter" de la barre d’outils, et toutes les personnes invitées pourront travailler ensemble sur le modèle.
5. Lorsque vous avez terminé vos modifications, cliquez sur **Enregistrer et quitter** dans le coin supérieur gauche de votre tableau pour enregistrer vos modifications.![custom_templates_sharing_collaboration.gif](../../../../../../../docs/getting-started/start-here/your-first-board/images/14706316557330_custom_templates_sharing_collaboration.gif)
   *Permettre la collaboration sur des modèles personnalisés*

### Accès aux modèles de société et d’équipe

Pour faciliter la navigation, les modèles d’entreprise et d’équipe sont désormais regroupés sous un seul nom d’entreprise personnalisé dans la section Modèles personnalisés. Le nom de l’entreprise, tel qu’il figure dans les paramètres de l’entreprise, sera affiché, suivi du mot "modèles" (par exemple, **Mycompany templates**).

Lorsque vous accédez à cette zone, vous voyez deux onglets en haut du panneau de droite : **Entreprise** et **équipe**. Tous les modèles que vous avez créés dans le cadre de votre équipe ou que vous avez partagés avec elle se trouvent dans l’onglet Équipe. Tous les modèles partagés avec l’entreprise se trouvent sous l’onglet Entreprise.![custom_templates_company_and_team_tabs.png](../../../../../../../docs/getting-started/start-here/your-first-board/images/14706316559762_custom_templates_company_and_team_tabs.png)
*Navigation dans les modèles personnalisés avec les onglets Entreprise et Équipe*

### Placer en une un modèle personnalisé

> **Disponible pour :**les forfaits Starter, Business et Enterprise **Qui peut le faire ?** les admins d’entreprise

Les admins d’entreprise peuvent  consulter le sitepour trouver des modèles de fonctionnalités qui correspondent à leurs meilleures pratiques internes et à leurs méthodes de travail uniques. Les modèles en vedette ont un badge bleu et apparaissent en haut d’un dossier de modèles personnalisés. Les utilisateurs peuvent facilement trouver et réutiliser les modèles personnalisés présentés.

Pour placer un modèle en une, ouvrez la page des modèles, faites défiler jusqu’à **À propos de ce modèle** et cliquez sur **Placer en une****.**

## Partager un modèle personnalisé

### Niveaux d’accès des modèles

Gardez les modèles privés ou partagez-les avec votre équipe ou votre entreprise pour éviter de dupliquer le travail.

Il existe trois niveaux d’accès pour les modèles personnalisés : *Personnel*, *équipe* et *entreprise*.

- Les modèles **personnels** ne sont visibles que pour leur créatrice ou créateur.
- Les modèles **partagés avec l’équipe** sont disponibles pour chaque membre de l’équipe.
- Les modèles **partagés avec l’entreprise** sont partagés entre toutes les équipes de l’abonnement.

:::note
Avec le forfait Business, tous les membres de l’équipe peuvent publier **des modèles d**’entreprise sans l’approbation préalable de l’admin. Ce paramètre est appliqué par défaut.
:::

Vous pouvez mettre à jour les niveaux d’accès depuis le sélecteur de modèles en passant en mode de modification :

1. Cliquez sur le bouton **Modèles** dans la barre d’outils de création.
2. Choisissez le niveau d’accès de votre modèle : Personnel, Équipe, Entreprise.
3. Cliquez sur les **trois points** dans le coin supérieur droit du modèle et sélectionnez **Modifier**.
4. Cliquez sur le nom du modèle dans le coin supérieur gauche du tableau, modifiez votre niveau d’accès, puis cliquez sur **Enregistrer les modifications** pour valider la mise à jour.

### Partage de liens des modèles

Partager des liens vous permet de diriger les autres pour qu’ils trouvent rapidement le modèle approprié, étend la portée des ressources recommandées et vous aide à créer votre propre [Miroverse](../../../using-miro/miroverse/01-what-is-miroverse.md) privé.

Accédez au modèle que vous souhaitez partager et copiez le lien de partage d’une de ces façons :

- Cliquez sur les trois points dans le menu contextuel et sélectionnez **Copier le lien**.
- Cliquez sur Aperçu pour afficher les détails du modèle et sélectionnez **Copier le lien** **à partager** en haut à droite.

![lien_du_modèle_copier.png](../../../../../../../docs/getting-started/start-here/your-first-board/images/11168231423890_copy_template_link.png)*L’option permettant de copier un lien de modèle sur l’aperçu du modèle.*

En ouvrant le lien, le membre de votre équipe arrivera sur la page de prévisualisation du modèle. Notez que vous ne pouvez copier que des liens vers les modèles Équipe et Entreprise.

:::note
Les notes de visibilité indiquent qui peut visualiser certains modèles personnalisés. Ces derniers sont indiqués en cliquant sur les trois points sur une carte de modèle (visible à), et dans l’aperçu du modèle (visible uniquement à). Par exemple, si vous créez un modèle uniquement pour l’équipe de développeurs, lorsque quelqu’un prévisualise le modèle, il verra "Visible uniquement pour l’équipe de développeurs".
:::

> **Disponible pour :** les forfaits d’entreprise, Business Plan **Mise en place par :** les admins d’entreprise

- Créer des modèles d’entreprise
- Gérer (modifier et supprimer) les modèles partagés de l’entreprise/de l’équipe
- Obtenir des informations d’administration sur l’utilisation des modèles

## Foire aux questions

Puis-je partager mes modèles personnalisés avec d’autres utilisateurs ?

Oui. Le moyen le plus rapide d’y parvenir est d’utiliser l’option Copier le lien à partager dans l’aperçu d’un modèle. Si vous disposez d’un forfait Business, vous pouvez partager votre modèle avec votre équipe ou avec votre organisation par le biais du sélecteur de modèles. Indiquez simplement à vos collaborateurs le nom du modèle et ils pourront le trouver dans les modèles d’équipe et à l’aide de la barre de recherche.
Si vous bénéficiez du forfait Enterprise, le partage dépendra des [paramètres choisis par l’admin de votre entreprise](../../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md).

Puis-je partager mon tableau sous forme de modèle en envoyant un lien ?

Oui, si les paramètres de contenu du tableau sont correctement définis, tout le monde peut maintenant faire une copie de votre tableau à l’aide d’un simple lien.

1. Ouvrez le menu **Partager** du tableau > **Paramètres de partage** > **Autorisations.**
2. Autorisez toute personne ayant accès au tableau à copier le contenu du tableau (notez que le menu est disponible uniquement sur les forfaits payants ; l’option est activée et non configurable sur les tableaux du [forfait Free](../../../plans-billing/miro-plans/09-free-plan.md)).
3. Partagez le tableau pour [un affichage public](../../../using-miro/sharing-boards/03-sharing-boards-and-inviting-collaborators.md#partage-de-tableaux-via-un-lien-public).
4. Une fois le lien du tableau partagé, les utilisateurs enregistrés de Miro peuvent désormais y accéder et utiliser l’option permettant de dupliquer le tableau.

Puis-je importer le modèle d’un autre utilisateur dans mon Miro ?

Oui. Il vous suffit de sélectionner le modèle, de le copier puis de le coller sur votre tableau, ou de dupliquer le tableau modèle pour votre propre équipe et de l’enregistrer en tant que modèle. Notez que l’option permettant de copier le contenu et le tableau peut être restreinte par le propriétaire du tableau.
Vous pouvez également découvrir [restreindre la copie et l’exportation de tableaux](../../../using-miro/sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md).

Comment puis-je supprimer un modèle ?

1. Ouvrez le sélecteur de modèles et trouvez votre modèle dans la zone MODÈLES PERSONNALISÉS.
2. Cliquez sur les trois points de votre modèle et sélectionnez **Supprimer**. Notez que seuls les propriétaires de modèles et les admins d’entreprise disposant des autorisations d’administration de contenu sur le forfait Enterprise peuvent supprimer des modèles.

Mon abonnement a expiré. Vais-je perdre mes modèles personnalisés ?

Lorsque votre abonnement payant expire, les modèles personnalisés ne sont plus disponibles tant que vous ne le renouvelez pas. Les modèles qui ont déjà été insérés dans des tableaux ne sont pas affectés.
