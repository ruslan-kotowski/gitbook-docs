Assurer l'accessibilité pour tous est une partie essentielle de la mission de Miro. Miro a développé des outils pour vous aider à créer des expériences auxquelles tout le monde peut participer. Le Vérificateur d'accessibilité de Miro est conçu pour vous aider à vous assurer que vos tableaux Miro sont aussi inclusifs et accessibles que possible.

## Qu'est-ce que le Vérificateur d’accessibilité Miro ?

Le vérificateur d'accessibilité de Miro est un outil innovant conçu pour permettre à tous les utilisateurs de collaborer efficacement, sans les limitations imposées par les barrières d'accessibilité. Il effectue divers contrôles sur vos tableaux Miro pour identifier les zones qui pourraient ne pas respecter les normes d’accessibilité, vous fournissant des insights exploitables sur la manière d’améliorer votre contenu pour tous les utilisateurs.

## Pourquoi utiliser le vérificateur d’accessibilité de Miro ?

Créer une expérience accessible ne concerne pas seulement la conformité. Le Vérificateur d’accessibilité de Miro vous guide pour créer un contenu plus inclusif, garantissant à chaque participant, quelles que soient ses besoins d'accès, une expérience fluide et engageante.

## Pour utiliser le Vérificateur d'accessibilité de Miro :

1. Accédez au menu **trois points verticaux** (![icon-main.svg](../../../../../../../docs/getting-started/start-here/your-first-board/images/28438530164626_icon-main.svg)) > **Accessibilité** > **Vérificateur d'accessibilité**.![new-accessibility-checker.png](../../../../../../../docs/getting-started/start-here/your-first-board/images/28438515675410_new-accessibility-checker.png)
   *Le vérificateur d’accessibilité se trouve dans la Boîte à outils du tableau > Menu principal > Accessibilité > Vérificateur d’accessibilité*
2. Le Vérificateur d'accessibilité de Miro analysera automatiquement votre tableau pour détecter les problèmes potentiels d'accessibilité. Cela inclut des vérifications pour le contraste des couleurs, les descriptions d'images et les titres de cadres, afin de garantir que votre contenu soit percevable par tous.
3. Une fois l'analyse terminée, le vérificateur présentera un rapport détaillé de ses conclusions. Ce rapport comprend des recommandations spécifiques sur la façon de traiter les problèmes identifiés. Le rapport divisera les tickets en deux catégories : Descriptions et Contraste des couleurs.
   ![Le vérificateur d’accessibilité indique que 4 problèmes d’accessibilité ont été trouvés sur le tableau](../../../../../../../docs/getting-started/start-here/your-first-board/images/19479175122578_f4530230-4f9f-4155-b801-1554c1393a56.png)*Le vérificateur d’accessibilité indique que 4 problèmes d’accessibilité ont été trouvés sur le tableau*
4. Suivez les recommandations du vérificateur pour modifier votre tableau. Cela pourrait impliquer d'ajuster les couleurs ou d'ajouter des descriptions aux objets.
5. L'activation d'un ticket sélectionné vous emmènera à ce ticket sur le tableau, facilitant ainsi la modification.
   ![Un objet texte avec un contraste insuffisant est sélectionné sur le tableau](../../../../../../../docs/getting-started/start-here/your-first-board/images/19479175123346_8f32a246-8d3d-4558-8a3d-d5adf1167df7.png)
   *Un objet texte avec un contraste insuffisant est sélectionné sur le tableau*
6. Après avoir effectué les ajustements suggérés, vous pouvez relancer le vérificateur pour vous assurer que tous les problèmes ont été résolus.![Accessibility checker shows no issues](../../../../../../../docs/getting-started/start-here/your-first-board/images/19479175124114_4522a346-c8de-44a5-b79f-60f8ce5cc9cc.png)
   *Le vérificateur d’accessibilité n'indique aucun problème*

## Vérifications d’accessibilité

Quatre vérifications d'accessibilité sont actuellement prises en charge sur un tableau Miro.

### Contraste des couleurs

Le contraste de couleur est défini comme la différence de luminosité ou de brillance entre deux couleurs. Si le rapport est trop bas, il peut être difficile voire impossible de distinguer les deux couleurs. Cela peut rendre difficile pour certains utilisateurs de percevoir le texte ou les formes sur un tableau Miro. Les conseils actuels du W3C WCAG 2.2 AA sont les suivants :

- Le texte doit avoir un rapport de contraste d'au moins 4.5:1 par rapport à l'arrière-plan![Text with insufficient contrast saying Future is accessible and marked Fail, same text with sufficient contrast marked Pass](../../../../../../../docs/getting-started/start-here/your-first-board/images/19479175125522_ff02eeb3-c357-41b9-8c15-f8e17f7affa5.png)
  *Texte avec contraste insuffisant indiquant « L’avenir est accessible » et marqué « Échec », même texte avec contraste suffisant marqué « Réussite »*
- Les éléments graphiques doivent avoir un ratio d'au moins 3:1 par rapport à l'arrière-plan![An arrow with insufficient contrast marked Fail, same arrow with sufficient contrast marked Pass](../../../../../../../docs/getting-started/start-here/your-first-board/images/19479175127314_88063df8-8a9d-4191-ac09-6e18f6cb9e74.png)
  *Une flèche avec un contraste insuffisant marquée « Échec », même flèche avec un contraste suffisant marquée « Réussi »*

### les descriptions d’image

- Les descriptions d'images fournissent aux technologies d'assistance, telles que les lecteurs d'écran et les commandes vocales, des informations qui peuvent être communiquées aux utilisateurs.

### Titres des cadres

- En fournissant des titres de cadres, il est facile pour les utilisateurs de naviguer sur un tableau Miro.

## Catégorisation des tickets

Les problèmes dans le Vérificateur d'accessibilité de Miro sont classés en deux niveaux distincts d'importance :

- Critique : Les problèmes qui auront un impact bloquant sur le tableau, rendant impossible pour certains utilisateurs de l'utiliser efficacement.
- Sérieux Problèmes pouvant avoir un impact négatif sur l'expérience des utilisateurs de technologies d'assistance.

Notez que l'utilisation du vérificateur d'accessibilité de Miro ne détectera pas tous les problèmes d'accessibilité, et des étapes supplémentaires peuvent être nécessaires pour rendre votre tableau Miro accessible à tout le monde. Pour plus d'informations, reportez-vous au guide sur la création d'expériences Miro accessibles et inclusives.
