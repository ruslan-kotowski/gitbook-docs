Un tableau Miro est un espace de travail en ligne que vous pouvez utiliser pour visualiser vos idées et travailler sur des projets, individuellement ou en équipe.

Lorsque vous [rejoignez Miro](../02-how-to-register-with-miro.md), votre premier tableau est automatiquement créé et est enregistré soit dans votre propre équipe gratuite, soit dans l’équipe à laquelle vous avez été invité. Vous le trouverez dans votre tableau de bord, sous le nom My First Board (Mon premier tableau).

## Méthodes pour créer un tableau Miro

Vous pouvez créer autant de nouveaux tableaux que vous le souhaitez depuis votre tableau de bord ou directement à partir de la barre d’adresse de votre navigateur.

### Créer un tableau à partir du tableau de bord

Pour créer un tableau à partir du tableau de bord, suivez ces étapes :

1. Ouvrez votre tableau de bord.
   1. Si vous êtes membre de plusieurs équipes, choisissez l'équipe dans laquelle vous souhaitez enregistrer votre tableau.
   2. Pour créer un tableau dans un espace particulier, ouvrez l'espace.
2. Cliquez sur **+ Créer nouveau**.
   Un menu s’ouvre.
3. Cliquez sur **Tableau**.
   Un nouveau tableau est créé.

### Créer un tableau à partir d'un modèle

Pour créer un tableau à partir d'un modèle, suivez ces étapes :

1. Cliquez sur **+ Créer nouveau** sur votre tableau de bord.
   Un menu s’ouvre.
2. Cliquez sur **Explorer les modèles**.
   Le sélecteur de modèles s’ouvre.
3. Parcourez ou recherchez un modèle pertinent.
4. Cliquez sur **Utiliser le modèle** pour ouvrir un nouveau tableau avec le modèle. Vous pouvez également cliquer sur **Aperçu** pour consulter plus d'informations sur le modèle.
5. Depuis l'aperçu du modèle, vous pouvez cliquer sur **Utiliser le modèle** pour ouvrir un nouveau tableau avec le modèle.

### Créer un tableau à partir de la barre d'adresse du navigateur

Pour créer un tableau à partir de la barre d'adresse du navigateur, suivez ces étapes :

1. Tapez **miro.new** dans la barre d'adresse du navigateur.
   Un nouveau tableau s’ouvrira dans votre fenêtre de navigateur.
2. Si vous êtes membre de plusieurs équipes, choisissez dans quelle équipe vous souhaitez enregistrer votre tableau en cliquant sur Switch team (Changer d'équipe).
3. Si vous n'êtes pas connecté, vous serez invité à vous connecter avant que le nouveau tableau ne s'ouvre.

## Résolution des problèmes : Pourquoi ne puis-je pas créer un tableau ?

Il y a trois raisons possibles pour lesquelles vous ne pourriez pas créer un tableau : vous n'êtes pas membre de l'équipe, vous n'avez pas le bon type de licence ou les paramètres de votre équipe vous en empêchent.

**Vous n'êtes pas membre de l'équipe**

- Vous êtes invité dans l'équipe et ne pouvez donc pas créer de nouveau contenu. Demandez au propriétaire du tableau de rejoindre l'équipe ou essayez de rejoindre l'équipe à partir de votre tableau de bord.
- Vous n’êtes pas encore membre d’une équipe Miro. Pour créer votre propre équipe Miro, cliquez sur l’icône plus dans la barre latérale de votre tableau de bord.
- Vous avez reçu une invitation à rejoindre un tableau, mais pas l’équipe. Cliquez sur Ask to join team (Demander à rejoindre l'équipe) pour créer un nouveau tableau dans cette équipe.

**Vous n'avez pas le bon type de licence**

Vous êtes membre d'un forfait Enterprise et ne pouvez pas créer de tableaux parce que vous avez une licence gratuite restreinte. Pour créer des tableaux, demandez un accès éditeur et demandez à votre admin d’entreprise de vous attribuer une licence complète.

**Les paramètres de l'équipe l'empêchent**

Vous êtes membre d'une équipe d'un forfait Enterprise et ne pouvez pas créer de tableaux parce que votre admin d’entreprise a limité la création de contenu dans les paramètres de votre équipe. Pour créer des tableaux, demandez à votre admin d’entreprise de vous accorder des droits de création de contenu.

## Foire aux questions

**Comment copier un tableau ?**

Cliquez sur l'icône **Menu principal** dans la barre d'outils en haut à gauche, puis cliquez sur **Tableau**, et dans le sous-menu cliquez sur **Copier**.

**Plus d’informations :** Voir [Comment dupliquer un tableau](../../../using-miro/managing-boards/03-how-to-duplicate-a-board.md).

**Puis-je copier du contenu d’un tableau sur un autre ?**

Oui, [sélectionnez le contenu](../../../using-miro/working-on-the-board/10-working-with-objects.md) à copier et utilisez Ctrl + C/Ctrl + V pour Windows ou Cmd + C/Cmd + V pour Mac.

**Comment supprimer un tableau ?**

Cliquez sur l'icône **Menu principal** dans la barre d'outils en haut à gauche, puis cliquez sur **Tableau**, et dans le sous-menu cliquez sur **Supprimer**.
