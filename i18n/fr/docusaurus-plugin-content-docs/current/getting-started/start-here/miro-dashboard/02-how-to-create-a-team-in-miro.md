Lorsque vous démarrez avec Miro et que vous enregistrez votre profil, vous pouvez créer votre première équipe Miro ou rejoindre celle de quelqu’un. Au fur et à mesure que l’utilisation de votre produit se développe, vous pouvez vouloir créer des équipes supplémentaires pour pouvoir séparer votre travail en différents projets.

## Créer votre première équipe dans Miro

Lorsque vous vous inscrivez sur Miro, vous pouvez soit *créer* une nouvelle équipe, soit *rejoindre* une équipe pour laquelle vous avez reçu une invitation ou dans laquelle votre compte a été provisionné.

Si vous indiquez une *adresse e-mail d’entreprise* lorsque vous vous inscrivez, vous découvrirez peut-être que votre société possède déjà une équipe dans Miro configurée pour pouvoir être [découverte par les utilisateurs de votre domaine](../../../administration/team-management/02-manage-team-signup-mode.md). Dans ce cas, vous pouvez voir les options **Request a licence, Join a team** ou **Create a new team (Demander une licence, Rejoindre une équipe ou Créer une nouvelle équipe)** pour commencer à utiliser des tableaux.

![Rejoindre d’autres équipes.jpg](../../../../../../../docs/getting-started/start-here/miro-dashboard/images/21017005313938_Join%20other%20teams.jpg)*Créer un nouveau profil en tant qu’utilisateur de l’entreprise*

En choisissant l’option **Request (Demande)** pour obtenir une licence, vous enverrez la demande aux admins d’équipe. Comme le traitement de votre demande par l’admin d’équipe pourrait prendre un certain temps, Miro vous suggèrera de créer *votre propre équipe gratuite* pour commencer à travailler immédiatement.

Si vous choisissez l’option **Join** (Rejoindre) pour rejoindre une équipe existante, Miro vous redirigera vers le tableau de bord de l’équipe.

:::note
Vous pouvez rejoindre les équipes à découvrir de votre domaine plus tard sur votre tableau de bord - [en savoir plus](../../../administration/team-management/02-manage-team-signup-mode.md).
:::

Vous pouvez également choisir de créer votre propre équipe gratuite en cliquant sur **Create a new team** (Créer une équipe).

### Créer une nouvelle équipe lors de l’inscription d’un profil

Après avoir cliqué sur **Create a new team (Créer une nouvelle équipe)**, nous vous proposerons d’en remplir les détails :

![mettre_en_place_votre_équipe_en_Miro.jpg](../../../../../../../docs/getting-started/start-here/miro-dashboard/images/21017005314834_set%20up%20your%20team%20in%20Miro.jpg)
*Mise en place d’une nouvelle équipe d’entreprise*

Vous pouvez inviter vos collègues lors de la configuration de l’équipe ou le faire plus tard.

![invite_team_members.jpg](../../../../../../../docs/getting-started/start-here/miro-dashboard/images/21017005315858_invite%20team%20members.jpg)
*L’option d’inviter des utilisateurs lors de l’enregistrement d’une équipe*

Une fois l’équipe prête, vous pouvez commencer à créer des tableaux, inviter les utilisateurs à collaborer et [passer](../../../plans-billing/manage-your-subscription-and-plan/03-upgrade-your-plan.md) à un forfait payant en fonction de vos besoins.

## Créer des équipes supplémentaires dans Miro

Vous pouvez voir toutes vos équipes sur la [barre latérale gauche de votre tableau de bord](04-profile-and-teams.md). Créer de nouvelles équipes pour de nouveaux projets est l’action la plus logique lorsque vous devez inviter différentes personnes à y travailler et que vous souhaitez pouvoir gérer le contenu et l’accès de la manière la plus efficace possible.

Trois options principales sont disponibles pour les utilisateurs à la recherche de fonctionnalités multi-équipes :

- Acheter plusieurs équipes *payantes* si nécessaire. Cliquez sur l’icône plus dans la barre latérale gauche pour acheter une nouvelle équipe :
  ![créer_une_nouvelle_équipe_payée.gif](../../../../../../../docs/getting-started/start-here/miro-dashboard/images/21016967781138_create%20a%20new%20paid%20team.gif)
  *Création d’une nouvelle équipe rémunérée*
- Achat d’un forfait Business. Le forfait permet de créer plusieurs équipes au sein d’un même abonnement (sans frais supplémentaires pour chaque nouvelle équipe). Découvrez [ici](../../../administration/get-started-as-a-miro-admin/05-manage-business-plan.md) comment créer une nouvelle équipe avec un forfait Business.
- Achetez le [forfait Enterprise](../../../plans-billing/miro-plans/04-enterprise-plan.md) si vous travaillez dans une organisation ayant des exigences avancées en matière de sécurité et de gestion des utilisateurs, où différentes équipes utiliseront Miro pour différents projets. Découvrez comment [créer une nouvelle équipe dans un forfait Enterprise](../../../enterprise-administration/managing-enterprise-teams-and-content/09-create-a-new-team-on-enterprise-plan.md).

## Foire aux questions

**Je suis membre de l’équipe Miro de quelqu’un, mais je veux créer ma propre équipe. Comment faire ?**

- Vous pouvez acheter une nouvelle équipe en cliquant sur l’icône plus dans la barre latérale gauche de votre tableau de bord. Pour certains utilisateurs, cependant, cette option peut être limitée par les admins d’entreprise via l’[option Domain control (Contrôle de domaine)](../../../enterprise-administration/canvas-25-admin-features/domain-control/01-domain-control.md). Notez que la création d’une *nouvelle* *équipe gratuite à l’aide du bouton plus* est uniquement possible si vous n’êtes pas membre d’une autre équipe Miro (si vous avez un [rôle](../../../using-miro/sharing-boards/07-collaboration-with-guests.md) d’invité dans l’équipe de quelqu’un ou si vous avez [quitté](../../../using-miro/managing-your-profile/06-how-to-leave-a-team.md)/[supprimé](../../../administration/team-management/06-delete-and-restore-teams.md) toutes vos équipes).

**Comment puis-je rejoindre d’autres équipes dans mon organisation après avoir créé ma propre équipe ?**

- Vous pouvez demander à vos collègues de [vous inviter dans leurs équipes](../../../administration/user-management/01-invite-users.md) ou de rejoindre [des équipes découvertes pour vous](../../../administration/team-management/02-manage-team-signup-mode.md) (s’il y en a) en cliquant sur l’icône plus dans la barre latérale gauche de votre tableau de bord.

**Un membre d’une autre équipe payante occupera-t-il une licence payante dans la mienne ?**

- Oui, lorsque vous invitez un nouveau membre dans votre équipe payante, vous devez lui acheter une licence. Sur le forfait Starter, vous pouvez inviter des [membres pour un essai](../../../administration/user-management/01-invite-users.md).
