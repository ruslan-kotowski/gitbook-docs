Utilisez la recherche Miro pour trouver facilement un tableau ou un espace.

:::tip
Pour savoir comment effectuer une recherche sur un tableau spécifique, consultez [cet article](../../../using-miro/working-on-the-board/19-searching-text-on-the-board.md).
:::

## Comment utiliser la recherche

Pour trouver un tableau ou un espace sur le [tableau de bord](https://miro.com/app/dashboard/), cliquez dans la **barre de recherche** en haut du panneau gauche de la page ou appuyez sur **Ctrl + E** *(pour Windows)*/**Cmd + E** *(pour Mac)*. Commencez à saisir le nom d'un tableau ou d'un espace. Vos tableaux et espaces les plus récemment ouverts apparaissent sous la barre de recherche. Vous verrez toutes les correspondances partagées avec vous dans l'équipe actuelle.

Si vous souhaitez voir les détails d'un tableau spécifique :

1. Cliquez sur l'icône des **trois points** (**...**) à côté du nom du tableau.
2. Sélectionnez **Détails du tableau**.
   Une fenêtre modale s'ouvrira avec les informations suivantes :
   1. classification de tableau
   2. propriétaire du tableau
   3. description du tableau
   4. date de création du tableau
   5. date de la dernière modification
   6. emplacement du tableau (Nom de l'équipe > Nom de l'espace)

Vous pouvez affiner la recherche par **propriétaire** ou **espaces** (sur le forfait Free, vous pouvez rechercher uniquement par propriétaire). Pour appliquer des filtres, cliquez sur **tous les filtres** ou choisissez un propriétaire dans la liste déroulante sous la barre de recherche. Pour supprimer un filtre, cliquez sur **X**.

La fenêtre de recherche affichera les résultats en fonction de l’équipe dans laquelle vous vous trouvez actuellement.

Vous pouvez également [partager](../../../using-miro/sharing-boards/03-sharing-boards-and-inviting-collaborators.md), renommer, [déplacer des tableaux](../../../using-miro/managing-boards/04-how-to-move-a-board.md) et effectuer d'autres actions clés directement à partir du menu des résultats de recherche. Le menu avec toutes les options s'ouvrira lorsque vous cliquerez sur les **trois points** (**...**) à côté du nom du tableau.

*![search-three-dots-menu.png](../../../../../../../docs/getting-started/start-here/miro-dashboard/images/21262219090578_search-three-dots-menu.png)
Menu contextuel du tableau dans les résultats de recherche*

:::tip
Utilisez cette fonctionnalité couplée aux filtres de recherche pour rationaliser l’organisation des tableaux. Par exemple, vous pouvez filtrer les tableaux par propriétaire et les déplacer sur une équipe ou un projet plus rapidement qu’auparavant.
:::

:::tip
N'hésitez pas à installer l'[Extension de recherche Chrome pour Miro](https://miro.com/marketplace/chrome-search/?backUrl=%2Fmarketplace%2F). Une fois l’extension ajoutée, tapez 'M*iro'* dans la barre d’adresse du navigateur et appuyez sur la touche **tabulation**. L'extension permet une recherche rapide des tableaux Miro directement depuis la barre d'adresse.
:::

## Recherche avancée

> **Disponible pour :** les forfaits Education, Starter, Business et Enterprise

Les utilisateurs des forfaits Education, Starter, Business et Enterprise peuvent utiliser la barre de recherche pour trouver des mots ou des expressions spécifiques dans les titres et descriptions des tableaux et des espaces, ainsi que dans les widgets, commentaires et pense-bêtes sur un tableau.

Si vous êtes sur le forfait Business ou Enterprise, vous pouvez rechercher dans toutes les équipes depuis votre tableau de bord, ce qui vous permet de trouver du contenu pertinent dans l'ensemble de votre organisation.

La fenêtre de recherche affichera tous les éléments de contenu qui contiennent le mot ou la phrase que vous recherchez. Vous pouvez cliquer sur chaque élément sous la section **Contenu** pour consulter les résultats de recherche et agrandir la liste des correspondances en cliquant sur la flèche à gauche du nom du tableau.

Lorsque vous cliquez sur un résultat de recherche sous cette section, le tableau s'ouvrira à l'emplacement spécifique où se trouve le résultat de recherche pour que vous n'ayez pas à le chercher.
