## À propos de l’utilisation de Miro sur un affichage interactif

Miro peut être utilisé sur un affichage interactif de deux manières :

- Sur l’affichage interactif, même s’il dispose d’un PC intégré.
- En connectant un ordinateur à un affichage interactif.

### Affichages recommandés pour Miro

Nous vous recommandons de considérer les écrans interactifs suivants, testés par Miro pour garantir une compatibilité et des performances optimales.

Les besoins et les préférences de votre entreprise sont uniques. Il est donc important de tester les appareils avant de les acheter afin de s'assurer qu'ils sont parfaitement adaptés.  [E](09-selecting-the-right-interactive-display-for-hybrid-collaboration.md)n savoir plus sur le choix d’un affichage adapté à la collaboration.

**Écrans avec PC intégré :**

- Neat Board
- DTEN ONboard
- Vibe Board
- [Tableau Google Meet Series One](12-using-miro-with-google-meet-series-one-boards-beta.md)

**Affichages avec connexion PC externe :**

- Écrans interactifs Dell 4K (55" à 86")
- Sharp (PN-L652B, PN-L752B ; PN-L862B)
- Écrans NEC (WD551, M551/ M651 /M751/ M861 IGB)

**Configurations PC externes recommandées :**

- Dell OptiPlex Micro PC avec Intel Core i7 & 16GB RAM (Windows)
- Intel OPS/SDM avec Core i7 et 16GB RAM

## Mise en place de Miro sur des écrans interactifs : applications et options de navigation

Sur les écrans interactifs, vous pouvez utiliser l'application Miro, ou ouvrir Miro dans le navigateur.

### Application Miro :

- [Téléchargez l’application Miro pour les affichages basés sur Windows.](https://desktop.miro.com/platforms/win32/Miro.exe)
- [Téléchargez l’application Miro pour les affichages Vibe Board.](https://vibe.how/en/articles/6880969-how-to-download-and-install-your-favorite-apps-in-vibe-app-store)
- Neat Board et DTEN ONboard : contactez le responsable Customer Success de votre fournisseur d'écrans pour vous aider à accéder à l'application Miro.

### Navigateurs

- Navigateur Microsoft Edge (version 85 et supérieure)
- Navigateur Google Chrome (version 85 et supérieure)

> **[✏️](../../using-miro/essential-tools/10-pen.md) Si vous utilisez un stylet actif lorsque vous travaillez dans Miro, vous passez automatiquement à notre outil Stylo.**  Ce mode active le rejet de paume et la possibilité de naviguer avec le doigt. Pour désactiver ce mode (pour commencer à dessiner avec les doigts), rechargez le tableau ou arrêtez d’utiliser le stylet numérique pendant 10 minutes.

> **✏️ Miro ne prend en charge qu’un seul point tactile par affichage.**

### Enregistrer le tableau

Si vous créez un nouveau tableau, vous pouvez l’enregistrer pour y accéder ultérieurement. Pour ce faire, vous aurez besoin d’un compte Miro.

1. Dans le coin supérieur gauche du tableau, cliquez sur **Enregistrer**.
2. Saisissez votre adresse e-mail et cliquez sur **Envoyer maintenant**, ou scannez le code QR.
3. Ouvrez le tableau à l’aide de votre adresse e-mail. Si vous avez scanné le code QR, le tableau s’ouvrira automatiquement sur votre appareil.
4. Il vous sera demandé de **saisir un nouveau nom de tableau** et de **choisir une équipe** dans le menu déroulant.
5. Cliquez sur **Enregistrer**.

## Barre d’outils Miro sur les affichages interactifs

Lorsque vous travaillez dans Miro sur un affichage interactif, la barre d’outils de création est placée en bas de l’affichage. Par défaut, il n'y aura que les outils les plus utilisés : les [pense-bêtes](../../using-miro/essential-tools/14-sticky-notes.md), les [formes](../../using-miro/essential-tools/11-shapes.md), le [texte](../../using-miro/essential-tools/16-text.md), les [lignes](../../using-miro/essential-tools/05-connection-lines.md), le [stylo](../../using-miro/essential-tools/10-pen.md), le surligneur et la gomme. Les autres outils se trouvent dans le menu **Outils, médias et intégrations****(+**).

> **[✏️](10-send-to-display.md)**Si vous travaillez dans un navigateur sur un périphérique tactile 4K ou plus et que vous n’utilisez pas la Connexion rapide pour vous connecter à Miro, la barre d’outils sera placée à gauche de l’affichage.

## Paramètres de temporisation pour les écrans interactifs

Les administrateurs ont la possibilité d'appliquer des paramètres de délai personnalisés pour les écrans interactifs de leur organisation. Deux paramètres peuvent être définis :

1. Période d'inactivité.
2. Autoriser ou non les utilisateurs individuels à outrepasser le délai d'inactivité.

Vous pouvez accéder à ces paramètres sous **Sécurité et conformité** > **Affichages**.
