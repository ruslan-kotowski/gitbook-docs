Commencez à collaborer en quelques secondes. Utilisez la fonctionnalité Envoyer vers l’écran pour afficher n’importe quel tableau Miro sur votre écran interactif.

> ***Mises à jour de l’interface utilisateur de Miro en déploiement progressif***
> Miro améliore l’interface utilisateur du tableau pour la rendre plus inclusive et intuitive, et introduit une évolution des projets, maintenant appelés espaces. Le déploiement se fera progressivement pour tous les comptes Miro sur plusieurs semaines.
>
> Si vous disposez déjà de l’interface utilisateur améliorée et de la présentation des espaces, cet article peut décrire les points d’entrée qui ont changé.
>
> Pour consulter la documentation la plus à jour, voir [la nouvelle interface utilisateur simplifiée de Miro](../../using-miro/working-on-the-board/02-miro's-new-simplified-user-interface.md).
>
> Cet article sera mis à jour lorsque le déploiement sera terminé.

Découvrez [comment paramétrer Miro sur votre écran interactif](07-interactive-displays.md).

## Comment utiliser la fonction Envoyer vers l’écran

1. Sur votre écran interactif, ouvrez l’application Miro ou ouvrez le navigateur et allez à l’adresse [miro.com/displays](https://miro.com/displays/).
2. Ouvrez le tableau Miro sur votre appareil personnel.

**Depuis votre ordinateur portable ou tablette**

1. Depuis le tableau Miro sur votre ordinateur portable ou tablette, dans la barre du tableau, sélectionnez les trois points verticaux.
   Le menu **Principal** s’ouvre.
2. Sélectionnez **Envoyer vers l’écran interactif**.
3. Saisissez le code d’appariement unique que vous voyez sur l’écran interactif. Vous afficherez ainsi le tableau sur l’écran à partir de votre ordinateur portable ou de votre tablette.

**À partir de votre appareil mobile**

:::note
Si vous utilisez un appareil mobile, assurez-vous de télécharger d’abord l’application mobile Miro pour [iOS](https://apps.apple.com/us/app/miro-collaborative-whiteboard/id1180074773) ou [Android](https://play.google.com/store/apps/details?id=com.realtimeboard&hl=en&gl=US).
:::

1. Depuis le tableau Miro sur votre appareil mobile, touchez l’icône **Paramètres** dans le coin supérieur droit.
   **![board_settings.jpg](../../../../../../docs/getting-started/apps-for-devices/images/4967840616850_board%20settings.jpg)**
   *Ouverture des paramètres du tableau sur l’application mobile*
2. Appuyez sur **Envoyer vers l’écran interactif.**
   **![send_to_interactive_display.jpg](../../../../../../docs/getting-started/apps-for-devices/images/4967865515794_send%20to%20interactive%20display.jpg)**
   ***L’option Envoyer vers l’écran interactif sur l’application mobile***
3. Saisissez le code d’appariement unique que vous voyez sur l’écran interactif. Vous afficherez ainsi le tableau sur l’écran à partir de votre appareil mobile.
   ![enter_code.jpg](../../../../../../docs/getting-started/apps-for-devices/images/4967892004114_enter%20code.jpg)
   *L’option pour entrer le code*

:::tip
Une fois la session terminée, n’oubliez pas de vous déconnecter de l’écran afin de protéger vos données. Si vous oubliez, votre compte sera automatiquement déconnecté après 15 minutes d’inactivité.
:::

## Résolution des problèmes

Si vous ne voyez pas la fenêtre Envoyer vers l’écran dans l’application de bureau Windows, essayez les étapes de dépannage ci-dessous.

1. Installez l’[application Miro pour ordinateur de bureau](https://miro.com/apps/).
2. Cliquez avec le bouton droit sur l’icône de l’application de bureau Miro, sélectionnez **Propriétés**.
   ![properties.jpg](../../../../../../docs/getting-started/apps-for-devices/images/4949111804946_properties.jpg)*Propriétés de l’application Miro*
3. Passez à l’onglet **Raccourci**, ajoutez l’indicateur ci-dessous aux arguments CLI dans le champ **Cible**, puis cliquez sur OK pour appliquer les modifications.

   ```
   --public-device
   ```

   ![target_field.jpg](../../../../../../docs/getting-started/apps-for-devices/images/4949083211538_target%20field.jpg)*L’onglet Raccourci dans les propriétés Miro*
4. L’option Envoyer vers l’écran sera désormais affichée par défaut chaque fois que vous lancerez l’application.
