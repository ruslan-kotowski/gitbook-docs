Libérez le potentiel d'une collaboration dynamique grâce au module complémentaire Miro sur vos tableaux Google Meet Series One. Cette fonctionnalité est parfaite pour des activités telles que le brainstorming, l'idéation, la création de diagrammes et la conduite de rétrospectives. L'extension Miro est disponible pour les tableaux 65 et 27.

:::warning
Le module complémentaire Miro est actuellement en version bêta ouverte sur les tableaux Google Meet Series One. Toutes les fonctionnalités ne sont pas encore disponibles.
:::

:::note
Pour activer le module complémentaire Miro sur vos tableaux Google Meet Series One, votre administrateur informatique doit l'activer via le panneau d'administration de l'espace de travail Google.
:::

## Comment utiliser le module complémentaire Miro

**Pendant un appel Google Meet**

Utilisez le module complémentaire Miro lors des appels Google Meet programmés ou impromptus. Cette **fonction** est idéale pour les sessions collaboratrices qui bénéficient d'une communication en temps réel.

1. Lancez ou rejoignez un appel Google Meet via l'interface utilisateur de Google Meet.
2. Lancez le module complémentaire Miro pendant votre appel en cliquant sur le bouton **Démarrer l'activité**.

**Mode autonome**

Utilisez le module complémentaire Miro indépendamment des appels Google Meet. Il est parfait pour les moments où vous avez besoin de brainstorming, de planification ou de création sans discussion en direct.

1. Dans l'interface utilisateur de Google Meet, cliquez sur le bouton **Démarrer un tableau blanc**.
2. Choisissez le module complémentaire Miro pour participer à un tableau sans entamer une réunion complète.

:::note
Si vous avez d'autres questions ou si vous avez besoin d'aide avec le module complémentaire Miro, contactez notre [équipe d'assistance](../../using-miro/tools/troubleshooting/06-contacting-miro-support.md).
:::
