## Fonctionnalités à disponibilité ou fonctionnalité limitée

Certaines fonctionnalités de Miro ne sont pas prises en charge sur mobile. Cela inclut les modèles, l'export de tableau, le mode présentation, le chat vidéo, le vote et les tableaux favoris. Vous ne pouvez pas modifier votre abonnement ou ajouter des licences dans l'application mobile ou via les navigateurs mobiles.

L'application mobile fournit actuellement une *fonctionnalité limitée* pour certaines fonctionnalités:

|  |  |
| --- | --- |
| **Fonctionnalité** | **Fonctionnalité limitée** |
| Création et partage de tableaux | Accès de modification non autorisé pour [les visiteurs](../../using-miro/sharing-boards/08-collaboration-with-visitors.md) |
| Espaces | Filtrer les tableaux par [espace](../../using-miro/spaces/01-spaces.md) |

## Exigences pour mobiles

- **Utilisateurs iOS :** iOS 16 ou supérieur
- **Utilisateurs Android :** Android 7 ou supérieur

Si l'application n'est pas compatible avec votre téléphone, vous pouvez toujours accéder aux fonctionnalités Miro suivantes via votre navigateur mobile :

- **Consulter les tableaux :** Accédez aux contenus et visualisez-les.
- **Commenter :** Appuyez et maintenez sur votre écran pour ajouter un commentaire.

## Comment travailler sur un tableau dans l'application

### Gestes tactiles pour l'application mobile

- **Balayez** pour vous déplacer sur le tableau.
- **Appuyez longuement** et faites glisser pour sélectionner plusieurs objets.
- **Pincez** pour zoomer et dézoomer.
- **Appuyez deux fois** sur un tableau pour zoomer.
- **Appuyez deux fois et faites glisser vers le haut** **ou vers le bas** pour zoomer ou dézoomer.
- **Faites glisser vers le haut ou le bas sur le bord de l’écran** pour zoomer ou dézoomer.
- Sélectionnez un objet et appuyez sur **Modifier** pour modifier l’objet.
- **Appuyez deux fois** sur l’objet pour ajouter du texte.
- **Appuyez longuement** sur l’objet pour le déplacer.

### Comment modifier des objets sur le tableau

Lorsque vous ouvrez un tableau dans l’application mobile, il sera par défaut en mode lecture seule. Cela vous permet de vous déplacer facilement sur le tableau sans déplacer les objets.

1. Sélectionnez l’objet et appuyez sur **Modifier**.
2. Appuyez deux fois sur l’objet pour commencer à y ajouter du texte.
3. Appuyez longuement sur l’objet pour le déplacer immédiatement.

### Comment copier et coller entre les tableaux

Copier un élément d’un tableau à un autre est aussi simple que copier et coller des éléments sur le même tableau.

1. Ouvrez le tableau depuis lequel vous voulez copier un objet.
2. Sélectionnez l’objet et appuyez ensuite sur le menu des **trois points verticaux** dans la barre d’outils inférieure.
3. Sélectionnez **Copier**.
4. Ouvrez le tableau dans lequel vous voulez coller l’objet.
5. Appuyez sur l’**icône d’ajout (+)** puis appuyez sur **Coller**.
6. Déplacez l’objet collé à la position adéquate sur votre tableau.

Si vous souhaitez copier et coller une image, un fichier ou tout autre contenu non textuel depuis l'extérieur de Miro, vous devrez utiliser la fonction **Charger** au lieu de copier-coller. Vous trouverez l'option Charger dans le menu **Ajouter (+)**.

### Comment tracer des lignes de connexion

Tracer des lignes de connexion entre des objets vous permet de créer un lien entre eux qui est maintenu même lorsque les objets sont déplacés sur le tableau.

1. Sélectionnez l'objet à partir duquel vous souhaitez commencer la connexion.
2. Appuyez sur l'icône **Modifier**.
3. Faites glisser le **point bleu** qui apparaît en dessous de l'objet et faites-le glisser vers l'objet avec lequel vous souhaitez vous connecter.
4. Une flèche apparaîtra, reliant les objets.
   ![connector-lines.gif](../../../../../../docs/getting-started/apps-for-devices/images/21020253626770_connector-lines.gif)
5. Pour supprimer la ligne de connexion, sélectionnez-la puis cliquez sur l'icône **Poubelle** dans la barre d'outils inférieure.

### Comment consulter les détails du tableau

Appuyez sur le menu à trois points dans le coin supérieur droit pour afficher les détails du tableau, changer la couverture du tableau et mettre à jour l'accès au tableau.

Sous **Paramètres du tableau**, vous pouvez activer ou désactiver les curseurs des utilisateurs, la grille du tableau, [enclencher des objets](../../using-miro/formats/diagramming/01-miro-for-mapping-diagramming.md), ainsi que choisir d'afficher ou non les commentaires résolus.

*Paramètres du tableau dans l'application mobile de Miro*

### Demandes d'accès à modifier

Lorsqu'une personne demande l'accès de modification à un tableau, le propriétaire du tableau reçoit une notification push de l'application Miro. Il peut ensuite cliquer sur la notification pour naviguer facilement vers le tableau et accorder l'accès de modification au demandeur.

## Prise en charge de la vocalisation des tableaux

Les utilisateurs nécessitant une assistance avec des éléments visuels peuvent activer la fonction de vocalisation, disponible sur iOS et Android. Il suffit d'activer la vocalisation dans les paramètres de votre téléphone pour l'utiliser avec Miro.

Lorsque la vocalisation est activée, elle lira à haute voix ce qui figure sur votre écran lorsque vous sélectionnez des éléments. Cela vous permet d'entendre ce qui se trouve dans l'application, afin que vous puissiez créer et visualiser du contenu plus facilement.

## Notifications push

Lorsque vous vous connectez pour la première fois à l'application, nous vous demanderons si vous souhaitez activer les notifications push. Ainsi, vous serez toujours informé lorsqu'un membre de votre équipe vous mentionne sur un tableau. Vous pouvez désactiver ces notifications à tout moment dans les **Paramètres** de l'application.

Cela ne s'applique qu'aux notifications push de votre smartphone. Découvrez comment désactiver les [notifications par e-mail et les newsletters](../../using-miro/managing-your-profile/02-miro-notifications.md).

## FAQ

Puis-je ajouter des liens Web à mon tableau à l'aide de l'application mobile ?

Oui, pour ajouter un lien, commencez par le copier. Ensuite, appuyez sur le bouton créer (**+**) situé en bas à droite du tableau. Sélectionnez **Téléverser**, puis **Coller depuis le presse-papiers**. Votre lien sera collé sur le tableau.

Comment activer le mode sombre ?

Par défaut, le mode sombre est activé selon les paramètres de votre téléphone. Si vous souhaitez activer ou désactiver le mode sombre spécifiquement pour l'application mobile de Miro, cliquez sur le bouton **Changer de mode** dans la bannière de l'écran d'accueil de votre application, puis sélectionnez **Mode sombre** ou **Mode clair**.
