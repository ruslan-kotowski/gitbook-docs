Améliorez votre travail sur les tableaux blancs en utilisant Miro sur un Webex Board. Configurez l’application Miro et commencez facilement à collaborer, à présenter vos idées et à créer vos prochains projets d’envergure !

Vous pouvez ajouter l’application Miro sur un Webex Board de deux manières différentes : directement à partir du Control Hub ou depuis l’UI Extensions Editor (Éditeur des extensions de l’interface utilisateur).

### Ajouter l’application à partir du Control Hub

Pour ajouter l’application à partir du Control Hub, rendez-vous sur **Devices** (Périphériques) et ouvrez le périphérique (vous devez déjà avoir enregistré l’appareil dans Control Hub. Pour ce faire, consultez l’[article du Centre d’Aide de Webex](https://help.webex.com/n3hi0z8/Activate-a-Cisco-Webex-Room-or-Desk-Device-or-Webex-Board) pour apprendre comment activer un Webex Board ou un périphérique de bureau.).

devices_on_Webex.jpg
Ouverture du périphérique sur le Webex Control Hub

Faites défiler vers le bas et cliquez sur **Web Apps** (Applications Web).

Web_apps.jpg
Accès à Web Apps (Applications Web) sur le Webex Control Hub

Choisissez d'ajouter une nouvelle application Web. Saisissez le nom de l'application qui apparaîtra sous l'icône de l'application Web sur l'écran d'accueil du tableau Webex. Tapez l'URL (par exemple, miro.com/displays pour avoir un écran de lancement et une expérience optimisée pour les écrans interactifs). Ajoutez une icône personnalisée en saisissant ce lien dans le champ Icon URL(URL de l’icône) (facultatif). Cliquez sur Add (Ajouter), puis sur Save (Enregistrer) pour sauvegarder les résultats.

Adding_the_Miro_web_app_from_Webex_Control_Hub.gif
*/span>Ajout de l’application Web Miro à partir du Webex Control Hub*

Le périphérique se synchronisera automatiquement et vous verrez l’icône de Miro sur l’écran d’accueil de votre tableau Webex.

### Ajouter l’application depuis l’UI Extensions Editor (Éditeur des extensions d’interface)

Ouvrez le portail Web de votre périphérique et rendez-vous sur **UI Extensions Editor** (Éditeur des extensions d’interface utilisateur).

extensions_editor.jpg
Ouverture du UI Extensions Editor (Éditeur des extensions d’interface)

Choisissez ensuite **New** (Nouveau) dans le panneau Extensions et cliquez sur **Add** (Ajouter) sous Web App (Application Web).

Adding_a_new_Web_App_within_UI_Extensions_Editor_.gif
*Ajout d’une nouvelle application web depuis* l’UI Extensions Editor (Éditeur des extensions d’interface)

Saisissez l’identifiant, le nom et l’URL dans la barre latérale gauche. Insérez [ce lien](https://miro.com/static/images/awwapp-miro/miro_logo_rounded.png) dans le champ **Web app icon URL** (URL de l’icône de l’application Web) pour ajouter une icône personnalisée (facultatif). Choisissez **Always** (Toujours) pour que l’application Miro soit disponible pendant les appels. Cliquez sur le bouton fléché dans la barre supérieure pour terminer.

Adding_the_Miro_app_with_UI_Extensions_Editor_on_a_Webex_board.gif
Ajout de l’application Miro avec l’UI Extensions Editor (Éditeur des extensions d’interface) sur un tableau Webex

:::note
Apprenez-en plus sur l’ajout des applications Web sur des Webex Boards dans le [Webex Help Center](https://help.webex.com/h47w6/Add-Web-Apps-on-Webex-Boards-and-Desk-Pros) (Centre d’Aide de Webex).
:::

### Travailler dans Miro sur un Webex Board

Une fois que l’icône de Miro apparaît sur l’écran d’accueil de votre Webex Board, appuyez dessus et connectez-vous à votre profil Miro. Vous pouvez désormais utiliser Miro avec toutes les fonctionnalités de l'application. Pour en savoir plus sur le travail sur les tableaux Miro, consultez les sections suivantes du Centre d'assistance : [Mise en route](..), [utilisation de Miro](../../using-miro).

- Pour profiter de la meilleure expérience possible, nous vous recommandons d’utiliser un câble Ethernet plutôt que le Wi-Fi.
- Vérifiez votre [mode de navigation](../../using-miro/working-on-the-board/05-using-miro-with-a-mouse-trackpad-or-touchscreen.md) et activez le mode pavé tactile ou le mode souris en fonction de vos besoins.
- Utilisez la mini-carte dans le coin inférieur droit du tableau pour naviguer facilement sur le tableau.

Mini-carte d’un tableau Miro

Lorsque votre session est terminée et libérée, votre compte Miro sera automatiquement déconnecté.
