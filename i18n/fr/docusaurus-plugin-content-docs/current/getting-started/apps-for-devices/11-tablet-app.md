#### **Gestes**

- **Balayez avec un ou deux doigts** pour déplacer le canevas
- **Appuyez une fois** pour sélectionner un objet
- **Appuyez et déplacez** pour faire glisser un objet
- **Appuyez longuement et faites glisser** sur le canevas pour sélectionner plusieurs objets
- **Pincez** pour zoomer et dézoomer

#### **Outils de stylet**

Vous pouvez utiliser n’importe quel type d’outil stylo avec Miro lorsque vous travaillez sur une tablette, y compris Stylus, Apple Pencil, Surface Pen et Samsung S Pen. Améliorez votre expérience avec l’application pour tablette Miro grâce à des fonctionnalités comme le [stylo, le surligneur](../../using-miro/essential-tools/10-pen.md) et le [dessin intelligent](../../using-miro/essential-tools/12-smart-drawing.md).

**Dessiner avec Stylus**

Lorsque vous dessinez avec un Stylus, il est automatiquement identifié comme un stylo. Utilisez simplement vos doigts pour sélectionner et déplacer des objets, et votre Stylus lorsque vous utilisez les outils stylo.

Vous pouvez toujours modifier ce comportement en désactivant **Ne dessiner qu’avec Stylus** dans **Paramètres** > **Préférences**.

![Only_draw_with_Stylus.png](../../../../../../docs/getting-started/apps-for-devices/images/21016967659026_Only%20draw%20with%20Stylus.png)*Ne dessiner qu’avec Stylus activé*

### Notifications push sur les tablettes

Lorsque vous vous connectez à l’application pour tablette la première fois, nous vous demandons si vous souhaitez activer les notifications push pour toujours savoir si un ou une collègue vous mentionne sur l’un des tableaux. Les notifications push peuvent être désactivées dans la section **Settings** (Paramètres) de votre tablette.

### Exigences techniques

- iOS et iPadOS 15 ou version supérieure
- Android 7.0 ou version ultérieure
- Windows 10, version 1607 ou ultérieure
- Résolution d’écran de 768×1024 pixels ou plus

### Restrictions

- [Plugin Dropbox](../../integrations-apps/more-integrations/06-dropbox.md) non disponible
- Seuls les fichiers JPG peuvent être [chargés](../../using-miro/import-and-export/import/05-uploading-files-to-boards.md) sur les tableaux depuis l’appareil
- [La mise à niveau](../../plans-billing/manage-your-subscription-and-plan/03-upgrade-your-plan.md) et [le changement de taille d’équipe](../../plans-billing/billing-and-payments/04-miro-billing.md) ne sont pas disponibles dans l’application pour tablette. Vous pouvez utiliser le navigateur de la tablette à cette fin
- La fonctionnalité *Réorganiser les cadres* dans la barre latérale n’est pas disponible sur les appareils tactiles (application et navigateur de tablette).
- La fonctionnalité *Réorganiser les outils* dans la barre d’outils n’est pas disponible sur les appareils tactiles (application et navigateur de tablette).

### Limitations de l’iPad

Notre application utilise WebView pour faire le rendu des éléments visuels et l’une des règles liées à la gestion de la mémoire fait que le processus de rendu n’est pas autorisé à utiliser plus de 25 % de la mémoire RAM de l’appareil. Une fois ce seuil dépassé, l’application est limitée et cesse de se charger correctement, sans afficher de messages d’erreur ni de plantages. C’est pourquoi les barres d’outils peuvent disparaître et réapparaître occasionnellement, et les performances peuvent ralentir considérablement.

Nous vous suggérons d’essayer les solutions suivantes :

- Fermez toutes les applications inutiles exécutées en arrière-plan avant d’utiliser Miro afin d’améliorer les performances.
- Travaillez sur des tableaux *de plus petite taille*. Cela devrait alléger la charge de l’application sur le système.
- Enfin, basculez sur *un autre appareil* (ordinateur portable ou de bureau) doté d’une meilleure mémoire RAM et utilisez la version navigateur de Miro, de préférence sur un navigateur Chrome.

:::note
Si vous rencontrez d’autres **problèmes de performance** en travaillant sur une tablette, consultez les solutions possibles [ici](../../using-miro/tools/troubleshooting/16-troubleshooting-mobile-and-tablet-device-issues.md).
:::

### Foire aux questions

1. *Puis-je réaffecter des nœuds de* [*carte mentale*](../../using-miro/advanced-tools/03-mind-map.md) *sur tablette ?*
   - Oui, il suffit de faire glisser le nœud vers un autre nœud parent.
2. *Le rejet de paume est-il pris en charge sur l’application pour tablette ?*
   - La gamme complète des fonctionnalités pour stylet (dont les événements tactiles standard, le dessin avec l’outil stylo et le rejet de paume) est prise en charge sur iPad lorsque vous utilisez un Apple Pencil et sur les tablettes Android lorsque vous utilisez un Samsung S Pen. D’autres combinaisons d’appareils peuvent ne pas inclure le rejet de paume ou présenter d’autres lacunes imprévues.
3. *Comment vider le cache de l’application pour tablette ?*
   - Pour vider le cache de l’application sur iPad, allez dans **Réglages** > **Général** > **Stockage iPad** > trouvez l’application > **Supprimer l’application**. Sur une tablette Android, la configuration dépend de la version de l’OS, mais vous pouvez faire ce qui suit : **Paramètres** > **Stockage** > **Stockage interne** ou **Autres applications** > trouvez l’application > **Vider le cache**.
