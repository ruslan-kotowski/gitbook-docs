Déplacez-vous plus facilement dans vos tableaux Miro à l’aide de votre clavier.

## Barres d’outils et panneaux

- Appuyez sur **Tab** pour naviguer entre les [barres d’outils](../start-here/your-first-board/05-toolbars.md) et les panneaux.
- Utilisez les touches fléchées pour naviguer dans les éléments des barres d’outils et les menus.
- Utilisez les flèches haut et bas pour naviguer dans la [barre d’outils de création](../start-here/your-first-board/05-toolbars.md).

## Navigation au clavier

### Activer/désactiver les raccourcis à un seul caractère

Par défaut, les raccourcis à un seul caractère sont activés. Pour les désactiver (par exemple, pour éviter les interférences avec des technologies d'assistance comme les lecteurs d'écran) :

1. Cliquez sur l'icône du **Menu principal** (![icon-main.svg](../../../../../../docs/getting-started/accessibility-in-miro/images/31688274627218_icon-main.svg)) dans la barre d'outils du tableau.
2. Sélectionnez l'option de menu **Accessibilité** pour ouvrir le sous-menu.
3. Dans le sous-menu, activez ou désactivez les **Raccourcis à un seul caractère**.

### Accéder au tableau

- Appuyez sur **Tab** jusqu’à ce que vous atteigniez le bouton "Passer au premier objet du tableau" et appuyez sur **Entrée**, ou
- Appuyez sur **B** lorsque le focus est sur une barre d’outils ou un panneau pour déplacer le focus vers le tableau. Lorsque le focus est sur le tableau, vous pouvez :
  - Zoomer avec **Ctrl+/Cmd+** et **Ctrl-/Cmd-**.
  - Effectuer un panoramique sur le tableau avec les touches fléchées.
  - Sous macOS, appuyez sur **Cmd + Maj + Bas** pour sélectionner le premier objet dans le tableau.
  - Sous Windows, appuyez sur **Ctrl + Maj + Bas** pour sélectionner le premier objet dans le tableau.

### Revenir aux barres d’outils

- Appuyez sur **Échap**.

### Naviguer de manière linéaire dans le tableau

- Utilisez **Tabulation** pour passer d’un objet à l’autre du tableau dans l’ordre de lecture, de haut en bas et de gauche à droite.
- Utilisez **Maj + Tab** pour vous déplacer dans l’ordre inverse.

### Naviguer spatialement dans le tableau

macOS

**Cmd + touches fléchées** pour passer d’un objet à l’autre du tableau dans un ordre spatial :

- **Cmd + flèche droite** pour passer à l’élément se trouvant à droite de l’objet actuel.
- **Cmd + flèche haut** pour passer à l’élément se trouvant au-dessus de l’objet actuel.
- **Cmd + flèche bas** pour passer à l’élément se trouvant au-dessous de l’objet actuel.
- **Cmd + flèche gauche** pour passer à l’élément se trouvant à gauche de l’objet actuel.

Windows

**Ctrl + touches fléchées** pour passer d’un élément à l’autre du tableau dans un ordre spatial :

- **Ctrl + flèche droite** pour passer à l’élément se trouvant à droite de l’objet actuel.
- **Ctrl + flèche haut** pour passer à l’élément se trouvant au-dessus de l’objet actuel.
- **Ctrl + flèche bas** pour passer à l’élément se trouvant au-dessous de l’objet actuel.
- **Ctrl + flèche gauche** pour passer à l’élément se trouvant à gauche de l’objet actuel.

### Aller au premier ou au dernier objet

macOS

- **Option + Maj + flèche gauche**, ou **Option + Accueil**, pour passer au premier objet dans le conteneur actuel.
- **Option + Maj + flèche droite**, ou **Option + Fin**, pour passer au dernier objet dans le conteneur actuel.

Windows

- **Alt + Maj + flèche gauche**, ou **Alt + Accueil**, pour passer au premier objet dans le conteneur actuel.
- **Alt + Maj + flèche droite**, ou **Alt + Fin**, pour passer au dernier objet dans le conteneur actuel.

### Entrer dans un objet conteneur ou le quitter

Les objets conteneurs comprennent les cadres et les objets groupés. Lorsque vous êtes dans un conteneur, la navigation est limitée à cet objet.

macOS

- **Cmd + Maj + flèche bas** pour entrer dans un objet conteneur.
- **Cmd + Maj + flèche haut** pour quitter un objet conteneur.

Windows

- **Ctrl + Maj + flèche bas** pour entrer dans un objet conteneur.
- **Ctrl + Maj + flèche haut** pour quitter un objet conteneur.

### Modifier le texte d’un objet

- Appuyez sur **Entrée** sur un objet pour commencer à le modifier (par exemple, un pense-bête).
- Appuyez sur **Échap** sur un objet pour arrêter de le modifier (par exemple, un pense-bête).

:::note
La navigation au clavier ne fonctionne que lorsque des objets sont sélectionnés, et non lorsqu’ils sont en cours de modification.
:::

### Déplacer des objets

- Utilisez **les touches fléchées** pour déplacer un objet.
- Utilisez **Maj + une touche fléchée** pour déplacer un objet plus loin.

### Sélectionner plusieurs objets du tableau

macOS

- Sélectionnez le premier objet.
- Appuyez sur **Cmd** + **Option** + **Shift** + **Flèche** pour choisir chaque objet supplémentaire.

Windows

- Sélectionnez le premier objet.
- Appuyez sur **Ctrl** + **Alt** + **Shift** + **Flèche** pour choisir chaque objet supplémentaire.

### Redimensionner les objets du tableau

macOS

- Sélectionnez l'objet du tableau que vous souhaitez redimensionner.
- Appuyez sur **Cmd** + **Option** + **Maj** + **Plus/Moins**.

Windows

- Sélectionnez l'objet du tableau que vous souhaitez redimensionner.
- Appuyez sur **Ctrl** + **Alt** + **Maj** + **Plus/Moins**.

### Accéder au menu contextuel d’un objet et y naviguer

Le menu contextuel d’un objet comprend des fonctions supplémentaires qui vous permettent de personnaliser l’objet, par exemple en changeant sa couleur, son type ou son style de texte. Après avoir sélectionné un objet, son menu contextuel apparaîtra horizontalement au-dessus de l’objet, donnant accès à ces options.

macOS

- Appuyez sur **Cmd + Enter** pour déplacer le curseur vers le menu contextuel d’un objet.
- Utilisez les **flèches gauche/droite** pour naviguer dans le menu contextuel d’un objet et **Entrée/Espace** pour sélectionner un élément.

Windows

- Appuyez sur **Ctrl + Entrée** pour déplacer le focus sur le menu contextuel d'un objet.
- Utilisez les **flèches gauche/droite** pour naviguer dans le menu contextuel d'un objet et **Entrée/Espace** pour sélectionner un élément.

### Créer un objet

La manière la plus simple d'ajouter un nouvel objet est d'utiliser la palette de commandes :

macOS

- Appuyez sur **Cmd+K** pour ouvrir la palette de commandes.
- Commencez à taper le nom de l'objet, par exemple, Pense-bête.
- Utilisez les **flèches** pour sélectionner l'objet.
- Appuyez sur la **touche Entrée** et l'objet sera ajouté au centre du tableau.

Windows

- Appuyez sur **Ctrl+K** pour ouvrir la palette de commandes.
- Commencez à taper le nom de l'objet, par exemple Pense-bête.
- Utilisez les **flèches directionnelles** pour sélectionner l'objet.
- Appuyez sur la **touche Entrée** et l'objet sera ajouté au centre du tableau.

Autres méthodes pour créer un objet avec le clavier :

- Tabulez jusqu’à la [barre d’outils de création](../start-here/your-first-board/05-toolbars.md), puis appuyez sur les **flèches haut ou bas** jusqu’à atteindre le type d’objet souhaité (forme, pense-bête, etc.) et appuyez sur **Entrée**, ensuite **Tab** pour sélectionner l’objet, et appuyez de nouveau sur **Entrée** pour créer l’objet. L’objet sera placé sur le tableau.
- Appuyez sur le raccourci clavier associé à l’objet (par ex. **N** pour les pense-bêtes), puis appuyez sur **Tab** pour sélectionner l’objet, puis appuyez sur **Entrée**. L’objet sera placé sur le tableau.
- Copiez et collez un élément existant avec **Ctrl**/**Cmd+C** puis **Ctrl/Cmd+V**.
- Dupliquez un objet existant avec **Ctrl/Cmd + D**.
- Pour modifier un pense-bête, appuyez sur **Entrée**, puis sur **Tabulation**. Un nouvel objet sera créé à côté de l’objet sélectionné.

### Créer des connexions de diagrammes

Vous pouvez créer des lignes de connexion entre les objets sur le tableau.

- Utilisez la touche Tab pour accéder au premier objet à connecter.
- Appuyez sur Cmd+K (Mac) ou Ctrl+K (Windows) pour ouvrir la palette de commandes.
- Tapez et sélectionnez **Créer une connexion vers**.
- Utilisez la touche Tab pour accéder au second objet.
- Appuyez sur Cmd+K (Mac) ou Ctrl+K (Windows) pour ouvrir la palette de commandes.
- Tapez et sélectionnez **Connecter à cet objet**.

### Commentaires

macOS

- **Option+Tab** pour naviguer vers l'avant à travers les commentaires.
- **Option+Shift+Tab** pour naviguer vers l'avant à travers les commentaires.
- **Option+**C pour ajouter un commentaire à l’objet actuel.

Windows

- **Alt + C** pour ajouter un commentaire à l’objet actuel.

## Commandes de technologie d’assistance

Les commandes clavier suivantes sont uniquement disponibles lorsque vous utilisez des technologies d’assistance comme les lecteurs d’écran.

### Résumé du tableau

Le résumé du tableau fournit aux utilisateurs de lecteur d’écran un bref aperçu des objets du tableau.

macOS

- **Option + S** pour recevoir des informations concernant le nombre et les types d’objets dans le tableau.

Windows

- **Alt + S** pour recevoir des informations concernant le nombre et les types d’objets dans le tableau.

### Informations supplémentaires sur l’objet

Cette action fournit aux utilisateurs de lecteur d’écran des informations supplémentaires sur l’objet actuellement sélectionné.

macOS

- **Option + I** pour recevoir des informations supplémentaires sur un objet.

Windows

- **Alt + I** pour recevoir des informations supplémentaires sur l'objet.

### Annonce de sélection d'objet

Il est possible de réitérer les informations fournies lors de la sélection de l'objet du tableau.

macOS

- **Option + R** pour réitérer l'annonce de sélection.

Windows

- **Alt + R** pour réitérer l'annonce de sélection.
