Dans cet article, l’équipe d’accessibilité de Miro a réuni des conseils sur la conception et la gestion de sessions collaboratives inclusives dans Miro.  Nous le mettrons à jour régulièrement, en fonction des bonnes pratiques qui se révéleront utiles pour nos clients.

Notre recommandation générale est de vérifier, lorsque vous préparez votre tableau Miro, si parmi les personnes participant à la collaboration de manière asynchrone ou en temps réel, certaines auraient des besoins en termes d’accessibilité.

Si tel est le cas, nous vous recommandons de définir des instructions claires pour toutes les personnes participant à la réunion ou à la collaboration afin de rendre l’expérience inclusive pour tout le monde et de vous assurer que tout le monde en a pris connaissance avant de commencer le travail sur Miro.

## Utilisation du vérificateur d'accessibilité Miro

Le vérificateur d'accessibilité Miro permet à tous les utilisateurs de créer des tableaux accessibles. Le vérificateur analyse votre tableau Miro afin d'identifier les zones susceptibles de ne pas respecter les normes d'accessibilité, ce qui vous donne des indications utiles pour améliorer votre contenu pour tous les utilisateurs.

Le vérificateur effectue les contrôles suivants :

- Contraste du texte
- Contraste non textuel
- Description des images
- Titres des conteneurs (cadres, tableaux, tableaux Kanban, etc.)

Le respect des recommandations du vérificateur d'accessibilité améliorera l'accessibilité pour les utilisateurs de lecteurs d'écran, ainsi que pour les daltoniens et les malvoyants.

### Comment ouvrir le vérificateur d'accessibilité

Pour ouvrir le vérificateur d'accessibilité, procédez comme suit :

1. Ouvrez un tableau Miro.
2. Dans la [barre du tableau](../../using-miro/working-on-the-board/02-miro's-new-simplified-user-interface.md), sélectionnez les trois points verticaux.
   Un menu contextuel s'ouvre.
3. Sélectionnez **Tableau** > **Vérificateur d'accessibilité**.
   Le panneau du vérificateur d'accessibilité s'ouvre et analyse automatiquement votre tableau.

## Rendre les tableaux Miro plus accessibles aux utilisateurs de lecteurs d'écran

Si vous collaborez avec des utilisateurs de lecteurs d'écran, il leur est possible de créer, lire, modifier et supprimer des objets sur un tableau Miro. Vous pouvez toutefois prendre certaines mesures pour faciliter l'utilisation de votre tableau.

En règle générale, plus les tableaux sont structurés, plus il est facile pour les utilisateurs de lecteurs d'écran d'accéder au contenu. Si vous voulez vous assurer que les utilisateurs de lecteurs d'écran peuvent facilement naviguer dans le tableau et accéder au contenu du tableau, suivez les recommandations suivantes :

- [Utilisez](../../using-miro/essential-tools/07-frames.md) des cadres pour structurer le contenu du tableau et assurez-vous qu’aucun objet du tableau n’est placé en dehors de ces cadres.
- Créez les cadres dans une séquence allant de gauche à droite : de cette façon, les utilisateurs pourront suivre facilement le flux de la session collaborative.
- Idéalement, chaque cadre devrait s’intégrer dans la fenêtre d’affichage à un zoom de 100 % à la fois dans le navigateur et sur le canevas de Miro : cela garantira une expérience utilisateur la plus fluide possible. Les cadres devraient également éviter de se chevaucher les uns sur les autres.
- Fournissez des descriptions pour les images. Il suffit de sélectionner une image et d'activer le bouton **ALT**, puis d'ajouter votre description de ce que l'utilisateur doit percevoir.

![accessibilité-alt-texte.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647616796690_accessibility-alt-text.png)
*Ajouter un texte alternatif aux images*

### Ajouter un texte alternatif aux images

Fournissez des alternatives textuelles/descriptions pour tout visuel complexe tel que les diagrammes - utilisez du [texte](../../using-miro/essential-tools/16-text.md) ou [forme](../../using-miro/essential-tools/11-shapes.md) pour insérer l'annotation.

### Utiliser consciemment les pense-bêtes de couleurs et les étiquettes

[Donner différentes](../../using-miro/essential-tools/14-sticky-notes.md) couleurs aux pense-bêtes est un excellent moyen de regrouper des idées ou de les différencier en fonction des contributeurs. Si vous souhaitez rendre votre atelier plus inclusif, il existe une alternative aux couleurs des pense-bêtes : les étiquettes. Ces dernières peuvent également être utilisées pour identifier les auteurs d’un pense-bête ou pour catégoriser les pense-bêtes du tableau.

![accessibility-tags.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647563445650_accessibility-tags.png)

*Utilisation des étiquettes*

### Augmenter le niveau de zoom du navigateur

Rendez-vous dans le menu du navigateur, ouvrez les paramètres du zoom et augmentez la taille de l’interface utilisateur jusqu’à 200 %. Les dimensions de la barre d’outils et des contrôles de Miro augmenteront.

## Rendre Miro plus accessible pour les personnes ayant une sensibilité aux mouvements

### Désactiver le curseur pour réduire les distractions sur le tableau

Miro se focalise avant tout sur la collaboration. Le fait de voir les curseurs de toutes les personnes présentes sur le tableau est essentiel pour émuler une expérience en personne engageante.

Toutefois, vous avez la possibilité de désactiver les curseurs lorsque vous souhaitez réduire les distractions sur le tableau si les personnes avec qui vous collaborez sur le tableau le préfèrent. Cela améliorera également la performance générale du tableau si vous collaborez avec des dizaines ou des centaines de personnes.

![accessibility-hide-cursors.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647616803858_accessibility-hide-cursors.png)

Masquage des curseurs des collaborateurs sur le tableau

### Activer la réduction du mouvement

Les animations peuvent distraire, provoquer des vertiges, le mal des transports et déclencher des migraines. Activez l'option Réduire le mouvement (Menu principal > Préférences > Réduire le mouvement) pour :

- Empêchez la lecture automatique des GIF.
- Passez instantanément d'un cadre à l'autre à l'aide du panneau des cadres.
- Suppression des transitions de l'interface utilisateur lors de l'ouverture et de la fermeture des boîtes de dialogue et des menus.

![accessibility-reduce-motion.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647563446802_accessibility-reduce-motion.png)

*Activation du mouvement de réduction*

## Rendre Miro plus accessible pour les personnes ayant une sensibilité à la lumière

### Utiliser l’arrière-plan sombre

Réduisez la luminosité de votre tableau en allant dans le menu à **trois points** (**...**) > **Tableau** > **Couleur de fond** et en choisissant un fond gris, gris foncé ou noir.

![accessibilité-couleur de fond.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647563448210_accessibility-background-color.png)

*Utilisation d'une couleur de tableau personnalisée*

### Choisir des couleurs sombres pour les objets du tableau

[Vous pouvez créer des pense-bêtes et des](../../using-miro/essential-tools/14-sticky-notes.md) [formes](../../using-miro/essential-tools/11-shapes.md) avec les couleurs les plus sombres possibles et du texte blanc ou gris clair lorsque c’est nécessaire.

![accessibility-color-tools.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647616804626_accessibility-color-tools.png)

La couleur de l’arrière-plan et du texte d’une forme

## Utilisation des lignes directrices pour un facilitateur accessible

Le facilitateur avant, pendant et après les sessions de collaboration peut avoir un impact important sur l'accessibilité de la collaboration. Lisez notre guide pour en savoir plus sur [10 principes pour une collaboration inclusive](https://miro.com/10-principles-for-inclusive-collaboration/)

### Autoriser le rôle de visiteurs pour faciliter l’accès aux tableaux

[Pour faciliter l’accès au tableau, un animateur ou une animatrice peut permettre aux](../../using-miro/sharing-boards/08-collaboration-with-visitors.md) visiteurs d’accéder au tableau. Ainsi, les personnes qui recevront le lien vers le tableau pourront l'ouvrir sans avoir à s'identifier ou à s'inscrire à Miro. Pour l'activer, allez dans Partage et choisissez Toute personne ayant le lien peut modifier (disponible sur les plans Starter, Business, Education et Enterprise). En savoir plus.

![accessibilité-partage de tableaux.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647563449106_accessibility-board-sharing.png)

Partage d’un tableau avec des visiteurs qui peuvent le modifier

Si un utilisateur n'a pas besoin de modifier un tableau, envisagez de lui donner un accès "Peut voir" ou "Peut commenter". Ainsi, les utilisateurs n'auront pas à s'inquiéter de modifications involontaires.

### Utiliser les fonctionnalités de gestion de l’attention et les liens pour une meilleure navigation sur le tableau

[Pour une navigation plus fluide sur le tableau, un animateur ou une animatrice peut utiliser la fonctionnalité](../../using-miro/facilitation-tools/04-attention-management.md) Bring everyone to me (Amener tout le monde vers moi). Ainsi, toutes les personnes présentes sur le tableau peuvent suivre la progression de l’animateur ou de l’animatrice sur le tableau. En savoir plus.

![accessibility-bring everyone.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647563449618_accessibility-bring-everyone.png)

Amener tous les collaborateurs à votre emplacement sur le tableau

[Un animateur ou une animatrice peut également utiliser la fonction](../../using-miro/working-on-the-board/16-internal-and-external-linking.md) Copy link (Copier le lien) de n’importe quel objet du tableau et le partager avec les collaborateurs. Pour ce faire, cliquez sur n'importe quel objet, cliquez sur le menu à **trois points** (**...**), puis sur **Copier le lien.**

![accessibilité-copie-lien.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647563450642_accessibility-copy-link.png)

L’option permettant de copier le lien d’un objet
