Miro prend en charge le contrôle clavier, les lecteurs d'écran et les logiciels de reconnaissance vocale. Cet article explique comment utiliser Miro avec les technologies d'assistance.

> **💡** Visitez le [Centre d’accessibilité Miro](https://miro.com/accessibility-statement/) pour en savoir plus et rester informé de toutes nos dernières mises à jour.

:::tip
Nous nous efforçons d’améliorer en permanence l’expérience de nos utilisateurs en matière d’accessibilité. Veuillez partager vos retours à [accessibility@miro.com](mailto:accessibility@miro.com).
:::

## Navigateurs et lecteurs d’écran recommandés

:::note
L’équipe chargée de l’accessibilité de Miro continue de travailler à l’amélioration de la compatibilité avec les technologies d’assistance et mettra à jour cette liste au fur et à mesure qu’elle deviendra plus compatible avec d’autres navigateurs, lecteurs d’écran et appareils.
:::

Nous vous recommandons d’utiliser les navigateurs et les lecteurs d’écran suivants avec l’application de bureau pour profiter de la meilleure expérience possible :

### Navigateurs

- Chrome
- Firefox
- Safari

### Lecteurs d’écran

- NVDA pour Microsoft Windows
- JAWS pour Microsoft Windows
- VoiceOver intégré pour macOS

### Reconnaissance vocale

- Contrôle vocal pour macOS
- Voice Access pour Microsoft Windows

:::note
Nous fournissons actuellement une assistance limitée pour les technologies d’assistance sur les appareils mobiles et les tablettes.
:::

## Conversion vocale en texte

### Contrôle vocal pour macOS

Lorsque vous activez le Contrôle vocal sur macOS, le bouton **Explorer le contenu du tableau** apparaît sur votre tableau Miro.

:::note
Pour apprendre comment activer Voice Control sur MacOS, consultez [le service d’assistance Apple](https://support.apple.com/en-gb/102225).
:::

:::tip
Sur votre Mac, lorsque vous activez **Voice Control** dans les **Réglages**, assurez-vous également de définir **Overlay** sur **Noms des éléments**.
:::

Pour commencer à donner des commandes, dites *Appuyez sur Explorer le contenu du tableau*. Miro affiche les noms des éléments pour chaque outil et objet sur le tableau.

Par exemple, dites *Appuyez sur Explorer le contenu du tableau*, puis donnez les commandes suivantes pour ajouter un pense-bête avec texte :

1. *Appuyez sur **Pense-bête***
2. *Appuyez sur **Placer un pense-bête jaune clair***
3. *Appuyez sur la touche **Entrée***
4. *« Bonjour ! »*
5. *Appuyez sur la touche **Échap***

### Voice Access pour Microsoft Windows

Lorsque vous activez Voice Access sur Windows, dites *Afficher les numéros.* Dites ensuite *Cliquez* et le numéro qui s'affiche au centre de votre écran. Par exemple, dites *Cliquez 44*. Miro est activé pour Voice Access.

:::note
Pour savoir comment activer l’accès vocal sur MS Windows, consultez le [site de support de Microsoft](https://support.microsoft.com/en-gb/windows/use-voice-recognition-in-windows-83ff75bd-63eb-0b6c-18d4-6fae94050571).
:::

Pour commencer à donner des commandes, dites *Afficher les numéros*. Ensuite, dites *Cliquer* et le numéro de l'outil ou de l'objet que vous souhaitez utiliser.

## Lecteurs d’écran

Un tableau Miro est structuré comme suit :

- Barres d’outils
- Bouton pour passer au premier objet du tableau
- Aperçu du contenu du tableau/table des matières
- Contenu du tableau

## Barres d’outils

Les tableaux Miro comportent cinq barres d’outils :

- Menu et réglages du tableau
- Barre d’outils de collaboration
- Barre d’outils de création
- Aperçu du tableau
- Contrôles du zoom et barre d’outils de navigation

> **💡** Consultez notre [article sur les barres d’outils](../start-here/your-first-board/05-toolbars.md) pour un aperçu complet.

### Comment utiliser les barres d’outils

- Pour naviguer dans les barres d’outils, appuyez sur la **touche Tab**.
- Pour naviguer dans une barre d’outils, utilisez les **touches fléchées**.
- Pour activer un élément, appuyez sur **Entrée**.

## Passer au premier objet du tableau

L’activation du bouton **Passer au premier objet du tableau** permet de déplacer le curseur sur le premier objet du tableau.

### Comment utiliser la fonction "Passer au premier objet du tableau" ?

- Pour déplacer le focus sur le premier objet du tableau Miro, appuyez sur **Entrée**.
- Appuyez sur **Echap** pour revenir aux barres d’outils.

## Explorer le contenu du tableau

**Explorer le contenu du tableau** fournit une vue d’ensemble de la structure du tableau, comme une table des matières, dans laquelle on peut naviguer et qui permet d’accéder directement aux objets du tableau.

### Comment utiliser l’option "Explorer le contenu du tableau" ?

- Pour activer la vue d’ensemble du tableau, appuyez sur la touche **Entrée** du bouton **Explorer le contenu du tableau**.
- Utilisez la navigation de votre lecteur d’écran pour vous déplacer dans la vue d’ensemble, par exemple :
  - JAWS :
    - Utilisez les **touches fléchées** pour vous déplacer parmi tous les objets.
    - Appuyez sur **H** pour parcourir tous les objets du conteneur, tels que les cadres.
    - Appuyez sur **F** pour parcourir tous les objets modifiables du tableau, tels que les pense-bêtes.
- Pour déplacer le curseur sur un objet du tableau, appuyez sur **Entrée** - le curseur se déplace alors sur l’objet du tableau Miro.
- Appuyez à nouveau sur **Entrée** pour modifier l’objet.
- Appuyez sur **Echap** pour revenir à la vue d’ensemble du tableau.
