Si le mouvement affecte votre utilisation de Miro, vous pouvez arrêter ou réduire les animations et autres mouvements dans vos tableaux Miro.

## Réduire le mouvement dans Miro

Activez la réduction du mouvement dans vos paramètres Miro pour arrêter ou réduire les mouvements des fonctionnalités et fonctionnalités de Miro suivantes :

- Mode présentation
- Navigation entre les cadres
- Navigation avec un lien vers un objet
- Navigation dans les widgets à l’aide des raccourcis clavier
- Lecture automatique des GIF

:::note
L’activation de la réduction du mouvement dans vos paramètres Miro correspondra aux paramètres de votre système. Vous pouvez activer ou désactiver ce paramètre à tout moment sans modifier les paramètres de votre système.
:::

### Activer Réduire le mouvement

1. Dans la barre du tableau, sélectionnez l'icône **trois points verticaux** (![icon-main.svg](../../../../../../docs/getting-started/accessibility-in-miro/images/31688274627218_icon-main.svg)).
   Le menu principal s'ouvre.
2. Sélectionner **Accessibilité**.
3. Activez la fonction **Réduire le mouvement**.
