Vous pouvez facilement transférer vos diagrammes depuis Draw.io vers Miro afin de collaborer dans un outil unifié. Les diagrammes importés sont entièrement fonctionnels, vous permettant ainsi de les modifier, colorier, déplacer et redessiner selon vos besoins au sein de Miro.

:::note
Actuellement, Miro prend en charge l’importation de diagrammes uniquement à partir de Lucidchart, MS Visio et Draw.io. Notez que vous pouvez uniquement importer un diagramme vers un nouveau tableau Miro, et non vers un tableau existant.
:::

:::warning
La modification des diagrammes importés ne fonctionne que dans un sens. Les modifications apportées dans Miro ne seront pas répercutées dans le diagramme original Draw.io. Pour créer de nouveaux diagrammes Draw.io modifiables directement dans Miro, utilisez l’[application de diagrammes Draw.io](../../using-miro/formats/diagramming/03-draw.io-diagrams-by-miro.md).
:::

## Importer un diagramme Draw.io sur un nouveau tableau

Suivez ces étapes pour importer un seul diagramme Draw.io sur un nouveau tableau Miro :

1. Dans Draw.io, exportez le diagramme en tant que fichier `.vsdx`.
2. Rendez-vous dans le tableau Miro où vous souhaitez importer le diagramme.
3. Sur la barre d'outils de création à gauche, cliquez sur **Formes et lignes**, choisissez **Plus de formes**, et cliquez sur l'icône **Importer un diagramme** en haut à droite de la fonctionnalité **Diagrammes**.
4. Dans la boîte de dialogue **Importer le diagramme comme un nouveau tableau**, faites glisser le fichier `.vsdx` ou cliquez sur le bouton **Choisir un fichier** et naviguez jusqu’au fichier `.vsdx`.
5. Une fois le fichier sélectionné, cliquez sur **Importer**.
6. Lorsque le processus d'importation est terminé, cliquez sur **Aller au tableau** pour ouvrir le nouveau tableau avec votre diagramme.

## Importation en bloc de diagrammes Draw.io depuis votre tableau de bord

Vous pouvez également importer plusieurs diagrammes Draw.io à la fois depuis votre tableau de bord Miro. Chaque diagramme importé créera un nouveau tableau Miro portant le nom de fichier original. Notez que vous ne pouvez importer plusieurs diagrammes qu’à partir du tableau de bord :

1. Rendez-vous sur votre tableau de bord Miro à l’adresse `https://miro.com/app/dashboard/`.
2. Dans le coin supérieur droit, sélectionnez **+ Créer nouveau**.
3. Sélectionnez **Importer**, puis **Importer un diagramme**.
   La **fenêtre modale Importer des diagrammes** s’ouvrira.
4. Glissez vos fichiers `.vsdx` dans la fenêtre modale ou utilisez le lien **Choisir des fichiers**.
5. Une fois l’importation terminée, vous pouvez cliquer sur **Terminé** pour revenir à votre tableau de bord, ou sur **Ouvrir tous les tableaux** pour lancer les tableaux dans lesquels vos diagrammes ont été importés. Chaque tableau s’ouvrira dans un onglet dédié dans votre navigateur.
