Vous pouvez importer en masse vos diagrammes à partir des applications sources sous forme de PDF ou VSDX.

:::note
Pour certaines applications sources, un seul type de fichier est pris en charge. Pour vérifier, voir Prise en charge du type de fichier à l'importation.
:::

## Comment importer en masse des diagrammes dans Miro

Pour importer vos diagrammes dans Miro, assurez-vous d'avoir exporté le ou les fichiers de votre application source sous forme de PDF ou VSDX. Ensuite, complétez la procédure suivante.

1. Sur votre tableau de bord Miro, pour l'espace où vous souhaitez importer des diagrammes, cliquez sur **Créer nouveau** (**+**).
   ![](../../../../../../docs/getting-started/migrating-content-to-miro/images/32654520716690_image.png)
2. Cliquez sur **Importer** > **Importer depuis \{source\}**. Par exemple, **Importer depuis Mural**.
   La **fenêtre modale "Importer depuis \{source\}"** s'ouvre.
3. Suivez les instructions à l’écran.
4. (Optionnel) Changez l'espace cible pour l'importation. Ou cliquez sur le bouton plus (**+**) pour créer un nouvel espace cible.
5. Cliquez sur **Importer** ***x*** **fichiers**.

## Prise en charge des types de fichiers à importer

| Source | Type de fichier |
| --- | --- |
| Conceptboard | PDF, VSDX |
| Lucidchart | PDF, VSDX |
| Lucidspark | PDF, VSDX |
| Mural | PDF |
| Visio | VSDX |
