Migrez votre contenu Conceptboard de manière transparente dans Miro pour une expérience de collaboration plus robuste. Cela vous permet de consolider votre travail et de tirer parti des fonctionnalités étendues de Miro.

:::warning
L’édition de contenu importé est à sens unique. Les changements effectués dans Miro ne seront pas synchronisés avec Conceptboard.
:::

:::note
Les tableaux Conceptboard sous licence Free ou restreinte peuvent être migrés.
:::

## Importez vos tableaux Conceptboard

Avant de commencer à importer vos tableaux Conceptboard dans Miro, assurez-vous de les avoir exportés de Conceptboard au format PDF. Pour ce faire dans Conceptboard, accédez aux tableaux que vous souhaitez exporter, puis cliquez sur **Tableau** > **Exporter**, et sélectionnez **Exporter le tableau en PDF**.

Une fois que vous avez vos fichiers PDF, procédez comme suit pour les importer dans Miro :

1. Depuis le tableau de bord **Home** de Miro, sélectionnez **+ Créer nouveau**.
   > 💡 Vous pouvez également accéder au menu **Créer nouveau** (**+**) depuis la barre latérale lorsque vous ouvrez un tableau.
2. Sélectionnez ou survolez **Importer**.
3. Sélectionner **Importer depuis Conceptboard**. Une fenêtre modale s’ouvre avec les détails de la procédure d’importation.
4. Sélectionnez **Parcourir** pour ouvrir le sélecteur de fichiers et sélectionner vos fichiers PDF, ou glissez-déposez vos PDF dans la fenêtre modale.
5. (Facultatif) Pour **Ajouter vos tableaux à un espace**, sélectionnez un espace dans le menu déroulant.
6. Sélectionner **Importer des tableaux**. Une fenêtre modale s’affiche pour vous informer que les tableaux sont en cours d’importation. Vous recevrez une notification par e-mail lorsque l’importation sera terminée et que vos nouveaux tableaux Miro seront prêts.

## Comment les objets Conceptboard apparaissent dans Miro

Bien que Conceptboard et Miro aient des fonctionnalités similaires, il peut y avoir des différences dans les options de style et de formatage après l'importation. Ce tableau fournit une comparaison des objets courants de Conceptboard traduits en objets Miro :

| **Conceptboard** | **Miro** |
| --- | --- |
| Collaborateurs et partage | 🟠 Peut être recréé manuellement |
| Commentaires | 🟠 Peut être recréé manuellement |
| Connecteurs | Connecteurs |
| Documents | 🟠 Peut être recréé manuellement |
| Dessiner | Lignes |
| Images | Images |
| Carte mentale | Formes et connecteurs |
| Sections | Cadres et formes |
| Formes | Formes et images |
| Pense-bêtes | Pense-bêtes |
| Tableaux | Tableaux/formes et connecteurs |
| Texte | Texte |
| Vidéos et autres URL | 🟠 Peut être recréé manuellement |

## Restrictions

Bien que le processus d'importation vise à être aussi fluide que possible, soyez conscient des limitations suivantes lors de l'importation depuis Conceptboard :

- Les zones de texte Miro peuvent contenir jusqu’à 6 000 caractères, espaces compris. Tout texte supplémentaire sera recadré.
- Les couleurs et les niveaux d’opacité sont mis en correspondance avec les couleurs les plus proches dans Miro.
- Les pense-bêtes Miro ne permettent pas l'ajustement de la rotation ou de la palette de couleurs qui pourraient avoir été présents dans Conceptboard.

:::note
Pour toute question concernant la migration de Conceptboard, veuillez contacter le [service d’assistance Miro](../../using-miro/tools/troubleshooting/06-contacting-miro-support.md) ou vous adresser directement à votre responsable Customer Success Miro.
:::
