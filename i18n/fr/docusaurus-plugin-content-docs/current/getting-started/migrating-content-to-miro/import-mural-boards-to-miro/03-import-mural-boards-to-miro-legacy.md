Transférez facilement votre contenu de Mural à Miro, vous permettant de poursuivre votre travail collaboratif avec un contenu familier dans un nouvel environnement. Ce guide présente deux méthodes pour importer vos tableaux Mural : en copiant et collant du contenu directement, ou en utilisant la fonctionnalité d'importation en masse avec des fichiers PDF.

:::warning
Modifier le contenu importé est un processus à sens unique. Les changements effectués dans Miro ne seront pas synchronisés avec Mural.
:::

:::note
Les tableaux Mural sous licence complète ou gratuite restreinte peuvent être migrés vers Miro en utilisant ces méthodes.
:::

## Importer le contenu Mural en copiant et collant

Vous pouvez copier manuellement le contenu d'un tableau Mural et le coller dans un tableau Miro. Cette méthode convient pour migrer des tableaux individuels ou des sélections de contenu spécifiques.

:::note
Tout utilisateur disposant d'un accès de modification à la fois au tableau source Mural et au tableau cible Miro peut effectuer cette action.
:::

1. Ouvrez le tableau Mural qui contient le contenu que vous souhaitez exporter.
2. Sélectionnez tous les contenus que vous voulez déplacer. Vous pouvez utiliser le raccourci clavier **Ctrl + A** (Windows) ou **Commande + A** (Mac) pour tout sélectionner sur le tableau.
3. Cliquez avec le bouton droit de la souris sur le contenu sélectionné et choisissez **Copier**, ou utilisez le raccourci clavier **Ctrl + C** (Windows) ou **Commande + C** (Mac).
4. Ouvrez un tableau Miro existant ou créez-en un nouveau où vous souhaitez importer le contenu.
5. Cliquez avec le bouton droit de la souris sur une zone vide du tableau Miro et sélectionnez **Coller**, ou utilisez le raccourci clavier **Ctrl + V** (Windows) ou **Commande + V** (Mac).
6. Examinez le contenu importé sur votre tableau Miro. Vous devrez peut-être effectuer des ajustements, car il peut y avoir des différences dans les options de style et de formatage entre Mural et Miro. Reportez-vous à la section Comment les objets Mural apparaissent dans Miro (Copier-coller) pour plus de détails sur la cartographie des objets.

## Importer des tableaux Mural en vrac en utilisant l'export PDF

Pour migrer plusieurs tableaux Mural, vous pouvez utiliser la fonctionnalité d'importation en masse de Miro, qui accepte les exports PDF de Mural.

> Cette fonctionnalité d'importation en masse est disponible pour les utilisateurs sur les forfaits Starter, Business, Education et Enterprise.

1. Accédez aux tableaux Mural que vous souhaitez exporter.
2. Pour chaque tableau Mural, cliquez sur **Télécharger en tant que** et enregistrez le tableau sous forme de fichier **PDF**.
3. Ouvrez votre tableau de bord Miro.
4. Dans le coin supérieur droit, cliquez sur le bouton **+ Créer nouveau**, puis choisissez **Importer**.
5. Sélectionnez **Importer depuis Mural** dans les options.
6. Dans la fenêtre modale qui apparaît, vous pouvez soit cliquer sur **Parcourir** pour ouvrir le sélecteur de fichiers de votre système et sélectionner vos fichiers PDF, soit faire glisser et déposer vos fichiers PDF directement dans la fenêtre modale.
7. (Optionnel) Utilisez le menu déroulant **Ajouter vos tableaux à un espace** pour sélectionner un [Espace](../../../using-miro/spaces/01-spaces.md) spécifique dans Miro où vos tableaux importés seront ajoutés. Si vous ne sélectionnez pas un espace, les tableaux seront ajoutés par défaut à votre zone principale d'équipe.
8. Cliquez sur le bouton **Importer des tableaux** pour commencer le processus d’importation.
9. Une fenêtre modale vous informera que les tableaux sont en cours d’importation. Vous recevrez une notification par e-mail lorsque l'importation sera terminée et que vos nouveaux tableaux Miro seront prêts à être utilisés.
10. Après l'importation, vérifiez le contenu de vos nouveaux tableaux Miro. Reportez-vous à la section Comment les objets Mural apparaissent dans Miro (Importation en bloc via PDF) pour obtenir des conseils sur la manière dont les objets Mural sont traduits.

## Restrictions et considérations

Bien que Miro s'efforce de rendre le processus d'importation aussi fluide que possible, veuillez prendre en compte les limitations suivantes lors de la migration de contenu depuis Mural :

- **Limites de texte :** Les zones de texte Miro peuvent contenir jusqu'à 6 000 caractères, espaces compris. Tout texte dépassant cette limite sera recadré lors de l'importation.
- **Formes de pense-bêtes :** Les pense-bêtes circulaires de Mural seront convertis en pense-bêtes carrés dans Miro.
- **Couleurs et opacité :** Les couleurs et les niveaux d’opacité de Mural sont mis en correspondance avec les équivalents les plus proches disponibles dans Miro. Quelques différences visuelles peuvent survenir.
- **Mise en forme du pense-bête :** Actuellement, les pense-bêtes Miro ne prennent pas en charge la rotation, les ajustements de palette de couleurs personnalisée au-delà de l'ensemble standard, ni le formatage du texte en liste à puces à l'intérieur du pense-bête lui-même.

### Comparer la structure de contenu de Mural et Miro

Comprendre les différences dans l'organisation du contenu entre Mural et Miro peut vous aider à planifier votre migration de manière plus efficace.

|  |  |
| --- | --- |
| **Élément mural** | **Équivalent Miro** |
| Espace de travail :  - Créé par les admins de l’entreprise - Géré par les admins d’équipe | Équipe :  - Créé par les admins de l’entreprise - Géré par les admins d’équipe |
| Salles :  - Créé par les utilisateurs d’un espace de travail Mural - Géré par les utilisateurs | Espaces  - Créé par des utilisateurs au sein d'une équipe Miro - Géré par les utilisateurs - Ne peut être imbriqué |
| Dossiers :  - Créé par les utilisateurs d’un espace de travail Mural - Géré par les utilisateurs - Peut être imbriqué dans des Rooms | Les projets peuvent être utilisés pour l'organisation, mais les espaces Miro sont le principal conteneur au sein d'une équipe. Miro n’a pas d’équivalent direct aux dossiers imbriqués de Mural dans les Salles. |
| Murals (tableaux) :  - Créé par les utilisateurs d’un espace de travail Mural - Géré par les utilisateurs | Tableaux :  - Créé par des utilisateurs au sein d'une équipe Miro - Géré par les utilisateurs |
