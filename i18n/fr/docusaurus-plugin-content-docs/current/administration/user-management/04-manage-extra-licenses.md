Si vous ajoutez un nouveau membre à votre équipe et que toutes les licences de votre forfait sont déjà utilisées, une licence supplémentaire est automatiquement ajoutée. Ce guide fournit des étapes pour gérer ces licences supplémentaires.

## Gestion des ajustements de licences et de la facturation

### Avant d'être facturé pour des licences supplémentaires

Pour éviter des frais supplémentaires sur votre prochaine facture, vous devez supprimer la licence supplémentaire avant votre date de facturation.

Après avoir ajusté la taille de votre équipe, une confirmation vous sera envoyée. Votre facture sera mise à jour pour refléter le nombre correct de licences, en ne facturant que pour les jours durant lesquels les licences supplémentaires ont été utilisées.

### Après avoir été facturé pour les licences supplémentaires

Si votre facture récente inclut des frais supplémentaires pour des licences, la première étape consiste à supprimer la licence supplémentaire.

La suppression des licences après la date de facturation n'entraîne pas une réduction immédiate des licences. La réduction est prévue pour le renouvellement. Aucun remboursement n’est disponible.

Pour en savoir plus sur la façon dont Miro calcule les coûts au prorata, consultez [la facturation Miro](../../plans-billing/billing-and-payments/04-miro-billing.md).

## Comment supprimer les licences supplémentaires

1. Supprimer l'utilisateur supplémentaire.
   1. Depuis votre tableau de bord Miro, cliquez sur votre avatar dans le coin supérieur droit, puis cliquez sur **console d’admin** | **Paramètres**.
   2. Dans le panneau de gauche, cliquez sur **Équipes**.
   3. Dans l'onglet **Utilisateurs**, pour l'utilisateur que vous souhaitez supprimer, cliquez sur les trois points (**...** ).
   4. Cliquez sur **Supprimer de l’équipe**.
2. Modifiez la taille de l'équipe pour correspondre au nombre correct de licences.
   1. Depuis votre tableau de bord Miro, cliquez sur votre avatar à l'extrême droite, puis cliquez sur **console d’admin** | **Paramètres**.
   2. Dans le panneau de gauche, cliquez sur **Facturation**.
   3. Dans l'onglet **Aperçu**, sous **Détails du forfait**, cliquez sur **Modifier la taille de l'équipe**.
      Le modal **Modifier la taille de l'équipe** s'ouvre.
   4. Pour **Licences**, cliquez sur le menu déroulant pour modifier la taille de l'équipe.
      Vous avez programmé la suppression d'une licence, qui prendra effet à votre date de renouvellement. Pour plus d'informations, consultez la page [Facturation mensuelle et annuelle de Miro](../../plans-billing/billing-and-payments/04-miro-billing.md).

Pour en savoir plus sur les licences et la facturation, consultez [Facturation Miro](../../plans-billing/billing-and-payments/04-miro-billing.md).

## Éviter les licences supplémentaires

Les bonnes pratiques suivantes vous aident à éviter l’ajout de licences supplémentaires à votre forfait :

- Invitez davantage d'utilisateurs sur un tableau sans frais supplémentaire en explorant nos options [Visiteur](../../using-miro/sharing-boards/08-collaboration-with-visitors.md) et [Invité](../../using-miro/sharing-boards/07-collaboration-with-guests.md).
- Les admins peuvent ajuster leurs [paramètres d'invitation](02-invitation-settings.md) pour s'assurer que des licences supplémentaires ne soient pas ajoutées par erreur.

:::note
Si vous rencontrez des problèmes avec votre facturation, veuillez [contacter le service d’assistance](../../using-miro/tools/troubleshooting/06-contacting-miro-support.md). Nous ne pouvons partager les informations relatives à la facturation qu’avec les admins de Miro ou la personne qui a acheté l’abonnement. Si ce n'est pas vous, veuillez contacter votre admin Miro pour obtenir de l'aide.
:::
