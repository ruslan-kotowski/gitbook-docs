Les admins peuvent spécifier quels membres de l’équipe peuvent inviter de nouveaux membres à leur forfait gratuit ou payant. Par exemple, les admins peuvent activer uniquement les admins pour inviter de nouveaux membres.

Les admins peuvent également autoriser tous les membres de l’équipe à inviter de nouveaux membres.

:::note
Pour les forfaits payants, lorsqu'un invité accepte une invitation d'un membre de l'équipe existant, y compris les admins, une licence est automatiquement ajoutée à votre abonnement.
:::

Si vous autorisez uniquement les admins à ajouter de nouveaux membres d'équipe, alors les membres existants, non-admins, n'auront pas l'option dans Miro d'inviter de nouveaux membres.

:::tip
Pour les forfaits Business et Enterprise, les admins d’entreprise peuvent [configurer les paramètres d’invitation](../get-started-as-a-miro-admin/01-i-am-a-new-miro-admin.-where-to-start.md) pour chaque équipe individuellement dans leur abonnement.
:::

## Gérer les paramètres d'invitation de l'équipe

Pour gérer les paramètres d'invitation de l'équipe sur un forfait Free, Starter ou Education, assurez-vous d'avoir le rôle d'admin d'équipe.

Pour gérer les paramètres d'invitation de l'équipe sur un forfait Business ou Enterprise, assurez-vous d'avoir le rôle d'admin d’entreprise.

### les forfaits Free, Starter et Education

En tant qu'admin d’équipe, suivez ces étapes :

1. Depuis votre tableau de bord Miro, cliquez sur votre avatar dans le coin supérieur droit et sélectionnez **Console d'administration**.
2. Allez dans **Sécurité** > **Autorisations**.
3. Sous **Invitation**, sélectionnez qui peut inviter des utilisateurs dans votre équipe.
4. (Facultatif) Pour fournir un lien d’équipe que tout le monde peut suivre pour rejoindre, activez **Activer le lien d’invitation de l’équipe** en position activée.

:::note
Pour les forfaits Starter et Education, si les membres de l'équipe ne sont pas autorisés à inviter de nouveaux membres, alors tout membre qui envoie une invitation à modifier voit une fenêtre contextuelle avec **Demander à l'admin d'accorder l'accès de modification** pré-sélectionné. Le membre de l'équipe peut envoyer son invitation, mais l'invité est ajouté en tant qu'invité ou commentateur, en attente de l'approbation de l'admin pour l'accès en modification. Seuls les membres de l’équipe peuvent modifier les tableaux.
:::

### Forfait Business

En tant qu'admin d'entreprise, suivez ces étapes :

1. Cliquez sur votre avatar dans le coin supérieur droit de votre tableau de bord Miro et sélectionnez **Console Admin**.
2. Cliquez sur **Équipes**.
3. Sous **Nom de l’équipe**, sélectionnez une équipe.
   Le panneau des paramètres de l'équipe s'ouvre.
4. Cliquer sur **Paramètres**.
5. Sous **Invitation**, sélectionnez qui peut inviter des utilisateurs à rejoindre cette équipe.
   > ⚠️ Le nombre de licences est automatiquement augmenté lorsqu'un nouvel utilisateur est ajouté. Si vous autorisez n'importe qui à inviter de nouveaux utilisateurs, alors n'importe qui peut entraîner l'ajout de nouvelles licences à votre abonnement.
6. Sélectionnez **Autoriser** ou **Ne pas autoriser** pour les [invités](../../using-miro/sharing-boards/07-collaboration-with-guests.md).
7. En haut à droite, cliquez sur le **X** pour fermer le panneau des paramètres d'équipe.
   Vos paramètres sont enregistrés.

:::note
Si les invités ne sont pas autorisés, alors un membre de l’équipe qui essaie d'inviter un invité voit une fenêtre contextuelle l'informant que les invités ne sont pas autorisés.
:::

### Forfait Enterprise

Pour en savoir plus sur les paramètres d'invitation de l'équipe dans un forfait Enterprise, consultez les [autorisations de l'équipe sur le forfait Enterprise](../../enterprise-administration/managing-enterprise-teams-and-content/10-team-permissions-on-enterprise-plan.md).
