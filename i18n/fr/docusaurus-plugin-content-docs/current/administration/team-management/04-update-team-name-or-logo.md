Pour mettre à jour le nom ou le logo de l'équipe :

1. Cliquez sur l'avatar de votre profil, puis sur **Console d'administration**.
2. Dans la barre latérale gauche, cliquez sur **Équipe,** puis sur **Profil de l'équipe.**
3. (Facultatif) Pour mettre à jour le nom de l'équipe, saisissez un nouveau nom dans le champ **Nom de l'équipe.**
4. (Facultatif) Pour mettre à jour le logo de l'équipe, cliquez sur **Charger** et choisissez une image sur votre appareil.
   - **Types de fichiers pris en charge**:.jpg, .jpeg, .bmp, .png ou .gif
   - **Taille maximale du fichier**:30 MB
5. (Facultatif) Pour supprimer le logo de l'équipe, cliquez sur **Supprimer.**
