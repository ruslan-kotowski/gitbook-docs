Pour gérer les autorisations de l'équipe, dans votre tableau de bord Miro, sélectionnez votre avatar en haut à droite. Allez dans la **console d'administration** > **Sécurité**. Ouvrez ensuite l'onglet **Permissions** .

![gestion des permissions de l'équipe.png](../../../../../../docs/administration/team-management/images/25007076612498_managing-team-permissions.png)

*Permissions d'équipe sur les plans Free, Starter, Business, Education*

Dans la section **Permissions**, vous pouvez gérer les permissions d'équipe suivantes :

- (Plan d'affaires) [**Mode d'inscription des équipes**](02-manage-team-signup-mode.md)
  Indiquez comment les nouveaux membres peuvent rejoindre une équipe dans votre organisation. Ce paramètre doit être activé par un admin d'entreprise.
- (Plan d'affaires) [**Paramètres d'invitation de l'équipe**](../user-management/02-invitation-settings.md)
  Indiquez qui peut inviter de nouveaux membres à rejoindre une équipe. Par exemple, vous pouvez interdire aux membres non administrateurs d'inviter de nouveaux membres. Ce paramètre doit être activé par un admin d'entreprise.
- (Business plan) **Paramètres de collaboration**
  Activer et désactiver le [rôle de copropriétaire](../../using-miro/sharing-boards/06-co-owners-of-boards-and-spaces.md).
- les paramètres de partage.
  Spécifiez les autorisations d'accès et de partage par défaut pour les tableaux et les espaces.
- Sécurité du contenu
  Indiquez si seuls les membres de l'équipe sont autorisés à copier le contenu du tableau.

:::note
Enterprise Plan Les admins peuvent spécifier plus d'autorisations pour leurs équipes. Pour plus d'informations, consultez les [autorisations d'équipe sur les plans Enterprise.](../../enterprise-administration/managing-enterprise-teams-and-content/10-team-permissions-on-enterprise-plan.md)
:::
