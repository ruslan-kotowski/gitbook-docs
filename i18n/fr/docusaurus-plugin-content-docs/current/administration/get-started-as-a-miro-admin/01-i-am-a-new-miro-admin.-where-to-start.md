Lorsque vous créez une nouvelle équipe dans Miro ou que vous [êtes promu au rôle d'admin](../user-management/06-how-to-manage-admin-roles.md), vous avez accès à la console d'admin avec des options telles que les autorisations de l'équipe, les utilisateurs, les intégrations et d'autres attributs de l'équipe et de l'entreprise. L'article donne un aperçu rapide de la console d'administration de Miro.

### Team settings (Paramètres de l’équipe)

Vous pouvez voir toutes vos équipes dans le menu déroulant de la barre latérale gauche de votre tableau de bord. Pour accéder aux paramètres de l'équipe, survolez le nom de l'équipe et cliquez sur l'**icône en forme de roue dentée**.

![team-settings.png](../../../../../../docs/administration/get-started-as-a-miro-admin/images/25005833525906_team-settings.png)
*Accéder aux paramètres de l’équipe*

Si vous êtes membre ou admin de plusieurs équipes, vous pouvez également passer d’une équipe à l’autre dans Team settings (Paramètres de l’équipe) en sélectionnant l’équipe souhaitée dans le menu déroulant situé dans le coin supérieur gauche.

### Paramètres de l’entreprise

Pour accéder aux paramètres de l'entreprise sur Business Plan ou Enterprise Plan, cliquez sur **Entreprise** dans le coin supérieur gauche de la console d'administration.

Le contenu de la section **Team settings** (Paramètres de l’équipe) varie selon les [différents forfaits de Miro](../../plans-billing/miro-plans/02-plans-and-features-available.md), mais tous les admins de Miro peuvent voir les sections suivantes sur la gauche :

- Profil de l’équipe
- Applications et intégrations
- Autorisations
- Utilisateurs actifs

La section **Team profile (Profile de l’équipe)** est l’onglet où vous pouvez changer le nom et le logo de l’équipe et voir les détails de votre plan : le plan actuel, le nombre de tableaux et le nombre de membres de l’équipe. À partir de là, vous pouvez également [quitter votre équipe](../../using-miro/managing-your-profile/06-how-to-leave-a-team.md) ou [la supprimer](../team-management/06-delete-and-restore-teams.md).

![team-profile.pngProfil](../../../../../../docs/administration/get-started-as-a-miro-admin/images/25005833526930_team-profile.png)
*de*

Dans la section **Applications**, l'admin peut :

- Aller sur Miro Marketplace en cliquant sur **Install apps** (Installer des applications)
- Autoriser ou restreindre les membres de l’équipe à installer de nouvelles applications pour l’équipe
- Désinstaller des applications (sélectionnez une application de la liste pour voir l’option de désinstallation)

Pour définir les autorisations de l'équipe, cliquez sur **Sécurité** > **Autorisations**. À partir de là, les admins d’équipe peuvent

- Configurer [le mode inscription à l’équipe](../team-management/02-manage-team-signup-mode.md)
- Définir les [paramètres d’invitation](../user-management/02-invitation-settings.md)
- Gérer les [paramètres de partage](../../using-miro/sharing-boards/11-default-sharing-settings.md) (uniquement sur les plans payants)
- Définir les [paramètres du contenu du tableau](../../using-miro/sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) (uniquement sur les plans payants)
- Les admins peuvent configurer [des paramètres de partage de tableau supplémentaires](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md) avec le forfait Enterprise

![équipe-permissions.png](../../../../../../docs/administration/get-started-as-a-miro-admin/images/25005896069522_team-permissions.png)
Autorisations d’équipe

L'onglet Utilisateurs actifs (situé sous **Utilisateurs** > Utilisateurs **actifs**) est l'endroit où vous avez accès aux options de gestion des utilisateurs :

- [Inviter de nouveaux membres](../user-management/01-invite-users.md)
- [supprimer des membres et des invités des équipes](../user-management/08-remove-users.md)
- [Promouvoir d’autres utilisateurs au rôle d’admin](../user-management/06-how-to-manage-admin-roles.md)

Consultez ces pages pour en savoir plus sur l’administration sur les différents forfaits de Miro :

- [Forfait Free](07-manage-free-plan.md)
- [Forfaits Starter et Education](06-manage-starter-and-education-plan.md)
- [Forfait Business](05-manage-business-plan.md)
- Rendez-vous dans [le Centre d’assistance](https://help.miro.com/hc/en-us) et faites défiler la page jusqu’à la section Administration du forfait Enterprise

### Admin d’équipe et admin d’entreprise

> **Disponible pour** : les forfaits Business et Enterprise

Les plans Business et Enterprise permettent de créer plusieurs équipes au sein d'un même abonnement - ces équipes sont rattachées à un "parapluie" d'entreprise. Il existe deux niveaux de paramètres (**Team settings (Paramètres d’équipe)** et **Company settings (Paramètres d’entreprise)**) et deux rôles d’admin (**admins d’équipe** et **admins d’entreprise**).

:::tip
Dans l'admin d'équipe, l'icône de l'équipe indique les paramètres de l'équipe qu'un administrateur d'équipe peut modifier. En tant qu'admin d'entreprise, allez dans **Admin Console** > **Équipes** > **\{nom de l'équipe\}** > onglet **Paramètres** .

Icône de l'équipe : ![](../../../../../../docs/administration/get-started-as-a-miro-admin/images/26671728983826_image.png)
:::

L’admin d’équipe a le droit de [modifier le nom et le logo de l’équipe](../team-management/04-update-team-name-or-logo.md), d’installer et de désinstaller des applications pour l’équipe, de [promouvoir d’autres utilisateurs en tant qu’admins d’équipe](../user-management/06-how-to-manage-admin-roles.md), de supprimer des membres, d’inviter de nouveaux utilisateurs si cela est autorisé dans la section [Invitation settings](../user-management/02-invitation-settings.md) (Paramètres d’invitation), de [gérer les paramètres de partage par défaut](../../using-miro/sharing-boards/11-default-sharing-settings.md), les [paramètres de contenu du tableau](../../using-miro/sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) et d’activer ou de désactiver le rôle de copropriétaire.

Les admins d’entreprise peuvent gérer toutes les équipes de l’abonnement ainsi que les attributs de l’entreprise :

- Modifier le nom et le logo de l'entreprise.
- Voir les détails de l'abonnement dans l'onglet **Profil de l'entreprise** (Business Plan uniquement). Pour connaître les détails de l'abonnement à Enterprise Plan, allez dans la **console d'administration** > Facturation > Abonnement).
- [Gérer les abonnements](../../plans-billing/manage-your-subscription-and-plan/01-manage-your-subscription.md) dans la section **Billing** (Facturation)
- Convertir les licences d’utilisateur, inviter des utilisateurs dans l’entreprise ou les supprimer dans la section **Active users (Utilisateurs actifs)**
- Gérer les **invitations**

   - Connectez-vous à Miro dans un navigateur, accédez aux paramètres de l'équipe à partir de votre tableau de bord - vous pourrez copier le numéro d'identification de l'équipe dans la barre d'adresse du navigateur (uniquement disponible dans la version web). Il s'agit des numéros situés après **/company/.**
