Pour les organisations utilisant Microsoft Entra ID (anciennement Azure AD) comme fournisseur d’identité, Enterprise Guard transfère de manière sécurisée les prompts et les réponses de l'IA à Microsoft Purview Data Security Posture Management (DSPM) pour l'IA. Les équipes de sécurité et de conformité peuvent ensuite surveiller, auditer et contrôler l'utilisation de l'IA générative depuis une plateforme unique et fiable, réduisant ainsi la surcharge opérationnelle, atténuant les risques tels que les fuites de données et les utilisations abusives, et renforçant la gouvernance de l'IA de niveau entreprise avec Miro.
