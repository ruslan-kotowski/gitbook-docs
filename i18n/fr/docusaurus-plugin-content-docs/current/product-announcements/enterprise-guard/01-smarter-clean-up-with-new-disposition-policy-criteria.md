Nous avons mis à jour les politiques de suppression pour vous donner plus de contrôle sur le moment où les tableaux sont automatiquement déplacés vers la corbeille. Lors de la configuration d'une **politique de suppression**, vous pouvez désormais choisir si la période de suppression est calculée à partir de :

- **Dernière modification**
- **Dernier accès**

### Pourquoi c'est important

Différentes équipes traitent l'activité différemment. Certaines consultent principalement des tableaux, tandis que d'autres les mettent souvent à jour. Avec les nouvelles options, vous pouvez :

- Cibler le contenu vraiment inactif et garder les espaces de travail propres.
- Éviter de déplacer les tableaux de référence dans la corbeille simplement parce qu'ils n'ont pas été modifiés.
- Mieux aligner vos règles de disposition sur les politiques internes de cycle de vie et de gouvernance.
