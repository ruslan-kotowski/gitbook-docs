Dans la console d’admin, les admins d’Enterprise Guard utilisant eDiscovery peuvent désormais annuler les exportations de tableaux en cours ou en file d'attente, filtrer les exportations par statut et créateur, et inclure les journaux de contenu dans les résultats d'exportation.
