Avec les **paramètres de vue analytiques**, les admins peuvent choisir d'afficher ou de masquer les noms d'utilisateur dans les vues de tableau de bord qui incluent l'activité au niveau de l'utilisateur, comme les principaux utilisateurs d'IA. Pour plus d'informations, consultez la [documentation analytique](../../enterprise-administration/getting-started/admin-analytics/01-analytics-overview.md).
