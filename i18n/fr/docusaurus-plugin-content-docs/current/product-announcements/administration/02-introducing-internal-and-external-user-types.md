Les admins peuvent identifier le type d'utilisateur comme interne pour les utilisateurs dont l'e-mail est vérifié, et externe pour ceux dont l'e-mail ne l'est pas. La différenciation visuelle entre les types d'utilisateurs internes et externes entraînera des améliorations fonctionnelles sur la manière dont les admins pourront gérer les utilisateurs à l'avenir. Pour en savoir plus, consultez [Contrôle de domaine](../../enterprise-administration/canvas-25-admin-features/domain-control/01-domain-control.md).
