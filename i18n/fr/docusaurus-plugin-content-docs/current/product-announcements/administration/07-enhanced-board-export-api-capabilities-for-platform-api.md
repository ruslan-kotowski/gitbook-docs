Nous introduisons des points de terminaison supplémentaires pour l'API d'export de tableaux afin de vous aider à gérer les exports de tableaux plus efficacement. Vous pourrez lister les tâches d'export au sein de votre organisation, consulter les tâches d'un export spécifique, récupérer les liens de téléchargement pour les tâches d'export, et annuler les tâches d'export qui ne sont plus nécessaires. Ces mises à jour faciliteront la surveillance, le contrôle et l'automatisation de vos workflows d'export de manière programmée.
