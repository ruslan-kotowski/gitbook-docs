Introduction de cinq nouveaux tableaux de bord pour les clients Enterprise Guard, offrant une vue d'ensemble complète des indicateurs clés. Cela inclut des tableaux de bord pour la découverte des données, la classification des données, le cycle de vie du contenu et la recherche électronique, ainsi qu'un tableau de bord récapitulatif qui regroupe les indicateurs de tous les domaines. Les métriques actuelles serviront de point d'entrée dans l'Explorateur de contenu, qui ne sera plus un élément de menu distinct.
