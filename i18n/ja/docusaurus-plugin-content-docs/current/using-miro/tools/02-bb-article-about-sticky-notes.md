付箋は、簡単なブレインストーミング、メモの作成、情報の視覚的な整理に最適です。カンバンボードやホワイトボードに付箋を貼る手法に慣れている場合は、すぐに馴染むことができるでしょう。

> **利用可能なバージョン：**ブラウザー版、[デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)、[タブレットアプリ](../../getting-started/apps-for-devices/11-tablet-app.md)、[モバイルアプリ](../../getting-started/apps-for-devices/08-mobile-app.md)（機能制限あり）

### はじめに

ツールバーの**付箋**(![icon-sticky.svg](../../../../../../docs/using-miro/tools/images/25953100365714_icon-sticky.svg))アイコンをクリックするか、[キーボードの N を押して](../working-on-the-board/06-shortcuts-and-hotkeys.md)ツールを使用し始めてください。また、ツールバーから直接ドラッグ＆ドロップするか、ボードをクリックして、左のマウスボタンを押しながらカーソルをドラッグすることで付箋を追加することもできます。

付箋のコンテキスト メニューのアイコンをクリックして、付箋の形状を変更できます。

![sticky-switch-type.png](../../../../../../docs/using-miro/tools/images/25953100366994_sticky-switch-type.png)
*正方形の付箋を長方形に変換する*

付箋には、文字の読みやすさとボードのデザインの一貫性に配慮して厳選された 16 色が利用できます（ユーザーが設定できるカラーはありません）。

![sticky-fill-color.png](../../../../../../docs/using-miro/tools/images/25953130442642_sticky-fill-color.png)
*付箋の色*

付箋に文字を追加するには、付箋を選択して入力を始めてください。文字サイズにもよりますが、付箋の文字制限は約 3,000 文字です。コンテキスト メニューで**自動**フォント サイズを有効にすることができます。

複数の付箋を変更するには（サイズや色の変更、タグの追加など）、[こちらのガイド](../working-on-the-board/10-working-with-objects.md)の手順に従って付箋を選択してください。

:::tip
[寸法を有効にする](../formats/diagramming/01-miro-for-mapping-diagramming.md) と、ボード全体で同じサイズの付箋を正確に作成できます。
:::

付箋を削除するには、コンテキストメニューの三点リーダーをクリックして、**削除** を選択するか、単に[付箋を選択](../working-on-the-board/21-work-smarter-not-harder.md)して**Backspace** を押してください。

:::tip
付箋を横一列または縦に並べるには、[付箋を選択](../working-on-the-board/10-working-with-objects.md)し、コンテキストメニューの **[整列]** 機能を使用してください。
:::

*付箋を整列させる*
