ボード上のコンテンツを、より構造化された Doc の形式に変換します。キャンバス上のオブジェクトを入力として使用すると、要約、調査レポート、製品概要を作成して、インサイトの整理と分析を開始することができます。

> 利用可能なプラン：Miro の全プラン
> 利用可能な環境：デスクトップ、モバイル、インタラクティブ ディスプレイ

## ドキュメントの利用方法

新しい文書を追加するには、プラスアイコンをクリックしてドキュメントを検索し、キャンバス上の好きな場所をクリックして追加します。ドキュメントがすでに追加されたボードテンプレートもあります。

![](../../../../../../docs/using-miro/tools/images/25640385657234_33fb246e-3278-4496-8a69-5bd34721a01e.png)

*文書アイコンから新規ドキュメントを追加*

Miro AI で文書を追加することもできます。

![](../../../../../../docs/using-miro/tools/images/25640369208978_678b2f2a-4e6b-449d-af82-0074d85d6d85.png)

*Miro AI による文書の追加*

コンテキストメニューから文書を追加するには、

1. ボード上の複数のオブジェクト（付箋など）を選択して Doc を作成します。
2. コンテキストメニューの **Miro AI** アイコンから **ドキュメント** を選択してサブメニューを開きます。
3. テンプレートを選択するか、**カスタムプロンプト**を使用します。
4. 文書が作成され、ボードに配置されます。

![doc-from-stickies.png](../../../../../../docs/using-miro/tools/images/25640369209362_doc-from-stickies.png)

*コンテキストメニューによる文書の追加*

Miro AI で Doc を追加する方法：

1. **AI で作成**パネルを開きます。
2. **ドキュメント**コンテンツ種別を選択します。
3. あらかじめ用意されたプロンプトを使用するか、自分でプロンプトを書いてください。
4. 必要に応じて、ボード上のオブジェクト（付箋など）を選択して、文脈を追加します。
5. **ドキュメントを生成**をクリックします。
6. 生成されたドキュメントはキャンバス上の空白エリアに表示されます。

## Miro ドキュメントテンプレート

現在、新しい Doc を開始する際に利用できるテンプレートは 4 つあります。製品概要、ふりかえりの要約、会議メモ、リサーチシンセシス。

新しい文書を作成してテンプレートを選択すると、文書にテンプレートが追加されます。

![docs-new.png](../../../../../../docs/using-miro/tools/images/25640385658642_docs-new.png)

*ふりかえりの要約テンプレートの例*

## Docs のコンテキストメニュー

- リンクをコピー
- コピーして連動

- ロック
- 前面に移動
- 一つ前へ
- 一つ後ろへ
- 背面に移動
- レイヤーに移動
- コピー
- 画像としてコピー
- 複製
- CSV にエクスポート（エクセル）
- フレームを作成
- テンプレートとして保存
- 削除

## ドキュメントを全画面モードで作業する

作業中のドキュメントに集中したいときは、ドキュメントをフルスクリーンモードで開くことができます。ボード上の他のコンテンツに気を取られることがありません。作業中のドキュメントの上にある**フルスクリーン アイコン**をクリックして、このモードにアクセスします。

![docs-full-screen-icon.png](../../../../../../docs/using-miro/tools/images/25640369213074_docs-full-screen-icon.png)

*ドキュメントのフルスクリーン アイコン*

全画面モードでは、テキスト書式設定のためのコンテキストメニューが含まれています。ボードの背景を削除し、潜在的な気を散らす要素を取り除きます。

全画面モードを終了するには、画面の上部にある**キャンバスに移動**ボタンをクリックします。

![docs-focus-mode.png](../../../../../../docs/using-miro/tools/images/25640385661202_docs-focus-mode.png)

### 文字数制限

Miro Docs は最大 80,000 文字まで含めることができます。スペースが必要な場合は、同じボード上で追加のDocを作成し、コンテンツを適宜分割できます。これにより、すべての情報を一か所にまとめて整理しつつ、制限内に収まることができます。

## 文書へのコンテンツのコピー

ボードから次のコンテンツを Doc にドラッグ & ドロップできます。

- 付箋
- テキストボックス
- 画像
- iFrame
- プレビュー
- 表
- タイムライン
- ダイアグラム

:::note
Docs は付箋とテキストボックスを箇条書きリストに変換します。
:::

![Miro Doc にデータウィジェットをドラッグ＆ドロップします。](../../../../../../docs/using-miro/tools/images/25640385663122_docs-tables-widget.gif)

*データウィジェットをドキュメントにドラッグ＆ドロップ*

### ドキュメント内のダイアグラム

Diagram をドキュメントにドラッグ＆ドロップすると、Miro は[同期されたコピー](../working-on-the-board/11-synced-copies.md)を作成します。これにより、ボード上のオリジナルダイアグラムに加えた変更は、ドキュメント内のコピーに反映されますが、その逆はありません。コピーコンテンツを変更するには、元のダイアグラムのコンテンツを修正してください。

これにより、ドキュメントが最新のビジュアル情報に合わせて常に最新の状態を保つことができます。

### Docs の他のコンテンツ動作

フォーカスモードを持つウィジェット（例：テーブル）の場合、ウィジェットがドキュメント内にあるときでも没入モードにアクセスできます。寸法は合わせて拡大縮小され、ドキュメント内をスクロールします。

ドキュメント外にコンテンツをドラッグして、ボード上に戻すこともできます。

## Docs でキーボードのショートカットを利用する

キーボードショートカットを使用して、テキストに見出しやリストタイプを適用できます（これらのショートカットは段落タイプのサブメニューで表示できます）：

変換**cmd + opt + \{number\} を使用**

- 0 -> 段落
- 1 -> 見出し 1
- 2 → 見出し 2
- 3 -> 見出し 3
- 4 -> 箇条書きリスト
- 番号付きリスト
- 6 -> チェックリスト

キーボードショートカットを使ってブロック選択も可能です。Escape キーを一度押してブロック選択モードに入り、その後：

- **shift + up/down** -> 選択範囲を拡張する
- **cmd + opt + 上/下** -> 選択範囲を上下に移動

Docsの他の機能は、ホットキーを通じてアクセス可能です。

|  |  |
| --- | --- |
| **⌘** + **enter** | テキストの選択メニューにフォーカス |
| **⌘** + **Shift** + **X** | 取り消し線を切り替える |
| **⌘** + **shift** + **U** | リンクを追加 |
| **⌘** + **E** | インラインコードを切り替える |
| **⌘** + **,** | チェックリストのアイテムにチェックを入れる / 外す |
| **⌘** + **/** | ブロックのコンテキストメニューを開く |
| **⌘** + **D** | 選択したブロックを複製 |
| **⌘** + **I** | ブロックへのリンクをコピー |

Miro アプリ内で画面の右下にある**ヘルプとリソース**アイコンをクリックすることで、キーボード ショートカットの全リストにアクセスできます。

![docs-keyboard-shortcuts.png](../../../../../../docs/using-miro/tools/images/25640369222418_docs-keyboard-shortcuts.png)

*ヘルプとリソースアイコンを介したキーボードショートカット*

## 文書で Miro AI を使用

Miro AI を使って文書を編集すると、編集プロセスがスピードアップし、より簡潔で読みやすい文書が作成できます。

Miro AI を使ってドキュメント内のハイライトされたテキストを修正できます。

![](../../../../../../docs/using-miro/tools/images/25640369225490_image.png)

*Miro AI を使って Miro Doc のハイライトされたテキストを修正します。*

Miro AI を起動させるために、Miro ドキュメント内でテキストをハイライトします。コンテキストメニューの右端にある**Miro AI**を改善するを選択します。ドロップダウンメニューから**カスタムプロンプト**または利用可能なプロンプトのいずれかを選択します。

## Miro 文書でのコラボレーション

Miro 文書では、他のユーザーとリアルタイムでコラボレーションできます。キャンバス上の他のコンテンツと同様に、カーソル表示が有効になっており、他のユーザーがDocのどこで作業しているかを確認することができます。

インラインコメントも可能で、他のユーザーを @メンションすることができます（アプリ内とメールの両方で通知されます）。コメントのスレッドとリアクションも両方有効です。

### Miro 文書でのユーザーチップ

ユーザーチップを使用すると、ドキュメント内のユーザーに関する詳細を提供できます。例えば、重要なチームメンバーや関係者のために @user チップを追加します。

Miro 文書で「@」を入力してユーザーチップを追加します。ユーザー名を入力して結果を絞り込むか、開いたドロップダウンメニューからユーザーを選択します。

![Miro ドキュメントのどこにでもユーザーチップを追加できます。](../../../../../../docs/using-miro/tools/images/25640369225490_image.png)

*ユーザーチップを Miro 文書の任意の場所に追加します。*

@ユーザーチップにカーソルを合わせると、そのユーザーに関する情報が表示されます。

![ユーザー チップにはユーザーに関する情報が含まれています。](../../../../../../docs/using-miro/tools/images/25640369225490_image.png)

*ユーザーチップにはユーザーに関する情報が含まれています。*

ユーザーチップはコメント内のメンションとは別に機能し、例えば、ユーザーチップは特定のユーザーに通知を送信しません。

## 文書のコピー、共有、エクスポート

文書はボード間でコピーできますが、その後の変更については同期されません。つまり、あるボード上のDocに行われた編集は、コピーされた他のボードには反映されません。

リンクで他のユーザーと文書を共有することができます。

ドキュメントはコンテキスト メニューで**その他のアイコン** (![icon-main.svg](../../../../../../docs/using-miro/tools/images/25640369228946_icon-main.svg)) から PDF 形式でエクスポートできます。
