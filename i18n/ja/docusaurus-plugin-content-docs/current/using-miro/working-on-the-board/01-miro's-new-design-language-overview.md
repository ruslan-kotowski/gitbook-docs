新しいMiroデザイン言語は、ボードの外観に重要なアップデートを提供し、アクセシビリティとユーザーエクスペリエンスを向上させます。

## 主な機能

刷新されたMiroのデザイン言語には、次のような主な特徴があります：

- より多くの色合いを持つ、拡張されたグローバルカラーパレット。
- モダンなデザインの付箋。
- アイコンデザインを更新しました。
- インタラクティブなステッカーと最新のリアクション。

## グローバルカラーピッカー

グローバルカラーパレットが大幅に刷新され、各色のシェードが拡大されたことで、ボード上でより親しみやすい配色が可能になりました。カラーパレットはよりモダンでフレッシュ。グローバルカラーピッカーの新しいデフォルトカラーは、既存のユーザーコンテンツに影響を与えたり、変更したりすることはありません。

**詳細：**[色を](14-colors.md)見る

*グローバルカラーピッカーの更新*

### タイムラインのカラーピッカーの拡張

タイムラインでは、グローバルカラーピッカーから任意の色を使用できるようになりました。

![タイムラインカラーピッカー.png](../../../../../../docs/using-miro/working-on-the-board/images/25286463421970_timeline-color-picker.png)

*タイムラインアイテムのカラーピッカーの拡張*

### カードのカラーピッカーの拡張

カードはグローバルカラーピッカーに基づき、21色からお選びいただけます。以前は14色しかありませんでした。

![カードカラーピッカー.png](../../../../../../docs/using-miro/working-on-the-board/images/25286463422226_cards-color-picker.png)

*カードのカラーピッカーの拡張*

## 付箋のアップデート

Miroボードの背景での視認性を確保するため、色彩を鮮やかにし、コントラストを高めました。さらに、スタイリングもよりナチュラルでモダンなデザインに一新。付箋の余白を合わせやすくするため、影を調整しました。

![付箋.png](../../../../../../docs/using-miro/working-on-the-board/images/25286463422482_sticky-notes.png)

*付箋の更新*

## ボードのサムネイル

あなたのボードのコンテンツを表現し、ユーザーが一目で関連するボードを見つけやすくするために、全く新しいデフォルトのボードサムネイルアイコンのセットから選択できます。

![ボードサムネイル.png](../../../../../../docs/using-miro/working-on-the-board/images/25286441892114_board-thumbnails.png)

*ボードのサムネイルオプションの更新*

サムネイルの背景にファイル形式が反映されるようになりました。たとえば、ドキュメントの背景は青、表の背景は緑になり、コンテンツの種類をすばやく識別しやすくなりました。

![ボード-サムネイル-ダッシュボード.png](../../../../../../docs/using-miro/working-on-the-board/images/25307411470354_board-thumbnails-dashboard.png)

*背景色はフォーマットに基づきます*

## インタラクティブなステッカーとリアクション

インタラクティブステッカーの追加により、ユーザーがボード上のコンテンツに参加する新しい方法が生まれます。一度ステッカーを貼ると、ユーザーはそれをクリックしてステッカーを+1することができ、ステッカーの外観だけでなくカウンターも変更できます。

![インタラクティブステッカー.png](../../../../../../docs/using-miro/working-on-the-board/images/25286441892370_interactive-stickers.png)

アニメーション スタンプ

リアクションのデザインも改善されました。

![リアクション.png](../../../../../../docs/using-miro/working-on-the-board/images/25286441892498_reactions.png)

*新しいリアクションデザイン*

## フォント

アプリ内テキストの本文がOpen SansからNoto Sansに変更され、より幅広い言語に対応できるようになりました。

![フォント.png](../../../../../../docs/using-miro/working-on-the-board/images/25308533047314_font.png)

*本文のフォントがNoto Sansに変更され、言語サポートが向上しました。*
