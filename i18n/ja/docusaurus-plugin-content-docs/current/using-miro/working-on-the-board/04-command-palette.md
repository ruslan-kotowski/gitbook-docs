コマンドパレットを使用すると、Miro のツールやアプリをすばやく検索して起動できます。コマンドパレットでは、最近使用したボードを検索することもできます。

コマンドパレットは、[編集アクセス権](../sharing-boards/01-board-access-rights.md)を持つユーザーだけが標準ボードモードで利用できます。プレゼンテーションモードではコマンドパレットを起動できません。

## コマンドパレットの使用方法

1. ボードツールバーで**縦の三点リーダー**(![icon-main.svg](../../../../../../docs/using-miro/working-on-the-board/images/24005170925074_icon-main.svg))アイコンを選択します。
   メインメニューが開きます。
2. **編集** > **コマンド** を選択します。または、**Cmd** + **K** のキーボードショートカットを使用します。
   コマンドパレットが開きます。
3. 検索フィールドにアプリやツール名を入力し始めるか、リストをスクロールします。
4. アプリやツールをクリックして起動させます。
