## 複数のオブジェクトを選択

[選択ツール](21-work-smarter-not-harder.md)がアクティブになっていることを確認し（または**V**を押してアクティブ化）、必要なオブジェクト上を選択フィールドでドラッグして囲みます。これにより、選択で触れたすべてのオブジェクトが選択されます（除く：[USM](../advanced-tools/07-user-story-mapping.md)、[カンバン](../advanced-tools/02-columns-formerly-kanban.md)、[マインドマップ](../advanced-tools/03-mind-map.md)、[テーブル](../advanced-tools/05-grid.md) - これらのオブジェクトを選択するには、選択フィールドで 90%以上を囲む必要があります）。[モバイル](../../getting-started/apps-for-devices/08-mobile-app.md)や[タブレットアプリ](../../getting-started/apps-for-devices/11-tablet-app.md)を使用している場合、またはタッチスクリーンを使用している場合は、**長押し**してドラッグしてください。

また、オブジェクトの絞り込み機能を使用して、特定の種類のオブジェクトを移動させるために選択することもできます。クリックしながらドラッグしてすべてのオブジェクトを選択し、コンテキストメニューの**フィルター**をクリックして、オブジェクトの種類を選択します。選択フィールドが調整され、フィルタリングしたオブジェクトのみを移動できるようになります。

![object-select.png](../../../../../../docs/using-miro/working-on-the-board/images/25827368311698_object-select.png)
*オブジェクトの種類でフィルター*

90% 以上が囲まれたオブジェクトのみを精密に選択するには、*長押ししてドラッグします*。これは、選択したいオブジェクトの背景に別の図形がある場合に便利です。

キーボードをご使用の場合は、**Shift** または **Ctrl***（Windows の場合）/***Command***（Mac の場合）*を押しながら 1 つずつ特定のオブジェクトをクリックして選択することもできます。

### 精密選択

精密選択では、オブジェクトの表面を90%以上囲んだときにのみオブジェクトを選択できます。

精密選択を使用するには、選択ツールを使用していることを確認してください。その後、マウスボタンを長押ししてください。これで、精密選択を使用して選択ツールをドラッグできます。

## 投げ縄ツールを使って複数のオブジェクトを選択する

他に、投げ縄ツールを使ってオブジェクトを選択することもできます。オブジェクトを選択に含めるには、選択エリアにその90%以上が含まれる必要があります。

:::tip
**Ctrl+A** / **Cmd+A** の[ショートカット](06-shortcuts-and-hotkeys.md)を使用して、ボード上のすべての要素を選択します。
:::

## 選択したオブジェクトを変更

選択したオブジェクトは、一括で移動やサイズ変更ができます。オブジェクトを[整列](08-structuring-board-content.md)したり、[グループ化](08-structuring-board-content.md)したり、[ロック](17-locking-content-on-the-board.md)したり、下記のようにフィルターをかけたりすることができます。また、メニュー上の他のオプションを使用することもできます。

:::note
選択したいすべてのオブジェクトが[ロック](17-locking-content-on-the-board.md)されていないことを確認します。そうでない場合は、オブジェクトをクリックして**ロック解除**を選択し、まずロックを解除する必要があります。
:::

:::warning
[テーブル](../advanced-tools/05-grid.md)内のオブジェクトや異なる[フレーム](../essential-tools/07-frames.md)にあるオブジェクトをグループ化することはできません。
:::

:::warning
[ビジター](../sharing-boards/08-collaboration-with-visitors.md)は、ボード上のオブジェクトをロック / ロック解除できません。オブジェクトに[保護ロック](17-locking-content-on-the-board.md)が有効になっている場合、ボード所有者/[共同所有者](../sharing-boards/06-co-owners-of-boards-and-spaces.md)のみがそれを解除できます。
:::

:::tip
オブジェクトを一緒に移動させるもう一つの方法は、オブジェクトを1つのフレームに配置し、フレームを移動させることです。[Miro のフレームについて詳しく学ぶ](../essential-tools/07-frames.md)。
:::

スマート複製

ショートカットキーの**Ctrl + D** を使用すれば、作業効率が上がり、素早く簡単にボード上のオブジェクトを複製することができます。

:::note
**Alt + 矢印キー**を使用すれば、垂直または水平方向にオブジェクトを複製することもできます。
:::

## オブジェクトのロック

オブジェクトをロックして、誤って移動、編集、削除しないようにします。他のユーザーが自分のコンテンツを変更できないようにするには、保護ロックを使用します。詳しくは次の記事をご覧ください：[ボード上のコンテンツのロック](17-locking-content-on-the-board.md)。

## オブジェクトを整列

このオプションを有効にすると、オブジェクトを動かす際に揃えられるようガイドが表示され、ボードのオブジェクトをすっきりとバランスよく配置できます。

メインメニューで、この機能を有効化 / 無効化することができます。**三点リーダー**（**...**）をクリック > **環境設定** > **オブジェクトを整列**。

![align-objects.png](../../../../../../docs/using-miro/working-on-the-board/images/25827368311954_align-objects.png)
*ボードの設定でオブジェクトを整列を有効にするオプション*

## オブジェクトの配置

ボード上でオブジェクトを配置します。この機能は、特に重複するコンテンツが多い場合に、ボードやダイアグラムを正確にレイアウトするサポートをします。

1. オブジェクトを選択します。
2. コンテキストメニューから、三点リーダー（**...**）をクリックして、**詳細**メニューを開きます。
3. 以下のオプションのいずれかを選択してください：

- **前面に移動：**あるオブジェクトをその他すべてのオブジェクトの前面に移動します。
- **背面に移動：**あるオブジェクトをその他すべてのオブジェクトの背面に移動します。
- **一つ前へ：**あるオブジェクトを他のオブジェクトの一つ前に移動します。
- **一つ後ろへ：**あるオブジェクトを他のオブジェクトの一つ後ろに移動します。

:::note
この機能はフレームでは使用できません。フレームは常にボード上のオブジェクトの背面に配置されます。
:::

## オブジェクトの回転

ボードでオブジェクトを簡単に回転して、コンテンツを調整します。オブジェクトの左下にある回転アイコンを見つけ、クリックしてドラッグすることで位置を変更できます。

## コンテンツのクリア

複数のウィジェット（付箋、図形、カードなど）のコンテンツを同時に消去できます。この機能により、選択したウィジェットからすべてのテキストやタグ、絵文字、作成者、担当者、期日を削除し、書式（色、サイズなど）を保持したまま元の状態に戻すことができます。

コンテンツをクリアするには：

1. 入力を消去したいウィジェットを選択します。
2. 右クリックでコンテキストメニューを開きます。
3. メニューから「コンテンツを消去」を選択します。
4. または、ショートカット Cmd + Backspace（Mac）または Ctrl + Backspace（Windows）を使用します。

コンテンツの消去は、他のウィジェット（例：テキスト、テーブル ウィジェット）や、Jira または Azure カードでは機能しません。ユーザーが複数の付箋、図形、カードを選択した場合、Jira/Azureカードを除くすべてのウィジェットのコンテンツが削除されます。

## よくある質問

1. *選択フィールドをドラッグできません。どうすればよいですか？* - [選択ツール](21-work-smarter-not-harder.md)に切り替えていることを確認してください。
2. *選択したオブジェクトをグループにまとめることができません。なぜでしょう？* - [テーブル](../advanced-tools/05-grid.md)内のオブジェクトや、異なる[フレーム内にあるオブジェクトをグループ化することはできませんので、ご了承ください。](../essential-tools/07-frames.md)
3. *グループ内の個々のオブジェクトを選択し、移動させることができますか？* - はい、オブジェクトをダブルクリックし、ドラッグしてください。こちらの[ページ](08-structuring-board-content.md)で確認してください。
