Miro ボードでのオブジェクト操作の可能性はほぼ無限大です。ここでは、よりシンプルかつ短期間で目標を達成するヒントをご紹介します。

## ボードのナビゲーション

### ミニマップの使用

ミニマップは、ボードの右下隅にあるパーセンテージアイコンをクリックし、次に**ミニマップを表示**する（または**M** [ホットキーを押して](06-shortcuts-and-hotkeys.md)ミニマップを開く/閉じる）ことで利用できます。

![ナビゲーション・ツールバー・ミニマップ.png](https://help.miro.com/hc/article_attachments/21999315785618)

*ミニマップの表示*

### 選択モードと移動モードの切り替え

[ホットキー](06-shortcuts-and-hotkeys.md)を使用して、オブジェクトの選択またはボード上の移動を選択できます。ホットキーの **V** と **H** を使えば、**選択 / 編集**モード（カーソルツール）と**ハンド** / **移動**モードを切り替えることができます。選択モードはツールバーからも開始できます。

:::tip
ボードのナビゲーションについての詳細は[こちらの記事](05-using-miro-with-a-mouse-trackpad-or-touchscreen.md)をご覧ください。
:::

![働き方をスマートに_選択ツール.png](https://help.miro.com/hc/article_attachments/21017429598098)*ツールバーの選択ツール*

## オブジェクトの操作

### スマート複製

ショートカットキーの **Ctrl + D** を使用すれば、作業効率が上がり、素早く簡単にボード上のオブジェクトを複製することができます。

![スマートに複製.gif](../../../../../../docs/using-miro/working-on-the-board/images/21016688231442_smart%20duplicating.gif)*スマートに複製*

> ️✏️ **Alt + 矢印キー**を使用すれば、垂直または水平方向にオブジェクトを複製することもできます。

### オブジェクトのサイズを利用して正確なダイアグラムを作成

より素早く簡単に専門的な作図ができます。[オブジェクトのサイズ](../formats/diagramming/01-miro-for-mapping-diagramming.md)を使用して、ボード全体で同じサイズのオブジェクトを正確に作成できます。

![Miro でオブジェクトのサイズを利用.gif](https://help.miro.com/hc/article_attachments/21017416545938)

### オブジェクトのロック

オブジェクトを誤って移動、編集、削除しないようにロックできます。他のユーザーが自分のコンテンツを変更できないようにするには、保護ロックを使用します。詳しくは次の記事をご覧ください：[ボード上のコンテンツのロック](17-locking-content-on-the-board.md)

![コンテンツのロック.jpg](https://help.miro.com/hc/article_attachments/21017429580562)*ロック機能*

### オブジェクトを整列

このオプションを有効にすると、オブジェクトを動かす際に揃えられるようガイドが表示され、ボードのオブジェクトをすっきりとバランスよく配置できます。

![オブジェクトの整列.gif](https://help.miro.com/hc/article_attachments/21017416559250)*ボード上のオブジェクトの整列*

メインメニューで、この機能を有効化 / 無効化することができます。**三点** リーダー（**...**） >**環境設定**>**オブジェクトを整列を**クリックします。

![align-objects.png](https://help.miro.com/hc/article_attachments/21858039122322)
*ボード設定でオブジェクトの整列を有効にするオプション*

### オブジェクトの配置

ボード上でオブジェクトを配置します。この機能は、特に重複するコンテンツが多い場合に、ボードやダイアグラムを正確にレイアウトするサポートをします。

1. オブジェクトを選択します。
2. コンテキストメニューから、三点リーダー（**...**）をクリックして、**詳細**メニューを開きます。
3. 以下のオプションのいずれかを選択してください：

- **前面に移動：**あるオブジェクトをその他すべてのオブジェクトの前面に移動します。
- **背面に移動：**あるオブジェクトをその他すべてのオブジェクトの背面に移動します。
- **一つ前へ：**あるオブジェクトを他のオブジェクトの一つ前に移動します。
- **一つ後ろへ：**あるオブジェクトを他のオブジェクトの一つ後ろに移動します。

:::note
この機能はフレームでは使用できません。フレームは常にボード上のオブジェクトの背面に配置されます。
:::

オブジェクトの選択と絞り込み

特定種類のオブジェクトを一括で変更する場合、絞り込み機能が非常に便利です。複数のアイテムを選択し、コンテキストメニューの [**絞り込み**] をクリックし、オブジェクトの種類を選択します。オブジェクト選択機能の詳細については[こちらの記事](10-working-with-objects.md)をご覧ください。

![Miro の絞り込み機能.gif](https://help.miro.com/hc/article_attachments/21017429581586)*複数オブジェクトの選択、絞り込み、修正*

オブジェクトの回転

ボードでオブジェクトを簡単に回転して、コンテンツを調整します。オブジェクトを選択し、左下に表示される回転アイコンをクリック＆ドラッグして、以下に示すようにオブジェクトを回転させます。

![オブジェクトの回転.gif](https://help.miro.com/hc/article_attachments/21017429584914)*オブジェクトの回転*

### クリアリングコンテンツ

複数のウィジェット（付箋、図形、カードなど）の内容を同時に消去できます。この機能により、選択したウィジェットからすべてのテキスト、タグ、絵文字、作成者、担当者、期日を削除し、スタイル（色、サイズなど）を保持したまま元の状態に戻すことができます。

コンテンツをクリアするには

1. 消去したいウィジェットを選択します。
2. 右クリックでコンテキストメニューを開きます。
3. メニューから「コンテンツを消去」を選択します。
4. または、ショートカット Cmd + Backspace (Mac) または Ctrl + Backspace (Windows) を使用します。

クリア コンテンツは他のウィジェット (テキスト、テーブル ウィジェットなど) では機能せず、Jira や Azure カードでも機能しません。ユーザーが複数の付箋、図形、カードを選択した場合、Jira/Azure カード以外のすべてのウィジェットでコンテンツが削除されます。

## ドキュメントの操作

### 複数ページのドキュメントを分割する

> **利用可能なバージョン：**ブラウザー、[デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)

ボード上に、ドキュメント、PDF、PowerPoint ファイルから好きなページや全ページを展開する、ページに直接コメントを残すなどして、チームとコラボレーションすることができます。

PDF または Powerpoint ファイルを任意のページ数で分割する手順を以下に示します。

1. ボードにファイルをアップロードします。
2. ファイルをクリックし、コンテキストメニューで [****ページを抽出****] を選択します。
   > ✏️ このオプションは、[カーソル（選択）モード](#mini)でのみ利用できます。オプションがメニューに表示されない場合は、**V** を押すか、ツールバーでカーソルを選択し、オブジェクトを再度クリックします。

   ![ページの抽出.jpg](https://help.miro.com/hc/article_attachments/21017416542866)*PDF のコンテキストメニューでページを抽出するオプション*
3. ファイルを分割する方法（すべて、または特定のページのみ）を選択し、[**抽出する**]をクリックします。
   ![ページの抽出](../../../../../../docs/using-miro/working-on-the-board/images/21016720055698_extract%20pages.gif)*ページの抽出*

展開したページは、元のファイルの右下に表示されます。元のファイルが必要がない場合は、削除できます。すべての展開したページがボードに残ります。

ページのピン留め

ボードでドキュメントの特定のページをピン留めするには、ドキュメントのコンテキストメニューで対象のページに移動して、[**ピン留め**] を選択し、[**ここを開始ページに設定**] をクリックします。ボード開くたびに、このページは最初のページとして設定されます。

> **✏️**️ [**ここを開始ページに設定**] オプションは、[カーソル（選択）モード](#pan)でのみ利用できます。オプションがグレーアウトされている場合、**V** を押すか、ツールバーでカーソルを選択し、オブジェクトを再度クリックします。

![ページのピン留め.jpg](https://help.miro.com/hc/article_attachments/21017429586834)*ページのピン留め*

## 画像の操作

### 画像を置き換える

ボード上のすべての画像は、キャンバスのその他のオブジェクトに影響を与えずに置き換えることができます。

1. 画像をクリックするとコンテキストメニューが開きます。
2. **画像の置き換える**アイコンをクリックし、次のオプションのいずれかを選択します：

- **ライブラリーから置き換える：**[画像とアイコン](../essential-tools/08-images-and-icons.md)のアプリが開き、新しい画像を選択できます。
- **ボードから置き換える：**ボード上に既にある別の画像を選択するよう求められます。
- **デバイスからアップロード：**デバイスにある画像をアップロードして置き換えます。
- **URL からアップロード：**ダイアログボックスに画像の URL を入力して、オンライン上の画像に置き換えます。

![画像の置き換え.png](https://help.miro.com/hc/article_attachments/21017416560402)

### 画像をトリミングする

Miro にはツールがあるので、サードパーティー製ソフトウェアを使用して画像をトリミングする必要はありません。画像を選択するか、コンテキストメニューで [**トリミング**] を選択します。これにより、トリミングモードが有効になり、**囲み部分**の編集が可能になります。境界線をトリミングして周囲のボードのコンテンツと位置合わせし、画像をすっきりとレイアウトします。ボード上の他のコンテンツとの位置バランスを損なわずに、トリミングする画像の位置やサイズを更新することができます。完了したら、ボードの他の場所をクリックすると確定します。

![画像のトリミング.gif](https://help.miro.com/hc/article_attachments/21017416553618)*画像のトリミング*

画像は、**あらゆる形（円形や正方形など）にトリミング**することができます。画像を選択し、コンテキストメニューの [**マスクとトリミング**] アイコンをクリックし、ドロップダウンから形を選択します。

![画像をいろいろな形にトリミング.gif](https://help.miro.com/hc/article_attachments/21017416552338)*画像を円形に切り抜く*

画像は、**一括でさまざまな形にトリミング**することもできます。クリックしながらドラッグして画像を選択し、コンテキスト メニューの [**マスクとトリミング**] アイコンをクリックし、ドロップダウンから形を選択します。

![](https://help.miro.com/hc/article_attachments/21017416554258)*複数の画像を一括で円形にトリミング*

:::tip
トリミングした画像はいつでも元のサイズに戻すことができます。ダブルクリックして、トリミングの選択範囲を元のサイズに拡大するだけです。
:::

### 画像の枠線

ボードにアップロード、または貼り付けた画像やスクリーンショットを強調するための枠線を追加します。

1. 画像をクリックします
2. コンテキストメニューの枠線アイコンをクリックします
3. 枠線の色や線の太さを選択します

![画像の枠線.gif](https://help.miro.com/hc/article_attachments/21017429590034)
*スクリーンショット画像への枠線の追加*

### 複数の画像のサイズを一括変更する

ボード上の複数の画像の高さや幅を一括変更します。次に、[自動レイアウト](08-structuring-board-content.md)を使用して素早く整列させます。

**複数の画像のサイズを一括変更する方法**

1. カーソルをドラッグして、サイズを変更する画像をすべて選択します
2. コンテキストメニューの [画像のサイズ変更] アイコンをクリックします。このアイコンを表示させるには、複数の画像を選択する必要があります。
3. **[高さを一致させる]** または **[幅を一致させる]**
4. 右上に表示される灰色の**自動レイアウト**アイコンをクリックします

*![画サイズ像の一括変更.gif](https://help.miro.com/hc/article_attachments/21017429594258)**画像の高さまたは幅を一括変更*

### GIF の追加

Miro ボードに GIF を追加し、楽しいアニメーション画像を使ってアイデアをわかりやすく表現しましょう。GIF は、ボードに追加された時とユーザーが GIF にカーソルを合わせた時に、8 秒間あるいは 1 回再生されます。GIF は、ボードを操作中のユーザーにのみ個別に再生されます。全ユーザーを対象にリアルタイムで再生はされません。

[[動きを減らす](../../getting-started/accessibility-in-miro/06-reduce-motion.md)] をオンにして、GIF の自動再生機能を無効にします。

:::tip
プレゼンテーションや [Miro Talktrack](../facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md) の GIF は、画面に表示されている間は自動的に再生され、無限にループします。
:::

![GIF 再生.gif](https://help.miro.com/hc/article_attachments/21017429599378)
*マウスオーバーで自動再生する GIF*

## よくある質問

1. *ボード上のオブジェクトを整列させることはできますか？*
   - はい、できます。詳しくは[こちらのページ](08-structuring-board-content.md)をご覧ください。
2. *[テキスト](../essential-tools/16-text.md)を回転させることはできますか？*
   - はい、矢印アイコンをドラッグしてテキストボックスを回転させることができます。
3. *PDF ファイルをトリミングできますか？*
   - いいえ、現時点ではできません。
