[種別の切り替え] **機能**を使用すると、ダイアグラムのオブジェクトを瞬時に変更することができます。付箋、テキストボックス/span>[、](../essential-tools/14-sticky-notes.md)カード、[図形](../essential-tools/16-text.md)など、1 つのオブジェクトから別のオブジェクトに瞬時に変換します。種別の切り替えは、基本図形とダイアグラム作成図形パックで利用できます。

**オブジェクトを変換するには：**

1. [選択**ツール**に切り替えます](05-using-miro-with-a-mouse-trackpad-or-touchscreen.md)
2. 変換したいオブジェクトをクリックします
3. オブジェクトメニューの **[種別の切り替え]** アイコンをクリックします
4. 次に、ドロップダウンから新しいオブジェクトを選択します

![オブジェクトの変換_greybg.gif](../../../../../../docs/using-miro/working-on-the-board/images/21017695579922_object_transformation_greybg.gif)*付箋を図形とテキストボックスに変換*

オブジェクトのテキストおよび色は同じままです。付箋をテキストや図形に変換すると、絵文字およびタグは破棄されますのでご注意ください。図形またはテキストボックスを付箋に変換すると、付箋の色は限られているため、色を似たものに調整します。

また、ボードでオブジェクトを回転し、拡大縮小することもできます。[オブジェクトを選択](05-using-miro-with-a-mouse-trackpad-or-touchscreen.md)し（選択ツールが有効になっているはずです）、特別なアイコンをドラッグして回転させます。一部のオブジェクト（カンバン、マインドマップ、テーブル）は回転できないことに注意してください。

サイズを変更するには、白いドットをドラッグします。図形またはカードの幅 / 長さを変更するには、オブジェクトの側面のいずれかをドラッグします。

![回転と拡大縮小_ミロ_グレーバーグ.gif](../../../../../../docs/using-miro/working-on-the-board/images/21017695580434_rotate_and_scale_in_Miro_greybg.gif)*図形の回転と拡大縮小*

オブジェクト操作の詳細については[こちらの記事](21-work-smarter-not-harder.md)をご覧ください。
