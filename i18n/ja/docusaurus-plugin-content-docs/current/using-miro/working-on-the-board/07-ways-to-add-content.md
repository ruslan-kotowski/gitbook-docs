ファイル、メディア、アイコンをインポートし、すべてのビジュアル情報を 1 つのボードにマッピングしましょう！

### ボードに追加可能なもの

- 文書
- スプレッドシート
- 画像
- プレゼンテーション
- プレビュー付きのウェブページとリンク
- [アイコン](../essential-tools/08-images-and-icons.md)
- また、[動画やその他のメディアファイルを埋め込み](../../integrations-apps/integrations-basics/03-embed-integrations-on-a-miro-board.md)することもできます

### コンテンツを素早く追加する方法

- ファイルをデスクトップからボードにドラッグ & ドロップするだけです。[サポートされているファイルフォーマットの一覧](../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md)もご覧ください。
- クリップボードからテキストや画像を追加する（**Ctrl + C** と **Ctrl + V** *（Windows）*、**Cmd + C** と **Cmd + V** *（Mac）* を使用）
- [デバイスからアップロード](../import-and-export/import/05-uploading-files-to-boards.md)（xls、doc、ppt、svg、jpg、その他のフォーマットがアップロードできます。[この記事](../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md)で完全なリストをご覧ください。）
- URL からアップロードする
- [Google ドライブ](../../integrations-apps/google/05-google-drive.md)、[Dropbox](../../integrations-apps/more-integrations/06-dropbox.md)、[Box](../../integrations-apps/more-integrations/05-box-legacy.md)、[Adobe XD](https://help.miro.com/hc/articles/360016621780)、または [OneDrive](../../integrations-apps/microsoft/06-onedrive.md) からドキュメント、スプレッドシート、または画像をアップロード

  > ✏️ 上記のオプションにアクセスするには、コラボレーションツールバーの**アップロード**ボタンをクリックしてください。
- [Fontawesome](../essential-tools/08-images-and-icons.md)、[Unsplash](../essential-tools/08-images-and-icons.md)、および[Google Image](../../integrations-apps/google/06-google-images.md)からアイコンや画像を使用する
- iFrame コードを使用して、動画、音声、その他のメディアを埋め込む。[詳細を学ぶ](../../integrations-apps/integrations-basics/03-embed-integrations-on-a-miro-board.md)
  ![embed_iframe_in_Miro.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21020253797266_embed%20iframe%20in%20Miro.jpg)
  *iFrame コードを使用して Miro ボードにメディアを埋め込み*
- スプレッドシートからコンテンツを追加（**Ctrl+C**と**Ctrl+V** *for Windows*、**Cmd+C**と**Cmd+V** *for Mac*を使用）して、Miroの[テーブル](../advanced-tools/05-grid.md) または[付箋](../essential-tools/14-sticky-notes.md)として使用することができます
  ![cells_as_sticky_notes_in_Miro.gif](../../../../../../docs/using-miro/working-on-the-board/images/21020264789266_cells%20as%20sticky%20notes%20in%20Miro.gif)
  *スプレッドシートの内容を付箋にして貼り付ける*

## よくある質問

**ボードに画像をインポートするにはどうすればいいですか？**

デバイスから**アップロード**メニュー経由で[アップロード](../import-and-export/import/05-uploading-files-to-boards.md)するか、クリップボードから貼り付ける（*Windows*では、**Ctrl + C**、**Ctrl + V**、*Mac*では、**Cmd + C**、**Cmd + V**を使用）か、デバイスからボードまでドラッグするだけです。

**ボード上のコンテンツを整理する最適な方法を教えてください。**

詳しくは次の記事をご覧ください：[ボードコンテンツの構造化](08-structuring-board-content.md)。

**自分のデバイスからボードに動画をアップロードできますか？**

いいえ、しかし[動画を埋め込む](../../integrations-apps/integrations-basics/03-embed-integrations-on-a-miro-board.md)ことができます。動画を動画共有プラットフォーム（*YouTube*、*Vimeo* など）にアップロードし、ボードに動画リンクを貼り付けるだけです。**Ctrl + C** と **Ctrl + V** *for Windows*、**Cmd + C** と **Cmd + V** *for Mac.*

**ボード上の画像を変更する方法を教えてください。**

アップロードした画像は、移動、[置き換え](21-work-smarter-not-harder.md)、サイズ変更、[トリミング](21-work-smarter-not-harder.md)および[回転](21-work-smarter-not-harder.md)が可能です。

**ボードにワイヤーフレームや図形を加えることができますか？**

はい、詳細は次をご覧ください：[プロトタイプライブラリー](../miroverse/prototyping/02-prototyping-library.md)、[図形](../essential-tools/11-shapes.md)。他のMiroツール一覧は[こちらのページ](../tools)で見つけることができます。

**スプレッドシートから Miro ボードにデータをインポートできますか？**

はい、スプレッドシートは閲覧専用ファイルとしてインポートするか、テーブルまたは表を作成することができます。詳細はこちら: [テーブル](../formats/14-tables.md) または [表](../advanced-tools/05-grid.md)。

**ボードにコンテンツをアップロードできません。どうすればよいですか？**

コンテンツのサイズと形式がサポートされていることを確認してください - [こちらのガイド](../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md)をチェックしてください。
