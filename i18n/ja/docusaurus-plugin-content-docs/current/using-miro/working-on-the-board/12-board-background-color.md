Miro ボードの背景色を変更して、閲覧を快適にしたり、作業に個性を加えたりすることができます。11 の背景色から選択できます。

ボードの背景色を変更することで、視覚的な魅力を高めることができます。グレーや黒などのような暗い色を使用することでも、目の疲れを軽減するのに役立つ可能性があります。

:::note
なお、ボードの背景色を変更すると、そのボードを利用するすべてのユーザーの背景色も更新されることになります。暗い背景色は目の疲れを軽減するのに役立ちますが、完全なダークモード体験を再現するものではありません。
:::

## ボードの背景色を変更する

1. ボードバーで縦の三点リーダーを選択します。
   **メイン**メニューが開きます。
2. **ボード**を選択 > **背景色**
3. 色を選択します。
   背景色が自動的に更新されます。

## 機能の制限

- ボードをエクスポートする際、背景色は含まれません。
- ボードの背景色は、あなたの[ボードの履歴](../managing-boards/11-board-history-activity.md)には反映されません。

## よくある質問

ボードの背景色を変更するオプションが表示されません。なぜですか？

ボードの編集権限がない可能性があります。ボードの所有者に連絡して、ボードの編集権限を依頼するか、所有者に背景色の変更をお願いしてください。
