Miro ボード上でオブジェクトをロックすると、誤って移動、編集、削除されるのを防ぐことができます。ボードに[メール](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)で招待された編集者や、[プロジェクト](../sharing-boards/16-projects.md)または[チーム](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)のメンバーであるためにアクセス権がある編集者は、オブジェクトをロックおよびアンロックすることができます。

追加の保護のために、有料プランまたはEducationプランのボード所有者と共同所有者は保護ロックを使用できます。この機能により、アイテムをロックしたボード所有者または共同所有者のみがロックを解除でき、他の編集者が誤って重要なコンテンツを移動または削除することを防ぎます。

:::warning
ビジターはボード上のオブジェクトをロックまたはロック解除することはできません。[テーブル](../advanced-tools/05-grid.md)、[カンバンボード](../advanced-tools/02-columns-formerly-kanban.md)、[マインドマップ](../advanced-tools/03-mind-map.md)、[ユーザーストーリーマップ](../advanced-tools/07-user-story-mapping.md)、および[スイムレーン](../formats/diagramming/01-miro-for-mapping-diagramming.md)内のコンテンツもロックすることはできません。
:::

## オブジェクトをロック/ロック解除する

ボード上の単一または複数のオブジェクトをロックおよびアンロックすることができます。

オブジェクトを固定するには、オブジェクトを選択し、コンテキストメニューで**ロック**アイコンをクリックします。あるいは、ショートカット **Ctrl + Shift + L** （*Windows の場合*）または **Cmd + Shift + L** （*Mac の場合*）を使用します。モバイルでは、オブジェクトをタップした後、縦の三点リーダー（![icon-main.svg](../../../../../../docs/using-miro/working-on-the-board/images/24005170925074_icon-main.svg)）メニューからロックオプションにアクセスできます。

![オブジェクトのコンテキストメニューにあるロックオプション。](../../../../../../docs/using-miro/working-on-the-board/images/21016057891346_lock%20in%20Miro.jpg)
*コンテクストメニューの「ロック」オプション*

複数のオブジェクトをロックするには、該当するオブジェクトを選択し、コンテキストメニューの**ロック**アイコンをクリックするか、キーボードショートカットを使用します。

オブジェクトの固定を外すには、コンテキストメニューの**ロック**アイコンを長押ししてください。同じショートカットを再度使用するか、オブジェクトを右クリックして**ロック解除**を選択することもできます。

:::note
オブジェクトに 保護ロック が有効になっている場合、それを解除できるのは、そのロックをかけたボードの所有者または共同所有者のみです。
:::

![ロックアイコンを長押ししてオブジェクトのロックを解除する。](../../../../../../docs/using-miro/working-on-the-board/images/21016057894418_long%20press%20to%20unlock.jpg)
*アイコンを長押ししてオブジェクトをアンロック*

### すべてのオブジェクトをロック解除

ボード上のすべてのオブジェクトの固定を一度に解除するには、ボードの空白部分を右クリックし、**すべてアンロック**を選択します。また、ロックされたオブジェクトのコンテキストメニューで三点リーダーをクリックして、同じオプションを選択することもできます。

:::note
保護ロックされたアイテムは、ボードの所有者またはロックを有効にした共同所有者でない限り、ロック解除されません。
:::

![ボード上のすべてのオブジェクトのロックを解除するオプション。](../../../../../../docs/using-miro/working-on-the-board/images/21016044523410_unlock%20all.jpg)
*ボード上のすべての要素のロック解除*

## 保護ロックの使用

> **設定者:** ボード所有者、[ボード共同所有者](../sharing-boards/06-co-owners-of-boards-and-spaces.md)

他のコラボレーターが重要なボードのコンテンツを解除できないようにするには、保護ロックを使用します。

保護ロックを有効にするには、まず通常の手順でアイテムをロックします。次に、コンテキストメニューに表示される盾アイコンをクリックします。シールドが有効化されると、他のボード上の人々はオブジェクトのロックを解除することができなくなります。保護ロックは、自分でアイテムを解除することでいつでも無効化できます。

![ロックされたオブジェクトで保護ロック機能を有効にしているユーザー。](../../../../../../docs/using-miro/working-on-the-board/images/21016044524434_protected%20lock.gif)
*オブジェクトの保護ロックを有効にする*

### コラボレーターが見るもの

保護ロックされたオブジェクトは、ボード上の他の協力者に対して異なって表示されます。他のユーザーには、オブジェクトのロックを解除するオプションが表示されず、ボード所有者によって保護されていることを示すメッセージが表示されます。

![ボード所有者によってオブジェクトが保護されていることを示すウィジェット](../../../../../../docs/using-miro/working-on-the-board/images/21016057899794_protected%20locked%20for%20users.jpg)
*保護されたオブジェクトが他の共同作業者にどのように表示されるか*
