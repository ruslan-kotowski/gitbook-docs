ショートカットとホットキーメニューにアクセスするには、Miro ボードの右下にあるキャンバス制御バーのクエスチョン マーク（**？**）を選択してください。**ヘルプとリソース**メニューが開きます。次に**キーボード ショートカット**を選択します。

:::tip
F1 を押してショートカットリストを開くこともできます。
:::

### Windows と Mac のショートカットとホットキー

次の表は、Mac と Windows のすべてのショートカットとホットキーを示しています。

:::note
テキストのショートカットは、ボード上のテキストを選択または編集している場合に機能します。
:::
