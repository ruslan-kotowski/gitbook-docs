Miro は、ボードのユーザー インターフェイスをより包括的で直感的なものに強化しています。

<iframe allowfullscreen="" frameborder="0" height="315" src="//fast.wistia.com/embed/iframe/uqbg7sog7l" width="560"></iframe>

この記事では、コラボレーションと作成ツール、ボードオプションと制御、役立つリソースへのアクセスのための更新されたエントリーポイントについて説明します。

## AI で作成 & 作成バー

作成バーの上部で **AI で作成** を選択して、Miro AI 機能にアクセスします。

![Create with AI button above the Creation bar.](../../../../../../docs/using-miro/working-on-the-board/images/21064617157010_create-with-ai.png)*作成バーの上にあるAIで作成*

作成バーを使用すると、基本的な作成および編集ツールにアクセスできます。

デフォルトでは、以下のツールが作成バーに固定されています。

- **選択する**ボード上のオブジェクトを選択する
- **テンプレート**テンプレートモーダルを開きます
- **付箋**付箋メニューを開く
- **テキスト**テキストモードを有効にします
- **図形と線**図形と線のメニューを開く
- **フリーハンドで描画します**フリーハンド描画メニューを開く
- **フレーム**フレームメニューを開く
- **スタンプ、絵文字、GIF**スタンプ、絵文字、GIFのライブラリを開きます
- **コメント**コメントモードを有効にする
- ツール、メディア、インテグレーション
  **ツール**と**マーケットプレイス**のライブラリを開きます

:::note
図形と線が統合されたツールにまとまりました。
:::

## キャンバスコントロールバー

キャンバスの右下隅には、キャンバスコントロールバーに次のオプションが含まれています:

- **フレームとレイヤー**ボード上の各フレームやレイヤーの設定を整理、提示、指定することができます
- **ズームとナビゲーション**ズームを調整し、ボード上のコンテンツのマップを固定することができます。
- **ヘルプとリソース**メニューが開き、フィードバックフォームへのアクセス、Miro ヘルプセンター、および追加の学習リソースが含まれています。

:::note
マップをピン留めまたはピン解除するには、画面に適合させるか、全画面モードに入ります。サブメニューにアクセスするにはズームパーセンテージをクリックする必要があります。
:::

:::note
アクティビティーは、フレームとレイヤーの下に移動しました。
:::

## コラボレーションバー

ボードの右上隅に共同作業バーが表示され、エンゲージメントを促進し推進するためのオプションとツールが含まれています。

### 進行ツール

進行ツールメニューには次のツールが含まれています：

- **リアクション**
  共同作業者が感情を表現できる絵文字がセットで提供されます。
  > ✏️ リアクション メニューには、**手を挙げる**が含まれなくなり、ボードの所有者と共同所有者は、**リアクション** メニューからすべてのユーザーに対するリアクションの有効化または無効化ができなくなりました。
- **タイマー**時間制限を設定してアクティビティーを行います
- **投票**コラボレーターが意思決定に投票できるようにし、結果を集約します
- **非公開モード**付箋の内容を無効化するまで非表示にします。ボード上でコラボレーターを匿名化することもできます。
- **メモ****ビジュアルノート**を書き込み、キャンバスにピン留めします。

:::note
次の機能は、**ツール、メディア、およびインテグレーション**メニューで利用可能です。見積もり、依存関係、ビデオ通話、チャット、グループフレーム。

Talktrack は**プレゼント**メニューで利用可能です。
:::

### アクティビティー

ボードコメント、Talktrack の録音、チーム通知（以前はお知らせ）を組み合わせた統合エクスペリエンスを提供しています。今、1 か所ですべてを把握できます。

ベルアイコンを選択すると、コメントや Talktrack の録画を含むボードのアクティビティを確認できます。現在のチームの任意のボードから通知を閲覧するには、**チーム**タブに切り替えてください。

### ユーザーバー

**ユーザーリスト**バーを使用すると、ボード上でコラボレーターとやり取りできます。

コラボレーターがボードにいる場合は、**ユーザーリスト**バーをクリックしてドロップダウンを展開し、次のオプションのいずれかを選択します。

- フォローするコラボレーターを選択するか、自分の画面に呼び出す
- コラボレーターを検索する
- 全員を自分のボードに呼ぶ
- カーソルの有効化または無効化

### プロフィール メニュー

アバターを選択してプロフィールメニューを開くと、名前と役割が表示されます。**プロフィール設定**にもアクセスできます。

:::note
**全員を呼ぶ**と**ユーザーを呼ぶ**を使用するには、**ユーザーリスト**の協力者リストを使用してください。
:::

### 発表

**発表**メニューを使用すると、ボードのフレームをスライドとして提示できます。Talktrack の録画を作成することもできます。

:::note
**ボード全体のプレゼンテーション**および**アクティビティーのプレゼンテーション**が削除されました。
:::

### 共有

**共有**メニューでは、ボードへのリンクをコピーしたり、コラボレーターをボードに招待したり、ボードを埋め込んだり、テンプレートとしてボードを保存または公開したりすることができます。

**共有設定**にもアクセスできます。

## ボードバー

ボードバーを使用すると、ワンクリックでボード名を変更でき、更新されたボードのサムネイルから選択することができます。適切な権限がある場合、ボードの機密分類を変更することもできます。

ボードバーには**メインメニュー**が含まれており、縦の三点リーダーを選択することでアクセスできます。

![menu.png](../../../../../../docs/using-miro/working-on-the-board/images/28438519349650_menu.png) *ボードバーからメインメニューにアクセスできます*

:::note
エクスポート、ボード検索、およびボードのスター付けが**メインメニュー**に含まれるようになりました。
:::

以下のリストは、**メインメニュー**の全オプションを示しています。

- **ボード**
  - コピーを作成
  - エクスポート、テンプレートとして保存、または埋め込み
  - 別スペースに移動
  - ボードにスターを付ける
  - 削除
  - 背景色を変更する
  - 新たに招待されたメンバーの開始画面を指定します
  - ボード履歴を表示
  - ボードの詳細を見る
- **編集**
  - 元に戻す / やり直す
  - **コマンドパレット**にアクセス
  - ボード コンテンツを探す
- **閲覧**
  - グリッドのオプションを指定し、表を無効化することを含む
  - 全画面モードに入る
  - コラボレーターのカーソル、コメント、スクロールバー、オブジェクトの寸法、およびやり直しと元に戻すためのコントロールを表示または非表示にします。
- **環境設定**
  - マウスまたはトラックパッドの操作を有効にする
  - ボード上のオブジェクトの整列を指定する
  - **全スレッドをフォロー**を有効にする
  - プロフィール設定にアクセスします。
- **アクセシビリティー**
  - **精密選択**を有効化
  - **動きを減らす**を有効にする
  - アクセシビリティーの確認
