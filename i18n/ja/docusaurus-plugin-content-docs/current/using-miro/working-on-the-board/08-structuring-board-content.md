無限大のホワイトボード キャンバスで作業していると、無限のコンテンツで埋め尽くしたい誘惑に駆られるかもしれません。ただし、ボードコンテンツを配置する際には、戦略的に考えることが重要です。ボードコンテンツを構成し、ボード上のオブジェクト間の関係を示す方法をいくつか説明します。

## 自動レイアウト

自動レイアウトを使って、Miro のボード上のウィジェットを素早く整列・配置する：

1. 整列したい[ウィジェットを選択](10-working-with-objects.md)します。
2. 右上のグレーのアイコンをクリックし、横にドラッグします。

:::warning
現在この機能は [表のセル](../advanced-tools/05-grid.md)では機能していません。
:::

![smart_alignment.gif](../../../../../../docs/using-miro/working-on-the-board/images/21020264748562_smart%20alignment.gif)
*複数のウィジェットをスマートに配置*

## グループ化

[複数のオブジェクトを選択](10-working-with-objects.md)して、**グループオブジェクト**のボタンをクリックする（または、Windows の場合 **Ctrl + G***、*Mac の場合 **Cmd + G** *を使用する*）と、グループ化することができます。その後は、一つのオブジェクトとして動作します（ただし、グループ内の各オブジェクトを編集することはできます）。

:::warning
[マインドマップノード](../advanced-tools/03-mind-map.md)、[表](../advanced-tools/05-grid.md)内のオブジェクト、[カンバン](../advanced-tools/02-columns-formerly-kanban.md)、[USM](../advanced-tools/07-user-story-mapping.md)、各種[フレーム](../essential-tools/07-frames.md)内にあるオブジェクトをグループ化することはできません。
:::

![group_in_Miro.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21020264748946_group%20in%20Miro.jpg)
*オブジェクト メニューのグループ オプション*

図形をグループ化し、それから[カスタムテンプレート](../../getting-started/start-here/your-first-board/04-templates.md)を作成することもできます。そのためには、コンテキストメニューの三点リーダーを選択し、**テンプレートとして保存**を選択します。

:::tip
グループ内で 1 つのオブジェクトを移動するには、ダブルクリックしてドラッグします。
:::

![move_an_object_within_a_group.gif](../../../../../../docs/using-miro/working-on-the-board/images/21020253751826_move%20an%20object%20within%20a%20group.gif)
*グループ内でのオブジェクトの移動*

## 整列

複数のオブジェクトを整列するには、[オブジェクトを選択](10-working-with-objects.md)し、コンテキストメニューの  **オブジェクトを整列** ボタンをクリックします。 選択したオブジェクトは、横方向、縦方向、左側、右側に相互に関連して整列させることができます。どんなオブジェクト（付箋、写真、フレームなど）でも整列できます。

:::warning
グループ化されたオブジェクトまたは [表](../advanced-tools/05-grid.md)内のオブジェクトは整列できません。
:::

![align_in_Miro.gif](../../../../../../docs/using-miro/working-on-the-board/images/21020253752978_align%20in%20Miro.gif)
*オブジェクトの整列*

:::tip
️️ オブジェクトの整理方法（フィルター、背面へ移動、最前面へ移動など）に関するヒントの詳細は、「[働き方をスマートに](21-work-smarter-not-harder.md)」の記事をご覧ください。
:::

## フレーミング

ボード上のすべてのオブジェクトは、[フレーム](../essential-tools/07-frames.md)機能を使用して、グループに分けることができます。そのためには、作成ツールバーの**フレーム**ツールを選択し、ボード上でカーソルをドラッグして、フレームのサイズを設定します。

既存のオブジェクトからフレームを作成することもできます。カーソルをドラッグして[オブジェクトを選択](10-working-with-objects.md)し、その後コンテキストメニューの三点リーダーをクリックして**フレームを作成**を選択するだけです。

![create_a_frame.gif](../../../../../../docs/using-miro/working-on-the-board/images/21020264750098_create%20a%20frame.gif)
*フレームの作成*

フレームを使用することで、コンテンツを構成して全体像の管理が容易になります。コラボレーターは、[フレームへのリンク](16-internal-and-external-linking.md)を共有することで、必要なコンテンツを見つけやすくなります。

コンテンツの構成は[ボードをエクスポート](../import-and-export/export/03-how-to-export-your-board.md)したい場合にも役立ちます。各フレームを PDF ドキュメントの個別の画像やページ、[プレゼンテーション](https://help.miro.com/hc/articles/360017731073)のスライドと見なすことができます。

> ️💡 [フレームに関する記事](../essential-tools/07-frames.md)をご覧になり、フレームの移動や並び替え、サイズ変更、複製、非表示、エクスポート、フレームの色の変更方法についてご確認ください。

## リンク

[接続ライン](../essential-tools/05-connection-lines.md)を使用すると、ボード上のオブジェクトをリンクすることができます。これは、ダイアグラムを構築する場合や、マインドマップを作成する際に役立ちます。

接続ラインを作成するには、次の 2 つの方法があります。

- [ツールバー](../../getting-started/start-here/your-first-board/05-toolbars.md)の矢印を選択し、線を引く
- オブジェクトを選択し、青色の点の 1 つをクリックまたはドラッグする
  - 点をクリックすると、線やオブジェクトが自動的に作成されます
  - 点をドラッグして、オブジェクトを別のオブジェクトに*手動*で接続します。
    ![quick_diagram_creation_2.gif](images/21020264769810_quick diagram creation 2.gif)
    *Miro のワンクリックでの作成と接続*

## よくある質問

1. *ボードのサイズを変更する方法を教えてください。*
   - Miro のボードは新しいコンテンツが追加される限り、無限に拡張されます。ただし、ボードに大量のウィジェットがある場合、操作や読み込みがスムーズにいかなくなることがあります。 ボードのパフォーマンスを向上させる方法に関しては、[こちら](../tools/troubleshooting/04-board-performance-and-loading-issues.md)をご覧ください。
2. *複数のオブジェクトを選択する方法を教えてください。*
   - 手順は[こちら](10-working-with-objects.md)をご覧ください。
3. *ボードのさまざまな部分につながるリンクを作成し、操作がしやすいよう一か所にまとめる必要があります。どうすればいいですか？*
   [- フレーム](../essential-tools/07-frames.md)を作成してボードのコンテンツを体系化し、[フレームへのリンク](16-internal-and-external-linking.md)をコピーしてボード上の特定の場所や[ビジュアルノート](../essential-tools/17-visual-notes.md)に貼り付けます。[フレームパネル](../essential-tools/07-frames.md)ではフレーム間を移動することもできます。
