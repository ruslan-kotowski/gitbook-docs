Miro ボードのコンテンツをコピーして、Miro の外部と簡単に共有することができます。 テキストまたは画像としてコピーしたコンテンツはクリップボードに保存され、他のプラットフォームやサービスに貼り付けることができます。

> **実行可能なソフトウェア：**デスクトップ ブラウザー、[デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)、[タブレットアプリ](../../getting-started/apps-for-devices/11-tablet-app.md)

### ボードのコンテンツをコピーできるユーザー

ボードのコンテンツをコピーするオプションは、Miro のプロフィールを持つユーザーと編集権限を持つビジターが利用できます。 Miro アカウントを持っておらず、ボードの閲覧またはコメントのみ可能な場合、コンテンツをコピーできるようにするには/span>、[まず Miro に登録](../../getting-started/start-here/02-how-to-register-with-miro.md)する必要があります。

さらに、ボードの所有者 / 共同所有者は、ボードコンテンツのコピーを許可する必要があります。 ボードの所有者がボードとコンテンツのコピーおよびエクスポートを許可または制限する方法をご覧ください/span>[。](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)

### テキストとしてコピーする

付箋[、](../essential-tools/14-sticky-notes.md)図形[、](../essential-tools/11-shapes.md)テキスト[、](../essential-tools/16-text.md)ライン[、](../essential-tools/05-connection-lines.md)フレーム[タイトル、](../essential-tools/07-frames.md)表[、](../advanced-tools/05-grid.md)カード[にテキストをコピーできます](../essential-tools/02-cards.md)。

1. [1 つあるいは複数のオブジェクトを選択する](10-working-with-objects.md)
2. Ctrl + C**（***Windows の場合*）または Cmd + C**（***Mac の場合*）を押します。テキストはクリップボードにコピーされます。
3. テキストを別のボードまたはプラットフォームに貼り付けるには、**Ctrl + V**（*Windows の場合*）または **Cmd + V**（*Mac* の場合）を押します。

[テキストオブジェクトを選択](10-working-with-objects.md)してコピーすると、テキストは改行で区切って貼り付けられます。

![コピー_テキストとして.gif](../../../../../../docs/using-miro/working-on-the-board/images/21019735460626_copy%20as%20text.gif)*Miroオブジェクトをテキストとしてコピー*

### 画像としてコピする

ボードに 1 つまたは複数のオブジェクトを画像としてコピーする方法

1. [オブジェクトを選択します](10-working-with-objects.md)
2. コンテキストメニューの三点リーダーをクリックして、**[画像としてコピーする]** を選択します。あるいは、Ctrl + Shift + C（Windows の場合）または Cmd + Shift + C（Mac の場合）/span>**を押します**。画像はクリップボードにコピーされます
3. 画像を別のボードまたはプラットフォームに貼り付けるには、**Ctrl + V***（*Windows の場合**）または** Cmd + V（*Mac の場合*）を押します。画像は PNG 形式で作成されます。

### よくある質問

*Miro からコンテンツをコピー / 貼り付けができない場合、どうすればよいですか？*

1. ボードの所有者に連絡し、ボード上で自分と同等の役割を持つユーザーに、ボードコンテンツのコピーを許可するよう依頼します
2.2. Miro プロフィールがなく、ボードの閲覧またはコメントのみ可能である場合は、Miro に登録してボードコンテンツをコピーできるようにします/span>
3. 3. ボードの所有者がボードコンテンツのコピーを許可したにもかかわらず、問題が解決しない場合は、ボードを別のブラウザーで開き、コンテンツをコピーできるかどうかを確認してください。
