オブジェクトを外部ウェブサイトやボード上の別のオブジェクトにリンクすることで、ボードのコンテンツを充実させることができます。

「**オブジェクトをリンク**」オプションを使用すると、以下のことが可能です：

- インタラクティブなプロトタイプを作成
- ボード上のナビゲーションを簡素化
- 参考資料や便利なソースへのリンクを追加
- [付箋](../essential-tools/14-sticky-notes.md)や[カード](../essential-tools/02-cards.md)をタスクトラッカーリンクにリンクします。

## オブジェクトをリンク

1. リンク先のオブジェクトを選択し、次にコンテキストメニューの**三点リーダー**（**...**）アイコンをクリックします
2. コンテキストメニューから選択します:**リンクをコピー**
3. リンク元のオブジェクトを選択し**、**コンテキストメニューの**三点リーダー**（**...**）アイコンをクリックします。
4. 選択してください **リンク先** または **Option +** **Cmd + K** (*Mac の場合*) または **Alt +** **Cmd + K** (*Windows の場合*)
5. URL を挿入するか、ボード上でリンクさせたい別のオブジェクトをクリックします。

:::tip
コマンドパレットを使用すれば素早くオブジェクトにリンクを追加できます。オブジェクトをクリックし、**Cmd + K** をタップすると、**オブジェクトにリンクを追加する**オプションがメニューの最初の項目に表示されます。テキストフィールドにリンクを貼り付け、**Enter** をタップするだけです。
:::

![linking_in_Miro.gif](../../../../../../docs/using-miro/working-on-the-board/images/21016057152146_linking%20in%20Miro.gif)
*付箋を Miro のブログにリンクする*

ボード上のオブジェクトは、*1* つのウェブサイトまたは Miro のオブジェクトにのみリンクできることにご注意ください。外部ウェブサイト、他の Miro ボード、ボード上の特定のオブジェクトへのリンクを作成することができます。
リンク先の URL に移動するには、リンクアイコンをクリックするだけです。

![Link_to_Google_Calendar.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016043778834_Link%20to%20Google%20Calendar.jpg)
*リンクアイコンには、リンク先サイトのロゴが表示されます*

リンクを削除または編集するには:

1. コンテキストメニューの三点リーダーをクリックします。
2. **編集リンク**を選択します。![edit_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057155218_edit%20link.jpg)*リンクを編集するオプション*
3. リンクを変更するか、ポップアップで**リンクを削除**をクリックします。![change_or_delete_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057156242_change%20or%20delete%20link.jpg)*リンクを削除するオプション*

## ボード上のオブジェクトへのリンク

ボード上の任意のオブジェクト（[フレーム](../essential-tools/07-frames.md)、画像、[図形](../essential-tools/11-shapes.md)など）への直接リンクを取得できます。このリンクをコラボレーターと共有すれば、ボード上の正確な場所へ注目してもらうことができます。

1. リンク先のオブジェクトをクリックして、コンテキストメニューを表示します。
2. **三点リーダー**（**…**）アイコンをクリックします。
3. **リンクをコピー**を選択します。![copy_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057158162_copy%20link.jpg)*フレームへのリンクをコピー*

リンク先オブジェクトが削除されると、リンクをフォローするユーザーに「*申し訳ありませんが、このボードからリンク先のアイテムが削除されました*。」というメッセージが表示されます。アクティビティ リストから[削除されたコンテンツを復元](18-restoring-board-content.md)することができます。

## ボードにリンクを貼り付ける

ショートカットを使用して、ボードにリンクを貼り付けることができます。**Ctrl + V** (*Windows の場合*) または **Cmd + V** (*Mac の場合*)。リンクにプレビューが表示されます。

*![link_to_help_center.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057159186_link%20to%20help%20center.jpg)
ボードの Miro ヘルプセンターへのリンク*

プレビューなしでリンクをボードに貼り付けるには、 [テキストツール](../essential-tools/16-text.md) を使用し、テキストボックスにリンクを貼り付けてください。

## テキストへのリンク

テキストを含むオブジェクトを操作する場合は、コンテキストメニューの**リンク**アイコンをクリックして、テキストにリンクを挿入します。

![insert_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016043786642_insert%20link.jpg)
 *リンクを挿入するオプション*

テキストを選択して、**Ctrl + V**（*Windows の場合*）/**Cmd + V**（*Mac の場合*）を使用してリンクを貼り付けることもできます。

![insert_link.gif](../../../../../../docs/using-miro/working-on-the-board/images/21016057161490_insert%20link.gif)
*テキスト行にリンクを挿入*

:::note
もし**リンクを挿入**オプションでボード上の 2 つのオブジェクトをリンクしてその後ボードを複製すると、コピーしたボードのリンクは元のボードにつながります。ただし、リンク先オプションを使用してボード上の 2 つのオブジェクトをリンクし、ボードを複製すると、コピーのリンクは内部に留まります（同じボード上のオブジェクトに移動します）。
:::

## よくある質問

ボードを別の Miro のボードにリンクできますか？

はい、リンクをボードへコピーします（またはボード上の特定のオブジェクトへ）。そのリンクを元のボードへ貼り付け（またはオブジェクトにリンクを追加したり、[ノート](../essential-tools/17-visual-notes.md)に追加したりします）。[Miro ボードを埋め込む](../import-and-export/export/02-embed-a-miro-board.md)こともできます。

ボードのリンクをコピーするには、どうすればよいですか？

ボードの[共有ダイアログ](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)を開き、**ボードのリンクをコピー**をクリックします。ブラウザーのアドレスバーからリンクをコピーすることもできます。[デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)でボードを開いている場合は、**[ファイル] > [ボードのリンクをコピー]** をクリックします。

ボードで特定のエリアへのリンクを作成するには、どうすればよいですか？

そのエリアをカバーする[フレーム](../essential-tools/07-frames.md)を作成し、フレームへのリンクをコピーします。[ボードにアクセス権を持つユーザー](../sharing-boards/05-who-has-access-to-my-board.md)は、ボードの他のエリアを移動し、表示できることにもご注意ください。

ボード上のすべてのリンクを一括削除することはできますか？

数回クリックするだけで、キャンバスに貼り付けられたすべてのリンクを削除できます。[すべてのオブジェクトを選択](10-working-with-objects.md)し、コンテキストメニューの**フィルター**を選び、**プレビュー**を選択して、選択したリンクオブジェクトを削除します。
![filter_perviews.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057163410_filter%20perviews.jpg)
*選択したオブジェクトでプレビューを絞り込む*

自分のコンピューターのローカルファイルのリンクを作成することはできますか？

いいえ。セキュリティー上の理由により、ファイルをクラウドベースのサービスにアップロードし、そこからリンクする必要があります。

Miro は、メールアドレスのハイパーリンクを mailto: リンクとして認識しますか？

現時点では、対応しておりません。
