Miro の高度なテキスト検索を使えば、ボード上で情報を迅速に発見し、整理することができます。

## 「検索」機能にアクセスする

**検索**機能には2通りのアクセス方法があります。

- ボードメニューの三点リーダー（**...**）アイコンをクリックし、「**編集**」サブメニューに移動します。
- キーボードショートカットを使用してください。**Cmd + F**（Mac の場合）または**Ctrl + F**（Windows の場合）[^1]。

## ボード上のオブジェクトを検索

オブジェクトを検索するには：

1. 上記のいずれかの方法を使用して、検索機能を開始します。
2. 検索フィールドに検索用語を入力します。
3. 結果のリストが表示され、検索用語を含む Miro のウィジェットが含まれます。
4. 検索されたオブジェクトはボード上でハイライト表示され、他のコンテンツはグレー表示されます。結果は検索フィールドの下にも一覧表示されます。
5. 検索結果のいずれかをクリックすると、そのオブジェクトにボード上で直接移動します。

## 検索結果のフィルタリング

検索結果をフィルターで絞り込んで、検索を最適化できます。例えば、特定のタグが付いている付箋を検索したり、テキストノートの中だけで検索することができます。フィルターを使用するには：

1. 検索フィールドの横にあるフィルターオプションをクリックします。
2. **すべてのコンテンツ**をドロップダウンメニューから別のカテゴリーに変更します。

## よくある質問

**ボードに「検索と置き換え」のオプションはありますか？**

いいえ、現時点ではそのようなオプションはありません。

**テキストボックスや付箋内の特定の単語を見つけるにはどうすればよいですか？**

ブラウザーで次の回避策を利用できます：テキストボックスや付箋をクリックしてテキスト編集モードにし、組み込みのブラウザページ検索を使用します（例えば、Chrome では **Ctrl + F** (Windows の場合) / **Cmd + F** (Mac の場合) を押します）。
