パレットにはデフォルトで 16 色が用意されています。これを[描画](../essential-tools/10-pen.md)、[図形](../essential-tools/11-shapes.md)、[線と矢印](../essential-tools/05-connection-lines.md)、[フレーム](../essential-tools/07-frames.md)、[表](../advanced-tools/05-grid.md)、[カード](../essential-tools/02-cards.md)、[テキスト](../essential-tools/16-text.md)に適用することができます。このパレットは、こうしたツール全体で同じものなので、見栄えの良いコンテンツを簡単に作成できます。

:::warning
[付箋の](../essential-tools/14-sticky-notes.md)カラーパレットは16色に制限されています。
:::

![グローバルカラーピッカー-new.png](../../../../../../docs/using-miro/working-on-the-board/images/25493642458386_global-color-picker-new.png)

*デフォルトのカラーパレット*

### 新しい色の追加

:::tip
[ブランド](../../administration/get-started-as-a-miro-admin/04-brand-center.md)センターに色をアップロードすることで、チームコンテンツ作成を簡素化し、独自の[ブランドスタイルを](../../administration/get-started-as-a-miro-admin/04-brand-center.md)ボードに適用できます。
:::

新しい色を追加するには

1. オブジェクトを選択します。
2. カラーパレットを開きます。
3. アイコンを**クリックして**ください。
   カラースペクトルが開いて表示されます。
4. 追加したい色を選択します。そのためには、以下の3つの方法があります。

![カスタムカラーピッカー-new.png](../../../../../../docs/using-miro/working-on-the-board/images/25493668317586_custom-color-picker-new.png)

*新しい色を追加するためのカラースペクトルツール*

新しい色を追加すると、すべてのツールのカラーパレットに追加され、その変更はプロフィールに適用されます。

[付箋](../essential-tools/14-sticky-notes.md)のカラーパレットはカスタマイズできません。

パレットに新しい色を追加するには、次の 3 つの方法があります。

カラースペクトルから：

1. スライダーを動かすか、スペクトル上の場所をクリックしてください。
2. 次にキャンバスをクリックして色を保存します。

Hexコードを入力します：

1. カラースペクトルの下部にあるフィールドに16進数のカラーコードを入力します。
2. **Enter** をクリックします。

カラーピッカーを使用します：

1. スポイトアイコンをクリックします。
2. ボードのどこかをクリックまたはドラッグして色を選びます。

カスタマイズされたパレットは、プロフィール内のすべてのボードに適用されます。

[図形](../essential-tools/11-shapes.md)/[付箋](../essential-tools/14-sticky-notes.md)/[カード](../essential-tools/02-cards.md)の色を変更し、ボードに新しい図形/付箋/カードを追加する場合、追加されたオブジェクトの色は、ボードを再読み込みするまで、以前使用していた色と同じになります。

### 色の削除

未使用の色をパレットから消去したい場合は、パレットの外にクリック＆ドラッグするだけです。デフォルトカラーは削除できませんのでご注意ください。
