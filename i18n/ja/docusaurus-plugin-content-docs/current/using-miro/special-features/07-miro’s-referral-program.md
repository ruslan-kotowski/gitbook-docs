Miro の紹介プログラムは、既存のユーザーが新しい企業を Miro に紹介することで報酬を得られるようにします。この収益分配プログラムは、1件の成功した紹介につき最大500ドルの支払いを提供します。

## 紹介プログラムの仕組み

**あなたのために（紹介者）:**

- 紹介コードを使用して登録する新しい会社ごとに、紹介先アカウントの月額支払いの10%（最大1件あたり500ドル）を受け取れます。

**紹介されたアカウント（招待された人）の場合:**

- 招待された方は、11 か月間、サブスクリプションの料金が 10% 割引されます。
- 招待された方は、割引を受けるために、有料プランにサインアップする際にプロモーションコードを適用する必要があります。

## 紹介プログラムの使用

1. ダッシュボードの右上にある **紹介プログラム** アイコンをクリックします。
2. **招待リンクをコピー**をクリックしてください。
   ![image.png](../../../../../../docs/using-miro/special-features/images/23383406736146_image.png)
   *招待リンクをコピーして、潜在的な紹介先に送信します*
3. リンクを他社の連絡先にメール、ソーシャルメディア、またはメッセージアプリを通じて送信してください。

### 紹介に対して報酬を受け取る

紹介による支払いを受け取る前に、支払いの詳細を追加する必要があります。

1. ダッシュボードの右上にある**レファラル プログラム**アイコンをクリックします。
2. **報酬**タブをクリックします。
3. **お支払情報を追加する**をクリックします。
4. ドロップダウンから支払い対象の国/地域を選択します。
5. 表示されるオプションから希望の支払方法を選択してください。
6. 支払情報を入力してください。
7. Cello の利用規約に同意します。
8. **支払い方法を保存**をクリックします。
   ![image (1).png](images/26846479309074_image%20(1).png)
   *紹介による支払いを有効化するために支払い情報を設定してください*

:::note
**Rewards** タブの **支払い情報を更新** ボタンをクリックすると、いつでもお支払い方法を更新できます。
:::

### 紹介者の追跡

**Referral Program** ダッシュボードで紹介を確認できます。

1. ダッシュボードの右上にある **紹介プログラム** アイコンをクリックします。
2. **報酬**タブをクリックします。
3. ご褒美の合計のサマリーが上部に表示され、アクティブな紹介とその支払い額のリストも見ることができます。
   ![image (2).png](images/26846462875666_image%20(2).png)
   *紹介プログラムの収益は「報酬」タブに表示されます*

## プログラム ポリシー

- **参加資格:**
  - 招待者は、仕事用のメールで新会社として登録を行う必要があります。
  - 招待者はプロモーションコードを期限内に適用する必要があります。
  - 自社内（同一のメールドメイン）への同僚紹介は対象外です。
- **プロモーションコードの詳細:**
  - プロモーションコードは発行から 60 日後に期限切れとなります。
  - プロモーションコードは、有料プランのチェックアウト時に適用する必要があります。
  - 紹介手数料を合計 500 ドルまで貯めましょう。
  - 招待者の割引は登録後 11 か月間有効です。
- **プログラム変更:**
  - いつでも紹介プログラムを変更または終了する権利を留保します。
  - 変更はメールで通知されるか、ウェブサイトに掲載されます。
- **悪用防止:**
  - 不正行為や誤用があるとプログラムへの参加資格が剥奪されます。
- **地域での利用可能性:**
  - 以下の国では紹介プログラムを利用できます。オーストリア、ベルギー、ブラジル、カナダ、チェコ、デンマーク、フィンランド、フランス、ドイツ、ギリシャ、ハンガリー、アイルランド、イタリア、インド、オランダ、ノルウェー、ポーランド、フィリピン、ポルトガル、ルーマニア、スペイン、スウェーデン、スイス、イギリス、アメリカ合衆国。

## よくある質問

**紹介できる会社の数に制限はありますか？**

紹介できる会社の数に制限はありません。ただし、1件の紹介につき獲得できる最大割引額は 500 ドルです。

**連絡先がプロモコードの適用を忘れたらどうなりますか？**

プロモーションコードは、招待者の割引と紹介者への支払いに不可欠です。サインアップ時またはコード送信後の最初の60日以内に直接適用するように彼らにリマインドしてください。

**プロモーションコードはどのくらいの期間有効ですか？**

プロモーションコードは発行から 60 日後に期限切れになります。この期間内にご連絡先を使用するようご確認ください。

**同じ会社の人を招待できますか？**

いいえ、紹介は異なる会社からである必要があります。招待者は、あなたのものとは異なるドメインの仕事用メールを使用する必要があります。

**獲得した割引をどのように追跡できますか？**

Miro のダッシュボードでアカウントの紹介プログラムアイコンをクリックして、成功した紹介と累積支払いを確認してください。

**紹介した企業が私の紹介リンクおよびプロモーションコードを使用したときに通知されますか？**

紹介プログラムのダッシュボード内で、紹介された会社が正常に登録し、プロモコードを適用すると通知が届きます。

**プロモコードの有効期限が使用前に切れるとどうなりますか？**

プロモーションコードの有効期限が切れた場合、招待者は割引を受け取ることができません。参加するには、新しい紹介リンクとプロモコードが必要です。

**紹介した会社がサブスクリプションをキャンセルすると、報酬は変わりますか？**

アカウントがサブスクリプションをキャンセルすると、この紹介に対する毎月の受け取りが停止されます。

**紹介割引に関する問題が発生した場合は、どうすればよいですか？**

サポートが必要な場合は、カスタマーサポートチームまでご連絡ください。

**同一の会社アカウント内で複数のコンタクトを紹介できますか？**

紹介は新規アカウントに限ります。同じアカウント内の複数の連絡先は、1 つの紹介としてカウントされます。

**紹介特典がまだ受け取れていない場合はどうすればよいですか？**

報酬を受け取るべきだとお考えの場合で適用されていない場合は、カスタマーサポートチームにご連絡ください。最初の支払いは、登録された新しい有料アカウントから少なくとも1か月後に受け取ることが予想されます。
