Miro Recap 2024でコラボレーションの力を讃えましょう！

Miroのユーザーはイノベーション・ワークスペース上で驚くべきマイルストーンを達成しています。リキャップがあれば、自分の業績を振り返り、それを可能にした人脈を祝うことができます。

> **利用可能なプラン：**Free、Education、Starter、Business、Enterprise
> **利用可能な環境：**デスクトップ

## 誰がMiro Recap 2024にアクセスできますか？

Miro Recap 2024は、Free、Starter、Business、Enterpriseの各プランで、非常にアクティブな一部のユーザーにご利用いただけます。Recapは個人的なものであり、個人ユーザーのためだけに設計されています。

現在のところ、チームや会社レベルの総括がありません。

:::note
Enterprise プランをご利用で、Recap にアクセスできない場合は、カスタマーサクセスまでお問い合わせください。
:::

## 自分のRecapにはどこでアクセスできますか？

Recapにアクセスするには、[miro.com/recap24に](https://miro.com/recap24)アクセスしてください。

デスクトップでは、ダッシュボードから直接Recapにアクセスすることもできます。

選択**2024年の総括の準備が整いました**。

![MiroダッシュボードからMiro Recap 2024にアクセスしてください。](../../../../../../docs/using-miro/special-features/images/23383406736146_image.png)

*MiroのホームダッシュボードからMiro 2024 Recapにアクセスしてください。*

## 私のリキャップは非公開ですか？

そうです。Recapデータはお客様のアカウントアクティビティに基づいており、他のMiroユーザーと共有されることはありません。

チームの管理者や会社の管理者は、個人の利用指標にアクセスすることはできません。

## Miro Recap 2024 データハイライトの説明

Recapは、集約された主要なコラボレーションとアクティビティメトリックスをハイライトします。MiroはMiro[プライバシーポリシーに従って](https://miro.com/legal/privacy-policy/)利用指標を処理します。

以下のリストでは、各リキャップデータポイントについて説明しています：

- コラボレーター数
  コラボレーションセッションに参加したユニークな登録ユーザーの総数
- **共同作業に費やした時間**
  登録参加者と非登録参加者を含む、コラボレーション・セッションに費やされたおおよその時間
- **トップ・コラボレーター**
  あなたと最もコラボレーションしたユーザー、滞在時間、共有ボードを表示します。登録ユーザーのみ
- **主な特徴**
  最も利用したツール、ウィジェット、機能
- **活動ピーク日**
  平均して最も活動的だった曜日
- **最も活発な月**
  2024年、あなたが最もアクティブだった月
- **トップ 使用リアクション**
  ボードで最もよく使ったリアクション
- **使用テンプレートトップ**
  最も使用したテンプレート
- **担当ボード数**
  閲覧、コメント投稿、編集のために訪れたボードの総数
- **協力した国の数**
  あなたまたはあなたの参加者が協力した国の総数。IPアドレスから工数見積を行います。この措置は、VPNのような位置情報を変更する可能性のあるツールについては考慮していません。
- **インスピレーションの瞬間**
  付箋のおおよその枚数

## Miro2024の総括を共有する方法

Recapを共有するには、以下の手順に従ってください：

1. [Miro2024の総括へ](https://miro.com/recap24)。
2. **My Miro 2024 year in review**」という最後のフレームで、「**コピーして共有**」を選択します。
   リキャップコピー
3. あなたのRecapを共有するソーシャルチャンネルを選択します。
4. (オプション）投稿に個人的なメッセージを追加します。
5. 画面の指示に従って、Recapを投稿してください。

   Miro2024の総括の共有に成功しました。

:::tip
Recapをダウンロードすることもできます。最後のフレームで、ダウンロードアイコンを選択します。
:::
