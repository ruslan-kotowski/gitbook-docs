Web ホワイトボードは、登録またはログインすることなく使用できる無料で簡単なオンライン ホワイトボードです。 Web ホワイトボードで次のオンライン ブレインストーミングまたは個別指導セッションを実施しましょう。[webwhiteboard.com](https://webwhiteboard.com/) を開き、ボードを作成し、チームとリンクを共有するだけです。

:::note
詳細については、[webwhiteboard.com/home](https://webwhiteboard.com/home/) もご覧ください。
:::

:::warning
Web ホワイトボードは、Chrome のシークレットモードまたは Safari ではサポートされていません。
:::

### Web ホワイトボードとは何ですか？

Web ホワイトボードは、デスクトップ デバイスやタブレット デバイスで登録することなく、すべてのユーザーが無料で利用できます。タブレットでは、パームリジェクションや [Apple Scribble](https://support.apple.com/guide/ipad/enter-text-with-scribble-ipad355ab2a7/ipados) をサポートしているので、タッチペンで使用することもできます。

Web ホワイトボードの利用を開始するには、ブラウザーで [webwhiteboard.com](https://webwhiteboard.com/) を開き、新しいボードを作成します。

このリンクをチームと共有でき、Miro に登録もしくはログインする必要がなく、リアルタイムでコラボレーションできます。 リンクを共有するには、画面右上隅にある **[ボードの共有]** ボタンをクリックしてください。ボードへのリンクはクリップボードにコピーされ、リンクを知っている人は誰でも、ボードへの編集アクセス権が得られます。

![share_webwhiteboard.jpg](../../../../../../docs/using-miro/special-features/images/21019704270610_share%20webwhiteboard.jpg)
*Web ホワイトボードでボードを共有*

Web ホワイトボードのボードは 24 時間利用できます。その後、7日間ロックされます。この間、Miro に登録してログインし、ボードのロックを解除して保存することができます。ボードが 7 日以内にロック解除/保存されない場合、完全に削除されます。

あるいは、画像または PDF としてボードをダウンロードすることもできます。画面左上にあるWeb ホワイトボードのロゴの横にある [このボードをエクスポート] アイコンをクリックして、ポップアップに表示される**画像**または **PDF** を選択します。

:::warning
ボードを保存またはエクスポートしない場合は、**7 日後に**完全に削除されますのでご注意ください。
:::

![export_webwhiteboard.gif](../../../../../../docs/using-miro/special-features/images/21019704274066_export%20webwhiteboard.gif)
*Web ホワイトボードでボードをエクスポート*

![webwhiteboard_popup.jpg](../../../../../../docs/using-miro/special-features/images/21019704276882_webwhiteboard%20popup.jpg) *24 時間後に表示されるポップアップ*

### ボードを保存したい場合の対応

Miro の登録ユーザーの場合は、ボードを保存するオプションがあり、複数のチームがある場合、ボードをどのチームに保存したいのかを選択できます。

![save_to_my_boards.jpg](../../../../../../docs/using-miro/special-features/images/21019704281618_save%20to%20my%20boards.jpg)
*Miro チームにボードを保存*

Web ホワイトボード ユーザーで、Miro のプロフィールをまだお持ちでない場合、24 時間経過後も引き続きボードを編集するには、Miro に登録する必要があります。

![sign_up_to_Miro.jpg](../../../../../../docs/using-miro/special-features/images/21019704278418_sign%20up%20to%20Miro.jpg)
*Miro プロフィールを登録してボードを保存*

最初に Miro に登録したユーザーが、保存するボードの所有者になります。他のコラボレーターは、同じリンクでこのボードにアクセスでき、[ビジター](../sharing-boards/08-collaboration-with-visitors.md)として引き続き作業を行うことができます。

### よくある質問

1. *Web ホワイトボードを使うには Miro ユーザーでなければなりませんか？*- いいえ、その必要はありません。Web ホワイトボードは、誰でも登録なしで使用できる無料のオンライン ホワイトボードです。
2. *Web ホワイトボードで作業できる時間はどのくらいですか？*- 各 Web ホワイトボードは 24 時間有効ですが、その後ロックされ、ログインしてボードを保存しない限り、7 日後に永久に削除されます。ボードで引き続き作業したい場合は、[Miro の Free プラン](../../getting-started/start-here/02-how-to-register-with-miro.md)に登録して作業を保存するか、画像や PDF としてボードをエクスポートしてください。
3. *Web ホワイトボードで作業を続けるには、料金が必要ですか？*- いいえ、ボードの作業を続けるには、[Miro の Free プランに登録](../../getting-started/start-here/02-how-to-register-with-miro.md)する必要があります。
4. *Web ホワイトボードは Miro とどう違うのですか？*- Web ホワイトボードは Miro よりシンプルで軽量なバージョンです。[Miro の Free プラン](../../plans-billing/miro-plans/09-free-plan.md)や[各種プレミアムプラン](../../plans-billing/miro-plans/02-plans-and-features-available.md)と比較し、機能数が限られています。
