コラボレーション セッション時や大きなボードを使用した際にボードパフォーマンスを向上させるためのヒントや、パフォーマンスや操作性の低下、ボードのフリーズ、読み込みが終わらないなどの問題のトラブルシューティングをご覧ください。

## ボードパフォーマンスを向上させる方法

多くのユーザーとの**コラボレーション セッション**や、多数のコンテンツを含む**大きなボード**では、ボードのパフォーマンスが低下する場合があります。

コラボレーション セッションを行う際のヒント大きなボードを使用する際のヒント

ボード上のユーザー数が増え、作業が集中すると、ボードのパフォーマンスに影響することがあります。古い低性能のデバイスを利用している場合も、パフォーマンスが遅延するリスクが高まります。/span>

**コラボレーション セッションに参加する場合は、以下を必ずご確認ください。**

- デスクトップで作業している場合は、冗長なタブやウィンドウをすべて閉じるか最小化します。 [ブラウザ](../technical-guidelines/02-supported-browsers-browser-restrictions.md)
- コラボレーターのカーソルを非表示にし、すべてのサイドバーを閉じる
- 同時に複数のボードオブジェクトを選択して、変更しない
- ボード全体の操作を最小限にする
- ノートパソコンで Miro を使用する場合、電源オプションが省電力モードではなく、高パフォーマンスモードであることを確認します。

**Miro でコラボレーション セッションを行う予定がある場合：**

- 編集権限が必要がないユーザーを閲覧者として招待する。[ボードアクセス権](../../sharing-boards/01-board-access-rights.md)の設定方法をご覧ください
- ボードコンテンツの整理整頓を行う - ガイドラインについては、上の 2 番目のタブにある**大きなボードを使用する際のヒント**をご覧ください。

ボードに追加できるオブジェクトの最大数は 10 万個です。ただし、オブジェクトが 1,000 個を超えるとパフォーマンスに影響する可能性があります。高い操作性を維持するには、ボード上のオブジェクト数を 5,000 個未満に保つことをお勧めします。
ボード上のオブジェクト数を確認するには：

- ボード上のすべてのオブジェクトを選択します（Windows では ctrl-A、Mac では cmd-A、または選択範囲をドラッグしてすべてのオブジェクトを囲みます）
- コンテキストメニューが表示され、オブジェクトの総数を確認することができます
- **[検索条件]** をクリックして、タイプ別のオブジェクト数を確認します

![オブジェクトの数.gif](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/25736281544466_number-of-objects.gif)
*ボード上のオブジェクト数を確認する*

オブジェクト数と併せて、重いオブジェクトや複雑なオブジェクト（特にアップロードされたファイルやドキュメント）を使用すると、ボードの操作速度が低下することがあります。

**大きなボードを高速化するには、以下に示すようなボードの整理整頓が重要です。**

- 不要なコンテンツ、特に重いアップロードされたファイルやドキュメント（多くの詳細情報を含むベクター PDF や高解像度画像など）を削除する
- 重い PDF や高解像度の画像を PNG/JPG ファイルに変換し、ボードに再度アップロードする
- 100% ズームレベルで見た目が大きすぎるボードコンテンツがあれば、縮小する
  - 右下のマップに移動し、ズームを 100% に設定しますする
  - このズームレベルでコンテンツの見た目が大きすぎる場合、**Ctrl + A**（Windows の場合）または **Cmd + A**（Mac の場合）を使用してコンテンツを選択し、縮小する
  - 大きな画像を縮小することも検討する

- [ペン](../../essential-tools/10-pen.md)による手書きオブジェクトを画像に変換する
  - 図のスクリーンショットを作成する
  - ボードにアップロードする
  - 図を削除する
- 可能であれば、ボードをいくつかのボードに分割する
  - ボードコンテンツの一部を選択し、**Ctrl + C**（Windows の場合）または **Cmd + C**（Mac の場合）を押して、コピーする
  - [新しいボードを作成](../../../getting-started/start-here/your-first-board/01-create-a-miro-board.md)し、コンテンツをボードに貼り付ける

## パフォーマンスの低下や読み込みが終わらない場合のトラブルシューティング方法

## 一般的な問題のトラブルシューティング方法

同期中...お待ちください接続が回復しました

ポップアップ通知の**「同期中...お待ちください」**は、処理中の負荷が高く、予定時間内に処理を完了するにはパワーが不足していることを意味します。従って、例えば大量のオブジェクトを一括操作する際に極端に重いボードで作業している場合や、パケットロスが発生した場合などにメッセージが表示されることがあります。ボードが比較的シンプルに見えても、高解像度画像、PDFファイル、ペン描画（これらはレンダリングが困難なベクターグラフィックスであるため）、表などは、Miro では重いオブジェクトになり、このことがパフォーマンス低下を引き起こして、メッセージが表示される可能性があることに注意してください。

新しいボードにコンテンツをコピー＆ペーストしてボードを分割し、問題が解決するかどうか試してみてください。問題が解決しない場合：

- お使いの端末が最小限のシステム要件を満たしていること、またブラウザが最新のバージョンにアップデートされていることをご確認ください。
- ブラウザで複数のタブを開いている場合は、タブを閉じるかフリーズしてから Miro で作業するようにしてください。そうすることで、ブラウザの処理能力を複数のタブに分散させることなく、すべてを Miro アプリに費やすことができます。
- シークレット（非公開）モード（ブラウザー拡張機能の干渉の可能性を排除するため）および別のブラウザーで Miro をテストしてください。必要に応じて、バックグラウンドで実行中のすべてのブラウザー タブとアプリケーションを閉じます。
- ブラウザーのキャッシュと Cookie を消去し、ブラウザーを再起動し、F5（または Ctrl / Cmd + R）を数回クリックして、ページをハードリフレッシュしてください。
- 特定のボードに問題が発生した場合は、ボードを複製して、問題が解決するか確認してください。アイテム数が少ないボードや小さいボードを開いて、問題が解決するか確認することもできます。
- VPN を使用する場合、オフにしたときに問題が発生しないかどうか確認してください。
- ボードを複製して、新しいボードでエラーが再現されるかどうか確認してみてください。

通常、次のような場合に「**再接続中...**、**接続が復元されました**」というエラーが表示されることがあります。

- ユーザー側で何らかの接続の問題が発生した場合。ネットワーク接続が最小限の要件を満たしていることを確認します。場合によっては、より高速なネットワークに切り替えてみてください。
- 同じブラウザで複数の重いボードを開いて作業している場合。このような場合は、ブラウザの余分なタブや実行中のアプリケーションをすべて閉じ、ブラウザのページを更新してください。

また、WebSocket 接続を確認するのもよいでしょう（特に、すべてのボード、小さなボードでも問題が発生している場合）。IT 部門に連絡し、ポート 80 と 443（SSL）の WebSocket 接続を有効にしてもらい、[他に原因がないか再確認](../../tools/troubleshooting/01-add-miro-to-allowed-apps.md)してください。

## よくある質問

*ボードパフォーマンスは、使用しているプラン（無料/有料）に関係しますか？*

いいえ。ボードパフォーマンスはプランの影響を受けません。

*ボードの共有設定はパフォーマンスに影響しますか？*

共有設定がボードパフォーマンスに影響を与えることはありませんが、ボード上のユーザー数は影響することがあります。上記のコラボレーション セッションを行う際のヒントをご利用ください。
