モバイルやタブレットデバイスで Miro を使用する際に、何らかの問題が発生した場合は、まず*アプリを再インストールし、デバイスの再読み込み*を試みてください。それでも問題が解決しない場合は、以下に示す想定される原因と対策をご確認ください。

| **モバイルデバイスでの問題** | | |
| --- | --- | --- |
| **問題** | **想定される原因** | **対策** |
| iOS のモバイルアプリがクラッシュし、正常に動作しません | iOS のバージョンが古い可能性があります | iOS バージョンをアップデートするか、別のデバイスでお試しください。 iOS 用のモバイルアプリは、iOS バージョン 12 以上に対応しています。 |
| デスクトップアプリに正常にログインできますが、モバイルアプリでは Miro のロゴが表示されたところでアプリが停止します | 認証データが破損しています（キャッシュ不良） | **[アプリ設定] > [ストレージ] > [ストレージのクリア]** へ移動するかデバイスに Miro のアプリを再インストールしてください |
| モバイルアプリで SSO 認証すると、「問題が発生しました」というエラーが発生します | 1. 1. ネットワークの保護により、要求がブロックされている可能性があります。  2. 2. Chrome が ADFS の WIAsupportedUserAgents リストに追加され、ユーザーが誤って誘導されている可能性があります/span>  3. 3. お使いの特定のデバイスでは会社の SSO 環境にアクセスできない可能性があります | 1. 1. 別のネットワークに接続してから認証をしてください  2. 2. システム管理者に連絡し、リストから Chrome を削除するように依頼します  3. SSO の使用が許可されている特定のデバイスに関する制限があるかどうか、IT 部門に確認してください。 |
| ボードからインポートしたファイルが、モバイルデバイスのファイルシステム上で見つかりません | ボードからダウンロードしたファイルは、モバイルデバイスでは、しばらくの間「非表示」なります | 恐れ入りますが、ダウンロードしたファイルがフォルダーに表示されるまでお待ちください |
| モバイルデバイスで Miro にログインすると、「利用可能なアカウントがありません」というメッセージが表示され、プロフィールにアクセスできません | お客様のアカウントがすべてのチームで削除されたか、ご自身でチームを[退出](../../managing-your-profile/06-how-to-leave-a-team.md)された可能性があります。 | デスクトップ PC やタブレットデバイスで Miro にログインして、チームを新しく作成するか、別のユーザーに依頼して Miro チームに招待してもらってください |
| モバイルデバイスのブラウザーで Miro のボードを編集することができません | これは、現時点では既知の制限事項です | [モバイルアプリ](../../../getting-started/apps-for-devices/08-mobile-app.md)、タブレットデバイスまたはデスクトップ PC に切り替えてご利用ください |
| モバイルアプリでボードをエクスポートすることができません | これは、現時点では既知の制限事項です | 別のデバイスに切り替えてご利用ください。Miro ボードのエクスポート機能の詳細については、[こちらのページ](../../import-and-export/export/03-how-to-export-your-board.md)をご覧ください |

| **タブレットデバイスでの問題** | | |
| --- | --- | --- |
| **問題** | **想定される原因** | **対策** |
| iPad で Miro を使用すると、ツールバーが消えたり、動作が不安定になります | Miro のアプリは、WebView を使用してビジュアルをレンダリングしていますが、メモリ管理に関するルールにより、レンダリングプロセスでデバイスの RAM メモリを 25% 以上利用することができません。この利用率を超えると、アプリの動作は制限され、エラーメッセージも表示されずにアプリが正常に読み込まれなくなります | - Miro を使用する前に、バックグラウンドで動作する不要なアプリケーションをすべて終了させてください - ファイルサイズの小さいボードで作業してください - 上記の対策を試しても効果がない場合は、デスクトップ PC など、より高性能な RAM を持った*他のデバイス*に切り替えてご利用ください |
| デスクトップアプリでは正常にログインできるのに、タブレットアプリでは Miro のロゴが表示されたところでアプリが停止します。 | 認証データが破損しています | **[アプリの設定] > [ストレージ] > [ストレージのクリア]** を実行するか、デバイスの Miro アプリの再インストールをお試しください。 |
| iPad でオブジェクトを貼り付けると、「多くのオブジェクトを一度にコピーすることはできません」というエラーメッセージが表示されます | iPad バッファーがオーバーフローしました | 一度にコピー ＆ ペーストするウィジェットの数を減らしてください |
| タブレットデバイ[スのボードにアップロードした Google ドキュメント](../../../integrations-apps/google/05-google-drive.md)を編集できません | これは、現時点では既知の制限事項です | 回避策として、[ソース] **アイコン**をクリックすると、Google ドキュメントアプリからドキュメントを開くことができます |
| iPad で Apple Pencil を使用しています。ダブルタップして、ペンと消しゴムを切り替えようとしても何も起こりません | これは、Miro の機能ではなく、第 2 世代の Apple Pencils 専用のネイティブ機能です。この機能は、対応するタブレットアプリでのみ動作します | [タブレットアプリ](../../../getting-started/apps-for-devices/11-tablet-app.md)が、Apple Pencil のこの機能に対応していることを確認した上で、アプリを切り替えてください |
| iPad で、以下の 2 つの機能が動作しません。   - マウスホイールによる画面のズーム - トラックパッドによる 2 本指スワイプ操作でのボードナビゲーション | これは、iPad OS の機能制限による既知の制限事項です | 残念ながら、この問題に対する対策はまだありません。 |
