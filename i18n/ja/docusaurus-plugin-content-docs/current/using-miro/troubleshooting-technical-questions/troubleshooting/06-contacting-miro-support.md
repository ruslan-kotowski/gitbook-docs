ユーザーの皆さまには、いつもスムーズに製品をお使いいただきたいと考えています。Miro ユーザーの共同作業をサポートするために、役立つリソースを提供しています。サポートに連絡する前に、[ヘルプセンター](https://help.miro.com/hc/en-us)、[Miro アカデミー](https://academy.miro.com/)、[ブログ](https://miro.com/blog/)、[Youtube チャンネル](https://www.youtube.com/channel/UCfhGfgBKDcFI74bBJ9yjLDQ)、[Miro ウェビナー](https://go.miro.com/webinars)を検索してみてください。

また、[Miro コミュニティー](https://community.miro.com/?utm_source=zendesk&utm_medium=referral&utm_campaign=contact_support)を訪れて、他の Miro ユーザーに質問したり、ベストプラクティスを共有したり、ソリューションを議論したりできます。また、[コミュニティーのウィッシュリスト](https://community.miro.com/community-welcome-guide-14/wish-list-everything-you-need-to-know-1099/?utm_source=zendesk&utm_medium=referral&utm_campaign=contact_support)で欲しい機能を提案することもできます。

### Miro サポートへのお問合せ方法

> **利用可能なプラン：**Starter、Business、Enterprise プラン

以下のトピックに関してサポートリクエストを送信することができます。

- Miro 製品
- 請求とサブスクリプション
- ログインと登録
- セキュリティーと法務
- 特別オファーとプログラム
- Miro 開発者向け情報

#### 前提条件

有料チームにログインしていることを確認してください。Miro サポートにリクエストを送信できるのは、有料チームのメンバーのみです。

#### 手順

以下の手順に従ってください。

1. Miro のダッシュボードの右上で自分のアバターを選択します。
   プロフィール メニューが開きます。
2. **ラーニングセンター**を選択
   **ラーニングセンター**モーダルが開きます。
3. **サポートに問い合わせる**を選択します。
4. リクエストのトピックを選択してください。
5. 画面の指示に従ってサブトピックを選択します。
   サポートリクエストフォームが開きます。
6. （任意）リクエストフォームの上に、関連する記事の提案が表示されます。
7. サポート依頼フォームに記入する。
8. **送信**を選択します。

   Miro サポートへのリクエストの送信に成功しました。

![support-contact.png](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21537436630418_support-contact.png)
*サポートリクエストの送信*

モバイルアプリでリクエストを送信するには、[モバイルアプリ](../../../getting-started/apps-for-devices/08-mobile-app.md)で左上のチームのアイコンを押し、**ヘルプ**をタップします。複数のチームのメンバーになっている場合は、必ず有料チームに切り替えてください。

サポートリクエスト送信前に、Miro のプロフィールにログインしてください（まだログイン済みでない場合）。

:::warning
プロフィールやサブスクリプション関連の詳細は、所有者のみに共有することができます。
:::

:::note
サインインできない場合は、[こちらのフォーム](https://miro.com/contact/recover/)を使用してサポートリクエストを送信してください。
:::
