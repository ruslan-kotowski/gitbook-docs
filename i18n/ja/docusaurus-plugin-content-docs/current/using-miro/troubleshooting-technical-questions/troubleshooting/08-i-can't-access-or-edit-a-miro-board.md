Miro ボードにアクセスできない場合や、編集アクセス権が失われた場合は、このガイドに従ってください。

### Miro ボードにアクセスできません

Miro ボードにアクセスできない場合は、以下のメッセージのいずれかが表示される可能性があります。メッセージをクリックして、解決法を探ります。

**ボードへのアクセスはありません。ボードの所有者に連絡し、このボードを閲覧する権限を付与するよう依頼してください**

![no_access_to_boards.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21016057935250_no%20access%20to%20boards.jpg)
このメッセージが表示された場合、ボードへのアクセス権を復元することは可能です。以下の手順をお試しください。

1. ポップアップの青いボタンをクリックして**アクセスをリクエスト**します。リクエストはボードの所有者に送信されます。
   ボードへのアクセス権をメールで付与された場合、メールの送り主に直接連絡し、ボードの共有を依頼することもできます。ユーザー名を検索するには、メールの受信トレイでボードへの招待メールを検索します。
   ボードが Enterprise アカウントに保存されている場合、[コンテンツ管理者権限](../../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md)が有効化されていると、会社の管理者はアクセス権を付与することができます。会社の管理者に連絡して、ボードを共有するよう依頼します。
2. Miro に別のメールアドレスで登録している場合は、もう一つのプロフィールにログインし、そのメールアドレスでボードにアクセスできるかどうかを確認します。
3. 自分で作成したボードにアクセスできない場合は、ボードが保存されているチームから削除された可能性があります。
   Miro の管理者に連絡して、チームへの再招待を依頼し、ボードへのアクセスを復元します。ボードが削除された場合、管理者は 90 日以内に[ボードを復元](../../managing-boards/08-how-to-restore-a-deleted-board.md)することができます。あるいは、ボードが別のユーザーに再割り当てされた場合は、新しいボード所有者に依頼して復元することも可能です。

**ボードが削除されました**

![board_has_been_deleted.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21016044559122_board%20has%20been%20deleted.jpg)
削除されたボードは、90 日以内に復元することができます。以下の手順を実施してください。

1. ボードの所有者に連絡して、[ボードの復元](../../managing-boards/08-how-to-restore-a-deleted-board.md)を依頼します。最初にメールでボードに招待された場合は、受信トレイでボードへの招待メールを検索し、ボード所有者の名前を探し出すことができます。
2. 元の所有者がボードを復元できない場合、その所有者が自分の Miro プロフィールとボードを一緒に削除したか、その所有者がチームから削除される際にコンテンツも削除されたと考えられます。
   Miro の管理者に連絡して、ゴミ箱からの[ボードの復元](../../managing-boards/08-how-to-restore-a-deleted-board.md)が可能かどうか、あるいはボードのリンクをフォローしてボードを復元できるかどうかを確認するよう依頼します。
   管理者は、[ユーザーを削除する際に、ボードを新しい所有者に再割り当て](../../../administration/user-management/08-remove-users.md)することもできます。その場合、新しいボード所有者がボードを復元することができます。

   ボードが Enterprise アカウントに保存されている場合、会社の管理者は、[コンテンツ管理者権限](../../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md)を有効化し、ボードが削除されてから 90 日以内であれば、ボードリンクを介してボードを復元することができます。

**ボードが存在しません**

![board_does_not_exist.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21016044564626_board%20does%20not%20exist.jpg)
ボードにアクセスするリンクが正しいことを確認してください。ボードリンクは、ブラウザー履歴や Miro のメール通知で検索することができます。

ボードリンクが正しい場合、そのボードはチームと一緒に削除された可能性があります。チームを削除すると、そのチームにあるボードも削除されます。チームを削除する前に、必ず[ボードをエクスポート](../../import-and-export/export/03-how-to-export-your-board.md)するか、[ボードのバックアップを保存](../../import-and-export/export/05-how-to-save-board-backup.md)してください。

**ボードがすでに共有されていない、または削除されました**

![this_board_is_no_longer_shared.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21016057938450_this%20board%20is%20no%20longer%20shared.jpg)

ボードにアクセスするリンクが正しいことを確認してください。ボードリンクは、ブラウザー履歴や Miro の通知で検索することができます。

ボードリンクが正しい場合、そのボードは 90 日以上前に削除されたか、チームと一緒に削除された可能性があります。チームを削除すると、そのチームにあるボードも削除されます。チームを削除する前に、必ず[ボードをエクスポート](../../import-and-export/export/03-how-to-export-your-board.md)するか、[ボードのバックアップを保存](../../import-and-export/export/05-how-to-save-board-backup.md)してください。

**アクセス権が取り消されました**

![access_revoked.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21016044566418_access%20revoked.jpg)

**アクセス権が取り消されました**というメッセージは、ボードへのアクセス権が削除されたことを意味します。

1. ボードの所有者または共同所有者と連絡を取り、[ボードへのアクセス権の付与](../../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)を依頼します。ボード所有者の名前を検索するには、メールの受信トレイでボードへの招待メールを検索します。
2. 自分のボードまたはアクセス権が付与されているボードにエラーメッセージが表示された場合：

- タブレットまたはモバイルデバイスで Miro ボードにアクセスしようとする度に「アクセス権が取り消されました」というエラーが表示される場合は、アプリを削除し再インストールをお試しください。
- デスクトップのブラウザーでこの問題が発生する場合は、お使いのデバイスにブロッカーがあるため、そのブラウザーのボードに関連する特定のリソースにアクセスできない可能性があります。会社の IT 部門に連絡し、アクセスの許可を依頼してください。[許可されたアプリに Miro を追加する](../../tools/troubleshooting/01-add-miro-to-allowed-apps.md)の記事で、ネットワーク接続または環境に適用される制限についてご覧ください。

[Miro のデスクトップアプリ](../../../getting-started/apps-for-devices/05-desktop-app.md)でボードを開くことや、別のデバイスで一時的に Miro にアクセスすることもできます。

**読み込み中が無限に続く現象**

ボードを開こうとすると、読み込み中が無限に続く場合、ボードパフォーマンスを向上させ、読み込みに関する問題を解決する方法については[こちら](../../tools/troubleshooting/04-board-performance-and-loading-issues.md)をご覧ください。

### Miro のボードが編集できなくなりました

ボードの編集権限を持っていたにもかかわらず、現在は閲覧またはコメントのみ可能な場合は、考えられる理由と解決法を以下でご確認ください。

1. ボード共有設定でアクセスレベルが変更された可能性があります。ボード所有者に編集権限をリクエストしてください。これを行うには、ボードの右上にある **[編集者権限をリクエストする]** をクリックします。
   ![Screenshot_background_template__1202__1_.jpg](images/25452698729106_Screenshot%20background%20template%20%201202%20(1).jpg)
   *ボードで編集権限をリクエスト*
   メールでボードへのアクセス権が付与された場合、最初にへの招待メールをくれた相手に連絡し、編集権限の付与を依頼することができます。ユーザー名を検索するには、メールの受信トレイでボードへの招待メールを検索します。

   ボードが Enterprise アカウントに保存されている場合、会社の管理者はだれでも[コンテンツ管理者権限](../../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md)を有効化し、ボードへの編集権限を付与することができます。
2. Miro の別のプロフィールからボードを編集できるか確認してください。別のメールアドレスで Miro に登録している場合は、そのメールアドレスでログインしてください。
3. ボードの複製をお試しください。ボードの所有者/共同所有者が[ボードコンテンツのコピー](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)を許可し、ボードがアクティブなチームにある場合は、[ボードを複製](../../managing-boards/03-how-to-duplicate-a-board.md)してそれを編集することができます。
4. Free プランをお使いの場合は、チームのボード数制限に達したか、非公開ボードが無料のプランに移動されたため、ボードを編集できない可能性があります。[ボードはロックされています](../../tools/troubleshooting/15-the-board-is-locked.md)の記事をご覧ください。
5. Miro のサブスクリプションの有効期限が切れると、ボードは閲覧専用モードでロックされます。Miro の管理者に連絡し、チームのサブスクリプションがアクティブであることをご確認ください。サブスクリプションの有効期限が切れている場合は、管理者はそれを更新するか、[Free プランにダウングレード](../../../plans-billing/manage-your-subscription-and-plan/04-downgrade-your-plan.md)する必要があります。

:::note
ボードコンテンツを編集しようとしてバグが発生した場合は、[バグとトラブルシューティング](../../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md)のガイドをご確認ください。
:::

:::note
ボードが見つからない場合やコンテンツの一部が消えてしまった場合、[ボードやコンテンツを紛失した場合](../../tools/troubleshooting/11-i-lost-my-board-or-content.md)の記事をご覧ください。
:::
