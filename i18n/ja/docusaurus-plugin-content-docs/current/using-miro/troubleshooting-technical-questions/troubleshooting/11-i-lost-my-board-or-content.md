Miro ボードを見つけることが困難な場合や、ボード上のコンテンツが紛失した場合に行うべきことをご紹介します。

:::tip
コンテンツを保護するには、必ず[ボードバックアップ](../../import-and-export/export/05-how-to-save-board-backup.md)を保存してください。
:::

## ボードが消えました

Miro ボードを誤って削除したり、ボードが消えてしまった場合、見つける方法がいくつかあります。

### Miro チームを確認し、検索機能を使用する

複数の Miro チームのメンバーの場合は、ダッシュボード左側のサイドバーで[チームを切り替える](../../../getting-started/start-here/miro-dashboard/04-profile-and-teams.md)ことを試してください。それから**このチームにあるボード**をクリックして、特定のチーム内のすべてのボードを確認します。

![switch_between_Miro_teams.gif](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21017417242386_switch%20between%20Miro%20teams.gif)
*Miro チームの切り替え*

検索を使用して[ボードを見つける](../../../getting-started/start-here/miro-dashboard/03-how-to-search-in-miro.md)こともできます。

![Searching for board name in Miro.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21017417250834_Searching%20for%20board%20name%20in%20Miro.jpg)

すべてのボードを閲覧していることを確認するには、Owned by anyone フィルターを適用する必要がある場合があります。フィルターを使用すると、所有しているボードや他の人が所有しているボードに検索を絞り込むことができます。

![sorting options.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/26846573077906_sorting%20options.jpg)
*ダッシュボード上のボードをフィルタリングする*

### ブラウザーの履歴や受信トレイでボードリンクを検索する

それでもボードを見つけることができない場合は、ブラウザー履歴や受信トレイでボードリンクを探します。ボード所有者である限り、[リンクを開くことでボードを復元](../../managing-boards/08-how-to-restore-a-deleted-board.md)することができます。ボードは削除された日から 90 日以内に復元することができます。

### ゴミ箱を確認する

有料プランのユーザーで、ボードの場所がわからなかったりURLが見つからない場合は、[ゴミ箱からボードを復元する](../../managing-boards/08-how-to-restore-a-deleted-board.md)方法を試してみてください。

![trash bin.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/26846558784530_trash%20bin.jpg)
*Miro ダッシュボードのゴミ箱セクション*

### カスタムテンプレートを確認する

ボードが有料チームまたは Education チームにあった場合、同様の名前を持つ[カスタムテンプレート](../../../getting-started/start-here/your-first-board/02-custom-templates.md)を確認してください。最初にテンプレートを作成した可能性があります。

### ボードアクセスへの変更を確認する

ボードがあるチームから削除され、ボードへのアクセスを失った可能性があります。ユーザーを削除する場合、管理者はそのユーザーのボードの再割り当てや削除を行うことができます。ボードが削除されていない場合、ボードリンクをフォローし、[現在の所有者からアクセスをリクエストする](../../sharing-boards/01-board-access-rights.md)ことができます。ボードが削除された場合、[削除されたボードを復元](../../managing-boards/08-how-to-restore-a-deleted-board.md)するようチームの管理者に90日以内に依頼することができます。

## ボードコンテンツが見つかりません

ボードコンテンツの一部が見つからない場合、見つけるためのヒントをいくつか用意しています。

### ボード履歴を確認する

ボードを開き、左下にある**サイドバーを開く**アイコンをクリックします。開いたボードの概要で、**ボード履歴** アイコンをクリックします。紛失しているコンテンツが表示された場合、ほとんどの場合、リストアアイコンをクリックすることで簡単にリストアすることができます。しかし、[コンテンツを復元する際にはいくつかの制限があります](../../working-on-the-board/18-restoring-board-content.md)。

:::tip
有料プランのユーザーは、[ボードバージョン管理機能](../../managing-boards/12-board-history-versions.md)を試して使用することもできます。
:::

![restore_board_content_restore_feature.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/26846573080338_restore_board_content_restore_feature.jpg)
*ボード履歴からコンテンツを復元しています*

### ミニマップでボードを確認する

ボード履歴で紛失しているコンテンツを見つけることができない場合、コンテンツがボード上のどこかにある可能性があります。

ミニマップを確認してみてください。ミニマップはボードの右下にあり、ズーム メニューからアクセスでき、コンテンツの全体図を見ることができます。そのため、フレームから抜け出した場合、そこで見つけることができます。

![minimap.gif](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/26846495500178_minimap.gif)
*ボード上のコンテンツの全体図は、ミニマップで確認することができます。*
