Miro のパフォーマンスに問題が発生している場合や、Miro サポートにバグを報告する方法をご紹介します。

## バグを報告する前に

1. 潜在的なパフォーマンス低下の報告については、[Miro ステータスページ](https://status.miro.com/)をご確認ください
2. シークレット[（非公開）モード](https://support.google.com/chrome/answer/95464)**および**別のブラウザー**で問題が再現されるかを確認してください**
3. [ブラウザーの拡張機能を無効にします](https://support.box.com/hc/articles/360044196613-How-To-Disable-Plugins-Add-Ons-Extensions-In-Multiple-Browsers)。Miro のプロセスと衝突することがあります（例：テキストウィジェットを使用した Grammarly）。
4. デスクトップアプリを使用している場合は、[アプリデータをリセット](../../../getting-started/apps-for-devices/05-desktop-app.md)してください
5. 特定のボードにパフォーマンスに関する問題が発生した場合は、ボードを[複製](../../managing-boards/03-how-to-duplicate-a-board.md)して、複製されたボードでも同じ問題が発生するかを確認してください
6. トラブルシューティング ガイドをご確認ください：

- [ボードパフォーマンスと読み込みに関する問題](../../tools/troubleshooting/04-board-performance-and-loading-issues.md)
- [ログインできません](../../tools/troubleshooting/09-i-can't-log-in.md)
- [Miro ボードにアクセスも編集もできません](../../tools/troubleshooting/08-i-can't-access-or-edit-a-miro-board.md)
- [ボードのエクスポート時の問題](../../tools/troubleshooting/03-board-export-issues.md)
- [ボードやコンテンツを紛失しました](../../tools/troubleshooting/11-i-lost-my-board-or-content.md)
- その他のガイド

## バグを報告する方法

できる限り多くの詳細をお知らせください。お客様の状況をただちに把握することで、問題の早期解決に役立ちます。

1. 問題の詳細な説明、スクリーンショット、GIF、[短い動画](https://chrome.google.com/webstore/detail/openvid-screen-recorder-c/liecbddmkiiihnedobmlmillhodjkdmb)などを送信してください。さらに、

- 特定のボードに問題が発生した場合は、[可能であればそのボードを編集権限付きで](../../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) [support@help.miro.com](mailto:support@help.miro.com) に共有してください
- アップロードした特定のファイルに関連する問題が発生した場合は、当社にファイルを送信してください

2. デバイス、オペレーティング システム、ブラウザーのバージョンを指定する
3. ブラウザーコンソールとネットワークログまたは、デスクトップアプリ ログを提供する

### コンソールログを記録する方法

**ブラウザー コンソールログを記録する方法**

1. Miro のボードを開いた状態で、ブラウザーのアドレスバー**をクリックしてください**（設定ページやダッシュボードではなく、ボードで問題が再現された場合は、こちらの手順をご使用ください）。mceclip1.png
2. F12 **または** fn + F12 **のショートカットキーを押して、ブラウザーの開発者ツールを開きます。**
3. ネットワーク**タブを選択**し、ログを保持**にチェックを入れてください。**
4. ページを再読み込みしてください。
5. 問題を再現してください。
6. ダウンロード矢印サインをクリックして**、ネットワークの HAR ログをエクスポートしてください。**
   network_console_logs.jpg
7. コンソールタブに切り替え、レコードを右クリックして、**[名前を付けて保存]** を選択します。save_console_logs.jpg
8. .*log* と .*har* ファイルを送信してください。ファイルが大きすぎてチケットスレッドにアップロードできない場合は、任意のクラウドストレージにファイルをアップロードし、そのリンクを送信します（リンクがあればだれでもダウンロードできるようにしておきます）。

**Mac でデスクトップアプリ ログを記録する方法**

Mac のデスクトップアプリでバグが発生した場合は、ログレコードを送信してください。

1. デスクトップアプリで、**左上にある**ヘルプをクリックします。[開発者ツールタブを開く] /span>を選択します​​​​​​​
   open_developer_tools_for_tabs.jpg
2. ​**Network** タブに切り替えます。​​​ チェックボックス**ログを保存**
3. トラブルシュートを行うボードを開きます（ボードにアクセスできない場合は、手順をスキップしてください）
4. Ctrl + R **のショートカット**キーでページを再読み込みする
5. 問題を再現します
6. ダウンロード矢印サインをクリックして、ネットワークの HAR ログをエクスポートしてください。
   preserve_logs.jpg
7. コンソールタブに切り替え、レコードを右クリックして、**[名前を付けて保存]** を選択します。save_as_.jpg
8. もう一度 **Helpを**クリック  > **Open developer tools**  を選択 し、ステップ2から7を繰り返します。これにより、別の種類のログが収集され、別のデータセットが提供されます。
9. .log と .har ファイルを送信してください。ファイルが大きすぎてチケットスレッドにアップロードできない場合は、任意のクラウドストレージにファイルをアップロードし、そのリンクを送信します（リンクがあればだれでもダウンロードできるようにしておきます）。

### ブラウザレポートの収集方法

読み込みやパフォーマンスの問題を報告する場合、拡張ブラウザのバージョン情報を共有することで、Miroサポートが問題を診断するのに役立ちます。この情報は、ブラウザの**アドレス**バーに特定のコマンドを入力することで見つけることができます。以下では、さまざまなブラウザでこの情報にアクセスする方法をご紹介します。

- **クローム**：クローム：//バージョン
- **Microsoft Edge**: edge://version
- **Firefox**: about:support (バージョンによってはabout:version)
- **オペラ**：opera://about
- **Yandexブラウザ**: browser://バージョン

> **✏️** [Miro サポートへのお問い合わせ方法は、こちらをご覧ください](../../tools/troubleshooting/06-contacting-miro-support.md)。
