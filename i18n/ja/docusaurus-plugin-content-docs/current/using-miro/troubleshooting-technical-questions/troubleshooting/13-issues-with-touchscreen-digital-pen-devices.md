タッチスクリーンやデジタルペンを搭載したハイブリッドデバイスで Miro を使用する際に問題が発生した場合は、ブラウザーの設定を確認してください。なお、ここで示す手順は、ブラウザーにのみ有効です。

## Google Chrome

1. Google Chrome で新しいページを開く
2. Chrome のアドレスバーに **chrome://flags** と入力し、検索フィールドに **touch** と入力する
3. **Touch UI Layout** が **[Enabled]**（有効）に設定されていることを確認する
4. **Touch initiated drag and drop** が **[有効]** に設定されていることを確認する
5. タッチスクリーン / デジタルペンを再度使用して、その違いを確認する

touch_enabled.jpg

## Edge

1. Edge で新しいページを開く
2. Edge のアドレスバーに **about:flags** を入力する
3. Ctrl + F を押し、**タッチイベント**を検索する
4. **タッチイベント**が**常にオンに**設定されていることを確認する
5. タッチスクリーン / デジタルペンを再度使用して、その違いを確認する
