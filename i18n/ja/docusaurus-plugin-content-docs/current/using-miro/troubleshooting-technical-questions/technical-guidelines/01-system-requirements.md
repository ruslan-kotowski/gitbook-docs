この記事では、Miro のシステム要件、デバイス、GPU、および WebAssemblyについて説明しています。

Miro で作業する場合、ご使用のデバイスが以下の最低または推奨システム要件を満たしていることをご確認ください。

ただし、Miro のパフォーマンスは、以下に挙げるような複数の他の要因に関連するので、以下のパラメーターは最終的なものではないことを念頭に置いておいてください。

- バックグラウンドのタスク
- ブラウザーのタブ数と、タブ間を切り替える頻度
- Miro を開くモニターの解像度
- Wi-Fi 接続の安定性
- ボードのユーザー数
- デバイスの冷却システム

パフォーマンス/アクセスに問題がある場合は、 [トラブルシューティングガイド](../troubleshooting)と [ボードパフォーマンスを最適化するためのヒント](../../tools/troubleshooting/04-board-performance-and-loading-issues.md)をご確認ください。

|  |  |  |
| --- | --- | --- |
|  | **最小要件** | **推奨要件** |
| **CPU** | 3 GHz (2 コア/4 スレッド) | 2.8 GHz (4 コア/8 スレッド) |
| **RAM メモリ** | 8 GB | 16 GB（DDR4） |
| **ネットワーク帯域幅** | 8 Mb/s | 32 Mb/s |

**Miro は、ブラウザーの Web エンジンを使用して動作するウェブアプリなので、推奨仕様をはるかに超える高性能なハードウェアで Miro を実行しても、期待するパフォーマンス向上が得られないこともあります。Web エンジンは、特定のオペレーティングシステムおよび CPU アーキテクチャ用に設計され、コンピューターにローカルでインストールされたソフトウェアのように、デバイスの性能を最大限に引き出すことはできません。*

タブレットで Miro を快適に使用するための最低システム要件は、[タブレット](../../../getting-started/apps-for-devices/11-tablet-app.md)は、6 GB の RAM です。

Miro は、さまざまなタイプのデバイスで使用することができます。ブラウザで Miro を開いたり、[デスクトップ](../../../getting-started/apps-for-devices/05-desktop-app.md)、[タブレット](../../../getting-started/apps-for-devices/11-tablet-app.md)、[モバイルアプリ](../../../getting-started/apps-for-devices/08-mobile-app.md)をダウンロードしたり、[インタラクティブディスプレイで Miro を使用](../../../getting-started/apps-for-devices/07-interactive-displays.md)することができます。

**オフラインモード**

Miro は、*オンライン*コラボレーションを実現するシームレスなクラウド ソリューションのビジョンを採用しているため、このツールの*オフライン*モードは現在考慮されていません。ただし、いくつかのエクスポート オプションを提供しています。[詳しくはこちら](../../import-and-export/export/03-how-to-export-your-board.md)。

## GPU と WebAssembly の要件

Miro はスムーズなレンダリングや特定の高度な機能をサポートするために、GPU ハードウェア アクセラレーションと WebAssembly（WASM）を使用しています。

### GPU なしで Miro を使用する

最適な性能を得るためには、Miro は GPU ハードウェア アクセラレーションを必要とします。

ハードウェア アクセラレーションが利用できない場合、例えば一部の仮想マシンでハードウェア アクセラレーションが無効化されている場合、Miro は自動的に CPU ベースのレンダラーに切り替わります。

:::tip
Miro を最適に利用するためには、可能な限りハードウェアアクセラレーションを有効にしておいてください。
:::

GPUハードウェアアクセラレーションがない場合、以下のようなパフォーマンスの変化が生じることがあります。

- GPU依存の一部の機能が使用できなくなるか、プレースホルダーとして表示されることがあります。
- 特に大きなボードや多くのメディアが含まれるボードでは、パンやズームの動作が遅くなることがあります。
- コアボードの機能が期待通りに動作しないことがあります。
- CPUの使用率が高くなることがあります。

### WebAssembly (WASM) を使用しない場合の Miro

Miro の一部の機能は WebAssembly (WASM) モジュールに依存しています。

ほとんどの最新ブラウザでは、WASMはデフォルトで有効になっています。企業のポリシーによりブロックされる、ブラウザで無効化されている、または旧環境でサポートされていない場合は、Miroは可能な限りJavaScriptベースのレンダリングパスに自動的に切り替わります。

**詳細情報:** WASMがブラウザでサポートされているかを確認する方法は[こちら](https://help.miro.com/hc/articles/33769132852498)をご覧ください。

:::tip
最適なMiroエクスペリエンスを得るには、WebAssemblyを有効にしてください。管理環境でWASMがブロックされている疑いがある場合は、ITチームに確認してください。
:::

WASMがない場合、次のようなパフォーマンスの変化が発生することがあります:

- WASM を必要とする機能が初期化されず、隠れるかプレースホルダーとして表示されることがあります
- WASM ベースの機能に依存するボードが完全に読み込まれない、または全く読み込まれないことがあります
