Miro にコンテンツを以下のファイル形式でアップロードできます：

| ファイルタイプ | ファイル形式 |
| --- | --- |
| 画像 | **bmp**、**gif**、**svg**（ソリッドイメージとして）、**jpeg**、**jpg**、**png**、**psd**、**heic, heif**、**pdf** |
| 表やスプレッドシート | **xls, xlsx, csv**、**ods** |
| テキストドキュメント | **doc**、**docx**、**odt, rtf** |
| プレゼンテーション | **ppt、pptx、odp** |
| ビデオ | **MP4、MOV、WebM** |

ソースの種類に関わらず、アップロードできる最大ファイルサイズは 30 MB です。最大画像解像度は（ソースに関わらず）32 MP です。画像のサイズ制限は 8192x4096 ピクセルです。

こちらのリンクを確認して、ボードにファイルをアップロードする方法について学びましょう: [ボードへのファイルのアップロード](../../import-and-export/import/05-uploading-files-to-boards.md)、[コンテンツの追加方法](../../working-on-the-board/07-ways-to-add-content.md)。

PDFファイルのアップロードに問題がある場合は、[このトラブルシューティングガイド](../../import-and-export/import/05-uploading-files-to-boards.md)をご覧ください。他のファイル種別でアップロードに問題がある場合は、[こちらのトラブルシューティングの手順](../../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md)をご確認ください。

:::tip
**PDFファイル**を追加する際は、[ページをめくったり、ページごとに表示する](../../working-on-the-board/21-work-smarter-not-harder.md)ことができます。
:::

:::tip
**Google ドキュメント**（スプレッドシート、ドキュメント、スライド）を[Google ドライブのインテグレーション](../../../integrations-apps/google/05-google-drive.md)を使用してインポートし、ボード上で直接編集することができます。
:::

:::tip
**スプレッドシート**をインポートする方法はいくつかあります。[アップロードメニュー](../../import-and-export/import/05-uploading-files-to-boards.md)を使用したり、[付箋](../../essential-tools/14-sticky-notes.md)として、または[Miro のテーブル](../../advanced-tools/05-grid.md)にインポートすることができます。
:::

:::tip
テキストを含む**SVG**画像を扱う場合は、ファイルのビジュアルがコラボレーターのデバイスにインストールされているフォントに依存しないように、必ずテキストを線に変換してください。
:::

## プラン別の動画アップロード

[動画アップロード](../../essential-tools/01-video-upload-and-playback-beta.md)は現在、Business、Educationプランおよびベータ版機能が有効なEnterpriseサブスクリプションで利用可能なベータ版の機能です。

無料プランのメンバーはベータ版の間、動画をアップロードできます。ベータ版が終了した後も、無料のメンバーはベータ版の間にアップロードされた動画を視聴できますが、アップグレードしない限り、新たな動画をアップロードすることはできません。

**詳細情報:** [動画のアップロードと再生（ベータ版）](../../essential-tools/01-video-upload-and-playback-beta.md)をご覧ください。

## よくある質問

Miro は透過 PNG 画像のアップロードをサポートしていますか？

はい、透過画像はボードにインポートすることができます。

Miro のボードではアニメーション GIF はレンダリングされますか？

はい、[GIF](../../working-on-the-board/21-work-smarter-not-harder.md) の詳細をご確認ください。

ZIP 形式のファイルを Miro にアップロードできますか？

いいえ、できません。ファイルを解凍してから Miro にアップロードしてください。ページ上部のサポートされているファイル形式の一覧をご確認ください。

PDF ファイルを Miro のボードに埋め込んだ後でソースの PDF を変更した場合、埋め込まれたバージョンは自動的に更新されますか？

いいえ。アップロードされた、デスクトップまたはクラウドベースの PDF ファイルと Miro 間の接続は一方向です。PDF に変更を加えた場合、再埋め込みが必要となります。

Keynote、Pages、Numbers の各形式を Mac から Miro のボードにインポートすることは可能ですか？

これらの形式は、サポートされているファイルのリストに含まれていません。ただし、対応策として、*ファイル* > *エクスポート先* > *Powerpoint...* をクリックして、ファイルを Powerpoint、Word、Excel 形式でエクスポートしてください。その後、エクスポートしたファイルを Miro にドラッグします。
