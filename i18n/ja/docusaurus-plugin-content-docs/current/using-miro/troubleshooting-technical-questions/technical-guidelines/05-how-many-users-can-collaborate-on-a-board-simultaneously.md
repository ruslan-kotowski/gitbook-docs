Miro はチームワークのために構築されており、多くのユーザーが1つのボードで効果的に共同作業することを可能にします。このセクションでは、多くの参加者とコラボレーションする際に期待できることを説明します。

Miro はコラボレーションを目的としており、同じボード上で複数のユーザーが安定した作業ができるようサポートしています。

PI プランニングとワークショップの 2 つのよくある導入事例は、数百人が参加することもあり、スケールアップしたコラボレーションを実現するために、常にパフォーマンスを最適化しています。

これまで開催した最大のセッションでは、377 人のユーザーの参加がありました。これは少し極端なケースですが、ボードは作動が停止することなく、コラボレーションは成功しました。より一般的なシナリオは、毎週のように見られるもので、**約 200 人のユーザー（編集者 / コメント投稿者）**が同じボードで同時に作業しています。

ユーザー数が増えると、定期的にアプリをテストしていますが、300 人を超えるコラボレーターが参加した場合、ユーザー全員がシームレスに操作できるかどうかは分かりません。

ユーザー数の増加に伴い、ボードの速度が徐々に低下し、ユーザーの操作の集中時は、ある程度の遅延が発生する可能性があることをご考慮ください。古くて性能の低いデバイスを使用している参加者は、早い段階で速度の低下を感じることでしょう。
