この記事では、Miro がサポートするデスクトップおよびモバイルブラウザについての情報を提供しています。

:::note
Miro は、すべての主要ブラウザーのバージョンを少なくとも 12 か月間サポートしており、アクティブで長期サポート版も含まれます。以前のブラウザーバージョンは開発者サポートが終了している可能性があり、Miro の使用に影響を与える場合があります。最適な Miro の使用体験を得るために、少なくとも年に一度ブラウザーを更新してください。
:::

Miro が公式にサポートしているブラウザーは以下の通りです：

- **デスクトップ**
  - Chrome
  - MS Edge
  - Firefox
  - Opera
  - Yandex Browser
- **モバイル**
  - Chrome
  - Safari
  - Samsung Internet

:::note
モバイルブラウザでアクセスするボードは閲覧のみ可能です。割り当てられた権限でアクセスするためには、[Miro モバイルアプリ](../../../getting-started/apps-for-devices/08-mobile-app.md)をダウンロードしてください。
:::

:::warning
Internet Explorer はサポートされていません。
:::

## Safari でのボード読み込みの問題

Safari v. 15.2、OS Monterey でボードのフリーズまたは読み込みの問題が発生した場合は、以下の手順に従ってください（「*問題が起きたため、このウェブページを再度読み込みました*」あるいは「*このウェブページともう 1 つのページを開けません*」というエラーメッセージが表示されることもあります）。

1. Safari > 環境設定 > **［開発］** > **［試験的機能］**を選択します。
2. **オフ**にするのは**［GPU プロセス: キャンバスレンダリング］**機能です。

   ![](/attachments/token/45hImX8u1weQZnUaPOXtAT971/?name=inline1581405683.png)

   > ✏️ ​「**開発**」メニューがメニューバーに表示されていない場合は、[メニューバー](https://support.apple.com/en-gb/guide/safari/aside/glos33eb8abd/15.1/mac/12.0)からSafari > 環境設定に移動し、**［詳細］**をクリックして、**メニューバーに開発メニューを表示**を選択してください。
