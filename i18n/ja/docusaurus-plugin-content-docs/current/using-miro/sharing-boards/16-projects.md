プロジェクトとは、チーム内にあるボードを集めたものです。プロジェクトは、ボードの整理、検索、共有を容易にしてくれます。

> 🚀 プロジェクト テンプレートを [Miroverse](https://miro.com/miroverse/submission/?backToUrl=/) に公開し、6000 万人以上のユーザーに発想を与えましょう。

*Miro のチーム、プロジェクト、ボード*

> **利用可能なプラン：**Starter、Education、Business、Enterprise

## プロジェクトの見つけ方

プロジェクトはすべて、ダッシュボードの左側のナビゲーションに、アルファベット順に表示されます。プロジェクト名をクリックすると、プロジェクトの設定が開き、詳細情報や参加者を確認することができます。

### プロジェクトの設定

1. 左側のサイドバーで、**[プロジェクト]** に移動します
2. プロジェクト名をクリックします
3. プロジェクトのダッシュボードの上部のプロジェクト名をもう一度クリックします
4. プロジェクトの設定が開きます

![Miro_projects_greybg.gif](https://help.miro.com/hc/article_attachments/21019535551762)
*Miro でプロジェクトを開いて詳細を表示*

## 重要なプロジェクトにスターを付ける方法

進行中または多用するプロジェクトにスターを付けると、アクセスが容易になります。初めてプロジェクトのスターをクリックすると、左サイドバーに新しい**スター付きプロジェクト**のセクションが表示されます。**スター付きプロジェクト**を展開したり、折りたたんだりすることで、ダッシュボードを管理できます。

プロジェクトにスターを付けるには、プロジェクト名の横にある**スター**アイコンをクリックします。

![starred_projects_greybg.gif](https://help.miro.com/hc/article_attachments/21019591632530)
*プロジェクトにスターを付ける*

## プロジェクトの作成方法

1. 左側のサイドバーで、**[プロジェクト]** に移動します
2. **追加** (![icon-zoom-in.svg](https://help.miro.com/hc/article_attachments/22638200619538)) ボタンをクリックします。
3. プロジェクトのダイアログが開きます
4. **プロジェクト名**を入力します
5. **[プロジェクト****を作成]** をクリックします
6. その後、ボードを追加したり、メンバーを追加したりすることができます

![create_a_project_greybg.gif](https://help.miro.com/hc/article_attachments/21019591641362)
*新規プロジェクトの作成*

## プロジェクトにボードを追加する方法

1. [[プロジェクト設定]](#h_01HKWFH7ZW3HJQEX7ZXKJME0W4) を開きます。
2. **[ボードを追加]** をクリックします
3. スクロールまたは検索して、プロジェクトに追加するボードを見つけて選択します
4. **[ボードを移動]** をクリックします

![Add boards to a project.pngプロジェクト設定でプロジェクトにボードを追加するオプション](https://help.miro.com/hc/article_attachments/21019535536274)

## プロジェクトの共有

### チームメンバーとのプロジェクトの共有

> **実行可能なユーザー：**プロジェクト所有者、共同所有者、編集者

チームメンバーとプロジェクトを共有するには、メンバーをプロジェクトに追加してください。共同作業のレベルに応じて、 [閲覧可、コメント投稿可、編集可](../../getting-started/start-here/05-roles-in-miro.md)にアクセス権を設定できます。選択したアクセス権が、プロジェクト内のすべてのボードに適用されます。

### チーム全体でのプロジェクトの共有

> **実行可能なユーザー：**プロジェクト所有者、プロジェクト共同所有者

1. [[プロジェクト設定]](#h_01H1Y9F4DH6CBDETX2FQ032PT0) を開きます。
2. **[チーム全員がプロジェクト内のボードを閲覧可能]** トグルをオンにします

:::note
チームの管理者は、新しく作成されたプロジェクトに対して[デフォルトの共有設定](11-default-sharing-settings.md)を行うことができます。
:::

![share project with the team.png](https://help.miro.com/hc/article_attachments/21019591613714)
*プロジェクトをチーム全員で共有*

### プロジェクト内でボードを共有する

プロジェクトメンバーのアクセスレベルは、ボードの**共有**ダイアログから変更できます。 例えば、コメント権限があるプロジェクトメンバーを、プロジェクト内の特定のボードに編集者として招待することができます。 プロジェクトを共有する場合でも、プロジェクト内でボードを共有する場合でも、**一番高いレベルのアクセス権が常に適用**されます。

ボードの[ビジター](08-collaboration-with-visitors.md)または[ゲスト](07-collaboration-with-guests.md)として招待すれば、チームやプロジェクト外のユーザーとボードを共有をすることもできます。

### 非公開プロジェクト

Miro 上でプロジェクトを非公開にすることを確実にするには、メンバーを追加せず、チームのアクセス権がオフになっていることを確認し、プロジェクト内のすべてのボードに対して、チームと会社の共有設定を **[アクセス不可]** に変更してください。

プロジェクトを共有する場合でも、プロジェクト内でボードを共有する場合でも、**一番高いレベルのアクセス権が常に適用**されます。以下はその一例です。

- ボードが非公開プロジェクトにあっても、チーム全体で共有されている場合は、すべてのチームメンバーがそのボードにアクセスできます
- ボードが明らかに誰とも共有されていなくても、チームで共有しているプロジェクトに保存されている場合は、すべてのチームメンバーがそのボードにアクセスできます

[公開ボードと非公開ボード](12-public-boards-vs.-private-boards.md)で詳細をご覧ください。

## プロジェクトメンバーの追加と管理

:::note
プロジェクトメンバーとして招待できるのは、チームメンバーのみです。
:::

プロジェクトメンバーは以下の操作が可能です。

- プロジェクト内のすべてのボード（既存のボード、追加または作成された新しいボードを含む）にアクセスする
- プロジェクト内に新しいボードを作成する
- プロジェクトに既存のボードを追加する
- プロジェクト内の全ボードのすべての変更についての通知を受ける

### プロジェクトにメンバーを追加する方法

> **実行可能なユーザー：**プロジェクト所有者、共同所有者、編集者

1. プロジェクト設定を開きます
2. **[メンバーを追加]** をクリックします
3. スクロールまたは検索して、追加するチームメンバーを見つけて選択します
4. メンバーがプロジェクトに追加されたら、**[メンバーに通知する]** 選択ができます
5. **[追加]** をクリックします。

![Adding members to a project.png](https://help.miro.com/hc/article_attachments/21019535540882)
*プロジェクトにメンバーを追加*

### ユーザーのアクセスレベルを変更する方法

1. プロジェクト設定を開きます
2. ユーザー名の横にあるアクセスレベルのドロップダウンを開きます
3. アクセスレベルを選択します（**共同所有者**、**編集可**、**コメント可**、**閲覧可**）

![Change a project member to project owner.png](https://help.miro.com/hc/article_attachments/21019591620370)
*プロジェクトに対するユーザーのアクセスレベルの変更*

### プロジェクトメンバーを削除する方法

:::warning
プロジェクトメンバーを削除しても、[招待メール](03-sharing-boards-and-inviting-collaborators.md)または[チーム、会社、公開リンクアクセス](03-sharing-boards-and-inviting-collaborators.md)からプロジェクトにアクセスできる場合があります。
:::

1. プロジェクト設定を開きます
2. ユーザー名の横にあるアクセスレベルのドロップダウンを開きます
3. **[削除]** を選択します

![](https://help.miro.com/hc/article_attachments/21019591621650)
*altRemove a project member.pngプロジェクトからユーザーを削除*

### プロジェクトの所有者を変更する方法

> **実行可能なユーザー：**プロジェクト所有者、共同所有者

:::note
プロジェクトの所有権を別のユーザーに譲渡しても、プロジェクト内の個々のボードの所有者は変更されません。
:::

1. プロジェクト設定を開きます
2. ユーザー名の横にあるアクセスレベルのドロップダウンを開きます
3. **[所有者]** を選択します

![](https://help.miro.com/hc/article_attachments/21019591620370)
*altChange a project member to project owner.pngプロジェクト所有者のアクセス権付与*

## プロジェクトにボードを移動する方法

> **実行可能なユーザー：**プロジェクトの所有者、共同所有者、編集者

:::note
プロジェクトにボードを移しても、ボードのリンクは変更されません。
:::

**ボード情報カードから：**

1. 左上のボードヘッダーで、ボード名をクリックします。
2. ボード情報カードが開きます
3. **「場所」**の隣で、**プロジェクト名**（または **[プロジェクトなし]**）をクリックします
4. ドロップダウンから、ボードを移動するプロジェクトを選択します
5. **[移動]** をクリックします

*![adding_a_board_to_a_project_greybg.gif](https://help.miro.com/hc/article_attachments/21019591636242)**ボード情報カードからプロジェクトへボードを移動*

**ダッシュボードから：**

1. 移動したいボードにカーソルを合わせます
2. 三点リーダー（**...**）をクリックして、ボードメニューを開きます
3. **[別プロジェクトに移動]** を選択します
4. ドロップダウンから、ボードを移動するプロジェクトを選択します
5. **[移動]** をクリックします

![move to project from dashboard.png](https://help.miro.com/hc/article_attachments/21019535548050)
*ボード情報カードからプロジェクトへボードを移動*

1. 左側のサイドバーで、**[プロジェクト]** に移動します
2. プロジェクト名をクリックします
3. プロジェクトのダッシュボード内で、**[+ 新しいボード]** をクリックします

## プロジェクトからボードを削除する方法

1. 左上のボードヘッダーで、ボード名をクリックします
2. ボード情報カードが開きます
3. **「場所」**の隣にあるプロジェクト名をクリックします
4. プロジェクトのドロップダウンから**、**[なし] を選択します

*![Removing_a_board_from_a_project_greybg.gif](https://help.miro.com/hc/article_attachments/21019535572754)**プロジェクトからボードを削除*

## プロジェクトを退出または削除する方法

> **実行可能なユーザー：**プロジェクト所有者

:::note
プロジェクトを削除しても、そのプロジェクト内のボードは削除されません。
:::

1. プロジェクト設定を開きます
2. **[プロジェクトを削除]** を選択します

プロジェクトの*所有者以外*のすべてのプロジェクトメンバーには、[プロジェクトを退出する] というオプションが表示されます。プロジェクトがチームのユーザー全員と共有/strong>されている場合、プロジェクトを退出する、または削除するオプションは表示されません。

プロジェクトを退出または削除しても、ユーザーは[メール](03-sharing-boards-and-inviting-collaborators.md)または[チームのアクセス権](03-sharing-boards-and-inviting-collaborators.md)で共有されたプロジェクト内のボードにアクセスすることができます。

![](https://help.miro.com/hc/article_attachments/21019535546514)
*altdelete a project.pngプロジェクトの削除*

## プロジェクトを複製する方法

プロジェクトを複製することはできませんが、プロジェクト内に[ボードを複製](../managing-boards/03-how-to-duplicate-a-board.md)してから、新しいプロジェクトを作成し、ボードのコピーを新しいプロジェクトに移動させることができます。

:::warning
Free プランにダウングレードした場合、新しいプロジェクトを作成することや、既存のプロジェクトを編集または削除することはできません。
:::

## よくある質問

**どのようにプロジェクトを整理できますか？**

現在、プロジェクトのアーカイブへの保管、プロジェクトへのリンクの作成、プロジェクト内でのプロジェクトの作成、プロジェクトやボードの順序の変更を行うオプションはサポートされていません。ただし、スター付きプロジェクトを使用して、現在および進行中のプロジェクトの整理に対処していただくことをお勧めしています。
