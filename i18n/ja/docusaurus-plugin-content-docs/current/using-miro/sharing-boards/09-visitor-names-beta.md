Miro の公開ボードでユーザーを招待し、実際の名前を指定できるオプションを有効にします。登録されていない訪問者を特定しコラボレーションする、最も迅速かつ簡単な方法です。

[ビジターを招待する方法](08-collaboration-with-visitors.md)をご覧ください。

> **利用可能なプラン：*教育、ビジネス、Enterpriseプラン***

### 訪問者名を有効化する方法

> **設定者：**ボード所有者

> **✏️** この機能は、対応しているアプリに埋め込まれたボードや埋め込みコード（iFrame）による埋め込みを含め、[Miro の埋め込みボード](../import-and-export/export/02-embed-a-miro-board.md)ではご利用いただけません。

ボードの**共有**ダイアログを開き、**共有設定に**切り替えます。**ボードが公開されている場合、[訪問者名を追加する]** ドロップダウンで、**[訪問者] を選択して名前を追加することができます**。

![visitor names.gif](../../../../../../docs/using-miro/sharing-boards/images/21017348753298_visitor%20names.gif)
訪問者名を追加するオプションを有効化

### 訪問者が自分の名前を追加する方法

公開編集用に共有されたボードに対して名前を追加するオプションが有効になっている場合、公開ボードを開く未登録ユーザーは、ボードに入る前に自己紹介することができます。空欄のままだと、ボードの匿名ユーザーとなり、、ランダムに名前が生成されます（例：訪問中の発明者

![Screenshot background template  5 (1).jpg](images/30446995482898_Screenshot%20background%20template%20%205%20(1).jpg)
ボード設定でオプションが有効になっている場合、未登録ユーザーは公開ボードに入力する前に名前を入力することができます

コラボレーターの名前は、カーソルの横と、ボードの右上にあるコミュニケーションツールバーに表示されます。

![Screenshot background template  5 (2).jpg](images/30447026242578_Screenshot%20background%20template%20%205%20(2).jpg)
ボード上の訪問者名

訪問者名を追加するオプションが無効になっている場合、すべての未登録ユーザーはボードで生成された名前を取得します。**ログイン**したユーザーは、実名でボードに表示されます。
