Miro ユーザーは、ボードをコラボレーターと共有し、いつでもアクセスを制限することができます。

### ボードの共有設定を確認する方法

ボードにアクセスできる人を確認するには、ボード**共有**ダイアログを開きます。ダッシュボードから、またはボード内から実施することができます。

share_from_the_dashboard.jpeg
*ダッシュボードからボード共有ダイアログを開く*

share_menu.jpg
ボードの右上にある [共有] ボタン

ボードは、さまざまなレベルで共有できます。

- [チーム](03-sharing-boards-and-inviting-collaborators.md)（チームの誰でも閲覧/コメント/編集可能）
- [会社](03-sharing-boards-and-inviting-collaborators.md)（メンバーは全員リンクによりボードにアクセスできます。Enterprise プランでのみ利用できます）
- [公開](03-sharing-boards-and-inviting-collaborators.md)（ボードのリンクを知っているユーザーなら誰でも[ビジター](08-collaboration-with-visitors.md)として閲覧 / コメント / 編集可能）
- [スペース](../spaces/01-spaces.md)（スペース内の役割に応じて、すべてのスペース参加者が閲覧/コメント投稿/編集可能）
- ボード（[メールで](03-sharing-boards-and-inviting-collaborators.md)ボードに招待された特定のユーザー）

**[共有設定]** をクリックして、メールでボードに招待されたユーザーのメールを表示します。以下の例では、**自分のチーム**のメンバー全員がボードに[コメント](01-board-access-rights.md)でき、**Jane** は[編集](01-board-access-rights.md)できるようになります。

who_has_access_to_the_board.gif
共有設定にはボードに招待されたユーザーのメールが表示される

ボードは、同時にさまざまなレベルで共有することができます。ユーザーには**より高いアクセス権**を持つレベルが適用されます。以下の例をご覧ください。

- メールでチームメンバーを**コメント投稿者**としてボードに招待*し*、チームの誰でもボードを**編集できる**場合、チームレベルでのアクセス権がユーザーに適用され、ユーザーはボードを**編集できます**
- 編集アクセスがある状態でボードが公開共有されている場合（リンクを知っているユーザーなら誰でも**編集可能**)、ボード上のすべてのユーザーは、コンテンツを変更できます

:::tip
[プライベートボードの作り方を学びましょう](15-make-a-miro-board-private.md)。
:::

### ボード共有設定を変更できるユーザー

ボード所有者、[共同所有者](06-co-owners-of-boards-and-spaces.md)、ボードが保存されているチームのメンバーである編集者は、ボードへのアクセスを共有および制限することができます。有料プランのボード所有者と[共同所有者は](06-co-owners-of-boards-and-spaces.md)、[共有アクセス権限を設定](02-who-can-share-a-miro-board.md)し、編集者のオプションを撤回して、ボードへのアクセスを変更し、他のユーザーを招待できます。

### Free プランでのボードアクセス

[無料チーム](../../plans-billing/miro-plans/09-free-plan.md)に保存されたボードには、チームメンバー全員がアクセスできるのでご注意ください。非公開ボードを作成するには、チームをアップグレードしてください。
