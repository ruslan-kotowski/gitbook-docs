コンサルタント、クライアント、同僚と一緒にプロジェクトに取り組んでいる場合など、外部のユーザーをチームのフルメンバーにせず、ボードに招待したい場合もあります。

すべてのユーザーには、公開ボードのリンクを使用して、**ビジター**とボードを共有するオプションがあります。有料プランのユーザーには、**ゲスト**とボードを共有するオプションもあります。ビジターとゲストでは、ボード上のセキュリティーと、個々のユーザーに提供できるアクセスレベルが異なります。

Miro では、以下のように招待することを推奨しています。

- 1 回限りコラボレーションして作業する場合はビジター
- クライアントやパートナーと時折コラボレーションする場合はゲスト
- 頻繁かつ継続的にコラボレーションする場合はフルチームメンバー

### プランに基づく外部共有オプション

|  |  |  |  |
| --- | --- | --- | --- |
|  | **Free** | **Starter、Education** | **Business、Enterprise** |
| **ビジター**  **（公開リンク）** | ✔  閲覧のみ | ✔  閲覧、コメント、編集 | ✔  閲覧、コメント、編集 |
| **ゲスト** | ✘ | ✔  閲覧、コメントのみ | ✔  閲覧、コメント、編集 |

## ビジターとのコラボレーション

ビジターとコラボレーションするには、ボードを公開する必要があります。

アクセスレベルとプランのタイプに応じて、ビジターは閲覧、コメント、編集することができます。ビジターは、Miro に登録する必要はなく、ユーザーは無料でビジターをボードに招待することができます。[ビジターについての詳細](08-collaboration-with-visitors.md)

:::warning
Miro は、公開ボードが Google や Bing のような検索エンジンにインデックスされないよう努めています。しかし、こうしたボードは、リンクがあれば誰でも開くことができ、意図しないユーザーにもリンクが共有される可能性があります。Miro のプランによっては、[公開ボードにパスワード](13-password-protection-for-public-boards.md)を設定することでセキュリティーを強化することができます。
:::

Free Starter、Business、Enterprise、Education

1. ダッシュボードに移動し、ボードカードにカーソルを合わせます
2. 右上にある三点リーダーをクリックします
3. **[共有する]** をクリックします
4. アクセスタイプを **[リンクを知る全員が]** に設定します
5. **[閲覧可]** を選択します（有料プランおよび Education プランのビジターのみ、編集とコメント投稿が利用できます）
6. **[ボードのリンクをコピー]** をクリックし、招待するユーザーと直接共有します

## ゲストとのコラボレーション

ゲストとのコラボレーションにより、ボードのセキュリティーレベルが追加されます。ゲストやチームメンバーとして招待されたユーザーのみが、ボードを閲覧することができます。

ゲストは、Miro にログインする必要があります。Miro の有料プランの多くの機能を利用でき、ダッシュボードで共有ボードにも引き続きアクセスすることができます。ゲストの追加は無料で、追加できるゲストの人数に制限はありません。

チームの設定で[ゲストを有効化](07-collaboration-with-guests.md)することを忘れないでください。

ゲストとのコラボレーションの詳細については、[こちら](07-collaboration-with-guests.md)をご覧ください。

Business、Enterprise Starter、Education

1. ダッシュボードに移動し、ボードカードにカーソルを合わせます
2. 右上にある三点リーダーをクリックします
3. [共有する] **をクリックします**
4. メールアドレスを入力します
5. 付与するアクセスレベルに応じて、**[閲覧可]、[コメント可]、[編集可]** を選択します
6. **[招待を送信]** をクリックします
7. **[編集可]** を選択した場合、チームメンバーやゲストとして追加するオプションのポップアップも表示されます。**ゲスト**を選択します

ゲストが共有ボードにアクセスするには、Miro にログインする必要があります。こうすることで、ダッシュボードには追加したボードだけが表示されます。

ボードの外部共有の停止

ゲストやビジターとのボードの共有をいつでも停止することができます。

### ビジターとの共有を停止する方法

ビジターとのボードの共有を停止するには、次のようにボードへの公開アクセスを削除する必要があります。

1. ボード右上にある **[共有]** をクリックします
2. ドロップダウンから、**[リンクを知る全員]** の隣にある **[アクセス不可]** を選択します

![4 Share button (6).gif](images/21301205913362_4%20Share%20button%20(6)
*.gif)ビジターアクセスの削除*

### ゲストとの共有を停止する方法

1. ボード右上にある **[共有]** をクリックします
2. **[共有設定]** に移動します
3. ゲストの隣にあるドロップダウン メニューをクリックします
4. **[削除]** を選択してボードへのユーザーアクセスを削除します

> **⚠️**  **ユーザーのアクセスレベルを変更しても、ボードが公開されている場合、またはチーム、スペース、会社の一部として共有されている場合、** **使用権を保持する**可能性があります。
