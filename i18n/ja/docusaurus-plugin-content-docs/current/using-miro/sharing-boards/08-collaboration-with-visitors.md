簡単かつ即座にコラボレーションできるように、ボードにビジターを招待します。<span>ビジターは無料で招待でき、Miro に登録する必要はありません。

> **利用可能な環境：**ブラウザー、デスクトップアプリ、タブレットアプリ

## ビジターとのコラボレーション

ビジターとコラボレーションするには、ボードを公開する必要があります。 ビジターは、設定したアクセスレベルとプランの種類に応じて、閲覧、コメント、編集を行うことができます。

:::warning
Miro は、公開ボードが Google や Bing のような検索エンジンにインデックスされないよう努めています。しかし、こうしたボードは、リンクがあれば誰でもアクセスでき、そのリンクが意図しない相手にまで共有される可能性があります。Miro のプランによっては、[公開ボードにパスワード](13-password-protection-for-public-boards.md)を設定することでセキュリティーを強化することができます。
:::

## ビジターのアクセス権を有効にする方法

ビジターは、ボードが公開されていれば、アクセスできます。

:::tip
ビジターのために最高の体験を生み出すには、ボードに[開始画面](03-sharing-boards-and-inviting-collaborators.md)を設定します。</span>[特定のフレームを非表示にする](../essential-tools/07-frames.md)こともできます。ボードにビジターに関係のない内容がある場合に有効です。
:::

Starter、Business、Enterprise、Education の各プラン Free プラン

1. ダッシュボードに移動し、ボードカードにカーソルを合わせます
2. 右上にある三点リーダーをクリックします
3. [**共有**] をクリックします
4. 「**リンクを知る全員**」の横にある **閲覧可**、**コメント可**、<strong>編集可</strong> のいずれかを選択します。</span>[パスワードでボードを保護する](13-password-protection-for-public-boards.md)こともできます。
5. 「**ボードのリンクをコピー**」をクリックして、直接ユーザーと共有します
   > **✏️** Enterprise の管理者が[一般公開を制限](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md)している場合、ビジターとボードを共有できないことがあります。この共有オプションが利用できない場合は、管理者にお問い合わせください。

   ![5-1-720p-10fps-s4-r20.gif](../../../../../../docs/using-miro/sharing-boards/images/20257484329874_5-1-720p-10fps-s4-r20.gif)
   *ビジター用の編集権限付きで公開ボードを共有*
   > ⚠️ **[編集可]** を許可すると、閲覧者やコメント投稿者として既に追加したユーザーとともに、今後のすべてのユーザーにも編集が許可されます。[ボード共有の仕組みはこちらをご覧ください。](05-who-has-access-to-my-board.md)

   > ✏️ Enterprise プランの会社の管理者は、Enterprise サブスクリプションのすべてのボードに必須パスワードを設定し、公開リンクの有効期限を有効にすることができます。[パスワードの設定](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md)と[公開リンクの有効期限](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md)</span>

Free プランでは、ビジターの機能が制限されます。

1. ダッシュボードに移動し、ボードカードにカーソルを合わせます
2. 右上にある三点リーダーをクリックします
3. **共有**をクリック
4. 「**リンクを知る全員が**」の横にある**閲覧可**を選択します（ビジター向けの編集とコメント権限は有料プランと Education プランのみ）。
5. **ボードのリンクをコピー**をクリックし、直接ユーザーと共有します。

### ビジターから見た公開ボードの機能

#### ビジターが使用できるツール

ボードへのアクセスレベル（[閲覧、コメント](01-board-access-rights.md)、または編集）に応じて、ビジターには、[図形](../essential-tools/11-shapes.md)、[線](../essential-tools/05-connection-lines.md)、[テキスト](../essential-tools/16-text.md)、[付箋](../essential-tools/14-sticky-notes.md)、および[ペンツール](../essential-tools/10-pen.md)が[作成ツールバー](../../getting-started/start-here/your-first-board/05-toolbars.md)に表示されます。

ビジターが Miro のアカウントを作成すると、作成ツールバーに完全にアクセスできるようになります。

![Public link expiration for end users (1)-1.png](images/21017725276306_Public%20link%20expiration%20for%20end%20users%20(1)
*-1.png)公開 Miro ボードのビジター側画面*

#### パスワード保護されたボード

ボードの所有者または共同所有者が[パスワード保護](13-password-protection-for-public-boards.md)を追加した場合、ビジターは、ボードを開く前にパスワードを入力する必要があります。

**公開リンクの有効期限**</span>
共有ウィンドウに時計のアイコンが表示されている場合、[公開リンクの有効期限](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md)が会社の管理者によって有効になっていることを意味します。</span>ビジターと共有された公開リンクは、ボードが設定された時間内に開かれなかった場合、自動的に有効期限切れとなります。ボードにアクセスできなくなった場合は、リンクの有効期限が切れてしまった可能性があります。ボード所有者に連絡をして、再度リンクを共有するように依頼してください。

![5-1.png](../../../../../../docs/using-miro/sharing-boards/images/20235568692370_5-1.png)
*共有設定内の公開リンク有効期限アイコン*

### ビジターに名前の追加を招待

ログインした登録ユーザーは、ボードに実名で表示されますが、編集権限を持つビジターは自動的に名前が割り当てられます（例：*訪問中の発明者*）。

ビジターとのコラボレーションを促すために、一部のボード所有者および共同所有者は、[未登録ユーザーがボードに参加する際に名前を追加できるようにすることができます](09-visitor-names-beta.md)。

## 編集権限を持つビジター

> **利用可能なプラン：**有料プランおよび Education プラン

パートナーや同僚と一緒に作業をする際に、Miro のプロフィールを持っていない、または Miro チームにアクセスできない人々を招待するには、[編集権限](01-board-access-rights.md)を持つビジターを招待してください。

### 編集権限を持つビジターが公開ボードでできること

ビジターは、チームメンバーやゲストよりも、利用できる Miro の機能が制限されています。これは、ボード所有者としてボードを完全に制御できる状態を維持するためです。

編集権限を持つビジターは、[作成ツールバー](../../getting-started/start-here/your-first-board/05-toolbars.md)から、[図形](../essential-tools/11-shapes.md)、[線](../essential-tools/05-connection-lines.md)、[テキスト](../essential-tools/16-text.md)、[付箋](../essential-tools/14-sticky-notes.md)を追加し、[ペンツール](../essential-tools/10-pen.md)を使用することができます。

> 未登録のビジターは、登録ユーザーよりも利用できるツールが制限されています。

#### 編集権限を持つビジターが利用*できない*機能とツール

- ボード名の変更
- ボードの共有設定の変更
- チームダッシュボードへのアクセス
- 他のボードへのアクセス
- コメントで他ユーザーをメンション
- ビデオチャット、投票セッション、画面共有の開始
- カードピッカーから Asana、Jira、Microsoft Azure、Rally カードを作成、編集、または追加すること（ただし、閲覧は可能です）。
- ボードバックアップのダウンロード
- ボード上のオブジェクトのロック/ロック解除、ロックされたオブジェクトは編集不可
- ボード通知の受け取り
- アクティビティ リストへのアクセスとボードコンテンツの復元
- ボードリンクの Google ドライブへの保存
- オブジェクト情報の閲覧
- モバイルデバイスのブラウザーでボードを編集する
- ボードコンテンツ設定で許可されていない場合の、ボードのコンテンツのコピー
- ボードの複製またはエクスポート（Miro に登録されていない場合、あるいはボードコンテンツ設定で許可されていない場合）
- コラボレーターを画面に呼ぶ
- Miro ボードへのコンテンツのアップロード

:::note
Starter、Business、Enterprise、Education プランのボード所有者は、[ボードコンテンツの設定](14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)を行い、ビジターに[チームへのボードの複製](../managing-boards/03-how-to-duplicate-a-board.md)、ボードに貼り付けられたファイル/画像/PDFのダウンロード、ウィジェットのコピー、[画像/PDF形式でのボードのエクスポート](../import-and-export/export/03-how-to-export-your-board.md)を許可するかどうかを定義することができます。
:::

## よくある質問

*自分のボードの [共有] メニューに、[リンクを知る全員が] のオプションがないのはなぜですか？*

Enterpriseプランでは、セキュリティー上の理由により、[会社の管理者](../../plans-billing/miro-plans/04-enterprise-plan.md)が[公開共有を制限](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md)することができます。</span>
一般編集を許可した共有は、[無料チーム](../../plans-billing/miro-plans/09-free-plan.md)に保存されているボードではサポートされていません。
ブラウザーで有効にしている広告ブロック拡張機能によって問題が起こる場合もあります。アドブロックを無効にして、すべての共有オプションが表示されるか確認してください。

*共有したリンクでビジターがボードにアクセスできないのはなぜですか？*

必ず **編集可、コメント可、閲覧可**を選択し、**リンクを知る全員**オプションの隣に設定し、ボードの [共有] メニューまたはブラウザーのアドレスバーからコピーしたボードのリンクを送信したことを確認してください。リンクは次のような形式になります:</span>

```
https://miro.com/app/board/o9L_kSnC_0=/
```

問題が解決しない場合は、別のブラウザーまたはシークレットモードでボードを開くようにユーザーに依頼してください。

*ビジターには招待メールが届きますか？*

いいえ、ビジターは、メールで明示的に公開ボードに招待されることはありません。ボードを公開設定にしたあと、ボードのリンクをコピーして相手に送信すると、ビジターとしてアクセスできます。ボードの公開設定をやめない限り、ボードのリンクを知る全員が、編集、コメント、または内容の閲覧ができます。

*ボードを公開して共有すると、新しいボードのリンクが生成されますか？*

いいえ、ボードを公開しても、リンクは変わりません。

*ビジターとボードを共有するのを停止するにはどうしたらいいですか？*

ボードの共有メニューを開き、**アクセス不可**を**リンクを知る全員**オプションの隣で選択します。

*同時にボードにアクセスできるビジター数は何人ですか？*

無料で何人でもビジターをボードに招待できます。

より多くのユーザーと同時に効果的に協力できるように、Miro は常に最適化を続けています。過去最大のセッションの詳細については、[こちら](../troubleshooting-technical-questions/technical-guidelines/05-how-many-users-can-collaborate-on-a-board-simultaneously.md)<span style="font-weight: 400;">をご覧ください。

*編集権限を持つビジターとしてボードに参加できるように、ユーザーにリンクを送信しましたが、登録しなければならず、チームメンバーになってしまいました。なぜでしょうか？*

ビジター向けの公開リンクを有効化せずに、[ボードとチームへの招待リンク](03-sharing-boards-and-inviting-collaborators.md)を送信してしまった可能性があります。

ユーザーと誤って追加したライセンスを削除する方法について詳しくは、[こちら](../../administration/user-management/04-manage-extra-licenses.md)をご覧ください。

*ビジターの作成ツールバーが変更されたのはなぜですか？*

ほとんどのビジターは、少数のツールしか使っていないため、シンプルにすることにしました。Miro のアカウントに登録することで、[全ての作成ツールバー](../../getting-started/start-here/your-first-board/05-toolbars.md)を利用できます。
