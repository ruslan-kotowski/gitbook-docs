Miroプロフィールの設定から、名前と写真を管理し、個人設定を行えます。[このリンク](https://miro.com/app/settings/user-profile)をクリックするか、[ダッシュボード](https://miro.com/app/dashboard/)から設定にアクセスしてください。右上のプロフィールアイコンをクリックし、**[設定]** を選択します。

profile_settings__Miro.jpg
Miro のダッシュボードからプロフィール設定へアクセス

プロフィール設定から、次のことができます。

- 氏名、会社名、業種、役割、写真の変更
- クッキーを管理 する
- [メールアドレスの変更](04-how-to-change-your-email.md)
- [パスワードの変更](05-how-to-change-your-password.md)
- [通知設定](02-miro-notifications.md)
- [他のサービスへの Miro 接続](../../integrations-apps)を管理
- [カスタムアプリの作成](https://developers.miro.com/docs/getting-started)
- [プロフィールの削除](07-how-to-delete-your-profile.md)
