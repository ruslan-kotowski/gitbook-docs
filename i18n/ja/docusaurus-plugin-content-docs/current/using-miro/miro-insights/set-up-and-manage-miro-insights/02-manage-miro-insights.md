このガイドは、Miro Insights の一般設定、チーム管理、通知、および API アクセスを含む継続的な管理タスクをカバーしています。これは、初期セットアップが完了した後に Miro Insights を管理する必要がある会社の管理者向けです。

まだ Miro Insights を設定していない場合は、[Miro Insights のセットアップ（管理者）](../../miro-insights/set-up-and-manage-miro-insights/01-set-up-miro-insights.md)ガイドから始めてください。

## 前提条件

Miro Insights の管理を行うには、以下が必要です:

- **会社の管理者**の役割を Miro で持っています。
- **Miro Insights がすでに組織に設定されていること**。

## 会社のプロフィール

このセクションでは、Miro Insightsに表示される会社情報を更新できます。

- **名前**: 会社の名称。
- **許可されたメールドメイン**: Miro Insightsにアクセスできるメールドメイン。
- **会社ロゴ**: 会社のロゴをアップロードまたは変更します。

## チーム

このセクションには、Miro Insightsチームに関連する設定が含まれています。管理者として、ユーザーを招待、追加または削除し、彼らの役割を管理できます。

## 通知

このセクションでは、新しいフィードバックやAIの提案、その他の重要なイベントに関する通知を、いつどのように受信するかを設定できます。

Slack などの通知方法を設定できます。通知の種類は、機能やフィードバックなどのカテゴリごとに設定可能です。

## インテグレーションと自動フロー

このセクションでは、接続されたすべてのインテグレーションと自動フローを管理できます。各インテグレーションのステータスを確認し、必要に応じて再接続したり、インポート設定を調整したりできます。

詳細な設定手順については、[Miro Insights 設定（管理者向け）](../../miro-insights/set-up-and-manage-miro-insights/01-set-up-miro-insights.md)ガイドをご覧ください。

## API キー

ここでは、Miro Insights データへのプログラムによるアクセス用の API キーを生成および管理できます。新しいキーを作成し、古いキーや危険にさらされたキーを無効化することができます。

:::warning
API キーを作成する際は、わかりやすい名前を付けて安全な場所にコピーしてください。このページを離れた後では再度確認できません。
:::

## 次のステップ

これらの管理設定を構成したら、Miro Insights のインスタンスはチームにとって円滑に稼働するはずです。継続的な使用ガイダンスについては、[Miro Insights の使用方法](../../miro-insights/use-miro-insights)ガイドをご覧ください。
