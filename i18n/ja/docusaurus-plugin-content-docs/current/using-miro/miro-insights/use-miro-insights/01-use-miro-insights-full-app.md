Miro Insights は、AI を活用した製品管理ツールで、顧客のフィードバックを分析し、機能を優先し、データに基づいた製品の意思決定を支援します。このプラットフォームは、既存の技術スタックとインテグレーションし、インターフェース全体でマゼンタでハイライトされたインテリジェントな提案を提供します。

## Miro Insights にアクセスする方法

Miro Insights へのアクセス方法は主に2つあります。

- 任意の Miro ボードから。
- Miro ダッシュボードからフルウェブアプリを体験する。

### Miro ボードから開く

Miro Insights に直接アクセスするには、どの Miro ボードでも便利なサイドパネルとして利用できます。このクイックアクセスにより、ワークスペースを離れることなくアイテムを選択してボードに直接カードとして追加できます。

キャンバス上で Miro Insights を使用することに関しては、さらに詳しくは[キャンバス上で Insights を使用する](../../tools/use-miro-insights/02-use-miro-insights-on-the-canvas.md)をご覧ください。

### Miro ダッシュボードから

専用アプリケーションインターフェースを通じて、完全な Miro Insights ウェブアプリにアクセスします。これにより、すべてのセクションで包括的なデータビュー、高度なフィルタリング、完全なワークフロー管理を利用できます。

## 主なセクション

Miro Insights のフルアプリを使用するには、[Miro ダッシュボード](https://miro.com/app/dashboard/)からアプリに移動します。

Miro Insightsは、左側のサイドバーからアクセスできる6つの主要セクションに組織化されています。それぞれのエリアを探索して、プラットフォームの全機能を発見してみてください。

### AI に質問

バックログ、機能、および顧客フィードバックに関する質問をしてください。AIがデータを分析し、優先順位付けと意思決定のためのインサイトを提供します。迅速な回答を得たい時や、会話形式でデータを探索したい時に最適です。

[AI に質問の使用法について詳しくはこちら](../../tools/use-miro-insights/03-ask-ai.md)

### 自動フロー

製品管理プロセスを効率化するために自動化されたワークフローを設定しましょう。特定のトリガーに基づいてフィードバックのカテゴリ化、機能ステータスの更新、通知の送信を自動で行うルールを作成します。

[自動フローの使用法について詳しくはこちら](../../tools/use-miro-insights/04-automations.md)

### バックログ

メインのワークスペースで、すべての機能と課題を管理します。高度なフィルター、グループ化、バルク操作で製品のバックログを閲覧、整理、優先順位付けが可能です。

[バックログの使用方法について詳しく学ぶ](../../tools/use-miro-insights/05-backlog.md)

### ロードマップ

タイムラインビューを用いて製品のロードマップを計画し、視覚化します。インタラクティブなロードマップビジュアライゼーションを使用して、機能の進捗を追跡し、関係者に計画を伝えます。

[ロードマップの使用方法について詳しく学ぶ](../../tools/use-miro-insights/06-roadmap.md)

### フィードバック

視覚的なチャートとインサイトを用いて顧客のフィードバックを分析します。フィードバックの傾向を追跡し、パターンを特定し、製品に関する顧客の意見を理解します。

[フィードバックの使用方法について詳しく学ぶ](../../tools/use-miro-insights/07-feedback.md)

### 企業

会社情報を管理し、特定の機能をリクエストする組織を追跡します。ARRへの影響などの主要な指標を表示し、CRMシステムに直接接続します。

[会社管理の詳細を学ぶ](../../tools/use-miro-insights/08-companies.md)
