自動フローは特定のトリガーに基づいてアクションを自動的に実行することで、プロダクト管理のワークフローを効率化します。ルールを設定して、フィードバックを分類し、機能のステータスを更新し、通知を送信し、手動介入なしでレポートを生成します。

自動フローは時間を節約し、一貫性を確保します：

- **フィードバックや機能リクエストを自動で分類**します。
- **定期的なレポート**や要約をステークホルダーに提供します。
- **事前に定義された基準に基づいてステータスを更新**します。
- **重要なイベントが発生した際に通知を送信**します。
- **トレンドを分析し**、定期的にインサイトを提供します。

## 新しいオートメーションの作成

1. 左サイドバーから**自動フロー**にアクセスします。
2. **自動フローを作成**を選択します。
3. 自動フローを設定します:
   - **タイトル**: 自動フローにわかりやすい名前を付けます。
   - **プロンプト**: 自動フローが行うべきことを定義します。例えば、「最も頻繁に報告された問題トップ5をリストする」です。
   - **送信先**: 結果を送る先を選びます。現在は**Slack**に送信できます。
   - **スケジュール**: 自動フローを実行するタイミングを設定します（手動またはスケジュール設定）。
   - **タグ**: 自動フローを整理するためのタグを追加します。
4. **下書きを保存**して後で確認するか、**自動フローを作成**してすぐに有効化します。

### スケジュールオプション

特定のインサイトが必要な場合、手動実行を選択します。臨時の分析や一度きりのレポートに最適です。

定期的なスケジュールを選択してください。

- **毎日**: 重要な指標と緊急の問題の監視に。
- **毎週**: チームの定期的なアップデートと進捗報告に。
- **毎月**: より広範なトレンド分析と戦略的レビューのために。

## 自動フローの管理

自動フローを作成した後は、メインの自動フローページから管理できます。

### オートメーションの詳細を表示

各オートメーションエントリーは、一目で分かる重要な情報を表示します:

- **タイトル** オートメーションの名称。
- **プロンプト** 特定のタスクやクエリを示します。
- **送信先** 結果が届けられる場所。
- **実行タイミング** 実行頻度を示します。
- **ステータス** 「アクティブ」、「一時停止」、または「ドラフト」の状態を示します。
- **作成者** それを作成した人を示します。
- **作成日** トラッキング用の日付。
- **タグ**で整理
- **最終実行** - 最新の実行日時

### オートメーションの実行管理

各オートメーションを管理するには、いくつかのオプションがあります。オートメーションを管理するには:

1. 自動フローの**タイトル**をクリックして詳細を開きます。
2. 次のコントロールを使用してください。
   - **今すぐトリガー**: スケジュールに関係なく、自動フローを即時実行します。
   - **自動フローを一時停止**: 自動フローを一時的に停止します。
   - **自動フローをアクティブ化**: 一時停止された自動フローを再開します。
   - **編集**: 自動フローの設定および構成を変更します。

### 自動フローを削除

自動フローを削除するには:

1. 自動フローの**タイトル**をクリックして詳細を開きます。
2. 右上の三点メニューを選択します。
3. **削除**を選択し、アクションを確認します。

## 自動フローの種類

自動フローは、ニーズに応じてさまざまな目的に使われることができます。ここにいくつかの一般的な例を示します。

### レポート自動フロー

定期的なサマリーやインサイトを生成します:

- 「最も頻繁に報告されている問題・バグ上位5項目をリスト化」
- 「頻度順にランク付けされた最もリクエストの多い機能上位5項目を特定」
- 「ステータス順に並べられたすべてのアクティブな製品イニシアチブをリスト化」

### 分析自動フロー

継続的なデータ分析を提供:

- 「フィードバック量が最も多い上位10社をリスト化」
- 「課題を説明する顧客フィードバックを分析」
- 「過去60日間のすべての顧客インタビューとフィードバックを要約」

### 監視自動フロー

重要な指標と変化を追跡:

- "顧客のフィードバックパターンに基づいて解約リスクを検出"
- "頻繁に言及される機能の競合ギャップ分析を監視"
- "イニシアチブの進捗を追跡し、ブロッカーをハイライト"
