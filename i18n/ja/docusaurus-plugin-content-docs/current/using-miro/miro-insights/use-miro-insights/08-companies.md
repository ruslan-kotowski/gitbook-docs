企業セクションでは、フィードバックを提供したり、バックログの機能に関連付けられているすべての組織を閲覧および管理することができます。この顧客中心のビューにより、アカウントベースの製品管理と戦略的な意思決定が可能になります。

企業セクションで確認できる内容:

- **すべての企業**：製品フィードバックを提供した企業。
- **主要な指標**：フィードバック量、総ARR影響、機能リクエスト。
- **エンゲージメント状況**：各企業の関係の現在の段階を示します。
- **リクエスト状況**：アクティブな機能リクエストがある企業の追跡。

## 企業データの理解

### 企業指標

各企業のエントリは重要な情報を表示します：

- **企業名とロゴ**：ビジュアルによる簡単な識別。
- **顧客タイプ**：顧客か見込み客か。
- **ステージ**：現在の関係ステータス（クローズドウオン、見込み客など）。
- **ドル価値**：企業に関連付けられたARRまたは取引規模。
- **合計機能**：この企業がリクエストした機能数。
- **合計フィードバック**：この企業からのフィードバックの量。
- **ドメイン**：企業のウェブサイトの簡単な参照用。
- **アクティビティーの日付**: 会社が作成された日付と最終更新日。

### エンゲージメント指標

- **クローズド・ウォン**: フィードバックを提供するアクティブな顧客。
- **見込み客**: 製品を評価している潜在顧客。
- **ステージの進行**: セールスプロセスを進行中の企業。

## キャンバスからのアクセス

企業セクションは、Miro ボードのインサイトサイドパネルからも利用可能です。これにより、企業情報やリクエストを閲覧し、企業の文脈を直接キャンバスに追加して、ロードマップディスカッションやアカウントベースの計画の意思決定に活用できます。

[キャンバス上での Insights の使用について詳しくはこちら](../../tools/use-miro-insights/02-use-miro-insights-on-the-canvas.md)。
