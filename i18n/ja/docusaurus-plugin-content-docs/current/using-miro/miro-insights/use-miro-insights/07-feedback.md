フィードバックセクションは、顧客のフィードバックパターンに関する視覚的な分析とインサイトを提供し、トレンドを理解し、主要な問題を特定し、顧客の声を時間とともに追跡するのに役立ちます。

フィードバックセクションには以下が表示されます：

- **フィードバックボリュームのトレンド**：時間の経過とともにどれだけのフィードバックを受け取っているか。
- **会社別の内訳**：どの組織が最も多くの入力を提供しているか。
- **トピック分析**：顧客のフィードバックにおける共通のテーマや問題。
- **インパクトメトリクス**：フィードバックがビジネスの価値や優先事項にどのように関連しているか。

## システムへのフィードバックの導入方法

フィードバックを分析する前に、Miro Insights にフィードバックを取り込む必要があります。次の 3 つのオプションがあります: 自動インポート、一回限りのインポート、または手動入力。

### 自動インポート

既存のツールを接続して、顧客フィードバックを継続的に同期します。

:::note
インテグレーションを設定するには管理者である必要があります。[インテグレーションの設定](../set-up-and-manage-miro-insights/01-set-up-miro-insights.md)について詳しく学びましょう。
:::

**利用可能なインテグレーション**:

- **Intercom**：顧客の詳細、会話、フィードバック、リクエストを同期
- **Zendesk**：顧客の会話、フィードバック、リクエストをインポート
- **Gong**：顧客の会話、詳細、フィードバック、リクエストを同期
- **Clari**：顧客の会話、詳細、フィードバック、リクエストをインポート
- **Zoom**：顧客の会話、詳細、フィードバック、リクエストを同期
- **Chorus**：顧客の詳細、会話、フィードバック、リクエストをインポート
- **Zoom Revenue Accelerator**: 顧客との会話、詳細、フィードバック、リクエストを同期します

これらのインテグレーションを利用することで、AIが顧客フィードバックを自動的に分析し、あなたの機能にリンクします。

### 一度限りのインポート

ファイルまたは他のツールからフィードバックをインポートします：

- **Productboard**: CSVエクスポートをアップロードしてフィードバックをインポートします。
- **CSVのアップロード**: CSVファイルをドロップするか、デスクトップから選択してアップロードします。

CSVでフィードバックをインポートするには：

1. **インポート**を選択して、インポートダイアログを開きます。
2. **ワンタイムインポート**セクションで**Productboard**または**CSVをアップロード**を選択します。
3. 指示に従ってファイルをアップロードし、フィールドをマッピングします。

:::tip
Productboardを使用している場合は、[フィードバックをエクスポートするためのドキュメント](https://support.productboard.com/hc/articles/360056354854-Exporting-your-notes-into-a-CSV)を参照して、正しいCSVフォーマットを取得してください。
:::

### フィードバックを手動で追加する

Miro Insightsで新しいフィードバックアイテムを直接作成します：

1. **新しいフィードバック**を選択して、作成ダイアログを開きます。
2. **概要を入力**: フィードバックの簡単な説明。
3. **添付ファイルを追加**: 関連するファイルや文書を追加します。
4. **フィードバックURLを設定** (任意): 元の情報源へのリンク。
5. **人物を選択または作成**: フィードバックの提供者を選びます。
6. **会社を選択**: 依頼してきた組織を関連付けます。
7. **関連機能をリンク**: 関連するバックログ項目に接続します。
8. **提供日を設定**: フィードバックが元々提供された日付。
9. **担当者を割り当て**: フォローアップを担当する社内チームメンバー。
10. **追加**を選択します。

この手動プロセスは、会議や電話、または直接インテグレーションを持たないソースからのフィードバックをキャプチャするのに最適です。

## フィードバック表示の閲覧とカスタマイズ

システムにフィードバックを取り込むと、その閲覧と分析の方法をカスタマイズできます。

### チャートの理解

デフォルトで、フィードバックセクションは以下の2つの主要チャートを表示します:

1. **フィードバック量の推移**: 一定期間内に受け取ったフィードバックアイテムの数を示す折れ線グラフです。
2. **企業別フィードバック**: フィードバック量を提供企業別に表示する棒グラフです。

フィードバックセクションの右上にあるチャートアイコンを切り替えて、**チャートを非表示/表示**が可能です。

メインチャートはフィードバック量の推移を表示し、次のことに役立ちます：

- **トレンドの特定**: フィードバックが増加しているか減少しているかを確認します。
- **パターンの発見**: 例えば、季節的または周期的なフィードバックパターンを認識します。
- **改善の追跡**: 製品の変更がネガティブなフィードバックを減らすかどうかをモニターします。
- **リソースの計画**: サポートおよび開発のニーズを予測します。

## キャンバスからのアクセス

フィードバック分析は、あなたの Miro ボード上のインサイト側面パネルを通じても利用可能です。これにより、顧客のフィードバックと洞察にアクセスし、それから議論をサポートするために関連するフィードバック項目をキャンバスに追加し、顧客の声をビジュアルプランニングセッションに直接つなげることができます。

[キャンバスでのインサイトの使用方法について詳しくはこちら](../../tools/use-miro-insights/02-use-miro-insights-on-the-canvas.md)。
