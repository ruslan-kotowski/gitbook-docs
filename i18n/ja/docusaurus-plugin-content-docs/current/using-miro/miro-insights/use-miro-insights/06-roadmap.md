ロードマップは製品計画の戦略的なビジョンを提供し、機能開発のタイムラインを視覚化し、コミュニケーションを支援します。バックログの項目がどのように戦略的イニシアティブや計画された納期に結びついているかを示します。

あなたのロードマップには、**期間、影響領域、イニシアティブ、ステータス**ごとに組織された機能や問題が表示されます。

## ロードマップデータの理解

バックログデータがどのようにロードマップビューに変換されるかを理解することは重要です。ロードマップはバックログ項目からの重要な情報を取り込み、計画と優先順位付けのコンテキストを提供します。

### 重要なカラム

- **インパクトエリア**：ビジネス領域や戦略目標。
- **イニシアティブ**：より広範なプロジェクトやテーマ。
- **機能**：開発されている具体的な機能。
- **ステータス**：現在の状態（調査中、進行中、出荷済みなど）。
- **優先順位**：相対的な重要度のランキング。
- **全企業数**：この機能を求めている企業の数。
- **総フィードバック**：顧客からのインプットの量。
- **企業**: この機能に関心のある特定の組織。

### ビジュアル指標

- **状態色**: 開発進捗のための迅速なビジュアル参照
- **優先度指標**: 最も重要な項目を識別するのを助ける
- **企業タグ**: どの顧客が要求を推進しているかを示す

## バックログから項目を追加する

バックログから機能や課題をロードマップに簡単に追加できます:

1. **バックログから追加**を選択して選択ダイアログを開きます。
2. **検索および絞り込み**により、以下の方法でバックログアイテムをフィルターできます。
   - 特定の機能を見つけるための検索バー。
   - ステータスフィルター（完了、キャンセル済みなど）。
   - ターゲット日付のフィルター。
   - その他の利用可能な条件。
3. **利用可能なアイテムを閲覧し**、主要なメトリクスを表示します：
   - ドル価値の影響。
   - 現在のステータス（アイデア、進行中など）。
   - リクエストした企業数。
   - フィードバックの量。
4. **アイテムを選択して**、詳細情報をサイドパネルで確認します。
5. **選択したアイテムのターゲット四半期を選択します**。
6. **ロードマップに追加**をクリックして、プランに組み込みます。

また、ロードマップビュー内で**+**（プラス）アイコンをクリックすることで、希望の期間、インパクト領域、あるいはイニシアティブの列に直接機能を追加することができます。

この機能は、各バックログアイテムのビジネスインパクト、顧客需要、および現在のステータスを表示することにより、あなたのロードマップに何を含めるかについての情報に基づいた意思決定をサポートします。

## 新機能の直接作成

ロードマップビューから直接新しい機能や問題を作成することもできます。

1. **機能を作成**を選択して、作成ダイアログを開きます。
2. **基本情報**を入力します：
   - 機能または課題のタイトル
   - 説明
   - タイプ（機能または課題）
3. **プロパティ**を設定します:
   - ステータス (アイディア、進行中 など)
   - 優先度レベル
   - 所有者とチーム
   - 開始日と目標日
   - サイズの見積もり
4. **メタデータで整理する**:
   - 影響領域
   - イニシアティブ
   - ストリームとサブストリーム
   - タグと機能領域
   - 外部仕様
   - マイルストーン
5. **企業との連携**:
   - リクエスト企業を追加します。
   - 収益影響を設定します（新規 ARR、保持 ARR、失われた ARR）。
   - 取引額と予想終了日を含めます。
6. **外部タスクのリンク** Jira チケットのように。
7. **作成** を選択して、新しいアイテムを直接ロードマップに追加します。

このワークフローは、ロードマップ計画セッション中に新しいアイデアをキャプチャする場合や、戦略的イニシアチブのためにプレースホルダー項目を作成する必要があるときに最適です。

## 期間の組織化

ロードマップは、さまざまな期間で組織化することができ、計画のニーズに対応します。

- **週間**: 短期のスプリント計画や直近の優先事項に適しています。
- **月間**: 中期の機能開発サイクルに適しています。
- **四半期**: 戦略的事業計画や長期的なイニシアチブに適しています。

この柔軟性は、リリース計画、リソース割り当て、およびステークホルダーとのコミュニケーションに役立ちます。

## フィルタリングとグループ化

ロードマップ閲覧をカスタマイズして、計画の特定の側面に焦点を当てることができます。

### フィルタリングオプション

以下のようなフィルターを適用してロードマップ閲覧を細かく調整できます。

- **期間**: 特定の週、月、四半期に焦点を当てる。
- **イニシアチブ**: 戦略的テーマの進捗を閲覧。
- **ステータス**: 特定の開発段階にある項目を見る。
- **優先順位**: 最も重要な機能に焦点を当てる。

### グループ化オプション

ロードマップビューを以下の方法で整理します:

- **イニシアチブ**：戦略的テーマ内のすべての機能を確認します。
- **インパクトエリア**：ビジネス目標ごとにグループ化します。
- **ステータス**：開発の進捗状況別に整理します。
- **会社**：リクエストした顧客ごとに機能を表示します。
