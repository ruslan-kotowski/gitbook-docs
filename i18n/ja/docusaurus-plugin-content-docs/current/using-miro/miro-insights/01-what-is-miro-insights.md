Miro Insights は顧客のインプットを明確で実行可能な優先事項に変換するのを支援する、集中化された**AI強化プラットフォーム**です。CRMプラットフォーム、サポートツール、内部会話チャネルを含むテックスタック全体から製品のフィードバック、使用データ、さらには収益に関する洞察を集約し、1つのインテリジェントなハブにまとめます。これにより、Miro Insights は、「*顧客が本当に求めているものは何か？*」や「*どの機能が最も価値を生むか？*」といった重要な製品に関する質問に答えやすくします。

## Miro Insights は誰のためのものですか？

Miro Insights は、製品の方向性や戦略の計画を推進するチーム向けに構築されています。主なユーザーには**プロダクトマネージャー**や**プロダクトオーナー**が含まれますが、**オペレーションリーダー**、**カスタマーサクセスマネージャー**、**デザイナー**、**リサーチャー**、さらに機能リクエストへの可視性が必要な**営業チーム**にも役立ちます。本質的には、次に何を構築するかを優先するすべての人が、このインサイトから利益を得ることができます。

## Miro Insights の価値とは？

Miro Insights は、分散されたフィードバックを集中的なアクションに移行させるのに役立ちます。主な利点には以下が含まれます。

- **一元化された顧客フィードバック**: サポートチケット、セールスコール、CRMノート、Slackスレッドなどからフィードバックを自動的に収集・統合し、手動でデータを追いかけることなく顧客のニーズを360度で把握できます。
- **AI駆動による優先順位付け**: Miro Insightsは既存の機能にフィードバックをリンク付けしたり、新しい提案をしたり、アカウント価値や緊急度を用いて影響を評価し、次に注力すべきことを推奨します。これにより、バックログはリアルタイムのエビデンスに基づいて動的に再構成されます。
- **インテリジェント検索とインサイト**：自然言語で質問するだけで、製品や顧客に関する明確で実用的な答えを即座に得ることができます。Ask AIは、あなたに最も関連性の高いデータ、トレンド、補助的な証拠を見つけてくれますので、より迅速で情報に基づいた意思決定が可能です。
- **数値化されたビジネスインパクト**：バックログのすべての機能には、何人の顧客がリクエストしたか、これらのリクエストにリンクされた年間収益（ARR）、取引がリスクにさらされているか、あるいはその機能を提供することで獲得できる可能性があるかなどのコンテキストが付加されます。これにより、チームは顧客の満足とビジネス価値のバランスをとることができ、ユーザーを満足させるだけでなく、収益やリテンションを促進する機能に焦点を当てることができます。
- **プロアクティブな自動化**: エージェントをスケジュールして、要約、レポート、トレンドを自動的にあなたの好みのチャネル（例えば Slack）に送信します。
- **シームレスなコラボレーション**: Miro Insights は Miro ボードと共存しています。優先順位付けされた機能カードや重要なフィードバックを計画セッション中に簡単に Miro ボードにドラッグし、ロードマップ作成や機会の優先付けを共同で、視覚的に行うことができます。チームはコメントを追加したり、議論したり、手元のデータで意思決定を行えます。
- **エンタープライズグレードのセキュリティー**: Miro Insights は潜在的に機密性の高い顧客データを集約するため、セキュリティーとプライバシーを重視して構築されています。権限管理を尊重しており、例えば、許可されたチームメンバーのみが特定のインテグレーションを接続したり、特定のデータを閲覧したりできます。顧客情報が安全に保たれるよう、業界標準のデータ保護に準拠しています。

## サポートされているインテグレーション

Miro Insights はインテグレーションライブラリを随時拡張しています。現在、主要なインテグレーションには以下が含まれます:

- **CRM**: Salesforce と HubSpot － 企業の記録、取引の価値、タイムラインノートを取り込みます。これにより、フィーチャーリクエストが収益に与える影響を結び付けることができます（例えば、あるフィーチャーが 10 万ドルの機会や更新に関連しているかどうかを確認できます）。
- **カスタマーサクセスとサポート**: Zendesk と Intercom － サポートチケットと会話を取り込みます。サポートのやりとりで言及された問題点やフィーチャー要望をキャプチャするのに最適です。フィルターを使用して特定のチケットのみをインポートすることができます（例えば、「フィーチャーリクエスト」というタグが付いているもののみ）ので、ノイズを避けることができます。
- **セールスの通話**: Gong と Zoom (Revenue Accelerator) – 通話の文字起こしや要約をインポートします。Miro Insights の AI が、ニーズや製品フィードバックの言及をスキャンします。(注: Zoom のインテグレーションは、Zoom のセールスインテリジェンストールを指し、通常の会議記録ではありません。)
- **製品管理と開発**: Jira と Linear – 機能のステータスを同期し、既存の機能バックログアイテムをインポートできます。例えば、Jira を接続すると、Miro Insights はエピックや製品バックログアイテムのリストを Insights のバックログに取り込み、そのステータスを更新し続けます。
- **通信・チャット**：Slack – 内部または外部の会話をキャプチャします。Slack インテグレーションでは、メッセージショートカットを使用して、任意の Slack メッセージ（例: Slack コミュニティーの顧客コメントや、セールス担当者が投稿したクライアントのフィードバック）を直接 Miro Insights へフィードバック項目として送信できます。メッセージテキストを自動的に含め、一致する場合はユーザーや会社にリンクします。これにより、システムへの臨時フィードバックの取得が大幅に容易になります。

**Zapier** もキャッチオールのインテグレーションオプションとして利用可能です。直接サポートされていないツールがある場合、Zapier を使って Miro Insights にデータを転送することが多くあります。例えば、Google Form の送信や独自のデータベースへの新しいエントリが現れたときの Zapier ワークフローを作成し、Miro Insights にフィードバック項目を作成することができます。
