スペースでは、スペース概要として機能するボードを任意に設定できます。そのボードが、スペースに訪問するユーザーのデフォルトの表示画面となり、背景情報などが分かり明確になります。スペース概要はチームを連携させ、スペースがインテリジェントでダイナミックな作業環境になります。

この記事では、スペース概要機能とスペース概要の作成方法について説明します。スペースについて詳しくは、[スペース](01-spaces.md)を参照してください。

![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)

*スペースサイドバーでスペース概要にアクセスします。*

## 主な機能

- **強化された組織化**
  スペース内のすべてのアクティビティーやリソースを集約して管理できる場所としてスペース概要を使用できます。関係者のためにスペース概要を定期的に更新します。
- **可視性**
  スペース概要はすべてのスペースメンバーに表示され、スペースサイドバーの上部でアクセス可能です。概要は会議中や会議の間の重要な参照ポイントです。
- **改善されたチームコミュニケーションとアライメント**
  スペース内で、特定のボードや意思決定、リソースにリンクします。

## スペース概要を作成する

1. 所有者または共同所有者であるスペースを開きます。
   スペースの閲覧が開きます。
2. スペース概要として設定したいボードの三点リーダー (**...**) をクリックします。
3. **設定にする**>**概要** をクリックします。
   スペース概要のボードはもとの名前のままで、スペースサイドバーの上部に設定されます。

:::tip
スペース内のボードを開き、スペースサイドバーでスペース概要に指定したいボードの三点リーダー (**...**) をクリックすることもできます。
:::

![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)

*オプションとして、スペースのサイドバーからボードをスペースの概要として設定することができます。*

## スペースの概要を削除する

1. 自分が所有者または共同所有者であるスペースを開きます。
2. スペースのサイドバーで、**概要** の三点リーダー (**...**) をクリックします。
3. **概要から削除** をクリックします。
   削除されたスペースの概要はスペースレベルに戻り、アイコンは元の状態に戻ります。

:::note
スペースの概要ボードがゴミ箱に移動されたり、スペース外に移動された場合、そのボードは自動的にスペースの概要から削除されます。
:::
