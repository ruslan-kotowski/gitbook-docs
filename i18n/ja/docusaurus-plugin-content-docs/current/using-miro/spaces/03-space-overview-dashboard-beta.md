[スペース概要](02-space-overview.md)は、あなたのスペースにアクセスする際のデフォルトの入口です。スペース内のアクティビティーとコンテンツを構造的に閲覧できるよう、ダッシュボードを作成できます。

![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)

*スペース概要ダッシュボード*

この記事では、スペース概要用のダッシュボードを作成する方法について説明します。スペース概要について詳しく知りたい方は、[スペース概要](02-space-overview.md)をご覧ください。

## 主な機能

- **自動レイアウト**
  ウィジェットを行や列に配置し、自動的にサイズを調整して配置します。
- **ドラッグ & ドロップでの整理**
  ウィジェットをドラッグしてダッシュボードに簡単にコンテンツを整理できます。

## スペース概要ダッシュボードを作成する

1. [Miro ボードをスペース概要として設定](02-space-overview.md)します。
2. ボード上で、作成バーの**ツール、メディア、およびインテグレーション** (**+**)をクリックします。
3. **ダッシュボード**を検索して選択します。
4. ダッシュボードを配置したいキャンバスをクリックします。
5. ダッシュボードを構築するには、サポートされているMiroフォーマットやオブジェクトをドラッグします。例として、テーブル、タイムライン、テキストなどがあります。また、連動コピーを追加することもできます。
   ![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)*ダッシュボードが自動的にフォーマットやオブジェクトのサイズを調整します。*
6. （オプション）各ウィジェットをドラッグして再配置し、ダッシュボードを整理します。
7. （オプション）誰かがスペース概要をアクセスした際にダッシュボードをデフォルト表示に設定するには、**ダッシュボード**のコンテキストメニューから三点リーダー（**...**）をクリックし、**デフォルト表示に設定**を選択します。

:::tip
あなたのダッシュボードをプロジェクトテンプレートとして利用するには、[カスタムブループリント](05-custom-blueprints.md)にスペースの概要とダッシュボードを作成して含めることができます。
:::
