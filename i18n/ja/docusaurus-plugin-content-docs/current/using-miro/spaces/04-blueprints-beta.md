ブループリントは、イノベーションのワークフローを完成させるために必要な各種ボード、フォーマット、ツール、テンプレートを備え、あらかじめ設定された[スペース](01-spaces.md)です。用途に合ったブループリントを選択して、あらゆるワークフローの資料を事前に設定できます。スペースを一から作る必要はありません。

![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)

*ブループリントは、プリセットされたテンプレートを持つスペースです。*

## ブループリントでプロジェクトの全行程に対応

ブループリントを使うと、すべてのチームメンバーが終始、同一の構造化された手法に従うことができます。ブループリントには、業界のベストプラクティスを取り入れた定型のボードやフォーマット、ツールが含まれ、エンドツーエンドのワークフローを提供します。チームでより効果的に、一貫した方法でコラボレーションを行うことができます。

:::note
ブループリントは Free プランではご利用いただけません。Free プランのユーザーには、アップグレードの提案が表示され、ブループリントの概要を確認できます。
:::

## ブループリントの利用

### ダッシュボードから開く

1. ダッシュボードの右側にある **テンプレートを見る** をクリックします。
   テンプレートピッカーが開きます。
2. 左側の **ブループリント** をクリックします。

### Miro ボードから

1. 作成バーから「**テンプレート**」をクリックします。
   テンプレートピッカーが開きます。
2. 左側の**ブループリント**をクリックします。
