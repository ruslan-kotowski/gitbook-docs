カスタム[ブループリント](04-blueprints-beta.md)は、独自のプロセスやワークフローのために作成する[スペース](01-spaces.md) テンプレートです。カスタム ブループリントには、ボード、フォーマット、またはニーズに合わせた任意のMiroリソースを含めることができます。

![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)

*カスタムブループリントには特定の目標を達成するために必要なすべてのボードとフォーマットが含まれています。*

カスタムブループリントを作成して、デザインプロセス、納品プロセス、ロールアウト、あるいは四半期ごとの計画に再利用できるテンプレートとして管理します。カスタムブループリントを組織、チーム、または個人のライブラリに作成して保存できます。

既存のスペースをカスタムブループリントとして保存することもできます。

ブループリントの詳細については、[ブループリント](04-blueprints-beta.md)をご覧ください。

## カスタムブループリントを発見する

あなたとあなたのチームは、**カスタムテンプレート**内の[テンプレートピッカー](../../getting-started/start-here/your-first-board/04-templates.md)で、すべてのカスタムブループリントを見つけることができます。

![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)

*テンプレートピッカーには、個人、チーム、会社レベルで作成されたカスタムブループリントも含まれるようになりました。*

## カスタムブループリントを作成

カスタムブループリントは、ホームダッシュボードのサイドバー、スペース内、またはスペース内のボードから作成できます。

以下の手順に従ってください。

1. [スペースを作成](01-spaces.md)するか、左サイドバーから既存のスペースを選択します。
2. ブループリントとして保存したいスペースで、左サイドバーの三点リーダー（**...**）をクリックします。
   **オプション**メニューが開きます。
3. **ブループリントとして保存**をクリックします。
   **ブループリントとして保存**モーダルが開きます。
4. ブループリントに名前を付けます。
5. （任意）概要を追加します。
6. カスタムブループリントを使用できる人を指定するには、**個人**、**チーム**、または有効な場合は**会社**を選択します。

   > 💡 会社レベルのカスタムブループリントの作成について詳しく学びましょう。
7. **テンプレートを保存** をクリックします。
    あなたのカスタムブループリントは、[テンプレートピッカー](../../getting-started/start-here/your-first-board/04-templates.md)の**カスタムテンプレート**の下で利用可能になります。チームレベルでカスタムブループリントを作成した場合、チームの誰でもテンプレートピッカーでそのカスタムブループリントを見つけることができます。

:::tip
スペース内のコンテンツとアクティビティーの概要を示すために、あなたのカスタムブループリントに[スペース概要](02-space-overview.md)と[ダッシュボード](03-space-overview-dashboard-beta.md)を含めてください。
:::

## カスタムブループリントを共有する

チームや企業レベルで作成したカスタムブループリントへのリンクをコピーして共有できます。

以下の手順を実施してください。

1. ホームダッシュボードで**テンプレートを探索**をクリックします。
   テンプレートピッカーが開きます。
2. **カスタムテンプレート**の下にある**[Your team]テンプレート**または**[Your company]テンプレート**をクリックします。
3. 共有したいカスタムブループリントにカーソルを合わせ、**プレビュー**をクリックします。
4. 右上で**共有用リンクをコピー**をクリックします。

:::note
個人ライブラリに保存されているカスタムブループリントは、チームや会社のライブラリに共有したり移動したりすることはできません。
:::

## カスタムブループリントの編集

新しいセクションやボード、フォーマットを追加するなど、カスタムブループリントを更新できます。

以下の手順に従ってください。

1. ホームダッシュボードから**テンプレートを探索**をクリックします。
   テンプレートピッカーが開きます。
2. **カスタムテンプレート**の左下で、**[Your team] テンプレート**をクリックします。カスタムブループリントがあなたとだけ共有されている場合は**個人用**をクリックします。
3. 編集したいカスタムブループリントにカーソルを合わせ、三点リーダー(**...**)をクリックします。
4. **編集**を選択します。

   > 💡 チームや個人のテンプレートピッカーから、カスタムブループリントにカーソルを重ねて**プレビュー**をクリックし、その後**テンプレートを編集**を選択することもできます。

   サイドバーが開いた状態で、スペース内の最初のボードからカスタムブループリントが開きます。青いバナーが表示されており、編集中であることと、変更が自動的に保存されることを示しています。
5. カスタムブループリントを編集します。例えば、サイドバーにセクションを追加したり、既存のボードやフォーマットを更新したりします。スペースの管理について詳しくは、[スペース](01-spaces.md)ガイドをご覧ください。
6. 青いバナーで、**編集を停止**をクリックします。
   ホームダッシュボードに戻ります。カスタムブループリントへのすべての変更が保存されます。テンプレートをすでに使用している人には、変更は共有されません。

:::note
会社の管理者とコンテンツ管理者は、会社レベルで作成されたカスタムブループリントを編集できます。
:::

## カスタムブループリントを削除する

作成したカスタムブループリントを削除できます。

以下の手順に従ってください:

1. ホームダッシュボードから、**テンプレートを探す**をクリックします。
   テンプレートピッカーが開きます。
2. **カスタムテンプレート**の下にある、**[Your team]のテンプレート**または**パーソナル**をクリックします。カスタムブループリントがあなたとだけ共有されている場合はパーソナルを選択します。
3. 削除したいカスタムブループリントの上にホバーし、三点リーダー（**...**）をクリックします。
4. **削除**をクリックします。
   カスタムブループリントが削除されます。

:::note
会社の管理者およびコンテンツ管理者は、会社レベルで作成されたカスタムブループリントを削除できます。
:::

## 会社レベルでカスタムブループリントを作成する

### StarterおよびBusinessプラン

管理者コンソールの**セキュリティ** > **共有**の下にある、**会社テンプレートの共有を制限**オプションはデフォルトで**オフ**になっています。組織内の誰でも、会社全体のために自分のカスタムブループリントを作成することができます。

管理者はこの設定を変更することはできません。

会社の管理者およびコンテンツ管理者は、会社レベルで作成されたカスタムブループリントを作成、編集、削除できます。

### Enterprise

デフォルトでは、会社の管理者およびコンテンツ管理者のみが、会社レベルのカスタムブループリントを作成できます。ユーザーは自分のスペースを会社レベルのカスタムブループリントとして保存するようリクエストする必要があります。

会社の管理者として、(Enterprise) ユーザーが会社レベルでカスタムブループリントを作成できるようにすることができます。

会社の管理者とコンテンツ管理者は、会社レベルで作成されたカスタムブループリントの作成、編集、削除が可能です。

### （Enterprise）ユーザーが会社レベルでカスタムブループリントを作成できるようにする

デフォルトでは、Enterpriseサブスクリプションのユーザーは会社レベルでカスタムブループリントを作成できません。会社の管理者として、この設定を変更することができます。

![](../../../../../../docs/using-miro/spaces/images/30182619614866_image.png)

*Enterpriseの場合、デフォルトでユーザーは会社レベルでカスタムブループリントを作成できませんが、会社の管理者がこの設定を変更できます。*

以下の手順に従ってください：

1. 会社の管理者として、管理者コンソールに移動します。
2. **セキュリティ** > **共有** に進みます。
3. **ロールと権限**の下で、**会社テンプレートの共有を制限**をオフに切り替えます。
   これで、組織内の誰でも会社レベルでカスタムブループリントを作成できます。

:::note
**会社テンプレートの共有を制限**をいつでもオンに戻すことができます。変更は、制限をオンまたはオフに切り替えた後に作成されたカスタムブループリントに影響を与えます。
:::
