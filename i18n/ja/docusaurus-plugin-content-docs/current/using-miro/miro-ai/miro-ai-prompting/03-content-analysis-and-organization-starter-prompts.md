Miro AI を初めて利用する場合は、コンテンツ分析と整理のための既成プロンプトから始めましょう。それぞれのユースケースには、その目的の説明とすぐにコピー可能な Miro AI プロンプトが含まれています。角かっこで囲まれたプレースホルダー (例えば、[役割]、[アーティファクト]、[トーン]) をあなたのコンテキストに置き換えて、Miro AI でプロンプトを実行してください。

## **情報処理と要約化**

生のノートを整理された要約、テーマ、実行可能なリストに変換します。

### ディスカッションスレッドの要約

**主な用途:** 長大なボードやノートクラスターの迅速で共有可能な要約を作成します。

**Miro AI プロンプト:**

コピー

```
Miroボードで選択されたディスカッションから重要なポイントを3段落の簡潔な要約として作成します。主要なテーマ、決定事項、次のステップをまとめます。Miro文書としてフォーマットします。
```

### キーテーマを特定しグループ化する

**用途:** パターンと重要事項を迅速にクラスター化する。

**Miro AIプロンプト:**

コピー

```
Miro ボードで選択されたアイデアとフィードバック項目を分析します。トップ5の繰り返されるテーマを特定して、各テーマの下に関連項目をグループ化します。構造化されたリストとして提示し、Miro 付箋としてフォーマットします。
```

### アクション アイテムを抽出して優先順位をつける

**目的：**雑多なノートからToDo、担当者、日付を抽出するため。

**Miro AI プロンプト：**

コピー

```
Miro ボードで選択されたメモを確認し、すべてのアクションアイテムを抽出して次の項目で整理します：タスクの説明、責任者（言及されている場合）、期限（言及されている場合）。フォーマットは Miro テーブルにします。
```

### フィードバックの分類

**用途:**優先順位をつけて入力を明確なカテゴリーにまとめる。

**Miro AI プロンプト:**

コピー

```
Miroボード上で選択されたフィードバックを論理的なグループに分類し、それぞれのカテゴリーに対して頻度と影響に基づいて優先度レベル（高／中／低）を提案してください。フォーマットはMiroテーブルで。
```

## **データ統合**

複数のソースからの入力を統合し、意思決定に準備の整った出力を作成します。

### ユーザー調査のインサイトを統合

**目的:**複数のセッションを統合し、緊密なインサイトのセットに収める。

**Miro AI プロンプト:**

コピー

```
Miro ボードに選択された複数のユーザー調査セッションからの主要な発見を統合し、サポート証拠と共に5つの主要な洞察にまとめます。さらに調査が必要な、矛盾する発見があれば強調します。フォーマットは Miro 文書として作成します。
```

### エグゼクティブの概要を作成する

**目的:** リーダーやステークホルダー向けの1ページの概要を提供する。

**Miro AI プロンプト:**

コピー

```
Miro ボードで選択した詳細なプロジェクト情報に基づいて、1ページのエグゼクティブサマリーを作成します。取り上げる内容：プロジェクトの現状、主要成果、現在の課題、推奨される次のステップ。フォーマットは Miro 文書として作成します。
```

### ステータスレポートの作成

**用途:** 進捗、障害、および優先事項を含む毎週の更新。

**Miro AI プロンプト:**

コピー

```
Miroボードで選択したプロジェクト追跡情報（現在の状況、完了済みのタスク、今後のマイルストーン）を使用して週間ステータスレポートを生成します。今週の進捗、阻害要因、及び優先事項を強調します。Miro Tableとしてフォーマットしてください。
```

### ステークホルダーのフィードバックを統合する

**目的：**観点を整合させ、対立と解決策を表面化する。

**Miro AIプロンプト：**

コピー

```
Miro ボードで選択されたさまざまなステークホルダーからのフィードバックを統合し、合意点、対立する視点、提案された解決策を示すサマリーを作成します。フォーマットは Miro ダイアグラムとします。
```
