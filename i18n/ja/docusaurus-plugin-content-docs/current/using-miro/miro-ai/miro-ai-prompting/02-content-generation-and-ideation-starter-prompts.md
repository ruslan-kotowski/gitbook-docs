Miro AI を初めて利用する場合は、コンテンツ生成とアイデア出しのための準備されたプロンプトから始めましょう。それぞれのユースケースにはその目的が説明され、コピー可能な Miro AI プロンプトが含まれています。

## **アイデアの生成と拡張**

Miro AI 用に用意されたプロンプトで、アイデアの流れを促進し、初期ドラフトの作成を迅速化します。

### 製品機能アイデアを生成する

**目的:** ユーザーニーズに基づいた迅速な機能リストの生成。

**Miro AI プロンプト:**

コピー

```
Miro のボードで選択したユーザーペルソナに基づいて、ユーザーの主な問題を解決する革新的な製品機能アイデアを10件生成します。価値があり技術的に実現可能な機能に焦点を当ててください。フォーマットは Miro 付箋として下さい。
```

### ワークショップのフォローアップ質問を作成する

**用途：**セッション後のより深い探索と鋭い促進。

**Miro AI プロンプト:**

コピー

```
Miro ボードで選択されたワークショップのトピックまたは決定事項に基づいて、5つの配慮のあるフォローアップ質問を生成します。このトピックをさらに深掘りし、見逃したかもしれない潜在的な問題や機会を発見する手助けをします。フォーマットは Miro 付箋で。
```

### 追加のコンセプトやバリエーションを作成

**目的：**素早いメモをより豊かなアイデアの集まりに変えること。

**Miro AI プロンプト：**

コピー

```
Miro ボードで選択されたブレインストーミングのアイデアから、3〜5 個の関連コンセプトやバリエーションを生成し、さらに探求すべきものを提示します。形式は Miro 付箋で。
```

### 代替ソリューションの生成

**目的:** 各種のルートを検討し、最終決定に進む。

**Miro AI プロンプト:**

コピー

```
Miroボードで選択した問題を解決するための代替アプローチを4つ生成し、現在のソリューションと問題文のコンテキストを考慮に入れてください。各代替案については、現在のプランと比較した際の重要なトレードオフを1つ記載します。Miro付箋としてフォーマットします。
```

## **会議準備**

効果的に計画し、進行し、フォローアップします。

### 会議のアジェンダを作成

**目的:** 一貫性のある、時間制限されたアジェンダと明確な結果を。

**Miro AIプロンプト:**

コピー

```
Miro ボードで選択した会議の種類と主な目的に基づいて、詳細なアジェンダ テンプレートを作成します。時間配分、主要な議論事項、アクション項目を記入するスペースを含めてください。フォーマットは Miro 文書として作成します。
```

### ふりかえりのディスカッション質問を作成

**目的：**バランスの取れた振り返りと未来志向のアクション。

**Miro AI プロンプト:**

コピー

```
Miro ボードで選択されたチームのふりかえりに焦点を当てて、8〜10 個の魅力的なディスカッションの質問やアイデアを作成してください。振り返りと今後の行動につながる質問を含めてください。フォーマットは Miro 付箋です。
```

### アイスブレイクの質問を作成する

**目的:** グループ全体のスムーズでコンテキストに即したウォームアップ。

**Miro AI プロンプト:**

コピー

```
Miro ボードで選択したチームの状況に基づいて、プロフェッショナルで楽しく、または考えさせられるような創造的なアイスブレイクの質問を6つ生成します。フォーマットは Miro の付箋です。
```

### 会議前の調査質問を作成

**用途:** 会議前に意見を把握する。

**Miro AI のプロンプト:**

コピー

```
Miro ボード上で選択された会議のタイプとトピックに基づいて、5 つの質問からなる会議前アンケートを作成してください。質問は現在の視点を理解し、よりターゲットを絞った議論の準備に役立つようにします。Miro 文書としてフォーマットします。
```
