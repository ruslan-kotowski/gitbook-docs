Miro AI を初めて利用する場合は、コンテンツの分析や整理のための準備済みのプロンプトを使って始めましょう。各ユースケースではその目的を説明し、すぐに使用できる Miro AI プロンプトが含まれています。

## **コンテンツ強化**

作業の明確さ、完全性、仮定を強化します。

### 付箋の明確さを向上

**目的:** ノートを具体的で簡潔かつ行動重視にします。

**Miro AI プロンプト:**

コピー

```
選択された Miro ボードの付箋やコンテンツを元の意図を維持しつつ、より明確で具体的、かつ実行可能なものに再作成してください。フォーマットは Miro 付箋として整えてください。
```

### 追加のプロジェクト検討事項を提案

**目的:** リスク、依存関係、および見逃しを早期に表面化させること。

**Miro AI プロンプト:**

コピー

```
Miro ボード上の選択された現在のプロジェクトプランを確認してください。どのような重要な考慮事項、リスク、依存関係を見落としている可能性がありますか？対処すべき追加項目を5～7個提案してください。Miro 文書としてフォーマットしてください。
```

### 欠落しているプロセスフロー要素の推奨

**目的：**手順、決定、フィードバックループの欠落を埋める。

**Miro AI プロンプト：**

コピー

```
Miro ボード上で選択された現在のプロセス フローを分析し、欠けているステップ、意思決定ポイント、フィードバックループを提案して、より完全かつ効果的なものにしてください。Miro フローチャート図としてフォーマットしてください。
```

### 仮説検証の質問を生成する

**用途:** リソース配分を決定する前に仮説をテストする。

**Miro AI プロンプト:**

コピー

```
Miro ボードで選択されたプロジェクト プランの各仮説を検証するための具体的な質問やテストを生成し、それを Miro の付箋としてフォーマットします。
```

## **意思決定ガイダンス**

構造、基準、測定可能な結果を持って情報に基づいた意思決定を行います。

### メリット デメリットリストの作成

**対象:** 選択肢間のトレードオフのバランス観を得る。

**Miro AI プロンプト:**

コピー

```
Miro ボードで選択した決定やオプションについて、短期的および長期的影響を含む包括的なメリットとデメリットの分析を作成してください。フォーマットは Miro 文書で行ってください。
```

### リスク評価基準の生成

**用途:** 提案やイニシアティブに対する一貫したリスクスコアリング。

**Miro AI プロンプト:**

コピー

```
リスク評価基準を生成
Miro ボードで選択したプロジェクトまたはイニシアティブのタイプに基づいて、5～7 の主要基準を持つリスク評価フレームワークを作成します。各基準を評価するためのスコアリングシステムとガイダンスを含めてください。フォーマットは Miro テーブルとします。
```

### 評価フレームワークの開発

**用途:** オプションを客観的に比較するための重み付け。

**Miro AI プロンプト:**

コピー

```
評価フレームワークを開発する
Miro ボードで選択した複数の選択肢（アイデア、ソリューション、ベンダーなど）のために、加重基準を用いた評価フレームワークを作成し、客観的でデータに基づいた意思決定を支援します。フォーマットは Miro テーブルとしてください。
```

### 成功指標を提案する

**用途:** 先行指標と遅行指標を事前に定義する。

**Miro AI プロンプト:**

コピー

```
Miro ボードで選択したイニシアティブに対して、具体的で測定可能な成功指標を5〜8個提案してください。先行指標（早期シグナル）と遅行指標（最終結果）の両方を含めてください。フォーマットは Miro テーブルとして。
```

## **プロセスの文書化**

ワークショップやフローを実用的なガイドやチェックリストに変換します。

### ブレインストーミングを構造化プランに変換する

**目的：**アイデアを具体的な行動プランに移行し、優先順位を設定します。

**Miro AI プロンプト：**

コピー

```
Miro ボード上で選択されたブレインストーミングの結果を、優先順位付きの手順と、今日の日付を開始日に、2週間後を終了日とする構造化されたアクションプランに変換してください。リソース要求や役立つ情報を含めて、Miro テーブルの形式でフォーマットしてください。
```

### ステップバイステップのガイドを作成

**用 途:** チームの誰でもフォローできる明確な指示。

**Miro AI プロンプト:**

コピー

```
Miro ボードで選択されたワークフローダイアグラムに基づいて、誰でも使える詳細なステップバイステップガイドを作成します。各ステップにおける意思決定のポイントや必要なツール、期待される成果を含めてください。フォーマットは Miro 文書で。
```

### プロセスマップからチェックリストを作成する

**用途:** 実行中に何も見落としがないようにします。

**Miro AI プロンプト:**

コピー

```
Miro ボードで選択したプロセスマップを、実行中に何も見逃さないことを保証する実用的なチェックリストに変換します。関連項目を論理的にグループ化します。Miro 文書（チェックリスト付き）としてフォーマットします。
```

### 学んだ教訓を記録する

**目的：**学びを記録して再利用や今後の改善に活用する。

**Miro AI プロンプト：**

コピー

```
Miro ボードで選択した完了したプロジェクトから学んだ教訓を記録します。インサイトを次のように構成します: うまくいったこと、うまくいかなかったこと、次回にやりたいこと、そして将来のプロジェクトへの推奨事項。形式は Miro 文書で作成します。
```
