会社内の組織構造、階層、関係性を作成して視覚化することで、組織の効率を高め、計画を簡素化することができます。

従業員がボードに集結して話し合い、フィードバックを提供して組織図に共同で取り組むことで、方向性や戦略について全員の同意を得ることができます。リアルタイムのデータとコラボレーション ツールを使用することで、組織のリソースを効率的に割り当てて、現在と将来のニーズを確実に満たすことができます。

> **利用可能なプラン：**Free、Starter、Business、Education、Enterprise プラン

## 主な機能

- **CSV ファイルからデータをインポート**して、組織図に情報を入力できます
- **組織図を簡単に更新**するには、必要に応じて新しい CSV データをアップロードします。
- **組織図をカスタマイズ**するには、汎用的なカードでフィールドのオンとオフの切り替えや募集中の役割を設定します。
- **図の外観を変更**するには、色付きのブランチ、背景色、フィルターなど、ニーズに合わせてカスタマイズ可能な書式設定オプションを使用できます。
- **自動レイアウト****を使用**すると、カードの配置を合理化し、組織図を効率的に作成することができます。

## 組織図の作成

1. 組織図を作成する Miro ボードを開きます。
2. ボード左側の[作成ツールバー](../../getting-started/start-here/your-first-board/05-toolbars.md)に移動します。
3. **[他のアプリ]**（**+**）をクリックして、「組織図」を検索します。
4. **組織図**をクリックして、ボード上に組織図の下書きを作成します。
5. 組織図の下書きをクリックしてコンテキストメニューを開き、**[CSV をインポート]** をクリックして組織データをアップロードします。
6. Miro は自動的にデータを処理し、それに応じて組織図に入力します。

### 役割とチームの再割り当て

自動レイアウトなら、カードの再配置も簡単です。カードをクリックしてドラッグするだけで、役割とチームを再割り当てすることができます。

### カードの追加

さらにカードを追加するには、既存のカードを囲むプラスアイコンをクリックします。こうすると、必要に応じてチャートをさらにカスタマイズできます。

### カードのテキストフィールドの編集

カードのテキストフィールドをダブルクリックすると、名前、役割、チーム、説明および場所を編集できます。また、インポートしたカスタムフィールドを編集することもできます。

### 特定の情報の表示または非表示

コンテキストメニューにアクセスし、フィルターアイコンをクリックします。次に、選択ボックスを使用して、**[勤務地]** あるいは **[チーム]** の情報、またはインポートしたその他のカスタムフィールドの表示と非表示を制御します。現在採用中の役割を示すには、**[採用中]** オプションをオンにします。

### 組織チャート色の変更

背景色の変更、境界線の追加、ブランチ色のカスタマイズを行って、組織図をパーソナライズすることができます。
