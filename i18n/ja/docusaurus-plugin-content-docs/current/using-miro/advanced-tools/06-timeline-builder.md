:::tip
最近、新しい方法でタイムラインを作成できるようになりました。新しいベータ版[タイムライン](../formats/15-timeline.md)機能について詳しく知る。
:::

タイムラインビルダーを使えばタイムラインを素早く視覚化し、作業を整理することができます。手動でタイムラインを作成する手間を省くには、時間枠や間隔などのいくつかの設定を行い、ビルダーに作成作業を任せます。

### タイムラインビルダーのインストール

チームにアプリをインストールするには、[Miro マーケットプレイス](https://miro.com/marketplace/timelinebuilder/?backUrl=%2Fmarketplace%2F)に移動し、**アプリを取得**をクリックします。</span>その後、ビルダーをインストールするチームを選択します。

または、Miro のボード内からビルダーをインストールします。ツールバーの矢印アイコンをクリックし、検索バーにアプリ名を入力して、**[追加]**をクリックします。

:::warning
管理者以外のユーザーは、**アプリとインテグレーション**設定で管理者が許可していなければ、アプリをインストールすることができません。
:::

### タイムラインを追加

アプリの中にタイムラインビルダーがあります。ツールバーのアプリをドラッグすると便利です。

![drag_to_the_toolbar.gif](../../../../../../docs/using-miro/advanced-tools/images/21016941813522_drag%20to%20the%20toolbar.gif)
*作成ツールバーにタイムラインビルダーを追加*

アプリを選択したら、タイムライン設定を行うことができます。

**日付の設定**

- 週次のチーム計画、四半期ごとのロードマップ、または年次戦略計画を行う際には、状況に合わせて**間隔**を選択しましょう：時間、曜日、日、週、月、四半期、年
- 時間枠を **設定**（例：間隔として月を選んだ場合は 1 月〜5 月）

**スイムレーン**

- スイムレーンに**ラベル**を追加する（タイムラインに異なるストリームが含まれる場合は、マーケティング、製品、サポートなど）。スイムレーンを追加するには、プラスボタンをクリックします。

**スタイル**

- タイムラインに使用する色を選んでください。**パレット**には、青、緑、赤、ピンクの4つのオプションがあります
- 縦または横**方向**を選択する
- 代替行/列のシェーディングを有効化または無効化**します**

**挿入**をクリックしてタイムラインを作成します。

![timeline_settings.gif](../../../../../../docs/using-miro/advanced-tools/images/21016928851858_timeline%20settings.gif)
*タイムラインビルダーの設定をする*

### タイムラインにデータを追加する

タイムラインが作成されるとすぐに、[付箋](../essential-tools/14-sticky-notes.md)、[カード](../essential-tools/02-cards.md)（Jira カード、Asana カードなど）、[図形](../essential-tools/11-shapes.md)を使用するか、テキストを挿入するだけで情報を追加できます。タイムラインに画像を含む任意のオブジェクトをドロップして、イベントやタスクをマッピングします。
