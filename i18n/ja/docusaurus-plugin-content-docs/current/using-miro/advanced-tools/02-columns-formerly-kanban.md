ワークフローを視覚化し、チームでより多くのことを達成するために、当社の[カンバンフレームワーク](https://miro.com/templates/kanban-framework/)を活用しましょう。Miro のカンバンは、アジャイル開発から個人のタスクトラッキングまで、さまざまなユースケースで活用できます。

## カンバンの追加

ボードにカンバンを追加するには、**ツール、メディア、インテグレーション**（![icon-tools.svg](../../../../../../docs/using-miro/advanced-tools/images/29029892260754_icon-tools.svg)）から、またはツールバーで選んで、必要な場所をクリックします。

カンバンの大きさを変更するには、カンバンを選択し、ハンドルをクリックしながらドラッグします。

## 列とスイムレーン

カンバンに列とスイムレーンを追加して整理する方法は次のとおりです:

1. カンバンをクリックしてコンテキストメニューを表示します。
2. カンバンに**列を追加**または**スイムレーンを追加**のアイコンをクリックしてください。
   列は右側に追加され、スイムレーンは下部に追加されます。
3. 列やスイムレーンの並べ替えは、**三点リーダー** (**...**) アイコンをクリックし、必要な**移動**方向を選択します。
4. 列の見出しをダブルクリックして名前を変更します。

三点リーダー (**...**) メニューの **下**では、列とスイムレーンの追加、移動、名前の変更、削除や列の色を変更できます。

## カード

:::tip
[詳細はこちら](../essential-tools/02-cards.md)、Miro カードについて説明します。
:::

カードを追加するには、[カード](../essential-tools/02-cards.md)、スイムレーン内のプラスアイコンをクリックします。または、既存のカードをボードからカンバンにドラッグします。

カードをドラッグして、別の列やスイムレーンに移動することができます。

:::warning
カンバン内のカードは[ロック](../working-on-the-board/17-locking-content-on-the-board.md)されたり、[グループ化](../working-on-the-board/08-structuring-board-content.md)することはできません。
:::

ショートカットを使用して作業を効率化しましょう:[ショートカット](../working-on-the-board/06-shortcuts-and-hotkeys.md):

- **Enter または Return** で新しいカードを作成
- **Tab** で列内の次のカードに移動
- **Tab** + **Shift** で列内の前のカードに移動
- **←→****↑↓** でカードを選択
- **Ctrl** + **C** と **Cmd** + **V**（*Windows の場合*）、**Cmd + C** と **Cmd + V**（*Mac の場合*）でカードを複製
- **Ctrl + ↑↓**（*Windows の場合*）、**Cmd + ↑↓** （*Mac の場合*）で新しいカードを上または下に追加
- **Escape** で編集モードを終了

## よくある質問

**カンバンに画像を追加するオプションはありますか？**

いいえ、追加できるのは[カード](../essential-tools/02-cards.md)のみです。

**カンバンに[Jira カード](../../integrations-apps/atlassian/03-jira-cards.md)を追加できますか？**

はい、他のカード（[Asana カード](../../integrations-apps/asana/01-asana-cards-legacy.md)、[Azure カード](../../integrations-apps/microsoft/03-azure-cards.md)）と同様に、Jira カードも追加できます。Jira カードの設定方法については、[こちらのページ](../../integrations-apps/atlassian/12-deprecated-–-set-up-and-disable-jira-cards-using-oauth-1.0.md)をご覧ください。

**カードの期限を自動的にリマインドする機能はありますか？**

いいえ、現時点では対応しておりません。
