[Miro のマインドマップ](https://miro.com/mind-map-software/)を使用すると、世界的に利用されるダイアグラムツールを応用して、コンテンツを階層的、また視覚的に整理することができます。

> **利用可能なソフトウェア：**ブラウザー版、[デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)、[タブレットアプリ](../../getting-started/apps-for-devices/11-tablet-app.md)、[モバイルアプリ](../../getting-started/apps-for-devices/08-mobile-app.md)（機能制限付き）

### Miro のマインドマップの作成方法

作成ツールバーからMiro AI を利用

1. 作成ツールバーから**マインドマップ**をみつけます。アイコンをツールバーにドラッグすると便利です。![mindmap_on_the_toolbar.gif](https://help.miro.com/hc/article_attachments/21017528565394)*ツールバーのマインドマップ*
2. **マインドマップ**を選択し、ボードの任意の場所をクリックして、親ノードを追加します。これが、マインドマップの始点になります。各側面のプラス記号は、ブランチを広げる場所を示し、子ノードを作成することができます。マインドマップは、縦横どちらにも展開させることができます。![starting_a_mindmap.gif](../../../../../../docs/using-miro/advanced-tools/images/21017515486610_starting%20a%20mindmap.gif)*親ノードの作成と横型のマインドマップのスタート*

以下のショートカットを使用して、作成プロセスをスピードアップさせることができます。

- **Return** キー：兄弟ノードの作成と編集開始
- **Shift + Return** キー：ノード内での改行
- **Tab** キー：新しい子ノードの作成
- **矢印**キー：ノード間の移動
- **Ctrl + C** と **Ctrl + V**（*Windows*）/ **Cmd + C** と **Cmd + V**（*Mac*）：ノードの複製
- **Escape** キー：編集モードの終了
- **Delete** キー：ノード全体の削除
- **Ctrl**（*Windows*）/ **Cmd**（*Mac*）（長押し）：自動再割り当ての停止

ノードを選択、ドラッグすることで、キャンバス上の位置を変更することができます。

1. 親ノードを作成し、コンテンツを入力します。
2. **Miro AI**  のアイコンをクリックします。
3. [**マインドマップを生成する**] をクリックします。
   ボード上で親ノードの周りにマインドマップが作成されます。マインドマップを保存、再試行、破棄するオプションがあります。
4. あなたのニーズに合わせてマインドマップを編集し続けましょう。

Miro AI は、質問で拡張、アイデアで拡張、トピックで拡張など、他にもマインドマップを作成する方法を提供しています。Miro AI について詳しくは、[AI による作成と編集の概要](../miro-ai/03-create-with-ai.md)の「AI によるマインドマップ」のセクションをご覧ください。

## マインドマップの操作

マインドマップには、ノードを限りなく追加することができます。必要に応じてノードを移動させることや、自動レイアウトを使用して見た目をすっきりさせることもできます。子ノードを他の親ノードに再割り当てすることや、ノードを完全に削除することもできます。

### ノードの移動、サイズ変更、追加、削除

マインドマップでノードを並び替えると、すべての子ノードも自動的に並び替わります。これは、**自動レイアウト**がデフォルトでオンになっているためです。オートレイアウトをオンまたはオフにするには、親ノードをクリックし、コンテキストメニューで **[自動レイアウト]** のトグルをオンまたはオフにしてください。

![image1.gif](https://help.miro.com/hc/article_attachments/21017528577042)*自動レイアウトによるノード配置の調整*

**自動レイアウトがオフになっている場合**でも、すべての子ノードの配置を合わせることができます。マインドマップの配置整理ができたたら、親ノードをクリックし、コンテキストメニューの三点リーダー（...）をクリックして、**[ノードをレイアウト]** を選択します。

![image2.gif](https://help.miro.com/hc/article_attachments/21017528578322)

ノードをドラッグするだけでするだけで、子ノードを別の親ノードに再割り当てすることができます。

:::note
ノードを再割り当てではなく、移動させたい場合は、**Ctrl**（*Windows*）/ **Cmd**（*Mac*）を長押ししてください。
:::

![reassign_nodes.gif](https://help.miro.com/hc/article_attachments/21017515585810)*ノードの再配置*

複雑な概念を視覚化したい場合、ノードリンクを使用すれば、マインドマップのアイデア間の依存関係を表すことができます。

![create_dependencies.gif](https://help.miro.com/hc/article_attachments/21017528569106)*ノード同士を繋ぐ*

マインドマップを[選択](../working-on-the-board/10-working-with-objects.md)して、白い点をドラッグすることで、サイズの変更もできます。

![changing_size.gif](https://help.miro.com/hc/article_attachments/21017528569874)*マインドマップのサイズ変更*

ノードにテキストを追加するには、ノードをダブルクリックします。

:::note
**Shift + Return** で、ノード内での改行ができます。
:::

ノード内で箇条書きリストを作成するには、**「-」**を入力して、スペースキーを押します。番号付きリストを作成するには、行の先頭に **1.** を入力します。
2 番目の（または 3 番目 / 4 番目の）行から始まる箇条書きリストを作成するには、**Cmd + Enter**（*Mac の場合*）または **Ctrl + Enter**（*Windows の場合*）で新しい行を作成します。

![adding_text_to_a_node.gif](https://help.miro.com/hc/article_attachments/21017515591698)*ノードに追加テキストを挿入*

ノードを削除するには、**Delete**（削除）キーを押すか、コンテキストメニューの三点リーダーをクリックし、**[削除]** を選択します。ノードはすべての子ノードと一緒に削除されます。

![delete_a_node.jpg](https://help.miro.com/hc/article_attachments/21017515592210)*ノードの削除*

:::warning
マインドマップのノードは、[ロック](../working-on-the-board/17-locking-content-on-the-board.md)や、[グループ化](../working-on-the-board/08-structuring-board-content.md)をすることはできません。
:::

### マインドマップ構成要素のフォーマット

マインドマップのスタイルを選択し（ノードは曲線または直線を使ったものの利用が可能）、向きを変更することができます。また、カラフルで明るいマインドマップにしたい場合は、**[ランダムに設定]** ツールを使用してください。

![changing_mind_map.gif](../../../../../../docs/using-miro/advanced-tools/images/21017515488658_changing%20mind%20map.gif)*マインドマップのスタイル*

すべてのマインドマップの主な構成要素はテキストなので、さまざまな文字スタイルのオプションをその簡略版から利用することができます。なお、マインドマップの視覚的な整合性を維持するため、親ノードの文字サイズを変更すると、マインドマップ全体にも反映されます。

![mind_map_font_size.gif](https://help.miro.com/hc/article_attachments/21017515583890)*マインドマップのフォントサイズの変更*

コンテキストメニューのさまざまなオプションを使用して、個々のノードの変更が可能です。スタイルや色の変更、テキストのハイライト、また URL の追加などができます。現在、フォントを変更することはできません。

![changing_a_node.gif](https://help.miro.com/hc/article_attachments/21017515591186)*ノードの変更*

### ノードの種類の変更

ノードには 4 つの表示スタイルがあります。

- **なし** - 枠なし
- **カプセル形** - 楕円のカプセル形の枠
- **角丸長方形** - 角が丸い長方形の枠
- **長方形** - 長方形の枠

ノードの種類を追加するには以下を実行してください。

1. 変更を反映させたいノードを選択します
2. ツールバーの **[ノードの種類]** のボタンをクリックします
3. お好みのノードの種類のスタイルを選択します
4. スタイルが適用され、ノードはブランチと同じ色に変わります
5. ノードの色や塗りつぶしの不透明度を変更して、視覚的なインパクトを高めることもできます。
   ![mind_map_changing_node_type.gif](https://help.miro.com/hc/article_attachments/21017528581010)*ノードの種類と色のオプションを変更*

### マインドマップの展開と折りたたみ

細部にとらわれて全体を見失うことなく、あらゆるサイズのマインドマップを構築しましょう。ブランチの展開と折りたたみをすることで以下を実行できます。

- マインドマップの全体像をより的確につかめる
- 作業中に適切な度合いの詳細に集中できる
- ユーザーがマインドマップを簡単にナビゲートできる
- オーディエンスに特定のレベルの詳細だけを提示する

**ブランチの折りたたみと展開の方法**

折りたたむには、ブランチ上にマウスオーバーして、マイナス（**-**）ボタンをクリックします。そのブランチに添付されたコメントも、非表示になります。

ブランチを折りたたむと、非表示のノードとコメント数が表示されます。ブランチを再び展開するには、数字をクリックするだけです。

![Expand_and_collapse.gif](https://help.miro.com/hc/article_attachments/21017515596178)*マインドマップのブランチの展開と折りたたみ*

### マインドマップのエクスポート

マインドマップを、画像または PDF ファイルとしてエクスポートすることができます。エクスポート機能の詳細については、[こちらのページ](../import-and-export/export/03-how-to-export-your-board.md)をご覧ください。

マインドマップを画像としてエクスポートするには、以下を実行してください。

1. **[このボードをエクスポートする]** アイコンをクリックします。何も選択する必要はありません。
2. **[画像として保存]** を選択します。
3. ハンドルをドラッグして、マインドマップを選択します。
4. 希望のサイズを選択し、**[エクスポート]** をクリックします。ここで PDF を選択することもできます。
5. このファイルは、ボード名をファイル名としてローカルのハードドライブに保存されます。
   ![main_menu_mindmap_export_image.gif](https://help.miro.com/hc/article_attachments/21017528581650)
*マインドマップを画像としてエクスポート*

マインドマップを PDF としてエクスポートするには、以下を実行してください。

1. **[このボードをエクスポートする]** アイコンをクリックします。何も選択する必要はありません。
2. [PDF として保存] を選択しますマインドマップのフレームがまだ存在しない場合は、フレームを作成するよう求められます。
3. フレームを作成するには、ポップアップボックスの **[フレームを作成]** ボタンをクリックします。左側のオプションからスタイルを選択します。マインドマップが収まるようにフレームのサイズを変更します。
4. **[このボードをエクスポートする]** をもう一度クリックし、**[PDF として保存]** を選択します。
5. 最適な PDF オプションを選択し、**[エクスポート]** をクリックします。
   ![main_menu_mindmap_export_pdf.gif](https://help.miro.com/hc/article_attachments/21017528582546)
*マインドマップを PDF ファイルとしてエクスポート*

マインドマップを選択し、右クリックして、**[画像としてコピー]** を選択すると、ボード全体ではなく、選択されたオブジェクトだけをコピーすることができます。この操作は、マインドマップをエクスポートするわけではありませんが、コピーをボード上に配置してくれます。

## よくある質問

ノードはいくつまで作成することができますか？

作成できる（親または子）ノード数に制限はありません。

ノードの移動 / 再割り当てはできますか？

はい、ノードをドラッグするだけ可能です。

ノードに画像を添付することはできますか？

ノードに画像を添付するオプションは現在ありませんが、バックログの案件となっています。

データをマインドマップからインテリジェント CSV データにエクスポートできますか？

はい、[Mindmap ダウンローダー](https://miro.com/marketplace/mindmapdownloader/?backUrl=%2Fmarketplace%2F)を使用してください。

同じ子ノードに複数のノードを接続できますか？

対応策として、[線と矢印](../essential-tools/05-connection-lines.md)を使用して、子ノードを複数の親ノードにリンクすることができます。

マインドマップを別の Miro のボードにコピーできますか？

はい、他のコンテンツと同様に、コピーして貼り付けすることができます。親ノードを選択し、コンテキストメニューの三点リーダーをクリックし、**[コピー]** を選択し、別のボードにウィジェットを貼り付けます。**[Ctrl + C/Ctrl + V](../working-on-the-board/06-shortcuts-and-hotkeys.md)**[*（Windows）*](../working-on-the-board/06-shortcuts-and-hotkeys.md)**[もしくは Cmd + C/Cmd + V](../working-on-the-board/06-shortcuts-and-hotkeys.md)***[（Mac）](../working-on-the-board/06-shortcuts-and-hotkeys.md)*も使えます。ボード所有者が[ボードコンテンツのコピーを許可](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)していることを確認してください。

マインドマップ全体をボード上で移動させるにはどうすればよいですか？

親ノードを選択して移動させます。

個々の子ノードのテキストサイズを変更できますか？

いいえ、現時点では、親ノードのサイズの変更のみが可能で、親ノードのサイズ変更は、マインドマップ全体の変更につながります。

[付箋](../essential-tools/14-sticky-notes.md)、[テキストブロック](../essential-tools/16-text.md)、[カード](../essential-tools/02-cards.md)、その他のウィジェットをマインドマップのノードに変換できますか？

いいえ、現在はできません。付箋 / カード / テキスト ブロックからテキストをコピーして、ノードに貼り付けすることはできます。

2 つの既存のノードの間にノードを挿入するにはどうすればよいですか？

ノードの 1 つを別のノードに一時的に再割り当てし、新しいノードを作成し、割り当てし直します。
![insert_a_node.gif](https://help.miro.com/hc/article_attachments/21017528574738)*既存のノードの間に別のノードを挿入*

:::tip
お求めの機能がまだない場合は、コミュニティーの[ウィッシュリスト](https://community.miro.com/wish-list-32)でアイデアをぜひ共有してください。
:::

マインドマップの使用上で問題が発生した場合は、[以下のトラブルシューティングのヒント](../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md)をお試しください。
