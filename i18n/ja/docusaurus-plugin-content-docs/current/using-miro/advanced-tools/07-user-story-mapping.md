高速で柔軟なフレームワークを使用して、ユーザーストーリー マップを迅速に作成できます。 **ユーザー ストーリー マッピング**は、ジェフ・パットンが開発した方法を使って作成されたインタラクティブなテンプレートです。このツールを使えば、アジャイル開発においてユーザーストーリーを使った作業をずっと簡単に行うことができます。これは、バックログの改良版で、製品の説明、優先順位付け、リリースの計画をサポートすることができます。

> 利用可能バージョン：**ブラウザー版**、[デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)、[タブレットアプリ](../../getting-started/apps-for-devices/11-tablet-app.md)、[モバイルアプリ](../../getting-started/apps-for-devices/08-mobile-app.md)（機能制限付き）

### ユーザーストーリー マップの追加

ユーザーストーリー マップツールをツールバーに取得するには、矢印をクリックしてアプリを開き、**ユーザーストーリー マップ**を検索し、インストールします。

Screenshot_background_template__7__2_.jpg
ユーザーストーリー マップアプリの追加

アプリに新しいアイコンが表示され、ツールバーにドラッグすると、素早くアクセスできます。

adding_USM_to_toolbar.gif
ツールバーのユーザーストーリー マッピングアイコン

ボードにユーザーストーリー マップを追加する簡単な方法が 2 つあります。

- ツールバーから**ユーザーストーリー マップ**のアイコンをドラッグし、ボードにドロップします。
- **ユーザーストーリー マップ**のアイコンを選択し、ボードをクリックしてください。

USM.jpg
ユーザーストーリー マップ

機能を最大限に体験していただくためには、ボードを **100％** にズームしてユーザーストーリー マップを作成してください。

以下の[ショートカット](../working-on-the-board/06-shortcuts-and-hotkeys.md)を使用して、作成プロセスをスピードアップしてください。

- **Return キー**で、選択したカードを編集し、新しいカードを作成する
- **Tab キー**で、新しいアクティビティ、タスク、またはストーリーを作成する
- **矢印キー**でユーザー ストーリーマップの要素間を移動する
- **Escape キー**でカードの編集モードを終了する
- **Ctrl** + **←→↑↓**（*Windows の場合*）/**Cmd** + **←→↑↓**（*Mac の場合*）でカードを追加する
- **Ctrl** + **C** と **Ctrl** + **V**（*Windows の場合*）/**Cmd + C** と **Cmd + V**（*Mac の場合*）でカードを複製する
- **Delete キー**でカードを削除する

### カードの編集

[カード](../essential-tools/02-cards.md)を上方にスクロールすると、カードの見出しのみ編集することができます。カードの色の変更、タグの追加、チーム メンバーへのタスクの割り当て、リンクと日付の追加など、その他の設定はすべてコンテキスト メニューで行うことができます。**[展開]** アイコンをクリックして、カードの詳細を追加または表示します。

カードの編集の詳細については、[こちらの役立つ記事](../essential-tools/02-cards.md)をご覧ください。

:::warning
USM 内のカードを[ロック](../working-on-the-board/17-locking-content-on-the-board.md)することや、[グループ化](../working-on-the-board/08-structuring-board-content.md)することはできません。
:::

### リリース

リリースを追加するオプションは、製品の開発のイテレーションの分離に役立ちます。リリースを追加する方法が 2 つあります。

- ポップアップ コントロール上でリリース「**+**」をクリックして、新しいリリースを追加する
- コンテキストメニューで上記または下記のリリースを追加します。移動、名前の変更、削除もできます。

### USM 内の Jira カード

特定のリリースに [Jira カード](../../integrations-apps/atlassian/03-jira-cards.md)をドラッグ&ドロップすると、ユーザーストーリー マッピングのフレームワークに簡単に挿入することができます。

[カードを簡単に Jira カードに変換](../../integrations-apps/atlassian/03-jira-cards.md)することもできます。USM **タスク**ラインにあるカードを Jira カードに変換することはできません。
