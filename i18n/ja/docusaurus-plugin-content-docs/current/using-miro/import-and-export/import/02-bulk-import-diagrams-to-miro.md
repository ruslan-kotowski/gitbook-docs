ダイアグラムをPDFまたはVSDX形式で一括インポートできます。

:::note
一部のソースアプリケーションでは、1種類のファイルタイプのみがサポートされています。詳細はインポートファイルタイプサポートを参照してください。
:::

## Miroへのダイアグラムの一括インポート方法

ダイアグラムをMiroにインポートするには、まずソースアプリケーションからPDFまたはVSDX形式でファイルをエクスポートしてください。その後、以下の手順を完了してください。

1. Miroのダッシュボードで、図をインポートしたいスペースに移動し、**新規作成**（**+**）をクリックします。
   ![](../../../../../../../docs/using-miro/import-and-export/import/images/32657459157138_image.png)
2. **インポート** > **\{source\} からインポート** をクリックします。例えば、**Mural からインポート**。
   **\{source\} からインポート** モーダルが開きます。
3. 画面の指示に従います。
4. （オプション）インポート先のスペースを変更するか、プラス（**+**）ボタンをクリックして、新しいインポート先のスペースを作成します。
5. **ファイルを*****x*****インポート** をクリックします。

## インポートファイルタイプサポート

| ソース | ファイルタイプ |
| --- | --- |
| Conceptboard | PDF, VSDX |
| Lucidchart | PDF, VSDX |
| Lucidspark | PDF, VSDX |
| Mural | PDF |
| Visio | VSDX |
