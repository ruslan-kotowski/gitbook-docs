ボードにファイルを追加するのに最も簡単な方法は、デスクトップからドラッグ ＆ ドロップすることです。画像、PDF ファイル、Google ドライブのドキュメント、MS Office ファイルを追加できます。対応ファイル形式の全リストは[この記事](../../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md)で確認できます。新しいファイルはコンピューターまたはウェブから追加可能です（最大ファイルサイズは30MB、最大画像解像度は32MP、最大サイズは8192x4096ピクセル）。

> **設定者:** [ボード編集者](../../sharing-boards/01-board-access-rights.md)
> **利用可能:** すべての Miro プラン（Free プランでは埋め込みビデオ再生不可）

### デバイスからファイルを追加

デバイスからファイルをアップロードするには、作成ツールバーで**アップロード**を選択します。オプションが隠れている場合は、**他のツール**の矢印 (>>)をクリックし、ツールバーにボタンを追加してください。**マイデバイス**をクリックします。

![upload_on_the_toolbar_greybg.gif](../../../../../../../docs/using-miro/import-and-export/import/images/21016967591442_upload_on_the_toolbar_greybg.gif)
*ツールバーのアップロードボタン*

これによりダイアログボックスが開き、ボードにアップロードしたいファイルを選択できます。ファイルを選択し、**開く**をクリックすると、ファイルがアップロードされ、ボードに表示されます。

コンピューターからファイルをアップロードするもう一つの簡単な方法は、ドラッグしてボードに置くことです。

:::note
サポートされているファイルフォーマットのリストはこちらで確認できます[こちら](../../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md)。
:::

アップロードしたファイルとインタラクションできます。サイズを変更したり、回転させたり、ページをめくったり、ページを抽出したりできます。

![change_an_uploaded_object_greybg.gif](../../../../../../../docs/using-miro/import-and-export/import/images/21016967592850_change_an_uploaded_object_greybg.gif)
*アップロードされたPDFファイルでの操作*

モバイルアプリを使用する場合は、[モバイルアプリ](../../../getting-started/apps-for-devices/08-mobile-app.md)のボードの右下にあるプラスアイコンをタップして**アップロード**を選択します。クリップボードからファイルを貼り付けたり、写真を撮ったり、モバイルライブラリーから画像を選んだりすることができます。モバイルデバイスからのPDFファイルのアップロードは、現在サポートされていません。

![upload on mobile.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005106578_upload%20on%20mobile.png)
*モバイル デバイスからファイルをアップロード*

### URL リンクでファイルを追加

ソースへの直接リンクを使用して、ウェブからファイルをアップロードするには、**URL から** **アップロード**を選択します。

*![Upload via URL.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005103890_Upload%20via%20URL.png)**ツールバーの URL からアップロード*

次に、YouTube や Vimeo 動画などのウェブからファイルへの直接 URL リンクを貼り付けます。

![upload via URL modal.png](../../../../../../../docs/using-miro/import-and-export/import/images/21016967594898_upload%20via%20URL%20modal.png)
*URL リンクからアップロード*

:::note
Embedded video playback is unavailable on Free プランおよびベーシックライセンスのユーザーには埋め込まれたビデオの再生機能は利用できません。
:::

動画を見るには、**再生**アイコンをダブルクリックします（追加したファイルは自動再生しません）。また、コンテキストメニューで**ソース**ページに移動し、他の機能を使用することもできます。

Miro に加えられた動画は、早送りや字幕の追加、動画の画質変更などが可能で、アップロードした動画をボードから直接管理することができます。

![video embed.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005108114_video%20embed.png)
*動画ソースに移動するオプション*

別の方法として、**Ctrl+C**/**Ctrl+V**（*Windows の場合*）または **Cmd+C/Cmd+V**（*Mac の場合*）のショートカットを使用して直接ボードにリンクを投稿することができます。

プレビューなしでボードに URL を貼り付けるには、[テキストツール](../../essential-tools/16-text.md)を使用し、テキストボックスにリンクを貼り付けます。

### 他のサービスからファイルをアップロード

また、[Google Drive](../../../integrations-apps/google/05-google-drive.md)、[Dropbox](../../../integrations-apps/more-integrations/06-dropbox.md)、[Box](../../../integrations-apps/more-integrations/05-box-legacy.md)、[OneDrive](../../../integrations-apps/microsoft/06-onedrive.md)、[Adobe CC](../../../integrations-apps/adobe/02-adobe-creative-cloud.md)からファイルをアップロードできます。すべてのオプションは、**アップロード**メニューで利用できます。詳細は関連記事をご覧ください。

なお、[ビジター](../../sharing-boards/08-collaboration-with-visitors.md)はこのオプションを使用できません。

![upload from other services.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005105810_upload%20from%20other%20services.png)
*別のストレージサービスからファイルをアップロードするオプション*

### アップロードしたファイルをライブラリーに保存

ファイルを選択し、コンテキストメニューの三点リーダーをクリックして、**保存済みファイルに追加**を選択することで、アップロードしたファイルを自分の Miro ライブラリーに保存し、後でこのチームで使用することができます。これは、PDF、画像、プレゼンテーション、Google ドキュメント、その他のファイルにも利用できます。

![add to saved files.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005108882_add%20to%20saved%20files.png)
*保存済みファイルにファイルを追加するオプション*

保存済みファイルは、ツールバーの**[保存済みファイル]**フォルダーにある**[アップロード]** メニューで利用できます。ライブラリーからファイルを追加するには、クリックするか、ボードにドラッグ＆ドロップします。保存済みファイルは、そのファイルが所属しているチームのボードでのみアクセス可能であることにご注意ください。

![saved files.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005109522_saved%20files.png)
*ツールバーの保存済みファイル*

ライブラリーからファイルを削除するには、そのファイルの上にカーソルを合わせて、**[ゴミ箱]** アイコンをクリックしてください。

![delete a saved file.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005111314_delete%20a%20saved%20file.png)
*ゴミ箱アイコンをクリックして保存済みファイルからファイルを削除*

**保存済みファイルに追加**オプションが非アクティブ（灰色）になっていて、**このボードではこのツールは利用できません**というエラーメッセージが表示された場合は、ボードが保存されているチームのメンバーではないため、アクションを完了する権限がないことを意味します。

### 複数ページの文書を分割する

> **利用可能な環境:** ブラウザ版、[デスクトップアプリ](../../../getting-started/apps-for-devices/05-desktop-app.md)

ドキュメントやPDF、Powerpointファイルをページごとに展開したり、ボード上に配置してページに直接コメントを残したりすることで、チームのコラボレーションを促進できます。

PDFまたはPowerpointファイルを特定のページ数に分割する手順は以下の通りです。

1. ファイルをボードにアップロードします。
2. ファイルをクリックし、コンテキストメニューから**ページの抽出**アイコンを選択します。

   > ✏️ このオプションは、[カーソル（選択）モード](#mini)でのみ利用可能です。メニューにオプションが表示されない場合は、**V**キーを押すか、ツールバーでカーソルを選択し、再度オブジェクトをクリックしてください。
3. ダイアログで、ファイルをどのように分割するかを選択します — 全ページまたは特定のページのみを選択し、**抽出**をクリックします。

展開されたページは元のファイルのすぐ下に表示されます。元のファイルが不要な場合は、削除できます — すべての抽出したページはボードに残ります。

### PDF ファイルをアップロードする際に起こり得る問題

一部の PDF ファイルは Miro のボードにアップロードできず、読み込んでいる間、ぐるぐるのアイコンのままとなったり、灰色のイメージになりエラーサインが表示されたりします。この問題が発生した場合、必ず次を確認してください:

- PDF ファイルが 30 MB 以下であること
- 安定したインターネット接続を使用していること
- デバイスが[システム要件](../../troubleshooting-technical-questions/technical-guidelines/01-system-requirements.md)を満たしていること

それでもボードにファイルをアップロードできない場合は、ファイル自体に問題がある可能性があります。複雑な PDF ファイルの一部は、当社の技術的制限のため、表示できないことがあります。これは通常、多量の要素や詳細な内容を含む PDF で発生します。当社は、レンダリングツールの向上に努めていますが、現時点では以下の対応をしてください:

- 作成に使用したソフトウェアで、PNG、または JPEG 形式で保存する
- もしくは、オンライン ファイル コンバーター（`https://www.freepdfconvert.com/pdf-to-png` や `https://cloudconvert.com/` などのいずれのコンバーターでも使用可）を使用して、PDF ファイルを PNG、または JPEG に変換する

:::note
もしMiroボードへのファイルアップロードに関して他の問題が発生した場合は、トラブルシューティングのステップを [この記事](../../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md)で試してみてください。
:::

## よくある質問

**自分のデバイスから Miro のボードに動画ファイルをアップロードすることはできますか？**

いいえ、ただし簡単に動画を埋め込むことは可能です。こちらのガイドをご覧ください: [メディアをボードに埋め込む](../../../integrations-apps/integrations-basics/03-embed-integrations-on-a-miro-board.md)。

**Excel や CSV ファイルから編集可能なデータをインポートできますか？**

スプレッドシート（.xslx や CSV ファイルを含む）は、閲覧専用ファイルとしてインポートすることや、テーブルや表を作成するために利用できます。詳細については、[テーブル](../../formats/14-tables.md)または[表](../../advanced-tools/05-grid.md)をご覧ください。

**ボードからファイルをダウンロードすることはできますか？**

はい、これは[ボードコンテンツ設定](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)で許可されている場合です。ファイルをダウンロードするには、ファイルを選択し、コンテキストメニューから**ダウンロード**を選択します。

**アップロードされた PDF ファイルのリンクをクリックできますか？**

いいえ、現時点では対応しておりません。
