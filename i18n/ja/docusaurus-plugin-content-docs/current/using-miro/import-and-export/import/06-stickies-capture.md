付箋キャプチャーを使用すると、実際の付箋を完全に編集可能な[Miro の付箋](../../essential-tools/14-sticky-notes.md)に変換できます。[Jira タスク](../../../integrations-apps/atlassian/03-jira-cards.md)やデジタル図形、[テンプレート](../../../getting-started/start-here/your-first-board/04-templates.md)などの一部にして、共有してリアルタイムでコラボレーションしましょう。

:::warning
付箋キャプチャーを利用するには Miro AI を有効にする必要があります。
:::

### スマートフォンで付箋を変換する方法

1. [Miro モバイルアプリ](../../../getting-started/apps-for-devices/08-mobile-app.md)をダウンロード ([iOS](https://apps.apple.com/us/app/miro-formerly-realtimeboard/id1180074773), [Android](https://play.google.com/store/apps/details?id=com.realtimeboard))。
2. 付箋を配置するボードを開きます。
3. プラス記号をタップしてメニューを開き、**付箋キャプチャー**アイコンを選択します。
   ![stickies_capture_on_mobile.jpg](../../../../../../../docs/using-miro/import-and-export/import/images/21017004784146_stickies%20capture%20on%20mobile.jpg)
   *モバイルアプリのツールバーの付箋キャプチャー*
4. 既存の写真を選択するか、新たに写真を撮ります。ファイルサイズは最大 15 MB までアップロードできます。
   ![choose_a_photo.jpg](../../../../../../../docs/using-miro/import-and-export/import/images/21016967314578_choose%20a%20photo.jpg)*写真を撮影するか、ライブラリーから選択して付箋をキャプチャーするオプション*
5. 正しく認識されない付箋がある場合は、それらの付箋をタップして輪郭を追加または編集します。次に**ボードに追加する**をタップします。トグル **テキストへの変換** を有効化して、付箋をボードで編集可能にしてください。 *![capture_stickies.jpg](../../../../../../../docs/using-miro/import-and-export/import/images/21017004786578_capture%20stickies.jpg)**付箋をキャプチャー*
   > 付箋の選択の編集に多くの時間を費やさないようにしましょう。どちらにしても Miro 付箋に変換されます。
6. キャプチャーされた付箋がボードに表示されます。文字や色などを変更できます。
    ![digitized_stickies.jpg](../../../../../../../docs/using-miro/import-and-export/import/images/21016967316498_digitized%20stickies.jpg)
   *Miro の付箋キャプチャーでデジタル化された付箋*

:::warning
付箋のテキストが認識されない場合は、このメモはボードに画像として表示されます。
:::

:::note
付箋キャプチャーがデジタル化できるのは*英語*のテキストのみです。ただ、手順 5 で **テキストに変換** トグルをオフにすると、付箋を画像としてデジタル化することは可能です。
:::

### [タブレットアプリ](../../../getting-started/apps-for-devices/11-tablet-app.md)またはウェブ版で付箋を変換する方法

1. 付箋を追加したいボードを開きます。
2. ツールバーの**付箋キャプチャー**アイコンをタップします。
   ![stickies_capture.jpg](../../../../../../../docs/using-miro/import-and-export/import/images/21016967310738_stickies%20capture.jpg)
   *タブレットアプリのツールバーで付箋キャプチャー*
3. デバイスから既存の写真を選択します。
4. 正しく認識されない付箋がある場合は、それらの付箋をクリックして輪郭を追加または編集します。次に**ボードに追加**をタップします。
5. キャプチャーされた付箋がボードに表示されます。付箋の文字や色を変更したり、タグを追加したりなどの編集が可能です。

:::tip
簡単なルールに従うことで、デジタル化された付箋は、はるかに見やすくなります。

ー付箋の色と対比する濃い色のフェルトペンでノートを書く
- 付箋を重ねないでください
- モノクロの表面に付箋を別々に貼り付ける
- 明るい部屋で写真を撮影し、暗い影ができないようにする
:::
