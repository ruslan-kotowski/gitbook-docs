他のサイトにMiroのコンテンツを埋め込む場合、そのサイトがお客様のデバイス上でMiroのクッキーにアクセスする必要がある場合があります。これらのクッキーは、ユーザーセッション、プリファレンス、その他の機能の維持に役立ちます。ユーザーは埋め込みボードがMiro.comのクッキーを使用することを許可するよう選択することができます。

## クッキーを許可するメリット

- Miroにログインしているユーザーは、埋め込みボードにログインしたままになります。
- リフレッシュ後も、ユーザーは埋め込みボードにログインしたままです。
- クッキーに依存するMiroの機能が完全に機能するようにします。

## クッキーを許可する方法

1. 埋め込みMiroボードのあるウェブサイトまたはアプリにアクセスしてください。
2. プロンプトが表示されたら、[**クッキーを許可]**をクリックし、ブラウザから表示されるその他のプロンプトを確認します。
3. すでにMiroにログインしている場合は、埋め込みボードでもログインしたままになります。そうでない場合は、再度ログインするだけで、次回埋め込みボードにアクセスしたときにログインされます。

:::note
プライベート ボードにアクセスするには Miro にログインする必要がありますが、パブリック ボードにはログインせずにアクセスできます。
:::
