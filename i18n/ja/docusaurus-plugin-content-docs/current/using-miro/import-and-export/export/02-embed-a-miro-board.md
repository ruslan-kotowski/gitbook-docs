あらゆる Miro ボードやボード内の特定のアイテム（フレームまたは形式）をサポートされているアプリやウェブサイトに埋め込むことで、チームメイトがツールを切り替えずにコンテキスト内で作業できます。

埋め込みはボードの[共有設定](../../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)を継承します：

- **パブリックリンクオン** - リンクを持っている人なら誰でも閲覧可能（有料プランや Education プランの場合、コメントや編集も可能）。
- **パブリックリンクオフ** - 招待された協力者のみがサインイン後に埋め込みを開くことができます。

[Enterprise 管理者](../../../plans-billing/miro-plans/04-enterprise-plan.md)は[セキュリティ設定](../../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md)でパブリックリンクの利用を管理できます。

## 埋め込み方法を選択

Miro はボードを埋め込むための2つの方法を提供しています：

- **対応アプリを使用**:

  - Zoom、Teams、Confluence、Jira、Notion などのプラットフォーム内で作業する。
  - ネイティブのインテグレーション機能とスムーズなワークフローを求めている。
  - ユーザーはその特定のプラットフォームを通じて主に操作することになる。
  - 最も簡単なセットアッププロセスが必要。
- **埋め込みコードを使用**:

  - ウェブサイト、ブログ、またはカスタムプラットフォームへの埋め込み。
  - WordPress、Webflow、または他のウェブビルダーを使用して作業する。
  - サイズや外観に対するより多くのコントロールが必要。
  - プラットフォームが iFrames をサポートするが、ネイティブな Miro インテグレーションがない。

## 対応アプリにボードを埋め込む

Miro には、Miro ボードを簡単に共有できるさまざまな対応アプリがあります。対応アプリには以下が含まれます：

- [Zoom](../../../integrations-apps/zoom/02-miro-app-for-zoom-user-guide.md)
- [Webex](../../../integrations-apps/more-integrations/10-miro-for-webex.md)
- [Microsoft Teams](../../../integrations-apps/microsoft/microsoft-teams/02-miro-for-microsoft-teams-user-guide.md)
- [Jira](../../../integrations-apps/atlassian/02-miro-for-jira-cloud.md)
- [Confluence](../../../integrations-apps/atlassian/01-miro-for-confluence.md)
- [Notion](https://miro.com/marketplace/notion-embed/)
- [Coda](https://miro.com/marketplace/coda-embed/)
- [Productboard](https://miro.com/marketplace/productboard-embed/)
- Medium

Miro ボードを別のアプリに埋め込むと、アプリのユーザーに特化したアクセス権を設定でき、アプリ内でのボードの閲覧、コメント、編集を許可できます。Miro 側のボードへのアクセス権は影響を受けません。[埋め込みボードの共有とアクセス権の機能](../../../integrations-apps/integrate-miro-with-other-apps/01-user-permissions-for-boards-embedded-in-third-party-apps.md)をご覧ください。

サポートされているアプリにボードを埋め込むには：

1. ターゲットアプリで、**/miro** を入力するか、挿入メニューから**Miro**を選択します。
2. ボードを選択します。
3. **Starting view**を選択します：
   - **Full board** — キャンバス全体。
   - **Specific item**、例えばフレームやフォーマット（Doc、Diagram、Table、Timeline、またはSlides）。
4. フォーカスのために**フォーカスモード**をオンにします。オフのままにすると、完全に操作できます。
5. すべてのビジターに対する**アクセス設定**を選択します：
   - **Can view** — 埋め込みを閲覧する誰もがボードを閲覧できます。
   - **Require access** — 埋め込みを閲覧するには、閲覧、コメント、編集のためのアクセス権が必要です。
6. **ボードを埋め込む** を選択します。

埋め込みはボードの共有設定を尊重します。モバイルデバイスでは、すべての埋め込みは閲覧のみ可能です。

## 埋め込みコードでボードを埋め込む

このオプションは、**WordPress** や **Webflow** など、iFrame をサポートするプラットフォームで使用できます。

1. 以下の方法で**共有**パネルを開きます：
   - 右上で**共有** > **埋め込み**を選択する、または
   - ボードのメインメニューで**ボード** > **エクスポート** > **埋め込み**を選択する、または
   - キャンバスで、埋め込みたいアイテム（フレームや形式）を選択します。例えば、文書の場合は、三点メニューを開いて**この文書を埋め込む**を選択します。
2. **開始ビュー**を選択します：
   - **ボード** — キャンバス全体。
   - **特定のアイテム**、フレームや形式（文書、ダイアグラム、テーブル、タイムライン、またはスライド）など。
3. （オプション）**開始エリアを設定** — ボードの正確な領域を指定してドラッグします。
4. 操作を決定します。
   - **閲覧のみ**を選択して表示をロックします。
   - **閲覧のみ**の選択を解除して、閲覧者がパンニング、ズーム、コメント、または編集ができるようにします（権限を持っている場合）。
5. **コードをコピー**して、必要な場所に貼り付けます。
   目的地がURLのみを受け入れる場合は、代わりに**リンクをコピー** を選択します。

同じボードに対して、開始ビュー、開始エリア、またはフォーカスオブジェクトをそれぞれ設定した複数の埋め込みを作成することができます。

### スライドの自動再生

スライドの埋め込みを自動再生するには、**埋め込み**タブで**自動スライド間隔**を1秒から30秒の間で設定します。ボードを別のボード内に埋め込む場合、自動再生は無視されます。

## 埋め込みの表示方法

- ボード名はクリックできません。
- ミニマップ、[ノート](../../essential-tools/17-visual-notes.md)、ポップアップはデフォルトで閉じています。
- **開始ビューの設定**のようなメニューオプションの一部は非表示です。
- すべての埋め込みはモバイルで閲覧専用です。
- サードパーティのクッキーブロッカーは、埋め込みの正常な読み込みを妨げることがあります。

## よくある質問

**開始ビューとフォーカスモードの違いは何ですか？**
開始ビューは初期位置を設定しますが、閲覧者はボードを自由に探検できます。フォーカスモードは選択されたオブジェクト以外をすべて非表示にし、常に閲覧専用です。

**フォーカスモードの埋め込みを編集可能にできますか？**
いいえ。共同作業を有効にするには、**閲覧専用**を解除し、ボードの共有設定で編集権限を付与してください。

**サポートされているウィジェットはどれですか？**
文書、ダイアグラム、テーブル、タイムライン、スライド、および任意のフレームです。

**Miro ロゴを削除することはできますか？**
いいえ。ブランディングの削除はできません。

**別のボード内にボードを埋め込むことはできますか？**
はい。埋め込みコードをコピーして、**iFrame コードを貼り付け**でターゲットボードに貼り付けます。
