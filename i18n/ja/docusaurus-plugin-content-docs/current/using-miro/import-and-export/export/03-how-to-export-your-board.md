Miro ボードを画像、PDF、CSV ファイルに簡単に変換できるので、同僚やクライアントとの共有や文書作成に最適です。

> 🚀 あなたのボードを世界中のユーザーに活用してもらいましょう。[Miroverse で公開](https://miro.com/miroverse/submission/?backToUrl=/)すると、6000 万人以上のユーザーの目に触れる機会となります。

## ご利用のプラン、ブラウザー、デバイスに応じたエクスポート オプション

Miro のプラン、ブラウザー、デバイスによっては一部のエクスポート オプションが利用できない場合があります。なお、エクスポートは、ボードの所有者や共同所有者が、[ボードコンテンツの設定](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)でボードコラボレーターの**オプションを有効**にしている場合にのみ利用できます。

## 画像として保存

:::warning
Edge（バージョン 79 未満）は、**ベクターのエクスポート**のみをサポートします。Free プランで対応するのは、小サイズのエクスポートのみです。Free プランのユーザーは、Chrome、Firefox、Opera、Safari、デスクトップアプリ、タブレットアプリでボードをエクスポートすることができます。
:::

**JPG 画像としてボードをエクスポートする手順**は以下のとおりです。

1. ボードの左上にある三点リーダー（**...**）アイコンをクリックし、次に**ボード**のサブメニューをクリックしてエクスポートサブメニューを開きます。
2. **[画像として保存]** を選択します。
3. 画像として保存するボードエリアを選択します。
4. 画像サイズを選択します。ご利用のプランに応じて、**小**、**中**、**大**、**ベクター**のいずれかのサイズでボードをエクスポートすることができます。ベクターの画質の場合は、PDF ファイルとして保存されます。ベクターでのエクスポートを行うと、大きなボードをエクスポートする際に画質を保つことができます。
5. **エクスポート**をクリックします
    を選択します

![export-entry-point.png](https://help.miro.com/hc/article_attachments/22040656889234)
*ボードの一部を画像として保存*

**個々のフレームを画像としてエクスポートする手順は以下のとおりです。**

1. フレームを選択します
2. コンテキストメニューの三点リーダーをクリックします
3. [画像としてエクスポート] を**選択します**
4. ファイルサイズを選択し、**[エクスポート]** をクリックします

![export as image.png](../../../../../../../docs/using-miro/import-and-export/export/images/21016928433042_export%20as%20image.png)
*フレームを画像として保存*

**ボード全体を画像としてエクスポートする手順****は以下のとおりです。**

1. Ctrl + A**（Windows の場合）または** ⌘ **+** A**（Mac の場合）**のショートカットを使って、ボード上のすべてのオブジェクトを選択します
2. 三点リーダーをクリックして、オブジェクトの周りにフレームを作成します
3. フレームのコンテキストメニューの三点リーダーをクリックして、**[画像としてエクスポート]** を選択します

*![export_the_whole_board_greybg.gif](../../../../../../../docs/using-miro/import-and-export/export/images/21016928437650_export_the_whole_board_greybg.gif)
選択したオブジェクトの周りにフレームを作成*

## PDF として保存

:::warning
Edge（バージョン 79 未満）では、**最高（ベクター）画質**でのみエクスポートが可能です。Free プランで対応するのは、小サイズのエクスポートのみです。Free プランのユーザーは、Chrome、Firefox、Opera、Safari、デスクトップアプリ、タブレットアプリでボードをエクスポートすることができます。
:::

小[または](../../essential-tools/07-frames.md)最高（**ベクター**）の画質で**フレーム****を PDF として**エクスポートします。

**PDF ファイルとしてボードをエクスポートする手順は以下のとおりです。**

1. 少なくとも 1 つのフレームを作成します。保存された PDF ドキュメントでは、1 フレームが 1 ページとなります
2. PDF ドキュメントでフレームが表示される順番を確認するには、左下のボードの概要を開きます。エクスポートされた PDF ページの順番を変更するには、ドラッグしてパネル上のフレームの順番を変更します。
3. ボードの左上にある三点リーダー（**...**）アイコンをクリックし、次に**ボード**のサブメニューをクリックしてエクスポートサブメニューを開きます。
4. **[PDF として保存]** を選択します。
5. ファイルサイズを選択します：**ファイルサイズ小** または**高品質**。ファイルサイズの小さい PDF は埋め込みリンクに対応していませんのでご注意ください。
6. **エクスポート**をクリックします

![export-entry-point.png](https://help.miro.com/hc/article_attachments/22040656889234)
*ボードを PDF として保存*

PDF としてボードをエクスポートすると、すべてのフレームが 1 つのファイルとしてエクスポートされます。

**特定のフレームを PDF としてエクスポートする手順**は以下のとおりです。

1. **Shift** を押しながらエクスポートするフレームを選択します。あるいは、エクスポートしたいコンテンツ上に選択フィールドをドラッグし、コンテキストメニューの **[絞り込み]** をクリックして、**[フレーム]** を選択します
2. コンテキストメニューの三点リーダーをクリックして、**[PDF としてエクスポート]** を選択します

![export_certain_frames_greybg.gif](../../../../../../../docs/using-miro/import-and-export/export/images/21016941395346_export_certain_frames_greybg.gif)
*特定のフレームを PDF として書き出し*

**ボード全体を 1 ページの PDF としてエクスポートする手順**は以下のとおりです。

有料、Education プランFree プラン

1. Ctrl + A**（Windows の場合）または** ⌘ **+** A**（Mac の場合）**のショートカットを使って、ボード上のすべてのオブジェクトを選択します
2. コンテキストメニューの三点リーダーをクリックして、オブジェクトの周りにフレームを作成します
3. フレームのコンテキストメニューの三点リーダーをクリックして、**[画像としてエクスポート]** を選択します
4. **ベクター**を選択し、[エクスポート] をクリックします
   ![main_menu_export_board_as_vector_greybg.gif](../../../../../../../docs/using-miro/import-and-export/export/images/21016928435346_main_menu_export_board_as_vector_greybg.gif)
*ボード全体を PDF としてエクスポート*

ボードに**フレームがない**場合の手順は以下のとおりです。

1. Ctrl + A**（Windows の場合）または** ⌘ **+** A**（Mac の場合）**のショートカットを使って、ボード上のすべてのオブジェクトを選択します
2. コンテキストメニューの三点リーダーをクリックして、オブジェクトの周りにフレームを作成します
3. ボード左上のエクスポートメニューを開き、**[PDF として保存]** を選択します
4. エクスポート**をクリックします**

![export_the_whole_board_as_PDF_free_plan_greybg.gif](../../../../../../../docs/using-miro/import-and-export/export/images/21016941396370_export_the_whole_board_as_PDF_free_plan_greybg.gif)
*Free プランでボードにフレームがない場合に、ボード全体を PDF としてエクスポート*

すでにボードに**フレームがある**場合の手順は以下のとおりです。

1. **Ctrl + A**（*Windows の場合*）または **⌘ + A**（*Mac の場合*）のショートカットを使うか、選択フィールドをドラッグして、ボード上のすべてのオブジェクトを選択します。
2. コンテキストメニューで、**[絞り込み]** をクリックして **[フレーム]** を選択します。
3. フレームを削除します（ただしコンテンツは保持します）。
4. **Ctrl + A**（*Windows の場合*）または **⌘ + A**（*Mac の場合*）のショートカットを使うか、選択フィールドをドラッグして、ボード上のすべてのオブジェクトを選択します。
5. ボードの左上にある三点リーダー（**...**）アイコンをクリックし、次に**ボード**のサブメニューをクリックしてエクスポートのサブメニューを開きます。その後、「**PDFとして保存**」を選択します。
6. **エクスポート**をクリックします
7. 左側のツールバーの **[元に戻す]** ボタンを 2 回クリックして、フレームの作成とフレームの削除を元に戻します。

*![export_all_content_as_PDF_Free_plan_greybg.gif](../../../../../../../docs/using-miro/import-and-export/export/images/21016928435730_export_all_content_as_PDF_Free_plan_greybg.gif)**Free プランでボードを PDF としてエクスポート*

:::note
大量のオブジェクトを含むフレームをエクスポートすると、エクスポート処理が中断される場合があります（例えば、エクスポートされた PDF ファイルの一部のテキストが欠落する可能性があります）。最適な性能でご利用になるには、大きなボードを複数のボードに分割し、各ボードを個別にエクスポートすることをお勧めします。[ボードのエクスポートの問題](../../tools/troubleshooting/03-board-export-issues.md)を確認して、ボードのエクスポートを最適化するヒントを確認してください。
:::

## スプレッドシート（CSV）にエクスポート

> **利用可能な環境：**[Chrome、Safari、Firefox ブラウザー](../../troubleshooting-technical-questions/technical-guidelines/02-supported-browsers-browser-restrictions.md)、[デスクトップアプリ](../../../getting-started/apps-for-devices/05-desktop-app.md)

ボード上のテキスト（付箋、表、カード、テキストボックス、図形）を CSV ファイルにエクスポートすることができます。

**CSV ファイルとしてテキストをエクスポートする手順は以下のとおりです。**

1. フレームまたはボードコンテンツを選択します。選択フィールドをドラッグするか、**Shift** を押しながら、[ボードのコンテンツを選択](../../working-on-the-board/10-working-with-objects.md)することができます
2. コンテキストメニューの三点リーダーをクリックします
3. [CSV に**エクスポート]** **を選択します**
4. すると、テキスト、[カード](../../essential-tools/02-cards.md)の概要と URL、付箋とカードのタグの順番で、ボードのコンテンツを列に配置した CSV ファイルが作成されます。

![Miro_CSV_export_gif_greybg.gif](../../../../../../../docs/using-miro/import-and-export/export/images/21016941398162_Miro_CSV_export_gif_greybg.gif)
*フレームを CSV ファイルに書き出し*

ボードの**エクスポート**のサブメニューから **[スプレッドシート（CSV）にエクスポート]** オプションを選択することで、ボード全体を CSV でエクスポートすることもできます。

![export-entry-point.png](https://help.miro.com/hc/article_attachments/22040656889234)
*スプレッドシートにボードをエクスポートするオプション（CSV）*

## エクスポートされたファイルの保存場所

ブラウザーで Miro を使用している場合は、ブラウザーのダウンロードファイルがデフォルトで保存されるフォルダーにファイルが保存されます（ブラウザー設定で設定します）。

Miro デスクトップアプリを使用する場合は、ご利用のデバイス上のダウンロード フォルダーを確認してください。

## 制限

- ボードのコンテンツ設定[で、ユーザーに対して Miro ボードのエクスポートが制限されることがあります](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)
- Miro の Free プランでは、透かし無しの高画質解像度のエクスポートは利用できません
- Edge（バージョン 79 未満）は、ベクターのエクスポートのみをサポートします
- Miro の CSV へのエクスポートは、Opera、Edge（バージョン 79 未満）、タブレットやモバイルデバイスではサポートされていません
- Miro のボードのエクスポートは、[開発チーム](https://miro.com/api/)ではサポートされていません
- Miro のボードのエクスポートは、モバイルデバイスではサポートされていません
- ベクター画質でエクスポートされた **PDF** ファイルでのみリンクをクリックできます
- ボード上のビットマップ画像はアップロード時に圧縮されますが、Miro で作成されたオブジェクト（図形、スタンプ、テキスト、リンクなど）の品質は維持されます

## よくある質問

*Miro のボードをエクスポートするオプションがありません。なぜですか？*

エクスポートのオプションは、ボード所有者が[ボードコンテンツの設定](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)で制限している可能性があります。ボードコンテンツの設定でボードのエクスポートが許可されているにもかかわらず、一部のエクスポート オプションが欠落している場合は、ご利用のプラン、デバイス、ブラウザーがボードのエクスポートをサポートしていることを確認してください。利用できるエクスポートを確かめます。

*ボードのコラボレーターにボードのエクスポートを許可するにはどうすればよいですか？*

[ボードコンテンツの設定](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)を確認し、他のユーザーがボードをコピーするオプションを利用できることを確認します。また、[チーム外のユーザーにボードコンテンツのコピーを許可](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)するよう管理者に依頼する必要があるかもしれません。

*PPT、PNG、SVG 形式でボードをエクスポートできますか？*

いいえ、現時点でボードを保存できるファイル形式は、PDF、JPG CSV です。
 を選択します

*エクスポートされたドキュメントには、コメントが含まれていますか？*

いいえ。ただ、この機能は今後の実装を予定しています。
 を選択します

*エクスポートされたドキュメントでは、フレームのタイトルが表示されますか？*

いいえ。しかし、フレームタイトルを[ドキュメントに表示されるテキストウィジェット](../../essential-tools/16-text.md)に置き換えることができます。

*投票結果をエクスポートできますか？*

いいえ、スクリーンショットを撮影してください。

*ボードで作業しているとき、変更はすべて自動的に保存されますか？*

はい。また、コンテンツが誤って削除されないよう、[ボードのバックアップ](05-how-to-save-board-backup.md)の保存や、ボードのエクスポートをお勧めします。[Web ホワイトボード](../../special-features/10-web-whiteboard.md)で作業していて Miro のプロフィールがない場合は、[Miro に登録](../../../getting-started/start-here/02-how-to-register-with-miro.md)すると、ボードを保存して、24 時間経過後も引き続き作業を行うことができます。

*個々のエレメントまたはエレメント一式をエクスポートする方法を教えてください。*

ボードの**エクスポート**メニューで **[画像として保存]**を選択し、画像としてキャプチャーする領域を選択してください。別の方法として、[オブジェクトを選択](../../working-on-the-board/10-working-with-objects.md)し、そのオブジェクトの周りに[フレームを作成](../../essential-tools/07-frames.md)して、エクスポートすることもできます。

*インテリジェント データと一緒にボードを CSV にエクスポートできますか？*

現時点では、CSV エクスポートにボードの構造や要素同士の関係といった情報は含まれません。ただし、[表](../../advanced-tools/05-grid.md)を CSV ファイルとしてエクスポートする場合は、構造が保存されます。

*ボードにアップロードされたファイルをエクスポートできますか？*

はい、[ボードコンテンツの設定](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)で許可されている場合は可能です。オプションが制限されていない場合は、ファイルを選択し、コンテキストメニューのダウンロードアイコンをクリックします。

> ️✏️ Miro のボードのエクスポートで問題が発生した場合は、[ボードのエクスポート時の問題](../../tools/troubleshooting/03-board-export-issues.md)に記載されたソリューションをお試しください。
