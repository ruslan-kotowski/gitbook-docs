Miro ボードを印刷するには:

1. 左上のツールバーの**三点リーダー**（**...**）アイコンをクリックし、**ボード**、**エクスポート**の順に選択して、エクスポートオプションにアクセスします。
2. ボードを画像またはPDFとしてエクスポートする
3. エクスポートしたファイルを開いて印刷します。

> **⚠️** 高解像度の PDF をエクスポートするには、有料プランが必要です。Free プランをご利用のお客様は、低解像度で透かし入りの PDF のみエクスポートできます。ボードのエクスポート機能の詳細については、[こちらのページ](03-how-to-export-your-board.md)をご覧ください。

![export-entry-point.png](../../../../../../../docs/using-miro/import-and-export/export/images/21537453537298_export-entry-point.png)
*ボードのエクスポート オプション*

ボードを PDF で保存すると、ボードの各[フレーム](../../essential-tools/07-frames.md)が、PDF ドキュメントの個別ページとして作成されます。チャート、ダイアグラム、または画像全体を一枚のページに印刷したい場合は、A4 またはレターサイズのフレームを使用すると、標準的な用紙サイズに自動的に合わせられます。

より良い体験のためには、フレームを作成し、ボードを100%のズームレベルで作業してください。

印刷された文書のテキストやオブジェクトが小さすぎる場合、オブジェクトを選択してボード上でサイズを大きくし、再エクスポートして印刷できます。

ボードのエクスポートで問題が発生した場合は、[トラブルシューティング ガイド](../../tools/troubleshooting/03-board-export-issues.md)をご覧ください。
