Miro の編集可能なチャートを使って運営会議用のダッシュボードを作成したり、データを使ってアイデアを検証したり、重要な指標を視覚化したりします。

### チャートの使い方

ツールバーの**チャート**をクリックし、チャートの種類を選択してクリックするか、ボードにドラッグします。

charts.jpg
ツールバーのチャート

オブジェクトを選択してコンテキストメニューを開き、三点リーダーをクリックして [**編集**] をクリックするか、オブジェクトをダブルクリックして編集モードに入ります。

edit_a_chart.jpg
編集モードに入る

名前を選択し、凡例をカスタマイズして、チャートを使いやすく編集します。**タイトル**と**凡例**のトグルを有効化したり無効化したりできます。ワンクリックですべてのノートをクリアすることもできます。

editing_a_chart.gif
チャートの編集

行を削除するには、行のすべてのセルを選択し、**ゴミ箱**アイコンをクリックして [**行を削除**] を選択します。

delete_a_row.gif
行の削除

### よくある質問

1. *チャートに負の値を追加できますか？*- いいえ、正の数の足し算しかできません。
2. *チャート要素の色を変更できますか？*- いいえ、色は自動的に選ばれます。
3. *チャートのエクスポート方法を教えてください。*- ボードのエクスポートオプションは[こちらを](../import-and-export/export/03-how-to-export-your-board.md)ご覧ください。
