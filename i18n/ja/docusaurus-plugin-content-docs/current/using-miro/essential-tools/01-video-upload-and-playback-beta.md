ビデオファイルをMiroのキャンバスに直接アップロードし、ボード上の誰でもいつでも再生できます。

## ビデオをアップロードする

サポートされているビデオファイルをキャンバスにドラッグ＆ドロップして直接アップロードします。または:

1. 作成ツールバーの下部にある**ツール、メディア、インテグレーション**アイコンをクリックします。
2. **ビデオ**を検索して選択します。
3. アップロードしたビデオを配置したいキャンバスをクリックします。
   空のビデオウィジェットが表示されます。
4. 作成されたビデオウィジェットで、**ビデオをアップロード**をクリックしてファイルブラウザーを開きます。
5. アップロードするビデオファイルを選択し、**開く**をクリックします。
6. ファイルサイズによりますが、ビデオのアップロードに数秒かかります。

:::tip
テンプレートを作成する際は、上記のステップ3までで停止して、テンプレートユーザーが後で自身の動画をアップロードするためのビデオウィジェットのプレースホルダーを作成できます。
:::

「アップロード」オプションを使用して動画をアップロードすることもできます。

1. 作成ツールバーの下部にある**ツール、メディア、インテグレーション**アイコンをクリックします。
2. 「**アップロード > ローカルデバイス**」を検索して選択します。
3. アップロードしたいファイルを見つけて**開く**をクリックします。
4. ファイルサイズに応じて、動画がアップロードされるまで数秒待ちます。

:::note
アップロードできる動画ファイルの最大サイズは150MBです。
:::

### 動画のタイトルを変更する

ビデオのファイル名は、ボード上のプレビューサムネイルのタイトルとして表示されます。よりわかりやすい名前に変更するには、以下の手順に従ってください。

1. ビデオをクリックしてコンテキストメニューバーを表示します。
2. コンテキストメニューバーで**タイトル**をクリックします。
3. 新しいタイトルを入力し、**Enter**キーを押します。

更新されたタイトルがビデオのプレビューに表示されます。

## サポートされている動画フォーマット

アップロード可能な動画フォーマットは次のとおりです：

- MP4
- MOV
- WebM

サポートされる動画コーデックは以下の通りです。

- h264
- h265
- av1
- vp8
- vp9

## ビデオコントロール

ビデオコントロールには以下が含まれます：

- 再生/一時停止
- 10秒ごとの早送り/巻き戻し
- 音声オン/オフ
- 全画面表示

フルスクリーン モードの時は、キーボードの操作もサポートされています。**スペースキー**でビデオを一時停止または再生し、**矢印キー**で10秒間隔で前進または後退、または**esc**でフルスクリーン モードを終了します。

## よくある質問

**キャンバス上の動画は誰が閲覧できますか？**

動画ファイルはアップロードされると、他のボードの共同作業者だけが閲覧可能になります（ボード全体と同じ権限設定です）。

**複数のボードユーザーが同時にビデオを視聴できますか？**

はい。ただし、各ユーザーは自分のボードで**再生**をクリックする必要があります。ボードユーザーは、他のボードユーザーによって既に視聴されているビデオを非同期で視聴できます。

**ビデオの特定の部分にコメントを残すことや注釈を付けることはできますか？**

現在はできません。ただし、ビデオを一時停止してコンテキストメニューをクリックし、**画像としてコピー**を選択することができます。その後、その画像をボードに貼り付けてコメントを残したり、注釈を付けたりすることができます。
