Miro のボードでのテキストツールの使い方を学びましょう。

:::note
この記事では、**テキスト**ツールで使用できる操作を説明します。[付箋](14-sticky-notes.md)、[テーブル](../advanced-tools/05-grid.md)、[図形](11-shapes.md)、[カード](02-cards.md)、[接続線](05-connection-lines.md)、[マインドマップ](../advanced-tools/03-mind-map.md)に関するテキストのフォーマットオプションについては、それぞれの記事をご覧ください。
:::

### テキストの追加と編集

ボードにテキストを追加するには、2 つの簡単な方法があります。

- **テキスト**をツールバーで選択するか[キーボードで T を押し](../working-on-the-board/06-shortcuts-and-hotkeys.md)、ボードをクリックして入力を開始します。
- ツールバーからテキストウィジェットをボード上にドラッグ＆ドロップします。

![text_on_the_toolbar.jpg](../../../../../../docs/using-miro/essential-tools/images/21017012885522_text%20on%20the%20toolbar.jpg)
*ツールバーのテキスト ツール*

書式設定オプションは、入力中およびテキストボックスが選択されているときに使用できます。テキストのフォント、色、不透明度の選択、テキストの左揃えや右揃え、フォントのサイズ変更、ハイライトなどを行うことができます。

:::note
1 つのテキストボックスの記号数の制限は 6,000 です。この制限にはスペースやコードのスタイル変更もすべて含まれるため、テキストの書式設定で入力できる記号数が減る可能性があります。制限を超える場合は、**「テキストボックスの制限に達しました。いくつかのテキストが切り取られる可能性があります。」**というメッセージが表示されます。
:::

![text_formatting.gif](../../../../../../docs/using-miro/essential-tools/images/21017042402578_text%20formatting.gif)
*テキストの書式設定オプション*

テキストを編集したり書式を一部変更したりするには、テキストをダブルクリックするか、テキストツールを使用しているときに一度クリックしてください。フォントや文字サイズを変更すると、テキストボックス全体に影響が及ぶことに注意してください。
![formatting_a_part_of_the_text.gif](../../../../../../docs/using-miro/essential-tools/images/21017042403090_formatting%20a%20part%20of%20the%20text.gif)
*テキスト行の一部を編集*

テキストボックス内のテキストを置き換えるには、そのテキストを選択して入力を開始します。

また、以下のテキスト書式のショートカットも使用できます。

- **Ctrl + B** *(Windowsの場合)*、**Cmd + B** *(Macの場合)* - 太字
- **Ctrl + I** *(Windowsの場合)*、**Cmd + I** *(Macの場合) -* イタリック
- **Ctrl + U** *(Windowsの場合)*、**Cmd + U** *(Macの場合) -* 下線

文字サイズを変更するには、コンテキストメニューを使用する方法と、白い点をドラッグする方法の2つがあります。

![changing_font_size.gif](../../../../../../docs/using-miro/essential-tools/images/21017042403858_changing%20font%20size.gif)
*文字サイズの変更*

テキストボックスのサイズを変更するには、テキストボックスの左枠か右枠をドラッグします。フォーカスモードでは、コンテキストメニューの**リサイズ**アイコンをクリックすることで、ピクセル単位でテキストボックスの幅を指定することもできます。

![resizing_a_text_box.gif](../../../../../../docs/using-miro/essential-tools/images/21017042404626_resizing%20a%20text%20box.gif)
*テキストボックスのサイズ変更*

テキストを回転させるには、矢印アイコンをドラッグします。

![rotate_text.gif](../../../../../../docs/using-miro/essential-tools/images/21017042405650_rotate%20text.gif)
*テキストボックスの回転*

テキストボックスでは、コンテキストメニューの**リンクを挿入**オプションを使用して、カスタマイズされた[リンク](../working-on-the-board/16-internal-and-external-linking.md)を作成できます。また、三点リーダー下にある**リンク先**オプションを選択してリンクを設定することもできます。さらに、テキストを選択して**Ctrl + V**（*Windows の場合*）または**Cmd + V**（*Mac の場合*）のショートカットを使用してリンクを貼り付けるだけです。

![linking_options.gif](../../../../../../docs/using-miro/essential-tools/images/21017012890002_linking%20options.gif)
*テキストへの URL リンクの貼り付け*

### 箇条書きリストと番号付きリスト

箇条書きリストと番号付きリストは、大きなテキストブロックを理解しやすく分け、重要な情報を際立たせるのに役立ちます。箇条書きリストや番号付きリストを開始するには、ダッシュまたは数字を入力してスペースキーを押します。コンテキストメニューの**[リストを追加]**ツールを使って、入力したテキストを箇条書きリストや番号付きリストに変換できます。リストを自由にカスタマイズでき、複数階層に設定することもできます。

![number_points.gif](../../../../../../docs/using-miro/essential-tools/images/21017042407186_number%20points.gif)
*複数階層リストの作成*

**Shift + Enter**（**Return**）を押して、番号付きリストに改行を追加します。

**Return**または**Enter**キーをダブルタップしてリストを終了します。

### テキストとスタイルのコピー

他のボードやサードパーティ製アプリケーションからテキストをコピー＆ペーストするには、**Ctrl+C**/**Ctrl+V**（*Windows の場合*）または**Cmd+C/Cmd+V**（*Mac の場合*）のショートカットを使用します。ボード上の複数のオブジェクトを選択する方法は[こちら](../working-on-the-board/10-working-with-objects.md)をご覧ください。

また、特定のスタイルをボード上のすべての図形やテキストボックスにすばやく適用することもできます。書式をコピーして適用するには、ショートカット**Ctrl + Alt+ C**と**Ctrl + Alt + V**（*Windows の場合*）または**Cmd + Alt+ C**と**Cmd + Alt + V**（*Mac の場合*）を使用します。または、テキストのコンテキストメニューで三点リーダーをクリックし、オプションを選択します。

![copy_paste_style.gif](../../../../../../docs/using-miro/essential-tools/images/21017042407826_copy%20paste%20style.gif)
*スタイルのコピー＆ペースト*

なお、サードパーティ製アプリケーションから書式をコピーすることはできません。箇条書きリストと番号付きリストだけは例外としてコピーできます。

### スペルチェック

Miro [デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)には、スペルチェッカーが内蔵されています。スペルチェッカーを無効化する必要がある場合は、[このガイド](../../getting-started/apps-for-devices/05-desktop-app.md)をご利用ください。

ブラウザーを使用している場合は、そのブラウザーがスペルチェックをサポートしていれば、Miro でもサポートされます。ブラウザーの設定でスペルチェックを有効にしてください。

- *Chrome*の場合、ブラウザーの設定を開き、**詳細設定** > **言語** > **スペルチェック**を有効にします。

### よくある質問

1. 1. *接続線にテキストを追加するにはどうすればよいですか？*
      - 接続線にテキストを追加する方法は[こちら](05-connection-lines.md)をご覧ください。
   2. *テキストボックスの枠の色は変更できますか？*
      - いいえ、このオプションは現時点では利用できません。[図形](11-shapes.md)の枠の色を変更することができます。
   3. *テキストボックスをクリックしても、すべての書式設定オプションが表示されません。なぜですか？*
      - 記事に記載されている一部の書式設定オプションは、他のテキストツール（[図形](11-shapes.md)、[マインドマップ](../advanced-tools/03-mind-map.md)、[カード](02-cards.md)など）ではサポートされていません。さらに、[選択モードに切り替えていること](../working-on-the-board/21-work-smarter-not-harder.md)をご確認ください。
   4. *テキストボックスを移動する方法*
      - [セレクトモードに切り替え](../working-on-the-board/21-work-smarter-not-harder.md)、テキストボックスをクリックしてドラッグしてください。ロックされていないことをご確認ください。
   5. *ボード上のすべてのテキストボックスの書式を一度に変更できますか？*
      - はい、可能です。ボード上のすべてのオブジェクトを選択してください（**Ctrl + A** *for Windows*または**Cmd + A** *for Mac*を使用できます）、[テキストをフィルターし](../working-on-the-board/21-work-smarter-not-harder.md)、書式を変更してください。

:::note
テキストに関してバグや問題が発生した場合は、[トラブルシューティング記事](../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md)をご覧ください。
:::
