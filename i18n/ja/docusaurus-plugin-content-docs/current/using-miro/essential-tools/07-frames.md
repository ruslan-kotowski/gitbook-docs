フレームを使って、ボード上のコンテンツに構造を加えます。フレームの追加、削除、カスタマイズが可能なほか、フレームを使用してボード上のコンテンツを簡単に移動させたり、フレームを相手にプレゼンテーションしたり、PDF としてエクスポートしたりすることができます。

> 🚀 ボードの整理術を披露しましょう。[Miroverse で公開](https://miro.com/miroverse/submission/?backToUrl=/)すると、世界中 6,000 万人以上のユーザーの仕事に役立つかもしれません。

## フレームの基本

### フレームを追加

:::tip
フレームツールを開いたら、**テンプレートを見る**をクリックし、あらかじめ用意された様々なプレゼンテーションやスライドの[テンプレート](../../getting-started/start-here/your-first-board/04-templates.md)を利用できます。
:::

1. ボードの左側にある[作成](../../getting-started/start-here/your-first-board/05-toolbars.md)ツールバーの**F****rame**アイコンをクリックします。
2. フレームツールが開きます。
3. フレームをボードにドラッグ＆ドロップするか、F ホットキーを押しながら[ボードのどこかをクリックしてフレームを追加します。](../working-on-the-board/06-shortcuts-and-hotkeys.md) </span> また、クリック＆ドラッグでボード上に直接フレームを作成することもできます。

![adding-a-frame-to-the-board.gif](https://help.miro.com/hc/article_attachments/22431732906898)
*ボードにフレームを追加*

既存のオブジェクトの周りにフレームを追加することもできます。

ボードに既にコンテンツが追加されている場合、既存のオブジェクトの周りにフレームを作成するのは簡単です。[オブジェクトを選択](../working-on-the-board/10-working-with-objects.md)し、コンテキストメニューの**三点リーダー** (**...**) アイコンをクリックし、**フレームを作成**を選択します。

![create-a-frame.gif](https://help.miro.com/hc/article_attachments/22431750495762)
*ボードオブジェクトを囲むフレームの作成*

:::tip
寸法を有効にすることで、[ボード全体で](../formats/diagramming/01-miro-for-mapping-diagramming.md)同じフレームを正確に作成することができます。
:::

### フレームを削除

1. コンテキストメニューの**三点リーダー** (**...**) アイコンをクリックします。
2. [**削除**] を選択します。

![delete a frame.png](https://help.miro.com/hc/article_attachments/22431750499090)
*フレーム 1 つを削除*

ホットキーを使用することもできます。フレームのタイトルをクリックし、**Backspace** キーか **Delete** キーを押します。

:::tip
誤ってフレームを削除した場合は、いつでも[ボードの履歴から復元](../working-on-the-board/18-restoring-board-content.md)可能です。
:::

複数のフレームを削除するには、

1. Shift を押しながらフレームを選択するか、選択フィールドを描きます。</span>[オブジェクト選択](../working-on-the-board/10-working-with-objects.md)の詳細をご覧ください。
2. コンテキストメニューでフィルターを使用して**フレーム**を選択します。
3. **三点リーダー** (**...**) アイコンをクリックします。
4. 「**削除**」をクリック。

![delete-multiple-frames.gif](https://help.miro.com/hc/article_attachments/22431732917778)
*一度に複数のフレームを削除する*

## **フレームのカスタマイズ**

**フレームの配置、色、名前、サイズ、縦横比を編集することができます。**フレームのグループ化、ロック、複製も可能です。

### フレームの移動と編集

フレームを移動するには:

1. [選択ツール](../working-on-the-board/05-using-miro-with-a-mouse-trackpad-or-touchscreen.md)に切り替えます。
2. フレームの境界線またはタイトルをクリックしてドラッグします。

フレームの色はデフォルトでは白です。コンテキスト ツールバーでフレームのサイズと色を変更することができます。

### フレームの名前変更

フレームの名前を変更するには：

1. フレームの見出しをダブルクリックします。
2. 新しい名前を入力開始
3. または、コンテキストメニューの**三点リーダー**（**...**）アイコンをクリックします。
4. 「**フレーム名を変更**」をクリックします。

### フレームのサイズ変更

フレームを選択し（枠かタイトルをクリック）、その枠をドラッグしてフレームサイズを調整します。また、コンテキストメニューの**三点リーダー**（**...**）アイコンをクリックすると、フレームの比率を変更できます。

:::tip
[寸法を有効にする](../formats/diagramming/01-miro-for-mapping-diagramming.md)と、ボード全体で同じサイズのフレームを正確に作成できます。
:::

### フレームのグループ化

フレームをグループ化するには：

1. Shift を押しながら複数のフレームを選択します。
2. フィルター機能を使用して、すべてのフレームを選択することもできます。
3. コンテキストメニューの**グループ**アイコンをクリックします。

### フレームのロック

フレームをロックすると、誤って移動されるのを防ぎます。ボードの編集者が誤ってフレーム内のコンテンツを動かさないようにするには、すべてのオブジェクトを選択してロックします。

フレームのロックとロック解除のオプションは、ご利用のプラン種別とアクセスレベルによって異なります。詳細は[ボード上のコンテンツのロック](../working-on-the-board/17-locking-content-on-the-board.md)をご覧ください。

### フレームの複製

フレームを複製するには、[ショートカット](../working-on-the-board/06-shortcuts-and-hotkeys.md) **Ctrl/Cmd + D**を使用します。フレーム名に日付が含まれている場合は、自動的に更新されます。年は翌年に進み、日付は翌日に進みます。
![duplicating-a-frame.gif](https://help.miro.com/hc/article_attachments/22431750515602)
*フレームの複製*

### フレーム内のコピー＆ペースト

フレーム内のコンテンツをコピー＆ペーストすると、コンテンツは元のフレームと同じ場所に表示されます。フレーム間でコピー＆ペーストするには：

1. コピーしたいコンテンツを選択します。Ctrl/Cmd を押しながら複数のオブジェクトを選択します。
2. コンテキストメニューの**三点リーダー**（**...**）にある**コピー**をクリックします。またはキーボードショートカットを使用します。**Ctrl/Cmd-C**。
3. コピー先のフレームを選択します。（選択しやすくするために、この操作を行う前にフレームをグループ化することができます）
4. コンテキストメニューの**三点リーダー**（**...**）にある**貼り付け**をクリックします。またはキーボードショートカットを使用します。**Ctrl/Cmd-V**。

コピー先のフレームとコピー元のフレームのサイズが異なる場合、コンテンツは元の x-y 座標に基づいてコピー先のフレームの左上隅を基準に配置されます。つまり、一部のコンテンツがフレームの外に表示されたり、エッジに対して異なる位置に表示されたりする可能性があります。

## フレームでのプレゼンテーション

### プレゼンテーション モード

ボードをオーディエンスにプレゼンしながら、フレーム間をスムーズに移動します。プレゼンテーション モードをオンにするには、ボードの右上にあるコラボレーション ツールバーの「発表」ボタンをクリックします。

全画面表示に切り替わり、フレームはスライドとして表示され、ボードツールとフレームのタイトルは非表示になります。

矢印を使用して、フレーム / スライド間を移動します。

### フレームの表示と非表示

> **実行可能なユーザー：**ボード所有者、ボード共同所有者 **対象プラン：**Education、Starter、Business、Enterprise プラン

フレームを非表示にすることで、ワークショップや会議中にコラボレーターや聴衆にどのコンテンツを公開するかを制御できます。

フレームを一旦隠すと、ボード上の全員がそのコンテンツを閲覧できなくなります。フレームの非表示は、会議の企画やワークショップの段取りの際に役立ちます。

フレームが非表示になると、ボード参加者はそのコンテンツを閲覧できなくなります。代わりに、閉じた目のアイコンが描かれた空白のフレームが表示されます。

ユーザーが隠しフレームの上にオブジェクトを配置すると、そのオブジェクトはプレースホルダーフレームの下に移動しますが、編集可能です。

:::tip
コンテンツを複数のフレームに分割し、会議やワークショップで1つずつ表示できます。ビジュアルノートを使用して議題を作成し、メモに隠しフレームを追加することができます。
:::

:::warning
フレームを隠しても、フレームのコメントやタイトルは隠れませんので、ご注意ください。
:::

フレームを隠すには、フレームをクリックし、フレームのオブジェクトメニューにある目のアイコンをクリックします。

![hiding-multiple-frames.gif](https://help.miro.com/hc/article_attachments/22431750519826)
*複数のフレームを非表示にする*

ナビゲーション ツールバーから開けるフレームパネルからフレームを非表示にすることもできます。**フレーム** アイコンをクリックし、**三点リーダー** （**...**）メニューを使用して非表示機能にアクセスします。

複数のフレームを一度に非表示にするには、ドラッグして[フレームを選択](../working-on-the-board/10-working-with-objects.md)し、コンテキストメニューの**目のアイコン**をクリックします。

非表示のフレームを表示するには、コンテキストメニューの**目のアイコン**をもう一度クリックします。

:::warning
ボード上で非表示なフレームを表示に変更しても、そのフレームが[ノート](17-visual-notes.md)内に自動的に表示されることはありません。フレームを表示するには、ノートを更新してください。
:::

:::warning
ボード参加者は、フレームが表示されるまで隠しフレームのコピーや複製はできません。
:::

## フレームのクイックプレゼン機能

フレームを素早く整理し、ボードやプレゼンテーション、ワークショップを円滑に実施する機能が豊富にあります。

### フレームのレビューと並び替え

1 つのフレームから別のフレームへ素早くジャンプし、フレームパネルでフレームの並び替えができます。フレームの順序を変更するには、フレームパネル内の新しい位置にドラッグ＆ドロップします。

![frames-button.png](https://help.miro.com/hc/article_attachments/22431750521490)
*ナビゲーション ツールバーからフレームパネルを開く*

:::warning
サイドバーでのフレームの並び替えは、モバイルやその他のタッチデバイス（タブレットアプリやブラウザー）では利用できません。
:::

### フレームの複数選択

マルチセレクトでは、フレームパネルで複数のフレームを選択して、一括で並び替えや削除ができます。複数のフレームを選択するには、**Windows の場合は ctrl** または **Mac の場合は command** を押し続けてください。

![frame-multi-select.png](https://help.miro.com/hc/article_attachments/22431750534930)

*複数のフレームを選択して削除、非表示、移動*

フレームが複数ある場合は、リスト表示で整理すると便利です。フレームをサムネイルではなくリストで表示するには、**三点リーダー**（**...**）をクリックし、**リスト表示**を選択します。

![frames-list-view-2.png](https://help.miro.com/hc/article_attachments/22431750541458)

*リストビューでフレームをリスト表示*

### フレームを整理

フレームの整理機能では、ボード内のフレームの順序を読み取り、サイドバーで自動的に並べ替えるので、プレゼンテーションの準備をすばやく行うことができます。アルゴリズムを使用し、フレームをボードに配置された順序（左から右、上から下）に配置します。

「フレームを整理」を使用し、前のフレーム順序に戻したい場合は、ボードの左側にある作成ツールバーの下にある[元に戻す](16-undoredo.md)ボタンをクリックしてください。

![frames-organize.png](https://help.miro.com/hc/article_attachments/22431732942354)*三点リーダー（...）メニューから自動的にフレームを整理*

### リンクを特定のフレームに共有する

ボードを共有する際、相手に特定のフレームに注目してもらいたい場合があります。オブジェクトメニューで特定のフレームにリンクをコピーすることができます: オブジェクトをクリック > **三点リーダー** (**...**) > **リンクをコピー** をクリックします。

![copy link to a frame.png](https://help.miro.com/hc/article_attachments/22431732945042)
*ボード上の特定のフレームへのリンクをコピー*

## フレームをエクスポートする

単一のフレーム、あるいは選択したフレームのみをエクスポートする場合もあります。

選択したフレームをエクスポートするには:

1. Shift キーを押しながらエクスポートするフレームを選択するか、選択範囲をドラッグしてフレームを囲みます。
2. コンテキストメニューで、フィルターアイコンをクリックし、**フレーム**を選択します。
3. **三点リーダー**（**...**）アイコンをクリックします。
4. メニューからエクスポートオプションを選択します。

単一のフレームをエクスポートするには、フレームを選択し、**三点リーダー**（**...**）アイコンをクリックし、エクスポートオプションを選択します。

![export a frame.png](https://help.miro.com/hc/article_attachments/22431732949906)
*単一フレームのエクスポート*

### ボードをエクスポートする

プレゼンテーションをチーム外のユーザーや、社外のコラボレーターやベンダーと共有したいこともあるでしょう。それには、ボード全体をエクスポートすることができます。**詳細情報：**[ボードをエクスポートする方法](../import-and-export/export/03-how-to-export-your-board.md)。

## よくある質問

**オブジェクトがフレームに張り付きません。なぜですか？**

オブジェクト上にフレームを追加しても、オブジェクトに張り付かないことがあります。オブジェクトを選択し、少し動かします。これでフレームに張り付くはずです。

**フレームを別のボードにコピーする方法を教えてください。**

Ctrl+C/Ctrl+V（Windows の場合）または Cmd+C/Cmd+V（Mac の場合）を使用して、フレームをコピーして別のボードに貼り付けます。ボードの所有者がボードのコンテンツのコピーを許可していることを確認してください。
