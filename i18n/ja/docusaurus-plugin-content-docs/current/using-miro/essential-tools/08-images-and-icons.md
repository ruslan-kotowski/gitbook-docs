魅力的でプロフェッショナルなボードとプレゼンテーションを作成しましょう。Unsplash や Fontawesome から多様な画像やアイコンを検索、閲覧、交換できる統合ライブラリを利用してください。

## Images and Icons の使い方

管理者は、[アプリ管理](../../enterprise-administration/managing-apps-on-enterprise-plan/02-app-management.md)設定で、Unsplash アプリへのアクセスを管理し、いつでもアクセスを許可または制限できます。

:::warning
ボードからUnsplashアプリにアクセスできない場合は、管理者に確認して、組織内でアプリが承認されていることを確かめてください。
:::

Unsplashのアクセスが許可されると、Unsplashからの画像用の専用タブが画像とアイコンのライブラリに含まれます。同様に、Iconfinderへのアクセスが許可されると、それもライブラリで別のタブとして表示されます。

![Images-and-Icons-tabs-visible-when-allowed-in-app-settings.png](../../../../../../docs/using-miro/essential-tools/images/21016134851602_Images-and-Icons-tabs-visible-when-allowed-in-app-settings.png)
*UnsplashおよびIconfinderタブ*

### 画像とアイコンへのアクセス方法

1. ボードの左側にある[作成ツールバー](../../getting-started/start-here/your-first-board/05-toolbars.md)に移動します。
2. **その他のアプリ**アイコン（**+**）をクリックし、「Images and Icons」を検索します。
3. **Images and Icons**アプリを開きます。

![Opening-Images-and-Icons-app.png](../../../../../../docs/using-miro/essential-tools/images/21016134850706_Opening-Images-and-Icons-app.png)
*Images and Iconsアプリの起動*

### Unsplash の画像

Unsplash からロイヤリティフリーの画像を取得できます。画像カテゴリを閲覧してインスピレーションを得たり、特定の画像を検索したりできます。

![Browsing-image-categories.png](../../../../../../docs/using-miro/essential-tools/images/21016121506834_Browsing-image-categories.png)
*Unsplash の画像の閲覧*

画像の上にカーソルを合わせ、左下の情報アイコン (**i**) をクリックして詳細を開きます。画像の詳細では、画像の作者、ライセンス、使用条件を確認できます。

![Viewing-image-details.png](../../../../../../docs/using-miro/essential-tools/images/21016134848274_Viewing-image-details.png)
*画像の詳細を表示中*

Unsplash から画像を追加するには、選択してボードに配置するか、ドラッグ＆ドロップします。

![Click-to-select-and-place.png](../../../../../../docs/using-miro/essential-tools/images/21016134854034_Click-to-select-and-place.png)
*ボードに画像を追加中*

### Fontawesome のアイコン

Fontawesome から広範囲にわたるアイコンにアクセスできます。アイコンパックを閲覧したり、特定のアイコンを検索したりしてください。

![fontawesome.png](../../../../../../docs/using-miro/essential-tools/images/31565336864018_fontawesome.png)
*アイコンを閲覧する*

アイコンを追加するには、クリックして選択し、ボードに配置するか、ドラッグアンドドロップを使用してください。

### アイコンの色を変更する

1. ボード上のアイコンを選択し、コンテキストメニューを開きます。
2. 「**塗りつぶしの色**」をクリックします。
3. アイコンの色を変更したい色を選択します。

![fillcolor.png](../../../../../../docs/using-miro/essential-tools/images/31565314568338_fillcolor.png)

*アイコンの色を変更する*

### 画像とアイコンの置き換え

画像とアイコンライブラリから直接画像を置き換えます。これは、特にプレゼンテーションの[テンプレート](../../getting-started/start-here/your-first-board/04-templates.md)を更新するのに役立ちます。

1. 画像またはアイコンをクリックしてコンテキストメニューを開きます。
2. **画像を置き換え** アイコンをクリックします。
3. **ライブラリから置き換え**を選択します。
4. 画像とアイコンのアプリが開きます。
5. 新しい画像またはアイコンを選択します。

![Swapping-an-image.png](../../../../../../docs/using-miro/essential-tools/images/21016134852626_Swapping-an-image.png)
*ボード上でのアイコンと画像の交換*

## 画像のスタイリング

Miroでは、さまざまなスタイリングオプションを使用して、画像の見栄えを簡単に向上させることができます。枠線を追加したり、枠線の透明度を調整したり、角を丸めたり、ボードの美観に合わせて画像を柔軟にカスタマイズすることが可能です。

![imagestyling.png](../../../../../../docs/using-miro/essential-tools/images/25592371909522_imagestyling.png)

*画像のスタイル設定*

ここでは、画像をスタイル設定する方法と利用可能なカスタマイズオプションについて説明します。

### 枠のスタイル

- **枠線の太さ**: スライダーを使用して画像の枠線の太さを調整します。これにより、ニーズに応じて枠線を目立たせたり、控えめにしたりできます。
- **枠線の色**: ブランドやカスタムカラーを含むMiroのカラーパレットから枠線の色を選択します。
- **枠線の不透明度**: スライダーを使用して枠線の不透明度を変更し、より透明にしたり、完全に不透明にしたりします。
- **角を丸める**: スライダーを使って角の半径を調整することで、画像に柔らかな印象を与えることができます。値を0に設定すると角が鋭くなり、値を増やすとより丸みを帯びてきます。

### 画像をトリミングする

Miro にはツールがあるので、サードパーティー製ソフトウェアを使用して画像をトリミングする必要はありません。画像を選択するか、コンテキストメニューで**トリミング**を選択します。これにより**長方形**の選択を編集できるトリミングモードが有効になります。

境界線をトリミングして周囲のボードコンテンツにスナップし、画像のレイアウトが視覚的に鮮明であることを確認します。トリミングする画像の位置やスケールをボード上の他のコンテンツと位置合わせを失わずに更新できます。完了したら、ボードのどこかをクリックするだけです。

画像を**さまざまな図形**（例：円形、四角形など）にトリミングできます。画像を選択し、コンテキストメニューの**トリミング**アイコンをクリックし、ドロップダウンから図形を選びます。

さまざまな形状に画像を一括でトリミングすることもできます。クリックしながらドラッグして画像を選択し、コンテキストメニューの**トリミング**アイコンをクリックし、ドロップダウンから図形を選びます。

![multi-crop.gif](../../../../../../docs/using-miro/essential-tools/images/25827434689298_multi-crop.gif)
*円形への一括トリミング*

:::tip
トリミングした画像はいつでも元のサイズに戻すことができます。ダブルクリックして、トリミングの選択範囲を元のサイズに拡大するだけです。
:::

さらに画像編集オプションがAdobe Expressとともにボード上で利用可能です。コンテキストメニューで**画像の編集**をクリックして、Adobe Expressを起動します。**詳細情報：**[Adobe Express（ベータ版）](../../integrations-apps/adobe/01-adobe-express.md)。

### 複数の画像のサイズを一括変更する

ボード上の複数の画像の高さや幅を一括変更します。その後、[自動レイアウト](../working-on-the-board/08-structuring-board-content.md)を使用して素早く整列させます。

**画像を一括でリサイズする方法**

1. カーソルをドラッグして、サイズを変更する画像をすべて選択します
2. コンテキストメニューの [画像のサイズ変更] アイコンをクリックします。このアイコンを表示させるには、複数の画像を選択する必要があります。
3. 高さを **一致させる** または **幅を一致させる**
4. 右上に表示される灰色の **自動レイアウト** アイコンをクリックします

### GIF の追加

Miro ボードに GIF を追加し、楽しいアニメーション画像を使ってアイデアをわかりやすく表現しましょう。GIF は、ボードに追加された時とユーザーが GIF にカーソルを合わせた時に、ユーザーごとに 8 秒間あるいは 1 回再生されます。GIF は、ボードを操作中の各ユーザーにのみ再生されます。全ユーザーを対象にリアルタイムで再生されるものではありません。

[動きを減らす](../../getting-started/accessibility-in-miro/06-reduce-motion.md) をオンにして、GIF の自動再生機能を無効化します。

:::tip
プレゼンテーションや [Miro Talktrack](../facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md) の GIF は、画面に表示されている間は自動的に再生され、無限にループします。
:::
