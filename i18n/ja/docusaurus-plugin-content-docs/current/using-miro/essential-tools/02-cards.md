Miro カードは、作業を整理して割り当て、関係者同士の認識合わせのための情報を提供し、すべてを計画通りに進めるための体系的な手段を提供します。計画/span>[や、](../advanced-tools/02-columns-formerly-kanban.md)ストーリーマップ作成[にカードをお使いください。](../advanced-tools/07-user-story-mapping.md)

> **利用可能な環境：**デスクトップ**ロウサー デスクトップアプリタブレットアプリ タブレットアプリと モバイルアプリ**

## カードを使う

### カードアプリをツールバーに追加する方法

ボード上でカードを頻繁に使用する場合、カード機能をツールバーに追加しておくと素早くカードを作成できます。

1. ボード左側の作成ツールバーに移動します
2. [他のアプリ] **アイコンをクリックします**
3. 「カード」を検索します
4. **[カード]** アイコンをクリックしてツールバーに追加します

![ツールバーにカードアプリを追加する.gif](../../../../../../docs/using-miro/essential-tools/images/21017682630802_Adding%20the%20card%20app%20to%20the%20toolbar.gif)*カードアプリをツールバーに追加*

### ボードにカードを追加する方法

ボードにカードを追加する方法は 3 つあります。

作成ツールバーから**カードアイコンをドラッグ**し、ボードの任意の場所にドロップします。

![カードをボードにドラッグする.gif](../../../../../../docs/using-miro/essential-tools/images/21017653007634_Dragging%20the%20card%20icon%20to%20the%20board.gif)*カードをボードにドラッグ*

**カードアイコンをクリック**した後に、ボードの任意の場所をクリックします。

![ボードをクリックしてカードを追加.gif](https://help.miro.com/hc/article_attachments/21017682739218)*カードアイコンをクリックしてカードをボードに追加します。*

**D のホットキー**を使って、ボードの任意の場所をクリックします。

![カードをボードに追加するDホットキーの使い方.gif](../../../../../../docs/using-miro/essential-tools/images/21017682640018_Using%20the%20D%20hotkey%20to%20add%20a%20card.gif)*ボードにカードを追加するDホットキーの使い方*

> [オブジェクトのサイズを有効化](../formats/diagramming/01-miro-for-mapping-diagramming.md)すると、ボード全体で同じサイズのカードを作成できるようになります。

### ボードからカードを削除する方法

1. カードをクリックして、キーボードのバックスペースキーを押します
2. コンテキストメニューの三点リーダー（**...**）をクリックして、、**[削除]** を選択することもできます。

*![カードの削除.jpg](../../../../../../docs/using-miro/essential-tools/images/21017682620178_deleting%20a%20card.jpg)**カードの削除*

### 他のオブジェクトをカードに変換する方法

既存の[付箋](14-sticky-notes.md)、[テキストボックス](16-text.md)、[図形](11-shapes.md)はすべて、[図形挿入](../working-on-the-board/20-switch-type.md)機能を使ってカードに変換できます。

1. オブジェクトをクリックしてコンテキストメニューを開く
2. **[図形を挿入]** アイコンをクリックします
3. ドロップダウン メニューからカードアイコンを選択します

![付箋をカードに変換する.gif](../../../../../../docs/using-miro/essential-tools/images/21017682622994_converting%20a%20sticky%20into%20a%20card.gif)*付箋をカードに変換*

**複数のオブジェクトをカードに一括変換**するには、クリックしたままドラッグしてオブジェクトを選択し、コンテキストメニューの [種別の切り替え] アイコンをクリックします。そしてカードのアイコンを選択します。

Bulk_converting_to_cards.gif
複数の付箋をカードに一括変換する/span>/span>/em>

:::tip
[カードを Jira カードに変換](../../integrations-apps/atlassian/03-jira-cards.md)できます。チームのブレストセッションやアジャイルセレモニーの後に、一括変換で複数の Jira カードを作成しましょう。
:::

### カードパネルを開く方法

カードパネルを開くことで、カードの全情報の確認、一括編集、概要説明を追加することができます。

カードパネルを開くには、カードの右上またはカードのコンテキストメニューにある **[展開する]** アイコンをクリックします。ホットキーを使うこともできます。Ctrl + **Shift** + **Enter**（**Windows の場合**）、*Cmd* + **Shift** + **Enter** （**Macの場合）**

![カードの拡大.gif](../../../../../../docs/using-miro/essential-tools/images/21017682634514_Expanding%20a%20card.gif)*カードパネルを開く*

## カードを編集、カスタマイズする

### カードを編集する方法

カードをクリックしてコンテキストメニューを開くか、カードパネルを開きますここで、カードの色やサイズの変更、タグ、リンク、日付の追加、ユーザーへのカード割り当てをすることができます。/span>

![カードのカスタマイズ.gif](https://help.miro.com/hc/article_attachments/21017682728722)*カードの編集*

### カードを一括編集する方法

1. 編集したいすべての付箋上に選択フィールドをドラッグするか、**Shift** または **Ctrl***（Windows の場合）*あるいは **Command** *（Mac の場合）を押しながら、付箋を 1 枚ずつ選択します*
2. コンテキストメニューが開きます
3. コンテキストメニューから任意のツールを選択して編集します

![一括編集_カード.gif](../../../../../../docs/using-miro/essential-tools/images/21017682641298_Bulk-editing%20cards.gif)*複数カードの一括編集*

### カードサイズを変更、また回転させる方法

カードをクリックして、白いドットをドラッグします。円矢印アイコンをドラッグすると、カードを回転させることができます。

![カードのサイズ変更と回転.gif](../../../../../../docs/using-miro/essential-tools/images/21017682626834_Changing%20size%20and%20rotating%20a%20card.gif)*カードのサイズ変更と回転*

### カードをユーザーに割り当てる方法

[招待メール](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)、[チームでの共有](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)、[プロジェクト](../sharing-boards/16-projects.md)を介して、ボードへのアクセス権があるユーザーにカードを割り当てることができます。ビジターにカードを割り当てることはできません。

1. カードをクリックしてコンテキストメニューを開くか、カードパネルを開きます
2. **[担当者を追加]** アイコンをクリックします
3. ドロップダウンからユーザーを選択します

![add_an_assignee.jpg](../../../../../../docs/using-miro/essential-tools/images/21017682621970_adding%20an%20assignee.jpg)*ユーザーへのカードの割り当て*

### カードのタグを追加または削除する方法

1. カードをクリックしてコンテキストメニューを開くか、カードパネルを開きます
2. **[タグを追加]** アイコンをクリックします
3. タグのテキストを入力します（タグ色も選択します）
4. [作成] をクリックするか、Enter キーを押します。
5. タグをクリックしてカードから削除します

> タグを使ってカードの[検索と絞り込み](../working-on-the-board/19-searching-text-on-the-board.md)をしましょう。

![カード上のタグの管理.gif](../../../../../../docs/using-miro/essential-tools/images/21017682625426_managing%20tags%20on%20cards.gif)*カードへのタグの追加と削除*

### カードのステータスを更新する方法

1. カードをクリックしてコンテキストメニューを開くか、カードパネルを開きます
2. **[ステータスを追加]** アイコンをクリックします
3. ドロップダウンから **[To Do]**、**[進行中]**、または **[完了]** を選択します
4. ステータスを削除するには、**[ステータスを削除]** をクリックします

![カードのステータス更新.gif](../../../../../../docs/using-miro/essential-tools/images/21017653012626_Updating%20the%20status%20of%20a%20card.gif)*カードのステータス更新*

### カードの日付を追加または削除する方法

1. カードをクリックしてコンテキストメニューを開くか、カードパネルを開きます
2. **[日付を設定]** アイコンをクリックします
3. 開始日および / または期日を入力します
4. 日付をクリアにするには、日付フィールドの横の **x** をクリックします

![カードに日付を追加する.gif](https://help.miro.com/hc/article_attachments/21017682747794)*カードに開始日と期限を追加*

### カードのタイトルと概要説明

カードの概要説明とタイトルには最大 20,000 文字のテキスト記号を入力できます。カードのタイトルは常に表示されますが、概要説明は、カードを展開すると表示されます。

#### **カードタイトルを追加する方法**

カードをクリックして、テキストを入力します。カードタイトルのテキストのフォントやサイズは変更できません。

![カードにタイトルを追加する.gif](https://help.miro.com/hc/article_attachments/21017682749074)*カードのタイトルの追加*

#### **カードの概要説明を追加する方法**

展開アイコンをクリックしてカードパネルを開き、**概要説明**のフィールドに入力をします。Ctrl + C/Ctrl + V/span>**（****Windowsの場合**）、または *Cmd + C/Cmd + V*（**Macの場合**）を使って、コピーしたテキストを直接概要説明のフィールドに貼り付けることもできます。

![カードの説明文の追加.gif](https://help.miro.com/hc/article_attachments/21017653117202)*カードの説明文の追加*

## カードをエクスポートする方法

1. 複数の付箋をまとめてクラスター化するには、選択カーソルをドラッグして付箋を選択するか、**Shift** / **Ctrl***（Windows の場合）*または **Command***（Mac の場合）*を押しながら、付箋を 1 枚ずつ選択します。
2. **[エクスポート]** アイコン > **[スプレッドシート（CSV）にエクスポート]** をクリックします

![export_menu_cards_export_to_csv.gif](https://help.miro.com/hc/article_attachments/21017682754578)
*カードをCSVにエクスポートします。*

## カードに使用できるホットキーのショートカット

- **D** + クリックで新しいカードをボードに追加
- **Ctrl + Shift + Enter*（Windows の場合）*、Cmd + Shift + Enter*（Mac の場合）***ですべてのカードを開く
- **Tab** で新しいカードを作成してカードタイトルを編集
- **Ctrl + B** *（Windows の場合）*、**Cmd + B***（Mac の場合）*- 太字
- **Ctrl + I***（Windows の場合）*、**Cmd + I***（Mac の場合）-* 斜体
- **Ctrl + U***（Windows の場合）*、**Cmd + U***（Mac の場合） -* 下線
- **行頭で「-」 +** **スペース**で箇条書きリスト
- **行頭で「1.」で行番号付きのリスト**
- テキストを選択して **Ctrl + V***（Windows の場合）または* **Cmd + V***（Mac の場合）*でハイパーリンクの作成

## よくある質問

**ユーザーにカードを割り当てると、そのユーザーにメール通知は届きますか？**

いいえ、ユーザーにメール通知は届きません。

**カードに追加した期限に応じてメールのリマインダーを設定できますか？**

現時点ではできません。
