Miro では、絵文字、スタンプ、GIF をボードに配置し、調整することができます。フィードバックを共有し、感情を表現して、考えやアイデアを視覚化しましょう。

> **利用可能なプラン:** Free、Starter、Business、Education、Enterprise の各プラン
> **利用可能なバージョン:** ブラウザー版、デスクトップアプリ、タブレットアプリ、モバイルアプリ（機能制限付き）

## スタンプと絵文字

スタンプや絵文字を使って Miro ボードを活気付け、コンテンツに遊び心を加えましょう。

:::note
スタンプや絵文字のアプリが見つからない場合は、[Miro マーケットプレイス](https://miro.com/marketplace/emoji-app/?backUrl=%2Fmarketplace%2F)からダウンロードしてください。アプリ管理の権限がない場合は、チームの管理者または会社の管理者にお問い合わせください。
:::

### ボードにスタンプや絵文字を追加する方法

1. ボードの左側にある[作成ツールバー](../../getting-started/start-here/your-first-board/05-toolbars.md)に移動します。
2. **ツール、メディア、インテグレーション**(![icon-tools.svg](../../../../../../docs/using-miro/essential-tools/images/23227364594834_icon-tools.svg))アイコンをクリックして、**スタンプと絵文字**を探します。
3. パネル上部で「**スタンプ**」または**絵文字**」タブを切り替えます。
4. スタンプや絵文字をクリックしてボードにドラッグします。

![stickers-and-emojis.gif](../../../../../../docs/using-miro/essential-tools/images/23227364597138_stickers-and-emojis.gif)*Miro ボードに絵文字とスタンプを追加*

ライブラリーを開いたまま、複数の絵文字やスタンプを追加できます。

上部のメニューからスタンプを種類別に切り替えることができます。

![sticker-groups.gif](../../../../../../docs/using-miro/essential-tools/images/23227380926354_sticker-groups.gif)*スタンプグループの切り替え*

検索を使い、絵文字やスタンプを素早く見つけることができます。

絵文字やスタンプを追加したあと、サイズの変更や回転ができます。

**スキントーン**をクリックして、絵文字のデフォルトの肌色を変更します。絵文字によっては、肌の色を変更できない場合があります（例えば、スマイリーの顔文字）。

最近使用された絵文字とスタンプは、それぞれのタブの**最近の項目**セクションに表示されます。

:::warning
技術的な制約により、Windows OS では旗の絵文字が文字として表示されます。また、2018 年以前に製造された OS では、絵文字の表示に問題がある可能性があります。
:::

### アニメーション スタンプ

一部のスタンプには、ユーザーがクリックして同意を示すと外見が変わるなどのアニメーション機能が備わっています。これらのアニメーション スタンプは、スタンプタブの横メニューから見つけることができます。

![interactive-stickers-2.gif](../../../../../../docs/using-miro/essential-tools/images/23227364599954_interactive-stickers-2.gif)

*アニメーション スタンプは、ユーザーがクリックすると変化します*

## GIF

> **利用可能なプラン:** Free、Starter、Business

GIF を使って Miro ボードに活気を与え、楽しく意欲的な、視覚表現に溢れるコラボレーション体験を実現しましょう。

### ボードに GIF を追加する方法

1. [作成ツールバー](../../getting-started/start-here/your-first-board/05-toolbars.md)に移動します。これはボードの左側にあります。
2. **ツール、メディア、インテグレーション**（![icon-tools.svg](../../../../../../docs/using-miro/essential-tools/images/23227364594834_icon-tools.svg)）のアイコンをクリックし、**スタンプと絵文字**を検索します。
3. パネル上部の **GIFs** タブに切り替えます。
4. 好きな GIF をクリックしてボードにドラッグします。検索を使って素早く GIF を見つけることもできます。
