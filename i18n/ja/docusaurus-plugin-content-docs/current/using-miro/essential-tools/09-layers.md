レイヤーを使用することで、ボード上のコンテンツを別々のセクションに整理でき、ダイアグラムの複雑さを管理し、より精密で構造化された作業が可能になります。

## レイヤーへのアクセス

**レイヤーパネル**にアクセスするには：

1. 作成ツールバーの**メディア、ツール、インテグレーション** (![icon-tools.svg](../../../../../../docs/using-miro/essential-tools/images/23227364594834_icon-tools.svg)) アイコンをクリック。
2. **レイヤー**を検索し、レイヤーツールをクリックします。
3. 作成ツールバーにレイヤーツールを保持するには、**レイヤー**アイコンを右クリックして「**ツールバーにピン留め**」を選択します。

![layers-new-entry-point.png](../../../../../../docs/using-miro/essential-tools/images/22431635505426_layers-new-entry-point.png)

*レイヤーメニューは「フレームとレイヤー」アイコンをクリックすることで表示されます*

**レイヤーアイコン**をクリックすると、右側にパネルが開きます。ここでは、レイヤーをアクティブにしたり、既存のレイヤーに名前を付けたり、新しいレイヤーを作成したりできます。

![layers-panel.png](../../../../../../docs/using-miro/essential-tools/images/21594007565842_layers-panel.png)

*レイヤーメニューはキャンバスの右側に表示されます*

### レイヤーを使用できるユーザー

レイヤーの機能はユーザーの役割に基づいています。

- 閲覧者とコメント投稿者（その権限を持つゲストを含む）はレイヤーにアクセスできません。
- 編集者（編集権限を持つゲストを含む）は、レイヤーを作成、編集、非表示、および表示に戻すことができます。
  - メールで招待された編集者には、レイヤーをロックおよび解除する機能もあります。
- ボード所有者と共同所有者は、編集者と同じすべての権限を持っているだけでなく、レイヤーをロックおよび解除し、保護ロックを使用することもできます。

## レイヤーの使用

コンテンツを選択し、新規または既存のレイヤーに追加することで、関連するコンテンツを整理できます。

1. 新規または既存のレイヤーに追加したいコンテンツを選択します。
2. **レイヤー**メニューをクリックします。
3. コンテンツを新しいレイヤーに追加するには、**＋新しいレイヤーに移動**をクリックします。その後、新しいレイヤーの名前を変更できます。
4. コンテンツを既存のレイヤーに移動するには、レイヤー名の横にある**三点リーダー**（**...**）をクリックし、**選択をレイヤーに移動**を選択します。

![layers-move-to.gif](../../../../../../docs/using-miro/essential-tools/images/21594007570962_layers-move-to.gif)

*既存のレイヤーへのコンテンツの追加*

特定のレイヤーに含めたいコンテンツを追加する場合、まずそのレイヤーを選択してください。新しいコンテンツはそのレイヤーに自動的に追加されます。

新しいレイヤーまたは既存のレイヤーにコンテンツを追加することもできます。

1. 追加したいコンテンツを選択します。
2. コンテキストメニューの**三点リーダー**（**...**）メニューをクリックします。
3. **レイヤーに移動**オプションを選択します。

![](../../../../../../docs/using-miro/essential-tools/images/21593982256018_803bbedc-722c-45ef-afb8-e9c46ba8a857.png)

***レイヤーに移動**オプションは、コンテキストメニューの三点リーダー（**...**）の下にあります*

レイヤーはニーズに応じて非表示、ロック、名前変更、または複製が可能です。

1. レイヤーメニューでレイヤー名をクリックするか、カーソルを合わせます。
2. **非表示**にするには：**目のアイコン**をクリックしてレイヤーを非表示にします。アイコンは、開いた目から閉じた目に変わります。選択したレイヤー内のコンテンツはキャンバスから消えます。（非表示になったコンテンツはすべてのユーザーのキャンバスから消え、ページをリロードしても隠されたままであることに注意してください。）
3. レイヤーを表示するには、**閉じた目のアイコン**をクリックします。非表示にされたコンテンツはキャンバスに再表示されます。![layers-eye.png](../../../../../../docs/using-miro/essential-tools/images/21593982258450_layers-eye.png)
   *レイヤーの非表示は目のアイコンで行います*
4. **レイヤーをロック**するには：**ロックアイコン**をクリックしてレイヤーをロックします。アイコンは、開いた鍵から閉じた鍵に変わります。レイヤーがロックされていると、そのレイヤー内のコンテンツは編集できません（移動や削除を含む）。
5. **閉じた** **ロックアイコン**をもう一度クリックして、レイヤーのコンテンツをアンロックします。![layers-lock.png](../../../../../../docs/using-miro/essential-tools/images/21594007576466_layers-lock.png)
   *ロック アイコンはレイヤーをロックまたは解除するために使用します*
6. レイヤーを**複製**するには:レイヤーの右側にある三点リーダー（**...**）をクリックします。
7. **レイヤーを複製**をクリックします。
8. レイヤーの2番目のインスタンスが、オリジナルのレイヤーのすぐ上にボード上に表示されます。
9. 複製したレイヤーを移動するには、レイヤーメニューでそのレイヤーが選択されていることを確認し、キャンバス上でレイヤーのコンテンツをクリックして、目的の位置までドラッグします。
   ![layers-three-dots.png](../../../../../../docs/using-miro/essential-tools/images/21593982264594_layers-three-dots.png)
   *レイヤーの複製は三点リーダー (...) メニューを通じて行います*

レイヤーの名前を変更するには:

1. レイヤーメニューでレイヤー名をダブルクリックします。
2. レイヤーの名前を編集します。
3. Enter を押します。

## ダイアグラム形式のレイヤー

ダイアグラム形式のレイヤーは、キャンバスレイヤーから独立して機能します。この分離は、ボードの一般コンテンツとダイアグラムの特定の要素間の混乱を防ぎ、ダイアグラム作成プロセスを効率化するように設計されています。レイヤーがダイアグラム内でどのように機能するかの詳細については、[ダイアグラム形式](../formats/diagramming/02-miro-diagrams.md)の詳細記事をご覧ください。

- **キャンバス 対ダイアグラムレイヤー**:キャンバスレイヤーは、プレゼンテーションなどの一般的な目的に使用されますが、ダイアグラム内のレイヤーは、ダイアグラム自身の要素を整理するために別々に管理されます。
- **ペアレンティング**:一度要素がダイアグラムの一部になると、その要素はダイアグラム形式自体が親となるため、キャンバスレイヤーに追加することはできません。

## レイヤーを並べ替える

パネルでレイヤーを並べ替えることができ、どのレイヤーのコンテンツが上に表示されるかに影響します。レイヤーを並べ替えるには、レイヤーパネル内でドラッグしてお好みの順序に配置するだけです。

これは、ダイアグラムの同じ部分に少し異なるコンテンツで2つのバージョンが必要な場合に、ダイアグラムを作成するための強力なツールです。レイヤーを互いの上に直接配置することで、レイヤーを並べ替えることでどれが表示されるかを変更できます。

## 標準レイヤー

標準レイヤーは常に表示され、他のレイヤーがアクティブでない場合、新しいウィジェットは標準レイヤーに追加されます。特定のレイヤーで作業していない場合は、デフォルトのレイヤーで作業しています。

デフォルトのレイヤーは、他のレイヤーと異なり、非表示やロックをすることができません。
