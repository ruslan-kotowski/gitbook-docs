ボードにコードブロックを追加して、共同プログラミング、デバッグ、問題解決に活用できます。Miro のコードブロック ウィジェットには、最も一般的なコーディング言語が含まれ、カスタマイズ可能です。

コードブロックを[マッピングやダイアグラム作成](../formats/diagramming/01-miro-for-mapping-diagramming.md)機能と組み合わせて、アーキテクチャーやフローをレビューすることができます。また、ダイアグラムのコネクターを使用して、ソースコードの部分間の関係をハイライト表示します。

**以下にコードブロックを使用します。**

- アジャイルセレモニー
- 共同開発とデバッグセッション
- リモートコーディングのインタビュー

## コードブロックを追加する方法

1. ボード左側の作成ツールバーに移動します
2. **他のアプリ** アイコンをクリック
3. 「**コードブロック**」を検索するか、コードブロックが見つかるまでスクロールします
4. コードブロックアプリのアイコンをクリックします
5. ボード上の任意の場所をクリックして、コードブロックを追加します。

*![Adding_a_code_block_to_the_board.gif](../../../../../../docs/using-miro/essential-tools/images/21016928888466_Adding%20a%20code%20block%20to%20the%20board.gif)
ボードにコードブロックを追加*

## コードブロックをカスタマイズする方法

コードブロックのコンテキストメニューでは、行のオン/オフの切り替え、フォントサイズの調整、プログラミング言語の切り替えを行うことができます。

1. コードブロックをクリックします。
2. コンテキストメニューでドロップダウンからプログラミング言語を選択し、フォントサイズを拡大または縮小し、行番号のアイコンをクリックして行のオン/オフを切り替えます。

![Customizing_a_code_block.gif](../../../../../../docs/using-miro/essential-tools/images/21016928890130_Customizing%20a%20code%20block.gif)*ボード上のコードブロックのカスタマイズ*
