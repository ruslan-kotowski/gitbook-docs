ボード上のウィジェットを誤って削除または移動しましたか？この操作は簡単に元に戻すことができるので、ご安心ください。

## 元に戻すオプションとやり直しオプション

**元に戻す**および**やり直し**ボタンは、作成ツールバーの下にあります。Miro では現在のセッション中に、*最大 30 件の操作*を元に戻したりやり直したりできます。ページを更新するか、ボードを再度開いた場合は、**元に戻す**や**やり直す**コマンドが*利用できなくなります*。

:::tip
誤って削除されたコンテンツを復元する場合は、[こちらのガイドをご確認](../working-on-the-board/18-restoring-board-content.md)ください。
:::

![undo-redo.png](../../../../../../docs/using-miro/essential-tools/images/21537436796434_undo-redo.png)
*Miro のボード上の元に戻す/やり直しオプション*

直前の操作を**元に戻す**には、**Ctrl + Z**（*Windows の場合*）/**Cmd** +**Z**（*Mac の場合*）を押し続けて、元に戻したい操作に到達してください。キーボード ショートカットよりもマウス操作を好む場合は、**元に戻す** (![icon-undo.svg](../../../../../../docs/using-miro/essential-tools/images/27942193905298_icon-undo.svg)) ボタンをクリックしてください。

**元に戻した操作をやり直す**には、**Ctrl + Shift + Z** (*Windows の場合*) /**Cmd** + **Shift** + **Z** (*Mac の場合*) を押すか、**やり直し** (![icon-redo.svg](../../../../../../docs/using-miro/essential-tools/images/27942193906194_icon-redo.svg)) ボタンをクリックします。

**やり直し**ボタンと**元に戻す**ボタンは、ボードで少なくとも 1 つの操作が行われた後にのみアクティブになります。あなた自身の操作のみを元に戻すことややり直すことができ、コラボレーターの操作を行うことはできません。

## よくある質問

**ボード全体の削除を元に戻すにはどうすればよいですか？**

手順はここをご覧ください。[削除されたボードを復元する方法](../managing-boards/08-how-to-restore-a-deleted-board.md)。

**ボード上のコンテンツの削除を元に戻すことはできますか？**

はい、[こちらで方法を学べます](../working-on-the-board/18-restoring-board-content.md)。

**他のボード編集者が行った変更を元に戻すことはできますか？**

いいえ、元に戻すことができるのは自分の操作のみです。

**元に戻す/やり直すボタンは有効ではありません。なぜですか？**

現在の作業セッションでボード上で変更を加えた場合にのみ、ボタンは有効になることにご注意ください。新しいセッションを開始した場合、アクティブになりません（例えば、ページを再読み込みするなど）。コンテンツを変更してもボタンが有効にならない場合は、[トラブルシューティング ガイド](../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md)をご確認ください。iPad ではツールバーが消えることがあるのでご注意ください - [詳細はこちらをご覧ください](../../getting-started/apps-for-devices/11-tablet-app.md)。
