ペンツールを使えば、手書きの絵をボードに追加したり、削除することができます。ツールは、マウス、トラックパッド、タッチスクリーンとの相性も良く、タブレットを使ったワークフローで欠かすことのできないツールになることでしょう。

> **利用可能環境：**ブラウザ版、[デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)、[タブレットアプリ](../../getting-started/apps-for-devices/11-tablet-app.md)

## ペンの使い方

:::note
Apple Pencil、Surface Pen、Samsung S Pen などの様々なペンツールを、[Miro と互換性のあるあらゆるデバイス](../../getting-started/apps-for-devices)で使えます。[動画](10-pen.md)を観て、Miro のタッチデバイスでの強化されたスタイラスサポートについて確認してください。
:::

**ペン**ツールをクリックするか、[キーボードの P を押す](../working-on-the-board/06-shortcuts-and-hotkeys.md)ことでツールを利用開始できます。**プリセット**を使えば、線の色や太さを簡単に変更することができます。

![using_pen.gif](../../../../../../docs/using-miro/essential-tools/images/21017348235538_using%20pen.gif)
*ペンの使用*

**ハイライト**を使って、モックアップに注釈を加え、会議をより魅力的にしましょう。

![highlighter.gif](../../../../../../docs/using-miro/essential-tools/images/21017348236946_highlighter.gif)
*ハイライトの使用*

[スマート図形](12-smart-drawing.md)を活用して[図形](11-shapes.md)、[付箋](14-sticky-notes.md)、[接続線](05-connection-lines.md)を簡単に作成できます。

:::tip
[図形ツール](11-shapes.md)を使えば、さらに多くの図形を作成できます。
:::

![smart_drawing_in_Miro.gif](../../../../../../docs/using-miro/essential-tools/images/21017318363666_smart%20drawing%20in%20Miro.gif)
*スマート図形*

ペン、ハイライト、スマート図形のそれぞれで、3 種類のプリセットを設定することができます。プリセットのアイコンをダブルクリックして、線の色と太さを変更します。

![presets.jpg](../../../../../../docs/using-miro/essential-tools/images/21017318365330_presets.jpg)
*ペンのプリセット*

描画オブジェクトを削除するには、スマート図形アイコンの**消しゴム**を選択し、マウスをクリックしながらオブジェクトの線を横にスワイプします。なお、消しゴムはペンで作成した描画だけを削除します。また、**選択**ツールで描画オブジェクトを選択し、キーボードの**Delete**キーを使って削除することもできます。

![eraser.gif](../../../../../../docs/using-miro/essential-tools/images/21017318366354_eraser.gif)
*Miro におけるペン描画の削除*

描画の一部を消去する必要がある場合は、**精密消去ツール**を使用できます。このツールを選択し、消去したい部分をクリックして押さえたまま、なぞってください。

![precision-eraser.png](../../../../../../docs/using-miro/essential-tools/images/31320402236690_precision-eraser.png)

*精密消去ツール*

投げ縄ツールは、手描きのオブジェクトやボード上の他のオブジェクトを選択して移動させるのに非常に便利です。

![lasso_tool.gif](../../../../../../docs/using-miro/essential-tools/images/21017318367506_lasso%20tool.gif)
*投げ縄ツールによるオブジェクトの選択*

ペン、消しゴム、投げ縄ツールの使用を中止するときは、他のツールを選択するか、ツールバーの [選択ツール] を選択します。

![select_tool.jpg](../../../../../../docs/using-miro/essential-tools/images/21017318368786_select%20tool.jpg)

### よくある質問

1. *Miro は手書き文字をテキストに変換できますか？*
   ー いいえ、まだできません。ただし、上の動画でご覧いただけるように、Apple Pencil と Scribble を使用する一部の iPad モデルでは、手書き文字を[テキスト](16-text.md)に変換することがサポートされています。
2. *ハイライトの透過率は調整できますか？*
   ー 現時点では調整できません。
3. *直線を描くにはどうすればよいですか？*
   - [接続線](05-connection-lines.md)を使うか、[スマート図形モード](12-smart-drawing.md)で直線を作成できます。
4. *ペンのプリセットを削除できますか？*
   - いいえ、できませんが、色や太さを簡単に変更することはできます。
