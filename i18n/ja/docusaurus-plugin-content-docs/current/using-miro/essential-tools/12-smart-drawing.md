スマート図形があれば、ボード上で一つのツールを利用して作成する美しい図形を、最初から楽しむことができます。スマート図形モードは、手描きしたオブジェクトを適切な図形、付箋、線や矢印に自動的に変換します。

> **実行可能なソフトウェア：**ブラウザー、[デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)、[タブレットアプリ](../../getting-started/apps-for-devices/11-tablet-app.md)、[モバイルアプリ](../../getting-started/apps-for-devices/08-mobile-app.md)

smart_drawing_in_Miro.gif
Miro のスマート図形

スマート図形を開始または終了するには、ツールバーの**ペン**ツールを選択し、**スマート図形**に切り替えます。線を中断せずに描画を開始します。1 ストロークは 1 つのオブジェクトとしてカウントされます。100% のズームレベルのご利用をお勧めします。

smart_drawing_on_the_toolbar.jpg
ツールバーのスマート図形

スマート図形アイコンをダブルクリックして、認識されるオブジェクトを確認します。

smart_drawing.gif
スマート図形で認識可能なオブジェクト

プリセットを使用して色や太さの異なるオブジェクトを作成します。最大 3 つまでのプリセットを作成し、必要に応じて編集できます。プリセットをダブルクリックすると設定変更できます。

editing_a_preset.gif
スマート図形プリセット

スマートオブジェクトを消すには、その上を覆うように線をジグザグに引きます。オブジェクトの 50% 以上が隠れるようにすると削除されます。

:::note
デフォルトの消しゴムは、スマートオブジェクトではなく標準のペン画のみで機能します。
:::

erasing.gif
スマートオブジェクトの削除

スマート図形モードを離れ、フリーハンドの描画に切り替えるには、[ペンまたはハイライトを](10-pen.md)選択します。

switching_to_pen.jpg
一般的なペンへの切り替え

該当するツールを使用して[図形](11-shapes.md)や[線](05-connection-lines.md)を描くこともできます。
