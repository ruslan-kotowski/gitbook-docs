Miro ビジュアルノートは、各ボードに埋め込まれた高度なテキストエディタ―です。他のテキストエディタ―を使う場合と同様に作業することで、ノートが読みやすくなります。

### ノートでのコラボレーション

ボードの左側にある作成ツールバーの**ツール、メディア、インテグレーション** **(+**) メニューから **Note**アプリを見つけて  ください。

![ビジュアルノート-エントリーポイント.png](../../../../../../docs/using-miro/essential-tools/images/21537451739922_visual-notes-entry-point.png)
/span>ノートへのアクセス

セクションの境界の三点リーダーをドラッグするだけで、ノートパネルのサイズを簡単に変更できます。

![ビジュアルノートパネル.png](../../../../../../docs/using-miro/essential-tools/images/21537435743634_visual-notes-panel.png)
*ノートのサイズ調整*

*To-do リスト*、*会議の議題*、その他の既成のテンプレートがいくつか用意されています。テンプレートをクリックしてノートに追加します。テンプレートは即座にノートに表示されます。

:::warning
テンプレートを追加できるのは、ノートセクションにコンテンツがないときだけです。
:::

![ビジュアルノートテンプレート.gif](../../../../../../docs/using-miro/essential-tools/images/21537451751442_visual-notes-template.gif)*テンプレートの追加*

チームと一緒にノートで作業することで、誰がどの作業を行っているかをリアルタイムで見ることができ、コラボレーションがしやすくなります。変更はすべてリアルタイムで見られます。

**[作成者を表示] アイコンをクリックしてコンテンツ作成者のイニシャルを確認することで、他の貢献者はノートへの変更や追加を誰が担当するのか容易に判断できます。**

![ビジュアルノート-ショー-オーサーシップ.png](../../../../../../docs/using-miro/essential-tools/images/21537435756434_visual-notes-show-authorship.png)
[作成者モードを表示] を有効にして作成者を確認

**ピン**アイコンをクリックして、ノートをピン留めし、将来のビジター全員にセクションを開いたままにしておくことができます。そうすることで、コラボレーターにノートセクションに注意が必要であることを知らせます。編集者であれば誰でも、ピンアイコンをクリックするだけでノートの固定を解除できます：

![ビジュアルノート-pin.png](../../../../../../docs/using-miro/essential-tools/images/21537435760530_visual-notes-pin.png)
*メモがピン留めされると、ピン留めした人のイニシャルがアイコンに表示されます。*

ノート上にコメントを残すことで、容易にアイデアを話し合うことができます。[@メンション](../facilitation-tools/01-@mentioning-people-on-the-board.md)を使用して、コメントセクションにチームメイトをタグ付けします。

![ビジュアルノーツコメント.png](../../../../../../docs/using-miro/essential-tools/images/21537435765522_visual-notes-comments.png)
コメントアイコンをクリックしてコメントを書き込み / 閲覧

### 書式設定

ノートでは、他のテキストエディタ―使う場合と同様に作業することで、ノートが読みやすくなります。そうすることで、読み手はドキュメントから必要な情報を、本来の意図通り容易に引き出すことができます。/span>

テキストをハイライトすると、テキスト書式のオプションが表示されます：

![ビジュアル・ノート・フォーマット.png](../../../../../../docs/using-miro/essential-tools/images/21537451775762_visual-notes-formatting.png)
テキストの書式設定オプションの選択

:::warning
ノートセクションに入力できる**記号は20万文字まで**ですので、ご注意ください。
:::

> ノート上のテキストをボード上のオブジェクトにリンクするには、[リンクをオブジェクトにコピーし](../working-on-the-board/16-internal-and-external-linking.md)、ノート上のテキストを選択します。

### ノート上のボードコンテンツ

ボードからノートに埋め込んだオブジェクトは、ボードの他のメンバーが容易に移動して貢献できるようにします。

ボードオブジェクトをノートに追加するには、オブジェクトを選択し、ノートにドラッグします。これにより、ボードの内容のコピーがノートに作成されます。

![visual-notes-drag-and-drop.gif](../../../../../../docs/using-miro/essential-tools/images/21537451782290_visual-notes-drag-and-drop.gif)
*ボードのオブジェクトをし、ノートにドラッグします。*

ノート上のコピーからボードコンテンツへは容易に移動できます。それを行うには、コンテンツを選択し、ポップアップの矢印アイコンをクリックしてください。

![ビジュアルノート-ボード-オブジェクト.png](../../../../../../docs/using-miro/essential-tools/images/21537451786514_visual-notes-board-object.png)
*ノートパネルからボードをナビゲート*

ボードコンテンツが更新された場合、ノート上の対応するコピーを手動で更新できます。そのためには、ノート上のコンテンツをハイライトし、設定のポップアップで更新アイコンをクリックする必要があります。

![ビジュアルノート-リフレッシュオブジェクト.png](../../../../../../docs/using-miro/essential-tools/images/21537451792658_visual-notes-refresh-object.png)
ノート上でのボードコンテンツの更新

:::note
ノートに埋め込まれたオブジェクトに別のウィジェットを追加し、埋め込まれたオブジェクトを更新した場合、新しいウィジェットはノートに表示されません。埋め込まれたオブジェクトを削除し、ボード上で両方のウィジェットを選択し、ノートに追加してください。
:::

:::warning
ノートにコピーされたオブジェクトが削除されても、対応するボードオブジェクトは削除されません。
:::

### エクスポートする

ビジュアルノートを PDF 形式でエクスポートしてコンテンツをポータブルにすると、テキストをオフラインで作業できるようになります。

![ビジュアルノートexport.png](../../../../../../docs/using-miro/essential-tools/images/21537451799314_visual-notes-export.png)
ノートを PDF としてエクスポート可能

### モバイルおよびタブレットアプリのノート

ビジュアルノートは、Android と iOS ユーザーの[モバイルアプリ](../../getting-started/apps-for-devices/08-mobile-app.md)や[タブレットアプリ](../../getting-started/apps-for-devices/11-tablet-app.md)でも利用可能です。Miro アプリバージョンは、Android と iOS モバイルおよびタブレットアプリの場合、 **3.3.1** 以上である必要があります。

機能は、一部の特殊な機能を除き、デスクトップ版とほぼ同じです。

:::warning
ノートは画面全体を取るので、ボードまたはビジュアルノートのどちらでも作業が可能です。
⚠️ ボードコンテンツをノートに追加することはできません。でも更新、移動、削除オプションは利用可能です。
⚠️ モバイルアプリではビジュアルノートをエクスポートすることはできません。
:::

## よくある質問

**ボードからノートを削除できますか？**

ノート内のコンテンツを削除できます。ボードをロードするたびにノートが開く場合、固定を解除してノートを隠すことができます。

**複数のノートリスト/複数のノートセクションを作成できますか？**

いいえ、1ボードにつき1ページです。

**チェックリストのテンプレートをボードに追加できますか？**

ボード上では、[ワイヤーフレームライブラリーの](../miroverse/prototyping/02-prototyping-library.md)チェックボックスを使用することができます。

**誤ってノートのテキストを削除してしまいました。**どうすればよいですか？/strong>

ノートの上部にある[元に戻す]ボタンを使用します。ショートカット Ctrl + Z（**Windows の場合**）または *Cmd + Z*（**Mac の場合**）を使用することもできます。
