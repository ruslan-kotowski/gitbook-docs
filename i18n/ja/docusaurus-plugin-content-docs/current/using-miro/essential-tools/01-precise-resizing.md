数値による寸法指定で、ピクセル単位での正確なサイズ調整を行います。

:::note
正確なサイズ調整は、ダイアグラミング、Miro Prototypes、Miro スライドなどの一部のフォーマットで利用可能です。
:::

## 正確なサイズ調整

1. フォーマットのコンテキストメニューで**フォーカスモード**アイコンをクリックして、フォーカスモードに入ります。
2. サイズを変更したいウィジェットをクリックします。サポートされているウィジェットには、テキスト、画像、付箋、ステンシル、およびプロトタイピング図形が含まれます。
3. ウィジェットのコンテキストメニューで**サイズ変更**アイコンをクリックします。
   メニューの下に寸法ダイアログが表示されます。
4. **幅**と**高さ**のピクセル寸法を入力します。
5. **Enter**キーを押して変更を確定します。

:::note
テキストボックスでは、幅のみを指定できます。高さはテキストボックスの内容に応じて自動的に調整されます。
:::
