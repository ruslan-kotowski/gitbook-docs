付箋は、簡単なブレインストーミング、メモの作成、情報の視覚的な整理に最適です。カンバンボードやホワイトボードへの付箋の貼り付けに慣れてしまえば、違和感なく使えるようになります。

> **利用可能なバージョン：**ブラウザー版、[デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)、[タブレットアプリ](../../getting-started/apps-for-devices/11-tablet-app.md)、[モバイルアプリ](../../getting-started/apps-for-devices/08-mobile-app.md)（機能制限付き）

### はじめに

付箋を使用するには、ツールバーの**付箋**（![icon-sticky.svg](https://help.miro.com/hc/article_attachments/25736234510482)）アイコンをクリックするか、[キーボードの N キー](../working-on-the-board/06-shortcuts-and-hotkeys.md)を押します。また、ツールバーから直接ドラッグ & ドロップするか、ボードをクリックし、マウスの左ボタンを長押ししたままカーソルをドラッグして、付箋を追加することもできます。

付箋のコンテキスト メニューのアイコンをクリックして、付箋の形状を変更できます。

![sticky-switch-type.png](https://help.miro.com/hc/article_attachments/25736234511250)
*正方形の付箋を長方形に変換*

付箋には、文字の読みやすさとボードのデザインの一貫性に配慮して厳選された 16 色が利用できます（ユーザーが設定できるカラーはありません）。

![sticky-fill-color.png](https://help.miro.com/hc/article_attachments/25736234512018)
*付箋の色*

付箋に文字を追加するには、付箋を選択して入力を始めてください。文字サイズにもよりますが、付箋の文字制限は約 3,000 文字です。コンテキストメニューで**自動**フォントサイズを有効にすることができます。

複数の付箋を変更するには（サイズや色の変更、タグの追加など）、[こちらのガイド](../working-on-the-board/10-working-with-objects.md)の手順に従って複数の付箋を選択してください。

:::tip
[オブジェクトのサイズ](../formats/diagramming/01-miro-for-mapping-diagramming.md)をオンにすると、ボード全体で同じサイズの付箋を正確に作成できます。
:::

付箋を削除するには、コンテキストメニューの三点リーダーをクリックして、**[削除]** を選択するか、[付箋を選択](../working-on-the-board/21-work-smarter-not-harder.md)して、**Backspace** を押してください。

:::tip
複数の付箋を行または列に揃えるには、[付箋を選択](../working-on-the-board/10-working-with-objects.md)し、コンテキストメニューの**整列**機能を使用します。
:::

![sticky-align.png](https://help.miro.com/hc/article_attachments/25736234512658)
*付箋の位置合わせ*

### 一括モード

多くの付箋を一括で追加したい場合は、**付箋**アイコンをクリックし、**一括モード**を選択して内容を入力します。**Enter** キーを押すと、次のアイデアを記入できます。付箋に入力できる記号の数はフォントサイズによります。入力を終え **[完了]** をクリックすると、アイデアが付箋になってボードに追加されます。

### 付箋スタック

付箋スタック機能を使って、ボードに空白の付箋一式を追加することができます。付箋スタックを追加するには：

1. **作成ツールバー**の **［付箋］**アイコンをクリックします。
2. [**スタック**] をクリックします。
3. 付箋スタックを置きたいボードの場所をクリックしてください。

ユーザーは、作成ツールバーから付箋を追加、またはキーボード ショートカットを使用する代わりに、付箋スタックからボードに付箋をドラッグすることができます。

### スプレッドシートからの貼り付け（Google スプレッドシート、Excel など）

また、任意のスプレッドシートからデータをコピーし、付箋の集合としてボードに貼り付けることもできます。 この場合、1 つのセルが 1 枚の付箋となります。

1. **Ctrl + C***（Windows の場合）*または **Cmd + C***（Mac の場合）*を使用して、スプレッドシートからセルをコピーする
2. Miro のボードを開いて、キャンバスをクリックする（一括モードを開く**必要はありません**）
3. **Ctrl + V***（Windows の場合）*または **Cmd + V***（Mac の場合）*を押す
4. **[付箋として貼り付ける]** を選択してボードに付箋を貼り付ける

各セルは 1 つの付箋としてインポートされます。一度に貼り付けることができる最大セル数は **5,000** 個で（ただし 50 行、100 列以内）、最大文字数は **6,000** 文字です。

### 作成者ラベル

ワンクリックで、簡単に付箋作成者の名前を付箋に追加できます。ボードにアクセスできる編集者は、コンテキストメニューの **[作成者を表示]** オプションを有効/無効にすることで、付箋の作成者ラベルを公開または非公開にすることができます。

![sticky-show-author.png](https://help.miro.com/hc/article_attachments/25736234513170)
*作成者ラベルの公開*

付箋の作成者ラベルには、付箋を作成したユーザーの名前が表示されます。ただし、他のユーザーが付箋上のテキストを置き換えると、作成者ラベルはそのユーザーに自動的に更新されます。ユーザー A が作成した空の付箋をユーザー B が選択し、作成者ラベルを有効にすると、ユーザー A ではなく、ユーザー B の名前が表示されることになります。[ビジター](../sharing-boards/08-collaboration-with-visitors.md)が付箋に記載し、作成者ラベルを有効にすると、作成者名には「ビジター」が表示されます（ただし、[ビジターに名前がある](../sharing-boards/09-visitor-names-beta.md)か、Miro にログインしている場合を除く）。

タグ タグを使用すればタスクやアイデアをまとめることができます。それでも、誰が付箋を作成し、編集したかは、[ボードの履歴](../managing-boards/11-board-history-activity.md)やコンテキストメニューの**情報**から把握することができます。

### タグ

**タグ**を使用すればタスクやアイデアをまとめることができます。付箋を選択して **[タグ]** アイコンをクリックし、新しいタグを作成するか、既存のタグを選択して付箋に追加できます。タグ付けできる付箋の数に制限はありません。タグ検索で、付箋のグループをすばやく見つけることができます。1 つの付箋には最大 8 個までタグを追加できます。

![sticky-tag.png](https://help.miro.com/hc/article_attachments/25736234514322)
*タグの使用*

特定のタグを含む付箋をすべて検索するには、[[ボードを検索する]](../working-on-the-board/19-searching-text-on-the-board.md) を使用します。

付箋からタグを削除するには、コンテキストメニューから**タグを追加**を選択し、削除したいタグをクリックします。

ボード上の**すべて**のオブジェクトからタグを**完全に**削除するには、ペンのアイコンをクリックし、**[タグを削除]** を選択します。

### 絵文字によるリアクション

付箋に**絵文字**のリアクションを追加して、メモに反応することができます。絵文字は、投票、やることリストのチェックマーク（または遊び要素）など、さまざまな目的に使用できます。

絵文字で反応するには、付箋を選択し、メニューにある **[絵文字を追加]** をクリックします。絵文字を選択すると、付箋の下の方に絵文字が配置されます。既存の絵文字で投票する、また 1 つの付箋に複数のリアクションを追加することができます。

![sticky-emoji.png](https://help.miro.com/hc/article_attachments/25736234515346)
*付箋への絵文字によるリアクションの追加*

追加した絵文字を削除するには、絵文字をクリックするだけです（必ず[選択ツール](../working-on-the-board/05-using-miro-with-a-mouse-trackpad-or-touchscreen.md)を使用してください）。

### クイック ダイアグラム作成

付箋、図形、カードを選択し、オブジェクトの近くにある青色のドットに合わせてカーソルを置くと、新たにオブジェクトや接続ラインを作成する場所が表示されます。ドットをクリックしてオブジェクトや接続ラインを作成します。ドットをドラッグすると、選択したオブジェクトを別の既存のオブジェクトに接続できます。

:::tip
ダイアグラム作成機能の詳細はこちらから：[Miro を使ったマッピングとダイアグラム作成](../formats/diagramming/01-miro-for-mapping-diagramming.md)
:::

### よくある質問

1. *付箋の文字の書式を設定することはできますか？*
   ー 付箋の文字サイズ、配置、スタイルは変更できます。他の書式設定オプションは利用することができません。
2. *付箋の文字をエクスポートできますか？*
   ー はい、[付箋を選択](../working-on-the-board/10-working-with-objects.md)し、コンテキストメニューの三点リーダーをクリックして、[**CSV にエクスポート**] を選択します。また、ボードのコンテンツを[画像や PDF としてエクスポート](../import-and-export/export/03-how-to-export-your-board.md)することもできます。
3. [ペン画](10-pen.md)*、画像、アイコンは付箋に自動的に添付（貼り付け）されますか？*
   ー いいえ、ただし付箋に図形や画像などを追加し、[両方のオブジェクトを選択](../working-on-the-board/10-working-with-objects.md)して、[グループ化](../working-on-the-board/08-structuring-board-content.md)することができます。そうすることで、付箋に図形や画像を添付することができます。
4. [コメント投稿者](../sharing-boards/01-board-access-rights.md)*は付箋や絵文字を追加できますか？*
   ー いいえ、コメント投稿者は[コメント](../facilitation-tools/asynchronous-tools/01-comments.md)を残すだけで、他のウィジェットを使用できません。
5. *ボードに付箋の束を追加する方法を教えてください。*
   ー 括モードを使用して事前に入力した付箋を追加するか、**付箋パック**の[テンプレート](../../getting-started/start-here/your-first-board/04-templates.md)を使用して複数の空白の付箋を追加することができます（検索から[テンプレートピッカー](../../getting-started/start-here/your-first-board/04-templates.md)で探します）。
6. *付箋のアイコンがツールバーから消えてしまいました。元に戻す方法を教えてください。*
   ー ツールバーの三点リーダーをクリックし、アプリとツールの検索パネルから付箋ツールを検索します。[付箋] アイコンを選択して、ツールバーにドラッグして戻すことができます。詳細は[こちら](../../getting-started/start-here/your-first-board/05-toolbars.md)をご覧ください。
7. *突然、付箋が編集できなくなりました。なぜですか？*
   ー 以下の点をご確認ください。
   - [編集](../sharing-boards/01-board-access-rights.md)権限が取り消されていないか（ツールバーの他のツールを使用できる場合は、まだ編集権限があることを意味します）
   - 付箋が[ロック](../working-on-the-board/17-locking-content-on-the-board.md)されていないか
   - 付箋を編集する前に[選択ツール](../working-on-the-board/05-using-miro-with-a-mouse-trackpad-or-touchscreen.md)に切り替えていないか
     それでも解決しない場合は、[こちらの記事](../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md)のトラブルシューティングの手順をお試しください。
