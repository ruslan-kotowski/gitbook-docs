テーブルは、Miro でコンテンツに骨組みを与え、アイデアから実行までを支えるインタラクティブなツールです。

> ***利用可能な環境:** すべてのデバイス*
> ***利用可能なプラン:** すべての Miro プラン*
> ***実施者:** ボードの所有者と編集者*

## 主な機能

テーブルの主な機能は次の通りです：

- **カスタムフィールドを作成**
  カスタムフィールドで情報を整理し、構造化できます。
- **Miro カードからレコードを作成**
  Miro カードをテーブルウィジェットにドラッグ＆ドロップして、新しいレコードを作成できます。
- **付箋からレコードを作成**
  Miro カードまたは付箋をテーブルに追加するを参照してください。
- **Jira カードから同期レコードを作成**
  Jira カードをテーブルに追加するを参照してください。
- **高度なフィルターと並び替え機能**
  テーブルをフィルターし並び替えて、レコードを整理し、優先順位を付けます。
- **レコードのグループ化**
  テーブル内のレコードをフィールドごとに整理し、情報を論理的にグループ化します。
- **複数のボードで同期されたテーブルの作成**
  テーブルをコピー＆ペーストして、同じレコードを同期表示させることができます。
- **タイムラインビュー**
  データを新しいレイアウトで参照するために、タイムライン表示に切り替えます。
- **列計算**
  数値フィールドについて、合計や平均などを集計し、一目でデータを分析します。
- **視覚的な数値フォーマット**
  数値を進捗バーとしてフォーマットし、パーセンテージまたは通貨表示で設定できます。特定の条件を満たす値を強調表示する条件付きフォーマットルールを使用しましょう。詳細は[テーブルでの視覚的な数値](04-visual-numbers-in-tables.md)をご覧ください。
- **依存関係**
  プロジェクト間で"次によりブロック"および"次をブロック"フィールドを使用して、レコード間の依存関係をマッピングし、可視化します。
- **一括操作**
  一度に複数のレコードに対して編集、移動、複製、削除などの操作を行うか、複数のレコードをカードとしてキャンバスにドラッグします。

## ボードにテーブルを追加する

:::warning
ゲスト編集者はテーブルを追加または編集する権限がありません。
:::

1. Miro ボードを開きます。
2. **ツール、メディア、インテグレーション**アイコン（**+**）を作成ツールバーでクリックします。
   ツール、メディア、インテグレーションパネルが開きます。
3. **テーブル**を検索して選択します。
   カーソルがテーブルのアイコンになります。
4. Miro ボード上の好きな場所をクリックして、テーブルウィジェットを配置します。

## Excel ファイルをテーブルに変換する

1. Miro ボードを開きます。
2. 作成ツールバーの「**ツール、メディア、インテグレーション**」アイコン（**+**）をクリックします。
   「ツール、メディア、インテグレーション」パネルが開きます。
3. 「**アップロード**」を検索して選択します。
   「アップロード」パネルが開きます。
4. **マイデバイス**を選択します。
5. アップロードしたい Excel ファイル (.xlsx) を見つけて選択します。
6. 次のオプション付きモーダルが開きます:
   1. テーブルに変換
   2. 表に変換
   3. ファイルとして追加
7. **テーブルに変換**を選択し、**最初の行をヘッダーとして使用**するかどうかを選びます。
8. **選択**をクリックします。
9. Excel ファイルのデータでボードにテーブルが作成されます。

:::warning
Excel ファイルをアップロードする際の制限は、500 行と 30 列です。
:::

## テーブルのコピー＆ペースト

ボード内またはボード間で、テーブルをコピー＆ペーストする場合、基本的に 2 つのオプションがあります。最初のオプションは、それぞれの場所で更新されたデータが同期される連動テーブルを作成することです。2 つ目は、データを連動させずにテーブルをコピーし、テンプレートのように活用するオプションです。

1. コピーしたいテーブルを選択します。
2. コンテキストメニュー (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg)) をクリックして「コピー」を選択します。または、Ctrl + C（Windows の場合）または Command + C（Mac の場合）のキーボードショートカットを使用します。
3. ボード上のテーブルを貼り付けたい場所に移動します。
4. 右クリックして「貼り付け」を選択します。または、Ctrl + V（Windowsの場合）または Command + V（Macの場合）のキーボードショートカットを使用します。
   ポップアップが開きます。
5. ポップアップ画面で、連動テーブルを作成するか、新規テーブルを作成するかを選択します。

## テーブルの権限管理

異なる Miro ボード間でテーブルの連動ビューを複数作成する場合、テーブルの連動ビューを新しいボードに追加するときに、そのテーブルへの編集および閲覧権限を持つユーザーを確認および管理できるよう、アクセス権を管理する必要があります。連動されたテーブルに対するアクセス権は、大元のテーブルが作成された元データボードで管理されます。

新しいボードにテーブルを連動ビューとして貼り付けた際、ボードのすべてのユーザーが該当テーブルについて閲覧または編集権限を持っていない場合に、ポップアップが表示されます。テーブルのアクセス権を表示または編集したい場合は、テーブルが表示されている元のボードに移動して変更を行います。

ボードのユーザーが、元のテーブルが作成されたホームボードにアクセスできない場合、テーブルはアクセス不可状態で表示されます。ユーザがホームボードへの閲覧専用アクセス権しか持っていない場合、新しいボードのテーブルを見ることはできますが、アイテムを編集したり、絞り込み、並び替え、グループ化などを適用して表示を変更することはできません。

## テーブルの操作

テーブルを使用すると、必要なコンテンツを自在に作成し、作業や仕事内容に合わせて最も効果的な方法で構成・整理することができます。

Miro ボードに新しいテーブルを作成すると、既存フィールドに、Miro カードにもなる数件のデフォルトフィールドが表示されます。これらのフィールドは削除、編集、非表示にでき、また独自の新しいフィールドを作成することもできます。

### フィールドの作成

以下の手順に従って、新しいフィールドを作成してください：

1. テーブルの右端の列の上部にある + アイコンをクリックします。
   メニューが開きます。
   ![tables-adding-fields.png](../../../../../../docs/using-miro/formats/images/25142699942930_tables-adding-fields.png)
   *テーブルに新しいフィールドを追加中*
2. メニューから作成したいフィールドの種類をクリックします。Miro フィールドとカスタムフィールドのオプションがあります。
   各種オプションのダイアログが開きます。
3. ダイアログにフィールド情報（フィールド名、選択肢フィールドの場合はドロップダウンのオプション）を入力し、保存をクリックします。

:::note
Link フィールドタイプは Business および Enterprise プランでのみ利用可能です。
:::

### フィールド名またはオプションの編集

1. フィールド名にカーソルを合わせます。
   三点リーダー（...）アイコンが表示されます。
2. **三点リーダー**（**...**）アイコンをクリックします。
   メニューが開きます。
3. **フィールドを編集** をクリックします。
   編集オプションのダイアログが開きます。
4. フィールド名やオプションを編集し、**保存**をクリックします。

### フィールドの削除

1. フィールド名にカーソルを合わせます。
   三点リーダー（...）アイコンが表示されます。
2. **三点リーダー**（**...**）アイコンをクリックします。
   メニューが開きます。
3. 削除をクリックします。

:::warning
削除したフィールドを元に戻すことはできません。現在のテーブルと連動するすべてのバージョンから直ちに削除されます。
:::

### フィールドの非表示/表示

以下の手順に従って、単一のフィールドを表示または非表示にします：

1. フィールド名にカーソルを合わせます。
   三点リーダー（...）アイコンが表示されます。
2. **三点リーダー**（**...**）アイコンをクリックします。
   メニューが開きます。
3. **フィールドを非表示**をクリックします。
   フィールドは非表示になります。
4. フィールドの非表示を解除するには、上記と同じ手順を繰り返しますが、「**フィールドの非表示解除**」をクリックします。

また、複数のフィールドを一度に非表示、非表示解除することもできます。

以下の手順に従って、複数のフィールドを非表示または非表示解除します：

1. テーブル上部の**非表示**アイコンをクリックします。
   テーブル内のフィールドリストが表示されます。
2. リストから非表示または非表示を解除したいフィールドを選択します。

### レコードを編集

1. 編集したいレコードをダブルクリックします。
   レコードが編集可能になります。
2. レコードを編集して Enter キーを押してください。

レコード内のテキストに書式を適用したり、リンクを追加するには次の手順を実行します：

1. 編集したいレコードをダブルクリックします。
   レコードが編集可能になります。
2. フォーマットしたいテキストをハイライトします。
   コンテキストメニューが表示されます。
3. コンテキストメニューや[キーボードショートカット](../working-on-the-board/06-shortcuts-and-hotkeys.md)を使って、テキストにフォーマットを適用したりリンクを追加したりします。
4. Enter キーを押してレコードを保存します。

レコードを編集する際にサイドパネルでもテキストのフォーマットを適用できます。

### 複数のレコードを一括編集する

1. 行にカーソルを合わせると、左側にチェックボックスが表示されます。
2. 該当する行の各チェックボックスを使用して編集するレコードを選択します。
   編集のためのオプションがあるツールバーが表示されます。
3. ツールバーでそれらのレコードを同時に編集、移動、複製します。

### 記録を削除

1. 削除したいレコードにカーソルを合わせます。
2. メニューを開くために6つのドットアイコンをクリックします。
3. **削除**を選択します。

### 複数のレコードを削除

1. 行にマウスを重ねて左にチェックボックスを表示させます。
2. 編集するレコードを、それぞれの行にあるチェックボックスを使用して選択します。
   編集のためのオプションがツールバーに表示されます。
3. ツールバーで**削除**アイコンをクリックして、選択したすべてのレコードを削除します。

### テーブルにコメントを追加する

テーブルの話し合いたい部分に直接コメントを追加することで、コラボレーションを容易にしましょう。

1. コメントを追加したい行にカーソルを合わせます。
   最初のセルの右側にコメント追加アイコンが表示されます。
2. **コメント追加**アイコンをクリックします。
   左にサイドパネルが開きます。
3. パネルにコメントを追加し、Enterキーを押します。

新しいコメントが追加されると、各行のコメント追加アイコンの横にコメント数が表示されます。アイコンをクリックしてコメントパネルを開きます。

コメントパネルからは以下の操作ができます：

- コメントに返信する。
- コメントにリアクションを追加する。
- コメントスレッドを解決する。
- コメントへのリンクをコピーする。
- コメントスレッドをフォローして通知を受け取る。
- コメントスレッドを削除する。
- 自分が残したコメントを編集する。

### テーブルに Miro カードや付箋を追加

Miro カードや付箋を使ってテーブルにアイテムを作成できます。

1. テーブルにコピーしたいカードや付箋を選択します。
2. カードまたは付箋をテーブルの上にドラッグ＆ドロップしてください。
   新しいアイテムの挿入場所に青い線が表示されます。
3. 新しいアイテムが作成され、カードの内容は適応するフィールドに入力されたます。
   付箋の場合、最初のフィールドに内容が入力されます。

### テーブルに Jira カードを追加

Jira カードをテーブルにドラッグ＆ドロップして、Jira と同期されたアイテムを作成できます。つまり、Miro と Jira 上での作業をテーブルまたはタイムラインに統合し、チーム全体の作業を一か所で管理・追跡することができます。

1. キャンバス上で該当する Jira カードを見つけます。
2. カードをテーブルの上にドラッグします。
3. テーブル内の該当する行にカードをドロップします。

Miro で行われた変更は Jira に反映され、その逆も同様です。テーブル内の以下のフィールドが Jira に同期されます：

- タイトル
- 概要
- 工数見積
- 開始日
- 終了日
- 担当者（ベータ版）
- ステータス（ベータ版）

テーブルの他のすべてのフィールドは Miro にのみ保存され、Jira には同期されません。

**詳細情報：**[Jira カードのよくある質問](../../integrations-apps/atlassian/17-jira-cards-faq.md)をご覧ください。

### Jiraカードを一括処理する

Jira に同期されたレコードを一括編集する際は、Jira インテグレーションがサポートしているアクションとフィールドのみが利用可能です。サポートされていないアクションは、一括アクションメニューに表示されないか無効化されます。

### テーブルの絞り込み

フィールドを1つ以上指定してテーブルの内容を絞り込み、作業したい閲覧やレコードを限定できます。

1. テーブルの上部にある**フィルターアイコン**をクリックします。
   ダイアログが開きます。
2. **フィルターを追加**または**フィルターグループを追加**を選択します。
   ダイアログが開きます。
3. フィルターのパラメーターを指定します。絞り込み条件の対象フィールド、絞り込みロジック、フィルターに利用する特定のコンテンツを指定します。
   テーブルにはリアルタイムでフィルターが適用されます。
4. フィルターダイアログの外側の任意の場所をクリックして閉じます。

### テーブルの並べ替え

1. フィールド名にカーソルを合わせます。
   三点リーダー（...）アイコンが表示されます。
2. **三点リーダー**（**...**）アイコンをクリックします。
   メニューが開きます。
3. **昇順で並べ替え**または**降順で並べ替え**のいずれかをクリックします。

テーブルの並べ替えを解除するには:

1. テーブルの上部にある**並べ替えアイコン**をクリックします。
   ダイアログが開きます。
2. **並べ替えを削除**をクリックします。

### テーブル内を検索する

1. テーブルの上部ツールバーで**検索**アイコンをクリックします。
2. 検索クエリを入力します。
3. 入力すると関連する結果が表示されます。
4. 検索バーの矢印アイコンを使用するか、テーブルをスクロールして結果をナビゲートできます。
5. **クリア** (**X**) アイコンをクリックして、テーブル全体に戻ります。

### フィールドごとに記録をグループ化

1. テーブル上部の**グループ**アイコンをクリックします。
   メニューが開きます。
   ![table-group-records.png](../../../../../../docs/using-miro/formats/images/25142699944338_table-group-records.png)
   *テーブルでレコードをグループ化する*
2. レコードをグループ化したいフィールドを選択します。
   テーブル内のレコードは選択したフィールドでグループ化されます。

:::note
レコードを既存のグループにドラッグすると、該当するフィールド値がそのグループに合わせて更新されます。
:::

テーブルのグループ化を解除するには、以下の手順に従ってください：

1. テーブル上部の**グループ**アイコンをクリックします。
   メニューが開きます。
2. **グループ解除**をクリックします。

### 連動カード

テーブルからキャンバスにレコードをドラッグ＆ドロップして、連動カードを作成できます。

1. 連動カードを作成したいレコードにカーソルを合わせます。
   レコードの左側にアイコンが表示されます。
2. ドットのアイコンをクリックしたまま、キャンバス上にドラッグします。
   そのレコードの情報でカードが作成されます。
3. テーブル上のレコードが更新されるたびに、カードも更新されます。その逆も同様です。

カードがテーブルと連動しているかどうかは、カードの右下に表示されるデータベースアイコンで確認できます。

レコードを削除した場合、対応する連動カードはボード上に残りますが、空白で表示されます。

キャンバス上で連動カードを削除しても、そのレコードはテーブル上に残ります。

既存の連動カードを元のテーブルにドラッグしても、カードは該当テーブルで一意のレコードとして扱われるため、機能しません。ただし、既存の連動カードを新しいテーブルにドラッグすると、連動していない新しいレコードとしてテーブルに表示されます。

### テーブルをタイムラインとして表示

タイムライン表示に切り替えるには、以下の手順に従ってください：

1. テーブルの上部にある**テーブル**アイコンをクリックします。
   ダイアログが開きます。
2. **タイムライン表示**を選択します（または**テーブル表示**に戻します）。

タイムライン表示に切り替えると、デフォルトの開始日と終了日が記載されている場合は、テーブル内のレコードがタイムライン上のバーとして配置されます。タイトルフィールドと担当者フィールドは、レコード名と担当者をバーに表示するために使用されます。

**詳細情報:** [タイムライン](15-timeline.md)

## 列の計算

> **対象プラン:** Business, Enterprise

列の計算を使用すると、テーブル内の数値フィールドに対して集計関数を実行できるため、データの分析や要約に役立ちます。任意の数値列に対して、合計、平均、カウント、最小値、最大値、中央値を計算できます。

1. データを含む列ヘッダーをクリックしてフィールドオプションメニューを開きます。
2. メニューから**列の計算を表示**を選びます。
3. 適用したい計算タイプを選択します:
   1. 合計: 列内のすべての値を加算します
   2. 平均: すべての値の平均を計算します
   3. 件数: エントリーの数をカウントします
   4. 最小: 最小の値を表示します
   5. 最大: 最大の値を表示します
   6. 中央値: 中央の値を表示します
4. 計算結果は、表の下部にあるフッタ行に表示されます。

列の計算を削除するには:

1. **計算**オプションをフッター行でクリックします。
2. **なし**を選択します。
3. 最後の計算が「なし」に設定されるまで繰り返します。

:::note
列ごとに 1 種類の計算を適用できます。テーブルをフィルターまたはグループ化すると、計算は表示中のレコードにのみ反映するよう自動で更新されます。グループ化されたビューでは、グループごとに計算が表示され、全体の合計も示されます。
:::

列計算は視覚的な数値フォーマッティングとシームレスに連携します。視覚的フォーマッティングを計算列に適用すると、結果はフォーマッティングルールに従ってプログレスバーとして表示されます。[テーブル内の視覚的な数値](04-visual-numbers-in-tables.md)を参照してください。

## 複数列の計算式

> **どのプラン:** Business, Enterprise

列の計算に加えて、複数列にわたる計算式のフィールドを作成できます。計算式フィールドは、同じ行の複数の列で計算を行います。

計算式フィールドを作成するには:

1. 新しいフィールドを追加するには、**+** アイコンをクリックします。
2. **計算式**タイプを選択します。
3. 視覚的な計算式ビルダーを使用して、フィールド、定数、演算子（+, -, ×, ÷, (, )）を選択します。
4. 計算式は自動的に各行に対して計算されます。

:::note
フォーミュラ フィールドでは、現在は数値フィールドと定数のみをサポートしています。
:::

## 関連付け（依存関係）

> **どのプラン:** Business, Enterprise

この関連付けのフィールドの種類では、テーブル内のレコード間の依存関係を「次によりブロック」と「次をブロック」フィールドを使用してマッピングできます。これにより、プロジェクトの関係を追跡し、作業項目がどのように互いに依存しているかを理解するのに役立ちます。

### 依存関係フィールドを作成

1. **+ アイコン**をクリックして新しいフィールドを追加します。
2. 次のいずれかを選択します：
   1. **次によりブロック** - このレコードの前に完了しなければならないレコードを表示します。
   2. **次をブロック** - このレコードの完了を待っているレコードを表示します。
3. フィールドに名前を付け、「作成」をクリックします。

### レコード間に依存関係を追加する

依存関係フィールドを作成したら、次の手順でレコードをリンクできます。

1. **次によりブロック**列または**次をブロック**列のセルをクリックします。
2. リンクしたいレコードをドロップダウンメニューから選択します。
3. セルの外をクリックして保存します。

:::note
レコードには複数の「次をブロック」および「次によりブロック」の関係を持つことができます。依存関係はすべての同期されたテーブルで同期され、閲覧やボード間での一貫性を保ちます。
:::

:::warning
**現在の制限（ベータ版）:**

- 依存関係は Jira 同期のレコードやその他のサードパーティーのインテグレーションにはまだサポートされていません
- 同期されたカードには依存関係のビジュアル指標がまだ表示されていません
- 依存関係に基づく自動日付調整はまだ利用できません
:::

## リレーション（階層構造）（ベータ版）

> **どのプラン：**Business, Enterprise

階層構造フィールド種別を使用すると、**親**と**子**フィールドを用いてテーブル内のレコード間に階層を作成できます。

### 階層フィールドを作成する

1. 新しいフィールドを追加するには、**+** アイコンをクリックします。
2. 以下のいずれかを選択してください：
   1. **親**: このフィールドを使用して、レコードを上位の項目（例：エピックにリンクされた機能）とリンクします。
   2. **子**: このフィールドを使用して、レコードを下位の項目（例：サブタスクを持つイニシアティブ）とリンクします。
3. フィールドに名前を付け、**作成**をクリックします。

### 親と子のレコードをリンク

1. 列の **親** または **子** のセルをクリックします。
2. ドロップダウンメニューからリンクしたいレコードを選択します。
3. セルの外をクリックして保存します。

### 階層を視覚化する

1. テーブルのヘッダーにある **表示設定** アイコンをクリックします。
2. **ネスト** をオンにします。

親レコードの横にある **山形記号** を使用して、子レコードを表示または非表示にします。

:::note
*ネストおよび階層構造はデフォルトでは非表示になっています。設定でオンにする必要があります。*
:::

### その他の階層の作成方法

1. 各行の左の**6 点メニュー**から**サブレコード追加**をクリックします。
2. 階層構造がデフォルトでオンになります。

   > ✏️ 親と子のフィールドが作成されますが、非表示になります。これらのフィールドを表示するには、テーブルヘッダーの「フィールドを非表示」メニューに移動します。

   > ✏️ 階層構造をオフにするには、テーブルヘッダーの表示設定に移動します。
3. 親と子フィールドを通じて階層を管理できます。
4. 階層構造がオンの場合、ドラッグ＆ドロップでも階層を作成できます。

:::warning
*親レコードを削除すると、そのレコードの子レコードもすべて削除されます。必要に応じて元に戻す機能を使用してこれを取り消すことができます。*
:::

親フィールドと子フィールドが非表示でない場合、サイドパネルに表示されます。タイムライン ビューに切り替えて、ポートフォリオが時間とともにどのように展開するかを見ることができます。

:::warning
***現在の制限事項（ベータ版）：***

- *階層構造の最大は 4 階層までです。*
- *階層構造は、Jira と同期されたレコードや他のサードパーティーのインテグレーションではまだ対応していません。*
- *同期されたカードには、階層構造のビジュアル指標はまだ表示されていません。*
:::

## フォーカスモード

フォーカス（全画面）モードでテーブルを編集および閲覧できます。ウィジェットの上部にある**斜め矢印アイコン**をクリックするだけです。絞り込み、並べ替え、グループ化、フィールドの非表示などの設定は右上に表示されます。

キャンバスに戻るには、上部の**キャンバスに移動**をクリックします。

## 構造化データウィジェットの制限

各 Miro ボードに追加できる構造化データウィジェットには最大 250 件の制限があり、テーブル、タイムライン、同期カードなどの合計がカウントされます。各テーブルには 1,000 行と 50 列の制限があります。行の制限に達した場合、追加行を追加できない旨のメッセージが表示されます。

最適なパフォーマンスを得るために、列が多い場合はテーブルを 200 行未満に抑えることをお勧めします。これは、グループ化、並べ替え、絞り込みといった操作がこのポイントを超えると遅くなる可能性があるためです。この制限により、Miro ボードの性能と信頼性を最適化しています。

### データウィジェットの上限に達するとどうなりますか？

ボードが 250 件の構造化データウィジェットの制限に達した場合、または制限を超えた場合、以下の現象が発生する可能性があります：

- 構造化データウィジェットをさらに追加しようとすると、エラーメッセージが表示される。
- 既存のデータウィジェットの読み込みに一貫性がなくなる。
- 変更の保存に関する問題が発生する。
- パフォーマンスの低下。

### データウィジェットの制限を管理するためのヒント

構造化データウィジェットの制限に近づいている、または制限を超えている場合は、次を試してください：

**複数のボードにウィジェットを分散:**

- 関連するコンテンツをそれぞれのボードにまとめてください。
- 分かりやすくするため、ボード名を工夫してください。
- すべての関連ボードへのリンクを貼った「マスター」ボードを作成します。

**類似データを統合:**

- 類似した構造を持つテーブルを統合します。
- 表示ごとに別々のテーブルを作成する代わりに、絞り込み機能を使用します。
