Miro スライドは、Miro 上で直接インタラクティブで魅力的なプレゼンテーション資料を作成できるようにします。Miro スライドを使用して、リアルタイムで共同創作、注釈付け、ブレインストーミングを行いながらスライド資料を発表できます。

![](../../../../../../docs/using-miro/formats/images/31678656996498_image.png)

*Miro スライドは、構造化されたスライド資料で共同創作と参加を可能にします。*

## 機能の説明

インタラクティブなキャンバスと構造化されたスライド資料を組み合わせた Miro スライドは、チームの効果的な共有とプレゼンテーションをサポートします。

Miro スライドは、ダイナミックでインタラクティブなスライド資料が求められるチームミーティングやワークショップに最適です。

### 簡単なスライド管理とプレゼンテーション

スライドにはテキスト、付箋、ビデオなど、さまざまなタイプのコンテンツを含めることができます。ダイアグラムやテーブルなどのフォーマットを追加することもできます。スライドには Miro ボードからコンテンツをドラッグ＆ドロップできます。全体のスライド資料にスタイルを適用し、ボードでスライドをドラッグしてプレゼンテーションを並べ替えることができます。

また、ボード上の既存のフレームを選択して他のコンテンツをスライドに変換することもできます。

Miro スライドには、一度に一つのスライドを作成・編集するための**フォーカスモード**が含まれています。プレゼンター向けのメモを追加したり、スライドを**フォーカスモード**でインポート及び並べ替えたりすることができます。

![slides-update-2.png](../../../../../../docs/using-miro/formats/images/27821820418578_slides-update-2.png)

*フォーカスモードで**スライド**を整理し、発表者ノートを追加します。*

フォーカスモードでプレゼンテーションを開始できます。**プレゼント**を選択すると、現在のスライドまたはボードからプレゼンテーションが開始されます。

:::note
Miro モバイルアプリでは、スライドにフォーカスモードは利用できません。
:::

## Miro スライドを活用

このセクションでは、Miro スライドの作成、管理、およびプレゼンテーションの方法について説明します。

### Miro スライドを作成する

スライドを作成するには、以下のいずれかを行ってください：

- Miro ボードで、作成バーから (**+**) を選択し、**ツール、メディア、インテグレーション** > **スライド** を選択します。
- Miro ボードで、フレームまたは複数のフレームを選択します。コンテキストメニューから **スライドに変換** を選択します。
- スペースのサイドバーから (**+**) を選択し、**新規作成** > **スライド** を選択します。
- Miro ダッシュボードから **+ 新規作成** > **スライド** を選択します。

プレゼンテーションにスライドを追加するには、任意のスライドの隣のプラスボタン (**+**) を選択します。また、ボード上の任意の場所からフレームをドラッグしてスライド資料に追加することもできます。

:::tip
スライドのコンテキストメニューからもスライドを追加できます。三点リーダーを選択し、**新しいフレームを追加**を選択します。コンテキストメニューの詳細については、スライドの管理方法をご覧ください。
:::

### スライド資料を共有する（ベータ版）

スライド資料のユニークリンクをコピーして、Miro アカウントを持たないメンバーや外部のステークホルダーと共有できます。

1. スライドのコンテキストメニューから、縦の三点リーダーをクリックして**詳細**メニューを開きます。
2. **共有およびエクスポート** > **プレゼンテーション共有**をクリックします。
   **プレゼンテーション共有**のモーダルが開きます。
3. **リンクをコピー**をクリックします。
4. （任意）**ブラウザでプレビュー**をクリックして、リンクを持つ誰かがスライド資料をどのように閲覧するかを確認します。
5. リンクを共有します。

> **注意：**外部ユーザーがアクセスできるようにするには、ボードを公開にしておく必要があります。外部ユーザーはプレゼンテーションモードでスライド資料を閲覧することしかできず、キャンバス上の他のコンテンツにはアクセスできません。ボードの権限が許可されている場合、外部ユーザーはコメントを追加することもできます。

> **ヒント：**フォーカスモードで、共有可能なリンクをコピーすることもできます。右上にある縦の三点リーダーをクリックして、**その他**メニューを開きます。その後、**プレゼンテーションを共有**をクリックします。

### PDFファイルをMiro スライドにインポート

他のツールからMiro スライドにプレゼンテーション資料をインポートします。

他のツールからスライド資料をPDFファイルとしてエクスポートしてください。

キャンバスから以下の手順に従ってください：

1. PDFをMiroスライドにインポートするためには、次のいずれかの方法を行います:
   - **ドラッグ&ドロップ**
     PDFファイルをMiroボード上にドラッグします。
   - **アップロード**
     作成バーで**ツール、メディア、インテグレーション**を選択します。その後、**アップロード**ツールを検索して選択します。**自分のデバイス**を選び、PDFファイルを選択してアップロードを完了させます。
2. ボード上でPDFを選択します。
3. コンテキストメニューから**スライドに変換**を選択します。

:::tip
フォーカスモードにおいてもインポートが可能です。スライドを作成し、コンテキストメニューからフォーカスモードを開きます。右上の**インポート** ボタンをクリックしてください。
:::

### Miro スライドをPDFにエクスポート

Miro スライドをPDFにエクスポートするには、プレゼンテーションを選択し、コンテキストメニューにアクセスします。縦の三点リーダーを選択し、**共有とエクスポート** > **PDFとしてエクスポート**を選びます。

エクスポートのファイル品質を選び、**エクスポート**を選択してください。

:::tip
フォーカスモードにおいてもエクスポートが可能です。右上の**三点リーダー** (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg)) アイコンをクリックし、**PDFとしてエクスポート**を選んでください。
:::

### スライドの画像としてエクスポート

Miro スライド資料から特定のスライドをJPG、PDF、またはSVG形式でエクスポートできます。たとえば、スライドを他の文書に埋め込みたい場合に使用します。

スライドを画像としてエクスポートするには、次の手順に従ってください：

1. スライド資料からスライドを選択します。
   スライドのコンテキストメニューが表示されます。
2. コンテキストメニューで、縦に並んだ三点リーダーをクリックして、**その他**メニューを開きます。
3. **共有およびエクスポート** > **画像としてエクスポート**をクリックします。
   **画像としてエクスポート**モーダルが開き、選択ウィンドウにスライドが表示されます。
4. **画像としてエクスポート**モーダルで、JPG、PDF、またはSVGとしてエクスポートするかを選択します。
   JPGの場合、解像度を**小**（デフォルト）、**中**、または**大**から任意で指定できます。
5. **エクスポート**をクリックします。

### PowerPoint ファイルを Miro スライドにインポートする

PowerPoint (.PPTX) ファイルをインポートして、完全に編集可能な Miro スライドに変換できます。変換可能なファイルサイズの最大は 50MB です。

以下の手順を実施してください。

1. 作成バーで、(**+**) **ツール、メディア、インテグレーション**をクリックします。
2. **アップロード**をクリックします。
   検索するか、メニューで**メディア** > **アップロード**にスクロールしてアクセスできます。
   アップロードメニューが開きます。
3. **マイデバイス**をクリックします。
   コンピュータのファイルマネージャが開きます。
4. PowerPoint (.PPTX) ファイルを選択します。
5. **開く**をクリックします。
   **インポートオプション**のダイアログが開きます。
6. **スライドに変換**をクリックします。
   Miro ボードに PowerPoint ファイルが読み込まれます。ファイルの読み込み時間は、ファイルのサイズや画像のサイズによって異なります。

:::tip
また、ファイルマネージャーからブラウザ上の Miro ボードに PowerPoint (.PPTX) ファイルをドラッグ＆ドロップすることもできます。**インポートオプション**のダイアログが開きます。**スライドに変換**を選択します。
:::

:::note
**インポートオプション**から**ファイルとして追加**をクリックすると、プレゼンテーションは閲覧のみの参照として読み込まれます。ファイルとして追加する場合の最大ファイルサイズは 30MB です。
:::

### スライドを管理する

Miro スライドには、プレゼンテーションを管理するためのコンテキストメニューが含まれています。プレゼンテーションの開始、スタイルの適用、スライド資料を PDF にエクスポートすることができます。

スライドのコンテキストメニューには、次のオプションが含まれています。

- **プレゼンテーションを開始**
  全画面プレゼンテーションモードを開き、整理された作成バーが表示されます。また、スライドナビゲーション、リアクションツール、設定を含むツールバーが利用可能です。プレゼンテーションを終了したり共有したりできます。

  > 💡 Miro モバイルアプリ内でもプレゼンテーションを共有することができます。スライドフレームを選択し、ツールバーの再生ボタンをクリックしてください。
- **フォーカスモード**
  スライド編集用の専用ビューが開きます。スライドの追加や配置変更が可能です。**フォーカスモード**を終了するには、**キャンバスに移動**を選択してください。
- **正確なサイズ変更**
  フォーカスモードで作業中に、スライド内のウィジェットをピクセル寸法で正確にサイズ変更できます。**詳細情報:** [正確なサイズ変更](../essential-tools/01-precise-resizing.md)をご覧ください。
- **マルチレーンプレゼンテーション**
  スライドを同じプレゼンテーション内で複数のレーンに配置し、個々のスライドを簡単に整理し再配置できます。新しいレーンを追加するには、既存のレーンの下にカーソルを合わせてプラスアイコンをクリックするか、スライドをドラッグアンドドロップします。
  ![Slides-multi-lane.gif](../../../../../../docs/using-miro/formats/images/26764078989970_Slides-multi-lane.gif)*スライドのマルチレーン例*
- **詳細**
  スタイル、PDF としてエクスポート、複製、リンクなどを含む垂直三点リーダーメニューです。

:::tip
スライドのリンクをボード上または直接**フォーカスモード**にコピーして共有できます。**詳細**メニューから、**リンクをコピー**または**フォーカスモードリンクをコピー**を選択します。
:::
