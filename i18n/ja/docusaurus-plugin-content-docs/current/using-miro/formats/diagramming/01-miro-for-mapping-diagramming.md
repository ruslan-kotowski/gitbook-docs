> **対象ユーザー:** すべてのユーザー
> **利用可能なプラン:** すべてのプラン* (Free、Starter、Business、Enterprise、Education)
> **利用可能なプラットフォーム:** ブラウザー、デスクトップ、タブレット（スマート描画）
>
> * 特定の図形パック（BPMN、AWS、電子工学）やカスタム図形および高度なダイアグラム作成フォーマットなどの機能は、Business、Enterprise、Educationプランでのみ利用可能です。

Miro は、マッピングやダイアグラムを作成するすべての段階に対して包括的なツール群を提供するオールインワン・ソリューションです。直感的なツールやフレームワークを使用してゼロからダイアグラムを作成したり、Miro の広範なライブラリから既成のテンプレートを活用することができます。Miro のコラボレーション機能を利用すれば、ボード上でチームメンバーとリアルタイムに共有し、ディスカッションや修正を容易に行うことができます。ダイアグラムが完成したら、簡単にエクスポートしてプレゼンテーションに使用できます。

:::tip
[Miro アカデミーのテクニカルダイアグラミング講座](https://academy.miro.com/technical-diagramming-in-miro)を受講して、ダイアグラム作成スキルを向上させましょう。
:::

## Miro で初めての図表を作成する

Miro は、マッピングやダイアグラミングのニーズに合わせたさまざまなツールとスマートなダイアグラム作成機能を提供しています。このセクションでは、利用可能な機能についてご案内し、開始する際の手助けをいたします。

まず、ツールバーの**図形ツール**を選択し、**すべての図形**をクリックして図形ライブラリーにアクセスします。この操作で、ボードの左側に**ダイアグラム作成**パネルが表示されます。

![miro_mapping_diagramming_shapes_panel.jpg](https://help.miro.com/hc/article_attachments/21016057762322)
*ボードの左側にあるダイアグラム作成図形パネル*

パネルで目的の図形をクリックするか、ドラッグアンドドロップしてボードに追加します。

新しい図形パックを追加して図形ライブラリーをカスタマイズできます。

1. ダイアグラミングパネルで**図形を管理**をクリックします。
2. 利用可能な図形パックのリストが表示されます。追加したい図形パックの横にあるボックスにチェックを入れます。基本図形、フローチャート、コネクタは、誰でも利用できます。他の専門的な図形パック、例えばBPMN、データフロー、AWS、Azure、Ciscoなどは、Business、Enterprise、Educationプランで利用可能です（図形パックのセクションをご覧ください）。
3. ダイアグラミングパネルを下にスクロールして、新たに追加された図形を確認して使用します。

パネルで図形にカーソルを合わせると、たとえばフローチャート図形の*事前定義されたプロセス*のように、その名前や目的が表示されます。

![manage_shapes.gif](https://help.miro.com/hc/article_attachments/21016044389394)
*ダイアグラム作成パネルに新しい図形パックを追加*

### 利用可能な図形パック

Miro は、さまざまな図作成のニーズをサポートする幅広い図形パックを提供しています。これらはプランごとに整理されています。

| **すべてのプランで利用可能** | **Business、Enterprise、Education プランで利用可能** |
| --- | --- |
| - 基本図形 - コールアウト - コネクター - フローチャート | - AWS - Azure - BPMN - Cisco - Cloudflare - DFD（データフロー図） - 電気工学 - ER 図（実体関連図） - Google クラウド - Kubernetes - プロセスエンジニアリング - Salesforce - UML - バリューストリーム マップ（VSM） - VMware |

#### カスタム図形を使用する

> **対象プラン**: Business、Enterprise、Education

組み込みの図形パックに加えて、[カスタム図形](../../../product-announcements/diagramming/04-upload-your-own-custom-shapes-for-diagramming-(beta).md)を作成、保存、再利用することができます。この機能により、プロジェクトの特定のニーズやブランド要件に合わせてビジュアルライブラリをカスタマイズできます。

### 高度なダイアグラム作成にMiro ダイアグラムを活用

Miroのスマートなダイアグラム作成機能は、基本的な図形描画を超えて、構造化されたプロフェッショナルなダイアグラムをより効率的に作成するための強力なツールを提供します。

[Miro ダイアグラム](02-miro-diagrams.md)は、ダイアグラム作成の体験を向上させる専用の環境と機能を提供し、次のことが可能になります：

- **フォーカスモード**で作業することで、ダイアグラム作業に特化した邪魔のないワークスペースを提供します。
- **Miro AI**を利用して、短いテキスト説明から自動的にダイアグラムを生成します。
- **レイヤー**を使用して、トピックやチームごとに特定のコンテンツを表示または非表示にし、複雑なダイアグラムを整理します。
- ボード上の既存の図形をワンクリックで接続されたダイアグラムに変換します。
- **スナップ グリッド** や **自動オブジェクト寸法** などの機能を使って、一貫した構造と整列を維持します。

図形を手動で追加するか、Miro AI のアシストを受けて初期作成を行うかを選択でき、ダイアグラムが整然とし、組織化され、管理しやすい状態を常に保つことができます。

### スタイリングを一貫性に保つためにダイアグラムテーマを適用する

視覚的に魅力的で一貫性のあるダイアグラムを作成するために、いくつかの事前定義されたダイアグラムテーマから選択できます。

ダイアグラミングパネル内で「**図形** ＞ **すべての図形**」にあるダイアグラムのテーマを見つけることができます。テーマは図形パックのちょうど上にあります。ダイアグラミングプロセスの最初にテーマを選択することで、後の手動スタイリングにかかる時間を大幅に節約できます。

:::tip
完全なブランドの見た目を実現するには、組織の[ブランドスタイル](../../../administration/get-started-as-a-miro-admin/04-brand-center.md)を使用してダイアグラムを作成することが可能です（該当するプランで利用可能）。これにより、プロフェショナルな外観のプレゼンテーションやボードを作成できます。
:::

:::note
現在、ダイアグラムのテーマで利用できるのは基本図形とフローチャート図形です。
:::

![Diagram-themes.png](https://help.miro.com/hc/article_attachments/21016044415378)
*ダイアグラミングパネルからダイアグラムテーマを選択する*

### スイムレーンを使ってダイアグラムを整理する

スイムレーンはダイアグラムを論理的なエリアに分けるのに役立ち、複雑な情報の視覚化や、明瞭性と責任の明確化のために重要です。フローチャート、BPMN ダイアグラム、UML ダイアグラムでよく使用され、異なるレーン（役割、部門、フェーズを表す）間の相互依存性、接続、引き継ぎを示します。スイムレーンを追加することで、プロセスの効率が向上し、無駄や非効率を特定するのに役立ちます。

スイムレーンは、フローチャート、BPMN、UML の図形パックに含まれています。スイムレーンを追加するには次の手順を実行します。

1. メニューから**図形** > **すべての図形**を選択して、ダイアグラミング パネルを開きます。
2. フローチャート、BPMN、または UML の図形パックが有効になっていることを確認します。
3. 各図形パック内で、スイムレーン オブジェクト（縦、横、または複数レーンをグループ化するためのプール）を見つけます。
4. スイムレーン オブジェクトをドラッグアンドドロップでボードに配置して開始します。

ボード上のスイムレーンにカーソルを合わせると、制御ポイントが表示されます。これらを使用して、レーンを追加したり、サイズを変更したり、移動したりできます。

:::warning
スイムレーン内のコンテンツは現在、[ロック](../../working-on-the-board/17-locking-content-on-the-board.md)したり、標準の整列ツールで複数のオブジェクトを[揃えたり](../../working-on-the-board/08-structuring-board-content.md)することはできません。しかし、スイムレーン内でオブジェクトを[グループ化](../../working-on-the-board/08-structuring-board-content.md)することができ、特にBPMNや他のプロセス図に役立ちます。
:::

![Swimlanes.gif](https://help.miro.com/hc/article_attachments/21016057764114)
*Miro スイムレーンの使用*

### コールアウトを使って注釈を追加

コールアウトを使用して、ダイアグラムに注釈をつけ、主なビジュアルを煩雑にすることなく重要な情報を目立たせましょう。コールアウトを追加するには：

1. ダイアグラミングパネルを開き、**図形** > **すべての図形**を選択します。
2. **コールアウト**図形パックが有効になっていることを確認します。
3. コールアウト図形をボードにドラッグアンドドロップします。

![add_callouts.gif](https://help.miro.com/hc/article_attachments/21016044402322)
*図に呼び出しを追加する*

呼び出しは3種類の形状（標準呼び出し、吹き出し、ブラケット）で利用可能です。呼び出しのテールをボード上のオブジェクトに接続することができます。これにより、オブジェクトまたは呼び出しを移動しても、テールは接続されたままです。

![callouts.gif](https://help.miro.com/hc/article_attachments/21016057777938)
*図形に接続された異なる種類の呼び出し*

### 実体関連図（ERD）を作成

> **利用可能**: Business、Enterprise、Education の各プランで利用可能

Miro のエンティティリレーションシップモデリングツールを使用すると、エンティティ、属性、リレーションという 3 つの基本概念を用いて高レベルなデータモデルを視覚化できます。これは特にデータベース設計やシステムアーキテクチャに有用です。

ERD の作成時の主な機能には次のものがあります:

- エンティティ内の属性に交互の色を適用して読みやすくする。
- エンティティは、異なる情報タイプを表現するためにシングル、ダブル、トリプルの列で設定できます。
- エンティティに属性（行）を簡単に追加するには、エンティティの上下に表示される**＋**記号またはフローティングパネルを使用します。
  ![エンティティ関係のダイアグラム.gif](https://help.miro.com/hc/article_attachments/21016057781906)
  *ERDでエンティティを追加および変更*
- エンティティ（図形）や特定の属性（図形内の行）に接続基数（エンティティ間の数的関係を表す）を接続します。
- ERD エンティティを操作する際、接続線は自動的にカーディナリティの表記を使用します。
  ![connect_entities.gif](https://help.miro.com/hc/article_attachments/21016044406418)
  *カーディナリティ表記でエンティティを接続する*

### クイックダイアグラム作成ツールを使用する

Miro は、図形をより効率的に作成、変換、接続するためのいくつかのツールを提供しており、ダイアグラム作成プロセスを加速します。

:::note
基本図形はすべてのユーザーが利用できます。専用のダイアグラミング図形パックは、Business、Enterprise、Education プランで利用可能です。
:::

**図形を迅速に作成して接続:**

1. 左側のツールバーから図形アイコンを選択します。
2. 任意の図形を選択し、クリックまたはドラッグしてボードに追加します。
3. 既存の図形を複製するには、それを選択して**Enter**キーを押します。
4. 別の方法としては、選択した図形の側に現れる青い点にカーソルを合わせると、新しい図形や接続ラインをすばやく作成できる場所が表示されます。ドットをクリックして、提案されたラインや新しい図形を追加します。
5. 自動的に提案されていない既存のオブジェクトに図形を接続したい場合は、青いドットをクリックしてドラッグし、通常通りターゲットオブジェクトに接続ラインを描画します。

![diagramming-new.gif](https://help.miro.com/hc/article_attachments/21174929928082)
*Miro でのワンクリック図形作成と接続*

**2つの接続された図形の間に図形を挿入する：**

既存のフローにステップや情報を追加する必要がある場合、接続ライン上に図形を簡単に挿入できます。

1. 2つの図形間の接続ラインをクリックします。
2. 表示されるオブジェクトツールバーから**図形を挿入**アイコン（小さな図形にプラス記号が付いたもの）をクリックします。
3. ドロップダウンから挿入したいオブジェクトのタイプを選択します。

挿入図形のオプションを利用するためには、接続されている 2 つのオブジェクト間の接続線に十分なスペースがあることが必要です。

![inserting_a_shape.gif](https://help.miro.com/hc/article_attachments/21016057783570)
*2 つの接続された図形の間にオブジェクトを挿入*

**オブジェクトタイプの簡単な切り替え:**

ボード上のオブジェクトのタイプを**タイプの切り替え**機能を使って即座に変更できます。これにより、1 つのオブジェクト（例：[付箋](../../essential-tools/14-sticky-notes.md)、[テキストボックス](../../essential-tools/16-text.md)、または別のオブジェクトタイプに変換し、可能な限りその内容と接続を保持したまま変換できます。[カード](../../essential-tools/02-cards.md)) から、ダイアグラム作成の図形パックの[図形](../../essential-tools/11-shapes.md)などの他のタイプのオブジェクトに変換し、可能な限りその内容と接続を保持します。

1. ボード上で変換したいオブジェクトをクリックします。
2. オブジェクトのコンテキストメニューの**種別の切り替え**アイコンをクリックします。
3. ドロップダウンメニューから新しいオブジェクトタイプを選択または検索します。

スイッチタイプ機能はベーシックな図形や図形パックの図形に利用可能です。
![Search_and_transform_object_type.gif](https://help.miro.com/hc/article_attachments/21016057782674)
*スイッチタイプメニューを使ってオブジェクトを他のタイプに変換する様子*

### オブジェクト寸法で正確さを追求

オブジェクト寸法により、ボード全体で一貫して同じサイズのオブジェクトを作成することで、プロフェッショナルなダイアグラムをより迅速かつ正確に作成できます。

この機能は、線を除くすべてのMiroオブジェクトで利用できます。

**オブジェクトの寸法を有効化する方法：**

1. ボードの左上にある三点リーダーメニュー (![icon-main.svg](https://help.miro.com/hc/article_attachments/27493491177618)) をクリックします。
2. **表示** > **オブジェクトの寸法** に移動します。
3. **オブジェクトの寸法** をトグルします。

**オブジェクトの寸法を使用する方法：**

一度有効にすると、新しいオブジェクトを作成したり、既存のオブジェクトのサイズを変更すると、オブジェクトの幅と高さがピクセル単位で表示されている青い長方形が見られます。また、オブジェクトのサイズが一致する際には、現在のオブジェクトを他のオブジェクトと整列させるための青いガイドラインが表示されます。

![Using_dimensions_in_Miro.gif](https://help.miro.com/hc/article_attachments/21016044407698)
*オブジェクトのサイズ変更と整列のための寸法の使用*

### 背景グリッドの表示をカスタマイズする

ボード上のグリッド表示を変更し、コンテンツをより正確に作成および整列させることができます。

1. ボードの左上にある三点リーダーメニュー（![icon-main.svg](https://help.miro.com/hc/article_attachments/27493491177618)）をクリックします。
2. **閲覧** > **グリッド** に移動します。
3. 次の 3 つのオプションから選択することができます：**なし**（グリッドなし）、**線グリッド**、または **点グリッド**。

![mind-mapping-entry-point.png](https://help.miro.com/hc/article_attachments/21830861273106)
*ボードの設定で背景グリッド表示を選択*

**線グリッド** は小さな四角形でのナビゲーションと位置合わせを容易にします。線グリッドと点グリッドの両方で、オブジェクトをグリッドにスナップさせることができます。

### グリッドにスナップを使用する

グリッドビュー（ラインまたはドット）が有効の場合、グリッドにスナップを有効にすることができます。そのためには、次の手順に従ってください。

1. キャンバスの空白部分を右クリックします。
2. コンテキストメニューで**グリッドにスナップ**オプションをトグルします。

![snap-to-grid-canvas.png](https://help.miro.com/hc/article_attachments/21174929932306)
*キャンバスコンテキストメニューからグリッドにスナップをトグルする*

グリッドにスナップがアクティブなとき、ボード上に追加または移動したオブジェクトは自動的に最寄りのグリッド線またはドットにスナップし、正確に配置するのを助けます。

![snap_to_grid.gif](https://help.miro.com/hc/article_attachments/21016057766418)
*オブジェクトがグリッド線にスナップする*

オブジェクトをドラッグ中にスナップを一時的に無効化するには、**Cmd**（macOSの場合）または**Ctrl**（Windowsの場合）を押し続けてください。

### スマートガイドを使用して整列

スマートガイドは、ボード上の他のオブジェクトと整列させ、均等な間隔を保つのに役立ちます。

1. 左上の三点メニュー（![icon-main.svg](https://help.miro.com/hc/article_attachments/27493491177618)）をクリックします。
2. **設定**を選択します。
3. **オブジェクトを整列**がオンになっていることを確認します。

![mind-mapping-align-objects.png](https://help.miro.com/hc/article_attachments/21830861276946)
*「環境設定」でスマートガイド（オブジェクト整列）を有効にする*

ボード上にオブジェクトを配置または移動すると、青いスマートガイドラインが表示され、他のオブジェクトとの整列（垂直または水平）や等間隔の提案がされます。

![snapping_objects.gif](https://help.miro.com/hc/article_attachments/21016044391570)
*スマートガイドの整列と間隔の提案*

### ダイアグラム要素をカスタマイズする

図形の外観をカスタマイズするための幅広いオプションがあります。図形の塗りの色、枠の色、不透明度、テキストのフォーマットを変更できます。接続線については、種類（直線、エルボー、曲線など）、色、太さの設定を行い、テキストラベルを追加することができます。

:::tip
AWS 図形パック内の AWS アイコンの色も変更できます。このオプションは 2025 年以前のアイコンには使用できません。
:::

また、[カード](../../essential-tools/02-cards.md)や[付箋](../../essential-tools/14-sticky-notes.md)を図形に取り込むことも忘れないでください。これらのオブジェクトを図形に（そしてその逆も）容易に[変換する](../../working-on-the-board/20-switch-type.md)ことで、スタイルと内容を保持することが多いです。

## コネクタラインでの最短経路

コネクターラインがオブジェクト間で常に最短経路を見つけるようにするには、コネクターラインをオブジェクトの本体までドラッグし、青い枠が表示されたら、コネクターを確定します。

青い枠は、中心から中心への接続を示します。中心から中心への接続は、接続されたオブジェクト間で最短経路を見つけます。たとえば、接続されたオブジェクトをキャンバス上のほかの位置に移動するときです。

> **注意：** コネクターラインを確定しないと、青い枠は数秒後に消えます。青い枠を更新するには、ラインを引き戻してオブジェクト本体に再度ドラッグします。

![](https://help.miro.com/hc/article_attachments/34703362094098) *接続されたオブジェクト間で常に最短経路を見つけるために、中心から中心への接続を行います。*

オブジェクトの端にある接続線はアンカー接続を作成します。アンカー接続は、接続されたオブジェクトを移動しても、最短経路には調整されません。

## マッピングとダイアグラム作成のためのキーボード操作

Miro には、ボード上のウィジェットやダイアグラムを操作するための包括的なキーボードコマンドが提供されています。効率的なナビゲーションは、多くの要素とコネクタがある複雑なダイアグラムでは特に重要です。

### キーボードナビゲーションコマンド

#### リニアナビゲーション（連続）

**Tab** キーを押して次の要素に移動するか、**Shift + Tab** キーで前の要素に順次移動します。

#### 空間ナビゲーション（方向性）

**Cmd + 矢印キー**（macOS）または**Ctrl + 矢印キー**（Windows）を使用して、現在選択されているオブジェクトに対して上下左右の空間配置に基づいて要素にフォーカスを移動します。

### コネクターリストを使った複雑なダイアグラムの操作

多くのダイアグラムは複雑なコネクターのネットワークで構成されています。キーボード操作や支援技術に頼っているユーザーのために、Miro は選択したオブジェクトにリンクされたすべてのコネクターを整理したリストを提供します。

#### 選択したオブジェクトのコネクターリストにアクセス

- **macOS での操作:** **Cmd + .**（Command キーとピリオド キー）を押します。
- **Windows での操作:** **Ctrl + .**（Control キーとピリオド キー）を押します。

このショートカットは、現在選択されているオブジェクトに関連するコネクタのカテゴリー別リストを表示します。分類は以下の通りです:

- **受信:** 選択されたオブジェクトに向かって矢印があるコネクタ。
- **送信:** 選択されたオブジェクトから外側に向かって矢印があるコネクタ。
- **円形:** オブジェクト自身に接続するコネクタ。
- コネクタに矢印が2つある場合、受信と送信の両方のグループに表示されます。

#### コネクタリスト内を移動

- **Tabキー**を押して、リスト内でインカミング、アウトゴーイング、円状グループ間のフォーカスを切り替えます。
- **上矢印キー**と**下矢印キー**を使って、現在選択されているグループ内のコネクタを移動します。
- **Enterキー**を押して、リストからボード上の実際の選択されたコネクタにキーボードフォーカスを移します。
