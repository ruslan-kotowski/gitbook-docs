ビジュアルナンバーを使用すると、ユーザーは数値を視覚的な進捗バーに変換できます。ユーザーは、カスタムカラーで条件付き書式ルールを設定し、データの視覚化を向上させるために最小/最大範囲を設定できます。ビジュアルナンバーは、パーセンテージや通貨形式での表示も可能です。

## 数値を視覚的にフォーマットする

ビジュアルナンバーのフォーマットは数値データを進捗バーに変換し、トレンドを簡単に把握し、進捗を一目で確認できるようにします。数値をパーセンテージや通貨で表示したり、カスタム範囲を設定したり、条件付き書式ルールを適用することができます。

数値フィールドにビジュアルフォーマットを適用するには:

1. 数値あるいは数式フィールド名にカーソルを合わせると、**三点リーダー**（**...**）アイコンが表示されます。
2. **三点リーダー**（**...**）アイコンをクリックし、**フィールドを編集**を選択します。
3. ダイアログの**表示**セクションで**バー**をクリックします。
   数値がプログレスバーとして表示されます。
4. フォーマットを選択します:
   1. パーセンテージ（%）：完了率や進捗を追跡するのに最適です。
   2. 通貨：主要な通貨（$、€、£、¥ など）から選択できます。
5. **最小値**と**最大値**を設定します。パーセンテージの場合は通常 0-100 を使用します。通貨の場合は適切な最小値/最大値を設定してください。
6. カラーピッカーからバーの色を選択します。
7. 数値ラベルをオン/オフ切り替え:
   1. オン: 進捗バーに数値を表示します。
   2. オフ: 進捗バーのみを表示し、よりクリーンなビューにします。
8. **保存**をクリックします。

## 条件付き書式を適用

条件付き書式を使用すると、定義したルールに基づいてプログレスバーの色が自動的に変わり、注意が必要な値を迅速に特定するのに役立ちます。

1. **フィールド設定**を開きます。（数値フィールドまたは数式フィールド）
2. **条件付きカラー**をオンにします。
3. **ルール追加**をクリックします。
4. ルールを定義します:
   1. 条件を選択します（等しい、等しくない、大きい、小さい、以上、以下、空、空ではない）。
   2. 比較対象となる値を入力します（該当する場合）。
   3. このルールに一致する値の色を選択します。
5. 必要に応じて複数のルールを追加します。ルールをドラッグして優先順位を設定します。上にあるルールから優先されます。
6. **保存**をクリックします。

条件付き書式はテーブルビューと個別レコードを閲覧する際のサイドパネルの両方で表示されます。

視覚的な数字のフォーマットは現在、テーブルビューとサイドパネルでのみ利用可能です。

タイムライン、カンバン、カードビューでは標準の数値フォーマットが表示されます。
