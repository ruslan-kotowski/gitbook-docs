フォーマットとフォーカスモードを使えば、チームは自由形式のブレインストーミングと構造化された文書、テーブル、タイムライン、ダイアグラム、スライドの間をシームレスに切り替えることができます。空白のキャンバスや構造化されたフォーマットから始め、フォーカスモードを利用して気を散らすものを最小限に抑え、作業に集中しましょう。フォーマットをデフォルトの閲覧に設定することで、ボードを開いた際に全員が望む場所に到達することが保証されます。

各フォーマットの詳細については、こちらをご覧ください：

## **フォーマットへのアクセス**

キャンバスに新しいフォーマットを追加するには：

1. ツールバーで**ツール、メディアおよびインテグレーション** (![icon-tools.svg](../../../../../../docs/using-miro/formats/images/29210901366418_icon-tools.svg) **アイコン**)をクリックします。
2. 必要なフォーマットを選択します：**文書**、**テーブル**、**タイムライン**、**ダイアグラム**、**プロトタイプ**、または**スライド**。
3. 選択したフォーマットをキャンバスに追加するには、キャンバスの任意の場所をクリックします。

## **フォーカスモード**

作業中のフォーマットに集中したいときに他のボード上のコンテンツを除外して**フォーカスモード**（全画面）で開くことができます。フォーカスモードにアクセスするには：

1. フォーカスモードに入りたいフォーマットをクリックします。
2. コンテキストメニューの**フォーカスモード**アイコンをクリックします。
3. フォーカスモードを終了するには、画面上部の**キャンバスに戻る**ボタンをクリックします。

## **フォーマットをデフォルト表示に設定する**

任意のフォーマットをボードのデフォルト表示に設定できます。つまり、ボードを開いたときに最初に文書、テーブル、タイムライン、ダイアグラム、またはスライドが表示されます。

フォーマットをデフォルト表示に設定するには:

1. フォーカスモードに入りたいフォーマットの任意の場所をクリックします。
2. **三点リーダー** (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg)) アイコンをクリックします。
3. **デフォルト画面として設定** を選択します。
4. モーダルで、**デフォルトを設定** をクリックします。

### デフォルト画面をロックする

ボードの所有者はデフォルト画面をロックでき、閲覧者が他の部分にアクセスできないようにすることができます。有効にするには以下を実行してください。

1. フォーカスモードに入りたいフォーマットをクリックします。
2. **三点リーダー** (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg)) アイコンをクリックします。
3. **デフォルト表示に設定**を選択します。
4. 表示されたモーダルで、トグルをクリックして**デフォルト表示をロック**します。
5. **デフォルトに設定**をクリックします。

## **フォーカスモードへのリンクを共有する**

キャンバスに集中したい場合は、フォーマットのフォーカスモードへのリンクだけを共有することができます。

1. フォーカスモードに入るには、フォーマット上のどこでもクリックします。
2. **三点リーダー** (![icon-main.svg](../../../../../../docs/using-miro/formats/images/22916604338834_icon-main.svg)) アイコンをクリックします。
3. **フォーカスモードリンクのコピー**を選択します。

## **ダッシュボードまたはスペースからフォーマットを作成する**

ダッシュボード、スペースの概要、またはスペースのサイドバーから直接任意のフォーマットを作成できます。これによりフォーマットはデフォルトの閲覧として自動的に設定され、ボードに参加するすべての人はフォーマットのフォーカスモードで開始します。

1. **ダッシュボード**または**スペース**の概要を開きます。
2. **新規作成**メニューをクリックします。
3. 作成したいフォーマットを選択します: **ドキュメント**、**ダイアグラム**、**プロトタイプ**、**タイムライン**、**テーブル**、または**スライド**。

## **スペースサイドバーからフォーマットを作成**

ボードで作業しているときに、**スペースサイドバー**から新しいフォーマットを作成できます。新しいフォーマットは同じスペースに作成されます。

1. Miro [ボードバー](../working-on-the-board/02-miro's-new-simplified-user-interface.md)で、**サイドバーを開く**ハンバーガーメニューを選択します。**スペース**サイドバーが開きます。
2. **新規作成**アイコンをクリックします。
3. 作成したいフォーマットを選択します：**ドキュメント**、**ダイアグラム**、**プロトタイプ**、**タイムライン**、**テーブル**、または**スライド**。

:::tip
フォーマットをスペースにピン留めできます。ピン留めしたフォーマットはスペースサイドバーに表示されます。
:::
