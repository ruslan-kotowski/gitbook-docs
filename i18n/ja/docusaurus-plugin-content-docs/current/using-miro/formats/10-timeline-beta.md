タイムラインは、関係者やチームを戦略的に調整するインタラクティブな計画ツールです。タイムラインを使用して、プロジェクトのロードマップを作成し、可視性を高め、より効率的にマイルストーンに到達します。Miro ボードから直接タイムラインを作成、管理、共有します。

タイムラインは、タスク、コールレコード、タイムバーとしてプロジェクトを可視化します。各レコードはタスクを表し、タイムバーはそのタスクを完了するのに予想される時間をはっきりと示します。タイムライン ウィジェットでは、複数のユーザーが同時にタイムラインを操作することもできます。

グループを作成してレコードを論理的に並べ、グループ間でレコードを移動させます。たとえば、プロジェクトをマイルストーンごとに並べ替えることができます。

タイムライン ウィジェットは、[Miro カード](../essential-tools/02-cards.md)とも連動します。

![](../../../../../../docs/using-miro/formats/images/19967187345042_29df001a-0a5b-4616-b2b6-a4128a91790f.png)

*タイムライン ウィジェットの動作*。

:::note
タイムラインはベータ版です。説明または表示されている一部の機能は、変更される場合があります。また、今年後半の GA のリリースまでは利用できない可能性があります。タイムラインは進化し続けるため、改めてこの記事の更新内容をご確認ください。
:::

## 主な機能

- Miro ボードのどこからでも**インタラクティブなタイムラインをカスタマイズ**します。
- タイムライン ウィジェット内に**レコードを追加して削除**します。
- タイムライン ウィジェットに **Miro カード、Jira カード、Azure カードをドラッグ＆ドロップ**します。*
- **レコードのグループを作成**し、情報を論理的に整理します。
- **各タイムバーのサイズを変更**して、個々のレコードの日付を変更します。
- 日付を調整すると、自動的に**タイムラインビューとタイムバーがスケール調整されます**。
- 同じ Miro ボードに、異なるデータソースを持つ**複数のタイムライン ウィジェットを含めます**。
- チームメンバーや関係者と**タイムラインを共有**します。

## タイムラインをボードに追加

1. Miro のボードを開く
2. [作成ツールバー](../../getting-started/start-here/your-first-board/05-toolbars.md)から[**その他のアプリ**（**+**）] を選択します。
3. [**タイムライン**] を検索して選択します。
   カーソルがタイムラインアイコンとして表示されるようになりました。
4. Miro ボードの任意の場所を選択し、タイムライン ウィジェットを配置します。

![](../../../../../../docs/using-miro/formats/images/19967187350162_674eabbc-5629-426a-aa7d-c6199cc9687a.png)

*タイムライン ウィジェットの配置*

*ベータ版では、Jira カードでのタイムライン ウィジェットの操作は制限されています。Azure カードでの操作は利用できません。

## タイムラインのインタラクション

タイムライン ウィジェットには、プランナーを管理するためのコントロールがいくつかあります。

### レコードを追加

レコード列の上にあるプラス記号（**+**）を選択します。タイムラインに新しいレコードが表示されます。

レコードの位置を変更するには、プランナーでレコードを上下にドラッグ＆ドロップします。対応するタイムバーをドラッグ＆ドロップすることもできます。

### レコードのテキストを編集

レコードまたはタイムバーを選択し、テキストを選択します。点滅中のカーソルは、テキストが編集可能な状態であることを示します。

### レコードを削除

1. 編集するレコードまたはタイムバーを選択します。
2. テキストを削除します。
   タイムラインの下部にダイアログが表示され、完全に削除されることを警告します。
3. レコードを削除するには、[**削除**] を選択します。

:::warning
ベータ版では、元に戻すことができません。
:::

### 開始日と終了日を変更

タイムライン ウィジェット内のカレンダーボタンを選択し、開始日と終了日を選択します。

プランナーは選択内容に合わせて自動的に拡大縮小します。

特定のレコードの開始日と終了日を変更するには、タイムバーのいずれかの端を選択してドラッグします。

![](../../../../../../docs/using-miro/formats/images/19967187352978_0c37764f-62f0-4a06-b031-e0b6229807be.png)

*タイムライン ウィジェットでの開始日と終了日の変更*

### レコードの色を変更

レコード列のカラーサークルを選択し、色を選択します。

レコードとタイムバーの色が選択内容に合わせて変更されます。

### レコードの配置変更

レコード列で、レコードをドラッグ＆ドロップしてプランナーに再配置します。タイムバーをドラッグ＆ドロップすることもできます。

### レコードグループを作成

グループでは、ロードマップをマイルストーン順に並べるなど、レコードを論理的に整理できます。す。

グループを作成するには、レコード列の上にある三点リーダー（**...**）を選択し、[**新しいグループを追加**] を選択します。

![](../../../../../../docs/using-miro/formats/images/19967187355794_4f687249-7573-4110-9c27-bb8dd45c8454.png)

*タイムライン ウィジェットへの新しいレコードの追加*

**ヒント：**レコードを別のグループにドラッグ＆ドロップすることができます。

### レコードグループを削除

レコード列の上にある三点リーダー（**...**）を選択し、[**グループを削除**] を選択します。

## タイムラインにカードを追加

タイムライン ウィジェットは、Miro カード、Jira カード、Azure カードのデータを視覚化します。

Miro ボード上で、タイムライン ウィジェットに任意のカードをドラッグ＆ドロップするだけです。

<スクリーンショット>

:::warning
ベータ版では、Jiraカード でのタイムライン ウィジェットの操作は制限されています。Azure カードでの操作は利用できません。
:::

## タイムラインを共有

Miro ボードで、以下の手順を実行します：

1. 共有したいタイムライン ウィジェットを選択します。
   ウィジェットの上にコンテキストメニューが表示されます。
2. [**その他**（**...**）] メニューを選択します。
   ドロップダウン メニューが開きます。
3. [**リンクをコピー**] を選択します。
4. ボードの閲覧権限がある人とリンクを共有します。
