**プロトタイピングライブラリ**を使用して、Miroキャンバス上で直接プロトタイプレイアウトを構築します。このライブラリには、フローをビジュアル化し、早期にアイデアを構造化するのに役立つスクリーン、UIコンポーネント、アイコンが含まれています。

プロトタイピングライブラリを使用して、静的なプロトタイプを作成できます。**高度なコンポーネント、コネクタライン、インタラクティブプレビュー**などの機能は**Miroプロトタイプアドオン**が必要です。

![prototyping-library.png](../../../../../../../docs/using-miro/miroverse/prototyping/images/31804538064914_prototyping-library.png)

*プロトタイピング ライブラリーには、Miroでシングルおよびマルチスクリーンフローを手動で作成するために必要なすべてのものが揃っています。*

## プロトタイピング ライブラリーを開く

1. キャンバスで、[作成バー](../../working-on-the-board/02-miro's-new-simplified-user-interface.md)から**ツール、メディア、インテグレーション** (![icon-tools.svg](../../../../../../../docs/using-miro/miroverse/prototyping/images/26758266547986_icon-tools.svg)) をクリックします。
2. 「プロトタイピング」を検索して見つけたら、**プロトタイプ ライブラリー**をクリックします。
3. **プロトタイプ ライブラリー**パネルが開きます**。**

## プロトタイプ ライブラリーの内容

プロトタイプ ライブラリーはタブに整理されています。すべてのユーザーがスクリーン、UI コンポーネント、アイコンを使用して静的なプロトタイプレイアウトを組み立てることができます。

:::tip
AI が生成したプロトタイプやインタラクティブなフローを作成する際は、[**Miro Prototypes**](03-miro-prototypes.md) と一緒にプロトタイピング ライブラリを使用します。
:::

### スクリーン

**スクリーン**は、プロトタイピングのフロー向けにあらかじめ用意されたフレームです。**モバイル**、**タブレット**、または**デスクトップ**のスクリーンをキャンバスに追加し、その上に UI 要素をドラッグしてレイアウトを構築することができます。

#### **スクリーンの操作**

- **表示または非表示**にして、デバイスのフレームのように見せたり、単純なフレームにしたりできます
- **回転**させる
- **リサイズ**して高さのみを延ばせます

### UIコンポーネント

UIコンポーネントは、ボタンや入力欄、ナビゲーションバー、フォーム要素などの一般的なインターフェイス要素で、画面上にドラッグして配置できます。

以下の操作が可能です：

- コンポーネントを画面にドラッグして配置
- リサイズや再配置
- コンテキストメニューからテキストやベーシックなスタイルを編集

:::note
コンテキストメニューのオプションは、選択した要素によって異なります。
:::

[**Miro Prototypesアドオン**](07-miro-prototypes-add-on.md)が有効化されている場合、一部のUIコンポーネントが**プレビューモードでインタラクティブ**になります。例えば、ボタン、スライダー、入力フィールド、ドロップダウンメニューは、定義したコネクターラインにもとづいてユーザー操作に反応します。

また、**高度なコンポーネント**のような一部のコンポーネントセットは、**Miro Prototypesアドオン**でのみ利用可能です。アドオンが有効でない場合、これらのコンポーネントはライブラリにインジケータ付きで表示されることがあります。

### アイコン

**アイコン**タブには、プロトタイプで使用できる検索可能なアイコンライブラリが含まれています。

#### **アイコンを追加または置換する**

1. ライブラリからアイコンをキャンバスにドラッグします。
2. アイコンを選択し、コンテキストメニューからその色を更新します。
3. **アイコンを置換** を選択して、位置やサイズを変えずに別のアイコンと交換します。

### ワイヤーフレーム（レガシー）

**ワイヤーフレーム** タブにはレガシーのワイヤーフレーム要素が含まれています。これらの要素は既存のボードで利用可能かつ編集可能ですが、新しいプロトタイプではプロトタイピングライブラリから画面やUIコンポーネントを使用してください。

## コネクターラインとインタラクティビティ（Miro Prototypesアドオン）

**コネクターライン**を使って、プロトタイプ間の画面遷移を定義できます。[**Miro Prototypes アドオン**](07-miro-prototypes-add-on.md)が有効になっていると、要素や画面間にコネクターラインを作成してマルチステップフローを構築できます。

コネクターラインは**インタラクティブ プレビュー**も可能にします。プレビューモードでは、接続された画面がクリック可能なフローとして機能し、画面がビューポートを超える場合は縦方向にスクロールします。アドオンがない場合、コネクターラインやインタラクティブな動作は利用できません。

:::tip
一部のUI要素は画面に追加されると稲妻アイコンが表示されます。マルチスクリーン フローでは、稲妻アイコンをドラッグして画面間にコネクターラインを作成します。
:::

## よくある質問

**ライブラリに独自の要素を追加できますか？**

いいえ。カスタムコンテンツをボードに追加することはできますが、プロトタイピングライブラリ自体に新しい要素を追加することはできません。

**新しいプロトタイピングライブラリの違いは何ですか？**

プロトタイピングライブラリは、画面、更新されたUIコンポーネント、アイコン、そしてクリック可能なインタラクティブプレビューをサポートしています。高度でインタラクティブな機能にはMiro Prototypesアドオンが必要です。

**プロトタイピングライブラリーはアドオンなしで利用可能ですか？**

はい。プロトタイピングライブラリーを使って静的なプロトタイプのレイアウトが作成できます。インタラクティブな接続や高度なコンポーネントには、Miro Prototypes アドオンが必要です。

**ワイヤーフレームライブラリーはまだ利用可能ですか？**

はい。ワイヤーフレーム タブはプロトタイピングライブラリーで利用可能で、既存のワイヤーフレームは引き続き機能します。
