Miroでのプロトタイピングは、チームがアイデアを視覚的に探求し、デジタル体験の初期バージョンを構築するのに役立ちます。Miroは、基本的な手動スクリーン作成ツールを提供し、AI駆動の作成およびインタラクティブな動作を拡張するオプションの**Miro Prototypes** アドオンを追加できます。

ワークフロー全体で、この両方のアプローチを活用できます。

## **プロトタイピングにおすすめのツール**

Miroのプロトタイピングワークフローは、以下の4つのツールに基づいて構築されています。

- **コンポーネント** — UI要素、デバイス、アイコン、高度なコンポーネント。
- **作成方法** — 手動での画面作成またはAIを活用した生成。
- **インタラクション** — スタティックなレイアウトまたはインタラクティブなクリックスループレビュー。
- **フォーマット** — プロトタイプのためのコンテナで、フォーカスモードへの素早いアクセスとプレビューが可能です。

アクセスはプランおよびアドオンの利用可否によります。

## **ツールの連携方法**

Miro のプロトタイピングツールは、別々のルートではなく、組み合わせて使用するように設計されています。ほとんどのチームはワークフロー全体で手動の作成とAI主導の作成を組み合わせています。

以下のことを行うかもしれません:

- AIで初期の画面セットを生成する。
- 画面を手動で再配置または調整する。
- 手動でコンポーネントを追加する。
- プロトタイプを再スタイルしたり拡張したりするために再びAIを使用する。
- フィードバックセッション用にインタラクティブなナビゲーションを追加する。
- アイデアが発展するにつれて手動で洗練を続ける。

このハイブリッド アプローチにより、**スピード、柔軟性、コントロール**を手に入れることができます。
