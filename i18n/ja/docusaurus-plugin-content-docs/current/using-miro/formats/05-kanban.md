カンバンビューを使用すると、タスクを列に整理でき、進捗を追跡したり、ボトルネックを見つけ出したり、チームを同じ方向に合わせることが簡単になります。カンバン、タイムライン、テーブルビューをシームレスに切り替えて、1つの場所で計画、実行、調整が可能です。

## 主な機能

- **カンバンボードをカスタマイズして**、Miro ボードのどこにでも配置できます。
- **カンバンウィジェット内でカードの追加、編集、削除が可能**です。
- **カンバンウィジェット内でカラムの追加、編集、削除、および非表示が可能**です。
- **カンバンウィジェット内でスイムレーンを作成できます**。
- **付箋、Miro カード、Jira カードをカンバンウィジェットにドラッグ＆ドロップできます**。
- **ロジカルに情報を整理するために、カードをグループ化、ソート、フィルターで絞り込みが可能**です。
- **テーブルやタイムラインレイアウトに切り替える**ことで、データをさまざまな方法で視覚化します。
- **異なるデータソースを持つ複数のカンバンウィジェットを同じ Miro ボードに含める**ことができます。
- **カンバンボードをフルスクリーンモードで表示および編集**して、集中力を高めます。

## ボードにカンバンを追加する

:::warning
ゲスト編集者はカンバンを追加または編集する権限がありません。
:::

1. Miro ボードを開きます。
2. [作成ツールバー](../../getting-started/start-here/your-first-board/05-toolbars.md)から **ツール、メディア、およびインテグレーション**(*![icon-tools.svg](../../../../../../docs/using-miro/formats/images/29210901366418_icon-tools.svg)*) を選択します。
3. **カンバン**を検索して選択します。
   カーソルがカンバンのアイコンに変わります。
4. カンバンボードを配置するために、Miro ボード上の好きな場所をクリックします。

## カンバンカードのアクション

カンバンウィジェットは、作業を管理するためのいくつかのカードコントロールを提供します。

### カードの追加

**プラス記号**（**+**）を列内でクリックします。すると、新しいカードがその列に表示されます。

### カードの移動

カードを再配置または移動するには、ドラッグアンドドロップします。カードを他の列に移動したら、そのカードの列フィールドも変更されます。

### カードのテキストを編集する

カードを選択し、次にテキストを選択します。点滅するカーソルがテキストが編集可能であることを示します。

カード内のテキストに書式を適用するかリンクを追加するには:

1. 編集したいカードをダブルクリックします。
   カードが編集可能になります。
2. フォーマットしたいテキストを選択します。
   コンテキストメニューが表示されます。
3. コンテキストメニューから、または[キーボードショートカット](../working-on-the-board/06-shortcuts-and-hotkeys.md)を使用して、フォーマットを適用したり、リンクを追加したりします。
4. Enter キーを押してレコードを保存します。

カードを編集する際には、サイドパネルでもテキストフォーマットを適用できます。

### カードの色を変更する

1. カードをクリックすると、**カラーホイール**が表示されます。
2. **カラーホイール**をクリックしてカラーピッカーを開きます。
3. 色を選択します。

### カードフィールドを編集

1. カードを選択します。
2. **サイドパネルでレコードを開く**アイコンをクリックして、サイドパネルを開きます。
3. 必要に応じてカードフィールドを編集します。
4. または、カードを詳細な行として表示するTableレイアウトに切り替えることができます。

カンバンカードに表示したいカードフィールドを設定することもできます。

1. カンバンのヘッダーで、フィールドを隠すアイコンをクリックしてメニューを開きます。
2. カンバンカードで表示または非表示にしたいフィールドを選択します。
   カードはリアルタイムで更新されます。

### カードを削除する

1. カードを選択します。
2. キーボードでDeleteまたはBackspaceキーを押します。または、レコードをクリックしてゴミ箱アイコンで削除することもできます。
3. レコードが削除されました。

## カンバン列のアクション

カンバンウィジェット内での作業をよりよく管理するために取れるいくつかの列のアクションがあります。

### カンバン列を追加する

1. カンバンの一番右にある**列を作成**をクリックします。
2. または、列名の横にある**三点リーダー**（**...**）メニューからカンバン列を追加することができます。

### カンバン列の編集

1. **列名**をクリックします。
2. 列の名前を変更します。ここで列の色も変更できます。
3. または、列名の横にある**三点リーダー**（**...**）メニューからカンバン列の名前を変更することができます。

### 列を非表示にする

1. 列名の横にある**三点リーダー** (**...**)アイコンをクリックします
2. メニューで**列を非表示**をクリックします。
3. 右側の**目の**アイコンをクリックして列を再表示します。

### 列を移動

1. 列名の横にある**三点リーダー** (**...**)アイコンをクリックします。
2. **左に移動**または**右に移動**をクリックします。

ドラッグ＆ドロップ機能は近日中に登場します。

### 列を削除

1. カラム名の横にある**三点リーダー**（**...**）アイコンをクリックします。
2. **カラムを削除**をクリックします。

### 使用するカラムを変更

1. カンバンヘッダーにある**カラムフィールド**アイコンをクリックします。
2. 使用したいフィールド（すべての単一選択フィールドの中から）をカラムとして選択します。
3. または、編集したり、新しいフィールドを作成してカラムとして使用できます。

:::note
現在、カラムとして使用できるのは単一選択フィールドのみです。
:::

### スイムレーンを作成

1. カンバンのヘッダーにある**グループ**アイコンをクリックします。
2. スイムレーンとして使用したいフィールドを選択します。
3. または、スイムレーンとして使用する新しいフィールドを作成することもできます。
4. スイムレーンを削除するには、もう一度**グループ**アイコンをクリックし、**グループ解除**をクリックします。

### フォーカス（全画面）モード

フォーカス（全画面）モードでカンバンを編集および閲覧できます。ウィジェットの上部にある**斜め矢印アイコン**をクリックするだけです。フィルター、並べ替え、グループ化、フィールドの非表示といった設定はヘッダーにあります。

キャンバスに戻るには、上部の**キャンバスに移動**をクリックします。

## カンバンに Jira カードを追加する方法 (ベータ版)

Miro と Jira の作業をカンバンビューで統合し、チーム全体の作業を一箇所で管理・追跡することができます。

カンバンに Jira カードを追加するには、以下の手順で行います：

1. キャンバス上で該当する Jira カードを見つけます。
2. カードをカンバンの上にドラッグします。
3. カンバン内の目的の列にカードをドロップします。

Miro で行われた変更は Jira に反映され、その逆も同様です。以下のフィールドはテーブルまたはタイムライン内で Jira に同期されます：

- タイトル
- 説明
- 工数見積
- 開始日
- 終了日
- 担当者（ベータ版）
- ステータス（ベータ版）

**詳細情報:** [Jira カードに関するよくある質問](../../integrations-apps/atlassian/17-jira-cards-faq.md)を参照してください。
