テーブル履歴とバージョン管理機能を使用すると、誰がテーブルを変更したか、いつ変更したかを把握できます。フィールドの変更、列の追加、データの更新をチーム全体で追跡できるため、自信を持って共同作業を行い、迅速に問題を解決し、Miroを離れることなくコンプライアンス要件を満たすことができます。

## テーブル履歴の表示

1. テーブルをクリックしてコンテキストメニューを表示します。
2. コンテキストメニューで詳細アイコンをクリックします。
3. メニューからバージョン履歴を選択します。
   バージョン履歴パネルがボードの側面に開きます。
4. 日付の横にある矢印をクリックして、その日付のバージョン履歴と編集者を表示します。

:::warning
各バージョンのプレビューはベータ版では利用できません。代わりに「コピーとして復元」を選んでテーブルの以前のバージョンを確認できます。
:::

### バージョンを復元する

1. バージョン履歴パネルから、日付の横にある矢印をクリックしてバージョン履歴を表示します。
2. 復元したいバージョンの横にある復元アイコンをクリックします。
3. 開いたダイアログで、ボードに**コピーとして復元**するか、現在のバージョンを**復元して置き換え**るかを選択します。

:::note
**コピーとして復元**すると、現在のバージョンのテーブルの隣にコピーが配置されます。
:::
