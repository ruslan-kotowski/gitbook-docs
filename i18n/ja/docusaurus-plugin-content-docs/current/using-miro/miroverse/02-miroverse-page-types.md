Miroverse は、必要なものを見つけるために役立つ 2 つの主要なページタイプ、テンプレートの説明ページとユーザープロフィールページで構成されています。

### テンプレートの説明ページ

Miroverse の各テンプレートには、それぞれの説明ページがあり、ボードとその作成者に関する詳細情報を見つけることができます。いくつかのテンプレートには、個別のガイドツアーや、始めるのに役立つ追加情報を提供する短い動画紹介も含まれています。

テンプレートの説明ページから、コミュニティーがテンプレートに対してどのようなエンゲージメントをしているかも確認できます。テンプレートの「いいね」、「閲覧」、「コピー」の数を確認でき、また他のユーザーのフィードバックをレビューすることもできます。

### Miroverse のプロフィールページ

プロフィールページでは、テンプレートの作成者について詳しく知り、彼らが公開したすべてのボードを見ることができます。作成者のプロフィールページから、作成者の経歴、プロフィール写真、ソーシャルメディアリンク、および公開されているすべてのテンプレートを閲覧できます。

## Miroverse コンテンツを活用して参加しましょう

Miroverse のテンプレートを使用し、コミュニティーに参加してお気に入りのテンプレートにフィードバックを提供したり、「いいね」を付けて交流することができます。

### テンプレートを使用する

テンプレートを使いたい場合は、**テンプレートを使用する** をクリックして始めてください。

Miro アカウントにログインしている場合、新しいボードは**すべてのボード**セクションにある最後にアクティブだったチームの下に自動的に保存されます。

:::tip
簡単に[作成したテンプレートをチーム間や特定のスペースに移動する](../../getting-started/start-here/your-first-board/05-toolbars.md)ことができます。コラボレーションを開始するには、[ユーザーをボードに招待する](https://help.miro.com/hc/articles/360017730693-Sharing-boards-and-inviting-collaborators)か、[リンクを介してボードへの公開アクセスを有効化する](../sharing-boards/08-collaboration-with-visitors.md)。
:::

**詳細情報：**[Miroverse テンプレートの見つけ方と使用法](04-find-and-use-miroverse-templates.md)をご覧ください。

### テンプレートに「いいね！」をしてフィードバックする

Miro プロフィールにログインしているユーザーであれば、誰でも Miroverse のテンプレートに「いいね」とフィードバックを追加することができます。テンプレートが気に入って「いいね」を付けることで、感謝の気持ちを示し、お気に入りの Miroverse テンプレートを後で保存しておくことができます。

- サポートを示すには、テンプレートカードやテンプレートの説明ページで**♡**アイコンをクリックしてください。
- 「いいね」を削除するには、**♡** アイコンを再度クリックします。
- テンプレートにフィードバックを与えたりコメントを残したりするには、メッセージアイコンをクリックします。

### 「いいね」したテンプレートとクリエイタープロフィールを見つける

「いいね」を付けたテンプレートを見つけるには主に 2 つの方法があります:

- Miroverse ページの右上隅にあるプロフィール画像をクリックし、**いいね**を選択します。
- 公開されているMiroverseのプロフィールページから**[Likes]（いいね）**タブを選択します。

Miroverse の作成者の詳細や、作成したすべてのテンプレートを確認するには、テンプレートページやテンプレートカードで作成者の名前をクリックしてください。Miroverse の作成者のプロフィールから、その作成者がいいねしたテンプレートを閲覧できます。Miroverse のプロフィールからお気に入りのテンプレートを共有することもできます。Miroverse のプロフィールを持っていない場合、「いいね」を付けたテンプレートは、あなた専用の非公開ギャラリーに保存され、あなただけがアクセスできます。
