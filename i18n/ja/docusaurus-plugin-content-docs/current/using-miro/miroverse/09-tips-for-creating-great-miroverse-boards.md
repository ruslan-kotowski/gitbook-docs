## Miroverse とは？

[Miroverse](01-what-is-miroverse.md) は、Miro のコミュニティー テンプレートのギャラリーで、Miro のクリエーターが作成した質の高いボードを掲載しています。このプラットフォームでは、検索機能や様々なカテゴリーを閲覧することで、豊富なワークフローやプロジェクト、フレームワークを探索できます。

## Miroverse のテンプレートとは？

Miroverse のテンプレートは、実際の Miro ユーザーが、独自のワークスタイルを反映して作成したソリューションです。個人用からプロフェッショナル用途まで、各テンプレートは本格的な視点を提供し、実在のユーザーや企業、業界のリーダーが Miro をどのようにコラボレーションに活用しているかを示しています。

テンプレートの基準については、[Miroverse 公開用チェックリストとガイドライン](08-miroverse-publishing-checklist-and-guidelines.md)**をご覧ください。**

## 優れたテンプレートとは？

使いやすさのみならず、視覚的にも魅力的でインパクトのある Miroverse のテンプレートを作成するための実践的なヒントを以下にご紹介します。これらのヒントは、明快さや構成、そしてテンプレートを便利で目を引くものにするためのあらゆる点をカバーしています。

:::tip
[Creator Toolbox](https://miro.com/miroverse/creators/) では、Miroverse 公開のさらなるヒントやリソースが見つかります。また、[Creator Community](https://miro.com/miro-creators/) やイベントへのアクセスも可能です。
:::

### ヒント #1:わかりやすく、使いやすい

Miroverse のテンプレートを作成する際、ユーザーフレンドリーであることは不可欠です。他の人が自分のボードを簡単に理解し、活用できるようにすることが目的です。「わかりやすいこと」が必ずしも「簡素」を意味するわけではありません。ニッチで複雑なテンプレートでも、明確な指示があれば輝くことができます。

ボードの使いやすさを高めるためのチェックリスト

- **わかりやすく、検索しやすいタイトルを選びましょう：**タイトルには、ボードの目的とユースケースを正確に記述してください。ユーザーの立場になって考えてみてください。ユーザーは、あなたのワークフローやフレームワークを検索するのに、どんな言葉やフレーズを使うでしょうか？
- **詳しい説明を記載：**[Miroverse の説明](10-tips-for-writing-a-miroverse-template-description.md)には、以下の要素を盛り込んでください…
  - *何を*：テンプレートを作成した理由と、それが達成を助けること。
  - *誰*:グループや個人など、対象のオーディエンスを特定してください。
  - *タイミング*：テンプレートが最も役立つ状況を強調します。
  - *どのように*：番号付きリストで、順を追った指示とヒントを提供します。
- **例を挙げる：**テンプレートの使い方を示すために、記入済みのテンプレートを追加してください。例として、[アレックスさんのチームキャンバス](https://miro.com/miroverse/the-team-canvas/)や[ジュリアさんの顧客質問ボード](https://miro.com/miroverse/the-question-board/)をご覧ください。
- **適応性を確保する:**テンプレートは使いやすく、パーソナライズしやすいものがいいでしょう。さまざまなユーザーが個別のニーズに合わせてカスタマイズするのは簡単でしょうか？
- **同僚にレビューを依頼する:** 提出する前に、信頼できる友人、家族、または同僚にテンプレートを確認してもらいましょう。サポートなしでそれを理解してもらえますか？
- **追加**[Talktrack](../facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md)**:**ユーザーが Miroverse のテンプレートを開くと、すべての Talktrack を閲覧できます。おおまかな概要、プロセスのステップについて短い説明、実際の操作などの 2～3 分（推奨）の動画を加えてみましょう。

### ヒント #2:整った構造と情報の流れ

考え抜かれた構成でボードを作成しましょう。ここでのゴールは、ワークフローをナビゲートし、すべての機能を簡単に利用する方法を理解してもらうことです。

以下のチェックリストを使用して、ボードの構成を最適化してください。

- **明確なスタート地点とフローを追加：**スタート地点が明確で、ボード全体に論理的なフローがあることを確認します。数字、矢印、[フレーム](../essential-tools/07-frames.md)、またはその他のガイドを使用して、明確で直感的な進行を示します。多くの文化圏では、左から右へ情報を扱います。例として、[Red Hat の Building Team Collaboration](https://miro.com/miroverse/building-team-collaboration-workshop-sitvjf8itx6jzduk/) や [Tini Studio の Diversity and Inclusion Workshop](https://miro.com/miroverse/diversity-and-inclusion-workshop-the-multiverse-toolkit/) をご覧ください。
- **ガイド機能：**役立つ要素を取り入れましょう。例えば、予想される回答数を示すために[付箋](../essential-tools/14-sticky-notes.md)を使ったり、アイデアを刺激するための文頭語を用意したり、最終結果の例を紹介したりすることができます。
- **アクセシビリティー**:[インクルーシブ デザインの原則](../../getting-started/accessibility-in-miro/04-how-to-make-your-miro-boards-more-accessible.md)を心に留め、Miro アクセシビリティー チェッカーを使用してください。これは Miro ボードをスキャンし、一般的なアクセシビリティー基準を満たしていない可能性のある箇所をハイライトし、改善のための実用的な提案を提供します。
- **カスタマイズ可能性**:ボードのほとんどの要素、またはすべての要素のロックを解除し、ユーザーが必要に応じて簡単に応用・カスタマイズできるようにします。

### ヒント #3:他の人に役立つ

良いテンプレートを作るには、*「他の人の役に立つか？」*という点を自問することから始めましょう。自分にとって役に立ったのなら、他の誰かにとっても役に立つ可能性があります。エンドユーザーを念頭に置き、多様な利用者のニーズに応えるテンプレートの作成を目指しましょう。チームのふりかえり、ワークショップのデザイン、クライアントプロジェクトなど、今あるボードは共有価値の宝庫かもしれません。

優れたテンプレートは個人の使用を超えて共有リソースとなり、その影響を幅広いオーディエンスに広げます。使用したことのないテンプレートを作成する場合は、提出する前にまず自分で使用してみるのもよいでしょう。また、友人や同僚に試してもらい、その有用性についてフィードバックを得ることもできます。

有用性の評価には、次のような質問を活用できます。

- 最終的なアウトプットは、テンプレートの使用目的に沿っていますか？
- 最終的なアウトプットは、その目的と目標を達成していますか？
- 見逃しているステップはありませんか？
- 指示は明確ですか？
- アクティビティーは理にかなっていますか？

### ヒント #4:楽しめる

魅力的で楽しいテンプレートを作成するのに、デザイナーである必要はありません。しかし、ボードが魅力的なほど、他の人も楽しみ、使ってもらえる可能性は高くなります。

コンテンツそのものが最優先ですが、ここではテンプレートを際立たせるための便利なデザインのヒントをいくつかご紹介します。

- 100% ズームでデザインし、付箋、カード、その他の要素にはデフォルトのサイズを使用します。
- 書式、フォントの種類、配色はすべて統一しましょう。
- 背景は落ち着いたトーン、編集可能な要素は鮮やかな色など、戦略的に色を使い分けましょう。情報の階層と奥行きを示すために、色調を活用します。
- 重要性を伝えるためにフォントサイズを活用しましょう。重要な要素には大きなフォントを、重要でない要素には小さなフォントを使用します。
- 視覚的に魅力的なレイアウトにするために、要素間の間隔を一定にします。
- [iconfinder](../../integrations-apps/more-integrations/09-iconfinder.md)、[ワイヤーフレーム ライブラリー](prototyping/02-prototyping-library.md)、絵文字を使用してビジュアルを追加または強化できます。
- 第三者の画像を使用する場合は、全体的な魅力を高めるために、高品質のストックフォトを選択します。
- あからさまな広告、宣伝、スパムは削除してください。アフィリエイトリンクはテンプレートの説明文の中に入れてください。
- 該当する場合は、第三者のコンテンツにクレジットを記載し、出典へのリンクを貼ってください。
- [適切な開始画面を設定](https://community.miro.com/ask-the-community-45/how-to-set-start-view-687)し、提出プロセスでサムネイルに類似のスクリーンショットを選択します。Miro の表が見えないようにし、タイトルが適切にフレーム化されていることを確認してください。
- テンプレート内には Miro の要素をできるだけ多く活用し、テキストや図形を使ってインタラクティブにします。ユーザーが加工できない画像の提出は避けてください。

美しく整理されたデザインは、シンプルで退屈なものというわけではありません。インスピレーションを得るために、[ニ・トランさんのふりかえり](https://miro.com/miroverse/retrospective-emoji-4ohfgtdnpetyigth/)をご覧ください。
