[Miroverse](https://miro.com/miroverse/)は、Miroコミュニティーによって作成・共有された便利で革新的なボードテンプレートを展示するコミュニティーのテンプレートギャラリーです。ワークフロー、プロジェクト、フレームワークを幅広く探索できる検索機能と閲覧機能を備えています。気に入ったテンプレートを見つけたら、自分のチームにコピーしてすぐに始めることができます。

:::tip
[Miroverse Creator Design Toolkit](https://miro.com/miroverse/miroverse-creator-design-toolkit/)を訪れて、Miroverse公開についてのさらなるヒントやリソース、Creator Communityやイベントへのアクセスを得ることができます。
:::

:::tip
自分のボードを[公開する方法](06-how-to-get-published-on-miroverse.md)について詳しく学びましょう。
:::

:::warning
Miroverse は、US および AU データレジデンシーに登録されたお客様には利用できません。
:::

## Miroverse 対 テンプレート ライブラリー

Miroverse とテンプレート ライブラリーの両方では、既存のボードテンプレートを自身の Miro チームにコピーすることで、ボードをゼロから作成することなく新しいプロジェクトを開始できます。ただし、それぞれのギャラリーで提供されるテンプレートは起源と目的が異なります。

### テンプレート ライブラリー

- Miro チームが構築。
- 様々な一般的な導入事例に対応。
- 業界のベストプラクティスとお客様からのフィードバックを基に構築。

### Miroverse

- Miro ユーザーが構築。
- 個人使用とビジネス向け両方の導入事例を紹介。
- 作成者それぞれの使い方に特化。
- 実際の企業や業界リーダーの Miro の活用事例を垣間見ることが可能。
