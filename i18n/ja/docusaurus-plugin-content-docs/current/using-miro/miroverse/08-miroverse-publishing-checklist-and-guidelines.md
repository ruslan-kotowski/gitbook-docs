[Miroverse は](https://miro.com/miroverse/)、Miro ユーザーによって作られた、Miro ユーザーのためのコミュニティー テンプレートのライブラリーです。**テンプレートとは、繰り返し使えてカスタマイズ可能な Miro ボード**のことです。

作成したワークフローやプロジェクト、フレームワークを Miroverse のテンプレートとして共有することで、他のユーザーに Miro の新しい使い方を提案し、仕事をサポートすることができます。

以下は、公開にいたるためのベストプラクティスとガイドラインです。テンプレートの提出方法については、[Miroverse で公開する方法](06-how-to-get-published-on-miroverse.md)をご覧ください。

:::note
すべての Miroverse のクリエイターは、Miro の [プライバシーポリシー](https://miro.com/legal/privacy-policy/)と[オンライン コミュニティー利用規約](https://miro.com/legal/online-community-terms-of-use/)への同意が必要です。
:::

## Miroverse テンプレート提出基準

Miroverse に掲載されるには、以下の条件を満たしている必要があります。

1. **実際にテンプレートであること。**提出されたボードは、他のユーザーが入力し再利用できる空のテンプレートまたはフレームワークを含めてください（記入済みボードではなく）。テキスト欄や画像のみのボードは受け付けられません。
2. 特に、新しい概念や複雑な概念を含む場合は、説明や例を用いて、**使いやすく手順がわかりやすい**ことが重要です。信頼できる友人、同僚、家族にテンプレートを見てもらい、助けがなくても使い方を理解できるか確認するのもいいでしょう。
3. テンプレートの使い方を示すために、**記入例や Talktrack を追加**することもできます。例として、[アーニャの「Emotions Wheel Icebreaker」](https://miro.com/miroverse/emotions-wheel-icebreaker/)、[アレックスの「Team Canvas」](https://miro.com/miroverse/the-team-canvas/)、[ジュリアの「Customer Question Board](https://miro.com/miroverse/the-question-board/)」をご覧ください。
4. **テンプレートは、現在 Miro が対応している言語で提出してください。**複数の言語でテンプレートを公開したい場合は、各言語を個別のボードで別々に送信してください。当社では、対応言語の拡大に取り組んでいます。[Miro コミュニティー ウィッシュリスト](https://community.miro.com/ideas)で、次に追加したい言語をお知らせください。
5. **コミュニティー ガイドラインの遵守**をお願いします。提出テンプレートは、適切かつ有用で、他者のプライバシー、情報、知的財産を尊重するものでなければなりません。
6. **Miroverse のプロフィールを完成してください。**アバター、自己紹介、会社名を追加してください。

## 公開用チェックリスト

以下は、テンプレートが Miroverse に提出・公開できるかを確認するための簡単なチェックリストです。

### 投稿前に

次の点を確認してください：

- ボードは空白のテンプレートで構成され、他のユーザーが個別の目的にそって使用できる。
- テンプレートの使い方がわかりやすい。
- テンプレートは、英語、日本語、スペイン語、ドイツ語、フランス語、ポルトガル語のいずれかで作成されている。
- テンプレートは有用で適切であり、他者のプライバシーや知的財産を侵害していない。
- テンプレートには、適切な使用法を示すサンプルやデモなどが含まれている。
- Miroverse のプロフィールには、写真、自己紹介、会社名が完成している。
- テンプレートには[非表示フレーム](../essential-tools/07-frames.md)がいない。
- テンプレートには[ロック](../working-on-the-board/17-locking-content-on-the-board.md)されたアイテムがほぼない。
- ボード上に、あからさまな広告や宣伝、スパムサイトがない。すべてのアフィリエイトリンクはテンプレートの説明に記載さている。
- 該当する場合は、テンプレートや説明文に情報源のリンクを貼り、使用したサードパーティーのコンテンツにクレジットを提供している。

チェックリストに目を通したら、[テンプレートを提出](https://miro.com/miroverse/submission/?backToUrl=/)する準備は完了です。提出する際の詳細な手順については、[Miroverse で公開する方法](06-how-to-get-published-on-miroverse.md)をご覧ください。

#### **テンプレートの説明への記載内容は？**

- **何を**：*なぜこのテンプレートを作成したのか？利用することで達成できることは？*
- **誰が**：*テンプレートを利用することで利点となるユーザーは？グループ向け、または個人向け？*
- **いつ**：*このテンプレートはどんな場面で最も役に立のか？*
- **どのように**：*テンプレートの順を追った使い方とそのヒント。*

:::tip
[魅力的な Miroverse テンプレートの説明文](10-tips-for-writing-a-miroverse-template-description.md)の書き方を学びましょう。
:::

## Miroverse テンプレートのベストプラクティス

テンプレートは、他のユーザーがボードを作成し、独自のボードとしていくための素晴らしい出発点となります。この点を踏まえて、投稿に際して守っていただきたいコンテンツのガイドラインをいくつか設けています。

外観と機能性 ユーザビリティー

**視覚的な一貫性を念頭に**
画像、フォント、色を追加する際は、フォーマットに注意してください。テンプレートやボードの書式を統一すると、使用感が高まります。高品質のストック画像やコンテンツは、大きな違いを生み出します。

![一貫した画像品質と書式.gif](../../../../../../docs/using-miro/miroverse/images/21017005620498_Consistent%20image%20quality%20and%20formatting.gif)*ニーナ・トールによる「モンスター ワークショップ」*

**明確な起点と流れを作成**
プロセスの各工程を簡単にたどれるようにしましょう。[フレーム](../essential-tools/07-frames.md)は、ボードの構造を作るのに役立つ方法です。必要に応じて数字や矢印などの案内表示も追加してください。

![順を追った使い方.gif](../../../../../../docs/using-miro/miroverse/images/21017005621010_step%20by%20step%20instructions.gif)*Zoom を使った効果的な会議*

**具体的な事例をあげてプロセスを明確化**
具体的な使い方や体験は多くの人が興味を持つ部分です。アイデアに命を吹き込むには、実例が不可欠です。

![Example_template_provided_by_template_creator.gif](../../../../../../docs/using-miro/miroverse/images/21017005621778_Example%20template%20provided%20by%20template%20creator.gif)
*サンドラ・ハインゼンによる「包括的な顧客体験」*

**自分の利用方法を説明して再現しやすく**
自分なりの使い方を提示してください。複数のステップに分けて説明するとわかりやすいでしょう。

![Guided_template_instructions.gifVMware](../../../../../../docs/using-miro/miroverse/images/21016968070162_Guided%20template%20instructions.gif)
*Tanzu Labs による「関係者マップ」*
**応用しやすいボード構造に**
ロックされた要素を少なくし、すべてのテキストフィールドを編集可能にすることで（テキスト画像の使用は避けるなど）、コンテンツの柔軟性を保ちます。

![Editing_text.gif](../../../../../../docs/using-miro/miroverse/images/21017005622674_Editing%20text.gif)
*Switch to eleven による「チームの意識合わせワークショップ」*

**説明動画の録画（オプション）**
動画は必須ではありませんが、使用方法を説明するいいツールになります。動画の長さは、3～10 分程度にしましょう。関連するインサイト、個人的な使用方法、解決できる課題などを追加してください。Loom などの画面録画ツールを利用します。

![Giving_a_video_walkthrough_of_your_template.gif](../../../../../../docs/using-miro/miroverse/images/21017005624850_Giving%20a%20video%20walkthrough%20of%20your%20template.gif)
*マイラ・ラーメによる「ワークショップと会議の活性化」*

## 不適切なテンプレートやプロフィールの報告

不適切または疑わしいテンプレートやプロフィールを Miro コミュニティーチームに報告するには、[**報告**] ボタンを使用するか、[miroverse@miro.com](mailto:miroverse@miro.com) にメールを送信します。内容を報告する理由を簡単に説明してください。

## コミュニティーのルールとガイドライン

以下のガイドラインに従えば、より速やかに承認を得られるはずです。

**🕊️ 礼儀正しく**

Miroverse は、クリエイターのコミュニティーです。分別のある人が不適切、攻撃的、脅迫的、ヘイトスピーチと見なすようなものは投稿しないでください。

**🌐 適切性と有用さ**

すべてのコンテンツは、ブランド、企業、作成者の主観を除いた観点で作成してください広告、宣伝、スパムに類似するウェブサイトは記載しないでください。すべてのアフィリエイト リンクはテンプレートの説明文に記載し、テンプレートのボードに追加しないでください。すべてのテンプレートは、追加購入項目がなく無料でなければなりません。

**🔒️ ️プライバシーと信用の尊重**

機密事項や秘密事項を含む情報がないか確認してください。機密事項や秘密事項（メールアドレスや個人を特定できる情報など）を含む、第三者のプライバシーを侵害するコンテンツは、当事者の明示的な同意がない限りテンプレートにおいてその使用を認められません。

**© 他者の知的財産権の尊重**

インスピレーションを得たコンテンツにはクレジットを与え、そのコンテンツを公開する権利を有していることを確認してください。他人の作品を自分のプロフィールで共有したり、作品の原作者が誰であるかについて混乱を生じさせるようなことは避けてください。
