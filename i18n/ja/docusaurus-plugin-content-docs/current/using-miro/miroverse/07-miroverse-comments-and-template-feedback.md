Miroverse は、ユーザーがフィードバックを共有し、テンプレートに関する洞察を交換できるようにすることで、品質の確保と協力的な学習の機会を創出します。建設的なコメントを残すことで、クリエイターがテンプレートを改善し、コミュニティーに貢献できるようになります。

:::note
テンプレートのフィードバックを残すには、[Miroverse](01-what-is-miroverse.md) にログインする必要があります。
:::

:::warning
Miroverse のテンプレートに対するすべてのコメントは、モデレートされています。Miroverse へのフィードバック ガイドラインに従ってください。
:::

## フィードバックとコメントを共有する方法

Miroverse のプロフィールやテンプレートのページから直接テンプレートを共有できます。コメントの投稿や返信でコミュニティーに参加することもできます。

### プロフィールからフィードバックを送信する

1. 右上隅のユーザープロフィール写真をクリックします。
2. **テンプレート フィードバック**をクリックします。
3. **テンプレートフィードバック** タブでは、使用したすべてのテンプレートが確認できます。
4. クリックして**フィードバックを送信**するか、**スキップ**してリストからテンプレートを削除します。
5. **このテンプレートのどこが良かったですか？** 該当する理由を選択してください。
6. **公開****コメント**（最大 1,000 文字）を残すこともできます。Miroverse のフィードバックガイドラインを守ることを忘れないでください。
7. **ご意見・ご感想** を送信するにはクリックしてください。

![Giving-template-feedback-from-profile.gif](../../../../../../docs/using-miro/miroverse/images/21016044663058_Giving-template-feedback-from-profile.gif)
*Miroverse のプロフィールページからテンプレートにフィードバックを残す方法*

### テンプレートページからフィードバックを送信する

1. フィードバックをしたいテンプレートのページに移動します。
2. **「いいね」**アイコン（ハート）をクリックしてテンプレートを保存します。
3. **テンプレートフィードバック**アイコンをクリックします。
4. **このテンプレートのどこが気に入りましたか？** で該当する理由を選択してください。
5. また、**公に****コメント**（最大 1,000 文字まで）を残すこともできます。Miroverse のフィードバック ガイドラインに従うことを忘れないでください。
6. **フィードバックを共有** をクリックして送信してください。

![Leaving-template-feedback-from-template-page.gif](../../../../../../docs/using-miro/miroverse/images/21016044664082_Leaving-template-feedback-from-template-page.gif)
*テンプレートページからテンプレートへのフィードバックを残す*

### コメントの管理方法

フィードバックの一部として残したすべてのコメントは、自動的にテンプレートページの**コメント**セクションに表示されます。テンプレートページに直接アクセスして、考えを共有し、議論に参加し、コメントを管理することもできます。

コメントするには:

1. **コメントを残す**フィールドに入力を開始してください。
2. **投稿**をクリックします。

![Leaving-a-comment-on-a-Miroverse-template.png](../../../../../../docs/using-miro/miroverse/images/21016044661778_Leaving-a-comment-on-a-template.png)
*Miroverse テンプレートにコメントを残す*

会話に参加するには、他のコメントに**返信**できます。

![Replying-to-comment-miroverse-template.png](../../../../../../docs/using-miro/miroverse/images/21016044667026_Replying-to-comment-miroverse-template.png)
*コメントに返信中*

コメントは **新しい順**または**古い順**に並び替えることができます。

![Sorting-Miroverse-template-comments.png](../../../../../../docs/using-miro/miroverse/images/21016044667538_Sorting-Miroverse-template-comments.png)
*コメントの並べ替え*

送信後にコメントを**編集**または**削除**するには、コメントの隣にある**三点リーダー**メニュー(**...**)をクリックしてください。

![Deleting-a-comment-on-a-miroverse-template.png](../../../../../../docs/using-miro/miroverse/images/21016044666386_Deleting-a-comment-on-a-miroverse-template.png)
*コメントを編集または削除するオプション*

:::note
テンプレートコメントと返信に対する通知を[Miroverse の設定](03-miroverse-profiles.md)でオンにすることができます。
:::

## Miroverse フィードバック ガイドライン

私たちの活発なコミュニティーへのご貢献、ありがとうございます。Miroverse でのポジティブで協力的な環境を維持するために、コメントを残す際には以下のガイドラインに従ってください。あなたの積極的な参加はすべてのメンバーにとっての体験を向上させ、今後の貢献を心待ちにしています。

### **やることリスト:**

- **テンプレート作成者に感謝と謝意を表明する**テンプレートを構築することは、愛情を込めた努力の賜物です。そして、あなたのポジティブなコメントは、彼らのハードワークと献身を認める上で大いに役立ちます。
- **建設的なフィードバックを提供する**:具体的で詳細なフィードバックは、クリエイターが優れたテンプレートを作成する力を与えます。たとえば、「テンプレートの使い方がわからない」と述べる代わりに、「ワークショップのステップ1と2の詳細な手順が含まれていると助かります」と言うことができます。ここまでがんばりましたね！おつかれさまでした。
- **積極的に励ます**:作成者が上手くできている点を強調するポジティブなフィードバックは、建設的なフィードバックと同様に重要です。具体的な称賛を行うことで、クリエイターが自分のテンプレートのどの部分が他の人々に響いているのかを理解するのに役立ちます。
- **他のユーザーと交流する**：会話に飛び込んで、投稿に対する他のコメント投稿者と交流し、ネットワークを広げましょう！アイデアを強化したり、コンテキストを追加したり、ヒントやリソースを提供したりして、Miroverse の豊富なテンプレート ライブラリーを活用して他の人が成功するのを支援しましょう。全員歓迎です！

### **避けるべきこと:**

- **宣伝または販売は控えてください**:コメントは、プロモーションではなく、テンプレートやコミュニティーとの関わりに焦点を当てるべきです。
- **過度な自己宣伝を避ける**:無関係なコンテンツやソーシャルメディアのプロフィールをリンクまたは宣伝しても、会話に価値を追加しない場合は不適切です。このような行動は、コメントの削除につながることがあります。
- **スパム行為を避ける**:コメントは Miroverse、特定のテンプレート、または進行中の議論に関連するものにしてください。同じコメントを繰り返し投稿したり、無関係なコンテンツを導入しないようにしてください。
- **否定的な感情を引き起こさないでください**:他人を挑発したり、ネガティブな交流を引き起こす意図を持ったコメントは禁止されています。繰り返し違反すると、コンテンツの削除やコメントへの制限が課される場合があります。
- **ヘイトスピーチや差別は禁止**：人種、宗教、性別、その他の特性に基づいて個人またはグループを標的にするコメントは受け入れられません。このようなコメントは速やかに削除され、コメントする権利が取り消されることがあります。
- **失礼なことはしないでください**:他のコメント投稿者や議論で言及された個人に対する個人攻撃、侮辱、または名前を呼ぶことを避けてください。このような種類のコメントは削除され、コメントする機能が制限される場合があります。
