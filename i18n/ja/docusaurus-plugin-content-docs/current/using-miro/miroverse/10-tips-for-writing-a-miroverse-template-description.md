[Miroverseにテンプレートを投稿する](06-how-to-get-published-on-miroverse.md)際には、テンプレートのタイトル、関連するカテゴリ、該当する役割、テンプレートの説明を追加する必要があります。

この記事では、テンプレートの認知度を高め、あなたの専門知識をアピールし、作成したテンプレートを最大限に活用してもらうためのテンプレート説明文の書き方について説明します。

:::tip
[Creator Toolbox](https://miro.com/miroverse/creators/) では、Miroverse 公開についてのさらに詳細なヒントやリソースが、また Creator Community では、イベント情報も掲載しています。
:::

## テンプレートの説明とは何ですか？

テンプレートの説明では、テンプレートの作成理由、用途、使用方法などを紹介します。説明文はMiroverseのテンプレートページで、テンプレートのプレビューの下に表示されます。

## なぜテンプレートの説明が重要なのですか？

明確で読みやすいテンプレートの説明を書くことには、次のような利点があります：

**1. ニーズに合うかどうかを判断する手助けをします。**説明文では、テンプレートが何なのか、誰のためのものなのか、その目的、なぜ作成されたのか、どのように使用するのか、さらにテンプレートのコンテンツを最大限に活用するためのヒントやコツ、ベストプラクティスなどを説明することができます。

**2. インスピレーションを提供**多くの人がMiroverseを閲覧し、Miroを使って同じような問題を解決する新しい面白い方法を学んでいます。あなたの説明は、彼らがあなたの方法から学ぶための追加のコンテキストを提供することができます。

**3. 人々があなたのテンプレートを見つけるのを助けます。**テンプレートのタイトルとともに、説明文は検索結果に表示されるかどうかを決定します。誰かがあなたのようなテンプレートを見つけるためにキーワードやフレーズを検索しても、あなたのタイトルにその特定のキーワードが含まれていない場合、説明文にコンテキストが追加されることで、関連する検索に追加表示される可能性があります。

## 良いテンプレートとは？

良いテンプレートの説明は、包括的で読みやすく、適切な文脈、キーワード、フレーズでよく整理されています。

### 総合

説明文はスペースを含めて300文字以上でなければなりません。しかし、潜在的なユーザーがテンプレートを最大限に活用できるよう、必要なだけの情報を提供することがベストプラクティスです。説明文の長さはテンプレートとそのテーマによって異なりますが、平均して500～800ワード、またはスペースを含めて1000～5000文字を推奨します。

### 読みやすい

テンプレートとその使用方法を説明するために、わかりやすく、シンプルで明確な言葉を使って十分な背景を説明してください。このコンセプトを聞いたことがない人に説明することを想像してみてください。どのような詳細を盛り込みますか？

### よく整理され、ナビゲートしやすい

ヘッダー（H2、H3）、箇条書きリスト、番号付きリストを使って、必要な情報をすぐに見つけられるように説明文をフォーマットしましょう。最も重要な情報は説明文の上部に、FAQやその他のヒントなど、あまり重要でない情報は下部に配置します。

### キーワードとフレーズを含む

上述したように、説明文の目的の一つは、人々があなたのテンプレートを見つけるのを助けることです。同じような解決策を探している人を助けるために、テンプレートの目的や主題に関連する一般的でなじみのある単語やフレーズを含めます。

## テンプレート説明文の上手な書き方

読者のニーズを見極めた上で、段落や箇条書き、リストなどを使って、コンテンツを整理されたセクションに分けましょう。これにより、読者と検索エンジンの両方がコンテンツを理解しやすくなります。

### 聴衆を考える

あなたのテンプレートを探して使っている人を想像してみてください。そうすることで、説明文の主な部分を把握することができます。自問自答してみてください。

1. 1. *その人物は特定の職務や業界に就いていますか？*
   2. *彼らがこのテンプレートを求める目的や動機は何ですか？*
   3. *このテンプレートは彼らの問題をどのように解決するのでしょうか？*
   4. *テンプレートは、彼らが何を達成するために役立つのでしょうか？*
   5. *どのような情報を求めているのでしょうか？*
   6. *このテンプレートで成功するためには、どのような詳細、定義、指示、リソースが必要ですか？*

### H2セクションヘッダーでメインセクションを作成します。

**セクションヘッダーは常にH2フォーマットを使用してください。**- これらは説明文の最も重要な要素です。ヘッダーは、読者がコンテンツを理解し、ナビゲートするのに役立ちます。簡潔でわかりやすく、そのセクションの目的を明確に伝えるものでなければなりません。ヘッダーには、練習、主題、業界、または役割に関連するキーワードやフレーズを含める必要があります。上記の質問の答えを使って、セクションの見出しを作成してください。

ヘッダーの例には以下のようなものがあります：

- *テンプレートタイトル]について*
- *このテンプレート[TEMPLATE TITLE]を使用できる人*
- *テンプレートの使い方*
- *この[テンプレート・ティルテ]で実現できること*
- *ヒントとベストプラクティス*

### H3でサブセクションを作成

セクションが長くてまとまりがないと感じたら、H2の下に小見出し（H3）を入れ、サブセクションに分割しましょう。H2の下にネストされていない限り、H3は決して使用しないでください。以下はその一例です。

*H2 「ふりかえりとは何ですか？*

*H3 「チームふりかえりとは？*

*H3 - 誰がふりかえりを使っていますか？*

*H3 - なぜふりかえりが有効なのか？*

*H3「ふりかえりを行うタイミング*

*H2 - ふりかえりテンプレートの使い方*

*H2 「ふりかえりの進め方*

*H2 - ふりかえりのヒントとベストプラクティス*

### 説明文を読みやすくするために、番号や箇条書きのリストを使用してください。

順序のないリストには箇条書きを、順序のあるリスト（ステップバイステップの指示など）には数字を使いましょう。これらのツールは、コンテンツをより整理され、読みやすく、魅力的なものにするのに役立ちます。絵文字を使うことで、より魅力的な説明文にすることもできます。

## プロのヒント

### テンプレートボードからコンテンツをコピー/貼り付け

すでにテンプレートのボードに指示や情報を書き込んでいる場合は、投稿プロセス中に説明欄にコピー/ペーストして、余分な作業を省くことができます。ボード自体のコンテンツは検索結果に役立てることはできませんが、説明文に追加することでテンプレートの可視性を向上させることができます。

### Miro AIを使って説明文を書いてください。

[Miro AI](../miro-ai/21-using-miro-ai-with-board-objects.md)(ベータ版)に説明を生成するよう促すことができます。

以下の手順を実施してください。

1. MiroボードのCreationツールバーの上で、**Create with AIを**選択します。
2. **ドキュメント**ボタンを選択します。
3. *このボードの簡単な説明を書いて*ください。
   Miro AIは説明を生成します。
4. (オプション）AIが生成した説明を編集します。
5. 説明文をコピーして、Miroverseテンプレート投稿フォームの**説明**欄に貼り付けてください。
