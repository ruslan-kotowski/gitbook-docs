Miroverse は、他の Miro ユーザーが作成したボードを発見して使用できるコミュニティー テンプレート ライブラリーです。さまざまなコレクション、役割、ユースケースに対応するテンプレートを見つけて、仕事を始めましょう。

Miroverse には、[Miroverse](https://miro.com/miroverse/) から直接アクセスすることができます、または Miro のダッシュボードからもアクセス可能です。

1. ダッシュボードで**＋新規作成**をクリックします。
2. **Miroverse を見る** を選択。

メインページには人気のテンプレート集、検索バー、およびニーズに合った完璧なボードを見つけるためのカテゴリ一覧が特徴として備わっています。

## テンプレートを探す

このセクションでは、Miroverse でテンプレートを見つける方法として、カテゴリを参照するか検索機能を利用する方法を説明します。

### カテゴリー別にブラウズ

Miroverse のホームページでは、テンプレートをカテゴリ別に参照できます。

1. ページ上部のカテゴリーをクリックして、そのカテゴリーに含まれるすべてのテンプレートを表示します。
2. カテゴリーページから、テンプレートを**最近追加された順**、**使用回数の多い順**、**閲覧回数の多い順**、および**いいねの多い順**で並び替えることができます。

### テンプレートを検索する

検索バーを使って特定のテンプレートを見つけることができます。

1. 検索ボックスに検索語句を入力してください。クエリはテンプレートのタイトル、プロフィール名、または会社名に対して一致するようにマッチングされます。検索結果の一致した用語がハイライト表示されます。
2. カテゴリーページや検索ページから Miroverse のホームページに戻るには、検索バーの横にある **Miro | Miroverse** をクリックしてください。

:::tip
検索結果を共有するには、ブラウザーのアドレスバーに表示された URL をコピーします。
:::

## テンプレートを使用する

テンプレートを気に入ったら、プレビューして新規または既存のボードに追加できます。

1. テンプレートのカードをクリックすると、そのページが開き、コンテンツをプレビューできます。
2. テンプレートページでは、2 つのオプションがあります。
   - 新しいボードをテンプレートから作成するには、**テンプレートを使用**をクリックします。
   - 既に作成したボードにテンプレートを追加するには、**テンプレートを使用**の横にあるドロップダウンメニューをクリックしてボードを選択します。

> Miro プロフィールをお持ちでない場合は、まず無料でサインアップするように求められます。プロフィールをお持ちで、サインインしていない場合は、テンプレートを使用するにはサインインが必要です。

:::tip
よく使うテンプレートにすばやくアクセスするには、ボードを[カスタムテンプレート](https://help.miro.com/hc/articles/360017737473-Custom-templates)として保存します。
:::
