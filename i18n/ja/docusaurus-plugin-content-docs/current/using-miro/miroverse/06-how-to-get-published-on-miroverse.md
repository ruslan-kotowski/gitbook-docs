[Miroverse](https://miro.com/miroverse/) は、Miro ユーザーによって作成されたテンプレートのコミュニティー ライブラリーです。テンプレートとは、繰り返し使用できる活動のために作られたフレームワークを持つ Miro ボードのことです。Miroverse であなたのユニークなワークフロー、プロジェクト、フレームワークを共有することで、他の人にインスピレーションを与え、より早く始める手助けができます。

<iframe frameborder="0" height="315" src="https://www.youtube.com/embed/pcUqCCRp8q8?si=E6lRt8Iil2PbmA01" title="YouTube video player" width="560"></iframe>

:::note
提出する前に、[Miroverse のコンテンツガイドライン](08-miroverse-publishing-checklist-and-guidelines.md)を訪れて、提出内容がすべての公開基準を満たしているかどうかご確認ください。
:::

:::tip
[Creator Toolbox](https://miro.com/miroverse/creators/) では、Miroverse 公開についてのヒントやリソースをさらにご覧いただけます。[クリエイターコミュニティー](https://miro.com/miro-creators/)やイベントにもアクセスできます。
:::

## テンプレートの投稿方法

ボードを[Miroverse](https://miro.com/miroverse/)で公開するには:

1. [Miroverse](https://miro.com/miroverse/) サイトに移動します。
2. Miro の登録プロフィールでログインしてください。
3. Miroverse の任意のページの右上隅にある**テンプレートを投稿**をクリックして、投稿フォームを開きます。
4. すでに Miroverse のプロフィールをお持ちでない場合は、テンプレートを投稿するためにプロフィールを作成する必要があります。写真、役職、会社名、簡単な自己紹介を追加します。
5. クリック **保存して続行します**。
6. **選択してください**、**ボードを**ドロップダウンを使用して、テンプレートとして提出したいボードを選択します。自分が所有するボードのみがドロップダウンリストに表示されます。
7. クリック **続ける**。

:::note
Starter、Business、Enterprise、Education プランをご利用の場合は、[ボードにアクセスできる全員にボードコンテンツのコピーを許可してください](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)。
:::

8. **テンプレートのタイトル**を入力してください。 テンプレートの公開名です。目的を明確に説明する、明確でわかりやすいタイトルを選びましょう。
9. 使用例に基づいて、テンプレートに関連する**カテゴリー**を 3 つまで選択します。
10. 主な**役割**または機能（エンジニアリング、製品など）をボードに選択してください。完全に一致するものがない場合は、最も近いものを選んでください。
11. **テンプレートの説明**を記入します。 テンプレートについて、使い方、対象者、ヒントやベストプラクティスなどのセクションを含めてください。説明欄の書式ツールバーを使用して、セクションヘッダー（H1、H2）、箇条書き、番号付きリスト、その他の書式を追加し、コンテンツを読みやすく、ナビゲートしやすくします。詳しくは、[Miroverse テンプレート説明文の書き方](10-tips-for-writing-a-miroverse-template-description.md)をご覧ください。
12. カバー画像を**追加**します。 テンプレートの最も魅力的な部分のスクリーンショット（最大サイズ 1080x480px）をアップロードしてください。
13. （オプション）**動画説明**を追加してください。[Talktrack](../facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md) を追加して、テンプレートの使い方を音声と動画で視覚的に説明・実演しましょう。YouTube、Loom、Wistia のリンクを追加することもできます。![Step_2__Describe_the_template.jpg](../../../../../../docs/using-miro/miroverse/images/21019734910866_Step%202_%20Describe%20the%20template.jpg)*テンプレートの詳細を追加*
14. （オプション）**プレビュー**をクリックして、レビューに提出する前にテンプレートを閲覧します。
15. フォームが完了したら**送信**をクリックしてください。

Miroverse の審査チームがテンプレートをレビューします。通常、最大で 2 営業日かかります。チームはテンプレートが[公開基準とガイドライン](08-miroverse-publishing-checklist-and-guidelines.md)に適合している場合には公開を行い、そうでない場合には公開準備が整うようにフィードバックをお送りします。Miroverse のプロフィールに関連付けられたメールアドレスで、アップデートを受け取ります。

:::note
お手続きについてご不明な点がございましたら、[miroverse@miro.com](mailto:miroverse@miro.com) にいる Miroverse チームまでお問い合わせいただくか、提出ステータス関連のメールに直接ご返信ください。
:::

## フォーマットのテンプレートの提出

複数の要素を持つボードテンプレートに加えて、単一のドキュメント、テーブル、タイムライン、図、またはスライドを含む[フォーマット](../formats/02-formats-focus-modes.md)テンプレートを提出することもできます。これらの集中した単一のツールは、チームがより大きなフレームワークの構成要素として、またはそれ自体で使用するのに最適です。

### 形式を作成し、提出する

1. Miro でフォーマットを作成
   1. ボードを開き、ツールバーの**ツール、メディア、インテグレーション**アイコン（**+**）をクリックします。
   2. 使用するフォーマットを検索して選択します。ドキュメント、テーブル、タイムライン、ダイアグラム、またはスライド。
   3. キャンバス上の任意の場所をクリックして、フォーマットを追加します。
   4. フォーマットをカスタマイズしてテンプレートを作成しましょう。
2. フォーカスモードをデフォルト表示に設定
   1. コンテキストメニューで**三点リーダー** (![icon-main.svg](../../../../../../docs/using-miro/miroverse/images/28308876333970_icon-main.svg)) アイコンをクリックします。
   2. **デフォルト閲覧に設定**を選択します。![](../../../../../../docs/using-miro/miroverse/images/28020475735954_9bddcb20-38ba-4a25-b33c-f7d59a42609f.png)
      *デフォルト表示に設定*
3. [テンプレート提出フォーム](https://miro.com/miroverse/submission/)を使って、フォーマットをコミュニティーと共有しましょう。

## 下書きとテンプレートの編集、プレビュー、削除方法

提出内容の変更は、すべて自動的に保存されます。提出フォームを終了するには、提出の準備ができていない場合は、左上の **終了** または **Miroverse ロゴ** をクリックしてください。テンプレートは、プロフィールページに下書きとして保存され、自分だけに表示されます。提出したコンテンツは、Miroverse プロフィールの下書きからいつでも確認できます。

必要に応じて[編集](05-how-to-edit-your-templates-on-miroverse.md)、**プレビュー**、または**ドラフトの削除**を行ってください。

1. Miroverse のプロフィールページに移動する。
2. テンプレートボックスの右上にある**三点リーダー**（**...**）アイコンをクリックします。
3. 実行したいアクションを選択してください (**編集**、**プレビュー**、または **削除**)。

:::note
プロセスに関する質問がある場合は、投稿状況のメールに返信することで投稿チームに連絡することができます。
:::

### よくある質問

**テンプレートのプレビューを調整する方法を教えてください。**

[開始画面](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)をボード用に設定してから、投稿フォームにアップロードしてください。公開後にプレビューを調整するには、編集モードで調整された開始画面を設定した新しいボードをアップロードする必要があります。

**Talktrack をテンプレートに追加する方法を教えてください。**

提出したいボードで[Talktrack](../facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md)を録音してください。Talktrack は自動的にテンプレートに追加され、テンプレートには Talktrack があることを示す特別なタグが付きます。

**Miroverse に投稿した後、ボードを削除することはできますか？**

公開後にユーザー全員がボードを利用できるようにするため、投稿の際にボードのコピーが作成されます。いったん Miroverse に投稿したバージョンを削除することはできますが、編集が必要となる場合に備えて、テンプレートが公開された後のみに削除することをお勧めします。

**Miroverse からテンプレートを削除するにはどうすればよいですか？**

Miroverse から公開したテンプレートを削除するには、Miroverse チーム[miroverse@miro.com](mailto:miroverse@miro.com)までご連絡ください。テンプレートを削除しても、すでに作成されたボードのコピーには影響しません。テンプレートを削除する前にコピーを作成したユーザーは、引き続きそのコピーにアクセスし、編集することができます。

**テンプレートのコメントはどうなりましたか？**

テンプレートが Miroverse に投稿されると、関連するコメントは削除され、新しい体験が提供されます。コメントはテンプレートのボードからは削除されず、テンプレート自体からのみ削除されます。

**テンプレート作成時のアクセシビリティーへのアプローチ方法は？**

Miro はすべてのユーザーにとって包摂的な体験を創出することを目指しています。Miroverse、コミュニティー駆動のスペースでは、ユーザーが作成したテンプレートをホストしています。クリエイターはコンテンツの所有権を保持し、その内容に責任を持ち、法令およびオーディエンスのニーズに準拠することを保証します。アクセシビリティーは必須ではありませんが、より広く利用できるように[インクルーシブデザイン](../../getting-started/accessibility-in-miro/04-how-to-make-your-miro-boards-more-accessible.md)を推奨しています。

Miroverse への提出に際し、クリエイターは以下に同意します：

- 彼らのコンテンツは公開されており、Miro によって定期的に監視されていません。
- Miro は、提出物のアクセシビリティまたは正確性に責任を負いません。

Miro のコア製品におけるアクセシビリティへの取り組みについては[こちら](https://miro.com/accessibility/)をご覧ください。また、アクセシビリティ機能の[詳細な概要](../../getting-started/accessibility-in-miro/01-overview-of-miro-accessibility.md)をヘルプセンターで探索してください。
