ダッシュボードまたはボードの情報ウィンドウからボードを複製できます。

> **利用可能な環境：**ブラウザー版（デスクトップ、タブレット）、デスクトップアプリ、タブレットアプリ
> **設定者：**無料プランのボードではチームメンバー
> Starter[、](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md) Business、 Enterprise、および Education プランの ボードの場合 - ボードのコンテンツ設定でボードの複製が許可されているユーザー

### Miro のボードの複製方法

ボード自体の中からボードを複製するには：

1. 左上のツールバーの**メインメニュー**alt（alt![icon-main.svg](../../../../../../docs/using-miro/managing-boards/images/22781142146322_icon-main.svg)）アイコンをクリックします。
2. **ボードの**サブメニューをクリックします。
3. **複製を**クリックします。
   ダイアログが開きます。
4. 新しいボード名を入力し、複製したボードの共有設定を保持するかどうかを選択し、[**コピー]**をクリックします。

あるいは、ボードの詳細ダイアログからボードを複製することもできます：

1. 左上のツールバーの**メインメニュー**alt（alt![icon-main.svg](../../../../../../docs/using-miro/managing-boards/images/22781142146322_icon-main.svg)）アイコンをクリックします。
2. **ボードの**サブメニューをクリックします。
3. **詳細を**クリックしてください。
   ダイアログが開きます。
4. 一番下の「**複製」**ボタンをクリックします。
   ダイアログが開きます。
5. 新しいボード名を入力し、複製したボードの共有設定を保持するかどうかを選択し、[**コピー]**をクリックします。

:::note
[ユーザーがボードを複製すると、Talktrack も新しいボードに複製されます。](../facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md)
:::

> ️️**[✏️](../sharing-boards/07-collaboration-with-guests.md)** ボードの[ゲスト](../../enterprise-administration/enterprise-subscription-management/enterprise-licensing/04-free-restricted-license.md)になっていて、他の Miro のチームにメンバーがいない場合や、制限付き無料ライセンスが付与されている場合、ボードのコピーを保存するために、新しい Miro チームを作成することをお勧めします。

ダッシュボードからボードを複製するには：

1. 削除されたボードのサムネイル上にマウスオーバーすると、
2. **三点**リーダー（**..**.）メニューアイコンをクリックします。
3. **複製を**クリックします。
   ダイアログが開きます。
4. 新しいボード名を入力し、複製したボードの共有設定を保持するかどうかを選択し、[**コピー]**をクリックします。

:::warning
ボード名の最大文字数は 61 文字です。ボードを複製する場合、ボード名に「...のコピー」が追加されます。文字数が多すぎる場合、ボードは複製されません。ボード名を短くし、もう一度複製してください。
:::

## よくある質問

1. *ボードのコピー内容を変更した場合、元のボードに影響はありますか？*
   - いいえ、コピーの内容は元のボードの内容とは連携されていません。
2. *ボードのコンテンツを別の既存のボードに複製するにはどうすればよいですか？*
   [- 必要な内容](../working-on-the-board/10-working-with-objects.md)を選択してコピーし、別のボードに貼り付けてください（*Windows の場合は* **Ctrl+C/Ctrl+V**、*Mac の場合は* **Cmd+C/Cmd+V** を使用できます）。
3. *複数のボードをまとめて複製できますか？*
   - いいえ、現時点ではできません。
4. *自分のボードをテンプレートとして他のユーザーと共有し、相手のチームに複製することはできますか？*
   - はい、[ボードのコンテンツ設定](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)で許可されていることを確認してください。
