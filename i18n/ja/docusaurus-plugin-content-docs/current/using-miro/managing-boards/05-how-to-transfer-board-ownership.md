Miro のボード所有者は、素早く簡単に他のチームメンバーにボードの所有権を譲渡することができます。

> **実行可能なユーザー**：ボード所有者、[コンテンツ管理者の役割が有効になっている](../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md) Enterprise プランの会社メンバー
> **実行可能なソフトウェア**：ブラウザー、[デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)、[タブレットアプリ](../../getting-started/apps-for-devices/11-tablet-app.md)

### ボードを別のユーザーに再割り当てする方法

:::warning
所有権の譲渡が完了すると、これを取り消すことはできません。
:::

1. 新しい所有者がボードに招待されていない場合は、メールや Slack でボードを共有してください。ボードの **[共有]** ダイアログを開き、ユーザーのメールアドレスを入力して、**[送信]** をクリックします。
   ![share_via_email__1_.gif](images/22250029728914_share%20via%20email%20(1).gif)
   *Miro のボードにユーザーを招待*

2. ボードの **[共有]** ダイアログの **[共有設定]** をクリックします。
3. 名前の横にある **[所有者]** を選択し、**[所有権を変更]** をクリックして承認します。
   ![change_board_owner.gif](../../../../../../docs/using-miro/managing-boards/images/21017043185042_change%20board%20owner.gif)
   *ボードの所有権を別のチームメンバーへ譲渡*

:::warning
️ ボードの再割り当ては、そのボードが所属しているチームのメンバーにのみ行うことができます。ユーザーがチームのメンバーではない場合は、招待するか、Miro の管理者に招待リクエストを送信する必要があります。
:::

### ボード所有者が会社を退職した場合

Miro のチームメンバーがいなくなり、そのメンバーのボードの所有権を取得する必要がある場合は、チームの管理者に連絡してください。

管理者はチームやサブスクリプションからユーザーを削除し、そのコンテンツを別のメンバーや自分自身に再割り当てすることができます。管理者が [Enterprise プランでユーザーを削除する方法](../../enterprise-administration/user-management/10-remove-users-on-enterprise-plan.md)や、[他のすべての Miro プランの](../../administration/user-management/08-remove-users.md)ユーザーを削除する方法をご覧ください。

[コンテンツ管理者の役割](../../enterprise-administration/managing-enterprise-teams-and-content/12-content-admin-permissions.md)が有効になっている Enterprise プランの会社のメンバーは、上記のガイドを実行して、ボードを別のユーザーに再割り当てすることができます。
