**紛失または削除された Miro ボードを復元しましょう。ボードは削除後 9****0 日****以内は復元が可能です。**

:::tip
[ボードのバックアップを保存](../import-and-export/export/05-how-to-save-board-backup.md)することで、ボードを保護することができます。
:::

## ボードのリンクを使用して削除したボードを復元

> **実行可能なユーザー：**ボード所有者
>
> **関連プラン：**すべてのプラン
>
> **利用可能な環境：**ブラウザー

### リンクを使用してボードを復元する方法

誤ってボードを削除してしまったり、ボードが消えてしまった場合、ボードのリンクから復元することが可能です。

Miro のボードリンクの例

```
https://miro.com/app/board/o9L_kSnC_0=/
```

以下で、ボード名を入力してボードリンクを検索してみます。

- ブラウザーのアドレスバー
- ブラウザーの履歴検索
- メール検索

![searcing_for_a_Miro_board_in_your_browser.gif](../../../../../../docs/using-miro/managing-boards/images/21017515436050_searcing%20for%20a%20Miro%20board%20in%20your%20browser.gif)*Miro ボードの検索*

リンクを見つけたら、ブラウザーで開きます。ボードが削除されましたというメッセージが表示されます。

![board_deleted_modal.jpg](../../../../../../docs/using-miro/managing-boards/images/21017515434258_board%20deleted%20modal.jpg)
*ボードが削除されましたというメッセージ*

**[ボードを復元する]** をクリックすると Miro のダッシュボードにリダイレクトされます。そこで復元されたボードを開くことができます。

![restoring_a_Miro_board_via_link.gif](../../../../../../docs/using-miro/managing-boards/images/21017528446354_restoring%20a%20Miro%20board%20via%20link.gif)*ボードのリンクを使用して削除したボードを復元*

## ゴミ箱からボードを復元

> **実行可能なユーザー：**ボード所有者
>
> **関連プラン：**Starter、Business、Enterprise、Education プラン
>
> **利用可能な環境：****ブラウザー、**デスクトップアプリ、タブレットアプリ

### ゴミ箱の機能はどこで見つけることができますか

[ゴミ箱の機能](../../getting-started/start-here/miro-dashboard/01-what-is-on-your-dashboard.md)は有料プランと Education プランのみで利用可能です。Free プランをご利用の場合は、[ボードのリンクを使用してボードを復元する](08-how-to-restore-a-deleted-board.md)ことができます。

ユーザーはゴミ箱の中身をチェックし、最近削除されたボードを復元することができます。**ゴミ箱**は、[ダッシュボード](../../getting-started/start-here/miro-dashboard/01-what-is-on-your-dashboard.md)の右上にあるアバターをクリックすると見つけることができます。

![trash.png](../../../../../../docs/using-miro/managing-boards/images/23122133552402_trash.png)
*ゴミ箱のアイコン*

### ゴミ箱からボードを復元する方法

1. ダッシュボードの右上にあるアバターをクリックして、**ゴミ箱**を開くと、削除されたボードが表示されます。
2. 関連するボードの横にある**三点リーダー**（**...**）メニューをクリックすると、**復元**するオプションが表示されます。
3. **[復元]** をクリックします。
4. ボードは、元の所有者とチームに戻されます。

![trash-restore.png](../../../../../../docs/using-miro/managing-boards/images/23122118937362_trash-restore.png)
*ゴミ箱からボードを復元*

## 過去のユーザーからのボードを復元

ユーザーがチームから削除され、そのユーザーのボードも削除された場合、Miro の管理者に復元依頼をしてください。ゴミ箱内の削除されたボードを確認し、**削除後 90 日以内に****ボードを復元**できます。 管理者が、復元されたボードの所有者となります。

:::note
チームを削除する前に、必ず[ボードをエクスポート](../import-and-export/export/03-how-to-export-your-board.md)するか、[ボードのバックアップを保存](../import-and-export/export/05-how-to-save-board-backup.md)してください。
:::

## よくある質問

**ボードを紛失しました。どうすればよいですか？**

[Miro のボードやコンテンツを紛失した](../tools/troubleshooting/11-i-lost-my-board-or-content.md)場合の記事をご覧ください。

**ボード上のコンテンツを削除してしまいました。復元できますか？**

はい、誤って削除してしまったコンテンツは探し出して、復元することができます。「[ボードコンテンツの復元](../working-on-the-board/18-restoring-board-content.md)」の記事で詳細をご覧ください。
