### Miro のボードを退出する方法

ボードを退出するオプションは、*有料チームと教育チーム*で利用できます。無料プランはボードのプライバシー機能をサポートしていないため、無料チームのメンバーはお互いのボードを退出することは*できません*。無料チームのボードから退出したい場合は、そのチームから退出することができます。

招待されたボードから退出する場合は、以下の手順に従います。

1. ダッシュボードで退出するボードを見つけます。
2. 三点リーダーをクリックして **[ボードを離れる]** を選択します。
3. この操作は取り消すことができないという警告メッセージが表示されます。
4. **[離れる]** をクリックすると、ボードへのアクセスは失われ、[ダッシュボード](https://miro.com/app/dashboard/)にも表示されなくなります。

## よくある質問

1. ***[ボードを離れる]** ボタンをクリックしたのに、ボードがダッシュボードに表示されます。*なぜですか？
   [なぜですか？](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) ー そのボードの共有設定が、チーム全体で共有するになっています（この設定を無効または有効にする方法については、こちらをご覧ください）。
2. ***ボードを離れる**ボタンがありません。*
   - ボードが[無料チームに属して](../../plans-billing/miro-plans/09-free-plan.md)いる場合、ボードプライバシーは無料プランでは利用できないため、デフォルトでチームと共有されます。[チームのアカウントをアップグレード](../../plans-billing/manage-your-subscription-and-plan/03-upgrade-your-plan.md)すれば、自分だけの非公開ボードを作成することができます。ダッシュボードでは、ボードを所有者ごとに並び替えることも可能です（方法については、[こちら](../../getting-started/start-here/miro-dashboard/01-what-is-on-your-dashboard.md)をご覧ください）。フリーチームのボードにアクセスしたくない場合は、[チームを去る](../managing-your-profile/06-how-to-leave-a-team.md)ことができます。

   ボードが有料チームに属しているにもかかわらず、そのボードから退出するオプションが表示されない場合は、（ボードを共有する権限を持っている場合）あなたの電子メールをボードに招待してから、そのボードから退出してみてください。

   あなたがボードのオーナーである場合、代わりに**削除**ボタンが表示されます。
3. *私はボードのオーナーですが、自分のボードを削除するつもりはありません。どうすればいいですか？
   -*作成したボードを離れるには、まず所有権を移す必要があります。ボードの所有者が所有権を移譲する方法については、こちらの便利な記事をご覧ください。
4. *Miro ボードに招待されましたが、自分のチームを持ちたいと思います。*どうすればいいですか？
   - チームに追加されずに特定のボードに招待され、[ダッシュボードに](https://miro.com/app/dashboard/)他のチームがない場合は、そのボードから離れる必要があります。利用可能なボードやチームがない場合、Miroは独自のチームを作成するよう提案します。もしあなたがメンバーとしてチームに招かれたのであれば、チーム全体を去らなければなりません。チームを退出する方法についてはこちらの記事をご覧ください。
5. *チーム管理者ですが、他のユーザーのボードを削除したり移動したりすることができません。*どうすればよいですか？
   -ボードの[削除や](07-how-to-delete-a-board.md) [移動が](04-how-to-move-a-board.md)できるのは、ボードのオーナーだけです。この場合、ボードの所有権をチームから削除します。ー ボードの所有者は、他のユーザーとボードを一緒に削除できます。
6. *ボードを自分の非公開のスペースに移動さたいと思います。*どうすればいいですか？
