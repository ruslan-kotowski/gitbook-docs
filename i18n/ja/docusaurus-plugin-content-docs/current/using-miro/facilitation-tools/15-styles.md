スタイルを使用すると、誰でもプロフェッショナルな雰囲気の視覚的に魅力的なプレゼンテーションやボードを作成できます。バリエーション豊富な 14 色のカラーパレットから選択できます。

- ボード全体を簡単にスタイリング可能
- オーディエンスのために洗練された作品を作成
- フォーマットに費やす時間を短縮

> **利用可能なプラン：** Free、Starter、Business、Enterprise、Education プラン

## スタイルの使用

### フレームにスタイルを適用する方法

1. ボード上でフレーム（一つまたは複数）を選択します。
2. コンテキストメニューが開きます。
3. **スタイル**アイコンをクリックします。
4. スタイルパネルが開きます。
5. 既定のスタイルまたはカスタム[ブランドスタイル](../../administration/get-started-as-a-miro-admin/04-brand-center.md)を選択します**。**
6. 選択したスタイルは、フレームとフレーム内のオブジェクトに適用されます。

![Applying-styles-to-frames.gif](../../../../../../docs/using-miro/facilitation-tools/images/21016020643090_Applying-styles-to-frames.gif)
*選択したフレームへのスタイル適用*

### さまざまなスタイル バリエーションの適用

複数のスタイルバリエーションを探ることができます。再度**スタイル**パネルを開き、**最近使用**の隣でスタイルにマウスを重ね、**シャッフル**をクリックします。 スタイルの色が新しい順序で表示されます。

![Trying-different-style-options-with-shuffle.gif](../../../../../../docs/using-miro/facilitation-tools/images/21016020640914_Trying-different-style-options-with-shuffle.gif)
*異なるスタイルバリエーションの適用*

:::note
万人に向けたコンテンツ利用を期するため、一部のブランドカラーを調整することがあります。これらの変更は、すべてのユーザーに最適な体験を提供できるようユーザビリティーを優先するため、アクセシビリティー基準に沿ったものです。
:::

## スタイルのリセット

不要な変更を簡単に元に戻し、ボードの元のスタイルを復元できます。**スタイル**パネルを開き、**適用したスタイル**の隣で**スタイルを削除**をクリックします。

![Remove-a-style.png](../../../../../../docs/using-miro/facilitation-tools/images/21016020644626_Remove-a-style.png)
*以前に適用したスタイルを削除するオプション*
