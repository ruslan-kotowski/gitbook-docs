議論したオプションやアイデアのうち、チームでどれを採用するか素早く決定したいと思ったことはありませんか？Miro の投票ツールを使えば、ボードで投票セッションを実施することができます。

> **利用可能なプラン：**Starter、Business、Enterprise、Education
> **利用可能な環境：**ブラウザー版、[デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)、[タブレットアプリ](../../getting-started/apps-for-devices/11-tablet-app.md)
> **設定者：**ボードの編集権限を持つチームメンバー。すべてのユーザーが投票に参加できます。

### 投票セッションの設定

このツールはコラボレーションツールバーの右上、**ファシリテーションツールとリアクションの**アイコンの下にあります。

![投票エントリーポイント.pngV](../../../../../../docs/using-miro/facilitation-tools/images/21537451582994_voting-entry-point.png)*コラボレーションツールバーの投票アイコン*

> ️️️️✏️  投票が利用できない場合は、有料チームか Education チームにボードが保存されていることを確認してください。

投票パネルがボードの右側に表示されます。そこで投票の設定ができ、ほとんどがオプションです。セッションを開始する前に以下のことを行います。

- 参加者に投票してもらいたいオブジェクトを、投票エリアを設定して定義します。投票してもらいたいオブジェクトを素早くフィルターにかけ、付箋などのサブカテゴリーを選択します。
- **+** と **-** ボタンを使用するか数字を入力し、一人当たりの投票数を設定します（投票は匿名で、最大投票数は 99 票です）
- **+** と **-** ボタンを使用するか数字を入力し、投票セッションの期間を設定します。単位は分、時間、日数から選ぶことができます。
- 参加者の投票数をオブジェクトごとに 1 票のみとする場合は、該当するトグル（オプション）を有効にします。

設定がすべて完了したら、**[スタート]** をクリックします。

![voting_setup.jpg](../../../../../../docs/using-miro/facilitation-tools/images/21017042464914_voting%20setup.jpg)*投票セッションの設定*

また、投票セッションを設定し、保存して後で使用することもできます。通常通り投票セッションを設定しますが、「**開始**」をクリックする代わりに、「**ボードに追加**」をクリックします。

### 投票の実行中

設定者本人やボードのコラボレーターは、セッションに参加することも、それを見送ることもできます。投票を設定するとすぐに、ボード参加者（登録ユーザーと非登録ユーザーを含む）には、投票セッションが開始されたことを通知するポップアップが表示され、投票までの時間が知らされます。

ユーザーが誤って投票をスキップした場合、右ツールバーの上にある投票アイコンをクリックすると参加することができます。アイコンには残り時間が表示されます。

セッションに参加するユーザーは、オブジェクトの横にあるプラス アイコンをクリックすると、オブジェクトに投票することができます。投票はすべて**匿名**です。参加者は、**[終了]** をクリックして投票の完了を知らせることができます。参加者は、[**参加者**] をクリックすると、他のユーザーの進捗状況（誰が投票を完了したか）を確認することができます。

![投票中.png投票](../../../../../../docs/using-miro/facilitation-tools/images/21537435599250_voting-in-progress.png)
*セッション*

選択したオブジェクトのプラスとマイナスのアイコンをクリックすると、投票セッション中に投票を変更することができます。投票パネルを閉じた場合は、ツールバーの投票ボタンをクリックすると、投票に再度参加できます。

### ファシリテーター向けの機能

投票の作成者は、ボードの右上で投票の進捗状況を見ることができます。[**参加者**] をクリックして、一人当たりの投票数と参加者が投票を終えたかどうかを確認します。また、それぞれの機能のボタンをクリックすれば、いつでも**投票セッションを終了**する、または投票時間を延長できます。

現在の投票セッションをリセットする必要がある場合は、セッションを終了し、新しい投票セッションを開始します。

### 投票結果

セッションが終了すると、投票参加者には上位 3 つの結果が表示され、**[結果をすべて表示]** ボタンをクリックすることができます。

**結果をすべて表示**をクリックすると 、投票パネルにセッション結果の一覧が表示されます。投票履歴や他のセッションの結果は、該当するタブから見ることができます。また、**結果**タブのトグルを使って、投票結果をボードに表示し続けるかどうかを選択することもできます。

![投票結果キープ.png](../../../../../../docs/using-miro/facilitation-tools/images/21537451600658_voting-results-keep.png)

投票セッションの名前を変更したり、投票結果を削除するには、セッションを開いて対応するアイコンをクリックします。

## よくある質問

1. *投票結果をエクスポートできますか？*
   - 投票結果をエクスポートするオプションはありませんが、代わりにスクリーンショットを撮ることができます。
2. *誰が投票セッションに参加できますか？*
   - ボード上にいる全ユーザーが参加できます。
3. *ボード編集者ですが、投票セッションを開始できません。なぜですか？*
   — ボードのゲストや編集権限のあるビジターは投票セッションを開始できません。編集権限のあるチームのメンバーだけが投票を設定できます。
4. *[ボードを複製](../managing-boards/03-how-to-duplicate-a-board.md)した場合、投票セッションの結果は複製ボードに保存されますか？*
   - いいえ、保存されません。
5. *テキストボックス内の単語や文章単位で投票できるようにするにはどうすればよいですか？*
   - 投票できるのは、テキストボックス全体に対してとなります。ボックス内の個別の単語や文章に対しての投票がほしい場合は、対象の単語や文章ごとにテキストボックスを作成してください。
6. *ドット投票ツールはありますか？*
   - テンプレートライブラリから[このテンプレート](https://miro.com/templates/dot-voting/)を使用するか、[テンプレートピッカー](../../getting-started/start-here/your-first-board/04-templates.md)からテンプレートを追加してみてください。
