Consultant プランのボードの所有者と共同所有者は、[タイマー](16-timer.md)、[投票](19-voting.md)、[ビデオチャット](18-video-chat.md)を起動でき、ボード上の[アテンション管理](04-attention-management.md)機能を使用できるユーザーを設定することで、ボードのコラボレーション ツールの使用状況を管理できます。これにより、会議ファシリテーターのキットへのアクセス権を持つユーザーグループを定義することができます。選択したユーザーのみがこれらのコラボレーション ツールを起動することができますが、他のボードの参加者はこれらのツールを使用することはできます。例えば、ボードの所有者は投票を起動して、会議の参加者全員が投票できるようにします。

ボードの **[共有]** メニューを開き、**[共有設定]** に移動し、[管理者権限] タブに**切り替え、**[コラボレーション ツールの起動者] **の下に表示されるドロップダウン メニューでオプションを選択します**。これをすべての編集者（リンクによるビジターを除く）、またはボードの所有者と共同所有者のみに許可することができます。
