Miro グループ フレームは、ボード上でグループのアクティビティーを準備して実施するのに役立ちます。参加者を少人数のグループに分け、特定のタスクを割り当てて参加を促します。グループフレームを活用すれば、参加者を個別のバーチャル コラボレーション空間に招待して、参加者同士をつなげる有意義な時間を提供できます。

> **利用可能なユーザー**：Business、Education、Enterprise プランの一部のユーザー
> **設定者**：ボードの所有者、ボードの共同所有者（編集者が参加可能）

### グループフレームの設定方法

グループフレームは、作成ツールバーから開きます。

1. [作成] バーで [**ツール、メディア、インテグレーション**（**+**）] を選択します。[**ツール、メディア、インテグレーション**] パネルが開きます。
2. **[ツール]** タブで、「Breakout frames」（グループフレーム）を検索して選択します。
   **グループフレーム**パネルが開きます。

グループフレームを追加するには、[pick a frame]（フレームを選択）ボタンをクリックするか、**[Create breakout frames]（グループフレームを作成する）**をクリックします。フレームへのリンクの追加は後で行います。

ボードのフレームを選択する方法では、コンテンツが同じ複数のフレームを簡単に作成できます。ボードのフレームを 1 つ選択して、ドロップダウン メニューでフレーム数を選び、青い **[Create breakout frames]**（グループフレームを作成する）ボタンをクリックします。元のフレームの隣に同じコンテンツのフレームが作成され、それらのフレームは自動的にグループフレームにリンクされます。

グループフレーム パネルでは、フレームとグループフレームとのリンクの接続、切断を行い、グループフレームに参加者を割り当てることができます。各ユーザーを割り当てられるのは、1 つのグループフレームだけです。なお、グループフレームに割り当てることができるのは、現在**ログインしていてボード上にいる**ユーザーのみです。

グループフレームの名前の変更、グループフレームの削除、新規のグレープフレームの追加も行うことができます。新規のグループフレームを追加するには、プラスボタンをクリックします。1 回のグループフレーム セッションで作成できるグループフレームの数は最大 **100** 件です。制限に達すると、新しいグループフレームを作成できなくなり、ホバーした際にツールチップが表示されます。

![changing_breakouts.gif](../../../../../../docs/using-miro/facilitation-tools/images/21017653371410_changing%20breakouts.gif)*フレームの名前変更と新規フレームの追加*

**[Lock participants to linked frame]**（参加者をリンク先のフレームにロックする）のトグルは、デフォルトで無効になっています。有効にすると、グループフレームに参加したユーザーは、他のフレームに移動できなくなります。この設定を無効にすると、参加者はグループフレーム セッションの実施中も、ボード上の他のフレームに自由に移動することができます。

**[Start]（スタート）**をクリックしてセッションを開始します。

> **✏️** なお、Miro のグループフレームは、今のところテレビ会議グループと接続することはできません。しかしながら、将来的にはこれに対応していきます。Zoom と Miro グループフレームを併用する方法については、こちらをご覧ください。

### ボード参加者用の機能

グループフレームのセッションを開始すると、ボードの参加者には、ボードの右側にパネルが表示されます。フレームに割り当てられたユーザーは、そのフレームにリダイレクトされます。その他のユーザーは、希望するグループフレームに参加できます。

参加者は、セッションの途中で自分のフレームを離れ、他のフレームに参加できます。

![leaving_and_joining_breakouts.gif](../../../../../../docs/using-miro/facilitation-tools/images/21017653372690_leaving%20and%20joining%20breakouts.gif)*グループフレームの退出と参加*

> **✏️** 参加者の画面が参加しているグループのフレームにロックされている場合、フレームとつながっているグループフレームを退出しない限り、*そのフレームから退出することはできません。*

セッションの実施中、進行役は各フレームの参加者の数やアバターを確認し、ユーザーを特定のフレームに割り当てることができます。セッションを停止して参加者をグループフレームから退出させるには、該当のボタンをクリックします。

breakout_frames_presenter_view.jpg![](../../../../../../docs/using-miro/facilitation-tools/images/21017683014162_breakout_frames_presenter_view.jpg)*進行役から見たグループセッションの表示*

### プレゼンテーションでグループフレームを使用する

Miro の会議またはプレゼンテーションの特定のスライドにグループフレーム アクティビティーを事前に追加して、保存します。

### グループフレームをテンプレートとして保存する方法

ボードをテンプレートとして保存すると、ボード上のグループフレームも自動的にテンプレートと一緒に保存されます。保存しておいた[カスタムテンプレート](../../getting-started/start-here/your-first-board/04-templates.md)を後で使えば、ボードの参加者に同じグループフレームの体験を提供できます。

### Miro グループフレームと Zoom グループルームの併用

Miro グループと Zoom グループを併用することで、チームの意思決定プロセスを加速させることができます。

1. Miro でグループフレームのコンテンツを準備してから、グループとフレームをリンクします。
2. Zoom でグループフレームを開始し、参加者をルームに割り当てます。
3. Zoom と Miro の部屋の数が同じであることを確認します。Miro のフレームは必要に応じて簡単に追加 / 削除できます。
4. Miro でグループフレームを開始し、Zoom で割り当てられたルームと同じグループに参加するよう参加者に依頼します。こうすることで、両方のアプリケーションに各参加者を手動で割り当てる手間を省くことができます。すべてのグループを監視して、支援が必要なユーザーがいれば、グループの割り当てを手動で調整することも可能です。
