Miro の**タイマー**は、リアルタイムにホワイトボードでセッションを実行する際の時間管理に便利です。チームメンバー、グループリーダー、または単なる個人的なプロジェクトを、期限に間に合うように管理したい場合でも、Miro のタイマーは、最も貴重なリソースを管理することで、生産性を向上させます。

> **利用可能なプラン：**Starter、Business、Enterprise、Education
> **設定者**：[電子メールで](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)明示的にボードに招待された編集者  、または  Miro の スペースや [チームの](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) 一員であるためにボードにアクセスできる 編集者 。すべての登録ユーザー（閲覧者、コメント投稿者、編集者）および[編集アクセス権を持つ未登録のビジター](../sharing-boards/08-collaboration-with-visitors.md)は、ボード上で作動中のタイマーを確認できます。

### タイマーの使用

タイマーはボードの右上にあるコラボレーション ツールバーの**進行ツールとリアクション**のアイコンの中にあります。

![timer-entry-point.png](../../../../../../docs/using-miro/facilitation-tools/images/21537453089298_timer-entry-point.png)
*コラボレーション ツールバーのタイマーボタン*

タイマーボタンからタイマーを開き、時間を入力するか、**＋** または  **−** をクリックして時間を設定し、青い再生ボタンで開始します。

タイマーはカウントダウン中、停止、一時停止、タイマーにさらに時間を追加する機能が備わっています。**+1m** または **+5m** ボタンをクリックして、カウントダウンの時間を追加します。

タイマーを一時停止するには、該当するボタンをクリックします。

タイマーを停止し、必要に応じて時間をリセットするには、停止ボタンをクリックします。

このオプションは、タイマーを開始したユーザーだけでなく、[電子メールで](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)明示的にボードに招待された  、または Miroの スペースや [チームの](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) 一員であるためにボードにアクセスできる他のボード編集 者も利用できます 。

ボード上の全員のタイマーが開始し、終了します。タイマーを最小化することができ、ツールバー アイコンに残り時間が常時表示されます。

時間が経過すると、すべてのコラボレーターに視覚的な通知とチャイムで通知されます。

### 内蔵音楽プレーヤー：タイマーで音楽を再生

タイマーを設定する際に、カウントダウンの間、著作権使用料無料の音楽リストから選択するオプションがあります。

![timer-music.png](../../../../../../docs/using-miro/facilitation-tools/images/21537453098898_timer-music.png)
*タイマーがオンの間の音楽を選択*

再生中にミュートすることもできます。

*![timer-mute.png](../../../../../../docs/using-miro/facilitation-tools/images/21537453104530_timer-mute.png)
タイマー音楽をミュートするオプション*

## よくある質問

**タイマーアイコンがコラボレーション ツールバーに表示されません。なぜですか？**

タイマーは[閲覧者](../sharing-boards/01-board-access-rights.md)、[コメント投稿者](../sharing-boards/01-board-access-rights.md)、[ビジター](../sharing-boards/08-collaboration-with-visitors.md)には*設定できず*、[無料チーム](../../plans-billing/miro-plans/09-free-plan.md)では*利用できません*のでご了承ください。また、作業中のボードがあるチームの[タイマーをインストール](https://miro.com/marketplace/)するか、チームの管理者にインストールを依頼する必要がある場合もあります。Enterprise プランでは、会社の管理者により[タイマーが制限されている可能性](../../enterprise-administration/managing-apps-on-enterprise-plan/02-app-management.md)があることをご了承ください。

**[プレゼンモード](https://help.miro.com/hc/articles/360017731073)でタイマーを確認できますか？**

*全画面*でプレゼンモードにした場合、画面の左上隅にタイマーがポップアップ表示されます。

**ボードの別の場所にタイマーを移動させることはできますか？**

いいえ、現在は対応していません。
