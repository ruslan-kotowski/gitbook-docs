アクションショートカットは、ボタン1つでボードやテンプレートにカスタム機能やAIショートカットを追加することができます。アクションショートカットを使えば、ボード上の繰り返しタスクや機能を簡単に効率化できます。

> ***利用可能な環境：デスクトップ ブラウザー、デスクトップ アプリ
> ***利用可能なプラン：すべてのプラン*** /em>/strong>
> *実行可能なユーザー*：ボードのオーナーと編集者はアクションのショートカットを設定でき、すべてのユーザーはアクションのショートカットを使用できます。***

## 主な機能

アクション・ショートカットには次のような主な機能があります：

- **機能のショートカット**
  通常メニューに隠れている40以上の機能にボード上で素早くアクセスできます。
- **Miro AIで作る**
  付箋、ドキュメント、イメージ、ダイアグラムを作成するボタンを追加し、ボードのコンテンツを入力として使用することもできます。

## ボードにアクションショートカットを追加する方法

以下の手順では、ボードにアクションショートカットを追加する方法を説明します。

**手順**

以下の手順を実施してください。

1. 作成ツールバーの「**ツール、メディア、インテグレーション」**(![icon-tools.svg](../../../../../../docs/using-miro/facilitation-tools/images/25581014501266_icon-tools.svg))アイコンをクリックします。
2. アクションショートカットを検索してクリックします。
   カーソルがアクションショートカットアイコンに変わります。
3. アクションのショートカットを置きたいボードをクリックしてください。
   ダイアログが開きます。

   アクションボタンの追加に成功しました。次に、アクションボタンの設定方法を学びます。

## 機能をトリガーするアクションショートカットの設定方法

以下の手順では、ボード上の機能をトリガーするためにアクションショートカットを設定する方法を説明します。

**手順**

以下の手順を実施してください。

1. 設定ダイアログで**ボタンラベルを**入力します。
2. **アクション」**ドロップダウンで、「**ショートカットを作成**」を選択します。
   新しいMiroフィーチャーフィールドが表示されます。
3. アクションショートカットに追加したい**Miroの機能を**選択します。矢印キーを使って検索したり、リストをスクロールすることができます。
4. **[保存]** をクリックします。

   あなたのボードにアクションボタンが追加されました。

## Miro AIでCreateのActionショートカットを設定する方法

以下の手順では、ボードのMiro AI機能で作成するためのアクションショートカットを設定する方法を説明します。

**手順**

以下の手順を実施してください。

1. 設定ダイアログで**ボタンラベルを**入力します。
2. **アクション]**ドロップダウンで[**Miro AIで作成]**を選択します。
   新しい「**何を作成しますか」**フィールドが表示されます。
3. アクションショートカットで作成したい出力の種類を選択します。ドキュメント、付箋、画像、図から選択できます。
4. 必要に応じて、アクション ショートカットのソースまたは宛先を選択します。
   1. ソースまたはデスティネーションにフレームを選択できます。
   2. ソースにフレームが選択されていない場合、ボード全体のコンテンツが使用されます。
   3. デスティネーションにフレームが選択されていない場合、出力はアクションボタンの近くのボードに配置されます。
5. Miro AIが出力を作成する際に使用するプロンプトを入力します。
6. **[保存]** をクリックします。

   ボードにMiro AIで作成するアクションボタンが追加されました。
