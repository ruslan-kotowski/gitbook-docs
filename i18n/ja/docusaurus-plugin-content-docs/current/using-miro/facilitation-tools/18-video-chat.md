[Miro の内蔵ビデオチャットを利用して複数のリンクやアプリ間の切り替えをすることなく、シームレスな共同のリモートセッションを実施できます。](../../getting-started/feature-intros/03-miro-for-workshops-meetings.md)

:::note
新しい[ビデオ通話](17-video-calls-beta.md)機能は、ビデオチャットに代わるものです。ビデオチャットは非推奨となりました。
:::

ビデオチャットは、リアルタイムのコラボレーションの機会を作り、全員がより参加しているように感じさせることで、分散チームまたはリモートチームをより良くサポートします。

> **利用可能なプラン：**Starter、Business、Enterprise、Starterプラン
> **設定者：**  [メール](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)で個別にボードに招待された編集者、または Miro の[プロジェクト](../sharing-boards/16-projects.md)や[チーム](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)のメンバーとしてボードにアクセスできる編集者[（閲覧者、](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) [メールで招待された](../sharing-boards/08-collaboration-with-visitors.md)[コメント投稿者](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)  、チームのメンバー、 編集アクセス権を持つビジターも参加可能）

:::warning
[Miro ビデオチャット](https://miro.com/marketplace/video-chat/)で最高の体験を得るには、最大 **25** 人のユーザーが同時にビデオチャット セッションに参加するリモート会議を開催することをお勧めします。
:::

## 通話をまとめる

ビデオチャットを開始するには、ボードの左側にある作成ツールバーで**ビデオチャッのアイコン**を見つけ（まだピン留めしていない場合は、**ツール、メディア、インテグレーション****（+）**アイコンから追加すると便利です）、**開始**をクリックします。

## 通話に参加

コラボレーターがビデオ通話を開始する場合は、ボード右上にビデオチャット メニューが表示されます。通話に参加するには、[**参加する**] をクリックします。

![video-chat-join.png](https://help.miro.com/hc/article_attachments/21857925288594)
*ビデオ通話に参加*

カメラ/マイクボタンをクリックして有効/無効にするか、設定に移動して別のカメラまたはマイクを選択します。Miro がカメラ / マイクにアクセスできない場合は、アクセスを有効化する方法をこちらからご覧ください。

![video-chat-settings.png](https://help.miro.com/hc/article_attachments/21857925290898)
*ビデオチャットで使用する別のカメラを選択*

通話中に**ビデオ**を**開始 / 停止**し、**マイクロフォン**を**ミュート / ミュート解除**するためには対応するボタンを使用します。

ボート上でビデオチャットの参加者を確認し、矢印でリストをスクロールすることができます。

![video_chat_participants.jpg](../../../../../../docs/using-miro/facilitation-tools/images/4813915951378_video%20chat%20participants.jpg)
*ボードに表示されるビデオチャットの参加者*

また、**[画面を共有]** ボタンをクリックすれば、コラボレーターはあなたの操作をフォローできるようになります（自分と同じ画面が見られる）。

![video-chat-share-screen.png](https://help.miro.com/hc/article_attachments/21857910318098)
*スクリーン共有機能*

通話を離れるには、[**離れる**] をクリックします。

> **✏️** コラボレーターが通話を開始したが通知が表示されない場合は、ページを更新するか、下のツールバーにあるビデオチャットアイコンをクリックします。

## カメラおよびマイクロフォンへのアクセスを許可する方法

ビデオチャットを初めて使用する場合は、ボード左上のブラウザーにポップアップが表示されます。[**許可する**] のクリックにより、ブラウザーのデフォルトカメラおよびマイクにアクセスを許可します。

![camera_and_sound__notification.jpg](../../../../../../docs/using-miro/facilitation-tools/images/4813976013074_camera%20and%20sound%20%20notification.jpg)
*Miro にカメラおよびマイクロフォンの使用を許可*

誤ってポップアップで **[ブロックする]** をクリックしたり、Miro がその他理由でカメラ / マイクにアクセスできない場合は、以下の手順に従ってください。

### Chrome

ブラウザーのアドレスバーにある [カメラ / マイク] アイコンをクリックし、設定を変更します。

![camera_icon.jpg](../../../../../../docs/using-miro/facilitation-tools/images/4814040555410_camera%20icon.jpg)

または、[[ブラウザー設定](chrome://settings/)**] > [プライバシーおよびセキュリティ] > [サイト設定] > [アクセス権限] > [カメラ / マイクロフォン] に移動できます**。

![camera_and_mic_in_Chrome_settings.jpg](../../../../../../docs/using-miro/facilitation-tools/images/4814066395794_camera%20and%20mic%20in%20Chrome%20settings.jpg)
*Chrome ブラウザ設定のカメラおよびマイク*

カメラまたはマイクを選択し、[**ブロック**] セクションから Miro を削除します。

![remove_from_block.jpg](../../../../../../docs/using-miro/facilitation-tools/images/4814070325138_remove%20from%20block.jpg)
*Chrome のカメラ設定の [ブロック] セクションから Miro を削除*

### Safari

Miro ウェブサイト開き、左上の **Safari** をクリックし、[**このウェブサイトの設定**] を選択します。

![Safari_settings_for_Miro.jpg](../../../../../../docs/using-miro/facilitation-tools/images/4814130697746_Safari%20settings%20for%20Miro.jpg)
*Safari で Miro ウェブサイト設定を開く*

カメラメニューで [**許可する**] を選択します。

![allow_camera_in_Safari.jpg](../../../../../../docs/using-miro/facilitation-tools/images/4814150793490_allow%20camera%20in%20Safari.jpg)
*Safari で Miro がカメラを使用することを許可する*

別の方法で Safari で Miro を開くには、[****環境設定**] に移動し、[ウェブサイト] をクリックします。**カメラ**または**マイク**を選択し、Miro に使用を許可します。この時点で Miro をブラウザーで開く必要があることに注意してください。**

![allow_mic_in_Safari.jpg](../../../../../../docs/using-miro/facilitation-tools/images/4814197812498_allow%20mic%20in%20Safari.jpg)
*Miro が Safari でマイクを使用できるように許可する*

### Firefox

ブラウザーのアドレスバーにあるカメラおよびマイクのアイコンをクリックし、十字アイコンを押します。その後ページをリロードすれば、カメラおよびマイクロフォンの使用が許可されます。

![camera_and_mic_in_Firefox.jpg](../../../../../../docs/using-miro/facilitation-tools/images/4814186949522_camera%20and%20mic%20in%20Firefox.jpg)
*Firefox でカメラおよびマイクロフォンのアクセス権限を変更する*

ブラウザ設定でアクセス権を管理することもできます。ブラウザー右上のメニューアイコンをクリックし、**[設定]** > **[プライバシーとセキュリティー]** を選択し、**許可設定** までスクロールダウンします。カメラ / マイクロフォンの**設定**を開きます：

![firefox_settings.jpg](../../../../../../docs/using-miro/facilitation-tools/images/4814220970898_firefox%20settings.jpg)
*Firefox のカメラおよびマイクロフォンのアクセス権限*

ブロックされたウェブサイトのリスト上で Miro を検索し、ステータスを [**許可する**] に変更します。

デバイスの環境設定（Mac）または設定（Windows）で、[Miro デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)にカメラがアクセスすることを許可できます。

## 技術要件およびトラブルシューティング

ビデオチャットには、マイクロフォンおよびウェブカメラへのアクセスを除いて、追加のソフトウェアや設定管理は必要ありません。miro.com がブラウザでマイクロフォンおよびカメラを使用できるように許可してください（アクセスをリクエストするポップアップ画面が通話開始時に表示されます）。

ビデオチャットのパフォーマンスは、CPU、RAM、ネットワーク接続によります。ビデオストリームがフリーズまたは遅い場合、**別のネットワーク**に接続し、**他のデバイス**を（より良い CPU および RAM で）使用し、**VPN** オン / オフを切り替えてください。

タスクマネージャーで CPU をチェックして、（ビデオチャットを使用および使用していない場合、その他のアプリが動作している、および動作していない場合）容量を確認することができます。

ネットワーク接続は、[Cloudharmony.com](https://cloudharmony.com/speedtest-for-aws) でチェックできます。Amazon EC2（eu-west-1）のテストのみが必要です。以下のポイントが重要です：

![network_connection_check.jpg](../../../../../../docs/using-miro/facilitation-tools/images/4814245122066_network%20connection%20check.jpg)
*ネットワーク接続のチェック*

一般に、結果が[システム要件](../troubleshooting-technical-questions/technical-guidelines/01-system-requirements.md)を満たす場合は、チャットがスムーズに動作する必要があります。デバイスが要件に適合したが、ビデオチャットが上手く動作しない場合は、[Miro サポートまで連絡](https://help.miro.com/hc/requests/new?referer=help-center-article)してください。

ビデオチャットの参加者が聞こえないか見えない場合は、[このウェブサイト](https://tokbox.com/developer/tools/precall/)でテストを実行してください。そして画面下までスクロールし、**シンプルテキストで [このデータを保存]** をクリックし、[Miro サポートで結果を共有します](../tools/troubleshooting/06-contacting-miro-support.md)。

## よくある質問

**チームに対してビデオチャットをアンインストールできますか？**

はい、管理者は[チームの設定](../../administration/get-started-as-a-miro-admin/01-i-am-a-new-miro-admin.-where-to-start.md) **> アプリとインテグレーション**からビデオチャットをアンインストールできます。**ビデオチャット**を開き、 [**チームに対してアンインストールする**] をクリックします。

**ビデオチャット参加者の画面を最小化／拡大することはできますか？**

いいえ、現時点ではできません。

**参加者にビデオチャットのリンクを送信する必要がありますか？**

いいえ、Miro のビデオチャットには特別なリンクはありません。会議参加者とボードを共有し、ビデオチャットセッションを開始します。参加者は、ボードからビデオチャットに参加することができます。

**ビデオチャット中にカメラを変更できますか？**

はい、ビデオチャットの設定で変更できます。カメラへのアクセスを許可してください。
![video-chat-settings.png](https://help.miro.com/hc/article_attachments/21857925290898)
*ビデオチャットの設定*
