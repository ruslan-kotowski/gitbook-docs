ボードエクスポートをより効率的に管理できるように、追加のボードエクスポート API エンドポイントを導入します。組織全体のエクスポートジョブをリスト表示し、特定のエクスポートジョブのタスクを閲覧し、エクスポートタスクのダウンロードリンクを取得し、不要になったエクスポートジョブをキャンセルできるようになります。これらの更新により、エクスポートのワークフローをプログラムで監視、制御、自動化することが容易になります。
