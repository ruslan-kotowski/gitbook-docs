User Groupsは、管理者がユーザーのグループを作成し、これをIDPと同期できる機能を提供します。管理者はグループをチームに割り当て、特定のコンテンツにアクセス権を与えることができます。

チームメンバーはUser Groupsを利用して他のグループとボードを共有し、特定のグループのユーザーだけがコンテンツにアクセスできるようにします。新しいユーザーとボードを再共有する代わりに、適切なUser Groupにユーザーを追加することができます。

## 主な機能

- **ユーザー グループの作成と管理**
  管理者コンソールで、会社の管理者はユーザー グループを作成、確認、編集、メンバーの追加、削除ができます。詳細は[ユーザー グループ](../../enterprise-administration/user-management/08-user-groups.md)をご覧ください。
- **ユーザー グループとボードおよびスペースの共有**
  チームメンバーは[任意のボードやスペースをユーザー グループと共有](../../enterprise-administration/user-management/08-user-groups.md)し、権限を設定できます。
- **APIでのユーザー グループ管理**
  ユーザー グループAPIにより、管理者はプログラムでユーザー グループを作成、編集、削除できます。
- **コメントでユーザーグループに言及する**
  任意のボードでユーザーグループをメンションします。グループのすべてのユーザーに通知が届きます。
- **ボードでユーザーグループのメンバーを見る**
  ボードでグループに言及すると、ユーザーグループのすべてのメンバーを確認できます。
