管理者カスタム告知は、組織内のユーザーに向けて、管理者コンソールからターゲティングされた時間制限付きメッセージを投稿できます。メッセージを作成し、サインアップフォームやTypeform、Confluence/SharePointの記事など、どこにでもリンクできる行動を促すアクション（CTA）を追加し、ユーザーリストを選択、表示されるタイミングをスケジュールできます。

管理者カスタム告知を使用して、トレーニングや新機能の展開を促進したり、適切なタイミングで適切なユーザーリストからフィードバックを収集したりできます。組織全体や特定のチームにアプローチするかを選択し、CTAでアクションを促進します。メッセージが自動的に公開されたり、ウィンドウまでスケジュールされたままにしたりするために、開始日と終了日を設定します。
