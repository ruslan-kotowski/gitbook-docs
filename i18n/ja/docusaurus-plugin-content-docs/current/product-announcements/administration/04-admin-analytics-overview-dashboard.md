概要ダッシュボードは、以下の指標を通じて導入状況を追跡し、組織の活動を理解するための洞察を提供します。

- **ボード:** ボードの合計数を確認し、使用状況においてどのボードがアクティブであるか、また過去の傾向を追跡します。
- **ユーザー:** Miro を積極的に利用しているユーザー数を時間の経過とともに追跡します。また、メンバー、会社の管理者、ゲスト、チーム内のゲストなど、特定のユーザー役割に基づいて追跡することもできます。
- **チーム:** チーム数を監視し、活動レベルを確認します。
- **ライセンス:** 割り当てられたさまざまなタイプのライセンスを追跡し、時間の経過による変更を確認します。
- **テンプレート:** 組織全体でどのテンプレートが最も使用されているかを発見します。
