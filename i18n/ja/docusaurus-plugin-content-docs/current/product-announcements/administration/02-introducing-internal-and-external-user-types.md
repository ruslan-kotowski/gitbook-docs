管理者は、メールアドレスが確認済みのユーザーを内部ユーザー、未確認のユーザーを外部ユーザーとして識別できます。内部ユーザーと外部ユーザーの視覚的な違いは、将来的に管理者がユーザーを管理するための機能強化につながります。詳しくは、[ドメイン制御](../../enterprise-administration/canvas-25-admin-features/domain-control/01-domain-control.md)をご覧ください。
