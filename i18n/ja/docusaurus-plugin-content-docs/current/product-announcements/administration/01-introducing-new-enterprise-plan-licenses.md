異なるチームやワークフローに合わせた適切な機能を選択しやすくするため、Miro は **Standard** と **Advanced** の Enterprise ライセンスを導入します。

### **Full は Standard になります**

現在フルライセンスの旧 Enterprise ライセンスを利用している場合、プラットフォームの使用はこれまで通り継続します。AWS コスト計算アプリ と Jira カードは、新しいライセンスモデルへの移行の一環として新しい Advanced ライセンスでのみ利用可能です。移行がスムーズに進むよう、アカウント担当者が計画を立ててサポートします。

### **Miro コアと、プロダクト加速のための特別なワークフロー**

**標準**および**高度**の両方に Miro コア体験が含まれています。これには、柔軟なキャンバス、コラボレーション、テンプレート、およびチームが愛する基本機能が含まれています。

さらに、プロダクト加速ソリューションは、特定の高価値ワークフローでチームを深くサポートし、次のことを行います。

- **技術設計と仕様**: エンジニアリングの手戻りを減らし、明確な技術文書を作成し、AI ツールで信頼性のあるコードを生成します。
- **目標、ロードマップ、および納品**: 戦略を実行に結び付け、障害要因を早期に明らかにし、チーム間の依存関係を管理します。

以下の表は、これらのワークフローにおける**Enterprise Standard**と**Enterprise Advanced**に含まれる内容の概要を示しています。

| エンタープライズ標準ライセンス | エンタープライズ高度ライセンス *プロダクト、デザイン、エンジニアリング、IT向けに推奨* |
| --- | --- |
| **テクニカルデザインと仕様** 明確な技術仕様でチームを整合させ、エンジニアリングの手戻りを削減します。  搭載機能:   - コード説明のようなベーシックMCP機能 - 3600以上の図形、レイヤー、PlantUML、Draw.ioなど - コードブロックのウィジェット | **高度な技術設計と仕様** Miro と AI ツールを接続して、適切なコンテキストで正しいものを構築することで、開発と意思決定を迅速化します。  提供機能：   - 全ボードの要約やダイアグラム作成など高度な Miro MCP 機能を提供し、すべての主要なコード生成ツール（GitHub、Copilot、Cursor、Claude Code など）と統合。 - AWS インフラストラクチャの可視化と費用計算 |
| **目標、ロードマップ、デリバリー** 製品開発を会社の目標、タイムライン、および定義された障害によって崩壊する前に軌道に乗せ続けます。  対応：   - 文書、データテーブル、タイムライン - ブループリント、スペース、テンプレート - Jira、Azure、Linear などの基本的なインテグレーション。 | **高度なゴール、ロードマップ、およびデリバリー** 自動調整、ゴールの可視性、積極的な依存関係管理を通じて、タイムトゥーマーケットを加速します。  提供:   - クロステーブル関連付けと階層構造 - 視覚的に明確な階層構造を示すテーブルのツリービュー - Jira、Azure、LinearなどのDevOpsシステムとの高度な双方向インテグレーション |
