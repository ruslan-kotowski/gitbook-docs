管理者コンソールからのボードエクスポートが一般リリースされたことをお知らせできることを嬉しく思います。Enterprise Guard の管理者は、管理者コンソールから直接ボードをエクスポートできるようになりました。これにより、組織はコンプライアンス、ガバナンス、および法的要件を満たすための効率的な方法が得られます。このリリースにより、管理者は追加のツールに頼ることなく、直接ボードをエクスポートできるようになり、ガバナンスのワークフローをよりコントロールしやすくし、コンプライアンスや法的準備を簡素化します。

さらに、エクスポートされたボードの一括ダウンロードもリリースします。ボードを個別にダウンロードすることに加え、管理者はエクスポートしたすべてのボードを単一のアーカイブとしてダウンロードできるようになりました。このアップデートにより、大規模なエクスポートの処理が容易になり、ボードパッケージの整理が可能になります。また、アーカイブが 50 GB を超える場合、自動的に複数のファイルに分割してサポートします。
