Microsoft Purview を利用する組織にとって、複数プラットフォームにわたるデータ セキュリティーおよび機密分類の一貫性を維持することは重要です。Miro と Microsoft Purview のインテグレーションにより、管理者は Microsoft Purview から Miro へ機密ラベルを直接インポートでき、両プラットフォーム間での分類スキーマの管理を簡素化します。

このインテグレーションを活用することで、組織は Miro 内のコンテンツを Microsoft Purview の既存フレームワークと一貫して分類することができます。これにより、機密ラベルを手動で再作成または更新する際の運用負担を軽減し、データ セキュリティーを強化します。Miro のデータ保護機能を Microsoft Purview と連携させることで、管理者はデジタルエコシステム全体での機密情報の管理を安心して行うことができます。
