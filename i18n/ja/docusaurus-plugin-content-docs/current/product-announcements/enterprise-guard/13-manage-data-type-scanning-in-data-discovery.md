機密コンテンツ管理者は、特定のラベルを簡単に有効化・無効化できるようになり、データ検出スキャンを設定する際に、組織のニーズに合わせて結果を調整するのに役立ちます。例えば、GDPRラベルのみに焦点を当てることができます。スキャン設定を保存すると、その選択に応じてスキャンは自動的に更新されます。これにより、管理者はスキャンの出力をより詳細に制御でき、関連性のない発見によるノイズを減少させることができます。
