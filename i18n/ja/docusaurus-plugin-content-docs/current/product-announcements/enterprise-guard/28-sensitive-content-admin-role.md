お客様の重要な情報が、適切な権限を持つ担当者によって管理され、監査されるようにします。

管理者は以下のような高度なセキュリティー操作を実行することができます。

- 機密分類ポリシーとレベルの表示と編集
- 自動機密分類ルールの設定
- ガードレールの設定
- データ検出ポリシーを作成
