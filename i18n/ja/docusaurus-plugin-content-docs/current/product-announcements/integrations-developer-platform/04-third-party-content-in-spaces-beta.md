すべての作業とツールを一元化し、Spaces にサードパーティリンクを追加しましょう。チームは Miro から直接 Microsoft Word などの外部リソースにシームレスにアクセスして操作できるため、コラボレーションと意思決定がさらにシームレスかつ効率的になります。

**サードパーティーの埋め込みに対応：**

- Box
- Figma
- Google ドキュメント
- Google スライド
- Google スプレッドシート
- Looker
- Microsoft Word ドキュメント
- Microsoft PowerPoint プレゼンテーション
- Microsoft Excel シート
- Power BI
