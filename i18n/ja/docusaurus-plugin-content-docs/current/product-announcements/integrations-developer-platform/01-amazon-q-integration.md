Amazon Q のインテグレーションにより、Sidekicks と Flows を通じて会社の知識を Miro AI キャンバスに取り込むことができます。

Amazon Q のインテグレーションは、チームが計画、設計、意思決定を行う場で、企業の知識を結びつけます。Slack、Gmail、Jira、Confluence、Google Drive、GitHub などのリソースにクエリをかけることで、分散した情報を組織のデータに基づく明確な成果物、アーティファクト、および洞察に変換します。
