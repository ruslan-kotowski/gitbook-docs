Sketch 用の Miro プラグインを使用すると、Sketch の画像をボードに簡単かつ素早くに取り込むことができます。アートボードを Miro に送信し、ワンクリックで簡単に更新できます。アートボードの画像は同期されるため、変更のたびに再アップロードする必要がありません。

### プラグインを有効にする

1. 1. GitHub から Sketch プラグインをダウンロードします：[このリンク](https://github.com/miroapp/sketch_plugin) > **[Code]** > **[Download ZIP]** をクリックする。

Download_from_Github.jpg

2. 2. ZIP アーカイブを展開し、RealtimeBoard.sketchplugin バンドルをダブルクリックして、プラグインをインストールします。

plugin_installed.jpg
Sketch 用 Miro プラグインのインストール

3. 3. プラグインを有効にするには、Sketch を開き、**[Plugins]** > **[Manage plugins]** に移動し、**[Miro by Miro]** のボックスにチェックを入れます。

Miro_plugin_in_Sketch.jpg
Miro プラグインを Sketch で有効にする

4. 4. その後、Sketch で Miro の認証情報を認証します。これを行うには、**プラグイン -** **Miroを**クリックします**：** **Miroにログインし、Miroからログアウト**します。

Log_in_to_Miro_in_Sketch.jpg
Miro アカウントのログイン

5. 5. メールアドレスとパスワードを入力するか、アカウントの SSO が有効になっているなら、**[Use company credentials]** のボックスにチェックを入れます。

Miro_login.jpg
Miro にサインインするための認証画面

### Sketch のアートボードを Miro に追加する

MiroにSketchのアートボードを追加するには、**プラグインにアクセスしてください：** **Miro -** **すべてのアートボードをMiroと同期**します。

ダイアログウィンドウが表示され、招待メールで編集権限を得たボード、または[プロジェクト](../../using-miro/sharing-boards/16-projects.md) / チームアクセス権限を持つボードのどちらにアートボードを追加するかを選択します。

> *⚠️ なお、この機能は[ビジター](../../using-miro/sharing-boards/08-collaboration-with-visitors.md)でアクセスしているボードには利用はできません。*

次のいずれかの方法で、アートボードを追加するボードを選択します。a) ドロップダウンリストから選択する。b) ボード名を入力する。その後、**すべて**のアートボードを追加するか、**選択**したアートボードを追加するのボックスにチェックを入れます。**同期後に Miro を起動する**場合は、該当するボックスにチェックを入れます。

select_a_board.jpg
同期するボードの選択

**[Sync]** をクリックすると、Miro のボードにアートボードが表示されます。

artiboards_in_Miro.jpg
**アートボードは、Miro の既存のボードにしか送信できない**

:::warning
なお、Miro の*ブラウザー*版だけが、アートボードの直接コピー & ペーストをご利用いただけます。
:::

### Sketch アートボードと Miro の同期

既にMiroに追加され、その後Sketchで変更されたアートボードを同期するには、**プラグイン -** **Miroに**移動します：**すべてのアートボードをMiroと同期**します。以前アートボードを同期させたボードがダイアログウィンドウで自動的に選択されます。**すべて**のアートボードを同期するか、**選択**したアートボードを同期するのボックスにチェックを入れます。**同期後に Miro を起動する**場合は、該当するボックスにチェックを入れます。

syncing_boards.jpg
Sketch アートボードと Miro の同期

### プラグインの無効化

Sketch と Miro の同期を停止するには、**[Plugins]** メニュー > **[Manage plugins]** に移動し、**[Miro by Miro]** のボックスのチェックを外します。

disable_Miro_sync.jpg
Miro プラグインが Sketch で無効になります。

| 5. 5. Sketch の検索結果にボードが表示されません | これは、ボードが他の[プロジェクト](../../using-miro/sharing-boards/16-projects.md)に移動された場合や、ボードがあるプロジェクトに空いているシートがない場合に発生します。 | 1. 1. Sketch の同期リストに表示されないボードが、Miro の他のプロジェクトに移動されていないかを確認します。  2. 2. ボードがあるプロジェクトに空きシートがあるかを確認します。 |
| 6. 6. Sketch でのアートボードの更新が Miro ボードのそれに同期されず、アートボードが複製されてしまいます | これは、Sketch と同期しているボードが、[他の Miro アカウントに](../../using-miro/managing-boards/04-how-to-move-a-board.md)[移動された](../../using-miro/managing-boards/04-how-to-move-a-board.md)場合に発生します。この場合、最初の同期では画像が複製され、その後は正常に同期されます。 | 複製前のアートボードを Miro ボードから削除します。新たに複製されたボードは正常に同期されます。 |

#### Miro サポート用 Sketch ログの記録方法

3. 画面右上の拡大鏡アイコンをクリックして、スポットライトサーチを選択して、/span>[コンソール](https://www.howtogeek.com/356942/how-to-view-the-system-log-on-a-mac/)を開きます。

spotlight_search.jpg
スポットライトサーチ

2. 2. コンソールの検索フィールドに「sketch-rtb-error」と入力して、任意のメッセージを検索します。

コンソールサーチ

3. 3. コンソール画面下部に表示されるメッセージをクリックし、スクリーンショットを取得して、Miro の担当者と共有してください。
