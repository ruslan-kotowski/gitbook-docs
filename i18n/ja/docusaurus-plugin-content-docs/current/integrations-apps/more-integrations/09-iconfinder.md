IconFinder を使えば、モックアップ、スキーム、マインドマップを作成し、ビジュアル ブレーンストーミング セッションを実施することができます。**Iconfinder** のアイコンセットは、世界中の何百万人ものデザイナー、開発者、その他のクリエイティブなプロフェッショナルに使用され、デザインやプロジェクトを完全に体系化し、分かりやすく視覚的な効果をもたらします。

### アイコンの追加方法

ツールバーにデータベースがない場合は、**アプリ**メニューで検索し、アイコンセットの横にある **[追加]** をクリックします。

:::warning
管理者以外のユーザーは、**アプリとインテグレーション設定**でアプリのインストールが許可されていなければ、このアプリをインストールすることはできません。
:::

![Iconfinder_on_the_toolbar.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21016057485586_Iconfinder%20on%20the%20toolbar.jpg)
*ツールバーの Iconfinder*

アイコンの追加方法：

1. 作成ツールバーから Iconfinder を開きます。
2. すぐにアイコンの一覧が表示されます。アイコンを一覧から選択するか、キーワードを入力して検索します。
3. アイコンをクリックするか、ドラッグ & ドロップしてボードに追加します。サイズを変更したり、回転することができます。

![using_Iconfinder_in_Miro.gif](../../../../../../docs/integrations-apps/more-integrations/images/21016057487378_using%20Iconfinder%20in%20Miro.gif)
*Iconfinder でアイコンを追加する*

:::warning
Miro では、Premium Iconfinder のアイコンは利用できません。
:::

:::tip
**AWS、Azure、Cisco** などのその他のアイコンパッケージは、Consultant、Business、Enterprise、Education プランのユーザー向けの[図形ライブラリー](../../using-miro/essential-tools/11-shapes.md)で利用できます。
:::

### よくある質問

1. *Premium Iconfinder を購入すれば Miro で利用できますか？*
    ー いいえ、Miro のピッカーは、Premium Iconfinder のアイコンをサポートしていません。
2. *Miro の Iconfinder ピッカーに自分でカスタムしたアイコンを追加することはできますか？* ー いいえ、現時点ではできません。
3. *アイコンを反転することはできますか？*
    ー いいえ、ただし、アイコンの左下に表示される回転ハンドルをドラッグして回転することで、アイコンを回転させることができます。
4. *アイコンにテキストを追加できますか？*
    ー [テキストツール](../../using-miro/essential-tools/16-text.md)でテキストを追加し、[アイコンとテキストを選択](../../using-miro/working-on-the-board/10-working-with-objects.md)して、[グループ化](../../using-miro/working-on-the-board/08-structuring-board-content.md)することができます。
5. *アイコンの色は変更できますか？*
    ー Iconfinder では変更できませんが、[ワイヤーフレーム ライブラリー](../../using-miro/miroverse/prototyping/02-prototyping-library.md)で変更できます。
