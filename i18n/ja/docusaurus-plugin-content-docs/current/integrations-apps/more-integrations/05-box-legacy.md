Box とのインテグレーションは、Box アカウントからファイルを利用し、Miro ボードに追加してさらなるディスカッションやコラボレーションを行うことができます。ボード上でディスカッションを行い、画像やドキュメントの上にフィードバックをマークし、ユーザーをメンションして、素早くイテレーションすることができます。

> **利用可能なユーザー：**Personal & Enterprise Box アカウントを持つすべてのユーザー
> **利用可能な環境**：ブラウザー版、[デスクトップアプリ](../../getting-started/apps-for-devices/05-desktop-app.md)

### プラグインをインストールする

プラグインの使用を開始するには、チームレベルでプラグインをインストールし、Box アカウントを Miro に接続する必要があります。プラグインは、マーケットプレイスや Miro ボードからインストールすることができます。

:::warning
管理者以外のユーザーは、**アプリとインテグレーション**設定で許可されていなければ、このアプリをインストールすることはできません。
:::

[Miro のマーケットプレイス](https://miro.com/marketplace/box/?backUrl=%2Fmarketplace%2F) に移動し、**アプリを取得** をクリックします。アプリをインストールするチームを選択できる画面が表示されます。チームを選択して、インストールを完了します。

![install_Box_plugin.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591350930_install%20Box%20plugin.jpg)
*Box プラグイン用のチームを選択*

ボードからアプリをインストールするには:

1. 作成バーで、**ツール、メディア、インテグレーション**（**+**）を選択します。 ****「ツール、メディア、インテグレーション」パネルが開きます。****
2. **ツール**タブで「**アップロード**」を検索します。
3. 「**アップロード**」パネル内で、「**Box**」を選択します。

![uploads-entry-point.png](../../../../../../docs/integrations-apps/more-integrations/images/21537452824210_uploads-entry-point.png)
*ツールバーの Box アイコン*

ポップアップ ウィンドウの**[アプリを取得]** をクリックすると、チームにプラグインがインストールされます。

Box アカウントを Miro に接続するには、**アップロード**メニューで**Box** を選択します。 Miro で Box を初めて使用する場合は、Box アカウントの承認を求めるポップアップメニューが表示されます。

![authorize_box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591352338_authorize%20box.jpg)
*Box の認証ウィンドウ*

プロフィールの[インテグレーションのページ](https://miro.com/app/account/profile/integrations/)でも Box アカウントの接続や接続解除ができます。

![connect_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591356946_connect%20Box.jpg)
*Box を Miro に接続*

### ファイルの追加

ボードにファイルを追加するには、ツールバーの **アップロード** メニューを開き、**Box** をクリックして、Box アカウント内のドキュメントや写真を選択し、**選択** をクリックします。

![Box からファイルを追加する.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019535297298_adding%20files%20from%20Box.jpg)
*Box から Miro のボードへファイルを追加*

ボード上のファイルを更新するには、ファイルの**更新**ボタンをクリックします。

![update_a_Box_file.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019535299218_update%20a%20Box%20file.jpg)
*Miro のボードにインポートされた Box ファイルの更新*

### プラグインの無効化

チーム用のプラグインをアンインストールしたい場合は、チーム設定に進み、**アプリとインテグレーション** セクションで Box を見つけて、**チームに対してアンインストール** をクリックしてください。

![uninstall_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591362962_uninstall%20Box.jpg)
*チーム設定で Box をアンインストール*

Box アカウントの接続を解除するには、プロフィールの[インテグレーション ページ](https://miro.com/app/account/profile/integrations/)に移動し、**ログアウト**をクリックします。

![disconnect_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591364498_disconnect%20Box.jpg)
*Miro から Box の接続を解除*
