リモート、対人、およびチームとのハイブリッド コラボレーションのために、Microsoft Surface Hub デバイスと共に Miro を使用します。Surface Hub で Miro を使用する詳細については、以下をご覧ください。

Miro は、Microsoft Surface Hub 84 インチと 55 インチ、および Microsoft Surface Hub 2S 50 インチと 85 インチのデバイスと互換性があります。

:::note
最新バージョンの Microsoft Edge を使用していることを確認してください。
:::

## Microsoft Surface Hub で Miro を使用する方法

Surface Hub で Miro を使用するには、次の 2 つの方法があります。

1. Microsoft Edge ブラウザーで使用する
2. Surface Hub に Windows 10/11をインストールし、Miro Windows アプリをインストールする

### Microsoft Edge を使用

1. 最新の **Windows バージョン**（[Windows 10 Team 2022 Update](https://learn.microsoft.com/surface-hub/surface-hub-2022-update)）で Surface Hub デバイスが実行されていることを確認してください。
2. 最新の **Microsoft Edge ブラウザー**を起動します。このブラウザーを Surface Hub ディスプレイにインストールする方法をご覧ください
   > Windows または Microsoft Edge を最新バージョンに更新するには、管理者の許可が必要になる場合があります
3. これで、miro.com/login 経由で Miro にログインできるようになります。また、[クイックログイン機能](../../getting-started/apps-for-devices/10-send-to-display.md)を使用して、個人デバイスから Surface Hub により迅速に Miro を起動することができます

### Miro Windows アプリで Surface Hub を使用

1. [Surface Hub に Windows 10/11](https://learn.microsoft.com/surface-hub/surface-hub-2s-migrate-os)（Windows 10 team ではなく）をインストールします
2. [Miro Windows アプリ](../../getting-started/apps-for-devices/05-desktop-app.md)をインストールします

:::warning
現在「Windows 10 Team」バージョン用 Miro Surface Hub アプリは利用できません。
:::

ご不明な点がある場合は、[サポートチーム](../../using-miro/tools/troubleshooting/06-contacting-miro-support.md)[までお問い合わせください](../../using-miro/tools/troubleshooting/06-contacting-miro-support.md)。
