会社の管理者として、組織内のチームに対して Microsoft Copilot インテグレーションを有効化および承認することができます。

Microsoft Copilot インテグレーションを使用すると、Copilot を Miro 内の[知識](../../using-miro/miro-ai/09-knowledge.md)リソースとして接続できます。たとえば、会社の情報をサイドキックやフローに提供するために Microsoft Copilot を接続します。

また、Miro 内の独立したチャットに Copilot を接続することも可能です。

:::note
Microsoft Teams で Miro エージェントを Copilot と一緒に使用する方法については、[Copilot 用の Miro エージェント](microsoft-teams/03-miro-agent-for-copilot.md)をご覧ください。
:::

このインテグレーションを使用するには、チームメンバー全員が Copilot ライセンスを持っている必要があります。

Microsoft Copilot インテグレーションを有効にするには、次の手順に従ってください:

1. 会社の管理者として**管理コンソール**に移動します。
2. **アプリ & インテグレーション** > **アプリ** > **アプリ追加**に移動します。
3. **Microsoft Copilot**を検索します。
   アプリ名で見つからない場合は、次のクライアント ID で検索してください: `5531308904693541040`。
4. アプリのプロフィールで、**すべてのチーム**に追加するか、**特定のチーム**を選択して追加するか選びます。
5. （オプション）アクセス権限ページを確認します。Miro用のMicrosoft CopilotアプリはMiroが開発・維持し、特別なアクセス権を必要としません。
6. **追加**をクリックします。

:::note
チームメンバーが初めてMicrosoft Copilotを知識リソースとして接続する際には、認証が求められます。チームメンバーはCopilotライセンスを所持している必要があります。
:::
