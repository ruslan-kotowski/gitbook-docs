MiroをMicrosoft Teams (MS Teams)とシームレスにインテグレーションすることで、チームはMS Teams環境で直接Miroを使ってブレーンストーミング、プランニング、共同制作を行うことができます。Miroインテリジェント・キャンバスは、アプリケーションを切り替えることなくプロジェクト管理を簡素化します。

> **利用可能なプラン：**すべてのプラン一部の高度な機能は、有料プランでのみ利用できる場合があります。
> **実行可能なユーザー： すべてのユーザーMicrosoft管理者の設定が必要です。**

## 主な機能

Miro for Microsoft Teamsインテグレーションは以下の主な機能を提供します：

- **MS Teams検索用Miro Copilotプラグイン**
  CopilotでMiroのコンテンツを検索し、メタデータ付きのリファレンスボードを即座にプレビューできます。
- **通知ボット**
  MS TeamsのチャットでMiroから新しいコメント投稿者やボードへの返信などの更新情報を即座に入手したり、チャットで直接承認できるアクセスリクエストを入手したりできます。
- **MSチームミーティング**
  Miroボードを開くか作成すると、通話中いつでもキャンバス上で対話を始めることができます。
- **MSチームカレンダー**
  Miro ボードを MS Teams カレンダーの招待に埋め込み、権限を設定し、会議の前に共同作業者にアクセス権を与えます。
- **MSチームタブ**
  Miro ボードを MS Teams のタブとして埋め込みます。
- **MSチームチャット**
  Miro ボードを MS Teams チャットの適応カードとして追加します。

## Miro for Microsoft Teamsの設定方法

Microsoft Teamsの管理者として、MS TeamsのMiroインテグレーションを有効にすることができます。

以下の手順に従ってください。

1. MS Teamsで、**アプリ****（+）を**選択します。
   **アプリパネルが**開きます。
2. Miroを検索。
3. 検索結果の「Miro」で**「Add**」を選択します。
   Miroアプリのモーダルが開きます。
4. **追加を**選択します。
   Miroアプリのビューにリダイレクトされます。
5. Miroアプリのビューから、Miroアカウントにログインします。
   MiroアカウントはMSチームに接続します。

   Miro アプリを MS Teams に追加し、アカウントを接続しました。

Microsoft Teams用の特定のMiroインテグレーションを使用するには、各インテグレーションの記事を参照してください。
