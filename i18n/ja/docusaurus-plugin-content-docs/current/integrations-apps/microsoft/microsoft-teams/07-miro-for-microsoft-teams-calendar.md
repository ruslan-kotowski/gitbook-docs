Miro ボードを MS Teams カレンダーの招待に埋め込み、権限を設定し、会議の前に共同作業者にアクセス権を与えます。

## Microsoft TeamsカレンダーイベントにMiroボードを追加する方法

#### 前提条件

- カレンダーイベントの作成と保存
- Miro for Microsoft Teamsが有効になっていることを確認してください。方法については、[Miro for Microsoft Teamsの概要を](06-miro-for-microsoft-teams-overview.md)参照してください。

#### 手順

以下の手順を実施してください。

1. Microsoft Teamsでカレンダーイベントを開き、**編集を**選択します。
2. プラスアイコン**（+）を**選択します。
   **タブの追加**]モーダルが開きます。
3. **Miroを**選んでください。
4. **開始を**選択します。
   まだログインしていない場合は、Miroにログインするよう促されます。
5. 埋め込むMiroボードを選択するか、新しいボードを作成します。
   > ✏️ ボード所有者またはボード編集者のロールを持ち、埋め込みたいボードを所有するMiroチームのメンバーである必要があります。
6. 埋め込みボードのユーザー権限を選択します。
   ![画像.png](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22476127831698_image.png)
7. **[保存]** を選択します。

   Miro ボードを MS Teams カレンダーイベントに追加できました。
