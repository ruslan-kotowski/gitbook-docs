Miro ボードを Microsoft Teams (MS Teams) チャンネルに埋め込みます。アプリを切り替えることなく、Miroコラボレーションを一元化し、意思決定を整理することができます。MS Teamsチャンネルにタブを追加し、ボード所有者またはボード共同所有者であるMiroボードを埋め込みます。

## Microsoft TeamsチャンネルのタブとしてMiroボードを追加する方法

#### 前提条件

1. あなたは埋め込みたいMiroボードのボード所有者またはボード共同所有者です。
2. あなたは埋め込みたいボードを所有するMiroチームのメンバーです。
3. Miro for Microsoft Teamsが有効になっていることを確認してください。方法については、[Miro for Microsoft Teamsの概要を](06-miro-for-microsoft-teams-overview.md)参照してください。

#### 手順

以下の手順を実施してください。

1. Microsoft Teamsで、チームを選択します。
2. プラスアイコン**（+）を**選択します。
   **タブの追加**]モーダルが開きます。
3. **Miroを**選んでください。
4. **開始を**選択します。
   まだログインしていない場合は、Miroにログインするよう促されます。
5. 埋め込むMiroボードを選択するか、新しいボードを作成します。
   > ✏️ ボード所有者またはボード編集者のロールを持ち、埋め込みたいボードを所有するMiroチームのメンバーである必要があります。
6. 埋め込みボードのユーザー権限を選択します。
   ![画像.png](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22476127831698_image.png)
7. **[保存]** を選択します。

   Miro ボードを MS Teams チャンネルのタブとして追加できました。
