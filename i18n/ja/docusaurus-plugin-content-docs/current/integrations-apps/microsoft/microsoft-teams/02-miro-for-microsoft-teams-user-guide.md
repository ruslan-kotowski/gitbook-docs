Miro for Microsoft Teamsを使用すると、ユーザーはリアルタイムで通知を受け取るだけでなく、Teamsのミーティング、チャンネル、チャット、カレンダーの招待に埋め込まれたMiroボードで共同作業を行うことができます。

Miroはまた、リンクの展開と検索メッセージの拡張機能によってアダプティブカードをサポートし、共有ボード上でより多くのコンテキストをユーザーに与え、迅速なボードアクセス管理を可能にします。

- Microsoft Teamsのミーティング、チャット、チャンネル、カレンダーイベントの[タブとしてMiroボードを追加します](04-add-miro-as-a-tab-in-microsoft-teams.md)。
- Microsoft TeamsでMiroの通知を受け取ります。
- リンクの展開と検索メッセージの拡張により、Miroのリンクをアダプティブ・カードとして共有します。

:::note
管理者はMicrosoft Teamsの設定内およびMiroアプリの管理設定からMiroアプリを有効にする必要があります。Miroが承認されない限り、ユーザーは利用できません。[Miro for Microsoft Teams (管理者ガイド)](01-miro-for-microsoft-teams-admin-guide.md)で、TeamsとMiroの管理者がどのようにユーザーのエクスペリエンスを有効にできるかをご覧ください。
:::

## アプリのインストール方法

1. [Microsoft AppSourceで](https://appsource.microsoft.com/product/Office365/WA104381906)Miroを見つけるか、[直接リンクをたどって](https://teams.microsoft.com/dl/launcher/launcher.html?url=%2F_%23%2Fl%2Fapp%2F8216e453-3db5-48ee-a3d6-5122f505c8a3&type=app&deeplinkId=660e2c79-d07b-46b9-b56f-473431aa9dd9&directDl=true&msLaunch=true&enableMobilePage=true&suppressPrompt=true)ください。
2. **追加]**をクリックしてアプリをインストールします。

Miroアプリをインストールしたら、ボードをタブに追加したり通知を受け取ったりするためにアカウントを接続する必要があります。
インストールプロセスの一環として、Miroチャットに移動し、アカウントを接続してアプリの設定を完了することができます。Miroの通知を設定できるようになります。

:::note
Microsoft Teams での Miro ボードの追加については、こちらをご覧ください。
:::

## Microsoft Teamsでの通知の設定

アプリを使用して、以下のアクティビィティーを確認することができます。

- 招待者の登録
- ボードが自分と共有されたとき
- ボード上での新しいコメントやコメントへの返信
- 誰かがコメントで自分を @メンション、また返信したとき
- ボードアクセスリクエストを受信し、承認する

通知はMiroボットチャットで受け取ります。Miroボットチャットを設定するには：

1. アカウントに接続します。**[Connect] （接続する）**コマンドに入力し、[Connect Miro to Microsoft Teams]（Miro を Microsoft Teams に接続する）をクリックします。
2. 新しいタブでMiroプロフィールを認証する必要があります。アカウントの接続に成功すると、すべての設定が完了したことを示すボットからの挨拶メッセージが表示されます。
3. 新着コメントやメンションが通知されるようになります。
4. Microsoft TeamsでMiroボードリンクを共有します。

Miro for Microsoft Teamsアプリを使用すると、Miroボードリンクをアダプティブカードとして共有することができます：

- リンク展開
- 検索メッセージの拡張子

アダプティブカードは、タイトル、所有者、最終更新日など、ボードに関する詳細なコンテキストをユーザーに提供します。また、ボードの権限を管理したり、[Miro AIを](../../../using-miro/miro-ai/03-create-with-ai.md)活用して重要な要点を文書にまとめたりすることもできます。

Miroアプリをインストールして接続している場合、Microsoft Teamsチャンネルのメッセージ作成ボックスにボードのリンクが貼り付けられると、Miroボードは自動的にアダプティブカードに展開されます。

アプリをインストールしてもまだMiroアカウントに接続していない場合は、ログインするオプションが表示されます。まだアプリをインストールしていない場合は、[こちらの](04-add-miro-as-a-tab-in-microsoft-teams.md)手順に従ってください。

## よくある質問

インテグレーションに問題がある場合はどうすればよいですか？

インテグレーションで問題が発生した場合は、Miroチャットで再接続を試みてください。これにより、一般的な接続の問題が解決されることがよくあります。

再接続しても問題が解決しない場合は？

Miroチャットで再接続しても問題が解決しない場合は、Miroアシストまでお問い合わせください。彼らはさまざまな技術的問題に対応できる能力を備えており、より具体的な指導を行うことができます。
