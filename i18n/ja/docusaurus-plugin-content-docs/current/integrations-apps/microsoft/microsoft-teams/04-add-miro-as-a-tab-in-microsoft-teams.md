ユーザーはMiroボードをMicrosoft Teamsのミーティング、チャンネル、カレンダーイベントに追加して、他のチームメンバーとシームレスにコラボレーションしたり、アクセスを共有したりすることができます。
この記事では、Miroの使い方を学びます：

- Microsoft Teams 会議
- Microsoft Teamsカレンダーイベント
- Microsoft Teamsチャンネルとチャット

## Microsoft TeamsミーティングにMiroを追加します。

- モバイルやタブレットを利用して MS Teams 会議に参加するユーザーは、添付された Miro ボードを閲覧することはできますが、編集やコメントはできません
- Miroアプリを承認したMicrosoft Teamsユーザーなら誰でも、Miroを会議に追加できます。Miro のプロフィールをお持ちの Teams ユーザーなら誰でも、センターステージにボードを共有することができます
- ⚠️ Microsoft は、Teams の会議でゲストユーザーがアプリを使用できる機能をサポートしていません。ユーザーは、どんなアプリを使用する場合にも（Miro を含む）、Teams にログインする必要があります。

1. ドロップダウンの**More actionsを**クリックします**。**
2. **アプリを追加]**を選択します**。**
3. Miro を検索し、Miro のアイコンをクリックします。
4. ここでは、Miro のプロフィールに登録またはログインするよう求められます。
5. 共有したいボードを選択するか、新しい空白のMiroボードを作成します。
6. 他の会議参加者の権限を設定し、ボードへのアクセスを許可または制限します。以下のアクセス権タイプから選択できます。

- **誰でも編集可能**（Miroへのログイン不要）
- **誰でもコメント投稿可能**（ログイン不要、フリーチーム内のボードには非対応）
- 全員が閲覧可（ログイン不要）
- **非公開**（過去にボードにアクセスしたことのある人だけがコラボレーションできます）

**「誰でも編集、コメント投稿、閲覧可能**」では、Microsoft Teamsテナント内の誰でもボードにアクセスできます。これには次が含まれます。

- 組織外の他の Miro ユーザー
- Miro プロフィールを持たないユーザー
- Miro にログインしていない組織内のユーザー

:::note
Miro でボードに設定されている共有設定は、Microsoft Teams 内でのボード アクセスも定義できます。ボードがMiroで一般に共有されている場合、ボードを[プライベートとして](../../../using-miro/sharing-boards/15-make-a-miro-board-private.md)ピン留めしていても、Microsoft Teamsの誰でも利用できます。ただし、Miro側でボードを非公開にしていて、「誰でも閲覧/コメント投稿/編集が可能」にしてピン留めしている場合、Miro側のボードへのアクセスは影響を受けません。詳細は[こちら](../../integrate-miro-with-other-apps/01-user-permissions-for-boards-embedded-in-third-party-apps.md)をご覧ください。
:::

> ️️✏️ Enterprise プランの場合、アクセス設定は組織全体のアクセス管理に従います。**会社の**管理者は、**会社の設定**> セキュリティーで、埋め込み用のパブリックリンク共有を有効にする必要があります。詳しくは、[埋め込みインテグレーションのEnterprise共有ポリシーの](../../../enterprise-administration/managing-apps-on-enterprise-plan/05-how-to-allow-or-restrict-embedding-miro-boards-in-supported-apps.md)管理をご覧ください。

埋め込みボードのアクセス権を変更する必要がある場合、タブを削除し、別のアクセスレベルで追加しなおします。

これで、会議中いつでも特定のタブからMiroボードにアクセスできるようになりました。複数のボードを作成した場合、各ボードには1つのタブがあります。

Miro をクリックすると、右側に Miro のタブがポップアップし、この会議に添付したボードが表示されます。[

ステージに共有] ボタンを選択して参加者全員にボードを送信すると、同時にコラボレーションすることができます。上部の [プレゼンテーションを停止] ボタンをクリックすると、いつでもボードの共有を停止することができます。

## Microsoft Teamsのカレンダーイベントにボードをピン留め

:::note
Outlook カレンダーはまだサポートされていません。
:::

- ⚠️ Miro ボードを会議に添付するには、Teams のカレンダーイベントを保存し、少なくとも 1 名の参加者が必要です。
- ⚠️ [チームの会議の招待から Miroボードを削除する方法はありません（Microsoft](https://support.microsoft.com/en-gb/office/remove-a-tab-in-microsoft-teams-c18c875c-0738-40ec-a228-61d7eb27f745#:~:text=In%20one%2Don%2Done%20and,the%20tab%20and%20select%20Remove.) の参照記事）。ボードなしで招待を削除し、新しい招待を作成する必要があります。

1. まず、新しい Microsoft Teams のカレンダー会議をスケジュールします。会議の名前を追加し、参加者を招待してください。
2. クリック **送信**をクリックして招待状を共有します。
3. **会議が保存されたら、再度会議をクリックし** [編集] を選択します。そうすることで Miro ボードを添付できます。
4. Miroをタブとして固定するには、画面上部のプラス記号**（+）を**使用します。
5. 次の画面で、Miroアプリを追加するよう促されます。検索バーでMiroを検索するか、すでに表示されている場合はMiroを選択してください。
6. Miroを追加できるように、 **Addを**選択 します。
7. Teams内のMiroプロフィールにログインするよう求められます。
8. Miro にログインしたら、会議に追加するボードを選択するように求められます。既存のボードを検索して選択するか、新しい空白のボードを作成することができます。
9. ここでは、残りの会議参加者にアクセス権限を設定し、ボードへのアクセス権を付与または制限することもできます。次に **保存 を選択し 、選択した Miro ボードを Teams ミーティングに添付できるようにします。以下のアクセス権タイプから選択できます。**

- **全員が編集可**（ログイン不要）
- **全員がコメント可**（ログイン不要）
- **全員が閲覧可**（ログイン不要）
- **非公開**

## ボードをMicrosoft Teamsチャンネルやチャットにピン留め

> **設定者：**[ボードが](../../../using-miro/sharing-boards/01-board-access-rights.md)設置されているチームのメンバーである[ボードオーナーと](../../../using-miro/sharing-boards/01-board-access-rights.md) [ボード編集者](../../../using-miro/sharing-boards/01-board-access-rights.md)

Microsoft Teamsチャンネルにボードをピン留めするには、新しいタブを作成します。

1. プラスアイコンをクリックしてください。
2. ピッカーが開き、様々なアプリが表示されます。
3. アプリのリストから Miro を検索し、選択します。
4. 同じブラウザー上、またはデスクトップ アプリ内の Miro で認証がされていない場合、ログインが必要です。**[Get Started]**（始める） をクリックしてログインするか、[Miro で登録](../../../getting-started/start-here/02-how-to-register-with-miro.md)してください。
5. 認証されると、Miro のボードでピッカーが表示されます。ピッカーには、Miro 側でアクセスできるボードが表示されます。なお、Miro と Microsoft Teams ではそれぞれ異なるメールアドレスでの認証が可能です。
6. Microsoft チームのチャンネルに追加したいボードを選択してください。必要なアクセスレベルを持たないボードを選択すると、警告メッセージが表示されます。
7. 他の会議参加者の権限を設定し、ボードへのアクセスを許可または制限します。以下のアクセス権タイプから選択できます。

   - **全員が編集可**（ログイン不要）
   - **全員がコメント可**（ログイン不要）
   - **全員が閲覧可**（ログイン不要）
   - **非公開**
   > ✏️ ️️Microsoft Teams のモバイルアプリで Miro を使用する Microsoft Teams のユーザーは、設定された権限に応じて、ボードの閲覧やコメントができます。ボードを編集するためには、ユーザー インターフェイスを最適化した Miro の[モバイル ネイティブアプリ](../../../getting-started/apps-for-devices/08-mobile-app.md)をインストールすることをお勧めします。

   ## よくある質問

Microsoft Teams に埋め込まれたボードを閲覧するには、各チームメンバーに Miro のプロフィールが必要ですか？

ー ボードを埋め込む際に、**全員が閲覧 / コメント / 編集可**を選択すると、登録されていないユーザーもボードを閲覧やコメントをすることができます。また、Miro 側でボードが公開共有されている場合は、Microsoft Teams 内の全員が利用することができます。

ボードの埋め込み後、MS Teams でボードのアクセスを変更できるのは誰ですか？（例：「全員が閲覧可」から「非公開」への変更）

ー 添付されたボードへのアクセス権を変更することはできません。ボードを追加した本人でも変更できません。ただし、誰でもタブで **[設定]** をクリックして、同じタブで別の（もしくは同じ）ボードを選択し、選択したボードで別のアクセスレベルを選択することは可能です。

メールを 2 つ Miro に登録しており、2 番目の Miro プロフィールから Miro ボードを埋め込みたいのですが、Miro プロフィールを切り替える方法を教えてください。

ー Miro に認証されたユーザーのボードは、同じブラウザー内でピッカーに表示されます。別のブラウザータブで Miro を開き、ログアウトしてから、2 番目の Miro プロフィールにログインします。

Microsoft Teams のデスクトップアプリを使用する場合は、アプリからログアウトします。すると、アプリ内の Miro からもログアウトされることになります。次にアプリにログインし、[ボードの埋め込み](05-embed-miro-boards-in-microsoft-teams.md)をしてください。Miro のログイン画面が表示され、別の Miro プロフィールでログインすることができます。
