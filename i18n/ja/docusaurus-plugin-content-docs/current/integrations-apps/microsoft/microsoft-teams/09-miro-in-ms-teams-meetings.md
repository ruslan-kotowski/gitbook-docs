Microsoft Teams (MS Teams) 会議に新規または既存の Miro ボードを埋め込みます。通話を切断することなく、即座に共同作業を開始できます。

## Microsoft TeamsミーティングにMiroボードを追加する方法

#### 前提条件

以下の前提条件を満たしていることを確認してください：

- Miro for Microsoft Teamsが有効になっています。方法については、[Miro for Microsoft Teamsの概要を](06-miro-for-microsoft-teams-overview.md)参照してください。
- あなたは埋め込みたいボードを所有するMiroチームのメンバーです。
- あなたは、埋め込みたいボードのボードオーナーまたはボード編集者です。

#### 手順

以下の手順を実施してください。

1. Microsoft Teamsで、チームを選択します。
2. プラスアイコン**(+**)を選択
   **タブの追加**]モーダルが開きます。
3. **Miroを**選んでください。
4. **スタート**」を選択します。
   まだログインしていない場合は、Miroにログインするよう促されます。
5. 埋め込むMiroボードを選択するか、新しいボードを作成します。
   > ✏️ ボード所有者またはボード編集者のロールを持ち、埋め込みたいボードを所有するMiroチームのメンバーである必要があります。
6. 埋め込みに参加している人のアクセス許可を選択します。
   ![Microsoft TeamsのMiro埋め込みに対する権限の選択](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22476127831698_image.png)
7. **[保存]** を選択します。
   ボードはMS Teamsのタブに埋め込みます。

   Microsoft Teams 会議に Miro ボードが追加されました。
