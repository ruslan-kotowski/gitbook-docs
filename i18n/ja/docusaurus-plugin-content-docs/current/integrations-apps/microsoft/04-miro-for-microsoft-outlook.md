拡張されたMiroリンクでOutlookメールにコンテキストをもたらします。このインテグレーションにより、ユーザーはOutlookの電子メールで送信された各Miroリンクに関する詳細情報を得ることができます。

> **利用可能なプラン：**Miro の全プラン
> **利用可能な環境：**デスクトップ

:::note
ユーザーは、Outlookエクスペリエンスを使用する前に、Microsoft Teams用のMiroインテグレーションを有効にする必要があります。詳細については、[Microsoft Teamsの](microsoft-teams/01-miro-for-microsoft-teams-admin-guide.md)ドキュメントを参照してください。
:::

## Miro for Microsoft Outlookの仕組み

Miro for Microsoft Outlookには、ユーザーエクスペリエンスを向上させる2つの重要な機能、リンクの展開とメッセージ拡張子の検索が含まれています。

ユーザーがメールにMiroリンクを追加すると、リンクはアダプティブカードに展開し、タイトル、ボードの所有者、最終更新時間など、ボードに関する詳細情報を得ることができます。

![](../../../../../../docs/integrations-apps/microsoft/images/20647652622098_9d5d21ee-76f3-4e99-9740-6095aa310079.png)

*Miroのリンクは自動的にアダプティブ・カードになります。*

メール作成画面から、ユーザーはアプリのメニューからMiroインテグレーションにアクセスし、Miroボードを検索することができます。

![](../../../../../../docs/integrations-apps/microsoft/images/20647667523090_5d17d2ad-8790-47d0-9b5c-7025ecde97d5.png)

*Outlookからボードを検索し、メールに挿入することができます。*
