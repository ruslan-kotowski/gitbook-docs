Miro が誇るコラボレーションの強みと、Power BI の分析力を組み合わせましょう。Power BI レポートとダッシュボードを Miro ボードに直接埋め込むことで、チームの意思決定プロセスを効率化し、データに基づく戦略を視覚化して、明確かつ精確にプロジェクトの進捗を促進できます。

- 埋め込まれた Power BI データを活用することで、リアルタイムのインサイトの取得、情報に基づいた意思決定を可能にします。
- Miro ボードに Power BI データが含まれるチャートを追加して更新することで、チームメンバーとの効果的なコラボレーションを実現します。

## Microsoft Power BI レポートを Miro に埋め込む方法

:::tip
組織で、Power BI インテグレーションが設定済みであることを会社の管理者に確認してください。
:::

1. Microsoft Power BI に移動し、ブラウザーのアドレスバーからレポートまたはダッシュボードのリンクをコピーします（共有メニューのリンクは現在未対応ですので使用しないでください）。
2. コピーしたリンクを Miro ボードに貼り付けます。
3. **[リンク]** をクリックして、Microsoft Power BI で Miro アプリを認証します。
4. リンクすると、埋め込むチャートを選択するためのダイアログが開きます。リストが元のレポートと一致することを確認してください。
5. **[全チャートを追加]** をクリックして、ボードに埋め込みます。
6. チャートが、画像として Miro ボードに追加されます。

## Power BI データを Miro に埋め込むための要件

Power BI レポートまたはダッシュボードを Miro ボードに埋め込むには、以下が必要です。

- Power BI インテグレーションが有効になっている Miro チームまたはアカウントに属していること。
- 埋め込む Power BI レポートまたはダッシュボードへのアクセス権を持っていること。
- Power BI データを埋め込む Miro ボードが、公開リンクを介して共有されていないことを確認すること。
- サポートされている Power BI クラウドサービス（Power BI Premium キャパシティ単位 SKU または Fabric 能力の予約 SKU）を所有していること。オンプレミスサービスはサポートされていません。

## 埋め込み Power BI データの表示と編集

埋め込み Power BI データが含まれる Miro ボードにアクセスできるユーザーは、Power BI の認証やライセンスステータスに関係なく、データを表示することができます。これには、ボードに対する閲覧、コメント、編集権限を持つユーザーが含まれます。

埋め込み Power BI データが含まれる Miro ボードに対する編集権限がある場合は、元の Power BI コンテンツに対するアクセス権がなくても、**更新**機能を使用して更新し、**チャートを追加**の機能を使用してチャートを追加することができます。ただし、インテグレーションを通じて元のチャートのデータを確認またはアクセスすることや、フィルターを変更することはできません。

## データの保存

埋め込み Power BI データには、すべての顧客データに適用される Miro の標準データ保存ポリシーが適用されます。[Miro のデータ処理規約](https://miro.com/legal/documents/Miro-Data-Processing-Addendum.pdf)をお読みください。

## トラブルシューティング

次に紹介するトラブルシューティング手順は、Miro で Power BI インテグレーションを使用する際によくある問題を解決するのに役立ちます。

認証および管理者の承認に関する問題

アプリを認証できない場合、または管理者の承認を求めるプロンプトに承認を要求するためのオプションが表示されない場合は、会社の管理者に問い合わせて承認の要求機能が有効になっていることを確認してください。**管理者の承認が必要**というウィンドウが表示される場合は、このウィンドウ画面から承認を要求します。

埋め込みに関する問題

チャートが予想通りに表示されない場合は、会社の管理者に連絡して、適切な Microsoft Power BI サブスクリプションを有していることを確認してください。

リンクの検証

見つからないアイテムがある場合は、使用したリンクをもう一度確認し、ブラウザーのアドレスバーから直接コピーしたものであることを確認してください。
