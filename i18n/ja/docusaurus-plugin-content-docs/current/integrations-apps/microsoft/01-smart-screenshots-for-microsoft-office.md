スマートスクリーンショットにより、Miro のボードやウィジェットを Microsoft Word、PowerPoint、Excel に直接画像として貼り付けることができます。コンテンツの同期を維持するための拡張機能も備えております。

## Miro のスマートスクリーンショット

:::note
Microsoft の管理者が、組織やチームのために[Miro Microsoft Office アドオン](https://miro.com/marketplace/microsoft-office/)をインストールする必要があるかもしれません。利用できない場合は、管理者に確認してください。
:::

Miro のサイドパネルインテグレーションにより、ドキュメントを離れることなく、Miro ボードのコンテンツを Microsoft Word、PowerPoint、Excel ファイルに直接埋め込むことができます。この機能により、Miro ボードへのシームレスなアクセスが可能となり、拡張機能を持つビジュアルコンテンツを挿入することができます。

## Miro サイドパネル

Microsoft Word、PowerPoint、Excel の Miro サイドパネルには、次の機能が含まれています：

- **ボードへ直接アクセス：**アプリケーションを切り替えることなく、Microsoft Word、PowerPoint、Excelから直接Miroボードにアクセスできます。
- **ボードの選択：**「Miro ボードを埋め込む」を選択するボタンを使用して、利用可能な Miro ボードから選択できます。
- **インタラクティブ プレビュー：**挿入する前に、Miro ボードから特定のコンテンツを閲覧して選択します。
- **正確な配置：**ドキュメント内のカーソルの位置に正確にコンテンツを挿入します。
- **スマート機能：**埋め込まれたコンテンツは、元のMiroボードとの接続を維持します。

## Miro サイド パネルの使用方法

1. Microsoft Word、PowerPoint、Excel ファイル内で、Miro コンテンツを挿入したい位置にカーソルを置きます。
2. **Miro インテグレーション アイコン**をクリックして、右側のパネルを開きます。
3. **Miro ボードを埋め込むのを選択**をクリックして、利用可能な Miro ボードから選択します。
4. ボードのプレビューから埋め込みたい特定のエリア、フレーム、またはコンテンツをブラウズして選択します。
5. 利用可能なドロップダウンオプションを使用して、異なるビュー設定や選択肢を選択します。
6. **確認**をクリックして、カーソル位置にコンテンツを挿入します。

埋め込まれたコンテンツは、元の Miro ボードへのスマート チップ接続を伴ったスクリーンショットとしてドキュメントに表示されます。

:::note
Miro サイドパネルは[Miro Microsoft Office アドオン](https://miro.com/marketplace/microsoft-office/)のインストールが必要です。この機能は Microsoft Word、PowerPoint、および Excel で動作します。
:::

## アドオンを管理者として管理する

Miro アドオンを管理する Microsoft 管理者である場合、以下のポイントをご確認ください。

- Microsoft Office アドオンは、Microsoft 側でのみインストールまたは削除できます。
- Microsoft Office スマートスクリーンショットへのアクセス制限を設定したい場合は、Microsoft 側で行う必要があります。Miro は、どのユーザーがスマートスクリーンショットをインストールし使用するかを管理できません。

## よくある質問

**どの Microsoft Office アプリケーションが Miro インテグレーションをサポートしていますか？**

Miro サイドパネルは、Microsoft Word、PowerPoint、Excel と共に機能します。

**埋め込まれた Miro ボードの要素はどのように更新されますか？**

Miro サイドパネルを通じて埋め込まれたコンテンツは、元の Miro ボードとの接続を保持します。自動的に同期はされませんが、埋め込まれたコンテンツを更新することで、Miro ボードの最新バージョンを反映させることができます。

**Miro のサイドパネルはどのように機能しますか？**

Miro のサイドパネルにより、ドキュメントを離れることなく、Miro ボードに直接アクセスできます。Miro インテグレーションアイコンをクリックして右側のパネルを開き、「Miro ボードを埋め込む」を使用して利用可能なボードから選択します。このパネルでは、ドキュメントのカーソル位置に挿入する前に、特定のエリアやフレームをプレビューして選択することができます。
