このガイドでは、Microsoft Power BI と Miro のインテグレーションを検討されている組織向けに、インテグレーションを設定する方法、チームでインテグレーションを有効にする方法、およびセキュリティー上の考慮事項に対処する方法について順を追って説明します。

主な機能：

- Power BI レポートとダッシュボードを Miro ボードに埋め込む
- Miro ボードにインポートするチャートを指定する
- 更新された Power BI コンテンツを Miro ボードから直接リクエストする

:::tip
Power BI インテグレーションは現在、非公開ベータ版です。
:::

### 実装に利用する技術

Miro と Power BI のインテグレーションは [REST API](https://learn.microsoft.com/rest/api/power-bi/) および [Power BI Embedded 分析クライアント API](https://learn.microsoft.com/javascript/api/overview/powerbi/) によって行われます。ユーザーは、Power BI アクセスを許可することで Power BI レポートまたはダッシュボードを Miro ボードに簡単にリンクできます。認証には、[OAuth2.0](https://learn.microsoft.com/entra/identity-platform/v2-protocols) を採用しています。

### インテグレーションの要件

サブスクリプションに以下が含まれることを確認します。

- Power BI クラウド
- サポートされるサブスクリプション：
  - Power BI Premium キャパシティ単位 SKU
  - Fabric 能力の予約 SKU

## Power BI インテグレーションの設定

1. Microsoft Entra に管理者としてログインします。
2. **[エンタープライズ アプリケーション]** > **[同意とアクセス許可]** > **[管理者の同意設定]** に移動します。
3. **[管理者の同意要求]** にある **[ユーザーは、自分が同意できないアプリに対して管理者の同意を要求できます]** を **[はい]** に設定します。
4. **[管理者の同意要求を確認できるユーザー]** で、管理者の同意要求を確認できるようにする必要があるユーザー、ロールおよびグループを選択します。
5. これで、ユーザーは承認を求めることができるようになります。管理者以外のユーザーが承認リクエスト画面を表示させるには、Miro と Power BI のインテグレーションのテストが有効になっている Miro チーム上の Miro ボードに Power BI リンクを貼り付ける必要があります。
6. ステップ 4 で選択した管理者は、[管理者の同意要求] の画面に移動して未承認の要求を承認することができます。
7. いったん承認されると、すべてのユーザーが自分で認証することで Miro と Power BI のインテグレーションを利用できるようになります。
8. インテグレーションが機能するかどうかを確認するには、インテグレーションを有効にしたチームに属する Miro ボード上に Power BI ダッシュボードまたはレポートへのリンクを貼り付けます。
9. **リンク**をクリックして、Power BI ウェブページで認証を行います。
10. ダイアログが開き、埋め込むチャートを選択するよう求められます。チャートを選択し、**[チャートを追加]** をクリックします。
11. チャートが、画像として Miro ボードに追加されます。

## Power BI インテグレーションをオフにする方法

管理者は、Microsoft Entra の [エンタープライズ アプリケーション] から Miro アプリを削除することで、アクセス権限を取り消すことができます。

1. Microsoft Entra にログインします。
2. **[エンタープライズ アプリケーション]** > **[同意とアクセス許可]** をクリックします。
3. アプリケーションのリストで **[すべてのアプリケーション]** を見つけて、選択します。
4. リストから **[Contenthub Microsoft Power BI インテグレーション]** アプリを見つけます。
5. アプリをクリックして、アプリのプロパティーにアクセスします。
6. アプリケーションのプロパティーで **[削除]** をクリックします。

## インテグレーションの制限事項

- 公開ボードに埋め込むことはできません。
- データセットリンクの埋め込みには対応していません。
- 共有メニューから取得するリンクの埋め込みには対応していません。

## データの保存

埋め込み Power BI データには、すべての顧客データに適用される Miro の標準データ保存ポリシーが適用されます。[Miro のデータ処理規約](https://miro.com/legal/documents/Miro-Data-Processing-Addendum.pdf)をお読みください。

貼り付けられた Power BI リンクからさまざまな種類のデータが画像として取得され、Miro に保存されます。

- Power BI ダッシュボードからのタイルの画像
- Power BI レポートからのビジュアルの画像
- Power BI ダッシュボード、レポート、ビジュアルおよびタイルのタイトル
- Power BI レポートからのページ名
- Power BI レポートからの検索条件名と値

## よくある質問

Power BI インテグレーションはなぜベータ版なのですか？

ベータ版は、フィードバックを集めて安定性とユーザー体験を向上させる目的で実施される段階です。引き続き、セキュリティーが最優先の課題です。
