**主な機能**

- Miro のボードを Asana 内に埋め込むと、他のユーザーが閲覧、コメント、編集することができます。
- コメントやテキスト、図形を追加したり、あるいは描画ツールを使ってフィードバックを残したりなど、ボード上のコンテンツとやり取りします。
- 簡単にズームインやズームアウトして、ボードを自由に見ることができます。

> **利用可能なプラン：**すべての Miro プラン

### Asana 内に Miro のアプリをインストールして認証する方法

Asana Marketplace [から Miro のアプリを認証してインストールします](https://app.asana.com/-/install_platform_ui_app?app_id=1201153108289813)。

### Asana プロジェクト概要に Miro を埋め込む方法

埋め込みを行う Miro のボードを開きます。右上の [共有] ボタンをクリックします。表示されるダイアログで [ボードのリンクをコピー]/span> をクリックします。

copy_board_link.jpg
/span>ボードのリンクをコピーするオプション

ブラウザーのアドレスバーやダッシュボードからボードのリンクをコピーすることもできます。

copy_link_from_dashboard.jpg
/span>ボードメニューのリンクをコピー

Asana で、ボードの埋め込みを行うプロジェクトを開きます。[概要] タブ/span>に移動します。

**[主な参考資料]** セクションで、**[プロジェクトの概要を作成]** をクリックします。すでにプロジェクト概要が存在する場合は、タイトルのどこかをクリックします。

create_project_brief.jpg
/span>Asana でプロジェクト概要を作成するオプション

概要の中で、埋め込む場所をクリックします。URLを貼り付けると、その下にボードのプレビューが展開されます。プレビューをクリックしてボードを読み込みます。

board_preview.jpg
/span>Asana プロジェクトの概要で Miro のボードをプレビュー
