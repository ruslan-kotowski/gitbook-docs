Google Workspace™ と Miro を接続することで、どこからでもビジュアル コラボレーションを強化し、会議でのエンゲージメントや創造性を高める強力で使いやすいツールを提供します。このインテグレーションにより、Miro を Google ドライブ、ドキュメント、Meet、カレンダーに接続できます。

## 主な機能

Miro アドオンをインストールすると、ワークフローを効率化するためのいくつかの主な機能を活用できます。

- Miro ボードを[Google カレンダー](08-miro-for-google-calendar.md)の招待に追加します。
- [Google Meet](09-miro-for-google-meet.md)内でボードを直接閲覧し、共同作業が可能です。
- [Google ドキュメント](10-smart-chips-smart-screenshots-for-google.md)にボードプレビュー付きの Miro スマートチップを埋め込みます。
- Miro ボードを[Google ドライブ](05-google-drive.md)に保存します。
- [Google Chat](01-miro-for-google-chat.md) を介して、通知を受け取ったり、Miro ボードのリンクをプレビューしたり、Miro ボードを作成したりできます。

:::note
Google Workspace の管理者によって、Miro アドオンを Google Workspace の組織やチームにインストールしなければならない場合があります。利用できない場合は、管理者に確認してください。
:::

## Miro アドオンのインストール

Miro アドオンを Google Workspace 製品に接続するには、まずインストールする必要があります。Google Docs または Google Calendar のサイドバーで Miro の「M」ロゴを確認することで、アドオンがすでにインストールされているかどうか確認できます。

アドオンのインストール方法:

1. [Google Workspace マーケットプレイス](https://workspace.google.com/marketplace/app/miro/1062019541050)にアクセスします。
2. **インストール**をクリックします。
3. アドオンに接続したい Google アカウントを選択します。

アドオンがインストールされると、サイドバーに Miro のアイコンが表示され、インストールが成功したことが確認できます。

## Google API サービスユーザーデータポリシー

Google Workspace 用 Miro が Google API から受信した情報の使用は、[Google API サービス ユーザーデータ ポリシー](https://developers.google.com/terms/api-services-user-data-policy)に従い、リミテッドユースの要件も含めて対応します。Google Workspace API は、一般的/非パーソナライズされた AI や ML モデルの開発や改善、学習には使用されません。

## よくある質問

Google Workspace 用 Miro アドオンのインストールに関するよくある質問の回答を以下に示します。

Miro の管理者ですが、組織に Miro アドオンをインストールするにはどうすればよいですか？

Google Workspace の管理者は、組織内のユーザーのためにアドオンをインストールし、それを管理できます。詳細は、[Google Workspace マーケットプレイス](https://support.google.com/a/topic/1056395?hl=en&ref_topic=27380)を参照してください。

なぜ Miro アドオンをインストールできないのですか？

管理者がアドオンを無効にしている可能性があります。または、管理者にインストールを依頼する必要があります。
