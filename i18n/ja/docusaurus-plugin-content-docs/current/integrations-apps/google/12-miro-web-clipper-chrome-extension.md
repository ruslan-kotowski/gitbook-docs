:::note
Miro Web Clipper は、2026 年 2 月 1 日をもってインストールできなくなり、メンテナンスも終了します。既にインストール済みのユーザーは、現在の状態のまま使用できます。

画像のアップロード、クリップボードからの貼り付け、またはキャンバスへのドラッグで、スクリーンショットを Miro に追加できます。
:::

Chrome でウェブページをキャプチャし、できるだけ手間をかけずに Miro のライブラリーに保存しましょう！

### 拡張機能の使用方法

1. Miro のライブラリーにウェブサイトのスクリーンショットを直接保存したいときは、Chrome の **Web Clipper アイコン**をクリックして拡張機能を開き、スクリーンショットを保存する**チーム**と保存したい領域（**表示領域**、**選択領域**、または**ページ全体**）を選択します。

![Web_clipper_menu.jpg](../../../../../../docs/integrations-apps/google/images/21016020037138_Web%20clipper%20menu.jpg)
*Miro の Web クリッパーのメニュー*

2. Miro のボードに保存したウェブページを追加する準備ができたら、ボードを開きます。ボードは、スクリーンショットを撮る際に選択したチームに属している必要があることにご注意ください。

3. 作成バーで**ツール、メディアとインテグレーション**(**+**)**.**パネルが開きます。**ツール**のタブで Web Clipper を検索します。**アップロード**を選択し、**Web Clipper**を選択します。
保存したスクリーンショットのギャラリーが開きます。必要なスクリーンショットをクリックするか、ボードにドラッグ & ドロップします。

![Miro_web_clipper.gif](../../../../../../docs/integrations-apps/google/images/21016020034962_Miro%20web%20clipper.gif)
*ツールバーの Web Clipper*

以下の場合には、Miro Web Clipper を最大限に活用することができる点にご注意ください。

- Miro のプロフィールにログインします（ログインしていれば拡張機能のアイコンがアクティブになっています）
- 拡張機能をインストールした後、ボードのウェブページが開いていれば更新されます（1 回のみ必要）

:::warning
Web クリッパーは、認証が必要なページでは機能しません。
:::

### よくある質問

1. *スクリーンショットを保存しましたが、Web Clipper ライブラリーに表示されません。*
   - スクリーンショットを保存する際に正しいチームを選択していることを確認してください。スクリーンショットは、このチームのボードの Web クリッパー ライブラリーに属することになります。
   また、拡張機能は認証が必要なページでは機能しませんのでご注意ください。
   拡張機能がどのページでも機能しない場合は、**削除して再度インストール**してみてください。
