[Confluence プラグイン](https://help.miro.com/hc/articles/360020712594)使用の際に問題が発生した場合は、以下のトラブル シューティングのヒントをご覧ください。

|  |  |  |
| --- | --- | --- |
| **メッセージ / 問題** | **考えられる原因** | **問題解決の手順** |
| Miro にログインしようとする時 / Confluence ページに Miro のボードを埋め込もうとする時に、黒 / 空白の Miro のピッカーが表示されます | ブラウザーの設定が正しくない | ブラウザー設定に移動し、以下を確認してください。   - **[サイト越えトラッキングを防ぐ]** のチェックボックスが無効になっている - [**すべての Cookie をブロックする**] チェックボックスが無効になっています。   mceclip0.png   - Miro と Atlassian ウェブサイトの**ポップアップ ウィンドウ**が許可されています。   mceclip1.png |
| このボードは閲覧でのみアクセスでき、共有や埋め込みはできません  **mceclip0.png** | ボードの編集者 / 所有者ではない | 以下の点をご確認ください。   - 編集者またはボード所有者です - Miro のブラウザーで自分の資格情報を使用して認証されています - 同じブラウザーで Confluence にボードを埋め込んでいる |
| Miroボードを埋め込むと、メッセージが表示されます： 「Miroはクッキーファイルへのアクセスを要求します。 | 使用しているブラウザーには、サードパーティーの Cookie を保存することができない | 埋め込みを有効にするには、お使いのブラウザーの Cookie を有効にする必要があります。これは主に Mozilla と  Safari で発生します |
| 埋め込まれたボードに、「セッションの有効期限が切れました」というエラーメッセージが表示される |
| ボードを埋め込もうとすると、次のようなメッセージが表示されます："あなたはどのチームのメンバーでもありません。フルバージョンの Miro プロダクトにログインし、チームを作成するか、他のユーザーから既存のチームに招待してもらってください。」  mceclip0.png | ブラウザーで認証された Miro のプロフィール内のどのチームのメンバーでもありません。 | [Miro](https://miro.com/app/dashboard/) でチームを作成します。Miro で、いずれかのチームにメンバーとして属していると思われる場合は、別のブラウザータブで Miro を開き、**正しいメールアドレス**で認証されているかどうか確認してください。 |
