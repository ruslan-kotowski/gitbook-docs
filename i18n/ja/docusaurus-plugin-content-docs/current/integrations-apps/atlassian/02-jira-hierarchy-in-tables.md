Jira の課題を Miro のテーブル形式にインポートできます。テーブルによって、戦略的イニシアチブやワークフローの全体像を確認でき、高レベルのエピックから具体的なチケットの詳細まで把握できます。

**詳細情報:** [Jira カードに関する FAQ](https://help.miro.com/hc/articles/360013463739)。

## Jira の課題をボードにテーブルとしてインポート

1. Miroのボード上で、作成バーの「ツール、メディア、インテグレーション」（＋）をクリックします。
2. Jiraカードを検索して選択します。
   初めてJiraに接続する場合は、認証が必要です。
   **課題を選択**モーダルが開きます。
3. Jiraの課題を検索して選択します。
   **課題を選択**には、アクセス権限のあるJiraの課題のみが含まれます。
4. 課題を**テーブル**フォーマットで追加します。
   ![](../../../../../../docs/integrations-apps/atlassian/images/32535032016146_image.png) *追加セレクターを使用してテーブルフォーマットを選択できます。*
5. **追加*****x***をクリックします。

## Jira 子レコードのインポート

親の課題をテーブルとしてインポートした後、子の課題をインポートできます。

以下の手順に従ってください。

1. テーブルで、子案件をインポートしたい行の最初の列で縦に並んだ6つの点をクリックします。メニューが開きます。
2. **子レコードをインポート**をクリックします。
   **案件を選択**モーダルが開きます。
   ![](../../../../../../docs/integrations-apps/atlassian/images/32535032016146_image.png) *案件をインポートした後、子案件をテーブルにインポートできます。*
3. インポートしたい子案件を選択します。
4. **追加** ***x*****をクリックします。**

### ネスト ビューを切り替え

親の課題と子の課題の階層ビューを切り替えるには、**ビュー設定**ボタンをクリックします。そして、**ネスト**をオンに切り替えます。

![](../../../../../../docs/integrations-apps/atlassian/images/32535032016146_image.png) *親と子の課題のための階層ビューを切り替えます。*

:::tip
階層ビューでは、子のレコードを折りたたんだり展開したりできます。親の課題は、子の課題が存在するかどうかを示すインジケーターを持っています。
:::

## テーブルレイアウトを変更する

テーブルレイアウトを変更するには、**レイアウト**ボタンをクリックしてください。それからレイアウトを選択します。

例えば、ツリー形式レイアウトを使用したい場合。

![](../../../../../../docs/integrations-apps/atlassian/images/32535032016146_image.png) *Jira 課題テーブルのレイアウトを変更します。*

:::note
(Enterprise) ツリービューはパブリックベータ版であり、Enterprise Advanced ライセンスでのみ利用可能です。詳細については、[Enterprise ライセンスについて](https://help.miro.com/hc/articles/33311996124306)をご覧ください。
:::
