## Jira と Miro の接続

### アプリのインストール方法

1. [ダッシュボード](https://help.miro.com/hc/articles/360017571294-What-is-on-your-dashboard)の右上のコーナーで、アバターをクリックし、**インテグレーションとアプリ**をクリックして、インテグレーションを有効にします。![mceclip0.png](../../../../../../docs/integrations-apps/atlassian/images/21017417672210_mceclip0.png)
   *アプリの管理*
2. **検索**行で「Jira カード」を検索し、ポップアップ メニューの右下にある青い**Connect**ボタンをクリックします。
3. **「Jira カード」**を追加するウィンドウが表示されます。ここで、インストールを確定するか、インテグレーションをインストールしたいチームを選択する必要があります（複数のチームのメンバーの場合）。**「追加」**をクリックしてインテグレーションを追加します。ダッシュボードの上部に**アプリがインストールされました**という確認メッセージが表示されます。
   ![mceclip1.png](../../../../../../docs/integrations-apps/atlassian/images/21017417673362_mceclip1.png)
   *確認メッセージ*

### Jira プロフィールの接続

1. ダッシュボードで再びアバターをクリックし、**設定 > チーム >** *あなたのチーム名* **> アプリ&インテグレーション > Jiraカード**を選択し、**接続**をクリックします:
   ![mceclip2.png](../../../../../../docs/integrations-apps/atlassian/images/21017004818066_mceclip2.png)
   *インテグレーションの設定*
2. Jiraのページに送信され、接続を認証します。Jiraにログインして**承認**をクリックします。

### JiraインスタンスをMiroチームに接続する

OAuth 2.0により、複数のJiraインスタンスを同じチームとボードに接続できるようになりました。設定でアプリを認証した後、**別のインスタンスを接続**オプションが表示されます。

1. 作成ツールバーから Jira カードピッカーを起動します（**More apps +**ボタンを使用してアプリを追加する必要がある場合があります）。
2. ピッカーで、**設定**をクリックします。
3. 設定の**アプリとインテグレーション**セクションに移動します。**別のインスタンスを接続する**オプションを探し、接続したい Jira インスタンスを追加選択します。![mceclip0.png](../../../../../../docs/integrations-apps/atlassian/images/21017417672210_mceclip0.png)*Miro アカウントの Jira カードの設定*

チームの管理者は、チームのメンバーが接続したインスタンスをすべて確認することもできます。

![mceclip1.png](../../../../../../docs/integrations-apps/atlassian/images/21017417673362_mceclip1.png)

:::warning
インスタンスのカードを使用して作業しようとする場合、エンドユーザー全員が、接続されているすべての Jira インスタンスで、Miro のボードから認証する必要があります。
:::

> ✍️ 一度にアクティブにできるインスタンスは 1 つだけなので、ユーザーはそこからカードを引き出すことができます。非アクティブなインスタンスの既存のカードは、Miro ボードでも作業できます。

### Jira からのリアルタイム更新の設定

双方向同期のリアルタイムの利点をすべて享受するには、追加した Jira インスタンスに対して Webhook を設定する必要があります。これにより、Jira で行った更新が Miro にリアルタイムで反映されます。

1. 作成ツールバーからJiraカードピッカーを起動します（**「アプリを追加 +」**ボタンを使用してアプリを追加する必要がある場合があります）。
2. ピッカーで**「設定」**をクリックします。
3. 設定の**「アプリとインテグレーション」**セクションに移動します。
4. **「接続されたインスタンス」**セクションには、以前に追加したすべてのインスタンスが表示されます。
5. 各インスタンスの横に**「Webhookを追加」**するボタンがあります。これをクリックすると、そのインスタンスに対してJiraからMiroへのリアルタイム更新が設定されます。
6. 将来的にこのインスタンスからWebhookを削除したい場合は、上記の手順に従って**「Webhookを削除」**ボタンをクリックしてください。

:::note
Webhookをインスタンスに追加するには、Miro*および*Jiraの管理者である必要があることに注意してください。
:::

それで、完了です！これでホワイトボードに Jira タスクをカードとして追加することができます。Jira で行われた変更はすべて、ボード上の Jira カードに反映され、その逆も同様に反映されます。

## プラグインのアンインストール

**チームの設定 > アプリとインテグレーション > Jira カード**に移動し、**チームをアンインストール**をクリックします。

:::tip
[Jira カードの使用方法](https://help.miro.com/hc/articles/360017572434)に関する主要な記事を忘れずにチェックしてください！
