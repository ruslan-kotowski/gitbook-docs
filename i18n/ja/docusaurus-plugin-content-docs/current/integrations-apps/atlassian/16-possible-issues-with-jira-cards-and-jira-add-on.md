Jiraカードや[Jira Сards](https://help.miro.com/hc/articles/360017572434)または[Jiraアドオン](https://help.miro.com/hc/articles/360017572414-Jira-Add-on)をインストールまたは使用する際に問題が発生した場合、このガイドが役立ちます。

## Jiraカードに関する提案

| **接続** | |

| OAuth 1.0 に適用されます。（Jira サーバーとデータセンター）のみ。  **Jira URL が無効です /**  **Jira ベース URL を入力してください /**   **無効なリクエストです。デシリアライゼーションエラー。** | Jira がプライベート ネットワーク上にある / 会社のファイアウォールが外部のネットワーク接続をブロックしています。  [当社の NAT ゲートウェイの IP アドレス（およびポート）を許可リストに追加してください](https://help.miro.com/hc/articles/360017572694-Add-Miro-to-Allowed-Domains)。   *nslookup を使って IP アドレスを確認すると、結果はロードバランサーのアドレスを返しますが、このアドレスは時間の経過とともに変化する可能性があります。 |
| プロキシーを使用している / 外部と内部の Jira の URL が一致していない。  アクセス可能なアドレスで**Jira URL**フィールドを必ず入力してください。そのためには、リバースプロキシを構成して私たちがアクセスできるようにするか、 この [Atlassian ガイド](https://confluence.atlassian.com/jirakb/configure-jira-server-to-run-behind-a-nginx-reverse-proxy-426115340.html)の手順に従ってください。このソリューションを用いると、外部の URL と内部の URL が異なる場合でも、インテグレーションが Jira と Miro の間を正常に接続し、リクエストを転送できるようになります。  プロキシサーバーのタイムアウト値を延長することも検討してください。[エンドポイントのリストはここで見つけることができます。](https://help.miro.com/hc/articles/360017572694-Add-Miro-to-Allowed-Domains) [Jiraカードに関するFAQ](https://help.miro.com/hc/articles/360013463739-Jira-Cards-FAQ) |
| SSL証明書に問題があります（自己署名証明書はサポートされていません）。  Jira サーバーのアクティブな SSL 証明書を確認してください。[このツール](https://www.ssllabs.com/ssltest/)をお試しください：Jira の URL を入力し、接続チェックの結果を表示します。 例：証明書は正しいかもしれませんが（緑色の**証明書**）、サーバー証明書チェーンが不完全な場合があるため（黄色の**鍵交換**）、システムには証明書を更新する必要があるという応答が届きます。 [こちらのサイト](https://whatsmychaincert.com/)をご覧になり、解決してください。 |
| Jira が SSO の対象になっています（**受信認証が正しく設定されていません**というエラーが発生する場合もあります）。  SSO プロセスがインテグレーションの接続リクエストに適用されていないことを確認してください。 そのためには、以下のエンドポイントを SSO プロセスから除外する必要があります：   ``` GET \{JIRA_URL\}/rest/api/2/serverInfo (OAuth 1.0) POST \{JIRA_URL\}/plugins/servlet/oauth/request-token (OAuth 1.0) POST \{JIRA_URL\}/plugins/servlet/oauth/access-token (OAuth 2.0) POST \{JIRA_URL\}/plugins/servlet/oauth2/* ``` |
| インストール中に予期しない動作が発生 | Jira のバージョン 6.4 以下を使用している。  当社のカードはこれらのバージョンでは動作しません。 [この Jira バグ](https://jira.atlassian.com/browse/JRASERVER-42811)により発生します。Jira を最新バージョンに更新してください。 |
| **アプリの認証に失敗しました。もう一度アプリの認証を試みてください。** | 1. 一瞬の接続断です。**接続**を再度クリックしてください。  2. 認証手続き中に送信されたトークンの有効期限が切れています。キャッシュされたデータをクリーンアップし、新しい環境から始めてください。つまり、Jiraが新しいトークンを生成するように促してください。 |
| OAuth 1.0 に適用されます。（Jira サーバーとデータセンター）のみ。  **Jira エラー：「Miro の Webhook の作成権限がありません。」** | Jira の管理者権限がありません。インテグレーションを設定できるよう、Jira の管理者に依頼して役割を管理者にアップグレードしてもらってください。 |

| **Miro 経由で Jira の認証ができません。 エラー: 例外 (例: io.netty.handler.timeout.ReadTimeoutException)** | これは、Jira インフラストラクチャーの設定ミスが原因で発生する可能性があります。インフラストラクチャーの設定は HTTP/2 プロトコルのサポートを示していますが、それを使用しようとするとデータ転送は行われません。ウェブサーバーの設定ファイルで HTTP/2 の設定が、正しく設定されているか確認してください。  必要に応じて、サーバー設定で HTTP/2 サポートを一時的に無効化して、問題が解決されるまで下位互換性と中断することのないサービスを確実に提供します。 |

| OAuth 1.0 にのみ適用されます。（Jira サーバーとデータセンター）  SSL 接続が失敗しました | このエラーは、Miro がユーザーの Jira にアクセスできないことを意味します。  Miro チームの管理者に連絡し、Jira カード設定の **Jira のベース URL** フィールドに接続できるアドレスが記載されているかどうか確認してください。 |
| Miro の Jira カードの「担当者」フィールドにユーザーが表示されない | Jira のグローバルレベルで「ユーザーの閲覧」権限が設定されていることを確認してください。 [グローバル権限の管理方法についてはこちらをご確認ください。](https://confluence.atlassian.com/adminjiraserver072/managing-global-permissions-828787760.html) |

## Jira アドオンに関する提案

| **メッセージ / 問題** | **考えられる原因と問題を解決する手順** |
| --- | --- |
| **ログインしていないため、選択した課題に対してゲストとして操作するのに必要な権限がありません。ログインしてください** | 残念ながら、Miro のプラグインは Cookie を使用しているため、このページから Jira にログインすることはできません。  別のブラウザータブで Jira にログインしてください。 |
| アドオンページの**インストール**ボタンをクリックすると、以下のエラーが表示されることがあります:  hiccup.png | 一瞬の接続断です。  この場合、1 分後に再度インストールしてみてください。 |
| Jira アドオンの設定中または設定後に、一部の手順で次のページに進むことができない | クッキーやキャッシュの何かが、プロセスを停止させています。  ドメイン *atlassian.com* のブラウザーのメモリーをクリアし、再度試してみてください。 |
| インストールが正常に完了すると、Miro に*登録されていない* Jira ユーザーには、添付のボードではなく、Miro のログインメニューが表示される。 | Jira ポリシーが、プラグイン機能の一部をブロックしています。  残念ながら、この動作は、最新の Jira API 更新によって生じ、現時点では修正することはできません。 |
| アドオンが認証情報を記憶していないため、毎回ログインを要求される。  Jira 課題にボードを追加しようとすると、ボードピッカーに「申し訳ありません、インテグレーションが利用できません」というエラーが表示される。 | サードパーティーのクッキーが、ご利用のブラウザーでブロックされています。  解決策として、ブラウザーでクッキーを有効にする方法についての[指示](https://uca.edu/it/knowledgebase/allowing-third-party-cookies/#Chrome)に従ってください。これは主に、新しいセキュリティーポリシーが原因で、Mozilla と Safari で発生します。 Safari には、[こちらのソリューション](https://support.apple.com/en-ke/guide/safari/sfri40732/12.0/mac/10.14)も役立ちます。 |
