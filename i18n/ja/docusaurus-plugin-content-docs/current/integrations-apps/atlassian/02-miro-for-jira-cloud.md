チームと共にどんな作業も視覚化しましょう。デジタル付箋で製品のバックログに取り組み、フローチャート、図表、ワイヤーフレームを作成することができます。Jira 課題にボードを添付し、ホワイトボードを使った会議のようにリアルタイムでチームとコラボレーションすることができます。

> **利用可能な環境：**Starter、Business、Enterprise プラン
> Jira Cloud のみ

> ️️✏️ Atlassian のスマート リンク機能で Miro のボードを埋め込むこともできます。

:::note
Miro には次の 2 種類の Jira インテグレーションがあります：**Miro for Jira Cloud**（Jira 側に Miro ボードを埋め込むことができます）および**Jira カード**。Jira カードの詳細については、[こちらの記事](https://help.miro.com/hc/articles/360017572434)をご覧ください。
:::

## インストール方法

インストールプロセスは、Jira のすべてのアドオンの標準になっています。まず、管理者権限で Jira にログインし、[ここから](https://marketplace.atlassian.com/apps/1215456/miro-for-jira-cloud?tab=overview&hosting=cloud)アドオンをダウンロードします (このアプリは、**アトラシアン マーケットプレイス** > **新しいアプリを探す** >**Jira Cloud 用 Miro** でも見つけることができます):**Get app**と**Get it now** をクリックします。
以上です！インストールが完了します。

Miro_for_Jira.jpg
正常にインストールされたことに関する Jira の通知

管理者として、設定時に Miro のユーザーを Jira のユーザーにマッピングする必要はありませんのでご注意ください。各ユーザーは、Jira 内の Miro で自己認証が必要です。

## アドオンの使用方法

### Jira 課題へのボードの添付

Jira 課題にボードを添付するには、Jira でその課題を開きます。**Miroボード**セクションの**Add Boardを**クリックします。
add_Miro_boards_in_Jira.jpg
*インストール後、アドオンボタンが表示されます。*

> Miro ボードセクションがない場合は、課題のコンテキストメニューから検索することができます。

Miro_boards_section.jpg
Miro ボードセクションを Jira 課題に追加する

Miro ボードのピッカーが表示されます。追加したいボードを選択してください（ピッカーでチーム間を自由に切り替えることができます）。Miro で認証されない場合は、まずログインする必要があります。

ドロップダウン メニューでボードの共有設定を設定します。Miro にプロフィールがないユーザーもアクセスできるよう、閲覧やコメント追加に対応可能なボードを作成することができます。

> ️✏️ [Enterprise プラン](https://help.miro.com/hc/articles/360017571534)の Miro ユーザーの場合、アクセス設定は組織全体のアクセス管理に準ずるので、共有オプションの一部は制限されている可能性があります。さらに詳しい情報： インテグレーションの埋め込みに関する Enterprise 共有ポリシーの管理/span>

embed_a_board_in_Jira.jpg
ボードを Jiro 課題に添付する場合の共有設定

埋め込むことができるのは、編集権限があるボードだけですのでご注意ください。

選択した Jira 課題にすぐにボードが添付されます。

Miro_board_in_Jira.jpg
 Jira 課題に添付された Miro のボード

### Jira から新規ボードの作成

Jira 課題から直接新しいボードを作成するには、**[ボードを追加]** をクリックし、ピッカーから **[新しいボード]** を作成します。

create_a_new_board_from_the_picker.jpg
ピッカーからボードを作成

### ボードの閲覧、コメント追加、編集

添付されたボードをクリックするだけで、設定されたアクセス権に応じて、閲覧 / コメント追加 / 編集することができます。ボードのウィンドウはオーバーレイ表示され、Miro と同じように作業やコラボレーションが可能です。

Miro_embed_in_Jira.jpg
Jira のボードのオーバーレイ

 ソースボタンをクリックすると、新しいタブで Miro のボードを開けることもできます。

source_button.jpg
Miro アプリに移動するボタン

### ボードの切り離し

ボードを切り離すには、✕アイコンをクリックするだけで、添付は課題から即座に削除されます（Miro 側では、ボードに影響はありません）。

remove_an_attached_board.jpg
添付されたボードを削除するオプション

## アドオンを無効にする方法

インテグレーションを無効にするには、**Atlassian マーケットプレイス**を開き > **[アプリを管理]** > アドオンのページを開いて、**[アンインストール]** をクリックします。

uninstall_Jira_add-on.jpg
**Jira アドオンセクションでアンインストールするオプション**

## Miro の Atlassian スマート リンク

Atlassian スマートリンク機能を使用して、Jira 課題に Miro のボードを埋め込むことができます。この機能により、プラグインをインストールすることなく、ボードを自動的に埋め込むことができます。

> ️️✏️ Miro と Atlassian アカウントを接続後、プレビューで作業できるのは、Miro 側で埋め込みボードへのアクセス権があるユーザーのみですのでご注意ください。Jira のユーザー全員がプレビューを利用できるようにしたい場合は、自由に Jira アドオンを使用してください。

Jira 課題に移動し、ボードリンクを貼り付けるか、/link を入力して挿入してください。初めてこの機能を使用する場合は、Miro のチームを接続するよう求められます。プレビューに接続をクリックし、Miro で認証を行い、ボードを埋め込むチームを選択します。

install_Atllassian_links.jpg
ボードを埋め込む先のチームを選択

Miro のボードのリンクを Jira 課題に貼り付けると、自動的に Jira ウィジェットに変換されます。リンクをクリックすると、カードとしてまたは埋め込みとしてリンクを表示するオプションを選択することができます。

display_as_link.gif
リンク、カード、埋め込みとして Miro のボードリンクを表示するオプション

ボードを埋め込みとして表示することを選択した場合は、ボードの端をドラッグすれば埋め込みサイズを変更することができます。

changing_embed_size_in_Jira.gif
Jira で Miro の埋め込みサイズを変更

:::warning
ご利用のブラウザーでサードパーティーのクッキーがブロックされている場合、埋め込みボードを表示する際に予期せぬ問題が発生する可能性があります。
:::

## よくある質問

Jira 課題で Miro のボードセクションを非表示にできますか？

はい、セクションの右上にある三点リーダーをクリックし、**Hide Miro boardsを**選択してください。
hide_Miro_boards.jpg
*Jira での Miro ボードの非表示*

アドオンは、Jira 次世代プロジェクトで機能しますか？

はい、プロジェクトにボードを添付することができます。

Jira アドオンに追加料金はありますか？

Jira Cloud 用 Miro アプリは、すべての有料プランで追加費用なしでご利用いただけます（Starter、Business、Enterprise プラン）。

Jira を 1 つのクラウドインスタンスから別のものに移行する予定です。Jira 課題に埋め込まれた Miro ボードは影響を受けますか？

コンテンツを変更せずに移動する場合、埋め込まれた Miro ボードに問題は発生しません。
