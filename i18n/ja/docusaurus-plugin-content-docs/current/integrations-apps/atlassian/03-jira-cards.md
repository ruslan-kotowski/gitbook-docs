Jira カードを活用することで、Miro のボードで Jira 課題の作業を直接することができます。このインテグレーションにより、Jira 課題をふりかえり、ストーリーのサイズ設定、バックログの優先順位付け、ストーリーマッピング、その他のチームのアクティビティーのためにコラボレーションワークスペースに取り込むことで、チームのワークフローを合理化できます。

![Jira cards in user story mapping](../../../../../../docs/integrations-apps/atlassian/images/21017348097170_Jira%20cards%20in%20USM.png)

## ボードに Jira 課題をインポート

ボードに Jira 課題をインポートするには、2 つの方法があります。

1. Jira 課題の URL をコピーしてボードに貼り付けます。
2. 作成ツールバーの**ツール、メディアとインテグレーション**（**+**）アイコンをクリックし、**Jira カード**を選択して、1つまたは複数の課題を選び、**追加**をクリックします。

初めて課題をインポートする場合は、Jira アカウントを接続する必要があります。

1. 表示されたダイアログボックスで**認証**をクリックします。
2. Jira アカウントに認証情報でログインします。
3. Miro と Jira の間の接続を認証します。

認証後、Jira カードピッカーでアクセス可能なすべての Jira 課題が表示されます。

:::note
Jira アカウントを承認していないユーザーには、担当者のアバターが表示されない簡易カードビューが表示されます。
:::

## 新しい Jira 課題を作成する

Miro から直接 Jira 課題を作成する方法は2つあります。

### Jira アプリを使用して作成

1. 作成ツールバーの**ツール、メディア、インテグレーション**（**＋**）アイコンをクリックします。
2. **Jira カード**を選択します。
3. **課題を作成**をクリックします。
4. 必要なフィールドに入力します。
5. **作成**をクリックします。

### 既存の項目を Jira 課題に変換

ボード上の既存の付箋やカードを Jira 課題に変換できます。

1. 付箋またはカードを最大 50 件選択します。
2. **変換先** > **Jira** をコンテキストメニューでクリックします。
3. デフォルトの値（課題タイプ、優先度、担当者など）を設定します。
4. **変換**をクリックします。

:::warning
注記:

- USM タスク ラインのカードは Jira 課題に変換できません。
- 変換の際、Miro カードのタグや開始日は保持されません。
- 変換後に担当者の情報を再設定する必要があります。
:::

## Jira 課題を閲覧および編集する

:::warning
Jira カードの編集は、デスクトップアプリまたはモバイルアプリではサポートされていません。
:::

Jira カードを閲覧するには、次の 2 つの方法があります：

- サイド表示
- 中央表示

### Miro で課題を編集する

1. **サイドパネルで開く** または **センターパネルで開く** アイコンをクリックします。
2. 変更を行います。
3. **更新** をクリックして保存します。

### 課題のステータスを変更する

1. **ワークフロー** アイコンをクリックします。
2. 目的の **ステータス** と **コメント** を選択します。
3. **更新** をクリックして保存します。

### Jiraで編集する

1. カードを選択し、**ソース**アイコンをクリックします。
2. 新しいブラウザータブで Jira の課題を編集します。
3. 変更は自動的に Miro カードに同期されます。

## Miro と Jira 間の同期

|  |  |
| --- | --- |
| **Jira インスタンスの更新 vs Miro カードの更新** | **更新はいつ行われますか？** |
| OAuth 1.0 および OAuth 2.0 を使用した Jira での更新 | Miro Jira カードは [Webhook](https://help.miro.com/hc/articles/360017731113) を通じて直ちに更新されます。 |
| Miroでの更新 | Miro Jiraカードは即時に更新され、対応するJiraの課題も同時に更新されます。 |

## Jiraカードをカスタマイズする

### カードの色を変更する

1. 1つ以上のJiraカードを選択します。
2. コンテキストメニューで**塗りつぶし色**をクリックします。
3. 希望の色を選びます。

### カスタムフィールドを設定する

1. 作成ツールバーの**ツール、メディア、インテグレーション** (**+**) アイコンをクリックします。
2. **Jira カード**を選択します。
3. **カードを設定**を選択します。
4. 表示したいフィールドを選択します。
5. **保存**をクリックします。

:::note
フィールドに関する重要な注意事項:

- 設定は現在のボードにのみ適用されます。
- デフォルトフィールド（担当者、課題タイプ、優先順位、ステータス）は削除できません。
- 値がない場合や、その課題タイプで利用できない場合、フィールドが表示されないことがあります。
- 一部のフィールドタイプ（色のカスタムフィールドなど）はサポートされていません。
:::

## Jira 課題を検索

Jira カードピッカーは最近のタスクを最初に表示し、いくつかの並べ替えオプションを提供します:

- 課題タイプ
- 優先度
- キー
- 概要
- 担当者
- ステータス

キーワードを使用して特定の課題を見つけるか、**Jira Query Language** (JQL) を使用して複雑な検索を行いましょう:

1. 検索バーの**高度な検索**トグルを選択します。
2. JQL クエリを入力します。

クエリに基づいて結果が更新されます。
