Miro における Linear インテグレーションは、Miro ボードと Linear イシュー間のシームレスな双方向同期を可能にすることで、協力的なワークフローを強化します。このインテグレーションにより、Linear イシューを Miro 内で直接インポート、閲覧、および編集でき、アプリケーション間の切り替えが不要になります。主な目的は、プロジェクトのワークフローを最新の状態に保ち、チーム全体が協調し、生産性を維持することです。

## 主な機能

Linear インテグレーションは以下の機能を提供します。

- **Linear イシューのインポート:** イシューを Miro のボードにインポートし、担当者、プロジェクト、またはステータスでフィルターしましょう。
- **新しいイシューの作成:** Miro のボードから直接 Linear イシューを作成可能です。
- **Miro でのイシュー編集:** イシューの詳細（タイトル、タイプ、ステータス、担当者、期日、プロジェクト、タグ、説明）を編集可能です。
- **双方向の同期:** Miro または Linear で行われたイシューの変更が自動的に同期されます。
- **イシューの視覚的な整理:** イシューをテーブル、タイムライン、カラム、ユーザーストーリーマッピングレイアウトで整理できます。
- **簡単アクセス:** ソースアイコンを使用して、ワンクリックでオリジナルのLinearイシューを開くことができます。
- **柔軟な表示方法:** サイドパネルとモーダルウィンドウの表示を切り替えてイシューディテールを確認できます。
- **ビジュアルの組織化:** イシューに色分けをして、優先度やステータスを区別できます。
- **安全なアクセス:** Linearアカウントで認証し、Linearアクセスに一致する権限を持つことができます。
- **管理者による制御:** Miroチームや組織全体のインテグレーションアクセス権限を管理できます。

## 制限

Linearインテグレーションには以下の制限があります:

- **カスタムフィールド:** インテグレーションでは、Linear の課題内でのカスタムフィールドの閲覧、編集、作成がサポートされていません。
- **カラムウィジェット:** カラムウィジェット内で課題を移動しても、Linear の課題ステータスは更新されません。
- **初期同期:** 大規模な Linear アカウントの場合、初回の同期には数分から数時間かかることがあります。
- **インストール要件:**
  - Linear が事前にインストールされていない場合は、マーケットプレイスからのインストールが必要です。
  - 組織がアプリのインストールを制限している場合は、管理者の承認が必要です。
