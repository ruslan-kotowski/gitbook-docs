Miro の Linear インテグレーションは、Miro ボードと Linear 課題間のスムーズな双方向の同期を可能にすることで、コラボレーションを強化します。Miro 内で直接課題をインポート、閲覧、編集でき、ワークフローが最新の状態に保たれ、チームの調和と生産性が向上します。

> **注意**: 管理者は、自分の Miro チームに対して Linear インテグレーションを承認する必要があります。チームメンバーは、これがチームレベルでインストールされた後にのみインテグレーションを使用できます。

## 前提条件

Linear インテグレーションを使用する前に、次のことを確認してください:

- 有効な Miro アカウント（必要に応じて[こちらで登録](https://miro.com/)）
- 有効な Linear アカウント
- アプリのインストールが制限されている場合、管理者の承認

## Linear を Miro に接続する

Linear インテグレーションを始めるには、自分の Linear アカウントを Miro に接続する必要があります。Miro のボードを開いて、作成バーで**ツール ＞ メディア & インテグレーション (+)**をクリックします。**Linear**を検索し、**接続**をクリックします。

認証時に以下を選択できます：

- 認証情報を使用する（推奨）
- APIキーまたはアクセストークンを使用する

認証プロセスが完了すると、Linear アカウントが Miro と同期を開始します。この初回の同期は、大規模アカウントの場合、数分から数時間かかることがあります。同期が完了すると、メール通知を受け取ります。

## Linear 課題をボードに追加する

接続が完了すると、Miro ボードに Linear 課題を追加できます。**ツール > メディア & インテグレーション (+)**からアクセスし、**Linear**を検索してください。選択ツールでは、ステータス、担当者、プロジェクトごとに課題をフィルターして、Linear 課題ウィジェットとしてインポートすることができます。

なお、選択ツールには Linear でアクセス可能な課題のみが表示されます。

## Linear 課題を扱う

### Miro で課題を編集

Miro 内で直接 Linear の課題を編集できます。Linear Issue ウィジェットをクリックし、サイドパネルのアイコンを使用して課題の詳細を開きます。ここからプロパティを変更し、**更新**をクリックして Linear と同期します。

### ワークフローを整理する

Miro は、Linear の課題を効果的に整理するためのいくつかのツールを提供しています：

[テーブル](../../using-miro/formats/14-tables.md)、[タイムライン](../../using-miro/formats/15-timeline.md)、[カラム](../../using-miro/advanced-tools/02-columns-formerly-kanban.md)、および[ユーザーストーリーマッピング](../../using-miro/advanced-tools/07-user-story-mapping.md)のツールを使用して、ワークフローをさまざまな方法で構築できます。単に Linear の課題をこれらのツールにドラッグ＆ドロップして、必要に応じて整理してください。

カラム ウィジェットで問題を移動させることは可能ですが、このアクションでは Linear のステータスが自動的に更新されないことに注意してください。

### 課題のナビゲートとカスタマイズ

Linear インテグレーションは、課題を操作するためのさまざまな方法を提供します：

Linear 内での完全な課題詳細を表示するには、詳細ビューまたはサイドパネルの**ソース**アイコンをクリックしてください。サイドパネルビューとモーダルウィンドウビューを切り替えるには**表示切替**アイコンを使用し、課題をより視覚的に整理するために**塗りつぶし色**アイコンを使用して色分けが可能です。

## 追加機能

### アクション ショートカット

Linear インテグレーションは[アクション ショートカット](../../using-miro/facilitation-tools/03-action-shortcuts-beta.md)をサポートしており、次のことが素早く可能です：

Linear イシュー ピッカーを開くか、カスタマイズされたショートカットで新しい Linear イシューを作成します。

## インテグレーションのアンインストール

Linear インテグレーションをチームまたは個人レベルで削除できます。

チームレベルで削除するには:

1. **チーム設定** > **アプリとインテグレーション**に移動します。
2. **Linear** を見つけて **チーム用にアンインストール**をクリックします。

個人レベルで削除するには:

1. 設定で **アプリとインテグレーション**に移動します。
2. **Linear** を見つけて **自分用にアンインストール**をクリックします。

## よくある質問

### インテグレーションを利用できるのは誰ですか？

Linearインテグレーションは、適切なLinear権限を持つMiroチームまたは組織内の認定ユーザーが利用可能です。

### MiroでLinearの課題を閲覧できるのは誰ですか？

ボードにアクセス権（閲覧、コメント、または編集権限）のあるユーザーは、インポートされたLinearの課題を閲覧できます。ボード上の課題を閲覧するために、Linear認証は必要ありません。

### MiroでのLinear権限はどのように機能しますか？

インテグレーションはあなたのLinear権限を尊重します。Linearのアクセス権に基づき、課題の検索、インポート、または編集が可能であり、Miroのボードにインポートされた課題はすべてのボードユーザーに表示されます。ただし、これらの課題の編集には適切なLinearの権限が必要です。
