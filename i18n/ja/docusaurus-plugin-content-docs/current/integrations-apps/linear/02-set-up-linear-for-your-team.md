Linear インテグレーションは、技術的には REST API を通じて実装されています。認証と認可の目的で、業界標準の OAuth 2.0 プロトコルを利用します。このアーキテクチャの中核要素は、サードパーティのデータのためのサブプロセッサとして機能する統合 API プラットフォームであり、異なる API プロバイダー間での認証、正規化、および同期を管理します。

## データ フロー

セキュリティとコンプライアンスを管理するには、データ フローの理解が重要です。

### Miro 内の Linear データ

ユーザーが Linear のイシューを Miro ボードにインポートすると、以下のデータが Miro キャンバスに不可欠です。

- タイトル
- 説明
- 担当者（名前/メールアドレス）
- ステータス
- 優先度

この列挙はデータガバナンスにとって重要であり、Miro 環境にどのような機密データが入るかを確認します。カスタムフィールドはサポートされていない点に注意してください。

### データ保持

すべてのインポートされた Linear データは、Miro の標準的なデータ保持ポリシーに厳密に従っており、すべての顧客データに一貫して適用されます。

## 認証および認可

最初のやり取りの際に、Linear インテグレーションは認証フローを開始します。各ユーザーのために、Miro は今後のやり取りのためのインテグレーションサービス用認証情報を作成します。

このインテグレーションは一般的に、Linear 管理者の承認が必要です。

### 必要な認可スコープ

| 範囲 | 説明 |
| --- | --- |
| コレクション | 課題のコレクションにアクセスします。 |
| ユーザー | 割り当てや表示のためにユーザー情報を読み取ります。 |
| 課題 | Linearで課題を読み取り、作成、修正します。 |

## Miroに保存されるデータと方法

- **認証関連データ:** トークンはAES-256で暗号化され、数日間Miroのデータベースに保存されます。
- **アンファーリング関連データ:** 課題のタイトルは暗号化された参照と共に保存されます。

### トークンの取り消し

トークンの取り消しは、**インテグレーション設定** または **アプリ**タブで**切断**を選択することによって行われます。このアクションはLinearへのアクセスを削除し、ユーザーの認証情報を消去します。

## Linearインテグレーションの設定方法

管理者とエンドユーザーのための手順は、制御された展開を確実にするためのものです。

1. **アクティブなアカウントの確認:** Miro および Linear のアカウントがアクティブであることを確認してください。
2. **チームレベルのインストール（管理者の操作）:**
   - 管理者はチームレベルで Linear のインテグレーションを認可する必要があります。
   - **Tools Media & Integrations** を介してインストールし、「Linear」を検索して接続します。
3. **ユーザーリクエストと管理者の承認:**
   - 厳格なコンセント組織では、Linearリンクの貼り付けにより管理者承認のリクエストがトリガーされることがあります。
   - 管理者はMiroまたはLinearのコンソールで承認できます。
4. **個別ユーザー接続:**
   - ユーザーはLinearウィジェットとOAuth認証を通じて接続します。

## セキュリティーとコンプライアンス

### ソースファイルへのアクセス制限

厳格なボード共有コントロールを維持することで、Linearの権限とMiroを一致させます。

### エラーハンドリング

インテグレーションでは、サードパーティによる拒否に対して優雅なUIフォールバックが特徴です。

### Miroデータ処理付属契約（DPA）

[Miroのデータ処理付属契約](https://miro.com/legal/customer-data-processing-addendum/)を参照して、詳細な法的およびコンプライアンス情報をご確認ください。

## トラブルシューティング & FAQs

### インテグレーションの停止方法（チームレベル）

管理者は**「アプリ & インテグレーション」**から「Linear」を選択し、**「チームのアンインストール」**をクリックすることでアンインストールできます。

### インテグレーションの停止方法（個人）

ユーザーは**「アプリ & インテグレーション」**をナビゲートし、「自分用にアンインストール」を選択することで、Linearをアンインストールできます。

### 管理者の権限

アプリを直接インストールできるのは Miro のチーム管理者のみです。Linear の URL をボードに貼り付けると、自動的にセットアップが行われます。

### 利用可能要件

Linear のインテグレーションは Business プランと Enterprise プランで利用可能です。

### 管理者の承認要件

はい、チームでアクセスするには管理者によるチームレベルの承認が必要です。
