Okta Workflows 用 Miro コネクターを使用すれば、Miro で反復的かつマルチステップな管理タスクを簡単に自動化できるようになります。ワークフローの自動化を設定し、チームとユーザーの管理を簡素化する方法を学びましょう。

> **対象プラン：**Enterprise プラン

## Miro ユーザー管理コネクター

Miro ユーザー管理コネクターを使用し、SCIM を有効にした Miro の Enterprises プランの顧客は、組織にユーザーを追加し、ユーザーのライセンスやステータスを管理することができます。

**Miro ユーザー管理コネクターを認証する：**

Miro ユーザー管理カードを初めてフローに追加する際に、組織との接続を設定するよう要求されます。詳細は、認証の項/span>をご覧ください。

**Miro ユーザー管理コネクター アクションカード：**

|  |  |
| --- | --- |
| **アクション** | **説明** |
| ユーザーを作成する | 新しいユーザーを作成する。 |
| ユーザーを読み込む | 組織内の既存ユーザーをメールアドレスで検索する。 |
| ユーザーのライセンスタイプをフルにアップグレードする | 既存のユーザーリソースを更新し、ユーザーのライセンスタイプを**フル**に変更する。 |
| ユーザーステータスを更新する | Miro User Management コネクタは SCIM トークンを使用して動作します 。Miro ユーザー管理は、SSO と SCIM が有効な企業でのみ使用できます。 |

## 認証

複数の接続は **接続**ページから複数の接続を作成および管理できます。
これは、複数の組織で活動する予定がある場合に便利です。Miro ユーザー管理コネクターの各接続は/span>、Miro 組織を 1 つだけ指すことができます。

SCIMを有効にして新しいトークンを取得する、または既存のトークンをコピーするには、以下の手順に従ってください。 [SCIMを有効にする方法](https://developers.miro.com/docs/how-to-enable-scim).
アクションカードから新しい接続を作成する方法：

1. [新規接続] **をクリックします**。
2. 接続名（ニックネーム）**を入力します**。組織を表すような名前を付けることをお勧めします。
3. この手順[に従って、Miro の Enterprise インテグレーション ページ](https://developers.miro.com/docs/how-to-enable-scim)から、SCIM プロビジョニングを有効にします。
   1. Miro からベース URL を**コピー**し、接続セクションの**ベース URL** フィールドに貼り付けます
   2. Miro から **Api トークン**をコピーし、接続セクションの **アクセストークン** フィールドに貼り付けます
4. [作成] **をクリックします**。接続が保存され、フローに戻ります。

## Miro 管理者コネクター

Miro 管理者コネクターを使用することで、企業顧客はチームを作成し、チームの設定とメンバーを管理することができます。

**Miro 管理者コネクターを認証する**：

Miro カードを初めてフローに追加する際に、組織との接続を設定するよう要求されます。詳細は、認証の項/span>をご覧ください。

**Miro 管理者コネクター**の**アクションカード**：

|  |  |
| --- | --- |
| **アクション** | **説明** |
| チームを作成する | 既存組織で新しいユーザーを作成する。 |
| チームを検索する | 組織内の既存チームを検索する。一致した最初の 10 件のレコードが検索結果セットから選択される。 |
| チームにメンバーを追加する | 既存チームに新しいメンバーを追加する。 |
| チームメンバーの役割を更新する | 既存チームのチームメンバーの役割を更新する。 |
| チームの設定を取得する | 既存チームのチームの設定を取得する。 |
| チームの共有ポリシーの設定を更新する | 既存チームの共有ポリシーの設定を更新する。 |
| チームの招待設定を更新する | 既存チームの招待ポリシーの設定を更新する。 |
| チームのコラボレーション設定を更新する | 既存チームのコラボレーション ポリシーの設定を更新する。 |
| チームの公開設定を更新する | 既存チームの公開ポリシーの設定を更新する。 |

| ユーザーセッションのワイプアウト（ベータ版） | 指定したメールアドレスのすべてのユーザーセッションをワイプします。 |

## 認証

Miro 管理コネクターは、OAuth API を使用することで機能します。Miro 管理コネクターは、Enterprises プランの顧客のみが利用できます。新しい接続を作成するために、ユーザーは、以下の機能を満たすアプリのインストールに必要な権限を有している必要があります。

複数の接続は **接続**ページから複数の接続を作成および管理できます。
これは、複数の組織で活動する予定がある場合に便利です。Miro 管理コネクターの各接続には、Miro 組織を 1 つだけ提示することができます。

アクションカードから新しい接続を作成する方法：

1. [新規接続] **をクリックします**。
2. 接続名（ニックネーム）**を入力します**。組織を表すような名前を付けることをお勧めします。
3. **こちらの手順**に従って、Miro の Enterprise インテグレーション ページから、**組織 ID** とアクセストークンを[取得](02-miro-connector-for-okta-workflows.md)します。
4. [作成] **をクリックします**。接続が保存され、フローに戻ります。

サポート対象範囲：

- 組織：チーム：書き込み
- 組織：チーム：読み込み
