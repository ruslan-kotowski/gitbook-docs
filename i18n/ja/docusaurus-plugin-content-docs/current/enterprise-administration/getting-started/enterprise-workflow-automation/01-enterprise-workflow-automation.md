Miro の Enterprise プランを会社全体で簡単に管理できます。ServiceNow Automation Engine や Okta Workflows のようなローコードまたはノーコードのソリューションとの統合を活用しましょう。その他のインテグレーションも近日中に利用可能になる予定です。

### ワークフローの自動化機能を使用する理由

ワークフロー自動化ソリューションを使用すれば、高度に技術的な知識を必要とせずに、反復的かつマルチステップな管理タスクの自動化が可能になります：

- エンドツーエンドなユーザー オンボーディングとシームレスなユーザー オフボーディング
- チームの作成やメンバーの追加など、日々のコラボレーション ライフサイクルの管理
- チームレベルやボードレベルでの共有、公開レベル、招待の設定と会社方針の一致を確保

### 対応しているワークフロー自動化ソリューション

Miro は現在、以下のサービスとの統合を提供、もしくは提供予定です。

- [ServiceNow Automation Engine](https://store.servicenow.com/sn_appstore_store.do#!/store/application/dd64b2f9c370201021f5e81aa840ddb9/3.0.2)
- [Okta Workflows](03-set-up-miro-connectors-for-okta-workflows.md)
