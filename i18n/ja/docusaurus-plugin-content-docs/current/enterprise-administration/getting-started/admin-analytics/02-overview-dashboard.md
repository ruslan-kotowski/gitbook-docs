概要ダッシュボードは、次の指標を通じて導入の進捗を追跡し、組織の活動を理解するための洞察を提供します。

- **ボード:** ボード総数を表示し、使用状況に基づくアクティブなボードの数を確認し、過去のトレンドを追跡します。
- **ユーザー:** Miro を通じてどの程度のユーザーが積極的に関与しているかを追跡します。また、メンバー、会社の管理者、ゲスト、チームゲストといった特定のユーザーロールに基づいて追跡することもできます。
- **チーム:** チーム数を監視し、活動レベルを確認します。
- **ライセンス:** 割り当てられたライセンスの種類を追跡し、その変化を把握します。
- **テンプレート:** どのテンプレートが組織全体で最も使用されているかを確認します。

## 概要ダッシュボードの操作

概要ダッシュボードでメトリクスを操作する際には、次の点に留意してください。

- **期間セレクター:** Analytics ページの右上にあるセレクターを使用して、概要ダッシュボードに表示される期間を調整できます（日次、週次、月次、四半期ごと）。
- **分析表示設定:** 時間範囲セレクターの横にある**歯車アイコン**をクリックすると、設定が開きます。**ユーザー プライバシー**の下で、トップ AI ユーザーのようなユーザーレベルの活動を含む分析ダッシュボードでユーザー名を表示するか非表示にするかを選択します。**デフォルトではユーザー名が表示されます。** **変更を保存**して適用します。
- **最終更新:** 指標は毎日更新され、各ダッシュボードに最終更新のタイムスタンプが表示されます。
- **部分的なデータ:** 機能が選択された期間の一部で無効になっていた場合、メトリクス履歴に部分的なデータが表示されることがあります（例: 機能が月の途中で有効になった場合）。
- **データなし:** 特定の期間（日、週、月）に活動が記録されなかった場合、その期間のチャートにはデータが表示されません。
- **履歴データの表示:**

  - 履歴データを表示するすべてのウィジェットには、各期間の最終日のデータが表示されます。たとえば、選択した期間が月単位の場合、ボードのチャートには各月末のボード数が表示されます。
  - 現在進行中の期間は履歴のチャートには表示されません。たとえば、選択した期間が月単位で現在の月が9月の場合、チャートには8月までのデータのみが表示されます（最後に完了した期間）。
  - 履歴データは1年またはデータが存在する限り提供されます。古いデータが欠落しているように見える場合は、Miroサポートに連絡してバックフィルの確認を依頼してください。

## ボード分析

ボードチャートにはボードの総数、使用に関してアクティブなボードの数が表示され、過去の傾向を閲覧および分析することができます。以下の表は、ボードチャートで利用可能な情報を一覧表示しています。

| 指標名 | 説明 |
| --- | --- |
| (1) 合計 | ボードの合計数。 これはゴミ箱にあるボードを除きます。 |
| (2) この<選択された期間>でのアクティブ (四半期/月/週/昨日のいずれか) | 選択された期間の開始時から開かれているユニークなボードの合計数。 これには、ゴミ箱に移動された可能性のあるボードも含まれます。 |
| (3) チャートにプロットされたボードの合計 | プロットされた日または月の終了時点でのボードの合計数。 これはゴミ箱にあったボードを除きます。 |
| (4) チャートにプロットされたアクティブなボード | プロットされた日または月の開始時から開かれているユニークなボードの合計数。 これには、ゴミ箱に移動された可能性のあるボードも含まれます。 |

*注記：これらのメトリクスは、少なくとも24時間ごとに更新されます。Analyticsページの左上にある「最終更新」情報は、最新のメトリクス更新が行われた時点を示しています。*

## ユーザー分析

ユーザーチャートには、Miroをどれだけ多くのユーザーが継続的に利用しているかが表示されます。メンバー、会社の管理者、ゲスト、チームゲストなど、特定のユーザーロールに基づいてユーザー分析を追跡することもできます。次の表は、ユーザーチャートで利用可能な情報を示しています。

| メトリック名 | 説明 |
| --- | --- |
| (1) 合計 | メンバー、会社の管理者、ゲスト、およびチームゲストを含むユーザーの総数。 選択されたユーザータイプに基づいて総数が変わります。 |
| (2) この<選択された期間>のアクティブ (四半期/月/週/昨日のいずれか) | 選択した期間の開始以降、少なくとも一度ボードを開いたユニークユーザーの総数。 現在非アクティブ化されているユーザーも含まれます。  選択されたユーザータイプに基づいて総数が変わります。 |
| (3) グラフにプロットされた総ユーザー数 | プロットされた各期間の終わりにおけるメンバー、会社の管理者、ゲスト、およびチームゲストを含むユーザーの総数。  選択されたユーザータイプに基づいて総数が変わります。 |
| (4) チャートのアクティブなユーザー | 各プロット期間の開始から一度でもボードを開いたユニークなユーザーの合計数。  これには、現在非アクティブ化されているユーザーも含まれます。合計数は、リストで選択したユーザータイプに基づいて変わります。 |

*注記： これらのメトリクスは、少なくとも24時間ごとに一度更新されます。Analyticsページの左上にある最終更新情報は、最新のメトリック更新がいつ行われたかを示します。*

## チーム分析

チームチャートはチーム数と活動レベルを表示します。以下の表では、チームチャートに利用可能な情報を一覧表示しています。

| 指標名 | 説明 |
| --- | --- |
| (1) 合計 | チームの合計数。  これはゴミ箱に入っているチームを除外します。 |
| (2) この<選択された期間>でアクティブなチーム (四半期/月/週/昨日のいずれか) | 選択された期間の開始から少なくとも一度、メンバーがボードを開いたユニークなチームの合計数。  これにはゴミ箱に移動された可能性のあるチームも含まれます。 |
| (3) グラフにプロットされた合計チーム数 | プロットされた日または月の終わり時点でのチームの合計数。 これはゴミ箱に入っているチームを除外します。 |
| (4) グラフにプロットされたアクティブなチーム数 | プロットされた日または月の開始から少なくとも一度、メンバーがボードを開いたチームの合計数。  これにはゴミ箱に移動された可能性のあるチームも含まれます。 |

*注記: これらのメトリックは24時間ごとに少なくとも一度は更新されます。アナリティクスページの左上にある"Last Updated"（最終更新）情報は、最新のメトリック更新がいつ行われたかを示しています。*

## ライセンス分析

ライセンスチャートは、割り当てられたさまざまなタイプのライセンスを表示し、ライセンス割り当ての変化を追跡することができます。次の表に、ライセンスチャートで利用可能な情報を一覧します。

| 指標名 | 説明 |
| --- | --- |
| 割り当て済み | Advanced、Standard、Full（レガシー）、Free、Free Restricted ライセンスを含む、割り当てられたすべてのライセンス数。これは、ご所属の組織で現在使用されているライセンスの数を示します。  選択したライセンスタイプに基づいて、合計数は変化します。 |
| チャートに表示される割り当て履歴 | 各プロット期間の終了時点での割り当てられたライセンスの合計数。  リストで選択したライセンスタイプに応じて合計数が変わります。 |

*注記：これらの指標は、少なくとも24時間ごとに更新されます。Analyticsページの左上にある「最後に更新された情報」は、最新の指標が更新されたときを示します。*

## テンプレート分析

「最も人気のあるテンプレート」セクションでは、組織内で最も頻繁に使用されているテンプレートを表示します。現在、このデータにはボードから直接追加されたテンプレートのみが含まれており、miro.com/templatesなど他のソースのものは含まれていません。今後のリリースで追加のソースがサポートされる予定です。

*注記：これらの指標は、少なくとも24時間ごとに更新されます。分析ページの左上にある最終更新情報が、最新の指標更新時刻を示しています。*
