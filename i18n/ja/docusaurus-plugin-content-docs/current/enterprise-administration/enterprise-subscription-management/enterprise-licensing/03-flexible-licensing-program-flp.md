フレキシブル ライセンス プログラム（FLP）は、当社の最も標準的なライセンスモデルです。FLP を使用すると、使用量に応じてライセンス数を変更することができます。組織のニーズを見積り、無駄な先行費用、遡及費用、契約変更を一切伴わず、ライセンスを追加または削除することができます。

[Enterprise ライセンスについてさらに詳しく](02-enterprise-licensing.md)

## フレキシブル ライセンス プログラム（FLP）の基本情報

FLP サブスクリプションの見直しは、予め決められた調整頻度に基づいて行われます。料金調整期日が近づくと、Miro のアカウントチームとデータに基づいて話し合いを行い、新ユーザーのうち、何人が今後スタンダードまたはフル（従来の）ライセンスが必要かを決定します。契約は追加ライセンスで修正され、遡及費用は一切発生しません。

## FLP ライセンスのアップグレード

ユーザーには、スタンダード、フル（従来の）、無料、または制限付き無料ライセンスを割り当てることができます。特定のアクションによって FLP サブスクリプションでライセンスのアップグレードが発生します。

さらに詳細は、[FLP ライセンス管理の詳細](05-license-management-on-the-flexible-licensing-program-flp.md)をご覧ください。

|  |  |  |  |
| --- | --- | --- | --- |
|  | **標準/** **フル（旧式）** | **無料** | **制限付き無料** |
| **アップグレードのオプション** | すでに最高のライセンスタイプにアップグレード済み | **自動アップグレード** は以下の場合にスタンダードまたはフル（旧型）ライセンスになります:   - ボードを作成する - 共有ボードを編集する - 編集者としてボードに招待される - ボードの共同所有権を付与される - [スペース](../../../using-miro/spaces/01-spaces.md)に編集者として追加される | **ライセンスのアップグレード リクエスト**が管理者に送信されるのは、ユーザーが以下を行うときです。   - ボードやスペースの作成を試みる - 編集権限をリクエストする - 招待を受けてボードを編集する - ボードの所有権が割り当てられる |

:::warning
ゲストは自動的にアップグレードされることはありません。
:::

## FLPユーザーアクセス

各ユーザーは、1つの Enterprise プラン内で複数の Miro [チーム](../../../getting-started/start-here/miro-dashboard/04-profile-and-teams.md)において、異なる Miro ロール（メンバー、ゲスト、またはビジター）を持つことができます。

[Enterprise プランにおけるユーザーアクセスレベル](../../user-management/11-user-access-levels-on-enterprise-plan.md)で、Miroのロールとライセンスタイプについてさらに詳しく学べます。

|  |  |  |  |
| --- | --- | --- | --- |
|  | **スタンダード/** **フル（レガシー）** | **無料** | **制限付き無料** |
| **メンバー** | **Standard または Full (legacy) ライセンスのメンバーは、以下が可能です:**   - ボード、スペース、テンプレートを作成する - 共有ボードを編集する - チームと共有されたボードを閲覧する | **無料ライセンスのメンバーは、以下のことができます。**   - スペースとボードに追加される - チームと共有されているボードを閲覧する（チーム共有ボードを閲覧し、コメントする） - 自動的に標準またはフル（従来の）メンバーに変換される | **制限付き無料ライセンスのメンバーは、以下のことができます。**   - スペースやボードに追加される - チームと共有されているボードを閲覧する（チーム共有ボードを閲覧し、コメントする） |
| **ゲスト** | 利用不可 | **無料ライセンスのゲストは、以下のことができます。**   - 共有ボードの閲覧やコメント追加     **無料ライセンスのゲストは次の操作ができません。**   - チームで共有されたボードの作成、または閲覧 - チームで共有されたスペースの参照または参加 | **制限付き無料ライセンスのゲストは、以下のことができます。**   - 閲覧やコメント追加 |
| **ビジター** | **ビジター**は、Miro への登録やライセンスは不要です。   - ビジターは、ボードの閲覧、コメント、および編集が可能です（[制限付き](../../../using-miro/sharing-boards/08-collaboration-with-visitors.md)） - ビジターは、チーム内で共有されているスペース、ボード、テンプレートを閲覧できません - ビジターは、チーム、チームメンバー、チームおよび会社の管理者の一覧を閲覧できません | | |
