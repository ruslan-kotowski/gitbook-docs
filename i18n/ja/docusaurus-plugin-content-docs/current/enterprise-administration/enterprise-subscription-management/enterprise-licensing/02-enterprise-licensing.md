Enterprise プランのお客様は、非フレキシブル ライセンスモデルかフレキシブル ライセンスモデルを選択できます。Miro のライセンスオプションと、それがサブスクリプション管理にどう影響するのかについて学びましょう。

:::note
フレキシブル ライセンス プログラム (FLP) では、高度なライセンスはサポートされておらず、常に非 FLP (ハードリミット) モデルで運用されます。お客様の組織が購入した高度なライセンス数までしか割り当てることができません。

FLP を使用している組織は、標準ライセンスを維持しつつ、高度なライセンスをハードリミットのままにして、ミックスライセンスモデルを採用できます。つまり、標準ライセンスは FLP のまま（ダウングレードで無料限定ライセンスが無制限）、高度なライセンスは購入済みのライセンス数に限定されます。高度な機能が必要なユーザーには、明示的に高度なライセンスを割り当てる必要があります（または組織のアップグレード/リクエストフローに従います）。
:::

## ライセンスモデル

### フレキシブル ライセンス プログラム（FLP）

Miro Enterprise プランのお客様が最もよく利用しているライセンスモデルは、[フレキシブル ライセンス プログラム](03-flexible-licensing-program-flp.md)です。FLP を使用すると、組織のニーズを見積もり、追加の初期費用なしでライセンスを追加できます。使用量に応じてライセンス数を変更することができます。

Miro は定期的にユーザーと連絡を取り合います。年に 2 回、組織に必要なライセンス数を再評価することができます。不要なライセンスは削除でき、遡及請求はされません。

- Standard ライセンスや Full (旧)ライセンスには制限がありません
- 無料ライセンスの制限なし
- Standard または Full (旧)ライセンスに自動アップグレード
- 外部ゲストは編集可

FLP により、すべての新規ユーザーが無料ライセンスや制限付き無料ライセンスを無制限に利用できます。

:::note
外部ゲストとは、ユーザーの会社ドメインを持たないゲストのことです。社外のメールアドレスを使用しています。
:::

### 非フレキシブル ライセンス（非 FLP）

非フレキシブル ライセンスモデルでは、あらかじめ設定したライセンス数に応じた利用料金を年単位でお支払いいただきます。これらのライセンスがすべて利用され、追加ライセンスが必要な場合は、通常注文フォームで追加でご購入いただきます。

ノンFLPサブスクリプションでライセンスを使い切った場合、新しいユーザーはすべて[制限付き無料ライセンス](04-free-restricted-license.md)で登録されます。ライセンスを追加購入するか、他のメンバーを削除してライセンスを解放することで、これらのユーザーは他のタイプのライセンスに変更可能です。

- スタンダードライセンスやフルライセンスには上限があります
- 追加されるのはすべて制限付き無料ライセンスです
- ゲストは閲覧とコメントのみ可

## ライセンスモデルの概要

|  |  |  |
| --- | --- | --- |
| **ライセンスの種類** | **非フレキシブル ライセンス (非 FLP)** | **フレキシブル ライセンス プログラム (FLP)** |
| **アドバンスト** | 契約ライセンス数の設定 | 契約ライセンス数の設定 |
| **スタンダード** | 契約ライセンス数の設定 | 無制限の利用可 |
| **フル（レガシー）** | 契約ライセンス数の設定。 | 無制限の利用可。 |
| **無料** | 利用不可 | **無料**ライセンスは、FLP プランでより管理者やユーザーに柔軟性を提供します。これらのライセンスはユーザーが以下を行うことで自動的にスタンダードやフル（レガシー）ライセンスにアップグレードされます：   - ボードを作成する - ボードの共同所有権を付与される - ボードを編集する - 招待を受けてボードを編集する - [プロジェクト](../../../using-miro/sharing-boards/16-projects.md)に編集者として追加される |
| **制限付き無料** | **制限付き無料**ライセンスは、有料のスタンダードまたは**フル**（旧バージョン）ライセンスがサブスクリプションに残っていない場合、新規ユーザーにのみ割り当てられます。  制限付き無料ライセンスでは、ユーザーのアクセスが制限されます。 | 会社の管理者は、いつでも**制限付き無料**ライセンスを手動で割り当てることができ、新規ユーザーのデフォルト* ライセンスとしても割り当て可能です。  制限付き無料ライセンスでは、ユーザーのアクセスが制限されます。 |
| **ゲスト** | コメントと閲覧が可能です。 | 外部ゲストは編集可能（Miro が許可し、チーム設定で有効になっている場合） |

*デフォルトライセンスの設定とライセンス変更の詳細については、[フレキシブル ライセンス プログラムのライセンス管理](05-license-management-on-the-flexible-licensing-program-flp.md)をご覧ください。
