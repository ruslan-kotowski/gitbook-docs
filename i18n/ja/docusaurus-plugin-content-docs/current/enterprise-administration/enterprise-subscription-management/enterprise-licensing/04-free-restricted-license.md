新しいユーザーが Miro サブスクリプションに参加すると、[Enterprise のライセンスモデル](02-enterprise-licensing.md)に応じて、制限付き無料ライセンスが割り当てられる場合があります。

> **対象プラン：**Enterprise プラン

## ユーザーに制限付き無料ライセンスを割り当てる場合

**フレキシブル ライセンス プログラム（FLP）では**、ユーザーに制限付き無料ライセンスを割り当てられるのは以下の場合です。

- 新規ユーザーのデフォルトのライセンスが制限付き無料に設定されている場合
- 会社の管理者がユーザーを招待する際に、招待ウィンドウで制限付き無料ライセンスを選択する場合
- 会社の管理者が、**会社の設定 > アクティブなユーザー** でユーザーを制限付き無料に変更する場合

:::note
詳しくは、[フレキシブル ライセンス プログラム（FLP）](03-flexible-licensing-program-flp.md)と[FLPでのライセンス管理](05-license-management-on-the-flexible-licensing-program-flp.md)についてご覧ください。
:::

**非フレキシブル ライセンス（非 FLP）**では、次の場合にユーザーに制限付き無料ライセンスを割り当てることができます。

- ユーザーが登録時に、自動捕捉され（[ドメイン制御](../../canvas-25-admin-features/domain-control/01-domain-control.md)または[ジャストインタイム プロビジョニング](../../user-management/13-user-provisioning-on-enterprise-plan.md)による）、組織におけるアドバンスト、スタンダード、またはフル（レガシー）ライセンスが不足している場合。
- ユーザーがアドバンスト、スタンダード、またはフル（レガシー）ライセンスが不足している組織のチームに招待された場合。

複数のユーザーを同時に招待した場合、招待者リストのメールアドレスの順にライセンスが付与されます。組織のライセンス数が不足している場合、リストの末尾にいるユーザーには、制限付き無料ライセンスが付与されます。この場合、招待したユーザーには、一部のユーザーにアクセス制限があることを知らせるポップアップ通知が届きます。

## ユーザーが使用できる制限付き無料ライセンスの機能

制限付き無料ライセンスのユーザーは、自分が参加しているチームのボードの閲覧やコメントをし、会社の管理者に編集権限や標準ライセンス、または完全（レガシー）ライセンスをリクエストすることができます。また、他のメンバーとともに組織内の他のチームを見つけて参加することもできます。

:::note
会社の管理者は[リクエスト管理設定を行う](../../user-management/09-request-management-on-enterprise-plan.md)ことができます。
:::

### 制限付き無料ライセンスのボードアクセス

制限付き無料ライセンスのユーザーには、次の閲覧、コメント、編集権限が適用されます。

|  |  |
| --- | --- |
| **ボードの共有方法** | **アクセスレベル** |
| 公開リンク | 制限付き無料ユーザーは、付与されたアクセスレベルに応じて、閲覧および / または編集ができます。 |
| チームまたは会社のリンク | 制限付き無料ユーザーは、付与されたアクセスレベルに応じて、閲覧および / またはコメントができます。 |
| [埋め込みリンク](../../../integrations-apps/integrate-miro-with-other-apps/01-user-permissions-for-boards-embedded-in-third-party-apps.md) | 制限付き無料ユーザーは、付与されたアクセスレベルに応じて、閲覧および / またはコメントができます。  制限付き無料ユーザーは、埋め込み権限で編集権限が付与されている場合でも、編集や編集権限のリクエストはできません。 |

## 制限付き無料ライセンスの管理方法

> **実行可能なユーザー：**会社の管理者

すべてのサブスクリプションで、会社の管理者は、チームの設定または会社の設定の**アクティブなユーザー**セクションで、ユーザーライセンスを制限付き無料からスタンダードまたはフル（旧版）へアップグレードすることができます。

**フレキシブルライセンスプログラム（FLP）**

フレキシブル ライセンス プログラムのサブスクリプションでは、会社の管理者は、アドバンスト、スタンダード、フル（レガシー）ライセンスをいつでも制限付き無料ライセンスにダウングレードすることもできます。

制限付き無料ライセンスを持つユーザーが編集アクセスをリクエストする場合、会社の管理者はそのリクエスト管理の設定に基づいてリクエストを受け取ります。[リクエスト管理設定](../../user-management/09-request-management-on-enterprise-plan.md)に基づいてリクエストを受け取ります。

:::note
詳細は[フレキシブル ライセンス プログラムのライセンス管理](05-license-management-on-the-flexible-licensing-program-flp.md)をご覧ください。
:::

## よくある質問

**非 FLP プランにさらに標準ライセンスやフル（従来）ライセンスを追加すると、制限付き無料ライセンスはどうなりますか？**

既存の制限付き無料ユーザーは、新しい標準ライセンスやフル（従来）ライセンスに自動的にアップグレードはされません。会社の管理者はライセンスを手動でアップグレードできます。
