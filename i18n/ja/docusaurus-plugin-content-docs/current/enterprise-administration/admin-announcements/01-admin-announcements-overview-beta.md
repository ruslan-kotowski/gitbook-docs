管理者告知を使用すると、会社の管理者が管理者コンソールから組織内のユーザーにターゲットを絞った時間制限メッセージを投稿できます。告知は選択されたオーディエンスに合ったユーザーのボードにバナーとして表示されます。

メッセージを書き、任意の宛先（例えばサインアップフォーム、Typeform、または内部ドキュメント）へのリンクとなるコールトゥアクション（CTA）を追加し、オーディエンスを選択し、告知が表示される日時をスケジュールすることができます。

管理者告知を使用して、トレーニングを促進したり、製品更新を共有したり、機能導入をサポートしたり、適切なタイミングで適切なオーディエンスからフィードバックを集めることができます。

## 主な性能

- **告知を作成すると、基本情報を追加できます**
  内部名称、メッセージテキスト、CTAラベル、リンク先URLを追加します。ライブプレビューで告知の表示を確認できます。
- **適切な対象に向けてターゲティング**
  全組織または特定のチームを選択して到達できます。エディタに推定受信者数が表示されます。
- **告知の公開期間をスケジューリング**
  開始および終了日時を設定し、告知が自動的に公開され、スケジュール期間後に削除されるようにします。
- **重要な告知を優先表示**
  告知を優先事項として設定し、他の告知よりも先に表示されるようにします。
- **告知のライフサイクルを管理する**
  すべての告知を一箇所で、ステータス、対象者、スケジュールと共に表示します。
- **いつでも告知を編集する**
  告知がライブ中でも、内容や対象者、スケジュールを更新できます。
- **告知を再利用し、コントロールする**
  告知を複製して内容を再利用したり、スケジュール済みの告知をキャンセルしたり、必要がなくなった告知を削除したりできます。
- **カスタム管理者ロールを利用して委任する**
  特定の役割に告知管理機能を割り当て、ガバナンスと内部ワークフローをサポートします。
- **テンプレートを使用して一貫性を保つ**
  定型のテンプレートを活用して、一般的なコミュニケーションシナリオに素早く対応する告知を作成します。
