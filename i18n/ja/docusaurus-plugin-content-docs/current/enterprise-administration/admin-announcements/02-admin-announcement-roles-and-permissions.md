告知は会社の管理者が管理し、カスタム管理者ロールを通じて委任できます。

## デフォルトの権限

会社の管理者は告知を作成、編集、公開、複製、中止、削除できます。

## カスタムロールでの権限設定

カスタムロールの設定では、告知の権限は**告知**の下にグループ化されています。

カスタム管理者ロールの作成と管理の詳細については、[カスタム管理者ロール](https://help.miro.com/hc/en-us/articles/22182074695698)をご覧ください。

| アクセス権限 | 説明 |
| --- | --- |
| **告知を閲覧** | ユーザーが既存の告知を閲覧できるようにします。 |
| **告知を管理** | ユーザーが告知を作成、編集、公開、複製、キャンセル、削除できるようにします。 |

## 告知管理の委任

**告知を管理**する権限を特定のユーザーやチームに割り当てることで、会社の管理者への完全なアクセス権を与えずに告知を管理させることができます。

## ユースケースの例

- **人事チーム**
  社内コミュニケーションやポリシーアップデートを管理します。
- **ITチーム**
  システムのアップデート、メンテナンスの通知、またはセキュリティー情報を共有します。
- **エネーブルメントチーム**
  トレーニングセッションやオンボーディングプログラムを促進します。
