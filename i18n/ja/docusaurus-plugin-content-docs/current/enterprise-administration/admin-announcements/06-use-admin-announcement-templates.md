テンプレートを使用することで、製品の更新情報を迅速に共有し、機能ロールアウトをサポートし、既存の更新カードを組織や特定のチーム向けのターゲット告知に変えることで採用を促進することができます。管理者告知テンプレートは、あらかじめ入力済みのコンテンツがあるため、より速く告知を作成するのに役立ちます。

## テンプレートを使用する

1. **管理者コンソール > 組織 > 管理者向けホーム画面** に移動します。
2. **What's new in Miro** で、告知したい更新情報を見つけます。
3. **告知する** をクリックします。
4. **告知作成**ページが開き、選択したアップデートの内容が自動入力されています。
5. 必要に応じて告知の詳細を確認し、更新してください。
6. **下書きを保存**や**公開**をクリックします。
   **下書きを保存**は告知を公開せずに保存します。
   **公開**は告知を即時公開するか、選択した日付に基づいてスケジュールします。
   **キャンセル**は変更を保存せずにエディターを閉じます。
