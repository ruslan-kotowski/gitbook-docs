告知ページを使用して、すべての告知を閲覧し、そのステータスを追跡し、ライフサイクル全体で管理します。

## 告知の閲覧と理解

**管理者コンソール > 組織 > 告知** に移動します。告知テーブルは、すべての告知について、名前、ステータス、日付、対象ユーザー、作成者を含む概要を提供します。

## 告知のステータス

| ステータス | 説明 |
| --- | --- |
| **下書き** | 保存されているが、まだ公開されていません。 |
| **スケジュール済み** | 将来の日付に表示されるように公開されました。 |
| **ライブ** | 現在ユーザーに表示されています。 |
| **終了** | 終了日以降はもう表示されません。 |
| **キャンセル済み** | 開始前に停止されました。 |

## 告知の更新

### 告知を編集する

1. **告知**を開きます。
2. 告知を選択します。
3. **編集**をクリックします。
4. 告知の詳細を更新します。
   メッセージ、リンクテキスト、リンク URL、対象ユーザー、スケジュール、優先順位を更新できます。
5. **公開**をクリックします。
   変更は即時に適用され、ライブ告知にも反映されます。

### 告知を公開する

1. その告知を開く。
2. 詳細を確認する。
3. **公開**をクリックする。
   開始日が未来の日付の場合、この告知は**スケジュール**され、開始日が現在または過去の日付の場合**ライブ**になります。

## 告知を再利用する

### 告知を複製する

1. 告知一覧で**アクション**メニューを開きます。
2. **複製**をクリックします。
3. 告知の詳細を更新します。
   必要に応じて名前、日付、対象者、その他の項目を変更します。
4. **下書きを保存**または**公開**をクリックします。
   **下書きを保存**すると、告知は公開されずに保存されます。
   **公開**すると、告知が指定された日付に基づいてライブまたはスケジュールされます。

## 告知のライフサイクルを管理する

### 告知をキャンセルする

1. 告知リストで、**アクション**メニューを開きます。
2. **キャンセル**をクリックします。

告知はどの状態でもキャンセルできます。ユーザーには告知が表示されなくなります。

### 告知を削除する

1. 告知リストで、**アクション**メニューを開きます。
2. **削除**をクリックします。

告知は完全に削除され、復元はできません。

## 変更履歴を追跡する

各告知にはライフサイクルと更新イベントを表示する履歴セクションがあります。

履歴には以下のようなアクションが含まれます:

- 作成
- 公開またはライブ
- 編集
- キャンセル

これらの操作は監査ログにも記録されます。
