このフローを使うと、組織のエンドユーザーが特定のアプリへのアクセスや Miro とのインテグレーションをリクエストできるようになります。会社の管理者は、これらのリクエストを承認または拒否することができます。

> ***管理者コンソールのアップデートを段階的に実施***
> Miroの新しい管理者コンソールは、再構成された設定と改善された一般的なUXパターンによって、Miroの本質的な管理ワークフローを実行しやすくしています。新しい管理者コンソールは数週間かけて順次リリースされます。
>
> すべての変更の概要を見るには、[Miroの新しい管理者コンソール（ベータ版）を](../managing-enterprise-teams-and-content/01-miro's-new-admin-console.md)ご覧ください。

> **利用可能なプラン：**[Enterprise プラン](../../plans-billing/miro-plans/04-enterprise-plan.md)

### ユーザーガイド

会社の Enterprise プランで、特定のアプリが管理者の承認を必要としている場合、アプリへのアクセスや Miro とのインテグレーションをリクエストすることができます。

アクセスをリクエストする手順は以下の通りです。

1. ボードを開き、ツールバーの **[アプリ]** アイコンをクリックします。使用するアプリを選択します。
   add_more_apps.jpg
   ツールバーからアプリを追加するオプション
   または、[Miro マーケットプレイスで](https://miro.com/marketplace/)利用可能なすべてのアプリを検索することもできます。
2. このアプリが管理者の承認を必要としている場合、管理者にリクエストを送信するオプションが表示されます。
3. ここで、インストールする理由を選択することもできます。
4. [リクエストを送信] を**クリックすると、管理者に通知が届きます。**彼らはあなたの要求を承認することも拒否することもできます。
   send_app_request.jpg
   Enterprise プランでアプリインストールのリクエストを送信するオプション
5. 管理者が判断を下すと、リクエストが承認されたか否かに関する通知が届きます。

### 管理者ガイド

> 設定者：**会社の管理者**

会社の管理者は、アプリをインストールするためのユーザー権限を設定し、アプリをインストールする際に管理者の承認を求めることができます。詳細については、こちらのガイド/span>をご覧ください。アプリケーションを使用するためのアクセスをユーザーがリクエストしたら、以下の手順に従ってリクエストを承認または拒否します。

1. ユーザーがリクエストを送信すると、メールで通知が届きます。通知は、会社の管理者全員に送信されます。
2. **会社** 設定 >**アプリとインテグレーション**>**アプリ**>**アプリリクエスト**]に移動すると、開いているユーザーリクエストのリストが表示されます。
3. アプリ名やチーム、リクエストした日付、ユーザー名、ユーザーの具体的なニーズやアプリの権限についての詳細を閲覧できます。
4. ここで、各リクエストを承認または拒否することができます。リクエストを承認すると、そのアプリは他のユーザーにもインストールが承認されます。
5. リクエストを承認または拒否すると、各ユーザーに通知が届きます。
