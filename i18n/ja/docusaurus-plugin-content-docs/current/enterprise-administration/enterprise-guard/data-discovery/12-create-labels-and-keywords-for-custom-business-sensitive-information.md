キーワードやウィジェットなど、Miroボードで特定したい条件を定義するためにラベルを作成します。最大100件のカスタムのビジネス機密ラベルを作成できます。ラベルを作成するには、以下の手順を実施してください。

:::note
カスタムラベルを作成するには、[機密コンテンツ管理者](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)の権限が必要です。機密コンテンツ管理者権限の申請については、会社の管理者にお問い合わせください。
:::

1. [Miro の設定](https://miro.com/app/settings)に移動します。
2. 左ペインで、**Enterprise Guard** の下にある**データ検出**をクリックします。
3. **データ検出**ページで、**設定**タブをクリックします。
4. **ビジネス感度の高い**カスタムのセクションで、**作成**ボタンをクリックします。
5. **カスタムラベルの定義**ページで、ラベルの詳細を追加します。

   |  |  |
   | --- | --- |
   | **フィールド** | **説明** |
   | **ラベル名** | **最大長:** 80 文字  カスタムラベルの説明的な名前です。このラベルはログには表示されないため、社内プロジェクト名を使用できます。  **注意:** ラベル名は監査ログに表示されません。このラベルに関連する監査ログを検索または閲覧するには、ラベル ID を使用できます。 |
   | **略称** | **最大長:** 10 文字、英数字  ラベル名の略称です。略称はデータ検出、コンテンツ エクスプローラー、機密分類でこのカスタムラベルを参照するために使用されます。 **注:** 略称は監査ログには表示されません。監査ログを閲覧・検索したい場合にはラベル ID を使用してください。 |
   | **説明** | **最大長:** 500 文字  このラベルが検出する情報の説明。この情報は他の管理者にとって役立ちます。 |
   | **条件** | 検出したいキーワードやウィジェットのタイプを追加し、Miroボード上で検出時にこのラベルを追加します。少なくとも1つの条件を追加する必要があります。  キーワードのみを追加し、ウィジェットのチェックボックスを選択しない場合、データ検出は提供されたキーワードの完全一致を含むすべてのサポートされたウィジェットがあるボードを検出します。現在のリリースでは、以下のボードアイテムのキーワード検出をサポートしています：付箋、カード、Jiraカード、コードブロック、コメント、フレーム、テーブル、コネクター/線、図形、テキストブロック、カンバンボード、ユーザーストーリーマップです。  また、キーワードを追加せずに、コードブロック、Jiraカード、Azureカード、またはプロトタイピング画面のみを検出することも選択できます。この場合、データ検出はそれらのウィジェットを含むすべてのボードを検出します。  キーワードとウィジェットの両方を条件として追加した場合、データ検出がボードを検出するためには、キーワードおよびウィジェットの基準を満たす必要があります。これにより、カスタムラベルを使用して検索を絞り込み、ターゲットボードをより正確に特定することが可能になります。  **例：**  - プロジェクト名が*Enterprise* *Guard*で、Jiraカードを含むボードを検出したいが、マーケティング関連のボードは除きたい場合、このラベルにはキーワード*Enterprise* *Guard*を含め、Jiraカードのチェックボックスを選択します。データ検出により、キーワードEnterprise GuardとJiraカードを含むボードが見つけられます。また、Jiraカード内のタイトルや説明にキーワードEnterprise Guardが含まれる場合も検出されます。キーワード*Enterprise* *Guard*のみを含むがJiraカードを含まないボードは、指定された両方の条件を満たさないため検出されません。  - すべての対応するウィジェットタイプに関係なく、*Enterprise* *Guard* という言葉が含まれるすべてのボードを検出したい場合は、**キーワードを追加** セクションで、キーワード **Enterprise** **Guard** を追加します。この例では、ウィジェットタイプを追加する必要はありません。  - 特定の内容に関係なく、Jira カードを含むすべてのボードを検出したい場合は、**ウィジェットタイプを追加** セクションで **Jira カード** チェックボックスを選択します。この例では、キーワードを追加する必要はありません。    **キーワードを追加するには：**  1. **キーワードを追加** をクリックします。  2. キーワードをカンマで区切って入力または貼り付けます。 **メモ：**  - キーワードは、英数字と Unicode 文字に対応します。 - キーワードやフレーズを最大100個まで追加できます。 - キーワードの前後にあるスペースは無視されます。 - データ検出は、ご提供のキーワードと完全に一致するものを大文字小文字に関係なく検出します。 - キーワードの前にスペースを追加した場合、データ検出はキーワードの前にスペースがある完全一致を検出します。 - 現在のリリースでは、キーワード検出に対応しているボードアイテムは以下のとおりです：付箋、カード、Jiraカード、コードブロック、フレーム、テーブル、コネクター/ライン、図形、テキストブロック、カンバンボード、ユーザーストーリーマップ。ノートやコメントは現時点ではデータ検出のスキャンに含まれていません。ノートとコメントを含む機能拡張のリリースを予定しています。  **例:** ボードに *confidential* または *internal* というキーワードが含まれているものを識別してラベル付けするには、次のキーワードを追加します: *confidential, internal* （キーワードをカンマで区切ってください）。データ検出はこれらのキーワードを含むすべてのボードを見つけます。  **ウィジェットタイプを追加するには:**  1. **ウィジェットタイプを追加** をクリックします。  2. Miroのボードで検出したいウィジェットタイプのチェックボックスを選択します。  **例:** Jiraカードが含まれるボードを検出してラベル付けしたい場合は、**Jiraカード**のチェックボックスを選択します。 |
6. **次へ** をクリックします。
7. カスタムラベルの詳細を確認します。

   カスタムラベルの詳細を編集したい場合は、**前へ**ボタンをクリックしてください。

   カスタムラベルの詳細が正しければ、**カスタムラベルを作成**ボタンをクリックしてください。

   ラベルを作成すると、最初のスキャンが自動的に開始されます。選択した条件に一致する結果は、組織内の Miro ボードの数に応じて数分または数時間後に利用可能です。
