:::note
ラベルは、機密分類レベルと関連付ける前に編集することをお勧めします。
:::

ラベルを編集して、キーワードやウィジェットのように、Miro ボード上で特定して見つけたい条件を更新しましょう。ラベルを編集するには、以下の手順を実施してください。

:::note
カスタムラベルを編集するには、[機密コンテンツ管理者の役割](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)が必要です。機密コンテンツ管理者権限の申請については、会社の管理者にお問い合わせください。
:::

1. [Miro の設定](https://miro.com/app/settings)に移動します。
2. 左ペインで、**Enterprise Guard** の下にある**データ検出**をクリックします。
3. **データ検出**の**概要**ページで、編集を希望するラベルの行にある三点リーダー（三つの点）をクリックし、**ラベルを編集**をクリックします。
4. **カスタム ラベルの編集**ページで、ラベルの詳細を編集します。

   |  |  |
   | --- | --- |
   | **フィールド** | **説明** |
   | **ラベル名** | **最大文字数:** 80 文字  カスタムラベル用の説明的な名前です。このラベルはログに表示されないため、社内プロジェクト名を使用することができます。  **注意:** ラベル名は監査ログには表示されません。このラベルに関連する監査ログを検索／閲覧する場合は、ラベル ID を使用してください。 |
   | **略称** | **最大長:** 10 文字、英数字  ラベル名の略称です。略称はデータ検出およびコンテンツ エクスプローラーでこのカスタムラベルを参照するために使用されます。 **注:** 略称は監査ログには表示されません。このラベルに関連する監査ログを検索/閲覧したい場合、ラベル ID を使用してください。 |
   | **説明** | **最大長:** 500 文字  このラベルが検出する情報の説明です。この情報は他の管理者に役立ちます。 |
   | **条件** | キーワードと検出したいウィジェットの種類を追加し、Miroボード上でこのラベルを追加してください。少なくとも 1 つの条件を追加する必要があります。  キーワードのみを追加し、ウィジェットのチェックボックスを選択しない場合、データ検出は提供されたキーワードに完全一致するすべてのサポートされているウィジェットを含むボードを検出します。現在のリリースでは、キーワード検出に以下のボードアイテムをサポートしています: 付箋、カード、Jiraカード、コードブロック、コメント、フレーム、テーブル、コネクター/ライン、図形、テキストブロック、カンバンボード、ユーザーストーリーマップ。  また、キーワードを追加せずに、コードブロック、Jiraカード、Azureカード、またはプロトタイピングスクリーンのみを検出するように選択することもできます。この場合、データ検出はそれらのウィジェットを含むすべてのボードを検出します。  条件としてキーワードとウィジェットの両方を追加する場合、データ検出がボードを検出するためには、キーワードとウィジェットの両方の基準を満たす必要があります。これにより、カスタムラベルを使用して、検索を洗練し、より正確にターゲットボードを絞り込むことができます。  **例:**  - プロジェクト名が*Enterprise* *Guard*を含む製品開発関連のボードを検出し、マーケティング関連のボードは検出しないように絞り込みたい場合で、さらに製品開発関連のJiraカードのみを含むボードを見つけたい場合、このラベルにキーワード*Enterprise* *Guard*を含め、Jiraカードのチェックボックスを選択します。データ検出では、キーワード*Enterprise* *Guard*とJiraカードを含むボードが見つかります。また、タイトルや説明にキーワード*Enterprise* *Guard*を含むJiraカードを含むボードも検出されます。ボードにキーワード*Enterprise* *Guard*だけが含まれていても、Jiraカードが含まれていない場合は、指定された条件を両方満たしていないため、検出されません。  - *Enterprise* *Guard*という単語が含まれているすべてのボードを、ボードに含まれているウィジェットの種類に関係なく検出したい場合は、**キーワードを追加**セクションにキーワード**Enterprise** **Guard**を追加します。この例では、ウィジェットの種類を追加する必要はありません。  - Jiraカードが含まれているすべてのボードを、特定の内容に関係なく検出したい場合は、**ウィジェットの種類を追加**セクションで**Jiraカード**チェックボックスを選択します。この例では、キーワードを追加する必要はありません。    **キーワードを追加するには:**  1. **キーワードを追加**をクリックします。  2. キーワードをカンマで区切って入力します。 **注意:**  - キーワードは英数字とUnicode文字に対応しています。  - キーワードやフレーズを最大100個まで追加できます。 - データ検出 は指定したキーワードに対して、大文字小文字の区別なく完全一致を検出します。 - 現在のリリースでは、キーワード検出の対象として以下のボードアイテムをサポートしています：付箋、カード、Jiraカード、コードブロック、フレーム、テーブル、コネクタ/線、図形、テキスト ブロック、カンバンボード、ユーザーストーリーマップ。ノートとコメントは、現在データ検出スキャンには含まれていません。ノートとコメントの機能強化リリースに向けて作業中です。  **例:** キーワード*confidential*や*internal*を含むボードを識別してラベルを追加するには、次のキーワードを追加します：*confidential, internal* （各キーワードをカンマで区切ります）。データ検出は、これらのキーワードのいずれかを含むすべてのボードを検出します。  **ウィジェットタイプを追加するには:**  1. **Add widget type**をクリックします。  2. Miro ボードで検出するウィジェットタイプのチェックボックスを選択します。  **例:** Jira カードを含むボードを検出し、ラベルを付けたい場合は、**Jira カード** のチェックボックスを選択します。 |
5. **次へ** をクリックします。
6. カスタムラベルの詳細を確認します。

   カスタムラベルの詳細を更新したい場合は、**前へ** ボタンをクリックします。

   カスタムラベルの詳細が正しければ、**カスタムラベルを更新** ボタンをクリックします。

   カスタムラベルを更新すると、スキャンが自動的に開始されます。選択した条件に一致する結果は、組織内の Miro ボードの数に応じて、数分から数時間で利用可能になります。
