[機密コンテンツ管理者](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)は、カスタム企業機密データ検出を活用することで、知的財産を含むカスタム企業機密情報を含むMiroボードの識別とラベリングを効率的に自動化できます。カスタム企業機密データ検出を使用すると、次のことができます：

- カスタム検索を使用して、ビジネス特有の機密データを検出します。
- *JIRAカードを含む*、*コードブロックを含む*、*Azureカードを含む*、または*プロトタイピング画面を含む*などの条件を追加し、キーワードと組み合わせてデータ検出結果をより精度高く絞り込みます。
- すべてのカスタムビジネス機密ラベルを一元管理して、簡単に整理および管理します。

:::note
カスタムビジネス機密ラベルを最大100個作成できます。
:::

カスタムラベルの作成方法については、[こちらのドキュメント](12-create-labels-and-keywords-for-custom-business-sensitive-information.md)をご覧ください。
