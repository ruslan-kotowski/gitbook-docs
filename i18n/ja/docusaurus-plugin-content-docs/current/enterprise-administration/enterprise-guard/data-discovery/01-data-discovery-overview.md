データ検出は、企業の堅牢なデータセキュリティーを確保する上で非常に重要な役割を果たしています。この重要なプロセスでは、組織内のすべての Miro ボードを定期的にスキャンして、プライバシー関連データやビジネス上の機密情報を含む Miro ボードを自動的に識別し、ラベル付けします。

プライバシー関連データ検出では、組織内のすべての Miro ボードを定期的にスキャンし、クレジットカード番号、国民ID番号、運転免許証番号、銀行情報などのプライバシー規制の対象となる可能性のある機密情報を特定・位置付けします。組織の Miro ボードを体系的に調査・分析することで、機密データに関連する潜在的なリスクを事前に特定できます。プライバシー関連データ検出を有効にすることで、コンプライアンス違反問題を防止するだけでなく、業務の妨げにならずに、組織全体にわたるデータの散在や漏洩に関連するリスクを軽減できます。さらに、機密データが特定されると、コンテンツ エクスプローラーを使用して特定された一致を調査し、ボードをそのリスクに応じたセキュリティー コントロールを適用することができます。[インテリジェント・ガードレール](../data-classification/01-intelligent-guardrails-overview.md)を使用して、詳細については、[プライバシー関連データ検出に関する詳細なドキュメント](https://help.miro.com/hc/sections/21607994053266)をご覧ください。

センシティブコンテンツ管理者は、企業機密情報や知的財産を含むMiroボードの識別とラベル付けを効率的に自動化するために、キーワードベースのカスタムデータ検出を活用できます。企業機密情報データ検出では、以下が可能です:

- あなたのビジネスに特有の機密データを検出するためにキーワード検索を使用します。
- Jiraカードやコードブロックを含むといった条件を加え、キーワードとともにデータ検出結果をより精度高く絞り込みます。
- 全てのカスタムキーワードラベルを一元管理し、簡単に整理と制御します。

詳細については、[企業機密情報データ検出に関する詳しいドキュメント](https://help.miro.com/hc/sections/21608065021074)をご覧ください。

- レイヤーグループ
