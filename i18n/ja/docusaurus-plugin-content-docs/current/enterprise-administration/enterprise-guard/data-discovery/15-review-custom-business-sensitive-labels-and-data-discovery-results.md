**データ検出概要**ページには、構成されたすべてのカスタムビジネス機密ラベル、ラベルのステータス、ラベルの種類、ラベルを作成した管理者、各ラベルに関連付けられたボードの機密分類、各ラベルでタグ付けされたボードの数、そしてボードを探索するためのリンクが表示されます。さらに、機密コンテンツ管理者はカスタムビジネス機密ラベルを編集したり、**データ検出概要**ページからラベル表示IDをコピーしたりすることができます。

:::note
カスタム業務機密データの検出結果を閲覧するには、[機密コンテンツ管理者の役割](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)が必要です。機密コンテンツ管理者権限の申請については、会社の管理者にお問い合わせください。
:::

## カスタムの企業機密データを含むボードを確認する

カスタム企業機密データを含むボードを探索するには、次の手順を実行します。

1. [Miro の設定](https://miro.com/app/settings)に移動します。
2. 左ペインで、**Enterprise Guard** の下にある「**データ検出**」をクリックします。
3. **データ検出****概要**ページで、ボード数のリンクをクリックします。コンテンツ エクスプローラーにボードの一覧が表示されます。詳細については、企業機密情報を含むボードのレビューを参照してください。

## ラベルの表示 ID をコピーする

監査ログにはラベル名が表示されません。特定のラベルに関連する監査ログを閲覧または検索したい場合は、ラベル表示IDを使用する必要があります。

ラベルの表示 ID を取得するには、以下の手順を実行します：

1. [Miro の設定](https://miro.com/app/settings)に移動します。
2. 左ペインの**Enterprise Guard**のセクションで**データ検出**をクリックします。
3. **データ検出** **概要** ページで、ラベルの行にある三点リーダー（...）をクリックし、ラベル表示IDをコピーしたいラベルを選択します。次に、**ラベル表示 IDをコピー**をクリックします。
