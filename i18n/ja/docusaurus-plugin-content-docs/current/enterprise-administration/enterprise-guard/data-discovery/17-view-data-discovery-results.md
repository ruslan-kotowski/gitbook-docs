データの検出サイクルは少なくとも1時間に1回実行され、すべてのボードの更新をスキャンしてプライバシー関連の情報を探します。これには、前回のデータ検出ですでにスキャンされたボードも含まれます。

:::note
データ検出結果を表示するには、[機密コンテンツ管理者ロールが](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)必要です。機密コンテンツ管理者権限の申請については、会社の管理者にお問い合わせください。
:::

図 1：データの検出結果*

当社は、技術パートナーおよびお客様と継続的に協力し、センシティブコンテンツ検出システムの改善に努めていますが、お客様のボード上のセンシティブデータを100％検出し、フラグを立てることを保証するものではありません。当社のセンシティブコンテンツ検出システムは、パターンやその他の基準を使用して、一致する確率を決定します。システムが、ボード上のデータを機密である可能性が高いとして誤ってフラグを立てたり（偽陽性）、機密であるとしてフラグを立てなかったり（偽陰性）することがあります。関連用語が近接していたり、機密データがフォーマットされているなど、さまざまな要因がこのような事態を引き起こしています。

偽陽性の一致を抑制する方法の詳細については、「[センシティブコンテンツの一致を抑制する](11-suppress-a-sensitive-content-match.md)」を参照してください。

## 最後に完了したデータの検出スキャンに関する情報の表示

データ検出**結果**」セクションには、最後のデータ検出スキャンがいつ完了したかが、「月」「日」「年」の日付形式と、「時」「分」「AM/PM」、タイムゾーン指定（GMT+オフセット）の時間形式で表示されます。例えば、 2023年12月14日午後10時15分 GMT+1（図1） 。

## データの検出結果の表示

データの検出**結果**セクションには、規制の名前、簡単な説明、関連するラベル、規制の範囲に該当する可能性のある機密コンテンツを含むボードの数などの情報が表示されます（図1）。

機密性の高いデータを含むボードを調べるには、ボード数のリンクをクリックしてください。コンテンツエクスプローラーがボードのリストと共に表示されます。詳細については、「[機密性の高いデータを扱うレビューボード](16-review-boards-with-privacy-related-information.md)」を参照してください。
