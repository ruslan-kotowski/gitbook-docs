データ検出ダッシュボードは、組織のボード全体で検出された機密情報を一元的に閲覧できるようにします。管理者はプライバシー関連または企業機密のあるコンテンツを特定することで、データリスクを監視、分類、管理することができます。データ検出ダッシュボードには、次の指標が含まれています：

> Enterprise Guard では、ゴミ箱にあるチームのボードやリーガルホールド中のボードはすべての指標から除外されます。

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| **タイトル** | **説明** | **ドメイン** | **ダッシュボード概要への表示** | **履歴指標の有無** |
| 機密情報のあるボード数 | 何らかの組み込みラベル、キーワードラベル、またはプライバシーラベルが割り当てられているボード数 | データ検出 | ✅ | ❌ |
| 企業機密情報を含むボードの数 | 何らかの組み込みラベルまたはキーワードラベルが割り当てられているボード数 | データ検出 | ✅ | ✅ |
| プライバシー関連の機密アイテムを含むボードの数 | 何らかのプライバシーラベルが割り当てられているボード数 | データ検出 | ✅ | ✅ |
| ラベルごとの、ラベルが割り当てられたボード数 | 3 種類の各ラベル（組み込み、キーワード、プライバシー）ごとに、ラベルが割り当てられたボード数をカウントします。 | データ検出 | ❌ | ❌ |
| 有効なプライバシー関連ラベルの件数 | 有効なプライバシー関連ラベルの件数 | データ検出 | ❌ | ❌ |
| 有効なキーワードラベルの件数 | 有効なキーワードラベルの件数 | データ検出 | ❌ | ❌ |
| 有効な企業機密ラベルの数 | 有効な企業機密ラベルの数 | データ検出 | ❌ | ❌ |

## エラー、空白状態、変更履歴を理解する

Enterprise Guard ダッシュボードの指標を正確に把握するには、空白状態とエラーメッセージの解釈方法を理解することが重要です。

### 設定変更に際した履歴データの動作の理解

データが収集された後にデータ検出が無効化された場合、履歴指標は依然としてアクティブ期間の値を示します。例えば、5 月にデータ検出を無効化し、4 月にデータ検出が有効だった場合：

- 4月の値が引き続きダッシュボードに表示されます。
- 5 月のグラフは、データ収集が停止したため、**データがありません**を表示します。

## データ検出結果を閲覧

データ検出サイクルでは、少なくとも 1 時間に 1 回実行され、すべてのボードの更新をスキャンして、プライバシー関連、ビジネス機密関連、またはカスタムビジネス機密関連の情報をデータ検出設定に基づいて探します。これには、前回のデータ検出ですでにスキャンされたボードも含まれます。

指標チャートの下にデータ検出結果が表示されます。ラベル名、ステータス、種別、機密分類、ボードの数などの情報を閲覧できます。

プライバシー関連の文書を伴うボードのレビューに関する詳細は、[こちらの記事](16-review-boards-with-privacy-related-information.md)をご覧ください。

ビジネス上の機密データおよびカスタムのビジネス上の機密データを含むボードの確認についての詳細は、[こちらの記事](14-review-boards-with-business-sensitive-and-custom-business-sensitive-information-beta.md)をご覧ください。

カスタムのビジネス上の機密ラベルを使用したボードの確認についての詳細は、[こちらの記事](15-review-custom-business-sensitive-labels-and-data-discovery-results.md)をご確認ください。

:::note
データ検出の結果を閲覧するには、[機密コンテンツ管理者の役割](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)が必要です。機密コンテンツ管理者権限の申請については、会社の管理者にお問い合わせください。

当社は、技術パートナーおよびお客様と連携して機密コンテンツ検出システムの改善を継続的に進めていますが、ボード上の機密データを 100% 検出してフラグを付けることを保証することはできません。当社の機密コンテンツ検出システムは、パターンやその他の基準を使用して一致の可能性を判断します。システムがボード上のデータを誤って機密情報として識別したり（偽陽性）、機密情報を見逃したり（偽陰性）することがあるかもしれません。これらの事象の発生には、関連用語の類似性や機密データの形式など、さまざまな要因が寄与しています。

[機密コンテンツの一致の抑制](11-suppress-a-sensitive-content-match.md)方法について、詳しくはリンクをご覧ください。
:::
