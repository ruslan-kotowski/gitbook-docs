データ検出スキャンの結果、コンテンツ エクスプローラーで表示されるボードのリスト件数が多く、特定の要件に基づいて結果リストをカスタマイズしたい場合があるかもしれません。[機密コンテンツ管理者](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)は、さまざまな基準に従ってボードのリストを検索、絞り込み、並び替えできるようになりました。これにより、データセキュリティーの重要な側面に集中して取り組めます。

## 特定のボードの検索

特定のボードを検索するには、コンテンツ エクスプローラーの上部にある検索バーにボード名またはボード ID のキーワードを入力します。
**ヒント：**ボードの ID は、ボードの URL から簡単に取得できます。

## コンテンツ エクスプローラーのボードのリストの並べ替え

ボードのリストは、特定の条件に基づいて昇順または降順で並べ替えることができます。たとえば、一致を基にボードのリストを昇順で並べ替えることができます。

ボードのリストを並べ替えるには、**[並べ替え]** ラベルの横にあるボタンをクリックし、適切な並べ替え条件を選択します。たとえば、一致を基にボードのリストを昇順で並べ替えたい場合は、**[並べ替え]** の横にあるボタンをクリックし、**[昇順]** をクリックし、**[一致]** をクリックします。

## コンテンツ エクスプローラーボードのリストを絞り込む

絞り込みのオプションには、場所や所有者の条件だけでなく、機密分類レベルやデータ検出ラベル（機密性ラベル）などのセキュリティー関連のパラメーターも含まれています。複数の絞り込み条件を同時に選択することも可能です。多様な絞り込み条件のオプションにより、機密コンテンツ管理者は、分析作業を効率的に行い、セキュリティー課題を素早く特定して対処することができます。

:::note
コンテンツ エクスプローラーの結果リストを絞り込むには、[機密コンテンツ管理者の役割](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)が必要です。機密コンテンツ管理者の役割をリクエストするには、会社の管理者にご連絡ください。
:::

コンテンツ エクスプローラーの結果リストの絞り込みを行う手順は以下のとおりです。

1. **コンテンツ エクスプローラー**のページにログインしている場合は、ステップ 2 に進んでください。
   **コンテンツ エクスプローラー**のページにログインしていない場合：
   a.[Miro の設定](https://miro.com/app/settings)に移動します。
   b.左枠の **Enterprise Guard** で **[コンテンツ エクスプローラー]** をクリックします。
2. **「コンテンツ エクスプローラー」**のページの **[コンテンツ セキュリティー]** の下にある **[データ検出]** をクリックします。
3. **「コンテンツ エクスプローラー / データ検出」**のページで、ページ上部の **[検索条件]** ボタンをクリックします。
   **「フィルター」**ボックスが表示されます。
4. 要件を満たす適切な検索条件をクリックします。一度に、複数の条件に基づいて検索を行うことができます。
   コンテンツ エクスプローラーでは、検索条件に一致するよう結果リストがリアルタイムで更新されます。
