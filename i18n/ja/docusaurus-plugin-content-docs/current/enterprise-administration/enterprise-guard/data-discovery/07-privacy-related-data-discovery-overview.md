プライバシー関連のデータ検出とは、組織内のすべての Miro ボードを定期的にスキャンし、クレジットカード番号、国民ID番号、運転免許証番号、銀行情報などのプライバシー規制の対象となる可能性のある機密情報を特定し、見つけ出すことです。組織の Miro ボードを体系的に探索し分析することで、機密データに関連する潜在的なリスクを事前に特定することができます。プライバシー関連のデータ検出を有効にすることで、コンプライアンス違反の問題を防ぐだけでなく、企業全体におけるデータのスプロールや流出に伴うリスクを軽減しながら、ビジネスの運営に影響を与えません。

さらに、プライバシー関連のデータが特定された後は、コンテンツ エクスプローラーを使用して特定された一致を調査し、自動分類でボードをその性質や重要度に基づいて自動的に分類し、[ガードレール](../data-classification/01-intelligent-guardrails-overview.md)を使用してリスク調整済みのセキュリティー コントロールを適用できます。

## サポートされているボード項目

- Azureカード
