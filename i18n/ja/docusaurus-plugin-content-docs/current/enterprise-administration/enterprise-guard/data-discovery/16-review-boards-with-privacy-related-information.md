データ検出ダッシュボードでは、[機密コンテンツ管理者](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)がデータ検出によって検出されたプライバシー関連データの発生を確認し、結果を検証することができます。

:::note
プライバシー関連のデータを含むボードをレビューするには、[機密コンテンツ管理者の役割](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)が必要です。機密コンテンツ管理者の役割をリクエストするには、会社の管理者にご連絡ください。
:::

プライバシー関連のデータを含むボードを確認するには、以下の手順を実行します。

1. [Miro の設定](https://miro.com/app/settings)に移動してください。
2. 画面左ペインの**Enterprise Guard**の下にある**データ検出**をクリックします。
3. **データディスカバリー****概要**ページで、メトリックの下にあるセクションまでスクロールし、確認したいカテゴリのボード数をクリックします。
   新しいページが表示され、ボードの一覧とその情報が表示されます。
4. 確認したいボードをクリックします。
   画面の右側にスライドアウトパネルが表示されます。
5. スライドアウトパネルでは、次の操作を実行できます。
   - **プライバシー関連情報を表示または非表示にする****:**デフォルトでは、プライバシー関連情報は黒塗りされます。プライバシー関連の情報を表示したい場合は、**機密情報を表示**トグルをクリックしてオンにしてください。
   プライバシー関連の情報が表示されている場合は、プライバシー関連の情報を**機密情報の表示**トグルをクリックしてオフにすることで非表示にすることができます。

   - **フィルター****プライバシー関連の****情報をデータカテゴリに基づいて：**特定のラベルに属するプライバシー関連情報を表示するには、**プライバシー関連情報**タブをクリックし、その下の適切な感度ラベルをクリックします。

   **- 誤検出を抑制する:**プライバシー関連のデータを発見する過程で、技術的には正確であっても、組織のさまざまなセキュリティーポリシーや特定のニーズに基づいて、関係がないまたは重要なデータとして見なされないケースに遭遇するかもしれません。セキュリティやプライバシーのリスクを引き起こさない一致を抑制することは、組織の特定のデータセキュリティおよびプライバシー要件に合わせてデータ検出プロセスを調整するために重要です。

   システムがボード上のデータを誤って機密の可能性があるとフラグを立てる場合もあります（誤検出）。これらの出来事には、関連用語の近接性やプライバシー関連データの書式設定が含まれる、さまざまな要因が関与しています。誤検出を抑制することもできます。

   一致を抑制すると、更新がリアルタイムで行われます。ボードの分類と適用されるガードレールは、オート分類とインテリジェントガードレールの設定に従って更新されます。

   誤検知マッチを抑制するには、抑制したいプライバシー関連のデータマッチの横にある省略記号をクリックし、**マッチを非表示にする**を選択します。更新はリアルタイムで行われることに注意してください。ボードの分類と適用されたガードレールも、自動分類およびインテリジェントガードレール構成に基づいて更新されます。
6. コンテンツ エクスプローラーの結果リストで、作業したい次のボードをクリックして必要な操作を行うか、パネルの右上にある**閉じる**ボタンをクリックしてスライドアウトパネルを閉じてください。
