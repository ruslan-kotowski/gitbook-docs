Miroボードのアイテムには、プライバシーや法令遵守に関するデータ（PII、保護対象保健情報、PCIなど）や、機密性の高いビジネスに重要なコンテンツ（財務情報、人事情報、知的財産、企業秘密など）が含まれることがあります。データ検出と自動機密分類を行った後、組織は、プライバシー、セキュリティー、そして関連法規への継続的なコンプライアンスを維持するために、プロアクティブな制御が重要です。

- ガードレールを使用すると、次のようなプロアクティブな制御を自動的に施行できます。
  ボードの内容と機密分類レベルに基づき、さまざまなレベル（公開、チーム、組織）での共有能力を自動的に制限します。
- コンテンツの複製を制限します。
- Miro AIの使用をブロックし、機密データや機密分類されたデータとのAIを活用したインタラクションを防ぎます。

これらのプロアクティブなコントロールにより、業務に支障をきたすことなく、プライバシーとコンプライアンスを持続的に維持することができます。

管理者は、組織内でインテリジェントガードレールを導入する際に次の2つのオプションを選択できます:
- **デフォルトモード:** デフォルトでは、ガードレールはボードのアクティブな共有オプションに影響を与えません。これにより、ボードの自動分類中にも継続中のコラボレーションを妨げることなく進行できます。

- **ストリクトモード:** 「**ストリクトモードでガードレールを適用**」トグルがオンの場合、ガードレールはすべてのアクティブな共有オプションを上書きします。これにより、管理者は最も厳格なレベルのコントロールが可能になりますが、一部のユーザーが即座にボードへのアクセスを失う可能性もあります。

ガードレールを設定して、機密情報に分類されたボードのユーザーが、そのボードを一般公開や組織内で共有したり、コンテンツを複製したりしないようにするシナリオを考えてみましょう。組織内の誰かが新しいボード「Financial Plan（財務計画）」を作成し、いくつかの収益数字を追加し、このボードに*機密*分類レベルを割り当てました。ガードレールの設定が自動的に適用され、すべてのユーザーがボードを共有できなくなり、ボード所有者を除くすべてのユーザーがコンテンツを複製できなくなります（図2）。

各ガードレールの詳細、説明、影響を受けるユーザーについては、[ガードレール参照ドキュメント](02-guardrails-reference.md)をご覧ください。
