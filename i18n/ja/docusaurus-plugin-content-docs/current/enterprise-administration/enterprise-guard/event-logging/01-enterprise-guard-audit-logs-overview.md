監査ログは、Enterprise Guard に関連するすべてのイベントの包括的な記録を管理者に提供します。これらのログは、効率的なトラブルシューティングのための貴重なリソースであり、ゴミ箱の保存期間ポリシーおよびゴミ箱に移動したボードの権限ポリシーの更新、組織の強制保持ポリシーの作成、更新、または削除、もしくはゴミ箱からのボードの永久削除といった重要なイベントに関する詳細な洞察を提供します。これらのアクティビティーを体系的に追跡することで、監視、分析、メンテナンスが強化され、安全かつ適切に管理されたシステムが確保されます。

## 監査ログにおける Enterprise Guard イベント

既存のイベントが記録されている[これらの](../../security-integrations/security-management/01-audit-logs.md)に加えて、監査ログには次のイベントカテゴリーおよびEnterprise Guardに関連するイベントの記録が含まれます。
