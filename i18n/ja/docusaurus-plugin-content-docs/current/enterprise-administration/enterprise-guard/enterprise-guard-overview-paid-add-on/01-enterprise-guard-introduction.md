今日のデジタル時代において、データ、特に機密情報の急激な増加は、企業にとって重要な懸念事項となっています。イノベーションとチームワークを促進するエンタープライズ対応のオンライン コラボレーション ワークスペースである Miro は、ボード内のコンテンツについて、その複雑さと量が大幅に増加していることを把握しています。多くの Miro ボードには、個人識別情報（PII）、保護された医療情報（PHI）、支払いカード情報（PCI）などの機密性の高いデータが含まれており、リスク管理とコンプライアンスの確保に課題をもたらしています。この傾向は、潜在的なデータ漏洩や知的財産の流出を防ぐために、高度なセキュリティーとコンプライアンス対策を導入することの重要性を浮き彫りにしています。

## Enterprise Guard の紹介：Miro の包括的なセキュリティーおよびガバナンス ソリューション

これらの課題を認識して、Miro は高度なセキュリティーとガバナンスのアドオンである**Enterprise Guard**を導入しました。Enterprise Guard は、組織が Miro ボード全体で機密コンテンツを効果的に識別、分類、保護、管理できる機能を提供します。このソリューションは、コンプライアンスと堅牢なデータ保護を大規模に保証するように調整されています。

Enterprise Guard が Miro の企業向けエコシステムに統合されたことで、企業のお客様は、より強固で包括的な自動化されたセキュリティー機能をご活用いただけます。このアドオンは単にデータを保護するものではなく、企業が Miro で安全に革新し、コラボレーションを続けることを可能にし、—業務の妨げにならないようにすることを目的としています。 業務を妨げることなく

## Enterprise Guard 一般公開リリース：主な機能

![Enterprise Guard 一般公開リリースの主な機能](images/21019694882834_Enterprise-Guard-Data-Security.png)

- **データ検出:**Enterprise Guard では、[データ検出](../../canvas-25-admin-features/data-discovery/01-data-discovery-overview.md)プロセスを能動的かつ徹底的に行うことができ、クレジットカード番号、社会保障番号などの重要な機密データを特定するために重要です。これらは様々な Miro ボードに散在しています。この能動的なプロセスは、潜在的な脆弱性を特定してリスクを軽減し、データ漏洩を防止してコンプライアンスを確保する上で極めて重要です。
- **eDiscovery:**法的、コンプライアンス、およびセキュリティ要件をサポートするために、ボードデータの安全な保存、追跡、エクスポートを可能にします。Enterprise Guard の eDiscovery 機能は、[法的保留](../../canvas-25-admin-features/ediscovery/02-legal-hold-overview.md)、[コンテンツログ](../../canvas-25-admin-features/ediscovery/06-content-logs-overview.md)、および[ボードエクスポート](../../canvas-25-admin-features/ediscovery/13-board-export-api-overview.md)機能を通じて、組織が規制遵守を達成するのを支援します。

  リーガルホールドは、調査や法的問題に関連するコンテンツの恒久的な削除を防ぐため、ホールド中のユーザーが関与するすべてのボードを保持します。これには、そのすべてのバージョンが含まれます。コンテンツログは、ユーザーの活動の詳細な記録を提供し、監査や法的レビューのために外部ツールにエクスポートおよび統合できます。eDiscovery API を使用することで、Enterprise のお客様はボードデータを大規模にエクスポートでき、重要な情報が法務およびコンプライアンスのワークフローでアクセス可能であることを保証します。
- **自動機密分類**:Miro に基準を設定し、ボードに見つかった機密コンテンツを基に[ボードを自動的に分類](../../canvas-25-admin-features/data-classification/03-auto-classification-overview-and-scenarios.md)します。
- **インテリジェント ガードレール****：**[リアルタイム セキュリティルールを強制し](../../canvas-25-admin-features/data-classification/01-intelligent-guardrails-overview.md)、ユーザーがボードでできることを制限します。例えば、ボードの手動または自動分類に基づいて、ボードコンテンツの複製や共有機能を各レベル（公開、チーム、組織）で制限します。これにより、業務に支障をきたすことなく、プライバシーとコンプライアンスを維持することができます。
- **ゴミ箱ポリシー**:[Enterprise Guard のゴミ箱ポリシー](https://help.miro.com/hc/articles/13860817985426)では、Miro ボードの削除と復元について高度な制御が可能になります。データ保持と企業リスク最小化の均衡という観点から、規制要件への準拠のため、自動削除の期限（30 日、60 日、90 日、180 日）を設定することができます。
- **保持:**データ保護とコンプライアンスのため、管理者が組織のニーズに合わせてポリシーを定義、編集、削除できます。これらのポリシーは、組織内の Miro ボードを保護するために重要な役割を果たし、特定のボードを指定期間保持することができます。[強制保持](https://help.miro.com/hc/articles/16855776325778)を適用すると、ボードが強制保持期間を過ぎるまで Miro ボードが誤って、または故意に削除されることはありません。強制保持ポリシーを活用することで、データ保護とコンプライアンスを担保し、ビジネスクリティカルな情報を保護することができます。
- ****強制処分:****ボードの自動クリーンアップを有効にし、保持ポリシーに基づいてアーカイブおよび削除します。[処分](../../canvas-25-admin-features/content-lifecycle-management/03-disposition-overview.md)は、必要な期間のみボードが保持され、一定期間利用がないと自動的にゴミ箱に移動されることを保証します。その後、標準のゴミ箱設定により、誰がボードを復元できるかや、いつボードが永久に削除されるかが決まり、コンプライアンスのサポート、運用効率、データセキュリティが強化されます。
- **暗号鍵管理****(EKM)****：**[EKM](../../canvas-25-admin-features/encryption-key-management/01-encryption-key-management-overview.md) は暗号鍵の一元管理を可能にします。組織内の鍵に関連するアクティビティーを監視し、必要な場合はいつでもアクセスを取り消すことができるため、データセキュリティーがさらに強化されます。
