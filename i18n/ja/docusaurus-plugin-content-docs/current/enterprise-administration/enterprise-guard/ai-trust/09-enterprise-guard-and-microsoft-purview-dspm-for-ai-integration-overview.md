Microsoft Entra ID (以前は Azure AD)をアイデンティティ プロバイダーとして使用している組織において、Enterprise Guard は AI プロンプトと応答を Microsoft Purview データセキュリティ ポスチャー管理 (DSPM) に安全に転送します。AI セキュリティおよびコンプライアンス チームは、単一の信頼されたプラットフォームから生成 AI の使用を監視、監査、制御することができ、運用上の負担を軽減し、データ漏洩や不正使用といったリスクを軽減し、Miro のエンタープライズ グレードの AI ガバナンスを強化します。

:::note
ベータ版のリリースでは、ダイアグラム、マインド マップ、文書、プロトタイプ、付箋、およびテーブルを含む Miro AI フォーマットをサポートしていますが、画像はサポートしていません。次回のリリースで画像およびその他の AI 機能のサポートを追加する予定です。
:::

## **対象ユーザー**

この機能は、Miro と Microsoft Entra ID（旧 Azure AD）/Microsoft Purview を管理する Enterprise Guard 顧客にベータ版として提供されています。

## **受けられる機能**

- **集中管理された可視性:** Microsoft Purview の AI ハブで Miro AI の使用状況を閲覧します。
- **監査可能性:** プロンプト（ユーザー入力）と応答（AI 出力）は、レビューのために記録されます。
- **ガバナンスの整合性:** Purview の既存のワークフローを使用して監視、アラート、および強制保持を行います。

詳細については、[こちらの詳細なドキュメント](../../enterprise-subscription-management/integrations/02-enterprise-guard-and-microsoft-purview-dspm-for-ai-integration-overview.md)をご覧ください。
