ブロックするラベルを調整したり、コードスキャンを切り替えたりするには:

1. **設定** → **Enterprise Guard** → **データ検出** → **設定**に移動します。
2. **プロンプトブロッキング**で、**管理**を選択します。
3. サイドパネルで、次のいずれかを実行します:
   - **すべて選択**をオンまたはオフにします。
   - ブロックしたい特定のラベルカテゴリーにチェックを入れる、または外します。
   - **コードスキャン**をオンまたはオフにします。
4. **変更を適用**を選択します。

変更はすべてのユーザーに対して即座に適用されます。新たにブロック解除された項目を含むプロンプトは進行し、それでもブロックされている項目を含むプロンプトは停止されたままとなります。
