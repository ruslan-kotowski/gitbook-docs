組織に対してプロンプトブロックを有効にするには:

1. Miro で、**設定** → **Enterprise Guard** → **データディスカバリー** → **設定** に進みます。
2. **プロンプトブロッキング** で、**有効化** をクリックします。
3. サイドパネルで、**すべてを選択** またはブロックする特定のラベルカテゴリを選びます。
4. （任意）**コードスキャン** をオンにして、ソースコード（最低5行）を含むプロンプトをブロックします。詳細は、[コードスキャン](../../enterprise-guard/ai-trust/06-prompt-blocking-overview.md) を参照してください。
5. **有効化** をクリックします。

プロンプトブロッキングは、あなたの組織で有効になっています。選択されたすべてのカテゴリが即座に適用されます。
