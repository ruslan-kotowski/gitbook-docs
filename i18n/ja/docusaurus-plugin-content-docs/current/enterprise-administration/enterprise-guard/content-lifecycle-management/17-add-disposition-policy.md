:::note
強制処分ポリシーを追加するには、[データガバナンス管理者の役割](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)が必要です。データガバナンス管理者の役割をリクエストするには、会社の管理者にご連絡ください。
:::

強制処分ポリシーを追加するには、次の手順を実行します：

1. 自分の[Miro 設定](https://miro.com/app/settings)にアクセスします。
2. **Enterprise Guard**の下で、左ペインから**コンテンツライフサイクル**をクリックします。
3. **強制処分**タブをクリックします。
   **強制処分ポリシー**のページが表示されます。
4. **強制処分ポリシーを追加**をクリックします。
5. 各フィールドに適切な情報を入力または選択します。以下の表に、各フィールドとその説明を示します。

   |  |  |
   | --- | --- |
   | **フィールド** | **説明** |
   | **名前**  **（必須）** | 強制処分ポリシーの名前  最大長：60 文字 |
   | **説明**  **（任意）** | この強制処分ポリシーについての説明。  最大長：300 文字。 |
   | **強制処分期間**  **（必須）** | ボードを自動的にゴミ箱に移動するタイミングを指定します。数を選択し、**月**または**年**を選び、期間がボードの**最終更新**日または**最終アクセス**日から計算されるかを選択します。  処分期間を「月」で指定する場合、1 か月から 120 か月の間で選択する必要があります。  処分期間を「年」で指定する場合、1 年から 10 年の間で選択する必要があります。  例えば、1 年間変更されていない場合にボードをゴミ箱に移動したい場合は、1 年を選択して「**最後に変更**」を選択できます。 |
   | **範囲**  **（必須）** | この強制処分ポリシーの範囲を選択します。範囲は、この強制処分ポリシーが適用されるボードを示します。組織内のすべてのボード、または特定のボードの機密分類レベルに対して強制処分ポリシーの範囲を設定できます。  **組織内のすべてのボードに対して強制処分ポリシーを設定する** 組織内のすべてのボードに対して強制処分ポリシーを設定する場合、**スコープ**リストで**組織内のすべてのボード**を選択します。  **組織内の1つまたは複数のチームに対して処分ポリシーを設定する** 組織内の1つまたは複数のチームのために処分ポリシーの範囲を設定したい場合、次の手順を実行します。  1. **スコープ**のリストで、**チーム**を選びます。 2. **チームを入力**のボックスをクリックし、強制処分ポリシーを適用したい各チームを選択します。 選択したチームの横にチェックマークが表示され、強制処分ポリシーに関連付けられます。   ✏️ - 強制処分ポリシーに対して複数のチームを選択できます。ただし、任意のチームは一度に1つの強制処分ポリシーのみと関連付けることができます。  - 削除されたチームも含め、任意のチームを強制処分ポリシーのスコープとして選択できます。   - 強制処分ポリシーのスコープとして選択されたチームは、そのチームがスコープから外されるまで完全に削除することはできません。  **ボード分類レベルの強制処分ポリシーを設定**  ✏️ 強制処分ポリシーの範囲を特定のボード機密分類レベルに設定するには、データの機密分類機能がオンになっていることを確認する必要があります。一度強制処分ポリシーにボード機密分類レベルを使用すると、データの機密分類機能をオフにすることはできません。詳細については、[データ分類](https://help.miro.com/hc/sections/15451275412498-Auto-classification)に関するドキュメントをご覧ください。  特定のボードの機密分類レベルに強制処分ポリシーの範囲を設定する場合は、次の手順を実行します：  1. **範囲** リストで **機密分類** を選択します。 2. **機密分類** リストの横にあるリストをクリックし、強制処分ポリシーを適用したい機密分類レベルを選択します。また、機密分類レベルを検索して、それから選択することもできます。  選択した機密分類レベルの横に強制処分ポリシーに関連付けるためのチェックマークが表示されます。  ✏️ **注意:** - 複数の機密分類レベルを一度に選択できます。 - 同じ機密分類レベルを異なる強制処分ポリシーに設定することはできません。特定の機密分類レベルがすでに強制処分ポリシーに関連付けられている場合、その機密分類レベルは灰色で表示されます。  - 強制処分ポリシーにボードの機密分類レベルが使用されると、データの機密分類機能をオフにすることはできません。  一度、分類レベルが強制処分ポリシーに関連付けられると、その特定の分類レベルを削除することはできません。 - ボードが組織スコープのすべてのボードと分類スコープの強制処分ポリシーの両方によって管理されている場合、処分期間の長い方のポリシーが適用されます。 |
6. Click **Next**.
   The **Review impact page** appears.
7. 強制処分ポリシーの影響を確認します。影響を確認するページには、以下の情報が記載されています：
   - **概要：**ポリシー名、強制処分期限、範囲などの強制処分ポリシーの設定。
   - **ポリシーによる影響：**ポリシーが適用されるボードの数。
8. 設定を保存して強制処分ポリシーを適用するには、**公開**をクリックします。
   **強制処分通知を有効にする**ダイアログボックスが表示されます。
9. **強制処分の通知**により、ユーザーはボードが非アクティブのために自動的にゴミ箱に移動される前に、事前に警告を受け取ることができます。これらの警告によって、コンテンツを保持したいユーザーが行動を起こす手助けとなります。

   強制処分の通知を有効にするには：

   a. **通知**をクリックします。

   b. 通知を何日前に送信するかを設定します — **1 から 30 日**のいずれかの値に設定可能です。

   通知を有効にしたことで**一部のボードが即座にゴミ箱に移動される**場合（すでに閾値を超えているため）、その特定のボードについてユーザーに通知するかどうかを尋ねられます。次の選択が可能です:

   - **はい** – ボードがすぐにゴミ箱に移動されたとしても、ボードの所有者および共同所有者に通知を送信する。

   -**いいえ** – この即時アクションについて通知を送信せずにボードを移動する。

   通知を有効にすると、通知がオンになっている強制処分ポリシーの範囲内にあるボードを持つユーザーは次のことができます:

   - Miroの**お知らせ**フィードで設定された検査期間中に通知を受け取る。

   - 通知から直接ボードを開ける。

   - ボードの上に**バナー**が表示され、今後の自動ゴミ箱移動について警告が出ます。保持したい場合は、**ボードを保持**するオプションがあります。

:::note
ポリシーの作成、更新、削除の操作は強制処分ポリシーのプロセスを開始し、最大で24時間かかることがあります。しかし、ポリシーの名前や説明の更新は、これらの操作が強制処分ポリシーのプロセスを起動しないため、即座に行われます。
:::
