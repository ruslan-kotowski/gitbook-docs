**ボードがゴミ箱から自動的に完全に削除された場合、チームメンバーに通知されますか？**

いいえ。ボードをゴミ箱から自動的に完全に削除しても、チームメンバーには通知されません。

**ゴミ箱から永久に削除されたボードを復元できますか？**

ゴミ箱から永久に削除されたボードを復元することはできません。

**ボードが自動的に永久に削除されないようにすることはできますか？**

ベータ版ではできません。

**ボードをゴミ箱から永久に削除するための公開 API はありますか？**

ベータ版リリースでは、公開 API はサポートされていません。
