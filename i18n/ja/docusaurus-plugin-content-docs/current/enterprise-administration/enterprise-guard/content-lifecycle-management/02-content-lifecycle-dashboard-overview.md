Content Lifecycle ダッシュボードは、ボードの作成から削除まで、データ利用のライフサイクル全体を監視・管理するための一元的な閲覧機能を管理者に提供します。これにより、組織のデータ保持ポリシーと整合性を保つことができます。各ボードの現在のライフサイクルステージの可視性を提供し、適切なコンテンツ処理を確保するのに役立ちます。

管理者は、強制保持および強制処分ポリシーによって管理されているボードを追跡し、ポリシー適用の履歴を閲覧することもできます。ダッシュボードには、強制処分予測が含まれており、今後の自動ライフサイクル処理に向けた積極的な計画が可能です。これにより、組織全体のポリシーに基づいたコンテンツ管理が一貫して行えます。

:::note
Enterprise Guard のすべてのメトリクスでは、ゴミ箱に入ったチームのボードやリーガルホールド中のボードは除外されます。
:::

## エラー、空白状態、変更履歴について理解する

Enterprise Guard ダッシュボードの指標を正確に把握するには、空白状態とエラーメッセージの解釈方法を理解することが重要です。

### 設定変更に際した履歴データの動作を理解する

データが収集された後にデータ検出が無効化された場合、履歴指標は依然としてアクティブ期間の値を示します。例えば、5 月にデータ検出を無効化し、4 月にデータ検出が有効だった場合：

- 4月の値が引き続きダッシュボードに表示されます。
- 5月のグラフは、データ収集が停止されたため**データがありません**を表示します。
