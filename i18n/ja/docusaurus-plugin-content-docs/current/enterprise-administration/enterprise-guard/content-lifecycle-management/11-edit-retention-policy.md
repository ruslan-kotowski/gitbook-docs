:::note
強制保持ポリシーを編集するには、[データガバナンス管理者の役割](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)が必要です。データガバナンス管理者の権限をリクエストするには、会社の管理者にご連絡ください。
:::

強制保持ポリシーを編集するには、次の手順を実施してください。

1. [Miro 設定](https://miro.com/app/settings)に移動します。
2. 左のペインで**Enterprise Guard** の下にある**コンテンツ ライフサイクル**をクリックします。
3. **保持**タブをクリックします。
4. **保持ポリシー** ページで、編集したい**保持ポリシー**をクリックします。
   そのポリシーに関連する情報が表示されます。
5. ページの右上にある **編集**をクリックし、必要なフィールドを編集します。以下の表に各フィールドとその説明が記載されています。

   |  |  |
   | --- | --- |
   | **フィールド** | **説明** |
   | **名前**  **（必須）** | 強制保持ポリシーの名前。  最大長：60 文字。 |
   | **説明**  **（任意）** | 強制保持ポリシーの説明  最大長：300 文字 |
   | **保持期間**  **（必須）** | ボードが完全に削除されないようにする期間を以下の基準のいずれかに基づいて選択します：**最後のアクセス**、**最後に変更**、または**作成日**。数値を選択し、**月**または**年**を選択した後、どのイベントから保持期間が計算されるかを選択してください。  保持期間を月単位で指定する場合は、1か月から120か月の間で選択する必要があります。  保持期間を年単位で指定する場合は、1年から10年の間で選択する必要があります。 |
   | **範囲**  **（必須）** | この強制保持ポリシーの範囲を選択します。範囲には、当該の強制保持ポリシーが適用されるボードが表示されます。強制保持ポリシーの範囲は、組織内のすべてのボード、または特定のボードの機密分類レベルに対して設定できます。  **組織内のすべてのボードに対する保持ポリシーの設定** 組織内のすべてのボードに対する保持ポリシーの範囲を設定する場合は、**範囲**リストで**組織内のすべてのボード**を選択します。  **組織内の1つまたは複数のチームに対する保持ポリシーの設定** 組織内の1つまたは複数のチームに対する保持ポリシーの範囲を設定する場合は、次の手順を実行します:  1. **スコープ**リストから**チーム**を選択します。 2. チームの入力ボックスをクリックして、強制保持ポリシーを適用したい各チームを選択します。 選択したチームの横にチェックマークが表示され、強制保持ポリシーに関連付けられます。   ✏️ - 強制保持ポリシーには複数のチームを選択できます。ただし、任意のチームは同時に1つの強制保持ポリシーのみに関連付けることができます。 - 強制保持ポリシーを設定する際、削除されたチームを含む任意のチームをスコープに選択できます。   - 強制保持ポリシーのスコープとして選択されたチームは、そのスコープから削除されるまで完全に削除することはできません。  **ボードの機密分類レベルに対して強制保持ポリシーを設定する**  ✏️ 強制保持ポリシーの範囲を特定のボード機密分類レベルに設定するには、データの機密分類機能がオンになっていることを確認する必要があります。強制保持ポリシーにボードの機密分類レベルを使用すると、データの機密分類機能をオフにすることはできません。詳細は、[データの機密分類](https://help.miro.com/hc/sections/15451275412498-Auto-classification)に関するドキュメントを参照してください。  特定のボードの機密分類レベルに強制保持ポリシーの範囲を設定する場合は、次の手順を実行します:  1. **機密分類**リストで、**分類**を選択します。 2. **機密分類**リストの横にあるリストをクリックし、強制保持ポリシーを適用したい機密分類レベルを選択します。また、機密分類レベルを検索して選択することもできます。 強制保持ポリシーに関連付けられた機密分類レベルの横にチェックマークが表示されます。  ✏️ **注意:** - 複数の機密分類レベルを同時に選択することができます。 - 異なる強制保持ポリシーに同じ機密分類レベルを設定することはできません。ある特定の機密分類レベルがすでに強制保持ポリシーに関連付けられている場合、その機密分類レベルは灰色で表示されます。  - 強制保持ポリシーにボードの機密分類レベルを使用すると、データの機密分類機能をオフにすることはできません。  機密分類レベルが強制保持ポリシーに関連付けられると、その機密分類レベルを削除することはできません。 - ボードが、組織スコープ内のすべてのボードと機密分類スコープの両方の強制保持ポリシーによって管理されている場合、保持期間の長い方が適用されます。 |
6. 終了したら **次へ** をクリックします。
   **影響を確認ページ**が表示されます。
7. 強制保持ポリシーの影響を確認します。この影響確認ページには、次の情報が記載されています：
   - **概要：**ポリシー名、強制保持期間、範囲などの強制保持ポリシーの設定内容。
   - **ポリシーによる影響：**このポリシーが適用されるボードの数。強制保持ポリシーはゴミ箱内のボードにも適用され、影響を確認する際の計算対象となります。

   > ✏️ ボードが時間ベースと機密分類ベースの両方の強制保持ポリシーによって管理されている場合、強制保持期間の長い方の方針が適用されます。
8. 設定を保存して強制保持ポリシーを適用するには、**公開**をクリックします。

:::note
ポリシーの作成、更新、削除を行うと、強制保持ポリシーのプロセスが起動し、完了までに最大24時間かかることがあります。ただし、ポリシーの名前や説明の更新は、これらのプロセスを起動せず、即座に行われます。
:::
