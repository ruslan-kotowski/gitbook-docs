:::note
強制処分ポリシーを編集するには、[データガバナンス管理者の役割](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)が必要です。データガバナンス管理者の権限をリクエストするには、会社の管理者にご連絡ください。
:::

強制処分ポリシーを編集するには、以下の手順を実行してください:

1. [Miro の設定](https://miro.com/app/settings)に移動します。
2. 左側のペインで**Enterprise Guard**の下にある**コンテンツ ライフサイクル**をクリックします。
3. **強制処分**タブをクリックします。
   **強制処分ポリシー**のページが表示されます。
4. **強制処分ポリシー**のページで、編集したい強制処分ポリシーをクリックします。
   そのポリシーに関連する情報が表示されます。
5. ページの右上にある**編集**をクリックし、必要なフィールドを編集します。以下の表に、各フィールドとその説明を示します。

   |  |  |
   | --- | --- |
   | **フィールド** | **説明** |
   | **名前**  **（必須）** | 強制処分ポリシーの名前。  最大長：60 文字。 |
   | **説明**  **（任意）** | この強制処分ポリシーについての説明。  最大長：300 文字。 |
   | **強制処分期間**  **（必須）** | ボードを自動的にゴミ箱に移動するタイミングを指定します。数値を選択し、**月**または**年**を選び、期間をボードの**最終更新**日または**最終アクセス**日から計算するか選択します。  処分期間を「月」で指定する場合は、1 か月から 120 か月の間で選択する必要があります。  処分期間を「年」で指定する場合は、1 年から 10 年の間で選択する必要があります。  たとえば、1 年間変更されていないボードをゴミ箱に移動する場合、「1 年」を選択し、「**最終変更**」を選ぶことができます。 |
   | **範囲**  **（必須）** | この強制処分ポリシーの範囲を選択します。範囲は、この強制処分ポリシーが適用されるボードの範囲を示します。強制処分ポリシーの範囲は、組織内のすべてのボードまたは特定のボードの機密分類レベルに対して設定できます。  **組織内のすべてのボードに対する強制処分ポリシーの設定** 組織内のすべてのボードに対する強制処分ポリシーのスコープを設定する場合は、**スコープ**リストで**組織内のすべてのボード**を選択してください。  **組織内の1つ以上のチームに対して強制処分ポリシーを設定する** 組織内の1つ以上のチームに対して強制処分ポリシーの範囲を設定したい場合、次のステップを実行してください。  1. **スコープ**リストで**チーム**を選択します。 2. **チームを入力**ボックスをクリックして、強制処分ポリシーを適用したい各チームを選択します。 選択したチームの横にチェックマークが表示され、強制処分ポリシーに関連付けられていることを示します。   ✏️ - 複数のチームを強制処分ポリシーに選択できます。ただし、特定のチームは同時に1つの強制処分ポリシーにしか関連付けられません。  - 削除済みのチームを含む任意のチームを、強制処分ポリシーの範囲として選択できます。  - 強制処分ポリシーの範囲に選択されたチームは、範囲から削除されるまで完全に削除することはできません。  **ボード分類レベルのための強制処分ポリシーを設定する**  ✏️ 強制処分ポリシーの範囲を特定のボード機密分類レベルに設定するには、データの機密分類機能がオンになっていることを確認する必要があります。強制処分ポリシーにボード機密分類レベルを使用すると、データの機密分類機能をオフにすることはできません。詳細については、[データ機密分類](https://help.miro.com/hc/sections/15451275412498-Auto-classification)に関するドキュメントをご覧ください。  特定のボードの機密分類レベルに強制処分ポリシーの範囲を設定する場合は、次の手順を実行してください：  1. **スコープ**リストで**機密分類**を選択します。 2. **機密分類**リストの横にあるリストをクリックし、強制処分ポリシーを適用する機密分類レベルを選択します。機密分類レベルを検索して選択することもできます。 強制処分ポリシーに関連付けるために選択した機密分類レベルの横にチェックマークが表示されます。  ✏️ **注:** - 複数の機密分類レベルを同時に選択できます。 - 同一の機密分類レベルを異なる強制処分ポリシーに設定することはできません。特定の機密分類レベルがすでに強制処分ポリシーに関連付けられている場合、その機密分類レベルは灰色で表示されます。 - 強制処分ポリシーでボードの機密分類レベルを使用すると、データの機密分類機能をオフにすることはできません。 - 機密分類レベルが強制処分方針に関連付けられると、その特定の機密分類レベルを削除することはできません。 - ボードが組織スコープ内のすべてのボードと機密分類スコープの両方の強制処分方針により管理されている場合、処分期間の長い方の方針が適用されます。 |
6. 「**次へ**」をクリックします。
   **影響の確認ページ**が表示されます。
7. 強制処分の影響を確認します。影響を確認するページには、以下の情報が記載されています。
   - **概要：**ポリシー名、強制処分期間、適用範囲などの処分ポリシーの設定。
   - **ポリシーによる影響：**このポリシーが適用されるボードの数。
8. 設定を保存して強制処分ポリシーを適用するには、**公開** をクリックします。
   もし強制処分通知が有効でない場合、**処分通知を有効にする** ダイアログボックスが表示されます。
9. **強制処分通知**は、ボードが自動的にゴミ箱に移動される前に、ユーザーが事前のアラートを受け取ることを可能にします。これらのアラートは、ユーザーがコンテンツを保持したい場合にアクションを取るのに役立ちます。

   強制処分通知を有効にしたい場合:

   a. **通知**をクリックしてください。

   b. 通知を何日前に送信するかを設定します—**1日から30日**の範囲で設定可能です。

   通知を有効にした場合、**一部のボードが即座にゴミ箱に移動される**（すでに閾値を超えているため）ことになる場合、その特定のボードについてユーザーに通知するかどうかが尋ねられます。選択できます：

   - **はい** – ボードがすぐにゴミ箱に移動される場合でも、ボードの所有者および共同所有者に通知します。

   - **いいえ** – この即時のアクションに対して通知を送信せずにボードを移動します。

   一度有効にすると、通知がオンになっている強制処分ポリシーの範囲に含まれるボードを持つユーザーは：

   - 設定した検査ウィンドウ内にMiroの**お知らせフィード**で通知を受け取ります。

   - 通知から直接ボードを開くことができます。

   - ボードに予定されている自動ゴミ箱移送を警告する**バナー**が表示されます。保持したい場合は、「**ボードを保持**」を選択できます。

:::note
ポリシーの作成、更新、削除の操作により、強制処分ポリシーのプロセスが開始されますが、最大で24時間かかることがあります。ただし、ポリシーの名前または説明の更新については、これらの操作は強制処分ポリシーのプロセスを起動せず、更新は即座に行われます。
:::
