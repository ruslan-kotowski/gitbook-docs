:::note
強制保持ポリシーを追加するには、[データガバナンス管理者の権限](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)が必要です。データガバナンス管理者の権限をリクエストするには、会社の管理者にご連絡ください。
:::

強制保持ポリシーを追加するには、次の手順を実施してください。

1. 自分の[Miro 設定](https://miro.com/app/settings)に移動します。
2. 左のペインで、**Enterprise Guard**の下にある**コンテンツライフサイクル**をクリックします。
3. **強制保持**タブをクリックします。
   **強制保持ポリシー**ページが表示されます。
4. **強制保持ポリシーの追加**をクリックします。
   **基準の定義**ページが表示されます。
5. 各フィールドに適切な情報を追加または選択します。以下の表に、各フィールドとその説明を示します。

   |  |  |
   | --- | --- |
   | **フィールド** | **説明** |
   | **名前**  **（必須）** | 強制保持ポリシーの名前  最大長：60 文字 |
   | **説明**  **（任意）** | 強制保持ポリシーの説明。  最大長：300 文字。 |
   | **保持期間**  **（必須）** | 特定の条件に基づいて、一定期間内はボードが完全に削除されるのを防ぎます。条件は**最終アクセス日**、**最終更新日**、または**作成日時**のいずれかです。数値を選択し、**月**または**年**を選択し、保持期間をどのイベントから計算するかを決定します。  保持期間を月単位で指定する場合は、1か月から120か月の期間を選択する必要があります。  保持期間を年単位で指定する場合は、1年から10年の期間を選択する必要があります。 |
   | **範囲**  **（必須）** | この強制保持ポリシーの範囲を選択します。範囲には、当該の強制保持ポリシーが適用されるボードが表示されます。強制保持ポリシーの範囲は、組織内のすべてのボード、または特定のボードの機密分類レベルに対して設定できます。  **組織内のすべてのボードに対する保持ポリシーの設定** 組織内のすべてのボードに対する保持ポリシーのスコープを設定する場合は、**スコープ**リストから**組織内のすべてのボード**を選択します。  **組織内の1つ以上のチームに対する保持ポリシーの設定** 組織内の1つ以上のチームに対する保持ポリシーのスコープを設定する場合は、以下の手順を実行します：  1. **対象範囲**のリストで、**チーム**を選択します。 2. チーム入力ボックスをクリックし、強制保持ポリシーを適用したい各チームを選択します。 強制保持ポリシーと関連付けるために選択したチームの横にチェックマークが表示されます。   ✏️ - 強制保持ポリシーには複数のチームを選択できます。ただし、特定のチームが同時に関連付けられる強制保持ポリシーは1つだけです。  - 強制保持ポリシーの設定時には、削除されたチームを含む任意のチームをスコープとして選択できます。   - 強制保持ポリシーのスコープとして選択されているチームは、スコープから削除されるまで完全に削除することはできません。  **ボードの機密分類レベルに対する強制保持ポリシーの設定**  ✏️ 強制保持ポリシーの範囲を特定のボード機密分類レベルに設定するには、まずデータの機密分類機能がオンになっていることを確認してください。強制保持ポリシーにボードの機密分類レベルを使用すると、データの機密分類機能をオフにすることはできません。詳しくは、[データの機密分類](https://help.miro.com/hc/sections/15451275412498-Auto-classification)に関するドキュメントをご覧ください。  特定のボードの機密分類レベルに強制保持ポリシーの範囲を設定する場合は、以下の手順を実行してください。  1. **範囲**リストで**機密分類**を選択します。 2. **機密分類**リストの横にあるリストをクリックし、強制保持ポリシーを適用する機密分類レベルを選択します。機密分類レベルを検索して選択することもできます。 強制保持ポリシーに関連付けるために選択した機密分類レベルの横にチェックマークが表示されます。  ✏️ **注:** - 複数の機密分類レベルを一度に選択することができます。 - 異なる強制保持ポリシーに同じ機密分類レベルを設定することはできません。特定の機密分類レベルがすでに強制保持ポリシーに関連付けられている場合、その機密分類レベルは灰色で表示されます。 - 強制保持ポリシーにボードの機密分類レベルを使用すると、データの機密分類機能をオフにすることはできません。 -機密分類レベルが強制保持ポリシーに関連付けられると、その機密分類レベルを削除することはできません。 - ボードが、組織スコープ内のすべてのボードと機密分類スコープ内の両方の強制保持ポリシーによって管理されている場合、保持期間の長い方のポリシーが適用されます。 |
6. クリックして**次へ**。
   **影響を確認するページ**が表示されます。
7. 強制保持ポリシーの影響が表示されます。影響を確認するページには、以下の情報が記載されています。
   - **概要：**ポリシー名、強制保持期間、範囲などの強制保持ポリシーの設定内容。
   - **ポリシーによる影響：**ポリシーが適用されるボードの数。強制保持ポリシーはゴミ箱内のボードにも適用され、影響を確認する際の計算対象となります。

   > ✏️ ボードが時間ベースと機密分類ベースの両方の強制保持方針によって管理されている場合、強制保持期間の長い方の方針が適用されます。
8. 設定を保存して強制保持ポリシーを適用するには、［**公開**］をクリックします。

:::note
ポリシーの作成、更新、削除を実施すると、強制保持ポリシーのプロセスを起動します。完了まで最大 24 時間ほど要する場合があります。ただし、ポリシーの名前または説明の更新については、強制保持ポリシーのプロセスは起動されず、更新は即座に行われます。
:::
