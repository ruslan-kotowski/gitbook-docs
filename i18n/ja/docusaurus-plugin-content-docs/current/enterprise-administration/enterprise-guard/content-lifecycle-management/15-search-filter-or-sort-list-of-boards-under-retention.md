ボードリストが強制保持中のボードの長いリストを表示し、特定の要件に基づいて結果リストをカスタマイズしたい場合があるかもしれません。[データガバナンス管理者](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)は、様々な基準でボードのリストを検索、フィルター、または並べ替えできるようになり、コンテンツライフサイクル管理タスクの重要な側面に集中する能力が向上しました。

## 特定のボードを検索する

ボードリストページの上部にある検索バーに、ボード名やボードIDのキーワードを入力することで、特定のボードを検索できます。

**ヒント：**ボード URL から簡単にボード ID を取得できます。

## ボードリストを並べ替え

ボード一覧を特定の基準に基づいて、昇順または降順で並べ替えることができます。例えば、ボードリストを保持日付に基づいて昇順に並べ替えることができます。

ボードリストを並べ替えるには、**並べ替え**ラベルの横のボタンをクリックし、適切な並べ替え基準を選択します。例えば、保存日付を基準にボードリストを昇順に並べ替えたい場合、**並べ替え基準**のラベルの横にあるボタンをクリックし、**昇順**をクリックし、次に**保存期限**をクリックしてください。

## ボードリストを絞り込み

絞り込みオプション（図 4）には、ボードのチームや所有者の基準だけでなく、ボードの使用状況や保持関連の基準も含まれます。

### クイックフィルター

クイックフィルターを使用すると、ワンクリックでボードのリストをフィルタリングできます。

### スマートフィルター

また、チーム、所有者、機密分類レベル、ボード状態、または使用基準（最終編集の期間、つまり最終編集の開始と終了の日付など）に基づいて、スマートフィルターを使ってボードリストを絞り込むことができます。また、適用された強制保持または処分ポリシー、保持の開始日と終了日などのポリシー基準に基づいてコンテンツを絞り込むことができます。

さらに、一度に複数の絞り込み条件を選択し、組み合わせることができます。多様な絞り込みオプションにより、データガバナンス管理者は、分析を合理化し、特定のコンテンツ ライフサイクル管理タスクを迅速に切り分けて対処することができます。

:::note
コンテンツ エクスプローラーの結果リストを絞り込むには、[データガバナンス管理者の役割](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)が必要です。データガバナンス管理者の役割をリクエストするには、会社の管理者にご連絡ください。
:::

ボード リストでスマート フィルターを使用するには、次の手順を実行します。

1. 自分のプロフィールアバターをクリックし、**管理コンソール**をクリックします。
2. 画面左側のサイドバーで**Enterprise Guard**をクリックし、その後**コンテンツのライフサイクル**をクリックします。
3. **コンテンツのライフサイクル概要**ページで、**強制保持**ヘッダーをクリックします。
   **強制的な保持と処分** ページがボードのリストと共に表示されます。
4. **保持と廃棄**ページで、ボードリストの上部にある**フィルター**ボタンをクリックします。
5. **絞り込み条件**ボックスが表示されます。
6. 要件に合った絞り込み条件をクリックします。できます。
   チーム、所有者、機密分類レベル、ボードの状態、または最終編集期間（最初の編集から最終編集までの日付）のような使用条件など、ボードの場所や所有者に基づいて、さまざまな基準に基づいてボードのリストを絞り込みます。
   - 適用された強制保持または処分ポリシー、または保持の開始と終了日などの基準に基づいてコンテンツを絞り込みます。
   - 一度に複数の条件に基づいて絞り込むことができます。

   ボードリストは、絞り込み条件に一致するように結果リストをリアルタイムで更新します。
