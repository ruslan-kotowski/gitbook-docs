:::note
永久削除期間を更新した場合、更新された期間は新たにゴミ箱に移動されたボードにのみ適用されます。すでにゴミ箱にあるボードは、既存の削除期間を維持します。
:::

1. ダッシュボードから、右端のアバターをクリックし、**管理者コンソールに**移動します。
2. 「**セキュリティーとコンプライアンス**」配下にある、「**コンテンツのライフサイクル**」をクリックします。
   ![図 1: コンテンツのライフサイクル > ゴミ箱の永久削除と設定](images/22019858121874_trash_settings.png)*管理者コンソールで永久削除期間を設定します。*
3. **永久削除では**、ゴミ箱のボードを自動的に永久削除する日数を選択します。
4. **[保存]** をクリックします。
