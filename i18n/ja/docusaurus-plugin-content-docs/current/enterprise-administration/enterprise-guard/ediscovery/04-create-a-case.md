訴訟や調査が予想される場合、リーガルホールドを作成することは、eDiscovery プロセスにおける最初の重要なステップです。事案は、リーガルホールドのプロセスを管理するための組織的な基盤として機能し、データ保全に関連するすべての活動を明確に特定、文書化し、監視することを可能にします。適切に事案を作成しないと、リーガルホールドのプロセス構造が欠如し、重要な情報の偶発的な損失や削除が発生し、潜在的な法的リスクや法的制裁を招く可能性があります。

[eDiscovery 管理者](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)として、あなたはリーガルホールドを開始し管理する上で重要な役割を担っています。事案を作成することで、法的事案の期間中、関連するすべての Miro ボードが適切に保存されるために必要な、正式な構造を確立します。事案を作成する目的の 1 つは、管理者が 1 つの事案の下に複数のリーガルホールドをまとめておけるようにすることです。これは、裁判のように、異なるリーガルホールドが同じ調査の一部である場合で特に便利です。

多くの場合、複数のユーザーをリーガルホールドの対象とする必要があります。調査や法的案件が進展するにつれて、すべてを 1 つの案件の下で整理しながら、追加のホールドを作成する必要があるかもしれません。関連するすべてのホールドを単一の事案にグループ化することで、より効果的な管理と監督が可能になります。特定の調査に関連するすべてのホールドが一つの一元的な場所に収められるためです。

リーガルホールド事案を効果的に作成および管理することで、関連データをすべて保存し、複雑な調査を管理するプロセスを合理化し、組織の法的リスクを軽減します。

事案を作成するには、次の手順を実施してください。

:::note
この作業を行うには、[eDiscovery 管理者の役割](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)が必要です。eDiscovery 管理者の役割をリクエストするには、会社の管理者にご連絡ください。
:::

1. Miro 設定に移動します。
2. 左ペインで、**Enterprise Guard** の下にある**eDiscovery**をクリックします。
3. **eDiscovery**ページで、**事案**タブをクリックします。
4. **事案**ページで**事案を作成**をクリックします。
5. **事案を作成**ページで、各フィールドに適切な情報を入力します。以下の表に、各フィールドとその説明を示します。

   |  |  |
   | --- | --- |
   | **項目** | **説明** |
   | 事案名  **（必須）** | 事案の名前。  最大長：60文字。 |
   | 説明  **（任意）** | 事案の説明。  最大長：300文字。 |
6. **事案を作成**をクリックします。事案が作成され、eDiscovery ページの事案一覧に表示されます。これで、事案にリーガルホールドを追加することができます。
