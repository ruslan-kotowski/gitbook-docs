1. プロフィールのアバターをクリックし、**管理者コンソール**をクリックします。
2. 左のサイドバーで Enterprise Guard をクリックし、次に**eDiscovery**をクリックします。
3. **ケース** タブをクリックします。
   ケースの一覧が表示されます。
4. エクスポートを開始したケースを開きます。
5. **エクスポート**タブをクリックします。
6. エクスポート ジョブのリストを確認する：
   - ジョブ名、ステータス、および含まれるボード数を確認します。
   - ボードが処理される際にリアルタイムの更新を閲覧します。
7. （オプション）**フィルター**をクリックして、以下の基準でエクスポートジョブを絞り込みます。
   - **エクスポート ステータス**
     進行中、キャンセル済み、または完了したジョブで絞り込む。
   - **作成者**
     所有者による絞り込み条件。
8. エクスポートジョブをクリックして詳細を表示します。
   - エクスポートジョブに含まれるボード。
   - 機密分類、所有者、エクスポート状態。
   - エクスポートサイズとダウンロードの可用性。エクスポートされたボードをダウンロードする方法については、[この記事](10-download-exported-boards.md)をご覧ください。
9. （オプション）エクスポートジョブをキャンセルするには、右側の三点リーダー（**...**）をクリックして、**エクスポートをキャンセル**を選択します。
