リーガルホールドの作成は、訴訟や調査が予想される場合において、[eDiscovery 管理者](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)にとって重要なプロセスです。リーガルホールドは関連する Miro ボードを改変、削除、または撤去から保護し、保存します。これは、法的および規制上の要件に準拠し、重要なデータの紛失や改変を防ぎ、法的問題が続いている間、重要な証拠を確保するために必要です。リーガルホールドにより、管理者はデータをロックダウンし、必要に応じて検討するべき関連するすべての Miro ボードが利用可能であることを保証します。

リーガルホールドの作成には、事案に関連するユーザーとMiroボードを特定し、修正を防止するためにホールドを適用することが含まれます。管理者は事案内で複数のホールドを管理でき、必要なデータを整理して保存することができます。このプロセスはデータの完全性と責任を維持し、組織が法的手続きに完全に準拠し、準備ができていることを保証します。

リーガルホールド中のMiroボードは引き続きアクセスと編集が可能ですが、すべてのバージョンが保存されます。コンテンツが削除された場合でも、リーガルホールド内では引き続き利用可能です。ホールド中のコンテンツのアイテム数は、今後のユーザー操作により増加することがあります。ボードがリーガルホールドの対象になると、そのボードのすべてのバージョンはリーガルホールドが解除されるまで無期限に保持されます。

リーガルホールドを作成するには、次の手順を実施してください：

:::note
このタスクを実行するには、[eDiscovery 管理者](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)である必要があります。eDiscovery 管理者の役割をリクエストするには、会社の管理者にご連絡ください。
:::

1. Miro の設定に移動します。
2. 左ペインで、**Enterprise Guard** の下にある **eDiscovery** をクリックします。
3. **eDiscovery** ページで、**ケース** タブをクリックします。
4. **ケース作成** ページで、リーガルホールドを追加したい事案をクリックします。
5. **リーガルホールドを追加**をクリックします。
6. **リーガルホールドを追加** ページで、各フィールドに適切な情報を入力または選択します。以下のテーブルに、各フィールドとその説明を示します。

   |  |  |
   | --- | --- |
   | **フィールド** | **説明** |
   | リーガルホールド名  **（必須）** | リーガルホールドの名前。  最大長：60 文字。 |
   | 条件  **(必須)** | このリーガルホールドに含まれるコンテンツの種類。このリリースではすべてのコンテンツをサポートします。 |
   | **コンテンツの所有者、共同所有者、アクセス、変更、作成したユーザー**  **(必須)** | リーガルホールドに設定したいユーザーを追加します。フィールドをクリックして、名前またはメールアドレスで検索します。一度に最大 200 人のユーザーを追加できます。    **注記:**  - リーガルホールド中のユーザーがボードを開いたり、変更したり、何らかの方法で操作した場合（名前を変更したり、コンテンツを追加したりした場合）、そのボードはフラグが立てられ保存されます。たとえば、ボードの名前が変更されたり、コンテンツが更新された場合、それは自動的にリーガルホールドに置かれます。また、ボードの所有および作成もホールドされます。  - リーガルホールドが作成されると、キュスタディアンがその時点で作成、所有、または共同所有していたボードに適用されます。また、ホールドが適用された後にキュスタディアンがアクセスして変更したボードも含まれます。このリリースでは、過去のボードアクセスおよび更新の詳細は利用できません。 |
7. **次へ**をクリックします。**影響を確認**するページが表示されます。
8. このリーガルホールドの作成に伴う影響を確認してください。例として、ホールドがかかる既存のボードの数や、ボードを所有、共同所有、アクセス、編集、作成したユーザーの情報を確認します。

   **注意:**
   - ホールド中のボードには依然としてアクセスおよび編集が可能ですが、すべてのバージョンが保存されます。コンテンツが削除された場合でも、引き続きホールド内で利用可能です。ホールド中のコンテンツのアイテム数は、今後のユーザー操作により増加することがあります。

   - リーガルホールド中のユーザーがボードを開いたり、変更を加えたりした場合、そのボードはすぐにフラグが立てられ、保存されます。たとえば、ボードの名前が変更されたり、コンテンツが更新された場合、自動的にリーガルホールドがかかります。さらに、ボードの所有権や作成もホールドされます。

   - リーガルホールドが作成されると、キュストディアン（保存者）が作成、所有、共同所有していたボードにも適用されます。また、ホールド中にキュストディアンがアクセスして変更したボードも含まれます。ただし、過去のボードのアクセス履歴や更新の詳細は今回のリリースにはありません。
9. 作成中のリーガルホールドの影響を確認した後、「**リーガルホールドを追加**」をクリックします。
   事案ページが表示され、そこには含まれているリーガルホールドと、リーガルホールドの名前、影響を受けるコンテンツの種類、このリーガルホールドに含まれるユーザーの数、リーガルホールドの作成日時、リーガルホールドの状態、そしてホールドされたボードの数に関する情報が表示されます。
