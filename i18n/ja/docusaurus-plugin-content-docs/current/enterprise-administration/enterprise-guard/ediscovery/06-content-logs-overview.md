コンテンツログを使用することで、エンタープライズ顧客はボード上でのユーザーの活動を詳細に記録することができ、調査や規制アーカイブのために活用することができます。

コンテンツログは、法務、コンプライアンス、セキュリティー目的で構築されたさまざまなツールに取り込むことができます。Miro は、ユーザーの活動データを大規模にエクスポートするソリューションを提供することで、顧客のリスクを軽減し、企業全体の知識労働者が厳格なセキュリティーとコンプライアンス要件を遵守しながら、Miro の協働力を体験する機会を広げます。

## コンテンツログデータ

ユーザーがボード上のウィジェットを更新すると、ユーザーのアクションの時間、ユーザーの詳細、アクションの種類（作成、更新、削除）、ボードやウィジェットのID、ユーザーのアクションに伴うウィジェットの状態に関する他の関連情報が記録されます。コンテンツログは、ウィジェットの位置、サイズ、回転の更新を*記録しません*。

## コンテンツログの収集

管理者がコンテンツログの収集を有効にした時点からイベントが記録されます。収集されたイベントはデフォルトで30日間保存されます。

コンテンツログの収集を有効にするには、次の手順を実行します：

1. 会社の設定に移動します。
2. 左側のパネルで、**セキュリティ** > **監査ログ**をクリックします。
3. **監査ログ**の下にある**設定**タブをクリックします。
4. **コンテンツ ログ**セクションで、**コンテンツ ログの収集**を有効にするトグルをクリックします。
   ![content_logs.png](images/24937029676946_content_logs.png)
   *コンテンツ ログの収集を有効にする*

## APIを通じてコンテンツ ログにアクセス

管理者は、組織内のコンテンツ ログ データにプログラムでアクセスするために[コンテンツ ログ API](https://developers.miro.com/reference/board-content-logs)を使用できます。管理者は、Smarsh や Theta Lake のようなサポートされているインテグレーションを利用してコンテンツ ログ データを収集することも可能です。

API のアクセスを認証するには、管理者が次のオプションから選択できます:

- Enterprise インテグレーションで eDiscovery トグルを有効にします。
- プラットフォームアプリケーションを作成し、Content log:read スコープへのアクセスを与えます。
- マーケットプレイスからの eDiscovery インテグレーションの1つをインストールして認証します。

## コンテンツログの削除

管理者はコンテンツログの保持期間を30日、90日、180日、または365日から選択して設定できます。デフォルトでは、保持期間は30日に設定されています。

:::note
コンテンツログが削除されると、復元できません。
:::

削除期間を設定するためには、以下のステップを実行します:

1. 会社の設定に移動します。
2. 左側のパネルで、**セキュリティ** > **監査ログ** をクリックします。
3. **監査ログ**の下で、**設定** タブをクリックします。
4. **コンテンツログ**の下で、ドロップダウンリストからオプションを選択します。選択を確定するよう求められます。
   ![content_logs_duration.png](images/24937029681554_content_logs_duration.png)
   *コンテンツログの強制保持ポリシーを設定*
