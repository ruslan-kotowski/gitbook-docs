1. プロフィールアバターをクリックし、次に**管理者コンソール**をクリックします。
2. 左サイドバーで Enterprise Guard をクリックし、次に **eDiscovery** をクリックします。
3. **ケース** タブをクリックします。
   ケースの一覧が表示されます。
4. エクスポートしたい1つ以上のリーガルホールドを含むケースをクリックします。
   ケースに該当するリーガルホールドの一覧が表示されます。
5. 以下の方法でボードのエクスポートを開始できます。
   - リーガルホールド リストビューから:リーガルホールド リストページで、ページ上部にある**エクスポートコンテンツ**ボタンをクリックし、関連するボードをすべてエクスポートするリーガルホールドを選択してください。
     ダイアログボックスが表示されます。ステップ 6 に進んでください。
   - リーガルホールドの詳細ページから:リーガルホールドリストページで、開きたいリーガルホールド名をクリックし、次にページ上部にあるエクスポートボタンをクリックします。
     ダイアログボックスが表示されます。ステップ 6 に進んでください。
6. **エクスポート名** ボックスに、このボードエクスポートジョブのエクスポート名を入力します。
7. **形式**リストで、ボードをエクスポートしたいファイル形式を選択します。SVG、PDF、または HTML ファイルにエクスポートすることができます。デフォルトでは、形式は SVG に設定されています。
8. （オプション）エクスポートジョブで各ボードの[コンテンツログ](06-content-logs-overview.md)を含めるには、**コンテンツログを含める**にチェックを入れます。
9. **エクスポート**をクリックします。
   エクスポートジョブはケースページの**エクスポート**タブに表示されます。エクスポートジョブの監視やエクスポート状態の確認については、[この記事](07-monitor-board-export-jobs-and-view-status-from-the-admin-console.md)をご覧ください。
