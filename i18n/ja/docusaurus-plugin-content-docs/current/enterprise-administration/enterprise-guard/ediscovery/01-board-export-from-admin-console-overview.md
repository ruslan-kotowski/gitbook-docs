eDiscovery 管理者は、管理者コンソールから直接リーガルホールド中のボードをエクスポートできるようになりました。
この機能により、eDiscovery 管理者は以下を実行できます。

- 管理者コンソールからボードのエクスポートを開始します。
- 各ケース内の**エクスポート**タブで、エクスポートジョブの進捗をリアルタイムで監視します。
- エクスポートジョブをステータスや作成者でフィルターし、どのボードが含まれているかを確認します。
- エクスポートされた各ボードに対して、完全なコンテンツログを取得します。
- エクスポートされたボードとそのメタデータ（機密分類、所有者、エクスポート状態）の一覧を表示します。
- 管理者コンソールから、エクスポートされたボードを個別に直接ダウンロードします。
- API やインテグレーションに依存せず、エクスポートワークフローを完了します。
- エクスポートジョブがキューにある場合や進行中の場合、それをキャンセルします。

:::note
ボードをエクスポートし、エクスポートジョブの操作を管理するには、[eDiscovery 管理者の役割](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)が必要です。機密コンテンツ管理者権限の申請については、会社の管理者にお問い合わせください。
:::

## **ボード エクスポート機能**

- 各**エクスポートジョブ**には最大**1,000 件のボード**が含まれます。
- **プランごとのエクスポート制限**：

  - **Enterprise Guard：**最大**100 件**のアクティブなエクスポートジョブ。
  - **Enterprise：**最大**10 件**のアクティブなエクスポートジョブ。
- **並列処理の制限**：

  - **Enterprise Guard**：最大**5 件**のエクスポートジョブを並列処理します。
  - **Enterprise**：**1 件**のエクスポートジョブを一度に処理します。
- **エクスポートジョブに関連するコンテンツログ：**エクスポートには、各エクスポートされたボードの完全なコンテンツログをオプションで含めることができます。
- **エクスポートジョブのフィルター**:エクスポートジョブをフィルターして、どのボードが含まれているかを確認します。
- **進行中および待機中のエクスポートジョブをキャンセルする**:エクスポートの回線容量を効率的に管理する。
  > ✏️ エクスポートをキャンセルすると、進行中のすべてのボードは完了し、ダウンロード可能になります。開始されていないボードはエクスポートされません。

- **ダウンロードアクセス**:**14 日間、結果をダウンロード可能です。**
- **管理者コンソールの範囲**:管理者コンソール経由で開始されたエクスポートのみが**エクスポート**タブに表示されます。API ベースのエクスポートジョブは管理者コンソールのリストに含まれていません。
