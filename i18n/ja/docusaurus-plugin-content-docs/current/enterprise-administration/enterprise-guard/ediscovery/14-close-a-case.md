事案をクローズすることは、eDiscovery プロセスの最終段階であり、法的な問題や調査が終了することを示します。[eDiscovery 管理者](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)は、事案をクローズする前に、関連するすべてのリーガルホールドが解除されていることを確認する必要があります。

事案をクローズするには、次の手順を実施してください。

:::note
このタスクを実行するには、[eDiscovery 管理者ロール](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)が必要です。eDiscovery 管理者ロールをリクエストするには、会社の管理者にご連絡ください。
:::

1. 関連するすべてのリーガルホールドが終了していることを確認してください。詳細は、[リーガルホールドを終了する](12-close-a-legal-hold.md)をご覧ください。
2. [Miro 設定](https://miro.com/app/settings)に移動します。
3. 左側のペインで、**Enterprise Guard** の下にある **eDiscovery** をクリックします。
4. **eDiscovery** ページで、終了したい事案をクリックします。
5. 終了したい事案の行で三点リーダー（三つの点のアイコン）をクリックし、その後、**事案を終了** をクリックします。
6. **事案の終了**確認ボックスが表示され、事案の全ての詳細が削除されることが通知されます。  ![closecaseconfirmationbox.png](images/22388838167954_closecaseconfirmationbox.png)
7. 事案を閉じることに確信が持てたら、**事案を閉じる**をクリックします。
   事案は削除されます。
