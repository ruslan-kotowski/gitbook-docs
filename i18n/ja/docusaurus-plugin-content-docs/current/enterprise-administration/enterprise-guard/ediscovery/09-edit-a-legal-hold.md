リーガルホールドを編集すると、eDiscovery 管理者が事案の要件の変化に応じて、法的保全活動を調整し、改善することができます。新しい管理者が特定された場合、追加の Miro ボードが関連するようになった場合、または既存のボードやユーザーがスコープから外れた場合、リーガルホールドを編集することにより、正確なデータが法的プロセスを通じて保存され、防御可能であることが保証されます。

管理者はリーガルホールドの名前や説明を更新したり、必要に応じてユーザーやボードを追加または削除したりできます。この柔軟性により、動的な法的ワークフローがサポートされ、保存が正確で最新の状態に保たれ、法的事項の範囲に沿って確保されます。これにより、コンプライアンスを維持しながら、不必要なデータの強制保持を回避できるようになります。

リーガルホールドが編集されると:

- ホールドに新たに追加されたボードは、その時点からバージョンが保存され始めます。
- ボードまたはユーザーがリーガルホールドから除外されると、これらの保持およびそのバージョンはもはや維持されません。
- ホールドが適用されたボードは、適用後の削除を含め、すべてのバージョンが保存され続けます。

このアプローチにより、案件が進展する中で、組織が法的要求に対して正確かつ責任を持って対応できることが保証されます。

リーガルホールドを編集するには、次の手順を実行してください。

:::note
このタスクを実行するには、[eDiscovery 管理者](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md)である必要があります。eDiscovery 管理者役割をリクエストするには、会社の管理者にご連絡ください。
:::

1. Miro の設定に移動します。
2. 左ペインで、**Enterprise Guard** の下にある **eDiscovery** をクリックします。
3. **eDiscovery** ページで、**事案** タブをクリックします。
4. 編集したいリーガルホールドのケースをクリックします。
   事案内でリーガルホールドのリストが表示されます。
5. 編集したいリーガルホールドの行にある三点リーダーをクリックし、**リーガルホールドを編集**をクリックします。
6. **リーガルホールド編集**ページで、各フィールドに適切な情報を入力または選択します。以下の表に、各フィールドとその説明を示します。

   |  |  |
   | --- | --- |
   | **フィールド** | **説明** |
   | リーガルホールド名  **（必須）** | リーガルホールドの名前  最大長：60 文字 |
   | 基準  **(必須)** | このリーガルホールドに含まれるコンテンツの種類。このリリースは、すべてのコンテンツのみをサポートします。 |
   | **コンテンツを所有、共同所有、アクセス、変更、または作成したユーザー**  **（必要）** | リーガルホールドに追加したいユーザーを追加します。フィールドをクリックして名前またはメールアドレスで検索してください。リーガルホールドごとに最大 200 人のユーザーを追加できます。これは、リーガルホールドの更新により追加されたユーザーも含まれます。  **ノート：**  ユーザーがリーガルホールドの対象となっている場合、ボードを開いたり、変更したり、名前を変更したり、コンテンツを追加したりするなど、何らかの形でボードとやり取りを行うと、そのボードはフラグが立てられ、保全されます。例えば、ボードの名前が変更されたり、コンテンツが更新された場合、自動的にリーガルホールドの対象となります。さらに、ボードの所有権とボード作成が保留されます。  リーガルホールドが編集されると、カストディアンが作成、所有、または共同所有したボードにホールドが適用されます。さらに、ホールドがかけられた後に管理者がアクセスして変更を加えたボードも含まれます。このリリースでは、ボードの履歴アクセスおよび更新の詳細は利用できません。  - 新しく追加されたボードは、ステップ9でリーガルホールドの更新を保存した時点から、そのバージョンが保持され始めます。  リーガルホールドから削除されたボードやユーザーは保持が停止され、そのバージョンがリーガルホールドの一部として保持されなくなります。  ホールドが継続されているボードは、ホールドが適用された後に発生する削除を含むすべてのバージョンが保持されます。 |
7. **次へ** をクリック**影響を確認**するページが表示されます。
8. このリーガルホールドの作成の影響を確認し、以下を含みます:
   ホールド下にあるボードの数、ホールドから解除されるボードの数、および新たにホールドが適用されるボードの数。
   - ボードを所有、共同所有、アクセス、変更、または作成したユーザー。
   - ホールドのための基準。
   - ホールド継続中のボード一覧。

   **ノート:**
   - ホールド中のボードへのアクセスや編集は可能ですが、すべてのバージョンが保存されます。コンテンツは削除された後でも、ホールド内で引き続き利用が可能です。ホールド中のコンテンツのアイテム数は、今後のユーザー操作により増加することがあります。

   リーガルホールドの対象のユーザーがボードを開いたり、変更したり、名前を変更したり、コンテンツを追加するなど何らかの形でやり取りをすると、そのボードはフラグが立てられ、保全されます。たとえば、ボードの名前が変更されたり、コンテンツが更新されたりすると、自動的にリーガルホールドにされます。さらに、ボードの所有権とボードの作成は保留されます。

   リーガルホールドが作成されると、そのホールドの時点でカストディアンが作成、所有、または共同所有しているボードに適用されます。さらに、保留が設定された後に管理者がアクセスおよび変更するすべてのボードも含まれます。このリリースでは、ボードの履歴アクセスおよび更新の詳細は利用できません。
9. 作成中のリーガルホールドの影響を確認した後、**リーガルホールドを保存**をクリックします。
   ケースページには、更新されたリーガルホールドが表示されます。具体的には、リーガルホールドの名前、リーガルホールドで影響を受けるコンテンツの種類、リーガルホールド内のユーザー数、リーガルホールドが作成された日付、リーガルホールドのステータス、リーガルホールドが適用されているボードの数が含まれます。
