## エンタープライズ グレードのセキュリティー

Miro は、あらゆる規模の分散型チームが共に夢を描き、デザインし、未来を創造できるようになる、イノベーションを目指したエンタープライズ対応のオンライン ワークスペースです。オフィスでも、リモートでも、あるいはこの二つを組み合わせた場合でも、チームは会社全体のあらゆるユースケースに Miro を使用できます。

しかし、それには大きな責任が伴います。だからこそ、私たちはコラボレーションと同様にセキュリティーを重視し、アイデアが安全であるよう尽力しています。

## 認定、認可済み

Miro は[ISO 27001、SOC2 Type II、SOC3](https://miro.com/trust/compliance/) などの業界のベストプラクティスと規制要件に準拠しています。また、お客様のインフラおよびサービスが GDPR 基準に準拠していることも保証します— これには Talktrack の録画も含まれます。

**コンテンツ ライフサイクル管理**

**Talktrack の削除**
**Talktrack の削除：**Talktrack を削除すると、復元することはできません。

**ボードの削除：**Talktrack は、ボードにコンテキストを提供するレイヤー録画です。 ボードが削除されると、Talktrack も削除されます。ただし、管理者が 90 日以内に削除されたボードを復元すると、ボードの Talktrack も復元されます。 [ボードの削除](../../../using-miro/managing-boards/07-how-to-delete-a-board.md)についての詳細を確認してください。

**プライバシー**

**Talktrack の録画時にキャプチャされるデータ：** レコーダーのカーソルの動きと Miro ボードのビューポート、Talktrack 作成時のボードのコンテンツ、レコーダーの動画、カメラのオン / オフに応じたカメラビューまたはアバター、選択したオーディオソースによるレコーダーのオーディオ、プレゼンターと同じ物理的空間に存在する他のオーディオ。

**Talktrack の録画時にキャプチャされないデータ：** 録画時にボードにアクセスしている他のユーザーのカーソルや情報、レコーダーの画面、コンピューターのサウンド。

**プライバシーに関する通知**

Miro が管理者（基本的にメタデータ）である、Talktrack に関連する個人データを処理する法的根拠は、契約の履行（セルフサーブユーザー）や正当な利害関係（すべてのユーザー）です。お客様は、Talktrack で記録されたデータの管理者になります。お客様の法的根拠は、お客様が評価することであり、正当な利益になる可能性が高くなります。

**アクセシビリティ**

Talktrack は、キーボードのナビゲーションと自動文字起こし / クローズドキャプションをサポートします。

**オブザーバビリティ**

[監査ログ](../../security-integrations/security-management/01-audit-logs.md)は管理者設定でTalktrackに利用可能です。当社では、次のSIEM（セキュリティ情報とイベント管理）のシステムとインテグレーションを提供しています:
[Splunk](../../security-integrations/security-information-and-event-management-siem/01-miro-app-for-splunk.md)
[IBM QRadar](../../security-integrations/security-information-and-event-management-siem/02-miro-connector-for-ibm-qradar.md)

**外部監査**

Miro は、クラス最高の外部のコンサルティング会社を利用して、年次監査を実施しています。現在の ISO 27001 認証は、英国の BSI（英国規格協会）と、米国の KirkpatrickPrice による SOC2 および SOC3 レポートによって署名されています。[Miro のコンプライアンスについてさらに読む](https://miro.com/trust/compliance/)。

## 信頼できる保護機能

当社のプラットフォームに作成または追加された知的財産を保護し、管理します。データは、転送時に TLS 1.3 プロトコルで、保管時に AES 256 で暗号化されます。

**暗号化**

Talktrack のデータを含む Miro のデータは、デフォルトで、保管時に AES256 アルゴリズムで、転送時に TLS1.3 プロトコルで暗号化されます。詳細は、[Miro 暗号化ホワイトペーパー](https://go2.miro.com/rs/228-GPV-835/images/Encryption%20Whitepaper.pdf)をご覧ください。

**データ分類**

[ボードの機密分類](../../canvas-25-admin-features/data-security/02-data-classification.md)ラベルは、Talktrack の視聴中や録画中に表示されません。

**暗号鍵管理**

組織に[暗号鍵管理](../../canvas-25-admin-features/encryption-key-management/01-encryption-key-management-overview.md) (EKM) が設定されている場合、管理者は Miro に対して、Talktrack コンテンツに組織の暗号鍵を使用するようリクエストできます。

**データレジデンシー**

デフォルトでは、Talktrack のデータは他のカスタマーコンテンツデータと同じ位置、つまり EU にある AWS サーバーに保存されます。Miro はすべてのカスタマーコンテンツをヨーロッパでホストすることにより、企業のデータに対するより高い管理性とコンプライアンスを提供しています。[米国データセンターレジデンシー](../../canvas-25-admin-features/data-security/09-us-data-center-residency.md)を要求されたお客様については、Talktrack のデータはオハイオ州の主要データセンターとバージニア州のバックアップデータセンターに保存されます。

## 安全なアクセス管理

高度な ID および管理機能を利用したエンタープライズグレードの機能で、Miro へのアクセス権を管理します。Enterprise プランの[セキュリティーとコンプライアンス機能](../../../administration/security-compliance)について詳しく読む。

**組織の Talktrack へのアクセス管理**

会社の管理者は、[機能アクセス](../../managing-enterprise-teams-and-content/06-feature-activation.md)設定で、会社全体または特定のチームに対して Talktrack のアクセス権を付与または取り消すことができます。

**Talktrack 収録のアクセス権**

[Talktrack を収録](../../../using-miro/facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md)するオプションは、ボードでコメントまたは編集のアクセス権があるユーザーや、ボードの所有者または共同所有者に対して利用可能です。

**Talktrack 閲覧のアクセス権**

Talktrack の再生は、ボードに[アクセス権がある](../../canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md)すべてのユーザーに利用可能です。

## よくある質問

会社の管理者は、どのボードに Talktrack があるか分かりますか？

ボードに Talktrack があるかどうかは、ボードを開いてみないと分かりません。ボードが共有されていない場合は、[コンテンツ管理者の権限](../../managing-enterprise-teams-and-content/12-content-admin-permissions.md)を使用してアクセスし、Talktrack を確認できます。

会社やチームの Talktrack をオフにするにはどうすればよいですか？

Talktrack をオフにするには、[機能アクセス](../../managing-enterprise-teams-and-content/06-feature-activation.md) 設定に移動し、**No one can use**（全員が使用不可）を選択するか、チーム名の横にある **X** をクリックして、特定のチームのアクセス権を削除します。

管理者が、Talktrack 機能へのアクセス権を取り消すと、既存の Talktrack はどうなりますか？

既存の Talktrack は引き続き利用可能ですが、新規の Talktrack を録画することはできません。

管理者は、Talktrack を削除できますか？

管理者は、[コンテンツ管理者の権限](../../managing-enterprise-teams-and-content/12-content-admin-permissions.md)を通じてボードを自分と共有し、そのボードからTalktrack を削除できます。

ユーザー名は、アプリに表示されるか、Talktrack データで保存されていますか？

Talktrack は、再生中に名前（利用可能な場合は姓名または表示名）を「レコーダー名」として表示します。ただし、Talktrack はユーザー ID のみを保存するため、録音には個人情報は保存されません。再生中にユーザーが組織に属していない場合、表示名は「ユーザー不明」として表示されます。
