Miroの顧客は、現在の地域外での[データレジデンシー](../../canvas-25-admin-features/data-residency/02-data-residency-at-miro.md)を必要とする場合があります。欧州連合（EU）外では、Miroはオーストラリア（AU）およびアメリカ合衆国（US）にデータレジデンシーを提供しています。

## リージョン間でデータを移動するためのオプション

データレジデンシーを移行するプロセスは、クロスリージョンマイグレーションと呼ばれています。新しい地域に組織を移行するには、Miroはいくつかの方法を提供しています。

- **手動でのエクスポートとインポート**
  Miro サポートは新しい地域で新しい組織を提供します。会社の管理者はすべての組織およびユーザー設定を再構成し、ユーザーを再招待します。エンドユーザーは旧地域から Miro ボードを手動でダウンロードし、新地域にアップロードします。詳細については、[地域間データ移動―手動でのエクスポートとインポート](../../canvas-25-admin-features/data-residency/06-move-data-between-regions-–-manual-export-and-import.md)をご覧ください。
- **自動データ移行**
  Miro サービスによる有料エンゲージメントとして利用可能です。組織全体の移行を自動化し、すべての組織コンテンツ、コンテンツ階層、ユーザー、および設定を含みます。詳細については、[地域間データ移動 – 自動移行](../../canvas-25-admin-features/data-residency/05-move-data-between-regions-–-automated-migration.md)をご覧ください。
  > ✏️ 自動データ移行は現在、[EKM enterprises](../../canvas-25-admin-features/encryption-key-management/01-encryption-key-management-overview.md)には利用できません。

どの移行方法が最適かを決定するために、専任のMiroコンタクト担当者に連絡するか、[support@miro.com](mailto:support@miro.com)にメールしてください。

## 地域間データ移動のオプションを比較する

以下のテーブルは、地域間データ移動の自動および手動オプションを比較しています。

|  | 自動 | 手動 |
| --- | --- | --- |
| コスト | Miro サービスとの有償契約。 | 追加コストなし。会社の管理者とエンドユーザーが、ボードのコンテンツを別の地域に移動します。 |
| 対象範囲 | 組織の大部分とそのデータが移行され、次のデータが含まれます。含まれるデータの詳細なリストについては、[管理者向けの自動化の記事]を参照してください。  - 組織データ - ユーザープロフィール - チームとチーム設定 - チームメンバーシップ - ボード - 監査ログ - データの機密分類 - コンテンツセキュリティー設定 | 管理者は組織設定を再構成し、チームを再作成してチーム設定を適用し、ユーザーを再招待してライセンスを割り当て、アプリやインテグレーションを再インストールする必要があります。エンドユーザーはボードを新しいリージョンに手動で移動する必要があります。 |
| 所要時間 | 通常は 8 時間未満のダウンタイムで、組織とそのデータが新しいリージョンに移行されます。 | 会社の管理者が手動設定を完了する速度や、エンドユーザーがボードを移動する速度によって異なります。 |
