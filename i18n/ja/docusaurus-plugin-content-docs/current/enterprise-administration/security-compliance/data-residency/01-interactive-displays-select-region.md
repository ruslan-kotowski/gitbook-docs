EU（欧州連合）以外にデータ レジデンシーを持つ Enterprise プランのユーザーは、インタラクティブ ディスプレイ上で適切な地域を選択できます。

この記事では、インタラクティブ ディスプレイのブラウザを適切なデータ レジデンシー地域に接続する方法や、適切な地域で Windows および Android ディスプレイ上で Miro アプリを使用開始する方法を説明します。

インタラクティブ ディスプレイについての情報は、[インタラクティブ ディスプレイ](../../../getting-started/apps-for-devices/07-interactive-displays.md)をご覧ください。

データ レジデンシーの詳細については、[Miro のデータ レジデンシー](../../canvas-25-admin-features/data-residency/02-data-residency-at-miro.md)をご覧ください。

## インタラクティブ ディスプレイのブラウザを地域に接続する

1. ディスプレイのブラウザを開きます。
2. 該当する地域のURLに移動します：
   - （デフォルト）**欧州連合**
     `https://miro.com/displays/?useAsAppDefaultOrigin`
   - **オーストラリア**
     `https://au.miro.com/displays/?useAsAppDefaultOrigin`
   - **アメリカ合衆国**
     `https://us.miro.com/displays/?useAsAppDefaultOrigin`
3. 画面の指示に従います。

## Windows インタラクティブ ディスプレイの Miro アプリの地域を変更する

1. Windows インタラクティブ ディスプレイで Miro アプリを開きます。
2. キーボード上で**ALT**キーを押します。
   コンテキストメニューが開きます。
3. **ヘルプ** > **公開デバイス** > **公開**を選択します。
   Miro がインタラクティブ ディスプレイ体験に切り替わります。
4. **ヘルプ** > **公開デバイス** > **デフォルト地域**を選択します。
5. 以下のいずれかを選択します：
   - （デフォルト）**グローバル**
     欧州連合地域に接続します
   - **オーストラリア**
     オーストラリア地域に接続します
   - **アメリカ合衆国**
     アメリカ合衆国地域に接続します

## Android インタラクティブ ディスプレイで Miro アプリの地域を変更する

1. Android インタラクティブ ディスプレイで Miro アプリを開きます。
2. 起動画面の右上で歯車アイコンをタップします。
3. **地域を選択**をタップします。
   **別の地域を選択**モーダルが開きます。
4. 以下のいずれかを選択します：
   - （デフォルト）**グローバル**
     欧州連合地域に接続します
   - **オーストラリア**
     オーストラリア地域に接続します
   - **アメリカ合衆国**
     アメリカ合衆国地域に接続します
