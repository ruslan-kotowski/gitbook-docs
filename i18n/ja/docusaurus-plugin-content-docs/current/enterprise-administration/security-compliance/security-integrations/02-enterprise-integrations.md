**Enterprise インテグレーション** ページは、SSO、SCIM、SIEM、SAM などの Enterprise 管理者機能をすべて設定できる唯一の場所で、セキュリティーを強化し、ユーザーおよびサブスクリプション管理を効率的に行うことが可能です。ワンクリックでインテグレーションを簡単に設定でき、開発者チームやプライベートアプリの作成は不要です。

> **利用可能:** [Enterpriseプラン](../../../plans-billing/miro-plans/04-enterprise-plan.md)
> **設定者:** 会社の管理者

Enterpriseプランの [会社の設定] の [**アプリとインテグレーション**] から **Enterprise インテグレーション** にアクセスします。

このページでは、いくつかの Enterprise インテグレーション設定を行うことができます。

- **クロスドメイン ID 管理システム。** ご利用の ID プロバイダーを介して、ユーザー プロビジョニングとユーザー管理を自動化する設定を行います。[Miro の SCIM についてさらに詳しく](../../security-integrations/system-for-cross-domain-identity-management-scim/02-scim.md)
- **セキュリティ情報とイベント管理。** Miro Enterprise 組織から監査ログを収集し分析します。[設定方法はこちら](../../security-integrations/security-information-and-event-management-siem/01-miro-app-for-splunk.md)
- **ソフトウェア資産管理。**ServiceNow、Productiv、Zylo とのインテグレーションを設定し、サブスクリプションの使用状況を分析してライセンスを効率的に管理します。[Miro での SAM について詳しくはこちら](../../security-integrations/software-asset-management/01-software-asset-management-miro-enterprise.md)。
