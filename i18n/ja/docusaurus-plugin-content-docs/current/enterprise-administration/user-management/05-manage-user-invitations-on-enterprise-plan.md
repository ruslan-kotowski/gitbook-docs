チームメンバーの追加や削除、招待権限の変更、ゲストの管理など、Enterprise プランへの招待を管理する方法をご覧ください。

> **該当プラン:** Enterprise プラン
> **実施者:** 会社の管理者

## 新しいメンバーを招待する方法

新しいメンバーをチームに招待するには、3 つの方法があります。[チームのプライバシー設定](../managing-enterprise-teams-and-content/11-manage-team-privacy-and-discovery-on-enterprise-plan.md)によっては、一部の招待オプションが利用できない場合があります。

詳細は[Enterprise プランの招待設定](03-invitation-settings-on-enterprise-plan.md)をご覧ください。

ダッシュボード チーム設定 会社設定

1. [ダッシュボード](../../getting-started/start-here/miro-dashboard/01-what-is-on-your-dashboard.md)からチームのリストを開いてください。
2. 追加したいチーム名の横にあるユーザーアイコンをクリック。
3. チーム設定パネルが開きます。
4. **チームにユーザーを追加**をクリック。
5. 追加したい人のメールアドレスを入力するか、**会社からユーザーを追加**をクリックしてください。
6. 追加する際には、**フリーメンバー**または**フリー制限メンバー**として追加するかを選択します。
7. **招待状を送信**をクリックします。

1. **会社の設定**を開きます。
2. **チーム**に進みます。
3. 追加するメンバーをチームにクリックします。
4. チーム設定パネルが開きます。
5. **チームに追加**をクリックします。
6. 追加したい人のメールアドレスを入力するか、**会社からユーザーを追加**をクリックします。
7. 追加する際、**Freeメンバー**または**Free制限付きメンバー**を選択します。
8. **招待を送信**をクリックします。

1. **会社**設定を開きます。
2. **Users** > **All users** > **Active users** に移動します。
3. 右上の**ユーザーを招待**をクリックします。
4. ダイアログが開きます。
5. 招待したいユーザーのメールアドレス（最大500件）を入力するか、**会社からユーザーを追加**をクリックしてリストからユーザーを選択します。
6. **+ Add teams** ボタンをクリックして、ユーザーを追加するチームを選択します。
7. **招待を送信**をクリックします。

### 新しいチームメンバーを招待した後の流れ

すべての招待者には、リンク付きのメール通知が届きます。招待者がメールのリンクをクリックすると、新しいユーザーには登録を促す画面が表示され、登録済みのユーザーはログインできます。

**登録済みの Miro ユーザー**がログインすると、ダッシュボード左側のサイドバーに新しいチームが表示されます。

**未登録の Miro ユーザー**の場合、この招待は30日間有効です。3、7、14、21、28日目にリマインダーメールが送信されます。30日目には招待が失効し、そのユーザーはアクティブなユーザーリストから削除されます。

## フレキシブル ライセンス プログラム（FLP）の招待管理

> **対象プラン：**Enterprise プラン
> **実行可能な役割：**会社の管理者

FLP サブスクリプションでは、会社の管理者が、権限の競合や非アクティブ化のケースなどの招待フローを完全に管理できます。例えば、管理者は、最初にユーザーを再アクティブ化してから権限を変更できます。

**権限**

ユーザーが既にあなたの Enterprise サブスクリプションに登録されていて、変更された権限レベルで招待を延長する場合、既存の権限を変更する、現在の権限設定で招待を延長する、または招待から除外するオプションがあります。

**ユーザーを再アクティブ化**

招待者が非アクティブ化されている場合、再アクティブ化するか、招待リストから削除できます。

**会社ドメイン外からのユーザーの招待**

プランで許可されていないドメインのユーザーを招待する場合、許可リストを更新してから再度そのユーザーを検証します。招待フローを開いたままで、別のウィンドウで許可リストを更新できます。ドメインを許可リストに追加したら、**許可リストを更新後、再度検証**をクリックしてください。

## ゲスト招待の管理

ユーザーをゲストとして招待することで、ユーザーをチームメンバーとして追加せずに、ボードに招待できます。

ゲストのアクセスレベル（閲覧、コメント、編集）は、ライセンスの種類とチームの権限によって異なります。

|  |  |  |
| --- | --- | --- |
| **ライセンスタイプ** | **非フレキシブル ライセンス（非 FLP）** | **フレキシブル ライセンス プログラム（FLP）** |
| **ゲスト** | コメントと閲覧が可能 | 社外のドメインのメールアドレスを持つ外部のゲストは編集可能 |

[フレキシブル ライセンス プログラムにおけるユーザー ロール](11-user-access-levels-on-enterprise-plan.md)についてさらに詳しく知りたい場合。

### フレキシブル ライセンス プログラム（FLP）で外部ゲストを招待

:::note
外部ゲストは、社外ドメインのゲストです。外部の会社のメールアドレスを使用します。
:::

[FLP ライセンス](../enterprise-subscription-management/enterprise-licensing/02-enterprise-licensing.md)で編集権限を持つ**ゲスト**を、チームメンバーとして追加せずにライセンスを使うことなく招待できます。

- ご利用の Enterprise プランで、編集者権限を持つ外部ゲストを招待するオプションが有効になっている場合。詳細については、Miro の担当者にお問い合わせください。
- 招待者がすでに同じ Enterprise サブスクリプション内の*別チーム*のAdvanced、StandardまたはFull（旧）メンバーである場合。既存のメンバーをゲストとして特定のボードを編集するために招待できます。

### ゲストをボードに招待する方法

ボードを共有する際、ユーザーのメールアドレスを入力し、ドロップダウンから**閲覧可**または**コメント可**を選択します。

**メンバーをボードに招待する権限がある場合**、編集権限を持つユーザーを招待すると、2 つのオプションを示すポップアップが表示されます。オプションの 1 つは、ユーザーをゲストとして追加し、招待されたボードにのみアクセスできるようにするものです。もう 1 つのオプションは、ユーザーをメンバーとして追加し、チーム内の他のボードへのアクセスも許可するものです。

ユーザーを編集権限を持つゲストとして招待するには、**[このボードにのみ追加する]** を選択します。

[制限付き無料ライセンス](../enterprise-subscription-management/enterprise-licensing/04-free-restricted-license.md)のユーザーは編集権限付きのゲストとして招待できません。会社の管理者は、あらかじめ制限付き無料ライセンスを取り消しておく必要があります。

### ゲストのチーム招待設定

会社の管理者は、**会社の設定** > **ユーザー** > **アクティブユーザー** で、すべてのゲストを確認できます。

ゲストは招待されたボードにのみアクセスでき、チームへの追加アクセスをリクエストすることができます。[ゲストとのコラボレーションについてさらに詳しく](../../using-miro/sharing-boards/07-collaboration-with-guests.md)知ることができます。

管理者は**ゲストを制限**することができ、[招待設定](03-invitation-settings-on-enterprise-plan.md)で非アクティブなゲストの自動無効化を[設定](03-invitation-settings-on-enterprise-plan.md)することもできます。また[許可された会社のドメイン以外](../canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md)のゲストも許可できます。

## 進行中の招待を管理

> **実行可能:** 会社の管理者

すべての招待状を一か所でフィルターして管理するには、**会社**設定 > **ユーザー** > **アクセスリクエスト** に移動してください。

**ライセンスリクエスト**の下に、過去30日以内にMiroの招待を受けたが承諾していない未登録メールアドレスのリストが表示されます。招待された日付や招待した人も確認できます。

招待を受けた人が30日以内に招待を承諾しない場合、その招待は失効し、ユーザーはリストから削除されます。招待を再送するには、単にそのユーザーを再度招待してください。

### 招待を取り消す

招待をキャンセルする必要がある場合は、ユーザーの横にある**X**アイコンをクリックしてください。

### 招待を一括で取り消す

会社の管理者は、招待を一括で取り消すことができます。

リストを確認するには**会社の設定** > **ユーザー** > **アクセスリクエスト**に移動します。左側のチェックボックスを有効にして、複数のユーザーを選択するか、最大 50 人のユーザーを一度に選択できます。

:::tip
アクティブユーザー リストでは、その他の一括操作を実行できます。アクティブユーザーのリストを最後までスクロールして、招待されたユーザーを表示してください。招待者のリストを選択して、チームに追加します。
:::

## よくある質問

**ユーザーにメールで招待が届かないのはなぜですか？**

ユーザーの受信トレイに招待メールが見当たらない場合は、各メールフォルダ（スパム、プロモーション、迷惑メール、ソーシャル、更新など）を確認するよう、ユーザーに依頼してください。ファイアウォールにより、メールが受信トレイに届かない場合もあります。[Miro メールを許可リストに追加する方法](../../using-miro/tools/troubleshooting/02-allowlist-miro-mailers.md)を学びます。
