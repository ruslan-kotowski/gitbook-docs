Miro の高度なユーザー管理では、会社の管理者はアカウントからユーザーを削除する代わりに、非アクティブ化することができます。非アクティブ化したユーザーは、プランのディレクトリに残り、いつでも再度アクティブ化することができます。

> **利用可能:** [Enterpriseプラン](../../plans-billing/miro-plans/04-enterprise-plan.md)
> **設定者:** 会社の管理者

## ルール

- 非アクティブ化したユーザーは、Enterprise アカウントとその機能にアクセスできなくなります。
- [「非アクティブ化されたユーザーをブロックする」](02-block-deactivated-users.md)の設定を有効にしている場合、非アクティブ化したマネージドユーザーは Miro にログインできなくなります。
- 非アクティブ化したユーザーは、会社の SSO オプションを使用したログインができなくなり、通常の認証方式に戻されます。
- 非アクティブ化されたユーザーが作成した共有ボードやスペースは*再割り当てされることはなく*、コラボレーターに引き続き利用されます（非アクティブ化する際にそのユーザーをチームから除去した場合を除きます。この場合、ボードはチームの管理者に再割り当てされます。これは通常、[SCIM](../security-integrations/system-for-cross-domain-identity-management-scim/02-scim.md)操作に関連します）。
- 非アクティブ化したユーザーへの[通知](../../using-miro/managing-your-profile/02-miro-notifications.md)はすべてブロックされます。
- 他のユーザーは非アクティブ化したユーザーとボードやスペースを共有できません。
- 非アクティブ化したユーザーを、Enterprise サブスクリプション内のチームに追加することはできません。会社の管理者はユーザーをメンバーとして招待することで非アクティブ化したユーザーを再アクティブ化できます。[詳細はこちら](05-manage-user-invitations-on-enterprise-plan.md)。
- 非アクティブ化したユーザーの利用料金は発生しません。これらのライセンスは解放され、別のアクティブユーザーに適用できます。
- 非アクティブ化したユーザーの次の属性を更新することはできません:

|  |
| --- |
| `userName` |
| `userType` |
| `roles.value` |

## ユーザーを非アクティブ化する

ユーザーの非アクティブ化はいつでも行えます。ユーザーを非アクティブ化すると、そのステータスは**アクティブ**から**非アクティブ**に切り替わり、ライセンスの消費が停止します。この変更は**ユーザー**設定のアクティブユーザーと非アクティブユーザーのリストにも反映されます。

ユーザーを非アクティブ化するには、以下を実行します。

1. **企業** 設定を開きます。
2. **ユーザー** メニューの下にある **すべてのユーザー** を選択します**。**
3. 非アクティブ化したいユーザーの右側にある**三点リーダー**（**...**）アイコンをクリックします。
4. **非アクティブ化** をクリックします。
   ![deactivate-users.png](../../../../../../docs/enterprise-administration/user-management/images/23921781594002_deactivate-users.png)
   *Enterprise プランではユーザーを非アクティブ化するオプションがあります*

   複数のユーザーを一括で非アクティブ化することもできます。左側のボックスをチェックして複数のユーザーを選択するか、検索条件を適用して最大 50 人までのフィルタリングされたユーザーを選択し、**一括操作**で **非アクティブ化** を選択します。
5. **ユーザーのコンテンツを再割り当て** チェックボックスを選択すると、ユーザーのボード、[テンプレート](../../getting-started/start-here/your-first-board/02-custom-templates.md)、および[スペース](../../using-miro/spaces/01-spaces.md)を移行できます。選択したユーザーが所属していた各チームごとに新しい所有者が必要です。ユーザーのコンテンツの再割り当ては元に戻すことはできません。
   ![deactivate-reassign-content.png](../../../../../../docs/enterprise-administration/user-management/images/23921804187154_deactivate-reassign-content.png)
   *ユーザーを非アクティブ化する際にコンテンツを再割り当てするオプション*
6. **非アクティブ化**を選択します。

ユーザーを非アクティブ化しても、Miro 内のデータは削除されません。ユーザーが持つ権限は保持され、再度アクティブ化されると復元されます。

:::note
注意: 会社の管理者を非アクティブ化するには、まず会社の管理者権限を取り消す必要があります。
:::

:::note
ユーザーを非アクティブ化しようとするときに**「チームには少なくとも一人の管理者が必要です」**という通知が表示されたら、そのユーザーがEnterprise チームの*唯一の*管理者であることを示しています。この問題を解決するには、[自分をこれらのチームに招待](05-manage-user-invitations-on-enterprise-plan.md)し、[チームの管理者権限を自分に付与](../../administration/user-management/06-how-to-manage-admin-roles.md)します。それぞれのユーザーのチーム数をクリックして、どのチームに所属しているかを確認します。
:::

:::note
御社が[SCIM](../security-integrations/system-for-cross-domain-identity-management-scim/02-scim.md)ソリューションを利用している場合は、アイデンティティプロバイダーを通じてユーザーを非アクティブ化することもできます。ユーザーがSCIMによって非アクティブ化されると、コンテンツは再割り当てされません。この場合の再割り当てオプションはUIでのみサポートされています。
:::

### ゲストの自動非アクティブ化

ゲスト（ボードにメールで招待されたユーザー）の場合は、[自動非アクティブ化](03-invitation-settings-on-enterprise-plan.md)を有効にすることができます。

## ユーザーを再アクティブ化する

ユーザーを再アクティブ化するには以下を実行してください。

1. **会社**の設定を開きます。
2. ユーザーメニュー項目の下で**すべてのユーザー**を選択し、**非アクティブ化されたユーザー** タブを選びます**。**
3. 再アクティブ化するユーザーの右側にある**三点リーダー** (...) アイコンをクリックします。
4. **再アクティブ化**を選択します。
5. 必要に応じて、ユーザーをチームに追加します。
6. **再アクティブ化**を確認します。

![reactivate-users.png](../../../../../../docs/enterprise-administration/user-management/images/23921804191762_reactivate-users.png)
*ユーザーを再アクティブ化*

ユーザーを再度アクティブ化すると以下のようになります。

- ユーザーはすぐログインできるようになります。
- 共有ボード、チームボード、非アクティブ化される前に作成したボードにアクセスできるようになります（ボードが再割り当てされていない限り）。

:::note
注意：非アクティブ化したユーザーを再度アクティブ化することができるのは、会社の管理者のみです。
:::

### ユーザーを永久に削除する

非アクティブ化したユーザーを完全に削除するには以下を実行してください。

1. **会社**設定を開きます。
2. **ユーザー** > **すべてのユーザー**をメニューからクリックします。
3. **非アクティブ化したユーザー**タブを選択します。
4. 削除したいユーザーの右側にある**三点リーダー** (**...**) アイコンをクリックします。
5. **削除**を選択します。
   ![delete-users.png](../../../../../../docs/enterprise-administration/user-management/images/23921781612562_delete-users.png)
   *非アクティブ化したユーザーを削除*
6. ユーザーのコンテンツを再割り当てするか削除するかを選択します。新しい所有者を選択して**ユーザーを削除**をクリックするか、**ユーザーとコンテンツを削除**を選択してください。

ユーザーは一括で削除することも可能です。

1. 非アクティブ化したユーザーのタブから、削除したいユーザーの横にあるチェックボックスをクリックします。
2. 上部の**会社から削除**ボタンをクリックします。

:::note
注記：削除後、ユーザーは新しいユーザーを[追加する](05-manage-user-invitations-on-enterprise-plan.md)権限を持つ人によってメンバーとして再びプランに招待されたり、ゲストとしてボードに招待されたりすることができます。
:::
