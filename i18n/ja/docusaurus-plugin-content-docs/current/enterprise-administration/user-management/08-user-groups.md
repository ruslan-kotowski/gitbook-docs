会社の管理者として、ユーザーグループを使用すると、各メンバーに個別に共有するのではなく、一括してグループのメンバーにコンテンツへのアクセスを管理することができます。組織内の全メンバーは、作成したユーザーグループとコンテンツを共有することが可能です。

この記事では、ユーザーグループを作成、管理し、コンテンツを共有する方法を説明します。機能に関する一般的な情報については、[ユーザーグループの概要](07-user-groups-overview.md)をご覧ください。

:::note
SCIMを使ってユーザーグループを管理する方法については、Miroのお客様担当者またはサポートにお問い合わせください。
:::

## 会社の管理者ガイド

### ユーザーグループを作成する

1. 会社の管理者として、管理者コンソールにアクセスします。
2. **ユーザー** > **グループ**を選択します。
3. 右上の**+ グループ作成**をクリックします。
   **新しいグループの作成**モーダルが開きます。
4. グループに名前を付けます。
5. （任意）新しいグループの説明を追加します。説明は後から追加または編集できます。
6. **グループ作成**をクリックします。
   新しいグループが**グループ**ビューに追加されます。

### ユーザーグループにユーザーを追加する

1. 管理者コンソールで、**ユーザー** > **グループ**に移動します。
2. 管理したいユーザーグループの行の末尾にある三点リーダー (**...**) を選択します。
3. **ユーザーを追加**をクリックします。
   **ユーザーを追加**のモーダルが開きます。
4. 名前またはメールアドレスでユーザーを検索します。
5. 追加する各ユーザーにチェックを入れます。
6. **選択したユーザーを追加**をクリックします。
   各選択したユーザーがユーザーグループに追加されます。

### ユーザーグループをチームに追加する

1. 管理者コンソールで、**ユーザー** > **グループ**に移動します。
2. 管理したいユーザーグループの行の末尾にある3点（**...**）を選択します。
3. **チームに追加**をクリックします。
   **チームにグループを追加**のモーダルが開きます。
4. チームを検索するには、名前で検索します。
5. ユーザーグループに参加させたい各チームにチェックを入れます。
6. **追加**をクリックします。
   選択した各チームにユーザーグループが参加しました。

   > ✏️ ユーザーグループのメンバーは、選択した各チーム内のすべてのコンテンツに編集アクセス権があります。

### ユーザーグループを編集する

1. 管理者コンソールで、**ユーザー** > **グループ**に移動します。
2. 管理するユーザーグループについて、行の末尾にある三点リーダー（**...**）を選択します。
3. **グループを編集**をクリックします。
   **グループを編集**のモーダルが開きます。
4. （オプション）グループの名前を変更します。
5. （オプション）新しいグループの説明を追加します。
6. **保存**をクリックします。

### ユーザーグループを削除する

:::warning
ユーザーグループを削除すると元に戻せません。ユーザーグループを削除すると、一部のユーザーが一部のチームから削除される可能性があります。
:::

1. 管理者コンソールで、**ユーザー** > **グループ**に移動します。
2. 管理したいユーザーグループの行末にある三点リーダー(**...**)を選択します。
3. **グループを削除**をクリックします。
   **\{ユーザーグループ名\}を削除**モーダルが表示されます。
4. **削除**をクリックします。
   そのユーザーグループは完全に削除されます。

## ユーザーガイド

### ユーザーグループとボードを共有する

チームメンバーは、組織内の任意のユーザーグループとボードを共有できます。そのボードはそのユーザーグループのすべてのメンバーと共有されます。

以下の手順に従ってください。

1. Miroボードの右上で**共有**をクリックします。
   モーダルが開きます。
2. 目的のユーザーグループの名前を入力します。
3. 自動補完されるオプションの中からユーザーグループを選択します。
4. （オプション）アクセス権を更新します。デフォルトは**編集可能**です。
5. （オプション）カスタムメッセージを追加します。
6. **招待を送信**をクリックします。
   ユーザーグループの各ユーザーに、あなたのボードにアクセスするためのメール招待が送信されます。

### スペースをユーザーグループと共有する

チームメンバーは組織内の任意のユーザーグループとスペースを共有し、権限を指定できます。スペースはそのユーザーグループのすべてのメンバーと共有されます。

以下の手順に従ってください：

1. Miroダッシュボードから、共有したいスペースの縦三点をクリックして**オプション**メニューを開きます。

   > 💡 また、スペースのサイドバーの上部にある縦三点をクリックして**オプション**メニューを開きます。
2. **共有**をクリックします。
   **「\{Space Name\}」スペースを共有** モーダルが開きます。
3. ユーザーグループ名を入力します。
4. （オプション） 権限を更新します。標準: **編集可能**。
5. （オプション）カスタムメッセージを追加します。
6. **招待を送信** をクリックします。
   ユーザーグループ内の各メンバーは、スペースにアクセスするためのメールでの招待を受け取ります。

:::note
ユーザーグループに追加されたメンバーは、共有されたスペースへのアクセス権を自動的に持ちます。ユーザーグループから削除されたメンバーのアクセス権は自動的に失効します。
:::
