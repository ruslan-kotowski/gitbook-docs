## ライセンス タイプ

[フレキシブル ライセンス プログラム（FLP）](../enterprise-subscription-management/enterprise-licensing/03-flexible-licensing-program-flp.md)には、**無料**ライセンスを無制限に利用できるメリットに加えて、いつでも制限付き無料ライセンスにダウングレードできる機能が含まれています。

|  |  |  |
| --- | --- | --- |
| **フル** | **無料（FLP のみ）** | **制限付き無料** |
| ユーザーには、ボードの作成だけでなく、[閲覧、コメント、編集](../../using-miro/sharing-boards/01-board-access-rights.md)のすべての権限があります。 | ユーザーは[閲覧やコメント](../../using-miro/sharing-boards/01-board-access-rights.md)することができ、**ボードを編集または作成する場合、ボードの編集の招待を受けた場合、ボードの共同所有権を付与された場合、あるいは**[編集者として](../../using-miro/sharing-boards/16-projects.md)プロジェクトに追加された場合、フルライセンスに自動的にアップグレードされます。 | ユーザーは[閲覧とコメント](../../using-miro/sharing-boards/01-board-access-rights.md)のみが可能ですが、チームのメンバーなので、すべての共有ボードを閲覧することができます。ライセンスのアップグレードをリクエストできます。 |

## Miro の役割

Miro の役割では、Enterprise プランの設定のユーザー アクセスレベルを定義します。

:::note
会社の管理者とチームの管理者は、常にメンバーであり、メンバーと同じ権限を持っています。
:::

|  |  |  |  |
| --- | --- | --- | --- |
| **会社の管理者** | **チームの管理者** | **メンバー** | **ゲスト** |
| すべてのチームの表示や、チームと会社の設定の管理**可** | 特定のチームの設定の表示や、管理**可** | **ボードの閲覧、コメント、編集**[可](../../using-miro/sharing-boards/01-board-access-rights.md)  チームや会社の設定の管理**不可** | 共有ボードの**閲覧、コメント、編集**[可](../../using-miro/sharing-boards/01-board-access-rights.md)（[ライセンスモデル](../enterprise-subscription-management/enterprise-licensing/02-enterprise-licensing.md)に基づく）  ボードの作成や所有、他のチームや会社の詳細情報の表示、チームや会社の設定の管理、ライセンスのリクエスト**不可** |

## よくある質問

**ユーザーのライセンスをダウングレードする方法を教えてください。**

会社の管理者は、Enterprise FLPサブスクリプションの場合、[会社の設定] > [**ユーザー**] > [**すべてのユーザー** **]**または[**チーム]**でユーザーのライセンスを制限付き無料ライセンスにダウングレードできます。

**2 つのチームのメンバーになる場合、そのチームごとでライセンスが必要ですか？**

2 つのチームが 1 つの Enterprise サブスクリプションに属している場合、必要なライセンスは 1 つだけです。チームが異なるサブスクリプションに属している場合は、すべてのチームにおいてライセンスが必要です。

**管理者に必要なライセンスの種類を教えてください？**

FLP プランの管理者は、フルライセンス、無料ライセンス、制限付き無料ライセンスを利用できます。非 FLP プランの管理者は、制限付き無料ライセンスまたはフルライセンスを利用できます。
