ユーザーグループは会社の管理者にとってユーザー管理を簡素化し、個々のユーザーではなく、グループ全体にコンテンツを共有できるようにします。

例えば、組織内のすべてのデザイナーとプロジェクトボードを共有したい場合、デザイナー全員をユーザーグループに追加し、そのグループと共有することができます。グループのすべてのメンバーには、編集、コメント、閲覧のいずれかのアクセス権が指定されます。

ユーザーグループの作成方法については、[ユーザーグループ](08-user-groups.md)をご覧ください。

![](../../../../../../docs/enterprise-administration/user-management/images/23921780232082_image.png)

*企業の管理者は管理者コンソールでユーザーグループを作成できます。*

ユーザーグループを利用することで、グループ内のすべてのユーザーが同じコンテンツにアクセスできるようになり、各ユーザー個別にボードを共有する必要がありません。また、ユーザーグループをチームに追加することもできます。

:::note
SCIMを介してユーザーグループを管理する方法については、Miroのお客様担当者またはサポートにお問い合わせください。
:::

## 主な機能

- **ユーザーグループの作成と管理**
  管理者コンソールで、会社の管理者はユーザーグループを作成、確認、編集、メンバーの追加、および削除ができます。詳細については、[ユーザーグループ](08-user-groups.md)をご覧ください。
- **ユーザーグループとボードまたはスペースを共有**
  チームメンバーはどのボードまたはスペースでもユーザーグループと[共有ができ](08-user-groups.md)、権限を設定できます。
- **APIによるユーザーグループの管理**
  ユーザーグループのAPIは、管理者がプログラムでユーザーグループを作成、編集、削除できるようにします。
- **コメントにユーザーグループをメンション**
  ボードでユーザーグループをメンションすると、グループ内のすべてのユーザーに通知が送信されます。
- **ボード上でユーザーグループのメンバーを確認**
  ボードでグループをメンションした際、そのユーザーグループのすべてのメンバーを確認およびレビューできます。
