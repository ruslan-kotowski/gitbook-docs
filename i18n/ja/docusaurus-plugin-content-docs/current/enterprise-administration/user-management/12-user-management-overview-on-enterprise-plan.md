プラン内の、何十、何百あるいは何千もの Miro ユーザーのアクセス権限を簡単に管理することができます。管理者はユーザーリストを追跡して絞り込み、ユーザーの役割やアクティビティ率、ライセンス消費量を閲覧することができます。ユーザーの招待や追加、削除や役割やライセンスの割り当て、チーム間のユーザーの移動などの一括操作を使用します。Miro の管理機能を使いこなせば、時間を節約し、Miro プランがどのように機能しているのかをより詳細に把握できるようになります。

ドメイン制御で要求が確認されたドメインに所属するすべての企業ユーザーは、[Enterprise 組織内の管理されたユーザー](06-managed-users-on-enterprise-plan.md)です。

## アクティブなユーザーセクション

チームの設定を開くには、ダッシュボードの左上にあるチーム名をクリックし、**チームメンバー**アイコンをクリックします。

企業の設定が開かれ、選択したチームに含まれるユーザーのリストが表示されます。このセクションでは、会社およびチームの管理者がチームにユーザーを追加または削除し、チームの管理者の役割を昇格または取り消すことができます。

会社の管理者は、ゲストをスタンダードまたはフル（旧）ライセンスを持つメンバーに変換することもできます。アドバンスト、スタンダード、またはフル（旧）ライセンスを取り消したりダウングレードしたりするには、代わりにそのメンバーに[Free 制限付き](../enterprise-subscription-management/enterprise-licensing/04-free-restricted-license.md)ライセンスを付与することができます。

:::note
検証済みドメインを共有する従業員は、アドバンスト、スタンダード、フル（旧）、Free、Free 制限付きライセンスを持つメンバーです。Enterprise プランでは、外部ドメインのユーザーのみがゲストとして追加できます。
:::

:::note
チームの管理者は、[招待設定](05-manage-user-invitations-on-enterprise-plan.md)で許可されている場合、新しいチームメンバーを招待できます。
:::

Enterprise サブスクリプションのユーザーの全リストを確認するには、**会社の設定**に移動します。左側の**ユーザー**の下で、**全ユーザー**を選択すると、アクティブなユーザーのリストが開きます（この画面から**無効化されたユーザー**や**招待**タブに切り替えることもできます）。特定のサブスクリプション内のチームやボードに追加または招待されたすべてのユーザーのリストと、最後の**活動日**の日付が表示されます。

:::note
チーム設定から会社の設定に行くには、左上の**会社**をクリックします。
:::

会社の管理者として、組織内のユーザーの一覧とその最終ログイン情報をダウンロードすることができます。アクティブなユーザーのリストの上部にある**CSV をダウンロード**ボタンを見つけてください。

**アクティブなユーザー** セクションでは、ユーザーの役割、ライセンス、チーム、アクティビティと共にすべてのユーザーリストをご覧になれます。

The **役割**は、プラン内のアクセス権限を定義します。会社の管理者はプランを管理するための最も強力な役割であるのに対し、ゲストは招待されたボードにしかアクセスできません。アクセスレベルについての詳細は、[アクセス権限に関する記事](11-user-access-levels-on-enterprise-plan.md)をご覧ください。

The **ライセンスタイプ**は、ユーザーが使用しているライセンスがAdvanced、Standard、Full（旧）、または無料ライセンスであるかを示します。

The **チーム**は、ユーザーが追加されているプラン内のチーム数です。

**Last** **activity**は、ユーザーがサブスクリプション内のどのボードを開いたかを示します。カレンダーの日付を選択するか、30、60、90、または180日間のプリセットオプションのいずれかを使用して、アクティブ/非アクティブなユーザーをフィルターできます。アクティブなユーザーとは、過去90日以内にMiroを利用したユーザーを指します。

### シングルユーザーのステータスを変更

会社の管理者として、ユーザーの役割やライセンスの変更、ユーザーあるいはグループのチーム数の変更が可能です。ユーザーを[非アクティブ化](01-deactivated-users.md)した後、[削除](10-remove-users-on-enterprise-plan.md)することもできます。これらのオプションにアクセスするには、任意のチームメンバーの行の隣にある**三点リーダー**(**...**)をクリックしてください。

:::tip
高度なユーザー管理システムは、購入したリソースをより効果的に管理するのに役立ちます。[フレキシブル ライセンス プログラム](../enterprise-subscription-management/enterprise-licensing/03-flexible-licensing-program-flp.md)が有効になっている場合、非アクティブなユーザーを制限付き無料に変換してライセンスを解除できます。
:::

### 絞り込み条件

メールや名前で**検索**したり、特定の基準で**リストを絞り込み**をして、迅速にユーザーを見つけることができます。招待されたユーザーを非表示にして、ご利用のプラン内の登録済み Miro ユーザーだけを表示することもできます。

一旦絞り込みが適用されると、リスト上で最大50人のユーザーを一括で選択し、一括操作を行うことができます。

### 一括操作

**一括操作**ボタンは、ユーザーグループをより素早く管理するのに役立ちます。複数のユーザーを選択し、一括で必要な変更を適用します。

左側のチェックボックスを有効にしてユーザーを一人一人選択するか、絞り込みを適用して最大 50 人のユーザーを一度に選択できます。

#### アクティブなユーザーを一括管理

**アクティブなユーザー**リストで、以下のアクションのいずれかを適用するためにユーザーのリストを選択します。

1. チームのメンバーシップを一括管理。
   1. ユーザーをチームに追加または移動します。
   2. [新しいチームを作成](../managing-enterprise-teams-and-content/09-create-a-new-team-on-enterprise-plan.md)し、ユーザーを追加します。
2. ライセンスおよび役割を一括管理
   1. 上位メンバーに切り替え。フレキシブル ライセンス プログラム (FLP) では上位ライセンスをサポートしておらず、常に非FLP（ハードリミット）モデルで運用されます。貴社が購入した上位ライセンスの数までのみ割り当て可能です。StandardをFLPで使用している企業は、上位ライセンスを購入量に固定することで、StandardをFLPのまま（自動的にFree Restrictedへダウングレードする無制限の無料ライセンス）にしておくことができ、ライセンスの混在モデルが可能です。上位機能を必要とするユーザーは、明示的に上位ライセンスの割り当てを受けるか、組織のアップグレードまたはリクエストのフローに従う必要があります。
   2. Standardメンバーまたはフルメンバー（レガシー）に切り替え。
   3. ベーシックメンバーに切り替え。
   4. ゲストまたはチームゲストに切り替え。
   5. 制限付き無料に切り替え ([FLP Enterprise サブスクリプション](../enterprise-subscription-management/enterprise-licensing/03-flexible-licensing-program-flp.md)で利用可能)。
3. 支払いグループを変更するか、新しいものを作成する。
4. 制限付きを取り消す。
5. ユーザーを[一括で非アクティブ化](01-deactivated-users.md)

#### 招待を一括管理

"招待" タブに切り替えて、招待済みのユーザー（サブスクリプションへの招待が送信されてから 30 日以内で、Miro にまだ登録していないユーザー）のリストを表示します。以下のアクションを適用するために、招待者のリストを選択してください。

1. チームメンバーシップを一括管理。
   1. 現在のチームから削除するかしないかにかかわらず、ユーザーを複数のチームに追加します。
   2. 新しいチームにユーザーを追加（[新しいチームを作成](../managing-enterprise-teams-and-content/09-create-a-new-team-on-enterprise-plan.md)）。
2. ユーザーを[一括非アクティブ化](01-deactivated-users.md)。
3. ユーザーライセンスを一括変更。

#### チームから一括削除

**チーム**のリストで、削除したいユーザーが所属するチームを選択します。 ユーザーを選択して、チームからユーザーを一括削除できます。

### ユーザー情報

ユーザー情報は、プラン内の各ユーザーのステータスカードで、個別に編集することができます。 一括管理とは逆に、ユーザーごとにステータスを確認し、管理することができます。 各ユーザーは、写真や名前、メールアドレス、ボード数、プロジェクト数、テンプレート数、現在のチームおよびライセンスが記載された**ユーザープロフィール**を持っています。それぞれの行の**三点リーダー**(**...**)アイコンをクリックして**ユーザー情報**を選択するとユーザーカードを開くことができます。

:::note
ユーザーの詳細には、**内部**または**外部**の分類が含まれます。内部ユーザーは、検証済みのドメインからのメールアドレスでログインします。外部ユーザーはそれを使用しません。詳細は、[ドメイン制御: 内部ユーザーと外部ユーザー](../canvas-25-admin-features/domain-control/01-domain-control.md)をご覧ください。
:::

会社の管理者はチームのメンバーシップを変更し、カードから直接ユーザーに管理者権限を付与することができます。ただし、管理者は名前、プロフィール写真、メールなどのユーザー情報を変更することはできません。これらの情報はユーザーがプロフィール設定で変更できます。[SSO](../security-integrations/single-sign-on-sso/09-single-sign-on-sso.md) を使用している場合、ログインが成功すると、IDプロバイダーによって自動的にデータが割り当てられます。

### よくある質問

1. *別チームへの追加の申請がユーザーからたくさん届きます。これらの通知を受け取らないようにしたいです。*
   - おそらく、[チームのプライバシー](../managing-enterprise-teams-and-content/11-manage-team-privacy-and-discovery-on-enterprise-plan.md)が無効化されているため、Enterprise ユーザーが組織内の新しいチームを発見できる状態です。これらのリクエストを止めたい場合は、次のいずれかの方法が考えられます：
   - プライバシーをオンにし、ユーザーが組織内の新しいチームを見つけられないようにする。あるいは、
   - チームを完全にオープンにして、承認なしでユーザーがチームに参加できるようにする。
2. *たくさんのユーザーが Standard ライセンスやフル（レガシー）ライセンスを割り当てられていますが、私は誰にも割り当てていません。なぜですか？*
   - チームごとに、特定のチームにユーザーを招待できるのは誰かを定義できます。必ず[招待設定](03-invitation-settings-on-enterprise-plan.md)を構成してください。[フレキシブル ライセンス プログラム](../enterprise-subscription-management/enterprise-licensing/03-flexible-licensing-program-flp.md)を有効にし、ユーザーがプランに参加すると取得するデフォルトのライセンス（Free あるいは制限付き無料）が設定できます。
