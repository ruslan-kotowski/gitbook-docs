このガイドは、無料の Miro のチームを作成したばかりで、管理オプションの詳細を知りたい方に役立ちます。

> **設定者：**チームの管理者

チームの設定を開くには、ダッシュボードの右上にある自分のアバターをクリックし、**管理者コンソールを**クリックします。

無料プランの管理者は、管理コンソールの以下のセクションにアクセスできます：

**[ユーザー]** タブでチームユーザーを管理します。右上の「**招待する」**ボタンをクリックして、新しいメンバーを招待します。無料チームに招待されたすべてのユーザーは、チームに保存されたすべてのボードにアクセスできることにご注意ください。ユーザーの横にある三点リーダーをクリックすると、[そのユーザーを管理者に昇格さ](../user-management/06-how-to-manage-admin-roles.md)せたり、[チームから削除する](../user-management/08-remove-users.md)ことができます。

![フリーユーザー.png](../../../../../../docs/administration/get-started-as-a-miro-admin/images/25005889311634_free-users.png)
*無料プランのユーザー管理*

セキュリティ無料プランの管理者は、チームに*2種類の権限を*設定することができます：**チーム登録モードと** **招待の設定**。[チームの登録モードを設定](../team-management/02-manage-team-signup-mode.md)すると、ドメインを持つユーザーがチームを検索できるようになります。招待設定では、管理者は、新しいユーザーをチームに招待できるユーザーを定義し、チームの招待リンクを有効化または無効化できます。**共有の設定も**このタブにあります。

> [チームをアップグレード](../../plans-billing/manage-your-subscription-and-plan/03-upgrade-your-plan.md)すれば、ボードの共有とコンテンツのアクセス権限を設定できます。

![フリー・パーミッション.png](../../../../../../docs/administration/get-started-as-a-miro-admin/images/25005901477266_free-permissions.png)
Free プランのアクセス権限設定

**アプリ**」タブで、チーム用の新しいアプリをインストールできます。一部のインテグレーションは、無料プランではサポートされておりませんのでご注意ください。アプリをアンインストールするには、一覧から選択します。これにより、アプリのプロフィールが開き、チームのアンインストール ボタンを確認できます。

**チームのプロフィール** タブでは、[チーム名やロゴを変更](../team-management/04-update-team-name-or-logo.md)できます。**お客様のプランの詳細**]で、[**プランの変更]**をクリックすると、プランをアップグレードするオプションが表示されます。その下にボードの総数とチームメンバーの数が表示されます。
