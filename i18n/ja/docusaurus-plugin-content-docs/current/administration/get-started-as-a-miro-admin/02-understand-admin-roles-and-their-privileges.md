あらかじめ定義された管理者ロールを割り当てることは、組織内のユーザーに特権を与える簡単な方法です。それぞれの管理者ロールは、特定のMiro機能を実行するための1つ以上の特権を提供します。

Miroは現在、会社の管理者、ユーザー管理者、コンテンツ管理者、セキュリティ管理者という4つの事前定義された組織レベルの管理者ロールを提供しています。

以下の表は、各ロールに関連付けられた特権を示しています。

:::note
これは進化中のロールと特権の一覧です。定期的にこのページをチェックして更新を確認してください。
:::
