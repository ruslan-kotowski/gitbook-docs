Miro はデータのプライバシーとセキュリティに配慮し、業界リーダーと遜色ないレベルのセキュリティ対策を維持できるよう努めています。データのプライバシーとセキュリティについて、よくある質問をご覧ください。

### Miro のデータはどこに保存されていますか？

EU データセンターレジデンシーのもと、コンピュートインフラストラクチャーおよびすべてのカスタマーコンテンツ（プロダクションデータ、バックアップデータ、メタデータ）は、デフォルトで EU 域内にホストされています。

:::note
データレジデンシーはオーストラリアとアメリカ合衆国でも利用可能です。詳細については、[Miro のデータレジデンシー](https://help.miro.com//hc/articles/23084283851026)をご覧ください。
:::

**詳細情報:**こちらをご覧ください [Miro のデータレジデンシー](https://help.miro.com//hc/articles/23084283851026)。

### 作成したコンテンツは非常に秘匿性が高いものです。Miro チーム以外でのボード共有を確実に食い止めるには、どうすればよいですか？

[Miro Enterprise](../../plans-billing/miro-plans/04-enterprise-plan.md) は、次の機能を提供して、チームメンバーがMiroでセキュリティとプライバシーを維持しながらコラボレーションできるようにします。

- [共有ポリシー](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md)により、信頼できるドメインのリストを設定することができます。リストにあるメールドメインのユーザーのみ、サブスクリプションに招待できます。
- [リンクアクセスコントロール](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md)は、ユーザーがボードを公開リンクで共有することを無効化でき、サブスクリプションのユーザーだけが特定のボードにアクセスできるようにします。
- [ドメインコントロール](../../enterprise-administration/canvas-25-admin-features/domain-control/01-domain-control.md)により、企業ドメインの所有権を確認し、一元管理されたEnterpriseサブスクリプションを維持するために必要な管理機能を提供します。

### Miro の従業員なら誰でもユーザーのボードにアクセスできますか？

いいえ、お客様のリクエストと許可がなければ、ボードコンテンツを閲覧することはできません。Miroでは、アクセスを生産環境内の限られたIPアドレスと従業員に制限しています。

### 自分だけがボードにアクセスできるようにするにはどうすればよいですか？

[非公開ボードを作成する方法](../../using-miro/sharing-boards/15-make-a-miro-board-private.md)を学びましょう。いつでも[ボードの共有ダイアログ](../../using-miro/sharing-boards/01-board-access-rights.md)で誰がボードにアクセスしているか確認できます。

### Miroは、すべてのユーザーに同じレベルのデータ保護を提供していますか？

はい、いずれの Miro プランでも、ご安心ください。お客様のデータは安全に管理され、保護されています。転送は TLS 1.2 以上、保存は AES 256 を採用し、GDPR と CCPA の基準に準拠した最高レベルのセキュリティが追加コストなしで提供されます。
高度なセキュリティとプライバシー、管理コントロールについて詳しく知りたい方は、[お問い合わせください](https://miro.com/contact/sales/?utm_source=security)。[Miro Enterprise](https://miro.com/enterprise/?utm_source=security)について詳しくご案内します。

### データをサードパーティベンダーに販売することはありますか？

いいえ、私たちはユーザーデータを販売していません。詳細は[プライバシーポリシー](https://miro.com/legal/privacy-policy/)をご覧ください。

### Miro は、一般データ保護規則（GDPR）の要件に準拠していますか？

はい、詳細については[プライバシーポリシー](https://miro.com/legal/privacy-policy/)をご確認ください。

### SOC3 レポートはどこでダウンロードできますか？

[システムおよび組織の管理レポート（SOC 3）](https://assets.ctfassets.net/w6r2i5d8q73s/1wSVE3U0GqAZOVKKBLcUhR/250dd4c346b99dfb56b729c1c8eaa78e/2021_Miro_SOC3_TypeII_Final__4_.pdf)を読み、ダウンロードしてください。

### クライアントのファイアウォールが妨げとなって、Miro ボードへアクセスをクライアントに付与できません。どうすればよいですか？

[Miro を許可ドメインに追加する方法](../../using-miro/tools/troubleshooting/01-add-miro-to-allowed-apps.md)をご覧ください。

### Miro に関する法的情報はどこで入手できますか？

当社のサービス利用規約、プライバシーポリシー、データ処理附則（DPA）、およびクッキーポリシーは[Miro トラストセンター](https://miro.com/trust/)にてご覧いただけます。

### 脆弱性報奨金制度はありますか？

はい、Miro は Intigriti で脆弱性報奨金制度を導入しています。参加をご希望の場合は、Intigriti のアカウントにログインし、[Miro Intigriti プログラムページ](https://app.intigriti.com/researcher/program-redirect/miro/miro)をご覧ください。報奨金の申し込みは、プログラムの規則に従って処理されます。提出の前に規則をよくご確認ください。
