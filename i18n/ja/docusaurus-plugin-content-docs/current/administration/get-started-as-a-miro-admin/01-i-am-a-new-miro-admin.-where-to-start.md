Miroで新しいチームを作成するか、[管理者ロールに昇格](../user-management/06-how-to-manage-admin-roles.md)すると、チームの権限、ユーザー、インテグレーション、その他のチームや会社の属性などのオプションを備えた管理者コンソールにアクセスできるようになります。この記事では、Miroの管理者コンソールの概要を簡単に説明します。

### チームの設定

ダッシュボードの左サイドバーのドロップダウンから、すべてのチームを確認できます。チーム設定に移動するには、チーム名にカーソルを合わせ、**歯車のアイコンを**クリックします。

![チーム設定.png](../../../../../../docs/administration/get-started-as-a-miro-admin/images/25005833525906_team-settings.png)
*チームの設定を始める*

複数チームのメンバーまたは管理者の場合、左上のドロップダウン メニューでチームを選択し、チームの設定でチームを切り替えることもできます。

### 会社の設定

Business PlanまたはEnterprise Planで会社の設定を行うには、管理者コンソールの左上にある「**会社**」をクリックします。

**チーム設定**は [Miro プラン](../../plans-billing/miro-plans/02-plans-and-features-available.md)により異なる場合がありますが、Miro の管理者全員が、左側に以下のセクションを表示できます。

- チームのプロフィール
- アプリとインテグレーション
- 管理者権限
- アクティブなユーザー

**チームのプロフィール**は、チーム名やロゴを変更し、プランの詳細（現在のプラン、ボード数、チームメンバー数）を確認できるタブです。そこからチームを退出、または[削除](../team-management/06-delete-and-restore-teams.md)することもできます。

![チームプロフィール.pngチーム](../../../../../../docs/administration/get-started-as-a-miro-admin/images/25005833526930_team-profile.png)
*プロフィール*

**Apps**セクションでは、管理者は以下のことができます：

- **[アプリをインストール]** をクリックして、Miro のマーケットプレイスに移動する
- チームメンバーが新しいアプリをインストールすることを許可または制限する
- アプリをアンインストールする（一覧でアプリを選択すると、アンインストールのオプションが表示される）

チームのアクセス許可を設定するには、「**セキュリティー**」 > 「**アクセス許可**」をクリックします。そこから、チームの管理者は次のことができます。

- [チームの登録モード](../team-management/02-manage-team-signup-mode.md)を設定する
- [招待設定](../user-management/02-invitation-settings.md)を設定する
- [共有設定](../../using-miro/sharing-boards/11-default-sharing-settings.md)を管理する（有料プランのみ）
- [ボード内コンテンツの設定](../../using-miro/sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)を定義する（有料プランのみ）
- Enterprise プランの場合、管理者は[ボードの共有設定を追加できる](../../enterprise-administration/canvas-25-admin-features/data-security/07-sharing-policy-on-enterprise-plan.md)

![チーム許可.png](../../../../../../docs/administration/get-started-as-a-miro-admin/images/25005896069522_team-permissions.png)

### チームの管理者と会社の管理者

> **利用可能なプラン：**Business、Enterprise

BusinessプランとEnterpriseプランでは、1つのサブスクリプションに複数のチームを作成できます。2 つのレベルの設定（**チームの設定**と**会社の設定**）と、2 つの管理者の役割（**チームの管理者**と**会社の管理者**）があります。

:::tip
チームのアイコンは、チームの管理者が変更できるチーム設定を示します。会社の管理者として、**管理コンソール** >**チーム**>**\{チーム名\}**>**設定** タブに移動します。

チームのアイコン ![](../../../../../../docs/administration/get-started-as-a-miro-admin/images/26671728983826_image.png)
:::

チームの管理者は、[チーム名やロゴの変更](../team-management/04-update-team-name-or-logo.md)、チームアプリのインストール / アンインストール、[他ユーザーのチーム管理者への昇格](../user-management/06-how-to-manage-admin-roles.md)、メンバーの削除、[新規ユーザーの招待](../user-management/02-invitation-settings.md)（招待設定が許可されている場合）、[デフォルトの共有設定の管理](../../using-miro/sharing-boards/11-default-sharing-settings.md)、[ボードのコンテンツの設定](../../using-miro/sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md)、共同所有者の有効化 / 無効化を行う権限があります。

会社の管理者は、サブスクリプション内のすべてのチームと、会社レベルの属性を管理できます。

- 社名とロゴの変更
- **会社概要**タブのサブスクリプションの詳細をご覧ください（ビジネスプランのみ）。Enterpriseプランのサブスクリプションの詳細については、**管理者コンソール** **>支払い** **>サブスクリプション**)を参照してください。
- [「支払い」](../../plans-billing/manage-your-subscription-and-plan/01-manage-your-subscription.md)セクションで**サブスクリプションを管理する**
- **[アクティブなユーザー]** セクションで、ユーザーライセンスの変更や、会社のユーザーの招待や削除を行う
- **招待**を管理する
