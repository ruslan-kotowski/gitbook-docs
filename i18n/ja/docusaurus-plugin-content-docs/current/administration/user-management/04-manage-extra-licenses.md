新しいチームメンバーを追加すると、プランにあるすべてのライセンスが既に使用されている場合、追加のライセンスが自動的に追加されます。このガイドでは、これらの追加ライセンスを管理する手順をご説明します。

## ライセンス調整と請求の管理

### 追加ライセンスの請求が発生する前に

次回の請求書で追加料金が発生しないように、お支払い日前に追加されたライセンスを削除する必要があります。

チーム規模を調整すると、確認メールが送信されます。請求書は、使用された追加ライセンスの日数分だけ課金されるように更新され、正しいライセンス数を反映します。

### 追加ライセンスの請求後

最近の請求書に追加のライセンス料金が含まれている場合、最初のステップは追加のライセンスを削除することです。

請求日後にライセンスを削除しても、即時のライセンス減少は発生しません。更新時に減少が予定されています。返金はありません。

Miroが日割り計算する費用についてもっと詳しく知りたい方は、[Miroの請求](../../plans-billing/billing-and-payments/04-miro-billing.md)をご覧ください。

## 追加ライセンスを削除する方法

1. 追加ユーザーを削除します。
   1. Miro のダッシュボードから、右上の自分のアバターをクリックして、**管理者コンソール** | **設定**を選択します。
   2. 左側のパネルで、**チーム**をクリックします。
   3. **ユーザー**タブで、削除したいユーザーの三点リーダー(**...**)をクリックします。
   4. **チームから削除する**をクリックします。
2. ライセンス数に合わせてチームの規模を変更します。
   1. Miro のダッシュボードから、右上の自分のアバターをクリックして、**管理者コンソール** | **設定**を選択します。
   2. 左側のパネルで、**請求**をクリックします。
   3. **概要**タブの**プラン詳細**の下で**チームの規模を変更**をクリックします。
      **チームの規模を変更**モーダルが開きます。
   4. **ライセンス**については、チームの規模を変更するためにドロップダウンメニューをクリックしてください。
      ライセンスの削除が予定されており、それは更新日に有効になります。詳細については、[Miro の月次および年次課金](../../plans-billing/billing-and-payments/04-miro-billing.md)をご覧ください。

ライセンスと請求に関する詳細は、[Miro の請求](../../plans-billing/billing-and-payments/04-miro-billing.md)をご覧ください。

## 追加ライセンスを防ぐ

以下のベストプラクティスは、プランに追加される余分なライセンスを回避するのに役立ちます。

- 追加費用なしでボードにさらに多くのユーザーを招待するには、[ビジター](../../using-miro/sharing-boards/08-collaboration-with-visitors.md)および[ゲスト](../../using-miro/sharing-boards/07-collaboration-with-guests.md)オプションを探索してください。
- 管理者は、[招待設定](02-invitation-settings.md)を調整して、誤って余分なライセンスが追加されないようにすることができます。

:::note
お支払いに問題がある場合は、[サポートにお問い合わせください](../../using-miro/tools/troubleshooting/06-contacting-miro-support.md)お支払いに関する情報を共有できるのは、Miro の管理者またはサブスクリプションを購入した方のみとなっています。もしそれがあなたでない場合は、Miro の管理者にお問い合わせください。
:::
