すべてのライセンスとチームへのアクセス要求を一元的に照会して管理することで、ライセンス使用を合理化し、ワークスペースを整理しつつセキュリティーを担保します。

> **利用可能なプラン：**Starter、Business
> **実行可能なユーザー：**会社の管理者

## アクセスリクエストの設定

**アクセスリクエスト**の設定中に、現在あるすべてのライセンスとチームのアクセスリクエストの概要が表示されます。リクエストは、アクセスを必要とする本人、または代理のユーザーが行うことができます。

アクセスリクエストの詳細は以下の通りです。

- ライセンスが必要なユーザー名
- ユーザーが参加を希望するチーム名（Business プランのみ）
- 依頼者名
- 依頼日
- リクエストの理由を説明する依頼者からのメッセージ

:::note
すべてのリクエストは 30 日後に自動的に期限切れとなり、削除されます。
:::

## ライセンスとチームのリクエストの承認または拒否方法

1. 管理者コンソールに移動します。
2. **ユーザーを**クリックします。
3. **アクセス要求を**クリックします。
4. **アクセスリクエスト**のセクションが開きます。ここには、保留中のリクエストが表示されます。
5. ****アクション******の列で、リクエストを承認する場合はチェックマーク（**✓）を、却下する場合は x をクリックします。
6. リクエストを承認または却下すると、リクエストの詳細と依頼者からのメッセージが表示される画面が開きます。
7. リクエストを承認する場合は [**承認**] を、承認しない場合は [**却下**] をクリックします。承認または却下すると、そのリクエストはアクセスリクエストの画面から削除されます。
8. ライセンスリクエストが承認されると、該当ユーザーはフルライセンスでチームに追加されます。割り当てられた総ライセンス数に達した場合、サブスクリプションに追加ライセンスが追加され、[日割り計算された請求書](../../plans-billing/billing-and-payments/07-understanding-your-invoice.md)が送付されます。

## ライセンスおよびチームへのアクセス要求

Miro で特定のアクションやイベントが実行すると、自動でライセンスやチームへのアクセスがリクエストされます。以下に概説するシナリオは、これらのアクセス要求がどのように開始されるかの詳細です。

リクエストが承認されると、そのユーザーにはフルライセンスが付与され、サブスクリプション内のメンバーとなり、チームも利用できるようになります。

| ユーザー種別 | アクション | シナリオ |
| --- | --- | --- |
| **既存のメンバー（フルライセンス）** | 新しいチームにアクセス | メンバーが、サブスクリプション内の新しいチームへのアクセスを要求する |
| 別ユーザーのチームへのアクセス（サブスクリプション内） | メンバーが、同じサブスクリプション内ではあるが、チームに所属していない別のユーザーのチームへのアクセスを要求する |
| 他のユーザーへのチームアクセス（サブスクリプション外） | メンバーが、通常は[メールやリンク](../../using-miro/sharing-boards/03-sharing-boards-and-inviting-collaborators.md)により、サブスクリプション外の新規ユーザーをチームに招待する |
| **既存のゲスト** | フルライセンスへのアップグレード | [ゲスト](../../using-miro/sharing-boards/07-collaboration-with-guests.md)が、ボードの作成と共有のため、無料ライセンスからフルライセンスへのアップグレードをリクエストする |
| フルライセンスへのアップグレード | [ゲスト](../../using-miro/sharing-boards/07-collaboration-with-guests.md)がボード編集のため、無料ライセンスからフルライセンスへのアップグレードをリクエストする（Starter プランのみ） |
| **新規ユーザー（Miro のサブスクリプション外）** | 同じドメインで参加 | 新規ユーザーが[同じドメインで登録またはログイン](../team-management/02-manage-team-signup-mode.md)すると、組織や特定のチームに参加できる |
| ボードのアクセス権なしで参加 | 新規ユーザーが、共有されているボードにアクセスできない場合、組織に参加することができる |
