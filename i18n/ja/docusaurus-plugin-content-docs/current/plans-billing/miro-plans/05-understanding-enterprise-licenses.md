様々なチームやワークフローに合った機能を選びやすくするために、Miro はStandard およびAdvanced Enterprise ライセンスを導入します。

## フルライセンスはStandardに

現在、フルライセンス付きの旧Enterprise ライセンシングモデルをご利用中の方は、これまで通りプラットフォームを使用できます。ただし、テーブル内の双方向Jira カードインテグレーション、AWS コスト計算アプリ、およびテーブル内の階層構造は、新しいAdvanced ライセンスでのみ利用可能となります。キャンバス上での双方向Jira カードインテグレーションは、引き続きフルライセンスとStandard ライセンスで動作します。アカウントマネージャーがスムーズな移行をサポートし、計画を立てるお手伝いをいたします。

## Enterprise Advanced ライセンス

Enterprise Advanced ライセンスは、複雑なプロダクト開発を管理するエンジニアリング、プロダクト、デザインチーム向けに最も強力な機能を備えた、Miro Enterprise プランの新しいライセンスタイプです。これはオプションのアップグレードです。

## Core Miro、およびProduct Accelerationのために目的に合わせて構築されたワークフロー

Standard と Advanced の両方には、柔軟なキャンバス、コラボレーション、テンプレート、チームに愛される基本機能を含む、コア Miro の体験が含まれています。

さらに、Product Acceleration ソリューションは、特定の高価値ワークフローでチームがより深く進めるのを手助けし、以下を含みます：

- テクニカルデザインと仕様: エンジニアリングの作業のやり直しを減らし、明確な技術文書を作成し、AIツールで信頼性のあるコードを生成します。
- 目標、ロードマップ、およびデリバリー: 戦略を実行に結びつけ、ボトルネックを早期に把握し、チーム間の依存関係を管理します。

| Enterprise 標準ライセンス | Enterprise 高度ライセンス  ***製品、デザイン、エンジニアリング、ITに推奨*** |
| --- | --- |
| **技術設計と仕様** 明確な技術仕様でエンジニアリングの手戻りを減らし、チームの方向性を統一します。  提供機能:   - コード説明のような基本的なMCP機能 - 3600以上の図形、レイヤー、PlantUML、Draw.ioなど - コードブロックのウィジェット   **目標、ロードマップ、およびデリバリー** プロダクト開発を会社の目標、タイムライン、および定義されたブロッカーに沿って軌道に乗せ、納品妨害を未然に防ぎます。  提供機能:   - ドキュメント、データテーブル、タイムライン - ブループリント、スペース、テンプレート - Jira、Azure、Linear などとの簡単な双方向インテグレーションをキャンバス上で実現 | **高度な技術設計と仕様**  Miro と AI ツールを接続して、より良い文脈で適切なものを構築し、開発と意思決定を加速。  Powered by:   - 主要なコード生成ツール（GitHub、Copilot、Cursor、Claude Code など）とのインテグレーションを伴う、ボード全体の要約やダイアグラム作成のような高度な Miro MCP 機能。 - AWS インフラストラクチャの可視化とコスト計算   **高度な目標設定、ロードマップ、デリバリー** 自動化された整合、ゴールの可視性、プロアクティブな依存関係管理を通じて市場投入までの時間を短縮します。  Powered by:   - 複数のテーブル間の関係と階層 - 視覚的階層を明確にするテーブルでのツリービュー - Jira、Azure、LinearなどのDevOpsシステムとのテーブル内での高度な双方向インテグレーション |

## よくある質問

**組織全体が Advanced ライセンスに移行する必要がありますか？**
いいえ。Enterprise Advanced は、必要な特定のユーザーやチーム向けに購入できます。組織の他の部分は、現在のライセンスのまま継続可能です。

**Miro Enterprise ライセンスについて今すぐ何かする必要がありますか？**
いいえ、現時点での具体的な対応は必要ありません。Advanced ライセンスのプロンプトやペイウォールがプロダクト内で表示されるのは、これらの機能が Advanced ライセンスを必要とするため、予期された動作です。お使いの組織に最適な選択について質問があれば、アカウントチームに連絡するか、当社までお問い合わせください。

**Enterprise プランでは今後、機能のベータ版へのアクセスはどのように機能しますか？**
Miro が新しい機能をベータ版でリリースする際、各機能には明確にベータタグが付けられます。ベータ機能がスタンダードとして指定されている場合、それはリリース時に追加料金なしでライセンスに含まれ続けます。Advanced として指定されている場合、ベータ期間中にそれを評価・使用し続けることができます。ただし、一般提供後は継続的なアクセスに Advanced ライセンスが必要となります。これをあらかじめ明確にお伝えし、適切に計画できるよう努力しています。

**新しい Enterprise ライセンスに関する詳細情報を得るにはどうすればよいですか？**
特定の権利、引き継ぎ状況、またはライセンスオプションに関する質問がある場合は、営業担当者またはお客様担当者にお問い合わせください。または、当社までご連絡いただくこともできます。
