## 消費税、付加価値税、物品・サービス税

Miro は、現地法で求められるサブスクリプション料金に適用される税金を課します。Miro の有料プランを購入する際に、お住まいの地域によっては、税金が課金されることがあります。Miro がこうした税金を徴収した場合、お客様に代わって全額を関連する税務当局に送金します。

- 売上税、物品・サービス税（GST）、付加価値税（VAT）は、料金プランページに記載されている価格には含まれていません
- 該当する場合、プロフィールの支払い情報セクションに記載されているその*会社の住所*を使用して、正しい税率を決定します
- お客様のサブスクリプションに関連する請求先国や納税者番号などの情報を更新できるのは、Starter プランのチームの管理者、Business プランの会社の管理者、[支払い管理者](../../administration/admin-faq/01-admin-faq.md)のみです

## 付加価値税（VAT）

欧州連合、ノルウェー、トルコ、イギリスに所在する場合、購入（サブスクリプション、追加ライセンス、更新など）には付加価値税（VAT）が加算され、請求書には税金が別ライン項目として表示されます。

### VAT 免除

お客様が企業登録されている場合、[お支払いの設定](../manage-your-subscription-and-plan/01-manage-your-subscription.md)ページで有効な VAT ID を入力すると、今後購入する際に VAT が免除される（リバースチャージが適用される）場合があります。

請求先住所が EU にある場合、提供する VAT ID が、[VIES データベース](https://ec.europa.eu/taxation_customs/vies/)に登録されていなければ、有効とみなされませんので、ご注意ください。このプロセスが自動化されていない一部の EU 諸国では、VIES データベースにお客様の VAT ID を含めるために、関連する税務当局に申請する必要があります。

### 購入時に VAT ID を入力する方法

チーム規模、支払いサイクル、支払い方法を選択した後、以下を行ってください。

1. 支払い情報セクションに、お住まいの国を入力します（VAT ID フィールドが表示されます）。
2. VAT ID を入力します。

### VAT ID を更新する方法

1. プロフィールアバターをクリックし、**管理者コンソールを**クリックします。
2. 左側のサイドバーで「**請求**」をクリックし、**「請求情報」**タブをクリックします。
3. 会社の住所を記入し、VAT ID を入力します（VAT ID に関連する 2 文字の国コードが含まれていることを確認してください）。

### Miro の VAT ID

Miro は、EU の ワンストップショップ（「OSS」）制度を通じて VAT に登録されており、個々の EU 加盟国で VAT 登録を行っているわけではありません。OSS 制度は、EU 域内に設立されていない課税対象者が、EU 加盟国の非ビジネス顧客に電子的に供給されたサービスに対する VAT を徴収・送金するために利用できるものです。Miro は、OSS の識別国としてオランダを選択しました。

## 物品・サービス税（GST）

組織がオーストラリアやニュージーランドにある場合、物品・サービス税（GST）が購入品（サブスクリプション、追加ライセンス、更新）に加算され、請求書に別項目として税金が表示されます。

### GST 免除

お客様が登録企業であり、請求先住所がオーストラリアまたはニュージーランドにある場合、リバースチャージ法方式により、Miro 購入時に GST の支払いが免除される場合があります。

### 納税者 ID の入力方法

チェックアウト時、またはお支払い設定ページで有効なオーストラリアの事業者登録番号（ABN）またはニュージーランドの GST 番号を入力していれば、現在または今後購入する際に GST が請求されることはありません。

会社情報または納税者 ID が記載されていない場合、すべての購入品に GST が請求されます。

#### **チェックアウト時**

チーム規模、支払いサイクル、支払い方法の詳細を選択した後、会社情報を追加することができます（オプション）。

1. **[会社情報の追加]** ボタンをクリックし、表示されるフィールドに必要事項を入力します。国名として「オーストラリア」または「ニュージーランド」を選択する必要があります。
   Taxes_billing_info_formatted.png
   *お支払い設定の会社情報フィールド*
2. **会社名**と**住所**の詳細を入力し、**納税者 ID** フィールドに ABN または GST ID（NZ）を追加します。
   - オーストラリアにお住まいの方は、リバースチャージ方式の対象になるよう GST に登録されている場合、チェックボックスをクリックする必要があります。
   - ニュージーランドのお客様にはこのチェックボックスは表示されません。![taxes_company_info_and_tax_id_formatted.png](../../../../../../docs/plans-billing/billing-and-payments/images/21019592631826_taxes_company_info_and_tax_id_formatted.png)
     *GST 登録ボックスが表示された会社情報*
3. Miro は、提供された納税者 ID が有効であることを確認するために、納税者に自動的にチェックを行うことになりました。納税者 ID が有効な場合、支払いの概要に表示される税額はゼロになります。
   - 無効なIDやチェックボックスが提供されていない場合、GSTが課金されます。![taxes_billing_order_summary_formatted.png](../../../../../../docs/plans-billing/billing-and-payments/images/21019603655442_taxes_billing_order_summary_formatted.png)
     *税別のご注文概要*

### 納税者 ID を更新する方法

1. [[チームの設定]](../../administration/get-started-as-a-miro-admin/01-i-am-a-new-miro-admin.-where-to-start.md) を開きます。支払い管理者になる必要があります。
2. **[支払い]** タブ > **[支払い情報]** に移動します。
3. 会社名と納税者 ID フィールドに入力します。
4. ボックスを選択して、会社が GST に登録されていることを宣言します（オーストラリアのみ）
5. Miro は、提供された納税者 ID が有効であることを確認するために、納税者に自動的にチェックを行います。有効な場合、今後購入する際に税金がかかりません。
   - ID が無効な場合、またはチェックボックスがない場合は、GST が請求されます。
   - ![tax_billing_VAT_ID_formatted.png](../../../../../../docs/plans-billing/billing-and-payments/images/21019592626450_taxes_billing_VAT_ID_formatted.png)タックスIDが購入時に提供されていない場合、Miroは過去の購入履歴を調整しません。*会社のGST登録の申告*

### Miro の GST ID

Miro は、電子的にサービスを提供する非居住者事業者として、簡易登録手続きにより GST に登録されます。そのため、Miro は ATO 参照番号（ARN）を保有しており、非ビジネス顧客への供給品にのみ GST を徴収します。
