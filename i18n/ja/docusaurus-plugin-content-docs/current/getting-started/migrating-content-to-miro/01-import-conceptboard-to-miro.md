Conceptboard のコンテンツをシームレスに Miro に移行し、優れたコラボレーション体験を実現します。これにより、作業を統合し、Miro の充実した機能を活用することができます。

:::warning
インポートしたコンテンツの編集は一方行です。Miro で行った変更は Conceptboard に同期されません。
:::

:::note
Conceptboard の無料版または制限付きライセンスのボードを移行できます。
:::

## Conceptboard のボードをインポート

コンセプトボードのボードを Miro にインポートする前に、コンセプトボードから PDF ファイルとしてエクスポートしたことを確認してください。これを Conceptboard で行うには、エクスポートしたいボードにアクセスし、**ボード** > **エクスポート** をクリックし、**ボードを PDF としてエクスポート** を選択します。

PDFファイルを用意したら、以下の手順に従ってMiroにインポートしてください。

1. Miro **ホーム** ダッシュボードから、**＋新規作成**を選択します。
   > 💡 ボードを開くと、サイドバーから**新規作成**（**+**）メニューにもアクセスできます。
2. **インポート**を選択するか、カーソルを合わせます。
3. **Conceptboard からインポート**を選択してください。モーダルが開き、インポート処理の詳細が表示されます。
4. **参照**を選択してファイル選択画面を開き、PDF ファイルを選択するか、PDF をモーダルにドラッグ＆ドロップします。
5. (オプション) **ボードをスペースに追加する** には、ドロップダウンメニューからスペースを選択します。
6. **ボードをインポート**を選択します。ボードがインポートされていることを知らせる画面が表示されます。インポートが完了し、新しい Miro ボードの準備が整うと、メールで通知が届きます。

## Conceptboard オブジェクトの Miro での表示

Conceptboard と Miro には似たような機能がありますが、インポート後のスタイルや書式のオプションには違いがあるかもしれません。この表は、一般的な Conceptboard のオブジェクトが Miro のオブジェクトにどのように翻訳されるかを比較したものです。

| **Conceptboard** | **Miro** |
| --- | --- |
| コラボレーターと共有 | 🟠手動で再作成可能 |
| コメント | 🟠 手動で再作成可能 |
| コネクター | コネクター |
| ドキュメント | 🟠 手動で再作成可能 |
| 描画 | 線 |
| 画像 | 画像 |
| マインドマップ | 図形とコネクター |
| セクション | フレームと図形 |
| 図形 | 図形と画像 |
| 付箋 | 付箋 |
| テーブル | 表・図形とコネクター |
| テキスト | テキスト |
| 動画とその他の URL | 🟠 手動で再作成可能 |

## 制限

インポートプロセスが可能な限りスムーズであることを目指していますが、Conceptboard からのインポート時に以下の制限事項に注意してください。

- Miro のテキストボックスは、スペースを含めて最大 6,000 文字まで入力できます。それ以上のテキストはトリミングされます。
- 色と不透明度は、最も近いものが Miro に適用されます。
- Miro の付箋は、Conceptboard にあったかもしれない回転やカラーパレットの調整をサポートしていません。

:::note
Conceptboard の移行に関するご質問については、[Miro サポート](../../using-miro/tools/troubleshooting/06-contacting-miro-support.md)にお問い合わせいただくか、Miro のカスタマーサクセス マネージャーに直接ご連絡ください。
:::
