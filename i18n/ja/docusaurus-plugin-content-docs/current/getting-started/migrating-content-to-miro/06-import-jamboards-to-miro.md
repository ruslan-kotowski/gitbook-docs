アイデアやプロジェクトを Jamboard から Miro に簡単に移行できます。ワークフローを補完する Miro のパワフルな機能をご活用ください。

:::warning
インポートしたコンテンツの編集は一方行です。Miro で行った変更は Jamboard には同期されません。
:::

:::note
Jamboard から Miro にコンテンツを移行できるのは、フルライセンスを持つ Miro ユーザーのみです。[Free Restricted](../../enterprise-administration/enterprise-subscription-management/enterprise-licensing/04-free-restricted-license.md)ライセンスのあるMiroユーザーと[ゲスト](../../using-miro/sharing-boards/07-collaboration-with-guests.md)ユーザーは、JamboardをMiroに移行できません。
:::

## Jamboard から Miro へのインポート

このセクションでは、Jamboard ファイルを Miro にインポートし、インポートされた Jamboard ごとに新しい Miro ボードを作成する手順を説明します。

1. Miro **ホーム** ダッシュボードから、**+新規作成**を選択します。
   > 💡 Miro ボードを開いているときは、サイドバーから**新規作成** (**+**) メニューにもアクセスできます。
2. メニューで**インポート**を選択するか、カーソルを合わせます。
3. **Jamboard からインポート** を選択します。モーダルが開き、インポート処理の詳細が表示されます。
4. **Jamboard をインポート**をクリックして続けます。
5. Google アカウントにサインインし、Jamboard による Google ドライブへのアクセスを承認するよう促されます。
6. Google の認証が完了すると、Google ドライブに接続され、すべての Jamboard にアクセスできるようになります。最大 10 個の Jamboard を一度に選択し、**選択**をクリックします。
7. 選択した Jamboard のすべてのコンテンツが編集可能な形式で Miro にインポートされました。インポートされた Jamboard 毎に新しい Miro ボードが自動的に作成されます。
8. インポートしたコンテンツを新しい Miro ボード上で確認し、必要な調整を行ってください。Miro は広範な機能を提供していますが、Jamboard と比べるとスタイルや書式設定のオプションにわずかな違いがあるかもしれません。Miro における Jamboard オブジェクトのマッピングの理解セクションを参照して、潜在的なバリエーションについてのガイダンスを得てください。

## Miro での Jamboard オブジェクトマッピングを理解する

この表は、Jamboard から Miro にオブジェクトがどのようにインポートされ、表現されるかの包括的な比較を提供します。

|  |  |
| --- | --- |
| **Jamboard** | **Miro** |
| ブラシ、蛍光ペン、マーカー | 図形またはステンシル |
| コネクター | コネクター |
| 絵文字 | 画像 |
| フレーム | フレーム |
| 画像 | 画像 |
| ページ | 画像 |
| 図形 | 図形またはステンシル |
| 付箋 | 付箋 |
| テキスト | テキスト |

## 制限

Jamboard からインポートする際には、いくつかの機能の違いや制限に注意することが重要です。

- Miro のテキストボックスは、スペースを含めて最大 6,000 文字まで入力できます。Jamboard のテキストオブジェクトからの追加テキストはトリミングされます。
- Miro の付箋は、Jamboard とは異なり、回転、カラーパレットの調整、テキストの箇条書きに対応していないため、いくつかの視覚的な違いが生じる場合があります。

## Jamboard デバイス移行の準備をする

Google が Jamboard デバイスの提供を終了するにあたって、Miro を使った共同作業を継続するためのハードウェアオプションとこの移行に関する重要な情報をご案内します。

2024 年 12 月より、Google は Jamboard 55 デバイスのサポートを終了します。コラボレーションを継続するには、2024年時点で Miro をサポートしている Google Meet Series One Board 65 および Desk 27 デバイスへの移行をご検討ください。

:::tip
Jamboard の移行に関するご質問は、[Miro サポート](../../using-miro/tools/troubleshooting/06-contacting-miro-support.md)にお問い合わせいただくか、Miro のカスタマーサクセス マネージャーに直接お問い合わせください。その他の Jamboard の移行に関するお知らせを希望される方は、[登録フォーム](https://miro-survey.typeform.com/to/f5EQKroq?typeform-source=www.google.com)に連絡先をご記入ください。
:::
