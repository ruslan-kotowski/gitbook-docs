ダイアグラムを Draw.io から Miro に簡単に転送して、1 つのツールでコラボレーションを始めましょう。インポートしたダイアグラムはすべて機能するため、Miro 内で必要に応じて編集、色付け、移動、デザイン変更が可能です。

:::note
現時点でインポートに対応しているのは Lucidchart、MS Visio、Draw.io のみです。ダイアグラムは新規ボードのみにインポートでき、既存のボードにはインポートできません。
:::

:::warning
インポートされたダイアグラムの編集は一方向のみです。Miro で行った変更は、元の Draw.io ダイアグラムには反映されません。Miroで直接新たに編集可能な Draw.io ダイアグラムを作成するには、[draw.io ダイアグラムアプリ](../../using-miro/formats/diagramming/03-draw.io-diagrams-by-miro.md)を使用します。
:::

## 新しいボードに Draw.io ダイアグラムをインポートする

以下の手順で、単一の Draw.io ダイアグラムを新しい Miro ボードにインポートしてください。

1. Draw.io で、ダイアグラムを `.vsdx` ファイルとしてエクスポートします。
2. ダイアグラムをインポートしたい Miro ボードに移動します。
3. 左側の作成ツールバーで **図形と線** をクリックし、**その他の図形** を選択し、**ダイアグラムのインポート** アイコンを**ダイアグラム作成**パネルの右上にあるアイコンをクリックします。
4. **新しいボードとしてダイアグラムをインポート**するダイアログボックスで、`.vsdx` ファイルをドラッグアンドドロップするか、**ファイル選択** ボタンをクリックして `.vsdx` ファイルに移動します。
5. ファイルを選択したら、**インポート**をクリックします。
6. インポートプロセスが完了したら、**ボードに移動**をクリックして、新しいボードにあなたのダイアグラムを開きます。

## ダッシュボードから draw.io ダイアグラムを一括インポート

複数の Draw.io ダイアグラムを一度に Miro のダッシュボードからインポートすることも可能です。インポートされた各ダイアグラムは、元のファイル名に基づいて新しい Miro ボードが作成されます。なお、複数のダイアグラムをインポートできるのは、ダッシュボードからのみとなります。

1. Miro のダッシュボードに移動します：`https://miro.com/app/dashboard/`。
2. 右上から**+ 新規作成**を選択します。
3. **インポート**を選択し、次に**ダイアグラムをインポート**を選択します。
   **ダイアグラムをインポート**モーダルが開きます。
4. `.vsdx`ファイルをモーダルにドラッグするか、**ファイルを選択**リンクを使用します。
5. インポートが完了したら、**完了**をクリックしてダッシュボードに戻るか、**すべてのボードを開く**をクリックして、インポートされたダイアグラムの各ボードを起動することができます。各ボードはブラウザーの個別のタブで開かれます。
