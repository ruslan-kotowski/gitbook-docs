ダイアグラムを MS Visio から Miro に簡単に転送し、1 つの統一されたツールでコラボレーションを始めましょう。

インポートされたダイアグラムはすべての機能が利用でき、必要に応じて編集、色付け、移動、デザイン変更が可能です。

:::warning
インポートされたダイアグラムの編集は、一方向のみです。Miro で行った変更は Visio には反映されません。
:::

## ひとつの Visio ダイアグラムを新しい Miro ボードにインポートする

以下の手順に従って、個別の Visio 図をインポートしてください。インポートされたダイアグラムは新しい Miro ボードを作成します。

1. Visio で、エクスポートしたいダイアグラムを開きます。
2. **ファイル** メニューを選択し、**名前を付けて保存** を選択します。場所を選択して、ファイルを`.vsdx`形式で保存します。
3. インポートを開始したい Miro ボードに移動します。これはどのボードでも構いません。インポートすると新しいボードが作成されます。
4. 左側の作成ツールバーで、**図形** > **さらに多くの図形** を選択し、ダイアグラム用図形ライブラリ パネルの右上にある **ダイアグラムをインポートする** アイコンを選択します。
5. 表示されたダイアログボックスで、`.vsdx` Visio ファイルをドラッグ＆ドロップするか、**ファイルを選択**ボタンをクリックして、システムからファイルを選択してください。
6. **インポート**を選択します。
   インポートプロセスが完了すると、**ファイルがインポートされました**ダイアログが表示されます。
7. **ボードに移動**をクリックして、インポートされたダイアグラムを含む新しい Miro ボードを開きます。

## Visio ダイアグラムを一括インポートする

また、ダッシュボードから Miro に複数の Visio 図を同時にインポートすることもできます。各ダイアグラムは、元のファイル名が付けられた新しい Miro ボードにインポートされます。

1. [Miro のダッシュボード](https://miro.com/app/dashboard/)に移動します。
2. **+ 新規作成** > **インポート** > **ダイアグラムをインポート** を選択します。
3. `.vsdx` ファイルを指定された領域にドラッグするか、**ファイルを選択**リンクを使用して複数の Visio ダイアグラムを選択してください。なお、インポートする前にファイルを削除することができます。
4. **ファイルをインポート**を選択します。
   インポートプロセスが完了すると、**ファイルがインポートされました**というダイアログが表示されます。
5. **完了**を選択します。

各ダイアグラムのために、元のファイル名を付けた新しいボードが作成されます。
