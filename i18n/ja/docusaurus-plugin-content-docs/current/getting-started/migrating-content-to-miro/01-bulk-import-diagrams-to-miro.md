ソースアプリケーションからダイアグラムを PDF または VSDX 形式で一括インポートできます。

:::note
一部のソースアプリケーションでは、1つのファイル形式のみがサポートされています。確認するにはインポートファイル形式のサポートを参照してください。
:::

## ダイアグラムを Miro に一括インポートする方法

ダイアグラムを Miro にインポートするには、ソースアプリケーションからファイルを PDF または VSDX 形式にエクスポートしていることを確認してください。その後、以下の手順を完了してください。

1. Miro ダッシュボードで、図をインポートしたいスペースの**新規作成**（**+**）をクリックします。
   ![](../../../../../../docs/getting-started/migrating-content-to-miro/images/32654520716690_image.png)
2. **インポート** ＞ **\{source\}からインポート**をクリックします。例：**Muralからインポート**
   **\{source\}からインポート**のモーダルが開きます。
3. 画面の指示に従います。
4. （オプション）インポート先のスペースを変更するか、**+**ボタンをクリックして新しいスペースを作成します。
5. **インポート*****x*** **ファイル**をクリックします。

## ファイルタイプインポートのサポート

| 元 | ファイルタイプ |
| --- | --- |
| Conceptboard | PDF、VSDX |
| Lucidchart | PDF、VSDX |
| Lucidspark | PDF、VSDX |
| Mural | PDF |
| Visio | VSDX |
