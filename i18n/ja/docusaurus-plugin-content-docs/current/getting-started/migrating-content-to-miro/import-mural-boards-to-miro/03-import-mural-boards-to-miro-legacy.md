> **ユーザー:**Mural と Miro の両方に編集権限を持っているユーザー
> **プラン：**Free、Starter、Business、Education、Enterprise の各プラン（コピー&ペースト用）；Starter、Business、Education、Enterprise の各プラン（PDF経由での一括インポート用）
> **プラットフォーム：**ブラウザー、デスクトップ

Mural から Miro にコンテンツをシームレスに移行して、新しい環境でおなじみのコンテンツを使いながら共同作業を続けることができます。このガイドでは、Mural ボードをインポートする 2 つの方法を説明します: コンテンツを直接コピー＆ペーストする方法と、PDF ファイルを使用した一括インポート機能を利用する方法です。

:::warning
インポートされたコンテンツの編集は一方向のプロセスです。Miro で行った変更は Mural には同期されません。
:::

:::note
フルライセンスまたは制限付き無料ライセンスの Mural ボードを、これらの方法を使用して Miro に移行できます。
:::

## Mural のコンテンツをコピーして貼り付けてインポートする

Mural ボードからコンテンツを手動でコピーして、Miro ボードに貼り付けることができます。この方法は、個々のボードまたは特定のコンテンツ選択の移行に適しています。

:::note
ソース Mural ボードとターゲット Miro ボードの両方に編集アクセスがあるユーザーは、このアクションを実行できます。
:::

1. エクスポートしたいコンテンツを含む Mural ボードを開いてください。
2. 移動したいコンテンツをすべて選択します。**Ctrl + A**（Windows）または**Command + A**（Mac）のキーボードショートカットを使用して、ボード上のすべてを選択できます。
3. 選択したコンテンツを右クリックして**コピー**を選択するか、キーボード ショートカットの**Ctrl + C**（Windows）または**Command + C**（Mac）を使用します。
4. 既存の Miro ボードを開くか、新しいボードを作成して、コンテンツをインポートしたい場所を選びます。
5. Miro ボードの空白領域を右クリックして、**貼り付け**を選択するか、キーボード ショートカット **Ctrl + V**（Windows）または **Command + V**（Mac）を使用します。
6. Miro ボード上のインポートされたコンテンツを確認してください。調整が必要になる場合があります。Mural と Miro の間でスタイルや書式設定のオプションに違いがあるためです。オブジェクトのマッピングに関する詳細は、Mural オブジェクトの Miro での表示（コピー＆ペースト）セクションを参照してください。

## PDFエクスポートを使用して、Mural ボードを一括でインポートする

複数の Mural ボードを移行するには、Miro の一括インポート機能を使用できます。この機能は、Mural からの PDF エクスポートを受け付けます。

> この一括インポート機能は、Starter、Business、Education、Enterprise プランのユーザーが利用できます。

1. エクスポートしたい Mural ボードを開いてください。
2. 各 Mural ボードで、**ダウンロード**をクリックし、ボードを**PDF**ファイルとして保存します。
3. Miro のダッシュボードを開きます。
4. 右上隅で、**＋新規作成** ボタンをクリックし、**インポート** を選択します。
5. **Mural からインポート** をオプションから選択します。
6. 表示された画面で、**参照** をクリックしてシステムのファイル選択画面を開き、PDF ファイルを選択するか、PDF ファイルを画面に直接ドラッグ & ドロップします。
7. (オプション) **ボードをスペースに追加する** ドロップダウンメニューを使用して、インポートしたボードを追加するための Miro の[スペース](../../../using-miro/spaces/01-spaces.md)を選択します。スペースを選択しない場合、ボードはデフォルトでメインのチームエリアに追加されます。
8. **ボードをインポート**ボタンをクリックして、インポートプロセスを開始します。
9. ボードがインポートされていることを知らせる画面が表示されます。インポートが完了し、新しい Miro ボードの準備が整うと、メールで通知が届きます。
10. インポート後、新しい Miro ボードのコンテンツを確認してください。Mural オブジェクトの Miro での表示（一括インポート）セクションを参照して、Mural オブジェクトの翻訳方法について確認してください。

## 制限と考慮事項

Miro はインポートプロセスをできるだけスムーズにするよう努めていますが、Mural からコンテンツを移行する際の次の制限事項をご確認ください。

- **テキストの制限:**Miro のテキストボックスは、スペースを含めて最大 6,000 文字まで入力できます。この制限を超えたテキストはインポート時にトリミングされます。
- **付箋の図形:**Mural の丸い付箋は Miro で四角い付箋に変換されます。
- **色と透明度:**Mural の色と不透明度は、Miro の利用可能な最も近い色にマッピングされます。いくつかのビジュアルの違いが発生することがあります。
- **付箋の書式設定：**Miro の付箋は現在、標準セットを超えたカラーパレットのカスタム調整や、付箋内でのテキストの箇条書き、回転をサポートしていません。

### Mural と Miro のコンテンツ構成を比較

Mural と Miro におけるコンテンツ整理の方法の違いを理解することで、移行をより効果的に計画できます。

|  |  |
| --- | --- |
| **ミュラル要素** | **Miro の同等物** |
| ワークスペース：  - 会社の管理者が作成 - チームの管理者が管理 | チーム：  - 会社の管理者が作成 - チームの管理者が管理 |
| Rooms：  - Mural ワークスペース内のユーザーが作成 - ユーザーが管理 | スペース：  - Miro チーム内のユーザーが作成 - ユーザーが管理 - 階層化不可 |
| フォルダー：  - Mural ワークスペース内のユーザーが作成 - ユーザーが管理 - Rooms に階層化可能 | プロジェクト（組織に使用できますが、Miro スペースがチーム内の主要なコンテナです）。Miro には、Mural の Rooms 内のネストされたフォルダーに直接対応するものはありません。 |
| 壁画 (ボード):  - Mural ワークスペース内のユーザーが作成 - ユーザーが管理 | ボード：  - Miro チーム内のユーザーが作成 - ユーザーが管理 |
