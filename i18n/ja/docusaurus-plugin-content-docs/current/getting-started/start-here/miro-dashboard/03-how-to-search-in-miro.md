Miro の検索機能を使って、ボードやスペースを簡単に見つけることができます。

:::tip
特定のボードを検索する方法については、[こちらの記事](../../../using-miro/working-on-the-board/19-searching-text-on-the-board.md)をご覧ください。
:::

## 検索機能の使い方

[ダッシュボード](https://miro.com/app/dashboard/)でボードやスペースを見つけるには、ページ左パネルの上部にある**検索バー**をクリックするか、**Ctrl + E***（Windowsの場合）*/**Cmd + E***（Macの場合）*を押してください。ボードやスペース名を入力し始めてください。最近開いたボードやスペースが検索バーの下に表示されます。現在のチームで共有されているすべての一致項目が表示されます。

特定のボードについて詳細を確認したい場合は、

1. ボード名の横にある**三点リーダー**(**...**)アイコンをクリックします。
2. **ボードの詳細**を選択します。
   モーダルが開き、以下の情報が表示されます。
   1. ボードの機密分類
   2. ボードの所有者
   3. ボードの説明
   4. ボードの作成日
   5. 最終更新日
   6. ボードの場所（チーム名 > スペース名）

**所有者**や**スペース**で検索を絞り込むことができます（Free プランでは所有者のみで検索できます）。フィルターを適用するには、**すべてのフィルター**をクリックするか、検索バーの下のドロップダウンリストで所有者を選択します。フィルターを解除するには、**X**をクリックします。

検索ウィンドウには、現在所属しているチームに基づいた検索結果が表示されます。

また、[共有](../../../using-miro/sharing-boards/03-sharing-boards-and-inviting-collaborators.md)、名前の変更、[ボードの移動](../../../using-miro/managing-boards/04-how-to-move-a-board.md)などの主要な操作を検索結果から直接メニューを通じて実行できます。ボード名の横にある**三点リーダー** (**...**) をクリックすると、すべてのオプションを含むメニューが表示されます。

*![search-three-dots-menu.png](../../../../../../../docs/getting-started/start-here/miro-dashboard/images/21262219090578_search-three-dots-menu.png)
検索結果に表示されるボードのコンテキストメニュー*

:::tip
この機能と検索フィルターを併用すれば、ボードの整理を合理化することができます。例えば、ボードを所有者で絞り込むことで、以前より迅速にチームやプロジェクトに移動させることができます。
:::

:::tip
[Chrome の Miro 専用の検索拡張機能](https://miro.com/marketplace/chrome-search/?backUrl=%2Fmarketplace%2F)を自由にインストールできます。拡張機能を追加した後、ブラウザーのアドレスバーに「M*iro*」と入力し、**Tab**キーを押します。この拡張機能により、アドレスバーからすぐに Miro ボードをクイック検索することができます。
:::

## 高度な検索

> **利用可能なプラン：**Education、Starter、Business、Enterprise プラン

Education、Starter、Business、Enterprise プランのユーザーは、ボードおよびスペースのタイトルや説明、ボード内のウィジェット、コメント、付箋に含まれる特定の単語やフレーズを検索バーで検索することができます。

Business または Enterprise プランをご利用の場合、ダッシュボードからすべてのチームを検索でき、組織全体で関連コンテンツを見つけることが可能です。

検索ウィンドウには、検索した単語やフレーズを含むすべてのコンテンツアイテムが表示されます。**コンテンツ** セクションの下にある各アイテムをクリックすると、検索結果が表示され、ボード名の左側にある矢印をクリックすると、一致するリストが展開されます。

このセクションで特定の検索結果をクリックすると、ボードが開かれてその検索結果に移動するので、検索結果を探す手間が省けます。
