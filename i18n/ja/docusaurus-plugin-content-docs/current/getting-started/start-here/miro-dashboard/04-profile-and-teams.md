## プロフィールとチームの違い

**プロフィール**は、ユーザーのメールアドレスです。招待された、または自分で設定したすべてのチームが、プロフィールにリンクしています。

**Teamは**、チームメンバーがコラボレーションしたり、ボードや[スペースを](../../../using-miro/spaces/01-spaces.md)作成・保存したりできるスペースです。Miro ユーザーは、複数のチームのメンバーになることができます。

## チームのアップグレード

チームを[アップグレード](../../../plans-billing/manage-your-subscription-and-plan/03-upgrade-your-plan.md)すると、ユーザーとそのチームメンバーは、チームに保存されているすべてのボードの有料機能にアクセスできるようになります。なお、アップグレードしたサブスクリプションは**チーム**にリンクされるのであり、プロフィールにリンクされるのではありません。したがって、ユーザーの他のチームは [Free プラン](../../../plans-billing/miro-plans/09-free-plan.md)のままということもあります。

## Miro チーム間の切り替え方法

Miroチームを切り替えるには、ホームまたはスペースダッシュボードから左上の現在のチーム名を選択します。チームピッカーのドロップダウンメニューが開きます。

![](../../../../../../../docs/getting-started/start-here/miro-dashboard/images/33913490012562_image.png)

*Miroのチームピッカーは、チームの整理、固定、切り替えを可能にします。*

チームピッカーで、「**すべてのチーム」の**下にある組織にカーソルを合わせると、その組織に所属するすべてのチームが表示されます。チームをピン留めすれば、より素早くアクセスできます。

チームを**ピン留め**するには、チームにカーソルを合わせ、ピン留めボタンを選択します。チームピッカーでチームにカーソルを合わせると、**チームメンバーや** **チーム設定にも**アクセスできます。

:::tip
**Pinned Teamの**下にあるチームをドラッグして並べ替えることができます。
:::

:::note
ピン留めされたチームおよびピン留めされたチームの順番は、クライアント上に保存され、デバイス間で持続しません。
:::
