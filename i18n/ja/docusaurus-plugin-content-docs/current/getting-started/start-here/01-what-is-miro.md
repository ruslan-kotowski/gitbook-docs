[Miro](https://miro.com/index/) は、あらゆる規模の分散型チームが共に夢を描き、デザインし、未来を想像できるようになる、イノベーションを目指したオンライン ワークスペースです。

Miro を利用して、コラボレーション機能をフル活用し、職域を超えたチームワークを円滑にし、[会議やワークショップ](../feature-intros/03-miro-for-workshops-meetings.md)を開催しましょう。[ビデオチャット](../../using-miro/facilitation-tools/18-video-chat.md)、[プレゼンテーション](https://help.miro.com/hc/articles/360017731073-Presentation-Mode)、[共有](../../using-miro/sharing-boards/03-sharing-boards-and-inviting-collaborators.md)、および[その他多くの機能](../../using-miro)を活用しましょう。

デザイン、開発、エンジニアリング チームに力を与え、プラットフォーム上ですべてをリアルタイムで実現し、連携と革新を促進します。コンセプトの作成、[ユーザーストーリーのマッピング](../../using-miro/advanced-tools/07-user-story-mapping.md)やカスタマージャーニー、またはロードマップの計画を簡単に行うことができ、お客様に適切な製品を届けることに集中できます。
