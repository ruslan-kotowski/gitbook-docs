Miro のボードは、アイデアを視覚化し、個人またはチームでプロジェクトの作業を行うことができるオンライン ワークスペースです。

Miro に[参加する](../02-how-to-register-with-miro.md)と、最初のボードが自動的に作成され、自分の Free チームまたは招待されたチームに保存されます。ダッシュボードで「My First Board」というタイトルのボードを確認できます。

## Miro ボードを作成する方法

新しいボードは、ダッシュボードまたはブラウザーのアドレスバーから直接、何枚でも作成できます。

### ダッシュボードからボードを作成

ダッシュボードからボードを作成するには、次の手順に従ってください：

1. ダッシュボードを開きます。
   1. 複数のチームに属している場合は、ボードを保存したいチームを選択します。
   2. 特定のスペースにボードを作成するには、そのスペースを開きます。
2. **+ 新規作成**をクリックします。
   メニューが開きます。
3. **ボード**をクリックします。
   新しいボードが作成されます。

### テンプレートからボードを作成

テンプレートからボードを作成するには、次の手順に従ってください：

1. ダッシュボードで**+ 新規作成**をクリックします。
   メニューが開きます。
2. **テンプレートを検索**をクリックします。
   テンプレートピッカーが開きます。
3. 関連するテンプレートを閲覧または検索します。
4. **テンプレートを使用**をクリックして、テンプレートで新しいボードを開きます。または、**プレビュー**をクリックしてテンプレートの詳細情報を表示します。
5. テンプレートのプレビューから、**テンプレートを使用**をクリックして、テンプレートで新しいボードを開きます。

### ブラウザーのアドレスバーからボードを作成

ブラウザーのアドレスバーからボードを作成するには、次の手順に従ってください：

1. ブラウザーのアドレスバーに**miro.new**と入力します。
   新しいボードがブラウザーウィンドウに開きます。
2. 複数のチームに所属している場合は、[チームを切り替える]をクリックして、ボードを保存したいチームを選択します。
3. ログインしていない場合、新しいボードが開く前にログインを求められます。

## トラブルシューティング：ボードを作成できない理由は？

ボードを作成できない理由は主に3つあります：チームメンバーではない、正しいライセンスタイプを持っていない、またはチーム設定が原因です。

**チームのメンバーではありません**

- チームのゲストであるため、新しいコンテンツを作成することができません。ボード所有者にチームに参加するよう依頼するか、ダッシュボードからチームへの参加を試みてください。
- Miro チームのメンバーではありません。自分自身の Miro チームを作成するには、ダッシュボードのサイドバーにあるプラスアイコンをクリックします。
- チームに招待はされていませんが、ボードには招待されています。そのチームで新しいボードを作成するには、「参加をリクエスト」をクリックします。

**誤ったライセンスタイプを使用しています**

Enterprise プランのメンバーですが、制限付き無料ライセンスであるため、ボードを作成することができません。ボードを作成するには、編集権限をリクエストし、会社の管理者にフルライセンスに変更するよう依頼してください。

**チーム設定が原因です**

Enterprise プランチームのメンバーですが、会社の管理者がチーム設定でコンテンツの作成を制限しているため、ボードを作成することができません。ボードを作成するには、会社の管理者にコンテンツの作成権限を付与するよう依頼します。

## よくある質問

**ボードを複製する方法を教えてください。**

左上のツールバーの**メインメニュー**アイコンをクリックし、次に**ボード**をクリックし、サブメニューで**コピーを作成**をクリックします。

**詳細情報：**[ボードを複製する方法](../../../using-miro/managing-boards/03-how-to-duplicate-a-board.md)をご覧ください。

**あるボードのコンテンツを別のボードにコピーできますか？**

はい、[コピーしたいコンテンツを選択し](../../../using-miro/working-on-the-board/10-working-with-objects.md)、Windows の場合は Ctrl + C/Ctrl + V、Mac の場合は Cmd + C/Cmd + V を使用します。

**ボードを削除する方法を教えてください。**

左上のツールバーの**メインメニュー**アイコンをクリックし、次に**ボード**をクリックし、サブメニューで**削除**をクリックします。
