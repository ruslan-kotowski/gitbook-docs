Miro にサインインする際、メールアドレスと認証方法を記憶することで、次回以降のサインインをより迅速に行うことができます。過去 3 回のログインプロフィールをこの方法で記憶することができます。

1. ログインの際、メールアドレスを入力した後、**認証情報を記憶する**のチェックボックスにチェックを入れてください。![remember-me-checkbox.png](../../../../../../docs/getting-started/start-here/images/20716822838290_remember-me-checkbox.png)*ログインの際、[ログイン情報を記憶する]を選択します*
2. Miro に再ログインすると、最近記憶した 3 つのログインプロフィールが保存されているのが確認できます。3 つのプロフィールが追加された後に、さらに 1 つのプロフィールを記憶させた場合、最も古いプロフィールは失われます。
3. ご希望のプロフィールをクリックしてログインを完了してください。![remember-me.gif](../../../../../../docs/getting-started/start-here/images/20716818238994_remember-me.gif)*記憶されたプロフィールを使った Miro へのログイン*

記憶されたサインインプロフィールを忘れるには:

1. **三点リーダー**（![icon-main.svg](../../../../../../docs/getting-started/start-here/images/26092786370706_icon-main.svg)）アイコンをプロフィールの横でクリックします。
2. **この方法を忘れる**を選択します。![forget-this-account.gif](../../../../../../docs/getting-started/start-here/images/26092786370962_forget-this-account.gif)*記憶されたサインイン方法を忘れる*
