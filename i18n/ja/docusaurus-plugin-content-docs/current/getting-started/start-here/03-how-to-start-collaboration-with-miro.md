[Miroは](https://miro.com/index/)、デジタル付箋を使ったブレインストーミングからアジャイルワークフローの計画や管理まで、分散したチームが効果的に共同作業を行えるようにするオンライン共同ワークスペースです。

手始めに、[新しいボードを作成](your-first-board/01-create-a-miro-board.md)し、[フレームを](../../using-miro/essential-tools/07-frames.md)追加します。すべてのボードは自動的に保存されます。それぞれのボードは無限大に広がっており、フレームはページのような働きをします。ゼロから始める必要はありません。どんどん増えている Miro のライブラリーから既成の[テンプレート](your-first-board/04-templates.md)を選択するだけで良いのです。フレームを使用してボードを簡単に移動し、さまざまな種類のコンテンツを追加することができます。

同僚や離れたところにいるユーザーを[招待](../../using-miro/sharing-boards/03-sharing-boards-and-inviting-collaborators.md)し、リアルタイムでブレインストーミングやアイデア出しセッションを開いたり、タイムゾーンが異なる相手と自分のペースで仕事をしたりすることができます。ボードを共有するには、右上にある [**共有**] ボタンをクリックします。

Miro ボードを共有するオプション

[コメント ディスカッション](../../using-miro/facilitation-tools/asynchronous-tools/01-comments.md)に参加すると、メールやブラウザ、または企業の [Slack](../../using-miro/managing-your-profile/02-miro-notifications.md) から重要なコメントや[メンションの](../../using-miro/facilitation-tools/01-@mentioning-people-on-the-board.md)[通知が届きます](../../integrations-apps/more-integrations/14-slack.md)。

Miro でコラボレーションを開始する方法についての詳細は、以下の役立つリソースをご確認ください：

- [ツール](../../using-miro/tools)
- [ボード上の作業](../../using-miro/working-on-the-board)
- [ボードの共有](../../using-miro/sharing-boards)
