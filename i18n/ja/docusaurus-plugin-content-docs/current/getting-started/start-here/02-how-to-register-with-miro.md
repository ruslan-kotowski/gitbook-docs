Miro への登録が済んだら、すぐにチームとボードを作成し、他のユーザーをプラットフォームに招待することができます。Miro への登録は無料です。

## 登録方法

Miro への招待メールを受信したら、メール内の招待を承諾します。Miro のパスワードを設定するよう求められ、設定後はチームやボードを登録するページにリダイレクトされて、すぐにコラボレーションを始めることができます。

招待メールを受信していない場合は、メールアドレス、Goolge、Slack、Office 365、Apple ID、Facebook で Miro に登録してから、新しいチームを作成するか、既存のチームに参加することができます。

メールアドレス サードパーティー アカウントによるログイン SSO

1. [登録ページ](https://miro.com/signup/)を開きます
2. **名前**、**仕事用のメールアドレス**、**パスワード**を入力フィールドに入力します
3. **Miro の利用規約とプライバシーポリシー**を確認し、チェックボックスにチェックを入れます
4. 最新の製品情報を受け取るには、**[Miro のニュースと最新情報を受け取る]** のチェックボックスにチェックを入れます
5. **[今すぐ登録する]** をクリックします

- 所属する組織が[シングルサインオン](../../using-miro/tools/troubleshooting/10-i-can't-log-in-via-sso.md)を使用している場合、SSO 経由でのログインにリダイレクトされます。ID プロバイダーの認証情報を使用して登録します
- すでにメールアドレスが Miro に登録されている場合、それに応じたメッセージが表示されます。メールアドレスを使用して [Miro にログイン](https://miro.com/login/)し、プロフィールにアクセスしてください。パスワードを忘れた場合は、[パスワードのリセット](../../using-miro/managing-your-profile/05-how-to-change-your-password.md)が可能です。パスワードが回復できない場合は、[パスワードのリセットメールの問題](../../using-miro/tools/troubleshooting/12-issues-with-confirmation-code-or-password-reset-emails.md)をご覧ください。

4. メールアドレスが初めて Miro で使用するもので、SSO 経由でのログインが不要な場合、確認コードを送信するページにリダイレクトされます

*![signing_up_with_email_to_Miro.gif](../../../../../../docs/getting-started/start-here/images/21017429154962_signing%20up%20with%20email%20to%20Miro.gif)
メールアドレス確認ページ*

5. 受信トレイで確認コードが記載されたメールを見つけます。メール内の **[メールアドレスを承認する]** ボタンをクリックするか、確認コードの承認ページで確認コードを入力します。

*![complete_registration_email.jpg](../../../../../../docs/getting-started/start-here/images/21017429149714_complete%20registration%20email.jpg)
認証コード*

確認コードが受信できない場合は、次の記事のトラブル対応手順をご覧ください：[承認コードやパスワードリセットのメールに関する不具合](../../using-miro/tools/troubleshooting/12-issues-with-confirmation-code-or-password-reset-emails.md)。

7 日以内にメールアドレスを認証しないと、未記入のプロフィールは削除されます。

既存の **Google、Facebook、Slack、Office 365** のアカウントや **Apple ID** で Miro に登録すれば、登録プロセスをスピードアップできます。

1. [登録ページ](https://miro.com/signup/)を開きます
2. 登録に使用するサービスを選択して、ログインします

![third-party_sign-in.jpg](../../../../../../docs/getting-started/start-here/images/21017416082706_third-party%20sign-in.jpg)
*サードパーティーのアカウントによるログイン*

:::note
Apple ID を使って最初に Miro に登録するときは、メールアドレスを共有するか、非表示にするかを選択することができます。**[メールを共有]** を選択すると、Apple ID のメールアドレスが Miro のプロフィールのメールアドレスとして使用されます。**[メールを非表示]** を選択すると、プロフィールに使われる新しいメールアドレスが作成され、Miro にログインする際はこのメールアドレスを使用しなければなりません。Miro の通知は、Apple ID に関連づけられたメールアドレスに届きます。Apple ID による Miro への登録は、iPhone（iOS 13 以降）、iPad（iPadOS 13 以降）、ウェブアプリ、[デスクトップアプリ](../apps-for-devices/05-desktop-app.md)から利用できます。
:::

会社が会社のドメインをメールアドレスに持つユーザーに対して Miro の[シングルサインオン](../../enterprise-administration/security-integrations/single-sign-on-sso/09-single-sign-on-sso.md)を設定している場合は、SSO のログインページに自動的にリダイレクトされます。ユーザーはそのページでID プロバイダーの認証情報を入力し、Miro の利用を継続することができます。このプロセスで問題が発生した場合は、こちらの記事をご覧ください：[SSO 経由でログインできない](../../using-miro/tools/troubleshooting/10-i-can't-log-in-via-sso.md)。

## Miro のチームに作成または参加する

Miro のチームとは、ユーザーがボードやプロジェクトを作成、保存、共有するためのスペースです。

プロフィールの登録前に Miro チームに招待またはプロビジョニングされた場合、サインアップ後すぐにチームにリダイレクトされ、同僚や友人とコラボレーションを始めることができます。追加のチームを作成する必要がある場合は、次の記事をご覧ください：[Miro でチームを作成する方法](miro-dashboard/02-how-to-create-a-team-in-miro.md)。

どのチームにも招待されていない状態で初めてサインアップするときは、チームを作成するか、会社のチームに参加するよう勧められます。

最初のチームを作成すると、すぐにチームメンバーを追加できます。

![invite_teammates.jpg](../../../../../../docs/getting-started/start-here/images/21017416083986_invite%20teammates.jpg)
*Miro チーム作成時にチームメンバーを招待*

[ドメイン内](../../administration/team-management/02-manage-team-signup-mode.md)のユーザーが参加できるチームがある場合、ユーザーはそのチームに参加するか、チームへのアクセスをリクエストすることができます。このリクエストは管理者に送信されます。管理者の承認を待つ間、自分のチームを作成することもできます。

![Join_other_teams.jpg](../../../../../../docs/getting-started/start-here/images/21017429153554_Join%20other%20teams.jpg)
*Miro 登録時、会社のチームに参加する、または新しいチームを作成するオプション*

## プロフィールの詳細を追加する

プロフィールを作成したら、[プロフィールの設定](../../using-miro/managing-your-profile/01-profile-settings.md)に移動し、写真やプロフィールの情報を追加できます。

:::note
プロフィール上でアクティビティーが 2 週間なかった場合、セキュリティー上の理由により、自動的に Miro からログアウトされます。
:::
