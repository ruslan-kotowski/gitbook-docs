Webex ボードで Miro を使用すれば、ホワイトボードでの活動を活性化させることができます。Miro アプリを設定し、簡単にコラボレーションを開始し、アイデアを提示し、より大きなものを創り上げましょう。

Webex ボードに Miro アプリを追加するには、コントロールハブから直接行う方法と、UI 拡張管理機能で行う方法の 2 つがあります。

### コントロールハブからアプリを追加する

コントロールハブからアプリを追加するには、**[デバイス]** に移動し、対象のデバイスを開きます（ここでは、コントロールハブに登録済みのデバイスを選択します。Webex ボードや Desk デバイスをアクティブにする方法については、[こちらの Webex ヘルプセンターの記事](https://help.webex.com/n3hi0z8/Activate-a-Cisco-Webex-Room-or-Desk-Device-or-Webex-Board)をご確認ください。）。

devices_on_Webex.jpg
Webex コントロールハブでデバイスを開く

スクロールダウンし、**[Web Apps]（ウェブアプリ）** をクリックします。

Web_apps.jpg
Webex コントロールハブで Web アプリ（ウェブアプリ）にアクセスする

新しいウェブアプリの追加を選択します。Webex ボードのホーム画面のウェブアプリアイコンの下に表示されるアプリ名を入力します。URLを入力してください（例えば、Miro.com/displaysと入力すると、インタラクティブ・ディスプレイに最適化された起動画面とエクスペリエンスが表示されます）。「Icon URL（アイコン URL）」の入力欄に[このリンク](https://miro.com/static/images/awwapp-miro/miro_logo_rounded.png)を入力して、カスタムアイコンを追加します（オプション）。入力が終了したら、[追加] > [保存] をクリックします。

Adding_the_Miro_web_app_from_Webex_Control_Hub.gif
*/span>Webex コントロールハブで Miro のウェブアプリを追加する*

デバイスは自動的に同期され、Webex ボードのホーム画面に Miro のアイコンが表示されます。

### UI 拡張管理機能でアプリを追加する

デバイスのウェブポータルを開き、**「UI 拡張管理機能」**に移動します。

extensions_editor.jpg
UI 拡張管理機能を開く

次に、拡張機能のパネルで **[New]（新規）**を選択し、ウェブアプリの下の **[追加]** をクリックします。

Adding_a_new_Web_App_within_UI_Extensions_Editor_.gif
*UI 拡張管理機能で*新しいウェブアプリを追加する

左サイドバーで ID、名前、URL を入力します。[このリンク](https://miro.com/static/images/awwapp-miro/miro_logo_rounded.png)を**ウェブアプリアイコンの URL** の入力欄に追加して、カスタムアイコンを追加します（オプション）。通話中に Miro アプリを利用できるように **[Always]（常時）** を選択します。トップバーの矢印ボタンをクリックして設定を終了します。

Adding_the_Miro_app_with_UI_Extensions_Editor_on_a_Webex_board.gif
UI 拡張管理機能を使って Webex ボードにで Miro アプリを追加する

:::note
[Webex ヘルプセンター](https://help.webex.com/h47w6/Add-Web-Apps-on-Webex-Boards-and-Desk-Pros)で Webex ボードにウェブアプリを追加する方法について詳しく学ぶことができます。
:::

### Webex ボードで Miro を使用する

Webex ボードのホーム画面に Miro アイコンが表示されたら、クリックして Miro プロフィールにログインします。アプリのすべての機能でMiroを使用できるようになりました。Miroボードでの作業については、ヘルプセンターのセクションをご覧ください：[はじめに](..)、[Miroの使い方](../../using-miro)。

- より快適にご利用いただくために、Wi-Fi よりもイーサネットケーブルでのご利用をお勧めします
- [ナビゲーションモード](../../using-miro/working-on-the-board/05-using-miro-with-a-mouse-trackpad-or-touchscreen.md)を確認し、必要に応じてトラックパッドやマウスに変更します
- ボード右下のミニマップを使用してボードを簡単にナビゲートできます

navigation_bar.gif
Miro ボードのミニマップ

セッションを終了してクリーンアップすると、自動的に Miro からログアウトされます。
