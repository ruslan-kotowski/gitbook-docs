Miro モバイルアプリで、いつでもどこでもチームのコラボレーションを強化しましょう。チームの進捗を常に把握し、アイデアや付箋を使ってダイナミックなブレストに参加し、シームレスなコメントを通じて継続的にフィードバックを提供できます。

:::tip
モバイルアプリは、Miro がサポートするすべての[言語](../../using-miro/managing-your-profile/03-language-settings.md)で利用可能です。
:::

## 制限付きで利用可能な機能

モバイルではサポートされていない Miro の機能があります。これには、テンプレート、ボードのエクスポート、プレゼンテーション モード、ビデオチャット、投票、およびスター付きボードが含まれます。モバイルアプリやモバイルブラウザでは、サブスクリプションを変更したり、ライセンスを追加することはできません。

モバイルアプリは、いくつかの機能に対して*限定された機能*を提供しています。

|  |  |
| --- | --- |
| **機能** | **限定的な機能** |
| ボードの作成と共有 | [ビジター](../../using-miro/sharing-boards/08-collaboration-with-visitors.md)には編集アクセスがありません |
| スペース | [スペース](../../using-miro/spaces/01-spaces.md)によるボードのフィルタリング |

## モバイルの要件

- **iOSユーザー:** iOS 16またはそれ以降
- **Androidユーザー:** Android 7またはそれ以降

アプリがスマートフォンに対応していない場合でも、以下のMiro機能にモバイルブラウザからアクセスできます:

- **ボードを閲覧:** コンテンツにアクセスして閲覧します。
- **コメントを残す:** 画面をタップして長押しし、コメントを追加します。

## アプリでのボード作業方法

### モバイルアプリのタッチジェスチャー

- **スワイプ**してボードの周りを移動します。
- **長押し**してドラッグすると、複数のオブジェクトを選択できます。
- **ピンチ**してズームイン/ズームアウトします。
- **ダブルタップ**してボードをズームインします。
- **ダブルタップして上下にスワイプ****して**ズームインまたはアウトします。
- **画面の端を上下にスワイプ**して、ズームインまたはアウトします。
- オブジェクトを選択し、**編集**をタップして編集します。
- **ダブルタップ**してオブジェクトにテキストを追加します。
- **長押し**してオブジェクトを移動します。

### ボードオブジェクトの編集方法

モバイルアプリでボードを開くと、デフォルトで閲覧専用モードになります。これは、オブジェクトを動かさずにボードの周りを簡単に移動できるようにするためです。

1. オブジェクトを選択し、**編集**をタップします。
2. オブジェクトをダブルタップして、テキストを追加します。
3. オブジェクトを長押しして、すぐに移動させます。

### ボード間のコピーとペーストの方法

あるボードから別のボードへの要素のコピーは、同じボード上でのコピーとペーストと同じように簡単に行えます。

1. コピーしたいオブジェクトがあるボードを開きます。
2. オブジェクトを選択し、下部のツールバーにある**縦三点メニュー**を押します。
3. **コピー**を選択します。
4. 貼り付けたいボードを開きます。
5. **追加（+）アイコン**を押し、その後**ペースト**を押します。
6. 貼り付けたオブジェクトをボードの適切な場所に移動します。

Miro の外部から画像、ファイル、またはその他のテキスト以外のコンテンツをコピーして貼り付けたい場合は、**アップロード**機能を使用する必要があります。アップロードのオプションは、**追加(+)**メニューから見つけることができます。

### コネクターラインの描き方

オブジェクト間でコネクターラインを引くことで、オブジェクトがボード上で移動されても維持されるリンクを作成できます。

1. 接続を開始したいオブジェクトを選択します。
2. **編集**アイコンを押します。
3. オブジェクトの下に現れる**青い点**を、接続したいオブジェクトまでドラッグします。
4. 矢印が現れ、オブジェクトが接続されます。
   ![connector-lines.gif](../../../../../../docs/getting-started/apps-for-devices/images/21020253626770_connector-lines.gif)
5. コネクターラインを削除するには、それを選択した後、下部ツールバーの**ごみ箱**アイコンをクリックします。

### ボードの詳細を見る方法

右上の三点リーダーを押すと、ボードの詳細情報が表示され、ボードカバーやボードへのアクセスを変更することができます。

### 編集アクセスリクエスト

誰かがボードの編集アクセスをリクエストすると、そのボードの所有者はMiroアプリからプッシュ通知を受け取ります。通知をクリックすることでボードに簡単に移動し、リクエスターに編集アクセスを許可することができます。

## ボードの音声サポート

視覚要素にサポートが必要なユーザーは、iOSおよびAndroidで音声機能を有効にすることができます。携帯電話の設定で音声機能をオンにすることで、Miroと一緒に使用できます。

音声機能がオンになっている場合、項目を選択すると画面上の内容が読み上げられます。これにより、アプリ上の内容を聞くことができ、コンテンツをより簡単に作成および閲覧できます。

## プッシュ通知

アプリに初めてサインインすると、プッシュ通知をオンにするかどうか確認します。これにより、チームメンバーがボード上であなたにメンションしたとき、常に通知を受け取ることができます。これらの通知はいつでもアプリの**設定**でオフにすることができます。

これはスマートフォンでのプッシュ通知にのみ適用されます。[メールとニュースレターの通知をオフにする方法](../../using-miro/managing-your-profile/02-miro-notifications.md)をご確認ください。

## よくある質問

モバイルアプリを使ってボードにウェブリンクを追加できますか？

はい、リンクを追加するには、まずコピーします。その後、ボードの右下にある作成ボタン（**+**）をタップします。**アップロード**を選択し、次に**クリップボードから貼り付け**を選びます。リンクはボード上に貼り付けられます。

ダークモードをオンにするには？

通常、ダークモードは電話の設定に従って有効化されています。Miroのモバイルアプリ専用にダークモードをオンまたはオフにしたい場合は、アプリのホーム画面にあるバナーで**モードを切り替え**ボタンをクリックし、**ダークモード**または**ライトモード**を選択してください。
