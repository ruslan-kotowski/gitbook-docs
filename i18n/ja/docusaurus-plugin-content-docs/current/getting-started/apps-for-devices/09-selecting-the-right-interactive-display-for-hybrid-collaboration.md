### インタラクティブ ディスプレイとは何か、考慮すべき理由

- インタラクティブ ディスプレイとは、タッチスクリーン デバイスで、ユーザーは、指やスタイラスを使ったタッチ操作により、情報やプレゼンテーションを表示し、コンテンツを編集することができます。
- 一部の参加者が対面で、一部がリモートであるハイブリッド会議でコラボレーションする際には、インタラクティブ ディスプレイを強く推奨します。
- チームにとってより包括的な環境を作り出し、コラボレーションを次のレベルに引き上げるために、次回の会議でインタラクティブ ディスプレイを使うことをご検討ください。

- インタラクティブ ディスプレイを使用することで、リアルタイムでオーガニック ブレインストームを行い、創造性を発揮することが可能になり、イノベーションの促進に役立ちます。
- インタラクティブ ディスプレイは、メンバーがどこにいても、情報への即時アクセスやチームメンバー全員の平等な参加を可能にし、ハイブリッド会議中に公平なエクスペリエンスを提供するのに役立ちます。
- 参加者は自分の個人用デバイスではなく 1 つのメイン画面を見ているので、インタラクティブ ディスプレイは、会議中の参加意欲を高めるのに役立ちます。
- 実物のホワイトボードとは異なり、インタラクティブ ディスプレイは、自動的に情報をデジタル保存するので、討議のフォローアップや追加のドキュメント作成は必要ありません。

### 考慮すべきこと

- 選択するディスプレイの種類を決定する前に、チームのニーズを検討する必要があります。以下の質問について考えます：
  - チームとのコラボレーション－素晴らしいタッチ機能を備えた大きなディスプレイ（55 インチ～ 85 インチ）を検討してください。画面が大きいほど、ハイブリッド会議の参加者が見やすくなります。
  - プレゼンテーション－より大きな画面（70 インチ以上）を検討した方が良いですが、高品質のタッチ機能は必要ありません。
  - 少人数グループとの臨時の重要性が低い会議ー全員が見て聞くことができるように、大きな画面を検討してください。リモート参加者も、画面に表示されます。
  - ワークショップ－グループの規模に応じて、アクティビティーには小さい画面を 2ー3 台、ファシリテーターには 1 つの大きな画面を検討してください。
  - 例えば、エンジニアリング チームやデザインチームは、ブレインストーミング セッションで、部屋から部屋へ移動できる高品質のタッチ機能付きインタラクティブ ディスプレイをより活用できるかもしれません。
  - 一方、マーケティングチームや戦略チームは、特定の会議室にある大きなデバイスを使用するかもしれませんが、それには素晴らしい動画と電話会議の品質が備わっています。
  - 小さなオフィス / 多目的スペースで作業している場合は、複数のチームがさまざまな目的で使用できるよう、ポータブルでより小さな画面を使用することも理にかなっているかもしれません。
  - 会議室や空いている会議スペースがある場合は、各部屋にディスプレイを購入するのが最も便利でしょう。

- インタラクティブ ディスプレイを何にご使用になりますか？
- 会社のどの個々のチームやグループが最も有益だと思いますか？
- オフィススペースはどのような状態ですか？インタラクティブ ディスプレイにどれだけのスペースを割くことができますか？

- 次に、ニーズに最も適したデバイスの機能を検討する必要があります。
  - 例えば、チームがテレビ会議に Zoom を使用する場合は、購入したデバイスは Zoom と互換性があることを確認してください。

- オフィスや会議スペースには、どの画面サイズが最適ですか？
- 高品質のタッチ機能は必要ですか？
- 部屋から部屋へ移動できるよう、デバイスをポータブルにしたほうがいいですか？
- ノートパソコンや PC には、どのタイプの接続が必要ですか？
- デバイスは、会社が使用するテレビ会議ツールをサポートしていますか？

### Miro アプリのおすすめ

- Android 端末をご利用の場合、Neat、DTEN、Vibe Board の使用を推奨しています。
- Dell などの Windows ベースのデバイスをご利用の場合は、こちらまたは Microsoft のアプリストアから[最新の Miro アプリをダウンロード](https://desktop.miro.com/platforms/win32/Miro.exe)できます。
- 画面上の描画や書き込みには、アクティブスタイラスやデジタルペンの使用もお勧めです。
- インタラクティブ ディスプレイにおける Miro の使用の詳細については、[こちら](07-interactive-displays.md)をご覧ください。
- インタラクティブ ディスプレイで Miro を使ったハイブリッド会議の実施方法については、[こちら](06-hosting-a-hybrid-meeting-with-miro-using-an-interactive-display.md)をご覧ください。
