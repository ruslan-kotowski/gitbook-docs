キーボードコマンドを使うと、Miro ボードのナビゲーションがスムーズになります。

## ツールバーとパネル

- **Tab**を押して、[ツールバー](../start-here/your-first-board/05-toolbars.md)とパネル間をナビゲートします。
- カーソル / 矢印キーを使用して、ツールバーの項目とメニューをナビゲートします。
- カーソルの上と下のキーを使って、[作成ツールバー](../start-here/your-first-board/05-toolbars.md)をナビゲートします。

## キーボード ナビゲーション

### 一文字キーショートカットをオン/オフに切り替える

デフォルトでは、一文字のショートカットがオンになっています。これをオフにするには（スクリーンリーダーなどの支援技術の干渉を防ぐため）：

1. ボードのツールバーにある**メインメニュー**（![icon-main.svg](../../../../../../docs/getting-started/accessibility-in-miro/images/31688274627218_icon-main.svg)）アイコンをクリックします。
2. **アクセシビリティ**オプションを選択してサブメニューを開きます。
3. サブメニューで、**一文字のショートカット**を切り替えます。

### ボードにアクセス

- **Tab** キーを押して「ボードの最初のオブジェクトに移動する」ボタンに達したら **Enter** キーを押すか、
- ツールバーまたはパネルにフォーカスしている場合、**B** を押してフォーカスをボードに移動します。ボードにフォーカスしているときは、以下が可能です:
  - **Ctrl+/Cmd+** および **Ctrl-/Cmd-** でズームインとズームアウトができます。
  - 矢印キーでボードをパンすることができます。
  - macOS では、**Cmd + Shift + 下** を押して、ボード上の最初のオブジェクトを選択します。
  - Windows では、**Ctrl + Shift + 下** を押して、ボード上の最初のオブジェクトを選択します。

### ツールバーに戻る

- **Escape** を押します。

### ボード上で直線的に移動する

- **Tab** を使用して、ボードのオブジェクトを左上から右下（読み順）に移動します。
- **Shift + Tab** を使用して、逆方向に移動します。

### ボード上を空間的に移動する

macOS

**Cmd + 矢印キー**で、ボードオブジェクト間を空間的な秩序に従って移動します。

- **Cmd + 右**で、現在のオブジェクトの右にあるエレメントに移動します。
- **Cmd + 上**で、現在のオブジェクトの上にあるエレメントに移動します。
- **Cmd + 下**で、現在のオブジェクトの下にあるエレメントに移動します。
- **Cmd + 左**で、現在のオブジェクトの左にあるエレメントに移動します。

Windows

**Ctrl + 矢印キー**で、ボードオブジェクト間を空間的な秩序に従って移動します。

- **Ctrl + 右** で、現在のオブジェクトの右にあるエレメントに移動する。
- **Ctrl + 上**で、現在のオブジェクトの上にあるエレメントに移動する。
- **Ctrl + 下**で、現在のオブジェクトの下にあるエレメントに移動する。
- **Ctrl + 左**で、現在のオブジェクトの左にあるエレメントに移動する。

### 最初または最後のオブジェクトにジャンプする

macOS

- **Option + Shift + 左矢印**、または **Option + Home** で、現在のコンテナ内の最初のオブジェクトにジャンプする。
- **Option + Shift + 右矢印**、または **Option + End** で、現在のコンテナ内の最後のオブジェクトにジャンプする。

Windows

- **Alt + Shift + 左矢印**、または **Alt + Home** で、現在のコンテナ内の最初のオブジェクトにジャンプする。
- **Alt + Shift + 右矢印**、または **Alt + End** で、現在のコンテナ内の最後のオブジェクトにジャンプする。

### コンテナオブジェクト内外に移動する

コンテナオブジェクトにはフレームおよびグループ化されたオブジェクトが含まれます。コンテナオブジェクト内にいるときは、すべてのナビゲーションがそのコンテナに制約されます。

macOS

- **Cmd + Shift + Down** でコンテナオブジェクトに入ります。
- **Cmd + Shift + Up** でコンテナオブジェクトから出ます。

Windows

- **Ctrl + Shift + Down** でコンテナオブジェクトに入ります。
- **Ctrl + Shift + Up** でコンテナオブジェクトから出ます。

### オブジェクトのテキストを編集する

- オブジェクト上で **Enter** を押して、編集を開始する（付箋など）。
- オブジェクト上で **Escape** を押して、編集を停止する（付箋など）。

:::note
キーボード ナビゲーションは、オブジェクトが選択されたときのみ可能で、オブジェクトが編集中のときは使えません。
:::

### オブジェクトを移動

- オブジェクトを移動させるには **矢印キー** を使用します。
- オブジェクトをさらに移動させるには **Shift + 矢印キー** を使用します。

### 複数のボードオブジェクトを選択する

macOS

- 最初のオブジェクトを選択します。
- **Cmd** + **Option** + **Shift** + **矢印キー**を押して、追加のオブジェクトを選択します。

Windows

- 最初のオブジェクトを選択します。
- **Ctrl** + **Alt** + **Shift** + **矢印キー**を押して、追加のオブジェクトを選択します。

### ボードオブジェクトのサイズ変更

macOS

- サイズを変更したいボードオブジェクトを選択します。
- **Cmd** + **Option** + **Shift** + **Plus/Minus** を押します。

Windows

- サイズを変更したいボードオブジェクトを選択します。
- **Ctrl** + **Alt** + **Shift** + **Plus/Minus** を押します。

### オブジェクトのコンテキストメニューへのアクセスと操作

オブジェクトのコンテキストメニューには、オブジェクトの色や種別、テキスト書式の変更など、オブジェクトをカスタマイズするための追加機能があります。オブジェクトを選択すると、オブジェクトの上に水平にコンテキストメニューが表示され、これらのオプションにアクセスできます。

macOS

- オブジェクトのコンテキストメニューにフォーカスを移動するには、**Cmd + Enter** キーを押します。
- **左右の矢印キー**でオブジェクトのコンテキストメニューを移動し、**Enter/スペース**で項目を選択します。

Windows

- **Ctrl + Enter** を押してオブジェクトのコンテキストメニューにフォーカスを移動します。
- オブジェクトのコンテキストメニューをナビゲートするには **左/右矢印キー** を使用し、 **Enter/Space** を押して項目を選択します。

### 新しいオブジェクトを作成する

新しいオブジェクトを追加する最も簡単な方法は、コマンドパレットを使用することです。

macOS

- **Cmd+K**を押してコマンドパレットを開きます。
- オブジェクト名（例：付箋）を入力し始めます。
- **矢印キー**を使用してオブジェクトを選択します。
- **Enterキー**を押すと、オブジェクトがボードの中央に追加されます。

Windows

- **Ctrl+K** を押してコマンドパレットを開きます。
- オブジェクトの名前を入力し始めます。例: 付箋。
- **矢印キー**を使ってオブジェクトを選択します。
- **Enterキー**を押すと、オブジェクトがボードの中央に追加されます。

キーボードを使用してオブジェクトを作成する他の方法には以下があります。

- タブで[作成ツールバー](../start-here/your-first-board/05-toolbars.md)に移動し、**上下矢印**キーで目的のオブジェクトタイプ（図形、付箋など）まで選択し、**Enter**キーを押します。その後、**Tab**キーでオブジェクトを選び、もう一度**Enter**キーを押してオブジェクトを作成します。オブジェクトがボード上に表示されます。
- オブジェクトに関連するショートカットキー（例：付箋なら**N**）を押し、その後**Tab**キーでオブジェクトを選び、**Enter**キーを押します。オブジェクトがボード上に表示されます。
- 既存の要素を**Ctrl**/**Cmd+C**キーでコピーし、**Ctrl/Cmd+V**で貼り付けます。
- **Ctrl/Cmd+D** で、既存のオブジェクトを複製する。
- **Enter** を押して付箋を編集し、次に **Tab** を押すと、新しいオブジェクトが選択されたオブジェクトのすぐ隣に作成されます。

### ダイアグラム作成の接続を行う

ボード上のオブジェクト間にコネクターラインを作成できます。

- タブキーで接続したい最初のオブジェクトに移動します。
- Command+K（Mac）または Ctrl+K（Windows）を押してコマンドパレットを開きます。
- **Create connection to**と入力して選択します。
- タブキーで次のオブジェクトに移動します。
- Command+K（Mac）または Ctrl+K（Windows）を押してコマンドパレットを開きます。
- **Connect to this object**と入力して選択します。

### コメント

macOS

- **Option+Tab** でコメントを前方へナビゲートします。
- **Option+Shift+Tab** でコメントを前方へナビゲートします。
- **Option+**C で、現在のオブジェクトにコメントを追加します。

Windows

- **Alt + C** で、現在のオブジェクトにコメントを追加します。

## 支援技術コマンド

以下のキーボードコマンドは、スクリーンリーダーなどの支援テクノロジーを使用している場合のみ利用できます。

### ボードの概要

ボードの概要では、スクリーンリーダーのユーザーにボード上のオブジェクトの概要を簡単に説明します。

macOS

- **Option + S** で、ボード上のオブジェクトの数と種類に関する情報を入手する。

Windows

- **Alt + S** で、ボード上のオブジェクトの数と種類に関する情報を入手する。

### 追加のオブジェクト情報

このアクションは、スクリーンリーダーのユーザーに、現在選択されているオブジェクトに関する追加情報を提供します。

macOS

- **Option + I** で、追加のオブジェクト情報を取得する。

Windows

- **Alt + I** で追加のオブジェクト情報を取得します。

### オブジェクト選択の通知

ボードオブジェクトを選択した際に提供された情報を繰り返すことができます。

macOS

- **Option + R**で選択の通知を繰り返します。

Windows

- **Alt + R** で選択の通知を繰り返します。
