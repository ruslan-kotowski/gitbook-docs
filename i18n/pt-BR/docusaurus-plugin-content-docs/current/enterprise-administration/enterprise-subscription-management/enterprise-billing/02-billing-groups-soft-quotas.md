## Visão geral

As cotas flexíveis são uma nova atualização de UI para grupos de cobrança, permitindo que os admins definam um limite flexível opcional para o número de licenças atribuídas a um grupo de cobrança. Esta funcionalidade oferece maior transparência e dados acionáveis para gerenciar as atribuições das licenças.

As cotas flexíveis fornecem uma maneira flexível e informativa de gerenciar as atribuições de licenças em grupos de cobrança, garantindo que os admins tenham os dados de que precisam para tomar decisões informadas.

## Como definir as cotas flexíveis

### Adicionar uma cota flexível

Admins podem adicionar uma cota flexível ao criar ou editar um grupo de cobrança. Este limite é baseado no número total de licenças atribuídas em relação ao número total de licenças disponíveis.
O limite geral de cota flexível para cada grupo de cobrança encontra-se na parte superior da visão geral do Grupo de cobrança, exibido como um valor numérico e uma barra de progresso de linha.

Ao defini-los, os limites de cota flexível também aparecem na tabela do grupo de cobrança.

### Indicadores visuais

- **Barra verde:** Indica que o grupo de cobrança está dentro do limite de licenças atribuídas.
- **Barra vermelha e ícone de aviso:** Indica que o grupo de cobrança ultrapassou o limite de atribuições de licenças.

## Como gerenciar as cotas flexíveis

### Ultrapassar o limite

Ultrapassar o limite de cota flexível não interfere na forma como as licenças são atribuídas. O objetivo é fornecer transparência e dados acionáveis para admins.

### Filtros rápidos

Admins podem filtrar os grupos de cobrança por:

- **Cota Definida:** para visualizar grupos com uma cota flexível definida.
- **Cota Excedida:** para visualizar os grupos que ultrapassaram o limite de cota flexível.
