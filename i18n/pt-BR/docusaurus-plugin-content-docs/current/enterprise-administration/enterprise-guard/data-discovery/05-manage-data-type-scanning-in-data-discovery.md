Os admins de conteúdo sensível podem agora habilitar ou desabilitar facilmente etiquetas específicas ao configurar varreduras de descoberta de dados, ajudando a adaptar os resultados às necessidades da sua organização. Por exemplo, você pode optar por focar apenas nas etiquetas de GDPR. Depois que você salva suas preferências de escaneamento, os escaneamentos são atualizados automaticamente para refletir o tipo de dado que você ativou ou desativou. Isso dá aos Admins maior controle sobre as saídas de varredura e ajuda a reduzir o ruído de descobertas irrelevantes. Por padrão, todos os tipos de dados/etiquetas de sensibilidade estão habilitados.

Para gerenciar o escaneamento de tipos de dados, siga os seguintes passos:

:::note
- Para habilitar ou desabilitar etiquetas para a descoberta de dados, você deve ter a [função de admin de conteúdo sensível](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md). Para solicitar a função de admin de conteúdo sensível, fale com seu Admin da empresa.
- Você não pode desabilitar etiquetas usadas para classificação de dados, pois desabilitá-las pode afetar a classificação automática e as proteções aplicadas ao conteúdo. Remova-os dos critérios de classificação antes de desativá-los.
:::

1. Vá para suas [configurações da Miro](https://miro.com/app/settings).
2. No painel esquerdo, em **Enterprise Guard,** clique em **Descoberta de dados**.
3. Na página **Descoberta de dados**, clique na guia **Configuração**.
4. Se você quiser ativar ou desabilitar tipos de dados/ etiquetas relacionados à privacidade, na seção **Relacionados à privacidade**, clique no botão **Gerenciar**.
   Se você quiser habilitar ou desabilitar tipos de dados/etiquetas confidenciais da empresa, na seção **Confidenciais da empresa**, clique no botão **Gerenciar**.
   Um painel lateral será exibido.
5. Para desabilitar um tipo/etiqueta de sensibilidade de dados: Clique para desmarcar a caixa de seleção para o tipo/etiqueta de dados.
   Para ativar uma etiqueta de tipos/dados de sensibilidade: Clique para selecionar a caixa de seleção para o tipo/etiqueta de dados.
6. Clique no botão **Aplicar alterações**.
   As atualizações podem levar até 24 horas.
