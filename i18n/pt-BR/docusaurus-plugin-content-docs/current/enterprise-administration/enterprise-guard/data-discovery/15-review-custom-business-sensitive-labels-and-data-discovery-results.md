A página **Visão geral da descoberta de dados** exibe uma lista de todas as etiquetas confidenciais personalizadas configuradas, o status da etiqueta, o tipo de etiqueta, o Admin que criou a etiqueta, a classificação do board associada a cada etiqueta, o número de boards marcados com cada etiqueta e o link para explorar os boards. Além disso, os admins de conteúdo sensível podem editar as etiquetas confidenciais personalizadas da empresa e copiar os IDs de exibição das etiquetas da página **Visão geral da descoberta de dados**.

:::note
Para visualizar os resultados personalizados da descoberta de dados confidenciais da empresa, você deve ter a [função de admin de conteúdo sensível](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md). Para solicitar a função de admin de conteúdo sensível, fale com seu Admin da empresa.
:::

## Revisar boards com dados confidenciais da empresa personalizados

Para explorar os boards com dados confidenciais da empresa personalizados, siga as seguintes etapas:

1. Vá para as suas [configurações da Miro](https://miro.com/app/settings).
2. No painel esquerdo, em **Enterprise Guard,** clique em **Descoberta de dados**.
3. Na página **Descoberta de dados** **Visão geral**, clique no link da contagem de boards. O Buscador de conteúdo mostra a lista de boards. Para mais informações, consulte Revisar boards com dados confidenciais da empresa.

## Copiar ID de exibição da etiqueta

Os nomes das etiquetas não são visíveis nos logs de auditoria. Caso queira visualizar ou pesquisar os logs de auditoria relacionados a uma etiqueta específica, você deve usar o ID de exibição da etiqueta.

Para descobrir o ID de exibição de uma etiqueta, siga as seguintes etapas:

1. Vá para suas [configurações da Miro](https://miro.com/app/settings).
2. No painel esquerdo, em **Enterprise Guard,** clique em **Descoberta de dados**.
3. Na página **Descoberta de Dados** **Visão Geral**, clique nas reticências (três pontos) na linha da etiqueta para a qual deseja copiar o ID de exibição da etiqueta e, em seguida, clique em **Copiar ID de exibição da etiqueta**.
