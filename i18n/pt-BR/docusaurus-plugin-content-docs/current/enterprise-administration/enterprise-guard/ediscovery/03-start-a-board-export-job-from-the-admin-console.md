1. Clique no avatar do seu perfil, e depois clique em **console de admin**.
2. No painel esquerdo, clique em Enterprise Guard e depois clique em **eDiscovery**.
3. Clique na guia **Casos**.
   A lista de casos aparece.
4. Clique no caso que contém uma ou mais retenções legais que você deseja exportar.
   A lista de retenções legais pertencentes ao caso aparece.
5. Você pode iniciar uma exportação de board de uma das seguintes maneiras:
   - A partir da visualização da lista de retenções legais: Na página da lista de retenções legais, clique no botão **Exportar conteúdo** no topo da página e então clique na retenção legal específica para exportar todos os boards relacionados.
     Uma caixa de diálogo será exibida. Vá para o passo 6.
   - Na página de detalhes da retenção legal: Na página da lista de retenções legais, clique no nome da retenção legal para abri-la e depois clique no botão Exportar no topo da página.
     Uma caixa de diálogo será exibida. Prossiga para o passo 6.
6. Na caixa **Nome da exportação**, digite um nome de exportação para este trabalho de exportação de board.
7. Na lista **Formato**, selecione o formato de arquivo para o qual deseja exportar os boards. Você pode exportar para um arquivo SVG, PDF ou HTML. Por padrão, o formato é definido como SVG.
8. (Opcional) Para incluir um [registro de conteúdo](06-content-logs-overview.md) para cada board no trabalho de exportação, marque **Incluir registros de conteúdo**.
9. Clique em **Exportar**.
   O trabalho de exportação aparece na guia **Exportações** da página do caso. Para informações sobre como monitorar trabalhos de exportação e visualizar o status da exportação, [veja este artigo](07-monitor-board-export-jobs-and-view-status-from-the-admin-console.md).
