O encerramento de um caso é a etapa final do processo de eDiscovery, que marca a conclusão de uma questão jurídica ou investigação. [Admins de eDiscovery](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md) devem garantir que todas as retenções legais associadas ao caso estejam encerradas antes de fechar o caso.

Para encerrar um caso, siga as seguintes etapas:

:::note
Você deve ter a [função de admin de eDiscovery](../../enterprise-subscription-management/enterprise-guard-overview/03-understand-admin-roles-and-their-privileges.md) para executar esta tarefa. Para solicitar a função de admin de eDiscovery, fale com seu Admin da empresa.
:::

1. Verifique se todas as retenções legais associadas ao caso estão encerradas. Para mais informações, consulte [Encerrar uma retenção legal](12-close-a-legal-hold.md).
2. Vá para as [configurações do Miro](https://miro.com/app/settings).
3. No painel esquerdo, em **Enterprise Guard**, clique em **eDiscovery**.
4. Na página **eDiscovery**, clique no caso que deseja encerrar.
5. Clique nas reticências (três pontos) da linha do caso que deseja encerrar, e então clique em **Encerrar caso**.
6. A caixa de confirmação **Encerrar caso** será exibida, informando que todos os detalhes sobre este caso serão removidos.  ![closecaseconfirmationbox.png](images/22388641716370_closecaseconfirmationbox.png)
7. Assim que tiver certeza de que deseja encerrar o caso, clique em **Encerrar caso**.
   O caso é excluído.
