Para ativar o bloqueio de prompts para sua organização:

1. No Miro, vá para **Configurações** → **Enterprise Guard** → **Descoberta de Dados** → **Configuração**.
2. Em **Bloqueio de Prompt**, clique em **Ativar**.
3. No painel lateral, mantenha **Selecionar tudo** habilitado ou escolha categorias específicas de etiquetas para bloquear.
4. (Opcional) Ative a **Varredura de Código** para bloquear prompts que incluam código-fonte (mínimo de 5 linhas). Para mais informações, consulte [Varredura de Código](../../enterprise-guard/ai-trust/06-prompt-blocking-overview.md).
5. Clique em **Ativar**.

O bloqueio de prompts está ativado para sua organização. Todas as categorias selecionadas são aplicadas imediatamente.
