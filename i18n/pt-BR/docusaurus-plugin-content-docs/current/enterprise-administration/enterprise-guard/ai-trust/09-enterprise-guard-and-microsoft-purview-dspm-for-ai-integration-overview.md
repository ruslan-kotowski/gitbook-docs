Para organizações que usam o Microsoft Entra ID (anteriormente Azure AD) como seu provedor de identidade, o Enterprise Guard encaminha de forma segura os prompts de IA e suas respostas para o Microsoft Purview Data Security Posture Management (DSPM). As equipes de segurança e conformidade podem então monitorar, auditar e controlar o uso de IA generativa a partir de uma única plataforma confiável, reduzindo a sobrecarga operacional, mitigando riscos como vazamento de dados e uso indevido, e fortalecendo a governança de IA em nível empresarial da Miro.

:::note
A versão Beta suporta formatos do Miro AI, incluindo diagramas, mapas mentais, documentos, protótipos, notas adesivas e tabelas, mas não imagens. Estamos trabalhando para adicionar suporte para imagens e mais funcionalidades de IA em lançamentos futuros.
:::

## **Para quem é**

Esta funcionalidade está disponível na versão Beta para clientes Enterprise Guard que gerenciam Miro e Microsoft Entra ID (anteriormente Azure AD)/Microsoft Purview.

## **O que você obtém**

- **Visibilidade centralizada:** Visualize o uso do Miro AI no hub de IA do Microsoft Purview.
- **Auditabilidade:** Solicitações (entradas do usuário) e respostas (saídas do AI) são registradas para revisão.
- **Alinhamento de governança:** Use seus fluxos de trabalho existentes no Purview para monitoramento, alertas e retenção.

Para mais informações, consulte [a documentação detalhada aqui](../../enterprise-subscription-management/integrations/02-enterprise-guard-and-microsoft-purview-dspm-for-ai-integration-overview.md).
