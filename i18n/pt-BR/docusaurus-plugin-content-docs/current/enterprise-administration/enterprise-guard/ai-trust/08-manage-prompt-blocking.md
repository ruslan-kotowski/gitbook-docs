Para ajustar quais etiquetas estão bloqueadas ou ativar/desativar a varredura de código:

1. Vá para **Configurações** → **Enterprise Guard** → **Descoberta de dados** → **Configuração**.
2. Em **Bloqueio de prompts**, selecione **Gerenciar**.
3. No painel lateral, faça o seguinte:
   - Ative ou desative **Selecionar tudo**.
   - Marque ou desmarque categorias específicas de etiquetas que deseja bloquear.
   - Ative ou desative **Escaneamento de código**.
4. Selecione **Aplicar alterações**.

As alterações têm efeito imediato para todos os usuários. Prompt com itens recém-desbloqueados serão processados. Prompt com itens ainda bloqueados continuarão a ser interrompidos.
