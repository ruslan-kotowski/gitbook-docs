Gerencie todas as solicitações de licenças em um único local. Ao receber as solicitações de licenças diretamente na Miro, você pode simplificar os processos de uso e aprovação de licenças da sua organização.

## Configurações de solicitações de licenças

Nas configurações de **Solicitações de acesso**, você encontra uma visão geral de todas as **Solicitações de licenças** atuais. Essas solicitações de licenças são iniciadas quando um usuário deseja fazer upgrade de uma licença Free Restrito para uma licença Avançada, Padrão ou Completa (legado).

Os detalhes da solicitação de licença incluem:

- O nome do usuário para quem a solicitação de licença é feita
- O nome do grupo de cobrança (se houver) ao qual o usuário será atribuído
- O nome do solicitante
- A data da solicitação

As solicitações podem ser enviadas pela pessoa que deseja a atualização da licença ou em nome de outra pessoa. Saiba mais sobre os diferentes cenários de upgrade de licenças para o plano Enterprise.

:::note
Para receber solicitações de licença diretamente na Miro, atualize suas preferências de [Gerenciamento de solicitações](09-request-management-on-enterprise-plan.md).
:::

## Como aceitar ou negar solicitações de licenças

:::note
Após 30 dias, todas as solicitações expiram automaticamente e são removidas.
:::

1. Vá para as configurações da Miro.
2. Clique em **Empresa**.
3. Em **Usuários**, clique em **Solicitações de acesso**.
4. Selecione a guia **Solicitações de licenças**. Nesta seção, você pode visualizar todas as solicitações de licenças pendentes.
5. Na coluna **Ações**, clique na marca de seleção (**✓**) para aceitar, ou no xis (**x**) para recusar a solicitação.
6. (Opcional) Para aceitar solicitações de licenças em massa, clique na caixa de seleção ao lado da coluna **Nome** para selecionar todas as solicitações, e clique em **Aprovação em massa**.
7. Quando você aceita ou recusa solicitações, um modal será aberto com os detalhes do solicitante, junto com quem é a solicitação de licença.
8. Clique em **Aprovar** para aprovar a solicitação ou em **Recusar** para recusá-la. Quando você aceita ou recusa uma solicitação, ela será removida da visão geral de suas solicitações de licença.
9. Assim que a solicitação de licença for aprovada, o usuário fará upgrade de uma licença Free Restricta para uma licença Avançada, Padrão ou Completa (legada).

## Cenários de upgrade de licenças

Certas ações ou eventos na Miro levam os usuários a enviarem solicitações de upgrade de licença. Os cenários descritos abaixo mostram como essas solicitações são geradas para os usuários do Enterprise Plan. Após a aprovação, a licença do usuário será atualizada de Free Restricted para Advanced, Standard ou Full (legado). Os usuários continuarão sendo membros dos mesmos times dos quais já faziam parte.

:::note
Para visualizar seu uso atual de licenças, vá para **Gerenciamento de usuários** > **Usuários ativos**.
:::

|  |  |  |
| --- | --- | --- |
| **Tipo de usuário** | **Ação** | **Cenário** |
| **Membros existentes (licença gratuita limitada)** | Criar um board ou projeto | Um usuário gratuito com acesso limitado tenta criar um novo board ou projeto em um time. |
| Editar acesso | Um usuário gratuito com acesso limitado solicita acesso para editar um board. |
| Convidado para editar | Um membro existente solicita acesso de edição para o usuário Free Restricted |
| Titular do board | O usuário Free Restricted recebe a função de [titular do board](../../getting-started/start-here/05-roles-in-miro.md) por um admin do time |
