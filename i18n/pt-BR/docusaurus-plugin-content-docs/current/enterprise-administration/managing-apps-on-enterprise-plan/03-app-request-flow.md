O fluxo permite que usuários finais em sua organização solicitem acesso a determinados aplicativos e integrações com o Miro. Os Admins da empresa podem optar por aprovar ou negar essas solicitações.

> ***Atualização do console de admin está sendo gradualmente implementada***
> Com configurações reorganizadas e padrões comuns de UX mais intuitivos, o novo console de admin da Miro simplifica a realização de fluxos de trabalho administrativos essenciais. O novo console de admin está sendo disponibilizado ao longo de várias semanas.
>
> Para ver todas as alterações, confira o [Novo console de admin da Miro (Beta)](../managing-enterprise-teams-and-content/01-miro's-new-admin-console.md).

> **Disponível para:** [Plano Enterprise](../../plans-billing/miro-plans/04-enterprise-plan.md)

### Guia do usuário

Se determinados aplicativos exigirem aprovação do administrador no plano Enterprise da sua empresa, você poderá solicitar acesso aos aplicativos e integrações com o Miro.

Aqui estão os passos para solicitar acesso:

1. Abra um board e clique no ícone **Aplicativos** na barra de ferramentas. Selecione o aplicativo que você deseja usar.
   ![adicionar_mais_aplicativos.jpg](../../../../../../docs/enterprise-administration/managing-apps-on-enterprise-plan/images/23034307860242_add%20more%20apps.jpg)
   *A opção de adicionar mais aplicativos da barra de ferramentas*
   Como alternativa, você pode acessar o [Marketplace da Miro](https://miro.com/marketplace/) e descobrir todos os aplicativos disponíveis.
2. Se este aplicativo exigir aprovação do admin, você verá uma opção para enviar uma solicitação ao seu admin.
3. Aqui, você também pode selecionar o motivo da instalação.
4. Clique em **Enviar solicitação** e seu admin receberá uma notificação. Eles podem aprovar ou negar sua solicitação.
   ![enviar_solicitação_de_aplicativo.jpg](../../../../../../docs/enterprise-administration/managing-apps-on-enterprise-plan/images/21019791264274_send%20app%20request.jpg)
   *A opção de enviar uma solicitação para instalação do aplicativo no plano Enterprise*
5. Depois que o admin tomar sua decisão, você receberá uma notificação informando se sua solicitação foi aprovada ou negada.

### Guia de admin

> **Configurado por:** Admins da empresa

Os Admins da empresa podem configurar permissões de usuário para instalar aplicativos e exigir aprovação do admin para a instalação de aplicativos. Para mais detalhes, confira [este guia](02-app-management.md). Depois que um usuário solicitar acesso para usar um aplicativo, siga as etapas abaixo para aprovar ou negar a solicitação.

1. Depois que a solicitação for enviada por um usuário, você receberá uma notificação por e-mail. A notificação será enviada a todos os Admins da empresa.
2. Se você for para Configurações **da empresa** > **Aplicativos e integrações** > **Aplicativos** > **Solicitações de aplicativos**, verá a lista de solicitações de usuário abertas.
3. Você pode ver o nome do aplicativo, a time, a data solicitada e o nome do usuário , bem como mais detalhes sobre as necessidades específicas do usuário e as permissões do aplicativo.
4. Aqui, você pode escolher aprovar ou negar cada solicitação. Quando você aprova a solicitação, o aplicativo também é aprovado para instalação por outros usuários.
5. Depois de aprovar ou negar a solicitação, o usuário individual receberá uma notificação.
