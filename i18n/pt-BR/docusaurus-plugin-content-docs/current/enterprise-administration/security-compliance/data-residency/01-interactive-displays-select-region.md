Os times no plano Enterprise com residência de dados fora da União Europeia (UE) podem selecionar a região apropriada nos displays interativos.

Este artigo explica como conectar o navegador de um display interativo à região apropriada de residência de dados e como começar a usar o aplicativo Miro em um display Windows e Android na região apropriada.

Para obter informações sobre displays interativos, consulte [Displays Interativos.](../../../getting-started/apps-for-devices/07-interactive-displays.md)

Para saber mais sobre a residência de dados, consulte [Residência de dados na Miro](../../canvas-25-admin-features/data-residency/02-data-residency-at-miro.md).

## Conectar o navegador do display interativo à região

1. Abra o navegador do display.
2. Acesse o seguinte URL para a sua região:
   - (Padrão) **União Europeia**
     `https://miro.com/displays/?useAsAppDefaultOrigin`
   - **Austrália**
     `https://au.miro.com/displays/?useAsAppDefaultOrigin`
   - **Estados Unidos**
     `https://us.miro.com/displays/?useAsAppDefaultOrigin`
3. Siga as instruções na tela.

## Alterar a região do app Miro no display interativo Windows

1. No seu display interativo Windows, abra o aplicativo Miro.
2. No teclado, pressione a tecla **ALT**.
   Um menu de contexto será aberto.
3. Selecione **Ajuda** > **Dispositivo público** > **Público**.
   O Miro mudará para a experiência de display interativo.
4. Selecione **Ajuda** > **Dispositivo público** > **Região padrão**.
5. Selecione uma das seguintes opções:
   - (Padrão) **Global**
     Conecta-se à região da União Europeia
   - **Austrália**
     Conecta-se à região da Austrália
   - **Estados Unidos**
     Conecta-se à região dos Estados Unidos

## Alterar a região do app Miro no display interativo Android

1. No seu display interativo Android, abra o aplicativo Miro.
2. Na tela inicial, no canto superior direito, toque no ícone de engrenagem.
3. Toque em **Selecionar região**.
   O modal **Selecionar uma região diferente** será aberto.
4. Selecione uma das seguintes opções:
   - (Padrão) **Global**
     Conecta-se à região da União Europeia
   - **Austrália**
     Conecta-se à região da Austrália
   - **Estados Unidos**
     Conecta-se à região dos Estados Unidos
