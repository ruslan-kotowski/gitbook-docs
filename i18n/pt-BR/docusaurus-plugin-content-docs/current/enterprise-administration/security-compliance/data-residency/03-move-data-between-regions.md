Os clientes da Miro podem exigir [residência de dados](../../canvas-25-admin-features/data-residency/02-data-residency-at-miro.md) fora da sua região atual. Além da União Europeia (UE), a Miro oferece residência de dados na Austrália (AU) e nos Estados Unidos (EUA).

## Opções para mover dados entre regiões

O processo de mudança de residência de dados é chamado de migração entre regiões. Para migrar sua organização para uma nova região, a Miro oferece as seguintes opções:

- **Exportação e importação manual**
  O Suporte da Miro faz o provisionamento de uma nova organização na nova região. Cabe ao Admin da empresa reconfigurar todas as definições da organização e do time, como também convidar os usuários novamente. Os usuários finais baixam manualmente seus boards da Miro da região antiga e os carregam na nova região. Para saber mais, consulte [Movendo dados entre regiões – Exportação e importação manual](../../canvas-25-admin-features/data-residency/06-move-data-between-regions-–-manual-export-and-import.md).
- **Migração de dados automatizada**
  Disponível mediante contratação paga de serviços da Miro. Automatiza a migração completa da organização, incluindo todo o conteúdo da organização, hierarquia de conteúdo, usuários e configurações. Para saber mais, consulte [Movendo dados entre regiões – Migração automatizada](../../canvas-25-admin-features/data-residency/05-move-data-between-regions-–-automated-migration.md).
  > ✏️ A migração de dados automatizada não está disponível atualmente para [empresas com gerenciamento de chaves de criptografia (EKM)](../../canvas-25-admin-features/encryption-key-management/01-encryption-key-management-overview.md).

Para decidir qual opção de migração é melhor para você, entre em contato com seu contato dedicado da Miro ou envie um e-mail para [support@miro.com](mailto:support@miro.com).

## Compare as opções de transferência de dados entre regiões

A tabela a seguir compara suas opções automáticas e manuais para mover dados entre regiões:

|  | Automático | Manual |
| --- | --- | --- |
| Custo | Contratação de serviços da Miro. | Sem custo adicional. Os Admins da empresa e os usuários finais movem o conteúdo dos seus boards de uma região para outra. |
| Escopo | Grande parte da organização e de seus dados serão migrados, incluindo os dados abaixo. Para ver uma lista completa dos dados incluídos, confira [o artigo Automatização para admins].  - Dados da organização - Perfis de usuários - Times e configurações dos times - Membros do time - Boards - Logs de auditoria - Classificação de dados - Configurações de segurança de conteúdo | Os Admins devem reconfigurar as definições da organização, recriar os times aplicando as respectivas configurações, convidar novamente os usuários, atribuir licenças e reinstalar os aplicativos e as integrações. Os usuários finais devem mover manualmente seus boards para a nova região. |
| Duração | A organização e seus dados são migrados para a nova região. | Depende da rapidez com que o Admin da empresa termina a configuração manual e os usuários finais movem seus boards. |
