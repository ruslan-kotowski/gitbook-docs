> **Residência de Dados na UE:** Disponível para todos os planos
>
> **Residência de Dados nos EUA e AU:** Disponível apenas para o Plano Enterprise

A residência de dados permite que os clientes controlem onde seu conteúdo é hospedado e armazenado, para ajudar a cumprir suas obrigações de privacidade e gerenciamento de dados.

## Entenda a residência de dados na Miro

A residência de dados é essencial para clientes de setores em que a proteção de dados é obrigatória ou regulamentada, como serviços bancários e financeiros, saúde e governo.

O programa de residência de dados da Miro foi desenvolvido com dois pilares funcionais:

- **Armazenamento regional**
  A Miro armazena os dados de produção de escopo, dados de backup e metadados em data centers locais, o que ajuda os clientes a atender aos seus requisitos de conformidade de dados.
- **Infraestrutura de computação regional**
  A Miro usa a infraestrutura de TI regional, o que elimina a necessidade de transferências de dados fora da região entre os elementos de TI do mesmo escopo, além de ajudar a otimizar o desempenho do produto.

## Regiões de residência de dados

A Miro fornece residência de dados nas seguintes regiões:

- (Padrão) **União Europeia**
  A Miro usa dois data centers na União Europeia (UE). O data center primário está situado na Irlanda e o data center de backup na Alemanha.
- **Estados Unidos**
  A Miro usa dois data centers nos Estados Unidos (EUA). O data center primário está situado em Ohio e o data center de backup na Virgínia.
- **Austrália**
  A Miro usa dois data centers na Austrália. O data center primário está situado em Sydney e o data center de backup em Melbourne.

:::note
A Miro pode acrescentar ou atualizar os locais de data centers de backup em uma determinada região. Os data centers de backup sempre estarão localizados na mesma região que seus respectivos data centers primários. Por exemplo, um data center de backup para a Austrália seria instalado na Austrália.
:::

## Governança de dados na Miro

A tabela a seguir mostra quais funcionalidades da Miro geralmente disponíveis (GA) estão, e quais não estão, sujeitas ao armazenamento de dados na região de residência.

> **NOTA:** Os dados da Miro AI são armazenados na região conforme os compromissos de residência de dados. O processamento pode ocorrer fora da região selecionada. A residência de dados se aplica apenas às funcionalidades geralmente disponíveis (GA) e exclui funcionalidades beta ou de pré-visualização.

> **NOTA:** Os aplicativos e integrações de terceiros podem armazenar e tratar informações fora da residência de dados da Miro.

### Miro AI e residência de dados

"Miro AI" refere-se a funcionalidades do produto que utilizam aprendizado de máquina ou modelos generativos de IA para analisar, transformar ou gerar conteúdo com base nos dados dos clientes na Miro.

Para residência de dados, os dados usados ou gerados pela Miro AI são armazenados na região de acordo com os compromissos de residência. O processamento pode ocorrer fora da região selecionada, uma vez que alguns modelos de IA ainda não estão disponíveis na região.

## Escolha a região de residência dos seus dados

Os clientes podem conversar sobre a residência de dados com seu contato de atendimento da Miro.

## Custo adicional por residência de dados

Para a residência de dados padrão na UE, não há nenhum custo adicional.

A residência de dados em regiões fora da UE está disponível somente para clientes Enterprise.
