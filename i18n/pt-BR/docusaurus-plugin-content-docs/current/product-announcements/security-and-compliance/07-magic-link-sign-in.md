O Miro agora oferece suporte à autenticação via Magic Link. Em vez de fazer login com uma combinação de e-mail e senha, os usuários agora podem simplesmente digitar seu e-mail para receber um Magic Link em sua caixa de entrada. Clicar neste link conecta automaticamente o usuário ao Miro. Essa funcionalidade oferece uma série de melhorias à segurança dos seus usuários, incluindo:

- Menor carga para os usuários lembrarem de senhas complexas
- Eliminação da reutilização de senhas (os usuários basicamente recebem uma nova senha a cada vez)
- Risco reduzido de ataques de phishing e preenchimento de credenciais
- Link de login de uso único – o link expira após o uso
