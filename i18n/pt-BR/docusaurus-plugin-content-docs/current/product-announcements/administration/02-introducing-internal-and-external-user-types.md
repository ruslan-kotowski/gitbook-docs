Os admins podem identificar o tipo de usuário como interno para usuários cujo e-mail é verificado, e externo para usuários cujo e-mail não é. A diferenciação visual entre tipos de usuários internos e externos levará a melhorias funcionais em como os admins podem gerenciar usuários no futuro. Para saber mais, consulte o [Controle de Domínio](../../enterprise-administration/canvas-25-admin-features/domain-control/01-domain-control.md).
