Estamos introduzindo endpoints adicionais de API de exportação de board para ajudar você a gerenciar exportações de board com mais eficiência. Você poderá listar trabalhos de exportação em toda a sua organização, visualizar tarefas para um trabalho de exportação específico, recuperar links de download para tarefas de exportação e cancelar trabalhos de exportação que não são mais necessários. Estas atualizações facilitarão o monitoramento, controle e automação de seus fluxos de trabalho de exportação programaticamente.
