Com as **configurações de visualização de Análise**, os admins podem escolher exibir ou ocultar os nomes dos usuários nas visualizações de painel que incluem atividades ao nível do usuário, como os principais usuários de IA. Para mais informações, consulte a [documentação de Análise](../../enterprise-administration/getting-started/admin-analytics/01-analytics-overview.md).
