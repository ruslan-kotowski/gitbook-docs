Para as organizações que utilizam o Microsoft Purview, manter a segurança e a classificação de dados consistente em múltiplas plataformas é essencial. A integração da Miro com o Microsoft Purview permite que os admins importem etiquetas de sensibilidade diretamente do Microsoft Purview para a Miro, simplificando o gerenciamento de esquemas de classificação em ambas as plataformas.

Ao aproveitar essa integração, as organizações podem garantir que o conteúdo dentro da Miro seja classificado de forma consistente com o framework estabelecido pelo Microsoft Purview. Isso não apenas reduz o esforço operacional de recriar ou atualizar manualmente etiquetas de classificação, mas também fortalece a segurança dos dados. Ao alinhar as funcionalidades de proteção de dados da Miro com o Microsoft Purview, os admins podem gerenciar com confiança informações sensíveis em todo o ecossistema digital.
