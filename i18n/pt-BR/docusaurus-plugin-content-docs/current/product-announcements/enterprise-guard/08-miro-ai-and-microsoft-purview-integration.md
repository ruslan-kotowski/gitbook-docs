A Miro está aprofundando sua parceria com a Microsoft para lançar uma integração com o Microsoft Purview Data Security Posture Management (DSPM) para IA, a partir do portal Microsoft Purview. Desenvolvida para organizações que usam o Azure como provedor de identidade, essa funcionalidade envia prompts e respostas de IA da Miro diretamente para o hub AI do Purview. Isso proporciona às equipes de segurança e conformidade uma plataforma única e confiável para monitorar e controlar o uso de IA generativa, reduzindo custos, mitigando riscos como vazamento e uso indevido de dados, e reforçando a governança de IA em nível empresarial da Miro.
