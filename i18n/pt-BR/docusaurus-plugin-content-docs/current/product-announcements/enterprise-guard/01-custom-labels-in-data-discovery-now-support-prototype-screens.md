As etiquetas personalizadas na **descoberta de dados** agora suportam **telas de protótipos** como uma condição de tipo de widget. Os admins podem configurar etiquetas para serem aplicadas automaticamente quando telas de protótipos forem detectadas em um board, estendendo a cobertura de descoberta de dados para conteúdos de protótipos junto com outros tipos de widgets suportados, como cartões do Jira, cartões do Azure e blocos de código.

Com esta atualização, os admins podem:

- Incluir telas de protótipos ao definir condições para etiquetas personalizadas.
- Identificar automaticamente boards que contêm conteúdos relacionados a protótipos.
- Melhorar a cobertura de informações sensíveis ou críticas para o negócio através de mais elementos do board.

Para mais informações, consulte nossa documentação sobre [etiquetas personalizadas](../../enterprise-administration/canvas-25-admin-features/data-discovery/08-custom-business-sensitive-data-discovery-overview.md).
