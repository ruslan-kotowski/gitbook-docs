Para organizações que utilizam o Microsoft Entra ID (anteriormente Azure AD) como seu provedor de identidade, o Enterprise Guard encaminha com segurança prompts e respostas de IA para o Microsoft Purview Data Security Posture Management (DSPM) para IA. As equipes de segurança e conformidade podem então monitorar, auditar e controlar o uso de IA generativa a partir de uma única plataforma confiável, reduzindo a sobrecarga operacional, mitigando riscos como vazamento e uso indevido de dados e fortalecendo a governança de IA em nível empresarial da Miro.
