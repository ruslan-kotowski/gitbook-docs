A time de Acessibilidade do Miro está coletando dicas para projetar e executar sessões colaborativas inclusivas no Miro neste artigo. Iremos atualizá-lo regularmente à medida que aprendermos mais sobre as melhores práticas que funcionam para nossos clientes.

Nossa recomendação geral é verificar se alguém que está participando de uma colaboração assíncrona ou em tempo real tem necessidades de acesso ao preparar seu board da Miro.

Se esse for o caso, recomendamos elaborar instruções claras para todos os participantes da reunião ou colaboração para tornar a experiência inclusiva para todos e garantir que todos estejam familiarizados com elas antes de começar a trabalhar no Miro.

## Usando o Miro Accessibility Checker

O Miro Accessibility Checker permite que todos os usuários criem boards acessíveis. O verificador verifica seu board da Miro para identificar áreas que podem não atender aos padrões de acessibilidade, fornecendo insights práticos para melhorar seu conteúdo para todos os usuários.

O verificador realiza as seguintes verificações:

- Contraste de texto
- Contraste não textual
- Descrições de imagens
- Títulos de contêineres (quadros, tabelas, boards kanban etc.)

Seguir as recomendações do Verificador de Acessibilidade melhorará a acessibilidade para usuários de leitores de tela, bem como para usuários daltônicos e com deficiência visual.

### Como abrir o Verificador de Acessibilidade

Para abrir o Verificador de Acessibilidade, siga estas etapas:

1. Abra um board da Miro.
2. Na [barra do board](../../using-miro/working-on-the-board/02-miro's-new-simplified-user-interface.md), selecione os três pontos verticais.
   Um menu de contexto é aberto.
3. Selecione **board** > **Verificador de Acessibilidade**.
   O painel Verificador de Acessibilidade abre e verifica automaticamente seu board.

## Tornando os boards da Miro mais acessíveis para usuários de leitores de tela

Se você estiver colaborando com usuários de leitores de tela, é possível que eles criem, leiam, editem e excluam objetos em um board da Miro. No entanto, há etapas que você pode seguir para tornar seu board mais fácil de usar.

Geralmente, quanto mais estruturados os boards são, mais fácil é para os usuários de leitores de tela acessarem o conteúdo. Se você quiser ter certeza de que os usuários de leitores de tela possam navegar facilmente pelo board e acessar o conteúdo do board , siga estas recomendações:

- Use [quadros](../../using-miro/essential-tools/07-frames.md) para estruturar o conteúdo do board e certifique-se de que nenhum objeto do board seja colocado fora dos quadros.
- Crie quadros em uma sequência da esquerda para a direita – dessa forma, os usuários poderão acompanhar facilmente o fluxo da sessão colaborativa.
- O ideal é que cada quadro se encaixe na janela de visualização com zoom de 100% do navegador e do Miro canvas – isso garantirá a experiência do usuário mais suave possível. Os quadros também não devem se sobrepor.
- Forneça descrições de imagem para imagens. Basta selecionar qualquer imagem e ativar o botão **ALT** , depois adicionar sua descrição do que o usuário deve perceber.

![acessibilidade-alt-text.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647616796690_accessibility-alt-text.png)
*Adicionar texto alternativo às imagens*

### Adicionar texto alternativo às imagens

Forneça alternativas/descrições de texto para quaisquer elementos visuais complexos, como diagramas — use [texto](../../using-miro/essential-tools/16-text.md) ou [forma](../../using-miro/essential-tools/11-shapes.md) para inserir a anotação.

### Usando cores e etiquetas de nota adesiva conscientemente

Usar [nota adesiva de cores](../../using-miro/essential-tools/14-sticky-notes.md) diferentes é uma ótima maneira de agrupar ideias ou diferenciar entre os colaboradores. Se você deseja tornar seu workshop mais inclusivo, há uma alternativa às cores dos nota adesiva : usar etiquetas para identificar os autores dos nota adesiva ou categorizar os notas adesivas no board.

Acesse o menu do navegador, abra as configurações de zoom e aumente o tamanho da interface do usuário em até 200%. Aumentará o tamanho das barras de ferramentas e controles do Miro .

## Tornando o Miro mais acessível para pessoas com sensibilidade ao movimento

### Desligar os cursores para reduzir distrações no board

O Miro tem tudo a ver com colaboração, e ver os cursores de todos que estão presentes no board é crucial para emular a experiência envolvente presencial.

No entanto, você tem a opção de desativar os cursores quando necessário para reduzir distrações no board, se essa for a preferência do grupo com o qual você está colaborando. Isso também melhorará o desempenho geral do board se você estiver colaborando com dezenas ou centenas de pessoas.

![acessibilidade-ocultar-cursores.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647616803858_accessibility-hide-cursors.png)

*Ocultando os cursores dos colaboradores no board*

### Ativar Reduzir movimento

Animações podem distrair, causar tonturas, enjoo e desencadear enxaquecas. Ative Reduzir movimento (Menu principal > Preferências > Reduzir movimento) para:

- Impedir que GIFs sejam reproduzidos automaticamente.
- Alterne instantaneamente entre quadros usando o painel de quadros .
- Remova transições da interface do usuário ao abrir/fechar caixas de diálogo e menus.

![acessibilidade-reduzir-movimento.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647563446802_accessibility-reduce-motion.png)

*Ativando Reduzir movimento*

## Tornando o Miro mais acessível para pessoas com sensibilidade à luz

### Usando o fundo escuro

Reduza o brilho do seu board acessando o menu de **três pontos** (**...**) > **board** > **Cor de fundo** e escolhendo fundo cinza, cinza escuro ou preto.

![acessibilidade-fundo-cor.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647563448210_accessibility-background-color.png)

*Usando cor de board personalizada*

### Escolhendo cores escuras para objetos no board

Você pode criar [notas adesivas](../../using-miro/essential-tools/14-sticky-notes.md) e [formas](../../using-miro/essential-tools/11-shapes.md) com as cores mais escuras, bem como cores de texto branco/cinza claro, quando apropriado.

## Usando diretrizes para facilitação acessível

A facilitação antes, durante e depois das sessões colaborativas pode ter um grande impacto na acessibilidade da colaboração. Leia nosso guia para aprender sobre [10 princípios para colaboração inclusiva](https://miro.com/10-principles-for-inclusive-collaboration/)

### Permitir que os visitantes tenham acesso mais fácil aos boards

Para facilitar o acesso ao board, um facilitador pode disponibilizá board aos [visitantes](../../using-miro/sharing-boards/08-collaboration-with-visitors.md). Isso significa que aqueles que receberem o link para o board poderão abri-lo sem precisar fazer login ou se inscrever no Miro. Para habilitar isso, vá em Compartilhar e escolha Qualquer pessoa com o link pode editar (disponível nos planos Starter, Business, Education e Enterprise ). Saiba mais.

![acessibilidade-board-sharing.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647563449106_accessibility-board-sharing.png)

*Compartilhando um board com visitantes que podem editar*

Se um usuário não precisar editar um board, considere dar a ele acesso “Pode visualizar” ou “Pode comentar”. Dessa forma, os usuários não precisarão se preocupar em fazer alterações não intencionais.

### Usando recursos de gerenciamento de atenção e links para melhor navegação no board

Para uma navegação mais suave no board, um facilitador pode usar a funcionalidade ["Trazer todos para mim"](../../using-miro/facilitation-tools/04-attention-management.md) . Isso significa que todos que tiverem o board aberto poderão seguir o facilitador no board, onde quer que estejam. Saiba mais.

![acessibilidade-traga-todos.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647563449618_accessibility-bring-everyone.png)

*Trazendo todos os colaboradores para sua visualizar*

Alternativamente, um facilitador também pode [copiar o link](../../using-miro/working-on-the-board/16-internal-and-external-linking.md) para qualquer objeto no board e compartilhá-lo com os colaboradores. Para fazer isso, clique em qualquer objeto, clique no menu de **três pontos** (**...**) e depois **em Copiar link**.

![acessibilidade-copiar-link.png](../../../../../../docs/getting-started/accessibility-in-miro/images/21647563450642_accessibility-copy-link.png)

*A opção de copiar link para um objeto*
