Navegue pelos seus boards da Miro usando comandos de teclado para uma experiência perfeita.

## Barras de ferramentas e painéis

- Pressione **Tab** para navegar entre [barras de ferramentas](../start-here/your-first-board/05-toolbars.md) e painéis.
- Use as teclas de seta para navegar pelos itens e menus da barra de ferramentas.
- Use as setas para cima e para baixo para navegar pela [barra de criação](../start-here/your-first-board/05-toolbars.md).

## Navegação com teclado

### Ativar/desativar atalhos de teclas únicas

Por padrão, os atalhos de um único caractere estão ativados. Para desativá-los (como para evitar interferência com tecnologias assistivas, como leitores de tela):

1. Clique no ícone do **Menu principal** (![icon-main.svg](../../../../../../docs/getting-started/accessibility-in-miro/images/31688274627218_icon-main.svg)) na barra de ferramentas do board.
2. Selecione a opção de menu **Acessibilidade** para abrir o submenu.
3. No submenu, ative ou desative os **Atalhos de um único caractere**.

### Acesse o board

- Pressione **Tab** até chegar ao botão “Pular para o primeiro objeto no board” e pressione **Enter**, ou
- Pressione **B** enquanto o foco estiver em uma barra de ferramentas ou em um painel para movê-lo para o board. Quando estiver focado no board, você pode:
  - Dar zoom in e out com **Ctrl+/Cmd+** e **Ctrl-/Cmd-**.
  - Mover-se pelo board com as teclas de seta.
  - No macOS, pressione **Cmd + Shift + Baixo** para selecionar o primeiro objeto no board.
  - No Windows, pressione **Ctrl + Shift + Baixo** para selecionar o primeiro objeto no board.

### Voltar para as barras de ferramentas

- Pressione **Esc**.

### Navegação linear pelo board

- Use **Tab** para navegar pelos objetos do board em ordem de leitura, do canto superior esquerdo para o canto inferior direito.
- Use **Shift + Tab** para navegar na ordem inversa.

### Navegação espacial pelo board

macOS

**Cmd + teclas de seta** para mover pelos objetos do board em ordem espacial:

- **Cmd + Direita** para mover para o elemento à direita do objeto atual.
- **Cmd + Cima** para mover para o elemento acima do objeto atual.
- **Cmd + Baixo** para mover para o elemento abaixo do objeto atual.
- **Cmd + Esquerda** para mover para a esquerda do objeto atual.

Windows

**Ctrl + teclas de seta** para mover pelos elementos do board em ordem espacial:

- **Ctrl + Direita** para mover para o elemento à direita do objeto atual.
- **Ctrl + Cima** para mover para o elemento acima do objeto atual.
- **Ctrl + Baixo** para mover para o elemento abaixo do objeto atual.
- **Ctrl + Esquerda** para mover para a esquerda do objeto atual.

### Pular para o primeiro ou último objeto

macOS

- **Option + Shift + Seta para a esquerda**, ou **Option + Home,** para pular para o primeiro objeto no contêiner atual.
- **Option + Shift + Seta para a direita**, ou **Option + End**, para pular para o último objeto no contêiner atual.

Windows

- **Alt + Shift + Seta para a esquerda**, ou **Alt + Home**, para pular para o primeiro objeto no contêiner atual.
- **Alt + Shift + Seta para a direita**, ou **Alt + End**, para pular para o último objeto no contêiner atual.

### Entrar ou sair de um objeto contêiner

Objetos de contêiner incluem quadros e objetos agrupados. Enquanto estiver em um objeto contêiner, toda a navegação ficará restrita a esse contêiner.

macOS

- **Cmd + Shift + Baixo** para inserir um objeto contêiner.
- **Cmd + Shift + Cima** para sair de um objeto contêiner.

Windows

- **Ctrl + Shift + Baixo** para inserir um objeto contêiner.
- **Ctrl + Shift + Cima** para sair de um objeto contêiner.

### Editar texto do objeto

- Pressione **Enter** em um objeto para iniciar a edição (por exemplo, uma nota adesiva).
- Pressione **Esc** em um objeto para parar a edição (por exemplo, uma nota adesiva).

:::note
A navegação pelo teclado só funciona quando os objetos são selecionados, não enquanto estão sendo editados.
:::

### Mover objetos

- Use **as teclas de seta** para mover um objeto.
- Use **Shift + tecla de seta** para mover um objeto para mais longe.

### Selecionar vários objetos do board

macOS

- Selecione o primeiro objeto.
- Pressione **Cmd** + **Option** + **Shift** + **Seta** para escolher cada objeto adicional.

Windows

- Selecione o primeiro objeto.
- Pressione **Ctrl** + **Alt** + **Shift** + **Seta** para escolher cada objeto adicional.

### Redimensionando objetos no board

macOS

- Selecione o board que você gostaria de redimensionar.
- Pressione **Cmd** + **Option** + **Shift** + **Mais/Menos**.

Windows

- Selecione o board que você gostaria de redimensionar.
- Pressione **Ctrl** + **Alt** + **Shift** + **Mais/Menos**.

### Entrar e navegar no menu de contexto de um objeto

O menu de contexto de um objeto inclui funcionalidades adicionais que permitem personalizar o objeto, como alterar sua cor, tipo ou estilo de texto. Após selecionar um objeto, seu menu de contexto aparecerá horizontalmente acima do objeto, fornecendo acesso a essas opções.

macOS

- Pressione **Cmd + Enter** para mover o foco para o menu de contexto de um objeto.
- Use as **teclas de seta para a esquerda/direita** para navegar pelo menu de contexto de um objeto e **Enter/Espaço** para selecionar um item.

Windows

- Pressione **Ctrl + Enter** para mover o foco para o menu de contexto de um objeto.
- Use as **teclas de seta esquerda/direita** para navegar pelo menu de contexto de um objeto e **Enter/Espaço** para selecionar um item.

### Criar um novo objeto

A maneira mais fácil de adicionar um novo objeto é usar a Paleta de Comando:

macOS

- Pressione **Cmd+K** para abrir a Paleta de Comando.
- Comece a digitar o nome do objeto, por exemplo, Nota Adesiva.
- Use as **setas** para selecionar o objeto.
- Pressione a **tecla Enter** e o objeto será adicionado ao centro do board.

Windows

- Pressione **Ctrl+K** para abrir a Paleta de comando.
- Comece a digitar o nome do objeto, por exemplo, Nota adesiva.
- Use as **setas** para selecionar o objeto.
- Pressione a **tecla Enter** e o objeto será adicionado ao centro do board.

Outras maneiras de criar um objeto usando o teclado incluem:

- Use a tecla **Tab** para navegar até a [barra de ferramentas de criação](../start-here/your-first-board/05-toolbars.md), depois pressione as **setas para cima ou para baixo** até chegar ao tipo de objeto desejado (forma, nota adesiva, etc.) e pressione **Enter**, depois **Tab** para selecionar o objeto e pressione **Enter** novamente para criar o objeto. O objeto será colocado no board.
- Pressione o atalho de teclado associado ao objeto (por exemplo, **N** para notas adesivas), depois pressione **Tab** para selecionar o objeto e, em seguida, pressione **Enter**. O objeto será colocado no board.
- Copie e cole um elemento existente com **Ctrl**/**Cmd+C** e **Ctrl/Cmd+V**.
- Duplique um objeto existente com **Ctrl/Cmd+D**.
- Para editar uma nota adesiva, pressione **Enter**, depois **Tab** e um novo objeto será criado adjacente ao objeto selecionado.

### Criar conexões de diagramas

Você pode criar linhas de conexão entre objetos no board.

- Use a tecla Tab para o primeiro objeto que deseja conectar.
- Pressione Cmd+K (Mac) ou Ctrl+K (Windows) para abrir a Paleta de Comandos.
- Digite e selecione **Criar conexão com**.
- Use a tecla Tab para o segundo objeto.
- Pressione Cmd+K (Mac) ou Ctrl+K (Windows) para abrir a Paleta de Comandos.
- Digite e selecione **Conectar a este objeto**.

### Comentários

macOS

- **Option+Tab** para navegar para frente pelos comentários.
- **Option+Shift+Tab** para navegar para trás pelos comentários.
- **Option+**C para adicionar um comentário ao objeto atual.

Windows

- **Alt + C** para adicionar um comentário ao objeto atual.

## Comandos de tecnologia assistiva

Os seguintes comandos de teclado só estão disponíveis ao usar tecnologias assistivas, como leitores de tela.

### Resumo do board

O resumo do board fornece aos usuários de leitores de tela uma breve visão geral dos objetos no board.

macOS

- **Option + S** para receber informações sobre o número e os tipos de objetos no board.

Windows

- **Alt + S** para receber informações sobre o número e os tipos de objetos no board.

### Informações adicionais do objeto

Esta ação fornece aos usuários de leitores de tela informações adicionais sobre o objeto selecionado no momento.

macOS

- **Option + I** para receber informações adicionais do objeto.

Windows

- **Alt + I** para receber informações adicionais do objeto.

### Anúncio de seleção de objeto

É possível repetir as informações fornecidas ao selecionar o objeto do board.

macOS

- **Option + R** para repetir o anúncio de seleção.

Windows

- **Alt + R** para repetir o anúncio de seleção.
