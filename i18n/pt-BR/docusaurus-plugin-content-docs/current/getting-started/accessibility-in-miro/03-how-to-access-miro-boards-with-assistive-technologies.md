Miro dá suporte a controle por teclado, leitores de tela e software de reconhecimento de voz. Este artigo explica como usar a Miro com tecnologias assistivas.

> **💡** Visite o [Hub de Acessibilidade da Miro](https://miro.com/accessibility-statement/) para saber mais e ficar atualizado sobre todas as nossas últimas novidades.

:::tip
Estamos empenhados em melhorar continuamente a experiência de acessibilidade dos nossos usuários. Por favor, envie seu feedback para [accessibility@miro.com](mailto:accessibility@miro.com).
:::

## Navegadores e leitores de tela recomendados

:::note
A equipe da Miro Accessibility continua trabalhando para melhorar a compatibilidade com tecnologias assistivas e atualizará esta lista à medida que ela se tornar mais compatível com outros navegadores, leitores de tela e dispositivos.
:::

Recomendamos usar os seguintes navegadores e leitores de tela na área de trabalho para obter a melhor experiência possível:

### Navegadores

- Chrome
- Firefox
- Safari

### Leitores de tela

- NVDA para Microsoft Windows
- JAWS para Microsoft Windows
- VoiceOver integrado para macOS

### Reconhecimento por voz

- Controle por voz para macOS
- Acesso por voz para Microsoft Windows

:::note
No momento, oferecemos suporte limitado para tecnologias assistivas em dispositivos móveis e tablets.
:::

## Voz para texto

### Controle por voz para macOS

Ao ativar Controle por Voz no macOS, o botão **Explorar conteúdo do board** aparece no seu board do Miro.

:::note
Para saber como ativar o Controle por Voz no MacOS, consulte o [suporte da Apple](https://support.apple.com/en-gb/102225).
:::

:::tip
No seu Mac, quando você habilitar o **Controle por Voz** em **Ajustes**, certifique-se de definir também **Sobreposição** como **Nomes dos Itens**.
:::

Para começar a dar comandos, diga *Pressionar Explorar conteúdo do board*. A Miro mostra os nomes dos itens para cada ferramenta e objeto no board.

Por exemplo, diga *Pressionar Explorar conteúdo do board*, depois dê os seguintes comandos para adicionar uma nota adesiva com texto:

1. *Pressione **Nota adesiva***
2. *Pressione **Colocar nota adesiva amarela clara***
3. *Pressione a tecla **Enter***
4. *“Olá, Mundo!”*
5. *Pressione a tecla **Esc***

### Acesso por voz para Microsoft Windows

Quando você habilita o Acesso por voz no Windows, diga *Mostrar números.* Diga *Clique* e o número que aparece no centro da sua tela. Por exemplo, diga *Clique 44*. A Miro é ativada para Acesso por voz.

:::note
Para saber como ativar o Voice Access para o MS Windows, consulte o [Suporte da Microsoft](https://support.microsoft.com/en-gb/windows/use-voice-recognition-in-windows-83ff75bd-63eb-0b6c-18d4-6fae94050571).
:::

Para começar a dar comandos, diga *Mostrar números*. Depois diga *Clique* e o número da ferramenta ou objeto que deseja usar.

## Leitores de tela

O board da Miro é estruturado da seguinte forma:

- Barras de ferramentas
- Pular para o primeiro objeto no botão do board
- Visão geral/índice do conteúdo do board
- Conteúdo do board

## Barras de ferramentas

Existem cinco barras de ferramentas em um board da Miro:

- Menu e configurações do board
- Barra de ferramentas de colaboração
- Barra de ferramentas de criação
- Visão geral do board
- Controles de zoom e barra de ferramentas de navegação

> **💡** Consulte nosso [artigo sobre barras de ferramentas](../start-here/your-first-board/05-toolbars.md) para uma visão completa.

### Como usar as barras de ferramentas

- Para navegar pelas barras de ferramentas, pressione **Tab**.
- Para navegar dentro de uma barra de ferramentas, use as **teclas de seta**.
- Para ativar um item, pressione **Enter**.

## Pular para o primeiro objeto no board

Ativar o botão **Pular para o primeiro objeto no board** moverá o foco para o primeiro objeto no board.

### Como usar “Pular para o primeiro objeto no board”

- Para mover o foco para o primeiro objeto no board da Miro, pressione **Enter**.
- Pressione **Esc** para voltar às barras de ferramentas.

## Explorar o conteúdo do board

A função **Explorar o conteúdo do board** fornece uma visão geral da estrutura do board, como um índice que pode ser navegado e usado para mover-se diretamente para os objetos do board.

### Como usar "Explorar o conteúdo do board"

- Para ativar a visão geral do board, pressione a tecla **Enter** no botão **Explorar o conteúdo do board**.
- Use a navegação do leitor de tela para percorrer a visão geral. Por exemplo:
  - JAWS:
    - Use **as setas** para mover-se por todos os objetos.
    - Pressione **H** para navegar por todos os objetos do tipo contêiner, como quadros.
    - Pressione **F** para navegar por todos os objetos editáveis ​​do board, como notas adesivas.
- Para mover o foco para um objeto do board, pressione **Enter** – isso moverá o foco para o objeto no board da Miro.
- Pressione **Enter** novamente para editar o objeto.
- Pressione **Esc** para mover o foco de volta para a visão geral do board.
