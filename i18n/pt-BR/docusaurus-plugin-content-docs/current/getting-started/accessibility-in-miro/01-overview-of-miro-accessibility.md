A Miro visa ser uma plataforma acessível para todos os usuários, incluindo pessoas com deficiências. Os usuários de tecnologia assistiva devem conseguir colaborar perfeitamente com todos os outros usuários.

## Conformidade e remediação

A Miro está comprometida em realizar auditorias regulares de conformidade com os padrões WCAG 2.2 AA e implementar remediações para resolver problemas de acessibilidade. Isso inclui a publicação anual de um Relatório de Conformidade de Acessibilidade (ACR), com base no Modelo Voluntário de Acessibilidade de Produtos (VPAT), acentuando nosso progresso e compromisso com os padrões de acessibilidade.

## Prevenção e educação

É fundamental prevenir problemas de acessibilidade. A Miro integra a acessibilidade ao ciclo de vida de desenvolvimento do produto, até mesmo nas fases de design, desenvolvimento e teste. A educação, o treinamento e a pesquisa com usuários são priorizados, promovendo uma mentalidade de design inclusiva.

## Suporte à navegação pelo teclado e tecnologia assistiva

A Miro fornece navegação aprimorada por [teclado](05-keyboard-navigation-while-working-on-boards.md), permitindo que os usuários naveguem por elementos da interface e objetos do board de maneira eficiente. Isso inclui modos de navegação linear, espacial e hierárquica.

Além disso, a Miro garante suporte a tecnologias assistivas ao disponibilizar etiquetas, descrições e ações para os objetos.

Também é possível criar, ler, atualizar e excluir objetos em um board da Miro apenas com o teclado e usando [tecnologias assistivas](03-how-to-access-miro-boards-with-assistive-technologies.md), como leitores de tela e software de reconhecimento de voz.

Atalhos são fornecidos para facilitar essas e outras ações. Atalhos de um único caractere podem ser desabilitados para evitar interferência com tecnologias assistivas.

## Funcionalidades de Acessibilidade e Inovações

Princípio: o design voltado para a acessibilidade melhora a experiência de todos os usuários.

- [**Configuração de Movimento Reduzido**](06-reduce-motion.md)**:** Usuários podem limitar animações para reduzir o enjoo.
- **Cor do fundo do board:** Mude as [cores do fundo do board](../../using-miro/working-on-the-board/12-board-background-color.md) para melhor visibilidade.
- **Etiquetas de Cor:** As cores nos menus de contexto são rotuladas para facilitar a identificação.
- [**Paleta de comando**](../../using-miro/working-on-the-board/04-command-palette.md)**:** Acesse um menu contextual semelhante ao rotor do VoiceOver para navegação rápida.
- **Legendas para** [**TalkTrack**](../../using-miro/facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md)**:** Grave áudio nos boards com legendas para inclusão.

## Criadores de boards

Princípio: a Miro reconhece que, embora seja possível proporcionar uma experiência acessível, muito depende das pessoas que criam os boards ou facilitam reuniões para projetarem boards acessíveis da Miro. A Miro criou as seguintes funcionalidades para ajudar nesse processo:

- **Texto Alternativo para Imagens:** Forneça texto alternativo para imagens.
- **Verificador de Acessibilidade do Miro:** O [Verificador de Acessibilidade do Miro](../start-here/your-first-board/03-miro-accessibility-checker.md) ajuda os usuários a identificar e resolver problemas comuns, como baixo contraste de texto, falta de texto alternativo e uso inadequado de quadros. Vale ressaltar que esta funcionalidade está atualmente em Beta.

A Miro também fornece orientações sobre [Como tornar os seus boards no Miro mais acessíveis](04-how-to-make-your-miro-boards-more-accessible.md).

## Diretrizes de colaboração inclusiva

A Miro publicou um eBook delineando os [10 princípios para colaboração inclusiva](https://miro.com/10-principles-for-inclusive-collaboration/). Este recurso ensina os organizadores a realizar reuniões que sejam acessíveis e eficazes.

## Conclusão

A Miro está comprometida em inovar e melhorar a acessibilidade das ferramentas de forma contínua. A Miro convida todos os usuários a testar essas funcionalidades e fornecer feedback, ajudando a criar um ambiente de colaboração digital mais inclusivo.

## Feedback e mais informações

Para mais informações, acesse a página de acessibilidade da Miro em [miro.com/accessibility](http://miro.com/accessibility). Seu feedback é crucial para moldarmos nossos esforços de acessibilidade. Portanto, deixe comentários ou sugestões de melhorias.
