Você pode importar em massa seus diagramas de aplicativos de origem como PDF ou VSDX.

:::note
Para alguns aplicativos de origem, apenas um tipo de arquivo é suportado. Para verificar, veja Suporte a tipos de arquivo de importação.
:::

## Como importar diagramas em massa para a Miro

Para importar seus diagramas para a Miro, certifique-se de ter exportado o(s) arquivo(s) do seu aplicativo de origem como PDF ou VSDX. Em seguida, siga o procedimento a seguir.

1. No seu painel do Miro, para o Espaço onde você deseja importar diagramas, clique em **Criar novo** (**+**).
   ![](../../../../../../docs/getting-started/migrating-content-to-miro/images/32654520716690_image.png)
2. Clique em **Importar** > **Importar de \{source\}**. Por exemplo, **Importar de Mural**.
   O modal **Importar de \{source\}** é aberto.
3. Siga as instruções na tela.
4. (Opcional) Altere o Espaço de destino para importação. Ou clique no botão de mais (**+**) para criar um novo Espaço de destino.
5. Clique em **Importar** ***x*** **arquivos**.

## Suporte para importação de tipos de arquivos

| Fonte | Tipo de arquivo |
| --- | --- |
| Conceptboard | PDF, VSDX |
| Lucidchart | PDF, VSDX |
| Lucidspark | PDF, VSDX |
| Mural | PDF |
| Visio | VSDX |
