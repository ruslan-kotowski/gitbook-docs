Um board da Miro é um espaço de trabalho online que você pode usar para visualizar suas ideias e trabalhar em projetos individualmente ou com um time.

Quando você [cria uma conta na Miro](../02-how-to-register-with-miro.md), seu primeiro board é criado automaticamente e é salvo no seu próprio time gratuito ou no time para o qual você foi convidado. Você pode encontrá-lo em seu painel, com o nome de Meu Primeiro Board.

## Métodos para criar um board da Miro

Você pode criar quantos novos boards quiser a partir do seu painel ou diretamente da barra de endereços do seu navegador.

### Como criar um board a partir do painel

Para criar um board a partir do painel, siga estas etapas:

1. Abra seu painel.
   1. Se você for membro de vários times, escolha em qual time deseja salvar seu board.
   2. Para criar um board em um espaço específico, abra o espaço.
2. Clique em **+ Criar novo**.
   Um menu é aberto.
3. Clique em **Board**.
   Um novo board é criado.

### Criar um board a partir de um template

Para criar um board a partir de um template, siga estas etapas:

1. Clique em **+ Criar novo** no seu painel.
   Um menu é aberto.
2. Clique em **Explorar templates**.
   O seletor de templates é aberto.
3. Procure ou pesquise por um template relevante.
4. Clique em **Usar template** para abrir um novo board com o template. Como alternativa, clique em **Visualizar** para ver mais informações sobre o template.
5. A partir da visualização do template, você pode clicar em **Usar template** para abrir um novo board com o template.

### Como criar um board a partir da barra de endereços do navegador

Para criar um board a partir da barra de endereços do navegador, siga estas etapas:

1. Digite **miro.new** na barra de endereços do navegador.
   Um novo board será aberto na janela do seu navegador.
2. Se você for membro de vários times, escolha em qual time deseja salvar seu board clicando em Alternar time.
3. Se você não estiver logado, será solicitado que faça login antes que o novo board seja aberto.

## Solução de problemas: Por que não consigo criar um board?

Existem três possíveis razões pelas quais você pode não conseguir criar um board: você não é membro do time, não tem o tipo de licença correto ou as configurações do seu time impedem isso.

**Você não é membro do time**

- Você é um convidado no time e, portanto, não pode criar novo conteúdo. Peça ao titular do board para participar do time ou tente ingressar no time a partir do seu painel.
- Você ainda não é membro de um time da Miro. Para criar seu próprio time da Miro, clique no ícone de adição na barra lateral do seu painel.
- Você recebeu um convite para um board sem ser convidado para o time. Clique em Pedir para participar do time para criar um novo board nesse time.

**Você tem o tipo de licença errado**

Você é membro de um plano Enterprise e não pode criar boards porque tem uma licença gratuita limitada. Para criar boards, solicite acesso de edição e peça ao seu Admin da empresa para converter sua licença em licença completa.

**Configurações do time impedem isso**

Você é membro de um time do plano Enterprise e não pode criar boards porque seu Admin da empresa restringiu a criação de conteúdo nas configurações do time. Para criar boards, peça ao Admin da empresa para conceder direitos de criação de conteúdo.

## Perguntas frequentes

**Como faço para copiar um board?**

Clique no ícone do **menu principal** na barra de ferramentas no canto superior esquerdo, depois clique em **Board**, e no submenu clique em **Fazer uma cópia**.

**Mais informações:** Consulte [Como duplicar um board](../../../using-miro/managing-boards/03-how-to-duplicate-a-board.md).

**Posso copiar o conteúdo do board de um board para outro?**

Sim, [selecione o conteúdo](../../../using-miro/working-on-the-board/10-working-with-objects.md) que você deseja copiar e use Ctrl + C/Ctrl + V para Windows ou Cmd + C/Cmd + V para Mac.

**Como faço para excluir um board?**

Clique no ícone do **menu principal** na barra de ferramentas no canto superior esquerdo, depois clique em **Board**, e no submenu clique em **Excluir**.
