O lousa online da Web éum lousa digital simples e gratuita que você pode usar sem precisar se inscrever ou fazer login. Execute sua próxima sessão de brainstorming ou tutoria on-online no Web lousa online. Basta acessar [webwhiteboard.com](https://webwhiteboard.com/), crie um board e compartilhe o link com sua time.

:::note
Para saber mais, visite também [webwhiteboard.com/home](https://webwhiteboard.com/home/).
:::

:::warning
O lousa online da Web não é compatível com o modo anônimo do Chrome ou com o Safari.
:::

### O que é Web lousa online?

O Web lousa online está disponível gratuita para todos os usuários, sem necessidade de registro, em dispositivos desktop e tablets. Você também pode usá-lo com uma caneta em tablets, pois ele suporta rejeição de palma e [Rabisco de maçã](https://support.apple.com/guide/ipad/enter-text-with-scribble-ipad355ab2a7/ipados).

Para começar a usar o Web lousa online, abra [webwhiteboard.com](https://webwhiteboard.com/)no navegador e crie um novo board.

Você pode compartilhar este link com sua time, e eles poderão colaborar com você em tempo real sem precisar fazer login ou se inscrever no Miro. Para compartilhar o link, clique no botão **Compartilhar board** no canto superior direito da tela – o link para o board será copiado para sua área de transferência, e qualquer pessoa com o link terá acesso de edição ao seu board.

![compartilhar_webwhiteboard.jpg](../../../../../../docs/using-miro/special-features/images/21019704270610_share%20webwhiteboard.jpg)
*Compartilhando um board no lousa online da Web*

Os boards lousa online da Web estão disponíveis 24 horas. UMDepois disso, ele fica bloqueado por 7 dias. Durante esse período, você pode se inscrever/entrar no Miro para desbloquear e salvar o board. Se o board não for desbloqueado/salvo dentro de 7 dias, ele será completamente excluído.

Como alternativa, você pode baixar seu board como uma imagem ou .pdf – basta clicar no ícone Exportar este board ao lado do logotipo do lousa online da Web no canto superior esquerdo da tela e escolher **imagem** ou **PDF** no pop-up.

:::warning
Observe que se você não salvar ou exportar seu board, ele será **excluído permanentemente** após 7 dias.
:::

![export_webwhiteboard.gif](../../../../../../docs/using-miro/special-features/images/21019704274066_export%20webwhiteboard.gif)
*Exportando um board no Web lousa online*

![webwhiteboard_popup.jpg](../../../../../../docs/using-miro/special-features/images/21019704276882_webwhiteboard%20popup.jpg) *O pop-up que você pode ver após 24 horas*

### O que acontece quando você quer salvar seu board?

Se você for um usuário registrado do Miro , terá a opção de salvar seu board e escolher em qual das times deseja salvá-lo, caso tenha várias.

![salvar_nos_meus_quadros.jpg](../../../../../../docs/using-miro/special-features/images/21019704281618_save%20to%20my%20boards.jpg)
*Salve seu board para uma time Miro*

Se você for um usuário do Web lousa online e ainda não tiver um perfil da Miro , será necessário se inscrever no Miro para continuar editando seu board após 24 horas.

![inscreva-se no Miro.jpg](../../../../../../docs/using-miro/special-features/images/21019704278418_sign%20up%20to%20Miro.jpg)
*Registre um perfil da Miro para salvar sua board nele*

O usuário que se registrar primeiro no Miro se tornará o titular do board que salvar. Outros colaboradores ainda terão acesso a este board com o mesmo link e poderão continuar trabalhando nele como [visitantes](../sharing-boards/08-collaboration-with-visitors.md).

### Perguntas frequentes

1. *Preciso ser um usuário do Miro para usar o Web lousa online?*- Não, você não precisa. O Web lousa online é um lousa digital gratuito que qualquer pessoa pode usar sem precisar de registro.
2. *Por quanto tempo posso trabalhar no meu board lousa online da Web ?*- Cada board lousa online da Web fica ativo por 24 horas, depois disso ele é bloqueado e excluído permanentemente após 7 dias, a menos que você faça login e salve o board. Se quiser continuar trabalhando com seu board , você pode [se inscrever no plano Miro Free](../../getting-started/start-here/02-how-to-register-with-miro.md) para salvar seu trabalho ou exportar seu board como uma imagem ou .pdf.
3. *Preciso pagar para continuar trabalhando no meu board lousa online da Web ?*- Não, você só precisa se [inscrever no plano Miro Free](../../getting-started/start-here/02-how-to-register-with-miro.md) para continuar trabalhando na sua board.
4. *Qual é a diferença entre o Web lousa online e o Miro?*- O Web lousa online é uma versão mais simples e leve do Miro. Ele tem menos recursos que os planos Miro [plano e](../../plans-billing/miro-plans/09-free-plan.md) [planos](../../plans-billing/miro-plans/02-plans-and-features-available.md).
