Para imprimir seu board da Miro:

1. Acesse as opções de exportação clicando no ícone de **três pontos** (**...**) na barra de ferramentas superior esquerda > **Board** > **Exportar**.
2. Exporte o board como imagem ou PDF.
3. Abra e imprima o arquivo exportado.

> **⚠️** Para exportar PDFs de alta resolução é necessário um plano pago. Os clientes do plano Free só podem exportar arquivos PDF de baixa resolução e com marca d'água. Para saber mais sobre as opções de exportação de boards, visite [esta página](03-how-to-export-your-board.md).

![export-entry-point.png](../../../../../../../docs/using-miro/import-and-export/export/images/21537453537298_export-entry-point.png)
*Opções de exportação do board*

Se você optar por salvar o board como PDF, cada [quadro](../../essential-tools/07-frames.md) no board será criado como uma página separada do documento PDF. Se você deseja que um gráfico, diagrama ou imagem inteiro seja impresso em uma única página, pode usar um quadro de tamanho A4 ou carta, pois ele corresponde automaticamente ao tamanho padrão do papel.

Para a melhor experiência, crie quadros e trabalhe no board com um nível de zoom de 100%.

Se o texto ou os objetos no documento impresso forem muito pequenos, você pode selecionar os objetos e aumentar o tamanho no board, depois reexportar e imprimir novamente.

Se você tiver problemas para exportar seu board, consulte nosso [guia de solução de problemas](../../tools/troubleshooting/03-board-export-issues.md).
