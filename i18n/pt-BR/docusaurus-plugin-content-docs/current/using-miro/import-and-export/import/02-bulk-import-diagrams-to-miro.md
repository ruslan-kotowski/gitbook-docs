Você pode importar em massa seus diagramas de aplicativos de origem como PDF ou VSDX.

:::note
Para alguns aplicativos de origem, apenas um tipo de arquivo é suportado. Para verificar, consulte Suporte a tipos de arquivo para importação.
:::

## Como importar diagramas em massa para a Miro

Para importar seus diagramas para a Miro, assegure-se de ter exportado o(s) arquivo(s) do seu aplicativo de origem como PDF ou VSDX. Em seguida, complete o seguinte procedimento.

1. No seu painel do Miro, para o Espaço onde deseja importar diagramas, clique em **Criar novo** (**+**).
   ![](../../../../../../../docs/using-miro/import-and-export/import/images/32657459157138_image.png)
2. Clique em **Importar** > **Importar de \{source\}**. Por exemplo, **Importar de Mural**.
   O modal **Importar de \{source\}** será aberto.
3. Siga as instruções na tela.
4. (Opcional) Altere o Espaço de destino para a importação. Ou clique no botão de mais (**+**) para criar um novo Espaço de destino.
5. Clique em **Importar** ***x*** **arquivos**.

## Suporte para tipos de arquivo de importação

| Fonte | Tipo de arquivo |
| --- | --- |
| Conceptboard | PDF, VSDX |
| Lucidchart | PDF, VSDX |
| Lucidspark | PDF, VSDX |
| Mural | PDF |
| Visio | VSDX |
