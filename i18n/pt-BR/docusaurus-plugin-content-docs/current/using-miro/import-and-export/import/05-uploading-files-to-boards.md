A maneira mais fácil de adicionar arquivos aos seus boards é simplesmente arrastar e soltá-los a partir do seu desktop. Você pode adicionar imagens, arquivos PDF, documentos do Google Drive e arquivos do MS Office. A lista completa dos tipos de arquivos compatíveis está disponível [neste artigo](../../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md). Novos arquivos podem ser adicionados do seu computador ou da web (o tamanho máximo do arquivo é 30 MB, a resolução máxima da imagem é 32 MP, as dimensões máximas são 8192x4096 pixels).

> **Configurado por:** [Editores do board](../../sharing-boards/01-board-access-rights.md)
> **Disponível para:**Todos os planos Miro (Planos Free sem capacidade para reproduzir vídeos incorporados)

### Como adicionar arquivos a partir do seu dispositivo

Para carregar arquivos do seu dispositivo, escolha **Carregar** na barra de ferramentas de criação. Se a opção estiver oculta para você, clique nas setas **mais ferramentas** (>>) e adicione o botão à barra de ferramentas. Clique em **Meu Dispositivo**.

![upload_on_the_toolbar_greybg.gif](../../../../../../../docs/using-miro/import-and-export/import/images/21016967591442_upload_on_the_toolbar_greybg.gif)
*O botão Carregar na barra de ferramentas*

Isso abrirá uma caixa de diálogo, onde você poderá selecionar os arquivos que deseja carregar para o board. Depois de selecionar os arquivos e clicar em **Abrir**, eles serão carregados e aparecerão no board.

Outra maneira simples para carregar arquivos do seu computador é arrastá-los e soltá-los no board.

:::note
Confira a lista de formatos de arquivo compatíveis [aqui](../../troubleshooting-technical-questions/technical-guidelines/03-supported-file-formats.md).
:::

Você pode interagir com arquivos carregados: alterar o tamanho, girá-los, virar e extrair páginas.

![change_an_uploaded_object_greybg.gif](../../../../../../../docs/using-miro/import-and-export/import/images/21016967592850_change_an_uploaded_object_greybg.gif)
*Interagindo com um arquivo PDF carregado*

Se você usar o [aplicativo móvel](../../../getting-started/apps-for-devices/08-mobile-app.md), pressione o ícone de mais no canto inferior direito do board, escolha **Carregar**. Você pode colar um arquivo a partir da área de transferência, tirar uma foto ou escolher uma imagem da galeria móvel. O upload de arquivos PDF a partir de dispositivos móveis não é compatível no momento.

![upload on mobile.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005106578_upload%20on%20mobile.png)
*Carregando um arquivo a partir de um dispositivo móvel*

### Como adicionar arquivos por meio de links de URL

Para carregar arquivos a partir da web usando um link direto para a fonte, escolha **Carregar por** **URL.**

*![Upload via URL.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005103890_Upload%20via%20URL.png)**Carregar via URL na barra de ferramentas*

Em seguida, cole um link direto de URL para um arquivo a partir da web, como um vídeo do YouTube ou do Vimeo.

![upload via URL modal.png](../../../../../../../docs/using-miro/import-and-export/import/images/21016967594898_upload%20via%20URL%20modal.png)
*Como carregar por meio de um link de URL*

:::note
A reprodução de vídeos incorporados não está disponível em planos Free e para usuários com licença básica.
:::

Para assistir a um vídeo, clique duas vezes no ícone **Reproduzir** (o arquivo adicionado não será reproduzido automaticamente). Você também poderá ir para a página de **Origem** e usar outras funções no menu de contexto.

Você pode gerenciar os vídeos carregados na Miro diretamente a partir dos seus boards: pode acelerar um vídeo, adicionar legendas e alterar sua qualidade.

![video embed.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005108114_video%20embed.png)
*A opção de ir para a fonte do vídeo*

Outra opção é postar um link para um arquivo diretamente em um board usando os atalhos **Ctrl+C**/**Ctrl+V** (*para Windows*) ou **Cmd+C/Cmd+V** (*para Mac*).

Para colar o link de URL em um board sem pré-visualização, use a [ferramenta de texto](../../essential-tools/16-text.md) e cole o link na caixa de texto.

### Como carregar arquivos a partir de outros serviços

Você também pode carregar arquivos do [Google Drive](../../../integrations-apps/google/05-google-drive.md), [Dropbox](../../../integrations-apps/more-integrations/06-dropbox.md), [Box](../../../integrations-apps/more-integrations/05-box-legacy.md), [OneDrive](../../../integrations-apps/microsoft/06-onedrive.md), e [Adobe CC](../../../integrations-apps/adobe/02-adobe-creative-cloud.md). Todas as opções estão disponíveis no menu **Carregar**. Verifique os artigos correspondentes para saber mais.

Note que [visitantes](../../sharing-boards/08-collaboration-with-visitors.md) não podem usar essa opção.

*A opção de carregar arquivos a partir de diferentes serviços de armazenamento*

### Como salvar arquivos carregados na galeria

Você pode salvar os arquivos carregados na sua galeria da Miro para uso futuro neste time selecionando o arquivo, clicando nos três pontos do menu de contexto e selecionando **Adicionar a arquivos salvos**. Isso funciona para PDFs, imagens, apresentações, documentos do Google e outros arquivos.

![add to saved files.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005108882_add%20to%20saved%20files.png)
*A opção de adicionar um arquivo a Arquivos salvos*

Os arquivos salvos estão disponíveis na pasta **Arquivos salvos** no menu **Carregar** na barra de ferramentas. Para adicionar um arquivo da biblioteca, clique nele ou arraste-o e solte-o no board. Observe que os arquivos salvos só estarão acessíveis nos boards do time ao qual o board de origem pertence.

![saved files.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005109522_saved%20files.png)
*Arquivos salvos na barra de ferramentas*

Para excluir um arquivo da biblioteca, passe o mouse sobre ele e clique no ícone da **Lixeira**.

![delete a saved file.png](../../../../../../../docs/using-miro/import-and-export/import/images/21017005111314_delete%20a%20saved%20file.png)
*Exclua um arquivo de Arquivos salvos clicando no ícone da Lixeira*

Se a opção **Adicionar a arquivos salvos** estiver inativa (cinza) e a mensagem de erro indicar **Esta ferramenta não está disponível neste board**, isso significa que você não tem direitos suficientes para concluir a ação, porque não é membro do time onde o board está armazenado.

### Dividir documentos de várias páginas

> **Disponível em:** versão para navegador, [aplicativo para desktop](../../../getting-started/apps-for-devices/05-desktop-app.md)

Uma maneira de o seu time colaborar em documentos, arquivos PDF ou PowerPoint: expanda as páginas, organize-as no board e deixe comentários diretamente nas páginas.

Para dividir um arquivo PDF ou um arquivo do PowerPoint em um determinado número de páginas:

1. Carregue o arquivo no board.
2. Clique no arquivo. No menu de contexto, escolha o ícone **Extrair páginas**.

   > ✏️ A opção está disponível apenas no modo [cursor (seleção)](#mini). Se a opção não aparecer no menu, pressione **V** ou selecione o cursor na barra de ferramentas e clique no objeto novamente.
3. No diálogo, escolha como deseja dividir o arquivo — todas ou apenas páginas específicas e clique em **Extrair.**

As páginas expandidas aparecerão logo abaixo do arquivo original. Se o arquivo original for desnecessário, você pode excluí-lo — todas as páginas extraídas permanecerão no board.

### Possíveis problemas com o carregamento de arquivos PDF

Alguns arquivos PDF podem falhar ao carregar em um board da Miro — eles ficam emperrados na roda de carregamento ou se tornam imagens cinzas com um sinal de erro. Se você estiver enfrentando este problema, certifique-se de verificar se:

- Seu arquivo PDF não ultrapassa 30 MB
- Você está usando uma conexão de internet estável
- Seu dispositivo atende aos [requisitos mínimos de sistema](../../troubleshooting-technical-questions/technical-guidelines/01-system-requirements.md)

Se você ainda não consegue carregar um arquivo para o seu board, o próprio arquivo pode estar causando o problema. Alguns arquivos PDF complexos não podem ser renderizados nos boards devido às nossas limitações técnicas. Isso geralmente acontece com PDFs que têm muitos elementos ou pequenos detalhes neles. Estamos trabalhando para melhorar nossa ferramenta de renderização, mas, por enquanto, use uma solução alternativa:

- Salve o arquivo no formato PNG ou JPEG no software que você usou para criá-lo
- Ou converta um arquivo PDF para PNG ou JPEG usando um conversor de arquivos online (você pode usar qualquer conversor que quiser, por exemplo, `https://www.freepdfconvert.com/pdf-to-png` ou `https://cloudconvert.com/`)

:::note
Se você encontrar qualquer outro problema ao carregar arquivos para os boards da Miro, tente os passos de solução de problemas deste [artigo](../../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md).
:::

## Perguntas frequentes

**Posso carregar arquivos de vídeo do meu dispositivo para os boards da Miro?**

Não, mas você pode incorporar vídeos facilmente. Confira este guia: [Incorporar mídia aos boards](../../../integrations-apps/integrations-basics/03-embed-integrations-on-a-miro-board.md).

**Posso importar dados editáveis de um arquivo Excel ou CSV?**

Planilhas, incluindo arquivos .xslx e CSV, podem ser importadas como arquivos somente visualização, ou podem ser usadas para criar uma Tabela ou uma Grade. Para mais informações: [Tabelas](../../formats/14-tables.md) ou [Grades](../../advanced-tools/05-grid.md).

**Posso baixar arquivos de um board?**

Sim, se isso for permitido nas [configurações de conteúdo do board](../../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md). Para baixar um arquivo, selecione-o e escolha **Baixar** no menu de contexto.

**Posso clicar em links em arquivos PDF carregados?**

Não, isso não é possível no momento.
