Use a **biblioteca de prototipagem** para construir layouts de protótipos diretamente no canvas da Miro. A biblioteca inclui telas, componentes de UI e ícones que ajudam a visualizar fluxos e estruturar ideias desde cedo.

Você pode usar a biblioteca de prototipagem para criar protótipos estáticos. Funcionalidades como **componentes avançados, linhas de conexão e visualização interativa** requerem o **complemento Miro Prototypes**.

![prototyping-library.png](../../../../../../../docs/using-miro/miroverse/prototyping/images/31804538064914_prototyping-library.png)

*A biblioteca de Prototipagem tem tudo o que você precisa para criar fluxos de uma ou múltiplas telas manualmente no Miro*

## Abrir a biblioteca de Prototipagem

1. No canvas, na [Barra de criação](../../working-on-the-board/02-miro's-new-simplified-user-interface.md), clique em **Ferramentas, Mídia e Integrações** (![icon-tools.svg](../../../../../../../docs/using-miro/miroverse/prototyping/images/26758266547986_icon-tools.svg)).
2. Procure e encontre **Prototyping**, depois clique em **Galeria de protótipos.**
3. O painel **Galeria de protótipos** é aberto**.**

## O que há na galeria de protótipos

A galeria de protótipos está organizada em guias. Todos os usuários podem usar a galeria para montar layouts de protótipos estáticos usando telas, componentes da UI e ícones.

:::tip
Para prototypes gerados por IA e fluxos interativos, use a biblioteca de prototipagem junto com o [**Miro Prototypes**](03-miro-prototypes.md).
:::

### Telas

**Telas** são quadros prontos para fluxos de prototipagem. Você pode adicionar telas de **Mobile**, **Tablet** ou **Desktop** ao seu canvas e construir layouts arrastando elementos de UI sobre elas.

#### **Trabalhe com telas**

- **Mostrar ou ocultar** o chrome da tela (para que pareça uma moldura de dispositivo ou um quadro simples)
- **Girar** uma tela
- **Redimensionar** uma tela arrastando para estender sua altura (apenas verticalmente)

### Componentes de UI

Componentes de UI são elementos de interface comuns que você pode arrastar para as telas, como botões, entradas, barras de navegação e elementos de formulário.

Você pode:

- Arrastar componentes para uma tela
- Redimensionar e reposicionar componentes
- Editar texto e estilização básica a partir do menu de contexto

:::note
As opções do menu de contexto variam dependendo do elemento que você seleciona.
:::

Quando o [**complemento Miro Prototypes**](07-miro-prototypes-add-on.md) está ativado, alguns componentes de interface tornam-se **interativos no modo de visualização**. Por exemplo, botões, slides, campos de entrada e menus suspensos respondem às ações do usuário com base nas linhas de conexão que você definiu.

Alguns conjuntos de componentes, como **componentes avançados**, estão disponíveis apenas com o **complemento Miro Prototypes**. Se o complemento não estiver ativado, esses componentes podem aparecer na biblioteca com um indicador.

### Ícones

A guia **Ícones** inclui uma biblioteca de ícones pesquisável que você pode usar em protótipos.

#### **Adicionar ou substituir um ícone**

1. Arraste um ícone da biblioteca para o canvas.
2. Selecione o ícone para atualizar sua cor a partir do menu de contexto.
3. Escolha **Substituir ícone** para trocá-lo por outro ícone sem alterar sua posição ou tamanho.

### Wireframes (legado)

A guia de **Wireframes** contém elementos legados de wireframes. Esses elementos permanecem disponíveis e editáveis para boards existentes, mas os novos protótipos devem usar telas e componentes de UI da biblioteca de Prototipagem.

## Linhas de conexão e interatividade (complemento Miro Prototypes)

**Linhas de conexão** permitem definir a navegação entre telas em um protótipo. Quando o [**complemento Miro Prototypes**](07-miro-prototypes-add-on.md) está ativado, você pode criar linhas de conexão entre elementos e telas para construir fluxos de várias etapas.

Linhas de conexão também ativam a **pré-visualização interativa**. No modo de pré-visualização, as telas conectadas se comportam como um fluxo clicável, e as telas rolam verticalmente se ultrapassarem a área de visualização. Sem o complemento, as linhas de conexão e o comportamento interativo não estão disponíveis.

:::tip
Alguns elementos de UI mostram um ícone de raio quando adicionados a uma tela. Em fluxos de várias telas, arraste o ícone de raio para criar uma linha de conexão entre as telas.
:::

## Perguntas frequentes

**Posso adicionar meus próprios elementos à biblioteca?**

Não. Você pode adicionar conteúdo personalizado ao seu board, mas não pode adicionar novos elementos à própria biblioteca de Prototipagem.

**O que é diferente na nova biblioteca de Prototipagem?**

A biblioteca de Prototipagem oferece suporte a telas, componentes de UI atualizados, ícones e previsões interativas de cliques. Funcionalidades avançadas e interativas requerem o complemento Miro Prototypes.

**A Prototyping library está disponível sem o complemento?**

Sim. Você pode usar a Prototyping library para criar layouts de protótipos estáticos. Conexões interativas e componentes avançados requerem o complemento Miro Prototypes.

**A Galeria de wireframes ainda está disponível?**

Sim. A guia de wireframes está disponível na Prototyping library, e os wireframes existentes continuam funcionando.
