Com o [mapa mental da Miro](https://miro.com/mind-map-software/), você pode aplicar a ferramenta de diagrama reconhecida no mundo todo para organizar o visual do seu conteúdo hierarquicamente.

> **Disponível em:** versão para navegador, [aplicativo para desktop](../../getting-started/apps-for-devices/05-desktop-app.md), [aplicativo para tablet](../../getting-started/apps-for-devices/11-tablet-app.md), [aplicativo móvel](../../getting-started/apps-for-devices/08-mobile-app.md) (funcionalidade limitada)

### Como criar um mapa mental na Miro

Na barra de ferramentas de criação,  com a Miro AI

1. Encontre o **mapa mental** na barra de ferramentas de criação. Você também pode simplesmente arrastar o ícone para sua barra de ferramentas.![mindmap_on_the_toolbar.gif](https://help.miro.com/hc/article_attachments/21017528585490)*Mapa mental na barra de ferramentas*
2. Selecione **Mapa mental** e clique em qualquer lugar do board para adicionar o nó pai — o ponto de partida do seu mapa mental. Os sinais de adição em cada lado do mesmo mostrarão onde você pode iniciar as ramificações e criar os nós filhos. Você pode criar um mapa mental vertical ou horizontal.![starting_a_mindmap.gif](https://help.miro.com/hc/article_attachments/21017528586258)*Criando um nó pai e iniciando um mapa mental horizontal*

Use os seguintes atalhos para acelerar o processo de criação:

- **Retornar** para criar um nó irmão e começar a editá-lo imediatamente.
- **Shift + Retornar** para quebrar as linhas dentro de um nó.
- **Tab** para criar um nó filho.
- **Setas** para mover entre os nós.
- **Ctrl + C** e **Ctrl + V** (*no Windows*)/ **Cmd + C** e **Cmd + V** (*no Mac*) para duplicar um nó.
- **Escapar** para sair do modo de edição.
- **Excluir** para excluir todo o nó.
- **Ctrl** (*no Windows*) ou **Cmd** (*no Mac*) (pressionar) para parar a redefinição automática.

Você pode selecionar e arrastar os nós para alterar a sua posição no canvas.

1. Crie o nó raiz e preencha-o com conteúdo.
2. Clique no ícone da  **Miro AI**.
3. Clique em **Gerar mapa mental**.
   Seu mapa mental aparecerá no board ao redor do nó raiz. Você também pode manter, tentar novamente ou descartar seu mapa mental.
4. Continue editando seu mapa mental até que atenda às suas necessidades.

A Miro AI oferece outros métodos para criar um mapa mental, incluindo Expandir com perguntas, Expandir com ideias e Expandir com tópicos. Para saber mais sobre a Miro AI, consulte a seção "Mapas mentais com IA" em [Visão geral: Criar e editar com IA](../miro-ai/03-create-with-ai.md).

## Como trabalhar com mapas mentais

Você pode adicionar quantos nós quiser ao seu mapa mental. Você pode mover os nós para atender às suas necessidades ou usar o layout automático para uma aparência limpa. Você também pode redefinir os nós filhos para outros nós pais ou excluir os nós completamente.

### Como mover, redimensionar, adicionar e excluir nós

À medida que você reorganiza os nós no seu mapa mental, todos os nós filhos serão alinhados automaticamente. Isso ocorre porque o **layout automático** é habilitado por padrão. Para habilitar ou desabilitar o layout automático, clique no nó pai e, no menu de contexto, habilite o **layout automático**.

![image1.gif](https://help.miro.com/hc/article_attachments/21017515619346)*Como usar o layout automático para alinhar as mudanças nos nós*

**Quando o layout automático está desabilitado**, você ainda pode alinhar todos os nós filhos. Depois de terminar de organizar o seu mapa mental, clique no nó pai, clique nos três pontos (...) do menu de contexto e selecione **Nós de layout**.

![image2.gif](https://help.miro.com/hc/article_attachments/21017528602002)

Para redefinir um nó filho para outro nó pai, basta arrastar o nó.

:::note
Mantenha pressionada a tecla **Ctrl** (*para Windows*) ou **Cmd** (*para Mac*) se quiser mover o nó em vez de redefini-lo.
:::

![reassign_nodes.gif](https://help.miro.com/hc/article_attachments/21017528592658)*Reatribuição de nó*

Use nós com links para mostrar dependências entre ideias no seu mapa mental ao visualizar conceitos complexos.

![create_dependencies.gif](https://help.miro.com/hc/article_attachments/21017528593426)*Nós que se conectam*

Você também pode alterar o tamanho do seu mapa mental [selecionando-o](../working-on-the-board/10-working-with-objects.md) e arrastando o ponto branco.

![changing_size.gif](https://help.miro.com/hc/article_attachments/21017528594194)*Como alterar o tamanho do mapa mental*

Para adicionar texto a um nó, clique duas vezes nele.

:::note
Use **Shift + Return** para quebrar linhas dentro de um nó.
:::

Para criar uma lista de marcadores em um nó, digite **-** e pressione a barra de espaço. Para criar uma lista numerada, digite **1.** no início de uma linha.
Para criar uma lista com marcadores começando na segunda (ou terceira/quarta/etc.) linha, crie uma nova linha com **Cmd + Enter** (*para Mac*) ou **Ctrl + Enter** (*para Windows*).

![adding_text_to_a_node.gif](https://help.miro.com/hc/article_attachments/21017528595474)*Como inserir texto adicional em um nó*

Para excluir um nó, pressione **Excluir** ou clique em três pontos no menu de contexto e escolha **Excluir**. O nó será excluído junto com todos os nós filhos.

![delete_a_node.jpg](https://help.miro.com/hc/article_attachments/21017515617810)*Como excluir um nó*

:::warning
Os nós do mapa mental não podem ser [bloqueados](../working-on-the-board/17-locking-content-on-the-board.md) e [agrupados](../working-on-the-board/08-structuring-board-content.md).
:::

### Como formatar elementos do mapa mental

Você pode escolher o estilo para o seu mapa mental (os nós podem usar linhas retas ou curvas) e alterar a orientação. E se quiser que o seu mapa mental seja colorido e vibrante, use a ferramenta **Randomizar**.

![changing_mind_map.gif](https://help.miro.com/hc/article_attachments/21017515609746)*Estilo do seu mapa mental*

Como o componente principal de cada mapa mental é o texto, você pode aplicar diferentes opções de estilo de texto na sua versão abreviada. Observe que, para preservar a consistência visual do mapa mental, alterar o tamanho do texto no nó pai afetará todo o mapa mental.

![mind_map_font_size.gif](https://help.miro.com/hc/article_attachments/21017528588946)*Como alterar o tamanho da fonte do mapa mental*

Você pode alterar os nós individuais usando diferentes opções do menu de contexto: alterar o estilo e a cor, realçar o texto e adicionar um URL. Atualmente, não é possível alterar a fonte.

![changing_a_node.gif](https://help.miro.com/hc/article_attachments/21017528594834)*Como alterar um nó*

### Como alterar o tipo de nó

Há quatro estilos visuais de nó:

- **Nenhum** — nenhuma forma é aplicada.
- **Pílula** — uma forma de pílula oval.
- **Retângulo arredondado** — uma forma retangular com cantos arredondados.
- **Retângulo** — forma retangular.

Para adicionar um tipo de nó:

1. Selecione o nó que você deseja afetar.
2. Clique no **tipo de nó** na barra de ferramentas.
3. Escolha o estilo de tipo de nó que você deseja.
4. O estilo será aplicado e o nó será preenchido com a mesma cor da ramificação.
5. Você também pode alterar a cor do nó e a opacidade de preenchimento para aumentar o impacto visual:
   ![mind_map_changing_node_type.gif](https://help.miro.com/hc/article_attachments/21017515621394)*Como alterar o tipo e as opções de cor de um nó*

### Como expandir e recolher os mapas mentais

Crie mapas mentais de qualquer tamanho sem se perder nos detalhes. Expandir e recolher ramificações para:

- Ter uma melhor visão geral do seu mapa mental.
- Concentrar-se no nível certo de detalhes ao trabalhar.
- Ajudar os usuários a navegar facilmente no seu mapa mental.
- Apresentar apenas determinados níveis de detalhes para o seu público.

**Como recolher e expandir ramificações**

Para recolher, passe o mouse sobre a ramificação e clique no botão de menos ( **-** ). Todos os comentários anexados a essa ramificação também serão escondidos.

Depois de recolher uma ramificação, você verá um número indicando quantos nós e comentários estão ocultos. Para expandir a ramificação novamente, basta clicar no número.

![Expand_and_collapse.gif](https://help.miro.com/hc/article_attachments/21017515618962)*Como expandir e recolher as ramificações de um mapa mental*

### Exportação de mapa mental

Você pode exportar o seu mapa mental como uma imagem ou arquivo PDF. Saiba mais sobre a funcionalidade de exportação [nesta página](../import-and-export/export/03-how-to-export-your-board.md).

Para exportar o seu mapa mental como uma imagem, faça o seguinte:

1. Clique no ícone **Exportar este board**. Você não precisa ter nada selecionado.
2. Escolha **Salvar como imagem**.
3. Use as alças de arrastar para selecionar o seu mapa mental.
4. Escolha o tamanho que você deseja e clique em **Exportar**. Você também pode selecionar o PDF aqui.
5. O arquivo será salvo no seu disco rígido local com o nome do seu board como nome do arquivo.
   ![main_menu_mindmap_export_image.gif](https://help.miro.com/hc/article_attachments/21017515622930)
*Como exportar seu mapa mental como uma imagem*

Para exportar o seu mapa mental como um PDF, faça o seguinte:

1. Clique no ícone **Exportar este board**. Você não precisa ter nada selecionado.
2. Escolha **Salvar como PDF.** Você será solicitado a criar um quadro para o seu mapa mental, caso ainda não exista.
3. Para criar um quadro, clique no botão **Criar um quadro** na caixa pop-up. Escolha um estilo nas opções à esquerda. Redimensionar o quadro para cobrir o seu mapa mental.
4. Clique em **Exportar este board** novamente e escolha **Salvar como PDF**.
5. Escolha a melhor opção de PDF para você e clique em **Exportar**.
   ![main_menu_mindmap_export_pdf.gif](https://help.miro.com/hc/article_attachments/21017528606738)
*Como exportar seu mapa mental como um arquivo PDF*

Você também pode selecionar o mapa mental, clicar com o botão direito do mouse e escolher **Copiar como imagem**, que copiará apenas o objeto selecionado em vez de todo o board. Isso não exportará o seu mapa mental, no entanto, ele simplesmente colocará a cópia no board.

## Perguntas frequentes

Quantos nós posso ter?

Não há limite para o número de nós (pai ou filho) que você pode criar.

Posso mover/redefinir um nó?

Sim, basta arrastar o nó.

Posso anexar uma imagem a um nó?

Embora não haja nenhuma opção para anexar uma imagem a um nó no momento, estamos providenciando essa funcionalidade.

Posso exportar os dados de um mapa mental para dados CSV inteligentes?

Sim, use o [Mindmap downloader (baixador de mapas mentais)](https://miro.com/marketplace/mindmapdownloader/?backUrl=%2Fmarketplace%2F).

Posso ter vários nós conectados ao mesmo nó filho?

Como uma solução alternativa, você pode usar as [linhas de conexão](../essential-tools/05-connection-lines.md) para ligar um nó filho a vários nós pai.

Posso copiar o meu mapa mental para outro board da Miro?

Sim, você pode copiar e colar como qualquer outro conteúdo: selecionar o nó pai, clicar nos três pontos do menu de contexto, escolher **Copiar** e colar o widget em outro board. **[Ctrl + C/Ctrl + V](../working-on-the-board/06-shortcuts-and-hotkeys.md)** [*(no Windows)*](../working-on-the-board/06-shortcuts-and-hotkeys.md) **[ou Cmd](../working-on-the-board/06-shortcuts-and-hotkeys.md)** + C/Cmd + V (*[no Mac)](../working-on-the-board/06-shortcuts-and-hotkeys.md)* também funcionará. Certifique-se de que o titular do board [permita copiar o conteúdo do board](../sharing-boards/14-how-to-allow-or-restrict-copying-and-exporting-boards-and-content.md).

Como faço para mover todo o mapa mental em torno do board?

Selecione o nó pai e mova-o.

Posso alterar o tamanho do texto de um nó filho individual?

Não, no momento, você só pode alterar o tamanho do nó pai, o que resultará na alteração do tamanho de todo o mapa mental.

Posso converter [notas adesivas](../essential-tools/14-sticky-notes.md), [blocos de texto](../essential-tools/16-text.md), [cartões](../essential-tools/02-cards.md) e outros widgets em nós do mapa mental?

Não, não é possível no momento. Você pode copiar o texto de uma nota adesiva/cartão/bloco de texto e colá-lo em um nó.

Como faço para inserir um nó entre dois existentes?

Reatribua temporariamente um dos nós a outro, crie um novo nó e reatribua o nó de volta.
