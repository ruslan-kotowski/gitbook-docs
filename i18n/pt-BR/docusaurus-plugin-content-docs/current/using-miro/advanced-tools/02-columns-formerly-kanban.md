Visualize seu fluxo de trabalho e faça mais em equipe com nosso [framework Kanban](https://miro.com/templates/kanban-framework/). O Kanban da Miro pode ser usado em uma variedade de casos de uso, desde o desenvolvimento ágil até o acompanhamento de tarefas pessoais.

## Como adicionar Kanban

Para adicionar Kanban ao seu board, escolha em **Ferramentas, Mídia ou Integrações** (![icon-tools.svg](../../../../../../docs/using-miro/advanced-tools/images/29029892260754_icon-tools.svg)) ou na barra de ferramentas e clique no board no local desejado.

Você pode alterar o tamanho do seu Kanban arrastando os lados.

## Colunas e raias

Adicione e organize colunas e raias no seu Kanban:

1. Clique no Kanban para revelar o menu de contexto.
2. Clique nos ícones **Adicionar coluna** ou **Adicionar raia** para adicioná-los ao seu Kanban.
   Colunas serão adicionadas à direita, enquanto as raias serão adicionadas na parte inferior.
3. Reorganize colunas ou raias clicando no ícone de **três pontos** (**...**) e selecionando a direção desejada para **Mover**.
4. Clique duas vezes no cabeçalho de uma coluna para renomeá-la.

No menu de **três pontos** (**...**), você pode adicionar, mover, renomear e excluir colunas e raias ou alterar a cor das colunas.

## Cartões

:::tip
[Saiba mais](../essential-tools/02-cards.md) sobre os cartões da Miro.
:::

Para adicionar um [cartão](../essential-tools/02-cards.md), clique no ícone de mais dentro de uma raia. Ou, alternativamente, arraste um cartão existente do board para o seu Kanban.

Arraste cartões para movê-los para outra coluna/raia.

:::warning
Cartões dentro do Kanban não podem ser [bloqueados](../working-on-the-board/17-locking-content-on-the-board.md) e [agrupados](../working-on-the-board/08-structuring-board-content.md).
:::

Acelere seu trabalho usando os [atalhos](../working-on-the-board/06-shortcuts-and-hotkeys.md):

- **Enter/Return** para criar um novo cartão
- **Tab** para alternar para o próximo cartão em uma coluna
- **Tab** + **Shift** para alternar para o cartão anterior em uma coluna
- **←→****↑↓** para selecionar um cartão
- **Ctrl** + **C** e **Cmd** + **V** (*para Windows*), **Cmd + C** e **Cmd + V** (*para Mac*) para duplicar um cartão
- **Ctrl + ↑↓** (*para Windows*), **Cmd + ↑↓** (*para Mac*) para adicionar um novo cartão abaixo ou acima
- **Escape** para sair do modo de edição

## Perguntas frequentes

**Existe uma opção para adicionar imagens ao Kanban?**

Não, você só pode adicionar [cartões](../essential-tools/02-cards.md).

**Posso adicionar [cartões do Jira](../../integrations-apps/atlassian/03-jira-cards.md) ao meu Kanban?**

Sim, você pode adicionar cartões do Jira como qualquer outro cartão ([cartões do Asana](../../integrations-apps/asana/01-asana-cards-legacy.md), [cartões do Azure](../../integrations-apps/microsoft/03-azure-cards.md)). Para aprender como configurar cartões do Jira, dê uma olhada [nesta página](../../integrations-apps/atlassian/12-deprecated-–-set-up-and-disable-jira-cards-using-oauth-1.0.md).

**Existem lembretes automáticos com base na data de vencimento do cartão?**

Não, isso não é possível no momento.
