As camadas permitem organizar seções separadas de conteúdo no board, o que é essencial para lidar com a complexidade dos diagramas, além de realizar um trabalho mais preciso e estruturado.

## Como acessar camadas

Para acessar o **painel Camadas**:

1. Clique no ícone de **Mídia, ferramentas e integrações** (![icon-tools.svg](../../../../../../docs/using-miro/essential-tools/images/23227364594834_icon-tools.svg)) na barra de ferramentas de criação.
2. Pesquise por **Camadas** e clique na ferramenta Camadas.
3. Você pode manter a ferramenta Camadas na barra de ferramentas de criação clicando com o botão direito do mouse no ícone **Camadas** e selecionando **Fixar na barra de ferramentas**.

![layers-new-entry-point.png](../../../../../../docs/using-miro/essential-tools/images/22431635505426_layers-new-entry-point.png)

*O menu Camadas é revelado clicando no ícone de Quadros e camadas*

Quando você clicar no **ícone Camadas**, um painel será aberto no lado direito do canvas. No painel, você pode ativar uma camada, nomear suas camadas existentes ou criar novas camadas.

![layers-panel.png](../../../../../../docs/using-miro/essential-tools/images/21594007565842_layers-panel.png)

*O menu Camadas aparecerá no lado direito do Canvas*

### Quem pode usar as camadas

Os recursos da funcionalidade Camadas variam de acordo com a função do usuário.

- Os visualizadores e comentaristas (até mesmo os convidados com essas permissões) não podem acessar a funcionalidade Camadas.
- Os editores (assim como os convidados com permissões para editar) podem criar, editar, ocultar e exibir camadas.
  - Os usuários editores convidados por e-mail também podem bloquear e desbloquear camadas.
- Titulares e cotitulares de boards têm as mesmas habilidades que os editores. Também podem bloquear e desbloquear camadas, e usar o bloqueio protegido.

## Como usar camadas

O conteúdo pode ser selecionado e adicionado a uma camada nova ou existente, ajudando você a manter o conteúdo relacionado organizado.

1. Selecione o conteúdo que deseja adicionar a uma camada nova ou existente.
2. Clique no menu **Camadas**.
3. Para adicionar o conteúdo a uma nova camada: clique em **+ Mover para nova camada**. Você pode renomear a nova camada.
4. Para mover o conteúdo para uma camada existente: clique nos **três pontos** (**...**) ao lado do nome da camada e escolha **Mover seleção para camada**.

![layers-move-to.gif](../../../../../../docs/using-miro/essential-tools/images/21594007570962_layers-move-to.gif)

*Como adicionar conteúdo a uma camada existente*

Ao adicionar o conteúdo que deseja incluir em uma camada específica, selecione a camada primeiro. O novo conteúdo será adicionado automaticamente a essa camada.

Você também pode adicionar conteúdo a uma camada nova ou existente por:

1. Selecione o conteúdo que deseja adicionar.
2. Clique no menu de **três pontos** (**...**) no menu de contexto.
3. Selecione a opção **Mover para camada**.

![](../../../../../../docs/using-miro/essential-tools/images/21593982256018_803bbedc-722c-45ef-afb8-e9c46ba8a857.png)

*A opção **Mover para camada** pode ser encontrada clicando nos três pontos (**...**) do menu de contexto*

As camadas podem ser ocultadas, bloqueadas, renomeadas ou duplicadas conforme as suas necessidades.

1. Clique ou passe o mouse sobre o nome da camada no menu Camadas.
2. Para **ocultar** uma camada: Clique no **ícone do olho** para ocultar a camada. O ícone mudará de olho aberto para olho fechado. Todo o conteúdo da camada selecionada desaparecerá do canvas. (Vale ressaltar que o conteúdo oculto desaparecerá do canvas para todos os usuários e permanecerá oculto mesmo quando a página for recarregada.)
3. Para exibir a camada, clique no **ícone de olho fechado**. O conteúdo oculto reaparecerá no canvas.![layers-eye.png](../../../../../../docs/using-miro/essential-tools/images/21593982258450_layers-eye.png)
   *Oculte uma camada usando o ícone do olho*
4. Para **travar** uma camada: Clique no **ícone do cadeado** para bloquear a camada. O ícone de cadeado aberto mudará para cadeado fechado. Quando uma camada está bloqueada, não é possível editar o conteúdo dentro dela (incluindo mover ou excluir o conteúdo).
5. Clique no **ícone de cadeado** **fechado** novamente para desbloquear o conteúdo da camada.![layers-lock.png](../../../../../../docs/using-miro/essential-tools/images/21594007576466_layers-lock.png)
   *O ícone de cadeado é usado para bloquear ou desbloquear uma camada*
6. Para **duplicar** uma camada: Clique nos três pontos (**...**) no lado direito da camada.
7. Clique em **Duplicar camada**.
8. Uma segunda instância da sua camada aparecerá no board, logo acima da camada original.
9. Para mover a camada duplicada, selecione-a no menu Camadas e depois clique no conteúdo da camada no canvas e arraste para o local desejado.
   ![layers-three-dots.png](../../../../../../docs/using-miro/essential-tools/images/21593982264594_layers-three-dots.png)
   *A duplicação de uma camada é feita através do menu de três pontos (...)*

Para renomear uma camada:

1. Clique duas vezes no nome da camada no menu Camadas.
2. Edite o nome da camada.
3. Pressione Enter.

## Camadas no formato Diagrama

As camadas no formato Diagrama funcionam independentemente das camadas do canvas. Essa separação é projetada para simplificar o processo de criação de diagramas e evitar confusão entre o conteúdo geral do board e os componentes específicos de um diagrama. Para saber mais sobre os detalhes de como as camadas funcionam dentro dos diagramas, consulte nosso artigo detalhado sobre o [formato Diagrama](../formats/diagramming/02-miro-diagrams.md).

- **Canvas vs. Camadas do diagrama**: Enquanto as camadas de canvas são usadas para fins gerais, como apresentações, as camadas dentro de um Diagrama são gerenciadas à parte para organizar os próprios elementos do diagrama.
- **Parentalidade**: Uma vez que um elemento faz parte de um Diagrama, ele não pode ser adicionado a uma camada de canvas, pois é gerenciado pelo próprio formato do Diagrama.

## Reordenar camadas

As camadas podem ser reordenadas no painel. Isso determina qual conteúdo da camada é exibido na parte superior. Para reordenar as camadas, basta arrastá-las dentro do painel Camadas na ordem que preferir.

Esta ferramenta é útil para criar diagramas, quando você precisa de duas versões das mesmas partes de um diagrama, com conteúdos um pouco diferentes. Ao colocar uma camada diretamente sobre a outra, é possível alterar qual delas será exibida reordenando as camadas.

## A camada padrão

A camada padrão fica sempre visível e novos widgets são adicionados a ela se nenhuma outra camada estiver ativa. Quando você não está trabalhando em nenhuma camada específica, a camada usada será a padrão.

A camada padrão é diferente das outras camadas, porque não pode ser ocultada nem bloqueada.
