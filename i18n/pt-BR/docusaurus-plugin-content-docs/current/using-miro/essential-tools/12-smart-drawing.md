Com o desenho inteligente, você pode aproveitar um trabalho com apenas uma ferramenta no board , que fica ótimo desde o início. O modo de desenho inteligente converte automaticamente seus desenhos a lápis em formas precisas, notas adesivas e linhas.

> **Disponível em:** navegador, [aplicativo para desktop](../../getting-started/apps-for-devices/05-desktop-app.md), [aplicativo para tablet](../../getting-started/apps-for-devices/11-tablet-app.md), [aplicativo para celular](../../getting-started/apps-for-devices/08-mobile-app.md)

![desenho_inteligente_em_Miro.gif](../../../../../../docs/using-miro/essential-tools/images/21017318363666_smart%20drawing%20in%20Miro.gif)
*Desenho inteligente no Miro*

Para iniciar/parar de usar o desenho inteligente, escolha a ferramenta **caneta**na barra de ferramentas e alterne para **o desenho inteligente**. Comece a desenhar sem quebrar a linha, um traço conta como um objeto. Recomendamos trabalhar com zoom de 100%.

![desenho_inteligente_na_barra_de_ferramentas.jpg](../../../../../../docs/using-miro/essential-tools/images/21019590977170_smart%20drawing%20on%20the%20toolbar.jpg)
*Desenho inteligente na barra de ferramentas*

Verifique quais objetos são reconhecíveis clicando duas vezes no ícone de desenho inteligente.

![desenho_inteligente.gif](../../../../../../docs/using-miro/essential-tools/images/21019590970642_smart%20drawing.gif)
*Objetos que podem ser reconhecidos pelo desenho inteligente*

Use predefinições para criar objetos de diferentes cores e espessuras. Você pode criar até 3 predefinições e editá-las sempre que precisar. Clique duas vezes em uma predefinição para editá-la.

![editando_uma_predefinição.gif](../../../../../../docs/using-miro/essential-tools/images/21019534899602_editing%20a%20preset.gif)
*Predefinições de desenho inteligente*

Para apagar objetos inteligentes, rabisque sobre eles. Certifique-se de cobrir pelo menos 50% do objeto, caso contrário ele não será apagado.

:::note
Observe que a borracha padrão funciona apenas com desenhos de caneta padrão, não com objetos inteligentes.
:::

![apagando.gif](../../../../../../docs/using-miro/essential-tools/images/21019534907410_erasing.gif)
*Apagando objetos inteligentes*

Para sair do modo de desenho inteligente e alternar para o desenho gratuita , escolha [caneta ou marca-texto](10-pen.md).

![trocando_para_caneta.jpg](../../../../../../docs/using-miro/essential-tools/images/21019534912146_switching%20to%20pen.jpg)
*Mudando para a caneta padrão*

Você também pode criar [formas](11-shapes.md) e [linhas](05-connection-lines.md) usando as ferramentas correspondentes.
