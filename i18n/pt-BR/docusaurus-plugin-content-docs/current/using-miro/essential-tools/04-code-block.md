Adicione blocos de código aos seus boards para programação colaborativa, depuração e resolução de problemas. Nosso widget de bloco de código possui as linguagens de programação mais populares e é personalizável.

Combine blocos de código com nossos [recursos de mapeamento e criação de diagramas](../formats/diagramming/01-miro-for-mapping-diagramming.md) para revisar arquitetura e fluxos. E use conectores de diagrama para destacar as relações entre partes do código-fonte.

**Use blocos de código para:**

- Cerimônias ágeis
- Sessões de desenvolvimento e depuração colaborativa
- Entrevistas de codificação remota

## Como adicionar um bloco de código

1. Vá para a barra de ferramentas de criação no lado esquerdo do board
2. Clique no ícone **Mais aplicativos**
3. Pesquise **bloco de código** ou role para baixo até ver bloco de código
4. Clique no ícone do aplicativo Code block
5. Clique em qualquer lugar do board para adicionar um bloco de código

## Como personalizar um bloco de código

No menu de contexto do bloco de código, você pode alternar linhas, ajustar o tamanho da fonte e alternar linguagens de programação.

1. Clique no bloco de código.
2. No menu de contexto, escolha uma linguagem de programação no menu suspenso, aumente ou diminua o tamanho da fonte e clique no ícone de números de linha para alternar as linhas ativadas e desativadas.

## Perguntas frequentes

Quais linguagens de programação estão disponíveis atualmente em blocos de código?

JavaScript, TypeScript, Python, C++, Java, Go, Rust, PlainText, Swift, Ruby, SQL, HTML, CSS, JSON, GraphQL, Kotlin, YAML e Mermaid.
Adicionamos idiomas regularmente com base nos pedidos dos clientes; entre em contato com seu Gerente de Sucesso do Cliente da Miro se tiver sugestões.
