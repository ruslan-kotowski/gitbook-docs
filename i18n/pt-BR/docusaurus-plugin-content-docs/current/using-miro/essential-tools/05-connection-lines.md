**As linhas de conexão** permitem que você conecte objetos no board. Isso é útil para criar diagramas e diagramas de fluxo.

> **Disponível em:** versão para navegador, [aplicativo para desktop](../../getting-started/apps-for-devices/05-desktop-app.md), [aplicativo para tablet](../../getting-started/apps-for-devices/11-tablet-app.md), [aplicativo móvel](../../getting-started/apps-for-devices/08-mobile-app.md) (funcionalidade limitada)

:::tip
Para saber mais sobre as linhas de conexão no mapa mental, confira [este artigo](../advanced-tools/03-mind-map.md).
:::

### Como criar e editar linhas de conexão

Para criar uma linha, selecione **linha de conexão** na barra de ferramentas ou use a [tecla de atalho](../working-on-the-board/06-shortcuts-and-hotkeys.md) **L**. Você também pode selecionar um objeto e clicar em um dos pontos azuis ao redor dele para desenhar uma linha.

![adding_connection_lines.gif](../../../../../../docs/using-miro/essential-tools/images/21017652614034_adding%20connection%20lines.gif)
*Como criar linhas de conexão*

Altere as pontas de seta, o tipo de linha (reta, ortogonal e arredondada), espessura, cor, etc. no menu de contexto.

![changing_a_connection_line.gif](../../../../../../docs/using-miro/essential-tools/images/21017652618130_changing%20a%20connection%20line.gif)
*Como modificar as linhas de conexão*

Para desenhar uma linha reta horizontal, vertical ou diagonal, comece a desenhar uma linha e mantenha pressionado o **Shift**.

Para desabilitar o ajuste em outros objetos, mantenha pressionado o **Ctrl** *(para Windows)* ou **Cmd** *(para Mac*).

![using_Shift_and_Cmd_with_lines.gif](../../../../../../docs/using-miro/essential-tools/images/21017652621714_using%20Shift%20and%20Cmd%20with%20lines.gif)
*Como desenhar uma linha reta e uma linha independente*

Se você quiser criar um caminho específico para a linha, pode fazer isso trabalhando com os marcadores azuis e brancos na linha. Para remover dobras e voltas extras e redefinir uma linha, basta clicar duas vezes nos marcadores *brancos* (use um toque duplo no tablet).

![adding_curves_to_lines.gif](../../../../../../docs/using-miro/essential-tools/images/21017652622866_adding%20curves%20to%20lines.gif)
*Como alterar uma linha de conexão*

Para desconectar uma linha e anexá-la a outro objeto, arraste o fim da linha.

![re-attaching_a_line.gif](../../../../../../docs/using-miro/essential-tools/images/21017652623634_re-attaching%20a%20line.gif)
*Como anexar uma linha de conexão a outro objeto*

Para excluir uma linha de conexão, selecione-a, clique nos três pontos no menu de contexto e clique em **Excluir** (ou simplesmente mantenha pressionado **B****ackspace/Excluir**).

### Como inserir formas

Você pode adicionar formas, cartões e outros objetos em linhas de conexão. Selecione uma linha de conexão e escolha **Inserir forma** no menu de contexto. Certifique-se de que há espaço suficiente entre dois objetos conectados.

![inserting_a_shape.gif](../../../../../../docs/using-miro/essential-tools/images/21017648700434_inserting%20a%20shape.gif)
*Como inserir um objeto entre duas formas*

### Como adicionar etiquetas de texto

Cada item do diagrama é significativo e as linhas não são uma exceção. Para estabelecer relações mais claras entre objetos nos seus boards, use etiquetas de texto.

Clique duas vezes em qualquer linha de conexão ou clique em**+T** no menu de contexto para começar a inserir o texto. Mova o texto ao longo da linha arrastando-o. Você pode adicionar várias etiquetas de texto a uma linha.

![adding_text_to_a_line.gif](../../../../../../docs/using-miro/essential-tools/images/21017648701074_adding%20text%20to%20a%20line.gif)
*Como adicionar uma etiqueta de texto à linha*

Você pode alterar o *tamanho do texto, a cor* no menu de contexto e corrigi-lo horizontalmente ou deixar o texto seguir os limites das linhas. Para excluir o texto, selecione-o e pressione **Excluir** no teclado.

![text_formatting_on_a_line.jpg](../../../../../../docs/using-miro/essential-tools/images/21017648702098_text%20formatting%20on%20a%20line.jpg)
*Controles de texto*

:::tip
Crie uma linha do tempo adicionando várias etiquetas de texto e alterando suas posições na linha ao arrastar.
:::

### Como criar linhas de conexão entre objetos

Você pode conectar [formas](11-shapes.md), [cartões](02-cards.md), [notas adesivas](14-sticky-notes.md), [blocos de texto](16-text.md) e outros objetos (mas não [quadros](07-frames.md)) com linhas de conexão. Selecione um objeto e arraste o ponto azul.

![connecting_two_objects.gif](../../../../../../docs/using-miro/essential-tools/images/21017652627218_connecting%20two%20objects.gif)
*Como conectar dois ícones com uma linha*

Se você selecionar uma forma, uma nota adesiva ou um cartão e passar o mouse sobre um ponto azul perto do objeto, ele mostrará onde uma nova forma ou linha de conexão será criada:

- Se houver outro objeto perto do selecionado, será sugerido que você crie *uma linha de conexão*
- Se não houver objetos perto do selecionado, será sugerido que você crie *o mesmo objeto ligado ao escolhido*

Clique no ponto para criar automaticamente uma linha ou um objeto. *Arraste o ponto* para conectar o objeto a outro *manualmente*.

![smart_diagramming.gif](../../../../../../docs/using-miro/essential-tools/images/21017648708242_smart%20diagramming.gif)
*Criação e conexão com um clique na Miro*

Se você arrastar uma linha e anexá-la a um ponto azul não central, a linha cruzará os objetos se você movê-los.

![Two_shapes_are_linked_via_a_side_blue_dot.gif](../../../../../../docs/using-miro/essential-tools/images/21017648709266_Two%20shapes%20are%20linked%20via%20a%20side%20blue%20dot.gif)
*Duas formas são ligadas por meio de um ponto azul lateral*

Se você conectar a linha ao ponto azul central, a linha não cruzará os objetos quando você movê-los.

![Two_shapes_are_connected_via_a_center_blue_dot.gif](../../../../../../docs/using-miro/essential-tools/images/21017648712594_Two%20shapes%20are%20connected%20via%20a%20center%20blue%20dot.gif)
*Duas formas são conectadas por meio de um ponto azul central*

### Saltos de linha

Os saltos de linha ajudam a esclarecer a qual objeto cada linha se refere quando as linhas se cruzam. Quando ativados, eles aparecem automaticamente nas linhas de interseção.

Os saltos de linha funcionam apenas com linhas retas e ortogonais.

#### Como ativar ou desativar os saltos de linha

1. Clique na linha de conexão
2. O menu de contexto será aberto
3. Clique no ícone **Tipo**
4. Selecione **Saltos de linha** para ativar ou desativar a funcionalidade

![Line-jumps.gif](../../../../../../docs/using-miro/essential-tools/images/21017648718994_Line-jumps.gif)
*Como desativar os saltos de linha*

### Perguntas frequentes

1. *Como criar uma linha de conexão com pontas de seta em ambas as extremidades?*
   - Selecione a linha, escolha **Nenhum** no menu de contexto e adicione a ponta de seta.
   ![line_start.jpg](../../../../../../docs/using-miro/essential-tools/images/21017652633618_line%20start.jpg)
*Início da linha*
2. *Como evitar que linhas de conexão se vinculem a objetos?*
   - Para desabilitar o encaixe ao mover uma linha de conexão, mantenha pressionado **Ctrl** *(para Windows)* ou **Cmd** *(para Mac).*
3. *Posso alterar a fonte e o alinhamento da etiqueta de texto em uma linha?*- Não. No momento, isso não é possível.
4. *Posso alterar o tamanho das pontas de seta?
   -* O tamanho das pontas de seta é alterado quando você altera a espessura da linha de conexão.
5. *Como altero a espessura da linha?*
   - Selecione uma linha, escolha **Tipo** no menu de contexto e ajuste a espessura.
   ![Screenshot_background_template__1207__1_.jpg](images/21017652736530_Screenshot%20background%20template%20%201207%20(1).jpg)
   *Como alterar a espessura de uma linha de conexão*
6. *Posso aplicar um estilo a todas as linhas de conexão no meu board?*- Sim, use a seguinte solução: selecione uma linha, clique nos três pontos no menu de contexto e copie um estilo da linha. Em seguida, selecione todos os objetos no board (você pode usar um atalho **Ctrl + A** (*para Windows*) ou **Cmd + A** (*para Mac*), [filtre](../working-on-the-board/21-work-smarter-not-harder.md) as linhas de conexão e escolha **Colar estilo** nos três pontos do menu de contexto.
7. *O que acontece se você [bloquear](../working-on-the-board/17-locking-content-on-the-board.md) uma linha de conexão?*- Você não poderá editar o tipo de linha, cor, espessura, etc., mas ainda poderá mover objetos aos quais a linha está vinculada.
8. *Posso ocultar linhas de conexão?*- Não, você só pode excluir linhas de conexão.
