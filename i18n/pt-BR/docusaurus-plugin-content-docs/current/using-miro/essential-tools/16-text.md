Saiba como você pode usar a ferramenta de texto nos seus boards da Miro.

:::note
Observe que este artigo descreve os controles disponíveis para a ferramenta de **texto**. Para saber mais sobre as opções de formatação de texto em [notas adesivas](14-sticky-notes.md), [tabelas](../advanced-tools/05-grid.md), [formas](11-shapes.md), [cartões](02-cards.md), [linhas de conexão](05-connection-lines.md), [mapas mentais](../advanced-tools/03-mind-map.md), consulte os artigos correspondentes.
:::

### Como adicionar e editar texto

Há duas maneiras simples de adicionar texto ao board:

- Selecione **Texto** na barra de ferramentas ou [pressione T no seu teclado](../working-on-the-board/06-shortcuts-and-hotkeys.md), clique em qualquer lugar do board e comece a digitar
- Arraste e solte um widget de texto da barra de ferramentas diretamente para o board

![text_on_the_toolbar.jpg](../../../../../../docs/using-miro/essential-tools/images/21017012885522_text%20on%20the%20toolbar.jpg)
*A ferramenta Texto na barra de ferramentas*

As opções de formatação ficam disponíveis enquanto você digita e sempre que a caixa de texto for selecionada. É possível escolher a fonte, a cor e a opacidade do texto, alinhar o texto à esquerda ou à direita, alterar o tamanho da fonte, destacar, etc.

:::note
Cada caixa de texto pode conter até 6.000 caracteres. Esse limite inclui os espaços e todos os códigos que alteram o estilo do texto. Portanto, a formatação do texto pode reduzir o número de caracteres que você pode inserir. Se você ultrapassar o limite, verá a mensagem **Você atingiu o limite da caixa de texto, parte do texto pode ser cortada**.
:::

![text_formatting.gif](../../../../../../docs/using-miro/essential-tools/images/21017042402578_text%20formatting.gif)
*Opções de formatação de texto*

Para editar o texto ou alterar parcialmente a formatação, clique duas vezes nele ou, se estiver usando a ferramenta de texto, basta clicar uma vez. Observe que ao alterar o tamanho da fonte ou do texto, toda a caixa de texto é afetada.
![formatting_a_part_of_the_text.gif](../../../../../../docs/using-miro/essential-tools/images/21017042403090_formatting%20a%20part%20of%20the%20text.gif)
*Como editar uma parte de uma linha de texto*

Para substituir o texto em uma caixa de texto, selecione-o e comece a digitar.

Você também pode usar os seguintes atalhos de formatação de texto:

- **Ctrl + B** *(para Windows)*, **Cmd + B** *(para Mac)* - negrito
- **Ctrl + I** *(para Windows)*, **Cmd + I** *(para Mac)* - itálico
- **Ctrl + U** *(para Windows)*, **Cmd + U** *(para Mac)* - sublinhado

Há duas maneiras de alterar o tamanho do texto: no menu de contexto ou arrastando o ponto branco.

![changing_font_size.gif](../../../../../../docs/using-miro/essential-tools/images/21017042403858_changing%20font%20size.gif)
*Como alterar o tamanho do texto*

Para redimensionar uma caixa de texto, arraste a borda esquerda ou direita. No modo foco, você também pode especificar a largura de uma caixa de texto em pixels ao clicar no ícone **Redimensionar** no menu de contexto.

![resizing_a_text_box.gif](../../../../../../docs/using-miro/essential-tools/images/21017042404626_resizing%20a%20text%20box.gif)
*Como alterar o tamanho de uma caixa de texto*

Para girar o texto, arraste o ícone da seta.

![rotate_text.gif](../../../../../../docs/using-miro/essential-tools/images/21017042405650_rotate%20text.gif)
*Como girar uma caixa de texto*

Você pode criar [links](../working-on-the-board/16-internal-and-external-linking.md) personalizados em caixas de texto através da opção **Inserir link** no menu de contexto. Você também pode criar um link ao escolher a opção **Link para** nos três pontos. Ou basta selecionar algum texto e colar um link usando os atalhos **Ctrl + V** (*para Windows*) ou **Cmd + V** (*para Mac*).

![linking_options.gif](../../../../../../docs/using-miro/essential-tools/images/21017012890002_linking%20options.gif)
*Como anexar o link de URL ao texto*

### Listas numeradas e com marcadores

As listas com marcadores e numeradas ajudam a dividir grandes blocos de texto para facilitar o entendimento e destacar as principais informações. Para iniciar uma lista com marcadores ou numerada, digite um traço ou um número e pressione a barra de espaço. É possível converter qualquer texto inserido em uma lista com marcadores ou numerada usando a ferramenta **adicionar lista** do menu de contexto. Sinta-se à vontade para personalizar suas listas e deixá-las com diversos níveis.

![number_points.gif](../../../../../../docs/using-miro/essential-tools/images/21017042407186_number%20points.gif)
*Criando uma lista em vários níveis*

Pressione **Shift + Enter** (**Return**) para adicionar uma quebra de linha a uma lista numerada.

Para finalizar a lista, pressione duas vezes a tecla **Return** ou **Enter**.

### Como copiar texto e estilo

Copie e cole o texto de outros boards e de aplicativos de terceiros usando os atalhos **Ctrl+C**/**Ctrl+V** (*para Windows*) ou **Cmd+C/Cmd+V** (*para Mac*). Aprenda [aqui](../working-on-the-board/10-working-with-objects.md) como selecionar vários objetos no board.

Você também pode aplicar rapidamente um estilo específico a todas as formas ou caixas de texto no board. Para copiar e aplicar a formatação, use os atalhos **Ctrl + Alt+ C** e **Ctrl + Alt + V** (*para Windows*) ou **Cmd + Alt+ C** e **Cmd + Alt + V** (*para Mac*). Ou clique nos três pontos no menu de contexto de texto e escolha a opção.

![copy_paste_style.gif](../../../../../../docs/using-miro/essential-tools/images/21017042407826_copy%20paste%20style.gif)
*Como copiar e colar o estilo*

Vale ressaltar que não é possível copiar a formatação de aplicativos de terceiros. As únicas exceções aqui são as listas numeradas e com marcadores.

### Verificação ortográfica

O [aplicativo para desktop](../../getting-started/apps-for-devices/05-desktop-app.md) da Miro possui uma verificação ortográfica embutida. Se você precisar desabilitar a verificação ortográfica, use [este guia](../../getting-started/apps-for-devices/05-desktop-app.md).

Se você estiver usando um navegador, a verificação ortográfica funcionará na Miro caso seja compatível com o navegador. Certifique-se de habilitar a verificação ortográfica nas configurações do navegador.

- Para o *Chrome*, abra as configurações do navegador > **Avançado** > **Idiomas** > ative a **Verificação ortográfica**.

### Perguntas frequentes

1. 1. *Como adicionar texto a uma linha de conexão?*
      - Veja como você pode adicionar texto às linhas [aqui](05-connection-lines.md).
   2. *Posso alterar a cor da borda de uma caixa de texto?*
      - Não, esta opção não está disponível atualmente. Você pode alterar a cor da borda das [formas](11-shapes.md).
   3. *Não vejo todas as opções de formatação quando clico em uma caixa de texto. Por quê?*
      - Observe que algumas opções de formatação listadas no artigo não são compatíveis com outras ferramentas de texto ([formas](11-shapes.md), [mapa mental](../advanced-tools/03-mind-map.md), [cartões](02-cards.md), etc.). Além disso, por favor, certifique-se de [mudar para o modo de seleção](../working-on-the-board/21-work-smarter-not-harder.md#como-alternar-entre-os-modos-de-selecao-e-panoramica).
   4. *Como mover uma caixa de texto?*
      - [Mude para o modo de seleção](../working-on-the-board/21-work-smarter-not-harder.md#como-alternar-entre-os-modos-de-selecao-e-panoramica), clique na caixa de texto e arraste-a. Certifique-se de que não esteja bloqueada.
   5. *Posso alterar a formatação de todas as caixas de texto no board de uma só vez?*
      - Sim. Selecione todos os objetos no board (você pode usar **Ctrl + A** *para Windows* ou **Cmd + A** *para Mac*), [filtro de texto](../working-on-the-board/21-work-smarter-not-harder.md), e altere a formatação.

:::note
Se você encontrar bugs ou problemas com o texto, confira [este artigo de solução de problemas](../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md).
:::
