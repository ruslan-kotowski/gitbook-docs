Os cartões da Miro fornecem a você uma maneira estruturada de organizar e atribuir trabalhos, fornecer detalhes para alinhar as partes interessadas e manter tudo nos trilhos. Use cartões para fazer um [planejamento](../advanced-tools/02-columns-formerly-kanban.md) ou [mapeamento de história](../advanced-tools/07-user-story-mapping.md).

> **Disponível em:** navegador para **desktop, aplicativo para desktop, funcionalidade limitada no aplicativo para tablet e aplicativo móvel**

## Como usar cartões

### Como adicionar o aplicativo de cartão à barra de ferramentas

Se você trabalha frequentemente com cartões no seu board, adicione a funcionalidade do cartão à sua barra de ferramentas para uma criação de cartões mais rápida.

1. Vá para a barra de ferramentas de criação no lado esquerdo do seu board
2. Clique no ícone **Mais aplicativos**
3. Pesquise por ‘cartão’
4. Clique no ícone do **cartão** para adicioná-lo à barra de ferramentas

![Adding_the_card_app_to_the_toolbar.gif](https://help.miro.com/hc/article_attachments/21017682764818)*Como adicionar o aplicativo de cartão à barra de ferramentas*

### Como adicionar cartões ao board

Há três maneiras de adicionar um cartão ao seu board.

**Arraste o ícone do cartão** da barra de ferramentas de criação e solte-o em qualquer lugar do board.

![Dragging_the_card_icon_to_the_board.gif](https://help.miro.com/hc/article_attachments/21017653140498)*Como arrastar o cartão para o board*

**Clique no ícone do cartão** e clique em qualquer lugar do board.

![Clicking_on_the_board_to_add_a_card.gif](https://help.miro.com/hc/article_attachments/21017653142034)*Clicar no ícone do cartão para adicionar um cartão ao board*

**Use a tecla de atalho** D e clique em qualquer lugar do board.

![Using_the_D_hotkey_to_add_a_card.gif](https://help.miro.com/hc/article_attachments/21017653143570)*Usar a tecla de atalho D para adicionar um cartão ao board*

:::tip
[Habilite as dimensões](../formats/diagramming/01-miro-for-mapping-diagramming.md) para criar cartões do mesmo tamanho em todo o seu board.
:::

### Como excluir cartões do board

1. Clique no cartão e pressione backspace no seu teclado
2. Você também pode clicar nos três pontos no menu de contexto (**...**) > **Excluir**

*![deleting_a_card.jpg](https://help.miro.com/hc/article_attachments/21017653122066)**Como excluir um cartão*

### Como converter outros objetos em cartões

Você pode converter qualquer [nota adesiva](14-sticky-notes.md), [caixa de texto](16-text.md) ou [forma](11-shapes.md) existente em um cartão usando a [funcionalidade](../working-on-the-board/20-switch-type.md) Alterar tipo.

1. Clique no objeto para abrir o menu de contexto
2. Clique no **ícone** Alterar tipo
3. Escolha o ícone do cartão no menu suspenso

![convertendo_um_postigo_em_um_cartão.gif](https://help.miro.com/hc/article_attachments/21017653127442)*Como converter uma nota adesiva em cartão*

**Para converter vários objetos em cartões**, clique e arraste para selecionar os objetos e clique no ícone Alterar tipo no menu de contexto. Selecione o ícone do cartão.

*![Bulk_converting_to_cards.gif](https://help.miro.com/hc/article_attachments/21017682764178)
Como converter várias notas adesivas em cartões*

:::tip
Você pode [converter os cartões da Miro em cartões do Jira](../../integrations-apps/atlassian/03-jira-cards.md). Use a conversão em massa para criar vários cartões do Jira após uma sessão de brainstorming do time ou uma cerimônia ágil.
:::

### Como abrir o painel do cartão

Abra o painel do cartão para ver todos os detalhes do cartão, faça todas as suas edições de uma só vez e adicione uma descrição.

Para abrir o painel do cartão, clique no ícone **Expandir** no canto superior direito do cartão ou no menu de contexto do cartão. Você também pode usar a tecla de atalho **Ctrl** + **Shift** + **Enter** (*para Windows*) **Cmd** + **Shift** + **Enter** (*para Mac)***.**

![Expanding_a_card.gif](https://help.miro.com/hc/article_attachments/21017653138450)*Como abrir o painel do cartão*

## Como editar e personalizar cartões

### Como editar um cartão

Clique no cartão para abrir o menu de contexto ou abra o painel do cartão Aqui você pode alterar a cor e o tamanho dos cartões, adicionar tags, links e datas e atribuir cartões aos usuários.

![customizing_a_card.gif](https://help.miro.com/hc/article_attachments/21017653129746)*Como editar um cartão*

### Como editar cartões em massa

1. Arraste o campo de seleção entre os cartões ou selecione cartões, um por um, enquanto mantém pressionado **Shift** ou **Ctrl** *(para Windows)* ou **Command** *(para Mac)*
2. O menu de contexto será aberto
3. Escolha qualquer ferramenta no menu de contexto para fazer edições

![Bulk-editing_cards.gif](https://help.miro.com/hc/article_attachments/21017682775570)*Como editar vários cartões de uma vez*

### Como redimensionar ou girar um cartão

Clique no cartão e arraste os pontos brancos. Você pode girar o cartão arrastando o ícone da seta.

![Changing_size_and_rotating_a_card.gif](https://help.miro.com/hc/article_attachments/21017682763538)*Como alterar o tamanho do cartão e girá-lo*

### Como atribuir um cartão para um usuário

Os cartões podem ser atribuídos para usuários que têm acesso ao board por [convite via e-mail](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md), [compartilhamento do time](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) ou um [projeto](../sharing-boards/16-projects.md). Os cartões não podem ser atribuídos a [visitantes](../sharing-boards/08-collaboration-with-visitors.md).

1. Clique no cartão para abrir o menu de contexto ou abra o painel do cartão
2. Clique no **ícone** adicionar responsável
3. Selecione um usuário no menu suspenso

![adding_an_assignee.jpg](https://help.miro.com/hc/article_attachments/21017653123474)*Como atribuir um cartão a um usuário*

### Como adicionar e remover tags de cartões

1. Clique no cartão para abrir o menu de contexto ou abra o painel do cartão
2. Clique no **ícone** adicionar tag
3. Digite o texto para sua tag (e escolha a cor da tag)
4. Clique em criar ou pressione enter no seu teclado
5. Clique em uma tag para removê-la do cartão

:::tip
Use tags para [pesquisar e filtrar](../working-on-the-board/19-searching-text-on-the-board.md) seus cartões.
:::

![Managing_tags_on_cards.gif](https://help.miro.com/hc/article_attachments/21017653131410)*Como adicionar e remover tags de um cartão*

### Como atualizar o status de um cartão

1. Clique no cartão para abrir o menu de contexto ou abra o painel do cartão
2. Clique no **ícone** adicionar status
3. Selecione **Fazer**, **Em progresso** ou **Concluído** no menu suspenso.
4. Para remover um status, clique em **Remover status**

![Atualizando_o_status_de_um_cartão.gif](https://help.miro.com/hc/article_attachments/21017682776466)*Como atualizar o status de um cartão*

### Como adicionar e remover datas em um cartão

1. Clique no cartão para abrir o menu de contexto ou abra o painel do cartão
2. Clique no **ícone** para definir data
3. Digite a data inicial e/ou a data final.
4. Para limpar uma data, clique em **x** ao lado do campo de data

![Adicionando_datas_a_um_cartão.gif](https://help.miro.com/hc/article_attachments/21017653147538)*Como adicionar a data inicial e final a um cartão*

### Títulos e descrições dos cartões

Você pode adicionar até 20.000 símbolos de texto na descrição e no título do cartão. O título do cartão é sempre visível. Os usuários podem expandir o cartão para ver a descrição.

#### **Como adicionar o título do cartão**

Clique no cartão e comece a digitar. Alterar a fonte de texto e o tamanho de um título de cartão não é possível.

![Adding_a_title_to_a_card.gif](https://help.miro.com/hc/article_attachments/21017653148690)*Como adiciona o título do cartão*

#### **Como adicionar uma descrição de cartão**

Clique no ícone de expandir para abrir o painel do cartão e comece a digitar no **campo** Descrição. Você também pode colar texto copiado diretamente no campo de descrição usando **Ctrl + C**/**Ctrl + V** (*para Windows*) ou **Cmd + C/Cmd + V** (*para Mac*).

![Adding_a_description_to_the_card.gif](https://help.miro.com/hc/article_attachments/21017653150226)*Como adicionar a descrição do cartão*

## Como exportar cartões

1. Arraste o campo de seleção entre os cartões ou selecione cartões, um por um, enquanto pressiona **Shift** ou **Ctrl** *(para Windows)* ou **Command** *(para Mac)*.
2. Clique no ícone **Exportar** > **Exportar para** **planilha (CSV)**.

![export_menu_cards_export_to_csv.gif](https://help.miro.com/hc/article_attachments/21022323561234)
*Como exportar cartões para um CSV*

## Teclas de atalho do cartão

- **D** + clique para adicionar um novo cartão ao board
- **Ctrl + Shift + Enter *(para Windows)*, Cmd + Shift + Enter *(para Mac)*** para abrir todos os cartões
- **Tab** para criar um novo cartão e editar o título do cartão
- **Ctrl + B** *(para Windows)*, **Cmd + B** (*para Mac)* — negrito
- **Ctrl + I** *(para Windows)*, **Cmd + I** *(para Mac) —* itálico
- **Ctrl + U** *(para Windows)*, **Cmd + U** *(para Mac) —* sublinhado
- **“-”** + **espaço** no início de uma linha para uma lista com marcadores
- **“1.”** no início de uma linha para uma lista numerada
- Selecione texto e **Ctrl + V** *(para Windows) ou* **Cmd + V** *(para Mac)* para criar um hiperlink

## Perguntas frequentes

**Se eu atribuir um cartão para um usuário, eles receberão uma notificação por e-mail?**

Não, o usuário não receberá uma notificação por e-mail.

**Posso configurar lembretes de e-mail com base na data limite que adicionei a um cartão?**

No momento, isso não é possível.
