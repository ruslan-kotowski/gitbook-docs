As notas adesivas são ótimas para fazer um brainstorming rápido, tomar notas e organizar as informações visualmente. Se já conhece os boards Kanban ou outras técnicas que envolvem colocar notas adesivas em uma lousa, você se sentirá em casa.

> **Disponível em:** versão para navegador, aplicativo para desktop, [aplicativo para tablet](../../getting-started/apps-for-devices/05-desktop-app.md), aplicativo móvel (funcionalidade limitada)

### Primeiros passos

Clique na **nota adesiva** (![icon-sticky.svg](https://help.miro.com/hc/article_attachments/25736234297234)ícone) na barra de ferramentas ou [pressione N no seu teclado](../working-on-the-board/06-shortcuts-and-hotkeys.md) para começar a usar a ferramenta. Você também pode adicionar uma nota adesiva arrastando e soltando a nota diretamente da barra de ferramentas ou clicando no board e arrastando o cursor com o botão esquerdo do mouse.

Você pode alterar a forma de uma nota adesiva clicando no ícone no menu de contexto da nota adesiva.

![tipo-interruptor-adesivo.png](https://help.miro.com/hc/article_attachments/25736210907154)
*Como converter uma nota adesiva quadrada em uma nota retangular*

Há 16 cores disponíveis para as notas adesivas, que foram cuidadosamente selecionadas para garantir melhor legibilidade e consistência do texto no design dos seus boards (sem cores personalizadas).

![cor-de-preenchimento-pegajoso.png](https://help.miro.com/hc/article_attachments/25736234303506)
*As cores das notas adesivas*

Para adicionar texto à sua nota adesiva, selecione a nota e comece a digitar. O limite de símbolos é de cerca de 3.000 por nota adesiva, dependendo do tamanho do texto. Você pode habilitar o ajuste **automático** do tamanho da fonte no menu de contexto.

Para modificar várias notas adesivas (alterar o tamanho, a cor, adicionar tags, etc.), selecione-as seguindo as etapas [deste guia](../working-on-the-board/10-working-with-objects.md).

> [💡 Habilite as dimensões para criar notas adesivas com o mesmo tamanho em todo o seu board com precisão.](../formats/diagramming/01-miro-for-mapping-diagramming.md)

Para excluir uma nota adesiva, clique nos três pontos do menu de contexto e escolha **Excluir** ou simplesmente [selecione a nota adesiva](../working-on-the-board/21-work-smarter-not-harder.md#como-alternar-entre-os-modos-de-selecao-e-panoramica) e pressione **Backspace**.

:::tip
Para alinhar um monte de notas adesivas em uma linha ou coluna, [selecione as notas adesivas](../working-on-the-board/10-working-with-objects.md) e use o recurso **Alinhar** no menu de contexto.
:::

![alinhamento-pegajoso.png](https://help.miro.com/hc/article_attachments/25736234309650)
*Alinhando notas adesivas*

### Modo em massa

Para adicionar vários notas adesivas em sequência, clique no ícone **de nota adesiva** , escolha **o modo em massa** e insira o conteúdo de cada um. Pressione **Enter** para separar ideias. O limite de símbolos depende do tamanho da fonte. Clique em **Concluído** quando terminar, e suas ideias serão adicionadas ao board como notas adesivas.

### Bloco de notas adesivas

Você pode adicionar uma pilha de notas adesivas em branco ao board usando o recurso Pilha de Notas Fixas. Para adicionar uma pilha fixa:

1. Clique no ícone **Fixo** na **barra de ferramentas Criação**.
2. Clique em **Empilhar**.
3. Clique no board onde você gostaria de colocar o Sticky Stack.

Os usuários podem então arrastar os notas adesivas da Pilha de itens fixos para o board em vez de precisar adicioná-los na barra de ferramentas Criação ou usar atalhos de teclado.

### Colar de uma planilha (Google Sheets, Excel, etc.)

Você pode copiar dados de qualquer planilha e colar no board como um grupo de notas adesivas, onde cada nota adesiva representa uma única célula.

1. Copie as células da planilha usando **Ctrl + C** *(para Windows)* ou **Cmd + C** *(para Mac)*
2. Abra um board da Miro, clique no canvas (você **não precisa** abrir o modo em massa)
3. Pressione **Ctrl + V** *(para Windows)* ou **Cmd + V** *(para Mac)*
4. Escolha **Colar como notas adesivas** para colar as notas adesivas no board

Cada célula será importada como uma nota adesiva. O número máximo de células que você pode colar de cada vez é de **5.000** (mas não mais de 50 linhas e 100 colunas) e o número máximo de caracteres é de **6.000**.

### Etiquetas de autoria

Adicione facilmente o nome de quem criou as notas adesivas com um clique. Quaisquer editores com acesso ao board podem revelar ou ocultar a etiqueta de autoria das notas adesivas, habilitando/desabilitando a opção **mostrar autoria** no menu de contexto.

![autor-do-show-pegajoso.png](https://help.miro.com/hc/article_attachments/25736234311442)
*Como revelar a etiqueta de autoria*

A etiqueta de autoria em uma nota adesiva com texto exibe o nome do usuário que criou a nota adesiva. No entanto, se o texto da nota adesiva for substituído por outro usuário, a etiqueta de autoria será atualizada automaticamente. Se o usuário B selecionar uma nota adesiva vazia criada pelo usuário A e habilitar a etiqueta de autoria, ela apresentará o nome do usuário B em vez do usuário A. Se um [visitante](../sharing-boards/08-collaboration-with-visitors.md) digitar em uma nota adesiva e habilitar uma etiqueta de autoria, o nome aparecerá como "visitante" (a menos que tal [visitante tenha um nome](../sharing-boards/09-visitor-names-beta.md) ou faça login na Miro).

As etiquetas de autoria são desabilitadas por padrão e não é possível aplicar etiquetas de autoria para todos os usuários do board. Mesmo assim, ainda há maneiras de rastrear quem criou e editou a nota adesiva (no [histórico do board](../managing-boards/11-board-history-activity.md) e em **Informações** no menu de contexto).

### Tags

Use **Tags** para estruturar suas tarefas e ideias. Para destacar uma nota adesiva, clique no ícone T**ag**para criar uma tag ou escolha uma existente e aplique a quantas notas adesivas quiser. A pesquisa por tags permite que você localize rapidamente um grupo de notas adesivas. Você pode adicionar até oito tags a cada nota adesiva.

![etiqueta-adesiva.png](https://help.miro.com/hc/article_attachments/25736234314514)
*Como usar as tags*

Para encontrar todas as notas adesivas que contêm uma tag específica, use a [pesquisa de boards](../working-on-the-board/19-searching-text-on-the-board.md).

Para excluir uma tag de um post, selecione **adicionar tag** no menu de contexto e clique na tag que deseja remover.

Para remover **completamente** uma tag de **todos** os objetos do board, clique no ícone da caneta e escolha **Excluir tag**.

### Reações com emoji

Você pode adicionar uma reação comEmoji a notas adesivas para responder a qualquer nota. O emoji pode ser usado para vários fins: votação, verificação de itens a fazer e apenas por diversão.

Para reagir com emojis, escolha uma nota adesiva e procure **adicionar emoji** no menu. Após selecionar um emoji, ele será colocado na parte inferior da nota adesiva. É possível adicionar votos ao emoji existente, além de várias reações a uma nota adesiva.

![emoji-pegajoso.png](https://help.miro.com/hc/article_attachments/25736210915602)
*Como adicionar reações de emoji a notas adesivas*

Para remover um emoji que você adicionou, basta clicar nele (certifique-se de usar a [ferramenta de seleção](../working-on-the-board/05-using-miro-with-a-mouse-trackpad-or-touchscreen.md)).

### Criação rápida de diagramas

Se você selecionar uma nota adesiva, uma forma ou um cartão e passar o mouse sobre um ponto azul perto do objeto, ele mostrará onde um novo objeto ou linha de conexão será criado. Clique no ponto para criar o objeto ou/e a linha de conexão. Arraste o ponto para conectar o objeto selecionado a outro existente.

:::tip
Saiba mais sobre as funcionalidades de criação de diagramas: [Miro para criação de mapas e diagramas](../formats/diagramming/01-miro-for-mapping-diagramming.md).
:::

### Perguntas frequentes

1. *Posso formatar texto dentro de notas adesivas?*
   - Você pode alterar o tamanho, o alinhamento e o estilo (negrito, itálico, sublinhado) do texto dentro das notas adesivas. Outras opções de formatação não estão disponíveis.
2. *Posso exportar texto de notas adesivas?*
   - Sim, basta [selecionar as notas adesivas](../working-on-the-board/10-working-with-objects.md), clicar nos três pontos do menu de contexto e escolher **Exportar para CSV**. Você também pode [exportar o conteúdo do seu board como uma imagem ou PDF](../import-and-export/export/03-how-to-export-your-board.md).
3. *[Desenhos a caneta](10-pen.md), imagens e ícones podem ser anexados automaticamente (colados) em notas adesivas?*
   - Não, mas você pode colocar seu desenho/imagem/etc. na nota adesiva, [selecionar os dois objetos](../working-on-the-board/10-working-with-objects.md) e [agrupá-los](../working-on-the-board/08-structuring-board-content.md). O desenho será anexado à nota adesiva.
4. *Os [comentaristas](../sharing-boards/01-board-access-rights.md) podem adicionar notas adesivas e emojis?*
   - Não, os comentaristas só podem deixar [comentários](../facilitation-tools/asynchronous-tools/01-comments.md) e não podem usar outros widgets.
5. *Como posso adicionar um monte de notas adesivas ao meu board?*
   - Você pode usar o modo em massa para adicionar notas adesivas pré-preenchidas ou usar o [template](../../getting-started/start-here/your-first-board/04-templates.md) de **Pacotes de notas adesivas** para adicionar várias notas adesivas em branco (use a pesquisa para encontrá-lo no [seletor de templates](../../getting-started/start-here/your-first-board/04-templates.md)).
6. *O ícone de nota adesiva sumiu da minha barra de ferramentas.*  Como posso recuperá-lo?
   - Clique nos três pontos na barra de ferramentas e encontre a ferramenta usando o painel de pesquisa. Você pode arrastá-lo de volta para a sua barra de ferramentas. [Saiba mais](../../getting-started/start-here/your-first-board/05-toolbars.md).
7. *De repente, não consigo mais editar as minhas notas adesivas.*  Por quê?
   - Por favor, certifique-se de que:
   - seus acessos de [edição](../sharing-boards/01-board-access-rights.md) não foram revogados (se conseguir usar outras ferramentas na barra de ferramentas, isso significa que você ainda tem acesso de edição)
   - suas notas adesivas não estão [bloqueadas](../working-on-the-board/17-locking-content-on-the-board.md)
   - você mudou para a [ferramenta de seleção](../working-on-the-board/05-using-miro-with-a-mouse-trackpad-or-touchscreen.md) antes de editar uma nota adesiva.
     Se isso não resolver, tente seguir as etapas de solução de problemas [neste artigo](../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md).
