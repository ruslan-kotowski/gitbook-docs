Crie painéis para reuniões operacionais, comprove ideias com dados e visualize números-chave usando gráficos editáveis ​​no Miro.

### Como usar gráficos

Clique em **gráficos** na barra de ferramentas, selecione um tipo de gráfico e clique nele ou arraste-o para o board.

![gráficos.jpg](../../../../../../docs/using-miro/essential-tools/images/21019591236114_charts.jpg)
*Gráficos na barra de ferramentas*

Selecione o objeto para abrir o menu de contexto, clique nos três pontos e clique em **Editar**ou clique duas vezes no objeto para entrar no menu de edição.modo.

![edit_a_chart.jpg](../../../../../../docs/using-miro/essential-tools/images/21019535206162_edit%20a%20chart.jpg)
*Entrando no modo de edição*

Escolha o nome e personalize a legenda para tornar seu gráfico mais informativo. Ative e desative as opções de **Título** e **Legenda**. Você também pode limpar todas as notas com um clique.

![editando_um_gráfico.gif](../../../../../../docs/using-miro/essential-tools/images/21019591247122_editing%20a%20chart.gif)
*Editando um gráfico*

Para excluir uma linha, selecione todas as células de uma linha, clique no ícone **lixeira**e escolha **Excluir linha.**

![delete_a_row.gif](../../../../../../docs/using-miro/essential-tools/images/21019535215250_delete%20a%20row.gif)
*Exclusão de linha*

### Perguntas frequentes

1. *Posso adicionar valores negativos aos gráficos?*- Não, você só pode somar números positivos.
2. *Posso alterar a cor dos elementos do gráfico?*- Não, as cores são escolhidas automaticamente.
3. *Como faço para exportar meu gráfico?*- Verifique as opções de exportação do board [aqui](../import-and-export/export/03-how-to-export-your-board.md).
