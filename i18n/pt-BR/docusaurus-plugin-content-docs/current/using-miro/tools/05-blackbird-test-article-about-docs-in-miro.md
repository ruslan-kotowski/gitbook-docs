Transforme o conteúdo do seu board no formato mais estruturado de um Doc. Ao usar objetos no canvas como entrada, você pode criar resumos, relatórios de pesquisa e briefings de produtos para começar a reunir e analisar seus insights.

> Disponível para: todos os planos da Miro
> Disponível em: desktop, aplicativo móvel e displays interativos

## Como acessar a funcionalidade Documentos

Para adicionar um novo documento, clique no ícone de adição, pesquise por Documentos e clique em qualquer lugar do canvas para adicioná-lo. Os documentos também já estão incluídos em alguns templates de boards.

![](../../../../../../docs/using-miro/tools/images/25640385657234_33fb246e-3278-4496-8a69-5bd34721a01e.png)

*Como adicionar um novo documento pelo ícone Documentos*

Você também pode adicionar um documento com a Miro AI.

![](../../../../../../docs/using-miro/tools/images/25640369208978_678b2f2a-4e6b-449d-af82-0074d85d6d85.png)

*Como adicionar um documento com a Miro AI*

Para adicionar um documento pelo menu de contexto:

1. Crie um documento selecionando vários objetos no board (como notas adesivas).
2. No ícone da **Miro AI**, selecione **Documento** no menu de contexto para abrir o submenu.
3. Escolha um template ou use um **prompt personalizado**.
4. O documento é criado e inserido no board.

![doc-from-stickies.png](../../../../../../docs/using-miro/tools/images/25640369209362_doc-from-stickies.png)

*Adicionando um documento via o menu de contexto*

Para adicionar um documento com a Miro AI:

1. Abra o painel **Crie com IA**.
2. Selecione o tipo de conteúdo **Documento**.
3. Use um dos prompts predefinidos ou escreva o seu.
4. Selecione objetos (como notas adesivas) no board para adicionar contexto, se necessário.
5. Clique em **Gerar documento**.
6. O documento gerado aparecerá em uma área em branco do canvas.

## Templates dos Documentos da Miro

No momento, há quatro templates disponíveis ao iniciar um novo Doc: briefing de produto, resumo da retrospectiva, notas da reunião e síntese de pesquisa.

Quando você cria um novo documento e seleciona um template, o template é adicionado a esse documento.

## Trabalhar em Documentos no modo de tela inteira

Os Documentos podem ser abertos no modo de tela inteira quando você quiser se concentrar apenas no documento em que está trabalhando e não em outros conteúdos do board. Para acessar este modo, clique no **ícone de tela inteira** acima do Doc em que você está trabalhando.

![docs-ícone-tela-inteira.png](../../../../../../docs/using-miro/tools/images/25640369213074_docs-full-screen-icon.png)

*Ícone de tela inteira de Documentos*

O modo de tela inteira ainda inclui os menus de contexto para formatação de texto. Ele remove o fundo do board, eliminando possíveis distrações.

Para sair do modo de tela inteira, clique no botão **Idealizar no canvas** na parte superior da tela.

![docs-focus-mode.png](../../../../../../docs/using-miro/tools/images/25640385661202_docs-focus-mode.png)

### Limite de caracteres

Documentos da Miro podem conter até 80 mil caracteres. Se precisar de mais espaço, você pode criar Documentos adicionais no mesmo board e dividir seu conteúdo de acordo. Isso ajuda você a permanecer dentro do limite enquanto ainda organiza todas as suas informações em um só lugar.

## Copiar conteúdo para Documentos

Você pode arrastar e soltar o seguinte conteúdo do seu board em um documento:

- nota adesiva
- Caixa de texto
- Imagem
- iFrame
- Visualização
- Tabela
- Linha do tempo
- Diagrama

:::note
A funcionalidade Documentos converte as notas adesivas e as caixas de texto em uma lista com marcadores.
:::

![Arraste e solte os widgets de dados em um documento da Miro.](../../../../../../docs/using-miro/tools/images/25640385663122_docs-tables-widget.gif)

*Arraste e solte os widgets de dados em um documento*

### Diagramas em Documentos

Quando você arrasta e solta um Diagrama em um Doc, a Miro cria uma [cópia sincronizada](../working-on-the-board/11-synced-copies.md). Isso significa que as alterações feitas no Documento original no board serão refletidas na cópia dentro do Doc, mas não o contrário. Para alterar o conteúdo da cópia, modifique o conteúdo do Diagrama original.

Isso garante que sua documentação permaneça atualizada com as informações visuais mais recentes.

### Comportamento de outro conteúdo em Documentos

Para widgets com modo foco, como uma Tabela, você ainda pode acessar o modo imersivo quando o widget estiver em um documento. As dimensões se ajustam para caber e rolar dentro do Doc.

Você também pode arrastar o conteúdo para fora do documento para colocá-lo de volta no seu board.

## Como usar atalhos de teclado em Documentos

Os atalhos de teclado podem ser usados para aplicar tipos de títulos e listas ao texto (esses atalhos podem ser vistos no submenu de tipos de parágrafo):

Transformar em: **Use cmd + opt + \{number\}**

- Parágrafo
- 1 -> Título 1
- 2 -> Título 2
- 3 -> Título 3
- 4 -> Lista com marcadores
- Lista numerada
- 6 -> Lista de verificação

Você também pode usar atalhos de teclado para seleção de blocos: pressione Esc uma vez para entrar no modo de seleção de blocos, em seguida:

- **shift + para cima/baixo** -> expanda sua seleção
- **cmd + opt + para cima/baixo** -> move sua seleção para cima e para baixo

Confira abaixo outras funcionalidades em Documentos que podem ser acessadas pelas teclas de atalho:

|  |  |
| --- | --- |
| **⌘** + **enter** | Focar no menu de seleção de texto |
| **⌘** + **Shift** + **X** | Alternar tachado |
| **⌘** + **Shift** + **U** | Adicionar link |
| **⌘** + **E** | Alternar código em linha |
| **⌘** + **,** | Marcar/desmarcar item da lista de verificação |
| **⌘** + **/** | Abrir menu de contexto do bloco |
| **⌘** + **D** | Duplicar blocos selecionados |
| **⌘** + **I** | Copiar link para um bloco |

Para acessar a lista completa de atalhos de teclado no aplicativo da Miro, clique no ícone de **Ajuda e recursos** no canto inferior direito da tela:

![docs-atalhos-teclado.png](../../../../../../docs/using-miro/tools/images/25640369222418_docs-keyboard-shortcuts.png)

*Atalhos de teclado pelo ícone de Ajuda e recursos*

## Como usar a Miro AI em Documentos

Usar a Miro AI para editar seus documentos é uma ótima maneira de acelerar o processo de edição e criar documentos mais concisos e fáceis de ler.

Você pode usar a Miro AI para modificar o texto destacado em um Doc.

![](../../../../../../docs/using-miro/tools/images/25640369225490_image.png)

*Use o prompt da Miro AI para modificar o texto destacado em um Documento da Miro.*

Para acionar o prompt da Miro AI usando texto embutido, destaque o texto no seu documento da Miro. No menu de contexto à direita, selecione **Aprimorar com a Miro AI**. No menu suspenso, selecione **Prompt personalizado** ou qualquer um dos prompts disponíveis.

## Colaboração em Documentos da Miro

Os Documentos da Miro são ideais para colaboração em tempo real com outros usuários. Assim como ocorre com outros conteúdos no canvas, é possível habilitar o rastreamento do cursor, permitindo ver onde os outros usuários estão trabalhando no Doc.

Também é possível incluir comentários e @mencionar outros usuários (que serão notificados tanto no aplicativo quanto por e-mail). As conversas e as reações dos comentários também estão habilitadas.

### Fichas de usuários em Documentos da Miro

As fichas dos usuários permitem fornecer detalhes sobre os usuários dentro de um doc. Por exemplo, adicione fichas de @usuário para os principais membros do time ou stakeholders.

Para adicionar a ficha de um usuário, digite '@' em um documento da Miro. Em seguida, digite o nome do usuário para filtrar os resultados ou selecione um usuário no menu suspenso exibido.

![Adicione fichas de usuários em qualquer lugar de um documento da Miro.](../../../../../../docs/using-miro/tools/images/25640369225490_image.png)

*Adicione fichas de usuários em qualquer lugar de um documento da Miro.*

Passe o mouse sobre a ficha de um @usuário para ver suas informações.

![As fichas de usuários incluem informações sobre os usuários.](../../../../../../docs/using-miro/tools/images/25640369225490_image.png)

*As fichas de usuários incluem informações sobre os usuários.*

As fichas de usuários são diferentes das menções em um comentário. Por exemplo, elas não enviam notificações a um usuário específico.

## Como copiar, compartilhar e exportar Documentos

Os Documentos podem ser copiados entre os boards, mas não são sincronizados para alterações futuras. Ou seja, todas as edições feitas no documento de um board não serão aplicadas a outros boards adicionais para os quais o documento foi copiado ou do qual foi copiado.

Os documentos podem ser compartilhados por link com outros usuários.

Os documentos podem ser exportados para o formato PDF pelo ícone **Mais** (![icon-main.svg](../../../../../../docs/using-miro/tools/images/25640369228946_icon-main.svg)) no menu de contexto.
