As notas adesivas são ótimas para fazer um brainstorming rápido, tomar notas e organizar as informações visualmente. Se já está familiarizado com os boards Kanban ou outras técnicas que envolvem colocar notas adesivas em uma lousa, você se sentirá em casa.

> **Disponível em:** versão para navegador, [aplicativo para desktop](../../getting-started/apps-for-devices/05-desktop-app.md), [aplicativo para tablet](../../getting-started/apps-for-devices/11-tablet-app.md), [aplicativo móvel](../../getting-started/apps-for-devices/08-mobile-app.md) (funcionalidade limitada)

### Primeiros passos

Clique no **ícone da nota adesiva** (![icon-sticky.svg](../../../../../../docs/using-miro/tools/images/25953100365714_icon-sticky.svg)) na barra de ferramentas ou [pressione N no seu teclado](../working-on-the-board/06-shortcuts-and-hotkeys.md) para começar a usar a ferramenta. Você também pode adicionar uma nota adesiva arrastando e soltando diretamente da barra de ferramentas ou clicando no board e arrastando o cursor enquanto mantém pressionado o botão esquerdo do mouse.

Você pode alterar a forma de uma nota adesiva clicando no ícone no menu de contexto da nota adesiva.

![sticky-switch-type.png](../../../../../../docs/using-miro/tools/images/25953100366994_sticky-switch-type.png)
*Como converter uma nota adesiva quadrada em uma nota retangular*

Há 16 cores disponíveis para as notas adesivas, que foram cuidadosamente selecionadas para garantir a melhor legibilidade do texto e consistência no design dos seus boards (sem cores personalizadas).

![sticky-fill-color.png](../../../../../../docs/using-miro/tools/images/25953130442642_sticky-fill-color.png)
*As cores das notas adesivas*

Para adicionar texto à sua nota adesiva, selecione a nota e comece a digitar. O limite de símbolos é de cerca de 3.000 por nota adesiva, dependendo do tamanho do texto. Você pode habilitar o tamanho **Automático** da fonte no menu de contexto.

Para modificar várias notas adesivas (alterar o tamanho, a cor, adicionar tags, etc.), selecione-as seguindo as etapas deste [guia](../working-on-the-board/10-working-with-objects.md).

:::tip
[Habilite as dimensões](../formats/diagramming/01-miro-for-mapping-diagramming.md) para criar notas adesivas com o mesmo tamanho em todo o seu board com precisão.
:::

Para excluir uma nota adesiva, clique nos três pontos do menu de contexto e escolha **Excluir** ou simplesmente [selecione a nota adesiva](../working-on-the-board/21-work-smarter-not-harder.md#como-alternar-entre-os-modos-de-selecao-e-panoramica) e pressione **Backspace**.

:::tip
Para alinhar várias notas adesivas em uma linha ou coluna, [selecione as notas adesivas](../working-on-the-board/10-working-with-objects.md) e use a funcionalidade **Alinhar** no menu de contexto.
:::
