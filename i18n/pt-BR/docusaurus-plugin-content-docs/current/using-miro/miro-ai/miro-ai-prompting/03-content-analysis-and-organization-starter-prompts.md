Começando na Miro AI? Utilize prompts prontos para análise e organização de conteúdo. Cada caso de uso explica sua finalidade e inclui prompts para Miro AI que estão prontos para copiar. Substitua os marcadores entre colchetes (por exemplo, [função], [artefato], [tom]) com seu contexto, depois execute o prompt no Miro AI.

## **Processamento e sumarização de informação**

Transforme anotações brutas em resumos claros, temas e listas de ações.

### Resumir tópicos de discussão

**Para que serve:** Resumos rápidos e compartilháveis de boards extensos ou grupos de anotações.

**Prompt do Miro AI:**

Copiar

```
Crie um resumo conciso em 3 parágrafos dos pontos principais da discussão selecionada no board da Miro. Capture os principais temas, decisões tomadas e próximos passos. Formate como um Documento da Miro.
```

### Identifique e agrupe os principais temas

**Para que serve:** Agrupamento rápido para ver padrões e o que é mais relevante.

**Prompt da Miro AI:**

Copiar

```
Analise as ideias e itens de feedback selecionados no board da Miro. Identifique os 5 principais temas recorrentes e agrupe os itens relacionados sob cada tema. Apresente como uma lista estruturada. Formate como notas adesivas da Miro.
```

### Extrair e priorizar itens de ação

**Para que serve:** Extrair tarefas, responsáveis e datas a partir de notas desorganizadas.

**Prompt Miro AI:**

Copiar

```
Revise as notas selecionadas no board da Miro. Extraia todos os itens de ação e organize-os com: descrição da tarefa, pessoa responsável (se mencionada) e prazo (se mencionado). Formate como uma Tabela Miro.
```

### Categorizar feedback

**Para que serve:** Agrupar entradas em categorias claras com prioridades.

**Prompt do Miro AI:**

Copiar

```
Categorize o feedback selecionado no board do Miro em grupos lógicos e sugira níveis de prioridade (alto/médio/baixo) para cada categoria com base na frequência e impacto. Formate como uma Tabela do Miro.
```

## **Síntese de dados**

Combine entradas de várias fontes em resultados claros, prontos para decisão.

### Combine insights de pesquisa de usuários

**Para que serve:** Consolidar várias sessões em um conjunto conciso de insights.

**Prompt do Miro AI:**

Copiar

```
Sintetizar as principais descobertas de várias sessões de pesquisa com usuários selecionadas no board da Miro em 5 principais insights com evidências de apoio. Destaque quaisquer descobertas conflitantes que precisem de investigação adicional. Formate como um Documento da Miro.
```

### Criar resumos executivos

**Para que serve:** Relatórios de uma página para líderes e stakeholders.

**Prompt do Miro AI:**

Copiar

```
Crie resumos executivos
Crie um resumo executivo de uma página com base nas informações detalhadas do projeto selecionadas no board da Miro. Cubra: status do projeto, principais realizações, desafios atuais e próximos passos recomendados. Formatar como um Documento da Miro.
```

### Gerar relatórios de status

**Para que serve:** Atualizações semanais com progresso, impedimentos e prioridades.

**Prompt do Miro AI:**

Copiar

```
Gere um relatório de status semanal usando as informações de acompanhamento do projeto selecionadas no board Miro (status atual, tarefas concluídas, marcos futuros). Destaque os progressos, bloqueios e prioridades para a próxima semana. Formate como uma Tabela do Miro.
```

### Consolidar feedback dos stakeholders

**Para que serve:** Alinhar pontos de vista e destacar conflitos + resoluções.

**Prompt da Miro AI:**

Copiar

```
Consolide o feedback de diferentes stakeholders selecionados no board da Miro em um resumo que mostre áreas de acordo, pontos de vista conflitantes e resoluções sugeridas. Formate como um Diagrama da Miro.
```
