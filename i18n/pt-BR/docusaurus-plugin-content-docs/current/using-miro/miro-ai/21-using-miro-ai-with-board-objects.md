Use a Miro AI com uma variedade de objetos do board, incluindo [notas adesivas](../essential-tools/14-sticky-notes.md), imagens, diagramas e [mapas mentais](../advanced-tools/03-mind-map.md).

> **Disponível em:** Navegador, Desktop
>
> **Disponível para:** planos Free, Starter, Education, Business e Enterprise

:::warning
A Miro AI está em constante evolução. A Miro AI pode produzir informações incorretas, tendenciosas ou não saber sobre eventos recentes dos últimos 6 a 12 meses, resultando em informações imprecisas ou desatualizadas. Sempre verifique seus resultados ao usar a Miro AI.
:::

:::note
A Miro AI está disponível somente para membros. Convidados e visitantes não podem usar a Miro AI.
:::

## Como usar a Miro AI com notas adesivas

A Miro AI permite as seguintes ações:

- Gerar nota adesiva
- Agrupar notas adesivas por palavra-chave, autor, tag, cor ou sentimento
- Gerar um documento com base em notas adesivas
- Resumir um grupo de notas adesivas

### Como usar a Miro AI para gerar notas adesivas

Siga estes passos:

1. Acima da barra de ferramentas de criação, selecione **Crie com IA**.
2. Selecione o botão **notas adesivas** .
3. (Opcional) Selecione um tipo.
4. Crie um prompt para a Miro AI:
   - Insira uma descrição
   - Selecione objetos no board
5. Selecione **Gerar notas adesivas**.
   Suas notas adesivas são adicionadas ao board da Miro.

   Você usou a Miro AI para gerar notas adesivas.

### Como usar a Miro AI para agrupar notas adesivas

Siga estes passos:

1. Use a ferramenta **Selecionar** para selecionar um grupo de notas adesivas.
   O menu de contexto é exibido acima da sua seleção.
2. No menu de contexto, selecione o botão **Agrupar objetos**.
3. Você pode fazer uma das seguintes ações:
   - Selecionar uma opção de agrupamento.
     Suas notas adesivas são agrupadas com base na sua seleção.
   - Selecionar **Criar um agrupamento**.
     Suas notas adesivas serão agrupadas. Para dar contexto, você pode renomear seu agrupamento.

     Você usou a Miro AI para agrupar notas adesivas.

### Como usar a Miro AI para gerar um documento com base em notas adesivas

Siga estes passos:

1. Use a ferramenta **Selecionar** para selecionar um grupo de notas adesivas.
   O menu de contexto é exibido acima da sua seleção.
2. No menu de contexto, selecione **Miro AI**.
3. Passe o mouse sobre **Documento**.
   Um menu suspenso é aberto.
4. Selecione um tipo de documento.
   A Miro AI gera seu documento.

   Você usou a Miro AI para gerar um documento com base em uma seleção de notas adesivas.

### Como usar a Miro AI para resumir um grupo de notas adesivas

Siga estes passos:

1. Use a ferramenta **Selecionar** para selecionar um grupo de notas adesivas.
   O menu de contexto é exibido acima da sua seleção.
2. No menu de contexto, selecione **Miro AI**.
3. Passe o mouse sobre **Documento**.
   Um menu suspenso é aberto.
4. Selecione **Resumo**.
   A Miro AI gera seu resumo.

   Você usou a Miro AI para gerar um resumo com base em uma seleção de notas adesivas.

## Como usar a Miro AI para remover fundos de imagens

Use a Miro AI para remover o fundo de uma imagem.

Siga estes passos:

1. Selecione uma imagem no seu board.
   O menu de contexto é exibido.
2. No menu de contexto, selecione **Miro AI**.
   Um menu suspenso é aberto.
3. Selecione **Remover fundo**.

   Você usou a Miro AI para remover o fundo de uma imagem.

## Usando Miro AI para gerar um diagrama

Use a Miro AI para gerar um diagrama.

Siga estes passos:

1. Acima da barra de ferramentas de criação, selecione **Crie com IA**.
2. Selecione o botão **Diagrama** .
3. (Opcional) Selecione o tipo de diagrama.
4. Digite seu prompt para a Miro AI.
5. Selecione **Gerar diagrama**.

   Você usou a Miro AI para gerar um diagrama.

## Uso da Miro AI para transformar um esboço desenhado à mão em um diagrama

A Miro AI inclui o Digitize Diagram (BETA), um recurso que converte seus esboços de diagramas desenhados à mão em diagramas totalmente editáveis ​​na Miro.

Siga estes passos:

1. Carregue uma imagem do seu diagrama desenhado à mão em um board da Miro.
2. Selecione a imagem.
   O menu de contexto é exibido.
3. No menu de contexto, selecione **Miro AI**.
4. Selecione **Digitalizar diagrama**.
   A Miro AI gera uma versão totalmente editável do seu diagrama. Certifique-se de inspecionar o resultado e fazer qualquer ajuste ou realinhamento necessário.

   Você transformou com sucesso um diagrama desenhado à mão em um diagrama totalmente editável na Miro.

## Como usar a Miro AI com mapas mentais

Use a Miro AI para gerar um **mapa mental** com base em um nó raiz.

Siga estes passos:

1. Adicione um **mapa mental** ao seu board.
2. Adicione texto ao nó raiz.
3. Selecione o nó raiz.
   O menu de contexto é exibido.
4. No menu de contexto, selecione **Miro AI**.
   Um menu suspenso é aberto.
5. No menu suspenso, selecione **Gerar mapa mental**.
   Um **mapa mental** aparece com base no seu nó raiz.
6. Selecione se deseja **Manter**, **Tentar novamente** ou **Descartar** o **mapa mental** gerado.

   Você usou a Miro AI para gerar um **mapa mental**.

**Mais informações** Leia o artigo [Mapa mental](../advanced-tools/03-mind-map.md).

## Como usar a Miro AI para editar texto

Use a Miro AI para fazer as seguintes edições no texto do seu board:

- Corrigir gramática e ortografia
- Reduzir texto
- Reescrever para explicar melhor
- Ajuste o tom para amigável, profissional, comercial ou divertido
- Traduza para inglês e outros 17 idiomas suportados, incluindo francês, alemão, japonês, italiano e turco. Para ver todos os idiomas para os quais a Miro AI traduz, consulte [Edição de texto otimizada pela IA](18-miro-ai-reference.md).

**Mais informações:** Veja [Visão geral de Criar e editar com IA](03-create-with-ai.md).

## Como usar a Miro AI para sugerir texto alternativo para imagens

A Miro AI pode gerar texto alternativo para suas imagens.

Siga estes passos:

1. Selecione uma imagem no seu board.
   O menu de contexto é exibido.
2. No menu de contexto, selecione **ALT**.
   A caixa de diálogo **Descrição da imagem** é aberta. A **Miro AI** gera uma sugestão automaticamente.
3. Selecione **Inserir**.
   A sugestão gerada é salva automaticamente.
4. (Opcional) Edite a sugestão inserida. As alterações são salvas automaticamente.
5. Feche a caixa de diálogo **Descrição da imagem**.

   Você usou a Miro AI para sugerir texto alternativo para uma imagem.

:::note
Gerar texto alternativo com a Miro AI não consome créditos de IA.
:::
