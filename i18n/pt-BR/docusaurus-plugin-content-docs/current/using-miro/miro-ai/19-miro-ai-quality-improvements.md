A partir de 3 de fevereiro de 2025, vamos coletar os dados de interação com IA dos usuários do plano Free para aprimorarmos as funcionalidades da Miro AI, como resumos, diagramas e assistentes de IA.

Este artigo explica como usamos as interações de IA para melhorar a Miro AI e como você pode controlar suas preferências de dados, inclusive como desabilitar o uso de seus dados para melhorar a Miro AI.

Os Admins da empresa podem desabilitar a coleta de dados de IA para suas próprias organizações. Isso não afetará a forma como você usa ou experimenta a Miro AI.

## Quais planos da Miro contribuem com dados de interação de IA para aprimorar a Miro AI?

Somente os dados de interação de usuários do plano Free são usados para aprimorar a Miro AI. Os admins de planos Free podem desabilitar a coleta de dados a qualquer momento.

A coleta de dados para aprimorar a Miro AI exclui os usuários gratuitos, como convidados e visitantes de planos pagos e Education.

## Finalidade da coleta de dados de IA

Seus dados nos ajudam a adaptar melhor nossas funcionalidades de IA às suas necessidades. Ao entendermos os padrões gerais e os casos de uso comuns baseados nas interações com a Miro AI, podemos melhorar a qualidade dos recursos e dos resultados gerados pela IA, para que sejam mais precisos e úteis.

## Quais dados coletamos?

Coletamos somente os seguintes dados necessários para aprimorar nossas funcionalidades de IA:

- **Dados de entrada de IA**
  Os prompts que você insere e qualquer conteúdo, como quadros, imagens e notas adesivas, que forem selecionados como contexto.
- **Dados de saída de IA**
  Qualquer resultado gerado por IA, como imagens, texto e notas adesivas.

:::note
Não é coletado nenhum conteúdo do board que não esteja diretamente relacionado aos processos de IA.
:::

## O que acontece ao desabilitar a coleta de dados de IA?

Ao desabilitar a coleta de dados de IA, nenhum novo dado será usado para aprimorar as funcionalidades de IA. Para garantir que suas preferências sejam totalmente respeitadas, tanto com dados futuros quanto passados, todos os dados coletados anteriormente não serão mais usados para desenvolvimento ou aperfeiçoamento de IA.

Desabilitar a coleta de dados de IA não afeta a experiência dos usuários com a Miro AI.

## Como desabilitar a coleta de dados de IA

O Admin da empresa pode desabilitar a coleta de dados de IA.

**Procedimento**

Siga estas etapas:

1. No painel da Miro, selecione seu avatar. Em seguida, selecione **Console de admin**.
2. Em **Segurança**, selecione **Miro AI**.
3. Desabilite a opção **Usar dados para melhorias da Miro AI**.

Você desabilitou a coleta de dados de IA.

## Medidas que aplicamos para proteger seus dados

A Miro aplica técnicas de anonimização para desidentificar suas interações com IA antes de analisar os conjuntos de dados para melhorar as funcionalidades. Os conjuntos de dados são mantidos separados dos sistemas de produção da Miro.

A Miro não usa interações com IA para treinar ou refinar modelos. A Miro não compartilha interações de IA com provedores ou desenvolvedores terceirizados de modelos para treinar seus próprios modelos.

Protegemos sua propriedade intelectual com as melhores práticas do setor e controles de segurança com certificação ISO.

Os dados coletados por IA sempre passam por:

- **Pseudonimização**
  Alteramos os dados para garantir que não possam mais ser associados a você. Transformamos identificadores pessoais e organizacionais através de um algoritmo unidirecional irreversível.
- **Desidentificação**
  Removemos dos dados de entrada as informações de identificação pessoal (PII), como nomes, sexo, data de nascimento, senhas, endereços IP, dados do cartão de crédito e nomes da empresa.

**Mais informações:** Consulte a [Política de Privacidade](https://miro.com/legal/privacy-policy/) da Miro.

## Medidas que aplicamos para evitar a divulgação de dados para outros clientes e usuários

A Miro não usa interações com IA para treinar ou refinar modelos. A Miro não compartilha interações de IA com provedores ou desenvolvedores terceirizados de modelos para treinar seus próprios modelos.

As interações de IA usadas para aperfeiçoar as funcionalidades da Miro AI são mantidas separadas dos sistemas de produção da Miro.
