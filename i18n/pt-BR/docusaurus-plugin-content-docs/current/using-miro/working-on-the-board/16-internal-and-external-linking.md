Enriqueça o conteúdo do seu board vinculando qualquer objeto a um site externo ou outro objeto no board.

Coma opção **Link para**, você pode:

- Criar protótipos interativos.
- Simplificar a navegação no board.
- Adicionar links a referências e fontes úteis.
- Link suas [notas adesivas](../essential-tools/14-sticky-notes.md) ou [cartões](../essential-tools/02-cards.md) aos links de rastreadores de tarefas.

## Vincular objetos

1. Selecione o objeto para o qual deseja criar um link e clique no ícone de **três pontos** (**...**) no menu de contexto
2. No menu de contexto, escolha **Copiar link**
3. Selecione um objeto do qual deseja criar um link **de**, e clique no **três pontos** (**...**) ícone no menu de contexto
4. Escolha **Link para** ou use **Opção +** **Cmd + K** (*para Mac*) ou **Alt +** **Cmd + K** (*para Windows*)
5. Insira o URL ou clique em outro objeto no board que você deseja vincular

:::tip
Vincule objetos rapidamente usando a paleta de comando. Clique no objeto, toque em **Cmd + K** e **o link para objeto** aparecerá como a primeira opção no menu. Basta colar seu link no campo de texto e tocar em **Enter**.
:::

Observe que um objeto no board pode ser vinculado a apenas *um* site ou objeto da Miro. Você pode criar links para sites externos, outros boards da Miro, objetos específicos nos boards.
Para ir para o URL vinculado — basta clicar no ícone do link.

Para excluir ou editar o link:

1. Clique nos três pontos do menu de contexto.
2. Escolha **Editar link**.![edit_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057155218_edit%20link.jpg)*A opção de editar um link*
3. Altere o link ou clique em **Excluir link** na janela pop-up.![change_or_delete_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057156242_change%20or%20delete%20link.jpg)*A opção de excluir um link*

## Links para objetos no board

Você pode obter um link direto para qualquer objeto no board ([quadros](../essential-tools/07-frames.md), imagens, [formas](../essential-tools/11-shapes.md), etc.). Compartilhe este link com seus colaboradores para chamar a atenção para o lugar exato no board.

1. Clique no objeto que você deseja vincular para mostrar o menu de contexto.
2. Clique no ícone de **três pontos** (**...**).
3. Escolha **Copiar link**.![copy_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057158162_copy%20link.jpg)*Copiando o link para um quadro*

Se o objeto vinculado for excluído, os usuários que seguirem o link verão a mensagem "*Infelizmente, o item vinculado foi excluído deste board*". É possível [restaurar o conteúdo excluído](18-restoring-board-content.md) por meio da lista de Atividades.

## Como colar links no board

Você pode colar um link no seu board usando os atalhos: **Ctrl + V** (*para Windows*) ou **Cmd + V** (*para Mac*). O link mostrará uma pré-visualização.

*![link_to_help_center.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057159186_link%20to%20help%20center.jpg)
O link para a Central de ajuda da Miro em um board*

Para colar um link em um board sem a pré-visualização, use a [ferramenta de texto](../essential-tools/16-text.md) e cole o link na caixa de texto.

## Texto de ligação

Ao trabalhar com objetos que incluem texto, clique no ícone do **link** no menu de contexto para inserir um link no texto.

![insert_link.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016043786642_insert%20link.jpg)
 *A opção de inserir um link*

Você também pode selecionar o texto e usar **Ctrl + V** (*para Windows*)/**Cmd + V** (*para Mac*) para colar um link.

![insert_link.gif](../../../../../../docs/using-miro/working-on-the-board/images/21016057161490_insert%20link.gif)
*Como inserir um link em uma linha de texto*

:::note
Se você vincular dois objetos em um board por meio da opção **Inserir link**e depois duplicar o board, o link na cópia do board levará ao board original. No entanto, quando você vincula dois objetos no board por meio da opção Link para e depois duplica o board, o link na cópia permanece interno (ele traz para o objeto no mesmo board).
:::

## Perguntas frequentes

Posso vincular meu board a outro board da Miro?

Sim, copie o link para o board (ou um objeto específico no board) e cole o link no board original (ou adicione o link a um objeto ou [notas](../essential-tools/17-visual-notes.md)). Você também pode [incorporar boards da Miro](../import-and-export/export/02-embed-a-miro-board.md).

Como faço para copiar um link para o meu board?

Abra a [caixa de diálogo Compartilhar](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) do board e clique em **Copiar link do board**. Você também pode simplesmente copiar o link da barra de endereço do navegador. Se você tiver um board aberto no [aplicativo para desktop](../../getting-started/apps-for-devices/05-desktop-app.md), clique em **Arquivo > Copiar link do board**.

Como faço para criar um link para uma área específica no meu board?

Você pode criar um [quadro](../essential-tools/07-frames.md) que cubra a área e copiar um link para o quadro. Observe que [os usuários que têm acesso ao seu board](../sharing-boards/05-who-has-access-to-my-board.md) poderão navegar e ver outras áreas do board também.

Posso remover todos os links do meu board de uma só vez?

Você pode remover todos os links que foram colados no canvas em vários cliques. [Selecione todos os objetos](10-working-with-objects.md), escolha **Filtro** no menu de contexto, selecione **Pré-visualizar,** e exclua os objetos do link selecionado.
![filter_perviews.jpg](../../../../../../docs/using-miro/working-on-the-board/images/21016057163410_filter%20perviews.jpg)
*Filtrar pré-visualizações em objetos selecionados*

Posso criar links para arquivos locais no meu PC?

Não. Por motivos de segurança, carregue seus arquivos em um serviço baseado em nuvem e vincule-os a partir daí.

A Miro reconhece hiperlinks de endereços de e-mail como links mailto:?

No momento, isso não é compatível.
