A função Fique por dentro oferece aos usuários uma visão geral simplificada, otimizada pela IA, das mudanças que ocorreram no board desde a última visualização.

> ***Disponível em:** Todos os planos*
> ***Disponível para:** Aplicativo para desktop, navegador desktop*
> ***Quem pode utilizá-lo:** Todos os usuários*

## Principais funcionalidades

Fique por dentro inclui os seguintes recursos essenciais:

- **Veja destaques visuais**
  As atualizações principais são destacadas no board.
- **Resumo rápido das mudanças**
  Veja imediatamente o que mudou e o que requer ação.
- **Tutorial passo a passo**
  Obtenha um tutorial passo a passo das edições e mudanças, organizadas por seções no board.

## Como usar o Fique por dentro

Siga estas etapas para acessar e usar o Fique por dentro.

1. Clique no ícone **Atividades** (![icon-activity.svg](../../../../../../docs/using-miro/working-on-the-board/images/24093924443794_icon-activity.svg)) na barra de ferramentas superior direita.
   O menu de atividades é aberto.
2. Clique no botão **Fique por dentro**.
   A caixa de diálogo Fique por dentro é aberta no board.

   ![catch-up-new.png](../../../../../../docs/using-miro/working-on-the-board/images/27120802154642_catch-up-new.png)*Caixa de diálogo Fique por dentro no board*
3. **Últimas alterações** serão mostradas junto com a visão geral.
4. Clique em uma alteração recente para ir diretamente a esse painel.
5. Clique em **Mostrar detalhes** para começar a revisar as alterações.
6. Use os botões de **seta** para frente e para trás na caixa de diálogo para navegar pelo Fique por dentro.
7. Clique nos links numéricos para alterar e visualizar a seção relevante no board.
8. Use o menu suspenso para selecionar um período de tempo diferente para visualizar: Semana passada, Nas últimas duas semanas ou Mês passado.

### Alternativo para acessar o Fique por dentro

Siga estas etapas para acessar o Fique por dentro de outra maneira.

1. Clique no ícone **menu principal** (![icon-main.svg](../../../../../../docs/using-miro/working-on-the-board/images/24005170925074_icon-main.svg)).
   O menu principal é aberto.
2. Passe o cursor sobre o botão **Board**.
   O submenu do board é aberto.
3. Clique no botão **Fique por dentro**.
   A caixa de diálogo Fique por dentro é aberta.

## Perguntas frequentes

**Por que não consigo acessar o Fique por dentro?**

Fique por dentro está disponível apenas para usuários com Miro AI habilitada. Se o seu admin não tiver ativado a Miro AI, precisará fazê-lo para que você possa acessar o Fique por dentro. Você pode seguir as instruções detalhadas aqui: [Ativação de funcionalidades](../../enterprise-administration/managing-enterprise-teams-and-content/06-feature-activation.md).
