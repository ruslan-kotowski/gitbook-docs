Altere os objetos no seu diagrama num instante com a funcionalidade **alterar tipo**.  Ela permite que você transforme instantaneamente um objeto em outro, seja uma nota adesiva, uma caixa de texto/span>[, um](../essential-tools/14-sticky-notes.md) cartão ou uma [forma](../essential-tools/16-text.md). A função Alterar tipo está disponível para as formas básicas e pacotes de formas para criação de diagramas.

**Para transformar um objeto:**

1. Altere para a [**ferramenta** Selecionar.](05-using-miro-with-a-mouse-trackpad-or-touchscreen.md)
2. Clique no objeto que você gostaria de transformar.
3. Clique no ícone de **alterar tipo** no menu do objeto.
4. Em seguida, selecione um novo objeto no menu suspenso.

![object_transformation_greybg.gif](../../../../../../docs/using-miro/working-on-the-board/images/21017695579922_object_transformation_greybg.gif)*Transformando uma nota adesiva em uma forma e uma caixa de texto*

O texto e a cor do seu objeto permanecerão os mesmos. Observe que os emojis e as tags são removidos ao transformaruma nota adesiva em um texto ou uma forma. Transformar uma forma ou uma caixa de texto em uma nota adesiva ajusta a cor para uma parecida, já que há poucas cores disponíveis para as notas adesivas.

Você também pode girar os objetos no seu board e dimensioná-los. [Selecione um objeto](05-using-miro-with-a-mouse-trackpad-or-touchscreen.md) (a ferramenta selecionar deve estar habilitada) e arraste o ícone especial para girá-lo. Observe que certos objetos (Kanban, mapa mental, tabelas) não podem ser girados.

Para alterar o tamanho do objeto, arraste os pontos brancos. Para alterar a largura/comprimento de uma forma ou um cartão, arraste um dos lados do objeto.

![rotate_and_scale_in_Miro_greybg.gif](../../../../../../docs/using-miro/working-on-the-board/images/21017695580434_rotate_and_scale_in_Miro_greybg.gif)*Girando e dimensionando uma forma*
