A paleta de comando permite que você pesquise e abra rapidamente ferramentas e aplicativos da Miro. A paleta de comando também permite que você pesquise por boards recentes.

A paleta de comando está disponível apenas para usuários com [acesso de edição](../sharing-boards/01-board-access-rights.md) e enquanto estão no modo padrão do board. Você não poderá abrir a paleta de comando enquanto estiver no modo de apresentação.

## Como usar a paleta de comando

1. Selecione o ícone dos **três pontos verticais** (![icon-main.svg](../../../../../../docs/using-miro/working-on-the-board/images/24005170925074_icon-main.svg)) na barra de ferramentas do board.
   O menu principal é aberto.
2. Selecione **Editar** > **Comandos**. Como alternativa, use o atalho de teclado **Cmd** + **K**.
   A paleta de comando é aberta.
3. No campo de pesquisa, comece a digitar o nome de um aplicativo ou ferramenta, ou percorra a lista.
4. Clique para iniciar o aplicativo ou ferramenta.
