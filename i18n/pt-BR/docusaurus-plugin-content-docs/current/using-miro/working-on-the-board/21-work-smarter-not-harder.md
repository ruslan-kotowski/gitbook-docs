A Miro oferece possibilidades quase infinitas de trabalhar com objetos em um board, então confira algumas dicas sobre como alcançar suas metas de forma mais fácil e rápida.

## Navegação no board

### Usar minimapa

Use um minimapa, que pode ser encontrado no canto inferior direito do board clicando no ícone de porcentagem e depois em **Mostrar minimapa** (ou apenas pressione a [tecla de atalho](06-shortcuts-and-hotkeys.md) **M** para abri-lo/fechá-lo).

![barra de ferramentas de navegação-minimapa.png](https://help.miro.com/hc/article_attachments/21999303510290)

*Mostrando o minimapa*

### Como alternar entre os modos de seleção e panorâmica

Tente usar as [teclas de atalho](06-shortcuts-and-hotkeys.md) para selecionar um determinado objeto ou se deslocar pelo board. Use as teclas de atalho **V** e **H** para alternar entre o modo de **seleção/edição** (ferramenta de cursor) e o modo de **mão**/**panorâmica**. Você também pode ativar o modo de seleção na barra de ferramentas.

> Saiba mais sobre a navegação no board [neste artigo](05-using-miro-with-a-mouse-trackpad-or-touchscreen.md).

![work_smarter_select_tool.png](https://help.miro.com/hc/article_attachments/21017416577682)*A ferramenta de seleção na barra de ferramentas*

## Como trabalhar com objetos

### Duplicação inteligente

Acelere o seu trabalho usando o atalho **Ctrl + D** para duplicar objetos no board de forma rápida e fácil.

![smart_duplicating.gif](https://help.miro.com/hc/article_attachments/21017429608082)*Duplicação inteligente*

:::note
Você também pode usar **Alt + setas** para duplicar um objeto vertical ou horizontalmente.
:::

### Dimensões do objeto para criação de diagramas precisos

Apresente diagramas profissionais de forma mais rápida e fácil. Use as [dimensões de objetos](../formats/diagramming/01-miro-for-mapping-diagramming.md) para criar formas com o mesmo tamanho em todo o seu board com precisão.

![Using_dimensions_in_Miro.gif](https://help.miro.com/hc/article_attachments/21017429620242)

### Bloqueio de objetos

Bloqueie os objetos para evitar que sejam movidos, editados ou excluídos acidentalmente. Use o bloqueio protegido para evitar que outros usuários alterem o seu conteúdo. Saiba mais no artigo: [Como bloquear conteúdo no board](17-locking-content-on-the-board.md).

![lock_content.jpg](https://help.miro.com/hc/article_attachments/21017429610002)*Opção de bloqueio*

### Alinhamento de objetos

A ativação desta opção criará guias de alinhamento para quaisquer objetos que você mover, ajudando a garantir uma aparência limpa e bem equilibrada para os objetos do seu board.

![main_menu_work_smarter_align_objects.gif](https://help.miro.com/hc/article_attachments/21017429633682)*Como alinhar objetos no board*

Você pode ativar/desativar o recurso no menu principal. Clique nos **três pontos**(**...**) > **Preferências** > **Alinhar objetos.**

![align-objects.png](https://help.miro.com/hc/article_attachments/21858049999634)
*A opção para habilitar Alinhar objetos nas configurações do board*

### Organização de objetos

Organize os objetos no seu board. Esse recurso ajuda a estilizar boards e diagramas com precisão, especialmente com uma grande quantidade de conteúdo sobreposto.

1. Selecione o objeto.
2. No menu de contexto, clique nos três pontos (**…**) para abrir o menu **mais**.
3. Escolha uma das seguintes opções:

- **Trazer para a frente:** move um objeto para a frente de todos os objetos.
- **Enviar para trás:** move um objeto para trás de todos os objetos.
- **Avançar:** move um objeto à frente do objeto diretamente à frente do objeto selecionado.
- **Recuar:** move um objeto para trás do objeto diretamente atrás do objeto selecionado.

:::note
Este recurso não está disponível para quadros. Os quadros são sempre posicionados atrás dos objetos do board.
:::

Seleção e filtro de objetos

Os filtros são extremamente úteis se você precisar alterar em massa um tipo específico de objeto em um grupo: selecione vários itens, clique em **Filtrar** no menu de contexto e escolha um tipo de objeto. Saiba mais sobre a seleção de objetos [neste artigo](10-working-with-objects.md).

![Miro_filters.gif](https://help.miro.com/hc/article_attachments/21017416564626)*Como selecionar, filtrar e modificar vários objetos*

Rotação de objetos

Gire facilmente os objetos no board para ajustar o seu conteúdo. Encontre o ícone no canto inferior esquerdo do objeto, clique e arraste-o para alterar a posição, como mostrado abaixo.

![rotate_an_object.gif](https://help.miro.com/hc/article_attachments/21017416566162)*Como girar um objeto*

### Limpando conteúdo

Você pode limpar o conteúdo de vários widgets (como notas adesivas, formas e cartões) simultaneamente. Este recurso permite que você remova todo o texto, tags, emojis, autores, responsáveis ​​e datas de vencimento dos widgets selecionados, revertendo-os ao status original, mantendo seu estilo (cores, tamanhos, etc.).

Para limpar o conteúdo:

1. Selecione os widgets que você deseja limpar.
2. Clique com o botão direito para abrir o menu de contexto.
3. Selecione "Limpar conteúdo" no menu.
4. Como alternativa, use o atalho Cmd + Backspace (Mac) ou Ctrl + Backspace (Windows).

Limpar conteúdo não funciona em outros widgets (por exemplo, texto, widgets de tabela) e não funciona em cartões Jira ou Azure. Se um usuário selecionar várias notas adesivas, formas e cartões, o conteúdo será excluído de todos os widgets, exceto dos cartões do Jira/Azure.

## Como trabalhar com documentos

### Como dividir documentos de várias páginas

> **Disponível em:** versão para navegador, [aplicativo para desktop](../../getting-started/apps-for-devices/05-desktop-app.md)

Uma maneira de o seu time colaborar em documentos, arquivos PDF ou PowerPoint: expanda as páginas, organize-as no board e deixe comentários diretamente nas páginas.

Para dividir um arquivo PDF ou um arquivo do PowerPoint em um determinado número de páginas:

1. Carregue o arquivo no board.
2. Clique no arquivo. No menu de contexto, escolha ****Extrair páginas.****
   > ✏️ A opção está disponível somente no [modo de cursor (selecionar)](#mini). Se a opção não aparecer no menu, pressione **V** ou selecione o cursor na barra de ferramentas e clique no objeto novamente.

   ![extract_pages.jpg](https://help.miro.com/hc/article_attachments/21017416567058)*A opção para extrair páginas no menu de contexto do PDF*
3. Escolha como deseja dividir o arquivo (todas ou apenas páginas específicas) e clique em **Extrair**.
   ![extract_pages.gif](https://help.miro.com/hc/article_attachments/21017416561554)*Como extrair páginas*

As páginas expandidas aparecerão logo abaixo do arquivo original. Se o arquivo original for desnecessário, você pode excluí-lo. Todas as páginas extraídas permanecerão no board.

Como fixar páginas

Para fixar uma página específica de um documento em um board, alterne para esta página no menu de contexto do documento, selecione **Fixar** e escolha **Definir atual como início**. Toda vez que você abrir o board, esta página será definida como a primeira.

> **✏️** A opção **Definir atual como início** está disponível somente no [modo de cursor (selecionar)](#pan). Se a opção estiver desabilitada no menu, pressione **V** ou selecione o cursor na barra de ferramentas e clique no objeto novamente.

![pin_pages.jpg](https://help.miro.com/hc/article_attachments/21017416567954)*Como fixar uma página*

## Como trabalhar com imagens

### Substituir imagens

Qualquer imagem no board pode ser substituída sem afetar outros objetos no canvas.

1. Clique na imagem para abrir o menu de contexto.
2. Clique no ícone **Substituir imagem** e selecione uma das seguintes opções:

- **Substituir da galeria:** o [aplicativo Imagens e ícones](../essential-tools/08-images-and-icons.md) será aberto e você poderá selecionar uma nova imagem.
- **Substituir a partir do board:** será solicitada a seleção de outra imagem já presente no board.
- **Carregar do dispositivo** : carregue e substitua a imagem por uma do seu dispositivo.
- **Carregar via URL:** substitua a imagem por uma hospedada online inserindo o URL da imagem na caixa de diálogo.

![Substituir-imagens.png](https://help.miro.com/hc/article_attachments/21017416583314)

### Recortar imagens

Não há necessidade de usar software de terceiros para recortar imagens, pois a Miro tem uma ferramenta para isso. Selecione uma imagem ou escolha **Recortar** no menu de contexto. Isso habilita o modo de recorte, que permite editar a seleção **retangular**. Os limites de corte se ajustam ao conteúdo do board para garantir que o layout das imagens seja visualmente nítido. Você pode atualizar a posição e a escala das imagens que está cortando sem perder o alinhamento com outro conteúdo no board. Quando terminar, basta clicar em qualquer lugar do board.

![crop_image.gif](https://help.miro.com/hc/article_attachments/21017416576146)*Como cortar uma imagem*

Você pode **cortar imagens em vários formatos** (por exemplo, em círculo, quadrado, etc.). Selecione a imagem, clique no ícone **Recortar** no menu de contexto e selecione uma forma no menu suspenso.

![cropping_in_shapes.gif](https://help.miro.com/hc/article_attachments/21017416573586)*Como cortar uma imagem como círculo*

Você também pode **cortar imagens em massa em vários formatos**. Clique e arraste para selecionar as imagens, clique no ícone **Recortar** no menu de contexto e escolha uma forma no menu suspenso.

![](https://help.miro.com/hc/article_attachments/21017416577042)*Corte de imagens em massa como círculo*

:::tip
Você sempre pode reverter a sua imagem cortada para o original. Basta clicar duas vezes e expandir a seleção de corte para o seu tamanho original.
:::

### Bordas da imagem

Adicione bordas às imagens e capturas de tela que você carrega ou cola no seu board para ajudá-las a se destacarem.

1. Clique na imagem.
2. No menu de contexto, clique no ícone da borda.
3. Selecione a cor e ajuste a espessura da sua borda.

![Image_borders.gif](https://help.miro.com/hc/article_attachments/21017429622546)
*Como adicionar uma borda de imagem a uma captura de tela*

### Redimensionamento de imagens em massa

Redimensione várias imagens no seu board de uma só vez por altura ou largura. Em seguida, use o [Layout automático](08-structuring-board-content.md) para alinhá-las instantaneamente.

**Como redimensionar imagens em massa**

1. Arraste o cursor para selecionar todas as imagens que você deseja redimensionar.
2. Clique no ícone de redimensionar no menu de contexto. Você deve selecionar várias imagens antes que a opção de redimensionamento apareça.
3. Selecione **Corresponder altura** ou **Corresponder largura.**
4. Clique no ícone cinza **Layout automático** no canto superior direito.

*![Bulk_resizing_images.gif](https://help.miro.com/hc/article_attachments/21017416572818)**Como redimensionar imagens em massa por altura ou largura*

### Como adicionar GIFs

Adicione GIFs aos seus boards da Miro para dar vida às ideias com conteúdo animado divertido. Os GIFs são reproduzidos para os usuários individuais por oito segundos ou em um loop quando adicionados ao board e quando os usuários passam o mouse sobre eles. Os GIFs só são reproduzidos para cada usuário que interage com o board, não para todos em tempo real.

Habilite [Reduzir movimento](../../getting-started/accessibility-in-miro/06-reduce-motion.md) para desabilitar a reprodução automática de GIF.

:::tip
Em apresentações e [Talktracks da Miro](../facilitation-tools/asynchronous-tools/02-talktrack-board-recordings.md), os GIFs são reproduzidos automaticamente e fazem loop infinitamente enquanto visíveis na tela.
:::

## Perguntas frequentes

1. *Posso alinhar objetos no board?*
   - Sim. Saiba mais detalhes [nesta página](08-structuring-board-content.md).
2. *Posso girar o [texto](../essential-tools/16-text.md)?*
   - Sim. Você pode girar as caixas de texto arrastando o ícone de seta.
3. *Posso cortar arquivos PDF?*
   - Não. No momento, isso não é possível.
