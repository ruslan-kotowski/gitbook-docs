Este artigo de referência lista cada domínio que a Miro usa em sua aplicação SaaS.

:::note
Alguns aplicativos de terceiros desenvolvidos para a Miro, e aplicativos do Miroverse, podem depender de domínios e serviços externos que não são controlados pela Miro.
:::

## Domínios de produção global

As organizações que usam uma rede segura devem permitir os seguintes domínios de produção global:

```
*.miro.com
Nota: Incluir derivados, por exemplo: *.api.miro.com | *.svc.miro.com
```

```
*.miro-apps.com
```

```
mirostatic.com
```

```
*.mirostatic.com
```

```
onlinewhiteboard.com
```

```
realtimeboard.com
```

```
*.realtimeboard.com
```

```
webwhiteboard.com
```

## Domínios de produção regionais

As organizações que usam uma rede segura devem permitir os seguintes domínios de produção regionais.

:::note
Além dos domínios de produção global e dos domínios de ferramentas de produção, você também deve permitir os domínios de produção regionais para [residência de dados](../../../enterprise-administration/canvas-25-admin-features/data-residency/02-data-residency-at-miro.md) na Austrália ou nos Estados Unidos, conforme aplicável.
:::

### Austrália

```
*.au.miro.com
Nota: Incluir derivados, por exemplo: *.api.au.miro.com | *.svc.au.miro.com
```

```
*.au01.miro.com
```

### Estados Unidos

```
*.us.miro.com
Nota: Incluir derivados, por exemplo: *.api.us.miro.com | *.svc.us.miro.com
```

```
*.us01.miro.com
```
