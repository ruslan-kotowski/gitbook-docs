A Miro é feita para o trabalho em equipe e permite que muitos usuários trabalhem juntos de forma eficaz em um único board. Esta seção descreve o que você pode esperar ao colaborar com um grande número de participantes.

A Miro é destinada à colaboração e dá suporte a um trabalho estável de múltiplos usuários no mesmo board.

Dois dos nossos casos de uso frequentes — Planejamentos de PI e Workshops — podem envolver algumas centenas de participantes, por isso estamos constantemente otimizando o desempenho para colaboração em escala.

A maior sessão que hospedamos até agora teve 377 usuários. Embora este caso seja um pouco extremo, o board permaneceu operacional e a colaboração foi bem-sucedida. Um cenário mais comum que vemos quase toda semana é **cerca de 200 usuários (editores/comentaristas)** trabalhando simultaneamente no mesmo board.

Testamos nosso aplicativo regularmente com um número maior de usuários, mas ainda é cedo para afirmarmos que a experiência de todos será tranquila se ultrapassar 300 colaboradores.

Considere que o board pode desacelerar gradualmente com o número de usuários ou apresentar algum atraso durante atividades intensas dos usuários. Os participantes com dispositivos mais antigos e menos potentes experimentarão uma desaceleração mais cedo.
