Você pode carregar conteúdo para a Miro nos seguintes formatos de arquivo:

| Tipo de arquivo | Formatos de arquivo |
| --- | --- |
| Imagens | **bmp**, **gif**, **svg**(como imagem sólida), **jpeg**, **jpg**, **png**, **psd**, **heic, heif**, **pdf** |
| Tabelas e planilhas | **xls, xlsx, csv**, **ods** |
| Documentos de texto | **doc**, **docx**, **odt, rtf** |
| Apresentações | **ppt, pptx, odp** |
| Vídeo | **MP4, MOV, WebM** |

O tamanho máximo de arquivo que você pode carregar de qualquer fonte é de 30 MB. A resolução máxima de imagem de qualquer fonte é de 32 MP. A restrição para dimensões de imagem é de 8192x4096 pixels.

Aprenda como você pode carregar arquivos para seu board: [Carregando arquivos para boards](../../import-and-export/import/05-uploading-files-to-boards.md), [Maneiras de adicionar conteúdo](../../working-on-the-board/07-ways-to-add-content.md).

Se você estiver enfrentando dificuldades ao carregar arquivos PDF, consulte [este guia de solução de problemas](../../import-and-export/import/05-uploading-files-to-boards.md). Em caso de dificuldades com o carregamento de outros tipos de arquivos, confira [estas etapas de solução de problemas](../../tools/troubleshooting/07-how-to-troubleshoot-and-report-a-bug.md).

:::tip
Você pode adicionar **arquivos PDF** com a opção de [virar as páginas ou página por página](../../working-on-the-board/21-work-smarter-not-harder.md).
:::

:::tip
Importe **Documentos do Google** (planilhas, documentos e slides) por meio da [integração do Google Drive](../../../integrations-apps/google/05-google-drive.md) com a opção de editá-los diretamente no board.
:::

:::tip
Existem várias maneiras de importar uma **planilha**: através do [menu de upload](../../import-and-export/import/05-uploading-files-to-boards.md), [como notas adesivas](../../essential-tools/14-sticky-notes.md), ou [em Tabelas do Miro](../../advanced-tools/05-grid.md).
:::

:::tip
Se você trabalha com imagens **SVG** que contêm texto, lembre-se de converter o texto em linhas para que o aspecto visual do seu arquivo não dependa das fontes instaladas nos dispositivos dos seus colaboradores.
:::

## Upload de vídeo por plano

O suporte para [upload de vídeo](../../essential-tools/01-video-upload-and-playback-beta.md) é atualmente uma funcionalidade beta disponível nos planos Business e Education, e assinaturas Enterprise que têm funcionalidades beta ativadas.

Membros no plano Free podem carregar vídeos durante o beta. Quando o beta terminar, membros Free poderão continuar assistindo aos vídeos carregados durante o beta, mas não poderão carregar novos vídeos, a menos que façam um upgrade.

**Mais informações:** Veja [Upload e reprodução de vídeo (BETA)](../../essential-tools/01-video-upload-and-playback-beta.md).

## Perguntas frequentes

A Miro é compatível com o carregamento de imagens PNG transparentes?

Sim, você pode importar imagens transparentes para os seus boards.

Os gifs animados são renderizados nos boards da Miro?

Sim, saiba mais sobre [GIFs](../../working-on-the-board/21-work-smarter-not-harder.md).

O formato ZIP pode ser carregado para a Miro?

Não, extraia os arquivos antes de carregá-los para a Miro. Veja a lista de formatos de arquivo compatíveis na parte superior da página.

Se eu inserir um arquivo PDF em um board da Miro e alterar o PDF de origem, a versão inserida será atualizada automaticamente?

Não. A conexão entre um arquivo PDF para desktop ou baseado em nuvem que foi carregado e a Miro é unidirecional. Você terá que reinserir o PDF se forem feitas quaisquer alterações.

É possível importar os formatos Keynote, Pages ou Numbers do Mac para um board da Miro?

A lista de arquivos compatíveis não inclui os formatos, mas como solução alternativa, você pode simplesmente exportar seu arquivo no formato PowerPoint/Word/Excel clicando em *Arquivo* > *Exportar para* > *PowerPoint...* Depois disso, arraste o arquivo exportado para a Miro.
