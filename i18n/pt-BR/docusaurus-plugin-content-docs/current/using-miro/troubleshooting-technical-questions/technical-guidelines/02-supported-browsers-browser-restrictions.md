Este artigo fornece informações sobre quais navegadores de desktop e mobile a Miro suporta.

:::note
A Miro oferece suporte a todas as versões dos principais navegadores por pelo menos 12 meses, incluindo lançamentos com suporte ativo a longo prazo. Versões anteriores dos navegadores podem estar fora do suporte dos desenvolvedores, o que pode impactar sua experiência com a Miro. Para garantir que você tenha a melhor experiência com a Miro, atualize seu(s) navegador(es) pelo menos uma vez ao ano.
:::

A Miro oferece suporte oficialmente aos seguintes navegadores:

- **Desktop**
  - Chrome
  - MS Edge
  - Firefox
  - Opera
  - Navegador Yandex
- **Mobile**
  - Chrome
  - Safari
  - Internet Samsung

:::note
Boards acessados em navegadores móveis são apenas para visualização. Para garantir o acesso com seus privilégios atribuídos, baixe o [aplicativo móvel da Miro](../../../getting-started/apps-for-devices/08-mobile-app.md).
:::

:::warning
Internet Explorer não é suportado.
:::

## Problema de carregamento do board no Safari

Tente seguir os passos abaixo se você encontrar problemas de congelamento/carregamento do board no Safari v. 15.2, OS Monterey (você também pode receber a mensagem de erro "*Esta página da web foi recarregada porque ocorreu um problema*" ou "*Esta página da web e outra página não estão respondendo*"):

1. Vá para Safari > Preferências > **Desenvolvedor** > **Funcionalidades Experimentais.**
2. Desative a **funcionalidade do** **Processamento de GPU: Renderização de Canvas** .

   ![](/attachments/token/45hImX8u1weQZnUaPOXtAT971/?name=inline1581405683.png)

   > ✏️ Se você não vir o menu  **Desenvolvedor** na  [barra de menu](https://support.apple.com/en-gb/guide/safari/aside/glos33eb8abd/15.1/mac/12.0), abra o Safari > Preferências, clique em **Avançado**, depois selecione **Mostrar menu Desenvolvedor na barra de menu**.
