Se você tiver problemas ao usar o Miro em um dispositivo híbrido com tela sensível ao toque ou com uma caneta digital, verifique as configurações do seu navegador. Observe que as etapas sugeridas aqui são úteis apenas para um navegador.

## Google Chrome

1. Abra uma nova página no Google Chrome
2. Digite **chrome://flags** na barra de endereço do Chrome e digite**t****touch** na linha de pesquisa
3. Certifique-se de que **o Layout da IU de toque**esteja definido como **Ativado**
4. Certifique-se de que **a opção Arrastar e soltar iniciada por toque**esteja definida como **Ativada**
5. Tente usar a tela sensível ao toque/caneta digital novamente para ver a diferença

![touch_enabled.jpg](../../../../../../../docs/using-miro/troubleshooting-technical-questions/troubleshooting/images/21017652518162_touch%20enabled.jpg)

## Edge < 79

1. Abra uma nova página no Edge
2. Digite **about:flags**na barra de endereços do Edge
3. Pressione Ctrl + F para pesquisar**eventos de** **toque**
4. Certifique-se de que**os eventos de toque** estejam definidos como**Sempre ativados**
5. Tente usar a tela sensível ao toque/caneta digital novamente para ver a diferença
