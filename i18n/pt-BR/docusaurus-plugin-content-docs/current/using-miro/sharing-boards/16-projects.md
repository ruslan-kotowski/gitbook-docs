O projeto é uma coleção de boards dentro de um time. Os projetos facilitam a organização, a localização e o compartilhamento de seus boards.

> 🚀 Publique os templates do seu projeto no [Miroverse](https://miro.com/miroverse/submission/?backToUrl=/) e inspire o trabalho em equipe organizado para mais de 80 milhões de usuários.

> **Disponível para:** planos Starter, Education, Business e Enterprise

## Onde encontrar seus projetos

Todos os seus projetos são listados em ordem alfabética na navegação à esquerda do seu painel. Você pode clicar no nome do projeto para abrir as configurações do projeto e ver os detalhes e participantes.

### Configurações do projeto

1. Na barra lateral esquerda, vá para **Projetos**.
2. Clique no nome do projeto.
3. Na parte superior do painel do projeto, clique no nome do projeto novamente.
4. As configurações do projeto serão abertas.

![Miro_projects_greybg.gif](https://help.miro.com/hc/article_attachments/21019591671698)
*Como abrir um projeto da Miro para ver os detalhes*

## Como marcar projetos importantes como favoritos

Marque como favoritos seus projetos em andamento ou usados com frequência para facilitar o acesso. Quando você clica na estrela de um projeto pela primeira vez, uma nova seção **Projetos favoritos** aparece na barra lateral esquerda. Você pode expandir e recolher os **Projetos favoritos** para gerenciar seu painel.

Para marcar um projeto como favorito, clique no ícone de  **estrela** ao lado do nome do projeto.

![Staring_projects_greybg.gif](https://help.miro.com/hc/article_attachments/21019535608594)
*Como marcar um projeto como favorito*

## Como criar um projeto

1. Na barra lateral esquerda, vá para **Projetos**.
2. Clique em **+ Adicionar** (![icon-zoom-in.svg](https://help.miro.com/hc/article_attachments/22638229093778)botão).
3. A caixa de texto do projeto será aberta.
4. Digite o **nome do projeto**.
5. Clique em **Criar** **projeto**.
6. Você pode então adicionar boards e adicionar membros.

![create_a_project_greybg.gif](https://help.miro.com/hc/article_attachments/21019591680658)
*Como criar um novo projeto*

## Como adicionar boards a um projeto

1. Abra as configurações do projeto.
2. Clique em **Adicionar boards**.
3. Role ou pesquise para procurar e selecionar boards que deseja adicionar ao projeto.
4. Clique em **Mover boards**.

![Add boards to a project.pngA opção de adicionar boards a um projeto nas configurações do projeto](https://help.miro.com/hc/article_attachments/21019591652114)

## Como compartilhar projetos

### Como compartilhar um projeto com um membro do time

> **Quem pode fazer isso:** titulares, cotitulares e editores do projeto

Para compartilhar um projeto com um membro do time, você pode adicionar o membro ao projeto. Dependendo do nível de colaboração dos membros, você pode definir o acesso como [Pode visualizar, Pode comentar ou Pode editar](../../getting-started/start-here/05-roles-in-miro.md). O acesso que você escolher será aplicado a todos os boards do projeto.

### Como compartilhar um projeto com todo o time

> **Quem pode fazer isso:** titulares e cotitulares do projeto

1. Abra as configurações do projeto.
2. Habilite a opção **Qualquer pessoa do seu time pode visualizar este projeto**.

:::note
Admins do time podem definir as [configurações padrão de compartilhamento](11-default-sharing-settings.md) para os novos projetos.
:::

![share project with the team.png](https://help.miro.com/hc/article_attachments/21019591655826)
*Como compartilhar um projeto com todo o time*

### Como compartilhar um board dentro de um projeto

Você pode alterar o nível de acesso de um membro do projeto por meio da caixa de diálogo **Compartilhar** do board . Por exemplo, um membro do projeto com acesso a comentários pode ser convidado como editor em um board específico do projeto. **O nível mais alto de acesso concedido sempre será aplicado,** seja compartilhando um projeto ou um board dentro de um projeto.

Você pode compartilhar um board com usuários fora do seu time ou projeto convidando-os como [visitantes](08-collaboration-with-visitors.md) ou [convidados](07-collaboration-with-guests.md) do board.

### Projetos privados

Para garantir que um projeto seja privado na Miro, não adicione membros. Verifique se o acesso do time está desabilitado e ajuste as configurações de compartilhamento do time e da empresa para **Sem acesso** para todos os boards dentro do projeto.

O nível mais alto de acesso concedido sempre será aplicado, seja compartilhando um projeto ou um board dentro de um projeto. Por exemplo:

- Se um board estiver localizado em um projeto privado, mas for compartilhado com todo o time*,* todos os membros do time terão acesso a ele
- Se um board não for compartilhado com ninguém explicitamente, mas for armazenado em um projeto compartilhado com o time, todos os membros desse time terão acesso a ele

[Saiba mais em boards públicos X privados.](12-public-boards-vs.-private-boards.md)

## Como adicionar e gerenciar membros do projeto

:::note
Somente membros do time podem ser convidados como membros do projeto.
:::

Os membros do projeto podem:

- Acessar todos os boards do projeto, incluindo os boards existentes e os novos boards adicionados ou criados
- Criar novos boards dentro do projeto
- Adicionar boards existentes ao projeto
- Receber notificações sobre todas as alterações feitas em todos os boards de um projeto

### Como adicionar membros a um projeto

> **Quem pode fazer isso:** titulares, cotitulares e editores do projeto

1. Abra as configurações do projeto.
2. Clique em **Adicionar membros**.
3. Role ou pesquise para procurar e selecionar membros do time que deseja adicionar.
4. Você pode optar por **Notificar membros** quando eles forem adicionados ao projeto.
5. Clique em **Adicionar**.

![Como adicionar membros a um projeto.png](https://help.miro.com/hc/article_attachments/21019535586962)
*Como adicionar membros a um projeto*

### Como alterar os níveis de acesso dos usuários

1. Abra as configurações do projeto.
2. Abra o menu suspenso do nível de acesso ao lado do nome do usuário.
3. Escolha o nível de acesso (**Tem a cotitularidade**, **Pode editar**, **Pode comentar** ou **Pode visualizar**).

![Change a project member to project owner.png](https://help.miro.com/hc/article_attachments/21019535591954)
*Como alterar o nível de acesso de um usuário em um projeto*

### Como remover um membro do projeto

:::warning
Um membro removido de um projeto ainda poderá ter acesso ao projeto por meio de [convites por e-mail](03-sharing-boards-and-inviting-collaborators.md) ou por [acesso via time, empresa ou link público](03-sharing-boards-and-inviting-collaborators.md#compartilhar-boards-por-meio-de-um-link-publico).
:::

1. Abra as configurações do projeto.
2. Abra o menu suspenso do nível de acesso ao lado do nome do usuário.
3. Escolha **Remover.**

![](https://help.miro.com/hc/article_attachments/21019591660562)
*altRemove a project member.pngComo remover um usuário de um projeto*

### Como alterar a titularidade do projeto

> **Quem pode fazer isso:** titulares e cotitulares do projeto

:::note
Quando você transfere a titularidade do projeto para outro usuário, essa ação não altera a titularidade de boards individuais do projeto.
:::

1. Abra as configurações do projeto.
2. Abra o menu suspenso do nível de acesso ao lado do nome do usuário.
3. Escolha **Tem a titularidade.**

![](https://help.miro.com/hc/article_attachments/21019535591954)

## Como mover boards para um projeto

> **Quem pode fazer isso:** titulares, cotitulares e editores do projeto.

:::note
Ao mover um board para um projeto, o link do board não muda.
:::

**No cartão de informações do board:**

1. No cabeçalho do board, na parte superior à esquerda, clique no nome do board
2. O cartão de informações do board será aberto.
3. Ao lado de **Localização**, clique em **nome do projeto** (ou **sem projeto**).
4. No menu suspenso, selecione o projeto para onde quer mover o board.
5. Clique em **Mover**.

*![adding_a_board_to_a_project_greybg.gif](https://help.miro.com/hc/article_attachments/21019535610898)**Mover um board para um projeto a partir do cartão de informações do board*

**A partir do painel:**

1. Passe o mouse sobre o board que deseja mover.
2. Clique nos três pontos (**...**) para abrir o menu do board.
3. Selecione **Mover para o projeto.**
4. No menu suspenso, selecione o projeto para onde quer mover o board.
5. Clique em **Mover.**

![move to project from dashboard.png](https://help.miro.com/hc/article_attachments/21019591664658)
*Como mover um board para um projeto do cartão de informações do board*

## Como criar um novo board em um projeto

1. Na barra lateral esquerda, vá para **Projetos**.
2. Clique no nome do projeto.
3. No painel do projeto, clique em + **Novo board.**

![Creating_a_new_board_in_a_project_greybg.gifComo criar um novo board dentro de um projeto](https://help.miro.com/hc/article_attachments/21019591683730)

## Como remover um board de um projeto:

1. No cabeçalho superior direito do board, clique no nome do board.
2. O cartão de informações do board será aberto.
3. Ao lado de **Localização**, clique no nome do projeto.
4. **A partir do menu suspenso do projeto, escolha** Nenhum.

*![Removing_a_board_from_a_project_greybg.gif](https://help.miro.com/hc/article_attachments/21019535616914)**Como remover um board de um projeto*

## Como excluir ou sair de um projeto

> **Quem pode fazer isso:** titular do projeto

:::note
A exclusão de um projeto não exclui nenhum board desse projeto.
:::

1. Abra as configurações do projeto.
2. Escolha **Excluir projeto.**

Todos os outros membros do projeto que *não* são titulares verão a opção **Sair do Projeto. Se o projeto for** compartilhado com todos os membros do time/strong>, os usuários não terão a opção de deixar ou excluir um projeto.

Depois de deixar ou excluir um projeto, os usuários ainda terão acesso a todos os boards desse projeto compartilhados com eles [por e-mail](03-sharing-boards-and-inviting-collaborators.md) ou [acesso ao time](03-sharing-boards-and-inviting-collaborators.md).

## Como duplicar um projeto

Embora você não possa duplicar um projeto, pode [duplicar boards](../managing-boards/03-how-to-duplicate-a-board.md) em um projeto, em seguida, criar outro projeto e mover as cópias do board para o novo projeto.

:::warning
Se você fizer downgrade para o plano Free, não poderá mais criar novos projetos nem editar ou excluir seus projetos existentes.
:::

## Perguntas frequentes

**Como posso organizar meus projetos?**

No momento, não oferecemos suporte à opção de arquivar projetos, criar links para projetos, criar projetos dentro de projetos ou alterar a ordem dos projetos e boards. No entanto, recomendamos organizar os projetos atuais e em andamento marcando-os como projetos favoritos.
