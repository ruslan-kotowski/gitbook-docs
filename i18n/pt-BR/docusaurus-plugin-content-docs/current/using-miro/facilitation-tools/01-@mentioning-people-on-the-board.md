Quando você trabalha em um board, pode precisar notificar rapidamente alguém sobre as mudanças que está fazendo. Você pode fazer isso mencionando-os em um comentário ou em um objeto de texto.

![A team being mentioned in a comment on a Miro board.](images/21017429424658_Screenshot%20background%20template%20%204%20(1).jpg)*O time mencionado em um comentário*

## Entender menções

Você pode usar @menções para chamar a atenção, solicitar feedback ou atribuir tarefas. As menções funcionam em diferentes partes da Miro, principalmente em comentários e textos, cada uma servindo para finalidades de notificação ligeiramente diferentes.

## Use @menções para notificar colaboradores

Esta seção explica como usar efetivamente as @menções para se comunicar com seus colaboradores em um board da Miro.

### Garanta que os usuários possam ser mencionados ao compartilhar o board

Você pode mencionar alguém em um board se o board for [compartilhado](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) com ele. O board pode ser:

- [Explicitamente compartilhado](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md) com o usuário que precisa ser mencionado.
- [Shared with the project](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md).
- [Compartilhado com todo o time](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md).

### Adicione uma menção em um objeto de texto

:::note
Menções a objetos de texto não estão disponíveis no aplicativo móvel no momento.
:::

Você pode referenciar outros usuários e grupos de usuários no board em objetos baseados em texto como [Notas Adesivas](../essential-tools/14-sticky-notes.md), [Formas](../essential-tools/11-shapes.md) e [Texto](../essential-tools/16-text.md). Para fazer isso, basta digitar @ seguido pelo nome do usuário dentro do objeto de texto. Os usuários não receberão notificações de feed para menções de objeto de texto. Use menções de objeto de texto quando você quiser:

- Especifique a quem está se referindo.
- Esclarecer envolvimento em uma tarefa ou conversa.
- Faça uma anotação sem precisar de entrada ou atenção imediata do usuário mencionado.

### Adicionar uma menção em um comentário

Você pode se mencionar, mencionar outros usuários ou grupos inteiros como o board, o time ou o projeto nos [comentários](asynchronous-tools/01-comments.md). Para fazer isso, abra um comentário, digite @ seguido do nome do usuário ou do grupo. As menções em comentários são ideais para comunicação diária e quando você deseja que os usuários recebam notificações. Use menções em comentários para:

- Inicie uma conversa ou peça feedback.
- Atribuir tarefas às pessoas.
- Enderece comentários a pessoas específicas.

### Executar comandos de menção específica

:::tip
Ao pesquisar nomes de usuário, digite quatro ou mais caracteres para obter melhores resultados.
:::

**Mencione-se**

Para se mencionar, digite @ seguido de **seu nome**. Isso é útil para:

- Atribua tarefas a si mesmo.
- Destaque sua participação em uma tarefa ou conversa.
- Defina lembretes para você mesmo nas notificações (isso funciona apenas para comentários).

**Mencionar um usuário específico**

Para notificar uma pessoa específica, digite @ seguido pelo **nome do usuário**. Por exemplo, você pode usar isso para:

- Peça a um editor para fornecer mais detalhes.
- Passe seu trabalho para revisão por um membro do time assim que terminar.
- Consulte um especialista do seu time em um campo no qual você está trabalhando atualmente.

:::note
Se o nome de um usuário não estiver listado ao tentar mencioná-lo em um comentário, você deve convidá-lo para o board via e-mail, ou para o time (se o board for [compartilhado com o time](../sharing-boards/03-sharing-boards-and-inviting-collaborators.md)), ou para o projeto (se o board pertencer a um [projeto](../sharing-boards/16-projects.md)).
:::

**Mencionar todos no board**

Para notificar todos que têm acesso ao board atual, digite **@board**. Considere usar isso para:

- Peça a opinião de todos os participantes no board.
- Solicite feedback após uma reunião realizada no board.
- Comunique atualizações significativas relevantes para todos no board.

Uma menção **@board** não inclui os membros do seu projeto ou membros do time se o board não for compartilhado com eles diretamente ou através do compartilhamento de projeto/time que lhes dá acesso a esse board específico.

**Mencionar membros do projeto**

Para notificar todos os membros de um [**projeto**](../sharing-boards/16-projects.md) específico, digite **@project** (se o board fizer parte de um projeto). Isso pode ajudá-lo a:

- Peça atualizações de status do projeto aos membros do projeto.
- Atualizar o time de um projeto sobre uma mudança nos prazos.
- Apresente um novo membro do time que está trabalhando em uma parte específica do projeto.

:::tip
Você pode combinar **@project** e menções diretas para obter insights de um time multifuncional.
:::

**Mencionar membros do time**

Para notificar todos os membros do seu time, digite **@time**. Use isto para:

- Convide todos do time a comentar sobre uma estratégia geral.
- Colete feedback sobre uma estrutura organizacional ou plano de ação de processo.
- Peça a participação de todos durante as sessões de ideação em todo o time.

### Seguir tópicos de comentários para atualizações

Para se manter atualizado sobre as respostas a um comentário, você pode seguir seu tópico. Você pode fazer isso seguindo estas etapas:

1. Localize o comentário que você quer seguir.
2. Clique no ícone **Seguir a conversa** no canto superior direito do comentário.

![The 'Follow thread' icon on a comment in Miro.](../../../../../../docs/using-miro/facilitation-tools/images/21017416358290_start%20following%20a%20thread.jpg)*Seguindo uma conversa*

:::tip
Passe o mouse sobre o nome de um usuário em uma menção ou comentário para ver seu cartão de perfil de usuário.
:::

## Informações adicionais sobre menções

Esta seção fornece mais detalhes sobre funcionalidades de menção específicas e restrições.

### Mencionar capacidades e restrições

:::warning
Por razões de segurança, [Convidados](../sharing-boards/07-collaboration-with-guests.md) podem encontrar e @mencionar somente usuários que foram diretamente convidados para o board. [Visitantes](../sharing-boards/08-collaboration-with-visitors.md) não podem mencionar outros usuários.
:::

### Recurso de menções sugeridas

> **Planos:** Business, Enterprise, Education

Quando você digita **@** na barra de comentários, a Miro pode mostrar uma lista de menções sugeridas. Esta lista inclui usuários que você mencionou antes e que atualmente têm acesso ao board.

Se a [privacidade do time](../../enterprise-administration/managing-enterprise-teams-and-content/11-manage-team-privacy-and-discovery-on-enterprise-plan.md) estiver habilitada no plano Enterprise, somente usuários dentro do mesmo time serão sugeridos.
