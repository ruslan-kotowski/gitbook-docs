As automações ajudam a otimizar seus fluxos de trabalho de gerenciamento de produtos executando automaticamente ações com base em gatilhos específicos. Configure regras para categorizar feedback, atualizar status de funcionalidades, enviar notificações e gerar relatórios sem intervenção manual.

As automações economizam tempo e garantem consistência ao:

- **Categorizar automaticamente** feedbacks e solicitações de funcionalidades recebidas.
- **Gerar relatórios periódicos** e resumos para stakeholders.
- **Atualizar status** baseados em critérios pré-definidos.
- **Enviar notificações** quando eventos importantes ocorrerem.
- **Analisar tendências** e fornecer insights em intervalos programados.

## Criando uma nova automação

1. Navegue até **Automações** na barra lateral esquerda.
2. Selecione **Criar automação**.
3. Configure sua automação:
   - **Título**: Dê à sua automação um nome descritivo.
   - **Prompt**: Defina o que a automação deve fazer. Por exemplo, "Liste os 5 itens mais frequentemente relatados".
   - **Destinos**: Escolha para onde os resultados devem ser enviados. Atualmente, você pode enviar resultados para o **Slack**.
   - **Agenda**: Defina quando a automação será executada (manualmente ou agendada).
   - **Tag**: Adicione tags para organizar as automações.
4. **Salvar Rascunho** para revisar mais tarde, ou **Criar Automação** para ativar imediatamente.

### Opções de agendamento

Escolha a execução manual quando precisar de insights específicos. Perfeito para análises ad-hoc e relatórios únicos.

Escolha agendamentos regulares:

- **Diário**: Para métricas críticas e monitoramento de questões urgentes.
- **Semanal**: Para atualizações regulares da equipe e relatórios de progresso.
- **Mensal**: Para análise de tendências mais amplas e revisões estratégicas.

## Gerenciando automações

Após criar as automações, você pode gerenciá-las na página principal de Automações.

### Visualizar detalhes da automação

Cada entrada de automação exibe informações-chave de forma resumida:

- **Título** da automação.
- **Solicitação** mostrando a tarefa ou consulta específica.
- **Destinos** onde os resultados são entregues.
- **Frequência** indicando com que frequência ela é executada.
- **Status** indicando se está "Ativa", "Pausada" ou "Rascunho".
- **Proprietário** indicando quem a criou.
- **Data de criação** para acompanhamento.
- **Tags** para organização.
- **Última execução** indicando a hora mais recente de execução.

### Controlar a execução de automações

Você tem várias opções para gerenciar cada automação. Para gerenciar uma automação:

1. Clique no **Título** da automação para abrir seus detalhes.
2. Use os seguintes controles:
   - **Disparar agora**: Execute uma automação imediatamente, independentemente do cronograma.
   - **Pausar automação**: Pare temporariamente uma automação.
   - **Ativar automação**: Reative uma automação pausada.
   - **Editar**: Modifique as configurações e configurações da automação.

### Excluir automações

Para remover uma automação:

1. Clique no **Título** da automação para abrir seus detalhes.
2. Selecione o menu de três pontos no canto superior direito.
3. Escolha **Excluir** e confirme a ação.

## Tipos de automações

As automações podem servir a diversos propósitos, dependendo de suas necessidades. Aqui estão alguns exemplos comuns.

### Automações de relatórios

Gerar resumos e insights regularmente:

- "Liste os 5 itens mais frequentemente reportados de problemas ou bugs"
- "Identifique as 5 funcionalidades mais solicitadas, classificadas por frequência"
- "Liste todas as iniciativas de produto ativas, ordenadas por status"

### Análise de automações

Forneça análise de dados contínua:

- "Liste as 10 empresas com o maior volume de feedback"
- "Analise o feedback dos clientes que descrevem dificuldades"
- "Resuma todas as entrevistas e feedbacks dos clientes dos últimos 60 dias"

### Monitoramento de automações

Acompanhe métricas e mudanças importantes:

- "Detectar risco de churn com base nos padrões de feedback dos clientes"
- "Monitorar análise de lacunas competitivas para funcionalidades mencionadas com frequência"
- "Acompanhar o progresso das iniciativas e destacar qualquer bloqueio"
