Os Admins da empresa e admins com os privilégios necessários agora podem criar e gerenciar funções personalizadas de acordo com as necessidades específicas de cada organização. Esta funcionalidade otimiza o controle sobre o gerenciamento de usuários, a segurança e o ciclo de vida do conteúdo, oferecendo privilégios personalizáveis. Os admins podem atribuir, atualizar ou remover funções de admin personalizadas com eficiência, conforme necessário, garantindo o alinhamento com os fluxos de trabalho da organização. Os principais benefícios das funções de admin personalizadas incluem:

- **Flexibilidade:** configure as funções de admin personalizadas para atender a diversas necessidades administrativas.
- **Escalabilidade:** faça ajustes conforme a demanda e o crescimento da sua organização.
- **Segurança aprimorada:** atribua privilégios específicos para garantir a integridade e a conformidade dos dados.
- **Facilidade de uso:** interface intuitiva para criação e gerenciamento de funções.

## Criar função de admin personalizada

:::note
Para criar uma função de admin personalizada, você deve ser Admin da empresa ou admin personalizado com privilégios para visualizar, editar e atribuir funções de admin.
:::

1. Vá para seu [console de admin](https://miro.com/app/settings).
2. No painel à esquerda, em **Usuários**, clique em **Funções de admin**.
3. Na parte superior direita da página **Funções de admin**, clique em **Criar função**.
4. Na página **Inserir detalhes**:
   a. No campo **Nome da função**, insira um nome exclusivo e descritivo para a nova função de admin personalizada que deseja criar. O nome da função deve conter no máximo 60 caracteres. e deve ser diferente dos outros nomes de funções personalizadas de uma organização.
   b. No campo **Descrição da função**, insira uma descrição que permita aos outros admins entender o papel dessa função personalizada. A descrição da função deve conter no máximo 120 caracteres.
   c. Clique em **Próximo**.
5. Na página **Definir privilégios**:
   a. Marque a caixa de seleção para cada privilégio que deseja habilitar para esta função personalizada. Se quiser selecionar todos os privilégios de uma categoria específica, clique em **Selecionar todos**.
   b. Clique em **Próximo**.
6. Na página **Atribuir usuários**:
   a. Marque a caixa de seleção ao lado de cada usuário para quem deseja habilitar esta função personalizada. Você também pode usar a barra de pesquisa para buscar na lista por nome, e-mail ou domínio.
   b. Clique em **Próximo**.
7. Na página **Revisar**:
   a. Confira todas as informações desta função personalizada para garantir que os detalhes, privilégios e usuários estejam corretos.
   b. Se os detalhes da função personalizada estiverem corretos, clique em **Criar função**.
   Se quiser fazer alterações após conferir os detalhes da função personalizada, clique no botão **Anterior**, faça as atualizações necessárias e revise os detalhes da função personalizada novamente.

   Após a criação, a função personalizada aparece na lista de funções de admin e será marcada com uma tag PERSONALIZADA.

:::note
Se um usuário perder a função de membro da ORGANIZATION_INTERNAL_USER ou ORGANIZATION_INTERNAL_ADMIN na organização, também perderá todas as funções personalizadas ou predefinidas associadas.
:::
