Atribuir funções predefinidas de admin é uma maneira fácil de conceder privilégios a outro usuário da sua organização. Cada função de admin corresponde a um ou mais privilégios que, juntos, permitem realizar funções específicas da Miro.

Atualmente, oferecemos quatro funções predefinidas de admin no nível da organização: Admin da empresa, admin de usuário, admin de conteúdo e admin de segurança.

A tabela a seguir mostra os privilégios associados a cada função.

:::note
Esta lista de funções e privilégios está em constante evolução. Consulte esta página periodicamente para ficar por dentro das atualizações.
:::
