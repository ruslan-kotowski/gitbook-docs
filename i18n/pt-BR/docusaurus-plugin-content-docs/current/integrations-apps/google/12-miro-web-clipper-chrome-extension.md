:::note
O Miro Web Clipper não estará mais disponível para instalação nem será mantido a partir de 1 de fevereiro de 2026. Para os usuários que já o instalaram, ele permanecerá funcional "como está".

Você pode adicionar capturas de tela ao Miro carregando imagens, colando do clipboard ou arrastando para o canvas.
:::

Capture páginas da web enquanto estiver no Chrome e salve-as na sua biblioteca Miro com o mínimo de esforço possível!

### Usando a extensão

1. Sempre que quiser salvar uma captura de tela de um site diretamente na sua biblioteca no Miro, clique no **ícone do Web Clipper** no seu Chrome para abrir a extensão e escolha um **time** onde a captura de tela será armazenada e a área que deseja salvar: **Área visível**, **Área selecionada** ou **Página inteira**.

![Web_clipper_menu.jpg](../../../../../../docs/integrations-apps/google/images/21016020037138_Web%20clipper%20menu.jpg)
*Menu do Miro Web Clipper*

2. Quando estiver pronto para adicionar as páginas da web salvas a um board do Miro, abra o board. Note que o board deve pertencer ao time que você selecionou ao tirar a captura de tela.

3. Na barra de Criação, selecione **Ferramentas, Mídia e Integrações** (**+**)**.** Um painel será aberto. Na guia **Ferramentas**, procure por Web Clipper. Selecione **Upload** e, em seguida, selecione **Web Clipper**.
Uma galeria de capturas de tela salvas será exibida. Você pode clicar ou arrastar as que precisar e soltá-las no seu board.

![Miro_web_clipper.gif](../../../../../../docs/integrations-apps/google/images/21016020034962_Miro%20web%20clipper.gif)
*Web Clipper na barra de ferramentas*

Observe que você pode aproveitar ao máximo o Miro Web Clipper se:

- Você está logado no seu perfil Miro (você sempre saberá que está conectado se o ícone da extensão estiver ativo)
- Após instalar a extensão, atualize as páginas dos boards se estiverem abertas (necessário apenas uma vez)

:::warning
O Web Clipper não funciona em páginas que exigem autorização.
:::

### Perguntas frequentes

1. *Salvei uma captura de tela, mas ela não aparece na biblioteca do Web Clipper. Por quê?*
   - Verifique se escolheu o time correto ao salvar a captura de tela. A captura pertencerá à biblioteca do Web Clipper nos boards localizados nesse time.
   Lembre-se também de que a extensão não funciona em páginas que exigem autorização.
   Se a extensão não funcionar em nenhuma página, tente **removê-la e instalá-la** novamente.
