Se você encontrar um problema ao instalar ou usar o [Cartão do Jira](https://help.miro.com/hc/articles/360017572434) ou [Complemento do Jira](https://help.miro.com/hc/articles/360017572414-Jira-Add-on), este guia pode ajudar.

## Sugestões para Cartões do Jira

| **Mensagem** **/ problema** | **Causas possíveis e etapas para resolver o** **problema** |
| --- | --- |
| **Conexão** | |
| Aplicável apenas ao OAuth 1.0. (Jira Server e Data Center).  **Jira não está conectado** erro ao tentar conectar o Miro com suas credenciais pessoais.  **Não foi possível adicionar cartões do Jira** pop-up ao tentar usar o aplicativo de cartões do Jira em um board  mceclip0.png | O aplicativo de cartões do Jira está instalado, mas o seu time no Miro não está conectado ao Jira.  Por favor, siga este guia de instalação: [Como configurar e desinstalar cartões do Jira.](https://help.miro.com/hc/articles/360019501754-How-to-set-up-and-to-uninstall-Jira-Cards) Se você não é o admin do time, peça para o admin fazê-lo. |
| **Solicitação para o Jira ... falhou: Ocorreu um timeout / Host desconhecido / Conexão recusada** | O Jira é acessível apenas na sua intranet (você está utilizando os endereços IP errados para se comunicar com o sistema Jira).  Certifique-se de [**incluir em sua lista de permitidos** nosso endereço IP, domínios e subdomínios](https://help.miro.com/hc/articles/360017572694-Add-Miro-to-Allowed-Domains) para fornecer à nossa integração o nível de acesso necessário.   Se você estiver usando o Jira Server e uma versão mais antiga, verifique se não há [funcionalidades ocultas](https://confluence.atlassian.com/jirakb/how-to-manage-dark-features-in-jira-959286331.html) que bloqueiem o acesso da Miro. |
| Aplicável apenas ao OAuth 1.0. (Jira Server & Data Center).  **Link de aplicação no seu Jira não está configurado corretamente** | - Você pulou algumas etapas na configuração do link ou do webhook  - Você instalou o [complemento do Jira](https://help.miro.com/hc/articles/360017572414-Jira-add-on) em vez de configurar o link para cartões do Jira.  Tente [instalar a integração dos cartões do Jira](https://help.miro.com/hc/articles/360019501754) do zero.   Se você optou por criar o webhook manualmente, tente criá-lo automaticamente. |
| Aplicável apenas ao OAuth 1.0. (Jira Server e Data Center).  **O link do aplicativo na sua instância do Jira não está configurado corretamente, ou o token expirou. Verifique o link do aplicativo e reconecte a integração.** | - O link de Aplicativo no Jira foi reconfigurado  - O token expirou  - O token foi revogado  Certifique-se de que o link de Aplicativo está configurado corretamente e tente **Conectar** o Miro aos cartões do Jira novamente.  Se você estiver usando um Jira altamente protegido ou estiver usando um proxy, tenha certeza de [**permitir na lista de permissões** nosso endereço IP, domínios e subdomínios](https://help.miro.com/hc/articles/360017572694-Add-Miro-to-Allowed-Domains) para fornecer à nossa integração o nível de acesso necessário.   Se você estiver no Jira Server e em uma versão mais antiga, verifique novamente se nenhuma [Funcionalidade Oculta](https://confluence.atlassian.com/jirakb/how-to-manage-dark-features-in-jira-959286331.html) está bloqueando o acesso para a Miro. |
| Aplicável apenas ao OAuth 1.0. (Jira Server e Data Center)  Seu link de aplicativo pede mais valores além de apenas URL, Chave do Consumidor, Nome do Consumidor, Chave Pública | Você está visualizando a guia **Autenticação de Saída** do menu de configuração.  - Mude para a guia **Autenticação de Entrada**. A **Autenticação de Saída** não requer configuração.  - Se não puder pular esta etapa, adicione *qualquer* valor temporário. Você poderá removê-los depois: ao acessar a página com a lista dos seus **links de Aplicação**, clique em **Editar** o link Miro Cards e remova os valores temporários. |
| Aplicável apenas ao OAuth 1.0. (Jira Server e Data Center).  **URL do Jira não é válida /**  **Digite a URL base do Jira /**   **Erro na solicitação. Desserialização.** | Seu Jira está em uma rede privada / o firewall da sua empresa bloqueia conexões de rede externas.  [Adicione nossos endereços IP do Gateway NAT (e portas) à sua lista de permitidos](https://help.miro.com/hc/articles/360017572694-Add-Miro-to-Allowed-Domains).   *Note que se você verificar nossos endereços IP usando nslookup, os resultados retornarão os endereços do nosso balanceador de carga, que podem variar e mudar ao longo do tempo. |
| Você usa um proxy / Seus URLs externos e internos do Jira não coincidem.  Certifique-se de preencher o campo **Jira URL** com o endereço ao qual podemos acessar. Portanto, configure um proxy reverso que nos permita acesso e/ou  siga as etapas deste [guia da Atlassian](https://confluence.atlassian.com/jirakb/configure-jira-server-to-run-behind-a-nginx-reverse-proxy-426115340.html). Com esta solução, a integração poderá conectar e encaminhar pedidos com sucesso entre seu Jira e a Miro se seus URLs Externo e Interno forem diferentes.   Você também pode [prolongar o valor do tempo limite no seu servidor proxy.](https://help.miro.com/hc/articles/360017572694-Add-Miro-to-Allowed-Domains)  A lista de endpoints pode ser encontrada aqui: [Perguntas frequentes sobre cartões do Jira](https://help.miro.com/hc/articles/360013463739-Jira-Cards-FAQ) |
| Há um problema com seu certificado SSL (certificados autoassinados não são suportados).  Verifique o certificado SSL ativo no servidor Jira. [Esta ferramenta](https://www.ssllabs.com/ssltest/) pode ser útil: insira seu URL do Jira e veja os resultados da verificação da conexão. Por exemplo: o certificado pode estar correto (o **Certificado**em verde), mas a cadeia de certificados do servidor pode estar incompleta (**Troca de chave** em amarelo), portanto, nosso sistema recebe uma resposta de que o certificado precisa ser atualizado. Consulte [este site](https://whatsmychaincert.com/) para resolver problemas. |
| Seu Jira está sob logon único (também pode resultar no erro **A autenticação de entrada não está configurada corretamente**).  Certifique-se de que seu processo de logon único não seja aplicado às solicitações de conexão da nossa integração. Para isso, os seguintes endpoints devem ser excluídos dos processos de logon único:   ``` GET \{JIRA_URL\}/rest/api/2/serverInfo (OAuth 1.0) POST \{JIRA_URL\}/plugins/servlet/oauth/request-token (OAuth 1.0) POST \{JIRA_URL\}/plugins/servlet/oauth/access-token (OAuth 2.0) POST \{JIRA_URL\}/plugins/servlet/oauth2/* ``` |
| Comportamento inesperado durante a instalação | Você está usando versões do Jira 6.4 ou inferiores.  Nossos cartões não funcionarão com essas versões devido a [este erro no Jira](https://jira.atlassian.com/browse/JRASERVER-42811). Por favor, atualize seu Jira para a versão mais recente. |
| **Falha na autorização do aplicativo. Tente autorizar o aplicativo novamente.** | 1. Perda momentânea de conexão. Clique em **Conectar** novamente.  2. Token expirado sendo enviado durante o procedimento de autorização. Limpe os dados em cache, comece com um ambiente totalmente novo. Em outras palavras, estimule o Jira para gerar um novo token. |
| Aplicável somente para OAuth 1.0. (Jira Server & Data Center).  **Erro do Jira: "Você não tem permissões para criar o Webhook 'Miro'."** | Você não tem direitos de Admin no Jira. Por favor, peça ao seu admin do Jira para atualizar sua função para Admin para que você possa configurar a integração. |
| **Solicitação para o Jira falhou: a construção do caminho PKIX falhou: não foi possível encontrar um caminho de certificação válido para o destino solicitado** | Há algum problema com o seu **certificado de servidor**.     Como uma **solução**, sugerimos que você entre em contato com seu Departamento de TI e peça para verificarem os certificados do seu lado (recarregar os servidores web; garantir que os certificados sejam de confiança pública, etc.). |
| **Incapacidade de autorizar no Jira via Miro.  Erro: exceções  (e.g. io.netty.handler.timeout.ReadTimeoutException)** | Isso pode ocorrer devido a uma configuração incorreta da infraestrutura do Jira, quando a configuração da infraestrutura indica suporte para o protocolo HTTP/2, mas nenhuma transferência de dados ocorre ao tentar usá-lo. Verifique as configurações de HTTP/2 nos arquivos de configuração do servidor web para garantir que estejam configuradas corretamente.  Se necessário, desabilite temporariamente o suporte para HTTP/2 na configuração do seu servidor para garantir compatibilidade retroativa e serviço ininterrupto até que o problema seja resolvido. |
| **Trabalhando com cartões** | |
| Os cartões do Jira não estão atualizando | Aplicável apenas para OAuth 1.0. (Jira Server & Data Center).  Você está usando um webhook manual.  Por favor, desabilite a integração e reconecte-a usando um **webhook automático**. Se tudo estiver funcionando bem com um webhook automático, isso significa que um manual foi configurado incorretamente.  Consulte também [Como Configurar um WebHook para Cartões do Jira.](https://help.miro.com/hc/articles/360017731113-How-to-Set-Up-WebHook-for-Jira-Cards?source=answerbot) |
| Aplicável a OAuth 1.0 e OAuth 2.0 (Jira Server & Data Center).  Se você estiver usando um webhook automático, o primeiro passo para solucionar problemas é reconectar a integração. Se isso não ajudar, pode haver várias razões pelas quais os cartões do Jira não estão mais atualizando. Por exemplo:  - um board da Miro foi movido ou baixado via backup para um time diferente  - itens do Jira foram movidos de um projeto para outro no lado do Jira  - você não tem acesso aos projetos onde os itens do Jira estão localizados  - (Enterprise apenas) o titular do board está desativado ou possui uma licença gratuita limitada  - (Somente OAuth1.0) os cartões do Jira não estão localizados na mesma instância do Jira que você está usando atualmente em seu navegador |
| Aplicável somente a OAuth 1.0. (Servidor Jira & Data Center).  Os cartões do Jira pararam de atualizar sem qualquer alteração de sua parte e, ao tentar reconectar, o **link da aplicação no seu Jira não está configurado corretamente.** | A mensagem de erro pode aparecer quando a Miro não consegue acessar um Jira conectado devido a um *erro de autorização*. Isso pode ocorrer se o usuário que configurou a integração *revogar o token* ou se o Jira estiver de alguma forma *configurado para que o token emitido tenha uma curta duração*, tornando-se simplesmente inválido após esse tempo e necessitando ser reconectado para obter um novo token de autorização válido com o qual a Miro acessa o Jira. |
| A opção **Editar cartão** retorna uma janela em branco | Aplicável apenas ao OAuth 1.0. (Jira Server e Data Center).  Você usa Jira ver. 7.6 e superior.  Por motivos de segurança, a Atlassian pode não permitir que o conteúdo seja incorporado em iFrames, o que também pode afetar as janelas pop-up para editar seus cartões do Jira. Você pode usar [estas instruções](https://confluence.atlassian.com/jirakb/security-headers-in-jira-939919914.html) como uma solução alternativa. |
| Não é possível adicionar cartões do Jira | Aplicável apenas ao OAuth 1.0 (Jira Server & Data Center).  Você criou um Webhook manual e não salvou as informações de configuração.  Verifique se o campo **Jira URL** está preenchido nas [Configurações do Miro](https://help.miro.com/hc/articles/360019501754-How-to-set-up-and-to-uninstall-Jira-Cards#Step_2_-_Connection). Certifique-se de clicar em **Conectar** |
| O ícone **Editar** não é exibido | Aplicável apenas ao OAuth 1.0 (Jira Server & Data Center).  Você usa versões do Jira Server 7.6 ou superiores.  O ícone de edição pode não ser exibido devido a uma atualização de segurança nesta versão. |
| Seu perfil não tem permissão para editar o item do Jira em questão.  Verifique se você consegue acessar o modo de edição abrindo o item no lado do Jira. |
| Você recebe a mensagem: *Você não está logado e não possui as permissões necessárias para atuar no item selecionado como convidado. Por favor, faça o login* | Devido à forma como nossa integração utiliza cookies, seu Jira pode não permitir que você faça login a partir desta página.  Faça login no Jira em outra guia do navegador.  Certifique-se de que cookies de terceiros estão permitidos em seu navegador. |
| Seu Jira está sob logon único e seu provedor de identidade não permite autenticação via iframes.  Se você estiver usando o aplicativo para desktop da Miro, recomendamos alternar para a versão do Miro no navegador em [miro.com](https://miro.com/app/). |
| Sem opção para converter/criar um cartão do Jira na Miro ao escolher alguns projetos específicos:  - nenhum dado no campo do tipo de item  - o botão Converter/Criar está inativo  mceclip0.png | Você não tem acesso ao Projeto no Jira. Verifique se você pode obter acesso. |
| **Incapaz de criar item do Jira** ao tentar converter/criar um novo cartão do Jira:   mceclip3.png | Você não tem permissão para criar itens do Jira.  Por favor, entre em contato com seu admin do Jira e peça para ele conceder a permissão necessária no lado do Jira. É assim que deveria parecer:  mceclip2.png |
| Alguns campos personalizados não são exibidos no **Converter para item do Jira/Editar item do Jira** menu  **Não é possível criar item do Jira. Campos obrigatórios (...) não são suportados**erro ao criar um item do Jira dentro da Miro | Os campos não estão habilitados no seletor de cartões do Jira no board.  Use o nosso seletor de Jira no aplicativo para configurar campos personalizados seguindo os passos deste [guia.](https://help.miro.com/hc/articles/360017572434#attributes) |
| Se a **Seleção de campos para exibir nos cartões** não mostra campos personalizados do seu Jira, é possível que algumas das [Telas](https://confluence.atlassian.com/adminjiracloud/defining-a-screen-776636475.html) configuradas para os projetos de sua instância do Jira estejam ocultando os campos da Miro.  Vá para *Configurações do projeto > Telas > Esquema de Tela Padrão* e verifique se os campos necessários estão permitidos. |
| A Miro não oferece suporte para campos de tipo de dados complexos.  A Miro oferece suporte a campos personalizados básicos, mas não a campos complexos. [Configure campos do cartão do Jira](https://help.miro.com/hc/articles/360017572434#attributes) e remova aqueles que não são compatíveis. |
| Você não pode escolher o **Reporter** ao editar/criar um cartão do Jira | Não há campo **Reporter** nos metadados da **Criação** do Jira: o campo está indisponível na **tela de Criação** do Jira [para o projeto selecionado.](https://confluence.atlassian.com/adminjiracloud/defining-a-screen-776636475.html)  Vá para *Configurações do projeto > Telas* e verifique se o campo **Reporter** está presente na tela de **Criação**. |
| Você não tem a permissão necessária para definir o repórter para itens no projeto selecionado. Para isso, ele precisa se inscrever no Jira > ir para *Configurações* > *Itens* > *Esquemas de permissão* > e verificar o campo **Modificar Repórter** (por favor, adicione o **Acesso à aplicação**: **Qualquer usuário conectado** caso você não tenha isso na lista): mceclip0.png |
| O campo do item ‘reporter’ não pode ser editado para manter a trilha de auditoria e é definido por quem criou o item.  A indisponibilidade do campo é o comportamento esperado. |

| Aplicável apenas ao OAuth 1.0. (Jira Server e Data Center).  **Erro: Jira não está disponível** nas configurações do aplicativo de cartões do Jira  mceclip0.png | 1. ## Sugestões para complemento do Jira

| **Mensagem / problema** | **Causas possíveis e etapas para resolver o problema** |
| --- | --- |
| **Você não está logado e não tem as permissões necessárias para atuar sobre o item selecionado como convidado. Por favor, faça login** | Infelizmente, devido ao uso de cookies pelo nosso plugin, o Jira não permite que você faça login a partir desta página.  Faça login no Jira em outra guia do navegador. |
| Após clicar no botão **Instalar** na página do complemento, você pode ver o seguinte erro:  hiccup.png | Uma perda momentânea de conexão.  Nesse caso, basta tentar instalar novamente um minuto depois. |
| Durante ou após a configuração do Jira Addon, você não consegue avançar para a próxima página em algum passo | Alguma coisa nos seus cookies ou cache interrompe o processo.  Limpe a memória do seu navegador para o domínio *atlassian.com* e tente novamente. |
| Após a instalação bem-sucedida, os usuários do Jira que *não* estão registrados na Miro veem o menu de login da Miro em vez do board anexado. | Políticas do Jira bloqueiam algumas funcionalidades do plugin.  Infelizmente, esse comportamento é causado pela atualização mais recente da API do Jira e não pode ser corrigido no momento. |
| O Addon não se lembra da sua autorização e continua pedindo para você fazer login toda vez.  Ao tentar adicionar boards a um item do Jira, um seletor de boards mostra um erro "Desculpe, a integração está indisponível". | Os cookies de terceiros estão bloqueados no seu navegador.  Como solução, siga a [instrução](https://uca.edu/it/knowledgebase/allowing-third-party-cookies/#Chrome) sobre como ativar os cookies no seu navegador. Isso ocorre principalmente com Mozilla e Safari devido às suas novas políticas de segurança. Para Safari, [esta solução](https://support.apple.com/en-ke/guide/safari/sfri40732/12.0/mac/10.14) também pode ajudar. |
