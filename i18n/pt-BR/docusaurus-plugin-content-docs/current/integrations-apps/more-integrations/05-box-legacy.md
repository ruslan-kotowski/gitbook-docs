A integração com o Box permite que você use arquivos da sua conta do Box e os adicione aos boards da Miro para discussão e colaboração adicionais. Você pode realizar uma discussão no board, anotar feedback em cima das suas imagens e documentos, mencionar pessoas e iterar mais rápido.

> **Disponível para:** todos os usuários com contas Personal e Enterprise Box
> **Disponível em**: versão para navegador, [aplicativo para desktop](../../getting-started/apps-for-devices/05-desktop-app.md)

### Como instalar o plugin

Para começar a usar o plugin, você precisa instalar o plugin no nível do time e conectar sua conta do Box à Miro. O plugin pode ser instalado a partir do Marketplace ou de um board da Miro.

:::warning
Os usuários que não são admins não podem instalar o aplicativo, se isso não for permitido nas **configurações de Aplicativos e integrações**.
:::

Vá para o [Marketplace da Miro](https://miro.com/marketplace/box/?backUrl=%2Fmarketplace%2F) e clique em **Obter App.** Será sugerido que você escolha um time para instalar o aplicativo. Selecione um time para concluir a instalação.

![install_Box_plugin.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591350930_install%20Box%20plugin.jpg)
*Escolhendo um time para o plugin Box*

Para instalar o aplicativo a partir de um board:

1. Na barra de Criação, selecione **Ferramentas, mídia e integrações** (**+**).O painel **Ferramentas, mídia e integrações** abre.
2. Na guia **Ferramentas**, pesquise por **Uploads**.</span>
3. No painel de **Uploads**, selecione **Box**.

![carregamentos-ponto-de-entrada.png](../../../../../../docs/integrations-apps/more-integrations/images/21537452824210_uploads-entry-point.png)
*Ícone do Box na barra de ferramentas*

Clique em **Obter aplicativo** na janela pop-up e o plugin será instalado para o time.

Para conectar sua conta do Box à Miro, escolha **Box** no menu **Carregar**. Se esta é a primeira vez que você usa o Box com a Miro, verá um menu pop-up pedindo para autorizar sua conta do Box.

![authorize_box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591352338_authorize%20box.jpg)
*Janela de autenticação do Box*

Você também pode conectar ou desconectar uma conta Box na página de [integrações do seu perfil](https://miro.com/app/account/profile/integrations/).

![connect_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591356946_connect%20Box.jpg)
*Conectando Box à Miro*

### Adicionando arquivos

Para adicionar arquivos ao board, abra o menu **Carregar** na barra de ferramentas, clique em **Box**, selecione documentos ou imagens da sua conta Box e clique em **Escolher**.

![adicionando_arquivos_do_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019535297298_adding%20files%20from%20Box.jpg)
*Como adicionar arquivos do Box aos boards da Miro*

Para atualizar seus arquivos no board, clique no botão **Atualizar** em um arquivo.

![atualizar_arquivo_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019535299218_update%20a%20Box%20file.jpg)
*Atualizando arquivos do Box importados para boards da Miro*

### Desabilitar o plugin

Se quiser desinstalar o plugin para um time, vá para as Configurações do time, encontre o Box na seção **Aplicativos e integrações** e clique em **Desinstalar para o time**.

![uninstall_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591362962_uninstall%20Box.jpg)
*Desinstalando Box nas configurações do time*

Para desconectar sua conta Box, vá para a página de [Integrações do perfil](https://miro.com/app/account/profile/integrations/) e clique em **Sair**.

![desconectar_Box.jpg](../../../../../../docs/integrations-apps/more-integrations/images/21019591364498_disconnect%20Box.jpg)
*Como desconectar o Box da Miro*
