Receba notificações do Miro como mensagens de bate-papo dentro do Microsoft Teams (MS Teams). Mantenha-se informado, compartilhe boards e gerencie o trabalho rapidamente sem alternar entre aplicativos.

![](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22451245005458_mceclip0.png)
*Notificações do Miro no bate-papo do Microsoft Teams*

As notificações do Miro permitem que você acompanhe os seguintes eventos diretamente no bate-papo do MS Teams:

- Um board é compartilhado com você
- Um comentar é postado em um board
- Você é mencionado em um comentar
- Você recebe uma solicitação de acesso ao board , que pode aprovar ou rejeitar imediatamente
- Um convidado se inscreve

### Como configurar notificações do Miro no Microsoft Teams

#### Pré-requisitos

Certifique-se de ter o Miro para Microsoft Teams habilitado. Para saber como, consulte [Visão geral do Miro para Microsoft Teams](06-miro-for-microsoft-teams-overview.md).

#### Procedimento

Para adicionar notificações do Miro ao Microsoft Teams, siga estas etapas:

1. No Microsoft Teams, abra um bate-papo com Miro.
2. Na barra de mensagens, digite "Conectar".![](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22452689633554_mceclip1.png)
   **Conectando o Miro ao MS Teams**
3. Selecione**Conectar sua conta Miro**.
   O modal**Instalar e autorizar o "Microsoft Teams"** é aberto em uma aba separada.
4. Selecione a time que você deseja acompanhar.
   ![](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22454855305362_mceclip2.png)
   **Selecionando uma time Miro para rastrear no Microsoft Teams**
5. Selecione**Instalar e autorizar**.
   No seu bate-papo do MS Teams com o Miro, uma mensagem de saudação das notificações do Miro indica que a configuração foi concluída.

   Você configurou com sucesso as notificações do Miro no MS Teams.
   > ✏️ As notificações são apenas para a time Miro selecionada. Para rastrear várias times, você pode repetir as instruções de configuração para cada time que deseja rastrear.

### Perguntas frequentes

**Por que parei de receber notificações da minha time?**

Se você configurou anteriormente as notificações do Miro no MS Teams e parou de recebê-las, repita as instruções de configuração. Se o problema persistir, entre em contato com o Suporte Miro .

**Posso obter um resumo das alterações em uma board da Miro?**

Um resumo das alterações não está disponível no momento nas notificações do Miro no MS Teams. No entanto, esse recurso agora está em nosso backlog.
