Incorpore um board da Miro novo ou existente em uma reunião do Microsoft Teams (MS Teams). Comece a colaborar instantaneamente sem sair da chamada.

## Como adicionar um board da Miro a uma reunião do Microsoft Teams

#### Pré-requisitos

Você deve atender aos seguintes pré-requisitos:

- Você ativou o Miro para Microsoft Teams. Para saber como, consulte [Visão geral do Miro para Microsoft Teams](06-miro-for-microsoft-teams-overview.md).
- Você é um membro da time Miro que possui a board que deseja incorporar.
- Você é o titular ou editor do board que board incorporar.

#### Procedimento

Siga estas etapas:

1. No Microsoft Teams, selecione um time.
2. Selecione o ícone de mais (**+**)
   O modal **Adicionar uma aba** é aberto.
3. Selecione **Miro**.
4. Selecione **Começar**.
   Você será solicitado a efetuar login no Miro caso ainda não tenha efetuado login.
5. Selecione uma board da Miro ou crie uma nova board para incorporar.
   > ✏️ Você deve ter a função de titular do board ou editor do board e ser um membro da time Miro proprietária do board que deseja incorporar.
6. Selecione permissões para qualquer pessoa na incorporação.
   ![Selecionando permissões para incorporar o Miro no Microsoft Teams](../../../../../../../docs/integrations-apps/microsoft/microsoft-teams/images/22476127831698_image.png)
7. Selecione **Salvar**.
   O board incorporado em uma aba é o MS Teams.

   Você adicionou com sucesso um board da Miro a uma reunião do Microsoft Teams.
