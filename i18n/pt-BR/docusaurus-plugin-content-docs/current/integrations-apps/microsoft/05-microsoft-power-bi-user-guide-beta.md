Combine a força colaborativa da Miro com o poder analítico do Power BI. Com os relatórios e painéis do Power BI integrados diretamente aos boards da Miro, seu time pode otimizar os processos de tomada de decisão, visualizar estratégias baseadas em dados e impulsionar o progresso do projeto com clareza e precisão.

- Utilize os dados integrados do Power BI para obter insights em tempo real e tomar decisões informadas.
- Colabore de forma eficaz com o time, atualizando e adicionando gráficos aos boards da Miro com dados do Power BI.

## Como inserir relatórios do Microsoft Power BI na Miro

:::tip
Confirme com seu Admin da empresa se a integração do Power BI foi configurada para sua organização.
:::

1. Acesse o Microsoft Power BI e copie o link do relatório ou painel da barra de endereço do navegador (não do menu Compartilhar, pois não é compatível no momento).
2. Cole o link copiado em qualquer board da Miro.
3. Clique em **Conectar** para autorizar o aplicativo da Miro no Microsoft Power BI.
4. Após a conexão, uma caixa de diálogo será aberta solicitando que selecione os gráficos que deseja inserir. Verifique se a lista corresponde ao relatório original.
5. Clique em **Adicionar todos os gráficos** para inseri-los no board.
6. Os gráficos serão adicionados como imagens ao seu board da Miro.

## Requisitos para inserir dados do Power BI na Miro

Para inserir um relatório ou painel do Power BI em um board da Miro, você deve:

- Fazer parte de um time ou conta da Miro em que a integração do Power BI esteja habilitada.
- Ter acesso ao relatório ou painel do Power BI que deseja inserir.
- Verificar se o board da Miro em que você deseja inserir os dados do Power BI não é compartilhado por um link público.
- Ter um serviço de nuvem do Power BI compatível (SKU do Power BI Premium por capacidade ou SKU de Reserva de Capacidade do Fabric). O serviço em instalação local não é suportado.

## Visualizar e editar dados inseridos do Power BI

Os usuários que têm acesso ao board da Miro com dados inseridos do Power BI podem visualizar esses dados, independentemente da autorização ou do status da licença do Power BI. Isso inclui usuários com permissões para visualizar, comentar ou editar o board.

Se você tiver permissão de edição em um board da Miro com dados inseridos do Power BI, pode atualizá-lo usando a funcionalidade **Atualizar** ou adicionar gráficos usando a funcionalidade **Adicionar gráficos**, mesmo que não tenha acesso ao conteúdo original do Power BI. No entanto, não é possível explorar ou acessar os dados do gráfico original nem alterar os filtros por meio da integração.

## Retenção de dados

Os dados inseridos do Power BI seguem a política padrão de retenção de dados da Miro, aplicada a todos os dados dos clientes. Leia o [Adendo de Processamento de Dados da Miro](https://miro.com/legal/documents/Miro-Data-Processing-Addendum.pdf).

## Solução de problemas

Siga os passos a seguir para solucionar problemas comuns encontrados ao usar a integração do Power BI na Miro.

Problemas de autorização e aprovação de admin

Caso você não consiga autorizar o aplicativo ou seja solicitada a aprovação do admin sem a opção de solicitá-la, fale com seu Admin da empresa para verificar se as solicitações de aprovação estão habilitadas. Se aparecer a janela **Aprovação de admin necessária**, solicite a aprovação através dessa janela.

Problemas de inserção

Se os gráficos não aparecerem como esperado, fale com seu Admin da empresa para verificar se você tem a assinatura certa do Microsoft Power BI.

Verificação de link

Caso faltem itens, verifique o link usado para se certificar de que ele foi copiado diretamente da barra de endereço do navegador.
