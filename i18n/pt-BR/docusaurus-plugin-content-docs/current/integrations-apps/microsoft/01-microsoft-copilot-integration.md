Como Admin da empresa, você pode ativar e aprovar a integração do Microsoft Copilot para times na sua organização Miro.

A integração do Microsoft Copilot permite que você conecte o Copilot como um [recurso de conhecimento](../../using-miro/miro-ai/09-knowledge.md) na Miro. Por exemplo, conecte o Microsoft Copilot para fornecer informações da empresa a Assistente de IA ou fluxos.

Você também pode conectar o Copilot ao chat independente na Miro.

:::note
Para informações sobre como usar um agente Miro com o Copilot no Microsoft Teams, consulte [Agente Miro para Copilot](microsoft-teams/03-miro-agent-for-copilot.md).
:::

Cada membro do time deve ter uma licença do Copilot para usar a integração.

Para ativar a integração do Microsoft Copilot, siga estas etapas:

1. Como Admin da empresa, vá para o **Console de Admin**.
2. Acesse **Apps & integrações** > **Apps** > **Adicionar apps**.
3. Procure e encontre o **Microsoft Copilot**.
   Se não conseguir encontrar o app pelo nome, então procure pelo seguinte ID do cliente: `5531308904693541040`.
4. No perfil do aplicativo, selecione se deseja adicionar o aplicativo para **Todos os times** ou selecione **Times específicos**.
5. (Opcional) Revise a página de permissões. O aplicativo Microsoft Copilot para a Miro é desenvolvido e mantido pela Miro, e não requer permissões especiais.
6. Clique em **Adicionar**.

:::note
Quando um membro do time conecta o Microsoft Copilot como um recurso de Conhecimento pela primeira vez, o membro é solicitado a se autenticar. O membro do time deve ter uma licença do Copilot.
:::
