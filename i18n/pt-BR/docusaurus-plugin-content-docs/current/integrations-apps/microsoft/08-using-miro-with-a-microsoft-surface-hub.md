Use o Miro com seu dispositivo Microsoft Surface Hub para colaboração remota, presencial e híbrida com sua time. Saiba mais sobre como usar o Miro no Surface Hubs abaixo.

O Miro é compatível com os dispositivos Microsoft Surface Hub 84” e 55” e Microsoft Surface Hub 2S 50” e 85”.

:::note
Verifique se você está usando a versão mais recente do Microsoft Edge.
:::

## Maneiras de usar o Miro com o Microsoft Surface Hub

Há duas maneiras de usar o Miro com um Surface Hub:

1. Em um navegador Microsoft Edge
2. Instalando o Windows 10/11 em um Surface Hub e instalando o aplicativo Miro Windows

### Usando o Microsoft Edge

1. Certifique-se de que seu dispositivo Surface Hub esteja executando a **versão mais recente do Windows** ([atualização do Windows 10 Team 2022](https://learn.microsoft.com/surface-hub/surface-hub-2022-update))
2. Inicie o **navegador Microsoft Edge**mais recente. [Aprenda a instalar este navegador em monitores Surface Hub](https://learn.microsoft.com/surface-hub/surface-hub-install-chromium-edge)
   > ✏️ Pode ser necessária permissão de admin para atualizar o Windows ou o Microsoft Edge para as versões mais recentes
3. Agora você poderá fazer login no Miro via miro.com/login. Você também pode usar nossa [experiência de login rápido](../../getting-started/apps-for-devices/10-send-to-display.md) para iniciar as boards da Miro do seu dispositivo pessoal para o Surface Hub ainda mais rápido

### Usando o Surface Hub com o aplicativo Miro para Windows

1. Instalar [o Windows 10/11 no Surface Hub](https://learn.microsoft.com/surface-hub/surface-hub-2s-migrate-os) (em vez do Windows 10 time)
2. Instalar o [aplicativo Miro Windows](../../getting-started/apps-for-devices/05-desktop-app.md)

:::warning
Atualmente, não há nenhum aplicativo Miro Surface Hub disponível para a versão “Windows 10 Team”.
:::
