Dê contexto aos e-mails do Outlook com links expandidos do Miro . Com essa integração, os usuários podem obter mais informações sobre cada link do Miro enviado por e-mail do Outlook.

> **Disponível para:** Todos os planos Miro
> **Disponível em:** Desktop

:::note
Os usuários devem habilitar a integração do Miro com o Microsoft Teams antes de poderem usar a experiência do Outlook. Consulte a documentação do [Microsoft Teams](microsoft-teams/01-miro-for-microsoft-teams-admin-guide.md) para obter mais informações.
:::

## Como funciona o Miro para Microsoft Outlook

O Miro para Microsoft Outlook inclui dois recursos importantes que melhoram a experiência do usuário : desdobramento de links e extensões de mensagens de pesquisa.

Quando os usuários adicionam um link do Miro em um e-mail, o link se desdobra em um cartão adaptável, onde os usuários podem obter mais informações sobre o board , como o título, o titular do board e a hora da última atualização.

![](../../../../../../docs/integrations-apps/microsoft/images/20647652622098_9d5d21ee-76f3-4e99-9740-6095aa310079.png)

*Os links Miro se transformam automaticamente em cartões adaptáveis*

Na área de composição de e-mail, os usuários podem acessar a integração do Miro por meio do menu do aplicativo para procurar um board da Miro, que pode então ser adicionado ao e-mail como um cartão adaptável.

![](../../../../../../docs/integrations-apps/microsoft/images/20647667523090_5d17d2ad-8790-47d0-9b5c-7025ecde97d5.png)

*Os boards podem ser pesquisados ​​e inseridos em e-mails a partir do Outlook*
