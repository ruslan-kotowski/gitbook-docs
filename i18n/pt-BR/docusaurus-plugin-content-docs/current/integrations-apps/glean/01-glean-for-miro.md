Principais funcionalidades

A integração do Glean visa trazer conhecimentos empresariais e públicos diretamente para os fluxos de trabalho da Miro, aprimorando o processo de inovação ao fornecer acesso rápido e eficiente a insights relevantes.

- **Interface baseada em chat:** Interaja com o Glean em uma interface de chat conversacional, permitindo iterar nas respostas e refinar os resultados.
- **Sumários de insights:** Crie sumários de insights relevantes para o seu trabalho com um único clique, melhorando a produtividade e a tomada de decisões.
- **Navegação pelas fontes:** Revise facilmente as fontes utilizadas para gerar informações e navegue diretamente até os dados originais a partir da Miro. Você também pode visualizar e copiar links para as fontes, e arrastá-los e soltá-los no canvas.

## Use a integração do Glean

Depois que a integração for configurada pelo seu admin, você pode começar a usar o Glean dentro dos seus boards no Miro.

1. Na barra de Criação, selecione **Ferramentas, Mídia e Integrações** (**+**).
2. Procure por **Glean**.
3. Se for a primeira vez que você usar o app, selecione **Conectar Glean** para iniciar a autorização.
   Você será direcionado a uma janela de diálogo com a autorização de logon único (SSO).
4. Use a interface baseada em chat para fazer perguntas e encontrar informações nos seus aplicativos conectados do ambiente de trabalho.
   - Aperfeiçoe as respostas do Glean modificando prompts para garantir que o conteúdo gerado atenda às suas necessidades específicas.
   - Vá diretamente para as fontes a partir da interface de chat ou arraste e solte-as diretamente no canvas.
5. Converter a resposta do Glean em um [Miro Doc](../../using-miro/formats/12-docs-in-miro.md) diretamente no seu board. Alternativamente, selecione **Criar com a Miro AI** para gerar [notas adesivas](../../using-miro/essential-tools/14-sticky-notes.md) ou um [diagrama](../../using-miro/formats/diagramming/02-miro-diagrams.md).

Restrições

- Encorajamos você a fornecer feedback para ajudar a melhorar a integração através dos mecanismos de feedback do aplicativo.
- Se sua organização utiliza aplicativos personalizados, você pode usar a [Plataforma para Desenvolvedores da Miro](https://developers.miro.com/) para vincular a Miro ao seu próprio Modelo de Linguagem de Grande Escala (LLM).
